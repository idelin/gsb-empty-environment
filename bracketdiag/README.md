# bracketdiag

为可插入、删除、撤销的文本缓冲提供**增量括号诊断**的 Go 模块。

## 功能

- `Buffer` 支持 `Insert` / `Delete` / `Undo`。
- `FirstError(start, end)` 返回字节区间内**首个**括号错误（位置 + 期待符号 + 实际符号）；
  `Errors(start, end)` 返回区间内全部错误。
- 字符串（`"` `'` `` ` ``）与注释（`//`、`/* */`）内的括号不计；
  转义字符可跨块（行尾 `\` 转义下一行首字符，含换行符本身）。
- 诊断类型：闭括号与栈顶不匹配、多余闭括号、未闭合开括号、未终结字符串/块注释。

## 设计

- **分块**：文本按行切分。每行针对全部 9 种词法进入状态
  （普通 / 三种字符串 / 两种注释 / 三种字符串内转义待续）预计算摘要，
  因此字符串、注释、转义都能自然地跨块传播。
- **可合并摘要**：每份摘要是一个 monoid——未匹配闭括号序列、未匹配开括号栈、
  不匹配错误事件列表。`mergeMonoid` 合并相邻两段：右段的闭括号与左段开栈对消，
  不匹配时记录错误（不弹栈，与朴素扫描恢复策略一致）。
- **增量维护**：摘要中的位置是相对行首的偏移。编辑只重算内容受影响的行
  （`Buffer.Recomputed` 可观察），后续行内容不变、摘要保持有效；
  远处语义变化（如删除开引号）在查询折叠时经由进入状态自动体现。
- **查询**：沿行折叠摘要（每行 O(1) 查表 + monoid 合并），
  汇总不匹配、多余闭括号、未闭合开括号、未终结构造四类候选，按位置排序过滤。

## 验证

`go test ./...`：

- 定向测试：基础配对、字符串/注释屏蔽、跨块转义、远处引号变化、区间查询、
  增量重算行数、撤销。
- 模糊测试：多种子 × 3000 轮随机插入/删除/撤销，每轮将全文及随机区间的
  完整错误列表与独立朴素 O(n) 扫描逐一比对。
- 一致性测试：周期性将增量维护的行索引与摘要同全新构建对比。
