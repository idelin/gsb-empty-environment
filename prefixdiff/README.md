# prefixdiff

输入旧、新两组前缀规则，输出权限**扩大**（expansion）与**缩小**（shrinkage）
的最小不交前缀集合，并用全路径枚举核对结果。

## 规则语义

- 一条路径的有效决策取**最深**匹配前缀的规则；
- 同一前缀（同深度）同时出现 allow/deny 时，**拒绝优先**；
- 无任何规则匹配时取 `-default`（默认 `deny`）。

## 规则文件格式

每行一条，`#` 为注释，`.` 表示根前缀：

```
allow a.b.c
deny  a.b
allow .
```

## 用法

```
go run main.go -alphabet a,b,c -depth 3 -old old.rules -new new.rules \
    [-default allow|deny] [-no-verify]
```

- `-alphabet`：有限字母表（逗号分隔，符号不得含 `.` 或空白）；
- `-depth`：最长路径深度，叶子空间大小为 `|alphabet|^depth`；
- 输出两个前缀集合：expansion（旧拒新放）与 shrinkage（旧放新拒）。

## 最小不交覆盖

对目标叶子集合，前缀 `p` 入选当且仅当 `p` 的子树被目标**完全覆盖**
且其父节点子树未被完全覆盖（"满子树取最顶"）。该覆盖是唯一最小的
不交精确覆盖。

## 验证

`-no-verify` 可关闭。默认对两个集合分别做独立核对：

1. 展开每个前缀到全部叶子，检查叶子集合与目标**恰好相等**；
2. 任意两前缀展开**无重叠**（不交）；
3. 每个前缀满足"满且极大"，即**无冗余**（去掉任何前缀或上卷一层都会
   破坏精确性）。

验证失败时进程以非零码退出。
