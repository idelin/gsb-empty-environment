# refcheck：重复表达式抽取的安全性检查

把重复表达式 `e` 的两次出现 `O1`、`O2` 抽取为 `__t = e`（插入在 `O1` 所属语句之前，
两处替换为 `__t`）之前，静态判定**求值次数、首错、读取版本**是否保持；
拒绝时输出依赖路径。语言含可变变量、函数调用（读/写集合与是否抛错由函数表输入给定）、
短路 `&&`/`||`、条件分支与异常。

## 可观察语义（interp.go）

轨迹事件：效果调用（有写或会抛错，含实参值）、变量写、`print`；结果另含首错（抛错调用名）
与非临时变量终态。纯调用（无写不抛错）不产生事件，其求值次数不可观察。

## 检查规则（check.go，任一不满足即拒绝）

- **C1 求值次数**：`e` 内含写副作用调用 → 提取后该调用求值 2→1 次，写丢失。
- **C2 首错**：`e` 可能抛错时，`O1` 必须是所在语句的首个求值位置，
  否则提升使异常先于语句内之前的求值/事件。
- **C3 读取版本（提升点）**：提升点（语句首）到 `O1` 之间不得写 `reads(e)`。
- **C4 支配性**：绑定语句必须支配 `O2`（不被 if 分支绕过）。
  注意是*语句级*支配：`O1` 本身位于 `&&`/`||` 右侧是允许的——
  纯表达式在语句首多求值一次不可观察。
- **C5 读取版本（两次求值之间）**：`O1` 与 `O2` 之间（含 `O1` 表达式其余部分、
  中间语句、`O2` 表达式之前部分）不得写 `reads(e)`；写可来自赋值或调用。

`reads(e)` = `e` 的自由变量 ∪ 各调用的 `Reads`。拒绝路径示例：

```
拒绝[读取版本改变] 表达式读取 x，两次求值之间存在对 x 的写
  依赖路径:
    -> O1 prog.s0.arg
    -> 写 x @ prog.s1.arg  [调用 f]
    -> O2 prog.s2.arg
```

## 枚举对照（gen.go / main.go / check_test.go）

确定性随机枚举小程序（短路、分支、介于两次求值之间的赋值写/调用写/抛错、纯调用），
对每个用例：检查器给出判定；解释器分别运行原程序与 `Refactor` 后的程序并比较轨迹。
健全性不变量：**接受 ⇒ 轨迹必然相同**。8 个种子 × 20000 用例，0 违反；
拒绝中约 1/3 为真阳性（轨迹确实不同），其余为保守拒绝。

## 运行

```sh
go test ./...   # 定向用例（短路/间写/首错/支配性）+ 20000 例枚举对照
go run .        # 演示各判定情形与依赖路径，并打印枚举对照统计
```
