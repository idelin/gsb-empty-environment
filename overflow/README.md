# overflow

溢出页回收库：大于单页的记录存为溢出页链，更新采用写时复制，回收只删不可达页。

## 设计

- 页 0 为超级块（magic、页大小、页总数、全部记录根指针、CRC32），数据页从 1 开始。
- 数据页头 13 字节：status(1) + next(8) + dataLen(4)，其余为载荷。
- 页归属由 status 字节决定：分配即写入 `USED`，释放即清零为 `FREE`。
  打开时扫描全部页重建空闲表，因此崩溃只会泄漏页（由回收兜底），不会重复分配。

## 更新协议（copy-on-write）

1. 分配并写入完整新链；2. `fsync` 数据页；3. 单页写超级块 + `fsync` 完成根引用原子切换。
任一步失败，旧根仍在超级块中，旧记录不丢；已写出的部分新链成为不可达垃圾页。

## 回收与核对

- `Reclaim`：从所有根出发标记可达页，仅删除不可达页；结构损坏时拒绝释放任何页。
- `Verify`：独立遍历所有链与空闲表，报告环（`cycle`）、页被重复引用（`shared-page`）、
  引用空闲页等坏结构；返回页总账 `Ledger{Total, Free, Reachable, Garbage}` 与全部记录内容的 SHA-256 摘要。

## 测试

```
GOCACHE=/tmp/gocache GO111MODULE=on go test ./...
```

覆盖：更新缩短、空载荷、根切换后重启、写失败注入（链写失败 / 根切换失败）、
共享页与环的坏结构检测、页总账平衡与内容摘要核对。
