# localfmt — 局部格式化工具

只修改选中的语法节点及其附着空白，绝不重排整份文件。
语言范围：四则运算表达式与函数调用，注释（`//` 与 `/* */`）保持归属不变。

## 用法

```sh
go run ./cmd/localfmt -start 19 -end 28 file.expr   # 输出补丁 + 扩区理由 + 验证报告 (JSON)
go run ./cmd/localfmt -w -start 19 -end 28 file.expr # 输出应用补丁后的全文
```

## 行为

1. **选区扩展**：选区落在 token 中间时先外扩到完整 token 边界；
   若仍不是完整语法节点，再扩到 AST 上最小覆盖节点（理由写入 `rationale`）。
2. **补丁范围**：节点字节区间 + 两侧附着的水平空白（不跨换行），
   附着空白规范化为单个空格。
3. **格式化**：仅重排节点内部 token 的间距（二元运算符两侧各一空格、
   逗号后一空格、调用与括号内无空格、一元负号右紧贴），注释作为 token
   原样保留在原附着位置。

## 验证（每次格式化自动执行）

- 补丁之外的字节逐字节不变；
- 幂等：对输出再次格式化无任何改动；
- 语义不变：原节点文本与格式化结果分别重新解析，AST 结构一致
  （注释夹在运算符两侧时同样成立）。
