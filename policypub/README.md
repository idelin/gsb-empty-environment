# policypub — 原子加密策略发布

隧道服务更新加密策略时，报文在任何时刻只能被**加密（且 SA 已确认安装）或丢弃**，
不存在明文/旁路状态，因此更新过程不会出现短暂明文窗口。

## 组件

- `selector.go` — 双向选择器编译器。规则（本地/远端前缀 + 出/入向 SA 句柄）
  被编译成不可变的二维最长前缀匹配（LPM）查找表：外层按源前缀、内层按目的前缀，
  通过父指针回溯支持重叠/嵌套前缀；入向表在编译时交换源目方向。编译后不再可变，
  可被任意并发读者无锁读取。
- `sa.go` — `Installer` 抽象与内存 SADB。`Install` 私有复制密钥材料，
  `Uninstall` 幂等并对存储的密钥清零。
- `publisher.go` — 两阶段发布：
  1. 编译并校验规则与 SA 的交叉引用（句柄存在、方向一致、无重复）。
  2. 按“全部出向 → 全部入向”的确定顺序安装 SA；任一方向失败即按 LIFO 回滚
     本次已装对象，旧代保持不动。
  3. 所有 SA 确认安装后执行 `SwapBarrier`（可选），再用一次
     `atomic.Pointer.Swap` 原子切换活动代。读者只加载快照指针，无锁。
  4. 切换后退役旧代独有 SA；两代共用的句柄保留。
  - `Decide` 只有 `ActionEncrypt`（且二次确认 SA 已安装）或 `ActionDrop`
    两种结果，无活动策略/无匹配选择器/SA 未安装一律丢弃。
- `driver.go` — 可暂停驱动 `Pausable`：包装任意 `Installer`，在安装前/后、
  交换前、卸载等步骤提供 `Hold`/`WaitHeld`/`Release` 闸门，支持一次性故障注入
  `Fail` 与有序事件审计，用于验证发布过程。

## 验证

```sh
go test -race -count=1 ./...
```

测试覆盖：

- 重叠/嵌套前缀的二维 LPM 优先级（IPv4 与 IPv6，含 `/0` 边界与默认拒绝）。
- 出/入向 SA 全部安装后才交换；失败时 LIFO 回收、旧代继续可用。
- 交换闸门前并发读者：每个敏感流要么用已安装的旧代 SA 加密，要么被丢弃。
- 回滚进行中（卸载闸门保持）敏感报文始终加密或丢弃。
- 旧代退役与回滚路径上的密钥材料清零，以及调用方密钥切片不被改写。
- `-race` 下的并发读者/发布者数据竞争检测。
