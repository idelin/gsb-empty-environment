# msf — 最小生成森林替代边分析

对一张无向整数加权图（允许平行边、自环、非连通）计算最小生成森林（MSF），
并对每条树边给出：移除它之后重新连通该切口的最便宜替代边；不存在时标记
`DISCONNECTED`。

## 规则

- 边按 `(权重, ID)` 字典序比较：权重小者优先，同权按稳定边 ID 决胜。
- 平行边合法；自环永不进入生成森林。
- 图非连通时输出每个连通分量的最小生成树（即生成森林）。

## 输入格式（stdin）

```
n m
id u v w      # 共 m 行；顶点编号 0..n-1，id 唯一，w 为整数（可为负）
```

## 输出格式（stdout）

```
total <MSF 总权重>
edge <树边ID> -> <替代边ID | DISCONNECTED>   # 按树边 ID 升序
```

## 示例

```
$ printf '4 6\n1 0 1 1\n2 1 2 1\n3 2 3 1\n4 0 3 10\n5 0 2 5\n6 1 3 6\n' | go run .
total 3
edge 1 -> 5
edge 2 -> 5
edge 3 -> 6
```

## 算法

1. Kruskal 按 `(w, id)` 排序求 MSF（全序保证结果唯一）。
2. 对森林每棵树定根，记录父指针与父边。
3. 每条非树边 `(u,v)` 恰是树上 u–v 路径中所有树边的替代候选；沿路径上爬，
   对每条树边保留 `(w, id)` 最小的候选。

## 验证

`msf_test.go` 不做局部启发式假设，而是对小图枚举全部生成森林：

- 子集是生成森林 ⟺ 无环且边数恰为 `n - 连通分量数`；枚举取最小总权，与
  算法输出的 MSF 总权对比。
- 对每条树边 `e`：枚举 `G \ {e}` 的全部生成森林得最小总权 `W'`，验证
  `W(MSF) - w(e) + w(替代边) == W'`；同时验证替代边确实跨越 `e` 所定义的
  切口、且是所有跨切口边中 `(w, id)` 最小者；若 `G \ {e}` 分量数增加则必须
  输出 `DISCONNECTED`。
- 固定用例（三角形、平行边同权决胜、非连通、菱形路径覆盖、自环）外加
  1000 个随机小图（含平行边/自环/负权/非连通/乱序稀疏 ID）。

运行：

```
go test ./...
```
