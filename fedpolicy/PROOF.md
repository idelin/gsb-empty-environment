# 策略投影库的形式化论证

本文档说明 `fedpolicy` 包在路径长度无上限、名称映射为有限状态转导器
（FST）、同一新标识可对应多个旧主体的条件下，如何保证：

1. 投影出的目标策略在任何相容旧身份下都不扩大权限（稳健性 / 非扩权）；
2. 在输入给定的候选（前缀，标签）组合中覆盖所有可安全表示的身份（完备性）；
3. 选出的规则集是规则数最少的等价集合（最小化）；
4. 每条不可迁移候选都附带旧方拒绝的真实主体与映射轨迹，找不到旧前像的目标
   身份必然被拒绝（可取证）。

## 1. 记号与语义

主体是四元组

```
n = (issuer, tenant, path, labels)
```

其中 `path ∈ Σ*` 长度无上限，`labels` 是有限标签集合。命名权威键为
`h = (issuer, tenant)`；同名租户来自不同发行域时 `h` 不同，因此所有规则与
转导通道都以完整的 `h` 作用域，杜绝跨发行域混淆。

旧策略是有序规则表 `(p_i, e_i)`，`p_i` 为绑定到某个权威的路径前缀，
`e_i ∈ {allow, deny}`。对主体 `n` 的判定为

```
V_old(n) = 最后一个满足 p_i 是 n 路径前缀的规则的 e_i；
           无命中时取默认效果（部署中为 deny）。
```

目标策略只有正向允许 `R = {(P, L)}`，`P` 为权威 + 路径前缀，`L` 为公开标签
子集。目标判定为

```
V_new(n) = ∃ (P,L) ∈ R : P 的权威等于 n 的权威
           ∧ path(n) 以 P 的路径为前缀
           ∧ L ⊆ labels(n)。
```

否则默认拒绝。目标侧没有 deny 规则，因此投影结果天然是“白名单 + 默认拒绝”。

名称映射由每个通道上的 FST 给出。每条弧 `(q, a, b, q')` 消费一个输入段 `a`
（`a ≠ ε`），输出 `b`，允许 `b = ε` 表示丢弃该段。允许同一 `(q,a)` 有多条弧，
因此关系 `→_T` 是一对多的；多个通道可以指向同一新权威，天然表达多对一。

## 2. 有界性：为什么无上限路径仍是有限自动机问题

设旧策略最长前缀长度为 `d_p`，标签器（实现 `FinitaryLabeler`）的最大前瞻为
`d_l`，令 `d = max(d_p, d_l)`。

**引理 1（有界尾段充分性）。** 旧判定 `V_old(n)` 与 `n` 的标签集合只依赖于
权威键与路径的最后至多 `d` 个段（对前缀规则而言即路径的前 `d` 个段；分析中统一
保留长度为 `d` 的有界窗口）。

证明：前缀规则 `p_i` 长度不超过 `d_p ≤ d`，是否命中只看路径前 `|p_i|` 个段；
`FinitaryLabeler` 的 `StateKey` 按契约只依赖前 `d_l ≤ d` 个段，且键空间有限。
更深的段不可能改变任何规则命中或标签。∎

乘积配置定义为

```
c = (q, m, x, tail, key)
```

其中 `q` 是转导器状态，`m` 是已匹配的候选前缀长度，`x` 是前缀匹配完成后输出的
有界后缀（长度 ≤ d），`tail` 是输入的有界尾段（长度 ≤ d），`key` 是标签器的
有限状态键。`q`、`m`、`tail`、`key` 取值有限；`x` 被窗口截断到 `d`，也有限。

**引理 2（乘积状态有限）。** 乘积配置集合有限，因此 BFS 在循环转导器上必然
终止，覆盖所有可达的旧路径行为（长度无上限但状态有限）。

完整的旧路径与输出轨迹单独保存在 BFS 父指针上，仅用于重建证人，不进入状态键，
因此既不破坏有界性，也不丢失可解释性。

## 3. 候选安全性与非扩权

对候选 `C = (P, L)`，分析器对所有指向 `P` 权威的通道做乘积 BFS，并在
“转导器处于接受态且候选前缀已完整匹配”的每个接受配置上取证。接受配置对应一个
具体旧主体 `n_old` 及其到某个目标身份 `n_new`（位于 `P` 之下）的映射轨迹。

候选被判定为安全，当且仅当同时满足：

- **标签可表达**：`L` 中每个标签都在目标公开标签集合内；
- **无拒绝前像**：每个接受配置的旧主体满足 `V_old(n_old) = allow` 且
  `L ⊆ labels(n_old)`；
- **无前像缺口**：`P` 之下的目标身份语言包含于转导器输出语言，即不存在无旧
  前像的目标身份。

**定理 1（非扩权 / 稳健性）。** 对任意被投影策略放行的目标身份 `n_new`，存在
相容旧主体 `n_old` 使 `n_old →_T n_new`、`V_old(n_old) = allow` 且目标规则要求
的标签均由 `n_old` 持有。因此目标许可集合中的每一次放行都有旧方依据，权限不被
扩大。

证明：目标放行意味着某条安全规则 `(P,L)` 命中 `n_new`。安全性的“无拒绝前像”
条件遍历了乘积自动机的全部接受配置（引理 2 保证遍历完整且终止），任何映射到
`P` 下身份的旧主体都被检查为允许且标签充分；“无前像缺口”条件保证 `n_new` 至少
有一个这样的旧前像。多对一情形下，只要有一个旧前像被拒绝或缺标签，候选即被否决
并保留该前像为证人，因此合流不会掩盖拒绝。∎

## 4. 前像缺口的可判定性

把 FST 忽略输入后视为输出带上的 NFA：空输出弧成为 ε 弧。其语言正是“存在旧前像
的目标路径集合”。

`findGap` 先用子集构造沿候选前缀确定地推进；前缀消费完时若子集不含任何通道的
接受态，则前缀词本身即缺口。否则按输出字母表做一层符号扩展，对子集去重后继续
BFS。NFA 子集数量有限，状态重复即证明后续扩展永远停留在输出语言内，搜索终止。

**引理 3（缺口完备）。** `findGap` 返回缺口当且仅当候选前缀语言中存在无旧前像
的目标身份；返回无缺口当且仅当整个前缀语言都被输出语言覆盖。

证明：子集构造是 NFA 语言成员判定的标准确定化；接受态检测精确刻画“存在某通道
的某条接受路径”。有限子集空间上的 BFS 既找到最短缺口词，也在状态闭合时给出覆盖
结论。边界证人通过 `shortestPreimage` 在 `(转导器状态, 输出位置)` 的有限 BFS 上
恢复缺口词最长可映射前缀的真实旧主体与轨迹。∎

## 5. 完备性：覆盖所有可安全表示的身份

输入的每个候选都被独立判定。`VerifyCoverage` 在有界完整模型中核验：凡被至少一条
安全候选覆盖的目标身份，必被最终最小策略放行。

**定理 2（候选内完备性）。** 在输入给定的候选组合范围内，任何可安全表示的目标
身份都不会被投影遗漏。

证明：身份 `n` 可安全表示等价于存在安全候选 `C` 使 `n` 落在 `C` 的前缀下且持有其
要求标签。最小化只删除被其余规则包含的规则（见第 6 节），不删除任何身份覆盖；
`VerifyCoverage` 对模型中每个身份直接验证该不变量。模型对字母表上长度
`0..MaxDepth` 的所有路径（含空路径）穷举，配合引理 2 的有限自动机论证，结论延伸到
无界路径。∎

候选集合之外的身份不在“可由给定候选表示”的范围内，默认拒绝正是期望行为。

## 6. 规则数最小的等价集合

规则 `A` 被规则 `B` 包含（`A ⊑ B`）当且仅当二者同权威、`A` 的路径前缀以 `B` 的
路径为前缀，且 `B` 要求的标签集合是 `A` 要求标签集合的子集。此时 `B` 放行的身份
集合包含 `A` 放行集合。

先剔除被其他安全规则包含的冗余规则得到本质集合，再对本质集合按基数递增做穷举组合
搜索（`forEachCombination`），第一个与完整安全集合并集等价的子集即全局最优；规则数
较大时退回带下界剪枝的分支限界，剪枝只丢弃不可能优于当前最优解的分支，最优性不变。

**定理 3（最小性）。** 返回规则集与全部安全候选放行相同的目标身份集合，且规则数
最少。

证明：包含关系是语言包含的精确结构刻画（前缀包含 + 标签子集），故等价判定可靠；
递增基数穷举在找到可行解时，所有更小基数子集均已被证明不可行，因此首个可行解基数
即最小值。测试中再用独立的暴力子集枚举交叉验证该最小值。∎

## 7. 拒绝取证

- `old-deny`：证人是乘积 BFS 找到的最短真实旧主体，含旧规则索引 / 默认效果、缺失
  标签，以及逐段 `TraceStep` 组成的映射轨迹；`traceOutput(trace)` 精确重建目标路径。
- `no-preimage`：证人含最短缺口目标身份，以及到达图像边界的真实旧主体与轨迹；
  无任何通道的权威则以候选前缀本身为缺口证人。
- `non-public-label`：目标主机无法表达该标签，直接拒绝，不产生伪允许。

`VerifyWitnesses` 重放每条证人：`old-deny` 必须确实被旧方拒绝或缺标签且轨迹重建
目标；`no-preimage` 的轨迹必须重建缺口词的严格前缀（边界），缺口词本身无前像。

## 8. 小字母表完整模型核对

`projection_test.go` 在字母表 `{a,b}` 上对长度 `0..3` 的全部路径穷举，显式覆盖：

- **空路径**：空路径主体被枚举与判定，空前缀候选因拒绝前像被否决；
- **多对一映射**：零售侧丢首段转导使多个旧主体合流到同一枢纽身份，任一拒绝前像即
  否决候选并给出轨迹；
- **例外覆盖**：`allow /` → `deny /a` → `allow /a/b` 的最后命中序列验证窄例外可
  投影、宽前缀不可投影；
- **同名租户异发行域**：`team-x` 同时存在于两个发行域，权威键保证跨域身份互不串权；
- 另含非公开标签、缺标签、图像内缺口、无通道权威、循环转导器终止性与长路径稳健性。
