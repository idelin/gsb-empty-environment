# markov-analyzer

有限马尔可夫链分析器：接收有理数转移概率与吸收状态集合，精确求解各状态的
最终吸收（命中）概率与期望吸收步数。全部运算在 `math/big.Rat` 上进行，无浮点误差。

## 输入

JSON（文件路径作为参数，或从 stdin 读取）：

```json
{
  "states": 3,
  "absorbing": [0],
  "transition": [["1","0","0"], ["1/2","0","1/2"], ["0","1","0"]],
  "queries": [1, 2]
}
```

- `transition` 元素为字符串，支持 `"3/4"`、`"0.5"`、`"1e-30"`，一律按精确有理数解析；
- `queries` 为空时查询所有状态。

## 方法

1. Tarjan 强连通分解，无出边的 SCC 即为闭类（单点吸收态 / 非吸收闭类）；
2. 仅在真正的瞬态子集上求解 `(I-Q)X = R`（命中概率）与 `(I-Q)t = 1`（期望步数），
   该子矩阵必非奇异；求解器检测到奇异时返回失败而不是硬解；
3. 能以正概率进入非吸收闭类的状态，期望吸收步数报告为 `+inf`，绝不伪造有限值；
4. 输出每个查询状态可达闭类的 BFS 见证路径作为证据；
5. 独立代回核验：命中概率方程与期望方程残差（精确为 0）、命中概率归一性、
   值域检查、`+inf` 当且仅当吸收概率 < 1。

## 运行与测试

```sh
go run . input.json
go test ./...
```
