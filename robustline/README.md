# robustline — 鲁棒直线拟合器

在 n (≤ 20) 个二维整数点中剔除至多 k 个离群点，求一条直线使其余点的
**最大垂直残差** 最小。直线统一用一般式 `a·x + b·y + c = 0` 表示，
竖直线（b=0）自然被覆盖；全部比较基于 `math/big` 大整数，结果精确。

## 算法

1. 固定法向 `n=(a,b)` 时，投影 `t_i = a·x_i + b·y_i` 为整数；保留
   `m = n−k` 个点的最优是投影排序后长度为 m 的最小窗口，
   误差 `= Δt / (2·|n|)`。
2. 最优直线方向必平行于某两个输入点的连线（临界方向），故枚举全部
   `C(n,2)` 个点对的法向即得全局最优。
3. 候选间比较用 `Δt₁²·|n₂|²` 对 `Δt₂²·|n₁|²` 交叉相乘，无浮点误差。

## 用法

```sh
go build -o robustline .
printf '4 1\n5 0\n5 1\n5 2\n0 0\n' | ./robustline
```

输入：第一行 `n k`，随后 n 行整数坐标 `x y`。
输出：最优直线（约分后的一般式）、最优误差（精确根式 + 小数）、
被剔除点、保留点残差，以及达到最大误差的证据点与最优性说明。
