== 初始装载 ==
  差量 +1  ('Eng', 1, 100)
  差量 -1  ('Eng', 1, 100)
  差量 +1  ('Eng', 2, 250)
  差量 +1  ('Ops', 1, 0)
  视图: {('Eng', 2, 250): 1, ('Ops', 1, 0): 1}

== 插入重复行 e6/e7（连接一侧重数相乘） ==
  差量 -1  ('Eng', 2, 250)
  差量 +1  ('Eng', 3, 350)
  差量 -1  ('Eng', 3, 350)
  差量 +1  ('Eng', 4, 450)
  视图: {('Eng', 4, 450): 1, ('Ops', 1, 0): 1}

== 删除 e4（Ops 组最后支撑行被撤回） ==
  差量 -1  ('Ops', 1, 0)
  视图: {('Eng', 4, 450): 1}

== 删除 e6/e7（重复行逐条撤回） ==
  差量 -1  ('Eng', 4, 450)
  差量 +1  ('Eng', 3, 350)
  差量 -1  ('Eng', 3, 350)
  差量 +1  ('Eng', 2, 250)
  视图: {('Eng', 2, 250): 1}

== 批次交换顺序 ==
  A->B: {('Eng', 2, 280): 1, ('Ops', 1, 80): 1}
  B->A: {('Eng', 2, 280): 1, ('Ops', 1, 80): 1}
  最终视图一致: True

== 错误处理 ==
  重复删除同一行: emp: 行 ID 'e4' 不存在
  重复插入行 ID: emp: 行 ID 'e1' 已存在
  负重数: 元组 ('Ghost', 1, 1) 重数变为负数: 0 + (-1)
