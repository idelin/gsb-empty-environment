=== 例 1：多项式（精确有理数） ===
f(x) = x^3 + (1/3)*x^2 + (-2)*x + 7
自然定义域: ℝ
求导步骤（来源规则 / 适用域）:
   1. [变量法则] d/dx(x): d/dx x = 1    适用域: ℝ
   2. [幂法则] d/dx(x^3): (u^3)' = 3·u^2·u'    适用域: ℝ
   3. [常数法则] d/dx((1/3)): d/dx (1/3) = 0    适用域: ℝ
   4. [复用] d/dx(x): 节点 #2 的导数已缓存，共享子图不重复展开    适用域: —
   5. [幂法则] d/dx(x^2): (u^2)' = 2·u^1·u'    适用域: ℝ
   6. [乘积法则] d/dx((1/3)*x^2): (u·v)' = u'·v + u·v'    适用域: dom(u) ∩ dom(v)
   7. [和法则] d/dx(x^3 + (1/3)*x^2): (u+v)' = u' + v'    适用域: dom(u) ∩ dom(v)
   8. [常数法则] d/dx((-2)): d/dx (-2) = 0    适用域: ℝ
   9. [复用] d/dx(x): 节点 #2 的导数已缓存，共享子图不重复展开    适用域: —
  10. [乘积法则] d/dx((-2)*x): (u·v)' = u'·v + u·v'    适用域: dom(u) ∩ dom(v)
  11. [常数法则] d/dx(7): d/dx 7 = 0    适用域: ℝ
  12. [和法则] d/dx((-2)*x + 7): (u+v)' = u' + v'    适用域: dom(u) ∩ dom(v)
  13. [和法则] d/dx(x^3 + (1/3)*x^2 + (-2)*x + 7): (u+v)' = u' + v'    适用域: dom(u) ∩ dom(v)
共享子图复用次数: 2
化简步骤:
   1. [乘法幺元] 3*x^2*1  ⇒  3*x^2    适用域: dom(左项)，定义域不变
   2. [乘法零元] 0*x^2  ⇒  0    适用域: 在原定义域 dom(被消去项) 上恒等；结果定义域由管线保留
   3. [单位指数] x^1  ⇒  x    适用域: dom(u)，定义域不变
   4. [乘法幺元] 2*x*1  ⇒  2*x    适用域: dom(左项)，定义域不变
   5. [常数合并（结合律）] (1/3)*2*x  ⇒  (2/3)*x    适用域: dom(剩余因子)，定义域不变
   6. [加法零元] 0 + (2/3)*x  ⇒  (2/3)*x    适用域: dom(右项)，定义域不变
   7. [乘法零元] 0*x  ⇒  0    适用域: 在原定义域 dom(被消去项) 上恒等；结果定义域由管线保留
   8. [常数折叠] (-2)*1  ⇒  (-2)    适用域: ℝ（精确有理数乘法）
   9. [常数折叠] 0 + (-2)  ⇒  (-2)    适用域: ℝ（精确有理数加法）
  10. [常数折叠] (-2) + 0  ⇒  (-2)    适用域: ℝ（精确有理数加法）
f'(x) = 3*x^2 + (2/3)*x + (-2)

=== 例 6：x^0 + x^(-2) + x^(1/2)，特殊点语义 ===

求导步骤（来源规则 / 适用域）:
   1. [零指数约定] d/dx(x^0): u^0 ≡ 1（常函数约定，含 u = 0），导数为 0    适用域: ℝ
   2. [变量法则] d/dx(x): d/dx x = 1    适用域: ℝ
   3. [幂法则] d/dx(x^(-2)): (u^(-2))' = -2·u^(-3)·u'    适用域: x ≠ 0
   4. [和法则] d/dx(x^0 + x^(-2)): (u+v)' = u' + v'    适用域: dom(u) ∩ dom(v)
   5. [复用] d/dx(x): 节点 #2 的导数已缓存，共享子图不重复展开    适用域: —
   6. [幂法则] d/dx(x^(1/2)): (u^(1/2))' = 1/2·u^(-1/2)·u'    适用域: x > 0
   7. [和法则] d/dx(x^0 + x^(-2) + x^(1/2)): (u+v)' = u' + v'    适用域: dom(u) ∩ dom(v)
共享子图复用次数: 1
化简步骤:
   1. [乘法幺元] (-2)*x^(-3)*1  ⇒  (-2)*x^(-3)    适用域: dom(左项)，定义域不变
   2. [加法零元] 0 + (-2)*x^(-3)  ⇒  (-2)*x^(-3)    适用域: dom(右项)，定义域不变
   3. [乘法幺元] (1/2)*x^(-1/2)*1  ⇒  (1/2)*x^(-1/2)    适用域: dom(左项)，定义域不变

导数定义域: {x ≠ 0} ∩ {x > 0}
