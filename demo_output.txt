样例 1：未被使用的除零表达式不报错（if 只强制被选中的分支）
====================================================================
源码:
  | let boom = 1 / 0
  | in if false then boom else 42
结果: 42
调试轨迹（强制求值链）:
+-> 强制 thunk '<结果>'  @ 第2行第1字节列: 'let boom = 1 / 0'
<-- thunk '<结果>' 求值完成 = 42

样例 2：同一 thunk 被引用十次，函数体只执行一次（tick 计数为 1）
====================================================================
源码:
  | let x = tick()
  | in x + x + x + x + x + x + x + x + x + x
结果: 10    tick() 真正执行次数: 1

样例 3：强制求值链展示依赖是如何一层层被拉动的
====================================================================
源码:
  | let a = tick() + 1
  | let b = a + 10
  | let c = b + 100
  | c
结果: 112
调试轨迹:
+-> 强制 thunk '<结果>'  @ 第5行第1字节列: 'c'
    +-> 强制 thunk 'c'  @ 第5行第1字节列: 'c'
        +-> 强制 thunk 'b'  @ 第4行第9字节列: 'b'
            +-> 强制 thunk 'a'  @ 第3行第9字节列: 'a'
            * tick() 第 1 次真正执行（位于 thunk 'a'）
            <-- thunk 'a' 求值完成 = 2
        <-- thunk 'b' 求值完成 = 12
    <-- thunk 'c' 求值完成 = 112
<-- thunk '<结果>' 求值完成 = 112

样例 4：异常也是结果，第二次引用命中缓存的同一异常对象
====================================================================
源码:
  | let boom = 1 / 0
  | boom + boom
第一次强制 boom 抛出: 除数为 0（整数除法）
boom 状态: done
第二次强制 boom 抛出: 除数为 0（整数除法）
是否同一个异常对象: True
调试轨迹:
+-> 强制 thunk '<结果>'  @ 第3行第1字节列: 'boom + boom'
    +-> 强制 thunk 'boom'  @ 第3行第1字节列: 'boom'
    <-x thunk 'boom' 缓存异常: 除数为 0（整数除法）
<-x thunk '<结果>' 缓存异常: 除数为 0（整数除法）
|== 命中缓存异常 (thunk 'boom'): 除数为 0（整数除法）

样例 6：间接自引用黑洞，环诊断给出每一环的源码位置
====================================================================
源码:
  | let rec a = b
  | and b = c
  | and c = a
  | in a
自引用黑洞：thunk 'a' 在自身求值完成前又被强制（环: a -> b -> c -> a）
强制求值环（外 -> 内，最后一环回到自身）:
  - a  @ 第5行第4字节列: a
    - b  @ 第2行第13字节列: b
      - c  @ 第3行第9字节列: c
        - a  @ 第4行第9字节列: a  <-- 回到自身，检测到环
