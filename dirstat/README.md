# dirstat

目录容量统计库：为一棵目录树同时维护两类容量指标，并在每次变更后沿受影响的祖先链增量更新。

## 指标

- **逻辑字节（LogicalBytes）**：子树内所有文件项的大小之和，每个目录项（硬链接）各计一次。
- **物理唯一块字节（PhysicalBytes）**：子树内引用的去重块大小之和。跨文件、跨硬链接、跨目录共享的块在同一目录子树内只计一次。

## 特性

- **硬链接与共享块**：每个目录维护子树块引用计数表，块引用数从 0 变 1 才计入物理字节，归 0 时释放。
- **移动子树 / 同父改名**：`Move` 先把子树聚合统计从源祖先链减去，再加到目标祖先链；同父改名自然抵消。
- **更换块引用**：`ReplaceBlocks` 原子地替换文件大小与块列表，文件的所有硬链接祖先链同步更新。
- **环拒绝**：移动目录前沿目标父链向上检查，若会遇到被移动目录本身则返回 `ErrCycle`。
- **失败原子性**：所有变更操作先完成全部校验（路径、重名、环、块是否存在、大小合法），校验通过后才触碰任何状态，失败绝不部分加减。
- **参考核对**：`Recompute` 提供全树逐项重算的参考实现；测试中每个目录的增量统计都在每步操作后与重算结果比对。

## API 摘要

```go
fs := dirstat.New()
fs.RegisterBlock("blk1", 4096)          // 注册块及其大小
fs.Mkdir("/data")
fs.AddFile("/data/f", 1000, []dirstat.BlockID{"blk1"})
fs.Link("/data/f", "/data/g")           // 硬链接
fs.Move("/data", "/archive")            // 移动子树 / 改名
fs.ReplaceBlocks("/archive/g", 800, []dirstat.BlockID{"blk2"})
fs.Unlink("/archive/f")                 // 最后一个引用移出时释放空间
s, _ := fs.Stats("/archive")            // 增量维护的统计
ref, _ := fs.Recompute("/archive")      // 全树重算参考值
```
