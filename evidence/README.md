# evidence — 增量来源证据组件

面向 Go 宿主的可导入包，用于在构建器/信任域被撤销后增量更新“最优来源
证书”，避免每次从全图枚举所有签名组合。仅依赖 Go 标准库。

## 数据模型

- `NodeID = Env + PayloadDigest`：部署环境是节点身份的一部分，不同环境
  下摘要相同的对象是不同节点，见证、边界指纹、来源结论全程不可互换。
- `RegistryState`：信任域注册表，支持域登记/改名/合并/分裂与构建器批量
  撤销；状态由确定事件序列重建并产生 `RegistryHash`，撤销逐条登记。
- `BagCert`：分解袋证书，主体经规范哈希进入受签根 `SignedRoot` 的
  Merkle 提交。
- `Envelope`：节点补丁与治理补丁共用一条连续序号序列，均由根权威
  Ed25519 签名；治理补丁携带前像注册表摘要。

## 增量流程（`Update`）

1. 锚定旧根：根签名、注册表摘要、袋 Merkle 提交。
2. 严格按序号验证并应用补丁，治理补丁校验前像注册表摘要。
3. 直接受影响节点（补丁命中或见证在新注册表失效）沿补丁前依赖图求祖先
   闭包，定位受影响袋；跨袋移动同时纳入节点离开的旧袋。
4. 只重算受影响袋；其余袋用边界指纹复用，指纹纳入环境身份、完整见证
   身份/公钥、依赖边与注册表代数。注册表代数一旦推进，所有袋必须在新
   约束边界下重验，杜绝“代数变了仍复用”。
5. 先独立组装确定性新根并对照，再由根权威签名。
6. 输出新根、新袋证书与最小披露 `Delta`。

## 独立重验（`VerifyDelta`）

第三方持有旧根、旧注册表、权威公钥、本地旧袋库与差分即可：重放补丁、
重算受影响袋、复核复用边界、按固定权重（`CostWeights`）重算成本账本、
重新组装根并与差分新根逐字节对照。成本只从验签尝试数与哈希数导出。

`FullRebuild` 强制全图重算，作为增量结果的对照基准，测试中断言两者的
根、袋摘要与来源结论逐字节一致。

## 测试覆盖

- 场景一 `TestScenario1_CrossBagMovement`：节点跨袋移动，受影响袋重算、
  无关节点凭边界指纹复用。
- 场景二 `TestScenario2_WitnessRemovedAlternativeSurvives`：旧见证撤销
  移除但替代来源仍有效，失效登记与成本可独立重算。
- 场景三 `TestScenario3_MergedDomainsFailTogether`：两域合并后共同失效，
  合并迁移的构建器随新域一起撤销，最终无来源时分别登记。
- 场景四 `TestScenario4_SameNameDifferentIdentityReuseRejected`：同名不同
  身份的域导致边界指纹变化，伪造复用记录被独立重验拒绝。
- 另有环境隔离、域分裂、补丁序号/前像摘要/根篡改拒绝等测试。
