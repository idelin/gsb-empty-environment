# 最优自适应询问树求解器

带成本的离散属性下，用询问区分离散候选对象（至多 18 个），构造**最坏总成本最小**的自适应询问树。

## 问题模型

- 每个候选对象有一组离散属性值；询问属性 `a` 需支付固定成本 `cost(a)`。
- 回答把当前候选集按该属性的取值分裂成若干分支，询问可自适应地沿分支继续。
- 允许候选共享全部属性：这样的对象**不可区分**，永远落在同一分支，
  最终作为**等价组**保留在叶子中，不再追问。
- 目标：最小化最坏情况下的总成本，即根到叶子路径上询问成本之和的最大值（极小化极大）。

## 算法

对候选子集做精确动态规划（位掩码记忆化，至多 2^18 个子集状态）：

```
solve(S) = 0                                          S 为单例或等价组（叶子）
solve(S) = min_a [ cost(a) + max_{B ∈ split(S, a)} solve(B) ]
```

- 枚举了**所有自适应问序**，因此是精确最优解——不是固定问序，也不是 ID3 式贪心。
- 属性按成本升序扫描并做下界剪枝（`cost(a) ≥ 当前最优` 即停止）。
- 每个分支节点都输出进入该分支的候选集；叶子输出候选或等价组。

## 文件

- `decision-tree.ts` — TypeScript 源（求解器：`solveProblem` / `simulate` / `formatTree`）
- `cli.ts` — 命令行入口（演示 / JSON 求解 / 对拍验证 / 18 候选基准）
- `decision-tree.mjs`、`cli.mjs` — 手工转译的可运行版（本环境无 tsc，逻辑与 TS 源逐行对应）
- `example.json` — 示例输入

## 运行

```sh
node cli.mjs                 # 内置演示（12 候选，含两组不可区分对象）
node cli.mjs example.json    # 求解 JSON 描述的问题
node cli.mjs --verify        # 300 个随机实例对拍：记忆化 DP vs 无记忆朴素极小化极大
node cli.mjs --bench18       # 18 候选上限规模基准
```

有 TypeScript 工具链时可直接编译 TS 源：

```sh
tsc decision-tree.ts cli.ts --target es2020 --module nodenext --moduleResolution nodenext
```

## 正确性校验

`--verify` 与每次求解后自动执行两项检查：

1. 沿树模拟各条根到叶子路径，最大路径成本必须等于 DP 给出的最坏总成本；
2. 叶子对候选集的划分必须恰好等于“全属性签名”的等价类划分
   （可区分对象必被分开，不可区分对象必在同一叶子）。
