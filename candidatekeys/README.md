# candidatekeys

枚举给定函数依赖集下的全部最小候选键（最多 24 个属性）。

## 用法

```sh
go run . [-attrs A,B,C] [fd-file]   # 或从 stdin 读取
```

输入每行一个 FD：`A, B -> C`；允许空左部（`-> X`）与 `#` 注释。
不出现在任何 FD 中的属性可用 `-attrs` 声明。

## 输出

候选键按大小升序、同大小按字典序输出。每个键附带：

- 全属性闭包（超键验证）；
- 删除任一成员后闭包中缺失的属性（最小性验证）；
- 空键（`{}`）同样支持。

## 算法

属性编码为 32 位掩码。按大小递增枚举子集，对已找到的候选键做包含剪枝
（任何包含已知键的超集都不是最小键，可连同其超集一并跳过），其余子集直接
用闭包计算判定。循环依赖（如 `A -> B, B -> A`）不做等价类合并，因此
`{A, D}` 与 `{B, D}` 这类含环上属性的键都不会遗漏。
