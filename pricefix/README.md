# pricefix — 价格修复求解器

给定若干商品的原始整数价格、成对价差约束（上下界），以及部分锁定不可改价的商品，
求满足全部约束的整数价格。目标按**字典序**依次优化：

1. **修改商品数最少**（主目标）；
2. **总绝对改价额最小**（次目标，仅在改动数最少的解中挑选）。

求解器严格按此顺序优化——先精确确定最少改动数，再最小化总改价额；
绝不先最小化总改价再声称改动数最少。

## 输入格式（stdin）

```
n m                  商品数 (0 <= n <= 18)，约束数
a1 a2 ... an         原始整数价格
l1 l2 ... ln         1 = 锁定不可改，0 = 可调整
i j lo hi            共 m 行：约束 lo <= p_j - p_i <= hi（1 起始编号；
                     lo/hi 为整数，或用 -inf / inf 表示单边无界）
```

## 输出（stdout）

可行：

```
FEASIBLE
changes: 1
total_adjustment: 5
prices: 15 20 30
changed item 1: 10 -> 15 (delta +5)
```

不可行（退出码 1），输出负环不可行证据——环上不等式左端求和为 0，
右端界之和却小于 0，矛盾：

```
INFEASIBLE
certificate: negative cycle whose bounds sum to -1 < 0:
  p1 - p2 <= -1      [constraint #1: 1 <= p2 - p1 <= 3]
  0 - p1 <= -5       [item 1 locked at original price 5]
  p2 - 0 <= 5        [item 2 locked at original price 5]
```

## 方法

- **可行性 / 不可行证据**：差分约束图上的 Bellman-Ford。约束
  `lo <= p_v - p_u <= hi` 拆成两条边 `u->v (权 hi)`、`v->u (权 -lo)`；
  固定价格 `p_i = a_i` 用接地节点 G 的两条边表示。不可行当且仅当存在负环，
  负环即证书。
- **主目标（最少改动数）**：n <= 18，按从大到小枚举"保持原价"的商品子集
  （锁定商品恒保持），首个可行的最大子集决定最少改动数。枚举按子集大小
  分层并行，最坏 2^18 次 Bellman-Ford。
- **次目标（最小总改价）**：固定保持集后，最小化 `Σ|p_i - a_i|`。
  该 LP 是最小费用环流的对偶：每个可改商品提供一对单位容量边
  （S->i 费用 a_i，i->T 费用 -a_i），约束为无限容量定价边，接地节点 G 锚定
  固定商品。用连续最短路增广求环流最优解，残量图上以 π_S = π_T = 0 为源点
  求最短路势，即得最优整数价格（数据全整，最优于整数点取得）。
  对每个最大保持集独立求解并取最小，保证次目标在**所有**最少改动解中最优。

## 复杂度

- 主目标：O(2^u · n · (m + n))，u 为可改商品数（<= 18）；
- 次目标：每个可行最大子集一次最小费用环流，O(n) 次增广、每次 O(n·(m+n))。
