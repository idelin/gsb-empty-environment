# merge3 — 三方文本合并工具

输入共同基线与两份修改稿，输出合并结果；冲突处以标记块形式展示三方来源区间。

## 用法

```
go build -o merge3 .
./merge3 [选项] <base> <left> <right>
```

选项：

- `-o <file>`：输出到文件（默认标准输出）
- `-label-base` / `-label-left` / `-label-right`：自定义三方标签（默认 BASE/LEFT/RIGHT）

退出码：无冲突为 0，有冲突为 1，参数/读写错误为 2。

## 合并规则

- 逐行对齐严格按序列位置：相同内容重复出现时，第 i 行只与对应位置的第 j 行配对（LCS 对齐，tie-break 固定，结果确定）。
- 两侧对同一区域做了相同修改：只保留一次。
- 仅一侧修改的区域：自动采用该侧。
- 两侧不同修改：产生冲突块。冲突块最小（首尾行必为不稳定行）、互不重叠（任意两个变更块之间至少隔一个稳定行），并在标记中标注三方来源区间（1 起始行号或空区间位置）。
- 合并规则对左右两侧完全对称：交换两份修改稿，结果互为镜像，不因修改先后顺序偏向任何一侧。

## 测试

```
go test ./...
```

包含短序列穷举对照（二元字母表长度 ≤4 的全部 31³ 个三元组、三元字母表长度 ≤3 的全部 40³ 个三元组），校验：块完整划分三方序列、变更块最小且不相邻、冲突块本不可自动合并、左右交换结果镜像对称、两侧相同/单侧修改时无冲突且输出正确。
