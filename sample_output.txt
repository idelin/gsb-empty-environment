自由族：x=y+1 与 y=x-1

========================================================================

输入等式：
  - x - y - 1 = 0
  - y - x + 1 = 0
变量顺序：x, y

逐步变换：
  1. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：x=y+1
     后：x - y - 1 = 0
     适用域：全体有理数；未引入除法或乘回变量分母
  2. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：y=x-1
     后：y - x + 1 = 0
     适用域：全体有理数；未引入除法或乘回变量分母
  3. [归一化主元] 主元 1 是非零有理数；第 1 行除以它。
     前：[x, y, 常数项] [1, -1, 1]; [-1, 1, -1]
     后：[x, y, 常数项] [1, -1, 1]; [-1, 1, -1]
     适用域：全体有理数；未除以含变量表达式
  4. [主元消元] 用第 1 行消去第 2 行中 x 的系数 -1：行2 ← 行2 - (-1)·行1。循环等式通过整行线性组合处理，不做无限回代。
     前：[x, y, 常数项] [1, -1, 1]; [-1, 1, -1]
     后：[x, y, 常数项] [1, -1, 1]; [0, 0, 0]
     适用域：全体有理数；未除以含变量表达式
  5. [检查零主元] 当前行起 y 的所有系数均为 0，因此不执行除法。
     前：[x, y, 常数项] [1, -1, 1]; [0, 0, 0]
     后：[x, y, 常数项] [1, -1, 1]; [0, 0, 0]
     适用域：全体有理数；未除以含变量表达式
  6. [识别循环/依赖等式] 第 2 行变为 0 = 0，源方程 2, 1 线性相关；它不制造矛盾，也不继续替换。
     前：[x, y, 常数项] [1, -1, 1]; [0, 0, 0]
     后：0 = 0
     适用域：全体有理数；未除以含变量表达式

除法/零系数分支：
  1. 条件：y 的候选系数 = 0
     类型：零系数分支
     结果：y 暂不能作为主元
     说明：未除以 0；继续检查后续变量，最终可能为自由变量

结论：自由族（线性相关但不矛盾）
主元变量：
  - x = y + 1
自由变量：y
最终 RREF 矩阵（最后一列为常数项）：
  [1, -1, 1]
  [0, 0, 0]

矛盾：x=y+1 与 y=x

========================================================================

输入等式：
  - x - y - 1 = 0
  - y - x = 0
变量顺序：x, y

逐步变换：
  1. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：x=y+1
     后：x - y - 1 = 0
     适用域：全体有理数；未引入除法或乘回变量分母
  2. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：y=x
     后：y - x = 0
     适用域：全体有理数；未引入除法或乘回变量分母
  3. [归一化主元] 主元 1 是非零有理数；第 1 行除以它。
     前：[x, y, 常数项] [1, -1, 1]; [-1, 1, 0]
     后：[x, y, 常数项] [1, -1, 1]; [-1, 1, 0]
     适用域：全体有理数；未除以含变量表达式
  4. [主元消元] 用第 1 行消去第 2 行中 x 的系数 -1：行2 ← 行2 - (-1)·行1。循环等式通过整行线性组合处理，不做无限回代。
     前：[x, y, 常数项] [1, -1, 1]; [-1, 1, 0]
     后：[x, y, 常数项] [1, -1, 1]; [0, 0, 1]
     适用域：全体有理数；未除以含变量表达式
  5. [检查零主元] 当前行起 y 的所有系数均为 0，因此不执行除法。
     前：[x, y, 常数项] [1, -1, 1]; [0, 0, 1]
     后：[x, y, 常数项] [1, -1, 1]; [0, 0, 1]
     适用域：全体有理数；未除以含变量表达式
  6. [发现矛盾] 第 2 行变为 0 = 1，由源方程 2, 1 线性组合得到。
     前：[x, y, 常数项] [1, -1, 1]; [0, 0, 1]
     后：无解
     适用域：全体有理数；未除以含变量表达式

除法/零系数分支：
  1. 条件：y 的候选系数 = 0
     类型：零系数分支
     结果：y 暂不能作为主元
     说明：未除以 0；继续检查后续变量，最终可能为自由变量

结论：矛盾，无解
最终 RREF 矩阵（最后一列为常数项）：
  [1, -1, 1]
  [0, 0, 1]

精确有理数唯一解

========================================================================

输入等式：
  - 2x + 4y - 1/2 = 0
  - x - y - 1/3 = 0
变量顺序：x, y

逐步变换：
  1. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：2x + 4y = 1/2
     后：2x + 4y - 1/2 = 0
     适用域：全体有理数；未引入除法或乘回变量分母
  2. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：x - y = 1/3
     后：x - y - 1/3 = 0
     适用域：全体有理数；未引入除法或乘回变量分母
  3. [归一化主元] 主元 2 是非零有理数；第 1 行除以它。
     前：[x, y, 常数项] [2, 4, 1/2]; [1, -1, 1/3]
     后：[x, y, 常数项] [1, 2, 1/4]; [1, -1, 1/3]
     适用域：全体有理数；未除以含变量表达式
  4. [主元消元] 用第 1 行消去第 2 行中 x 的系数 1：行2 ← 行2 - (1)·行1。循环等式通过整行线性组合处理，不做无限回代。
     前：[x, y, 常数项] [1, 2, 1/4]; [1, -1, 1/3]
     后：[x, y, 常数项] [1, 2, 1/4]; [0, -3, 1/12]
     适用域：全体有理数；未除以含变量表达式
  5. [归一化主元] 主元 -3 是非零有理数；第 2 行除以它。
     前：[x, y, 常数项] [1, 2, 1/4]; [0, -3, 1/12]
     后：[x, y, 常数项] [1, 2, 1/4]; [0, 1, -1/36]
     适用域：全体有理数；未除以含变量表达式
  6. [主元消元] 用第 2 行消去第 1 行中 y 的系数 2：行1 ← 行1 - (2)·行2。循环等式通过整行线性组合处理，不做无限回代。
     前：[x, y, 常数项] [1, 2, 1/4]; [0, 1, -1/36]
     后：[x, y, 常数项] [1, 0, 11/36]; [0, 1, -1/36]
     适用域：全体有理数；未除以含变量表达式

结论：唯一解
主元变量：
  - x = 11/36
  - y = -1/36
最终 RREF 矩阵（最后一列为常数项）：
  [1, 0, 11/36]
  [0, 1, -1/36]

除以可能为 0 的参数：x/(a-1)=2

========================================================================

输入等式：
  - x - 2a + 2 = 0
变量顺序：x, a

逐步变换：
  1. [条件除法展开] 对 x/(a-1)=2 按 a - 1 是否为 0 分支；非零分支乘回分母。
     前：x/(a-1)=2
     后：x - 2a + 2 = 0，且 a - 1 ≠ 0
     适用域：线性化适用于 a - 1 ≠ 0
  2. [移项标准化] 把右侧全部移到左侧，得到多项式 = 0。
     前：x/(a-1)=2
     后：x - 2a + 2 = 0
     适用域：满足 a - 1 ≠ 0 的有理数赋值
  3. [归一化主元] 主元 1 是非零有理数；第 1 行除以它。
     前：[x, a, 常数项] [1, -2, -2]
     后：[x, a, 常数项] [1, -2, -2]
     适用域：满足 a - 1 ≠ 0 的有理数赋值
  4. [无法消去剩余变量] 独立方程已经用尽；剩余变量缺少主元，不能通过代入唯一确定，记为自由变量。
     前：[x, a, 常数项] [1, -2, -2]
     后：剩余变量：a
     适用域：满足 a - 1 ≠ 0 的有理数赋值

除法/零系数分支：
  1. 条件：a - 1 ≠ 0
     类型：非零除数分支
     结果：x - 2a + 2 = 0
     说明：可乘回分母；线性化后只在该域有效
  2. 条件：a - 1 = 0
     类型：零除数分支
     结果：原除法未定义；无解
     说明：除数为 0，不属于原等式的适用域
  3. 条件：a 缺少独立方程
     类型：无法消去分支
     结果：a 为自由变量
     说明：不除以不存在的非零系数；参数化解保留该自由度

结论：自由族（线性相关但不矛盾）
主元变量：
  - x = 2a - 2
自由变量：a
解还必须满足：
  - a - 1 ≠ 0
最终 RREF 矩阵（最后一列为常数项）：
  [1, -2, -2]
