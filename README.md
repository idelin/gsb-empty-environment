# chunked-labeler

分块二值图连通域分析库（C++17）。图像以任意顺序、任意矩形分块流式到达，
库只保留**当前块**和每块 O(周长) 的**边界摘要**，即可完成与整图两遍扫描
完全一致的连通域分析。

## 语义定义

- 前景连通域：**8 邻域**；背景（孔洞）：**4 邻域**（满足 Jordan 曲线定理的对偶约定）。
- 面积：前景像素数。
- 周长：前景与背景之间的 4 邻域像素边数，**图像外视为背景**（图像外框计入周长）。
- 孔洞：不接触图像边界的背景连通域；归属到与其 4 邻接、稳定标签最小的前景连通域。
- 最终标签：按各连通域最小像素坐标 `(minRow, minCol)` 字典序编为 `1..N`，与分块方式、到达顺序无关。

## 工作原理

1. **块内标记**：前景 8 邻域 / 背景 4 邻域 BFS，局部标签映射到全局并查集 id。
2. **局部统计**：面积、最小坐标直接累计；周长先按"块外皆背景"计入，跨块合并时修正。
3. **边界摘要**：每块只存四条边的 `(像素值, 前景全局标签, 背景全局标签)`。
4. **乱序合并**：新块与所有已存摘要做矩形邻接判定——
   - 共边块：对齐比较重叠区间，前景-前景合并标签并将两侧多计的周长各减 1，
     背景-背景合并，前景-背景记录邻接对（用于孔洞归属）；
   - 跨边对角（偏移 ±1）：前景 8 邻域补充合并；
   - 角点相接块：仅比较相接角像素（前景 8 邻域）。
5. **finalize**：按并查集根聚合统计，按最小坐标稳定排序编号；非外界背景根
   计为孔洞并归属到稳定标签最小的邻接前景根。

## 构建与测试

```sh
cmake -S . -B build && cmake --build build
ctest --test-dir build --output-on-failure
```

测试（`tests/test_main.cpp`）覆盖：角点相接、四块交界（十字/跨块孔洞环/对角链）、
全黑边界与全黑/全白退化图，以及 400 组随机图 × 随机网格/不规则(guillotine)分块 ×
乱序到达，与整图参考模型（`tests/reference_model.hpp`）逐字段比对。

## 用法

```cpp
#include "chunked_labeler.hpp"

ChunkedLabeler lab(rows, cols);
// 块可以任意顺序到达；data 为行主序 h*w，0=背景，非 0=前景
lab.addBlock(row0, col0, h, w, data);
...
auto comps = lab.finalize();  // vector<ComponentStats>，label 1..N 稳定编号
// ComponentStats: label, area, perimeter, holes, minRow, minCol
```
