共享网关要把浏览器连接升级给某个租户的 WebSocket 服务。给 TypeScript 网关写可导入的握手授权包。启动握手时，宿主提供已经认证的租户、Origin、目标服务、允许的子协议序列及一条短时限。票据用 HMAC-SHA256 绑定这些字段、不可重复的 16 字节随机数和密钥代次；字段采用长度前缀字节编码，不能让两组字段拼成同一消息。上游只能选票据和客户端原请求共同允许的一个子协议。Origin 按 HTTPS 的规范主机、有效端口和 scheme 比较，拒绝带用户名、路径、查询或片段的值。101 响应必须绑定原始客户端 key 的 accept 值，并只回显最终选中的子协议。成功消费票据与切换连接须为一次原子操作；若连接先关闭或密钥已撤销，之后到达的上游成功响应不得产生可用连接。用可控时钟、固定随机数和假上游交错完成两次响应，核对跨租户重放、同票并发、签名字段分界、晚到响应及轮换密钥后的旧票。
