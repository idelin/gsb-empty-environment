# Wasm导入能力校验

插件市场在实例化 Wasm 前要保证模块只能拿到当前套餐授予的宿主能力，且加载服务是边收边判，不能等整段字节到齐。攻击者可声明同名但签名不同的导入、用 multi-value 结果错配、借 type 段索引复用伪造签名，或在 start 段调用未授权导入。为 TypeScript 加载服务写单遍流式校验包：按段顺序扫描，函数导入签名须解析到同一 type 段的完整参数与结果类型并与能力表逐项相等；memory、table、global 导入须在能力表显式授权；start 只能引用已授权函数。判定须在读到首个违规处的段尾前完成，返回违规段序号、该段内字节偏移和首个违规导入索引；段乱序、重复段、截断输入按同一套偏移报告。用签名错配、type 索引复用、未授权 start、乱序与截断输入对照偏移索引。
