# 通行密钥备份标志与高风险操作的凭据类型要求

同步型通行密钥可以随云账户复制到别的设备，攻击者拿下同步账户后，就能在自己的设备上断言同一个凭据；依赖方若不看备份标志，就分不出设备绑定凭据与可同步凭据。为Go依赖方写可导入的认证数据标志核对包，输入注册时的认证数据标志字节、之后每次断言的标志字节、凭据已记录的状态和调用方对本次操作的风险标记：标志位 0x01 为用户在场、0x04 为用户已验证、0x08 为备份资格、0x10 为已备份、0x40 为带凭据数据、0x80 为带扩展；保留位 0x02 与 0x20 非零一律拒绝；备份资格为 0 而已备份为 1 属于非法组合；备份资格在注册时记录，之后每次断言必须与记录相同，不同则拒绝；已备份由 0 变 1 允许并更新记录，由 1 变 0 要求重新做一次用户验证并记录告警；断言里不得带凭据数据位，注册时必须带；高风险操作要求备份资格为 0 的设备绑定凭据，或要求用户已验证且调用方给出的二次因子在 5 分钟内有效；用户在场位必须置位。用保留位置位、备份资格中途变化、非法组合、已备份回退和高风险操作遇到可同步凭据验证。
