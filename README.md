容器宿主在发布新的挂载视图前要证明租户看到的所有别名都满足只读、禁止提权和不可执行策略。给 Go 宿主写可导入的挂载计划准入包，只处理抽象树，不执行系统挂载。输入包含挂载对象身份、内容子树、父挂载点、传播组及视图私有的保护位；同一内容可在多处出现，但保护位附着在挂载视图上。计划操作可复制子树视图、移动挂载点、收紧指定子树的保护位，或从共享传播组向各成员复制子挂载。保护要求由租户、内容对象和路径前缀三层规则取并集。对于并发计划，宿主只提供部分先后关系，至多 12 步。须在所有合法顺序的每一步检查任一可见视图都不弱于保护要求，不能只验证结束时的树。返回可独立核对的准入证书：对每个已执行操作集合列出可能出现的规范化视图摘要及其合法后继；能证明两步互不影响时可合并等价顺序，但不能把共享传播或同源别名错当作独立。用小树全排列对照证书，涵盖保护位只收紧一个别名、传播晚于移动、退出传播组后再复制、最终相同但中间状态不同的计划。
