虚拟块设备在运行时切换队列配置，试装一批命令不能让旧客户的在途请求从原队列消失。队列后端须交付为设备宿主可导入的 Go 包；宿主构造设备实例，通过 Derive(parent, batchID, dictionary) 原子申请新句柄，通过 Lookup(handle, rank) 取得请求；批标识由宿主为每次调用唯一分配。设备从固定正容量的空 FIFO 起步，持有不可变世代；客户可从任一旧世代派生新世代。每次派生提交一个片段字典：叶子是入队(tag)或完成(tag)，tag 是可重复的字节，后续项可以串接任意两个较早片段，最后一项是要执行的整批。入队须有空槽，完成须匹配队首才弹出。整批合法才发布新世代；否则返回最早失败的批内展开偏移、当时深度和原因，不分配可见世代、不改变任何旧句柄。客户通过世代和队内秩取得在途项的 tag 及其原始提交位置（成功派生的批标识、该批内偏移），不能把同 tag 的请求混为一笔。提供实际持有后端的块设备宿主，至少演示两个客户从同一世代派生、一支失败后改用另一个命令批且另一支继续完成。所有批的字典总项数不超过 250，一条派生路径的展开事件总量不超过 2^63−1；时间和空间须为已接收字典总项数、调用次数及偏移位长的多项式，不能逐逻辑命令执行或逐在途项存储，不能仅凭哈希相等就承诺完成。小字典随机分叉并用独立深拷贝队列核对世代、首错、来源；另外实际走一次万亿规模的跨批完成，提交序列与回执序列的压缩切分不同，分别测试完全匹配与仅末段不匹配。
