# 多币种联合授信时态敞口监控器

集团授信额度与子公司敞口的**双时态**（bitemporal）监控器：

- **双时态内核**：每条事实同时携带业务生效时间（valid time）与系统记录时间（transaction time），
  可回答"以任意记录时点的知识，回看任意业务时点的集团敞口"。
- **授信协议有效期**：协议有效期外的子公司敞口不计入集团总敞口。
- **多币种折算**：汇率同样按双时态记录，历史时点敞口按该时点生效的汇率折算。
- **追溯修正**：历史借款的追溯上调自原生效时间起生效，旧记录事务时间关闭、全程留痕。
- **质押率重算**：担保物价值变动 / 借款修正自动触发质押率重算，重算流水（`pledgeTrace`）与
  告警流水（`alertLog`）可审计追溯。

## 运行要求

Node.js ≥ 22.6（原生 TypeScript 类型擦除运行，零依赖，无需编译）。

## 运行样例

```sh
npm run demo
```

场景时间线：集团总授信 1000 万 CNY（预警线 90%）；t=10 子公司 A 借款 600 万；
t=12 子公司 B 借款 40 万 USD；t=20 汇率 7.00→7.10；t=28 担保物 800 万贬值为 650 万；
**t=30 追溯上调 A 的历史借款为 700 万** → 重现时间 30 时总敞口 984 万触碰 900 万预警线并输出告警。

## 测试

```sh
npm test
```

7 个用例覆盖：验收场景（t=30 重现触线告警）、双时态对照（tx=29 不触线）、汇率波动折算、
协议有效期剔除、担保物贬值触发质押率重算留痕、追溯修正触发重算、修正历史留痕。

## 结构

- `src/bitemporal.ts` — 双时态存储内核（insert / correct / truncateValid / asOf / history）
- `src/monitor.ts` — 监控器：集团敞口评估、预警线判定、质押率重算、告警流水
- `examples/demo.ts` — 验收场景运行样例
- `test/monitor.test.ts` — Node.js 内置测试（node:test + assert）
