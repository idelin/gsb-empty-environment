# tx-batch-store

事务式批量状态存储（TypeScript，无响应式框架依赖，仅 Node.js 内置模块）。

## 语义

- 同一调度周期（`batch`）内多次更新合并为一次提交，只通知一次
- 函数式更新按顺序读取前一值；直接赋值与函数更新次序保留（两次 `x=>x+1` 得 +2）
- 条件更新、跨字段不变量、读后再写：整批在事务草稿上按序求值后一次原子提交
- 读者（`getState` / 订阅者）只能看到已提交快照，看不到事务中间态
- 失败批次（mutator 抛错 / 不变量违反）整批回滚，不留部分值
- 嵌套批次合并到最外层，只在最外层通知
- `cancel(id)` 只移除未提交的排队操作，不撤销后续独立更新
- 携带操作 ID 的 `dispatch` 幂等，重试安全
- 已提交操作进入日志，`rebuild()` 可回放重建状态
- `merged` / `unmerged` 两种执行策略在结果、错误与副作用次数上一致

## 运行

```sh
npm test     # node --test test/（Node.js 内置测试运行器）
npm run demo # node src/demo.ts（运行样例）
```

要求 Node.js >= 22.6（利用原生 TypeScript 类型擦除直接运行 `.ts`，无需编译步骤；开发环境为 v23.9）。
