# 单变量有理函数精确约分与定义域保持

纯 Python 3.11 标准库实现（仅用 `fractions.Fraction` 等，**不调用任何符号
代数库**），用多项式 GCD 约分有理函数，并在约分过程中完整保留原定义域的
实根排除集合。

## 文件

- `rational.py` — 核心实现
  - `Polynomial`：Q 上稠密一元多项式；精确长除、GCD（欧几里得算法）、
    **Yun 平方自由分解**、Sturm 链与 Cauchy 界、有理根定理求全部有理根、
    **Sturm 二分隔离**无理实根（有理端点、互不相交的隔离区间）。
  - `RationalPoint` / `IsolatedRoot`：排除点；无理点用“最小描述多项式 +
    有理隔离区间 + 近似值”表示，不强行给出闭式根。
  - `RationalFunction`：约分后的 `p/q`，分母首项系数符号归一（非常数时分母
    monic，常数时归一为 1）；内部保存 `exclusion_poly`（排除多项式），
    其互异实根即原表达式的全部无定义点。
- `test_rational.py` — `unittest` 套件（22 个测试），含独立恒等式验证与
  有理采样验证。
- `demo.py` — 运行样例。

## 关键规则

1. **约分**：`gcd(p,q)` 同时除分子分母；约分只影响显示形式，永不从
   `exclusion_poly` 删除根。因此 `x/x` 约成 `1`，但 `x=0` 仍被排除；
   `(x^2-2)/(x^2-2)` 约成 `1`，但 `±√2` 仍以隔离区间形式被排除。
2. **零分母拒绝**：构造时分母为零多项式、或除以零函数，抛
   `ZeroDenominatorError`。
3. **定义域**：保存为“原分母实根排除集合”。有理根是精确 `Fraction`；
   无理根是宽度 ≤ 10⁻⁶ 的有理隔离区间，端点不是根，区间两两不交。
4. **运算组合**：`+ - * /` 的结果排除集合为两操作数定义域的并；除法额外
   加入除式分子零点。组合后重新对排除多项式做去重/隔离（互异实根）。
5. **逐步适用域**：每个 `RationalFunction` 带 `steps`，`explain()` 输出
   每步变换及其有效域。
6. **值一致**：约分前后在所有有效点的 `Fraction` 取值完全相同。

## 验证方式（独立于约分代码）

- 代数恒等式：交叉相乘 `p1*q2 == p2*q1`，用独立的卷积实现比较系数。
- 有理采样：在大量精确有理点（跳过排除点）上用 Horner 法分别求值比较。
- 专测覆盖：重根、公共因子（含无理公共因子）、零函数、零分母、链式运算
  的排除集合并、分母符号规范、平方自由分解与根隔离计数。

## 运行

```sh
python3.11 -m unittest test_rational -v   # 测试
python3.11 demo.py                        # 运行样例
```
