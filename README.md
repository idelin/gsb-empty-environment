双根写时复制存储换代时不想为整个清单多刷一次盘，希望只增加少量持久标记。请给挂载层实现可导入的 Go 格式规划包。输入提供固定个数的物理扇区，每个扇区分成两个可独立落盘的原子半区；初始位串、带先决 DAG 的半区覆盖操作和最终两个根描述符均给出。同址操作不一定有先后，断电盘像来自任意拓扑执行前缀。另有候选标记位：选中一个须在指定半区额外存一位，初值及该半区每次覆盖时写入的位值都有定义，每次随半区原子落盘，不能加屏障或改变偏序。每个历史真正应该挂哪个根由一条独立的发布操作是否已经落盘决定；根的代号不可取自内存。读盘成本受限，挂载器每次可自选一个未读半区得到原始位串及此处选中的标记；根据返回值决定下一读，至多 K 读，必须始终选对根。不要求唯一确定崩溃前缀。最小化选中标记的总存储费用，平手先少位再取编号向量字典序最小；给出能被块读取回调实际驱动的判代树。另交付任意树的独立检查接口，判错给可重放写入前缀、逐读返回和错误根。上限二十四次覆盖、十四个标记、十个半区，原位串至多六十四位；不能枚举全部拓扑排列，不能把相同的已完成操作集合直接视为同一盘像。用小设备全序前缀作为对照，特测零标记可行、每幅完整盘像只属于一个根但 K 读不可分、同址乱序导致盘像不同，以及必须根据首读决定第二读的位置。
