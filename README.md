# 密钥妥协后的历史保护

安全协议教学模型要区分长期钥泄露与会话临时钥泄露对过去消息的影响。实现供Go分析宿主调用的符号可解密包，消息构造为配对、加密及不可逆派生，派生只有全部输入已知才能计算；输入各密钥销毁和泄露时刻，销毁不抹掉此前已获得知识。返回每个历史秘密的最早泄漏证明，用手工小协议核对。

## 包结构（`package netsec`）

- `model.go`：项构造与时间线。`Name` 原子项，`Pair` 配对，`Enc(key, plain)`
  对称加密，`Derive(inputs...)` 不可逆派生；事件为 `Send`、`Compromise`、`Destroy`。
- `analyze.go`：攻击者知识闭包与 `Model.Analyze`，返回每个秘密的 `LeakReport`
  （是否泄漏、最早时刻 `Earliest`、规则化证明树 `Proof`）。
- `analyze_test.go` / `example_test.go`：手工小协议核对与宿主调用示例。

## 语义要点

- 配对透明：已知配对即可拆分两侧，两侧已知即可重建配对。
- 加密精确匹配：只有同时持有密文与同一钥项才能 `decrypt`。
- 派生单向：`derive` 仅在全部输入已知后可计算，观察输出不能反推输入。
- 销毁语义：`Destroy(k, t)` 记录最早销毁时刻；晚于或等于该时刻的
  `Compromise` 无效，但销毁不会删除攻击者此前已获得的任何知识。
- 知识单调：最早时刻通过工作队列求最小不动点，证明树每个节点的时间等于
  其前提时间的最大值，叶子节点锚定具体时间线事件。
