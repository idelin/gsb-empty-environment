统计平台允许员工查看若干组精确或区间汇总，但同一张报表里的结果合在一起可能唯一确定受保护单元。写供Go报表发布服务导入的披露审查包。原始表是最多四乘四的非负整数格，每格有含端点的取值界，已公开行列合计和可选小计都是线性约束。输入实际表与候选汇总，某些汇总只能整体发布或整组隐藏。对每个敏感格，要求保留至少k个不同的可行整数值；只看最大最小之差不够，额外的倍数小计会在中间产生空档。选择总代价最小的隐藏组，使全部受保护格都达标；代价相同按组ID序列比较。为每个声称可行的值返回一张满足所有已发布数的完整表，未达标时给可复验的排除理由，预算耗尽不得批准。用独立小域枚举核对并行发布两张边际安全报表、空档、原表本身不满足公共约束以及隐藏最后一组仍会泄露。
