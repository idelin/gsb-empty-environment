# musdiag — 有限域约束配置诊断器

对最多 **20 条**有限域整数约束做可满足性诊断。当整组约束不可满足时，
用**按输入顺序的确定性删除缩减**求出一个**包含极小不可满足子集**（MUS）：
子集内删去任意一条约束即可满足（包含极小），但不保证条数最少（非基数最小）。

## 构建与测试

```sh
export GO111MODULE=on          # Go 1.11 需要显式开启 modules
go test ./...
go build -o musdiag ./cmd/musdiag
go build -o satcheck ./cmd/satcheck
```

## 问题文件格式

每行一条语句，`#` 后为注释：

```
var <名> = <下界>..<上界>          # 整数闭区间域
[<名>:] <表达式> <关系> <表达式>   # 无名约束自动命名 c1, c2, ...
```

- 关系：`==` `!=` `<` `<=` `>` `>=`
- 表达式：整数常量、变量、`+` `-` `*`、括号、一元负号
- 约束超过 20 条时解析报错

示例见 `examples/unsat.txt`（不可满足）与 `examples/sat.txt`（可满足）。

## musdiag — 诊断器

```sh
./musdiag -file examples/unsat.txt [-limit N]
```

- 可满足：打印一组见证赋值并退出。
- 不可满足：按输入顺序做删除缩减——依序尝试去掉每条约束，剩余集合仍
  不可满足则永久删除——输出 MUS，并对 MUS 中每条约束给出"删去它即可满足"
  的见证赋值，证明包含极小性。枚举顺序与删除顺序固定，结果只取决于输入
  文件，完全确定。
- 赋值空间超过 `-limit`（默认 1e8）时报告 UNKNOWN，退出码 3。

## satcheck — 独立满足性检查器

```sh
./satcheck -file examples/unsat.txt                 # 整集是否可满足
./satcheck -file examples/unsat.txt -subset c1,c3   # 验证子集是 MUS
```

`satcheck` 自带独立的穷举枚举器（无剪枝、逐一枚举完整赋值，不复用
`solver` 的搜索代码），用于独立复核 musdiag 的结论。带 `-subset` 时：

1. 枚举全部赋值，证明子集**无可解**；
2. 对子集中每条约束，枚举证明**删去它后**的集合**有解**并给出见证。

全部成立时打印 `MINIMALITY PROVEN`，退出码 0；任一论断不成立退出码 1；
用法/解析错误退出码 2；超出枚举上限退出码 3。

## 代码结构

- `csp/` — 问题建模、文本解析、表达式求值（两个程序共用的唯一代码）
- `solver/` — 带剪枝的穷举满足性检查、删除式 MUS 缩减、极小性复核
- `cmd/musdiag/` — 诊断器 CLI
- `cmd/satcheck/` — 独立检查器 CLI（自带枚举器）
