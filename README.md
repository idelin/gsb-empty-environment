# auditlog

哈希链审计日志：每项含单调序号 `Seq`、前项摘要 `Prev` 与自身摘要
`Hash = SHA-256(seq ‖ prev ‖ data)`，链锚定于零值 genesis。

## 合并规则（`Merge`）

- 多来源副本可缺段、可乱序、可含重复项；相同条目自动去重。
- 逐项重算哈希，内容被篡改的条目直接拒绝并记入 `Issues`。
- 只接受一致链：某序号在所有覆盖它的副本中哈希完全相同、且能
  从 genesis 连续链接，才进入输出。
- 输出**最长共同可信前缀** `Prefix`；遇到分叉即停止扩展，绝不
  按最大序号或链长选边。
- 分叉双方原样保留在 `Forks`（`ForkEvidence{A, B}`），由人工裁决。
- 全体副本共同缺失的序号之后的内容无法锚定，前缀在该处截断。

## 测试
