# SOPS密钥组与阈值元数据校验

SOPS 用密钥组把数据密钥分给多组主密钥，要求每组各出一把，并可设阈值，攻击者往元数据里加入自己的 age 或 KMS 条目、降低阈值，或删去某一组来获得解密能力。为 Go 文件加载服务写供解密前调用的元数据校验包：输入加密文件的 sops 元数据（key_groups、每组的 PGP、KMS、age、Vault 条目、shamir_threshold、mac、lastmodified、版本）、调用方登记的预期密钥组（各组及条目指纹）、阈值与最低版本；元数据中的组与条目须与预期完全一致，多出或缺失都拒绝，组顺序无关；阈值不得小于预期也不得大于组数；mac 须在解密后对全部值重算并以常量时间比对；不带 mac 的文件拒绝；版本低于最低版本拒绝。用多出 age 条目、降低阈值、删除组、mac 缺失和合规文件验证。
