# WebSocket子协议协商绑定

WebSocket 握手里 Sec-WebSocket-Protocol 的取值常被拿来传令牌或决定权限，攻击者可以提交服务端没有提供的子协议，或在列表里夹带令牌让它被回显进响应与日志。为TypeScript WebSocket 服务写可导入的握手协商包（RFC 6455 第 4.2 节）：服务端从客户端列表（逗号分隔，忽略空白）中按自身优先级只选一个并原样回显，没有交集则不回显该头，握手结果标记为无子协议；子协议名须是 token 字符，列表里重复的名字拒绝握手；形如 `bearer.<令牌>` 的元素只用于取令牌，不得出现在响应、日志或回显中；选定的子协议决定该连接允许的消息类型，其余类型收到即以关闭码 1008 关闭。测无交集、重复、令牌回显、越权消息类型。
