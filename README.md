安全升级器的影子分区按地址位交织到多块闪存，区段连续不代表实际写的物理字节连续。给 Go 固件发布宿主写可导入的写集证明包。逻辑地址限 48 位，物理地址由输入的 GF(2) 仿射位变换得到；每个镜像段和保护段均为半开逻辑区间，可有独立变换，矩阵不保证满秩。每次烧写会把实际触及的物理擦除块整个擦除，块大小是 2 的幂。入参给出一批按顺序的段写与只读保护区，判断每次擦除和最终写入是否都与保护区不相交；若有交，指出最早动作及按数值最小的冲突物理地址，同时提供分别满足两边区间的原像。原像不唯一时都取最小值。允许给定掩码选择写入段中的部分逻辑地址，掩码按逻辑坐标解释。不得遍历地址、展开擦除块或把稀疏像集当外包区间。安全证明需给可单独验收的区间分解与线性约束不可满足证据，预算不足返回未知。缩至 8 位时用逐字节模拟穷举，对照秩亏、两段物理包络重叠而实际像集不交、仅擦除范围相交、48 位顶端及两组不同原像。
