缓存代理要给仍分属不同配置世代的客户发布新路由。实现可导入的 Go 包，让配置服务交给它一串不可改的逐槽目标布局，由它返回可执行的复制、发版、落后客户确认和清理顺序。开始仅第零版有效；发版只能按输入推进。每一版附若干客户确认事件，某事件允许丢弃哪一旧版由输入指定；确认间有偏序，且须先发到给定版本才可执行。对尚有效的每个版本，每槽按该版有序读副本表依次尝试；任意一台节点离线或全在线时，第一个在线副本必须持有该槽该版指定的不可变内容。节点容量以页为单位，相同内容在同一节点只占一份；复制动作须从已有节点取整份，之后才可删源。离线只需在动作边界验读，无需故障下继续迁移。允许保留将来复用的内容。对最多八个槽、五个节点、六个发布、八个确认，找最少跨机架复制字节，其次最少总复制字节，再最少临时驻留页峰值（定义为所有时刻全集群实际占用的最大页数）；量为非负整数，不许把同价状态仅按当前峰值合并而丢失驻留差异。无解须区分输入中目标内容从未有过来源与合法输入但无容量安全路径。交付配置服务调用例及不调用规划器的逐动作验证器，独立小状态枚举对照最优值，覆盖两个旧版分别验证都可回收但并存不可、同节点跨槽复用、临时经第三节点中转，以及多次过渡同一内容只拷一次。
