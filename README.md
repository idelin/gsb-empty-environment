缓存客户端与服务的往来按 RESP3 编码。给连接层交付可导入的 Go 编解码组件。类型前缀区分简单串、错误、整数、二进制安全串、数组、空值、布尔、双精度、大数、映射、集合、推送和带属性的回复，长度前缀可以是 -1 表示空。属性回复后面必须紧跟另一个回复，对调用方以附加信息暴露；推送类型不出现在请求的回复位，而要交给单独的回调。大数与双精度保留原文给出的形式，不转成浮点。请求按调用方给出的参数数组编码，参数可含二进制。以下情况报错：长度不是十进制整数或超出上限、类型前缀未知、行结束符不是回车换行、映射或属性的个数为奇数。验收用逐字节喂入与整段喂入结果一致，对照手算的十六进制样例，覆盖空数组与空串的区分、负长度、嵌套集合、推送夹在两个回复之间和截断输入。
