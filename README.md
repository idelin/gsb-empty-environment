# 资源迁移规划器（Resource Migration Planner）

对层级资源树进行重组规划：在满足目标分组的前提下，求**移动次数最少**的方案，
并以**权限例外最少**为次目标；同时输出迁移前后每条相对引用的解析结果。

## 模型

- **节点**：`id`、`name`、父指针、可选本地 ACL（`acl`）、可选相对引用（`refs`）、可选固定标记（`pinned`）。
- **继承权限**：节点的有效权限 = 根到自身路径上所有本地 ACL 的并集。移动子树会改变其所有后代的继承权限。
- **权限例外**：迁移后有效权限集合发生变化的节点，需要显式 ACL 例外记录。次目标按
  （受影响节点数, 权限差异条目数）字典序最小化。
- **目标分组**：`mustBeUnder: { 节点: 容器 }`，要求节点在最终树中位于容器之下（严格后代）。
- **固定节点**：`pinned` 节点与根节点不可作为被移动对象（可作为挂载目标）。
- **相对引用**：支持 `.`、`..`、按子节点名逐段解析；迁移后可能重定向、失效或修复。
- **禁止复制虚增身份**：方案仅由移动操作组成；`assertIdentityPreserved` 校验迁移前后
  节点集合、名称、本地 ACL 完全一致，且固定节点未被移动。

## 算法

对移动次数 k 做迭代加深（k = 0, 1, 2, ...），首个有解的 k 即为最少移动次数：

1. 取当前第一个违规 (v 必须在 C 之下)，只生成能修复该违规的移动：
   将 v 或其某个可动祖先，挂载到 C 或 C 的某个后代之下。
   （移动其它节点不可能让 v 进入 C 的子树，因此该限制对主目标完备；
   中间挂载点会在其自身违规被修复后进入候选，次目标最优性亦保持。）
2. 同层状态按 `(状态签名, 剩余步数)` 去重剪枝，状态数有预算上限（默认 20 万）。
3. 在最少移动次数的全部方案中，按权限例外字典序取最优。

规模限定 15 节点，演示场景搜索状态数 < 100。

## 运行

需要 Node.js ≥ 23.6（原生 TypeScript 类型擦除）：

```bash
node src/main.ts        # 运行 15 节点演示场景
npm test                # 运行单元测试
```

## 文件

- `src/types.ts` — 类型定义
- `src/tree.ts` — 树构建/校验、移动、继承权限、相对引用解析
- `src/planner.ts` — 违规检测、迭代加深搜索、权限例外与引用对照、身份保持校验
- `src/scenario.ts` — 15 节点演示数据与目标分组
- `src/main.ts` — 演示入口，输出方案、权限例外与迁移前后引用解析对照
- `tests/planner.test.ts` — 单元测试
