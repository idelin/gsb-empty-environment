# 计算图误差分析器（Go）

基于**仿射算术**（affine arithmetic）的保守误差分析：每个量表示为
`c + Σ k_i·ε_i`（ε_i ∈ [-1,1]），全部用 `big.Rat` 有理数精确计算。

## 特性
- 加减乘除四则运算；共享子表达式（同一 `*Node`）只展开一次，噪声符号全局唯一。
- **同源相关性保留**：`x - x = 0` 精确抵消；独立变量 `x - x2` 误差叠加为两倍宽。
- 乘法二次项、除法（Taylor 线性化 `1/(c+u) = 1/c - u/c² + 余项`）的高阶余项
  归入新噪声符号，保证结果保守（sound）。
- **除数过零**：区间包含 0 时拒绝并给出区间证据。
- 输出保守误差界 + 按贡献降序的误差来源排名（最大来源高亮）。
- **有限小域精确枚举验证**：每个输入取端点+四分点网格，笛卡尔积精确求值，
  验证所有样本落在保守界内（除数恰为 0 的样本单独计数跳过）。

## 运行
```sh
GO111MODULE=on go test ./...   # 单元测试
GO111MODULE=on go run .        # 演示：x-x vs x-x2、x/x vs x/x2、共享节点表达式、除零拒绝
```

## 文件
- `affine.go` — 有理区间、仿射形式、四则运算、误差来源分析
- `dag.go` — 计算图节点、记忆化仿射求值、精确求值
- `verify.go` — 有限网格精确枚举包含性验证
- `main.go` — 演示；`errana_test.go` — 测试
