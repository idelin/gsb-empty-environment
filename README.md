# 嵌套模态焦点管理(TypeScript + Node.js 内置测试)

无浏览器依赖的嵌套弹层焦点/隔离模型:节点树与字形度量由夹具给出,
布局、命中、焦点顺序全部为核心纯计算。

## 行为规则

- **焦点限制在顶层**:任意时刻只有栈顶弹层拥有焦点;范围外的聚焦请求被拒绝,
  Tab 循环在顶层范围内回绕。
- **inert 引用计数**:打开弹层为其他每个顶层区域获取一份 inert 引用,关闭时释放;
  嵌套时计数叠加,关闭内层不解除外层对背景的隔离;节点子树移除时其上的计数随之消失,
  全部关闭后引用归零。
- **分代提交**:栈拓扑每次变化(open/close)世代号 +1;inert 引用与焦点请求按代提交,
  过时的异步焦点请求在执行时丢弃,不得夺焦——关闭、触发者删除、新层打开可安全交错。
- **焦点恢复**:关闭后优先恢复触发者;触发者已删除则回到合法后备
  (范围内 autofocus → 首个可聚焦节点);目标尚未挂载时请求挂起,
  异步挂载完成后重试(仍受分代保护)。
- **退出动画**:closing 中的层立即自我 inert,可交互范围明确为新的顶层
  (或文档);`finalize` 卸载子树并释放引用。`close`/`finalize` 幂等。
- **Escape**:只关闭可关闭(`dismissible`)的顶层,不向下穿透。

## 运行

需要 Node.js >= 22.6(`--experimental-strip-types` 直接运行 TypeScript):

```sh
npm test       # Node 内置测试运行器:单元测试 + 状态探索
npm run sample # 运行样例:打印一次完整交互轨迹
```

## 结构

- `src/tree.ts` 节点树(挂载/卸载/文档序),`src/glyphs.ts` 字形度量
- `src/layout.ts` 纯计算块布局与命中测试
- `src/inert.ts` inert 引用计数注册表
- `src/focus.ts` 焦点陷阱与候选计算
- `src/layers.ts` 弹层栈:分代提交、恢复链、退出动画、Escape
- `src/fixtures.ts` 节点树与字形夹具,`src/sample.ts` 运行样例
- `test/layers.test.ts` 单元测试,`test/exploration.test.ts` 状态探索

## 状态探索

`test/exploration.test.ts` 对 10 个操作(开三层/关顶/Escape/动画收尾/
删除并重新挂载触发者/单步与排空异步队列)做广度优先枚举(深度 6),
在每个可达状态上检查:

- I1 焦点(若存在)必在顶层可交互范围内、已挂载、可聚焦、非 inert;
- I2 每个节点的 inert 状态与"不在可交互范围"严格互补(closing 层自我隔离也算范围外);
- I3 对未知/已关闭 id 的重复关闭与收尾是幂等 no-op(状态指纹不变);
- I4 静止状态(无弹层、无动画、队列空)下 inert 引用全部释放,焦点回到页面。
