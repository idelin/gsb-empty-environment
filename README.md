# EAP-TLS恢复把访客身份带进企业网

无线控制器为EAP-TLS缓存TLS票据，若恢复键只按客户端证书摘要，访客SSID上获得的会话可在企业SSID恢复并继承更高VLAN。请实现供Go AAA服务调用的可导入恢复授权组件。初次认证冻结外层EAP身份、服务端虚拟身份、SSID/BSSID策略域、客户端证书链与验证策略代次、TLS版本/套件、导出的MSK身份和最终VLAN/ACL；票据AEAD封装这些字段及绝对过期，恢复时重新核对当前接入点、策略、证书撤销状态和channel binding。TLS 1.3 PSK early data不触发授权副作用，完成Finished后才原子消费或轮换票据；匿名外层身份不能替代内层证书主体。策略收紧、证书撤销、AP迁移和票据密钥轮换使旧授权失效。用两个SSID共证书、BSSID漫游、撤销后恢复、early data、并发票据使用和合法同域快速漫游验证网络权限不跨策略域。
