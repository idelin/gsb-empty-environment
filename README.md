# ccd2d — 二维轴对齐矩形连续碰撞检测

在查询区间 `[0, T]` 内对匀速运动的闭矩形做**连续**碰撞检测（CCD），
不会漏掉两帧之间穿过的障碍。所有时间运算使用 BigInt 有理数，结果精确。

## 原理

- **宽相（候选生成）**：每个物体在 `[0, T]` 上的扫掠包围盒（swept AABB）
  插入空间哈希网格；闭盒贴边会进入所有相邻格子，同一对去重后只保留一次。
- **窄相（精确求交）**：每轴两个线性有理不等式 `a + b·t ≤ 0`，
  与 `[0, T]` 求交得到精确接触闭区间 `[t0, t1]`；接触（含瞬时点触）算碰撞，
  初始重叠从 `t = 0` 开始，零相对速度、负坐标、`t = T` 才接触均正确处理。
  不做任何离散采样。
- **核对**：每次查询独立执行 O(n²) 全配对精算，验证候选无漏项；
  `stats` 报告候选数（`candidates`）与精算对数（`exactPairs`）。
- **批次更新**：`applyBatch` 原子生效，空间索引按存活集合整体重建，
  被删除的稳定 ID 不会从旧格子复活；同 ID 显式重新添加是允许的。

## 运行

需要 Node ≥ 23.6（原生类型擦除；Node 22.6+ 可加 `--experimental-strip-types`）。

```sh
npm test                          # node:test 测试套件
node src/cli.ts examples/scenario.json   # 或: node src/cli.ts - < scenario.json
```

## 场景格式

```json
{
  "T": "10",
  "cellSize": "2",
  "batches": [
    {
      "add": [{ "id": "a", "rect": { "x": "0", "y": "0", "w": "1", "h": "1" }, "v": ["1/2", "0"] }],
      "remove": ["old-id"],
      "update": [{ "id": "b", "v": ["0", "-3/4"] }]
    }
  ]
}
```

所有数字为精确有理数：`"3/2"`、`"7"`、`"-0.25"`、`1.5` 均可。
输出每个批次的碰撞对及接触区间（分数形式）和统计信息；
若全配对核对发现漏项，进程以非零码退出。

## 文件

- `src/rational.ts` — BigInt 有理数（约分、比较、向下整除取格子）
- `src/geometry.ts` — 闭矩形、扫掠包围盒
- `src/ccd.ts` — 精确求交、空间哈希宽相、批次世界、全配对核对
- `src/cli.ts` — 命令行入口
- `test/ccd.test.ts` — node:test 测试（含随机化无漏项核对）
