# 升级后存储布局把旧余额解释成权限

可升级合约的新版本若改变继承顺序或压缩字段，会把旧存储字节解释成新的权限标志。给TypeScript发布宿主实现可导入的布局兼容包：类型为uintN、intN、bool、address、固定数组、动态数组、mapping和struct；N为8的倍数至256。值类型按声明顺序在槽内从低位打包，不跨槽；struct与数组从新槽开始，动态数组/mapping只占一个根槽且元素布局由宿主固定且版本化的规范路径哈希回调表示；继承按宿主给出的线性化基类顺序展开。旧、新布局每个变量有稳定ID、类型、槽/偏移和保留gap归属。兼容要求所有旧稳定ID在新布局保持相同根槽、偏移和可递归兼容类型；整数只能同符号扩宽且不得挤占相邻旧字段，struct旧字段保持位置，新字段仅追加；动态根类型不可改变；删除只能把原位纳入同一合约gap，gap缩减只从末尾分配。实现差异路径和受影响旧位区间，另用小槽宽参考把随机旧状态按两布局解码，若任何保留变量值变化或普通旧值变成权限类变量则拒绝。覆盖基类重排、bool打包、struct追加、gap消费、mapping值类型变化及变量改名但稳定ID不变。
