容器镜像仓库同时托管多架构 Image Index、OCI v1.1 `subject` 反向关联的签名/SBOM 工件清单以及正在并发推送中的未封口上传租约；垃圾回收器若只从 Tag 向下扫描而漏掉通过 `subject` 反向依附于受保护镜像的签名工件，就会把合规签名清掉，而若未对平台变体做规范化（如 `arm64/v8` 等价于 `arm64`）或未防清单图环路，就会解析失败或死循环。为镜像仓库后端交付可导入的 Go OCI v1.1 清单解析与内容寻址 GC 包。组件实现：1）标准 OCI 层链标识计算：`ChainID(L0) = DiffID(L0)`，`ChainID(L0..Ln) = sha256(ChainID(L0..Ln-1) + ' ' + DiffID(Ln))`，用于校验镜像配置 `rootfs.diff_ids` 与解压层缓存映射；2）多架构 Image Index 平台解析器：按 OCI 规范归一化平台字段（`linux/arm64/v8 -> linux/arm64`、`linux/arm/v7` 等），优先精确匹配 `os/arch/variant/os.version`，支持 `arm/v7` 降级兼容 `arm/v6`/`v5`、剔除 `unknown/unknown` 证明（attestation）清单并确定性报错无匹配平台；3）内容寻址标记-清除 GC：根集合包含全部活跃 Tag、显式 Pin 的摘要、以及尚未过期的活跃上传租约引用；向下遍历 Image Index -> 子 Manifest -> Config + Layers（忽略指向外部不可拉取 URL 的 foreign/non-distributable descriptor 且对嵌套 Index 环路防死循环），同时沿 OCI v1.1 `subject` 反向索引将附着在任意存活清单上的签名/SBOM 工件（含多层链式 `subject`！）及其层一并标活；精准输出待回收的孤儿 Manifest 与 Blob 摘要列表并保证多镜像共享层绝不被误删。验收覆盖 4 层 `ChainID` 校验、`arm64/v8` 规范化与 `unknown/unknown` 证明清单过滤、多层 `subject` 工件保活、活跃上传租约保护、共享基础层保留及环路清单安全终止。
