# 备份恢复授权闭包

恢复一个目录会间接恢复它引用的秘密对象，因此仅有目录级许可并不够。`netsec`
是供 Go 恢复宿主调用的规划包：输入对象引用图（`Graph`）与逐对象许可
（`Authorizer`），计算经过授权校验的可恢复闭包。

## 规则

- **必需依赖（`EdgeRequired`）**：沿引用边传递闭包，每个可达对象都必须存在且被授权；
  任一必需对象缺失或未授权，则拒绝整个恢复（fail-closed），返回包装
  `ErrPlanRejected` 的错误，且不产出任何待恢复对象。
- **可选依赖（`EdgeOptional`）**：绝不隐式拉取。默认记录为显式“留空”的洞
  （`HoleLeftEmpty`）；只有调用方在 `Request.IncludeOptional` 中显式选择的目标才会
  被拉入闭包，并同样接受逐对象授权校验，未授权同样拒绝。
- **循环引用 / 共享秘密**：基于已访问集合的遍历会在环上终止；被多个目录共享的秘密
  在恢复集合中只出现一次。
- **计划与发布之间的撤销**：计划时刻冻结授权快照（`Snapshot`）。`Reverify` 与
  `Publish` 在发布前对照实时授权器重新校验闭包中的每个对象，若期间有许可被撤销，则
  返回包装 `ErrRevoked` 的错误并拒绝发布。

## 主要类型

- `Graph` / `Object` / `Ref`：对象引用图与必需、可选两类引用边。
- `Authorizer`：逐对象授权接口；`GrantTable` 是可撤销、默认拒绝未知对象的内存实现。
- `Request`：恢复根 `Roots` 与显式选择的可选目标 `IncludeOptional`。
- `Plan`：`Status`、`Restore`、`Holes`、`Missing`、`Snapshot`，以及
  `Reverify` / `Publish` 最终复核。

## 测试

```sh
go test ./...
```

测试覆盖必需传递闭包、未授权秘密导致整体拒绝、可选依赖默认留空与显式纳入、
循环引用（含环内未授权节点）、共享秘密去重，以及许可在计划与发布之间被撤销时
`Publish` 的最终复核拦截。
