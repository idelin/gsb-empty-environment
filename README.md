针对多闪存库、非对称擦除扇区及批内一次性编程（OTP）锁定的固件安全升级，给 Go 固件发布宿主实现可导入的写集证明组件。逻辑地址限 48 位，经可选逻辑到物理重映射表与各闪存库独立的 `GF(2)` 仿射位变换映射到多块闪存物理地址（变换矩阵不保证满秩）；各闪存库的引导区与主数据区可具有不同大小的 2 的幂擦除扇区。输入是一组按顺序执行的逻辑段写请求（附可选写掩码）、只读保护区（逻辑或物理坐标）以及批内中途触发的 OTP 写锁定指令（一旦锁定，后续任何擦除或写入均不得触及该物理扇区）。除直接写越界外，还须识别 NOR 闪存“脏字节覆写”触发的隐式整扇区擦除：若向已编程且位值需由 0 改 1 的字节再次写入，会引发所在整个物理扇区擦除并核验是否伤及只读或已锁 OTP 区。禁止遍历地址或展开扇区，发现冲突返回最早动作、最小物理地址及两边最小原像，安全时输出独立区间与线性不可满足证书；缩至 8 位用逐字节模拟穷举对照隐式擦除与 OTP 时序锁。
