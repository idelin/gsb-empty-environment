# 整数区间属性索引

纯 Python 3.11 标准库实现（`bisect` / `re` / `dataclasses`），不使用任何搜索服务或全文检索库。
为文档的整数区间属性建立 **相交 / 包含 / 被包含** 三类索引，支持开放端点与属性缺失，
文档更新时先删除旧索引项再插入新项。

## 文件

- `interval_index.py` — 核心模块（区间规范化、索引、查询、全扫描参照实现）
- `test_interval_index.py` — unittest 测试套件（21 个用例）
- `demo.py` — 运行样例：合成 UTF-8 文档、建索引、查询并与全扫描核对

## 分词规则

文档为本地合成的 UTF-8 文本：

1. 文本按 UTF-8 解码。
2. 先用正则 `range\s*=\s*([\[\(])\s*(-?\d+)?\s*,\s*(-?\d+)?\s*([\]\)])` 提取区间属性，
   形如 `range=[0,5)`、`range=(,8]`、`range=[3,)`；端点省略表示缺失（无穷）。
   出现多个 `range=` 规范时取第一个。
3. 剔除区间规范后的剩余文本用 Unicode 正则 `\w+` 切分词元（字母/数字/下划线的
   极大连续串），并做 `casefold` 小写化；词元进入一个简单的倒排表演示用。

## 区间约定

- 一律规范化为闭区间 `[lo, hi]`：开下界 `(v,` → `lo = v+1`，开上界 `,v)` → `hi = v-1`，
  缺失端点 → `-inf/+inf`。
- **点区间** `[v,v]` 合法，恰好覆盖整数 `v`。
- **空区间**（规范化后 `lo > hi`，如 `(3,3)`、`(2,3)`）：文档中视为缺失属性不入索引；
  作为查询区间构造时抛 `ValueError`。
- 因此 `[0,5)` 与 `[5,8)` **不相交**（前者 hi=4，后者 lo=5）；`[0,5]` 与 `[5,8)` 相交于点 5。
- 缺失区间属性的文档不进入区间索引，任何区间查询都不会命中它。

## 查询语义（Q=查询区间，D=文档区间）

| 方法 | 语义 | 条件 |
|---|---|---|
| `intersect(Q)` | 相交 | `D.lo <= Q.hi` 且 `D.hi >= Q.lo` |
| `contains(Q)` | D 包含 Q | `D.lo <= Q.lo` 且 `D.hi >= Q.hi` |
| `contained_by(Q)` | D 被 Q 包含 | `D.lo >= Q.lo` 且 `D.hi <= Q.hi` |

结果内部用 set 去重、返回排序列表，保证无重复 ID；`full_scan_*` 提供全扫描参照实现，
随机化测试（200 步随机 upsert/delete + 300 次随机查询 × 3 种语义）验证二者完全一致。

## 索引结构与更新

- 两个有序端点列表 `_by_lo` / `_by_hi`（`bisect.insort` 维护，元素为 `(端点键, 序号)`），
  查询时对一维做二分切片、另一维集合作交。
- `upsert(doc_id, text)`：若 doc_id 已存在先 `delete` 删除旧索引项（含词元倒排），
  再重新分词、解析、插入；`delete` 按 `(键, 序号)` 精确定位并移除。
- `check_invariants()` 校验两个有序列表与文档表的一致性（测试使用）。

## 运行

```bash
python3.11 demo.py                 # 运行样例
python3.11 -m unittest -v test_interval_index   # 测试
```
