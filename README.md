# Global Read-View Aligner（分布式事务全局一致性读取对齐器）

分库分表集群的全局快照读取器。各分片产生独立的本地提交时间戳，
对齐器协调各分片的 CDC 流，计算全局因果闭合的安全时间戳 `T_Safe`，
确保跨分片读取看到完全自洽的数据集。

## 核心算法

```
T_Safe = min( 各分片水位线, 所有未闭合事务的最早事件时间戳 - 1 )
```

- **水位线（Heartbeat）**：分片通过心跳上报水位线，表示该时间戳之前的
  CDC 事件已全部送达。
- **因果闭合**：跨分片事务的每个事件携带 `Parts`（涉及的分片总数）。
  当所有分片的事件全部就绪，事务闭合，其全局提交时间戳取各分片
  事件时间戳的最大值。
- **快照发布**：只有 `commitTS <= T_Safe` 的已闭合事务才会并入快照。
  请求 `ts > T_Safe` 的查询视图会被拒绝（`ErrNotClosed`）。
- **不变式**：任何快照要么包含一个事务的全部分片事件，要么完全不包含，
  因此转账的转出与转入永远同时可见，资金总额恒定，杜绝钱凭空消失。
