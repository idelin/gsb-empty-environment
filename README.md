ARM64 Protected KVM（pKVM）在 EL2 超管层通过页所有权状态机（`PKVM_PAGE_OWNED` / `PKVM_PAGE_SHARED_OWNED` / `PKVM_PAGE_SHARED_BORROWED` / `PKVM_NOPAGE`）协调宿主机（Host）、超管（Hyp）与受保护虚拟机（pVM）之间的内存 `share`、`unshare`、`donate`、`lend` 操作时，若某物理页在 `donate` 给 pVM 后宿主机 Stage-2 页表未同步撤销映射、同一物理页被宿主机同时 `share` 给两个隔离 pVM，或 `unshare` 时未校验所有借用方已取消映射并清零机密页内容，恶意宿主机内核可直接窃听或篡改受保护虚拟机内存。为 C++17 虚拟化安全审计宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 pKVM 页所有权状态机与多实体 Stage-2 页表一致性符号验证库。库建模多个隔离实体（Host、Hyp、多个 pVM）、物理页帧元数据与各实体稀疏 Stage-2 区间映射，以及 `HOST_SHARE_HYP`/`HOST_DONATE_HYP`/`HOST_SHARE_GUEST`/`HOST_DONATE_GUEST`/`GUEST_UNSHARE_HOST`/`RECLAIM` HVC 调用序列：（1）严格校验每次 HVC 状态跃迁的前置所有权与权限条件，硬拒绝非拥有者发起 `donate`/`share`、将已 `SHARED_OWNED` 或 `OWNED` 给其他 pVM 的页重复 `donate`/`share` 给第三方、以及越出实体合法物理范围的页帧操作；（2）在每步操作后验证全局页表不变式——任一标记为某 pVM 独占（`OWNED`）的物理页，在 Host 及全部其他 pVM 的 Stage-2 页表中必须彻底不可访问（`NOPAGE`）；共享页仅允许唯一拥有者与唯一借用者同时映射且权限不超过协议约定；页归还（`reclaim`）前必须执行机密擦除标记（`scrubbed=true`）；（3）检出任意违反独占隔离、双重借出或未擦除回收的操作序列并给出最小违例步号与物理页帧号见证。附双重借出拦截、未撤宿主机映射检测、未擦除回收与合法完整生命周期测试。
