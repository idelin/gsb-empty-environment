# treelimiter

树状（分层）令牌桶限速器 + 离散事件模拟。纯 Go 标准库，时间为整数 tick，
不产生真实网络流量。

## 语义保证

- **沿路径原子扣减**：包只在根到叶路径上每个桶都有足够额度时发送；
  扣减要么全部发生，要么全部不发生。子桶有额度但父桶不足时不可发送。
- **有理速率补充**：速率是 `math/big.Rat`（tokens/tick），无浮点误差；
  重复应用同一 tick 是幂等空操作，不会重复补充。
- **取消不消耗令牌**：排队包不预留令牌，`Cancel` 只改队列。
- **运行中重挂租户**：`Reattach` 把子树（含未发送队列与保留令牌）
  作为单个事件原子迁移到新父节点。
- **速率变更安全**：`SetRate` 先按旧速率结算到当前 tick，旧计时器
  不会重复补充。
- **大包显式拒绝**：超过路径上任一桶容量的包在入队时返回
  `ErrOversize`，不入队、不欠账。
- **逐包扣减证据**：每次发送记录 `SendEvidence`（根→叶有序扣减清单）。
- **独立账本审计**：`CheckLedger` 对每个桶验证
  `tokens == initial + refilled - deducted` 且 `0 <= tokens <= capacity`，
  可在任一事件后调用。

## 运行

```sh
go test ./...    # 单元测试 + 穷举/随机交错验证
go run ./cmd/demo
```

## 测试

- `limiter_test.go` 包含有理补充、重复 tick、父桶不足原子阻塞、
  大包拒绝、取消零消耗、速率变更、重挂迁移、证据完整性等专项测试。
- `TestInterleavingsExhaustive` 穷举 8 种事件（发送/取消/补充/重挂）
  所有长度 ≤ 6 的交错序列（262,144 条），每个事件后跑账本审计。
- `TestInterleavingsRandomized` 用 200 个种子跑 120 步随机交错，
  并把证据日志汇总与账本扣减总额交叉对账。
