Node.js 服务端网关受理 JSON Patch（RFC 6902）、JSON Merge Patch（RFC 7396）或嵌套查询字符串时，若对象合并逻辑仅用简单正则过滤 `__proto__` 而忽略 `constructor.prototype`、`JSON Pointer` 转义变体（`~0`/`~1`）、大小写或数组索引越界路径，攻击者可污染 `Object.prototype` 并借下游未定义属性读取（如模板引擎选项、鉴权标志 `isAdmin` 或子进程环境变量）触发远程权限绕过。为 TypeScript 服务端安全宿主实现可导入的零依赖安全补丁执行器与原型污染对抗检测引擎。组件包含两部分：（1）严格无原型污染的 RFC 6902 JSON Patch 与 RFC 7396 Merge Patch 原子事务执行器：完整解析 JSON Pointer（正确处理 `~1`->`/` 与 `~0`->`~` 的不可逆解码顺序，拒绝非法转义），所有写/移/拷/测操作严格校验每段键名不在危险原型链保留集（`__proto__`、`constructor`、`prototype`）且仅允许读取/写入对象自身自有属性（`Object.hasOwn`），并支持路径深度、键数上限及任意单步失败（含 `test` 断言不匹配）时完整回滚至原始不可变快照；（2）面向待审弱合并函数与配置消费链的动态/静态原型污染检测器：在隔离的 `Object.create(null)` 或受控沙箱原型代理（Proxy）上，自动构造 `__proto__`、`constructor.prototype`、嵌套数组/转义路径载荷，实时捕获任何对 `Object.prototype`/`Array.prototype` 的写入企图以及污染属性经下游默认配置对象传播至敏感 Sink 的完整 Gadget 链。附覆盖全部变种与原子回滚边界的验证套件，确保 `Object.prototype` 在测试全程保持零污染。
