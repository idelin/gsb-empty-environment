纠删码对象存储在 `(k, m)` 编码配置下若误用非正交矩阵构造编码行，部分数据与校验组合同时损坏时子矩阵会出现奇异不可逆导致数据永久丢失；此外小块覆写若每次都读回全部 `k` 个数据分片重算校验，放大带宽会拖垮集群。为对象存储数据面交付可嵌入的 C++20 头文件与静态库组件，供存储节点直接调用实现有限域 `GF(2^8)`（不可约多项式 `x^8 + x^4 + x^3 + x^2 + 1`，即 `0x11d`）上的系统化柯西里德-所罗门（Cauchy Reed-Solomon）纠删码引擎。支持任意 `k >= 1, m >= 1, k + m <= 256`：编码矩阵上半部分为 `k x k` 单位阵，下半部分 `m x k` 校验子阵由互异点集 `X, Y` 按 `M[i][j] = inv(x_i ^ y_j)` 构造（保证任意 `k x k` 子阵在 `GF(2^8)` 上严格可逆！）。提供四项核心能力：1）`Encode`：输入 `k` 个等长字节分片生成 `m` 个校验分片；2）`Reconstruct`：给定任意缺失集合（支持同时丢失最多 `m` 个任意数据分片与校验分片混合，超过 `m` 个返回明确错误），抽取存活 `k` 行在 `GF(2^8)` 上高斯消元求逆并精确恢复全部指定目标分片；3）`UpdateDelta`：单数据分片从 `old_data` 变为 `new_data` 时，仅通过 `delta = old_data ^ new_data` 与单列系数增量更新全部 `m` 个校验分片（不读取其余 `k-1` 个数据分片！）；4）`Verify`：快速校验全部 `k+m` 分片一致性并指出单字节篡改。验收覆盖 `(10, 4)`、`(17, 5)` 及极端 `k+m=256` 边界下随机抽取全部混合缺失组合恢复、`UpdateDelta` 连续百次随机覆写后与全量重编码逐字节一致、空分片/奇数长度分片处理及超 `m` 块损坏拒绝。
