# rbcast-sim

可靠广播模拟器（Go）。消息以 `(Source, Seq)` 标识，源端序号严格递增。

## 设计

- **连续水位 + 稀疏缺口表**（`rbcast/node.go`）：每个节点为每个源维护
  `watermark`（已连续交付的最大序号）和有界 `gaps` 集合（水位之上已交付的
  乱序序号）。`seq <= watermark` 或在缺口表中即判重；缺口表满时拒绝过远的
  消息，等待补传。历史有界，但离线重连后的旧消息重传仍可被识别为重复。
- **压缩门控**（`rbcast/source.go`）：源端保留重传日志，仅当**所有当前有效
  订阅者**的确认水位都越过某序号时才压缩到该点；离线（未退出）成员会一直
  钉住历史，保证其补传所需消息仍在。
- **成员代次**（`rbcast/membership.go`）：每次重入 `generation++`。确认携带
  `(MemberID, Generation)`，退出前代次的确认一律拒绝；退出即不再是有效订阅
  者、不再阻塞压缩，重入后须在新代次下重新确认。
- **网络模拟**（`rbcast/network.go`）：可配置丢包、重复、乱序（滑动窗口洗牌），
  种子随机数保证测试确定性。

## 运行

```sh
go test ./...
go run .
```
