# signal-recover — 整数信号恢复工具

从线性采样矩阵的部分观测反推有界整数信号：给定 `A·x = b`（欠定、满秩或秩亏均可）和每个分量的上下界 `lo ≤ x ≤ hi`，精确判定原信号是否唯一可恢复。

- **唯一**：输出恢复的信号；
- **多解**：输出两个不同的可行信号；
- **无解**：输出冲突观测（最小冲突子集，或整系数冲突证书）。

信号维度最多 12，全部运算使用任意精度有理数/整数（`math/big`），无浮点误差。判定基于**真实整数可行域的精确求解**，不会把矩阵秩不足直接等同于整数域多解——秩亏但界内只有一个整数点时仍正确判为唯一。

## 构建与运行

```sh
go build -o signal-recover .
./signal-recover examples/unique.json     # 从文件读取
cat examples/unique.json | ./signal-recover   # 或从标准输入读取
```

## 输入格式（JSON）

```json
{
  "matrix": [[1, 1], [1, -1]],
  "observations": [5, 1],
  "lower": [0, 0],
  "upper": [10, 10]
}
```

- `matrix`：m×n 采样矩阵；`observations`：m 个观测值；`lower`/`upper`：n 个分量的闭区间界。
- 数值可以是 JSON 整数、字符串整数或字符串分数（如 `"3/2"`），内部统一化为精确整数问题（每行乘以分母公倍数，界取整到最近合法整数）。

## 输出格式（JSON）

```json
{"status": "unique",   "signal": [3, 2]}
{"status": "multiple", "signals": [[6, 0, 0], [5, 0, 1]]}
{"status": "infeasible", "conflict": {"observations": [0, 1], "coefficients": [-2, 1], "explanation": "..."}}
```

- 观测系统本身在整数域不相容时，`coefficients` 给出整系数证书：观测的该整系数组合迫使 `0 = c`（或要求某倍数等于非倍数），`observations` 为证书实际用到的观测下标。
- 方程相容但界内无可行整数点时，`observations` 给出与界共同矛盾的最小观测子集（删除式极小化）。

## 方法

1. **Smith 对角化**：对整数矩阵 `A` 计算幺模矩阵 `U, V` 使 `U·A·V = S` 为对角阵。`A·x = b` 等价于 `S·z = c`（`z = V⁻¹x` 仍遍历整个 `Zⁿ`），相容性由 `s_i | c_i` 精确判定，不相容时 `U` 的对应行即整系数冲突证书。
2. **解的参数化**：`x = x₀ + W·t`，其中 `W` 为 `V` 的后 `n − rank` 列（整数零空间基），`t ∈ Zᵏ` 自由。
3. **界内搜索**：利用 `V⁻¹` 的行把每个自由变量表示为 `x` 的整线性型，得到精确有限初始域；随后区间传播 + 二分分支定界，找到至多两个可行信号即可判定唯一/多解，全部精确运算。
