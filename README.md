# 秘密比较的可观测轨迹

给Go认证宿主实现可导入的秘密字节串比较包及解释执行的恒定轨迹检查器。不是测墙钟：自定义指令只含定址读、异或、或、加一、公开上界循环和按值分支；每次记录读地址与分支结果。秘密固定32字节，候选固定32字节，长度验证在进入秘密区域前完成。实现比较程序和解释器，穷举每个字节位置的单字节差异及全相同，要求轨迹一致且结果正确；检测器还接收任意至多128条指令的程序，对调用方给定秘密/候选有限集合两两比较轨迹，返回最短差异及完整输入见证。未知预算不能当作通过，不能宣称有限集合证明任意机器码恒定时间。

## 实现说明

- `isa.go`：指令集（定址读/异或/或/加一/公开上界循环/按值分支）、轨迹事件与静态校验（≤128 条、寄存器编号、结构化循环、分支不出层）。
- `interp.go`：解释器 `VM`，逐步记录读地址与分支结果；显式步数预算，超预算返回 `ErrStepBudgetExceeded`。
- `compare.go`：`CompareProgram` 为无分支固定轨迹比较程序（64 次定址读，异或-或累积）；`Equal` 先做公开的长度验证再进入秘密区域。
- `check.go`：`Check` 对调用方给定秘密/候选有限集合做笛卡尔积并两两比较轨迹；发现分歧返回最短差异（最早分歧点，并列取较短轨迹）与完整输入见证。预算缺失或耗尽、程序非法、输入过少均为 `VerdictUnknown`，绝不算通过；`VerdictPass` 附带 `PassDisclaimer`，仅声明该有限集合在该预算下轨迹一致，不证明任意输入或任意机器码恒定时间。

```go
ok := netsec.Equal(secret, candidate)              // 固定轨迹比较
rep := netsec.Check(prog, secrets, candidates, 1<<16) // 有限集合轨迹检查
```

测试：`go test ./...` 穷举 32 个位置 × 255 种单字节差异及全相同，验证轨迹一致且结果正确。
