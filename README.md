# LSM钩子inode决策与审计

eBPF LSM 钩子拒绝打开受保护文件，攻击者借硬链接、重命名、绑定挂载或并发切换挂载命名空间换路径，且审计记录与决定不一致会掩盖拒绝。为C++17守护组件实现供模拟内核钩子调用的决策与审计包：策略按（设备号，inode）保护文件，路径提示只写入日志；多个程序按挂载顺序执行，任一返回拒绝即最终拒绝且后续程序不再执行；每次钩子调用恰产生一条审计，内容含最终决定、第一个拒绝的程序和inode；环形缓冲写满时仍按策略拒绝并累加丢失计数，下一条成功记录携带丢失数，并发调用下丢失计数与记录不得错配；策略代次切换时，旧代次在途调用按旧策略完成并标注代次。用硬链接别名、重命名后访问、并发切换命名空间、多程序拒绝顺序、缓冲写满和代际切换分别对照预期与实际结果。
