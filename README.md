# 秘密模逆算法泄露迭代轨迹

密码组件用分支欧几里得算法求秘密标量逆元，攻击者可观察每轮走减法还是交换分支并区分秘密。给Go侧信道测试宿主实现可导入的双执行包：模数p为调用方给定奇素数且p≤65521，秘密x在1至p-1；待审回调返回逆元及轨迹符号串，轨迹字母只能是A(若u偶则u/=2)、B(若v偶则v/=2)、C(若u>v则u=(u-v)/2)、D(否则v=(v-u)/2)，初态u=x、v=p，直到u或v为1，超过预算失败。包独立重放轨迹，核对每步分支条件和最终逆元；再枚举所有x，按轨迹分组，输出任何两秘密轨迹不同的最短区分前缀及每组候选集合。加固回调必须执行固定2*bitlen(p)+1轮：每轮以无分支掩码更新四个候选状态，完成后选择已收敛结果；对外轨迹只含固定轮数的统一符号，结果与大整数参考一致，否则拒绝。用p≤257穷举所有x核对正确性、轮数、候选分区和最大未收敛输入，明确统一符号不证明真实机器指令恒时，生产实现仍需平台级审计。

## 包结构

- `invert.go` — 待审回调 `VulnerableInvert(x, p, budget)`：分支二进制欧几里得求逆，返回逆元与 A/B/C/D 轨迹，超预算返回 `ErrBudget`。
- `verify.go` — `VerifyTrace(x, p, inv, trace, budget)`：独立重放轨迹，逐步核对分支条件与最终逆元。
- `analyze.go` — `Analyze(p)`：枚举全部 x 按轨迹分组，输出最短区分前缀、每组候选集合、最长轨迹与未收敛输入。
- `hardened.go` — 加固回调 `HardenedInvert(x, p)`：固定 `2*bitlen(p)+1` 轮，每轮无分支掩码更新四个候选状态 `(u, v, ua, vb)`，收敛后冻结，结束后选取已收敛结果并与 `big.Int` 参考核对，不一致即拒绝；对外轨迹为固定轮数的统一符号 `X`。

## 测试

`go test ./...` 对 p≤257 的全部奇素数穷举所有 x，核对：逆元正确性、轨迹重放、篡改检测、固定轮数与统一符号、候选分区一致性、最短区分前缀、无未收敛输入。
