# 时间桶词频趋势索引

纯 Python 3.11 标准库实现：按时间桶维护词文档频率（DF），比较两个滑窗的
平滑比率并输出 TopK趋势，附独立全量重算校验。不使用搜索服务或全文检索库。

## 分词规则（trend/tokenizer.py）

1. 输入为已解码的 Unicode 字符串（本地 UTF-8 文本由调用方解码）。
2. 先 `casefold()` 做 Unicode 大小写折叠。
3. token = 「Unicode 字母或数字」(`str.isalnum()`) 的极大连续片段；
   其余一切字符（空白、标点、下划线、符号）均为分隔符。
4. 不词干化、不去停用词、不做 CJK 切词：连续汉字整体为一个 token。
5. 文档频率语义：同一词在同一文档中重复出现只计一次。

## 设计要点

- **时间桶**：`bucket = ts // bucket_size`，每桶维护 `词 -> doc_id 集合`
  与 `doc_id 集合`；写入/撤回只触碰文档所属的单个桶，**禁止每次扫描全部历史**。
- **迟到文档**：按自带时间戳落入对应历史桶并修订该桶统计；
  同 `doc_id` 不同内容视为修订（先撤旧桶再入新桶）；
  同 `doc_id` 同内容为重复事件，幂等忽略并计数。
- **时间桶撤回**：`retract_document(doc_id)` 按文档身份移除。
- **滑窗**：窗口 = `[start, end)` 覆盖的连续桶；分母 = 窗口内去重的可见
  `doc_id` 数（按文档身份维护，随撤回/修订变化）。
- **平滑比率**：`score = (df_recent + alpha) / (df_base + alpha)`，
  `alpha > 0`，故 0→1 的变化得有限分 `(1+alpha)/alpha`，而非无穷。
- **空窗保护**：近期窗可见文档数为 0 时返回空排名，不伪报增长。
- **最低支持数**：`df_recent >= min_support` 才进入排名。
- **TopK 界剪枝**：逐桶扫描近期窗，词的部分 DF 为 `df`、窗口剩余文档数
  为 `rem` 时——
  - 支持数上界：`df + rem < min_support` ⇒ 剪枝；
  - 分数上界：`ub = (df + rem + alpha) / (df_base + alpha)` 低于当前候选
    第 k 大下界 `lb = (df + alpha) / (df_base + alpha)` ⇒ 剪枝。
  平滑项与最低支持数共同进入上界；正确性由「每个候选终分 ≥ 其下界」保证，
  并有暴力参考实现对照测试。
- **独立全量重算校验**（trend/checker.py）：只重算两个窗口覆盖桶内的文档，
  核对分母变化、零窗、重复事件与逐词 DF；每次排名更正都输出贡献证据
  （该词在两个窗口中分别由哪些 `doc_id` 贡献）。
