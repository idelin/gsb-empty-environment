云原生网络策略同时允许编写 Allow 与 Deny 规则，每条规则可指定多组带 `except` 排除列表的 CIDR 网段及端口闭区间；当多条带排除项的规则重叠且 Deny 优先时，朴素顺序扫描既慢又难以发现被彻底遮蔽的死规则。为数据面控制编译器交付可导入的 Go 策略编译与查表包。输入策略选择器是否命中当前工作负载、若干 Allow 与 Deny 规则（每条含唯一编号、协议 TCP/UDP、IPv4 CIDR、若干可嵌套或越界的 `except` CIDR 及端口区间列表）。规则：每条规则的有效地址集为原 CIDR 减去全部 `except` CIDR；若工作负载未被任何策略命中则默认放行，一旦命中至少一条 Allow 或 Deny 策略，未显式允许的流量默认拒绝，且同时命中 Allow 与 Deny 时 Deny 严格胜出。编译器须将全部有效 IPv4×端口矩形区域分解并合并为互不重叠的最简规范前缀与端口分段查找表（每个表项标明精确动作与命中规则 ID），同时报告被 Deny 或高优规则完全吞没、在任何输入流上都不会生效的无效 Allow 规则 ID。验收用压缩坐标网格枚举全部关键点对照逐规则朴素求值器，覆盖 `except` 挖洞切出多个子前缀、两相邻互补子网合并还原父前缀、Deny 仅切掉 Allow 的部分端口段、以及 Allow 完全落入 Deny 集合被判为死规则。
