# 低浪费切割计划（cutting stock）

Python 3.11，仅标准库（`fractions` / `unittest` 等），不调用任何求解器。
小规模精确分支搜索（branch & bound），支持：

- 有限原料规格集合（单一固定长度是其特例），每种规格可限量或不限量、带单根成本
- 需求段带数量，切缝（锯缝）损耗按定义计入
- 有限库存与余料复用：余料以 0 成本限量规格回库，跨批次顺序/联合优化
- 目标按"损耗再原料成本"字典序：先最小化毛损耗，再最小化原料成本
- 给出损耗下界、可行切割清单、独立长度守恒验证
- 预算（节点数）耗尽时返回当前最优可行解并标记"未证最优"
- 超长需求直接判不可行；需求逐项精确满足，不多用库存
- 同一根余料不会被多个批次同时消费（库存即时入账）

## 切缝定义

一根原料切出 k 段：仍有余料时需 k 次切割；恰好用尽时需 k-1 次。
可行条件：`sum(pieces) + kerf*k <= L`，或 `sum(pieces) + kerf*(k-1) == L`。

## 状态分类

- `optimal`：搜索完成，已证最优
- `feasible`：有可行解，但预算耗尽，未证最优
- `infeasible`：已证不可行（含超长需求的直接判定）
- `unknown`：预算耗尽且尚未找到可行解

## 用法

```python
from cuttingstock import Demand, Inventory, StockSpec, run_batches, solve, verify_plan

# 单次求解
res = solve([Demand.of(1200, 4), Demand.of(900, 3)],
            [StockSpec.of(6000, cost=12, count=10), StockSpec.of(3000, cost=7, count=5)],
            kerf=3, min_remnant=400, max_nodes=100_000)

# 跨批次：余料回库供后续批次；joint=True 合并为一次联合求解
inv = Inventory([StockSpec.of(6000, cost=12, count=10)])
camp = run_batches([("b1", [Demand.of(600, 1)]), ("b2", [Demand.of(400, 1)])],
                   inv, kerf=0, min_remnant=300)

# 独立校验：长度守恒 / 需求逐项满足 / 库存不超限，返回错误列表
errors = verify_plan(res.bars, demands, stocks, kerf=3)
```

长度、切缝、成本均可为整数或有理数（`Fraction`、字符串如 `"1/3"`），全程精确运算。

## 说明与限制

- 精确分支搜索面向小规模（需求段总数几十以内）；更大规模请调低 `max_nodes`
  换取 `feasible`/`unknown` 状态下的现任最优解与下界。
- 下界为松弛界：库存视为不限量、忽略切缝与整段不可分性，恒有 下界 ≤ 实际损耗。
- 优化目标为毛损耗（消耗总长 - 需求总长）；可复用余料不计入损耗减免，
  而是回库在后续批次以 0 成本优先消耗，避免"余料虚增"导致的退化解。
