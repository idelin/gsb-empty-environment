关系查询优化器若把普通内连接的交换律与结合律直接套用到外连接（`LEFT`/`RIGHT`/`FULL OUTER JOIN`）上，会立刻产生错误补空行或丢失本应保留的外表行；必须先执行精确的**强空值拒绝（Null-Rejecting）**外连接降级，再按 Galindo-Legaria / Rosenthal 恒等式严格验证重排合法性！例如：`WHERE NOT (b.x = 1)` 对 `b.x = NULL` 求值为 `UNKNOWN`（属于强空值拒绝，可将 `A LEFT JOIN B` 安全降级为 `INNER JOIN`！），但 `WHERE b.x IS NULL`、`WHERE COALESCE(b.x, 0) = 0` 以及析取 `WHERE b.x = 1 OR a.y = 2`（当 `b.x=NULL` 且 `a.y=2` 时整式为 `TRUE`！）均**不是**对 `B` 强空值拒绝；同样，`(A LEFT JOIN B ON p_ab) LEFT JOIN C ON p_bc` 只有当 `p_bc` 对 `B` 强空值拒绝时才等价于 `A LEFT JOIN (B LEFT JOIN C ON p_bc) ON p_ab`，而对 `FULL OUTER JOIN` 与 `INNER JOIN` 嵌套的重排条件更加苛刻！为查询优化器交付可导入的 Go 外连接降级与等价重排验证包。输入为含 `INNER`/`LEFT`/`RIGHT`/`FULL` 连接节点与顶层 `WHERE` 过滤的逻辑查询树（谓词支持三值逻辑 `AND`/`OR`/`NOT`、比较、`IS [NOT] NULL`、`COALESCE`、`CASE WHEN`、`IN`）。规则：1）实现基于三值 Kleene 逻辑（`TRUE`/`FALSE`/`UNKNOWN`）的精确强空值拒绝判定器（将目标关系全部属性强制置为 `NULL` 并穷举/符号评估其余属性所有可能真值组合，确认谓词永不可能为 `TRUE`！）；2）自顶向下应用空值拒绝降级（`FULL` 仅左拒绝降为 `RIGHT`、仅右拒绝降为 `LEFT`、双侧均拒绝或上层某侧拒绝级联降为 `INNER`，并正确区分 `ON` 谓词与 `WHERE` 谓词——`ON` 里的谓词只影响匹配，绝不能把所在外连接自身降级！）；3）枚举所有严格保持多重集（BAG）语义等价的合法外连接树形态（应用 `LEFT`/`FULL` 结合律、交换律与 `INNER`/`LEFT` 提升规则，拒绝全部反例重排！）；4）内置多表求值器在含重复行与大量 `NULL` 的测试表上逐一核验原计划与全部重写计划输出多重集 100% 相同。验收覆盖三值 `NOT`/`OR`/`COALESCE`/`CASE` 空值拒绝边界、`ON` vs `WHERE` 降级禁忌、`FULL` 单双侧降级、Galindo-Legaria 合法与非法结合重排以及含重复行与 `NULL` 的多重集求值等价性。
