# cogbin — 离散位置分箱求解器（精确重心约束）

为带重量的物品选择箱内离散位置，满足每箱容量，并使每箱重心落在安全区间内。

- **主目标**：最少箱数
- **次目标**：最小化最大偏心量 `max |重心 − 区间中心|`
- **规模**：最多 18 件物品、64 个离散位置
- **精确性**：所有重量、位置、重心、偏心量均以 `math/big.Rat` 精确分数计算与验证，不使用任何浮点容差放宽约束

## 构建与使用

```sh
go build -o cogbin .

./cogbin solve  examples/demo.json      # 求解，输出摆放证据 JSON（stdin 亦可）
./cogbin verify /tmp/demo.sol.json      # 独立复核解文档（内嵌输入）
go test .                               # 单元测试
```

## 输入格式

```json
{
  "capacity": "100",
  "positions": ["0", "10", "20", "30", "40", "50"],
  "safe_interval": ["18", "32"],
  "items": [{"id": "engine", "weight": "55"}],
  "max_nodes": 50000000
}
```

- 所有有理数可写为字符串（`"3/2"`、`"1.5"`、`"7"`）或 JSON 数字，解析为精确分数。
- `positions`：每个箱内相同的离散槽位坐标；每槽每箱至多放一件。
- `safe_interval`：每箱重心必须落在 `[lo, hi]` 内（硬约束）。
- `max_nodes` 可选，搜索节点预算，默认 5×10⁷，超限报错而非给出不可靠答案。

## 输出（摆放证据）

每个箱报告：物品→位置、总重量、重心（精确分数 `p/q` + 小数）、偏心量、是否在安全区间；整体报告箱数与最大偏心量。`verify` 子命令从摆放证据用精确分数**重新计算**全部量并逐项比对（重量不超容量、槽位不重复、重心确实落在区间内、报告值与重算值完全一致）。

## 算法

1. **预计算**：对每个满足容量与槽数上限的物品子集（位掩码，2¹⁸ 以内），精确求解其槽位分配问题——按重量降序放置，用重排不等式得到剩余物品与剩余槽位的力矩上下界做分支限界，记录该子集的最小偏心量及见证分配。
2. **主目标**：在可行子集上做集合划分搜索（最低位物品播种 + 失败状态记忆化），从容量/槽数下界起找最少箱数 k。
3. **次目标**：k 固定时，“存在最大偏心量 < L 的划分”关于 L 单调，对所有不同偏心量值二分查找最小可行 L，再构造见证划分。

`verify` 只复核一致性与约束满足；最优性（最少箱数、最小最大偏心量）由求解器的完备搜索保证。
