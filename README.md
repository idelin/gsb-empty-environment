# delaunay — 精确整数坐标的确定性 Delaunay 三角剖分

纯 Go 标准库实现。二维整数坐标（任意精度，`math/big`），支持逐点插入，
输出逆时针三角形、邻接关系和凸包；重复、共线、共圆数据均有明确、
公开、可复现的处理规则。

## 精确性

- 方向判定 `orient` 与内接圆判定 `inCircle` 全部使用 `math/big`
  任意精度整数运算，任何大小的坐标都不会溢出、不会有浮点误差。
- 输入坐标为任意精度整数（JSON number），内部以 `big.Int` 存储。

## 规范结果（公开的决胜规则）

同一批不同坐标点，无论输入顺序如何，输出完全相同（canonical）：

1. **去重**：相同坐标合并为一个点，保留所有来源 ID（输出中按字典序排列）。
2. **插入顺序**：内部一律按坐标 `(x, y)` 字典序插入（Bowyer–Watson）。
3. **共圆决胜**：内接圆判定为**严格**判定——第四点恰好共圆不算违反。
   结合固定的插入顺序，共圆退化被确定性地消解。
4. **输出规范化**：输出点按下标 `(x, y)` 字典序编号；每个三角形旋转到
   最小下标顶点开头（保持逆时针），三角形列表按字典序排序。

因此共圆四点（如正方形）的剖分对角线由上述规则唯一确定，
与输入顺序无关。

## 退化输入

- `empty` / `point` / `segment`：少于 3 个不同点，输出 `chain`。
- `collinear`：全部共线（≥3 点），输出沿支撑线严格有序的点链 `chain`。
- 凸包边界上的共线点保留在 `hull` 环中（不翻转、不丢点）。

## JSON 输入输出

```sh
echo '{"points":[{"id":"a","x":0,"y":0},{"id":"b","x":4,"y":0},{"id":"c","x":2,"y":3}]}' \
  | go run ./cmd/delaunay
```

输出：

```json
{
  "mode": "triangulation",
  "points": [{"index":0,"x":0,"y":0,"ids":["a"]}, ...],
  "triangles": [[0,1,2], ...],        // 逆时针，顶点为 points 下标
  "adjacency": [[1,-1,-1], ...],      // adjacency[t][i] = 三角形 t 第 i 顶点对边的邻居，-1 为边界
  "hull": [0,1,3,2],                  // 逆时针凸包环（含共线边界点）
  "valid": true                       // 内置独立校验器通过
}
```

共线时输出 `"mode":"collinear"` 与 `"chain":[...]`（有序线链）。

## 独立校验器

`Validate(raw, out)` 不复用剖分逻辑，独立检查：

- 去重/合并一致性（坐标与来源 ID 集合）；
- 每个三角形逆时针、顶点互异，每个点都被使用；
- 边流形性（每边至多 2 个三角形）与邻接对称（重算邻接并逐项比对）；
- Euler 关系 `V - E + F = 1` 与 `3F = 2E - B`；
- 面不重叠：三角形面积和（精确整数）== 凸包面积；
- 凸包覆盖：凸包逆时针、凸、每条边都是剖分边界边、所有点在凸包内或边界上；
- Delaunay 性质：任意第四点**不严格位于**任一三角形外接圆内（共圆允许）。

## 测试与可重现实验

```sh
export GO111MODULE=on
go test ./...        # 单元测试 + 全部校验
go run ./cmd/repro   # 可重现实验：50 次随机打乱输入，输出逐字节一致且通过校验
```

测试覆盖（均为精确断言，不以"网格看起来均匀"为验收）：

- 3×3 整数网格全部 512 个子集：逐一校验 + 打乱后输出一致；
- 四点共圆（正方形）全部 24 种排列、圆上 12 点 + 圆心 20 种随机打乱：
  输出逐字节一致；
- 500 点长共线链（含垂直线）：输出严格有序线链；
- 逐点插入到边上 / 凸包边延长线上 / 内部边上，每步插入后校验；
- 大坐标（~2^60）：`int64` 会溢出的方向/内接圆判定用例；
- 重复坐标合并与来源 ID 保留；
- 30 组随机点集 × 5 种打乱：规范输出一致；
- 校验器反向测试：翻转三角形、丢三角形、错误邻接、错误凸包、
  非 Delaunay 剖分、乱序线链、丢失来源 ID 均被检出。

## 实现说明

- 算法：Bowyer–Watson 逐点插入 + 超三角形。超三角形按点集直径立方
  （`32·d³`）缩放：整数点非共线三元组面积 ≥ 1/2，故外接圆半径
  `R = abc/(4A) ≤ D³/2`，超三角形顶点严格落在所有真实外接圆之外，
  不会抑制任何真实 Delaunay 三角形。
- 插入点与空腔边界边共线时跳过零面积三角形（该点必在边的延长线上，
  边留在凸包上，凸包链正确延伸）。
- 复杂度说明：`Insert` 仅登记点集，`Result` 一次性确定性重算，
  这是规范输出与输入顺序无关的直接保证。
