CA 跨机房汇聚多路验证回执时，须防范同一运营方借多探针或隧道地址刷票并防止历史撤销追溯污染已签证书。给 Go 签发宿主实现可导入的证据汇聚包：订单绑定公网 IP（严格规范化并拒绝所有 IPv4/IPv6 保留、文档、基准测试、链路本地、多播、环回，以及 IPv4 映射 IPv6 `::ffff:0:0/96`、NAT64 `64:ff9b::/96`、Teredo `2001::/32` 与 6to4 `2002::/16`）、端口、挑战类型、账户、nonce 与公钥摘要。每份签名回执携带探针观察区间 `[Start, End)`、连接地址、证明摘要、多个带版本号的身份归属以及路由起源与中转 ASN 集合；每个身份绑定和路由证明自带 `[NotBefore, NotAfter)` 有效期。签发仅在至少 `k` 个互异管理域、每个路由起源与共享中转运营方至多各计一票、所有选中回执各取一个同版本有效归属且所有选中观察区间与各绑定的有效期在订单授权窗内存在公共交点时成立。按见证数最多、总代价最小、编号字典序最优选择；撤销版本号 `v` 仅作废 `<= v` 绑定，且按签发时刻重验历史。另提供独立验收组件核对域数、特殊前缀拒绝、时间公共交点及是否存在更优合法子集，并用小集合穷举检验中转冲突、前缀拒绝与版本隔离。
