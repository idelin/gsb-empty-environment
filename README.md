# 跨账号代办角色的混淆代理绑定

备份平台代表多个客户调用云角色，若只按目标角色授权，客户A可让平台代入客户B的角色。给Go凭据宿主实现可导入的代办授权包：平台注册租户记录包含tenantID、精确roleID、随机128位externalID、允许的sourceResource集合、最大会话秒数和策略摘要；请求者身份由宿主认证上下文提供，不从请求体读取。Assume请求含tenantID、roleID、externalID、sourceResource、sessionName、duration和调用参数摘要；六项及请求者主体须写入规范授权决定摘要。只有tenantID属于请求者、roleID与登记精确相等、externalID常量时间匹配、sourceResource在集合中且资源所有者仍为该租户才调用外部STS回调；sessionName须为1至64字节安全ASCII且仅作审计，不能参与授权匹配。回调返回凭据的audience、roleID、sourceIdentity、过期时刻和sessionID，全部须与决定一致，过期不晚于请求上限；不一致立即销毁凭据。并发相同requestID与参数只调用一次并返回同结果，requestID相同参数不同拒绝。租户配置换代后旧在途结果不得发布。用两个租户同一平台主体测试换role、externalID、资源归属、迟到回调和并发重试，核对任何交付凭据都能回溯到唯一租户决定。
