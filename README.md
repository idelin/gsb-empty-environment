# tiered-piecewise

按题内合成阶梯规则计算分段函数：区分**累进分段**与**整量落档**，端点开闭显式，
多规则叠加带最低/最高/折扣条件，编译为精确分段函数，并支持**反求**所有满足给定输出的输入区间。
纯数值函数库，不连接真实订单或计费服务。

- 精确算术：全部基于 BigInt 有理数（`src/rational.ts`），大数不经过 `Number` 中转。
- 舍入显式：`floor` / `ceil` / `trunc` / `half-up`（平局向 +∞）/ `half-away-from-zero` / `half-even`，
  量子（quantum）为任意正有理数。段舍入与最终总额舍入**独立建模，不可交换**。
- 运行要求：Node.js ≥ 23.6（原生 TypeScript 类型擦除），零依赖。

## 语义约定

- **累进分段（progressive）**：每档只对自己覆盖的部分计费，`rate * 覆盖量 + fixed`；
  `fixed` 在覆盖量严格为正时触发（`x` 恰等于档下界时该档贡献为 0）。
- **整量落档（whole）**：`x` 落入的唯一档位对全部 `x` 计费，`rate * x + fixed`。
- 每条规则的档位必须构成全实轴的划分：相邻边界**恰好一侧闭**（恰阈值不双计、不留缝），
  结构校验拒绝闭-闭（重复计数）与开-开（漏点）。
- 每档可带 `min`/`max`（段贡献钳制，仅作用于激活段）；每规则可带 `discount`（小计折扣）；
  组合可带全局 `min`/`max` 与 `finalRounding`。
- 计算顺序固定：段原始值 → 段舍入 → 段 min/max → 规则小计 → 折扣 → 跨规则求和 → 全局 min/max → 最终舍入。
- 累进规则中下界为 -∞ 的档必须 `rate = 0`（否则覆盖量无穷）。

## API 概览

```ts
import { parse, evaluate, formatTrace, compile, evalCompiled, invert } from './src/index.ts';

evaluate(spec, parse('123.45'));   // 直接求值，返回逐段贡献证据（EvalTrace）
formatTrace(trace);                // 证据的文本渲染
compile(spec);                     // 编译为精确分段函数（断点 + 原子区间上的项）
evalCompiled(compiled, x);         // 编译形式求值，与 evaluate 完全一致
invert(compiled, y);               // 反求：所有满足 f(x)=y 的 x 区间（平台多解）
```

## 反求能力

`f = finalRound ∘ clamp ∘ S`，其中 `S` 为编译后的核（线性项 / 舍入阶梯项 / 钳制项之和）。
反求精确计算 `S(x) ∈ clampPreimage(roundPreimage(y))`：在有界原子区间上枚举全部舍入跳点与钳制拐点；
在无界区间上用线性部分的有界误差盒归约为有界枚举；常数射线（平台）整体判定。
已知限制：整条实轴为单一区间且带非零费率单侧钳制时会抛出说明性错误。

## 测试（`node --test test/*.test.ts`）

Node 内置测试运行器，30 个测试全部通过。要点：

- 小有理网格参考验证：编译形式与直接求值在 `k/4` 网格（含负输入、含全部断点）上逐点一致；
  反求区间与直接求值在网格上双向核对（`x` 在解集中 ⟺ `f(x)=y`）。
- 跨档时累进与整档结果不同；恰阈值恰好归属一侧；闭-闭/开-开划分被拒绝。
- 段舍入与最终舍入不可交换（同一输入给出不同精确结果）。
- 平台多解：`f(x)=5 → [-5,0] ∪ [5,10]`；不可达输出（非量子倍数）解集为空。
- 大数精确：`123456789012345678901234567890 / 3 = 41152263004115226300411522630`，不经 Number。
- 舍入逆像与舍入函数在网格上逐点一致（含 half-even 平局、负值）。
