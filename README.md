# matdiag — 小型矩阵数值诊断工具

带部分主元的 LU 求解 + 残差/后向误差估计 + 奇异性分级诊断 + 对角均衡缩放，
并以 `big.Rat` 有理精确解作为前向误差参照。

## 运行

```sh
go test ./...        # 全部测试
go run ./cmd/matdiag # 四个演示案例
```

## 诊断判据（尺度无关，不用固定绝对阈值）

- **真奇异**：消元中某一步主元列（第 k..n-1 行）全为精确的 0，即精确秩亏。
  这与任何阈值无关，单独报告，不给出解。
- **近奇异**：条件数估计 `cond1 >= 1/sqrt(eps) ≈ 6.7e7`（可用有效数字不足一半）。
  条件数对矩阵整体乘常数不变，因此判据天然尺度无关。
- **尺度不良**：原始 cond 越界但**对角均衡后** cond 良好——病态是缩放伪影，
  与真正的近奇异区分开。
- **主元比**：每步主元与矩阵最大元之比（同样尺度无关），仅作辅助提示。

反例见演示案例 2a：`1e-12·I` 的主元绝对值仅 1e-12，任何固定绝对阈值
（如 1e-8）都会误判为奇异，但它的 cond = 1，完全健康。

## 残差与后向误差

- 残差 `r = b - A x`，报告 `||r||_inf`。
- 范数后向误差 `η = ||r||_inf / (||A||_inf·||x||_inf + ||b||_inf)`：
  x 是邻近问题 `(A+ΔA)x = b+Δb`（相对扰动 ≤ η）的精确解。
- **小残差 ≠ 小误差**：前向误差受 `cond·η` 控制（演示案例 3：
  候选解残差 1e-6，前向误差却达 0.9）。

## 对角均衡与映射回原变量

`Equilibrate` 计算 `Dr = diag(Row)`、`Dc = diag(Col)`（均取 2 的幂，乘法精确）：

```
原系统:   A x = b
缩放后:   (Dr·A·Dc) y = Dr·b
映射回:   x = Dc·y        // MapBack
```

行缩放只作用于系数矩阵与右端项，不改变未知量；列缩放等价于换未知量
`y = Dc^{-1} x`，故解出 y 后必须乘回 `Dc`。

## 有理参照

`RatMatrix`/`RatVector` 把 `"1/3"`、`"0.563"`、`"1e-12"` 等字符串解析为
精确有理数，`ExactSolve` 用精确高斯消元求真值，`RelForwardError`
给出浮点解的真实前向误差。测试覆盖：行交换、尺度悬殊（`1e-12·I` 与
`diag(1e-12,1)`）、小残差大误差（Forsythe–Moler 经典例）、真奇异 vs
近奇异、Hilbert(8) 前向误差度量。

## 文件

- `lu.go` — 部分主元 LU 分解与求解
- `cond.go` — 显式求逆估计 cond1（诊断用途，O(n^3)）
- `diagnose.go` — 残差/后向误差/奇异分级报告
- `scale.go` — 对角均衡与映射回
- `exact.go` — big.Rat 精确解与前向误差
- `cmd/matdiag/main.go` — 演示
