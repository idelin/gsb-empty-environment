设备总线通过句柄授权消息端点。给 Go 总线宿主写可嵌入的能力转移包，调用方提交按部分顺序发生的一批消息：可新建端点、从源能力派生较窄能力、把可转移能力随消息移交给另一主体、只向被授权集合广播，以及撤销某个派生分支。持有权移交后发送方不再拥有该实例；广播产生的副本沿自己的派生边撤销，不能把接收方其他来源的同权能力一起收回。两个主体的本地句柄编号可以相同，授权身份由全局代次和派生链确定。对最多14条操作，判断给定授权声明在所有满足因果关系的交错中是否都成立；同一通信事件只能消费一次，不能把两条不同交错的权限合成一个状态。注册批次前输出覆盖所有可达权限状态的归纳证书，独立检查器核对初始权限、后继闭包和声明；失败仅标记未满足的声明编号。用独立小规模全排列验证转移与撤销竞争、两条路径同权但授权不可拼接、广播部分送达和句柄编号重用。
