# weightedvote — 带权重投票的协同决策无冲突选择器

多方分布式加权表决状态合并器（Go，仅标准库）。各节点基于持股权重提交
赞成/反对/弃权票，投票权重随时间因果动态调整；网络分区愈合后，
状态合并自动汇总全网有效总权重与弃权票，输出确定性最终定论。

## 设计

- **CRDT 合并**：每个投票人的票与权重各自构成 LWW-Register，
  按因果时间戳（Lamport 时钟 + 节点 ID 决胜的全序）取最新值。
  合并满足交换律、结合律、幂等律，结果与合并顺序无关。
- **因果动态权重**：`SetWeight` 产生带因果时间戳的权重记录；
  并发冲突按节点 ID 字典序确定性裁决；过时的远端记录不会覆盖较新的本地记录。
- **确定性决策**：`Tally.Decision()` 只依赖汇总数值——
  赞成权重严格超过有效总权重一半则 `Approved`；
  反对权重达到一半则 `Rejected`；弃权计入总权重（抬高门槛）；否则 `Pending`。

## 运行
