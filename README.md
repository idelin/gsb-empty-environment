# 长事务补偿与状态机持久化引擎（Saga Engine）

纯 Go 标准库实现，处理可跨越数小时的异步业务事务：

- **步骤切分**：长事务 = 有序步骤序列，每步含正向动作（状态迁移 + 外部调用）与逆向补偿动作。
- **异步等待**：步骤返回 `ErrWait` 即挂起，等待外部回调（`Complete`/`Fail`）或超时。
- **超时监控**：监控器周期扫描等待中的步骤，超时即触发逆向 Saga 补偿。
- **持久化状态机**：每次状态迁移先落盘（原子写状态快照 + 追加式 JSONL 审计日志），
  断电重启后 `Recover` 精确续跑——已完成步骤不重跑、中断步骤幂等重放、
  停机期间的超时在恢复时立即补偿，不重不漏。
- **可复核审计**：全链路状态迁移以 JSONL 追加写入 `audit/<id>.log`。

## 目录结构

```
saga/types.go        状态机类型与步骤定义
saga/store.go        持久化存储（原子快照 + 审计日志）
saga/engine.go       引擎：推进、补偿、超时监控、崩溃恢复
saga/engine_test.go  go test 测试
cmd/demo/main.go     验收场景运行样例
```

## 运行样例

```sh
go run ./cmd/demo
```

发起长采购事务（审批 → 采购 → 付款），付款等待银行回执超时后，
监控器唤醒并逆向取消采购单、通知审批人，输出完整审计轨迹。
持久化产物写入 `demo-data/`。

## 测试

```sh
go test ./saga/ -v
```

覆盖：验收主场景（付款超时→逆向补偿→审计轨迹）、外部拒绝补偿、
正常回调完成、重复回调幂等拒绝、断电恢复不重不漏、
中断步骤重放、停机期间超时恢复、磁盘持久化复核。
