# rcsp：风险约束最短路求解器

在有向图中找 **总风险 ≤ B 的最低费用路径**。边带非负费用与非负整数风险，
允许平行边和零费用环。同价时先比边数少，再按边 ID 序列字典序。

## 算法

- `solver.go`：标签设定法（多标准 Dijkstra）。每个点保留一组**互不支配的标签**
  （费用、风险、边数三维 + 路径字典序裁决），而不是只留一个距离；
  按 (费用, 边数, 风险, 路径) 顺序弹出，弹出的非支配标签即永久。
- `reference.go`：小图参照实现。把图展开成状态 **(点, 已用风险)** 后跑 Dijkstra，
  用于交叉验证主算法。
- 支配规则注意点：最终比较序是 (费用, 边数, 路径字典序)，风险只是约束。
  因此费用与边数都相同的两个标签，必须用路径字典序裁决，不能因风险更小就支配对方。

## 用法

```sh
go run . example.json    # 或从 stdin 读：cat example.json | go run .
```

输入 JSON：`source` / `target` / `budget` / `edges[{id,from,to,cost,risk}]`。
输出最低费用、总风险、完整路径（点序列与边 ID 序列）和逐步风险账本。

## 测试

```sh
go test ./...
```

覆盖：先贵后省的必要中间路径（便宜前缀吃光风险预算，必须走贵前缀）、
零费用环（零风险/带风险）终止性、同价少边、边 ID 字典序、无解、
源点即终点，以及 500 组随机小图与状态展开参照实现的对拍。
