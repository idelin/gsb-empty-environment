# snapshot-rule-engine

TypeScript 优先级规则引擎：条件按输入快照同时判定，逐字段按优先级仲裁，
同优先级异值报冲突，输出每字段证据树，并用朴素两阶段参考模型核对
配置排序无关性。

## 语义

- **快照判定**：每条规则的条件只对「本轮输入快照」求值。规则永远读不到
  本轮其他规则（包括自己）的赋值结果——赋值只在全部判定完成后生效。
- **逐字段仲裁**：对每个被赋值的字段，取命中规则中优先级最高的一组：
  - 组内值一致 → `resolved`（唯一来源记 `winner`，多来源记 `co-winner`）；
  - 组内值不一致 → `conflict`，字段不进入输出，记入 `conflicts`；
  - 无命中 → `unset`。
- **证据树**：`evidence[field]` 以字段为根，每条相关规则为子节点
  （优先级、命中与否、提案值、结局），规则节点下挂与条件表达式同构的
  求值轨迹子树，可逐级解释每个子条件的真值。

## 结构

- `src/engine.ts` — 主引擎：单遍流式聚合（求值与聚合融合的一趟遍历）。
- `src/reference.ts` — 朴素两阶段参考模型：阶段一全量求值成扁平提案表，
  阶段二分组排序仲裁。刻意与主引擎实现路径不同，用于交叉核对。
- `src/orderCheck.ts` — 排序无关性核对：对规则配置做全排列（小规模）或
  确定性洗牌（大规模），主引擎与参考模型的规范化结果必须逐字节一致。
- `src/canonical.ts` — 稳定序列化与结果规范化，消除遍历顺序差异。

## 运行测试

需要 Node ≥ 23.6（原生 TypeScript 类型擦除）；Node 22.6+ 可加
`--experimental-strip-types` 运行。

```sh
npm test
```
