监控系统中多组 Recording Rules 按各自周期运行并相互引用产出指标：同组规则按顺序求值可立即看到上游新值，跨组规则因求值周期与偏移不同存在错拍，且一旦上游指标停止采集写入特殊陈旧标记（StaleNaN），下游必须立即停止沿用旧样本而非继续拿回看窗里的陈年数据算出假指标。为规则求值引擎交付可导入的 Go 调度与语义求值包。输入原始时间序列样本（含普通浮点值与显式 `StaleNaN` 标记）、若干规则组（每组含求值周期 `interval`、起始偏移 `offset` 及组内有序规则列表；每条规则输出新序列名，表达式为对若干输入序列做求和/加权平均/差值并带可选瞬时向量查询回看窗 `lookbackDelta`）。规则：(1) 先分析全规则依赖图，检测任何规则循环依赖（含跨组间接环）并报告精确环路；(2) 按全局时间线 `[tStart, tEnd]` 推进各组定时求值（同一时刻多组到期按组名字典序依次求值，同组内按定义顺序求值使后者立即看到前者在当前时刻刚写入的样本）；(3) 对某输入序列在求值时刻 `t` 做瞬时向量选取时，查找 `(t - lookbackDelta, t]` 内最近一条样本，若该最近样本是 `StaleNaN` 或该区间无样本，则视为缺失（若上一次求值输出了有效值而本次缺失，则输出端自动写入一条 `StaleNaN` 向下游传播陈旧态！）。验收对照按时间戳全展开的朴素求值器逐点核对（含 `StaleNaN` 精确写入时刻），覆盖同组顺序可见 vs 跨组错拍读到上一周期值、上游写 `StaleNaN` 在回看窗未满前即刻阻断旧值沿用并向下游传播 `StaleNaN`、循环依赖拦截，以及精确左开右闭 `(t-lookback, t]` 边界。
