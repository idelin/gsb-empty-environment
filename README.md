# BM25 + 块级 TopK 剪枝（纯标准库 Python 3.11）

从零实现的 BM25 检索：维护文档长度 / 词频 / 文档频率，支持增删文档、
带正确上界的块级 TopK 剪枝、失效上界版本化、不可变快照。
不依赖任何搜索服务或全文检索库，仅使用 Python 标准库。

## 运行

```bash
python3.11 demo.py                          # 运行样例
python3.11 -m unittest discover -s tests -v # 24 个单元测试
```

## 公式（显式定义，可手算复核）

对查询 `q` 分词后的每个词项 `t`（**每次出现独立累加一项**）：

```
score(q, d) = Σ_{t 的每次出现 ∈ tokens(q)}  IDF(t) · f(t,d)·(k1+1) / (f(t,d) + K(d))
K(d)   = k1 · (1 − b + b · |d| / avgdl)
IDF(t) = ln( 1 + (N − df(t) + 0.5) / (df(t) + 0.5) )        # 非负 IDF 变体
```

- `f(t,d)`：词 `t` 在文档 `d` 中的词频；`df(t)`：文档频率；`N`：文档总数
- `|d|`：文档词数；`avgdl = total_len / N`（`N=0` 时定义为 `0.0`）
- 默认 `k1=1.5, b=0.75`；排名：得分降序，**同分按文档 ID 升序**
- **重复查询词规则**：`"apple apple"` 的得分恰为 `"apple"` 的两倍（逐项独立累加），
  测试中以浮点精确等式 `score(q+q) == 2·score(q)` 复核
- **空文档不除零**：空文档无词、不进倒排；`avgdl=0`（全空语料）时归一化分母
  退化为 `k1·(1−b)`，不做除法

## 分词规则（文档与查询共用）

1. 全文转小写（仅影响 ASCII 大小写）
2. 连续 ASCII 字母/数字 `[a-z0-9]+` 为一个词（`"BM25"` → `bm25`）
3. 每个 CJK 汉字（U+4E00–U+9FFF）单独成词（`"苹果"` → `苹, 果`）
4. 其余字符（空白、标点、emoji）均为分隔符，不产生词

## 增删维护的全局统计

| 操作 | 维护内容 |
|---|---|
| `add_document(id, text)` | `doc_len`、`postings`、`df`、`N`、`total_len` 更新，`version += 1` |
| `delete_document(id)` | 按建索引时保存的每文档词频精确回滚倒排与 `df`，`avgdl` 同步变化，`version += 1` |

## 块级 TopK 剪枝与失效上界

- 文档按 `doc_id // block_size` 分块；每个 `(词, 块)` 维护上界
  `bound = max_{d ∈ 块} 该词对 d 的真实贡献`（精确最大值，非近似）
- 块上界 = 按查询词序（含重复）逐项累加各词块上界；与文档评分求和顺序一致，
  由 IEEE 加法单调性保证任何文档得分 ≤ 块上界
- **剪枝判据**（严格，含同分规则）：`bound < 阈值`，或
  `bound == 阈值 且 块内最小 doc_id > 阈值文档 ID`（同分时 ID 大者必排后）
- **版本化防失效**：每条缓存上界携带统计版本号；任何增删推进 `version`，
  旧上界立即失效并惰性重算——绝不使用失效上界剪枝
- **证据**：`search_debug` 返回每个被跳过块的 `{上界, 阈值, 阈值文档, 块内最小ID}`，
  可直接核验“未读块不可能胜过阈值”

## 快照

`index.snapshot()` 深拷贝当前统计与倒排并冻结版本号；之后的增删不影响快照，
快照的查询结果与剪枝行为保持创建时状态（同分仍按 ID）。
