# phar清单元数据检出

PHP 的文件函数遇到 phar:// 路径会解析归档清单并反序列化其中的元数据，攻击者借上传的伪装图片触发。为Go上传网关实现供文件落盘前调用的 phar 检测包：忽略大小写识别 phar:// 流包装，包括嵌套在 compress.zlib:// 与 php://filter 内的写法；在内容中任意长度的前缀之后查找 __HALT_COMPILER(); ?>，其后可跟一个换行或回车换行，再按小端读取清单（4 字节清单长度、4 字节文件数、2 字节 API 版本、4 字节标志、4 字节别名长度及别名、4 字节元数据长度及元数据）；元数据长度非 0 即判含可反序列化元数据，清单越过末尾按畸形处理。用 JPEG 头加 phar 尾、嵌套包装路径、无元数据归档和合法图片验证。
