# 随机化加载布局精确抽样

沙箱加载器希望在所有合法布局中均匀随机选择，以免偏置降低地址随机化强度。实现供Go加载宿主调用的布局包，最多六个带对齐要求的区域放入至多32页地址域，保留区不可占，区域不可重叠；精确计数合法布局并按注入随机字节无偏抽样，不能以随机重试代替完整分布。用小域枚举核对每个布局排名、零解与取消后的随机流位置。

## 设计

- 地址域最多 32 页，用 `uint64` 位掩码表示占用；每个区域的候选起点按
  对齐与保留区预过滤，放置即掩码与运算判重。
- `Count` 用记忆化动态规划（状态为「已放置区域数 + 占用掩码」）精确计数，
  不枚举布局本身。
- `Rank` / `Unrank` 按区域标签顺序做字典序排名与反排名，互为严格逆映射。
- `Sample` 先计数，再对注入的随机字节做整数级拒绝采样得到 `[0,count)`
  上严格均匀的索引，最后经 `Unrank` 映射到布局。拒绝只发生在整数层，
  绝不通过反复试放布局来抽样，因此每个合法布局概率完全相等。
- `Stream` 包装 `io.Reader` 并记录已消耗字节数：零解时返回 `ErrNoLayout`
  且不消耗任何随机字节；唯一布局时确定性返回且不消耗字节；读取中途取消
  或出错时，`Position` 精确反映已交付的字节数。

## 用法

```go
spec := &netsec.Spec{
    Pages:    32,
    Reserved: []int{0, 31},
    Regions: []netsec.Region{
        {Size: 4, Alignment: 4},
        {Size: 2, Alignment: 2},
    },
}
stream := netsec.NewStream(rand.Reader)
layout, err := spec.Sample(stream)
// layout[i] 为第 i 个区域的起始页；stream.Position() 为消耗的随机字节数
```

`go test ./...` 以小域暴力枚举为独立参照，逐一核对计数、排名、反排名，
并覆盖零解、取消后流位置、拒绝采样字节消耗与全 32 页域（6 区域）场景。
