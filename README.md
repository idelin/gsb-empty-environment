边缘接入网关在实现 QUIC（RFC 9000 / RFC 9001）服务端握手前置防护时，若在未验证客户端源地址前发出超过收到字节数 3 倍的响应载荷、接受被篡改或跨客户端 IP 重放的 Retry Token、忽略 Retry Integrity Tag 校验，或未正确校验 Stateless Reset 最小长度与 128 位重置令牌，攻击者可利用网关发起大流量 UDP 反射放大攻击或构造双向无状态重置死循环耗尽带宽。为 Go 网络安全宿主实现可导入的 QUIC 传输握手防放大与地址验证状态机包，严禁联网（仅用标准库 `crypto/aes`/`crypto/cipher`/`crypto/hmac`/`crypto/sha256`）。组件严格实现：（1）按客户端未验证路径精确维护 `bytes_received` 与 `bytes_sent` 账本，硬保证在完成路径地址验证（收到合法 Retry Token 或成功解密客户端 Handshake 包）前，任意时刻累计发送字节严禁超过 `3 * bytes_received`（含重传与丢包探测包）；（2）签发与验证绑定 `(client_ip, original_dcid, retry_scid, timestamp)` 的加密认证 Retry Token，实现 RFC 9001 Section 5.8 的 Retry Integrity Tag 计算与校验，硬拒绝过期、跨 IP 重放或篡改 ODCID 的令牌；（3）实现 Stateless Reset 生成与识别：强制重置包总长度严格大于触发包且至少 21 字节（防无限乒乓循环），使用恒定时间比对末尾 16 字节重置令牌，并阻断对过短 Initial 包（<1200 字节）的非合规响应。附放大边界测试、跨 IP Token 重放、短包拒绝与重置乒乓阻断测试。
