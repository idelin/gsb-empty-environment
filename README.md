# 安全临时目录回收

服务删除请求临时目录时，攻击者可在递归遍历中替换目录项。实现供Go清理宿主调用的目录回收包，以已打开目录能力为边界，删除只作用于遍历时确认的对象代次，拒绝跟随链接；新插入项留待下一轮，不追踪无限增长目录。用可调度文件系统替身验证替换、循环链接和删除失败，根外对象始终不被触碰。

## 用法

```go
d, err := netsec.Open(path)        // 打开一次，得到目录能力（拒绝符号链接）
if err != nil { /* ... */ }
defer d.Close()
rep, err := netsec.Reclaim(d, nil) // 清空该目录；新插入项留待下一轮
```

或通过父目录能力连根回收子树：`netsec.ReclaimChild(parent, name, nil)`。

## 设计

- `Dir` 能力（`dir.go`）：所有操作只接受单条目名、相对已打开目录解析，任何操作都不跟随符号链接，无法触及能力之外的对象。
- 代次确认（`reclaim.go`）：删除前以 `(Dev, Ino)` 复核条目代次；遍历期间被替换或消失的条目跳过（`Report.StaleSkipped`），留待下一轮。
- 快照遍历：每层目录先取 `ReadDir` 快照再处理，遍历中插入的条目不可见，配合 `MaxDepth` 保证有限工作、必然终止。
- 后端（`rootdir.go`）：基于 `os.Root` 实现，符号链接无法逃逸已打开目录。
- 替身（`fakefs/`）：内存文件系统，钩子可在任意能力操作前调度攻击者动作（替换、换链、注入失败），并记录全部操作以断言根外对象未被触碰。
