缓存代理在透传客户端请求至后端 Redis（RESP2/RESP3）时，若参数序列化或协议解析未拦截键值中的 `\r\n` 换行符、允许内联命令（Inline Command）与多条命令管道走私，或未限制危险管理命令（`SLAVEOF`/`REPLICAOF`/`CONFIG`/`MODULE`/`EVAL`/`FLUSHALL`），攻击者可通过参数注入执行任意 Redis 命令甚至写入 SSH 公钥或触发 SSRF。为 Go 缓存安全代理宿主实现可导入的原始字节级 RESP2/RESP3 协议安全解析与命令白名单隔离包，严禁联网。组件严格从字节流解析 RESP 数组、块字符串（校验精确字节长度与结尾 `\r\n`，拒绝负长度越界与内联明文命令）、映射与集合，拦截任何键/参数中携带未转义控制字符的畸形帧；在策略层强制执行命令白名单与参数数量校验（阻断 `CONFIG`/`EVAL`/`REPLICAOF`/`MIGRATE` 等高危命令及 `SCRIPT LOAD`），并确保单条客户端请求只能编码为单一合法 RESP 数组帧（零管道走私）。附内联命令注入、CRLF 走私与高危命令拦截测试。
