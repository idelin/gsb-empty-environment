# SigV4预签名查询与头包含

对象存储网关接受 SigV4 预签名 URL，攻击者在合法链接后追加重复的 X-Amz-Expires、未签名的 x-amz-acl 请求头，或把有效期改成一年。为Go网关实现可导入的预签名校验包：规范查询串按编码后的键名排序并排除 X-Amz-Signature，X-Amz-Expires 只许 1 到 604800 秒，X-Amz-SignedHeaders 必须含 host，请求里出现的每个 x-amz-* 头都必须被签名，同名 X-Amz-* 参数出现两次即拒；当前时间不晚于签名时间加有效期才有效。用重复参数、有效期上下界、未签名头和路径含 %2F 的请求验证。
