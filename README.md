树状投机解码一次验证多条分叉草稿分支，但多子节点共享同一父节点时，按先后次序逐个验证子节点须在每拒绝一个兄弟后从目标分布中扣除已检验草稿质量，才能保证最终输出分布与纯目标模型严格一致。为推理运行时交付可嵌入的 C++20 树验证与槽位重排组件。输入一棵不超过 32 节点的草稿树（每节点含父节点号、候选 token ID、草稿条件概率 q 及当前占用的临时 KV 槽位号）、目标模型在每个位置（含根）给出的词表概率分布 p，以及调用方注入的确定性均匀随机数流 u∈[0,1)。规则：从当前已接受节点出发，按子节点声明顺序依次检验：设当前残差目标分布为 p_rem（初始为 p），若 u < min(1, p_rem[tok] / q_adj) 则接受该子节点并立即沿其继续向下验证（放弃其余未检验兄弟）；若拒绝，则将 p_rem 更新为 max(0, p_rem - q_vec) 后重新归一化（其中 q_vec 为该兄弟对应的草稿分布质量）再检验下一兄弟；当所有兄弟均被拒绝或到达叶节点时，从最终残差分布 p_rem（或叶节点自身目标分布 p）按精确前缀和采样一个补正 token 并结束。组件返回最终接受的 token 序列、补正 token、以及将接受路径对应 KV 槽位紧凑移到连续前缀位置 [0..L-1] 的无覆盖复制/交换操作序列。验收用蒙特卡洛频率检验与解析边际分布逐词表项比对（偏差在精确解析下为 0），覆盖首兄弟拒绝后二兄弟在残差分布上被接受、全兄弟拒绝触发残差采样、q 为零防护，以及 KV 槽位紧凑重排无源覆盖冲突。
