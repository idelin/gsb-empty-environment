查询内核编译到机器码前要把虚拟寄存器分到少量物理寄存器上。给后端交付可嵌入的 C++20 分配组件。输入是按起点排序的活跃区间，每个区间可带建议寄存器；活跃范围跨越调用点的区间只能用被调用者保存的那一组寄存器，其余寄存器保留。采用线性扫描：空闲寄存器优先分给建议值，否则取编号最小者；没有空闲时，若占用中结束最晚的区间比当前区间结束更晚就溢出它并接管其寄存器，否则溢出当前区间；两组寄存器按上述约束分别管理。输出每个区间的寄存器或溢出，以及每次溢出发生时的决策依据。验收核对任意两个重叠区间不共用寄存器、跨调用的约束成立，并与不超过十二个区间的穷举最优解比较溢出数；固定随机种子的输入下输出逐位确定。
