签发服务目前只检查当前请求是否落在父子证书的交集，结果一张本身扩大了范围的子证书仍能登记，再被其他服务当成有效授权。给 Go 证书签发宿主写可导入的委托登记包。每张证书用 Ed25519 对规范字段签名，声明稳定主体身份、有效期、允许动作以及按顺序匹配的路径规则。路径按段比较，规则支持字面段、单段通配、任意段通配和显式拒绝；默认拒绝。子证书可把本地根映射到父证书中的一个固定绝对前缀，映射只允许增加前缀，不能消掉路径分量。登记前须证明在子证书的全部有效时间、每个动作和每条可能的路径上，凡子证书允许的，沿同一条受信父链映射后都被允许。某些祖先链可覆盖一部分路径或时刻，这不能拼出一条完整登记授权。支持交叉签发、证书级撤销和同名主体换钥。为成功登记生成有限证书，独立函数检查路径语言包含关系与时间分段覆盖；验证复杂度按规则状态和路径前缀变化计，不按枚举路径深度截断。用有限标签的小样本全枚举对照拒绝规则遮住更宽通配、多级前缀映射、两条父链分别只覆盖一半权限和撤销切断时段。
