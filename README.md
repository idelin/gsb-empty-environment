# curveint — 分段有理多项式曲线交点工具

在有限区间内求两条**分段有理多项式**曲线的所有相等点与完全重合区间。
全部计算使用精确有理数（`math/big.Rat`），无浮点误差。

## 构建与运行

```sh
go build -o curveint .
./curveint input.json          # 分析
./curveint -selftest           # 运行构造核对用例
go test ./...                  # 等价测试入口
```

## 输入格式

```json
{
  "f": { "breaks": ["0", "1", "3"],
         "pieces": [ { "num": ["0", "2"] },
                     { "num": ["1", "1"], "den": ["1"] } ] },
  "g": { "breaks": ["0", "2", "3"],
         "pieces": [ { "num": ["1", "1"] },
                     { "num": ["-2", "2"] } ] }
}
```

- 多项式为**升幂**系数表，元素是有理数字符串（`"3/2"`、`"-2"`、`"0.5"`）。
- `den` 缺省为 `[1]`；`den` 不能是零多项式。
- 第 i 段覆盖 `[breaks[i], breaks[i+1])`；最后一段额外包含右端点。
- f、g 的定义域端点必须一致；断点可以任意错位。

## 语义约定

- **右连续**：断点处的取值来自右侧分段（即 `[l, r)` 的左闭约定）。
- **末端单独包含**：定义域右端点 `b` 属于最后一段，会被精确判定。
- **重根接触算相等**：差多项式的偶重根（相切）也算相等点，并标注重数。
- **未定义点剔除**：差分子为零但任一分母为零的点不算相等，列为
  "rejected candidates"；重合区间内的分母零点列为 excluded points。

## 算法

1. **断点合并**：取 f、g 断点的并集，得到加细划分；每段上两者都是
   普通有理函数。
2. **差函数**：每段计算 `D = Nf*Dg - Ng*Df`（分子）与 `Df*Dg`（分母）。
3. **恒零判定**：若 `D` 是零多项式，则该段为**重合区间**——直接输出
   区间与证据（约化后的公共表达式），绝不进入根隔离循环，避免把恒零
   差多项式当成无限多个根。相邻重合段合并为极大区间。
4. **根隔离**：否则先精确提取所有有理根（有理根定理），余下无有理根
   的因子用 **Sturm 序列**在开区间内计数并二分隔离，收紧到 `-eps`
   宽度。断点与右端点精确求值判定。
5. **重数**：用 **Yun 无平方因子分解**确定每个根的重数（偶重数 =
   相切，仍计为相等）。
6. **剔除**：候选根处若 `Df*Dg` 为零（用 `gcd(D, Df*Dg)` 的 Sturm 计数
   精确判定），则该点函数未定义，剔除并列明。

## 输出

- **Coincident intervals**：重合区间及其证据（零多项式交叉差、约化
  公共形式、被剔除的未定义点）。
- **Equality points**：每个相等点——有理根给精确值，无理根给有理数
  端点的隔离区间与近似值，附重数与所在分段。
- **Rejected candidates**：差分子为零但函数未定义的点。

## 核对方法（-selftest）

用例按"**构造公共因子 + 错位断点**"方法构造：差分子被设计为含已知
因子（如 `(x-1)^2 (x-2)`），因此所有根与重数先验已知；f/g 的断点
刻意错位以检验划分加细。覆盖：相切重根、恒零差（重合区间）、右连续
约定、右端点包含、分母零点剔除、无理根隔离、相邻重合段合并。
