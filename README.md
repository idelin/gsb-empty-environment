Windows 测试宿主为低权限子进程挑选受限令牌，同时要移交少量可继承句柄。给 Go 宿主写可导入的启动准入包，只使用合成的令牌、对象与访问控制表，不调用系统 API。每个对象有按顺序执行的允许或拒绝 ACE，可限定主体、对象类型以及是否只向子对象继承；请求的每一权限位分别按首次匹配决定，缺省拒绝。受限令牌要分别以普通 SID 集与限制 SID 集求值，只有两次均允许的位才能授予，deny-only SID 仅参与拒绝。继承句柄保留创建时已有权限，不能因重新算一次当前 ACL 就假定旧权限消失。输入还含父子进程与句柄复制的有向无环图；子进程可只能复制已有权限子集的句柄。为每次启动求最少需关闭或降权的初始可继承句柄集合，在所有合法复制顺序下都不能将超出策略的权限带到子进程，同时满足其必需对象访问。至多16个源句柄；并列先保留更多原权限位，再按句柄编号排序。用小规模穷举验证最优解，覆盖同一对象多别名、deny-only、继承专用 ACE、撤权前打开的句柄及后代复制。
