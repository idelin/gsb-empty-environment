# gsbstream — 确定性层级随机流（Go）

从主种子派生根流，任意流可按路径段派生子流：

```go
root := stream.New(20261006)
s := root.Child("ingest").Child("shard-7")
x := s.Uint64()
```

## 保证

- **派生次序无关**：子流状态是「父状态 + 路径段」的纯函数，兄弟流以任意次序、
  在父流推进前后派生，结果逐位一致。
- **兄弟互不影响**：推进任一子流不会改动其父流、祖先或任何兄弟。
- **路径编码不可歧义**：每段以 uvarint 长度前缀编码，`("ab","c")` 与 `("a","bc")`、
  含 `/` 或 NUL 的段均不会碰撞。

## 固定公开规范（v1）

**整数递推（SplitMix64）**：状态为单个 uint64 `s`。每次 `Uint64`：

```
s += 0x9E3779B97F4A7C15            (mod 2^64)
z = s
z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9
z = (z ^ (z >> 27)) * 0x94D049BB133111EB
z = z ^ (z >> 31)
return z
```

`New(seed)` 令 `s = seed`。黄金值：`New(0)` 的前三个输出为
`0xE220A8397B1DCDAF`、`0x6E789E6AA1B965F4`、`0x06C45D188009454F`。

**子流派生**：子状态 = SplitMix64 混合函数作用于以下字节序列的 FNV-1a/64
（偏移基 14695981039346656037，素数 1099511628211）：

```
"gsbstream/child" 0x00 "v1" 0x00   域分隔符
父状态，8 字节小端
uvarint(len(段))                   长度前缀，消除歧义
段原始字节
```

派生不修改父状态。

**字节编码**：`Read` 依次输出 `Uint64` 的小端字节；缓冲区长度非 8 的倍数时
截取最后一个字的前缀。

**状态保存格式（13 字节）**：

| 偏移 | 内容 |
|------|------|
| 0–3  | 魔数 `"GSTR"` |
| 4    | 版本 `0x01` |
| 5–12 | 状态，8 字节小端 |

`Restore` 校验长度、魔数与版本，拒绝未知版本以便未来演进。

