# 加密索引泄露的关键词共现

文档虽然加密，服务器仍能看到同一查询令牌命中了哪些匿名文档，关键词可能据共现频次被恢复。为Go隐私测试宿主实现可导入的泄漏分析包，攻击者知道同一语料的关键词集合但不知道文档匿名ID映射：输入至多18个关键词和若干明文文档的关键词集合，以及与关键词数量相等的匿名令牌各自的命中文档ID集合；文档重复作为不同文档计数，单文档内重复关键词只计一次。分别计算单词频数及两词共现矩阵，搜索保持这些统计的关键词—令牌双射，可附少量已知对应，重复关键词ID、重复令牌ID、已知对应不成单射或统计冲突直接报告。输出至少一个完整见证、在所有可行双射中始终固定的对应，以及最多20个完整映射，先按令牌ID字节序形成对应关键词ID序列，再按该序列字节序排序；必须穷尽才能称某对应确定，预算耗尽只返回已找到见证和未完成，不以首个解恢复全部关键词。用有对称词的语料、重复文档、零命中词和相同边频但不同原始文档组的例子验证：结论仅限单点及二阶泄漏，不能暗中加入未授权的更高阶统计。
