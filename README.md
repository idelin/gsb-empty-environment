# 共享描述符表执行隔离

插件进程共享描述符表时，一方清理句柄可能误关闭另一方的资源。写供Go进程宿主调用的描述符模型包，支持复制进程时共享或复制表、局部脱离共享、复制槽位和执行时关闭标记；脱离须原子取得一致表，后续修改互不影响。用小表穷举事件验证对象引用计数、关闭标记按槽独立及编号复用。

## 包 `fdtab`

`fdtab` 为 Go 进程宿主提供描述符表模型，语义对齐 Linux 的 `files_struct`：

- **File**：打开文件描述（对象），带原子引用计数；计数归零时恰好释放一次。
- **Table**：描述符表，槽位 = 文件引用 + 按槽独立的 close-on-exec 标记；表记录绑定进程数，最后一个进程离开时清扫剩余槽位。
- **Process**：绑定到表的逻辑进程句柄。

### 操作语义

- `Clone(true)` 共享表（类 `CLONE_FILES`），双方改动互相可见；`Clone(false)` 深拷贝表，文件引用计数 +1，此后互不影响。
- `Unshare()` 在源表锁内原子拷贝一致快照后脱离；此后双方修改互不可见。
- `Open`/`Dup` 分配最低空闲编号，关闭后的编号被复用；`Dup`/`Dup2` 复制槽位并清除目标的 cloexec 标记。
- `SetCloExec` 只作用于单个槽位；`Exec` 关闭本进程表中所有置标记的槽位。
- `Exit` 解除进程与表的绑定；表失去最后一个进程时关闭其全部槽位。

### 验证

- `fdtab_test.go`：引用计数、按槽独立的关闭标记、编号复用、dup2 替换、并发 unshare 一致性的针对性单测。
- `exhaustive_test.go`：对 3 槽双进程配置做 BFS 穷举（52 类事件），以独立 oracle 模型比对全部 27,260 个可达状态、约 142 万次事件应用，校验引用计数、标记独立性与共享关系。

运行：`go test -race ./...`
