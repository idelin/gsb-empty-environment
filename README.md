# shortest

把任意 IEEE 754 binary64 值格式化为**最短可往返十进制字符串**的 Go 库。

```go
import "shortest"

s := shortest.Format(f)
```

## 保证

- **可往返**：对任意有限 `f`，`strconv.ParseFloat(Format(f), 64)` 精确还原 `f` 的位模式。
- **最短**：不存在位数更少的可往返十进制表示。
- **最近优先**：同样最短时，选择与真实值数值最近的候选。
- **末位取偶**：候选与真实值严格等距时，选择末位为偶数的候选。
- **符号零保留**：`Format(0)` 为 `"0"`，`Format(-0)` 为 `"-0"`。
- **非有限值独立标签**：`NaN`、`+Inf`、`-Inf`。
- 输出格式与 `strconv.FormatFloat(f, 'g', -1, 64)` 一致（指数小于 -4 或不小于 6 时用科学计数法）。

## 算法

核心搜索与候选选择均为自行实现，不依赖标准库的浮点格式化（`strconv` 仅在测试中作对照）：

1. 把 `f` 分解为 `m × 2^e`，用任意精度整数（`math/big`）精确表示
   **舍入区间** `(low, high)`：区间内所有实数在 round-to-nearest-even 下都舍入到 `f`。
   尾数为偶时边界闭、为奇时边界开；2 的幂处下半区间宽度减半（次正规与
   正规交界不减半）。
2. 对长度 `k = 1..17`，在缩放 `10^(⌊log10 f⌋-k+1)` 下用精确除法求出落在区间内的
   所有 k 位整数候选；首个非空的 `k` 即最短长度。
3. 在候选中精确比较与 `f` 的距离，取最近者；等距时取偶数系数。
4. 去掉尾部零后按 `'g'` 风格排版。

## 验证

`go test` 覆盖：

- 与 `strconv.FormatFloat(f, 'g', -1, 64)` 的随机差分对照（30 万随机位模式 +
  5 万随机次正规数 + 前 2 万个次正规数穷举 + 全部 2047 个指数 × 7 种边界尾数）。
- 相邻值（`math.Nextafter` 链）产生不同字符串且各自往返，含次正规/正规交界与 2 的幂。
- 构造的严格等距中点用例，验证末位取偶。
- 最短性独立自检：少一位有效数字即无法往返。
