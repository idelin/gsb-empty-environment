Java 插件提交任务到宿主线程池时，访问检查还要经过提交时捕获的限定域。给 Go 宿主实现可导入的权限摘要包，文件资源按已规范化的路径分量表示，目录本身、直接子项、任意严格后代分别建模，根目录和租户根别名都适用。调用图可递归，边含同步调用、带限定域的特权调用、投递异步任务和从队列消费；异步投递冻结当时的有效域集合，消费时与消费者的当前栈求交，同一任务只能消费一次，且禁止将异步任务内部再次派生的子任务逃逸出父任务的冻结域限制。至多 4 个不同的待消费句柄；栈深不设人为上限，输入程序的递归必须用摘要求不动点。域内授权按路径语言求并，栈帧间求交；特权截断只能移除其下方同步栈的限制，不能移除任务携带的限制。针对给定文件操作，求每个程序点在所有可达调用上下文中必定拥有、可能拥有的权限语言，域条件用有限 DFA 给出，不得只对样例路径求值。返回绑定程序、域与租户根版本的证书，可用独立有限检查器核对初始条件、调用返回配对和所有异步边界。无可达上下文单独报告；资源预算耗尽保留未定。用可穷举的小图对照根目录直接子项、互递归返回到不同调用点、消费者复用、两个投递源同一程序点和特权帧吞掉普通栈但保留异步限制。
