共享搜索索引在词典拆分合并与跨段撤权期间易通过排序并列或续页令牌泄露私有文档存在，给 TypeScript 搜索宿主写可导入的建议准入与排名组件。所有文档带不可变对象 ID、层级化拒绝优先于允许的段落 ACL，以及版本化分词词典；组件必须使用 `node:crypto` 的真实 HMAC-SHA256 生成授权指纹与分页续页令牌。每次前缀或多词短语间距查询仅从同一授权快照的可见段落计算词频、文档频次与邻接位置，严禁同一来源段落重复计入文档频次，且禁止通过共享前缀树节点的并列计数残差暴露不可见文档数量。词典支持旧词拆分与合并，必须按精确词位重映射并拒绝跨权限来源的错误合并，且丢弃并发更新中迟到的过期索引回执。严格执行无干扰性质：同一用户在仅改动不可见文档内容或无关标签的两份索引中，所得 top-k 列表、排序、可见来源说明、授权指纹及分页续页令牌必须字节完全一致。附独立逐段重建包检验多词短语、层级拒绝、乱序回执与令牌稳定性。
