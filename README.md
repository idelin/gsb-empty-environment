# Cephx能力串授权

Ceph 的 caps 字符串决定用户能读写哪些存储池和命名空间，攻击者通过含糊的语法或大小写让授权服务把能力扩大。为Go的认证服务写可导入的 caps 解析与匹配包（语法为本题给定）：`allow <权限> [pool=名] [namespace=名]`，权限是 r、w、x 的任意组合或 `*`，多条以逗号分隔并取并集；pool 与 namespace 按精确字节匹配，不支持通配；未知关键字、重复 pool、空名、不以 allow 开头一律使整串无效，而不是忽略该条；续期票据时新 caps 必须是旧 caps 的子集（逐条按权限与范围判断），票据过期或其轮换密钥已退出两代窗口即拒绝。测并集、未知关键字、续期放大、过期票据。
