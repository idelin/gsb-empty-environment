代理做滚动灾备时，每个日志分区只存了少数几个可能的持久化前缀和一价多选的恢复票据。请给事务代理做可导入的 Go 交接解码器。每分区任选一个给定前缀，记录内含全局事务号和唯一消息号；业务要求同一事务的记录必须全在各自前缀内或全在外。每张票据覆盖一组事务，只有当这组被保留的笔数处在指定闭区间内时，票据才可选用；选用能抵扣非负重放成本，一张票据最多用一次，同一个具名许可只能供一张票据使用。各分区前缀另有带符号恢复成本。求最低净成本、不同最低成本交接配置数（精确整数，配置按前缀和使用票据的编号集合区分），并按配置的前缀下标序列、随后票据位串的字典序，支持按零起始大整数名次直接提取配置。将选中配置装入代理后，应能按消息号判断要不要重放。输入附带一棵宽度至多 7 的树分解：变量分别为分区前缀、事务保留位及票据使用位；所有约束以显式作用域给出，包括事务与各分区的出现一致性、每票据的计数范围启用条件、同许可互斥。须验证每个作用域被包住、变量出现连通、树合法且变量完整；每分区最多四个前缀，但可有数千个分区，树可有高扇出和重复袋。不能枚举总体配置或按所给名次从第零个逐个取。测试用小日志全枚举逐个名次对照，另构造计数超过 128 位、两个分支共享一个许可、袋本身重复但不应重复计费、以及一个事务在同一分区两次出现而候选前缀正落在两者之间的情况。
