# 压缩边界扩大了能力指针范围

运行时用有限精度压缩能力边界，派生子对象时向外取整可能意外覆盖相邻秘密。给Go安全宿主实现本题能力模型包：地址空间0至2^32-1，能力含base、length、cursor、权限集合{Load,Store,Execute,Derive}、sealedType或未密封、tag与对象代次。编码边界按调用方精度p(4至16)表示：非零length选择最小e使length≤(2^p)*2^e，编码base向下取2^e倍数、top向上取同倍数；若top超过2^32或编码范围覆盖原请求外字节则Derive默认失败，只有调用方显式allowInexact且父能力原始范围完整包含编码后范围才可接受。派生只能收窄权限、范围和代次不变，cursor须位于编码范围；密封能力禁止Load/Store/Execute/Derive，只能用持有同sealedType且有Unseal权限（权限集合另含Unseal，普通派生也只能收窄它）的宿主密钥解封，密钥能力不可从请求构造。实现编码、派生、密封/解封及访问判定，输出精确/非精确和额外覆盖区间。用任意精度整数参考枚举小地址域，测试相邻秘密、零长对象、顶端溢出、权限扩张、密封类型混淆及父能力已宽时的显式非精确派生。
