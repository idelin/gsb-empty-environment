多租户低代码与 API 网关平台允许业务方上传自定义 JSON Schema（Draft 2020-12 子集）校验请求体时，若解析器自动加载 `$ref` 中的远程 `http://`/`file://` URI（触发内网 SSRF 或本地文件读取）、未拦截 `$ref` 相互循环引用导致的无限递归栈溢出、或在校验与合并对象默认值（`default`）时未隔离 `__proto__`/`constructor`/`prototype` 键名且忽略 `additionalProperties: false` 与 `allOf`/`oneOf`/`unevaluatedProperties` 的组合边界，攻击者可通过恶意 Schema 触发服务端 DoS/SSRF，或利用原型污染与未声明属性注入绕过业务风控。为 TypeScript 安全宿主实现可导入的零外部依赖安全 JSON Schema 解析、静态审计与实例校验组件。组件严格实现：（1）Schema 加载静态安全门禁：硬拒绝全部外部 `$ref`/`$dynamicRef` URI（仅允许文档内合法 JSON Pointer `#/$defs/...`，严禁 `http:`/`https:`/`file:`/`data:`），解码 RFC 6901 `~0`/`~1` 转义并检测任意直接或间接 `$ref` 环路与超深嵌套（上限 32 层）；（2）防原型污染与严格对象校验：对输入实例与 Schema 自身均使用安全无原型容器或 `Object.hasOwn` 精确访问，硬拒绝含 `__proto__`/`constructor`/`prototype` 键名的恶意载荷，严禁在应用 `default` 时向 `Object.prototype` 写入属性；（3）精确实现 `type`/`properties`/`required`/`additionalProperties: false`/`allOf`/`anyOf`/`oneOf`/`not`/`patternProperties` 与有界资源预算（限制总校验节点步数、禁止回溯灾难正则如嵌套量词 `(a+)+$`）。附外部 `$ref` SSRF 拦截、间接 `$ref` 环路、ReDoS 恶意 `pattern` 拒绝、原型污染注入与 `additionalProperties: false` 绕过测试。
