# TACACS+明文标志与序号

TACACS+ 的报文体用共享密钥异或加密，攻击者把头部 flags 的 UNENCRYPT 位置 1，想让服务器接收明文，或乱序重放同一会话的报文。为Go的 TACACS+ 服务端写可导入的报文处理包：头固定 12 字节（版本、类型、序号、标志、4 字节会话 ID、4 字节长度，长度只计报文体）；版本字节的主版本须为 0xc，小版本为 0 或 1；UNENCRYPT 置位且调用方未显式允许明文时拒绝并断开；报文体以 MD5 伪随机填充异或解密（pad_1 = MD5(session_id ‖ key ‖ version ‖ seq_no)，pad_n = MD5(session_id ‖ key ‖ version ‖ seq_no ‖ pad_{n-1})）；客户端序号须为奇数且在同一会话内从 1 开始逐一加 1，重复、跳号、偶数、超过 255 均拒绝；length 与实际体字节数不符或超过 65536 拒绝。测明文标志、序号重放、长度失配、解密还原。
