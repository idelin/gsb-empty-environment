ARM64 虚拟化宿主机配置 SMMUv3（ARM IHI 0070）二级流表（L1STD / STE）、上下文描述符（CD）与 Stage-1/Stage-2 嵌套地址翻译时，若 `STE.Config` 误配为 Bypass（`0b100`）放行未翻译 DMA、二级流表 `Span` 越界导致非法 StreamID 落入相邻设备上下文，或 Stage-2 大页（2MB/1GB）与宿主机内核保留物理区部分重叠，恶意设备可通过伪造 StreamID/SubstreamID（PASID）直接读写宿主机敏感内存。为 C++17 虚拟化安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 SMMUv3 流表与两阶段页表隔离符号验证库（严禁逐页枚举）。输入为二级流表结构、STE/CD 表项、Stage-1 与 Stage-2 稀疏页表树、设备合法 StreamID 范围、各虚拟机合法物理内存区间与宿主机受保护物理区间集合。验证库精确执行：（1）按 `STRTAB_BASE_CFG` 解析 L1STD 与对应 STE，硬检出任意有效或未屏蔽 StreamID 指向 `Config=Bypass`、非零保留位、或 `S1CDMax` 越界访问非法 CD 槽位；（2）联合分析 Stage-1（4KB/64KB 粒度）与 Stage-2（含 Block Descriptor 大页）映射区间与读写权限交集，检出任意可到达宿主机敏感物理区、跨虚拟机物理区或违反只读约束的 DMA 映射路径；（3）针对存在违例的配置输出字典序最小的 `(StreamID, SubstreamID, IOVA)` 反例及完整 L1STD/STE/CD/页表级联见证。附 16 位缩微地址空间全枚举交叉验证与 Bypass/跨机越界测试。
