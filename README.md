# 拓扑保持的多折线简化（精确有理数运算）

在误差阈值内简化多条共享边界的折线/多边形环，保证不产生新交叉、不翻转环、
不破坏共享接缝、不封死狭窄通道，并为每个被删点提供精确的误差上界。
全部判定使用 `fractions.Fraction` 精确运算，**没有任何 epsilon 修补**。

## 文件

- `exactgeom.py` — 精确平面几何谓词（定向、在线段上、线段相交、点到线段距离平方、点在闭三角形内）
- `polysimplify.py` — 核心算法：`simplify_polylines(polylines, threshold, closed)`
- `demo.py` — 运行样例：`python3 demo.py`
- `test_polysimplify.py` — 单元测试：`python3 -m unittest test_polysimplify -v`

## 算法

1. **建图分链**：在并集图中度 ≠ 2 的顶点（以及开放折线端点）是"关节"，永不删除。
   折线在关节处被切成链；顶点序列相同（或互为反向）的链合并为**同一条共享链**，
   只简化一次 —— 因此两个区域的共享边简化后逐点完全一致。
2. **贪心删除**：每轮在误差 ≤ 阈值的候选中删误差最小者。删除 `p`（用弦 `(prev, next)`
   替代两段边）需通过全部精确判定：
   - **几何恒等捷径**：若 `p` 恰好在 `(prev, next)` 上（共线中间点或重复点），
     点集完全不变，直接允许 —— 阈值 0 时删除的恰好是这类严格冗余点；
   - **环保护**：环至少保留 3 个顶点，且有向面积符号不变（精确符号比较）；
   - **扫掠三角形为空**：三角形 `(prev, p, next)` 的闭包内不得有整个布局的
     任何其他顶点；
   - **弦不相交**：弦不得与任何保留线段相交或相触（共享端点处仅允许恰好
     触于该端点；共线重叠一律拒绝）。
   由于每次删除相对当前布局都是合痕（isotopy），归纳可知：不会产生新交叉/
   新接触，通道不会被封死，环不会翻转。
3. **认证误差**：结束后对每个被删点计算它到**最终**链的精确平方距离，
   连同最大值 `max_error2` 一起返回（`RemovedPoint.dist2_to_result`）。

## 退化情形定义

- 空折线 / 单点折线 / 两点折线：原样返回。
- 闭环按"不重复末点"给出；若重复了首末点，自动去除。
- 顶点数 < 4 的环不简化（环至少保留 3 个顶点）。
- 连续重复点、共线中间点：误差为 0 的严格冗余点，阈值 0 即可删除。
- 自相交或互相穿越的输入未定义（算法仍保证不引入*新的*相交）。
- 负阈值抛出 `ValueError`。

## 用法

```python
from fractions import Fraction
from polysimplify import simplify_polylines

left  = [(0,0),(10,0),(10,4),(11,5),(10,6),(10,10),(0,10)]
right = [(10,0),(20,0),(20,10),(10,10),(10,6),(11,5),(10,4)]
r = simplify_polylines([left, right], threshold=Fraction(3,2),
                       closed=[True, True])
r.polylines      # 简化后的两条环（共享边逐点一致）
r.max_error2     # 认证误差上界（精确平方距离，Fraction）
r.removed        # 每个被删点及其到最终链的精确平方距离
```

坐标接受 `int` / `Fraction` / 可分数字符串（如 `"1/3"`），阈值同理。
复杂度为多项式（每轮删除 O(候选数 × 布局规模)），面向正确性而非大规模性能。
