# 分块嵌套TLV的原子提交与长度额度

消息网关用4字节有符号长度解析不可信TLV流，攻击者可发送负长度、INT32_MIN、嵌套记录里大于父长度的子长度，或把长度前缀拆在两个网络分片之间。为C++17网关写可嵌入的增量TLV读取头文件：记录为2字节大端类型、4字节大端有符号长度和值，类型最高位为1表示嵌套，其值须恰好由零个或多个完整子记录占满，深度上限8，整个流累计字节额度（含头与值）由调用方设置且可取到SIZE_MAX。feed(分片)按需继续，长度先作为有符号数拒绝负值，再与剩余字节和剩余额度比较，累计量不得回绕。一个顶层记录整棵子树校验通过后才按先序调用回调；任一子记录越界、不足或超深，该顶层记录零回调，committed()偏移停在其起点，读取器进入终止态，之后的feed都不再回调。分片切法不得影响回调序列与最终状态。用-1、INT32_MIN、恰等于剩余、多一字节、子记录差一字节、深度8与9、额度为SIZE_MAX时的累加，以及在每个字节处切分的同一输入验证。
