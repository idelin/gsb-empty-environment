# errbudget — 误差预算：重排有理输入以最小化逐步定点加法偏差

给定最多 12 个有理数（整数分子 / 正整数分母）与精度 p（保留 p 位小数），
累加器从精确的 0 开始，按某排列逐项计算 acc+x 并**立即**按精度 p 做半偶舍入
（首项同样如此，不做先精确求和再舍入）。本工具求使最终累加值与精确和的
绝对偏差最小的排列；并列时取原始索引序列字典序最小者，重复输入按索引区分。

## 输入格式（标准输入）

```
p n
num1/den1
num2/den2
...
```

每项为 `num/den` 或整数（分母为正），`1 <= n <= 12`，`p >= 0`。

## 输出

最优排列的原始索引、每步的输入、舍入前有理值、舍入后定点值，
以及精确和、最终累加值与最终（绝对）偏差。`n <= 8` 时自动用独立的
全排列逐步运算核对 DP 结果，不一致则以非零码退出。

## 算法

- 舍入：`roundScaled` 用 `big.Rat` 精确计算 `r * 10^p`，向零截断后比较
  `2|余数|` 与分母，恰好一半时向偶数取舍（正、负数对称）。
- 求解：子集 DP，状态为 `(已用子集, 当前累加值)`；后续演化只取决于当前
  累加值与剩余元素，故同一状态只保留字典序最小的索引序列即可同时保证
  最优性与字典序并列规则。12 项实例秒级完成。
- 核对：`bruteForce` 独立枚举全部排列逐步运算（仅用于 `n <= 8`）。

## 运行

```sh
go build -o errbudget .
printf '2 12\n1/3\n1/3\n1/3\n1/6\n5/4\n7/8\n2/5\n11/20\n3/7\n13/11\n1/2\n9/10\n' | ./errbudget
go test ./...
```

测试覆盖：单项 `1/2` 在 `p=0` 时得 0、正负半偶边界（`p=0` 与 `p=1`）、
重复输入的索引字典序并列、8 项以内 DP 与全排列核对一致、12 项实例的
重放一致性与参照排列对比。
