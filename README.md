# 云凭据来源链约束

云作业可能先后读取实例凭据、任务凭据和环境注入凭据，不能让低信任来源覆盖高信任会话。写供Go凭据宿主调用的选择包，来源组成有向信任偏序，候选绑定租户、受众及有效期；不可比较的候选返回冲突而不按到达顺序挑选。刷新期间固定选择证据，用并发来源变化与撤销测试身份不会漂移。

## 包结构

- `trust.go`：不可变的有向信任偏序 `TrustGraph`，含传递支配、环检测与支配路径证明。
- `credential.go`：`Credential`、`Request`、`Source`，以及并发安全的 `MutableSource` 与区分显式撤销的 `RevokingSource`。
- `selector.go`：`Selector.Refresh` 并发读取来源、对快照做租户/受众/有效期过滤，按偏序求唯一极大元；不可比较时返回 `ConflictError` 并保留已发布身份。
- `atomic.go`：原子指针封装，保证 `Selection` 与来源值的无锁一致读取。

## 关键语义

- 低信任来源永远无法覆盖高信任会话；选择结果只取决于偏序，与到达顺序无关。
- 两个互不支配的合格候选产生冲突，宿主收到 `ConflictError` 而不是任意一个身份。
- 每次刷新对每个来源只读取一次并复制成不可变快照，证据（合格候选、拒绝原因、支配证明）在刷新期间固定。
- 冲突、无候选或来源错误不会替换当前 `Selection`；成功刷新以原子指针整体换发，代际号单调递增。

## 测试

`go test ./...` 覆盖偏序、冲突、过滤、撤销回退与并发漂移；`go test -race ./...` 验证并发来源变更与撤销下身份不漂移。
