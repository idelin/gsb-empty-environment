# lincheck — 单键寄存器线性一致性检查器 + 事件模拟器

纯 Go 标准库实现（兼容 Go 1.11+），无第三方依赖。

## 组成

- `history.go` — 带调用/返回区间的操作历史模型（`Respond == -1` 表示未完成调用）。
- `checker.go` — 线性一致性判定：带记忆化的回溯搜索，预算耗尽报 `UNKNOWN`。
- `simulator.go` — 单进程事件模拟器：逻辑时钟、网络延迟、崩溃/丢包故障、
  可注入的过期读服务端 bug，全部确定性（种子驱动）。
- `main.go` — 四个演示场景（见证 / 未完成调用 / 反例 / 预算耗尽）。

## 判定语义

- 实时先后：A 的响应早于 B 的调用 ⇒ A 必须排在 B 前（不重叠不可重排）。
- 重叠操作（含重叠写）可任意排序。
- 未完成调用按允许扩展语义：未完成的读直接丢弃（扩展可返回任意值）；
  未完成的写是可选的——可丢弃，也可放置在其调用之后的任意位置。
- 搜索状态 = (已解决操作位掩码, 寄存器当前值)，失败状态记忆化；
  `Budget` 限制展开的状态数，耗尽即 `UNKNOWN`（最多 64 个有效操作）。

## 证据

- 安全性：`LINEARIZABLE` 输出一条合法顺序作为见证；`NOT LINEARIZABLE`
  时整个历史即反例（预算内搜索已穷举所有合法顺序）。
- 活性：模拟器报告 `quiescent`（事件队列完全排空）与 `unanswered`
  （既未崩溃也未丢包却未获响应的请求数，必须为 0）。

## 运行

```sh
go test -v ./...   # 单元测试 + 模拟器安全性/活性测试
go run .           # 四个演示场景
```
