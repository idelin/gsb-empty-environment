# fvs — 带非负删除成本的有向图反馈点集求解器

求有向图的反馈点集（feedback vertex set）：删除最少的“代价”，使剩余图无环。
目标按字典序优化：

1. **最小总删除成本**（顶点成本为非负整数，缺省为 1）
2. **最少删除顶点数**
3. **最小 ID 字典序**（删除集合排序后比较）

## 用法

```sh
go build -o fvs .
./fvs solve  [-budget 500ms] graph.json   # 分支定界求解
./fvs brute  graph.json                   # 全子集枚举（n <= 25），用于核对
./fvs verify graph.json solution.json     # 校验删除集 + 拓扑序证书
```

输入格式（允许自环；`cost` 省略时为 1，必须非负）：

```json
{"vertices": [{"id": "a", "cost": 2}, {"id": "b"}], "edges": [["a", "b"], ["b", "a"]]}
```

输出包含：`status`（`optimal` / `interrupted`）、`deleted`、`cost`、`count`、
`topological_order`（剩余图的拓扑序，即可行性证书）、`lower_bound` / `upper_bound`。
给定 `-budget` 超时时返回 `interrupted`：上界为当前最优可行解（初始为贪心解），
下界为搜索前沿所有开放节点的最小下界。

## 算法

分支定界，每个节点依次：

- **强制删除**：自环是长度为 1 的环，其顶点必须删除；
- **SCC 约简**：顶点在环上当且仅当属于非平凡强连通分量，其余顶点免费保留；
- **下界**：剩余图中贪心找点不相交环打包，每个环的最小成本之和（及环数）
  是合法下界——任何反馈集必须从每个环删至少一个顶点；
- **分支**：取最短环，对其每个顶点各分一支（任何反馈集必删环上至少一点）。
  注意并不假设“一个 SCC 删一个顶点就足够”——删除后重新计算 SCC 并递归处理，
  单个 SCC 可能需要多次删除。

剪枝只在子树严格劣于当前最优的 (cost, count) 时进行；(cost, count) 持平的
子树仍被探索，以保证 ID 字典序的最优性。

## 测试

```sh
go test ./...
```

覆盖：自环（含零成本自环）强制删除、零成本顶点优先、共享顶点环、
单 SCC 需多次删除、并列时 ID 序、成本优先于点数，以及 400 例随机图
（含自环、零成本、多重相交环）与全子集枚举的逐点比对，另有预算中断的
上下界一致性测试。
