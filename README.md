# minparen：可配置优先级的最小括号打印器

纯 Python 3.11 标准库实现（`fractions` + `unittest`），不依赖任何符号代数库。

## 功能

- **可配置运算符表**：二元运算符的优先级与结合性（left / right / none）、
  一元前缀运算符的优先级均由 `OperatorTable` 给出；**歧义表在构造时拒绝**
  （同层结合性不一致、none 运算符与他人共享优先级等）。
- **独立解析器**（`minparen/parser.py`）：优先级攀爬，支持一元负号、分数（除法）、
  右结合幂 `^`、条件表达式 `c ? t : e`、函数调用 `f(x, y)`。
- **独立打印器**（`minparen/printer.py`）：输出**最少必要括号**，目标以语法树
  结构相等定义——`parse(to_string(t)) == t`，且删去任意一对输出括号都会使
  解析失败或得到结构不同的树（由穷举测试保证）。
- **精确有理数**：字面量经 `Fraction(str)` 精确转换（`0.1` 即 1/10，无浮点
  损失）；求值全程 `Fraction`，拒绝 float。

## 默认运算符表

| 运算符 | 优先级 | 结合性 | 说明 |
|--------|--------|--------|------|
| `? :`  | 0      | right  | 条件表达式（内建语法） |
| `+ -`  | 1      | left   | |
| `* /`  | 2      | left   | 分数即精确有理数除法 |
| 一元 `-` | 3 | 前缀 | 低于 `^`：`-x^2 == -(x^2)`；`(-x)^2` 需括号 |
| `^`    | 4      | right  | `2^3^2 == 2^(3^2)` |

关键约定：一元负号只在其优先级 ≥ 当前上下文处被接受，因此 `2^-1`
是解析错误，必须写 `2^(-1)`；打印器与解析器严格对应。

## 括号规则（每条规则的适用域见 `printer.py` 文档字符串）

每个节点在"阈值"（上下文允许的最小优先级）下打印：**节点优先级 < 阈值 ⇒
加括号**。左结合 op 的右操作数、右结合 op 的左操作数、none 结合 op 的两侧
阈值各加 1。常量打印适用域：非负且分母仅含因子 2、5 的有理数（负常量的
规范形式是 `Unary('-', Const(...))`）。

## 运行

```bash
python3.11 -m unittest discover -s tests   # 测试
python3.11 examples/demo.py                # 运行样例
```

## 运行样例（`examples/demo.py` 实际输出）

```
== 解析 -> 最小括号打印 -> 结构往返 -> 精确求值 ==
  输入: a - (b - c)            打印: a - (b - c)            值: 3
  输入: a - b - c              打印: a - b - c              值: 1
  输入: -x ^ 2                 打印: -x ^ 2                 值: -4
  输入: (-x) ^ 2               打印: (-x) ^ 2               值: 4
  输入: 2 ^ 3 ^ 2              打印: 2 ^ 3 ^ 2              值: 512
  输入: (2 ^ 3) ^ 2            打印: (2 ^ 3) ^ 2            值: 64
  输入: 2 ^ (-1)               打印: 2 ^ (-1)               值: 1/2（即 1/2）
  输入: a + b * c              打印: a + b * c              值: 8
  输入: a * (b + c)            打印: a * (b + c)            值: 20
  输入: a ? b : c ? 1 : 2      打印: a ? b : c ? 1 : 2      值: 3
  输入: f(a + b, g(c))         打印: f(a + b, g(c))         值: 9
  输入: 0.1 + 0.2              打印: 0.1 + 0.2              值: 3/10（即 3/10）
  输入: 1 / 3 * 3              打印: 1 / 3 * 3              值: 1

== 每对括号的理由（适用域说明）==
  a - (b - c)
    - 为[二元运算 '-']加括号：其优先级 1 < 上下文阈值 2（left 结合运算符 '-'（优先级 1）的右操作数，阈值 2）
  (-x) ^ 2
    - 为[一元运算 '-']加括号：其优先级 3 < 上下文阈值 5（right 结合运算符 '^'（优先级 4）的左操作数，阈值 5）
  2 ^ (-1)
    - 为[一元运算 '-']加括号：其优先级 3 < 上下文阈值 4（right 结合运算符 '^'（优先级 4）的右操作数，阈值 4）
  (a ? b : c) ? x : 1
    - 为[条件表达式 ?:]加括号：其优先级 0 < 上下文阈值 1（条件表达式的条件（?: 右结合，左侧同层必须加括号））

== 精确性对照 ==
  0.1 + 0.2 = 3/10（精确）；浮点结果会是 0.30000000000000004
  1 / 3 * 3 = 1（精确）
  Fraction('0.1') = 1/10，字面量无浮点损失
```

## 测试结果（Python 3.11.15，`python3.11 -m unittest discover -s tests`）

```
.....................................................
----------------------------------------------------------------------
Ran 53 tests in 0.294s

OK

自定义表：324 棵树往返通过，45 对括号删除验证通过
默认表：14930 棵树往返通过，4300 对括号删除验证通过
```

穷举验证（`tests/test_roundtrip.py`）：对默认表穷举所有节点数 ≤ 5 的树
（常量 0、1、1/2，变量 a、b，一元负号，五种二元运算，条件表达式，一元/
二元函数调用，共 14930 棵），以及一张含 none 结合性运算符的自定义表
（324 棵），逐一验证结构往返与"删任一对括号即失败或变树"。

## 目录结构

```
minparen/
  ast_nodes.py   # AST：Const/Var/Unary/Binary/Cond/Call（结构相等）
  operators.py   # 可配置运算符表 + 歧义拒绝
  parser.py      # 独立解析器（优先级攀爬）
  printer.py     # 独立最小括号打印器（含括号理由）
  evaluate.py    # 精确有理数求值（每步注明适用域）
tests/           # unittest：解析、打印、求值、表校验、穷举往返
examples/demo.py # 运行样例
```
