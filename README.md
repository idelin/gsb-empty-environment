# checksumsync — 数据同步校验和实时比对器

源库与目标库一致性在线巡检器。采用**分桶滚动 XOR 校验和**（等价于两层
Merkle 树：桶 = 叶子分组，行哈希 = 叶子）：

- 每行按主键哈希落入 1024 个桶之一；每桶维护 `XOR(行哈希) + 行数` 的滚动摘要。
- 每次增/删/改以 O(1) 滚动更新摘要（旧值 XOR 出、新值 XOR 入），变更持续流动时摘要始终正确。
- 巡检周期只比对 1024 个桶摘要（毫秒级）；仅对摘要不一致的桶下钻，逐行比对哈希，**精确定位主键 ID**。
- 在线巡检器对连续两个周期都存在的分歧才告警，过滤复制在途造成的瞬时误报。
- 桶摘要通过原子读无锁获取，巡检扫描与写入流零锁竞争（实测高负载下全量比对约 0.14ms/周期）。

## 运行测试

```sh
go test ./... -v
```

## 运行样例

```sh
go run ./cmd/demo
```

样例中：两端各 10 万行，复制流持续写入数十万条变更，随后在目标库悄悄
篡改某行单个字段，巡检器在毫秒级内捕捉到桶 Checksum 不匹配并打印主键。

## 文件

- `table.go` — 带滚动校验和的表（`Upsert`/`Delete`/`Digest`）
- `inspector.go` — 比对器 `Compare` 与在线巡检器 `Inspector`
- `table_test.go` / `inspector_test.go` — 单元与端到端测试
- `cmd/demo/main.go` — 运行样例
