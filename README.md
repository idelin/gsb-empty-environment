经典全局值编号（GVN）只能消除完全被支配的冗余表达式，对菱形分支或循环中“一条前驱路径已计算、另一条前驱路径未计算”的部分冗余束手无策；而 GVN-PRE 必须把全程序表达式映射到同余值编号（Value Number）上，先自底向上计算每基本块的预期可用集（`ANTIC_IN` / `ANTIC_OUT`，通过 `phi_translate` 把后继块中的 `phi` 变量沿对应前驱边精准翻译为前驱块的值编号！），再自顶向下在满足“部分可用且在目标块入口预期可用”的合并点向缺失前驱安全提升插入计算并合成新 `phi` 节点！一旦在存在**不可安全推测的陷阱指令**（如除数可能为 0 的整数除法）时错误提升，或在关键边（前驱有多个后继、后继有多个前驱）直接向原前驱块末尾插指令导致污染无关兄弟分支，就会引入原程序不存在的崩溃或错误计算。为编译器中端交付可导入的 Go SSA GVN-PRE 优化与等价性验证包。输入为合法 SSA IR 函数（含基本块 CFG、显式 `phi` 节点、纯算术/交换律/位运算、可陷阱除法/取模及有副作用的 `store`/`call` 指令）。规则：1）实现逆后序迭代值编号（处理交换律如 `a + b == b + a`、常量折叠与死 `phi` 折叠）；2）实现精确 `phi_translate` 与反向不动点数据流求 `ANTIC_IN`（按表达式依赖拓扑序清理所有不可用项，严禁把依赖有副作用指令或潜在除零陷阱的表达式标为可安全提升！）；3）对存在部分冗余的合并点，仅当至少一条前驱路径已有对应值编号且另一缺失前驱安全可插时执行提升——若该边为关键边，必须自动分裂关键边建立着陆块插入，绝不污染前驱的其他后继！随后在合并块合成新 `phi` 并消除所有已变为完全冗余的下游计算；4）内置 SSA 解释器，在含循环、菱形、关键边与潜在除零分支的测试用例上校验优化前后对所有输入产生逐指令等价的返回值与副作用序列（含零新增异常）且验证冗余计算次数严格下降。验收覆盖菱形与循环不变量部分冗余消除、`phi_translate` 多层嵌套变量映射、关键边自动分裂防污染、除零陷阱禁提升以及 SSA 解释器全路径语义等价验证。
