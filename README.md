# bpmigrate — 断点迁移工具

以**语句结构 + 邻域**为锚点定位断点，文件编辑后把断点对应到新文件中的语句。
对复制出的相同代码绝不随意选择：无法区分时返回全部候选及理由，交由用户裁决。

## 用法

```sh
go build -o bpmigrate ./cmd/bpmigrate
./bpmigrate --old <旧文件> --new <新文件> --line <断点行号>
```

输出 JSON，退出码便于脚本集成：`0` 唯一位置，`1` 候选冲突，`3` 语句已删除。

```json
{
  "status": "unique",        // unique | ambiguous | deleted
  "source_line": 4,
  "line": 8,                 // unique 时的新行号
  "span": 3,                 // 语句被拆分时占用的行数
  "confidence": 0.9,
  "candidates": [...],       // ambiguous 时的候选列表（含各自理由）
  "reasons": ["..."]
}
```

## 定位原理

1. **锚点**（`anchor.go`）：断点 = 目标语句 + 前后各 3 条邻域语句。
2. **候选匹配**（`matcher.go`）：
   - 内容匹配：规范化文本精确匹配 / 仅空白差异 / 编辑距离与词元相似度模糊匹配；
   - 拆分检测：连续 2–3 条语句拼接（去空白）后与目标一致，判定为语句被拆行；
   - 邻域匹配：候选前后 ±1 漂移窗口内匹配锚点邻域，用于在相同文本间消歧；
   - 综合置信度 = 0.65 × 内容 + 0.35 × 邻域。
3. **裁决**（`migrate.go`）：
   - **唯一**：置信度 ≥ 0.8 且领先次优 ≥ 0.12；或内容唯一精确匹配且分差足够
     （覆盖语句被移动到其他函数、邻域大变的情形）；
   - **冲突**：前若干候选分差 < 0.12 时全部返回，附"不随意选择"的理由说明；
   - **删除**：最高内容相似度 < 0.5，判定原语句已不存在。

## 覆盖场景

- 语句移动（函数内、跨函数）→ 唯一新位置，理由注明移动轨迹
- 语句拆分为多行 → 唯一定位到拆分块首行，`span` 标出占用行数
- 语句删除 → `deleted` 及原因
- 相同行文本：邻域可区分 → 唯一；邻域也不可区分（复制块）→ 候选列表
