查询引擎从解释器热切换到向量内核时要就地搬栈；GC 和去优化请求可在任意两条搬运指令之间到达。请实现可导入的 Go 帧转换包。输入给出有限字节槽的初态映射（每字节为独立符号、已有符号的别名或具体常量）、目标字节表达式、引用根清单（每个根为四个有序符号字节）和候选机器指令表。指令可将连续 1/2/4 字节按指定排列复制到另一段，或将两等宽段逐字节 xor 写回，部分重叠时先一次性读取再同时写。暂存区是明确列出的额外槽，初值是不允许依赖的独立符号。每条指令给正代价和可用次数上限，大端小端由字节排列而非主机决定。每一步必须有栈图可向 GC 报告每个根所在的连续完整四字节槽，不允许拆零拼接或用逆运算拼回根；同时要求输入列出的解释器活值能由当时槽按 xor 和常量复原，有些活值只在列出的编译阶段需要。阶段由输入列出的不可逆前进指令切换，依然有中断点。最终到指定阶段且所有目标字节对任意输入成立。求最小代价，平价优先指令少再按编号字典序，并生成每步根位置及活值恢复式；实现解释器中断回调，给出具体字节时按表还原。最多十八个槽、十二个候选、单条最多使用两次，禁止遍历所有寄存器输入值或把抽样当等价。另提供检查给定程序和栈图的接口，失配要定位第一步并给可重放的具体输入或确切的根缺槽原因。用缩位后穷举验证恢复式，覆盖别名覆盖一半根、值可逆但 GC 无处扫描、临时 xor 混码后尚可去优化、以及最廉价合法序列必须绕开表面最短搬运。
