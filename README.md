# 密钥服务器第三方签名泛滥过滤

公共密钥服务器允许任何人给任何公钥附加第三方认证签名，攻击者给目标公钥灌入几十万条垃圾签名，让导入该公钥的客户端卡死。为Go密钥服务器写可导入的更新包准入过滤包，输入已解析的公钥包（主密钥、用户标识、各自的自签名与第三方签名、子密钥数量）、调用方的签名者白名单和预算，签名验证由回调完成：每个用户标识只保留有效的自签名（取最新一条）和来自白名单签名者的第三方签名，其余丢弃；自签名无法验证时整个用户标识丢弃；每个用户标识最多保留 50 条第三方签名，每个公钥最多 10 个用户标识与 20 个子密钥，超出时按创建时间保留较新的，不得因此拒绝整个公钥；整个包序列化后超过 1 MiB 时拒绝；合并已存公钥时，被丢弃的签名不得因后续更新被加回，并以内容摘要去重。用灌入上万条第三方签名、伪造自签名、超出子密钥上限、重复提交和合并回灌验证。
