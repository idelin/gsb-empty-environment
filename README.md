多租户通知与页面渲染服务允许租户编写模板表达式（`{{ ... }}`、条件与循环块）时，若直接拼接生成 JS 代码交给 `Function`/`vm` 执行，或仅用黑名单关键字过滤 `constructor`/`__proto__`，攻击者可通过字符串拼接计算属性（`obj['con'+'structor']`）、解构、`Array.prototype.map` 回调或超深递归循环实现服务端模板注入（SSTI）任意代码执行或事件循环拒绝服务。为 TypeScript 服务端宿主实现可导入的零外部依赖安全模板词法/语法解析器与纯 AST 解释执行沙箱组件。组件从零解析模板文本与受限表达式语法（变量、点/下标属性访问、算术/比较/逻辑运算、管道过滤器、`if/else` 与 `for` 循环），严禁调用 `eval`/`new Function`/`vm`；求值器强制执行：（1）所有属性访问无论字面量还是动态计算键，一律只允许访问目标对象自身可枚举自有属性（`Object.hasOwn`），硬拦截 `__proto__`/`constructor`/`prototype`/`__defineGetter__` 以及任意返回函数对象的隐藏原型链方法；（2）仅允许调用宿主显式注册的纯函数过滤器白名单，禁止任意方法调用与对象原地修改（输入上下文视作只读）；（3）严格资源与防 DoS 配额：限制 AST 最大深度、循环总迭代步数、输出字符串最大字节数与求值步数预算，超限立即中止报错。附涵盖动态拼接 `constructor`、数组回调逃逸、原型链遍历、无限循环炸弹与合法复杂渲染的测试集。
