# tricheck — 三角剖分检查器

判断一组候选三角形是否**无重叠地精确覆盖**一个简单多边形。顶点坐标为有理数
（整数、小数或分数 `p/q`），允许共线边，三角形可以使用新增的内部点
（Steiner 点）。全部计算使用自实现的任意精度有理数算术，无任何浮点误差。

## 构建与运行

```sh
make            # 生成 ./tricheck（C++17，无外部依赖）
make test       # 运行 tests/cases 下的全部测试
./tricheck input.txt        # 或 cat input.txt | ./tricheck
```

退出码：`0` = 合法剖分，`1` = 非法（输出具体反例），`2` = 输入解析错误。

## 输入格式

```
polygon <n>
x1 y1
...                      # n 行顶点（顺/逆时针均可）
triangles <m>
ax ay bx by cx cy
...                      # m 行三角形
```

坐标可以是整数（`3`）、小数（`1.25`，按精确值解析）或分数（`-2/7`）。
`#` 之后为注释。

## 为什么面积相等不够

三角形面积之和等于多边形面积只是**必要条件**。反例
（`tests/cases/invalid_equal_area_overlap.txt`）：4 个三角形面积和 = 16 =
正方形面积，但其中一个三角形与另一个重叠，同时留下等面积的空洞——纯面积
检查会错误地接受。因此本检查器执行完整的几何验证：

1. **多边形合法性**：非退化、无零长边、非相邻边不相交、相邻边不回折
   （简单多边形）。
2. **三角形非退化**：面积必须为正。
3. **包含性**：每个三角形顶点在多边形内或边界上；三角形边不与多边形边
   真交叉；并把每条三角形边在所有接触点处切分，逐段取中点确认不在多边形
   外（可捕获"从凹顶点处穿出但不真交叉任何边"的越界）。
4. **两两不重叠**：对每对三角形检查真交叉、顶点严格在内、共线边同侧重合、
   顶点落在对方边上且同侧四种情形。
5. **边界覆盖**：多边形每条边被切分后，每个基本段必须被某条三角形边覆盖，
   否则报告 `boundary-gap`。
6. **内部边配对**：每条严格位于多边形内部的基本边必须被**恰好一个**相邻
   三角形在异侧共享；缺失即报告 `hole`（该边就是空洞的边界证据），同侧
   重复或多方共享即报告 `overlap`。
7. **面积一致性**：最后核对面积和（必要但不充分，仅作为汇总信息）。

检查 3+4 保证并集 ⊆ 多边形且内部互不重叠；检查 5+6 保证并集的边界恰好是
多边形边界。由于简单多边形内部连通，两者合起来蕴含并集 = 多边形（无空洞）。

## 反例输出

非法时输出每类问题的具体证据，例如：

```
[info] polygon area = 16, triangle area sum = 16
INVALID: triangulation rejected (7 problem(s)):
  [overlap] triangles 0 and 2 overlap: edge (3, 2) -> (0, 0) crosses
            edge (2, 2) -> (4, 0) at interior point (24/10, 16/10)
  [hole] interior edge (3, 2) -> (4, 0) of triangle 0 has no triangle
         on its opposite side: it borders an uncovered region (hole)
```

诊断类别：`polygon`、`degenerate`、`outside`、`crossing`、`overlap`、
`boundary-gap`、`hole`、`area-mismatch`。

## 测试

`tests/cases/` 下 17 个用例，文件名前缀决定期望结论（`valid_`/`invalid_`），
`# expect:` / `# expect-absent:` 指定输出中必须出现/不得出现的子串。覆盖：

- 等面积但重叠+漏区的伪剖分（纯面积检查会被骗过）
- 重复三角形（等面积、对角线成空洞边界）
- Steiner 内部点、T 型接头、共线边、非凸多边形
- 有理数/小数/大整数坐标的精确处理
- 顶点越界、经凹顶点穿出边界、边真交叉、退化三角形、非简单多边形

## 代码结构

- `src/bigint.h` — 任意精度整数（加减乘、比较、十进制读写）
- `src/rat.h` — 精确有理数（不约分，比较用交叉相乘）
- `src/geom.{h,cpp}` — 精确几何谓词（方向、在线段上、真交叉、交点、
  边切分、点在多边形内）
- `src/checker.{h,cpp}` — 上述 7 项检查与诊断生成
- `src/main.cpp` — 输入解析与命令行界面
