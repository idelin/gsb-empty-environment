# keyfinder

给定关系上的函数依赖（FD），枚举全部候选键（最小超键），按**大小**再按**字典序**输出。
最多支持 **24 个属性**（位掩码实现）。

## 构建与运行

```sh
go build -o keyfinder .
./keyfinder fds.txt      # 从文件读取
./keyfinder < fds.txt    # 或从标准输入读取
```

## 输入格式

每行一个 FD，左右两侧属性名用逗号和/或空白分隔；`#` 之后为注释；允许空左部：

```
A, B -> C, D
C -> A
-> D          # 空左部：∅ → D
```

## 输出

- 属性列表与解析后的 FD；
- 全部候选键（按大小、再按字典序），每个键附带：
  - **闭包**（恒为全属性集，作为校验）；
  - **删除任一成员后的缺失属性**（最小性证据：`full \ closure(key \ {member})`）。
- 若 `∅` 的闭包即为全属性集，输出空键 `{} (empty key)`。

## 算法

- 闭包：对 FD 列表做不动点迭代（`closure`）。
- 枚举：对子集格做 DFS；一旦当前集合闭包为全属性集即停止下潜——其任何严格超集都包含某个键，必非最小。
  剪枝完全基于闭包，**不预先排除任何属性**，因此右部属性、乃至循环依赖
  （如 `A -> B, B -> A`）中的属性构成的键（上例中 `{A}` 与 `{B}`）都不会遗漏。
- 最小性：DFS 可能先沿某分支到达含键的超集（如经 `A` 到达 `{A,B}` 而 `{B}` 才是键），
  故对每个候选逐一验证：删除任一成员后闭包都不是全属性集（`isMinimal`）。
