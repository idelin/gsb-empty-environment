# intersect — 带可验证证据的多列表交集

每条有序 ID 列表被切分为独立的块（`Block`）。每个块有一份承诺摘要
`BlockSummary{Min, Max, Count, Hash}`（Hash 为块内容规范编码的 SHA-256），
所有块的摘要按序提交进一个清单根 `ManifestRoot`，验证方只信任该根。

## 协议

1. **证明方** `Prove(lists)`：
   - 由全部摘要计算可行区间 `[lo, hi]`（各列表最小值的最大者、最大值的最小者）。
     区间外的 ID 必然缺席至少一个列表，不可能出现在交集中。
   - 与可行区间重叠的块：完整放入证明（作为证据）。
   - 不重叠的块：跳过，并记录依据（`Reason` + 人类可读的 `Detail`）：
     `below-feasible-range` / `above-feasible-range` / `empty-block` / `infeasible-range`。
   - 块内定位用二分跳转 `firstBlockAtOrAfter`：目标值恰好等于某块 Max 时
     选中该块（相等不能跳过）。
   - 范围重叠本身不作为命中依据：命中只能来自块的真实内容。
2. **验证方** `Verify(root, proof)`：
   - 用证明中的全部摘要重算清单根，与可信根比对（篡改摘要/丢块即失败）。
   - 对提供的块重算摘要并与承诺摘要比对（篡改内容即失败）。
   - 重算可行区间，检查每个跳过决定的依据成立；重叠区间却未提供的块直接拒绝。
   - 从证据块重建各列表候选集（过滤到可行区间、去重规范化），重算交集，
     与声明结果逐项比对（漏项/多项即失败）。

## 运行测试

```sh
go test ./... -v
```

覆盖：空列表、重复 ID 规范化、跳转到恰好相等的边界、范围重叠但无实际命中、
以及十类篡改（摘要计数/哈希/最小值、块内容、结果增删、隐藏重叠块、
伪造跳过理由、丢块、错误可信根）均被拒绝。
