内容寻址仓库换摘要算法时，一条旧名称可能对应不止一个新对象，还可能经别名链间接引用另一批待迁移对象。为 Go 仓储宿主实现可导入的迁移见证包。旧清单由签名的有向引用图组成，节点分别为原始块或按序拼接的节点引用；旧摘要允许碰撞，引用只含旧摘要和期望逻辑长度。宿主分批提供签过名的原始块与节点说明，及部分绑定“某清单、父边序号、候选身份”的消歧回执。新身份绑定节点类型、顺序、完整长度和子节点的新摘要。对一个根，判定所有与当前证据相容的解析是否都指向同一完整新身份，若确有多个给两棵可复核的解析证书；若候选表尚未收到签名闭合回执，只能返回待证。允许循环候选与合法非循环候选并存，循环展开非法但不会令其他分支失效，同一个有身份的清单节点在整份解析中对同一条边必须作一致选择。用共享子图表达证书，支持增量撤回某个消歧回执后重新求值，旧证书应按原证据版本复核。候选组合总量可能指数增长，允许状态预算，预算内判不完不得发布。用小图全部赋值核对共享选择、同长不同内容、循环旁边的合法解和不同树形得出相同根身份的去重。
