# 分层仲裁多数派决策引擎 (hierarchical-quorum)

多数据中心分级 Quorum 仲裁器,纯 Go 标准库实现。

## 特性

- **分级权重 Quorum**:各区域(数据中心)拥有独立权重,正常拓扑下按全局权重严格多数派仲裁。
- **本地多数派门限**:每个区域的投票须先满足区域内本地多数派门限(`LocalThreshold`)方可计入权重。
- **降级仲裁拓扑**:主中心不可达时,存活区域基于"全部非主中心区域权重"的静态多数派门限达成临时多数派,避免跨区网络闪断引起全局不可用;单一区域无法自决,防止脑裂。
- **纪元围栏与接管**:降级决议抬升纪元对旧主中心围栏;主中心恢复后须出示更高的纪元编号方可重新接管,旧纪元决议一律拒绝,无状态冲突。
- **签名证据**:每份仲裁结果携带全部区域的 HMAC-SHA256 签名投票,`VerifyDecision` 可独立重放验证(签名、本地门限、权重、多数派门限)。

## 验收拓扑

| 区域  | 权重 | 角色   |
| ----- | ---- | ------ |
| IDC-A | 2    | 主中心 |
| IDC-B | 1    | 区域   |
| IDC-C | 1    | 区域   |

- 正常拓扑:总权重 4,多数派门限 3(A + 任一区域)。
- A 失联:B+C 权重 2 ≥ 降级门限 2,达成临时多数派并抬升纪元。
- A 恢复:出示更高纪元重新接管;同/低纪元接管被拒绝。

## 运行

```sh
go test ./...    # 验收测试
go run ./cmd/demo  # 全流程运行样例
```

## 结构

- `quorum/types.go` — 区域/投票/决议类型,HMAC 签名证据与独立验证。
- `quorum/arbiter.go` — 仲裁器:拓扑切换、多数派计算、纪元围栏、恢复接管、冲突检测。
- `quorum/arbiter_test.go` — 验收边界测试。
- `cmd/demo/main.go` — 运行样例。
