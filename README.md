# sccp — 控制流图上的稀疏条件常量传播

对 8 位机器的 CFG 做 Wegman–Zadeck 风格的稀疏条件常量传播（SCCP），
输出常量替换、删边及理由，并用穷举执行对照验证优化前后语义一致。

## 语义

- 所有运算在 `uint8` 上进行，自然按 mod 256 回绕（`interp.go:evalConcrete`）。
- `div`/`mod` 除数为 0 时产生陷阱（异常），程序立即终止。

## 分析（`sccp.go`）

- 格：`Undef > Const(v) > Over`，合并（meet）只在格上向下移动，
  因此循环携带的信息单调收敛，工作列表必终止。
- 块入口状态只合并**已可行**前驱的出口状态（`flowEdge`），
  不可达前驱永不参与合流。
- 分支条件为 `Undef`（尚未确定）时不产生任何出边——未访问的边
  只是"未知"，绝不当作"永不可达"。
- 除数恒为 0 时才判定块必然陷阱；除数为 `Over`（可能为零）不删任何边。

## 优化（`optimize.go`）

只在有正面证据时变换，并在 `Report` 中给出理由：

- 常量替换：指令结果恒为常量时改写为 `const`，理由含操作数值与回绕说明。
- 删边：分支条件为常量（删另一支）或前驱块必然陷阱（删其全部出边）。
- 删块：入口无可行路径到达的块。

## 验证

`CheckExhaustive` 对全部输入组合（≤3 个 8 位输入）分别解释执行
原图与优化图，比较返回值 / 陷阱 / 发散三种可观察结果。

## 运行

```sh
go test ./...        # 单元测试 + 全部示例的穷举对照
go run ./cmd/sccp-demo   # 打印每个示例的 CFG、变换报告与穷举结果
```
