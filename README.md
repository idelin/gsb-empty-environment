# stcollide：分段匀速轴对齐盒的精确时空碰撞检测

Python 3.11+，仅标准库。坐标、速度、时刻一律为 `int` 或
`fractions.Fraction`（有理数），全部拓扑判定为精确运算，
**不使用任何 epsilon 容差**。

## 功能

- 时间窗内**首碰撞**（`World.first_collision`）与**全部碰撞区间**
  （`World.collision_intervals`）查询；
- **事件驱动模拟**（`World.simulate`）：支持速度变更
  （`set_velocity`，即轨迹后缀替换）、对象销毁（`destroy`）、
  计划动作（`schedule`）与碰撞后轨迹替换（响应回调）；
- **宽阶段**：时空哈希网格（`STGrid`）维护每个对象每个匀速分段的
  时空包围盒，产出保守候选对；**窄阶段**：逐对逐段精确解析求解；
- 预测事件携带双方**轨迹版本号**，轨迹修改后旧预测出队即丢弃；
- 同一时刻的事件**基于同一前态批处理**：先执行该刻计划动作，
  再校验并收集全部有效碰撞，最后统一触发响应；
- **事件预算**：零时间环（响应后仍重叠导致同刻反复碰撞）被预算
  截断，结果状态为 `"budget_exceeded"`。

## 显式规则（退化情形定义）

- 盒为**闭集**：相交（含边界相贴）即碰撞，区间分类为
  - `overlap`：存在某时刻两盒**内部**严格相交（唯一会产生事件的类别）；
  - `contact`：持续接触但内部始终不相交（如沿棱滑移）；
  - `touch`：瞬时相切（零时长区间）。
- `contact` / `touch` 只在区间查询中报告，**不产生事件**；
- 静止分离永不碰撞（零相对速度 + 正间隙 ⇒ 空区间，精确判定）；
- 初始重叠 ⇒ 碰撞区间起点即窗口起点，事件在窗口起点触发；
- 销毁为**半开区间**：对象在 `t_destroy` 时刻已不存在，恰好落在
  销毁时刻的相切不计为碰撞；窗口终点 `t1` 为闭端点；
- 同刻批处理顺序：计划动作 → 事件版本校验 → 统一响应；
- 任何轨迹修改使涉及对象的未决事件失效并立即重预测；若修改时
  双方已处于重叠状态，会立即产生新事件（零时间环由预算兜底）。

## 目录

- `stcollide/core.py`：精确 1D 区间求解与分段碰撞原语
- `stcollide/trajectory.py`：分段匀速轨迹（位置/速度查询、后缀替换）
- `stcollide/broadphase.py`：时空哈希网格宽阶段索引
- `stcollide/world.py`：事件队列、版本校验、批处理、预算、快照
- `stcollide/reference.py`：独立的全对分段解析参考实现
  （候选时刻剖分 + 中点精确判定，与引擎路径互不复用）
- `tests/`：unittest 测试；`examples/demo.py`：可运行样例

## 运行

```bash
python3 -m unittest discover -s tests -v   # 运行全部测试
python3 examples/demo.py                   # 运行样例
```

## 测试覆盖

- 核心数学：零相对速度、边界根、有理数根、负速度、相切/滑移/重叠分类；
- 区间查询：初始重叠、跨分段合并、销毁截断、销毁时刻相切不计；
- 引擎：转向取消旧预测（A、B 预测 5 碰撞、3 时 A 转向）、销毁取消、
  三物体同刻碰撞全部处理且基于同一前态、零时间环被预算截断、
  弹性碰撞后快照精确、首碰撞与区间一致；
- 随机对照：300 组随机世界（含变速/销毁/有理数速度）的碰撞区间与
  首碰撞同参考实现逐一相等，宽阶段候选对覆盖全部真实碰撞对，
  无响应模拟的首批事件与首个 overlap 区间一致。
