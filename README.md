查询网关在任意合数模与多串通组重叠条件下发布线性聚合时，高估剩余联合熵将导致组合秘密推断泄漏，给 Go 查询网关写可导入的发布准入组件。每个未知秘密属于任意给定合数模域 `Z/(M_j Z)`（`2 <= M_j <= 2^48`，非必为 2 的幂），单行聚合带各自合数模与有符号整系数，另支持跨代映射约束以及对单变量或线性组合的模区间与位切片辅助约束。多个串通组策略可同时生效且变量集允许重叠，各自限定所保护线性量联合可能取值数相对先验的最大缩小倍数（禁止以单量缩小倍数的乘积替代联合投影像基数）；整批候选须满足原子性，输入矛盾或任一串通组超界时整批回滚且历史状态保持不变。须将约束按中国剩余定理（CRT）分解为素数幂模并用任意精度整数求 Smith 标准型，输出不依赖于消元顺序的可复核素数幂分解基数证书，显式拒绝非良定义同态。用小合数模（如模 6、12、15）全赋值枚举核对混合素数幂核、区间收缩与重叠串通组回滚。
