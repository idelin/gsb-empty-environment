# anchor-document

一个带批注锚点（anchor）的 TypeScript 文档模型：锚点附着在字符边界上，
编辑时按亲和性（affinity）规则随文本变换，支持选区变换、原始坐标批量
编辑与撤销/重做。

## 运行要求

Node.js ≥ 24（原生运行 TypeScript；Node 22.6+ 可用
`--experimental-strip-types`）。无第三方依赖。

```sh
npm test   # node --test test/*.test.ts
```

## 核心语义

位置是字符之间的边界偏移量 `0..text.length`。

### 锚点与亲和性

- 在锚点处**插入**文本时：`left` 锚点留在插入文本之前，`right` 锚点移到
  插入文本之后；其余锚点按插入长度平移。
- **删除**覆盖锚点（锚点严格位于 `[from, to)` 内部或右边界）时，锚点吸附
  到删除起点；删除起点处的锚点保持不动。
- **替换** = 先删除后插入：被覆盖的锚点先吸附到删除起点，再按自身亲和性
  决定位于插入文本之前还是之后。

### 选区变换

`transformSelection` 同时变换选区两端，两端亲和性可分别配置
（默认 `start: 'left'`、`end: 'right'`，即在边界插入会扩选）。空选区
（光标）两端传相同亲和性即可在插入后保持为空。

### 批量编辑

`applyBatch(edits)` 中的所有编辑以**原始坐标**给出，必须互不重叠：

- 区间相交（含真包含零宽插入点）会抛出 `overlapping edits`；
- 边界相接的删除、删除边界上的插入、同点多个插入都是合法的；
- 同点插入按数组顺序依次落在最终文本中；
- 整个批次是**一步**可撤销操作。

### 撤销 / 重做

`undo()` / `redo()` 以快照方式恢复文本、全部锚点偏移与选区。

## 文件

- `src/document.ts` — 主模型（偏移量算术实现）
- `src/marker-model.ts` — 逐字符标记参考模型（token 数组 + 间隙算术），
  用于差分核对
- `test/document.test.ts` — 单元测试
- `test/marker-model.test.ts` — 差分测试：随机批次下两个模型逐锚点比对，
  并针对相邻删除、同点插入、空选区做定向核对
