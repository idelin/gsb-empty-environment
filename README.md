多个供应商可签署同一配置树的不同子树，发布服务还允许引用模板、覆盖和删键。为TypeScript配置宿主实现可导入的合并验收包。输入为已经解析的有限树、不可变节点ID、扩展引用和签名范围；签名只覆盖原树中指定节点及其原有后代，不能靠改名、移动或模板展开取得新授权。显式空值、缺失与墓碑三种状态在多分支合并时分别处理。对每个输出叶追溯键名、值、父子关系与存在性各自的决定来源；四项都须由允许该位置和用途的签发者授权，若删除较低优先级的签名键会暴露另一个分支值，也要核对暴露后的来源。共享模板可在多个角色下展开，递归环和未授权叶要有确定位置且失败零发布。用小树真值解释器验证签名子树被搬动、同名键在不同父节点、删除再继承、共享模板跨租户与空值覆盖。
