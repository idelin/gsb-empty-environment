消息接收端允许多条边指向同一段字节，但两个字段对它的解释不一定相同。给 C++17 消息库写可导入的只读校验组件。缓冲以小端 u32 根偏移开头；节点由 u16 类型、u16 边数和逐边的 u16 字段号、u32 目标偏移组成，目标为绝对偏移，允许向前或向后引用。宿主提供每种类型允许的字段号、目标类型集合、是否必需及是否允许有环；重复字段拒绝。节点字节区间可完全复用，局部重叠一律拒绝。同一个偏移从不同字段可达时须满足每个入边的类型约束；有环的强连通分量中只要有一条内部边不许成环就拒绝。只对可达节点计数，按不同节点、实际边和所占字节分别限额。校验成功返回绑定不可变缓冲的访问视图，失败返回最短字段路径，等长按字段号序列取最小。写独立的小图枚举对照，包含合法共享、同址异型、只含一条禁环边的分量与重叠节点。
