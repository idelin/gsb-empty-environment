恢复控制器要把归档条带放进一组同轴旋转的盘面，坏扇区不能占数据位，跳过后后续逻辑块的物理角度会整体变化。为块设备格式化器写可导入的 Go 包。轨道共用整数周期 T，给出各轨第零扇区的相位；每轨按角顺序给若干不交叠的物理段，段内扇区等宽连续，含明确的坏段与伺服保留段。每轨有几种可选的格式方案，每种给起始物理扇区、正整数交错步长及要放的连续逻辑块编号区间。从起点起每次沿物理扇区环前进该步长，遇到好扇区就顺序放下一块，坏或保留只跳过。走回起点仍未放完则该方案无效；每轨只能用一案，全盘每个指定逻辑块恰放一次。验收负载是若干有序读取串，各自从给定轨道和绝对整数时刻启动，单磁头不能并发；换轨按有向轨对付寻道时间，盘在寻道时仍转，到轨后只能在对应扇区前沿经过时开始，恰好压线可读，读满整扇区才结束。部分串给启动时刻闭区间，要求在任一整数启动时刻上都不超过该串给的完成时限（以启动为零）。求满足时限的格式中所有串最坏响应时间的最大值最小者，同值按轨号顺序取方案编号向量字典序最小。交付能双向查询逻辑块与物理扇区的格式映射、逐次读取回放器和核对器：给不满足时限的格式能返回具体的串、启动时刻及首次错过扇区前沿的位置（若未错过则说明纯服务时间超限）。T 与扇区总数可到 2^48，段数每轨至多十六、轨道至多六、每轨四案、每串二十读；不得逐扇区展开映射或遍历全部启动时刻。用小盘枚举所有格式和起始相位对照，覆盖步长非互素导致空闲容量足却绕回、高位坏段跳过后首块压线、及区间两个端点都满足但内部相位超时。
