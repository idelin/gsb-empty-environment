# Lease-based Cache Coherence(租约式分布式缓存失效一致性保证器)

基于 AFS / Leases 协议的缓存一致性模型,TypeScript 实现,Node.js 内置测试器验证。

## 协议

- **读租约**:客户端向服务端申请某文件的读租约(默认 5 秒)。租约期内客户端可**绝对放心**地读本地缓存,零服务端往返。
- **撤销回调**:写客户端修改文件时,服务端先向所有持租者发送 revoke 回调;持租者作废本地缓存并 ack 后,写入立即放行。
- **安全阻塞**:若持租者失联,服务端阻塞至租约自然过期才落盘 —— **零读脏**。
- **防脏读窗口**:写阻塞期间新租约申请被挂起,落盘后按新数据发放。
- **写串行化**:同一文件的并发写按到达顺序执行,版本单调递增。

## 运行

要求 Node.js >= 22.6(使用 `--experimental-strip-types` 直接运行 TypeScript)。

```bash
npm test     # node:test 验收测试
npm run demo # 运行样例(完整复现验收边界场景,约 5 秒)
```

## 验收边界

客户端 1 获得文件 X 为期 5 秒的读租约;客户端 2 在第 2 秒尝试修改 X;服务端通知客户端 1 撤销租约,若 1 失联则安全阻塞等待满 5 秒后才放行客户端 2 的写入,保证零读脏。

## 结构

- `src/leaseServer.ts` —— 服务端:租约发放/撤销/过期、写阻塞与串行化
- `src/client.ts` —— 客户端:本地缓存、撤销回调应答、失联模拟
- `test/lease.test.ts` —— 6 个 `node:test` 用例(含验收边界)
- `demo.ts` —— 验收场景运行样例(带时间线日志)
