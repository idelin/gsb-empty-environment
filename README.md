冷数据卷分两级编码：每组本地行与跨组全局行均用题内给定不可约多项式的二元扩域运算，部分物理页只保留线性校验的少数位。给文件服务交付可导入的 Go 包，输入要恢复的字节投影、已有读取及可选物理 I/O 窗口，每窗口返回数行的位选择。窗口可跨槽，但只对整个窗口收费，多个窗口重叠不重复获得信息。设备可能返回可识别的擦除，故障集合由机架布尔约束给出；每次观察擦除与否后允许自适应选下一窗。求最小最坏费用并输出对每一种到达终态真正能计算目标字节的系数；不可完成时给相同观察而目标不同的两份数据与故障集。最多十二窗口、六机架，符号位数可达 256。小码本穷举数据与故障验证，必须区分位选择在域乘法之前和之后的不同结果。
