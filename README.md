# 命名管道模拟了已断开的客户端

高权限命名管道服务收到请求后模拟客户端，客户端若在验证前断开并由另一连接复用实例，服务可能以错误身份执行操作。给Go IPC宿主实现题内管道状态机：管道实例有唯一instanceID和代次，状态Listening、Connected、Reading、Impersonating、Disconnected；Connect由认证层绑定clientProcessID、clientStartTime、tokenID和连接随机数。ReadRequest返回不可变请求字节及连接快照，Impersonate必须在线性化点核对实例仍Connected、快照完全一致且请求尚未消费且ReadRequest只产生一份快照，成功得到绑定该连接代次的一次性模拟句柄；敏感Call前再次核对句柄未撤销。Disconnect立即递增实例代次并撤销句柄，重新Listen前必须清除旧请求；同一实例可复用但旧快照无效。服务只在Revert成功后处理下一请求，panic路径也须恢复。实现可控客户端在Read与Impersonate、Impersonate与Call之间断开/重连，搜索待审实现中请求A内容以客户端B或主进程身份成功Call的最短轨迹。覆盖半包读取、重复请求ID、多个管道实例、客户端PID复用及取消，身份错误和协议错误对外同形。
