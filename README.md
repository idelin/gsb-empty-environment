# subbill — 订阅月中升级结算库

Go 实现的订阅结算库：支持月中升级、升级追溯覆盖本月用量、已付款不重复扣除，
并求最终最低应付金额与合法变更路径。所有金额以整数分计算与核验。

## 模型

- `Plan`：月费（分）、月包含量、超量单价（分/单位）。
- 升级关系为有向边，只允许沿边升级，**不允许降级绕过**包含量/价格限制。
- 月中升级**追溯生效**：最终套餐的包含量覆盖整月用量。
- 已付款（月初扣费及历次追补）**全额抵扣**最终账单，不重复扣除。

## 结算公式

```
Total = 最终套餐月费 + max(0, 用量 - 最终套餐包含量) × 超量单价
Due   = max(0, Total - Paid)      // 月末应补
Credit = max(0, Paid - Total)     // 溢付余额，不退款
```

## 用法

```go
c, _ := billing.NewCatalog(plans, [][2]string{{"basic", "pro"}, {"pro", "max"}})
s, _ := c.Settle("basic", 800, 1000) // 起始套餐、本月用量、已付款（分）
// s.FinalPlan / s.Path / s.Steps / s.TotalCents / s.DueCents
err := c.Verify(s) // 整数分独立核验：升级边合法、追补与总额自洽
```

`Settle` 沿升级图 BFS 枚举全部可达套餐，取总费用最低者；平局时偏好更少跳数、
字典序更小的路径，结果确定。`Verify` 逐步重算升级边、追补金额、已付款下限与
Due/Credit，任何篡改都会报错。
