# corpustrim — 语料裁剪器

从最多 30 个输入中选出**保留集**，在完整保留全语料观测到的
**覆盖边**与**失败类别**的前提下，按字典序优化目标：

1. **样本数最少**（主目标）
2. **执行成本最小**（次目标，仅在样本数并列时比较）

输出**精确解**以及独立计算的**下界**。

## 语义

- 每个输入带有：覆盖边集合、执行成本、失败类别（单个 `failure_category`
  或列表 `failure_categories`，可同时使用）。
- 保留集的覆盖边并集必须等于全语料的覆盖边并集；失败类别同理。
- **重复输入按 `content` 合并**：各自观测到的覆盖边与失败类别取并集
  （不丢失任何观测），成本取各副本中的最小值，输出中保留全部原始 `id`。
- 预处理会剔除永不属于最优解的输入：空覆盖输入，以及被其他输入
  支配的输入（覆盖为子集且成本不低）。

## 用法

```sh
go run ./cmd/corpustrim examples/corpus.json   # 或从 stdin 读入
go test ./...
```

输入 JSON：

```json
{"inputs": [
  {"id": "t1", "content": "login happy path", "cost": 4,
   "coverage": ["e1", "e2"], "failure_categories": ["flaky-timeout"]}
]}
```

输出 JSON（节选）：`samples` / `total_cost` 为精确最优值，`kept` 为保留集，
`lower_bound` 为根节点处证明的下界，`search_nodes` 为搜索规模。

## 算法

精确分支限界（branch and bound）：

- **分支**：选择"可用输入中最少能覆盖它"的未覆盖元素，枚举覆盖它的输入
  （任何可行解必含其一），按增益降序展开。
- **样本数下界**：将各可用输入对未覆盖集的增益降序排列，前缀和首次
  ≥ 未覆盖数时的项数 k —— 任何可行补全至少还需 k 个输入。
- **成本下界**：可用输入中 k 个最低成本之和（可行补全至少用 k 个输入，
  其成本不低于最便宜的 k 个）。
- **现任解**：两种贪心（最大增益、最大增益/成本比）先给出上界，加速剪枝。

正确性由随机用例与暴力枚举对照测试保证（`solver_test.go`），
30 输入的稠密/稀疏对抗用例均在毫秒级求解（`hardcase_test.go`）。
