数据库页整理器把字节段从旧偏移搬到新偏移，并重写指向段内的相对指针。为页缓存提供可导入的 Go 包和真实内存回放器，不能以另建整页作为实现。输入为页的符号初值（重复字节串可用游程）、带重叠的搬移段、跨段指针字段及新的变长有符号 LEB 偏移；偏移长度会反过来改变段布局。需找满足指定对齐和页容量的最小长度规范布局，随后生成使用不超过 B 字节临时空间的原位写计划。每次操作只能复制给定粒度的连续片段或写入指针，无额外工作页；部分重叠复制按明确的前向或后向语义。掉电可发生在任意操作后：给定不可变原页摘要及至多 K 个可持久化暂存槽，恢复必须只凭中间页和持久槽完成，而非假设能重读旧页。若预算不足需给可检查的不可行证明。每次最多十段、八个指针，页可有 2^35 字节重复区；不能逐地址展开。小页对布局和每个掉电点穷举；测试两种自洽编码长度、字段扩张越过对齐线、临时字节未持久化导致循环搬移不可恢复。
