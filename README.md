多域企业身份宿主在受理 Kerberos V5 跨域服务票据与 S4U2Self/S4U2Proxy 约束委派请求时，若 KDC 仅校验末跳签名而忽略 RFC 4120 `transited` 压缩域路径展开或允许 `forwardable` 标志在非委派链上被静默放大，被攻陷的边缘域可伪造直达核心域的捷径票据或越权冒充高权限主体。为 Go 认证宿主实现可导入的 Kerberos V5 跨域信任与约束委派策略核验包，严禁联网。组件完整实现 RFC 4120 §3.3.3 `DOMAIN-X500-COMPRESS` 转递字段编码与精确展开（支持斜杠分层 X.500 路径、点分 DNS 后缀缩写、尾部逗号空项表示禁止隐式补全、以及最大路径长度防爆限制），对照宿主配置的双向/单向跨域信任图与 `capaths` 显式策略，验证票据中声明的每个中转域均位于客户端域至服务域的合法授权路径上且无未经许可的跨捷径跳变。对 S4U2Self 与 S4U2Proxy 委派链，结合真实 HMAC-SHA256 密钥核验内部票据与 PAC（Privilege Attribute Certificate）完整性摘要、检查服务主体在目录中的 `AllowedToDelegateTo` 白名单、拒绝将受保护不可委派主体（`NOT_DELEGATED`/`SENSITIVE`）纳入委派链，并强制票据标志与有效期满足单调约束（续期与委派产出的票据不得扩大 `endtime`/`renew-till`、不得凭空置位 `forwardable`/`proxiable`，且严格校验时钟偏斜边界）。另附有界跨域信任图对抗搜索器：给定带腐化中转域的多域图，自动找出能伪造未授权中转或非法绕过 `NOT_DELEGATED` 的最短攻击路径并用小图全枚举验证零漏报。
