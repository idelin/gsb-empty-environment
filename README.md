# modal-focus-workbench

嵌套弹层的焦点与背景隔离管理。纯 TypeScript，零依赖；核心计算（可见性、可聚焦性、
inert 传播）全部基于夹具给出的节点树与盒/字形度量完成，不借浏览器布局引擎。

## 运行

需要 Node ≥ 22.6（TypeScript 类型擦除运行；23.6+ 可去掉 `--experimental-strip-types`）。

```sh
npm test      # node --test 内置测试（单元 + 状态探索）
npm run sample  # 叙事式运行样例
```

## 语义

- **顶层焦点限定**：任一时刻只有栈顶（非退出中）弹层可交互、可持有焦点。
- **inert 引用计数**：打开弹层时对背景（层根祖先路径之外的所有兄弟子树）施加
  inert 引用，关闭时按引用计数释放——关闭内层不解除外层对背景的隔离。
- **分代焦点请求**：每次打开/关闭/重定向推进代际（epoch）；恢复目标未挂载时
  请求保持待决，树变化时重试（允许异步挂载）；过时请求（含已入队的异步重试）
  不得夺焦。弹层关闭、触发者删除、新弹层打开可任意交错。
- **退出动画**：close 即进入 exiting——inert 引用立即释放、子树立即不可交互，
  DOM 由 `finishExit()` 才移除，退出期间可交互范围始终明确。
- **恢复链**：触发者 → 新顶层内第一个可聚焦节点 → 全局后备；触发者已删除时
  自动落到合法后备。
- **幂等与 Escape**：`closeLayer`/`finishExit` 幂等；Escape 只关闭可关闭的顶层。

## 结构

- `src/tree.ts` — 节点树 + 夹具度量驱动的可见性/可聚焦性/inert 引用计数
- `src/layer-manager.ts` — 弹层栈、分代焦点请求、退出动画可交互范围
- `fixtures/workbench.fixture.ts` — 节点树与盒/字形度量夹具
- `tests/` — 单元测试与随机状态探索（每步校验：焦点只属于顶层、退出层不可交互、
  重复关闭幂等；收尾校验 inert 引用与待决焦点全部释放）
- `samples/demo.ts` — 运行样例
