# Buildah构建运行选项准入

Buildah 的构建步骤可选隔离方式（chroot、oci、rootless）、命名空间、能力、挂载与设备，不可信构建若选了 chroot 隔离、主机网络或额外能力，就能影响构建主机。为 Go 构建平台写供构建请求准入调用的运行选项校验包：输入隔离方式、命名空间选项（网络、PID、IPC、UTS、用户）、新增能力集、挂载（源、目标、选项）、设备路径与用户映射；不可信构建只允许 oci 或 rootless；网络不得为主机，PID 与 IPC 不得共享主机；新增能力限于调用方登记的小集合，不得含 SYS_ADMIN、SYS_PTRACE、SYS_MODULE；宿主路径挂载须在白名单目录内并带 ro、nosuid、nodev，源路径经符号链接解析后仍须在白名单内；设备只允许登记项；用户映射不得把宿主 0 映射进构建。用 chroot、主机网络、挂载逃逸、SYS_ADMIN 和合规请求验证。
