# 计算作业分批调度（精确求解，无外部求解器）

按相容类型把不可拆分的计算作业分批：每批有固定启动成本与资源容量上限，
在满足全部截止约束的前提下最小化总成本（= 批数 × 启动成本）。
仅使用 Python 3.11 标准库（`fractions.Fraction` 精确处理整数/有理数）与 `unittest`。

## 模型

- 单机顺序执行各批；批处理时间 = 批内作业处理时间之和，批内作业同刻完成。
- 硬约束：批内作业类型必须一致（不相容不得同批）；批资源合计 ≤ 容量；
  作业完成时刻 ≤ 截止时刻；作业不可拆分；单作业超容量直接拒绝。
- 启动成本按批计，不按作业计，故最小化总成本等价于最小化批数。

## 求解与状态

- 精确子集 DP：`dp[S]` = 调度集合 S 的最少批数，枚举 S 的最后一批
  （类型纯、容量可行、批内截止 ≥ S 的处理时间总和），可证最优。
- 状态/转移超预算时回退 EDF 贪心，并区分四种状态：
  `OPTIMAL`（已证最优）、`FEASIBLE`（可行但未证最优）、
  `INFEASIBLE`（已证不可行/拒绝）、`UNDECIDED`（预算未决）。

## 运行

```bash
python3 main.py                  # 运行样例（四种状态各演示）
python3 -m unittest discover -s tests -v   # 运行测试
```

## 文件

- `batching.py` — 模型（`Job`/`Instance`/`Solution`）、`solve()`、`verify()`
- `main.py` — 合成数据运行样例
- `tests/test_batching.py` — 单元测试（含与暴力枚举划分对拍）
