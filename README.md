# 跨分区一致切面求解器 (Consistent Cut Solver)

求解跨分区读切面问题：事务可能同时修改多个分区，历史切面中只包含半个事务的
切面必须排除。给定各分区版本日志、事务关联与水位（watermark），求**不晚于水位
的最大一致切面**，并返回每个被回退事务的**原因链**。

## 问题模型

- 分区 `p` 持有按版本递增的提交日志 `Logs[p]`，每条记录 `(Version, Txn)`。
- 一个事务 `t` 在若干分区各有一个提交点（`commits(t)`）。
- 切面 `c = (c_1..c_P)` 取每个分区日志的一个前缀。
- **一致性**：对任意事务 `t`，其提交要么全部落在切面内，要么全部在切面外。
  不允许"半个事务"被读到。
- 水位 `W = (W_1..W_P)` 给出每个分区允许的最高版本（全局水位是其特例：
  所有分量相等）。目标：在 `c ≤ W` 的约束下求**最大**一致切面。

## 算法（工作清单 / 最大不动点）

1. 初始切面取水位切面：`cut[p] = max{ i : Logs[p][i].Version ≤ W[p] }`（二分）。
2. 维护 `included[t]` = 事务 `t` 当前在切面内的提交数。若
   `0 < included[t] < |commits(t)|`，则 `t` 被切了一半，必须**整体回退**：
   把 `t` 仍包含的每个提交所在分区的切面前沿降到该提交之前。
3. 降低切面会逐出更多日志项；因此变得"半含"的事务入队，递归处理。
4. 队列清空时，不存在半含事务，切面一致。

回退原因链：事务首次变"半含"时记录原因——要么是根因（自身横跨水位，
`Watermark`），要么是级联（`Cascade`，记录肇事事务与被逐出的提交点）。
原因只在首次赋值，沿链的"发现时间"严格递减，因此**原因图是以横跨水位
的事务为根的森林**，即使事务关联有环，链也必然有限。

## 终止性证明（允许关联成环）

定义测度 `μ = Σ_p (cut[p] + 1)`，即当前切面包含的日志项总数。

- 每次有效迭代（处理一个仍半含的事务）至少把某个 `cut[p]` 降 1，
  故 `μ` **严格递减**；
- `μ ≥ 0` 有下界；
- 等价地，切面向量在积序 `ℕ^P` 上严格下降，而 `ℕ^P` 是良基的
  （不存在无穷下降链）。

因此迭代必在有限步内停止。关联环不会导致振荡：切面只降不升，级联沿环
每绕一圈至少消耗一个日志项，环上的事务一旦完全逐出（`included = 0`）就
不会再被入队——每个事务的 `included` 单调不增，"变半含"最多发生一次。

## 最大性证明（结果确为 ≤ 水位的最大一致切面）

- **结果一致**：循环不变式保证队列清空时无半含事务。
- **结果 ≥ 任意一致切面 C ≤ 水位切面**：对级联顺序归纳。若事务 `t` 在
  水位切面中半含，则任何 `C ≤ 水位切面` 不可能完整包含 `t`（`t` 有提交
  超出水位切面 ⊇ C），故 `C` 必整体排除 `t`；`C` 排除 `t` 后，被算法
  级联逐出的下一批事务在 `C` 中同样半含，同理必被 `C` 排除。归纳得
  `C` 排除算法所排除的一切，即 `C ⊆ 结果`。
- 一致切面在并与交下封闭（前缀封闭 ∪ 事务并封闭均保持），构成分配格，
  故最大元存在且唯一，算法算出的正是它。

## 复杂度

记 `N` = 日志项总数（= 事务-分区关联数之和），`T` = 事务数，`P` = 分区数。

- **时间 `O(N + P·log N)`**：每个分区的初始切点一次二分；每条日志项最多
  被逐出一次（切面只降不升，逐出扫描均摊 O(1)）；每个事务最多入队、
  处理一次，处理代价 `O(|commits(t)|)`，合计 `O(N)`。
- **空间 `O(N + T)`**：提交索引、计数器、原因表。

## 使用

```go
in := snapshot.Input{
    Logs: [][]snapshot.LogEntry{
        {{Version: 1, Txn: 3}, {Version: 2, Txn: 1}}, // 分区 A
        {{Version: 1, Txn: 1}, {Version: 2, Txn: 2}}, // 分区 B
        {{Version: 1, Txn: 2}, {Version: 2, Txn: 3}}, // 分区 C
    },
    Watermark: []int64{2, 2, 1},
}
res := snapshot.Solve(in)
fmt.Println(res.Cut)       // 各分区最终切点版本
for _, rb := range res.Rollbacks {
    fmt.Println(rb.Txn, res.Chain(rb.Txn)) // 回退事务及其原因链
}
```
