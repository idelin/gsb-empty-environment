# 可靠广播模拟器

模拟一个可靠广播组：消息以「源编号 + 每源递增序号」标识，节点只保留
有界的去重历史，通过确认代次（epoch）管理成员退出与重入。

## 核心设计

- **连续水位 + 稀疏缺口表**（`dedup.go`）：每个源一个 `SourceWindow`。
  水位以下的序号视为已见（O(1)）；水位之上的乱序到达进入有界缺口表，
  缺口表满时拒绝继续接收乱序消息（`ErrGapTableFull`），触发修复。
- **压缩门控**（`cluster.go` `MaybeCompress`）：只有当所有**有效订阅者**
  都以当前代次确认了某序号，集群压缩水位才能越过它。压缩水位永不越过
  任何成员的确认水位，因此离线节点补传旧消息时仍能被水位/底线识别为
  重复，不会丢失未收到的消息。
- **确认代次**（`cluster.go` `RecordAck`）：成员每次重入 epoch 递增；
  携带旧代次的确认（退出前的重放）被拒绝，且不计入压缩门控。
  退出期间成员不再是有效订阅者，不阻塞压缩。
- **补传**（`cluster.go` `CatchUp`）：重入节点向在线对等方拉取水位以上
  的全部区间，缺口表中已有的序号被去重窗口识别为旧消息。

## 运行

```sh
go run .        # 五阶段模拟：丢包广播 → 退出 → 离线广播 → 重入 → 校验
go test ./...   # 单元测试
```
