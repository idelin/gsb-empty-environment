# 条件清洗器摘要推导

库函数只在返回true时保证字符串安全，调用方忽略返回值便可能形成注入。写供Go分析宿主调用的摘要包，输入无循环函数图和有限污染类别，分别推导各返回值下参数与结果的必然净化集合；不确定分支取交集，副作用字段单独建模。用完整路径枚举比较摘要，再测试调用方取反条件与忽略返回值。

## 包结构：`sanitsum`

- `Analyze(*FuncGraph)`：在无循环 CFG 上做位集数据流，汇合点取并集、返回点对各路径取交集，产出按 `RetVal` 分组的参数 / 结果 / 副作用字段必然净化集合。
- `EnumeratePaths(*FuncGraph)`：枚举每条完整路径独立传播，再在同一返回值上取交集；与 `Analyze` 的摘要用 `Summary.Equal` 比较，作为交叉校验。
- `AnalyzeCaller(*CallerGraph)`：消费库摘要做调用方分析。库摘要中跨返回值的交集净化立即生效（忽略返回值时唯一可用的保证）；仅在特定返回值下成立的条件净化挂起，由 `BranchOnStmt` 按实际分支应用，取反条件或缺少分支时不生效，污染到达 `SinkStmt` 即产出 `Finding`。
- 副作用字段通过 `Ref{Var, Field}` 独立建模，字段净化不会提升到整个变量。

## 验证

```sh
go test ./... -race -cover
```

测试覆盖：条件守卫摘要、菱形不确定分支交集、DAG 与完整路径枚举一致性、环路拒绝、字段副作用、多类别逐类净化，以及调用方正确守卫 / 取反条件 / 忽略返回值三类场景。
