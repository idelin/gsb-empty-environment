两个秘密状态能产生完全相同的公开事件序列，但这些序列出现的概率不同，协议仍会泄露信息。给 Go 网关写可导入的协议版本准入包。宿主输入两组秘密初始分布、有限公开动作和有理数转移概率。每轮调用方选一个公开动作，机器可进行若干不可见转移，再发出恰好一个带长度桶的可见事件并进入下轮；若永久停在不可见闭类，产生单独的永久沉默结果，不能当成显式超时或以某个步数截断。调用方可依据此前看到的事件选择下一个动作。只有任意这样的调用策略下所有有限观测前缀的精确概率均相同，才准注册。最多18个状态、每个分母小于256；计算与证书核验须用精确有理数。为每个动作消去不可见步，处理多个不可见闭类和可能以部分概率进入闭类的状态；再给出有限线性空间证书，使独立函数只用输入矩阵、初始分布和证书就能检查所有可见后继的闭包与各类终止概率。绑定协议摘要与观察投影后签出注册句柄。用短序列枚举核对精确分数，并测试支持集相同但概率不同、隐藏环部分吸收、交换两个同观测状态和只有长前缀才显出差异的协议；不连接真实网络。
