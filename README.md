# 跨租户快照导入准入

租户导入共享磁盘快照时，隐藏的增量基底可能属于其他租户。实现供Go导入宿主调用的快照闭包包，清单列出块来源及父快照摘要，沿全部增量依赖验证共享授权；同一逻辑块只能由确定优先级的一份来源提供，冲突拒绝。用共享祖先、撤销授权和循环父引用测试不可只校验顶层清单。

## 包：`netsec`

导入宿主通过两个接口接入：

- `ManifestStore`：按摘要取快照清单（`Manifest`）。清单声明自身摘要、属主
  租户、逻辑块及其物理来源（`BlockSource`）、父快照摘要（增量基底）。
- `Authorizer`：回答某属主的某快照当前是否共享给导入租户；撤销即返回
  `false`。

入口为 `Verify(ctx, importer, rootDigest, store, auth)`，它对 `root` 的完整
增量闭包做准入校验，而不是只看顶层清单：

1. 沿父快照边 BFS 遍历所有可达快照，每个清单只取一次；清单缺失、摘要与
   存储键不符、结构非法均拒绝。
2. 对闭包内**每一个**快照调用授权检查（含导入者自有快照与隐藏基底，
   自有/共享策略由宿主 `Authorizer` 决定）；任何节点返回未授权，例如
   共享已撤销，整体拒绝。
3. 对父引用图做 DFS 三色标记，发现回边（循环父引用）即返回 `CycleError`，
   不会无限遍历。
4. 块来源裁决：每个逻辑块只能由一份物理来源提供。离根更近的快照
   （BFS 深度更小）覆盖更深基底中的同名块；同深度出现不同来源返回
   `BlockConflictError`。来源快照必须位于已授权闭包内，且其声明属主必须
   与来源清单的属主一致，否则返回 `InvalidSourceError`。

成功时返回 `Closure`：闭包内全部快照摘要（有序）、各快照最小深度，以及
每个逻辑块唯一选定的来源和深度，宿主据此执行实际导入。

## 错误类型

所有失败均返回带类型的错误，宿主可用 `errors.As` 分支处理：
`SnapshotNotFoundError`、`DigestMismatchError`、`UnauthorizedError`、
`CycleError`、`BlockConflictError`、`InvalidSourceError`、
`InvalidManifestError`；上下文取消返回可 `errors.Is` 匹配的 `ErrCanceled`；
宿主接口自身的错误原样透传。

## 测试

`go test ./...`（含 `-race`）覆盖 22 个用例，语句覆盖率 100%。关键安全
场景：

- 菱形跨租户链：共享祖先可达且每个节点（含隐藏基底）都经过授权检查。
- 撤销授权：深层基底共享撤销导致整体拒绝；先前放行、随后撤销的再次导入
  立即被拒。
- 循环父引用：回边被检出并报 `CycleError`。
- 块冲突与优先级：同深度异源拒绝，同源去重，近根来源覆盖深层来源。
- 来源伪造与越界：来源不在授权闭包内、来源属主与清单不符均拒绝。
