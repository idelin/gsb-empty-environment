# Tcl安全解释器访问路径令牌翻译

Tcl 安全解释器不让从属脚本看到真实路径，宿主用访问路径列表给它虚拟令牌路径（本题规定形如 $p(:N:)/子路径），再由主解释器代为 source 与 glob。攻击者在令牌后拼 ..、伪造令牌编号，或把目录换成符号链接。为 Go 宿主写供安全从属解释器的主侧别名调用的路径翻译包：输入访问路径列表与可访问的子目录，令牌路径翻译成真实路径后规范化须仍在对应访问路径下；令牌编号越界、含 .. 逃出、符号链接指向外部均拒绝；glob 结果反向翻译回令牌，不得暴露真实路径，错误信息也不含真实前缀；source 只接受 .tcl 文件，且最终打开的文件须通过同一检查。用伪造编号、令牌拼 ..、符号链接替换、glob 回显和错误信息验证。

## 实现

包 `netsec` 提供 `Translator`。令牌编号从 `0` 开始，与 `$p(:0:)`、`$p(:1:)` 对应：

```go
tr, err := netsec.New([]string{"/srv/tcl/lib"})
if err != nil {
    // 配置错误
}

realPath, err := tr.Translate("$p(:0:)/pkg/init.tcl")
token, err := tr.PathToken(realPath)
matches, err := tr.Glob("$p(:0:)/pkg/*.tcl")
script, err := tr.Source("$p(:0:)/pkg/init.tcl")
```

如需进一步禁止访问访问路径下的其他子目录，可将可访问子目录传给构造函数：

```go
tr, err := netsec.New([]string{"/srv/tcl/lib"}, []string{"pkg"})
```

### 安全边界

- 只接受完整的 `$p(:N:)/...` 形式；索引必须落在访问路径列表内。
- 任何 `..` 路径分量（包括反斜杠形式）都在文件系统操作前拒绝。
- 所有文件和目录路径先经过 `filepath.EvalSymlinks`，再做访问路径包含检查；指向外部的文件或目录符号链接都会失败。
- `glob` 只返回 `$p(:N:)/...` 令牌，并在返回前对每个匹配项做同样的规范化检查。外部符号链接匹配项会被排除。
- `Source` 只接受 `.tcl` 普通文件，并在打开后再次解析令牌，用 `os.SameFile` 确认打开的文件仍是检查通过的那个文件。
- `errors.go` 中的错误均为不含真实路径的 sentinel；文件系统错误不会原样返回给从属解释器。
