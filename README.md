Web 应用防火墙与表单校验服务装载用户或业务方提交的正则表达式时，若直接交由回溯型正则引擎执行，含嵌套量词（`(a+)+$`）、重叠分支循环（`(a|aa)+$`）或相邻可重叠加号（`a+a+$`）的病态正则会在几十字节恶意输入下触发指数/多项式级回溯导致服务 CPU 100% 拒绝服务（ReDoS）。为 TypeScript 安全审计宿主实现可导入的零外部依赖正则 AST 解析、NFA 歧义回溯静态分析与对抗攻击串合成引擎。组件从零解析正则子集（字面量、字符类 `[a-z]`/`[^...]`、`.`、分组 `(...)`、分支 `|`、量词 `*`/`+`/`?`/`{m,n}` 与锚点 `^`/`$`）并构造带 epsilon 边的 Thompson NFA；通过构建乘积自动机（Product NFA `N x N`）精确检测两类 ReDoS 漏洞：（1）指数级歧义（EDA：存在某状态 `q` 与非空串 `pump` 使 `q` 沿两条不同 NFA 路径均能回到 `q`，且存在可达前缀 `prefix` 与无法匹配终止的后缀 `suffix`）；（2）多项式级歧义（IDA：存在前后两个同字符集循环重叠）。一旦检出漏洞，引擎不仅报告复杂度等级（`SAFE`/`POLYNOMIAL`/`EXPONENTIAL`），还必须自动合成最小可复现的 `(prefix, pump, suffix)` 攻击串并在内置受限步数回溯模拟器上实证该攻击串随 `pump` 重复次数增加触发超线性回溯步数爆炸。附经典 ReDoS 漏洞库、安全线性正则（必须零误报）与合成攻击串实测验证。
