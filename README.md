# cep — 多模式复合事件序列匹配器

基于非确定性有向无环图（NFA）的轻量 CEP 引擎，仅使用 Go 标准库。

## 模式语义

识别时序模式 **A -> B 且中间不能出现 C**：

- 每个 `A` 在 NFA 中启动一条部分匹配运行（run），多条 run 可并行存活（非确定性）。
- `B` 落在 `A` 之后且 `B.Time - A.Time <= Window`（滑动时间窗，边界含 10s）时，run 迁移到完成态并发出 `MATCH` 通知。
- `C` 落在 `(A, B)` 区间内则使 run 失效（否定模式）；若 run 已完成，则发出 `RETRACT` 补偿通知，精准撤销先前命中。
- 引擎时钟随最大事件时间推进，挂起 run 的窗口过期后被丢弃并记入日志（超时丢弃）。
- 事件允许乱序到达：迟到的 `C` 触发补偿撤销，迟到的 `B` 仍按事件时间正确匹配。

## 运行

```sh
go test ./...    # 运行测试
go run ./cmd/demo  # 运行验收场景样例
```

## 验收场景

`A@0`、`B@5` 产生命中；随后迟到事件 `C@2` 到达，系统撤销先前命中并记入日志。
