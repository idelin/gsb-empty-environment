B+ 树页采用前缀压缩，重启键用全长，其他键相对前驱存共同前缀长度和后缀；长度字段均用无符号 LEB128。为索引构建器提供可导入的 Go 包，给定严格有序的字节键和频率，选择叶页切点及每页重启点，每两重启点间解码比较次数不超过 K。页分裂时父分隔键取左页末键与右页首键之间满足 左末<分隔≤右首 的最短字节串，同长字典序最小。每个父页也按相同编码但只在页首重启，父页不得跨越给定范围栅栏。找能满足两级页容量的布局，先最少父页和叶页总数，再最小按频率加权的查找解码次数，最后切点和重启序列最小。交付编码器与独立逐字节回读检查器，不接受只估算长度。小表枚举核对，覆盖 127/128、前一键是后一键前缀和局部最省叶空间却多占父页的情况。
