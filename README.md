# 加密记录乱序与重放

Go通信服务需要嵌入连接层的认证记录接收包，使用标准库AES-GCM，密钥由调用方提供。记录携带连接ID、epoch、uint64序号和密文，AAD为连接ID字节长度大端uint32、连接ID、epoch大端uint32、序号大端uint64；nonce为epoch与序号的12字节拼接。每epoch维护1024位重放窗口，允许乱序但重复、太旧和认证失败不得交付；伪造高序号认证失败不能推进窗口。密钥轮换时仅当前和前一epoch可用，前一epoch在调用方显式Retire后拒绝；同epoch密钥不得替换，序号不得回绕。实现并发接收原子去重，回调报错仍算已消费且不能重复交付，给出真实加密测试及并发同包、伪造前移、轮换和退休竞态测试。
