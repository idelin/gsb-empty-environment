监控代理用指数直方图记录耗时，各采集点的桶粒度不同，汇总前要统一。给聚合路径交付可导入的 Go 直方图组件。桶编号由观测值的以二为底对数乘以二的尺度次方取整得到，正负数分开编码，零值计入零桶；每条直方图带尺度、正负桶的区间和计数、零桶阈值与计数、总和与个数。合并要求先统一到较小尺度，降尺度时桶编号右移并把落进同桶的计数相加，同时按规范保持桶区间的连续表示。组件还要能把正桶映射回上下界的十进制数值。验收用随机样本的原始观测逐个对照朴素模型，覆盖降尺度后区间首尾相接、全零观测、负观测、桶区间中间出现空洞，以及尺度相差超过十位时单桶合并成很宽的区间。

## 组件

`expohist` 包（`prescreen.local/ps-2c403e57ff/expohist`）提供可直接导入的指数直方图：

- `New(scale, zeroThreshold)` 创建直方图，尺度范围 `[-10, 21]`；`Observe` 按 `index = floor(2^scale * log2(|v|))` 编码，正数进正桶、负数进负桶，`|v| <= zeroThreshold` 进零桶。
- `Merge` 先把两条直方图降到较小尺度（索引算术右移、同桶计数相加），零阈值取较大值，越界桶重归入零桶；桶数组保持连续区间，中间零计数即空洞。
- `Positive`/`Negative` 返回 `BucketRange{Offset, Counts}`；`PositiveBounds` 与 `LowerBound`/`UpperBound` 把桶编号映射回十进制半开区间 `[2^(index/2^scale), 2^((index+1)/2^scale))`。
- `Scale`、`ZeroThreshold`、`ZeroCount`、`Sum`、`Count` 暴露每条直方图的完整元数据。

## 验收

```
go test ./... -race -count=1
```

测试以固定随机种子逐观测对照朴素模型，并覆盖降尺度后区间首尾相接、全零、负值、空洞、零阈值重归类，以及尺度相差 12/14 位时折叠成少量很宽桶的场景。
