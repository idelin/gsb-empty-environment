# schemamigrate

Go 模式迁移库：在整数（int64）、有理数（*big.Rat）、文本与可空字段之间迁移行数据。

## 核心语义

- **往返安全才允许转换**：`Convert` 先正向转换，再转回源类型逐位比较；
  不能精确还原原值的转换一律拒绝。例如 `1/2 → int`、`"007" → int`、
  `"1.50" → rational` 都会被拒绝；`4/2 → int → 2`、`"42" → int` 允许。
- **缺字段用显式默认值**：`Field.HasDefault` 为真且提供了 `Default` 时
  才填充；否则该行报错。默认值在建模式时校验类型与可空性。
- **未知字段单列保留**：源行中不在目标模式里的字段被序列化为确定性
  JSON，存入 `Schema.UnknownColumn` 指定的一列；未配置该列则拒绝。
- **批次原子性**：`MigrateBatch` 中任何一行失败则不发布任何结果
  （返回 nil），并以 `*BatchError` 输出逐行错误路径
  （如 `rows[3].id: ...`）。
- **空值**：null 只能进入 `Nullable` 字段；缺字段与显式 null 是不同概念。

## 测试

`go test ./...` —— 往返矩阵测试覆盖所有类型对：凡转换成功，转回后必须
等于原值；另有类型收窄、空值、默认值、未知列与批次原子性用例。
