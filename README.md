# fdtool — 函数依赖规范化工具

计算函数依赖集的正则覆盖（canonical / minimal cover），并为每一次删除给出
推导证据；同时提供属性闭包计算与依赖集等价核验。

## 构建与测试

```sh
go build ./cmd/fdtool
go test ./...
```

## 输入格式

每行一条依赖，`#` 开头为注释：

```
A,B -> C      # 逗号/空格分隔的属性名
AB -> C       # 纯大写字母连写按单字母属性拆分（教科书记法）
{} -> A       # 空左侧（也可写作 "-> A" 或 "∅ -> A"）
```

## 子命令

### `fdtool cover`

从 stdin 读取依赖集，输出正则覆盖与完整变更日志：

1. **拆分右侧**：`X -> BC` 拆为 `X -> B`、`X -> C`；平凡依赖（右侧 ⊆ 左侧，
   自反律）直接丢弃；
2. **去除多余左属性**：对 `α -> B` 中的 `a ∈ α`，若在当前工作集下
   `B ∈ (α − a)+`，则 `a` 多余，替换为 `(α − a) -> B` 并附闭包推导轨迹；
3. **去除冗余依赖**：按排序顺序逐条检查 `f`，若 `f.RHS ∈ f.LHS+`
   （在其余依赖下）则删除，并附推导证据。

步骤 2、3 均按 `SortFDs` 的确定性顺序扫描（依赖按 LHS、RHS 字典序，
左属性按字典序），因此输出与输入顺序无关，是稳定的。`cover` 结束时还会
自检覆盖与原依赖集等价。

空左侧 `{} -> A` 在闭包中立即触发；循环依赖（如 `A -> B, B -> A`）按序
处理，对成环的冗余边（`A -> C` 与 `B -> C` 同时存在时）恰好保留一条，
保证等价性不被破坏。

### `fdtool closure A,B`

计算给定属性集在 stdin 依赖集下的闭包，并打印逐步推导。

### `fdtool equiv`

stdin 中以单独一行 `---` 分隔两个依赖集，做双向蕴含核验（F ⊨ G 且
G ⊨ F）。每条依赖给出可推导性结论；不可推导的依赖即反例。不等价时以
退出码 1 结束。

## 代码结构

- `fd/fd.go` — 依赖类型、解析器、确定性排序
- `fd/closure.go` — 属性闭包不动点计算与推导轨迹（证据）
- `fd/canonical.go` — 正则覆盖三步算法与变更日志
- `fd/equiv.go` — 双向蕴含等价核验
- `cmd/fdtool/main.go` — CLI
