秘密交付服务需要判断断线后还能向客户端承诺什么。请给 Go 会话宿主实现可导入的回执判定包。输入是显式有限状态协议：状态有服务方可见持久字段、会话持有者、仍能读出秘密的主体集合和已成功交付次数；迁移注明动作、执行者、可见回执或不可见标记。服务只见初始公开字段和随后回执，不可见迁移可出现任意次，包括循环与超时重传。提供者每步从列出的服务动作中选一个，环境可在前后任选不可见迁移，再从该动作的所有结果中任选一个；同一观察历史必须选同一动作。若某个可能状态无此动作，该选择非法。求在最多 H 次动作内保证结案的观察策略：每个相容实际状态都只能向同一原会话交付至多一次；终止回执“已交付”要求恰交付一次且无人再能读取，“未交付”要求零次且已销毁。允许在真相无法确定时明确返回“未知”，但它不算保证结案。若可保证，先最小化最坏动作数，再按动作名排序，返回共享子策略的决策图；若不能，返回覆盖所有合法首选动作的环境反例树；独立检查器须拒绝只挑一个失败动作或漏掉不可见循环的假反例。初始状态与迁移至多 32 状态、H≤12，超资源预算不得声称无解。用小协议完整策略枚举对照，覆盖丢回执后不可区分、隐藏循环、同回执不同持久状态及最后一步销毁。
