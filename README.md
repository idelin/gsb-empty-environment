# DynamicConvexHull

动态点集凸包维护与极值查询。Python 3.11，仅标准库，测试用 unittest。

## 设计要点

- **精确算术**：坐标接受 `int`、`fractions.Fraction` 或 `(分子, 分母)` 元组，内部统一为
  `Fraction`；方向/共线判断全部用精确叉积，无 epsilon。`float` 被拒绝以避免隐式误差。
- **多 ID 同坐标**：坐标 → ID 集双向映射；删除一个 ID 只移除该 ID，
  同坐标还有其他 ID 时几何点保留。
- **固定共线策略**：凸包边上的共线点保留在包络中，按边界逆时针顺序输出
  （单调链算法，严格叉积 < 0 才弹出）。
- **退化定义**：空集 → `[]`；单点 → 该点；全共线 → 从一端到另一端的有序链（线段）。
- **来源映射**：`hull()` 返回 `HullVertex(x, y, ids)`，每个几何点附带存活 ID。
- **极值查询**：`extreme(dx, dy)` 返回最大点积及全部达到最大值的包络点
  （方向垂直于某边时返回整条边，含共线点）。
- **重复 ID**：`add` 已存在的 ID 抛 `ValueError`；`remove` 不存在的 ID 返回 `False`。

## 运行

```sh
python3.11 demo.py                      # 运行样例
python3.11 -m unittest test_dynamic_hull -v   # 测试
```

## 测试结果

24 个用例全部通过，覆盖：退化情形（空/单点/两点/全共线）、边上共线保留与顺序、
内部点不改变包络、同坐标多 ID 的增删语义、精确算术（2e-18 级近共线不被误判）、
极值查询平局返回整条边、动态增删与缓存一致性。
