口令库切换摘要格式时，旧摘要、双写日志和灾备导出会存活不同的时间。给 Go 认证宿主写可导入的迁移审查包，只用不含口令的有限符号。输入最多 18 个有偏序约束的动作和若干副本，每个动作搬运、覆写、擦除一个具名凭据版本，或改变哪组副本允许联合读取；覆写只擦除目标位置的上一版本，已被观察方取得的摘要不会收回。每份摘要声明盐域、代价级和可验证的账号集合；同盐域且由同一口令族生成的摘要，只要一份被观察方拿到，后续所有该族账号都按其中最低代价暴露，哪怕当时还没有搬入该账号的新摘要；若发生副本联合读取策略收窄前未同步擦除的瞬态窗口，已读出的低代价摘要同样永久计入暴露。账号族与可合谋观察组都由输入给定。合法用户每步后至少有一份当前验证器接受的摘要。求一条可完成的迁移顺序，先最小化所有前缀中低于迁移目标代价的暴露账号数峰值，再最小化前缀暴露数之和，最后按动作编号破同分。给出峰值发生在哪一步、哪组观察方与哪些摘要；返回的最优性证据可由宿主复核，每个前缀的暴露数按最坏单组合谋计。用小图全排列对照，测盐域隔离、擦除后记忆保留、两份低成本摘要影响同账号只计一次，以及已执行动作集相同但所见历史不同。
