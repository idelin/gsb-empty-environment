# tlv

Go TLV（Type-Length-Value）编解码库，仅依赖标准库。

## 线格式

```
+------------+------------+===================+
| type (4B)  | len  (4B)  | payload (len B)   |
+------------+------------+===================+
```

均为大端序。`type` 最高位（`ContainerFlag = 1<<31`）置位表示容器：
payload 为若干子 TLV 的拼接，且必须恰好填满；其余类型一律视为
不透明载荷，原样保留。

## 规则

- **未知类型透传**：未知字段解码后 `Raw` 原样保留，重编码字节一致。
- **容器嵌套**：容器可任意嵌套；空容器（len=0）合法。
- **规范序列化**：`Encode` 声明长度恒等于实际载荷大小，子项按原始
  顺序输出，重复字段顺序保留。
- **父边界约束**：子项声明长度不得越过父容器边界，否则报
  `*CorruptError`，`Offset` 为该子项在整个流中的绝对偏移。
- **长度额度**：声明长度超过 `MaxLength`（1<<30）在分配前即判为坏数据。
- **分块解析**：`Decoder.Write` 接受任意分块；`Next` 用
  `ErrIncomplete`（缺数据，`errors.Is` 可判）与 `*CorruptError`
  （坏数据，含绝对偏移）区分两类失败。

## 运行样例

`example_test.go` 中的 `Example` 构造含未知字段与空容器的嵌套消息，
规范编码后逐字节喂回解码器：

```
wire: 800000010000001f0000000100000005616c6963650000999900000002dead8000000200000000
children: 3, unknown field: dead
round-trip identical: true
```

```
GOCACHE=/tmp/gocache go test -v ./...
```

11 个测试全部通过，覆盖：回环、未知透传、嵌套规范编码、重复字段
顺序、空容器、越界绝对偏移报错、逐字节分块、缺数据/坏数据区分、
分配前额度检查、流内多值。
