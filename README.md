# treecrdt — 树形文件系统的无环 CRDT 移动/重命名协调器 (Go)

多节点分布式虚拟目录树的移动协调。每个移动/重命名操作携带 **Lamport 逻辑时间戳 +
副本 ID**,构成确定性全序;各副本合并操作日志后按全序**重放**,重放时沿父链做
**因果追溯**,凡会引入拓扑依赖环的操作(即全序中"后发生"的成环操作)被确定性
撤销,先发生的操作保留,目录不丢失。

## 设计

- `MoveOp{Node, NewParent, NewName, Time}`:操作即日志条目,`Time = (Lamport, ReplicaID)`。
- 全序:Lamport 升序,平局按 ReplicaID 字典序 —— 所有副本仲裁结果一致,与合并顺序无关。
- 重放(`recompute`):从一致的基准树出发按全序应用日志;应用前从 `NewParent`
  沿父链向上走,若遇到被移动节点则成环,拒绝该操作并记入 `Rejected()` 审计日志。
- 合并(`Merge`):日志按操作 ID 取并集(幂等),本地时钟推进到已知最大值。
- 附带确定性同名冲突消解:目标目录已有同名子项时追加 `@副本ID` 后缀。

## 运行

```sh
go test ./crdt/ -v   # 测试
go run ./cmd/demo    # 验收场景演示
```

## 验收场景

节点1 移动 `/dirA` 到 `/dirB` 下,节点2 并发移动 `/dirB` 到 `/dirA` 下。
合并后检测到拓扑依赖环,依据全序(node1 < node2)撤销 node2 的操作,
最终 `/dirA` 位于 `/dirB` 下,`/dirB` 留在根下,无目录丢失,两副本视图一致。
