新闻归档中一篇文章可同时属于公开组和私有组。给 Go 阅读网关写可导入的可见索引组件，供按组翻页、按消息 ID 取文和订阅变更共用。每份发布版本含属于各组的独立内容片段、回复边和引用计数；用户只可见所获授权组的片段，并且只能看到两端均可见的引用边。查询按同一用户可见的首发顺序分页，页游标必须绑定主体、授权代次及快照，不能由隐藏插入、删除或私有编辑改变可见页长、计数、顺序、续页状态和通知。公开片段最后一次解除关联后，消息 ID 查询与根本不存在须给出相同结果；可见引用计数要按已去重的消息对重算。批更新可能同时更改组关系、内容和 ACL，通知只发送提交前后可见视图的最小差异，不得发出短暂私有内容。编写两个只在未授权数据上有差异的内存归档，穷举短操作序列，比较每个用户全部输出；验证同一消息多组关联、回复环、撤权时分页及批内先公开后隐藏。
