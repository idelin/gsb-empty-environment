# 配置包含的信任降级

Go策略服务会合并受签名保护和租户自定义的配置，需要一个嵌入加载器的包含解析包。配置文档包含ID、信任级别trusted或untrusted、键值设置和有序include，文档由调用方不可变映射提供，最多128份；攻击者只能提供untrusted文档及其包含关系。展开采用深度优先顺序，后写覆盖前写，但untrusted路径永远不能覆盖trusted路径写入的键；文档本身trusted仍会因任一包含祖先untrusted而降级。相同文档可经不同信任路径多次包含，不能按文档ID全局缓存结果；环路返回完整环路径且不发布部分配置。实现有效值、来源路径及拒绝覆盖记录，验证菱形包含、信任洗白、同值覆盖与环路；以不缓存参考实现对随机小图核对结果。
