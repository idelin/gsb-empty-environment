# 去中心化集群拓扑视图分歧检测与校验和快速比对（TypeScript）

多节点成员状态一致性审计器：每个节点为「成员 ID + 状态 + 版本」维护**增量哈希环 Digest**
（4 字节 CRC-32，XOR 聚合，O(1) 增量增删改）。周期探活时邻居间仅交换 4 字节摘要；
失配时交换**分区间摘要**定位分歧区间，仅拉取差异区间内的成员记录做双向合并（LWW +
状态优先级 DEAD > SUSPECT > ALIVE），实现区间状态对账。

## 结构

- `src/crc32.ts` — CRC-32（IEEE）4 字节摘要
- `src/digest.ts` — 增量哈希环 Digest（XOR 环，顺序无关、O(1) 更新）与区间映射
- `src/membership.ts` — 成员表：全局 Digest + 8 个区间 Digest，合并规则
- `src/node.ts` — 集群节点：探活协议（摘要比对 → 区间定位 → 差异拉取合并）
- `src/simulation.ts` — 两子集群分区愈合场景模拟
- `test/` — Node 内置测试（`node:test` + `node:assert`）

## 运行

要求 Node ≥ 22.6（原生 TypeScript 类型擦除；开发使用 v23.9.0），无需安装依赖。
仓库附带 `.nvmrc`，使用 nvm 时先执行 `nvm use` 切换到正确版本。

```bash
npm start    # 运行分区愈合模拟
npm test     # 运行全部测试
```


场景：{A1,A2,A3} 与 {B1,B2,B3} 两子集群分区后各自独立变更（A 侧新增 A4、误判 B1 死亡；
B 侧新增 B4、怀疑 A1）。愈合瞬间恢复链路，首轮探活即通过 4 字节摘要失配察觉不一致，
经区间对账在 **1 轮内（≤5 轮）** 完成 6 节点 × 8 成员的全量双向对齐。
