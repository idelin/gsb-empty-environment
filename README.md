# archive-audit

按块逻辑长度加权、无放回抽样的归档审计工具（Go 实现）。

## 用法

```sh
go build -o archive-audit .

# 1. 建归档：清单自带每个块的逻辑长度与 SHA-256 摘要
./archive-audit create -out data.arc -block-size 4096 INPUT...

# 2. 抽样审计：调用方提供种子，过程可复现
./archive-audit sample -archive data.arc -seed "audit-2026-10-05" -k 10

# 3. 小归档：穷举随机域，精确核对选择概率
./archive-audit enumerate -archive small.arc
```

## 设计要点

- **长度加权、无放回**：逐次 PPSWOR。每一步以 `权重/剩余总权重` 的概率
  选中一个块并移出抽样池，已选块不会被再次选中。
- **调用方提供种子、可复现**：随机流来自内置的 SHA-256 计数器 DRBG
  （`sampler.go`），不依赖 `math/rand`，跨 Go 版本、跨平台结果一致。
  同一种子重复抽样或"恢复"继续抽样时，k 次抽取结果是 k+m 次结果的
  严格前缀——已选块永不改变。
- **大整数、无取模偏差**：总长度与所有区间运算使用 `math/big.Int`，
  任意大的归档不会溢出。均匀抽样用拒绝采样（生成 ⌈log2 n⌉ 位、
  越界即丢弃重采），绝不使用取模折叠，因此无 modulo bias。
- **归档自带块摘要**：清单中每个块携带逻辑长度与 SHA-256 摘要；
  验证时对抽中块的负载重新计算摘要并比对。
- **抽样结论 ≠ 全文件完整**：输出只声明 "SAMPLED BLOCKS VERIFIED
  (k of n)"，并附明确声明：结果仅覆盖已抽中的块，不证明整个归档
  或任何未抽中块的完整性。
- **小归档枚举核对**：`enumerate` 穷举随机域 `[0, W)` 及第二次抽取的
  全部条件域，精确验证 `P(first=i) = w_i/W`、
  `P(second=j|first=i) = w_j/(W-w_i)`（即 (i,j) 恰好出现 `w_i*w_j`
  次、(i,i) 出现 0 次），从定义上确认无偏差、无放回。

## 输出

`sample` 打印完整抽样过程（每步的剩余总权重、随机值、命中块及其
区间）与逐块验证结果，便于第三方用同一种子独立复现核对。
