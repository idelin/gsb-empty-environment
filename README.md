# 确定性事件重放调试内核

支持**无副作用时间旅行**的事件调度器：将系统所有外部输入（网络包到达）、
时钟中断（超时）与随机种子记录为日志序列，可跳转至任意历史事件，
并完全复现当时所有组件的内存不变量（SHA-256 快照逐字节比对）。

## 环境要求

- Node.js ≥ 23.6（原生 TypeScript 类型擦除，无需编译、零依赖）
- 仓库内含 `.nvmrc`：`nvm use` 即可切换到 v23.9.0

## 运行

```bash
nvm use          # 或自行切换到 Node >= 23.6
npm run demo     # 运行样例：录制 -> 快照 -> 时间旅行 -> 全量校验
npm test         # Node.js 内置测试运行器 (node:test)
```

## 设计

| 文件 | 职责 |
| --- | --- |
| `src/rng.ts` | mulberry32 确定性随机流，状态为单个 uint32，可序列化/恢复 |
| `src/scheduler.ts` | 最小堆调度器，按 `(tick, 插入序号)` 全序调度，虚拟时间确定性推进 |
| `src/node.ts` | 演示组件：带超时重传的可靠发送节点，状态全为可序列化纯数据 |
| `src/kernel.ts` | 内核：`record()` 录制日志+快照；`travelTo(n)` 从原点重放到第 n 个事件；`verify()` 全量校验 |
| `src/canonical.ts` | 规范化序列化（键排序）+ SHA-256 状态指纹 |

关键机制：

- **录制/重放同一条代码路径**：录制时外部输入由环境随机流生成并写入日志；
  重放时外部输入逐条取自日志，时钟中断由组件逻辑确定性重导，并与日志逐条校验。
- **无副作用时间旅行**：`travelTo(n)` 从「种子 + 日志」全新构建世界，
  不触碰任何现存状态；组件除变更自身状态外无任何 I/O。
- **完整内存不变量**：快照覆盖虚拟时钟、RNG 状态、调度器插入计数与待触发队列、
  组件全部状态，规范化后计算 SHA-256。

历史快照 hash   : af10cc596631ef87bb856e434e1bc802d071ba52cca88c0ec2ee3616193e5f22
哈希一致        : true
字节逐一致      : true

`node:test` 共 10 项测试全部通过（含 0..53 全部 54 个快照复现、
时间旅行无副作用、篡改检测、确定性双录制一致等）。
