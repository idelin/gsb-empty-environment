# Yggdrasil隧道内层源地址与公钥派生核对

Yggdrasil 式网络里节点地址由公钥派生，攻击者可在加密隧道里发出内层源地址属于他人的包，冒充其他节点。给Go节点写供解封装后调用的源地址校验包，派生规则按本题规定：取 32 字节公钥的 SHA-512，统计开头连续 1 位的个数 n，跳过其后的第一个 0 位，地址为 [0x02, n, 之后的 14 字节]；子网前缀为 [0x03, n, 之后的 6 字节] 加零补成 /64。内层 IPv6 源地址必须等于该对端公钥派生的地址，或落在其子网内，否则丢弃；对端宣告的地址若与其公钥派生结果不符，拒绝建立隧道；目的地址为本节点以外的内层包按路由处理，不得因源地址校验通过而绕过。用 n 为 0 与大值的密钥、地址冒用、子网内源地址和宣告不符验证。
