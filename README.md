网关把若干认证会话合并到新版消息通道时，部分在途回复无法从旧日志唯一确定接收实例。给 TypeScript 宿主实现可导入的迁移授权规划包。签名日志记录发送、确认、转授与撤销，部分旧回执仅给出候选接收实例集合；同一帧的所有后续回复必须沿同一实例解释，不能在不同队列分别挑一个身份。打断并重新认证一个实例会撤销它全部旧许可，但不应波及仅共享传输连接的其他实例。为保全指定的已确认公开消息并保证所有相容历史下都不会把私有回复交给未授权主体，求最少需重新认证的实例及所有未被打断通道的接续映射；并列按稳定实例号决胜。至多18个可打断实例，日志可大量共享。独立验收函数既核对迁移安全，也核对没有更小的重新认证集合。用小日志穷举真实归属和所有选择，覆盖两个局部歧义共享同一收件者、撤销只关闭一个代次、同连接不同主体和必须停止整个互斥组的情形。
