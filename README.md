机箱内有输入、中间、输出三级交叉开关，每条连接在各段独占一根物理线。控制器要把全量连接从旧路由切到新路由，中途不能断开受保护的连接；测试流可以短时走一条指定旁路。为机箱控制器实现可导入的 Go 包：配置切换是按板卡批写，卡内同时生效，板与板之间可以乱序到达；重排步骤结束时才屏障确认。对于一个步骤中的任意到达次序不能把数据错误投给另一客户，受保护连接不得中断；分光复制允许两份相同数据到达同一端口，但计入带宽。求旁路容量给定时最少屏障步骤和规范化操作表；不可行时给出任意首步都会违约的可检验证书。至多八板、六条业务，候选中间线有限。小机箱枚举板写到达顺序，特别测试旧新配置都合法但先后次序造成短暂串流。
