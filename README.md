# cowtree — 无锁只读快照 + 页级 Copy-On-Write（Go）

一个纯标准库实现的 B+ 树存储内核，演示两个核心机制：

- **无锁只读快照**：`View()` 捕获当前根页指针即开启只读事务，遍历全程不加任何锁。
- **页级 CoW**：写操作从不原地修改页。写路径自根至叶复制途经的每一页（分配新页 ID），
  在副本上应用修改/分裂，最后原子替换根指针。旧页保持不可变，旧快照因此永远一致。

## 结构

- `tree.go` — 不可变页结构、CoW 插入与页分裂（叶页/内部页溢出时分配全新页）。
- `db.go` — `DB`（写事务互斥 + 原子根指针）、`Snapshot`（只读事务）、`Iterator`（栈式中序全表扫描）。
- `tree_test.go` — 单元测试与验收测试（含 `-race` 并发测试）。
- `cmd/demo/main.go` — 可运行样例：写事务分裂节点的同事，只读事务持旧根反复全表扫描。

## 运行

```sh
go test -race -v ./...   # 测试（含验收：分裂中的快照一致性扫描）
go run ./cmd/demo        # 运行样例
```

## 关键不变式

1. 页一旦发布即不可变 —— 读者遍历的内存永远不会被写者触碰。
2. 根指针通过 `atomic.Pointer` 单次原子写入切换 —— 读者要么看到旧版本，要么看到完整的新版本。
3. 写者由互斥锁串行化 —— 任意时刻只有一个写事务在构造新版本。
