# rational_id：有理多项式表达式恒等判定

在**精确有理数**（`fractions.Fraction`）上展开、规范化两个有理多项式表达式，
判定它们是否恒等。**仅使用 Python 3.11 标准库，不调用任何符号代数库。**

## 支持域

- 运算符：`+ - * / ^`（`^` 的指数必须是非负整数字面量，且 ≤ 100000）
- 运算数：整数/小数常量（精确转为有理数）、变量标识符、括号
- 超出支持域（函数调用、负指数、非常量指数、隐式乘法等）→ 返回**未知**
- 展开项数超过预算（默认 2000，可调）→ 返回**未知**

## 判定方法

1. **解析**：递归下降解析为语法树；超出支持域的构造直接判“未知”。
2. **规范化**：每式化为 `(分子, 分母, 定义域分母)` 三元组（稀疏多元多项式，
   字典序单项式 → 有理数系数）。定义域分母是所有出现过的分母（含除数的分子）
   之积：它在某点为 0 当且仅当原表达式在该点无定义。每一步变换都写入日志并
   注明**适用域**（该步成立的条件）。
3. **比较有理函数**：交叉相乘 `n1·d2 − n2·d1`，判断是否为零多项式。
   非零 → **不恒等**，并按对角顺序枚举有理点找到反例，用原始表达式精确求值验证。
4. **比较定义域**：有理函数相同还不够——分母定义域不同不能仅看约分结果。
   计算两边定义域分母的**无平方部分**（多元多项式 GCD，本原 PRS，精确有理数），
   相同（相差非零常数倍）→ **恒等**；不同则搜索有理见证点：找到 → **不恒等**
   （反例为恰好一边无定义的点），预算内找不到 → **未知**。

关键原则：

- **随机点相等不等于恒等**：恒等只由规范化后的精确多项式比较得出；
  点求值仅用于构造并验证反例，绝不用于证明恒等。
- **分母定义域不同不能仅看约分结果**：如 `x/x` 与 `1` 约分后相同，
  但 `x/x` 在 `x=0` 无定义，判为不恒等并给出反例 `x=0`。
- **项数预算超限标未知**：不猜测、不截断结论。

## 运行

```bash
python3.11 -m rational_id "左式" "右式" [--term-budget N] [--eval-budget N] [-q]
```

退出码：`0` 恒等，`1` 不恒等，`2` 未知。

  1. 支持域：仅含 + - * / ^（非负整数次幂）、有理数常量、变量、括号；超出支持域即返回未知
  ...
  14. 比较有理函数：交叉相乘 n1·d2 − n2·d1，判断是否为零多项式；适用域：有理函数域 Q(x) 中的恒等，等价于在两式共同定义域上处处相等；不依赖随机点取值

## 代码结构

- `rational_id/poly.py`：稀疏多元多项式（精确有理数）、GCD（本原 PRS）、无平方部分、项数预算
- `rational_id/ast_nodes.py`：语法树节点与精确求值
- `rational_id/parser.py`：词法/语法分析，支持域检查
- `rational_id/normalize.py`：规范化为 `(分子, 分母, 定义域分母)`，每步记录适用域
- `rational_id/checker.py`：判定主流程、有理点枚举、反例验证
- `rational_id/cli.py`：命令行界面

## 已知限制

- 定义域按“定义域分母在 Q 上的零点集”理解。无平方部分不同但预算内找不到
  有理见证点时（例如零点集在 Q 上实际相同），诚实地返回“未知”。
- 反例/见证点搜索按对角顺序枚举有理点，受 `--eval-budget` 限制。
