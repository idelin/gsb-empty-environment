# INI节注入

程序把用户输入写进 INI 文件时，攻击者在值里放换行与 `[admin]`，或在键里放 `=`，让下次读取多出一个节或覆盖某个键。为Go的配置库写可导入的 INI 写入器与解析器：写入时键含 `=`、`:`、`;`、`#`、换行或首尾空白一律拒绝；节名含 `]` 或换行拒绝；值含换行或 CR 时用双引号包裹并转义为 `\n`、`\r`，含 NUL 拒绝；值以 `[`、`;`、`#` 开头或首尾有空白时同样加引号；解析器须还原这些转义，并满足 parse(write(x)) 与 x 完全一致；读取时行尾反斜杠的续行不得跨越节头。测换行注入、引号还原、续行跨节、往返一致。

## 使用方式

包名 `netsec`，通过 `Set`/`Get` 操作配置，`Marshal` 与 `Unmarshal` 负责序列化：

```go
cfg := netsec.NewConfig()
if err := cfg.Set("app", "note", "line1\n[admin]\nrole=root"); err != nil {
    // 只有 NUL 值等非法输入才会到这里
    log.Fatal(err)
}
data, err := netsec.Marshal(cfg)
// [app]
// note = "line1\n[admin]\nrole=root"

parsed, err := netsec.Unmarshal(data)
v, ok := parsed.Get("app", "note") // 原样还原，[admin] 不会变成新节
```

## 安全与解析语义

- 写入校验：键含 `=`、`:`、`;`、`#`、换行、NUL、首尾空白或以 `[` 开头一律拒绝；节名含 `]`、换行或 NUL 拒绝；值含 NUL 拒绝。校验在 `Set` 与 `Marshal` 两处都会执行。
- 引号转义：值含换行/CR、双引号、反斜杠，或以 `[`、`;`、`#` 开头、首尾有空白时加双引号；`\n`、`\r`、`\"`、`\\` 在解析端还原，未知转义保留字面形式。
- 续行规则：行尾反斜杠会与下一物理行拼接；下一行是节头（含带缩进的 `[`）时续行立即终止，节头独立解析，未消费的反斜杠按普通字符保留。
- 往返保证：节、键均按顺序保存（支持重名节与重复键），`Unmarshal(Marshal(x))` 与 `x` 深度相等，且重复序列化结果幂等。
- 其他：支持 CRLF 输入、空字符串全局节；`;`、`#` 开头为注释，引号内的注释符视为普通值。
