# 加权最大最小公平带宽分配（wmmf）

纯 Python 3.11 标准库实现，全部数值用 `fractions.Fraction` 精确表示
（合成整数/有理数），不调用任何求解器。

## 功能

- **加权最大最小公平注水分配**：归一化速率 `rate / weight` 同步抬升，
  逐轮冻结，输出**冻结顺序**与**瓶颈链路**（`wmmf/allocator.py`）。
- **需求上限**：到达上限的需求立即冻结，之后不再继续分配。
- **多链路/多路径共享需求**：一个需求只获配一个标量速率，在其经过的
  每条链路上各计一次，绝不在每链路上重复获配。
- **公平证书**：对每个未满足需求给出一条饱和瓶颈链路，其上所有需求的
  归一化速率都不更高——因此提高它必然降低某个归一速率不更高者
  （`wmmf/certificate.py`）。
- **增量再分配**：链路故障、容量调整、需求撤回后重新注水；饱和集合
  变更时**解冻原需求**，而不是只继续扣剩余量（`wmmf/network.py`）。
- **小有理网格穷举核验**：枚举有理网格上的可行分配，按排序归一化
  速率向量的字典序确认最优性；枚举预算耗尽时返回 `budget_undecided`
  （预算未决），与"可行""最优"结论严格分开（`wmmf/exhaustive.py`、
  `wmmf/verify.py`）。

## 运行

```sh
python3.11 main.py                     # 运行样例
python3.11 -m unittest discover -s tests -v   # 运行测试
```

## 运行样例（节选）

```
== 基本加权分配（d2 多链路共享，速率不重复计算） ==
  需求 d1: 速率 7/2 (归一 7/2, 上限 8, 未满足)
  需求 d2: 速率 7/2 (归一 7/2, 上限 6, 未满足)
  需求 d3: 速率 3 (归一 3/2, 上限 3, 已达上限)
  链路 A: 负载 10 / 容量 10
  链路 B: 负载 7/2 / 容量 4
  冻结顺序:
    第 0 轮 @ 水位 3/2: 冻结 ['d3'], 因达上限冻结 ['d3']
    第 1 轮 @ 水位 7/2: 冻结 ['d1', 'd2'], 瓶颈链路 ['A']
  公平证书:
    需求 d1（归一速率 7/2）受瓶颈链路 A 约束：A 已饱和（负载 10 = 容量 10），
    且其上所有需求的归一速率均 <= 7/2；提高 d1 必然降低其中某个归一速率不更高者
  可行: 是
  最优(证书): 是
  网格穷举: confirmed_optimal (检查 1547 个网格点)

-- 撤回需求 d1，触发增量再分配（解冻 d2，而非只扣剩余量）--
  需求 d2: 速率 6 (归一 6, 上限 10, 未满足)     # 原冻结在 5
  饱和集合: ['A'] -> ['B']
  被解冻提速的需求: ['d2']

== 预算未决演示（网格 11x11，预算 10） ==
  可行: 是
  最优(证书): 是
  网格穷举: budget_undecided (检查 10 个网格点)
```
