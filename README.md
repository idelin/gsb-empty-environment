# Bazel远程缓存写入准入

团队的构建缓存同时服务 CI 与外部贡献者的 PR 构建，攻击者在 PR 构建里写入被投毒的 ActionResult，让主干构建命中并产出带后门的二进制。为Go缓存服务实现可嵌入 gRPC 前置的写入准入包：只有标记为可信的写入者能更新动作缓存，PR 来源只读；CAS 上传的 blob 必须与资源名里的 sha256 和大小一致；ActionResult 引用的每个输出摘要都要已在 CAS 中且大小相符；同一动作摘要被不同输出覆盖时拒绝并记录；ByteStream 资源名里的 hash 必须为 64 位小写十六进制。用伪造摘要、缺失 blob、PR 写入和覆盖冲突验证。
