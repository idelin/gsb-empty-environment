# objstore

带宽限期与代际（generation）机制的引用计数对象库。

## 生命周期

```
                 Delete              宽限期结束且引用归零
  Active  ─────────────────►  PendingDelete  ─────────────────►  Deleted（终态）
    ▲                            │
    └────────── AddRef ──────────┘
        （撤销待删，代际 +1）
```

- **Delete**：进入待删态，调度一个携带当前代际的清理任务；重复调用幂等，不顺延截止时刻。
- **AddRef**：活跃对象正常计数；待删对象在 `now < deleteAt` 时引用合法——撤销待删并将代际 +1；
  已删除或已过截止时刻返回 `ErrDeleted`，**绝不隐式重建**。
- **清理任务**：仅当对象仍处于待删态且代际与任务携带的一致时才生效（旧任务只对原代生效）；
  若仍有引用未释放，则等待，由最后一次 `Release` 在截止时刻过后完成真正删除。
- **Deleted 为终态**：id 永久退役，`Create` / `AddRef` / `Delete` 均失败。

## 引用账（ledger）不变量

`Store.Ledger()` 返回按 id 排序的快照，用于核对边界竞争：

- `Refs >= 0`，且等于未释放的 `Ref` 句柄数；
- `Deleted` 对象 `Refs == 0`；
- `Generation` 单调不减，每次撤销待删严格 +1。

## 虚拟时钟

`FakeClock` 的时间只随 `Advance` / `SetNow` 前进，到期任务按触发时间（同刻按注册顺序）同步执行，
可确定性重放“清理任务 vs 新增引用”的边界竞争；执行回调时不持有时钟锁，避免锁序环。

## 测试

```sh
go test ./...        # 确定性边界测试（虚拟时钟）
go test -race ./...  # 并发竞争 + 引用账核对
```
