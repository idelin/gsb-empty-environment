# cyclecut — 构建循环拆解工具

给定一个有向依赖图，其中只有**被授权的边**（`cuttable: true`）可以切断，
且每条可切边都绑定了**指定的引导产物**（`artifact`）与成本（`cost`）。
`cyclecut` 求出使图无环的**总成本最小**的切边集合，输出拓扑构建计划
以及每条切边所用的引导产物。

规则保证：

- 未授权的边永远不会被切断，也不允许声明成本或产物（输入即报错），
  杜绝用旧产物替代未授权的边。
- 每条被切的边只能花费它自己绑定的产物，产物不可跨边挪用。
- 可切边数量上限为 25 条，超出即拒绝。
- 若图中存在不含任何可切边的环，报告 `INFEASIBLE`。

## 用法

```sh
go build -o cyclecut ./cmd/cyclecut
./cyclecut -f examples/graph.json            # 文本输出
./cyclecut -f examples/graph.json -format json
cat graph.json | ./cyclecut                  # 从标准输入读取
```

退出码：可行 `0`；不可行（存在无法切断的环）`1`；输入非法 `2`。

## 输入格式

```json
{
  "nodes": ["a", "b"],
  "edges": [
    {"from": "a", "to": "b"},
    {"from": "b", "to": "a", "cuttable": true, "cost": 3, "artifact": "bootstrap-a-v1"}
  ]
}
```

- `nodes` 可省略，端点会自动补全；孤立节点需显式列出。
- 可切边必须带非空 `artifact` 与 `cost >= 0`。
- 平行边、自环均支持（自环即长度为 1 的环）。

## 输出

- `cuts`：每条被切边的编号、端点、所用引导产物与成本。
- `topoOrder`：剩余无环图的字典序最小拓扑序，即构建计划。
- `totalCost`：切边成本之和（保证全局最小）。

## 算法

精确求解（非近似）：

1. 贪心切环得到初始上界，同时发现不可切环即判不可行。
2. 分支定界：任找一个环，对其每条可切边分支；以下界剪枝——
   下界取剩余图中边不相交环 packing 上各环最便宜可切边成本之和。
3. 可切边 ≤ 25，搜索规模有界；测试中以暴力枚举对拍验证最优性。
