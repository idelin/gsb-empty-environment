Linux eBPF 验证器在静态证明数据包与 Map 指针偏移 `ptr + reg` 绝不越界时，单靠无符号区间 `[umin, umax]` 或单靠按位已知掩码 `tnum{value, mask}` 都会损失精度，因此同时维护 `tnum`（已知位与未知位掩码）加上 64 位无符号/有符号和 32 位无符号/有符号共四对区间，并在每条 ALU 指令和条件跳转分支后双向互相精化收紧；一旦 32 位操作未执行高位零扩展（ALU32）、带符号右移 `ARSH` 误用无符号边界、或 `tnum` 与区间交叉同步遗漏边界溢出，就会放行越界内存访问（安全漏洞）或误杀合法 XDP 程序。为数据面字节码验证器交付可嵌入的 C++20 头文件与静态库组件，供字节码加载器直接调用实现 eBPF 标量抽象域与有界指针越界验证核。状态域包含 `tnum{uint64_t value, mask}`（不变式 `(value & mask) == 0`）、`[umin64, umax64]`、`[smin64, smax64]`、`[u32_min, u32_max]`、`[s32_min, s32_max]` 以及指针偏移范围。规则：1）实现精确 `tnum` 运算（`add`/`sub`/`and`/`or`/`xor`/`lshift`/`rshift`/`arshift`/`cast32`）与跨 64/32/有符号/无符号/`tnum` 的双向不动点同步收紧（例如由 `smin64 >= 0` 收紧 `umin64`，由 `tnum` 推出最小/最大可能值与低 32 位边界，由 `umax64 <= UINT32_MAX` 同步高低 32 位，拒绝任何无解空区间分支为不可达死路径！）；2）实现 64 位与 32 位（结果高 32 位清零！）ALU 抽象转移函数，在发生 64 位或 32 位回绕溢出时安全放宽回全集而非产出错误狭窄区间（绝不允许不健全 unsound 漏报！）；3）实现条件跳转（`JEQ`/`JNE`/`JLT`/`JGT`/`JLE`/`JGE`/`JSLT`/`JSGT` 含 32 位版本）对真/假双分支寄存器状态的精确拆分收紧，支持有向无环 CFG 路径汇聚（Join 取保守并集）与基于包边界 `pkt_end` 的指针合法性证明。验收用穷举小位宽/随机具体值采样验证**绝对健全性**（每个具体执行结果必须严格落在抽象状态与 `tnum` 允许集合内，零漏报！），覆盖 `r &= 0xFF` 后越界证明、`ALU32` 零扩展收紧、带符号/无符号混合分支交叉推导出精确常量、溢出回绕保守放宽以及故意注入差 1 字节越界的恶意字节码拦截。
