# FlatBuffers缓冲校验

FlatBuffers缓冲来自不可信对端，根偏移、vtable、向量长度都可能越界或自指。给C++写供接收线程调用的校验函数：调用方给表布局，核对根偏移与文件标识（若声明），vtable 偏移须为负且在表前，vtable 长度与字段偏移都须落在缓冲内且字段偏移不得回指自身；偏移按有符号解释，字符串长度与 NUL 位置一致，向量长度乘元素大小不得溢出且元素须对齐；联合的类型与值成对，类型为零时值必须缺省；嵌套深度、表数量与总字节预算各有上限，超限拒绝而不是截断；同一表被重复访问按预算计费。用自指 vtable、负偏移回指、长度溢出、联合错配、预算耗尽与合法缓冲验证。
