# 隐私机制耦合证书

安全研究服务希望用可检查证书证明两个有限随机程序的输出相近。写供Go验证宿主调用的耦合求解包，两侧分布为有理数，允许配对边由输入给出，求满足边约束的联合分布或最小不可配对质量；返回有理流量及割证据。用小分布穷举核验边际守恒，禁止把总质量不足强行归一化。

## 使用

```go
p, _ := coupling.NewProblem(
    []*big.Rat{big.NewRat(1, 2), big.NewRat(1, 2)}, // 左侧分布
    []*big.Rat{big.NewRat(1, 2), big.NewRat(1, 2)}, // 右侧分布
    [][2]int{{0, 0}, {1, 0}},                       // 允许配对边
)
r, _ := coupling.Solve(p)        // 有理最大耦合 + 最小割证据
err := coupling.Verify(p, r)     // 验证宿主独立复核证书
```

## 设计

- `coupling.Solve` 将权重按分母最小公倍数放大为整数，用 Edmonds-Karp
  求精确最大流，再除以公因子得到有理流量；绝不归一化子分布。
- `Result` 含每条允许边的有理流量、已配对质量、两侧最小不可配对质量，
  以及最小割见证（`Cut`)。
- `coupling.Verify` 只做有理数复核：流量非负且不超过两侧边际、账目一致、
  割不跨越允许边且割容量等于已配对质量。由最大流最小割对偶，这证明
  不可配对质量最小。
- 测试在小分布上穷举（2x2 共 1296 例、3x3 共 32768 例），核验边际守恒
  并与暴力枚举最小割对照。
