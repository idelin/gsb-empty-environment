# planar_segments

线段集合精确求交并分割为平面图。Python 3.11+，仅标准库（`fractions` / `dataclasses` / `json` / `unittest`）。

## 精确性保证

- 所有坐标统一为 `fractions.Fraction`（输入接受整数或 `"p/q"` 字符串，拒绝浮点）。
- 拓扑判断（相交、共线、点在段上）全部基于精确叉积符号，**不使用任何 epsilon 容差**。
- 交点坐标（如 `1/3`、`1/2`）以有理数精确表示，输出 JSON 中写为 `"p/q"`。

## 退化情形定义（确定性行为）

| 情形 | 行为 |
|---|---|
| 零长度段（两端点相同） | 单独收集，不参与求交与分割，不进入任何除零分支；建图后分类为 `vertex`（落在已有顶点）/ `on_edge`（落在某子边内部）/ `isolated`（孤立） |
| 平行不共线 | 无交 |
| 共线部分重叠 | 重叠区间两端点加入双方分割点集合；重叠原子子边携带全部来源（如 `sources: [0, 1]`） |
| 完全重合 | 合并为一条子边，保留双来源 |
| 端点触碰 / T 型接触 | 交点同时加入两条段的分割点集合 |
| 共享端点 | 全局点表按坐标去重，同一坐标只建一个顶点 |

## 算法

1. 规范化输入，分离零长度段。
2. 两两精确求交（参数方程 + 叉积符号；共线时投影到主导轴求区间交），收集每段的分割点。
3. 每段的分割点沿主导轴精确排序，切出原子子边；全局点表去重，边按无序顶点对合并来源。
4. 零长度段对照顶点表与原子边分类。

## 用法

```bash
# 库
python3 -c "from planar_segments import build_planar_graph; ..."

# CLI：输入 JSON [[[x1,y1],[x2,y2]], ...]，坐标为整数或 "p/q"
python3 planar_segments.py input.json

# 演示样例
python3 demo.py

# 测试
python3 -m unittest test_planar_segments -v
```

## 运行样例（节选自 `python3 demo.py`，完整输出见 `demo_output.txt`）

十字交叉 `[[0,0],[4,4]]` × `[[0,4],[4,0]]` → 5 顶点、4 条子边，交点 `(2,2)`：

```json
"edges": [
  {"id": 0, "u": 0, "v": 1, "sources": [0]},
  {"id": 1, "u": 1, "v": 2, "sources": [0]},
  {"id": 2, "u": 1, "v": 3, "sources": [1]},
  {"id": 3, "u": 1, "v": 4, "sources": [1]}
]
```

完全重合两段 → 1 条子边 `sources: [0, 1]`；部分重叠 `[0,6]×[3,9]` → 3 条子边，中段 `sources: [0, 1]`；零长度段分类为 `vertex` / `on_edge` / `isolated`，不触发分割。
