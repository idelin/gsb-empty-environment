# writebacksim — 脏页回写模拟器

模拟一个容量受限、带版本化回写的页缓存，以及一块可注入故障的
版本化磁盘，用于验证回写协议的正确性。

## 模型

- **页状态**：`Clean` / `Dirty` / `Writeback`，由版本簿记推导
  （`version` 最新内存版本，`acked` 磁盘已确认版本，`wbVersion`
  正在回写的版本），不存在独立维护、可能漂移的状态字段。
- **回写中可再修改**：回写对某一版本做快照；期间的新写只会递增
  `version`，回执只确认它携带的那个版本，页面保持脏并触发下一轮
  回写。迟到 / 重复的旧回执因不匹配当前 `wbVersion` 而被忽略。
- **容量与背压**：淘汰只选干净页，脏页和回写中的页绝不丢弃。
  缓存满且无干净页时 `Alloc` 阻塞（背压），`context` 可取消；
  `TryAlloc` 提供非阻塞变体。
- **关闭**：`Close` 停止接收新写并冲刷所有脏页，等待回执；超时则
  中止并返回错误，未确认的版本永远不会被标成干净。

## 磁盘模型（`VersionedDisk`）

- `Hold` / `Unhold` / `ReleaseMatching`：屏障，排队并按需释放回执，
  测试可精确控制回执到达的时机与顺序。
- `Inject`：注入迟到 / 重复的回执。
- `FailNext` / `SetFailAll`：注入写失败。
- `Stored` / `Pending` / `Writes`：观测持久内容与在途回执。

## 测试

```sh
go test -race ./...
```

覆盖：回写中再脏化、旧回执迟到、回写失败重试、容量背压与取消、
优雅关闭后“持久页 == 最新已确认版本”、磁盘持续故障时关闭不谎报
干净。
