审计日志依法擦除部分正文后，读端仍须核对某租户在指定时段内的全部有效记录。给Go审计宿主写可导入的选择性披露校验包。日志按全局追加序号提交，各叶签入租户、事件时刻范围、正文承诺和上一版本摘要。更正记录可能引用旧叶并缩窄时刻或更换租户，擦除只能附加授权墓碑，不能移动旧序号。签名检查点另承诺按租户及时间上下界排列的索引根。服务端提供部分日志、多重证明及索引范围的左右边界；校验须同时确认返回项来源、声明区间无漏项以及更正已取到同一检查点，跨根拼接不得通过。分成确定落入、可能落入和已合法擦除，未知正文不等于无记录。用小日志完整重建独立核对更正移入与移出、同一时刻多条记录、边界索引只漏一项和已擦除叶被后来的更正引用。
