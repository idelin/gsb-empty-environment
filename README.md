可信根固件使用 TPM 2.0 非易失性（NV）单调计数器与策略会话（PolicySession）防止系统状态回滚时，若状态机允许在未满足全部 `PolicyPCR` + `PolicyNV` 复合条件前解锁写入，或未绑定会话 `nonceCaller`/`nonceTPM` 与 HMAC 授权摘要，攻击者可重放旧策略会话或回滚固件版本号。为 C++17 固件安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 TPM 2.0 NV 策略会话与单调防回滚验证库（SHA-256/HMAC 由内置确定性实现提供）。库精确建模 NV 索引表（含 `TPMA_NV_COUNTER`/`ORDERLY`/`AUTHWRITE`/`POLICYWRITE` 属性与 `authPolicy` 摘要）、PCR 寄存器组及策略会话状态机（维护滚动 `policyDigest`）：（1）每次执行 `PolicyPCR` 或 `PolicyNV` 必须按 TPM 2.0 规范将命令码与参数摘要延展进 `policyDigest`，仅当最终 `policyDigest == nvIndex.authPolicy` 且 HMAC 绑定双端 `nonce` 时才允许 `NV_Increment` 或读写；（2）严格保证 `TPMA_NV_COUNTER` 只增不减且每次授权会话单次消费防重放；（3）支持对错误授权尝试计数并在达到字典攻击锁定阈值（`DA`）时强制进入锁定冷却。附策略摘要错序、旧会话重放与计数器回滚拦截测试。
