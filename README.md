浏览器维护的相似字符表和后缀名表会分别更新，收藏夹里的旧站点与新遇到的域名仍须区分。请给 TypeScript 地址栏宿主写可导入的展示决策包。输入是已经过 IDNA 校验的标签序列、两版脚本归类及混淆转写表和签过名的品牌别名。每个转写规则可消费一至三个 Unicode 标量并输出零至三个骨架符号，最长匹配，同长度按声明顺序；需跨输入块继续匹配，终止时不能吞掉待决后缀。允许 Unicode 显示的条件是脚本策略成立，而且与受保护注册域在同一表版本下骨架相同的每个允许域都存在适用于当前后缀和品牌身份的别名证明。备选域由有限自动机给出，长度上限 64 个标量，不得枚举表内所有名字；一版无法证明时退回该标签的 ASCII 形式。输出需标到实际标签与 UTF-16 位置，不把代理对拆开。给独立检查器验证已准许范围和表摘要，用小码点集穷举检查最长匹配变化、空输出、脚本扩展集合、后缀例外和只在旧版成立的别名。
