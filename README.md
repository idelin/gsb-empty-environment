列存文件（Parquet PageIndex 风格）在同一个行组内按字节大小分别切分每列的数据页，因此列 A 与列 B 的页行号范围彼此错开；扫描器要根据跨列复合过滤条件精确算出须读取的最少行号区间与每列必须拉取的物理页编号。为存储扫描器交付可导入的 Go 裁剪包。输入行组总行数 N、各列页索引表（每页含起止行号半开区间、是否全空、是否有空值、非空最小值与最大值，及可选精确字典值集合）和投影输出列集合，以及支持 AND、OR、NOT、=、<、<=、>、>=、BETWEEN、IN、IS NULL、IS NOT NULL 的复合过滤树（SQL 三值语义：注意在页级统计上 `NOT(col = v)` 不能简单对 `col = v` 的可能命中页取补集，因为含混合值的页在正反两面都可能命中！）。组件为每个过滤节点同时维护“必然为真行区间”与“可能为真行区间”并在 NOT/AND/OR 下精确传播，最终输出规范化不重叠的升序候选行号区间列表，以及结合输出列与过滤列后每列实际需读取的物理页编号集合。验收用逐行真实数据页构造朴素扫描对照不漏行且裁剪严格紧致，覆盖两列页边界交错的 AND 交集、含混合值页在 `NOT(a = 5)` 下不可被误剪、全空值页在 `IS NULL` 必然命中而在比较谓词必剪，以及仅 `min==max==v` 的单值页在 `NOT(a = v)` 下可安全剪除。
