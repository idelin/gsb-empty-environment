同一台设备上的两个蓝牙控制器允许会话迁移。给 C++17 固件宿主写可嵌入的链路授权组件，只对抽象协商事件作判定。设备持有经认证的配对记录，包含双方身份、配对代次、密钥强度下限和允许的模式集合；会话恢复不得比保存时更弱。握手记录绑定两端角色、控制器 ID、随机数、规范化的提议与选择以及当前配对代次，消息认证由注入回调完成。协商可先走普通模式再升至安全模式，已经确认过的保护下限在同一会话中不得下降。迁移须由源控制器签出一次性交接凭据，目标验证到同一握手记录后才可承接；任一端主动解除配对后，即使旧控制器晚到的提交仍能验签也不得恢复。输入给出两个控制器看到的局部事件序列，另有若干跨控制器先后约束；至多14个事件。返回所有合法交错中每次应用数据是否都受策略保护，输出可复核的状态集摘要。用独立枚举对照断连重传、两个目标竞争同一凭据、角色互换、旧配对凭据和只在特定交错中出现的强度回退。
