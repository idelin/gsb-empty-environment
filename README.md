企业终端分批撤下旧签名算法。同一服务证书在交叉签发图里有多条链，不能用一条当前可走的链证明全部终端都能安全更新。给Go证书库提供可导入的迁移验收包。输入证书图、锚点分组、用途中间限制、每个更新阶段可用的签名算法集合、客户端特性条件，与签过名的发布先后约束。对每个可达更新状态和合法客户端配置，至少有一条可验证且用途未超出约束的证书路径；同时任何已明确禁止的密钥材料即使换证书编号也不能重新成为受信锚。自签与交叉签可以形成环，路径中不能复用同一证书；可用路径随客户端变化。输出压缩的配置覆盖证书，失败时返回按变更次数最短的发布前缀和客户端，以及证明其不存在合规路径的可核验截断集。最多16个更新及16个特性位，允许显式预算耗尽。用小配置穷举对照交叉签环、相同公钥不同编号、互斥客户端和端点恰逢旧算法退役。
