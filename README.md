归档网关通过多个对象保存一个稀疏文件，恢复时要把逻辑字节范围变成精确的对象读取，不能把对象的旧尾巴当成文件数据。请给网关交付可导入的 Go 包。布局由按逻辑起点递增的若干段组成，各段指定条带单元、循环对象 ID 列表及各对象基址；末段在逻辑 EOF 截断，前段允许在条带单元中途结束。输入写入历史包含普通写、打洞、截短和扩展。写入只更新来源索引，记录逻辑范围以及本次写入独有的对象代号前缀；数据按写入时的布局映射到带此前缀的不可变对象，不实际搬字节；截短后扩展的区域必须读零。每次布局变更给新的段表，并给一组已经迁移完成的逻辑区间；未迁移的旧内容仍须走老布局。每次迁移也有独立对象代号前缀，非空数据按新布局落入这些对象，洞保持为空；迁移复制的是变更当时的可见数据，新写始终落最新布局。返回指定版本的逻辑读计划（零段或对象、物理偏移、长度），只有逻辑相邻且为同对象连续物理字节的读才可合并。再实现反查，给某对象物理区间，找该版本所有能从这里读到数据的逻辑区间；不同段允许别名，不能只取第一个。对大范围读支持惰性迭代并可跳到第 n 个条带周期，不展开文件内所有条带。偏移与长度可到 2^60，操作与版本数各五万；历史版本不能整表复制。交付测试用小文件的逐字节来源标记对照正反查询，覆盖迁移跨段尾、同对象重复出现在循环中、截短后扩展再局部写、旧版本与新版本同时读取。
