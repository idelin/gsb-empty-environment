覆盖网络可在多层隧道间切换，收到的包过大通知只证明某次探测经过的具体链路组合。给Go发送宿主写可导入的MTU推断库。每条链路有未知但在有限整数范围内的MTU，封装经过每段会按该段的头长和对齐规则改变长度。已签探测回执绑定探测代次、发送长度、可能经过的路由集合以及成功或因包过大失败；一条回执实际只走其中一条路，同一受签路径标签的多次回执必须采用同一条路。对给定发送上下文求一定能通过的最大净荷，以及至少有一种相容网络可通过的最大净荷；两者分别给可复核的全称证据与见证，矛盾证据不能当成零MTU。重复通知不增加约束，路径代次变更后只有明确绑定同一物理链路的证据可复用。最多12段、每标签4条候选路，禁止枚举整个净荷和MTU乘积。以小上界全配置枚举核对内外层填充、失败通知的多种归因和同标签前后回执共同缩小区间。
