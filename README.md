证书校验服务能取得若干签过名的服务器时间，但一批服务可能共用同一个上游时钟。给 Go 校验宿主写可导入的时间证明库。每个回执绑定 nonce、服务器身份、信任域、发送与接收的本地单调时刻及服务器处理时间区间；宿主给出分段的单调时钟漂移上下界和网络单向延迟上下界，所有量是有理数。求查询时刻所有可能的真实时间，允许最多 f 个信任域提供任意错误证据，同一域的回执必须整体保留或整体舍弃；其余证据要同时满足跨时刻漂移和本地事件顺序。返回规范化的不相交闭区间并集，不能把中间的空档填成可信。对证书的左闭右开有效窗分别给出必定有效、必定过期或不确定；无相容证据单列冲突，不按时钟过期处理。每个边界给一个可核验的相容域集合与时间赋值，每段空档给独立可核验的排除证据。最多 12 个域、64 个时刻，可使用状态上限但不可用浮点近似宣称确定结论。用小整数域枚举和差分约束交叉验证漂移跨段、同上游多签、端点恰在过期时刻、不可相容环以及晚到回执收窄旧结论。

## timeproof 包

导入路径：`prescreen.local/ddd-6541-20261109-v2/timeproof`

全部时间量使用 `math/big.Rat`（类型别名 `timeproof.Rat`），不使用浮点；确定性结论只来自精确有理运算。

### 建模

- 每个事件（查询、各回执的发送/接收单调时刻）是一个差分约束变量，真值原点 `origin` 表示真实时间零点。
- 分段漂移时钟对相邻单调点生成两条约束 `x_b-x_a<=hi` 与 `x_a-x_b<=-lo`，精确积分各漂移段。
- 每张回执依据签名时间区间、处理时间区间与单向延迟上下界，导出发送/接收真实时刻的绝对上下界，以及往返时延（RTT）的上下界，全部写成 `x_v-x_u<=w` 形式。
- 同一信任域的回执在掩码中整体保留或整体舍弃；枚举所有“故障域数 ≤ f”的域掩码（迭代位枚举，域按名排序，位与域一一对应）。
- 对每个掩码用 Bellman-Ford 求查询变量的最紧上下界；不可行时提取负权环作为冲突证据。下界通过反向图求得，证据统一保存为前向路径与完整可行赋值。

### 输出与证据

- `Solution.Union`：规范化的两两不相交闭区间并集（`nil` 端点表示无界），相邻闭区间仅在相触/重叠时合并，空档绝不填充。
- `Solution.Gaps`：每个空档含一个严格内部探针点，以及对每个相容掩码的独立排除证据（探针在该掩码区间的下界之下或上界之上）。
- `Interval.LoWitness/HiWitness`：每个边界携带相容域集合、保留回执、完整变量赋值和可望远镜求和的紧路径，可由 `VerifyWitness` 独立复核。
- `Solution.Conflicts`：不相容掩码的负权环（权重和严格为负、首尾闭合），由 `VerifyCycle` 独立复核；冲突与时钟过期严格分离。
- `Classify` 对左闭右开窗 `[NotBefore, NotAfter)` 给出 `definitely-valid` / `definitely-expired` / `uncertain` / `conflict`，恰在 `NotAfter` 判过期、恰在 `NotBefore` 判有效。
- `Solution.Verify` 重算整次分析并交叉核对所有区间、边界证据、负环、空档与不相交性。
- `Query.StateCap` 限制枚举掩码数；触顶时 `Truncated=true` 且分类强制为 `uncertain`，不宣称任何必然结论。

### 验证

测试内含一个独立的精确有理 Floyd-Warshall 参考求解器，与 Bellman-Ford 结果逐掩码交叉验证，覆盖：漂移跨段积分、同上游多签的域原子性、端点恰在过期时刻、不可相容负环、晚到回执收窄旧结论，以及空档保留、状态上限、纯有理数、域原子性、无证据无界与 nonce 重放拒绝。运行：

```
go test ./...
go test -race ./...
```
