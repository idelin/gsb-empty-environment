x86-64 虚拟化宿主机在配置 Intel VT-d 可扩展模式（Scalable Mode）的 Root/Context Table、PASID 目录/表、4/5 级 Second-Level 页表与中断重映射表（IRTE）时，若某设备的 `PASID` 表项配置为 Pass-Through（`PGTT=0b100`）、Second-Level 2MB/1GB 大页跨界覆盖宿主机内核物理区，或 `IRTE` 缺失源设备 `SID`/`SQ`/`SVT` 校验（允许任意恶意 PCIe 设备伪造其他设备的 MSI 中断索引注入高优先级 NMI/SMI 向量），攻击者可实现 DMA 越权读写或跨设备中断伪造。为 C++17 虚拟化安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 VT-d Scalable Mode 与 IRTE 策略符号验证库（严禁逐页枚举）。输入为 Root/Context/PASID 稀疏树、Second-Level 页表、IRTE 表项数组、设备所属虚拟机表、合法物理区间及宿主机受保护区集合。验证库精确执行：（1）遍历全量已启用设备（Bus/Dev/Func）与 PASID 表项，硬检出非法 `PGTT=Pass-Through`、保留位非零或指向跨虚拟机页表根；（2）对全部有效 Second-Level 4KB/2MB/1GB 映射执行区间相交判定，拦截任何重叠宿主机敏感区或跨机内存的 DMA 读写权限并报告最小违例 `(BDF, PASID, IOVA)`；（3）逐条审计有效 `IRTE`（`Present=1`）：强制要求启用源验证（`SVT=0b01` 精确匹配合法 `SID` 且不得用过宽 `SQ` 掩码跨设备放行），硬拒绝向非授权目标 LAPIC ID 注入 `NMI`/`SMI`/`ExtINT` 投递模式。附 Pass-Through 逃逸、大页部分重叠、宽松 `SQ` 掩码与伪造 NMI 中断测试。
