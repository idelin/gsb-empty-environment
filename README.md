# 稀疏截断器：连续矩阵乘法链的保守 L∞ 误差证书

纯 Python 3.11 标准库实现（无 NumPy/SciPy）。对链式计算

```
z_1 = A_0 z_0, z_2 = A_1 z_1, ..., z_L = A_{L-1} z_{L-1},   z_0 ∈ [lo_0, hi_0]
```

逐层截断矩阵元素，并在**全局** L∞ 误差预算下决定每层阈值与保留非零数，
输出逐层保守误差传播证书。

## 证书递推（不是各层独立满足同一预算）

1. **输入区间 + 负系数传播**：用**精确矩阵**做符号精确的区间映射
   （负系数对区间端点取反），得到各阶段分量最坏幅度
   `M_l[j] = max(|lo_l[j]|, |hi_l[j]|)`。
2. **注入误差**：第 `l` 层丢弃集合 `D_l`（写 `A_l = Ã_l + Δ_l`），
   分量注入误差 `d_l[i] = Σ_{(i,j)∈D_l} |Δ_l[i,j]| · M_l[j]`。
3. **全链复合递推**（用实际近似矩阵）：

   ```
   e_0 = 0
   e_{l+1}[i] = Σ_j |Ã_l[i,j]| e_l[j] + d_l[i]
   证书 = ‖e_L‖∞
   ```

   第 `l` 层的小误差会被其后每一层的 `|Ã_k|` 连乘放大，因此后层大范数
   必然反映在最终偏差上。各层还给出 `injected_linf`（本层局部注入）与
   `final_contribution_linf`（仅该层注入传播到末端的归因值，供阅读；
   真正的判定使用同时包含全部注入的共享递推）。

## 阈值、非零预算与平局规则

- 每层候选按 `(|value|, row, col)` 升序排列；**相同绝对值按稳定坐标
  （行、列下标）选择**，结果确定可复现。
- 全局贪心：每步在所有层中选取“再丢一个元素后**最终** `‖e‖∞` 增量最小”
  的候选，并以 `(代价, 层, 行, 列)` 决胜。代价超过全局预算或任何
  每层/总非零上限时拒绝。
- 预算不可满足时**保留精确部分**（不截断）、`final_linf_bound = 0`，
  在 `unsatisfied_layers` 中报告未满足的层，`feasible=False`。
- 证书阈值定义为该层已丢弃元素的最大绝对值（无丢弃时为 0）。

## 增量更新、撤销与回滚

- `update_input(lo, hi)`：局部输入修改后立即重算证书（所有下游区间与
  误差均重新传播），操作进入误差账本可撤销。
- `edit_exact_entry(l,r,c,v)`：修改精确矩阵（元素处于丢弃状态时修改
  其隐藏精确值；`v=0` 删除为结构零）。
- `restore_entry(l,r,c)` / `restore_layer(l)`：可撤销的近似选择
  （恢复被截断元素）。
- `snapshot(name)` / `rollback(name)`：回滚恢复原矩阵与误差账本
  （截断状态、输入、账本长度一并恢复）。`undo(n)` 逐步逆操作账本事件。

## 校验（极点枚举，绝不以观察误差代替上界）

`validate.check_corners` 枚举输入盒所有 `2^n` 个极点，比较精确链与近似链
输出的最大 L∞ 偏差，仅断言“观察偏差 ≤ 证书上界”；证书始终由递推式产生，
观察值永不参与上界构造。相关坐标会使分量界过估计——这是有意的保守性
（见 `test_certificate_is_conservative_under_error_coupling`）。
另有手写稠密实现（`dense.py`）在小矩阵上交叉核验稀疏结果。

```
python3 run_demo.py                 # 可运行样例

```

## 文件

- `sparse_trunc/core.py`：稀疏矩阵、区间传播、证书递推、截断调度、账本
- `sparse_trunc/dense.py`：手写稠密 matvec/matmul 核验工具
- `sparse_trunc/validate.py`：小矩阵输入极点枚举校验
- `run_demo.py`：端到端可运行样例
- `tests/`：17 个定向单测 + 60 个随机小链性质测试
