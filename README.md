# 多来源采集表的数值格式与计量单位不一致，单列样本可能同时符合两种解释

多来源采集表的数值格式与计量单位不一致，单列样本可能同时符合两种解释。写供Go入仓宿主调用的联合类型推断包，至多12列，每列给最多4种小数符、分组规则及有理单位倍率候选，整列必须使用同一候选；输入另给按业务键关联的最多18条行级线性校验关系，缺失值不作零，只有相关值齐备才约束。解析为精确有理数，返回全部满足关系的格式组合与每单元规范值；零解返回按条数最少、ID字典序决胜的冲突关系集，并给删除其中任一关系后的可行解释。预算耗尽返回未完成，不以首个可行解宣称唯一。用小表全组合枚举核对千分位歧义、不同单位、重复业务键冲突及不可判定的缺失列。
