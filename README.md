# 证书CRL分发点URL类型与目标拒绝

证书里的 CRL 分发点由签发者写入，攻击者若能让校验方信任某张含恶意分发点的证书，就能让校验服务去访问 ldap、file 或元数据地址。给Go证书吊销检查包写供链验证回调调用的取回组件：只允许 http 一种 scheme，ldap、ldaps、file、ftp 及无 scheme 的分发点一律忽略；解析出的地址须全为全局单播，连接使用已校验地址，跟随重定向最多三次且每次重新校验；响应体最多 8MiB；每张证书最多处理前 4 个分发点，整条链总计最多 12 次取回；间接 CRL 的 cRLIssuer 与 reasons 字段存在时不取回。用 ldap 与 file 分发点、169.254.169.254、DNS 先公后私的重绑定、超大响应和超过上限的分发点验证。
