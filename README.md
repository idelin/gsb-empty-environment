联邦社交收件箱在遭遇三方及以上分叉转让与过期子编辑授权时，须保证收敛语义与撤销不可逆，给 TypeScript 服务端写可导入的所有权判定组件。对象身份绑定永久 ID 与原始签发域，支持带时间窗与字段作用域的委托子编辑授权及历史公钥版本核验；每次正式转让须旧持有人与新接收者双签名并绑定精确父转让与代次，普通 HTTP 投递签名仅作传输来源参考，禁止利用重放传输签名或旧别名在分叉未决时发布局部字段。支持 3 路及以上多支并发分叉及分叉子分支的嵌套分叉：域名排序不能裁决分叉，合并须提交覆盖当前所有活跃分叉末端的法定恢复门槛签名，且恢复后严禁复活任一分支在分叉前或分叉期间已撤销的编辑权或子授权。各时点输出允许、拒绝或挂起证据清单并按对象严格隔离冲突影响。提供无缓存全事件重放核对，用事件乱序排列验证三路分叉合并、子授权到期边界、检查点压缩后旧别名隔离与并发撤销。
