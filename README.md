# 受限查询表达式的主体级 L1 敏感度保守推导

Python 3.11，仅标准库 + unittest。**只处理合成数据**；有限域枚举核验是
工程一致性检查与紧性见证，**不构成形式化隐私证明**，统计实验不能替代证明。

## 定义

- **主体级替换邻接**：数据集 D 与 D' 相邻，当且仅当它们仅在某个主体 s
  的全部行上不同；s 的行可在**所有表中同时**被替换/增删（有界/替换邻接）。
- **贡献参数**：每张表声明 `max_rows_per_subject = m`（每主体最多 m 行）
  与值域 `[lo, hi]`。`m = None` 表示无贡献上限，**一律拒绝**（无界）。
- **敏感度**：标量输出取 `|q(D) - q(D')|`；固定键向量输出取 L1 范数
  `Σ_k |q(D)_k - q(D')_k|`。全局敏感度 = 对所有相邻对取上确界。
- **主体贡献关联**：同一主体可被多个子表达式/多张表同时引用；组合时
  其贡献**相加**（顺序组合），绝不对算子局部取 max。

## 表达式语言

| 节点 | 含义 |
|---|---|
| `Table(name, m, lo, hi, groups)` | 基础表，含贡献上限 m（`None` 即无界）、值域、固定组域 |
| `Clip(child, lo, hi)` | 逐行裁剪值域 |
| `Join(left, right)` | 按主体等值连接；连接行值 = 左值×右值，组键继承左侧（要求两侧 lo ≥ 0） |
| `Sum / Count(child)` | 标量聚合 |
| `GroupSum / GroupCount(child)` | 固定分组聚合，输出固定键向量 |
| `Add(l, r)` / `Scale(c, f)` | 组合 / 缩放 |

## 推导规则（保守上界）

| 规则 | 界 |
|---|---|
| TABLE | 行数界 m，值域 [lo, hi]；m 缺失 ⇒ 拒绝（无界） |
| CLIP | 值域与 [lo,hi] 求交，行数界不变 |
| JOIN | m = m_L·m_R，值域 = 乘积区间（两侧上限联合传播；任一侧无界 ⇒ 拒绝） |
| SUM | m·(max(hi,0) − min(lo,0))；lo ≥ 0 时即经典 **m·b** |
| COUNT | m |
| GROUP-SUM（固定组） | 2·m·max(\|lo\|,\|hi\|)：替换邻接下旧/新行可落入不同组，向量 L1 跨组相加 |
| GROUP-COUNT（固定组） | 2·m |
| ADD（声明的组合规则） | s₁ + s₂（相关主体顺序组合，相加而非 max） |
| SCALE(c) | \|c\|·s |

`analyze(query)` 返回 `(上界, 推导树)`；`Derivation.render()` 输出逐步推导。
无界贡献抛出 `UnboundedContributionError` 并附带部分推导树。

## 有限域枚举核验（`finite_check.py`）

固定少量主体、行数上限 m、有限取值网格与固定组域后：

1. 枚举全部数据集（每主体 0..m 行的多重集 × 各表 × 各主体）；
2. 枚举全部主体级相邻对（替换某主体在所有表中的行）；
3. 计算每对输出的 L1 距离，**核验上界不被突破**；
4. 输出达到最大观测值的**邻接见证**——观测值等于上界即紧性证据。

这是对完整表达式的端到端核验，不是对单个算子局部取最大。

## 运行

```sh
python3.11 demo.py          # 运行样例：推导树 + 枚举核验 + 无界拒绝
python3.11 -m unittest -v   # 测试
```
