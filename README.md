浏览器在结合 Schemeful Same-Site、Lax 宽限期、BFCache 恢复与分区 Cookie 后极易在重定向链中产生越权携带，给 TypeScript 宿主实现可导入的 Cookie 携带决策包与独立核验组件。输入包括浏览上下文树、祖先来源链（含不透明身份及 `sandbox` 是否启用 `allow-same-origin`）、请求发起时的 HTTP 方法与时刻、`303` 降级或 `307`/`308` 保留方法的重定向链、策略版本及带外传入的受签 `trustedRulesRoot`。组件强制校验带外 `trustedRulesRoot` 及公共后缀规则（含精确、通配与例外）的 Merkle 包含或缺失证明，缺少外部根直接拒绝。遵循 Schemeful Same-Site（`http` 与 `https` 视为跨站）、SameSite=Lax 安全方法与 2 分钟 `LAX-allow-unsafe` 宽限边界、以及 CHIPS 分区键绑定；严禁 `303` 重定向将已跨站的链洗回同站或重新激活 Lax 资格，BFCache 恢复页必须恢复原有冻结上下文且在途请求不受暂定导航与后续策略升版影响。以无缓存重算参考对照缺失外部根拒绝、303 洗白拦截、跨协议降级、sandbox 切换与 Lax 宽限临界点。
