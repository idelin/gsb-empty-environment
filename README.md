# riskpath

共享风险组 + 成本/时延**双预算**下的**最大成功概率简单路径**求解器。
纯 Python 3.11 标准库实现（`fractions` / `heapq` / `math`），不调用任何外部求解器；
约束数据为合成整数或有理数（`Fraction`），概率以精确有理数保存。

## 模型

- 有向图，每条边带整数/有理数 `cost`、`delay`，并属于一个**风险组**。
- **共享风险组**：同组边由同一失效事件控制。路径成功率 =
  经过的**不同**风险组生存概率的乘积，同组边只计一次，
  绝不能按边独立相乘，更不能把概率相加。
  例：两条独立 0.9 边 → 0.81；两条同组 0.9 边 → 0.9。
- **独立假设**：不同风险组的失效事件相互独立，因此跨组概率可乘。
  该假设是乘积形式成立的前提；若组间存在相关性，需要更大的联合组来建模。
- **稳定表示**：乘积用负对数似然 `nll = Σ(-log p_g)` 计算，避免长路径下溢
  （测试中验证 1000 个 1/2 组 → 精确的 `2^-1000`）。
  边界：`p = 0` → `nll = +∞`，直接剪枝；`p = 1` → `nll = 0`，为中性元。

## 搜索与支配关系

标签设置（label-setting）搜索，标签状态为
`(节点, 成本, 时延, 已访节点集, 已经过风险组集)`：

- `已访节点集` 保证**简单路径**（不重复经过节点）；
- `风险组集` 保证同组不重复计费；
- 标签 `a` 支配 `b`（同节点）当且仅当
  `cost_a ≤ cost_b`、`delay_a ≤ delay_b`、`groups_a ⊆ groups_b`、`visited_a ⊆ visited_b`
  且至少一项严格。因每组 `nll ≥ 0`，组子集蕴含成功率不更差；
  已访子集保证 `b` 的任何简单延拓对 `a` 也可行 —— 支配关系因此正确。

## 结果状态（三者严格区分）

- `OPTIMAL`：搜索耗尽且找到可行解，预算内最优已证明；
- `INFEASIBLE`：搜索耗尽但预算内无任何可行路径（无解，已证明）；
- `UNDECIDED`：达到扩展上限被截断，预算内可行/最优**未决**。
  `SearchState` 保存优先堆与全部非支配标签，再次调用 `run()` 即可恢复继续。

返回 `SearchResult`：状态、终点 Pareto 前沿（成本/时延/组集合三维非支配）、
最优标签（前沿中 `nll` 最小者）及可恢复搜索状态。

## 最优性条件

- **无环图（DAG）**：标签设置 + 上述支配关系给出精确最优
  （此时可省略 `visited` 状态，本实现保留它以统一支持一般图）。
- **一般有向图**：携带 `visited` 的标签保证简单路径语义下仍精确，
  但标签数最坏为指数级；小图可用 `riskpath.evaluate` 全路径枚举对照
  （测试在随机 DAG 与含环图上验证两者前沿与最优值一致）。

## 运行

```bash
python3.11 -m unittest discover -s tests -v   # 20 个测试
python3.11 examples/run_sample.py             # 运行样例
```

样例输出（节选）：

```
状态: optimal
Pareto 前沿 (成本, 时延, 成功率):
  cost=4  delay=4  success=18/25 (~0.7200) path=s->b->t
  cost=6  delay=8  success=9/10  (~0.9000) path=s->a->t
  cost=8  delay=9  success=7/10  (~0.7000) path=s->t
最优路径: s->a->t 成功率 = 9/10   # 两条 backbone 边共享风险组，0.9 而非 0.81
搜索前沿与枚举前沿一致: True | 最优成功率一致: True
截断后状态: undecided -> 恢复后状态: optimal
过紧预算状态: infeasible
```

## 文件

- `riskpath/model.py` — 风险组/边/图，精确有理数概率与对数表示
- `riskpath/search.py` — 标签设置搜索、支配关系、可恢复状态、三种结果状态
- `riskpath/enumerate.py` — 小图全简单路径枚举对照
- `tests/test_riskpath.py` — 20 个 unittest（0.81 乘积、禁加和、共享组、
  0/1 边界、双预算、支配关系、未决/无解区分、枚举对照、深乘积稳定性）
- `examples/run_sample.py` — 端到端运行样例
