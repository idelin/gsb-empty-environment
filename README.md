# TraceVault — 可追溯轨迹时态加密索引与假名化审计器

保护隐私的时空数据检索组件。纯 TypeScript 实现，零第三方依赖（仅 Node.js 内置 `crypto` / `test` 模块）。

## 安全设计

| 能力 | 机制 |
| --- | --- |
| 实体假名化 | 带密钥时变 PRF：`HMAC(HKDF(master, epoch), realId)`，同一时态窗口内稳定、跨窗口不可链接 |
| 空间索引 | 网格坐标加盐哈希：`HMAC(salt, cellX:cellY)`，仅支持聚合统计，不可反推坐标 |
| 静态密封 | 真实 ID + 精确坐标经 ECIES（P-256 ECDH → HKDF → AES-256-GCM）加密，公钥加密、系统自身无法解密 |
| 定向还原 | 监管方 ECDSA 签名的限时审计凭证（限定目标 + 时间段 + 用途）+ 监管私钥（授权密钥）二者齐备才能解密 |
| 审计留痕 | 追加式哈希链日志（含拒绝记录），篡改可检测 |

## 验收边界映射

- **存储海量用户位置**：`vault.ingest(realId, lat, lng, timestamp)`，存储记录只含假名、网格哈希与密文。
- **日常只读查询只能获取脱敏聚合热力分布**：`vault.heatmap(from, to)` 仅返回 `{gridHash, count}`。
- **输入监管授权密钥后精准定向还原**：`vault.reveal(credential, revealKeyPem)` 校验凭证签名/时效/范围，按时态窗口重算目标假名，解密并校验载荷身份一致性，返回精确轨迹，同时写入审计日志。

## 运行要求

Node.js ≥ 22.6（原生 TypeScript 类型擦除 + 内置 `node:test`；开发验证使用 v23.9.0）。

```bash
npm test    # 运行测试（node --test）
npm run demo  # 运行端到端样例
```

## 代码结构

- `src/crypto.ts` — HKDF/HMAC、ECIES 密封、ECDSA 签名
- `src/grid.ts` — 网格划分与加盐网格哈希
- `src/authority.ts` — 监管方：密钥对、签发/校验审计凭证
- `src/vault.ts` — 核心组件：写入、热力图、定向还原
- `src/audit-log.ts` — 哈希链审计日志
- `src/demo.ts` — 端到端样例
- `test/vault.test.ts` — 13 个 Node 内置测试

## 测试结果

```
✔ 时变假名：同一窗口内稳定，跨窗口不可链接
✔ 假名依赖密钥：不同主密钥产生不同假名
✔ 存储记录不包含明文真实 ID 或精确坐标
✔ 网格哈希加盐：相同坐标不同盐结果不同，且可稳定索引
✔ 日常查询：热力图只返回脱敏聚合计数
✔ 定向还原：有效凭证 + 监管密钥精准还原目标轨迹
✔ 还原跨时态窗口：假名随 epoch 轮换仍可被凭证串联
✔ 伪造凭证被拒绝并留下审计记录
✔ 过期凭证被拒绝
✔ 其他机构签发的凭证不被接受
✔ 错误的监管密钥无法解密载荷
✔ 审计日志：哈希链完整且篡改可检测
✔ 密钥派生：HKDF 不同 info 产生不同密钥
ℹ tests 13  pass 13  fail 0
```
