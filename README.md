# wce-bnb — 最坏情况误差约束下的最低成本档位选择

给定各部件的精度档位（成本 + 区间误差）、有理灵敏度、共享/独立误差源、
互斥档位与依赖档位，用**分支定界**选出满足最坏情况总误差上限的最低成本组合，
并产出可独立验证的**方案证书**。小实例用**穷举**交叉核验。

## 误差模型（关联求界，不是独立相加）

- 每个误差源是一个共享标量。被多个部件共用的源（如共享校准 `cal`）把各部件
  贡献**先在同一个区间内相加**，再与其他源做区间加法。
- 灵敏度为负时按区间缩放规则翻转端点（即按绝对值贡献），但同一共享源内部
  的正负抵消被精确保留——因此得到的是区间输入下的**精确值域（紧界）**，
  绝不把各部件绝对值独立相加后假称紧界。
- 总误差区间 `T = Σ_s Σ_c sens[c][s]·err_c`，最坏误差 `W = max(|T.lo|, |T.hi|)`，
  可行当且仅当 `W ≤ errorLimit`。
- 整数档位选择（离散轴）与区间误差方向（lo/hi 连续轴）严格分离，互不混淆。

## 精确算术与舍入规则

- 全部数值为 BigInt 支撑的有理数 `{num, den}`（`den>0`、已约分）。
- 解析精确十进制或分数字符串（`"0.05"`、`"7/3"`），**绝不经过 Number 中转**，
  大整数无精度损失。
- 加/减/乘/除全部精确；唯一的舍入发生在 `toDecimal()` 的**显示**环节，
  默认 6 位小数、**round-half-even**（可选 `half-up`/`up`/`down`），
  显示结果绝不回流参与计算。证书中使用精确规范形（如 `-41/1000`）。

## 分支定界与证书

- 下界：已承诺成本 + 各未分配部件域内最小档位成本（对任意符号成本均有效）。
- 误差剪枝：未分配部件取域内区间包络的乐观总区间；包络完全落在
  `[-limit, limit]` 之外才剪枝（保守，绝不误剪可行完成）。
- 互斥/依赖约束在每个节点做域传播的定点迭代。
- 节点预算 `--budget N` 耗尽时报告 `undecided`：给出可行上界（若有）与
  已证下界，**不宣称最优**。
- 证书（`wce-bnb-cert/1`）记录问题哈希、完整节点日志与所用预算；验证器
  从头重算解的成本与误差、并按相同预算确定性重放搜索逐条核对日志。
  **目标（成本）或实例改动后旧证书哈希不匹配，标记 stale 且判定无效**，
  必须重新求解。

## 用法

```sh
npm test                    # Node.js 内置测试运行器（22 个测试）
npm run solve               # 求解 examples/sample.json 并写证书
npm run verify              # 独立验证证书
npm run exhaustive          # 穷举交叉核验（48 种组合）

node src/cli.ts solve examples/sample.json --budget 3      # 预算耗尽 -> undecided
node src/cli.ts solve examples/sample.json --cert c.json
node src/cli.ts verify examples/sample.json c.json
```

需要 Node.js ≥ 23.6（原生 TypeScript 类型擦除），无第三方依赖。

## 样例结果（examples/sample.json）

- 最便宜的约束相容组合（ref/std, sensor/a, amp/cheap, adc/fast, psu/hi，成本 14）
  最坏误差 0.116 超出上限 0.05 —— 全选最便宜档不可行。
- 分支定界（56 节点）得最优成本 **27**：ref/prec, sensor/b, amp/mid, adc/fast, psu/hi
  （依赖档位 adc/fast 强制 psu/hi；互斥 amp/cheap × adc/fast 生效）。
- 总误差区间 `[-41/1000, 9/250]`，最坏 |误差| = `41/1000 = 0.041 ≤ 0.05`。
- 上界 = 下界 = 27（最优性已证）；穷举 48 种组合独立确认最优成本 27。
- 共享校准源上 ref(+1) 与 sensor(−1) 的误差部分抵消：关联求界给出紧界，
  独立绝对值相加会得到更保守的非紧界。
- `--budget 3`：状态 `undecided`，已证下界 16，不宣称最优。
