# signalrec — 整数信号恢复工具

从线性采样矩阵的部分观测中精确反推整数信号。信号各分量有整数上下界，
维数最多 12，全部运算使用精确有理数算术（`math/big`），不做浮点近似。

## 构建与运行

```sh
go build -o signalrec .
./signalrec < input.txt
```

## 输入格式（stdin，空白分隔）

```
n m                # n = 信号维数 (1..12)，m = 观测条数
lo_1 hi_1          # 第 1 个分量的下界、上界
...
lo_n hi_n
a_11 ... a_1n b_1  # 第 1 条观测：A 的一行 + 观测值 b
...
a_m1 ... a_mn b_m
```

数字可以是整数、小数或分数 `p/q`。非整数边界会自动收紧到
`ceil(lo)` / `floor(hi)`。

## 输出（stdout）

- 唯一解：
  ```
  UNIQUE
  x_1 ... x_n
  ```
- 多解（给出两个不同的可行信号）：
  ```
  MULTIPLE
  x_1 ... x_n
  y_1 ... y_n
  ```
- 无解（给出一组极小的冲突观测，1-based 行号）：
  ```
  INFEASIBLE
  CONFLICT i1 i2 ...
  ```

## 方法

1. 对增广矩阵 `[A|b]` 做精确有理数高斯消元（RREF），检出 `0 = c (c≠0)`
   型矛盾；主元变量表示为自由变量的仿射函数。
2. 仅枚举自由变量（按定义域宽度升序），枚举过程中用主元表达式的
   可达区间与自身界做剪枝；叶子处检查主元值的整性。
3. 找到 2 个解即提前停止；穷举后恰 1 解判 `UNIQUE`，0 解进入第 4 步。
4. 无解时用删除过滤（deletion filtering）求极小的冲突观测子集。

注意：实数域上矩阵秩不足**并不**意味着整数域多解——整数格点与分量界
可能把解钉死唯一。本工具始终通过精确整数搜索判定，不做秩推断。
