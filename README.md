跨站报告管道合并多文档失败遥测时，攻击者可通过子源策略继承差、压缩字典大小变化或乱序撤销重放推断隐藏页面访问。给TypeScript网络宿主构建可导入的零泄漏遥测聚合与投递核验组件，严禁联网。每条原始事件绑定不可变文档代次、逻辑矢量时钟、顶层站点、子源策略继承链、可披露字段白名单与全局采样承诺，并支持跨多策略域共享或隔离的可选压缩字典表；然而输出的事件计数、最早/最晚时间戳、状态码集合、每批体积、分桶数量、切分边界及携带的字典引用摘要均严格受限：只允许由接收方在当前有效因果前沿下的授权可见事件导出，严禁因压缩字典引用了未授权事件的词条或填充差异导致密文/编码长度随隐蔽事件变化。策略替换、导航切代、子源降级委托与端点撤销均按因果矢量时钟建立偏序；系统乱序接收事件与撤权，缺失前置因果包时整批保留为待决态而禁止部分提前发布。提供增量入队与无状态投递复核双入口：重传只能原样重放此前经不可变快照批准的载荷，一旦新到的因果撤销生效，立即阻断后续重传并禁止将同一端点URL跨策略主体混用。用无干扰配对差分验证机测试仅在未授权或已撤销文档上存在差异的两条历史：验证全输出批序列及编码字节长度分布完全一致，覆盖因果乱序、子源继承撤销、字典跨租户隔离与配额满隐藏竞争。
