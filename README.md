钱包中继支持多链回滚，用户签过的同一授权不能在两支竞争历史里同时变成最终支出。给 TypeScript 中继宿主写可导入的授权账本。签名恢复由调用方注入，授权绑定链、合约、签发者、受益人、总额度、有效区块区间及授权 ID，允许多次部分消费。事件带区块哈希、父哈希、区块内序号和可选撤销，链头可切换到已知分支。最终性证书固定某一块及其祖先；以后与最终块不相容的头必须拒绝，不得改写已最终的扣款。未最终分支切换须精确撤销离开分支的消费、失效和撤销，并重放新分支。授权的剩余额度和已使用的同名业务请求必须按签名授权身份与链历史隔离；同一签名在未最终分支出现不得阻塞另一合法分支。宿主可提交只含变更路径证明的压缩快照，节点承诺绑定总额度、已消费值与请求集合根；缺失兄弟或同高度异根不得静默接受。提供可暂停持久接口、历史块查询和独立的全链事件回放参考；逐个持久化点断电后，历史查询、当前头和最终性标记必须属于同一个提交。用分叉、共同祖先消费、撤销后回滚、边界区块和超过 JS 安全整数的额度对照。
