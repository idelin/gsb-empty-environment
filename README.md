# CDS接纳一致性与删除信号

子区被攻陷的一台权威服务器可能注入 CDS 想让父区替换 DS。为 Go 注册局写可导入的 CDS/CDNSKEY 接纳判定，时间只由调用方传入的单调时钟推进：只接受当前 DS 所指 KSK 签名的记录；同一轮询全部权威服务器返回的 CDS 集须逐字节一致，任一台偏离即重置连续观察；连续观察须覆盖配置时长，窗口内出现回退到更小 serial 的响应即重置；CDS 与 CDNSKEY 并存须互相对应；删除记录为 0 0 0 00 且不得与其他记录混放；新 DS 须对应已发布的 DNSKEY。回调顺序即时间顺序，不得自行重排或合并同一时刻的多次响应。用单台偏离、签名钥不符、混放删除、观察中断与 serial 回退对照。
