归档阵列要从一条纠删码条带中取回投影 P·x，而不是重建整个条带。为冷存储读通路写可导入的 Go 包。源 x 是至多 96 位的未知二进制列向量；目录列出至多十二个物理扇区，每个可读一次，返回一至三行给定掩码与 x 的模二点积。健康扇区按实返回；整次会话至多一个物理扇区静默损坏，可返回任意同宽比特，包括碰巧正确。不知道哪个坏，不能对多次响应改选不相容的源。扇区分布在至多四盘，读一个的正费用取决于上次实际读取的盘与本次盘（首次另给）。运行时只能根据已收到的原始位选择下一扇区；只有所有相容的源产生同一个 P·x 才能停。合成保证正确的最小最坏费用策略，再在最优费用约束下最小化展开后所有可达叶的数量；同一读序下不可实现的响应不算叶。给出按步驱动的解码器；预算 B 不够时还要给可核验的对手证书：在每个未决节点为每个尚可支付的读选择一个相容响应，叶给两组真实源及各自坏扇区和值，逐条重放到相同观测却投影不同；读全仍不能确定和仅预算不足分开。可共享相同证明节点，但必须验证剩余可读盘位、磁头位置和预算。不得枚举 2^96 个原始向量，也不能先对每一盘选一套未来最优计划再拼作共同策略。独立小域穷举比较两个目标，测试两种坏盘解释各自秩已足却投影不同、最坏代价相同但叶数不同、以及先多付一次换盘能省掉后续整轮校验。
