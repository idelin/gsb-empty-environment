冷归档把块号做异或重排后复用底层对象；有些投影视图还会把多个逻辑块映到同一物理块。网关只拿到批读描述，不能先把所有块读出再过滤。给 Go 归档宿主写可导入的放行组件。块号是48位向量，每个请求片、授予片和撤销片都以 GF(2) 线性方程组表示，视图边给出仿射映射和绑定的父对象版本。能力用真实 Ed25519 签名绑定租户、对象版本、动作和物理块集合。请求中的每个逻辑块经整条指定视图链映射后都必须被同一主体的有效授予并集覆盖，且不能落入任何有效撤销片；缺少受信根、环或版本不符拒绝。非满秩映射和不相交逻辑片的物理别名都要按实际不同块计数。返回不展开块号的读取票：它只描述请求确需的物理集合，并给出每个对象的确切不同块数以及覆盖成立的代数证书。独立使用端从签名能力、视图清单和证书校验语义相等，不能仅比块数。每对象至多12个请求或授权子空间，既可能完全包含、重叠，也可能为空集。给出6位空间逐块参考并对照多层降秩、不同集合基数相等、同集合不同方程表示和单点撤销，同时用48位大空间证明确实未逐块枚举。
