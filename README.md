代理用分层虚拟完成时间选择下一条请求。叶队列与父调度器分别有整数权重；子树空转时虚拟时间停住，重新活跃时从父虚拟时间与本地上次完成时间的较大者起算，平局按租户编号。为诊断服务提供可导入的 Go 包，输入候选权重区间、压缩到达记录、每次真实发出的叶标识与部分完成时间，仅包长已知而不预知哪个候选权重被部署。求所有能产生该段观测的整数权重向量，支持计数及字典序第 k 个解；无解要给导致排除全部候选的最短观测前缀。虚时运算必须保持有理数精确，不能用近似排序；权重每层总和给定、自由租户至多五个，上界到 2^32，不把所有候选值逐一代入。附小区间全枚举及实际正向重放，覆盖空树重新激活和只有在并列时才能解释的轨迹。
