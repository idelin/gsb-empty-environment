# 远程构建缓存键遗漏安全输入

构建服务复用远程缓存时，若键没有覆盖工具链或安全策略，攻击者可把旧产物冒充当前构建。给Go构建宿主实现可导入的缓存身份包：动作输入包括源码树根、命令参数数组、规范工作目录、逐项环境变量、工具链制品摘要、依赖动作输出摘要、平台属性和当前安全策略摘要；字段按固定标签和大端长度编码，映射键按原始UTF-8字节排序，重复键拒绝，秘密环境值的名称仍进入编码，秘密环境值不进明文而以宿主HMAC得到的版本标识参与。动作键为SHA256规范编码。缓存条目还绑定输出树根、生成者身份、动作键、签发时间和Ed25519签名；命中时重算全部输入、验签、检查生成者授权及输出树内容摘要，任何缺字段或不匹配视为未命中而非降级到弱键。提供一个待审的key回调，针对每个输入字段给两个有限候选值，搜索回调键相同但规范动作键不同且输出安全含义不同的最短碰撞，返回漏掉字段。测试参数边界、环境排序、工具链升级、策略收紧、秘密轮换和依赖输出变化；相同语义的映射重排应保持命中。
