# mailbox/mq

Go 持久化邮箱队列库：取出不删、确认才删、拒收重回队尾、超时重投后旧收据作废、批量发送全有全无。

## 语义

- `Send(bodies...)` — 事务性入队：整批先落 WAL 再入内存，持久化失败则一条也不可见。
- `Take()` — 领取队首消息但不删除；消息在可见性超时前对其他消费者不可见，返回绑定「代际 + 令牌」的 `Receipt`。
- `Confirm(receipt)` — 凭收据删除。重复确认、超时重投后的旧收据一律返回 `ErrStaleReceipt`，消息不受影响。
- `Reject(receipt)` — 拒收，消息重新排到队尾。
- 超时重投 — 领取超时未确认的消息自动回到可见队列（按截止时限先旧后新），重投时发放新一代收据，旧收据随之失效。

## 持久化

`Persister` 接口（`Apply` 原子批量 / `Replay` 回放）。自带：

- `MemPersister` — 内存实现，测试用。
- `FilePersister` — JSONL 预写日志，每条 CRC 校验、每批一次 fsync；回放时截断崩溃留下的损坏尾部，保证一批要么全见要么全不见。

所有状态变更（入队 / 领取 / 确认 / 重回）都先持久化成功才改内存，因此持久化故障不会造成消息丢失或半提交。

## 测试

```sh
go test ./... -race
```

覆盖：FIFO 可见顺序、拒收归尾、重复确认、超时重投使旧收据失效、重投顺序、
持久化故障下的事务性发送 / 领取 / 确认 / 拒收、重启恢复、文件 WAL 损坏尾部截断、并发领取确认。
