# JAR签名覆盖检查

Java 应用加载插件 JAR 时验证签名，攻击者往已签名 JAR 里追加未列入清单的类，或更换签名者，让验证通过后加载恶意代码。为Go插件宿主实现供加载前调用的 JAR 签名覆盖检查包：META-INF/MANIFEST.MF 为各条目列摘要，.SF 文件对清单段摘要签名（签名验证由调用方注入）；除 META-INF 下的签名文件外，每个条目都须有清单摘要且与内容一致，缺失、多余或不一致的条目拒绝；同一包名下的类必须由同一组签名者签署；有多个签名文件时，条目须被每个所需签名者的 .SF 覆盖才算其签署。用追加未签名类、摘要错位、包内签名者混用和合法 JAR 验证。
