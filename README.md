# occupancy-peak

从**可能乱序**的 start/end 记录中重建设备占用区间，并查询**峰值并发**与
**所有达到峰值的时间段**。纯标准库实现，不接外部数据库。

## 运行

```bash
python3 examples/demo.py        # 连贯样例：配对 -> 索引更新 -> 峰值查询
python3 -m pytest tests/ -q     # 自动测试（也可 python3 -m unittest discover -s tests）
```

## 数据模型与写入语义

每组占用有独立 ID，两个端点可以任意顺序到达（end 可先于 start）。
两个端点齐全且 `end > start` 时形成**半开区间 `[start, end)`** 并进入索引。

| 操作 | 结果 `Status` | 说明 |
| --- | --- | --- |
| 新孤立端点 | `RECORDED` | 只有一端的记录单列于 `orphans()`，不进索引 |
| 配对完成 | `PAIRED` | 形成半开区间并入库 |
| 端点更正 | `CORRECTED` | 替换旧端点，索引同步撤销旧贡献、计入新贡献 |
| 重复端点 | `DUPLICATE` | 幂等忽略，状态不变 |
| 无效端点 | `REJECTED_INVALID` | 会导致 `end <= start`，**拒绝且原状态不变** |
| 撤回 | `RETRACTED` | 整组记录删除，区间贡献从索引撤销 |
| 撤回未知 ID | `NOT_FOUND` | 无此记录 |

关键不变式：**任何会使 `end <= start` 的端点都被拒绝**，因此：

- 孤立 end 不会被补零成 `[0, end)`，孤立 start 不会被补成 `[3, 0)`——
  不产生零长 / 负长度的虚假占用；
- 无效的 end（早于 start）不会破坏此前已生效的区间；
- 区间平移需要两步更正（先移远端的端点），每步都保持 `end > start`。

## 峰值查询与证据

`tracker.peak(qs, qe)` 返回 `PeakResult(peak, segments)`：

- `peak`：窗口 `[qs, qe)` 内的最大并发数；
- `segments`：所有达到峰值的**最大连续时段**（裁剪到窗口内），每段携带
  `ids`——该时段内有贡献的占用 ID，查询证据可回溯到具体占用。

半开语义下 `[0,5)` 与 `[5,9)` 交界处不重叠（峰值 1，时段贯通为 `[0,9)`）；
加入 `[4,6)` 峰值升为 2，撤回后恢复。

## 工程实现：如何避免每次更新重扫全部区间

核心是 `SweepIndex`（`occupancy_peak/index.py`）——扫描线差分 + 树状数组：

- **差分思想**：每个区间只在两个端点产生计数变化（`s` 处 +1，`e` 处 -1）。
  新增 / 撤回 / 更正一个区间只触碰这两个端点，**绝不遍历已有区间**。
- **树状数组（Fenwick）**：按坐标升序维护差分前缀和，任意时刻的在占用数
  O(log n) 可得；坐标只增不删保证位次稳定，已知时间戳的更新是 O(log n)
  点更新（仅当出现全新时间戳时插入坐标并重建，O(n)，均摊少见；生产可换
  带子树和的平衡树获得稳定 O(log n)）。
- **窗口查询**：初始水位一次前缀和 O(log n)，之后只扫描落在窗口内部的
  变化点，合计 O(log n + k)，k 为窗口内端点数——与全量区间数无关。
- **证据回溯**：峰值时段的贡献 ID 按需扫描区间字典获得（O(n)，仅查询
  证据时发生；峰值数值本身不依赖它）。

| 操作 | 复杂度 |
| --- | --- |
| 记录 / 更正 / 撤回一个端点 | O(log n)（新时间戳首次出现时 O(n) 重建） |
| 峰值数值查询 | O(log n + k) |
| 证据（贡献 ID） | O(n)，按需 |

## 正确性核验

- `occupancy_peak/brute.py`：**逐端点扫描**的参考实现——把窗口按所有端点
  切成基本段、逐段数覆盖，作为小数据基准。
- `tests/test_fuzz.py`：随机操作序列（乱序、更正、撤回、重复、无效端点）
  先与**独立重放模型**比对区间集合，再与逐端点扫描基准比对峰值、时段与
  贡献 ID（200 轮 × 20 个随机窗口，固定种子可复现）。
- `tests/test_tracker.py`：明确场景测试——乱序配对、重复结束、半开交界、
  重叠升峰 / 撤回恢复、更正移出查询范围且旧贡献全部撤销、无效 end 不破坏
  状态、孤立记录不产生虚假占用等。

## 项目结构

```
occupancy_peak/
  tracker.py   # 状态机：配对 / 更正 / 撤回 / 峰值查询
  index.py     # SweepIndex：端点差分 + 树状数组（增量更新，不重扫）
  brute.py     # 逐端点扫描参考实现（核验基准）
examples/demo.py   # 可直接运行的连贯样例
tests/             # 场景测试 + 随机对拍
```
