# SMTP终结符走私

收发两台邮件服务对 DATA 结束序列的理解不同，攻击者可在正文里嵌入 <LF>.<CR><LF> 或 <CR>.<CR><LF>，让其中一台提前截断，把后半段当作新邮件提交以伪造发件人。为Go入站 SMTP 会话写供 DATA 读取循环调用的终结符扫描包：只有 CRLF.CRLF 结束数据；正文里出现裸 LF 或裸 CR（前后不与另一个字符构成 CRLF）时整封邮件拒绝，不得规范化后继续；行首的 .. 还原为 .；扫描按块接收字节，块边界可以落在 CR 与 LF 之间，结果必须与整块输入一致；累计超过调用方给的上限时拒绝。用 <LF>.<CR><LF>、<CR>.<CR><LF>、跨块切开的结束序列和合法点填充验证，并枚举全部切块位置。
