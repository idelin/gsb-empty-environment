分布式密钥库掉了一份合成测试分片，修复脚本可以得到正确结果，却可能让某个协作域多看到一项原本无权获知的量。为 TypeScript 密钥库宿主写可导入的修复准入组件。输入是有限素域上的原分片生成矩阵、独立随机掩码及经签名的修复步骤；每条步骤声明发送域、接收域、局部可用的输入编号、线性运算和所属代次。每域只能发送其当时确实持有的值，不能借另一域尚未送达的量作证明。既要证明目标域最后确实得到原缺失分片，又要证明给定的每个可能串通域集合看到的全部修复消息和已有分片联合起来，没有比修复前多决定任何受保护线性量。掩码可能在一批修复间复用，同编号跨代也可能代表不同随机量，不能逐条或逐目标检查后相加。记录体用注入的验签回调，缺签名、跨代无授权及无法证明的新观测一律拒绝。返回仅含矩阵承诺、秩证书和公开步骤编号的验收结果，不输出秘密值。小素域枚举所有合成秘密与掩码赋值作独立对照，涵盖合法修复、两个目标单独安全但联合不安全、共址副本和相同标签的不同代次。
