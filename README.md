热迁移器只看见设备回报的粗粒度脏位；重放时，两个来宾地址还可能写过同一物理页。写一个供迁移引擎导入的 Go 包。给定至多八个有序 epoch，每个 epoch 冻结两级地址表，项含来宾或中间页起点、长度、下一层起点、正向或反向连续映射；同表输入区间不交，输出可别名，未映射不能写。物理页身份是一对（分配代，设备页号），同号不同代不等价。每个 epoch 给若干次已完成的单页 DMA 写，各有允许的来宾页闭区间；具体命中哪一页未知。脏位样本是指定 epoch 的一段来宾页或一段带代物理页，其中至少被一次本 epoch 的对应写命中（置位），或没有写命中（清位）；未采样没有约束。各写可选同页，重用页号不继承旧代的脏位。求满足全部样本的解释中被写过的不同物理页身份最少是多少，并返回唯一的规范解释：在最小数下，按全局 DMA 次序取来宾页号向量字典序最小。再提供确定性查询，给某个带代物理页，回答它是在所有允许解释、仅部分、还是绝不可能被写，并为可能的两种答案给具体可重放的写向量；该查询不能只看最小解释，更不能把最小集冒充安全拷贝清单。输入矛盾须区别于零写。总共至多十八次 DMA、二十四条样本、每级每代至多三十二项；页号是 52 位，允许整地址空间，禁止展开到每页、遍历候选页号或用采样裁决。交付独立的逐写回放器，短地址域穷举对照目标值、规范解、三态查询。测试反向表跨多项复合、不同来宾别名使一页同时解释多个样本、同号换代、最小解之外才会脏的页，以及唯一合法点在最大页号。
