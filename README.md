# 委托调用覆盖代理的管理员槽

代理合约在自身存储上下文中执行不可信实现逻辑，若实现的普通变量占到管理员或实现地址槽，调用者可接管升级权限。给TypeScript安全测试宿主实现可导入的EVM子集解释与布局检查包：存储为256位槽到256位值映射，调用帧含codeAddress、storageAddress、caller、value和静态标志；指令仅含SLOAD、SSTORE、CALLER、PUSH、EQ、JUMPI（目标必须是已登记指令边界）、DELEGATECALL、RETURN与REVERT，最多256步。DELEGATECALL切换codeAddress但保留storageAddress、caller和value，子调用成功提交写集，REVERT回滚该子调用及其后代。代理保留槽集合由宿主给出，含admin、implementation和rollback；实现布局输入变量ID、槽、位偏移、位宽及可写入口。先检查变量位区间不与保留槽相交，再具体执行调用者可控入口；任何路径写保留槽且写值受caller或题内给定的calldata字节数组影响即输出最短控制流见证。实现升级入口必须先核对当前storage中的admin，升级后新implementation代码摘要与审核摘要一致才发布。用恶意布局、汇编常量槽写、嵌套delegatecall、子调用回滚及合法命名空间槽测试，不能只按变量名判断安全。
