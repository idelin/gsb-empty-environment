Linux Cgroup v2 的 CPU 控制器同时叠加了多级树的 `cpu.weight`（1..10000 比例分配）与 `cpu.max` + `cpu.max.burst`（周期配额加结转突发桶）：当子组需求小于配额时会向突发桶积攒额度，后续高负载周期可借用突发桶突破单期配额，但整棵子树的总消耗仍受任意祖先节点的剩余配额与祖先突发桶上限约束，且因限流或空闲剩出的算力必须按权重工作守恒地重分配给未受限的兄弟与堂兄弟组。为容器运行时资源模拟器交付可导入的 Go 分层 CPU 周期分配器。输入为任意深度 cgroup 树（每节点含 `weight`、可选 `quota`/`period` 及 `burst` 上限，子节点 `period` 可与父节点不同）与按离散时间步推进的叶节点算力需求序列及主机总核数容量。规则：每个周期边界为有配额节点补充 `quota` 并将上期结余并入突发桶（结余桶封顶 `burst`，本期可用上限为 `quota + burst_balance`，跨周期不透支）；单步内按主机总容量自顶向下执行分层加权最大最小公平（Hierarchical Weighted Max-Min Fair）分配，同时受每条从根到叶路径上所有祖先剩余额度与叶节点需求的共同封顶，将受限于自身需求或限流节点的盈余精确迭代重分配给同级未饱和节点直至收敛，并按实得算力同步扣减沿途各祖先额度与突发桶（先扣本期基础配额再扣突发结余！）。验收覆盖四层不对称树、子组突发被父组 `cpu.max` 截断、突发桶先用基础配额再耗结余的精确跨期演进、多兄弟先后撞墙后的工作守恒重分配及总分配量守恒校验。
