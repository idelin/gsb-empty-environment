代理换源后，旧连接上迟到的分段响应还会进缓存；只清现存页仍可能拼出半新半旧的下载。为代理控制面交付可导入的 Go 包。对象长度 L≤2^52，内容用带偏移的不可变块名表示，同名同块内偏移才是同一字节。输入给出新旧对象完整的连续区间映射、每处分片缓存的初始区间及有偏序的至多十二个一次事件：旧连接的范围回填、新源回填、客户改变代理读链、客户端确认换源。回填写覆盖区间，不改变其他位置；每个客户沿当前优先链按字节取首个命中的缓存，全未命中回对应源。确认之前只能返回完整旧对象或完整新对象，确认以后只能返回完整新对象；这意味着同一次下载的所有字节必须能由同一世代解释，并不禁止来自多个缓存。环境按任一拓扑序送事件，初态及每步后都可下载任意半开区间，直到全部事件结束。可在给定事件前或后购买原子钩子：清某缓存的区间，或给该区间装永久世代栅栏，令以后旧回填仅在未设栅栏的部分生效；装栅栏本身不清旧字节。同一事件绑定的钩子按给定编号执行，钩子和事件整体不可被读取打断。求使所有客户全部下载都合法的最低费用钩子集合，同费用取件数最少再取编号向量最小；不能假定多清一页一定更安全。另给独立计划验证器：失败返回最少外部事件数的一条合法前缀、客户和最短能复现的非空下载区间（同长取左端小）；无解与输入有环分开。最多六缓存、四客户、十钩子，允许按不同可达状态增长，不得枚举所有完整交织或展开 L 个字节。小域逐字穷举比对反例长度与费用；验证两段各自都合法但合起来没有一致世代、清首选页露出旧后备、旧回填跨栅栏两端部分可写，以及两个版本切块边界不同却字节完全等价。
