# 执行映像测量时间窗

可信启动器测量完文件后，另一线程可能修改同一对象再执行。实现供Go启动宿主调用的测量执行组件，输入只读对象句柄、稳定版本证明和执行回调；测量期间任何版本变化均重试，执行须消费同一版本的不可变视图，不能重新按路径打开。以可阻塞对象接口模拟原地修改、重命名和版本号复用，核对回调实际消费的摘要。

## 组件

- `measure.go`：`MeasureAndExecute` 测量执行器与 `Object`/`View`/`VersionProof` 接口。
  - 每轮先取版本证明，再经句柄打开不可变视图并测量，测量后复核证明；窗口内任何变化都丢弃视图重试，持续变化耗尽重试返回 `ErrExhausted`。
  - `VersionProof` 同时比较 `ObjectID`、单调 `Seq` 与每次更替唯一的 `Nonce`，可识别版本号复用；重命名不改变证明。
  - 执行回调只能消费测量通过的同一视图，并回传实际消费摘要与字节数，与测量摘要不符返回 `ErrDigestMismatch`。
  - 全程只使用句柄，接口层没有按路径打开的入口。
- `mock_object.go`：可阻塞模拟对象。`Barrier` 可把竞态钉在视图读取中途；支持原地修改、重命名、复用版本号替换，以及按路径打开计数。
- `measure_test.go`：覆盖稳定执行、读窗口内原地修改重试、重命名不失效、版本号复用识别、回调摘要核对、重试耗尽、上下文取消、并发下零路径重开。

## 运行

```sh
go test -race -count=1 ./...
```
