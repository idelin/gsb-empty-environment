# 多币种联合授信双时态敞口监控器

集团授信额度与子公司敞口的**双时态**（业务时间 / 记录时间）监控器，Go 标准库实现，无第三方依赖。

## 设计

- **双时态事实库**：每条事实（借款、汇率、授信协议、担保物估值）都带有
  `[validFrom, validTo)` 业务时间区间与 `[txFrom, txTo)` 记录时间区间。
  追溯修正不改写历史：关闭旧记录的 `txTo` 并追加新记录，
  因此可以重现"任意记录时间点上我们所知道的任意业务时间"。
- **重放 `Replay(validTime, txTime)`**：在该双时态坐标下折算集团总敞口——
  折算受**授信协议有效期**（过期协议下的借款不计入）与**该时点汇率**双重影响；
  同时对担保物按当时估值**重算质押率**并留下追溯记录（`Report.Trace`）。
- **告警**：集团总敞口触碰预警线 / 击穿授信额度、子公司敞口超过协议额度、
  质押率超阈值、汇率缺失。

## 验收场景

集团总授信 1000万（预警线 95% = 950万，质押率阈值 110%）；
子公司 A 协议有效期 `[0,50)`、额度 1000万；A 借款 600万 USD；
汇率 1.4 →（业务时间 15 起）1.5；担保物 1200万 →（业务时间 20 起）800万；
**记录时间 30 追溯上调 A 的历史借款为 700万**。

| 重放（业务时间, 记录时间） | 总敞口 | 结果 |
|---|---|---|
| (30, 29) 修正前 | 600×1.5 = 900万 | 未触预警线 |
| (30, 30) 修正后 | 700×1.5 = 1050万 | **触碰预警线 950万、击穿授信 1000万，输出告警** |
| (30, 29) 修正后再查 | 仍为 900万 | 修正不改写历史 |
| (60, 30) 协议过期 | 0 | 过期协议下敞口不计入 |
| (30, 15)→(30, 25) 担保物下跌 | 900万 | 质押率 75% → 112.5%，重算并告警 |


```
  质押率重算: 子公司A 敞口1050万 / 担保物估值800万 = 质押率131.25% (阈值110%)
```
