生产环境 GraphQL 网关启用自动持久化查询（APQ）与 JSON 数组批处理（Batching）时，若仅对单个 HTTP 请求限流而忽略数组内百条并发查询、允许客户端在 APQ 注册阶段覆盖已有 `sha256Hash` 对应的查询体，或未校验变量类型与只读持久化白名单，攻击者可通过批量 OTP 爆破或 APQ 缓存投毒绕过查询白名单。为 TypeScript 网关宿主实现可导入的零外部依赖 APQ 完整性与批处理安全门禁库，严禁联网。组件严格校验：（1）APQ 请求的 `extensions.persistedQuery.sha256Hash` 必须精确等于查询原文 SHA-256（禁止空查询或哈希不匹配），且仅允许从预签名只读清单加载白名单查询（拒绝未授权客户端动态注册新查询体或覆盖已有哈希）；（2）对批处理数组请求强制展开每条子查询并按统一令牌桶与总复杂度预算计费（禁止按 HTTP 请求数计 1 次），同时限制单批最大条目数与禁止重复高敏感变更（Mutation）堆叠；（3）强制变量与查询绑定，拒绝未声明的多余变量注入。附 APQ 投毒、批处理限流绕过与多突变堆叠测试。
