高性能动态语言 JIT（如 V8 TurboFan / HotSpot C2）在投机优化期间把多层函数调用内联进单个物理机器帧，并对未逃逸临时对象做标量替换（把对象字段拆散存在寄存器或栈槽，堆上根本没分配！）；一旦运行时守卫失败（如整数加法溢出变浮点、对象隐藏类突变）触发去优化（Deoptimization），运行时必须依据 `DeoptMetadata / FrameState` 在微秒内无损切回字节码解释器：1）从单个物理机器帧的寄存器/栈槽快照中，按**由外向内**顺序精确重建多层被内联函数的独立解释器调用帧（每层独立的字节码 `pc`、局部变量数组与操作数栈！）；2）对所有处于“延迟物化（Virtual Object）”状态的对象执行真实堆分配并回填字段——最致命的陷阱在于**虚拟对象间可以存在共享引用甚至互相循环引用（`A.next = B; B.next = A`）**，且多个内联帧的局部槽可能同时指向同一个虚拟对象 ID！物化器必须采用两阶段协议（先为全部涉及的虚拟对象分配空堆实例并登记 `virtualID -> heapRef` 映射表，再第二趟遍历回填每个字段的标量值或已映射 `heapRef`！），既不陷入死循环又 100% 保持对象引用同一性（`===`）；3）重建后的调用栈交由字节码解释器从去优化 `pc` 精准续跑（支持处理异常抛出沿重建帧正确逐层展开！）。为动态运行时交付可导入的 Go 字节码解释器、内联 Deopt 帧重建与两阶段虚拟对象物化包。验收覆盖 3 层以上嵌套内联帧去优化、带循环引用的虚拟对象图物化防死循环、跨帧共享同一虚拟对象引用身份等价、去优化后立即抛异常逐层捕获以及与纯解释器从头执行结果的终态及堆图同构校验。
