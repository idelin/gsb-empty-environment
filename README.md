# 分段仿射时间映射多轨读取器

Python 3.11，仅标准库 + unittest。样本数组与采样率由本地夹具
（`fixtures.py`，确定性生成）提供，不接触任何音频设备。

## 模型

- 源时间映射是**多段关系**：控制点 `(out_t, src_t)` 之间仿射插值，
  斜率 >0 前进、<0 反向、=0 冻结（`timemap.py`）。
- 映射定义在**输出时间**上，因此冻结、反向、片段重复都保留来源身份；
  复合编辑是段的序列，**不可简单相乘为一个速度**。
- 段边界为半开区间：边界输出样本属于下一段，反向段端点（转折点）
  只发出一次，不重播两次。
- 所有轨共用同一映射（同一 `positions`/`kinds`），同步由构造保证。

## 编辑计划与修订

- `EditPlan` 不可变（`plan.py`）；`revise()` 返回新计划，
  持有旧计划的读者不受影响。
- `affected_output_range(old, new)` 给出两计划有差异的最小输出区间，
  只需重算该区间内的输出。

## 渲染与声明

- `render_direct`：逐样本解释器（基准真值）。
- `render_chunked`：固定计划分块渲染，块内按段递增推进（流式引擎的消费方式）。
- **插值策略**：线性插值，`floor(pos)` 与 `floor(pos)+1` 两点；
  距整数 1e-6 内的位置吸附到样本网格。
- **延迟**：算法延迟 0 输出样本；插值前瞻 ≤ 1 源样本。
- **数值容差**：`TOLERANCE = 1e-9`（分块累加与直接求值可有 ulp 级差异）。
- **滤波尾部**：位置越出 `[0, n-1]` 时值钳制、掩码置无效
  （插值核尾部超出可用源）；缺测（`None`）抽头同样置无效并标明。

## 运行

```sh
python3.11 demo.py          # 运行样例
python3.11 -m unittest -v   # 全部测试
```

测试覆盖：速度 2 输出时长减半、反向端点单次重放、冻结段重复同一位置并标明、
随机计划 × 随机块长的分块/直接对照（位置、值、掩码）、转折点、
滤波尾部、多轨缺测掩码、控制点修订的受影响区间与旧计划读者。
