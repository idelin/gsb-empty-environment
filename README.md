# 批量验签中的等式抵消

签名服务为提速把多份Schnorr签名直接相加验证，攻击者可构造两份错误项互相抵消。请交付供Go服务调用的P-256批量验证包：单签名为规范点R和标量s，公钥P为规范非无穷远点，挑战e=SHA256(固定标签||公钥||R||消息长度||消息) mod q，单验sG=R+eP。批量1至256项，先拒绝重复的完整(公钥,R,s,消息)条目；系数a_i由SHA256对批次域标签、宿主随机32字节种子、整批规范转录、索引和大端计数器取模q生成，遇0递增计数器，验证Σa_i s_i G=Σa_iR_i+Σa_i e_iP_i。随机种子必须来自宿主且每批新取，缺失即退回逐份验证，不能使用固定或请求方种子。批量等式失败后按原系数使用同一整批转录和种子派生的原索引系数递归二分定位，子集等式通过仅说明该子集在本批随机挑战下通过；最终叶子必须单验，返回精确无效索引，若父失败而两子均通过则整批退回全部单验。用真实签名构造两项代数抵消、篡改消息、重复项和不同种子，和逐份参考比较无效集合；批量成功是概率性接受，结果记录种子摘要和转录摘要。
