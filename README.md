两套云目录用不同的主体语言，迁移时需要把原策略翻译成目标方可以执行的一组策略。给Go联合身份宿主写可导入的策略投影库。每个主体有经过签名核验的发行域、租户、路径与有限标签集合；旧方按最后命中的前缀规则决定允许或拒绝，目标方只支持对路径前缀和少量公开标签的正向允许。名称映射是输入给出的有限状态转导器，同一新标识可能对应多个旧主体，路径长度无上限。生成在任何相容旧身份下都不扩大权限的目标策略，并证明在输入给定的候选前缀与标签组合中已覆盖所有可安全表示的身份；能合并条件时选规则数最少的等价集合。对每种不得迁移的候选规则返回一个旧方拒绝的真实主体及映射轨迹，找不到旧前像的目标身份也必须拒绝。用小字母表完整模型核对空路径、多对一映射、例外覆盖和两个同名租户来自不同发行域。
