# 信号恢复帧伪造系统调用入口

嵌入式运行时允许用户态提交信号恢复帧，攻击者可能借此把程序计数器切到未授权入口并抬高权限位。用Go写供信号分派宿主调用的恢复组件，采用自定义帧模型：帧含线程ID、64位单调帧序号（耗尽拒绝再入，不回绕）、16个64位寄存器、PC、SP、flags和父帧摘要；进入信号时宿主保存不可修改的影子记录，返回仅允许该线程当前最内层帧。未获允许的普通寄存器须逐位等于影子记录；允许修改的普通寄存器索引由宿主给定，PC必须落在已登记可执行区间且是4字节对齐入口，SP必须落在该帧登记栈区并16字节对齐，flags与影子记录的异或结果必须包含于给定用户位掩码。所有范围为半开区间，地址加法溢出拒绝。验证全部通过后一次性恢复并消费帧，失败不消费；跨线程、重放、越过内层帧或父摘要不符均拒绝。用嵌套信号、旧序号重放、保留权限位抬高及验证中途失败测试影子链与寄存器状态不被部分修改。
