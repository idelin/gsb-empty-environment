同一物理区间通过不同设备的地址窗口可见，旧设备还可能持有只读或可写的在途租约。给 Go 虚拟化宿主写可导入的交接凭据组件，不访问硬件。窗口以对齐区间和页号位排列表示，可分段投影到共享物理空间；许可与失效确认绑定设备永久身份、启动代次、域代次、队列和范围。调用方要把逻辑窗口的一部分转给新租户，必须证明其全部物理像既无有效旧写租约，也无能看见新租户数据的旧读租约；不同确认可以联合覆盖但不能跨代拼接。凭据应准确返回可安全交接的最大子集合，不得用一个可交接页代表整段。使用方仅拿窗口清单和证书就能核验覆盖与缺口；48位页号空间不得逐页展开。用小位域逐页参考检查跨设备别名、位排列后逻辑连续而物理离散、确认只覆盖隔页和设备复位后的同名队列。

## handover 包

`handover` 是纯 Go、无硬件依赖、仅用标准库的可导入组件（module
`prescreen.local/ddd-10518-v3`，包路径 `prescreen.local/ddd-10518-v3/handover`）。

核心类型与入口：

- `Interval` / `IntervalSet`：48 位页号空间内排序、不相交、合并的半开对齐区间，
  所有集合运算（`Union`/`Intersect`/`Subtract`）都是结构化的，不按页号分配数组。
- `Perm`：页号位排列（双射），`Image` 用对齐圆柱 + 按目标位递归合并求物理像；
  整个排列域经双射映射到自身，走 O(1) 快路径，绝不展开 2^48 个页。
- `Segment` / `Window` / `Manifest`：分段地址窗口、窗口清单、租约与失效确认。
  租约 `Lease` 与确认 `Confirmation` 都绑定完整 `Identity`
  （永久设备 ID、启动代次、域代次、队列）+ 许可位 + 物理范围。
- `Issue(m, req)`：逐页（区间集合层面）判定每个物理页的所有在途租约是否都被
  **同身份、同许可**的确认失效，返回可安全交接的最大子集 `SafeLogical` /
  `SafePhysical` 以及带归因的 `Gaps`；不同身份（含复位后同名队列、跨域、跨设备）
  的确认不能拼接。
- `Verify(m, cred)`：仅凭窗口清单和证书全量重算并逐字段比对，拒绝任何夸大覆盖、
  隐藏缺口或伪造证据引用的凭据。
- `Manifest.AliasWindows`：辅助排查跨设备别名（哪些窗口能看到给定物理页）。

测试用小位域的逐页参考实现（`helpers_test.go` 中的 `refImage` / `refSafety`）
对拍结构算法，覆盖：跨设备别名、位排列后逻辑连续而物理离散、确认只覆盖隔页、
设备复位后的同名队列（启动/域代次不匹配），并含随机对拍、48 位边界与防篡改。
