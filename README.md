ARMv8.3-A/v8.5-A 固件与内核在启用指针认证（PAC）和分支目标识别（BTI）缓解 ROP/JOP 时，若函数序言 `PACIASP` 与尾声 `AUTIASP` 之间的栈指针 `SP` 偏移未严格还原、间接跳转目标缺失对应的 `BTI c`/`BTI j` 着陆垫，或在 `AUTIA` 失败写入错误码高位后未立即触发访存/陷阱而允许分支推测（PACMAN 签名预言机），攻击者可伪造返回地址或暴力测出合法 PAC 签名。为 C++17 二进制安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 ARM64 PAC/BTI 控制流图符号验证库。输入为函数基本块指令序列、间接分支目标表、入口导出表与异常返回点集合。验证器沿全部可达路径执行数据流与状态分析：（1）追踪每条返回路径的 `SP` 相对偏移与 PAC 密钥域（IA/IB/DA/DB），硬检出 `PACIASP`/`AUTIASP` 修饰符不匹配、未签名即溢出到栈内存的返回地址以及 `XPACI` 剥离签名后未经重新校验直接间接跳转的降级路径；（2）核对所有通过 `BLR`/`BR` 可达的非 `x16`/`x17` 目标首指令必须带合法 `BTI c`/`BTI j`/`BTI jc` 或等价隐式着陆垫（如 `PACIASP`），区分尾调用与普通间接调用权限；（3）识别 `AUT*` 与实际解引用/返回之间存在可被攻击者控制条件分支的签名预言机窗口，输出最短反例指令路径。附含合法序言尾声、SP 漂移、`BTI` 缺失与 PACMAN 预言机样本的测试集。
