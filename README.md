回调宿主原先只处理顺序归还的借用，现在插件可在父回调尚未返回时重入，同时在一条取消通知后恢复另一个挂起回调。给 C++17 生命周期宿主写可嵌入的借用授权组件，只处理抽象对象与区间，不解引用真实指针。回调帧可产生共享或独占子借用，权限受整个尚未返回的调用链约束；暂停不会归还借用，取消只撤销对应帧及其实际后代。来自不同历史分支的恢复票不允许拼接成一条合法调用链。输入为一组带版本化对象身份的事件段与栈摘要，中间可缺段，缺段可取宿主登记的多个操作类别。对给定范围的读写、移动及归还判定所有相容历史共同允许、共同禁止或未决；相同摘要引用的缺段必须取同一种解释。返回可独立验真的可访问区间与栈证书，用小对象逐字节解释器核对重入、移动后的旧代、兄弟帧取消、仅半区间归还及后来补到缺段使未决变确定。
