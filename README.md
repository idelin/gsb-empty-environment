# 设备重读描述符造成越界DMA

虚拟设备提交前校验DMA描述符，设备若在执行时重读客户机可写内存，攻击者可把已检查地址换到受保护页。为Go设备宿主实现可嵌入的描述符冻结与执行包：描述符环至多64项，每项16字节，含64位地址、32位长度、16位next索引和flags；flags仅READ、WRITE、END三位，长度1至1MiB，地址加长度不得溢出。客户内存接口提供ReadAt和单调64位版本号，读取前后版本一致才形成快照；沿next从头遍历，END项不得继续，未END环、重复项、越界索引和总字节预算超限拒绝。全部描述符复制到宿主私有不可变数组后，逐项验证区间属于该虚拟机已登记DMA页、权限不超过底层页且不碰保留区，再一次提交给只接受私有数组的设备回调。提供一个待审的“执行时重读”适配器，用同步点在验证后改地址，测试应重现越界DMA；正确实现中客户后续改环不得改变提交数组。设备回调失败不释放仍在途页，完成回执逐项绑定提交代次，重复或旧代完成不能回收。覆盖共享next子链、接口返回版本倒退或相同版本下字节变化视为ABA并拒绝、跨页权限、复位前未完成项及验证后改写，不能用最终版本相同证明期间没变。
