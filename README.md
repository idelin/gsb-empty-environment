# temporal — Allen 时间区间代数约束求解器

基于 Allen 区间代数（Interval Algebra）的时间关系约束网络求解器，用于时区与日历
排程场景：处理任务间的 `Before`、`Meets`、`Overlaps` 等时态约束，通过传递闭包
（路径一致性）传播约束并检查相容性，输出所有任务的最早/最晚可行时间窗与项目
全局关键路径窗口。纯 Go 标准库实现，无第三方依赖。

## 结构

- `allen/` — Allen 区间代数核心
  - 13 种基本关系（`Before`/`Meets`/`Overlaps`/`Starts`/`During`/`Finishes`/`Equal`
    及其逆关系），用位掩码表示析取关系集
  - 组合表（composition table）：初始化时枚举三区间六端点的所有弱序精确计算，
    而非手工转录
  - `Network.Propagate()`：路径一致性传播（R_ij ← R_ij ∩ (R_ik ∘ R_kj) 迭代至
    不动点），关系集变空即判定不相容
  - `EndpointConstraints()`：从（可能是析取的）关系集中提取所有析取支都成立的
    端点约束
- `sched/` — 排程求解器
  - 任务工期区间、Allen 关系约束、绝对时间约束（如"第 5 天前开始"）、项目截止
  - 将传播后的网络转换为端点上的简单时态问题（STP），用带严格标记的
    Floyd-Warshall 求最紧界，负环即不相容
  - 输出每个任务开始/结束的最早/最晚时间窗（含开闭区间）、项目全局窗口、
    关键路径（最长紧约束链上的任务）
- `cmd/demo/` — 验收场景演示

## 验收场景

任务 A 必须在 B 之前结束（`A before B`），B 与 C 部分重叠（`B overlaps C`），
C 必须在工期第 5 天前开始（`start(C) < 5`）。工期：A=2 天，B=3 天，C=4 天。

## 运行

```sh
go run ./cmd/demo
go test ./...
```

## 运行样例

```
=== Allen 时间区间代数约束求解器：排程演示 ===

任务（工期，单位：天）:
  A: 2 天
  B: 3 天
  C: 4 天

时态约束:
  A before B        (A 必须在 B 之前结束)
  B overlaps C      (B 与 C 部分重叠)
  start(C) < 5      (C 必须在工期第 5 天前开始)

传播后的导出关系（传递闭包）:
  A -> B : b   (before)
  A -> C : b   (before)     ← 传播导出的新事实
  B -> C : o   (overlaps)

各任务可行时间窗（项目第 0 天开始）:
  A  开始 [   0,    3)   结束 [   2,    5)
  B  开始 (   2,    5)   结束 (   5,    8)
  C  开始 (   2,    5)   结束 (   6,    9)

任务 A 最迟结束时间: 第 5 天 之前（开区间）
项目全局关键路径窗口: 项目结束时间 ∈ (   6, +inf)
关键路径: A -> B -> C
```

## 测试结果

```
$ go test ./...
ok      temporal/allen
?       temporal/cmd/demo       [no test files]
ok      temporal/sched
```

共 15 个测试全部通过：

- `allen`：组合表基本性质（含恒等元、逆关系对称性、对全部 13×13 基本关系对的
  逆一致性校验）、网络传播导出（`A b B ∧ B o C ⇒ A b C`、Meets 链）、
  传播可判定的不相容、端点约束提取
- `sched`：验收场景的全部时间窗（含 A 最迟结束 = 第 5 天前、C 最迟开始 < 5）、
  关键路径 `A -> B -> C`、传播导出关系 `A before C`、两类不相容检测
  （截止冲突、Before 环）、Meets 链 + 项目截止、工期区间

## 说明

- 路径一致性对完整区间代数是可靠但不完备的（NP 完全）；本实现叠加了 STP 层的
  数值传播，对单关系约束（如纯 `Before` 环）的不相容也能检出。
- 析取关系集在数值层取"所有析取支共同蕴含"的端点约束，是保守（sound）近似。
