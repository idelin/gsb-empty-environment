LSM 引擎的点查代价主要落在不存在的键上：每层都要先探布隆过滤器。给读路径交付可导入的 Go 包，内含按块划分的布隆过滤器和内存预算分配器。每个 SST 的键按每块固定条数切分，各块独占一段位数组，位数向上取整到 64 的整数倍；插入与查询用调用方注入的两个 64 位哈希做双重哈希，第二个哈希强制为奇数。每层可从给定档位表选一个每键位数，档位表同时给出该档的理论误判率；第零层不配过滤器，最下层可以不配，其余层必须配。分配器在总位数不超过预算时，最小化“键不存在”时一次点查的期望块探查数：层间按层序依次探查，本层是否探查取决于此前各层都未误判，期望值保留全精度；并列取各层档位编号组成的向量字典序最小者。验收用小实例穷举全部档位组合对照分配结果与期望值，用随机键统计实际误判率并与档位表相差不超过两成，覆盖预算只够部分层配高位、最下层配与不配同值的情形；层数不超过九、每层档位不超过十二，分配不得枚举全部组合。
