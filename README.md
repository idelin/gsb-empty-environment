终端取证与安全分析引擎在离线解析 Windows Registry Hive 文件（`regf` 基块 + `hbin` 区块 + `nk`/`vk`/`lh`/`lf`/`li`/`ri`/`db` 单元）时，若未做原始字节级结构审计，攻击者可构造损坏的 `regf` 头校验和、越界或非 8 字节对齐的单元偏移、`nk` 键节点子键列表形成有向环路（无限递归 DoS）、相邻已分配单元区间重叠以及 `vk` 值数据长度/大值 `db` 块越界触发堆溢出或内核级蓝屏。为 C++17 二进制安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的原始字节级 Windows Registry Hive 安全审计库。库从 4096 字节 `regf` 基块起严格校验：（1）校验魔数 `regf`、`PrimarySequence == SecondarySequence`、`HiveBinsDataSize` 与实际文件长度严格匹配（无 32 位溢出或尾随藏毒），以及前 508 字节按 32 位小端逐字异或计算的精确校验和（含 `0x00000000`/`0xFFFFFFFF` 规范边界）；（2）顺序扫描全部 `hbin` 块（偏移 4096 起，校验 `hbin` 魔数、相对偏移连续性与 4096 对齐、块内全部已分配负长度与未分配正长度单元精确铺满 `hbin` 且无越界或零长度死循环）；（3）从 `RootCellOffset` 递归遍历全量 `nk` 键树、子键索引（`lf`/`lh`/`li`/`ri`）与 `vk` 值列表：用已访问单元偏移集合硬拦截任意环路与跨父节点非法共享 `nk` 单元，校验所有 `vk` 内联/外部数据单元及 `db` 大值数据段均指向合法已分配单元且不与元数据单元重叠，限制最大键树深度防栈溢出。附手工构造的合法微型 Hive 样本与 `regf` 校验和篡改、`hbin` 单元重叠、`nk` 环路及越界 `vk` 偏移测试。
