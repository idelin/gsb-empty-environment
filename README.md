# diff

Go 行级差异库：输出**最少插入+删除行**的编辑脚本（即保留一个 LCS）。

## 决胜规则

最短脚本不唯一时，按序应用两条规则：

1. **优先保留更早旧行**（保留的旧行下标序列字典序最小）；
2. **再优先保留更早新行**（在满足规则 1 的脚本中，保留的新行下标序列字典序最小）。

实现：LCS 动态规划 + 贪心回溯。相等行必保留；插入/删除仅其一在最短路径上时被迫选择；
两者皆可时，若某最短脚本仍能保留当前旧行则插入（服务于规则 1），否则删除（服务于规则 2）。

## 行模型

`SplitLines` 保留每行末尾的 `\n`；末行可能没有换行符。因此：

- 空文件是零行，与含一个空行的文件（`"\n"`）不同；
- `"a"` 与 `"a\n"` 是不同的行，互相转换是一对删除+插入。

## API

- `Diff(oldLines, newLines []string) []Edit` — 最短编辑脚本（`Keep`/`Delete`/`Insert`）。
- `Apply(oldLines []string, script []Edit) ([]string, error)` — 应用器；逐步校验旧行并精确还原新行，脚本不匹配旧文件时返回错误。
- `SplitLines` / `JoinLines` / `DiffText` — 文本与行列表之间的转换及便捷入口。

## 验证

`exhaustive_test.go` 对短序列（二元字母表长度 ≤6、三元 ≤5 的全部序列对）枚举**所有**最短编辑脚本，
按决胜规则三路比较，核对 `Diff` 的输出不劣于枚举最优，并用 `Apply` 验证精确还原。
