# 短窗口价格预言机被单笔交易操纵

借贷协议直接采用AMM现货价格，攻击者可用临时大额交换推高抵押品价格后借走资产。给TypeScript风险宿主实现题内常数乘积池与时间加权预言机包：储备x,y为正整数，交换输入扣除有理手续费后按x*y不减规则求最大整数输出；每次储备变化前，按单调时间差把price0=y/x和price1=x/y的精确有理数累加到累计值，并写入最多64条环形观察(time,cumulative0,cumulative1)。查询窗口W要求找到time≤now-W的最近观察，并用从该观察到now的累计差除以实际时长；历史不足、时钟倒退、时长小于W或价格分母为0拒绝。借贷动作使用该TWAP、调用方给的最大观察年龄和最小流动性，在同一交易先固定价格回执再检查抵押率，交换与借贷不能共享尚未落观察的临时状态。实现现货待审回调与至多3笔攻击动作搜索，找借入交换、借款、反向交换后池储备在调用方给的储备差绝对值上限内恢复而坏账为正的最短见证；正确TWAP在给定W下拒绝或限制借款。用精确有理参考测试环覆盖、同时间多交换、手续费舍入、窗口边界和长期真实价格变化，不能把“TWAP”表述成完全抗所有操纵。
