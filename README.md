# 最小重建成本计划（Minimum Rebuild-Cost Planner）

给定：

- 一个有向无环依赖图（DAG），每个节点是一个带语义版本的包构建产物；
- 一批**失效产物**（`failed`）；
- 一个**本地缓存**：节点 id -> 摘要（digest）；
- 若干**目标**（节点 id 或带版本约束的包）。

求一个满足所有目标、**成本最小**的执行计划。全程只读取本地 JSON，**不联网查包**；
仅依赖 Python 3.11 标准库。

## 成本与恢复规则

对每个被目标闭包（targets + 全部传递依赖）需要的节点，按优先级选择成本最低的获取方式：

1. **local（成本 0）**：节点不在 `failed` 且 `available` 非 false，视为仓库中已有的有效产物。
2. **restore（成本 0）**：节点失效/缺失，但缓存中存在该 id，且缓存摘要与节点声明摘要**完全一致**。
3. **build（成本 = 节点 `cost`）**：既无有效产物，又无匹配缓存（无缓存条目，或**摘要不匹配**）时从依赖重建。

共享成本只算一次：

- 多个目标共享的中间产物只会出现在闭包集合中一次，因此 `build` 成本只计一次；
- 执行顺序按依赖拓扑序给出，每个节点执行前它的全部依赖都已满足；
- `restore` 出来的目标同样要求其依赖已满足，再视为完成。

## 版本与约束

- 版本格式为 `major.minor.patch`，可选预发布 `-alpha.1`、`-rc.2` 等，可选构建元数据 `+build`，遵循语义化版本（SemVer）解析与预发布优先级。
- 约束支持：`=`（默认）、`>`、`>=`、`<`、`<=`、`^`（兼容版本）、`~`（补丁级兼容），以及目标对象中的 `*`。
- 默认**不选预发布版本**；只有约束本身写了预发布（如 `>=2.0.0-rc.1`）或显式 `"allow_prerelease": true` 才允许。
- 同一约束匹配多个版本时，选择**最高版本**；匹配不到则报错。

## 输入 JSON（本地）

顶层字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `nodes` | 数组 | 构建节点：`id`、`package`、`version`、`cost`、`digest`、`dependencies`（节点 id 列表）、可选 `available` |
| `cache` | 对象 | `节点id -> 缓存摘要`；只做本地精确摘要比对 |
| `failed` | 字符串数组 | 失效产物的节点 id |
| `targets` | 数组 | 节点 id（`"app-300"`）、包规格（`"app@^3.0.0"`）或对象 `{package, constraint, allow_prerelease}` |

参考 `sample_input.json`。

## 运行样例

人类可读输出：

```bash
python3.11 rebuild_planner.py sample_input.json
```

完整 JSON（含逐节点校验）：

```bash
python3.11 rebuild_planner.py sample_input.json --json
```

样例结果：

- 目标：`app@^3.0.0`、`service@~1.2.0`、`web >= 2.0.0-rc.1`（允许预发布，选中 `web-2rc2` 而不是 `web-190`）。
- `util-140`：缓存摘要一致 -> `restore`（0）。
- `core-231`：缓存摘要不匹配 -> 必须 `build`（250），但被 `app` 与 `service` **共享，只计一次**。
- `app-300`（80）、`web-2rc2`（40）无缓存 -> 重建。
- `service-120`：缓存一致 -> `restore`（0）；`json-010`：本地有效 -> `local`（0）。
- `legacy-090` 不在目标闭包内，不参与计划（避免无谓的 999 成本）。
- **最小总成本 = 370**。若按目标分别独立求和，`core-231`/`util-140` 会被重复计算，得到 620。

输出同时附带 `verification`：对每个节点检查“依赖是否已先满足”“缓存摘要是否精确一致”
“动作是否是成本最低的合法动作”，并复核总成本与目标闭包。

## 测试

```bash
python3.11 -m unittest discover -v
```

覆盖：SemVer 解析/预发布优先级、`^`/`~`/比较/精确预发布约束、共享依赖成本去重、
缓存命中与摘要不匹配、本地有效产物零成本、最高版本选择与预发布隐藏、
依赖环/未知依赖/无法满足目标报错、拓扑序与错误动作被校验器拒绝、CLI 人类/JSON 输出。

当前测试结果：**18 个测试全部通过（Ran 18 tests — OK）**。
