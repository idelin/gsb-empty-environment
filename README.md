多规则 SNAT 网关在高并发短连接下既要最大化端口复用，又要严格保证反向回包能唯一映射回内网连接。给数据包转发控制面交付可导入的 Go 状态表与分配包。输入有序 SNAT 规则列表（每条含源/目 CIDR、协议、外网 IP 池与端口闭区间、是否优先保留原端口）及按毫秒到达的新建、FIN/RST 状态迁移和超时事件。核心规则：同一外网 IP 与端口可同时服务不同目的（IP,Port），但已存在或处于活跃态的完全相同外网五元组绝不可冲突；TCP 进入 TIME_WAIT 后，仅当原连接已过冷却保护期且新连接初始序列号大于旧连接末尾序列号（按 32 位回卷比较）时才可提前复用该五元组，否则必须换端口；规则池耗尽时须按顺序回退下一条匹配规则，全部耗尽则显式拒绝并记录原因。组件返回每条新连接的精确外网五元组或拒绝码，并支持按反向五元组精确查回内网五元组。验收用事件重放对照朴素全表碰撞检测器，覆盖不同目的复用同一外网端口、优先保留原端口冲突后线性探查、TIME_WAIT 序列号回卷复用与拒绝、以及首规则满池回退次规则。
