# dynconn — 离线动态图连通性分析库

离线读取一段边增删操作日志，回答"某个历史时刻两顶点是否连通"的查询。

## 语义

- 操作按切片顺序应用；时刻 `t`（`0 <= t <= len(ops)`）的图 = 应用前 `t` 个操作后的状态。
- **引用计数**：重复 `OpAdd` 同一条边只累加计数，只有让计数归零的那次 `OpDel` 才真正断开（支持平行边）。
- **自环**：`OpAdd{U: x, V: x}` 合法，不影响连通性；查询 `(x, x)` 恒为真。
- 对计数为零的边执行 `OpDel` 是空操作。
- 查询可指定任意历史操作序号 `At ∈ [0, len(ops)]`，越界自动钳位。

## 算法

1. `AliveIntervals` 把操作日志展开成每条边的存活区间 `[L, R)`（引用计数从 0→1 开始、1→0 结束）。
2. 区间插入时间轴上的线段树（每个区间覆盖 O(log n) 个节点）。
3. DFS 线段树，进入节点时应用该节点所有边，离开时**回滚**并查集（按大小合并、无路径压缩，保证 O(1) 撤销），叶子时刻回答挂在该时刻的查询。回滚保证兄弟时间段之间状态不泄漏。
4. 测试中用 `bruteAnswers` 对每个查询时刻从零重建图 + BFS，与线段树结果逐一核对（含 60 组随机用例，混合平行边、自环、未匹配删除）。

复杂度：`O((len(ops) + len(queries)) · log len(ops) · α(V))`。

## 用法

```go
ops := []dynconn.Op{
    {Kind: dynconn.OpAdd, U: 0, V: 1},
    {Kind: dynconn.OpAdd, U: 0, V: 1}, // 引用计数 = 2
    {Kind: dynconn.OpDel, U: 0, V: 1}, // 计数 = 1，仍连通
    {Kind: dynconn.OpDel, U: 0, V: 1}, // 计数 = 0，断开
}
ans := dynconn.Answers(ops, []dynconn.Query{
    {U: 0, V: 1, At: 3}, // true
    {U: 0, V: 1, At: 4}, // false
})
```
