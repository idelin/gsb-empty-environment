# kano: 最小损失 k-匿名全域泛化搜索（仅合成数据）

给定每个字段的**有限泛化树**，在所有字段的全局层级组合（level 向量）中，
寻找满足 **k-匿名约束** 且**信息损失最小**的组合。支持小规模**精确搜索**
（带单调性剪枝的 BFS，穷举保证最优）与**预算截断搜索**（限制评估节点数，
明确区分"未找到"与"未搜完"）。Python 3.11，仅标准库，unittest 测试。

## 定义

- **泛化树**：每字段一棵有根树，叶子为原始取值。层级 `h` 表示把原始值替换为
  高度 `h` 的祖先（0 = 不泛化，根 = 完全抑制）。层级有限：`0..max_level`。
- **层级组合（搜索节点）**：向量 `(l_1, ..., l_d)`，每字段一个层级
  （full-domain generalization）。向上泛化 = 某坐标 +1。
- **路径去重**：不同泛化路径（坐标递增顺序不同）收敛到同一向量；BFS 用
  visited 集合去重，每个向量至多评估一次（测试
  `test_converging_paths_deduplicated` 验证）。
- **等价类**：泛化后准标识符元组相同的记录集合。**k-匿名**：所有等价类
  大小 ≥ k。
- **损失**（分类属性的归一化歧义度）：值泛化到节点 u 的损失为
  `(|leaves(u)| - 1) / (|leaves(H)| - 1)`（叶子 = 0，根 = 1）；记录损失为
  各字段（可加权）均值，数据集损失为记录均值。损失对每个坐标单调不减，
  因此 k-匿名节点的更泛化后代不可能更优，可安全剪枝。

## 搜索状态（区分"找不到"与"未搜完"）

| status | 含义 |
|---|---|
| `optimal` | 搜索穷举完成，返回最小损失解 |
| `no_solution` | 搜索穷举完成，**不存在**满足 k 的组合 |
| `truncated_best` | 预算耗尽，返回当前最优可行解（不保证全局最优） |
| `truncated_none` | 预算耗尽，尚未找到可行解（**不代表无解**） |

## 参数

`python3.11 main.py --k K [--records N] [--seed S] [--budget B] [--brute-force]`

- `--k`：k-匿名阈值（必填）
- `--records` / `--seed`：合成数据规模与随机种子（均匀随机生成，可复现）
- `--budget`：评估的层级向量数上限；缺省为精确（穷举）搜索
- `--brute-force`：同时运行独立的全枚举实现交叉验证

输出 JSON 包含：最优层级、损失、**可验证的等价类大小计数**
（`equivalence_class_sizes`，其和 = 记录数、最小值 ≥ k）、评估节点数、
以及 `verified`（由 `kano/verify.py` 独立重算等价类并校验）。

## 运行样例

精确搜索 + 全枚举交叉验证（`python3.11 main.py --k 4 --records 120 --seed 7 --brute-force`）：

```json
{
  "status": "optimal",
  "levels": [2, 1, 0],
  "loss": 0.21845574387947309,
  "equivalence_class_sizes": [6, 6, 6, 9, 10, 10, 10, 11, 11, 13, 13, 15],
  "nodes_visited": 16,
  "verified": true,
  "brute_force": {"levels": [2, 1, 0], "nodes_visited": 24, "matches_search": true}
}
```

预算截断（`--budget 5`）：`"status": "truncated_none", "exhaustive": false`
—— 预算耗尽且未找到可行解，与无解明确区分。

无解（`--k 200`，记录仅 120 条）：`"status": "no_solution", "exhaustive": true`
—— 穷举后确认不存在满足约束的组合。

## 测试

`python3.11 -m unittest discover -s tests -v` —— 13 个测试全部通过，覆盖：
层级结构与非法树拒绝、损失界与单调性、精确搜索 vs 独立全枚举一致性
（含默认三字段层级）、剪枝有效性、收敛路径去重、无解/截断状态区分、
等价类计数可验证性、结果确定性。
