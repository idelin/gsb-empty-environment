# 堆对象跨过程释放分析

代码审查服务需要追踪释放后的别名访问。编写供分析服务调用的Go包，输入是调用方构造的过程图，节点仅含分配、复制、字段读写、释放、解引用、分支与调用；对象按分配点抽象，字段敏感，递归调用求摘要不动点。返回可能的重复释放和释放后访问及可重放路径；不确定别名必须保留，不能当作安全。用有界具体解释器枚举小程序，检查报告覆盖所有真实错误并标注不可证实的路径。

## 用法

```go
prog := &netsec.Program{Main: "main", Procs: ...} // 调用方构造过程图
res, err := netsec.Analyze(prog)                  // 摘要不动点分析
// res.Reports: 可能的 double-free / use-after-free，各自携带可重放路径

cr := netsec.Check(prog, res, netsec.DefaultBounds)
// cr.Missing:  未被报告覆盖的真实错误（应为空）
// cr.Unproven: 见证路径无法被具体执行证实的报告（同时置 Report.Proven=false）
```

- `ir.go`：过程图 IR（分配、复制、字段读写、释放、解引用、分支、调用）。
- `analyze.go`：may-分析。对象按分配点抽象、字段敏感、弱更新；上下文不敏感摘要 + 混沌迭代不动点处理递归；不确定别名一律保留。
- `concrete.go`：有界具体解释器（步数/调用深度受限），枚举小程序的真实错误，做覆盖检查并标注不可证实路径。

已知局限：穿越递归的见证路径是摘要压缩过的，具体重放可能无法证实（会被标注为 unproven）；循环中同一分配点重复分配后释放可能产生保守误报，同样由 `Check` 标注。
