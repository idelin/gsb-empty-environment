交换芯片为组播帧只分配一个缓冲槽，所有出口副本发送完才能还槽。请为驱动交付可导入的 Go 门表编译包。负载是无限重复的同一超周期，周期 ≤96 拍；按周期相位释放的每个帧给出出口集合、各口的非抢占发送时长及相对期限（可大于一周期且不超过两周期）。对同一种帧的各周期实例，每口必须用相同相对起发偏移。每口同拍至多发送一个副本且不得跨过本口禁发拍；同一帧可在多口同时发送。全芯片共享槽从释放拍占用到最后一个副本结束，半开区间，跨周期甚至与本帧下一实例重叠时必须分别计槽。硬件按端口烧录周期位图，1 表示占线，物理表把每个掩码连续不变的最大区间压成一项，以圆环计数；恒定掩码也占一项。目标是在硬性槽数及全芯片表项预算内最小化各帧最坏完成延迟，平局再取各帧每口起发偏移按输入顺序构成的最小字典序。交付逐拍设备回放，返回真实起发、释放槽、当前端口掩码，而不只是整数解。最多四口、十个帧类型。用独立短周期实例枚举所有偏移核对最优结果；另测周界两端同掩码必须合并、相邻两代并存、两个各口局部可行的门表合在一起却无法满足槽预算，以及零空闲拍的静态表。
