# 音频编辑器把片段拼接后，直流跳变造成点击声

音频编辑器把片段拼接后，直流跳变造成点击声。实现供Go音频宿主调用的拼接包，输入多声道PCM、样本级剪辑点和每处给定交叉淡化长度；为各剪辑点在给定搜索窗内选择边界，目标先最小化通道最大幅值跳变再最小化移动距离，并保持所有片段最小长度。交叉区使用平方和为一的正弦余弦窗，输出源样本映射。用短PCM穷举全局剪辑位置，核对相邻淡化区冲突、立体声同步与无淡化时长度。

## 用法

包 `taskpkg` 暴露 `Splice(pcm, cuts, opts)`：

- `pcm` 为平面（planar）多声道 `[][]float64`，所有声道等长并共享同一边界，保证立体声样本同步。
- 每个 `Cut` 给出标称剪辑点 `At`、交叉淡化帧数 `Fade`（0 为硬切）和对称搜索窗半宽 `Window`。
- `Options.MinSegmentLength` 约束头部、尾部及相邻淡化区之间普通段的最小帧数；相邻淡化区重叠或长度不足时返回 `ErrInfeasible`。
- 边界选择对每个候选点计算 `max_c |x[c][b] - x[c][b-1]|`，按「最大通道跳变 → 移动距离 → 有符号偏移」做全局字典序最优（动态规划，等价于对短 PCM 的全量穷举）。
- 交叉区采用等功率正弦/余弦窗 `gL=cos θ`、`gR=sin θ`，满足 `gL²+gR²=1`。
- 返回值 `Result` 含拼接后的 `PCM`、每个剪辑点的 `Boundaries` 决策，以及逐输出帧的 `Mapping` 源样本（帧号、声道、增益）。

```go
res, err := taskpkg.Splice(pcm, []taskpkg.Cut{
    {At: 1000, Fade: 64, Window: 128},
}, taskpkg.Options{MinSegmentLength: 256})
```
