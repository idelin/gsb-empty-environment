# 工作负载联合身份模板碰撞

集群把OIDC声明拼成云主体名，两个不同工作负载若落到同一主体就能共享权限。给Go联合身份宿主实现可导入的映射与碰撞审查包：提供者配置固定issuer、允许audience集合、声明模式及模板。令牌验签和时间校验由宿主回调完成后返回不可变claims；iss须精确，aud至少命中一个允许值且azp在多aud时必填并受允许。声明模式可读取sub、namespace、serviceAccount、repository、ref，缺失或非字符串拒绝；模板由字面段和{claim}占位组成，每个值先按UTF-8字节做百分号编码，只有ASCII字母数字和-._~不编码，分隔符来自模板字面量，最终主体长度受限。禁止对值先转小写、裁剪、路径规范化或二次解码。配置发布前，调用方给每个声明的有限允许语言（枚举字符串或前缀加有限后缀集合），包构造确定性有限状态转导并判断两个不同声明元组是否能生成同一主体；找到则输出字典序最小碰撞，无法在预算内闭合则拒绝发布而非假定唯一。运行时映射还绑定providerID和配置代次，缓存不得跨代复用。用包含斜杠、百分号、允许语言不得包含空字符串，运行时声明也不得为空；覆盖空字符串拒绝、大小写差异及不同占位分割方式验证，权限回调只接无碰撞配置产生的主体。
