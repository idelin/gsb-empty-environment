闪存阵列的读控制器只想取出一个编码标记，却要为慢盘上的下一笔读取做选择。提供可嵌入控制器的 Go 包：条带是未知的 64 位字 x；已缓存的观察和可选探针均给盘号与一个 64 位掩码，正常盘读回 parity(x & mask)。从开始到结束最多一块盘不可信；该盘每次可以给任意一位，甚至同掩码两次读出不同结果，其余盘始终正确。调用方给出带实测返回位的缓存、最多 12 个只可各读一次的探针（各有正整数成本）及目标掩码。返回可执行的自适应读策略，叶子直接交付目标奇偶位；策略须对每种与缓存相容的条带、坏盘和后续应答均正确。最小化最坏分支新增成本，成本相同时取当前可行最优探针中输入下标最小者，已能确定便不再读。缓存本身矛盾须与后续无论怎样探测都不能保证恢复区分；无解时给出两个完整条带、各自可疑盘（允许无坏盘）和一份对全部剩余探针都相同的合法应答，使两个目标值不同。不得枚举 64 位条带，成本总和可超过 uint64；实际读取沿决策路径调用设备回调，不提前读未选探针。用小位宽逐条带、逐坏盘、逐应答的树搜索对照最坏成本和根选择，再覆盖高位独占的目标、同盘互相矛盾的缓存读、零掩码、每条分支分别有便宜补读但不存在同价固定探针集合的例子，并独立重放无解见证。
