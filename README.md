# tpllex

流式模板词法器：在普通文本、表达式、可嵌套原始字符串三种模式间切换。

## 特性

- **显式定界符驱动模式切换**：`{{`/`}}` 进入/退出表达式，`[[`/`]]` 进入/退出原始字符串（可嵌套，按深度计数）；定界符可通过 `Config` 自定义。
- **转义只在对应模式生效**：文本与表达式模式中 `\` 可转义定界符首字符与自身；原始字符串中无任何转义，反斜杠为字面量。
- **真流式**：`Feed` 增量喂入（可逐字节），每个字节只被消费一次，绝不重新扫描已处理前缀；token 边界与喂入分块方式无关。
- **保存/恢复点**：`Mark`/`Reset`/`Release`。恢复后重新产出的 token 及其原始区间（`Start`/`End` 绝对偏移）与首次完全一致；缓冲区按存活 mark 保留，无 mark 时自动压缩。
- **定界符前缀重叠**：最长匹配优先；缓冲区尾部若可能成长为更长定界符则等待更多输入（EOF 时按字面量收尾）。
- **每种模式的 EOF**：文本模式直接结束；表达式/原始字符串未闭合时产出 `KindError` 后再发 `KindEOF`。

## 用法

```go
l := tpllex.New(tpllex.Config{}) // 默认 {{ }} [[ ]] \
l.Feed([]byte("a {{ x }} [[ y ]]"))
l.Close()
for {
    tok, ok := l.Next() // ok=false 表示需要更多输入
    if !ok { /* feed more */ }
    if tok.Kind == tpllex.KindEOF { break }
    // tok.Start/tok.End 为原始输入区间；tok.Val 为解析转义后的值
}
```


覆盖：定界符前缀重叠（`<%` vs `<%%`）、逐字节到达与整体喂入等价、每种模式的 EOF、
