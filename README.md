# domain — 有理幂表达式的精确定义域分析器

对含有理常量、四则运算和 `p/q` 次幂的单变量表达式，在变量取给定有理
区间的前提下，精确计算其在实数域上的分段定义域，并明确列出无法精确
判定的部分。

全程使用 `math/big.Rat` 精确有理数运算（幂的边界用有理数二分逼近），
**不依赖浮点 NaN 猜测边界**；无法精确判定的部分会被排除在定义域之外，
并作为 unsupported 条目报告。

## 规则

- 指数为最简分数 `p/q`（`big.Rat` 自动约分，故 `2/4` 与 `1/2` 等价）。
- `q` 为偶数：实数分支要求底数 `>= 0`（`p < 0` 时 `> 0`），负底数拒绝。
- `q` 为奇数：负底数有实数奇次根，全实数有定义。
- `p < 0`：零的负次幂无定义，底数零点被剔除。
- `p = 0`：约定 `x^0 == 1`（含 `0^0 = 1`）。
- 嵌套幂按结构递归处理，**绝不合并指数**：`(x^(1/2))^2` 的定义域是
  `x >= 0`，而合并后的 `x^(2/2) = x` 会是全体实数——两者不同。

## 可精确判定的内容

- 常量、变量、仿射表达式（`a*x + b`）的符号与零点：精确有理根。
- 乘/除/幂的符号：由各因子的符号分区组合。
- 加减（非仿射）：用精确有理区间算术判定定号；判不定则报告 unsupported
  （例如 `x^2 - 2` 的零点是无理数，没有有理边界，输出 unsupported 而非
  浮点近似）。

## 用法

```go
res, err := domain.AnalyzeString("(x-1)^(1/2) + 1/(x-5)", "x", "0", "10", false, false)
// domain: [1, 5) ∪ (5, 10]
// unsupported: (none)
```

命令行：

```sh
go run ./cmd/domain "1/(x^2-2)" x 0 3
# domain: ∅
# unsupported:
#   - cannot determine the sign of x^2 - 2 on [0, 3] exactly
#   - cannot prove x^2 - 2 != 0 on [0, 3]; that part is excluded from the reported domain
```

表达式语法：数字（整数/小数/分数）、变量、`+ - * /`、括号、
`^` 后接有理字面量指数（`x^2`、`x^-1`、`x^(1/2)`、`x^(-2/3)`）。

## 测试

```sh
go test ./...
```

覆盖：约分前后指数等价（`x^(2/4)` ≡ `x^(1/2)`）、嵌套幂不合并、
偶分母负底数拒绝、奇分母负底数实分支、零的负次幂、开闭区间端点、
以及无法支持部分的报告。
