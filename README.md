# archive-restore

Go 归档恢复模型：条目先暂存（`Stage`），提交时（`Commit`）一次性解析并原子发布快照。

## 语义

- **前向引用**：硬链接条目可引用尚未出现的目标路径；引用在暂存期仅记录，`Commit` 时沿链解析到最终普通文件，共享同一 inode（`Node.LinkFrom` 保留原始目标）。
- **符号链接独立**：符号链接始终是独立内容节点，拥有各自 inode，绝不并入共享 inode 组；硬链接指向符号链接会被拒绝。
- **拒绝情形**（提交失败，不发布半棵树）：硬链接环（自指/互指/多节点）、硬链接指向目录（显式或隐式）、悬空目标、重复路径、路径前缀冲突、非法路径。
- **失败回滚**：`Commit` 失败返回 nil 快照，暂存集保持不变，可修正后重试。

## 核对

`Snapshot.Graph()` 返回 inode 引用图（inode → 路径集），用于核对前向引用解析结果、共享组与独立节点；`Snapshot.InodePaths` / `Snapshot.Shared` 提供单点查询。

```sh
go test ./restore/
```
