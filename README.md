车载交换机的一条出端口给周期帧预留窗口，低优先级长帧可以在允许的字节边界被抢占，但重新发射有前导开销。为门控驱动提供可导入的 Go 时序包。门表是按整数拍重复的开放/关闭区间；两条 FIFO 各有有限清单，列出帧的入队时刻、字节数、截止以及可切分的字节边界。每拍传一个字节；每次启动或恢复先连续占用 h 拍头部，且同一开放窗内须至少能传到下一个允许停点或帧尾。低队列只能在允许停点让出，不能因新高优先帧到达中断头部。驱动可选择空闲、在合法边界暂停或继续；允许在高队列非空时继续低帧以避免浪费窗口。全局只有一个不可直接观察的未知相位偏移，是输入列出的至多十个整数之一；每拍开始只看到当前门是否开放，不能读真实相位。同一策略须保证任何可能相位都不传入关闭窗且按期送完所有帧。求最小最坏帧切分次数；所有合格策略中在此上限下再取各相位完成时刻之和最小。时刻可到 2^50，最多六个帧、每帧八个合法边界，每周期至多十段，不得逐拍扫描漫长空闲或重复周期。实现驱动按带时间戳的实际门沿、入队、发射进度推进，返回真实发射片段；离散小例另写逐拍对照解释最优代价。包括尚未出现的门沿也能排除某相位、观察相同门史时不能预知下一次关门、同一拍帧到与门关撞车、为了少切一刀主动空等。
