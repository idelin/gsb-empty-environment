高安全点对点 VPN 宿主在实现 WireGuard 握手与传输层会话生命周期管理时，若未严格按每个已知对端公钥独立维护最大已见 12 字节 `TAI64N`（8 字节大端秒 + 4 字节大端纳秒）握手时间戳，或未在 `REJECT-AFTER-TIME`（180 秒）与 `REJECT-AFTER-MESSAGES`（`2^64 - 2^4 - 1`）硬边界强制销毁传输会话密钥并拒绝继续收发，抑或允许未完成的半开握手在收到首条合法传输包前就覆盖当前活跃会话密钥，攻击者可重放旧 `Handshake Initiation` 触发反复重协商断流（DoS）或迫使超龄会话密钥继续复用。为 Go 网络安全宿主实现可导入的 WireGuard `TAI64N` 防重放、三槽位密钥轮换（Current / Previous / Next）与传输层 64 位计数防重放状态机包，严禁联网。组件严格实现：（1）按对端静态公钥独立追踪最新 `TAI64N` 12 字节无符号大端单调水线：硬拒绝小于或等于已见最大值的重放握手（含同秒低纳秒与非法 `nanosec >= 10^9` 畸形时间戳）；（2）精确实现 WireGuard 白皮书 Section 6.1–6.4 的三槽位（`current`/`previous`/`next`）密钥轮换状态机：响应方新握手密钥先置入 `next` 槽位，仅在收到对端用该新密钥加密的首条合法传输包（含空 Keepalive）后才原子晋升 `next -> current -> previous`（防止未确认握手踢掉活跃连接）；（3）严格执行计时器与消息数硬熔断：超过 `REKEY-AFTER-TIME`（120s）触发主动重协商，超过 `REJECT-AFTER-TIME`（180s）或 `REJECT-AFTER-MESSAGES` 硬拒绝收发并在 `3 * REJECT-AFTER-TIME` 后彻底清零全部三槽位密钥材料，同时对每个接收槽位维护 2048 位滑动防重放窗口。附 `TAI64N` 纳秒回退重放、未确认握手防覆盖、180s 超龄硬拒收与 2048 位窗口越界测试。
