调度器要把同一类 Pod 尽量均匀铺到可用区和节点上。给过滤器与打分器交付可导入的 Go 约束组件。每条约束给出拓扑键、最大偏差、可选的最小域数，以及计入哪些节点和哪些 Pod 的策略；匹配的域按各节点上标签取值得到，匹配 Pod 由选择器决定，待调度 Pod 自身要计入。节点上的偏差定义为把待调度 Pod 放入后，该节点所在域的匹配数与全局最小域匹配数之差；域数不足最小域数时全局最小值取零。硬约束要求每个节点的偏差都不超过最大偏差才可行，软约束按各节点偏差归一化打分。验收用枚举放置的朴素模型对照可行集合与分数，覆盖策略使污点节点或亲和不匹配的节点被排除在域统计之外、域数不足、只有一个域、待调度 Pod 已计入使偏差刚好越界，以及两条约束同时生效。
