# treemerge — 离线文件树的确定性合并器

语义：**全序重放（total-order replay）**。合并 = 操作集并集，按
`(逻辑时间, 操作ID)` 全序排序后从空树重放。不实现即时增量算法；
任何新操作（包括迟到的早操作）都会触发完整重放，自然完成回滚与重判。

## 保证

- 相同操作集，无论分批、到达顺序如何，父映射与拒绝清单完全一致。
- 展示树永远无环：非法移动在重放时被拒并保留理由，不会进入父映射。
- 根节点稳定 ID 为 `root`，不可移动、不可删除。

## 操作与拒绝理由

- `OpCreate` / `OpMove` / `OpRename` / `OpDelete`，每个操作含
  操作 ID、节点 ID、新父 ID（create/move）、名称（create/rename）与逻辑时间。
- 重放时拒绝并记录：父不存在、父已隐藏、目标是自身或后代、移动/删除根、
  节点已存在（create）、节点缺失、操作 ID 冲突（载荷不同，规范序小者胜，
  败者保留在拒绝清单中；完全相同者静默去重）。
- 重命名不改节点 ID；同名兄弟允许，路径输出携带 ID，如
  `/root(root)/docs(a)` 与 `/root(root)/docs(b)`。
- 删除是独立的可见性标记：后代按祖先可见性隐藏，不改动父子结构。

## Checkpoint 恢复

`Checkpoint()` 保存完整操作日志与状态快照；`Resume(cp, more...)` 将
checkpoint 日志与后续操作的并集重新全序重放，因此与一次性合并全量
操作严格等价（测试对每个切分点验证）。

## 独立树校验器

`Validate(Snapshot)` 与重放引擎不共享代码，独立检查：根存在且无父、
每个非根节点父链在 `len(Names)` 步内到达根（无环、无孤儿）、删除标记
引用存在的节点、可见路径唯一。
