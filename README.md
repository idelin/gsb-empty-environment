调度代理按内存访问样本决定容器页迁移。给节点代理写可导入的 Go 包，处理稀疏虚拟映射、物理别名、NUMA 容量和可拆分大页。多个容器可能映射同一物理页，迁移只做一次，所有别名同时受益；固定页不能动，大页未拆时必须整体迁移，拆页一次性扣费且以后不可合并。给短时间窗各阶段的节点访问次数、迁移预算和可用容量，阶段切换允许先腾空再装入但任何中间状态都不能超容，不能把两节点满载互换视作原子操作。返回访问延迟加迁移与拆分费用最小的计划，及逐步可回放的物理占用证书；同价先少拆再少迁移。每个亲和分量最多十二个可独立移动单元，连续等价冷页要按区间计，不展开 2^40 地址空间。小分量枚举检验，覆盖别名双计、钉住子页和需要经过第三节点的交换。
