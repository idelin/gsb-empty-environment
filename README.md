# 时间拉伸后语音音高不应跟着变化

时间拉伸后语音音高不应跟着变化。实现供Go音频编辑宿主调用的相位声码器包，基于调用方给定FFT长度与分析hop，合成hop由有理拉伸比例累积决定；相位差扣除期望前进后绕回[-π,π)，用估计频率更新合成相位，输出按窗口平方和归一。比例运行中只在帧边界变化。用单音、双音和静音验证主频不变、时长误差不超过一个hop及任意输入分块等价，明确不要求瞬态保真。

## 包结构

- `vocoder.go`：流式相位声码器 `Vocoder`（实现 `io.Writer` / `io.Reader`）与一次性封装 `Process`。
- `fft.go`：纯标准库 radix-2 迭代 FFT（要求长度为 2 的幂）与周期 Hann 窗。
- `doc.go`：包级文档，明确瞬态保真不在范围内。

## 算法要点

- 合成 hop 不固定：每帧把有理比例 `num/den × 分析hop` 累加进整数累加器，整数商作为该帧合成 hop，余数跨帧累积，无浮点漂移。
- 每个频点扣除该 bin 在线性相位下的期望前进 `2πk·Ha/N`，残差绕回 `[-π, π)` 后得到瞬时频率，再按 `Hs/Ha` 缩放推进合成相位；幅度保持不变，因此音高不变。
- 逆变换结果加 Hann 窗做 overlap-add，并逐样本除以窗口平方和，保证重叠区幅度恒定。
- `SetRatio` 只登记待生效比例，在下一个完整分析帧边界才应用，流中途改比例不破坏分块等价性。
- `Flush` 零填充尾部并补足零帧，使实际输出时长与理想目标之差不超过一个分析 hop。

## 用法

```go
v, _ := taskpkg.New(2048, 512, 3, 2) // FFT=2048，分析hop=512，拉伸 3/2
_, _ = v.Write(input)                // 任意分块写入
v.Flush()
var out []float64
buf := make([]float64, 4096)
for {
	n, err := v.Read(buf)          // Read 直接消费 []float64
	out = append(out, buf[:n]...)
	if err == io.EOF { break }
}
// 或一次性：
out, err := taskpkg.Process(2048, 512, 3, 2, input)
```

## 验证

`go test ./...` 覆盖：FFT 与朴素 DFT 一致性、单音/双音主频保持、静音输出为零且有限、时长误差 ≤ 一个分析 hop、任意写入与读出分块逐样本等价、恒等比例内部重构到机器精度、帧边界改比例、非法参数，以及 fuzz 不变量（无 NaN/Inf、确定性、时长约束）。
