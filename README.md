# 预算项目组合求解器（Go）

在预算约束下选择项目组合，使**总收益 = 项目固定收益之和 + 成对协同收益之和**最大。
支持前置项目、互斥关系、可正可负的成对协同收益，最多 26 个项目，
输出成本与收益分解以及最优性的上界证据。

## 使用

```sh
go build -o budget-solver .
./budget-solver                    # 运行内置演示实例（demo.json）
./budget-solver -input case.json   # 求解自定义实例
go test ./...                      # 含与暴力枚举对拍的随机测试
```

## 输入格式（JSON）

```json
{
  "budget": 60,
  "projects": [
    {"id": "ML", "name": "推荐模型", "cost": 12, "value": 16,
     "requires": ["DATA"], "excludes": ["APP"]}
  ],
  "synergies": [
    {"a": "DATA", "b": "ML", "value": 8},
    {"a": "LAB",  "b": "CORE", "value": -6}
  ]
}
```

- `requires`：前置项目，选中本项目必须连带选中其整个前置闭包。
- `excludes`：互斥项目（自动对称化），二者不可同时选中。
- `synergies`：两个项目**同时**选中时的额外收益，允许为负（负协同）。
- 项目数 ≤ 26；金额绝对值 ≤ 2^40（保证上界计算整数不溢出）。

## 模型与算法

设 x_i ∈ {0,1}，最大化

    Σ_i v_i·x_i + Σ_{i<j} s_ij·x_i·x_j

约束：`Σ c_i·x_i ≤ B`、`x_i ≤ x_j`（i 前置 j）、`x_i + x_j ≤ 1`（互斥）。

采用**分支定界**精确求解：

- 分支顺序按“乐观密度”（固定收益 + 正协同之和）/ 成本降序；
- 选中分支自动连带前置闭包，并做互斥与预算可行性检查；
- 预处理把“前置闭包超预算”或“闭包内部互斥”的项目标记为永不可选。

**上界**（用于剪枝与最优性证据）对当前节点取松弛：

1. 未决定项目的边际收益（含对已选项的协同）取正部，
   在剩余预算下做背包 LP 松弛（分数件向上取整，128 位整数运算防溢出）；
2. 未决定项目之间的协同只累加正部——负协同不会削弱上界的有效性。

搜索穷尽后，所有被剪子树的上界均不超过最优解收益，即构成全局最优的证明；
报告中给出根节点上界、节点数与剪枝数作为证据。

## 为什么协同收益不能摊成项目固定价值

把 s_ij 预先分摊进 v_i、v_j 会把二次目标伪造成线性目标：
分摊后即使只选中 i 也会计入部分协同，导致估值失真、最优解改变。
本求解器全程把协同保存在对称矩阵 `syn` 中，只有当一对项目**同时**
进入选中集合时才计入目标；上界同样以成对形式估计，保证界有效。
输出报告单独列出每条被实现的协同（含负协同）及其合计，与固定收益分列。

## 输出内容

- 选中项目清单：ID、名称、成本、固定收益，及成本/固定收益合计；
- 协同收益分解：每一对实际实现的协同及其正负值、合计；
- 总成本（含预算剩余）与总收益（固定 + 协同）；
- 上界证据：根节点上界、最优解收益、搜索/剪枝节点数与最优性结论。
