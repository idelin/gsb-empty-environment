# planner

Go 规划库，包含两个互补的规划器。

## caps：确定性能力规划（最多 12 个布尔能力）

- 状态是最多 12 个布尔能力的位掩码（`caps.Set`）。
- 动作带前置条件（`Require` 必须持有、`Forbid` 必须缺失）与效果
  （`Add` 授予、`Del` 撤销；撤销优先于授予，能力可反复得失——非单调）。
- `caps.Solve` 用 BFS 求到达目标且不进入禁用状态的**最短**动作序列；
  初始已满足目标时返回空序列。解中附带逐步能力集 `States`。
- `caps.Replay` 是独立重放核对器：逐步检查前置条件、禁用状态、
  撤销语义与最终目标，用于验证 BFS 的解（含非单调撤销）。

## belief：部分可观测规划（有限世界 + 观察）

- 给定有限世界集合，每个世界产生一个观察；观察相同的世界不可区分，
  因此**相同观察历史必须选择相同动作**。
- 动作结果可以是非确定性的，执行后才通过新世界的观察揭晓。
- 目标：所有可能的世界都**安全**到达目标世界（不得进入 `Unsafe` 世界）。
- `belief.Solve` 在有限信念状态空间上做精确值迭代（完整信念状态搜索），
  输出**最坏步数最短**的策略树；不可解时返回不可解信念状态集。
- `belief.Verify` 独立重放策略树，核对动作可执行性、观察分支完备性、
  安全性与目标达成，并返回实际最坏步数。

## 运行

```sh
go test ./...      # 两个规划器及其核对器的测试
go run ./cmd/demo  # 演示：逐步能力集 + 策略树
```
