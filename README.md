# 可擦除合规数据脱敏证明器（Erasable Compliance Prover）

面向隐私法规（GDPR 被遗忘权 / 个保法删除权）的可验证擦除存证系统。
客户记录以 Merkle 树存证；客户注销时，叶子被重写为携带**删除签名**的
`EraseMarker`，树根平滑演进，其余未注销客户的存证路径依然完全有效可验。

## 核心机制

- **注册存证**：`leaf = H("leaf/v1" | canonical(record))`，树上只留哈希，明文仅存于易失存储。
- **签名擦除**：合规官用 Ed25519 私钥对删除意图 `H 意图 = ("GDPR-ERASE/v1" | treeId | idx | 原叶哈希 | 时间)` 签名；
  叶子重写为 `EraseMarker = H("erase/v1" | idx | 原叶哈希 | 签名)`，根沿路径重算平滑演进。
- **物理擦除**：明文 `Buffer` 先原地清零（`buf.fill(0)`，同步破坏字符串内容）再切断引用，原数据不可恢复。
- **独立审计**：`verifyErase` 仅凭公开回执核验「删除签名有效 + 标记哈希在当前根上」，无需接触任何明文。
- **存证演进**：Merkle 树任何叶子变更都会使旧路径失效，因此擦除回执携带被擦除节点的
  逐层哈希链 `levelHashes`；其余客户凭公开回执即可用 `updateInclusionReceipt`
  把旧存证**本地重放**为新根下的有效路径，无需再次访问树。树也可随时重新出具存证。

## 运行要求

Node.js ≥ 23.6（原生运行 TypeScript，零依赖，仅用 `node:crypto` / `node:test`）。

```bash
npm run demo   # 运行样例
npm test       # Node.js 内置测试
```

## 代码结构

- `src/crypto.ts` — 域分离哈希、擦除标记构造、确定性 JSON 序列化
- `src/merkle.ts` — Merkle 树核心：根计算、存证路径生成/验证、叶子原地重写
- `src/erasableTree.ts` — 证明器主体：注册 / 擦除 / 存证出具 / 存证演进 / 静态核验
- `src/demo.ts` — 端到端运行样例
- `test/erasableTree.test.ts` — Node.js 内置测试（11 例）
