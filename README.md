备份服务把一个路径恢复为新文件时，旧进程仍可能持有原文件的句柄。给 TypeScript 移动存储宿主写可导入的保护类验证包。调用方提供有限的操作偏序图（至多 24 个事件），路径、卷、文件内容和句柄均用编号表示。创建和原子替换分配以事件编号标识的新对象并采用卷默认类，硬链接增加路径别名，改类影响同对象全部别名。打开句柄固定对象；取消链接或替换路径都不撤销句柄。锁屏后 complete 类禁止一切读，untilLock 类只允许本次锁屏之前已打开且仍有效的句柄读，public 类始终允许。解锁后再锁屏按新的锁屏时点判断。复制经句柄读源，目的对象按目标卷默认类创建，源内容的保密标签随副本保留。事件的路径、句柄或权限前置条件失败则记录拒绝，零副作用，后续事件继续。检查每个满足偏序的执行前缀，是否存在锁屏后成功读出标为 complete 的内容。返回最短违规前缀，同长按事件编号字典序取最小；安全结论附可单独验收的状态闭包证明，检查器须核对每个已启用事件。预算耗尽返回未知。用全排列核对小图，另测独立文件上的二十四次操作、同一路径的不同对象、二次锁屏、同对象跨路径改类，以及删掉一条可行边的伪证明。
