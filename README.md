复制组希望在撤掉一批机架前判定哪些读请求仍可放行。用 Go 写一个嵌入读路径的包。请求冻结任期、配置世代、唯一请求号、提交上限和本机应用位置；同一成员重复确认只保留最高持久位置，其他请求的确认不可复用。配置由若干可重叠的加权成员组组成，每组都须达到自己的权重门槛。每个故障域下线会同时移除其成员集合，域可重叠，任意至多 k 个域都可能下线。返回在所有允许故障下仍满足每组门槛的最大可读位置，受两个冻结上限约束；零位置有效，无法证明须单独表示。给出能推翻下一档确认位置的故障域集合与失守组（若仅被上限截断则说明原因）。支持 48 域、k≤8、最多 256 成员；不能物化全部域组合，展示能剪掉被支配分支的精确搜索。组总权重可超过 uint64，比较不能回绕。成员关系和确认顺序均不得影响答案。用独立穷举参照核对随机小例及见证；构造逐个挑最大域会漏掉致命组合、跨组共享成员且同域重复覆盖的回归例。
