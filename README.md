# 布尔规则修复器（boolean-rule-fixer）

给定一组布尔变量（最多 25 个）及其当前取值，以及若干条 **前提蕴含结论** 的规则
（`p1 ∧ p2 ∧ … ∧ pk → c`，前提为字面量合取、结论为单个字面量），在只允许翻转
「可修改变量」且每次翻转都有成本的前提下，求使全部规则成立的 **最低成本修复方案**。

- 有解：输出最低成本、每处改动，以及每条规则在修复后赋值下的逐条复核。
- 无解：输出由不可修改（固定）变量导致的 **最小冲突核心**（核心中再删去任意一条规则即恢复可解）。

## 运行环境

- Node.js ≥ 22.18（或 ≥ 23.6），可直接运行 TypeScript（类型擦除）。
- 可选：`npm install` 后可用 `npm run typecheck` 做完整类型检查。

## 使用方法

```bash
node src/cli.ts <输入文件.json>     # 人类可读报告
node src/cli.ts --json <输入文件>   # 机器可读 JSON
cat input.json | node src/cli.ts -  # 从标准输入读取
```

退出码：`0` 修复成功，`1` 无解，`2` 输入错误。

## 输入格式

```json
{
  "variables": ["a", "b", "c"],
  "assignment": { "a": true, "b": false, "c": false },
  "modifiable": { "b": 2, "c": 1 },
  "rules": [
    { "name": "r1", "premise": ["a", "!b"], "conclusion": "c" }
  ]
}
```

- `variables`：变量名列表，最多 25 个。
- `assignment`：每个变量的当前布尔值（必须覆盖全部变量）。
- `modifiable`：可修改变量及其翻转成本（非负数）；未列出的变量为固定变量，不可翻转。
- `rules`：规则数组；`premise` 为字面量数组（合取，可为空表示恒真），
  `conclusion` 为单个字面量；字面量用 `"x"` / `"!x"` 表示正负形式；`name` 可省略（自动命名 r1、r2…）。

规则语义：前提全部成立而结论不成立时，规则被违反。

## 输出说明

### 修复成功

- 最低成本与改动列表（变量、原值 → 新值、单次成本）。
- 每条规则的复核：前提各字面量取值、结论取值、是否满足，并标注变量是「固定 / 已翻转 / 可改」。

### 无法修复

- 最小冲突核心：一组规则，即使任意翻转可修改变量也无法同时满足；
  核心通过删除法极小化，删去其中任意一条即恢复可解。
- 核心涉及的不可修改变量及其当前取值，即冲突根源。

## 算法

- 分支限界（branch-and-bound）枚举可修改变量的翻转组合：优先探索「不翻转」分支，
  用当前最优成本剪枝；每条规则维护增量计数（前提已假数 / 前提未定数 / 结论状态），
  规则被确定违反时立即回溯。变量按规则出现次数降序分支（fail-first）。
- 无解时用删除法提取最小不可满足核心，存在性判定复用同一搜索（找到即停）。
