# 分层仲裁多数派决策引擎

多数据中心分级 Quorum 仲裁器（TypeScript，零依赖，Node.js ≥ 23.6 原生类型擦除运行）。

## 设计

- **分级 Quorum**：每个区域（IDC）拥有独立权重与本地多数派门限。区域内部赞成节点数达到本地门限时，才将其权重计入全局仲裁；全局门限为 `floor(总权重/2)+1`。
- **动态降级**：主中心不可达时自动切换为 `degraded` 降级拓扑，门限仅基于仍可达区域的权重重算，避免跨区网络闪断引起全局不可用。
- **纪元围栏（Epoch Fencing）**：每次拓扑切换推进纪元；主中心恢复时必须出示严格更高的纪元才能接管，旧纪元的决议一律被拒绝应用，保证无状态冲突。
- **签名证据**：每张选票由投票区域用 Ed25519 私钥签名（含纪元、决议、拓扑、投票者），仲裁结果携带全部选票、公钥与 SHA-256 证据摘要，任何第三方可独立验证，篡改即失效。

## 结构

- `src/types.ts` — 选票、签名投票、仲裁结果、接管证据等类型
- `src/region.ts` — 区域：本地多数派门限、Ed25519 投票签名
- `src/arbiter.ts` — 分级仲裁器：拓扑切换、纪元围栏、证据验证
- `test/arbiter.test.ts` — Node.js 内置测试（node:test）
- `examples/demo.ts` — 验收场景端到端运行样例

## 运行

```sh
npm test     # node --test "test/*.test.ts"
npm run demo # node examples/demo.ts
```

## 验收场景（examples/demo.ts）

1. IDC-A 权重 2（主中心），IDC-B/C 权重各 1，正常门限 3，全票 4 达成决议；
2. A 失联 → 自动降级、纪元 +1，B+C 以权重 2/2 达成临时多数派；
3. A 恢复，出示更高纪元（3）重新接管，拓扑恢复 hierarchical；
4. 纪元围栏：失联前与降级期的旧纪元决议均被拒绝应用，新纪元决议正常接受，无状态冲突；
5. 篡改决议内容后证据验证失败。

✔ 降级拓扑（degraded）：主中心失联

✔ 区域本地多数派门限
