# 法定集合相交性检查工具（quorum-check）

判断两组法定集合（quorum）族是否满足相交性：

- **读/写相交性**：任意读集合与任意写集合必相交；
- **写/写相交性**：任意两个写集合必相交。

- 成立时，返回**证明**（大小论证或带统计信息的完备搜索证明）；
- 不成立时，返回**字典序最小的不相交见证** `(A, B)`。

节点数设计目标 `<= 20`。集合族用**压缩描述**表达：原子为"至少选某组若干个"
（`atLeast k of G`），可用 `all`（且）/ `any`（或）任意嵌套组合，均为单调公式。

## 运行环境

需要能直接运行 TypeScript 的 Node：

- Node `>= 23.6`：直接运行（本仓库在 v23.9 上验证）；
- Node `22.6+`：加 `--experimental-strip-types` 标志。

```bash
node src/cli.ts examples/majority.json          # 人类可读报告
node src/cli.ts examples/majority.json --json   # 机器可读 JSON
node --test test/quorum.test.ts                 # 运行测试
```

退出码：`0` = 所有检查成立；`1` = 找到不相交见证（反例）；`2` = 用法/输入错误。

## 输入格式

```json
{
  "nodes": 5,                                  // 或节点名数组 ["a", "b", ...]
  "read":  { "atLeast": 3, "of": "*" },        // 可选；缺省时只检查写/写
  "write": { "atLeast": 3, "of": "*" }
}
```

规格（`read` / `write`）为单调公式，三种形式可任意嵌套：

| 形式 | 含义 |
| --- | --- |
| `{ "atLeast": k, "of": ["n1", "n2", ...] }` | 集合与该组节点的交集大小 `>= k` |
| `{ "atLeast": k, "of": "*" }` | 同上，组为全部节点（即集合大小 `>= k`） |
| `{ "all": [spec, ...] }` | 全部子公式成立（且） |
| `{ "any": [spec, ...] }` | 任一子公式成立（或） |

示例见 `examples/`：多数派（`majority.json`）、3x3 网格 quorum
（`grid.json`，写集合 = 含某整行且含某整列）、反例（`counterexample.json`）。

## 字典序定义

- 集合表示为按**输入节点顺序**排列的有序列表，按字典序比较，前缀较短者更小：
  `[] < [a] < [a,b] < [a,c] < [b]`（设输入顺序为 a, b, c）。
- 集合对 `(A, B)` 先比较 `A`，`A` 相同再比较 `B`。

## 算法

不是"枚举全部子集再筛选"，而是**带可靠剪枝的字典序搜索**：

1. **大小论证快速通道**：先用分支限界求最小法定集合大小 `minA`、`minB`。
   若 `minA + minB > n`，由鸽巢原理直接得证（多数派、网格等经典 quorum
   都走这条路）；若某族为空（规格不可满足），命题空虚成立。
2. **完备搜索**：大小论证不足时，枚举器按字典序生成候选 `A`，沿途对单调公式做
   三值求值（必真/必假/未定）：部分赋值一旦使公式**必假**，整棵子树被剪掉；
   同时维护"B 的可行视角"（`A` 已占用节点不可用），`B` 无可行完成时同样剪枝。
   第一个找到的不相交对即为字典序最小见证；搜索穷尽而无见证即构成完备性证明，
   返回的统计（展开节点数、剪枝次数、检查候选数、最大深度、耗时）即证明统计。

正确性由两类测试保障（`test/quorum.test.ts`）：经典场景（多数派、网格、Fano
平面等）的精确断言，以及 600+ 随机规格上与暴力枚举预言机的交叉验证
（存在性、字典序最小性、最小集合大小均一致）。

## 复杂度

`n <= 20` 时所有检查均在亚秒级完成。搜索最坏情况仍是指数量级（问题本身
coNP 难），但单调性剪枝 + 大小论证使实际输入（阈值/分组描述）几乎瞬时完成。
