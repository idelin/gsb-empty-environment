编译器中端执行常量传播时，若先做简单数据流传播再删死分支，往往无法发现依赖循环或死分支互相锁定的常量；而 Wegman-Zadeck 稀疏条件常量传播（SCCP）乐观地将所有 CFG 边初始置为不可执行、所有 SSA 值置为 `Top`，在格上同步传播边可达性与常量值——关键在于对 `Phi` 节点求值时只能合并**当前已标记为可执行**的入边对应值（忽略不可达入边，否则死分支里的非常量会把 `Phi` 污染成 `Overdefined`！）。为编译器后端交付可导入的 Go SSA 构造与 SCCP 优化包。输入为结构化三地址码控制流图（基本块列表、前驱/后继边、允许含不可达死块、自然循环、不可约多入口循环与自环；指令支持常量、算术/比较/位运算、条件分支、无条件跳转、输入参数与返回）。规则：1）计算支配树（Dominator Tree）与支配边界（Dominance Frontier），在保留语义的前提下仅在必要汇合点插入最小 `Phi` 节点并完成全图 SSA 重命名（对未定义读给出显式 `Undef`）；2）在 SSA 上执行完整的双工作表（CFG 边工作表 + SSA 使用边工作表）SCCP 格迭代（`Top` -> `Const(v)` -> `Bottom`），正确处理除零不错误折叠、已知条件分支仅标记目标单边可执行、`Phi` 仅汇聚可执行入边（注意：当某新入边后来变为可执行时必须重排对应 `Phi` 重新求值！）；3）依据收敛结果将常量指令替换、把常量条件分支降级为无条件跳转、裁剪全部不可执行死块并清理被删前驱对应的 `Phi` 入项（单入项 `Phi` 自动消除）；4）内置 IR 解释器对照优化前后在所有测试输入上的返回结果与副作用序列。验收覆盖不可约双入口循环支配边界构造、带循环的常量条件分支（仅 SCCP 乐观迭代能折叠，普通悲观传播折叠不了！）、死分支含输入参数不污染 `Phi`、除零保护不误折以及优化前后解释执行逐输入等价。
