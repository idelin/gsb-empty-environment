# rect_diff — 整数网格矩形布尔差与最优矩形分解

对整数网格（最大 12×12）计算 `保留矩形集 ∪` 减去 `排除矩形集 ∪` 后的区域，
输出**不重叠矩形分解**，目标依次为：

1. 矩形数量最少（由穷举精确搜索证明，而非扫描线启发式）；
2. 数量相同时，排序后的矩形列表字典序最小。

## 构建

```sh
g++ -std=c++17 -O3 -o rect_diff rect_diff.cpp
```

## 输入（stdin）

```
W H          # 网格尺寸，1..12
K            # 保留矩形个数，随后 K 行
x1 y1 x2 y2  # 半开区间 [x1,x2) x [y1,y2)，越界自动裁剪，顺序自动交换
E            # 排除矩形个数，随后 E 行
x1 y1 x2 y2
```

## 输出

- 区域栅格图与单元数
- 搜索记录：分数装填下界、贪心不相容单元集下界、每个 k 的可行性及搜索节点数
  （k 从下到上逐一判定，所有更小的 k 均被穷举证否，据此证明最少性）
- 最少矩形分解（字典序最小）
- 重建校验：输出矩形两两不相交、并集逐单元等于 保留\排除

## 方法要点

- 候选集 = 区域内全部轴对齐单元矩形（12×12 时最多 6084 个）。
- 精确判定 `canPartition(S, b)`：区域 S 能否用 ≤ b 个矩形划分。
  剪枝：面积上界、分数装填下界（MWT 求得的静态权重，任意子区域有效）、
  贪心两两不相容单元集下界、预算 1 时哈希直判、全状态记忆化。
- 字典序最小化利用不变量：剩余区域划分中字典序最小的矩形必覆盖
  (x,y) 字典序最小的剩余单元，逐位贪心 + 可行性判定即可。
