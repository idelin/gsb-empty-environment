C++17 插件宿主在回调之间传递固定对象的借用凭据。给测试宿主写可嵌入的内存安全检查包，仅模拟事件，绝不解引用输入地址。对象由分配号、不可回绕的代次及半开字节区间标识。共享借用可在相交区间共存，独占借用只能从仍活跃的父借用派生，派生期间仅冻结父借用对应的子区间；分离的两段仍可各自派生。释放子借用才恢复父区间；取消一棵借用子树须使其中所有旧凭据失效，不得解冻仍被其他子树覆盖的部分。钉住对象后，迁移到新地址必须拒绝，除非所有借用已归还、钉住令牌已由其所有者撤销。释放后即便同址重新分配，旧凭据仍不能访问。一次回调可提出一批操作，任一步失败须报告最早冲突及其尚存的借用来源，整批状态原样保留。写一个按字节展开的参考模型，在小对象上枚举嵌套区间、兄弟释放顺序、跨代重用和批中失败，对比每一步的准入结果与失败后的可用区间。
