主机在密钥环之间搬迁服务凭据时，同一个密钥对象可同时经用户环、会话环和临时委托环被持有。用Go给内核策略测试宿主写可导入的权限验收库。各环的链接可限制允许传递的权限位、所属用户命名空间和有效代次；循环链接合法，同一密钥的两条不同路径不能把一路的持有者身份和另一路的操作位拼成新的权利。输入旧新两组有条件的环链接、用户命名空间映射和明确允许新增的操作集合，求哪些合法命名空间映射下会新增未获批的读、改写或转授能力。映射表按互不重叠的UID区间平移，缺项按未映射处理，不能当作根用户。区间用64位端点，给出完整的异常区域与一条逐边可复算的最短授权路径。用小UID域逐用户逐路径对照重复持有、范围断点、密钥代次更换和两条局部路径各缺一项权限。
