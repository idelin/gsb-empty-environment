# safearchive

一个仅使用 Go 标准库实现的安全归档工具（自定义二进制格式 SAR1），
覆盖打包、校验与安全解包。

## 格式（SAR1，全部小端）

```
magic   : 8 字节  "SAR1\x00\x00\x00\x01"
count   : uint32  条目数（上限 65536）
每个条目:
  pathLen : uint16  路径字节数（1..1024）
  path    : []byte  UTF-8，'/' 分隔的相对路径
  size    : uint64  内容长度（单文件上限 1 GiB，总量上限 4 GiB）
  digest  : 32 字节 内容的 SHA-256
  content : size 字节
```

## 安全属性

- **先验证长度再分配**：所有长度字段（条目数、路径长、文件大小）在
  任何内存分配之前对照硬上限校验。
- **解码不执行宿主代码**：格式为纯长度前缀字节布局，显式边界检查解析，
  不使用 gob/反射等可触发型构造的机制。
- **路径规范化**：`NormalizePath` 拒绝空路径、绝对路径、`..` 逃逸、
  反斜杠、NUL、非 UTF-8，并归一化为根内相对路径。
- **摘要与大小校验**：每个条目的 SHA-256 与声明大小在解码时全部验证。
- **重复路径不覆盖**：编码、解码、解包三层均拒绝重复路径；写文件使用
  `O_EXCL`，任何情况下不覆盖已有文件。
- **防路径穿越与符号链接逃逸**：`secureJoin` 逐组件拒绝 `..` 与符号链接，
  并在拼接后做根包含性复查；目标父目录为符号链接时拒绝解包。
- **先暂存再发布**：先解到目标旁的 `.sar-stage-*` 暂存目录，全部成功后
  才 `rename` 发布；任何失败都清理暂存目录，正式输出不留部分结果；
  目标已存在（含符号链接）时拒绝发布。

## 用法

```sh
go build -o safearchive .
./safearchive pack   out.sar <文件或目录>...
./safearchive verify out.sar
./safearchive unpack out.sar <目标目录>   # 目标目录必须不存在
```
