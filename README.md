# 密钥更新确认丢失模型

双方完成新密钥安装但确认丢失时，重试路径不能恢复已销毁旧钥。写供Go协议宿主调用的状态探索包，端点动作含派生、安装、确认、销毁及数据收发，消息可丢失或重复；检查每个已交付明文对应双方共同认可的密钥代。至多两次轮换，输出最短违例轨迹，用显式小状态参考核对。

## 用法

```sh
go run ./cmd/keyrot   # 打印最短违例轨迹
go test ./...         # 轨迹回放、参考核对、修复变体验证
```

宿主调用：`netsec.Explore(netsec.DefaultConfig())` 返回 `Result`，
其中 `Violation.Trace` 为最短违例轨迹（每步含名称与后继状态）；
`netsec.Replay` 可重放轨迹校验合法性；`netsec.RefCheck` 提供独立的
显式小状态参考实现，与 `CountReachable` 交叉核对可达状态数与违例深度。
