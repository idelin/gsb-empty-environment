# KTLS换钥边界复用了旧序号

长连接把TLS记录卸载给内核，KeyUpdate时若用户态密钥代次与KTLS记录序号切换不原子，攻击者可重放边界记录或让旧密钥解密新序号。请实现供C++20 TLS终止器调用的可导入换钥协调组件，驱动接口暴露当前发送/接收record sequence、安装密钥及完成栅栏。每个方向独立绑定连接代次、traffic secret generation、精确序号和未决记录；收到或发送KeyUpdate后先冻结该方向新记录，在所有旧代记录完成且回读序号一致时安装新key/IV并从规范序号继续，失败关闭连接。异步完成、半双工更新、重复KeyUpdate和连接fd复用不得越代提交；序号将溢出时必须终止。用可暂停驱动交错边界记录、旧完成迟到、双向同时更新、安装失败及合法连续记录，核对每个密文只属于唯一密钥代次。
