光交换机每隔 T 个整数时隙复用同一张交叉连接日历。给控制面的变更审批服务交付可导入的 Go 包，由审批接口传入预约变更，校验或计算最小修复日历：每条预约连接一个输入端口和一个输出端口，窗口用环上起点和长度描述；窗口内每个时隙都必须连通，窗口外允许提前建路和延迟拆路，但不能占用没有授权给该预约的时隙。端口从对端 a 切换到 b 时，中间必须连续空出 g(a,b) 个槽，切换代价有方向，输入端和输出端分别给表，首尾相接也算一次切换。相邻预约若为同一对端可连续持有而不需空槽；每时隙的整机连线必须构成匹配。运维允许丢弃带优先级的整条预约，先使丢弃总权重最小，再使整周期持有但不承载预约的端口对时隙数最少，最后按预约 ID 给出字典序最小的丢弃列表。返回区间压缩的连接与保护空槽证书；另写核对器，只读原预约和证书验证可行性与两项数值，不调用求解器。T 可达 10^12，一个冲突分量最多十四条预约，各端口至多八个窗口，禁止逐时隙展开；同一物理端口即使没有窗口重叠也可能因保护时间产生冲突。小周期用逐槽穷举作对照，覆盖跨零切换、旧路延长能消除一次不必要的重建、分别看输入输出均可排但无法拼成全局匹配的情况。
