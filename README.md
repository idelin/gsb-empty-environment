# statewait

状态等待库：等待方注册任意谓词，更新方只替换状态，无需了解等待者。

## 保证

- **原子检查与登记**：`Wait` 在持有锁的情况下先检查谓词、不满足则登记，
  `Update` 持同一把锁提交新状态，状态变更不可能落在检查与登记之间，
  因此不存在"检查后登记"导致的永久休眠。
- **恰好一次返回**：唤醒（从注册表删除 + 向缓冲 channel 发送）与取消
  （从注册表删除）由同一把锁串行化，一次等待只会以满足的状态或
  context 错误之一返回，且恰好返回一次。
- **可验证的可见性**：每次提交追加一条带单调版本号的事件历史，
  成功的 `Wait` 返回其观察到的版本，调用方可对照历史验证结果
  对应真实可见的状态。

## API

- `New[T](initial)`：创建存储，初始状态记为版本 0。
- `Update(fn func(T) T) Result[T]`：提交新状态并唤醒谓词满足的等待者。
- `Wait(ctx, pred) (Result[T], error)`：阻塞到谓词满足或 ctx 结束。
- `Get` / `History` / `PendingWaiters`：查询当前状态、事件历史、等待者数。

注意：`Update` 的 `fn` 与等待者的 `pred` 在锁内执行，必须快速、
不阻塞、不得回调 Store。
