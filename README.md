ZNS 固态盘限制同时处于打开状态（Open）的 zone 不超过 MOR、处于活跃状态（Open+Closed）的不超过 MAR；如果为了腾出打开槽而把未写满的 zone 提前 Finish，其剩余空白页会全部浪费成填充写放大。给闪存转换层交付可导入的 Go 调度求解包。设备有 Z 个 zone（Z≤7），每区容量 C 页，给定 MOR≤MAR≤Z，以及按序到达的一批逻辑页写入请求（含逻辑地址 LBA 与温度组；同一 LBA 再次写入会使旧物理页失效，且任一时刻空区数不足时可对已满且含失效页的 zone 执行 GC 搬移存活页并 Reset，但 GC 写入同样消耗打开区槽位）。动作包括向打开 zone 追加、Close（释放 MOR 但保留 MAR）、Reopen、Finish（填充剩余页并释放 MAR 与 MOR）以及对满区 GC+Reset。求完成全部请求序列使总物理写入页数（含正常写、GC 存活页搬移与 Finish 填充空白页）最小的精确操作序列，并列按操作步数最少，无解报告空间与配额死锁。验收用小状态空间最短路搜索对照最小总物理写入页数，覆盖 MOR<MAR 时 Close+Reopen 避免提前 Finish 填充、多热流交替写触发最优关闭选择、GC 与前台写争抢唯一打开槽，以及有效数据占满全盘导致死锁。
