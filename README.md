# 连续丢失PCM时重复上一周期会产生机械音，恢复帧又可能突变

连续丢失PCM时重复上一周期会产生机械音，恢复帧又可能突变。写供Go播放宿主调用的预测补音包，仅由最近N个真实样本估计自相关r[k]=sum(x[i]x[i-k])/N，通过Levinson-Durbin求P阶预测器，反射系数绝对值达到1即截断到前一稳定阶；在给定周期范围对预测残差找最高归一化相关，超过阈值用周期残差，否则用注入随机源的零均值噪声，能量匹配真实残差。预测合成状态随补音前进但统计窗不能加入补音，连续缺口按输入指数衰减；恢复时将真实与预测各延续L样本按线性权重交叉混合，保持精确样本数。双声道共用周期判定而分别保留预测器。用已知稳定AR信号、静音、左右反相及任意分块核对预测残差、稳定性、噪声可复现与恢复边界。
