# grayquant — 字典序灰度量化求解器

将灰度直方图压缩为 K 个整数代表值（调色板），按字典序精确优化：

1. **先**最小化最大绝对误差 `M = max over pixels |gray - rep|`
2. **再**在所有满足 `max误差 ≤ M` 的方案中，最小化加权平方误差 `SSE = Σ w[g]·(g - rep[g])²`

不是"先求均方误差再附报最大误差"——两者可能冲突。例如直方图
`w = [1, 0, 100, 100, 0, 1]`、`k = 2` 时，MSE 最优解为
`[0..2][3..5]`（SSE=8，但 max误差=2），而字典序最优解为
`[0..2][3..5]` 之外唯一满足 max误差=1 的分组（SSE=202，max误差=1）。
本求解器输出后者。

## 算法（精确动态规划）

灰度级 `0..n-1`，权重 `w[i]`，分成 `k` 个连续段。空灰度（`w[i]=0`）
不产生误差，被所在段自然吸收，不强制分组。

- **阶段一**：`f[t][i] = min over j of max(f[t-1][j], segErr(j,i-1))`，
  其中段 `[a,b]` 的最小可达最大误差为 `ceil((hi-lo)/2)`（`lo/hi` 为段内
  首个/末个非空灰度）。得全局最优 `M = f[k][n]`。
- **阶段二**：在每段 max误差 `≤ M` 的约束下做 SSE 最小化 DP。
  段 `[a,b]` 的可行代表值区间为整数 `r ∈ [hi-M, lo+M]`（空集则该段
  不可行、跳过），SSE 最小的整数 `r` 为加权均值取整后 clamp 到该区间。
- 回溯得到分组边界与调色板。

复杂度 `O(k·n²)`（`n=256` 时约千万级操作），段代价经前缀和 `O(1)` 计算，
全程整数运算，无浮点误差。

## 核验

`brute.go` 提供暴力枚举（枚举所有连续划分 × 每段所有整数代表值，
按 `(max误差, SSE)` 字典序取优）。`solver_test.go` 中
`TestAgainstBruteForce` 用 300 组随机小直方图（含空灰度）对拍 DP 与
暴力结果；`TestLexicographicNotMSE` 锁定上述"MSE 优先会出错"的用例。

## 用法

```sh
go build -o grayquant .
# 输入：每行 "count"（按灰度顺序）或 "level count"；# 为注释
./grayquant -k 8 histogram.txt
./grayquant -k 2 -levels 6 -verify < small.txt   # 小规模可暴力核验
```

输出：最优 max 误差、加权 SSE，以及每组的分组边界、调色板代表值、
像素数、组内 max误差 与 SSE。
