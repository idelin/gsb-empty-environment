GPU 内核后端要把全局内存里的矩阵块装进共享内存，再按线程碎片取出。给后端交付可嵌入的 C++20 布局组件。线程束 32 线程，分八组，每组四线程。按 PTX 中 16×8×16 半精度矩阵乘的布局，A 操作数每线程四个寄存器：前两个在组号行，后两个在组号加八行，列为组内线程号的两倍加寄存器序号的奇偶；B 操作数两个寄存器，行为组内线程号的两倍加奇偶，列为组号；累加器四个寄存器行列规则与 A 相同，列宽为八。共享内存按行主序存放并以 128 字节为周期做交织：元素列号与行号低三位左移三位的结果异或。组件输出每个线程四次 128 位读取的地址，以及由寄存器反推行列的逆映射。验收核对往返恒等、三十二个线程的地址两两落在不同存储体，并给出线程零到三十一的完整对照表。
