为档案服务实现支持多级授权与时间窗口耦合的权限控制，给 Go 验权宿主写可导入的委托收窄证明库。每份签名委托绑定动作、租户与规则列表，每条有序规则同时包含路径模式（单段与任意深度通配）、有限对象标签谓词以及有效期区间 `[Start, End)`，按最后匹配生效；对象标签受互斥、必选与蕴含约束限制。支持深度大于等于 3 的委托链，其中每一层可指定 `k-of-n` 多父门限法定人数（允许来自不同父组合的 `k` 个父委托交集之并，但子委托自身的显式拒绝不得被任意合法父路径的末尾允许规则绕过）。交付包含关系判定与独立核验组件：证明成立时输出覆盖任意长路径与时间分段的状态机证书；若子委托放宽权限或存在未闭合法定人数，须返回段数最短、同长按字典序最小的 `(path, tags, timestamp)` 反例，且报告的 `FailedParent` 或 `FailedQuorum` 归因必须严格匹配该最小反例。用小字母表与多时段样本对照单对象解释包验证三层链、门限交并及归因一致性。
