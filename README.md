IPSec VPN 网关实现 IKEv2（RFC 7296）Child-SA 协商与并发重密钥（Rekey）时，若流量选择器（Traffic Selector：`TSi`/`TSr`）窄化算法遗漏多段 IPv4/IPv6 与端口/协议笛卡尔区间交集边界，或双端同时发起 `CREATE_CHILD_SA` 重密钥时未按最小 Nonce 字典序正确裁决胜出方，攻击者或异常对端可导致流量选择越权放行（如将单端口策略拓宽为全端口）或造成旧 SA 残留与双活黑洞。为 Go 网络安全宿主构建可导入的 IKEv2 流量选择器精确区间求解与并发重密钥状态机包，严禁联网。组件完整实现 RFC 7296 §2.9 流量选择器集合代数：每条选择器由 `(protocol, [portStart..portEnd], [ipStart..ipEnd])` 构成（支持 IPv4 32 位与 IPv6 128 位闭区间及通配协议 0），禁止逐地址/逐端口枚举，必须以精确二维区间求交计算“发起方提议 ∩ 响应方本地策略”，返回最小规范化的不相交允许子集；并严格核验响应方返回的窄化结果必为发起方提议的数学子集（否则以 `TS_UNACCEPTABLE` 立即拒绝，拦截恶意扩权响应）。状态机同时管理 IKE_SA 与多条 Child_SA 生命周期：按 RFC 7296 §2.25 精确处理双端同时 Rekey 碰撞——比较四组 Nonce（`Ni_1/Nr_1` 与 `Ni_2/Nr_2`）中全局最小字节串所属的冗余 SA 并主动发起 `DELETE` 清理，确保任何乱序/并发报文下不会提前删除唯一活跃 SA 或遗留僵尸 SPI；严格执行消息 ID 滑动窗口防重放与 NAT-T 端口漂移源校验。附小地址/端口空间全枚举交叉验证区间窄化零误差与并发 Rekey 碰撞状态机测试。
