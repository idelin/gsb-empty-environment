# 克隆恢复后的随机源重播种

服务在虚拟机快照恢复或 fork 之后，各个克隆里的随机数生成器状态完全相同，攻击者对两个克隆各取一次会话令牌，就能得到相同的值，或据此预测另一个克隆的输出。为Go业务进程写可嵌入令牌签发路径的随机源包装包：内部是计数器模式的确定性生成器，种子由调用方注入的熵源提供；每次取数前读取调用方给的世代标识（进程号与虚拟机世代 ID 的二元组）和单调时钟，二元组与上次不同，或时钟比上次回退，就先用“旧状态 ‖ 新熵 ‖ 世代标识 ‖ 时钟读数”混合后重播种，重播种期间并发调用者阻塞到完成，熵源失败时返回错误而不是继续输出；重播种前已缓冲但未使用的字节要丢弃。用两个克隆共享同一熵源输出回放、世代变化、时钟回退、熵源失败和并发取数验证两份输出互不重叠。
