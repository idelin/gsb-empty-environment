# OpenPGP签名子密钥回签与归属

OpenPGP 的签名子密钥必须由子密钥自己对主密钥签一份回签，否则攻击者可以把受害者公开的签名子密钥绑定到自己的主密钥上，再声称受害者的签名出自自己。给Go密钥环组件实现可导入的子密钥归属校验包，输入主密钥与子密钥的公钥材料、绑定签名（类型 0x18，含密钥标志与可选的嵌入签名子包）、嵌入的主密钥绑定签名（类型 0x19）和调用方的签名验证回调：绑定签名须由主密钥产生，创建时间不晚于验证时刻；子密钥标志含 0x02（签名）或 0x01（认证）时，绑定签名必须含嵌入的 0x19 签名，由子密钥对主密钥产生，哈希输入为主密钥后接子密钥，缺少时拒绝；只含加密标志（0x04、0x08）的子密钥无需回签；子密钥或其绑定签名过期，或被 0x28 子密钥撤销签名撤销时，撤销时间之后创建的消息签名不接受，之前的接受；一个子密钥被多个主密钥绑定时，只承认签名里发行者指纹所对应、且回签对得上的那一个。用缺回签、他人主密钥重新绑定、仅加密子密钥、撤销前后和过期验证。
