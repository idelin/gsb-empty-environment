支持嵌套保存点（Savepoint）与部分回滚的事务在提交后，其单条键的版本链上可能混杂已回滚子事务留下的废弃版本、同一事务覆盖的中间版本以及被多个活跃快照或逻辑复制槽钉住的历史版本；错误回收某中间版本会截断旧快照的可见路径或破坏版本链连续性。为存储引擎垃圾回收器交付可导入的 Go 版本链裁剪包。输入单键有序版本链（每版本含版本 ID、创建事务及所属子事务栈、是否已中止/被保存点回滚、逻辑提交序号与删除标记）、当前活跃快照列表（各带快照可见边界与所属事务，含同一事务内处于某保存点处的读视图）及逻辑复制槽保留下界。规则：已中止或被已回滚保存点创建的版本对所有非其自身未回滚子分支一律不可见，可直接摘除；对已提交版本，须保留每个活跃快照各自可见的精确最新版本、逻辑复制槽下界及之后的所有已提交版本、以及全链最新已提交版本（即使为删除墓碑，若仍有更老快照依赖其上界也须保留直至无老快照早于它）；其余彻底不可见的历史覆盖版本标记回收，并返回摘除回收版本后每个保留版本的新前驱指针。验收对照全快照逐版本可见性朴素模拟，覆盖三层嵌套保存点仅回滚中层、同事务先删后插留墓碑、复制槽钉住比所有活跃事务更老的版本，以及仅留删除墓碑且无老快照时整链清空。
