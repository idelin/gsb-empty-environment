冷备恢复器只能挂一盘磁带，中间块也不一定能同时装下。请给恢复服务做可导入的 Go 规划包和流式写出适配器。每盘带是有序记录，记录可直接产出一个块，也可是给一组前置块生成一个输出块的差分配方；同一块 ID 代表相同内容。挂带要付装载费并回到原点，已挂带可以顺序跳过记录或读下一条，移动、读、重新挂载各有给定非负费用；不可倒带，除非重新挂。读到配方时前置块须同时驻留；原子生成期间前置块与新块须同时装下，不能先逐出一个前置块。内存按块大小计，逐出免费，被丢弃的块可重算。目标是一串带重复 ID 的有序写出请求，只有下一目标驻留时才允许写；写出后可保留，并非已写块能从目的端免费读回。全局先最小总费用，再最小化读取记录次数，返回可逐动作执行的操作序列；无解时要与零费用解区分。最多十四种块、四盘带、各至多十条记录，费用累加用精确整数。实际执行器只在走到相应记录时调用注入的带机，接配方回调和输出回调；应能用运行轨迹检查每次驻留峰值、带头位置和写出次序。独立小状态图对照最优双指标，覆盖最优解需要反复重读同一记录、绕过便宜配方避免瞬时超内存、零费用重挂环和重复目标跨带序列。
