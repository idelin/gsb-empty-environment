对象存储网关先按预签名请求查缓存，再在上游读取对象。同一对象的两个版本、两种 Range 请求或两个租户不能借缓存共用授权。给 Go 网关写可导入的只读请求验签与缓存准入包，采用题内签名格式：签名输入按顺序由租户、密钥代次、有效期终点、原始对象键、版本号、起止字节各字段组成，每段前置四字节大端长度，字节串使用 HMAC-SHA256。键以原始 URL 路径按斜杠分段，每段仅百分号解码一次；编码的斜杠、空段及点段拒绝，字面加号保留。字节范围只接受一个闭区间，按对应版本的已认证长度裁剪；签名绑定裁剪前的请求。缓存命中也要按当前密钥集合和时间重新准入，密钥撤销立即对新打开操作生效。上游只能读取被签版本并须返回同一版本号，版本变化时不得退回最新版。允许并发共享同一授权内容的读取，但一个等待者取消不能替其他等待者放行或撤销。用真实 MAC 与可控的上游逐项核对编码路径、不同版本内容、过期缓存命中、跨租户同名键、越界范围裁剪和并发撤钥。
