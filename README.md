空间数据库索引（R*-Tree / GiST 空间访问方法）相比朴素 R-Tree 在多维矩形重叠度与高选择性 K 近邻（KNN）性能上有质的飞跃，但核心维护与搜索算法极易在边界出错：1）**选择子树（ChooseSubtree）**：面向叶节点的上一层必须优先选**重叠面积增量（Overlap Enlargement）最小**的子节点（平局按面积增量最小 -> 当前面积最小 -> 节点 ID 最小），更高内部层按面积增量最小选优；2）**单层一次强制重插（Forced Reinsert）**：当非根节点上溢（条目数 `M+1`）且当前插入流程尚未在该树层执行过重插时，**绝不立刻分裂**——按各条目中心点到节点 MBR 中心的欧氏距离排序，摘除最远的 `p = floor(0.3 * M)`（至少 1）个条目，收缩本节点并向上传播 MBR，随后将摘除条目按由近及远（Close Reinsert）重新插回原树层；若该层已重插过再次上溢，才执行标准 R*-Tree 分裂（先遍历各维按低端点与高端点排序枚举全部 `[m, M+1-m]` 切分，按总周长和 `Margin` 最小选分裂轴，再在该轴上按重叠面积最小、次按总面积最小选切分点！）；3）**删除下溢重插与缩根**：删除导致节点条目 `< m` 时把孤儿条目（保留原节点高度信息！）暂存并删除空节点，沿路径向上收缩 MBR 后把各高度的孤儿子树精准重插回对应树层，并在根仅剩 1 个子节点时安全降高；4）**Best-First 增量精确 KNN（Hjaltason-Samet）**：使用最小优先队列同时保存待展开节点与叶对象，按精确 `MinDist(query, box)`（支持点与多维矩形查询、欧氏距离平方避免浮点误差！）升序弹出，保证按严格非递减距离（同距按对象 ID 升序！）增量吐出精确前 `K` 个近邻，绝不漏掉任何边界等距对象。为空间数据库引擎交付可导入的 Go R*-Tree 空间索引与增量 KNN 包。验收在含重叠大矩形、退化零面积点、高频增删与批量重插的随机 2D/3D 数据集上对照暴力全扫描，校验范围相交查询、包含查询、增量精确 KNN 排序及全部树节点 MBR 紧致包含不变式 100% 成立。
