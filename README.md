# 表达式引擎与优化器

一个小型表达式语言，含解释器、优化器和随机差分测试。函数分三类：

- **纯且全函数**（`add/sub/mul/neg/abs/min/max`）：无副作用、不抛错；
- **纯但部分函数**（`div/mod/sqrt`）：无副作用，但可能抛错（除零、负数开方）；
- **带计数副作用函数**（`tick(x)`、`bump()`）：每次调用递增计数器并记入调用轨迹。

`if(cond, then, else)` 是唯一的惰性结构：只求值被命中的分支。函数参数严格按从左到右求值。

## 优化器的不变量（`src/optimizer.ts`）

1. **只复用纯子树**：公共子表达式消除（CSE）只包裹不含副作用调用的子树；
   含 `tick`/`bump` 的子树永不共享，副作用的顺序与次数不变。
2. **不跨惰性分支提前执行可能报错的纯函数**：共享通过 `shared(id)` 节点实现——
   每个出现位置原地包裹，不做任何提升（hoisting）；`shared` 体在运行时第一次
   被动态到达时才求值并记忆化。因此可能抛错的纯子树不会在原程序不会执行它
   的时刻被求值，错误抛出的时点与其之前的副作用完全不变。
3. **常量折叠只针对纯且全函数的子树**：含部分函数的子树不折叠，避免把运行期
   错误提前到优化期或将其消除。`if` 条件为字面量时归约为被命中分支（字面量无副作用）。

## 差分测试（`src/differential.ts`）

对每个随机 AST（种子化生成器，会以 15% 概率克隆已有子树以制造重复），
分别解释执行原始与优化后的 AST，比较：

- 成功/失败状态与完整错误消息；
- 结果值；
- 副作用调用的有序子序列（纯调用允许因去重/折叠而不同）；
- 副作用计数器终态。

另含 8 个定向用例：错误前的副作用、惰性分支不执行、两个惰性分支上的重复
抛错纯子树（共享但不提升）、严格位置的重复部分函数、副作用顺序、副作用
不被去重等。

## 运行

需要 Node ≥ 23.6（原生 TypeScript 类型擦除），或用任意 TS 工具链编译后运行：

```sh
node src/differential.ts 50000   # 参数为随机种子数，默认 5000
```

最近一次运行：8/8 定向用例通过，50000 个随机 AST 0 处不一致
（约 9.7% 的用例会抛错，平均每次运行 1.5 个副作用调用，CSE 在 2608 个
AST 中引入了 9509 个共享节点）。
