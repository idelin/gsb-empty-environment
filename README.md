# RDAP应答与引导来源准入

域名风控服务通过RDAP查询注册信息，攻击者控制的注册商可在应答的links里把后续请求引向内网地址，或返回与查询对象不一致的实体。给TypeScript客户端写供查询流程调用的应答准入包：服务器须来自IANA引导文件当前内容，跟随links只允许https且主机属于引导服务器或调用方白名单，重定向最多三次且不得到私有地址；每次跳转都重新校验，出现环或跨出允许主机立即终止；ldhName与查询名按小写Punycode逐标签比较，objectClassName和rdapConformance须符合预期，rel不符或指外的self链接整条丢弃；未通过校验的结果不得写入正缓存，失败按查询名与响应体哈希记入带TTL的负缓存。用内网链接、重定向环、IDN混合大小写、错类型对象和负缓存污染验证。
