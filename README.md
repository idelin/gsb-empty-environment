同一份 SBOM 可用于多个目标平台，依赖边由功能开关和平台条件控制。给 Go 发布门禁写可导入的批次准入包。每条已签依赖声明绑定父制品摘要、子制品永久标识、允许的精确版本集合和生效条件，条件是全局布尔开关与平台枚举组成的标准 AST；同一部署只能选择一个平台、每个永久标识只能选一个版本。受信 VEX 声明只有在签署者有该制品范围授权、主体摘要完全匹配且列出的编译条件同时成立时，才可将某个已登记漏洞判为不受影响。不能把互斥配置中的依赖路径合并成命中，也不能选一套安全配置就代替全部配置。门禁接收部署方可能启用的配置集合，只有每个可实现配置下的每个合法解析结果都满足安全策略且根制品可解析才准发布；配置无可行解析要单列。返回可独立核验的分区证书，逐块说明哪些已签声明足以证明该块的依赖闭包和 VEX 适用范围。最多16个开关、12个多版本包，要求按等价配置共享证据。用小图全枚举对照循环依赖、两个包对共享版本的约束冲突、VEX 的编译条件只在部分平台成立和同名不同摘要的证明。
