# sccp — 控制流图上的稀疏条件常量传播

Go 实现的 SCCP（Sparse Conditional Constant Propagation）模块，面向 8 位回绕语义的 CFG。

## 特性

- **三值格单调收敛**：`⊥ < const < ⊤`，合流（Meet）只在格上上升，循环信息必然在有限步内收敛；每次环境提升都记录在 `Analyzer.Updates` 中可检验单调性。
- **只合流已可达前驱**：块的入态仅合流已被判定可执行的前驱边；尚未访问的前驱贡献 `⊥`，不参与合流。
- **8 位回绕运算**：加减乘、位运算、比较均在 `uint8` 上自然回绕（如 `200+100=44`）。
- **除零异常**：除数为常量 0 时块被证明必然 trap，其全部出边删除并附异常理由；trap 判定只影响报告，不影响分析的单调传播。
- **不误判未访问的边**：只有源块可达的边才会被判定删除；源块不可达的边列入 `Unresolved`（未决），明确标注"不能判定为永不可达"。
- **穷举执行对照**：`ValidateExhaustive` 对全部 256^n 种输入（超出预算时退化为边界值+随机抽样）具体执行，验证任何被删边从未经过、任何常量替换与实际值一致；循环由步数上限保护。

## 结构

- `lattice.go` — 三值格与 Meet
- `cfg.go` — 指令、基本块、CFG、8 位回绕运算
- `analyze.go` — SCCP 不动点分析
- `report.go` — 常量替换 / 删边及理由 / 未决边
- `interp.go` — 具体执行解释器（含除零 trap）
- `validate.go` — 穷举执行对照
- `cmd/sccpdemo` — 演示程序

## 运行

```sh
go test ./...
go run ./cmd/sccpdemo
```
