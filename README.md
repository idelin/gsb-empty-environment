# 懒绑定符号解析原子性

动态加载器第一次调用某导入符号才解析，恶意并发调用可能观察到半写的跳转槽。实现供Go加载宿主调用的懒绑定组件，槽位状态为未解析、解析中、已绑定或失败，递归解析同一槽必须识别环而不死锁；只有验证目标模块签名和地址范围后才原子发布。用可重入解析器测试并发首次调用、模块卸载与失败重试，旧回调不能写新代槽。

## 组件

- `Binder`：宿主入口，持有跳转槽表与模块注册表；`Resolve(slot)` 对应每次通过导入槽的调用。
- `Slot`：单个跳转槽，四态状态机 `Unresolved → Resolving → Bound/Failed`，失败后下一次调用可重试。
- `Resolver` / `ResolutionCtx`：宿主提供的可重入回调；回调内可用 `ctx.Resolve` 解析依赖符号，参与同链环检测。
- `Registry` / `Module`：模块表与描述符（基址、大小、签名、加载状态）。

## 关键不变量

- 并发首次调用合并为一次回调，其余调用者在完成通道上等待，槽位只写一次即原子翻转为 `Bound`，不存在半写跳转目标。
- 环检测按解析链（调用栈维度）进行：同链递归到正在解析的槽立即返回 `ErrCycle`，不自锁；不同 goroutine 的无关解析仍正常等待。
- 发布前依次校验模块已加载、签名有效、地址位于 `[Base, Base+Size)`（含溢出防护），任一失败记录为 `Failed` 且不发布任何目标数据。
- 模块卸载会令受影响槽进入新一代（generation+1）并回到 `Unresolved`：`Resolving` 槽一律失效，`Bound` 槽仅在指向被卸模块时失效；等待者被唤醒后在新代上重试。
- 旧代回调结束时若世代已变化，`publish`/`fail` 被拒绝并返回 `ErrStaleGeneration`，旧回调无法写新代槽。
- Resolver panic 会被恢复并转为失败尝试，槽不会永久卡在 `Resolving`。

## 测试

`go test -race ./...` 覆盖：128 goroutine 并发首次调用、可重入环、依赖链、跨 goroutine 等待、解析中卸载、旧代回调隔离、按模块精准失效、签名/地址范围校验、panic 恢复、失败重试与原子可见性。
