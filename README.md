# 格式串计数写入的最小载荷

日志兼容层仍支持计数写入转换，需要验证攻击者控制格式文本能否修改受保护字节。本包只模拟题目限定的格式子集，不调用真实格式化函数。

## 支持的格式

```text
format    = *(ordinary / "%%" / count / write)
ordinary  = ASCII 0x20..0x7e，但不能是 '%'
count     = "%" N "c"
write     = "%" K "$hhn"
```

- 普通可打印字符和 `%%` 各使输出计数加 1。
- `%Nc` 使输出计数加 `N`。
- `%K$hhn` 把当前计数模 256 写到第 `K` 个参数指向的字节，`K` 从 1 开始。
- `N`、`K` 均为不带前导零的正十进制数。
- 最多 8 个参数，内存窗口最多 16 字节，总计数最多 4096。
- 同一参数最多写一次；指向同一地址的不同参数仍算不同参数。

## 规划

```go
initial := make([]byte, 16)
targets := map[int]byte{12: 0x41}
plan, err := netsec.Plan([]uintptr{12}, initial, targets)
if err != nil {
    // 无解或输入不合法
}

result, err := netsec.Replay(plan.Format, []uintptr{12}, initial)
```

`Plan`/`Replay` 使用从 0 开始的内存地址，因此参数值就是内存偏移。若宿主使用真实地址，可用：

```go
plan, err := netsec.PlanAt(base, args, initial, targets)
result, err := netsec.ReplayAt(base, format, args, initial)
```

此时参数值是绝对地址，`targets` 的键仍是相对 `base` 的偏移。

规划结果按以下顺序最优：

1. 最终计数最小；
2. 写入次数最少；
3. 格式字节按字典序最小。

已经等于目标值的字节不会写入。需要修改的字节按目标值升序写入，因此最终计数等于需要修改的字节中的最大目标值。计数用空格递增，因为空格（0x20）是字典序最小的可打印递增字符；同一计数下的 `%K$hhn` 按转换文本排序。若某个地址有多个参数，使用编号最小的参数。

## 回放与拒绝规则

`Replay` 严格拒绝以下情况：

- 未知转换、裸 `%`、不完整转换；
- `N=0`、`K=0`、带前导零的数字；
- 参数编号超出宿主给出的参数数量；
- 参数地址落在受保护内存之外；
- 同一参数被写第二次；
- 计数超过 4096；
- 非可打印普通字节。

所有写入先在同大小的私有副本中执行。任何错误都会返回 `nil` 结果，且不会向宿主内存提交部分写入。成功结果包含按执行顺序排列的 `Writes`、实际 `FinalCount` 和 `FinalMemory`，每个写入项记录参数编号、地址、偏移、格式位置、当时计数和写入值。
