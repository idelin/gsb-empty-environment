# checkpoint

内容寻址的检查点存储库（Go 实现，无第三方依赖）。

## 模型

- **块（Chunk）**：按 SHA-256 内容寻址，全库共享，多个快照引用同一份数据。
- **快照（Snapshot）**：增量节点，只记录相对父快照的**新增引用**与**删除引用**操作序列。
- **DAG**：0 个父（根）、1 个父（线性）、2 个父（合并）。父快照必须先存在，因此依赖图天然无环；`ValidateDAG` 提供防御性审计。
- **摘要（Digest）**：绑定父快照摘要（含合并父顺序）与操作次序——重排操作或交换合并父都会改变摘要。

## 语义

- `Store.Expand`：展开快照，回放 DAG 得到完整引用集（带记忆化）。
- `Store.DownloadPlan`：去重下载计划——多个名字引用同一块只下载一次，排除本地已有块，输出排序后的哈希列表。
- 删除引用只作用于当前分支的新快照；`Store.GC` 只回收所有保留分支头都不可达的块，其他分支仍在使用的块不会被删除。
- 合并采用相对合并基（最大公共祖先）的三方合并；双侧对同一引用作出不一致修改时报 `MergeConflictError`，且不会留下半成品快照。
- 校验：缺父（`ErrMissingParent`）、自父（`ErrSelfParent`）、重复快照 ID、删除不存在的引用、引用未存储的块。

## 全量集合版本模型核对

`FullModel` 是独立的全量集合参照实现：每个版本直接保存完整引用集，不做增量回放。`TestCrossCheckFullSetModel` 在随机分叉/合并历史上逐快照比对 `Store.Expand` 与 `FullModel.Full`，并覆盖合并冲突、缺父、同块重复引用等场景。
