# vfrcfr

手机录制的可变帧率视频要转成固定帧率送入编码器，音画越转越不同步。给Go转码管线实现时间戳规整组件：按目标帧率决定每个输出槽取哪一帧，必要时复制或丢弃，累计误差不超过半帧；重复时间戳只保留最后一帧，跳变超过一秒视为新段并重新对齐；音频按样本数推进并作为同步基准。用合成的时间戳序列核对每个输出帧的来源和长期漂移。

## 实现说明

- `VideoRegularizer`：按目标帧率把输入帧映射到输出槽。槽时刻用有理数精确计算（`origin + n*step`，不逐步累加），每个槽取时间上最近的输入帧，因此选择误差天然不超过半帧且无长期漂移；输入帧率不足时复制上一源帧，过高时丢弃被挤掉的帧。
- 重复时间戳只保留最后一帧；与上一帧相差超过 `JumpThresh`（默认 1 秒）视为新段，段首帧重新对齐到槽 0。
- `AudioSync`：音频时钟只按已消耗样本数推进（`样本数/采样率`），作为音画同步基准，`Drift` 可查询任意视频时间戳相对音频位置的偏差。

```go
v := vfrcfr.NewVideoRegularizer(vfrcfr.Rational{Num: 30, Den: 1}, 90000)
for _, f := range frames {
    for _, o := range v.Feed(f.PTS, f.ID) { /* 送编码器 */ }
}
for _, o := range v.Flush() { /* 收尾 */ }
```

测试（`go test ./...`）用合成时间戳序列覆盖：恒定帧率直通、重复时间戳去重、跳变分段重对齐、突发 VFR 输入、低帧率复制、高帧率丢弃，以及 23.976fps 下 10000 帧的来源核对与长期漂移/音画偏差验证。
