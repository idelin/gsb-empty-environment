仓库里的 zonekey.EncodeV1 是已有客户端写入磁盘的名称编码，测试列出了持久字节；同一区的区顶点在其后代之后排序。请在这个 Go 模块中给递归名称宿主增加可导入的认证缓存层，保留现有公开 API 和 v1 字节。区发布者在不可变清单中签出区身份、代次和一棵按 v1 字节走边的稀疏基数树根。终点可有精确记录、下级区委派或通配模板，三者是不同槽，通配不通过普通名称编码表示。查询遇到有效委派就须进入子区，从子区信任键继续；否则精确记录优先，确实无精确名时仅可用最接近的已存在祖先的通配模板。给客户端实现只接收签名清单和不可信多路径证明的验证入口，要能区分已证实不存在、存在但没有此类记录、缺少证明三种结果。证明须把负答、最近祖先和委派边界都绑定到同一批清单，允许几个查询共享节点，但同一摘要在不同边位置不能替代路径。自行规定节点规范编码并写成固定兼容夹具；根签名用真实 Ed25519。客户端不持有整区记录。用更新前后的两组签名清单验证新委派阻断父区旧负缓存、无通配的近祖先遮住更远通配、区顶点排序，以及省略一条必需节点时不得返回确定负答。
