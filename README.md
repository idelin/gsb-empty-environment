# diffdag：DAG 共享子表达式的符号求导

对**加、乘、幂（有理数常数指数）及限定初等函数**（`sin` / `cos` / `exp` / `log`）
求导。纯 Python 3.11 标准库实现（`fractions.Fraction` 精确有理数），
不调用任何符号代数库；测试使用标准库 `unittest`。

## 设计要点

- **DAG 共享子表达式**：`Factory` 哈希一致化（hash-consing），结构相同的
  子表达式全仓库只存一个节点；求导器按节点记忆化，共享子图只求导一次，
  命中缓存时记录「复用」步骤，不重复展开（见 `diffdag/derive.py`）。
- **来源规则追踪**：每步求导记录规则名（和/乘积/幂/链式法则、零指数约定等）、
  被作用的子表达式与**适用域**；每步化简同样记录规则与适用域。
- **化简不改变定义域**：定义域条件（如 `x > 0`、`x ≠ 0`）由管线随原表达式
  保留；`0·u ⇒ 0` 等可能扩大定义域的重写只在原定义域上断言相等，并在步骤
  中注明。最终导数定义域 = 原函数定义域 ∩ 导数表达式的自然定义域。
- **log 导数保留定义域**：`(log u)' = u'/u`，步骤适用域标注「保留原定义域
  u > 0」，最终定义域保留 `{x > 0}`。
- **常数幂 0 的特殊点语义**：约定 `u^0 ≡ 1`（常函数约定，**含 u = 0**，即
  `0^0 = 1`），导数为 0；该约定在求导步骤与化简步骤中均显式注明。
- **精确有理数**：所有系数为 `Fraction`，如 `(1/3)x^3` 的导数精确为 `x^2`。

## 运行样例（节选）

```
=== 例 3：log(x)，定义域保留 ===
f(x) = log(x)
自然定义域: {x > 0}
求导步骤（来源规则 / 适用域）:
   1. [变量法则] d/dx(x): d/dx x = 1    适用域: ℝ
   2. [链式法则·对数] d/dx(log(x)): (log u)' = u'/u    适用域: 保留原定义域 x > 0
化简步骤:
   1. [乘法幺元] 1*x^(-1)  ⇒  x^(-1)    适用域: dom(右项)，定义域不变
f'(x) = x^(-1)
导数定义域: {x > 0} ∩ {x ≠ 0}

=== 例 4：共享子图 y=x^2+1，f = y·y·y ===
   4. [和法则] d/dx(x^2 + 1): (u+v)' = u' + v'    适用域: dom(u) ∩ dom(v)
   5. [复用] d/dx(x^2 + 1): 节点 #4 的导数已缓存，共享子图不重复展开
共享子图复用次数: 2

=== 例 6：x^0 + x^(-2) + x^(1/2)，特殊点语义 ===
   1. [零指数约定] d/dx(x^0): u^0 ≡ 1（常函数约定，含 u = 0），导数为 0    适用域: ℝ
   3. [幂法则] d/dx(x^(-2)): (u^(-2))' = -2·u^(-3)·u'    适用域: x ≠ 0
   6. [幂法则] d/dx(x^(1/2)): (u^(1/2))' = 1/2·u^(-1/2)·u'    适用域: x > 0
f'(x) = (-2)*x^(-3) + (1/2)*x^(-1/2)
导数定义域: {x ≠ 0} ∩ {x > 0}
```

## 目录结构

- `diffdag/expr.py` — 表达式 DAG 与哈希一致化 Factory
- `diffdag/derive.py` — 求导器（记忆化 + 规则/适用域追踪）
- `diffdag/simplify.py` — 化简器（重写规则 + 适用域注明）
- `diffdag/domain.py` — 自然定义域符号分析
- `diffdag/pretty.py` — 中缀格式化
- `main.py` — 运行样例；`tests/test_diffdag.py` — 26 个 unittest 用例
