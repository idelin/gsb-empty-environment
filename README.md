交换机模拟器按包串行发送，但合同要求包的优先级来自并行流体服务模型。实现供模拟器调用的 Go 调度包：链路每个整数时刻可传一字节，每流权重为正整数；流体参照系统只在有积压的流之间按权重分带宽。一个包的虚拟完成标签取本流上一标签与到达时系统虚拟时间的较大者，再加包长除以权重；虚拟时间在流体系统非空时按活跃总权重的倒数前进，空闲时冻结。真实发包器不可抢占，每次空闲取等待包中标签最小者，同标签按全局到达序号。接口一次接收一个时刻的整批到达，先结算到该时刻的完成、再纳入整批、最后决定此刻开始发送的包。提供排空接口返回剩余发包区间。时间戳、长度与权重为正的或适用时非负的 64 位整数，比较和累计不得因浮点舍入或溢出而改变次序。用测试说明真实队列空掉的流为何可能仍参与流体分带宽；覆盖批量同时到达、分数标签相差小于浮点分辨率以及长空闲后的恢复，时间推进不能逐字节循环。
