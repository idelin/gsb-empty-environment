# treemedian — 树上设施选址（k-median）求解器

在一棵 **非负边长** 的树上选择 **至多 K 个** 设施点（部分节点禁止选址），
最小化所有节点的 **整数需求 × 到最近设施的距离** 之和。输出选址集合、
逐点归属（等距时归属设施 ID 较小者）与总成本。

## 算法

- **精确解**：树形 DP。以节点 0 为根，状态 `f[u][k][a]` 表示子树 `u`
  内放置 `k` 个设施、且全树中离 `u` 最近的设施为节点 `a` 时，子树 `u`
  的最小加权距离成本。合并子节点 `c` 时，`c` 的最近设施 `b` 要么在
  `subtree(c)` 内且满足 `dist(c,b) ≤ dist(c,a)`，要么等于 `a`
  （仅当 `a` 在 `subtree(c)` 外）。利用按 `dist(c,·)` 排序的前缀最小值，
  每条边的合并复杂度为 `O(n·K²)`，总体 `O(n²·K²)`。
- **预算降级**：通过 `-budget`（默认 2×10⁸）限制 DP 运算量。预算耗尽
  （或规模超出精确 DP 上限）时退化为 **贪心可加设施** 的可行解，
  其成本是精确最优值的 **可行上界**，输出状态为 `upper_bound`。
- **归属规则**：对每个节点取 `(距离, 设施ID)` 字典序最小的设施，
  等距自动归属较小设施 ID。
- **边界情形**：`K=0` 或全部节点禁止选址时，若存在正需求则不可行
  （`infeasible`），否则空选址成本为 0；零长度边天然支持。

## 输入格式（stdin，节点编号从 0 开始）

```
n K
d_0 d_1 ... d_{n-1}     # 各节点需求
f f_1 ... f_f           # 禁止选址节点个数及列表（f 可为 0）
u v w                   # 共 n-1 行边，w >= 0
```

## 输出（JSON）

```json
{
  "status": "exact | upper_bound | infeasible",
  "cost": 17,
  "facilities": [2, 4],
  "assignment": [2, 2, 2, 4, 4]
}
```

`assignment[i]` 为节点 `i` 归属的设施 ID，无设施时为 `-1`。
不可行时进程退出码为 2。

## 使用

```sh
go build ./cmd/treemedian
printf '5 2\n3 0 5 2 1\n1 3\n0 1 2\n1 2 3\n1 3 4\n3 4 1\n' | ./treemedian
./treemedian -budget 1000000 < input.txt   # 限制精确 DP 预算
```

## 测试

```sh
go test ./...
```

- 400 组随机小树（含零长度边、禁止点、`K=0`、`K≥n`）与**枚举全部设施
  子集**的暴力解逐一核对成本与可行性；
- 零长度边、全禁止（有/无需求）、单节点、`K=0` 等边界单测；
- 等距归属按设施 ID 的确定性单测；
- 预算耗尽时返回贪心可行上界（成本 ≥ 精确最优）的单测。

## 规模参考

精确 DP 内存 `O(n²·K)`。实测：n=300/K=8 约 0.06s，n=1000/K=10 约 4s。
更大规模请调低 `-budget` 以获得贪心可行上界。
