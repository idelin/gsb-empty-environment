对象仓库按摘要去重，副本补齐和租户授权却可能先后到达不同节点。为 Go 存储宿主实现可导入的读取证明检查包。对象清单是一棵有序拼接树，叶为块编号与长度，内节点为子区间列表，允许同一子树多次引用；根签名由注入回调验证，节点身份取规范编码的 SHA-256。输入包含可乱序到达的清单节点、已校验字节区间、租户读取凭据和撤销事件。每个凭据授权特定租户、根摘要、根内半开字节区间和代次，只能在根坐标系内求并，不得因物理块相同就把另一个位置或租户的授权搬来，且禁止通过拼接树共享节点边界拼出未授权前缀的跨块校验覆盖。针对指定读取范围，给出刚好覆盖它的证书：每段指明根到叶的引用位置、物理范围、凭据与已验证区间；首先最小化分段数，再按每段终点降序、凭据编号升序破同分。缺证据返回首个缺口及原因。根逻辑长度可达到 2^50，禁止展开重复子树或按字节建表；允许最大输出段数，超限明确返回超限而非错误证明。签名失败、长度溢出、环、撤销后迟到的旧授权均不得产生可用段。读取端只信自己的根和当前授权视图；宿主在放行读取前调用包内验收函数，重新验证证书的授权、字节定位和连续覆盖。用小树穷举所有切分作最优性对照，测试同块两位置不同授权、非对齐切片、撤销与迟到凭据，以及深层重复树末端的短读。
