# pagecheck

有序页文件检查器（Go）。每页带摘要：最小键、最大键、记录数、下一页 ID。
记录按 `(Key, Seq)` 排序——重复键合法，只要其显式序号非递减。

## 组成

- `page.go` — 类型：`Record` / `Summary` / `Page` / `File`，排序键为 `(Key, Seq)`。
- `codec.go` — PGF1 二进制编解码（`WriteFile` / `ReadFile`）。检查器只依赖解码后的
  文件内容，与写入方完全独立。
- `checker.go` — `Check(*File) *Report`，检测：
  - 页内局部排序错误（含重复键序号倒退）
  - 跨页逆序（下一页首记录 < 上一页末记录）
  - 循环链接（含自环；从链头不可达的环也能发现）
  - 计数不符，以及摘要最小/最大键与实际内容不符、悬空 next、重复页 ID
- `query.go` — `Scan` / `Get` 先校验后查询：校验失败返回 `*ValidationError`
  （含完整 `Report`），绝不静默跳过坏页。`ScanTolerant` 是显式例外：同时返回
  幸存记录与 `Report`，由调用方明确选择绕过。

## 最小坏页集合

`Report.BadPages` 是解释全部异常所需的最小页集合：

1. 摘要/内容不一致、局部乱序、闭环指针、悬空指针等单页异常直接归因于该页；
2. 跨页逆序涉及相邻两页，已被第 1 类覆盖的不再重复计入；剩余逆序边构成
   链上的路径图，用 DP 求精确最小点覆盖（并列时确定性选择）。

## 测试

```sh
go test ./...
```

`pagecheck_test.go` 为每种元数据/内容不一致构造了样例（计数、最小/最大键、
局部乱序、跨页逆序、循环、悬空指针），并验证：
- 正常重复键按显式序号排列（含跨页边界）仍合法；
- 校验失败后 `Scan`/`Get` 返回错误而非部分数据；
- 损坏摘要经二进制往返后仍能被独立检查器发现。
