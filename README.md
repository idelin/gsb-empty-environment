# pseq — 持久化整数序列库

Go 实现的不可变多版本序列，基于隐式笛卡尔树（treap）做结构共享，
每个版本带多项式摘要与长度证据。

## 功能

- 两端添加/删除：`PushBack` / `PushFront` / `PopBack` / `PopFront`，均返回新版本，旧版本不变。
- 快照：`Snapshot` O(1) 复制版本句柄；`Release` 释放句柄并精确回收不可达节点（引用计数）。
- 多版本拼接：`Concat(a, b)` 只新建路径节点，共享子树不可变，
  两个共享底层节点的版本拼接不会产生可变别名。
- 区间剪切：`Slice(l, r)` 返回子区间新版本。
- 摘要证据：`Evidence()` / `RangeEvidence(l, r)` 输出 `{Digest, Len}`。

## 摘要定义

元素先入队前规范取模：`Norm(x) = ((x % Mod) + Mod) % Mod`（负整数先取模）。
序列摘要多项式折叠：`h = 0; h = (h*Base + Norm(x)) % Mod`，
`Mod = 998244353`，`Base = 91138233`。摘要与树形无关：
不同操作路径得到相同序列，摘要与长度必然相同。

## 契约：摘要相同 ≠ 内容相同

- `[0]` 与 `[]` 摘要同为 0，须靠 `Len` 区分；
- `[1,0]` 与 `[0,Base]` 在模 `Mod` 下摘要碰撞但内容不同。
- 判等只能用 `EqualContent`（逐元素比较），禁止用 `Digest` 判等。

## 内存管理

节点在版本间结构共享，引用计数管理。`Release` 后仅不可达节点被回收；
`LiveNodes()` / `AllocatedNodes()` / `FreedNodes()` 供审计。
测试以数组模型重算核对：分叉、重复自拼接、模碰撞、零元素与两端删除。
