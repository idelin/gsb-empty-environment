# layerarea — 图层可见面积库

按顺序覆盖的轴对齐矩形图层（整数坐标、可含透明孔洞），精确计算每层最终可见面积，
并支持任意点的最上层编号查询。**全程不栅格化**，与坐标平面大小无关（int64 坐标）。

## 核心设计

- **半开矩形** `[X1,X2)×[Y1,Y2)`：共边相邻不重复计面积，边上点归属唯一。
- **精确矩形布尔运算**：矩形减法把每层切成互不相交的分块；自顶向下维护
  「已覆盖集合」，逐层求 `本层 − 更高层并集` 得到可见区域。
- **归一化**：同层矩形互相重叠时先归一化为不相交并集，避免重复计数。
- **并集面积**：扫描线 + 坐标压缩精确计算，用于面积守恒检查。
- **点查询**：所有矩形边界把平面切成 O(E²) 压缩网格，每格记录最上层编号，
  查询二分定位 O(log E)；另提供暴力版 `TopmostAt` 用于交叉校验。

## 面积守恒检查

`CheckConservation` 断言：各层可见面积之和 == 全体实体区域的并集面积。
两者独立计算（前者逐层减法、后者扫描线求并），相等即证明无遗漏、无重复。

## API 一览

| 函数 | 说明 |
|---|---|
| `NewLayerWithHoles(bounds, holes)` | 用「外框 − 孔洞」构造一层（孔洞可重叠、可越界） |
| `Normalize(rects)` | 重叠矩形列表 → 不相交并集 |
| `SubtractRects(a, b)` | 矩形集合差 |
| `UnionArea(rects)` | 并集面积（扫描线） |
| `ComputeVisible(layers)` / `VisibleAreas` | 每层可见区域 / 面积 |
| `CheckConservation(layers)` | 面积守恒检查 |
| `NewLayerMap(layers)` / `TopmostAt` | 任意点最上层查询（索引 / 暴力） |

## 运行

```sh
go test ./...   # 共边、完全遮挡、孔洞重叠、随机守恒、索引 vs 暴力一致性
go run .        # 10^9 尺度三层演示：可见面积、守恒检查、点查询
```
