新闻归档中一篇文章可同时属于公开组和私有组。给 Go 阅读网关写可导入的可见索引组件，供按组翻页、按消息 ID 取文和订阅变更共用。每份发布版本含属于各组的独立内容片段、回复边和引用计数；用户只可见所获授权组的片段，并且只能看到两端均可见的引用边。查询按同一用户可见的首发顺序分页，页游标必须绑定主体、授权代次及快照，不能由隐藏插入、删除或私有编辑改变可见页长、计数、顺序、续页状态和通知。公开片段最后一次解除关联后，消息 ID 查询与根本不存在须给出相同结果；可见引用计数要按已去重的消息对重算。批更新可能同时更改组关系、内容和 ACL，通知只发送提交前后可见视图的最小差异，不得发出短暂私有内容。编写两个只在未授权数据上有差异的内存归档，穷举短操作序列，比较每个用户全部输出；验证同一消息多组关联、回复环、撤权时分页及批内先公开后隐藏。

## 组件

包路径 `prescreen.local/ddd-10559-v2`，可直接导入。

```go
import newsindex "prescreen.local/ddd-10559-v2"

archive := newsindex.New()
_, err := archive.Commit(newsindex.NewBatch().
    Put(newsindex.PublicGroup, "article-1", "public text").
    Put("subscribers", "article-1", "subscriber text").
    Link("article-2", "article-1").
    Grant("user-7", "subscribers"))

page, _ := archive.Page("user-7", newsindex.PageRequest{Limit: 20})
article, _ := archive.Get("user-7", "article-1")
notifications, _ := archive.Changes("user-7", 0)
```

`Page` 返回 `Next` 游标、`Snapshot` 可见视图令牌和授权代次。`Next` 绑定主体、授权代次和可见快照，只含可见数据，因此隐藏提交不会改变其内容或续页结果。`Get` 对“无可见片段”和“不存在”统一返回 `ErrMessageNotFound`。

## 语义

- 每个 `Commit` 生成一个不可变版本。批次内按顺序构造最终状态，但通知只比较提交前后的完整可见视图，不暴露中间态。
- 同一消息可有多个组的独立片段；可见首发顺序取该用户可见片段中最早的首发序号。隐藏片段不参与排序。
- 回复边仅当两端消息均可见时可见；同一有向消息对无论出现在多少个组或重复发布多少次，只计一次。
- 授权代次只在该主体的有效私有组集合变化时递增。批内先授权后撤权且净结果不变时，代次不变。
- 撤回权限使旧游标返回 `ErrStaleCursor`；从新视图起始页重新分页，不会跳过仍可见的消息。

## 验证

`archive_test.go` 覆盖多组片段、最后关联解除、回复环、去重计数、游标主体/代次/快照绑定、撤权分页和批内先公开后隐藏。

`differential_test.go` 构造两个仅在未授权组数据上有差异的内存归档，穷举短操作序列（并对更长序列抽样），逐步比较每个用户的分页、消息查询、通知和授权代次；另有一组测试在镜像归档中插入额外的纯隐藏提交，确认所有可见输出不变。
