# SSE Last-Event-ID游标注入

SSE 重连时浏览器会带上 Last-Event-ID，服务端若直接把它拼进查询或当游标，攻击者就能借此读取别的租户的事件，或注入换行。为TypeScript服务写可导入的 SSE 续传包：事件 ID 由服务端按 `流名:序号:HMAC前16字节十六进制` 签发，HMAC 绑定流名、租户与序号；Last-Event-ID 头和 lastEventId 查询参数同时出现且不同则拒绝；含 CR、LF、NUL 或超过 200 字节拒绝；签名不符、流名不属于当前订阅、序号超出保留窗口（最近 1000 条）时从当前位置开始并先发送 reset 事件，不返回具体原因；输出事件时 id 与 data 里的换行须拆成多行，不能产生额外字段。测跨租户游标、伪造签名、换行注入、超窗口。
