# polyfactor：有理系数多项式的公因子提取 DAG 搜索与展开验证

纯 Python 3.11+ 标准库实现（`fractions.Fraction` 精确有理数），不调用任何符号代数库。
从多项式项中提取**有理系数 GCD** 与**最小指数公共单项式**，支持递归分组，
在**有限候选分组空间**上搜索**运算次数最少**的因子提取 DAG，并为每一步生成
**独立展开验证证书**。只做公因子提取，**不承诺完全因式分解**。

## 模型与保证

- **公因子**：系数取有理 gcd（`gcd(分子)/lcm(分母)`，恒正），单项式取逐变量最小指数；
  商式在 Q[vars] 内精确相除（`Fraction` 精确计算）。
- **候选空间**：项集的所有集合划分（Bell 数规模）；≥2 项的块必须有非平凡公因子
  （平凡因子等价于更细划分，不损失最优性）；块的商式递归优化。
- **成本模型**：`add`/`mul` 节点成本 = 子节点数 − 1；叶子单项式 `c·m` 成本 =
  (系数 ≠ ±1 计 1) + 指数和 − 1（常数与单变量为 0）。节点全局 hash-consing，
  **共享子表达式只计费一次**。
- **精确性**：小项数穷尽候选空间，给出本成本模型下的**全局最优**（非局部贪心）；
  预算耗尽时中断，保留**上界**（当前最优完整候选）与**下界**（全体候选的可采纳
  乐观估计的最小值），并明确声明不承诺最优。
- **验证**：证书中每步提取都用独立的多项式展开核验等价；最终 **DAG 乘回必须严格
  等于原式**（规范形逐项相等）。
- **定义域**：提公因式是多项式环内的恒等变换，不做任何除以变量的操作，因此
  **定义域限制不因提取而消失**（也从不引入新限制）；证书每步均注明适用域。
  解析器拒绝负指数，从输入侧排除 `x ≠ 0` 之类的限制。
- **零多项式**：特殊处理，约定表示为常数 0 叶子，成本 0，证书单独说明。

## 运行

```bash
python3 -m polyfactor        # 或 python3 main.py
python3 -m unittest discover -s tests -v
```

## 代码结构

- `polyfactor/poly.py`：规范稀疏多项式、有理 gcd、公因子、精确除法
- `polyfactor/parser.py`：表达式解析（拒绝负指数）
- `polyfactor/dag.py`：hash-consing DAG、成本、独立展开、打印
- `polyfactor/search.py`：候选划分枚举、精确搜索、预算中断与上下界
- `polyfactor/certificate.py`：验证证书生成与逐步独立核验
- `polyfactor/cli.py`：演示样例；`tests/test_polyfactor.py`：18 个单元测试

## 限制说明

- 只做公因子提取 DAG，不做完全因式分解（如不识别 `x^2−y^2=(x−y)(x+y)`）。
- 叶子单项式内部的幂次成本不在叶子之间共享（如两个叶子各自的 `x^2`）。
- 下界为可采纳的保守估计，中断时下界可能明显低于真实最优。
