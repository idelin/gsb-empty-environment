# PSBT输入所有权与金额证据校验

PSBT 交给硬件或软件签名器时，攻击者可虚报输入金额让手续费悄悄变高，把外部地址标成找零，或夹带不属于签名者的输入。给Go签名器写供签名前调用的 PSBT 策略包，密钥派生由调用方注入：只签名其 scriptPubKey 等于由本机密钥按声明路径派生结果的输入，其他输入跳过；非隔离见证输入须带 non_witness_utxo，其哈希的交易 ID 须等于 prevout，隔离见证输入的金额须与调用方提供的链上来源一致，否则拒绝；输出只有能由本机密钥派生并匹配声明路径才算找零，其余全部展示给用户；手续费不超过上限；sighash 只允许 SIGHASH_ALL。用虚报金额、伪造找零、外来输入、非 ALL sighash 与超限手续费验证。
