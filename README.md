# 匿名发布最小泛化

安全导出服务希望按明确的信息损失预算发布匿名记录。写供Go导出宿主调用的泛化包，最多六个准标识列，每列给定高度不超过五的分类树；为每列选择统一祖先层级，相同泛化元组构成组，少于k条的组必须整组抑制且总抑制不超过s。精确最小化给定层级成本与抑制成本，并列按层级向量排序。返回分组与最优性证据，用完整格点枚举核对剪枝；空解明确拒绝发布。

## 包 `netsec`

入口是 `Anonymize(Config) (*Result, error)`。

- `NewTaxonomy` 构造并校验单列分类树：唯一根、无环、深度不超过 `MaxTreeHeight`（5），并预计算每个值在各祖先层级的泛化结果。
- `Config` 声明 1..`MaxQuasiIdentifiers`（6）个准标识列、每列的层级成本切片（长度为树高+1，允许非单调）、每条抑制记录的成本、最小组规模 `K`、抑制预算 `MaxSuppressed` 与输入记录。
- 求解器在层级向量的乘积格上做规范 DFS：每列选择统一祖先层级，泛化元组相同的记录构成等价类；不足 `K` 的等价类整组抑制，抑制记录数超过预算的向量判为不可行。
- 目标为 `层级成本之和 + 抑制记录数 × 抑制成本` 的精确最小值；成本并列时取字典序最小的层级向量。
- 剪枝只使用保守的层级成本下界（各列后缀最小值之和），不对层级成本或抑制的单调性做假设；不可行点继续向上搜索，可行点也继续搜索，因为其子孙可能因列成本下降而更优。
- 每次求解都额外进行一次无剪枝完整格点枚举，独立恢复最优成本与并列层级向量，并与剪枝结果及遍历点数守恒（`Evaluated + BoundPruned = LatticePoints`）核对；不一致时返回内部错误而不是发布。
- 没有任何可行层级向量时返回哨兵错误 `ErrNoFeasiblePublication`，同时返回非空 `Result`，其 `Published=false` 并携带顶格抑制情况与核对证据，明确拒绝发布；结构性非法输入返回 `ErrInvalidConfig`。

`Result` 给出选中层级、按泛化键排序的全部分组（抑制组带 `Suppressed=true`）、仅含发布组的 `PublishedGroups`、被抑制记录 ID，以及 `Evidence`（成本明细、剪枝统计、完整枚举核对）。
