实时报表引擎处理变更日志流（`+I`/`-D` 插入与撤回事件）时，若查询包含复合 `GROUPING SETS`、`ROLLUP(a, (b, c), d)` 或 `CUBE(x, y)`，常因把输入数据本身携带的 `NULL` 值和上卷汇总生成的占位 `NULL` 混为一谈导致分组被错误合并，或在撤回当前最大/最小值后无法恢复次极值。为流式 SQL 运行时交付可导入的 TypeScript 增量多维聚合引擎。组件接受由任意组合的 `GROUPING SETS`、`ROLLUP`、`CUBE`（支持括号复合列元组如 `(b, c)`、空集 `()` 以及嵌套重复分组集）构成的规范，展开为精确的分组集列表（保留重复分组集的独立行语义，不得偷偷去重吞行！）；为每条分组输出严格按 SQL 标准计算的 `GROUPING(col)`（被上卷折叠为 1、参与分组即使列值为 `null` 也为 0）及二进制拼接位图 `GROUPING_ID(c1, ..., ck)`。聚合器支持增量处理 `+1` 插入和 `-1` 撤回记录，维护 `COUNT(*)`、`COUNT(col)`（跳过 `null`）、`SUM`、`AVG`、`MIN`、`MAX`（撤回当前极值时借助有序计数结构精确回退至新极值；某分组计数归零时按需移除该普通分组，但全表空输入时 `GROUPING SETS (())` 全局汇总仍须输出单行 `COUNT=0, SUM=null`！）。验收在含数据 `null`、复合括号 `ROLLUP`、重复 `GROUPING SETS` 及随机插入/撤回变更流上对照每步全量批处理重算结果，覆盖数据 `null` 与上卷 `null` 共存、`MIN`/`MAX` 连续撤回回退及空表全局汇总行语义。
