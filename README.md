静态链接器在布局各输入段并解析重定位项（`.rela.*`）时，不仅要按架构 ABI 严格检验有符号/无符号位宽与页对齐边界（如 AArch64 `ADR_PREL_PG_HI21` 必须计算 `Page(S + A) - Page(P)` 且页偏移落在 `[-4GB, +4GB)`，而非简单的 `S + A - P`），在启用指令松弛（Relaxation）时把 `mov sym@GOTPCREL(%rip), %reg` 改写或把跨长跳转缩短还会改变后续符号地址，必须迭代收敛直至无段尺寸变化。为工具链链接器交付可导入的 Go ELF64 重定位与松弛引擎。组件接受规范化的段列表（代码/只读/GOT/数据段及其字节缓冲、对齐要求）、符号表（局部/全局/弱符号/未定义/段内偏移）及重定位表，支持 x86-64（`R_X86_64_64`、`R_X86_64_PC32`、`R_X86_64_32`、`R_X86_64_32S`、`R_X86_64_PLT32`、`R_X86_64_GOTPCRELX`、`R_X86_64_REX_GOTPCRELX`）与 AArch64（`R_AARCH64_ABS64`、`R_AARCH64_CALL26`、`R_AARCH64_ADR_PREL_PG_HI21`、`R_AARCH64_ADD_ABS_LO12_NC`）。规则：严格执行按位编码与溢出检查（例如 `R_X86_64_32` 检查 `[0, 2^32-1]`、`R_X86_64_32S`/`PC32` 检查 `[-2^31, 2^31-1]`、`CALL26` 检查 4 字节对齐及 `[-128MB, +128MB)` 且将 26 位有符号立即数精准拼入 `BL` 指令低 26 位、`ADR_PREL_PG_HI21` 将 21 位页差拆分写入 `ADRP` 的 `immlo[30:29]` 与 `immhi[23:5]`！）；实现 `GOTPCRELX`/`REX_GOTPCRELX` 松弛（将指向本地可见符号的 `0x8B` `mov` 指令原地改写为 `0x8D` `lea` 绕过 GOT 间接访存并可回收未引用 GOT 槽位），以及跨段短缩松弛的多轮地址重算收敛。验收覆盖 x86-64/AArch64 全指令位域编码手算对照、边界 +/-1 溢出精准报错、GOT 松弛改写操作码与死槽位回收，以及缩段引发的连锁地址偏移重算。
