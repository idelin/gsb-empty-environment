# 分层租约与多级代理授权协调器

大规模微服务集群的分级授权模型：根协调器只与少量区域网关维系**长周期粗粒度租约**，
区域网关在本区内独立颁发**短周期细粒度子租约**，把海量边缘节点的租约流量从中央分流到区域。

## 架构

```
┌────────────────────┐  60s 粗粒度租约(配额)   ┌──────────────────┐
│  RootCoordinator   │ ◄────────────────────► │  RegionGateway   │ ─┐
│  (根协调器, 1 个)   │   仅 5 个网关, 半周期续租 │  (区域网关, 5 个)  │  │ x5
└────────────────────┘                        └──────────────────┘  │
                                                        │ 5s 细粒度子租约 + 2s 心跳
                                                        ▼
                                              ┌──────────────────┐
                                              │   WorkerNode     │ x200/区 = 1000
                                              │  (边缘工作节点)    │
                                              └──────────────────┘
```

- **RootCoordinator**（`src/root-coordinator.ts`）：颁发/续期/撤销 60s 粗粒度租约；
  惰性过期，自身无任何周期任务，只对网关的消息做出响应。
- **RegionGateway**（`src/region-gateway.ts`）：持有根租约（50% 生命周期处自动续租），
  在配额内颁发 5s 子租约；子租约超时**纯本地回收**，不通知根协调器。
- **WorkerNode**（`src/worker-node.ts`）：2s 心跳续租；`disconnect()` 模拟崩溃——
  不打招呼直接消失，子租约由网关超时回收。
- **Clock**（`src/clock.ts`）：可注入时钟。`ManualClock`（最小堆虚拟时间）用于
  确定性测试与快速模拟；`SystemClock` 用于真实运行。

## 运行

需要 Node.js ≥ 22.6（使用内置 `--experimental-strip-types` 直接运行 TypeScript，
无需编译步骤；测试使用内置 `node:test`，零第三方依赖）。

```bash
nvm use            # 或任意 >= 22.6 的 Node
npm run demo       # 运行样例：1000 节点集群模拟 2 分钟
npm test           # Node.js 内置测试（15 个用例）
npm run typecheck  # 可选：需先 npm i -D typescript（离线环境可跳过）
```

## 验收边界对应

| 验收边界 | 验证方式 |
| --- | --- |
| 1000 个边缘节点请求配额 | `test/acceptance.test.ts` 边界 1：5 区 × 200 节点全部获得子租约，超额被拒 |
| 根仅与 5 个网关维系租约 | 边界 2：根有效租约恒为 5 个区域；2 分钟根消息 25 条 vs 边缘 61000 条（分流比 >1000:1） |
| 节点掉线根 CPU 零波动 | 边界 3：掉线后 5s 本地超时回收配额，观察窗口内根消息增量为 0；含 200 节点同时 churn 用例 |
