支持 Intel CET（控制流强制技术）的内核与运行时在调度用户态协程、信号帧返回及内核-用户切换时，若影子栈（Shadow Stack）恢复令牌的忙碌位（Busy Bit）与 64 位地址自指校验不严、允许用户态通过 `RSTORSSP` 切换到内核态影子栈或未在间接跳转目标放置 `ENDBR64`，攻击者可在多线程竞争或信号返回中伪造影子栈指针并绕过控制流完整性。为 C++17 系统安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 CET 影子栈与 IBT 状态机符号验证库。库建模 64 位虚拟地址空间、当前特权级（CPL 0/3）、影子栈指针 `SSP`、影子栈内存页属性（只读影子栈页 vs 普通可写页）及指令流状态机（`TRACKER = IDLE | WAIT_FOR_ENDBRANCH`）：严格执行（1）`CALL`/`RET` 双栈返回地址一致性校验与 `INCSSPQ` 步长上限检查（拦截越过当前栈帧破坏上层调用链）；（2）`RSTORSSP`/`SAVEPREVSSP` 与中断/信号切换令牌验证：核对令牌位于 8 字节对齐的合法影子栈页、低位模式位与 CPL 匹配、地址字段精确自指令牌地址且原 Busy Bit=0，切换时原子置 Busy Bit=1 防止双线程并发复用同一影子栈；（3）IBT 状态机校验全部间接 `CALL`/`JMP` 后首条指令必须为 `ENDBR64`（追踪跨越条件/无条件直跳与异常处理边界），并阻断任何把用户态 `SSP` 指向内核地址或普通可写页的切换请求。附令牌竞态复用、伪造非自指令牌、跨特权 SSP 与缺失 `ENDBR64` 对抗测试。
