宿主的追踪记录只给出每个线程内部顺序和少量跨线程屏障，不能把写日志的先后当成真正的身份切换顺序。给 Go 监视宿主写可导入的身份归属分析包。事件包括进入请求、显式借用、恢复、派生异步回调、挂起与指定句柄恢复；身份令牌绑定租户和请求代次，队列槽会复用。异步句柄只能带捕获时的身份快照，恢复必须消费对应句柄，线程退出时普通借用栈为空。输入为至多 36 个事件的偏序，宿主另给固定宽度的并发链分解。对每个受保护读取，分类为所有合法交错均符合、所有均违规、既有符合也有违规；无合法历史另报。非法事件的交错不能当作违规证据。返回两类可达事实各自的最短前缀及复核函数；安全结论须附可独立检查的覆盖关系，不能只给一个通过的调度。不逐个枚举拓扑排序，允许工作预算并明确未知。用小事件集的全排列对照，测同线程嵌套异常、跨线程归还、槽号重用和部分顺序中相同已执行集合却有不同身份栈。
