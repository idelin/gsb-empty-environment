融合内核的两个 SRAM bank 各只有四个字，编译器在加载权重的同时常把后面反向算子还需要的中间量覆盖。为张量执行后端写可导入的 Go 排程包。输入一张至多十二个值的无环图，每个值占一至三个连续字，不可跨 bank；源值永久保留在片外，其余值只能由给定算子产生，各算子有若干合法布局，逐项给出有序操作数和结果的 bank、起点对齐、正整数延迟，及哪些操作数允许与结果完全同址。物理副本可任意复用，不能部分重叠。设备有两个独立发射口：每个整数时刻可启动一个算子及一个片外读或写，端口到完成才空闲；所读片上副本从发射到完成一直锁读，目标锁写。仅当布局准许时，一次算子内部可以先保住自己的输入再原址出结果，该例外不对另一端口开放。完成先于同拍发射；同拍发射须联检锁，已完成副本可免费丢弃。每个非源值有自己的片外槽，写完整后可重新装入；同一值可重算，不要求每个算子只跑一次。输入给出各值的片外读写耗时，及最大总传输字数 K≤20，读写都计字数。求所有给定输出都已写回片外时的最早拍，同拍最少传输字数；无解与非法图分开。交付允许宿主逐事件发射的计划和能查出锁读覆盖、未完成回读、同拍竞争及传输超额的独立回放接口。延迟可达 2^40，不按空拍迭代；优化不能固定拓扑序、预设溢出策略或把两块存储的剩余字数当作完整状态。小例用单拍设备穷举，覆盖宁可推迟空闲端口也更早结束、完全同址的第二读者尚未完成、以及只能重算共享中间量才能满足预算。
