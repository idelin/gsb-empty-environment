# 上传文件的真实类型绕过了扩展名策略

附件服务按扩展名放行上传，攻击者把HTML或脚本内容命名为图片并用内容嗅探触发执行或存储型注入。请实现供Go附件服务调用的可导入类型判定组件。读取魔数与容器结构判定真实类型，扩展名只作附加信息；图片重新编码并剥离元数据，PDF与Office按声明的结构校验，未知或类型不符拒绝。内容与声明不一致、双扩展名、尾随数据和多分部件都要记录。存储时使用服务端生成的名称与固定内容类型，响应加`Content-Disposition`与`X-Content-Type-Options`。用HTML改名png、双扩展名、尾随脚本、合法图片和重新编码验证浏览器不把附件当页面执行。
