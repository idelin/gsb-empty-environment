机密计算宿主在恢复虚机快照后收到一批延迟的工作负载请求，旧策略下签出的请求不能借同名工作负载重建后再次生效。给 Go 消息宿主写可导入的请求准入包。宿主提供已认证的启动度量、工作负载声明树、策略版本和单调恢复代次；声明树中每个节点约定可创建的子节点、可读写的卷标识和允许的委托层数。父节点给子节点签出票据时只能转授自己的权限，票据须同时绑定父子声明摘要、实际实例随机数、恢复代次与用途。批请求可先引用尚未提交的子节点，但整体提交时必须存在一棵从已认证根出发的无环实例树，所有票据在同一时刻有效；不能从两棵合法树分别取父身份和卷权限拼接。提交使用宿主比较并替换回调，整批成功才发布实例与消费票据；回执丢失后相同批次摘要应能取回原结果，不得重复消费。提供独立快照校验函数，从已发布实例和签名收据重建授权链。用内存宿主验证快照恢复后旧票、同名新实例、环形前向引用、两棵树交叉绑定与提交后丢回执。
