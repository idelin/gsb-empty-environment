# polyfactor: 有理系数因子提取 DAG 的精确/有界搜索

纯 Python 3.11 标准库实现(`fractions.Fraction` 精确有理数, 不调用任何符号代数库),
`unittest` 测试。

## 功能

- **内容提取**: 从多项式各项提取有理系数 gcd(`gcd(分子)/lcm(分母)`)与最小指数公共单项式,
  如 `6*x^2*y + 9*x*y^2 = 3*x*y * (2*x + 3*y)`; 零多项式特殊处理(无内容, 表示为常数 0)。
- **有限候选搜索**: 候选 = 全体内容提取 + 全体项二分组的递归组合(可递归分组,
  不承诺完全因式分解)。按 DAG 运算次数(add/mul 节点数)全局比较选优,
  哈希共享使共享子表达式只计费一次; 不以局部贪心声称全局最优。
- **精确与有界**: 小项数枚举全部候选给出精确最优并输出展开验证证书;
  预算耗尽时中断, 保留可采纳下界(结构下界 `ceil(log2 t)` 与候选下界)与当前最优上界。
- **验证证书**: 每步记录变换、适用域与独立规范展开核验; 最终乘回展开必须与原式
  规范形逐项严格相等。提取只除以非零常数与非负指数单项式, 定义域限制不因提取消失,
  也不新增(负指数在解析阶段直接拒绝)。

## 运行

```sh
python3 main.py                          # 运行样例(输出见 sample_output.txt)
python3 -m unittest discover -s tests -v # 测试(输出见 test_output.txt)
```

## 文件

- `polyfactor/poly.py` — 精确有理系数多项式、规范形、内容/本原部、解析器
- `polyfactor/dag.py` — 哈希共享表达式 DAG、运算计费、独立规范展开
- `polyfactor/search.py` — 带预算的精确搜索、分支定界、上下界
- `polyfactor/certificate.py` — 验证证书生成与逐步核验
- `main.py` — 5 个演示样例
- `tests/test_polyfactor.py` — 19 个 unittest 用例
- `sample_output.txt` / `test_output.txt` — 运行样例与测试结果

## 样例摘要

- `6*x^2*y + 9*x*y^2`: 内容提取得 `3*x*y * (2*x + 3*y)`(乘回严格相等);
  优化器诚实报告展开式 3 次运算更便宜(提取形式需 5 次), 选择展开式。
- `x^2 + x*y + x*z + y*z`: 递归分组 `y*z + x*(y + z + x)` 精确最优 4 次运算(展开式 5 次)。
- `1/2*x + 1/3*y + 1/2*x*y`: 有理内容 `1/2*x` 精确提取。
- `0`: 零多项式特殊处理, 费用 0, 证书注明约定。
- 27 项多项式 + 预算 400: 中断并报告 `下界=5, 上界=27`, 上界表达式仍通过乘回核验。

测试结果: 19 个用例全部通过(详见 `test_output.txt`)。
