验证器缓存了已经审核的 JSON-LD context，但多个凭证套用不同的默认词汇、属性级 context 和导入顺序后，同一缓存键未必代表同一解释。写给 TypeScript 凭证宿主导入的离线解析包，只接受签名清单内的上下文对象和内容摘要，禁止联网。支持术语别名、词汇前缀、局部作用域、受保护定义与可回滚的嵌套 context；父定义可以引用稍后出现的术语，未锚定的循环定义报错，不能依字典插入顺序挑一个解释，且禁用 `@vocab` 与属性级 `@context` 组合时的静默重绑定。每个展开后的字段须附最小充分的来源闭包，能还原完整 IRI、类型解释和实际生效的签发者，来源相同的前缀允许共享节点。另给独立验收函数，只读凭证、信任清单根和证据，拒绝删掉一层作用域或把同 URL 的其他版本借进来。两个 JSON 键经别名展开到同一受保护字段，即使值相同也拒绝，未知字段不能悄悄覆盖受保护字段。以小上下文图的无缓存解释器覆盖导入菱形、跨作用域同别名、深嵌套退出恢复、轮换受信根和相同输入不同成员顺序。
