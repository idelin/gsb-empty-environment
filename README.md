# 引用计数 + 显式周期收集的对象图

## 设计

- `objgraph::Graph` 拥有全部 `Object`，外部根（`addRoot`/`removeRoot`）与内部边
  （`addEdge`/`removeEdge`）分开登记，二者共同构成引用计数。
- 引用计数经 1→0 转换时立即回收（`release` → `reclaimIterative`）：
  用显式工作栈级联销毁并移除出边，不做递归析构。
- `collect()` 从外部根做普通图可达性遍历（BFS），回收全部不可达对象，
  包括互相引用环与自环；先批量断边再逐个 `delete`，全程迭代。
- `~Graph` 预先清空所有边再循环 `delete`，深结构下析构不会递归溢出。

## 验证（普通图可达性作裁判）

`src/tests.cpp` 中的 `Model` 是与实现无关的结构模型（根集合 + 邻接表 +
结构化引用计数）：

- 每次操作后：实现存活集合 == 模型的"零计数不动点"（即时回收语义），
  且可达集 ⊆ 存活集，存活对象引用计数与结构推导一致。
- 每次 `collect()` 后：存活集合 == 根可达集（普通 BFS 可达性）。
- 确定性用例：删除根、共享子图（双亲共享孩子）、析构时移除边
  （被销毁对象的出边正确减计数，他处引用的孩子存活）、自环、
  百万级深链/大环的迭代回收与迭代析构（防栈溢出）。
- 随机压力测试：20 轮 × 4000 步随机操作，逐步对照裁判模型。
