# 机密日志字段传播

Go服务把结构化事件送到日志库，需可导入的机密字段传播与脱敏包。值为有向对象图，支持字串、数字、数组、字典、引用及secret标签，可有环；secret节点的全部可达子图都视为机密，即使另一路公开引用也不能输出。攻击者控制图形和别名但不能移除可信入口标签。脱敏后保留公开共享关系，机密节点统一为固定占位符，环用稳定编号引用，编号只能由公开遍历顺序产生，不能泄露机密节点数量；字典按键字节排序，secret字典的键也隐藏。实现两遍标记与序列化，预算超限完全拒绝输出；测试改变秘密子图大小/值后公开输出字节一致、反向别名、环及正常共享。

## 用法

```go
event := netsec.Dict(map[string]*netsec.Value{
    "user":  netsec.Str("alice"),
    "token": netsec.Sec(netsec.Str("s3cr3t")), // 可信入口标签
})
out, err := netsec.Redact(event, 1<<16) // 超预算返回 ErrBudgetExceeded，无部分输出
// out = {"token":"[REDACTED]","user":"alice"}
```

## 设计

- **第一遍（mark.go）**：迭代式遍历全图，从每个 `Secret` 标签节点向前传播污点；污点是前向闭包的，公开路径的反向别名无法洗白。
- **第二遍（encode.go）**：只遍历公开子图。先统计公开入度（根算一条入边），入度大于 1 的节点（共享或环入口）在首次出现时按公开遍历顺序分配 `$id`，后续出现输出 `$ref`；机密节点一律输出固定占位符 `"[REDACTED]"`，不参与编号，因此编号不泄露机密节点数量。字典键按字节序排列，机密字典整体折叠、键不外泄。
- **预算**：写入前检查字节预算，超限返回 `ErrBudgetExceeded` 且返回 nil，不产生任何部分输出。
- **健壮性**：所有遍历均为显式栈迭代，深图不爆栈；纯引用环无具体值，编码为 `null`；NaN/Inf 返回 `ErrInvalidNumber`。
