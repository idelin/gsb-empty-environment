# arcode — 整数区间算术编码（Go 标准库实现）

从零实现的自适应算术编码器，不依赖任何压缩库，仅使用 Go 标准库。

## 特性

- **整数区间算术编码**：32 位区间 `[low, high]`，E3 下溢挂起比特处理，
  全部中间量用 `uint64` 计算（最大约 2^46），长单一符号流不溢出。
- **自适应频率表**：257 个符号（256 字节 + 终止符 `SymbolEOF`），初始频率全 1；
  每编码一个符号频率 +1，总频率达到 `maxTotalFreq = 2^14` 时按 `(f+1)/2` 缩放，
  已知符号缩放后保持正频率。
- **编解码状态同步**：编码器与解码器各自维护相同模型，对每个符号（含终止符）
  按相同顺序更新，区间归一化规则完全镜像。
- **终止符**：数据末尾编码 `SymbolEOF`，解码器读够声明长度后必须再读到终止符，
  否则报错。
- **输出预算**：`Decode(r, maxOutput)` 在解码前检查头部声明长度，超出预算立即拒绝；
  解码符号数恒为 `length + 1`，负载读取量也有上限，错误流不能无限解码。
- **完整性校验**：头部含魔数、格式版本、原始长度与 CRC32 校验和，
  篡改、截断、垃圾输入均被检出。

## 流格式（大端）

| 偏移 | 长度 | 含义 |
|-----:|-----:|------|
| 0  | 4 | 魔数 `PAC1` |
| 4  | 1 | 格式版本（当前 1） |
| 5  | 1 | 保留，须为 0 |
| 6  | 8 | 原始数据长度（字节，不含终止符） |
| 14 | 4 | 原始数据 CRC32(IEEE) |
| 18 | … | 算术编码负载（数据符号 + 1 个终止符） |

## API

```go
err  := arcode.Encode(w, data)            // 编码到 io.Writer
data, err := arcode.Decode(r, maxOutput)  // 解码，maxOutput 为输出预算
```

## 命令行样例

```sh
go run ./cmd/arcode encode <输入文件> <输出文件>
go run ./cmd/arcode decode <输入文件> <输出文件> [输出预算字节数]
```

## 测试

```sh
go test ./...
```

覆盖：多类型数据往返、2 MiB 单一符号流（不溢出且正确往返）、缩放后正频率、
偏斜分布下的模型同步、输出预算、坏魔数/版本、负载篡改、截断流、
头部长度篡改、垃圾输入有界终止。

## 文件结构

- `model.go` — 自适应频率表（更新与缩放）
- `coder.go` — 位流读写、区间编码器/解码器
- `format.go` — 流格式头、Encode/Decode、错误定义
- `cmd/arcode/main.go` — 命令行样例
- `arcode_test.go` — 全部测试
