# 带释放回调的对象图解码

消息宿主解码对象图时会在失败路径调用清理函数，攻击者可让两个字段引用同一对象，诱发重复销毁。为Go宿主写可导入的图解码包，格式由本题定义：输入记录数组，每项为唯一整数ID、类型名、子ID列表；类型表按子ID列表的位置声明每条子边是own或borrow，数量必须匹配，指定一个根ID。仅own边转移销毁责任，borrow不转移；根可达的own子图必须无环且每个非根对象恰有一个own入边，borrow可成环但目标必须存在并且在根的own可达集合中。先完成结构检查再调用构造回调，仅按own边依赖以子对象先于父对象构造；borrow用稳定ID交给回调，不要求借用目标已构造；同层按ID升序。任一构造失败时按成功构造顺序逆序各销毁一次，失败的对象由构造回调自行负责。成功后返回根句柄，Close幂等并按相同逆序销毁，不递归调用子对象析构。限制最多1000节点，重复ID、整数越界和未知类型拒绝。用记录实际分配释放次数的回调测试共享own攻击、借用环、每个构造点失败以及重复Close，必须证明非法图没有触发任何构造回调。
