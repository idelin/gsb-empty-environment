# 有限域反例收缩器 (Finite-Domain Counterexample Shrinker)

给定一个整数向量和一个确定性失败谓词，在有限的可达状态空间内搜索
"最小"的失败向量。纯 Python 3.11 标准库实现，无第三方依赖。

## 合法操作（收缩移动）

1. **删除**任意一个元素；
2. **减小**任意元素的绝对值 1（**符号保持不变**，不会越过 0）。

因此从 `[4, 4, 9]` 永远无法到达 `[-1, -1]`——符号不可变。
验收用例：谓词"存在连续两个相同非零数"作用于 `[4, 4, 9]` 的最终
答案为 **`[1, 1]`**（已证明全局最小）。

## 目标函数

按成本元组字典序最小化：

```
(向量长度, 绝对值之和, 向量字典序)
```

## 正确性约定

- 状态空间有限：每个元素只能被删除或沿 `|x| -> 0` 逐步缩减。
- 扩展（生成邻居）**不消耗**谓词预算；求值（调用谓词）只对成本
  严格小于当前最优失败态的状态进行。便宜状态可能藏在昂贵祖先
  之后（如 `[-1,-1]` 只能由 `[-2,-1]` 展开得到），因此不能简单
  地"弹出第一个失败态即宣布最优"。
- `proven_minimal: true` **仅当**优先队列被排空：所有可达状态均已
  展开，且所有比结果更便宜的可达状态均已求值且无一失败。
- 预算耗尽时 `proven_minimal: false`，`result` 只是"目前找到的
  最好失败态"，**绝不**以局部极小冒充全局最小；`frontier_*` 字段
  给出已生成但尚未求值、且比当前最优更便宜的状态（未探索边界）。
  注意：预算耗尽时还可能存在尚未被生成的更便宜状态，frontier
  只是已知边界。
- 所有谓词结果都缓存在 `cache` 中，同一状态绝不重复求值
  （`predicate_calls == cache_entries`，且无重复调用）。

## 命令行用法

```sh
# 从 stdin 读取 JSON 数组
echo '[4, 4, 9]' | python3.11 shrinker.py --predicate consecutive_equal_nonzero

# 从文件读取 JSON 对象（可含 budget），命令行 --budget 优先
python3.11 shrinker.py --predicate any_nonzero --budget 500 --input case.json
```

### 输入

- JSON 整数数组：`[4, 4, 9]`；或
- JSON 对象：`{"vector": [4, 4, 9], "budget": 1000}`。
- `--budget` 缺省为 10000。

### 内置谓词（全部为确定性谓词，示例数据均为合成数据）

| 名称 | 含义 |
|---|---|
| `consecutive_equal_nonzero` | 存在相邻两个相等且非零的元素 |
| `any_nonzero` | 存在非零元素 |
| `zero_sum_pair` | 存在两个不同位置的非零元素之和为 0 |
| `sum_at_least_ten` | 元素总和 >= 10 |

### 输出（JSON）

| 字段 | 含义 |
|---|---|
| `input` | 原始输入向量 |
| `result` | 最小失败向量；不存在失败态时为 `null` |
| `proven_minimal` | 是否已证明全局最小（见上文正确性约定） |
| `budget` / `budget_exhausted` | 预算及其是否耗尽 |
| `predicate_calls` | 谓词实际求值次数（缓存未命中数） |
| `cache_entries` | 缓存的不同状态数 |
| `states_explored` | 实际求值的状态数 |
| `frontier_size` / `frontier_sample` | 未探索边界的大小及样例（最多 10 个） |
| `note` | 人类可读的结论说明 |

## 测试

```sh
python3.11 -m unittest test_shrinker -v
```

测试包含：验收边界（`[4,4,9] -> [1,1]` 而非 `[-1,-1]`）、与暴力
枚举预言机逐例对比全局最小性、预算耗尽时不得声称最优、谓词
去重缓存、移动合法性（每步严格降低成本且不变号）等。
