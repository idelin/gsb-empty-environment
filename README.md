# 有限字母路径合规（DFA-constrained shortest path）

有向图的每条边带一个字符标签与非负整数成本。要求路径的标签串被给定
确定有限自动机（DFA）接受（允许重复顶点）。求从 `source` 到 `target`
的最优路径，比较顺序为：

1. 总成本最小；
2. 平局时边数最少；
3. 再平局时标签序列字典序最小；
4. 再平局时边 ID 序列字典序最小。

输出**双证据**：图上的顶点/边 ID 路径，以及对应的 DFA 状态路径。

## 运行环境

Python 3.11+，仅使用标准库。

## 命令行

```sh
python3 dfa_path.py 输入.json     # 从文件读取
cat 输入.json | python3 dfa_path.py   # 或从 stdin 读取
python3 -m unittest test_dfa_path -v  # 运行测试
```

## 输入格式（JSON）

```json
{
  "graph": {
    "vertices": ["s", "m", "t"],
    "edges": [
      {"id": 0, "src": "s", "dst": "t", "label": "a", "cost": 1}
    ]
  },
  "dfa": {
    "states": ["q0", "q1", "q2"],
    "alphabet": ["a", "b"],
    "start": "q0",
    "accepting": ["q2"],
    "transitions": [["q0", "a", "q1"], ["q1", "b", "q2"]]
  },
  "source": "s",
  "target": "t"
}
```

- 边 `id` 为唯一整数；`label` 必须是字母表中的单个字符；`cost` 为非负整数。
- DFA 必须确定（同一 `(状态, 字符)` 至多一条转移），允许部分转移函数
  （缺失的转移视为不可走）。
- 输入非法（负成本、重复边 ID、非确定转移等）时输出 `{"found": false, "error": ...}`
  并以退出码 1 结束。

## 输出格式（JSON）

```json
{
  "found": true,
  "cost": 2,
  "edge_count": 2,
  "label": "ab",
  "vertices": ["s", "m", "t"],
  "edge_ids": [1, 2],
  "dfa_states": ["q0", "q1", "q2"]
}
```

- `vertices` / `edge_ids`：图路径证据（顶点序列与边 ID 序列）。
- `dfa_states`：自动机状态路径证据，长度 = 边数 + 1，末状态必为接受状态。
- 无解时输出 `{"found": false}`。

## 算法与正确性要点

在积图 `(顶点, DFA状态)` 上做最佳优先搜索，堆优先级为
`(成本, 边数, 标签串, 边ID元组)`：

- 成本非负 ⇒ 成本沿扩展单调不减；边数严格 +1；标签/边ID序列只能追加，
  前缀字典序更小 ⇒ 整个优先级沿扩展单调不减。因此每个积状态首次弹出
  即最优，之后同状态条目直接丢弃。
- 积状态总数有限（|V|×|Q|），每个只结算一次，**零成本环不会导致无限搜索**。
- 字典序剪枝安全：到达同一积状态且 `(成本, 边数)` 相同的路径标签等长、
  互不为前缀，拼接公共后缀后字典序保持，故每状态只留最优条目即可。

## 测试与最优性验证

`test_dfa_path.py` 含 12 个用例，全部为合成数据：

- 验收边界：直边 `a`（成本 1）不被只接受 `ab` 的 DFA 接受，必须绕行
  （成本 2）才合法；仅有不合规直边时返回未找到。
- 零成本环 / 零成本自环：搜索正常终止且结果正确。
- 三级平局裁决（边数 → 标签字典序 → 边 ID 字典序）。
- 边界情形：`source == target`（空串接受/不接受）、不可达、负成本拒绝。
- **最优性对照**：300 组随机合成小实例上，与积图简单路径暴力枚举的
  最优解逐一比较（最优解必不重复积状态，否则删环后成本不增、边数更少，
  矛盾），全部一致。
