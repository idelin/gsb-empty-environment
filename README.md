# 四维时空反向索引与历史相交证明器

追溯引擎：证明「实体 A 与实体 B 是否在历史某个时空相遇过」。
基于**时间切片倒排网格索引**快速检索两实体在任意时刻空间距离小于给定阈值的接触记录，
精确输出全部相交时段，并签发**哈希链式地点证书**（不可抵赖）。

## 架构

| 模块 | 职责 |
| --- | --- |
| `src/grid-index.ts` | 时间切片倒排网格：`slice(时间段) -> cell(空间格子) -> [实体位置]`，轨迹段登记到其覆盖的所有切片，支持 O(1) 反查候选时间范围 |
| `src/prover.ts` | 精确求交：把重叠时段切成双方均匀速直线运动的单元段，逐段解二次不等式 `\|pA(t)-pB(t)\|² ≤ r²`，合并相邻区间；支持楼层（z 轴） |
| `src/certificate.ts` | 不可抵赖证明：轨迹 SHA-256 输入承诺 + 证书哈希链（prevHash 链接）+ 根哈希；`verifyProof` 独立重放验证 |
| `src/scenario.ts` | 疾控流调样例：两名确诊者的商场轨迹与柜台区域定义 |
| `src/demo.ts` | 端到端演示：建库 → 求交 → 出证 → 验证 → 篡改检测 |

## 运行

要求 Node.js ≥ 22.6（使用内置类型擦除直接运行 TypeScript，零依赖）。

```bash
npm run demo   # 运行流调样例
npm test       # Node 内置测试运行器
```

## 验收边界对照

- **输入**：两名确诊者轨迹（时间戳 + 平面坐标 + 楼层）。
- **数毫秒内求交**：样例场景稳态约 2.2ms；24 小时 1Hz 全量轨迹（86400 采样点/人）约 358ms。
- **精准输出**：检出 3 个相距 <10 米的时段（咖啡柜台 / 生鲜柜台 / 收银台A），含精确到毫秒的时段边界、最近距离与坐标、楼层、柜台名。
- **不可抵赖**：轨迹输入承诺 + 证书哈希链 + 根哈希；篡改地点/时间、删除证书、替换轨迹均被 `verifyProof` 检出。
