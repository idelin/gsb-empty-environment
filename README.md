# frame_decoder

C++17 增量帧解码库。

## 帧格式

```
[1 字节类型][变长长度][负载]
```

- **长度**：无符号 LEB128 varint，最多 5 字节（32 位值），必须是最短编码
  （多字节编码的末字节不得为 0，第 5 字节不得超过 0x0F）。
- **控制帧**（类型 `0x00`）：负载为一个最短 varint（值 ≥ 1），设置后续
  数据帧允许的最大负载长度。控制帧自身不受当前上限约束，因此随时可以把
  上限再调大。默认上限为 1 MiB。

## 解码器语义

- `feed()` 接受任意大小的分块输入，完整帧通过回调即时交付。
- 一旦发生协议错误，解码器锁定在错误状态，后续 `feed()` 一律失败，
  只有显式调用 `reset()` 才能恢复（同时清空缓冲并恢复默认上限）。

## 构建与测试

```sh
cmake -S . -B build && cmake --build build
ctest --test-dir build --output-on-failure
```

测试对每个合法样本枚举所有两处切分（切成三段输入），核对增量解码输出
与整块输入完全一致，并覆盖各类错误场景（非最短长度、超长 varint、
32 位溢出、超过上限、畸形控制帧、错误锁定与重置）。
