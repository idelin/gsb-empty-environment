UEFI 固件在系统管理模式（SMM）中处理操作系统触发的 SW SMI 通信请求时，若 SMI Handler 未校验 `CommBuffer` 及其中嵌套的二级指针/长度是否与 `SMRAM`/`TSEG` 物理地址区间重叠、遗漏 `base + size` 64 位整数回绕检查、未先将外部 OS 可写内存整体拷贝至 SMRAM 私有缓冲再校验与使用（双取 TOCTOU），或在 SMM 态直接间接调用位于 SMRAM 外的回调函数（SMM Callout），内核态攻击者可直接提权至 Ring -2 持久化植入固件木马。为 C++17 固件安全审计宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 SMM 内存边界与双取/Callout 静态验证库。输入为 SMRAM/TSEG/MMIO 受保护物理区间表、SMI 通信结构体布局描述符（含嵌套指针与变长字段偏移）以及简化 Handler 控制流/访存操作序列。验证库精确执行：（1）提供 64 位无溢出区间校验器，精确判定一级 `CommBuffer` 及全部递归嵌套指针区间是否与任意 SMRAM/TSEG/保留区相交或发生地址回绕，硬拒绝零长度之外的边界穿越；（2）在 Handler 操作流上执行外部内存别名与读次数追踪，检出任意位于 SMRAM 外部的共享字节在未拷贝入私有缓冲前被读取超过一次（尤其首次用于长度/权限校验、二次用于实际拷贝或索引的 TOCTOU 漏洞）；（3）检出任意间接跳转/函数指针目标地址来自外部可控内存或落于 SMRAM 可执行代码区之外的 SMM Callout，并输出具体违规指令序号与构造的恶意物理地址见证。附含整数回绕、二级指针指向 TSEG、双取 TOCTOU 与 SMM Callout 样本测试。
