# 多版本时态证据选择

从多版本事实中选择同一观察时刻可见、业务有效区间重叠的证据集，受版本可见性、
业务区间与来源互斥约束，返回全部极大可行时间段及一致选择（证据见证）。
纯 Python 3.11 标准库实现，测试基于 unittest。

## 语义定义

- **版本可见性**：观察时刻 T 仅可见 `recorded_at <= T` 的版本；每个事实/规则 ID
  取最新可见版本。观察时刻之后录入的证据不参与历史解释。
- **一致选择**：可见事实的非空子集，两两不冲突（无可见互斥规则同时覆盖两者来源），
  且所有成员业务区间（半开 `[from, to)`）交集非空。
- **极大一致选择**：不能再加入任何可见事实而保持一致（兼容图的极大团，
  Bron–Kerbosch 枚举，顺序确定）。
- **极大可行时间段**：极大一致选择的共同区间之并的连通分量；每段附带分段覆盖，
  每个覆盖片给出至少一个一致选择。结果不是所有候选区间的简单交集——互斥来源
  会产生多个互斥的极大选择，各自给出可行段。
- **不一致原因**：`EMPTY_COMMON_INTERVAL`（极大选择共同区间为空，如 [0,5) 与
  [5,9)）、`NO_VISIBLE_FACTS`、`SEARCH_TRUNCATED`。
- **未知段**：团枚举预算截断时，被事实覆盖但未被已枚举选择覆盖的区域明确标记为
  `unknown`；搜索完整时该区域标记为 `infeasible`。
- **增量撤销**：修改一个事实后，仅撤销触及受影响时间 span 的段并局部重算
  （span = 旧区间 ∪ 新区间）；来源变化或涉及空交集团时影响无界，回退全量重算。
- **可重放**：事实、规则、求解步骤都带稳定 ID 与版本；所有变更记录为事件日志，
  `replay(events)` 确定性重建并得到相同结果 digest。

## 结构

- `evidence/model.py` — 多版本事实/互斥规则、事件溯源仓库
- `evidence/solver.py` — 极大团枚举、可行段装配、原因与未知段、digest
- `evidence/bruteforce.py` — 穷举全部子集的参照求解器（小规模对照）
- `evidence/incremental.py` — 增量求解器（撤销受影响段）
- `evidence/replay.py` — 事件日志重放
- `demo.py` — 合成数据运行样例
- `tests/` — unittest 测试（可见性、可行段、互斥、截断未知段、穷举对照、
  增量一致性、重放确定性）

## 运行

```sh
python3.11 demo.py                        # 运行样例（合成数据）
python3.11 -m unittest discover -s tests  # 运行测试
```
