# 安全查询自适应预算

分析人员根据前次结果选择下次查询，隐私账本必须区分预声明固定序列与自适应序列。实现供Go隐私宿主调用的计划状态机，每次发布回执绑定父结果摘要和成本，分支计划只能消费父计划预留预算；发布后取消不退还，未发布分支可释放。用分叉重试与回执重复测试总成本上界和路径归属。

## 状态机

- `NewPlan(id, reserve, fixedSteps)`：创建根计划。`fixedSteps > 0` 为预声明固定序列（`Fixed`），否则为自适应计划（`Adaptive`）。
- `OpenBranch(id, parent, parentReceipt, reserve)`：基于父计划已发布回执分叉，子计划恒为自适应；预留额在创建时即锁定，且不得超过父计划当前可用预算。
- `Publish(PublishInput)`：扣费并发布不可变 `Receipt`。回执绑定父结果摘要（计划内上一条，或分叉点父回执）、成本与完整分叉路径 `Path`。相同回执 ID 重复发布为幂等重试，不重复扣费；同一结果摘要在计划内重放会被拒绝。
- `Release(id)`：仅未发布的 `Reserved` 分支可释放，预留全额退回父计划。
- `Cancel` / `Finish(id)`：已发布计划终结，未花完的预留罚没，不退还父计划；仍有开放分支时拒绝终结。

计划状态：`Reserved → Active → Completed|Canceled`，未发布分支可转入终态 `Released`。固定序列在最后一步发布后自动 `Completed`，且禁止分叉与超步发布。

## 预算不变量

- 分支可用额 = 自身预留 − 自身花费 − 未释放子分支预留；`TotalSpent ≤ 预留总额 ≤ Ledger 全局预算`。
- 取消/完成不退还：终结分支的预留继续对父计划不可用，只有 `Release` 才回收。
- 所有读写由 `sync.RWMutex` 保护，`Plan`/`Receipt` 返回防御性拷贝。

## 测试

`go test -race -count=1 ./...` 覆盖：固定序列生命周期、分叉重试与路径归属、回执重复幂等、预算上界、嵌套分叉、状态守卫、并发重复发布/竞争分叉、回执链校验（`VerifyReceipt`）。
