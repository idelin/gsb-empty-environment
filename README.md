# 设备控制规则的通配覆盖允许了宿主磁盘

容器设备策略由多条允许和拒绝规则组成，错误合并通配符可能让租户打开宿主块设备。给Go运行时实现可嵌入的设备规则编译包：设备请求为类型c/b、major、minor和权限r/w/m；规则含Allow或Deny、类型可为a、major/minor可为*及权限集合。语义按规则顺序维护每个设备权限集合：Allow并入匹配权限，Deny删除匹配权限，初始权限默认空；类型a同时匹配c和b，m控制创建设备节点但不自动给r/w。目标策略由有限允许设备集合与强制拒绝集合给出，major/minor范围0至4095。编译器把规则序列转为不相交的符号区域决策图，验证任一允许结果都属于目标允许且不命中强制拒绝，并找目标允许却被误拒的按类型c<b、major、minor、权限位顺序取最小设备作为完整性提示；不能枚举全部设备对。另接受待审优化器，比较优化前后所有符号区域，返回首个语义差异。用先allow all后deny磁盘、deny后精确allow、类型a、权限子集和边界4095测试，输出能实际获得宿主磁盘w权限的最小规则链见证。
