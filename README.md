分区控制器将一组键区间拆分给配置不同的副本组。为提交路径写可导入的 Go 包：每个候选日志条目给确切键区间、前驱指纹、值摘要和签收节点；切换记录同时包含旧组与各新组所覆盖的区间，其生效条件是旧侧写仲裁和每个非空新段的接管仲裁都成立。仲裁用单调布尔表达式定义，同一物理节点可出现在多个组；一个节点在同一任期不能签收重叠区间上不同的后继。输入部分签收只给若干可能的条目，且同一签收在全局只能归属一次。请判定指定读范围是否在所有合法补全中均能给出同一提交视图；能则输出压缩视图与证书，不能则输出两份可重放补全及最小分歧键，若无合法补全另报矛盾。各重叠分量至多十六个含糊签收，不逐键展开或复制无关分量。小域全补全枚举核对，覆盖分裂两侧各自看似达标却争用同一签收、分裂后又合并及只有单个键发生分歧。
