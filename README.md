服务滚动升级时，同一份经过校验的缓冲会同时交给新旧两种消费视图。给 C++17 消息宿主实现可嵌入的联合准入组件，输入只包含抽象的定长或有界变长字段布局、字段读取区间和一张受签的可见性清单。字段可引用共享子对象，也可根据同一公开判别值选择一种布局；一个判别值在所有相关引用中必须作同一解释。允许旧字段映到多个新片段，但不得让不可见字节通过新别名成为可读字段。检查对所有符合冻结布局的消息长度和判别值，两种视图均只读各自获准的字节，且承诺兼容的字段在两边取得相同的字节序列。长度区间可大至 2^40，不可逐字节展开。宿主可提供按判别值和长度边界压缩的证明，独立校验入口要拒绝漏掉的类别和重叠字段中的矛盾解释。失败只报告布局与权限义务编号；成功才发绑定两份布局摘要及策略代次的只读句柄。用小空间穷举对照共享对象在两个入口具有不同可见性、变长字段跨边界、迁移前后判别值重命名和策略撤销。
