# mutest — 小语言的精确变异测试工具

对一类支持整数加减、比较和条件分支的小语言做单点变异测试。
在有限输入域内把每个变异体与原程序**精确比较**，将变异体分为三类：

- **killed**：被测试套件杀死的变异体（给出杀死它的测试输入）；
- **equivalent**：在整个输入域上与原程序行为完全一致的等价变异体；
- **surviving**：未被杀死且不等价的存活变异体（给出区分它和原程序的反例输入）。

所有整数都是**有符号 8 位**，加减法溢出按二进制补码回绕（如 `127 + 1 = -128`）。

## 语言

```
program := ["input" ident ("," ident)*] stmt*
stmt    := ident "=" expr
         | "if" expr "{" stmt* "}" ["else" "{" stmt* "}"]
         | "return" expr
expr    := add [cmpOp add]              # 比较不结合，最多一层
add     := unary (("+"|"-") unary)*
unary   := "-" unary | primary
primary := num | ident | "(" expr ")"
```

- 值动态分型：整数（int8）与布尔；比较产生布尔，`if` 条件必须是布尔。
- 整数字面量按 int8 回绕解释（`128` 即 `-128`）。
- `#` 开始行注释。

示例见 `examples/demo.mut`：

```
input a, b
d = a - b
if d < 0 {
    r = 0
} else {
    r = d
}
return r
```

## 变异算子（均为单点变异）

| 算子 | 含义 |
|------|------|
| AOR  | 算术运算符替换：`+` ↔ `-` |
| ROR  | 关系运算符替换：`==` `!=` `<` `<=` `>` `>=` 两两互换 |
| CRR  | 常量替换：`c → c+1` 与 `c → c-1`（int8 回绕） |
| CND  | 条件取反：`if c` → `if !c` |

## 用法

```
go build -o mutest .
./mutest [-tests file] [-domain boundary|full] [-max n] program.mut
```

- `-tests`：测试套件文件，每行一组逗号分隔的输入值（按 `input` 声明顺序），
  值必须在 [-128, 127] 内；`#` 为注释。参见 `examples/tests.txt`。
- `-domain`：每个输入变量的取值集合。`boundary`（默认）为
  `{-128, -127, -2, -1, 0, 1, 2, 126, 127}`；`full` 为全部 256 个 int8 值。
- `-max`：输入组合数上限（默认 4,000,000），防止全域 × 多变量的组合爆炸。

分类流程：先用测试套件杀死变异体；对存活者在整个输入域上枚举比较，
找不到区分输入的判为等价，否则报告反例（含原程序与变异体各自的输出）。
给出测试套件时还会输出变异得分（等价变异体不计入分母）。
