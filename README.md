# interval-regex

带捕获区间的正则匹配库（TypeScript）。支持：字面量、`\` 转义、分组 `(...)`、
并集 `|`、连接、星号 `*`（优先级 `*` > 连接 > `|`，`*` 可叠加）。

## 匹配语义

1. **最左起点**：从位置 0 起，取第一个存在匹配的起始位置。
2. **最长整体**：该起点下取整体匹配最长的路径。
3. **按组顺序选最长捕获**：整体长度并列时，按组号（左括号出现顺序）依次裁决——
   参与的组优先于未参与的组；都参与时捕获区间更长者优先；长度相同取起点靠前者
   （仅为确定性兜底）。
4. **未参与 ≠ 空捕获**：未参与的组输出 `null`，空捕获输出 `[i, i]`，严格区分。
5. **星号迭代重置**：星号体内含的捕获组在每轮迭代开始时重置，最终捕获来自最后
   一轮迭代（与 ECMAScript 量化组行为一致）。
6. **零长度循环防护**：星号体若匹配空串，该轮捕获计入结果后立即停止展开，
   不会死循环（如 `(a*)*`、`|()*`、`|((|a)b*)*` 等均可安全匹配）。

## API

```ts
import { compile, exec } from "interval-regex";

const re = compile("(a|ab)(c|bcd)");
re.groupCount;          // 2
re.exec("abcd");
// { start: 0, end: 4, groups: [ {start:0,end:1}, {start:1,end:4} ] }

exec("(a)|(b)", "b");
// { start: 0, end: 1, groups: [ null, {start:0,end:1} ] }
```

`MatchResult.groups[i]` 为第 `i+1` 组的捕获区间（半开 `[start, end)`，
按 UTF-16 码元计），`null` 表示未参与。无匹配时 `exec` 返回 `null`。

## 验证方法

测试分两部分（`test/regex.test.ts`）：

- **显式用例**：人工推导的期望结果，覆盖空组/未参与组区分、嵌套空分支、
  星号迭代重置、最左最长等语义点。
- **穷举交叉核对**：`{a,b}` 上全部长度 ≤ 4 的串（外加若干含其他字符的串）
  × 40+ 个含嵌套空分支的模式，与 `test/reference.ts` 的**独立参考实现**逐一比对。
  参考实现不复用库代码：它把每个星号有界展开为“重复 0..K 次”的并集
  （K = 文本长度 + 1；消耗字符的迭代至多 len 次，空迭代只有最后一轮可能影响
  最终捕获，故 +1），得到无星语法树后用状态集模拟穷举全部匹配路径。
  全程不调用宿主（JS）正则引擎。

注意：匹配器按“枚举全部路径”实现，最坏情况复杂度为指数级，适用于小输入与
测试场景，不适合对大文本运行病态模式。
