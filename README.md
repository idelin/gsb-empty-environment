多租户 API 网关暴露 GraphQL 端点时，若仅在顶层解析器校验登录态且按简单括号层级限制深度，攻击者可通过在同一层使用数百个别名（Alias）重复调用高开销查询发动批量撞库/DoS、借助具名片段（Fragment）与内联片段（`...on`）相互引用触发解析栈溢出，或用 `@include`/`@skip` 变量组合绕过静态权限扫描访问受限租户字段。为 TypeScript 服务端宿主实现可导入的零外部依赖 GraphQL 词法/语法解析器与静态安全策略验证组件。组件从零解析查询文档（操作定义、变量、选择集、别名、参数、指令、具名与内联片段）并与给定 Schema 及角色字段策略表联动：（1）检出任意直接或间接的片段循环引用（禁止指数级片段展开炸弹）并精确计算展开后的最大查询深度、别名总倍数与节点加权复杂度（含列表参数 `first`/`limit` 乘法因子），任一超限即在执行前硬拒绝；（2）对每个可达字段（无论藏于片段、别名还是 `@include`/`@skip` 条件分支中）执行最坏情况字段级授权检查与内省字段（`__schema`/`__type`）阻断，并校验所有变量引用类型匹配与敏感租户作用域参数不可被客户端覆盖；（3）输出全部违规字段的规范路径、片段展开链与确定性复杂度上界。附别名放大攻击、间接循环片段、条件指令越权与合法嵌套查询测试集。
