# LSDB 路由计算器

本地链路状态数据库(LSDB)+ 最短路查询,TypeScript 实现,Node 内置测试。

## 语义

- 有向图,权重为非负整数;每条边更新携带源节点的 `(epoch, seq)` 版本,按二元组字典序比较新旧。
- 同版本同内容 → 忽略(平行/重复投递去重);同版本内容冲突 → 抛 `VersionConflictError`;旧版本 → 忽略。
- 删除边保留带版本的墓碑,旧版本的新增无法复活;只有更新版本才能复活。
- `applyBatch` 两阶段提交:批次内任何冲突或非法输入都导致整批回滚,原子可见。
- 路由选择:距离 → 跳数 → 完整节点 ID 序列字典序;零权环下必然终止。
- 不可达通过 `{ reachable: false }` 单独返回,不用任意大数冒充无穷。
- `routesFrom(source)` 输出每个目的的距离、下一跳、完整路径与版本(路径最后一条边的版本),带缓存;
  缓存失效范围包含被删边影响的路径(按路由依赖边 + 可达性精确失效)。

## 运行测试

需要 Node ≥ 23.6(原生类型擦除),或 Node ≥ 22.6 加 `--experimental-strip-types`:

```sh
node --test
```

## 文件

- `src/lsdb.ts` — LSDB、版本裁决、原子批次、带缓存的最短路查询。
- `src/verify.ts` — 独立校验器:Bellman-Ford 核对距离/跳数,穷举简单路径核对决胜顺序。
- `test/lsdb.test.ts` — `node:test` 测试:平行输入去重、旧删除/墓碑、节点重启升 epoch、
  零权环、等距路径决胜、批次回滚、不可达、缓存失效,以及 40 组随机小图交叉核对。
