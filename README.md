# 员工绩效考评时态指标账本（Temporal KPI Ledger）

跨考评周期的 KPI 目标时态管理组件。目标值与权重随组织战略在考核周期内
按版本调整；每个版本是不可变、带责任人签名的战略快照，赋值（目标值 +
权重）落在半开日区间 `[from, to)` 上。支持在任意历史快照下重算季度末
加权得分，并输出版本变更的得分影响与责任人签名。

仅使用 Go 标准库。

## 设计

- **追加式版本库**：`Ledger.Append` 记录新版本，旧版本永不修改，可任意
  回放历史快照（`Score(versionID, actuals)`）。
- **时态赋值**：`Assignment{KPI, Target, Weight, Valid: [from, to)}`，
  日内权重按天平均为期末有效权重 `Σ weight(day) / periodDays`。
- **追溯调整**：新版本可覆盖任意历史区间（如第 45 天追溯调整全季度），
  `ActiveAt(versionID, day)` 给出某快照下任意一天的生效权重。
- **版本签名**：每个版本的内容（责任人、说明、记录日、全部赋值）经
  SHA-256 签名，`Impact` 报告携带新版本责任人及其签名用于审计。
- **期末得分**：`Score = Σ_kpi 有效权重 × (实际值 / 目标值)`。

## 验收场景

Q1 共 90 天（日区间 `[1, 91)`）：

- v1（carol，第 1 天）：A 权重 0.6 于 `[1, 60)`、0.4 于 `[60, 91)`；
  B 权重 0.4 于 `[1, 60)`、0.6 于 `[60, 91)`。
- v2（alice，第 45 天记录）：追溯调整全季度 —— A 权重 0.4、B 权重 0.6，
  均于 `[1, 91)` 生效。
- 实际值：A = 110（目标 100），B = 40（目标 50）。

结果：调整前 0.959333，调整后 0.920000，差值 **-0.039333**，影响记录
绑定 alice 的版本签名。
