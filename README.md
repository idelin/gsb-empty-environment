可串行化快照隔离（SSI）不阻塞读写，而是通过追踪读写反依赖（rw-antidependency）检测形如 T1 -rw-> T2 -rw-> T3 的危险结构来决定中止事务，但对满足安全快照条件的只读事务应予豁免。为事务管理器交付可导入的 Go SSI 冲突检测包。输入并发事务的启动、读键或范围（加 SIREAD 谓词锁）、写键、提交与中止事件，以及事务是否声明只读安全（READ ONLY DEFERRABLE）。规则：当活跃事务 T1 读取了键 k（或覆盖 k 的范围），随后并发事务 T2 写入 k（T2 在 T1 快照不可见），即建立有向反依赖边 T1 -rw-> T2；若存在枢轴事务 T2 同时具备入边 T1 -rw-> T2 与出边 T2 -rw-> T3 且 T3 已先于 T1 和 T2 提交（或 T1=T3 形成两事务写偏斜环），则检测到危险结构，须在提交检查点优先中止尚未提交的枢轴 T2（若 T2 已提交则中止当前企图提交的 T1）；若 T1 为只读事务且其快照启动前所有并发读写事务均无指向 T1 之后的提交链，则豁免中止。验收用串行化依赖图（DSG）环检测对照，覆盖经典双事务写偏斜、三事务链状危险结构中 T3 先提交触发 T2 中止、范围谓词锁捕获幻读插入，以及只读安全快照豁免假阳性中止。
