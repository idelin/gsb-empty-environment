# Web Locks跨分区复用了同一锁名

不同顶层站点下的同源页面若共享同名Web Lock，第三方可探测或阻塞另一站点的敏感操作。给TypeScript浏览器宿主实现可导入的锁管理包：锁身份绑定storagePartition、origin、lockName原始UTF-8和hostPolicyGeneration；请求模式Shared/Exclusive，含documentGeneration、requestID、截止时刻和可选ifAvailable。每身份维护按请求序号严格FIFO的等待队列；Exclusive与任何持有者冲突，Shared仅与Exclusive冲突，连续Shared可成批授予但不能越过更早Exclusive。授予产生不可转移lease，绑定文档代次和随机leaseID；回调完成、AbortSignal、截止、导航或策略撤销释放，释放恰一次。ifAvailable冲突时立即返回未获得且不入队，不能暴露其他分区是否持锁；查询接口只返回本分区/源且调用文档有权看的锁。host策略变化使旧Pending拒绝，已授予lease按策略可立即撤销；迟到回调不得释放复用后的同名新lease。实现确定调度器与两个顶层分区，验证同名锁互不阻塞、FIFO/共享批次、导航释放、取消与授予竞争及leaseID复用。另用待审key回调搜索键碰撞导致跨分区阻塞或时序观察的最短轨迹。
