# unitinfer — 单位推导器

以基本量的整数指数向量表示单位（如 `L^2 M T^-2`），对表达式做单位推导，
输出**最一般约束解**（参数化通解），或在约束矛盾时输出**最小冲突表达式集合**。

## 表示

- 单位项 `Term` = 常量指数向量 + 单位变量的整数线性组合（`term.go`）。
- 每个表达式节点、每个程序变量分配一个单位变量；加减要求两边相等，
  乘除对应指数加减，整数幂 `x^k` 对应指数乘 `k`（`infer.go`）。
- 函数签名 `FuncSig` 可含签名局部单位变量，每次调用 freshen，
  实现单位多态（如 `sq: α → α²`）。

## 求解

- 约束 `Term = 0` 按维度展开为线性方程组，用 `big.Rat` 精确
  Gauss-Jordan 消元求特解 + 零空间整基（`solve.go`）：
  `x = Part + Σ tⱼ·Basis[j]`，即最一般解。
- 欠定变量保留自由参数 `p0, p1, ...`，**不会**被随意置为无量纲；
  `Solution.IsFree` 可查询。
- 矛盾时用删除法提取最小不可满足子集（MUS），并映射回表达式节点，
  得到最小冲突表达式集合（`conflict.go`）。

## 验证

`CheckInclusion`（`enum.go`）在小指数域 `[-2,2]` 上枚举全部整数解，
双向检查解集包含关系：枚举解都能被参数化通解表示（E ⊆ P），
且参数扫描产生的每个域内整点都满足原约束（P ∩ Z ⊆ E）；
同时报告被压成单值的变量，用于确认欠定变量未被钉死。

## 运行

```sh
go test ./...     # 单元测试（含枚举包含关系检查）
go run ./cmd/demo # 演示：动能公式 / 欠定表达式 / 冲突定位
```
