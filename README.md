# 列目录的前缀条件被分隔符绕过

对象存储桶策略用`s3:prefix`限制列目录范围，攻击者给`ListObjectsV2`带上`delimiter`与父前缀，响应聚合出其他前缀的对象键。请实现供Go对象存储网关调用的可导入桶策略判定组件。对列表请求同时考虑prefix、delimiter、start-after与max-keys，按每个返回键与公共前缀逐项判定是否在允许前缀内；delimiter不得把受限前缀折叠成父级公共前缀。分页令牌绑定原始参数与策略代次，策略变更后旧令牌失效。用delimiter绕过、父前缀、start-after、分页令牌重放、合法前缀列举和策略更新验证不返回范围外键。
