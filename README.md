# 安全规则证书独立核验

分析器输出复杂约束证明，接入层不能信任分析器自报“安全”。写供Go接入宿主调用的证书核验包，证明规则限定为区间包含、交集、加常数和分支合流，每步引用先前步骤且绑定原指令；拒绝循环引用、越界编号与非法强化。用独立小域语义验证所有被接受结论，再逐字段篡改证书测试拒绝定位。

## 接入方式

```go
cert := &netsec.Certificate{ /* 分析器提交的程序、证明步骤与最终结论编号 */ }
if err := netsec.Verify(cert); err != nil {
    var verr *netsec.Error
    if errors.As(err, &verr) {
        // verr.Step 定位出错步骤（-1 为证书级字段），verr.Field 定位字段，verr.Reason 为原因
    }
    // 拒绝该结论
}
```

- `cert.go`：区间、指令、规则与证书类型；区间运算（包含、交集、凸包、饱和加常数）。
- `verify.go`：结构检查与逐条规则推演，拒绝循环/前向引用、越界编号、非法强化。
- `semantics.go`：独立小域（[-64,64]）逐值语义复核，防御规则实现缺陷。
- `cert_test.go`：合法证书接受、逐字段篡改拒绝定位、边界与溢出用例。
