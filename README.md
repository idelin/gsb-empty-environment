# keyshift

可变主键的原子重键引擎。纯 Python 3.11 标准库实现，测试使用 `unittest`。

## 语义

- **原子重键**：一笔事务内先摘下全部旧键索引、再挂全部新键索引；
  校验或落库任一环节失败，整笔事务失败并按撤销日志回滚，绝不部分落库。
- **冲突检测**：新键已被占用且占用者不在同事务内让出，则整笔失败；
  同一事务内允许两实体交换键（乃至多实体成环轮换）。
- **稳定身份**：每个实体持有单调分配、永不复用的 `entity_id`，
  与可变主键解耦；退役身份进入 `retired_ids`，核验器保证不复用。
- **反向引用同步**：反向索引以 `(表, entity_id)` 为键，主键变更时
  同事务级联修订所有引用行的外键值（跨表外键更新与主键变更同属一笔事务）。
- **版本隔离**：事件携带 `(tx_id, commit_seq)`；重复事件不再次移动，
  提交序号落后于当前版本的旧键迟到事件被隔离并记录，键的版本谱系
  存于 `key_history`。
- **一致性快照**：`db.snapshot()` 提供冻结深拷贝；独立核验器
  `verify_model` 在任意可读快照上校验索引、外键、反向引用与身份约束。
- **本地夹具**：变更来自本地 JSON 文件，字段为事务 ID、表、主键
  前后值与提交序号；不接入任何消息平台。

## 结构

- `keyshift/model.py` — 实体、表、索引、反向引用、快照
- `keyshift/engine.py` — 事务分组、冲突校验、两阶段落库、回滚
- `keyshift/events.py` — 本地夹具加载与校验
- `keyshift/verify.py` — 独立全量关系模型核验
- `fixtures/sample_events.json` — 示例事件（交换/冲突/迁移/重复/迟到）
- `main.py` — 运行样例；`test_keyshift.py` — 17 个 unittest

## 运行

```sh
python3 main.py            # 演示：交换 u1<->u2、冲突整笔失败、u3->u30、隔离记录、快照核验
python3 -m unittest -v     # 测试
```
