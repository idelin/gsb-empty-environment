实时网关处理 WebSocket（RFC 6455）握手与二进制帧流时，若忽略 `Origin` 白名单校验、未验证 `Sec-WebSocket-Key` 规范格式，或放过客户端发送的未掩码帧（`MASK=0`）与控制帧分片/超 125 字节载荷，攻击者可发动跨站 WebSocket 劫持（CSWSH）或利用协议走私污染代理缓存。为 TypeScript 网关宿主实现可导入的零外部依赖（仅用 `node:crypto`）RFC 6455 握手安全门禁与原始字节级帧状态机组件，严禁联网。组件在握手阶段严格校验 `GET` 方法、`Upgrade: websocket`、`Sec-WebSocket-Version: 13`、24 字符 base64 `Sec-WebSocket-Key` 精确计算 `Sec-WebSocket-Accept`，并强制 `Origin` 精确命中允许源集合（拒绝 `null` 与子域后缀欺骗）且绑定一次性 CSRF 握手令牌；在帧解析阶段强制要求客户端上行帧必须 `MASK=1`、控制帧（`Close`/`Ping`/`Pong`）`FIN=1` 且载荷 `<= 125` 字节、保留位 `RSV1-3` 在未协商扩展时全为 0、禁止在分片消息中间插入非控制帧，并校验 UTF-8 文本帧与 Close 状态码合法性。附 CSWSH、未掩码帧、控制帧分片与非法 UTF-8 拦截测试。
