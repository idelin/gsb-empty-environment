# 宿主路径挂载的前缀与规范化判定

集群准入策略只允许工作负载挂载少数宿主目录，攻击者在 hostPath 里写 /var/log/../run/containerd，或挂载某个允许目录下指向根的符号链接，把运行时套接字和宿主根文件系统暴露给容器。为Go准入控制器写可导入的宿主路径判定包，输入卷的 hostPath（路径、type）、容器的 volumeMounts（含 subPath 与 subPathExpr）、调用方的允许前缀白名单、禁止清单和宿主文件系统的符号链接表：路径必须是绝对路径，先去掉重复斜杠与 . 段，遇 .. 段按词法折叠，折叠前后两个结果都要落在白名单前缀内，前缀按路径段边界比较；符号链接表给出的链接逐段展开，展开结果须仍在白名单内；折叠后命中禁止清单（根目录、/proc、/sys、/etc、/var/lib/kubelet，以及形如 *.sock 的套接字文件）一律拒绝，即使它在白名单前缀之下；type 为空时不做存在性检查，仍按路径判定；subPath 与 subPathExpr 含 .. 段、绝对路径或展开后越出卷目录时拒绝；readOnly 为 false 的挂载只允许白名单里标注可写的前缀。用 .. 折叠、符号链接指向根、*.sock、前缀边界 /var/log2 和 subPath 逃逸验证。
