# shardalloc — 加权分片分配器

按节点权重把分片摊派为**整数配额**，在满足配额的所有方案中取**搬迁最少**者，
并输出搬迁下界证明。一切并列按节点编号（分片编号）升序决胜，结果完全确定。

## 用法

```go
nodes  := []allocator.Node{{ID: "n1", Weight: 5}, {ID: "n2", Weight: 3}, {ID: "n3", Weight: 1}}
shards := []allocator.ShardID{"s0", "s1", ...}
old    := map[allocator.ShardID]allocator.NodeID{ /* 旧归属，可为 nil */ }

plan, err := allocator.Allocate(nodes, shards, old) // 计算最小搬迁分配
err = allocator.Verify(plan, nodes, shards, old)    // 独立复核配额与下界
fmt.Println(plan.Proof())                           // 人类可读的下界证明
```

## 设计要点

- **精确配额**：最大余数法（Hamilton 分摊），纯整数运算。配额之和恒等于
  分片总数，每个节点配额与理想值 `N·w_i/Σw` 的偏差严格小于 1，不是近似均衡。
  余数并列时节点编号小者优先。
- **最小搬迁**：每个节点保留 `min(旧持有, 配额)` 个分片（编号小者优先保留），
  其余进入待分配池，按节点编号升序依次用编号最小的分片补齐缺口。
- **下界证明**：任何满足配额的方案中，节点 i 上归属不变的分片至多为
  `min(旧持有_i, 配额_i)`，已下线节点上的分片必然迁出，故
  `搬迁数 ≥ (有旧归属的分片数) − Σ_i min(旧持有_i, 配额_i)`。
  本方案逐项达到该上界，`Migration == LowerBound`，最优性得证。
- **边界场景**：新增节点按配额迁入；节点下线（从列表移除）其上分片全部迁出；
  权重归零等价于平滑下线（配额为 0）；新增分片计入迁入但不计入搬迁；
  全零权重且有分片待分配时返回错误而非静默给出近似结果。
