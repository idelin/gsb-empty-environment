站点隔离升级后，浏览器重放会话时无法解释为什么第一次重定向携带 Cookie，第二次却没有。实现可导入的 TypeScript 携带决策包和离线验收器。输入是浏览上下文树、每个祖先最近一次提交的来源、发起者、顶层站点、重定向链与策略版本。来源可为不透明身份，有唯一编号；字面 URL 相同不代表可合并，且沙箱化 iframe 与 data URL 继承不透明来源。公共后缀由宿主给出可换版的右向标签规则，含精确、通配和例外。按题内约定：请求的站点上下文须在发起时冻结；重定向只会收紧其同站等级，不能靠最后一跳洗回同站；分区 Cookie 键由顶层站点及祖先链中是否存在跨站边组成。一次导航的暂定上下文不得影响仍在途的旧请求，恢复旧页要恢复它原有的身份；策略版本变化不能追溯改写既有发送回执。决策证书需解释同站、分区及每次重定向的约束；独立验收器可只取相关祖先与后缀规则的包含或缺省证明，不接受遗漏例外规则的证明。用冻结快照的参考重算对照导航回滚、public suffix 例外、多重不透明来源、跨站再回同站和同 URL 但顶层分区不同的两条链。
