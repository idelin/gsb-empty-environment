# 资源继承切断语义

云资源可以阻止继承父级安全标签，迁移子树后不能把旧继承值当作显式标签。实现供Go资源宿主调用的标签解析包，分别保存显式值、继承值与切断标记，父级变更只重算受影响闭包；删除显式值可恢复继承，切断仍阻止穿透。用多层树和移动事务核对来源证明，旧快照保持原路径解释。

## 模型

包 `netsec` 维护一棵（或多棵）资源树。每个节点对每个标签键独立保存三种状态：

- 显式值（`explicit`）：直接写在节点上的标签，解析时优先级最高；
- 继承缓存（`inherited`）：沿父链解析得到的值，附带来源证明 `Provenance`
  （来源节点、值、节点到来源的完整路径，以及是否被切断）；
- 切断标记（`blocked`）：阻止某个键从祖先穿透到本子树，显式值仍可在本节点
  覆盖切断并向下重新开放。

## 解析语义

- 沿父链向上遇到的第一个显式值即为继承来源；
- 切断标记拦截继承，并在缓存中以 `Blocked: true` 记录设置标记的节点；
- 删除节点的显式值后该键重新走继承；若同键存在切断标记，继承仍被拦截；
- 任意变更只对以变更节点为根的闭包做 DFS 重算，闭包外的缓存与来源证明保持
  不变；
- 子树移动在事务中进行：提交后仅重算被移动闭包，旧的继承缓存不会被提升为
  显式标签；回滚则完整恢复拓扑、缓存与来源路径；
- 快照是深拷贝的不可变视图，移动或删除后仍按捕获时的旧路径解释来源证明；
- `VerifyProvenance` 重新走当前（或快照内的）祖先链，逐条核对缓存中的来源、
  值、路径与切断状态。

## 用法

```go
f := netsec.NewForest()
_ = f.AddNode("root", "")
_ = f.AddNode("vm", "root")
_ = f.SetTag("root", "env", "prod")

tags, _ := f.EffectiveTags("vm") // env=prod，来源 root

_ = f.BlockInheritance("vm", "env")
tags, _ = f.EffectiveTags("vm") // 空：切断阻止穿透

txn, _ := f.BeginMove("vm", "other-host")
_ = txn.Commit() // 仅重算 vm 闭包，旧继承值不会变成显式标签

snap := f.Snapshot() // 不可变快照，永久保留旧路径解释
ok, _ := f.VerifyProvenance("vm")
_ = ok
```
