# QUIC重置令牌重用关闭新连接

边缘网关轮换QUIC连接ID时若过早复用stateless reset token，能观察旧流量的攻击者可以伪造短包关闭无关新连接。请实现供QUIC栈调用的Go连接ID与重置令牌生命周期组件。每个token由当前密钥代次、路由分区和完整CID经HKDF派生，CID签发、retire、peer确认、连接关闭和密钥轮换都进入确定状态机；旧token至少保留到对应CID的最大包寿命与确认宽限均结束，但只能匹配旧连接，任何CID值在隔离期内不得重新签发。检测重置时先完成最小长度、固定比特和不可由已知短首部成功解密等检查，再以常量时间比较尾部16字节；普通无效包、NAT重绑定和乱序RETIRE_CONNECTION_ID不能触发关闭。密钥销毁前核对没有活跃或隔离CID引用，崩溃恢复日志必须防回滚重发。以可控时钟、丢包和CID生成器验证旧包重放、令牌碰撞注入、跨路由分区、崩溃回滚与合法重置，并返回导致状态转换的审计见证。
