递归 DNS 解析器的响应策略区（Response Policy Zones, RPZ）允许运维按顺序叠加多个策略区对查询或应答实施精准拦截与改写，规则优先级与编码规范极易写错：1）支持完整五类 RPZ 触发器——`RPZ-CLIENT-IP`（客户端源 IP）、`QNAME`（原查询域名及 `CNAME` 链上每一跳别名！）、`RPZ-NSDNAME`（权威 NS 主机名）、`RPZ-NSIP`（权威 NS 的 IP）与 `RPZ-IP`（应答段中的 A/AAAA 记录 IP），IP 触发器须严格遵循标准反向 CIDR 域名编码（IPv4 如 `24.0.1.168.192.rpz-ip` 对应 `192.168.1.0/24`；IPv6 支持 `zz` 单次零段压缩编码如 `48.zz.db8.2001.rpz-ip` 对应 `2001:db8::/48`！）；2）支持完整七类策略动作：`NXDOMAIN`（`CNAME .`）、`NODATA`（`CNAME *.`）、`PASSTHRU`（`CNAME rpz-passthru.`）、`DROP`（`CNAME rpz-drop.`）、`TCP-ONLY`（`CNAME rpz-tcp-only.`）、本地数据替换（A/AAAA/TXT/CNAME 改写）及递归通配符匹配（`*.bad.example` 匹配子域但不匹配裸域 `bad.example`！）；3）**多策略区与多触发器精确决胜序**：严格优先按策略区配置顺序（高优策略区任意命中压倒低优策略区！）；同一策略区内按触发器优先级 `CLIENT-IP > QNAME > NSDNAME > NSIP > IP`；同区同触发器下按最长前缀/最精确域名（精确名优先于通配符，更长 CIDR 掩码优先于短掩码！）决胜；一旦高优规则命中 `PASSTHRU`，立刻停止求值后续更低优先级策略区并放行原始 DNS 应答！4）支持 `CNAME` 链逐跳审查（对原名及每跳 `CNAME` 目标按顺序执行 `QNAME` 触发检查，避免攻击者经合法域名 `CNAME` 跳转至恶意域绕过！）与 `min-ns-dots` 防误伤根/顶级域权威。为 DNS 解析服务交付可导入的 Go RPZ 策略区编译与裁决引擎包。验收覆盖 IPv4/IPv6 `zz` 反向 CIDR 编码解析、多区顺序与 `PASSTHRU` 阻断低优策略、同区五类触发器优先级与最长前缀决胜、通配符不匹配裸域以及 `CNAME` 链逐跳拦截。
