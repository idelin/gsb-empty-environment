推理后端已把融合张量的根存储切成若干不重叠字节段，段的生存期不同，但设备指令仍只允许给整个根存储打一个基址。交付后端可导入的 Go 放置包和指令重定位适配器：每个根给出大小、二次幂对齐及若干半开段；每段有唯一写入节点及读取节点列表，图由流内次序与显式等待构成。写和所有读均为访问，读须严格晚于写。两个不同根的段若映射到同一物理字节，仅当图保证其中一段的所有访问严格早于另一段的写时才可复用；同节点不足以证明先后。段间空洞无访问，但根的完整大小均占用地址上界，不能拆散根以节省空间。指令经任意深度的切片视图访问，偏移相对直接父视图；拒绝视图环、越界、落在空洞或跨越分段的非空读写。求最小地址上界（所有基址加根大小的最大值），同上界取输入顺序上字典序最小的整组基址。最多八个根，每根至多四段，地址和大小允许到 2^48；不得枚举从零到上界的每一个地址，不得按固定根次序做一次最低地址首次适配就声称最优。返回按原指令顺序重定位的物理访问及每对相交段的先行方向见证；独立重放器须沿真实依赖边核证方向，不得给图补边。用小地址空间全枚举比对最优上界和稳定基址，再实跑一个极大空洞例，覆盖同两根不同段分别靠相反先行关系合法复用、嵌套切片的局部坐标以及为给后续高对齐根让位而必须上移首根的例子。
