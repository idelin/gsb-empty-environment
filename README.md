发布平台有多级安全基线和带期限的豁免，资产拆分或改名后，旧豁免不得自动扩大到新资产。给 TypeScript 检查宿主实现可导入的生效策略解析包。资源身份由签名租户根、不可变资源 ID 与路径版本组成。继承图不是树，同项约束按严格度求交，集合为空为冲突，不能回到默认。豁免可仅取消由指定签名来源引入的一项约束，且只适用于签发时承诺的资产集合；同一文字约束由两个来源引入时需分别处理。资源范围用路径段有限自动机与受签名根保护的成员证明表示。对一个变更方案求有效约束在哪些资产语言区域收紧、放宽、保持和仅因缺证明而未知；输出不相交的符号区域及独立验收的继承来源链。支持有向环中的无新增约束继承，递增约束传播需取稳定结果，不能因回访节点就跳过另一条有效支撑。用小图逐路径全枚举对照两份看似相同的豁免、旧路径出现新资源、同一资源改名、区间开闭边界与交叉继承撤销。
