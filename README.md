# contour

从二值图提取四邻接边界的 Go 库：按 4-连通性标记前景区域（角接触区域彼此分开），
输出可回放的边环及其来源区域，并以单位边计数和洪泛背景模型做交叉验证。

## 功能

- **区域统计**：每个 4-连通区域的面积（像素数）、网格周长（前景/背景间单位边数，
  含图像外边界）和孔洞数（内环数）。
- **可回放边环**：每条边界是整数格点上的闭合环（`Loop`），携带来源区域 ID 与
  类型（`Outer`/`Hole`）；`Loop.Edges()` 重放为有向单位边序列，`Loop.Moves()`
  给出紧凑步进串，`Replay()` 可还原顶点序列。
- **角接触分离**：仅在角点相接的前景格属于不同区域，各自成环；同一区域边界
  自接触（对角捏合）时，外环与孔环在该顶点分开、共享顶点但不合并。
- **交叉验证**（`Result.Validate()`）：
  1. 回放：所有环重放出的有向边集合与独立生成的边界边完全一致；
  2. 周长：每区域环长之和 == 单位边计数；
  3. 面积：每区域外环鞋带面积减去孔环面积 == 像素数；
  4. 孔洞：每个孔环包围的背景格属于洪泛模型的内部连通分量，且每区域
     孔环数与相邻内部分量数一致。

  当一个内部背景分量同时邻接多个区域（共享孔）或背景分量自身对角自接触
  （一个分量对应多个孔环）时，每区域孔洞数在拓扑上无唯一定义，
  `Validate` 会报告该歧义而不是静默通过。

## 用法

```go
res := contour.Analyze(contour.FromRows(
    ".##",
    "#.#",
    "###",
))
reg := res.Regions[0] // area=7, perimeter=16, holes=1
for _, l := range res.Loops {
    fmt.Println(l.Region, l.Kind, l.Points[0], l.Moves())
}
for _, p := range res.Validate() {
    fmt.Println("discrepancy:", p)
}
```

## 算法

边界提取采用裂缝跟随（crack following）：为每条前景/背景分界生成
"前景在左"的有向单位边，顶点处的后继边按连通性配对——对角顶点处若两个
前景格属于不同区域则绕前景象限配对（区域各自成环），属于同一区域则绕
背景象限配对（外环与孔环分离）。该配对是边界边上的固定置换，环即置换
的轨道。背景模型为对背景格的 4-连通洪泛，触界分量为外部，其余为孔。

坐标约定：x 向右、y 向下，格点 (x,y) 是单元格的角点；图像坐标下外环
鞋带面积为负、孔环为正。

## 测试

```
go test ./...
```

覆盖：单像素洞、一像素宽狭缝（无孔、单环进出狭缝）、自接触角
