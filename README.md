# floodsim — 时空栅格动态连通性与洪水蔓延模拟器

纯 Go 标准库实现的时空二维栅格状态演化仿真内核。在离散 tick 下模拟
地表淹没区域随降雨时序、渗透率与地形坡度的动态扩散，支持查询任意
历史时刻的积水连通区域边界多边形与道路通行断点列表。

## 模型

每个 tick 依次执行三个阶段：

1. **降雨注入**：`Rain[t]` 为第 t 个 tick 的全域均匀降雨水深（米）；
2. **渗透消减**：每单元按 `Infil[i]`（米/tick）下渗，不产生负水深；
3. **漫延再分配**：按水位（DEM 高程 + 水深）差向 4 邻低处转移，
   通量 `f = FlowRate * Δh / 2`，并按单元出流上限缩放，严格守恒。

## 主要 API

- `NewGrid(w, h, elev, infil)`：构建 DEM 栅格与渗透率场；
- `NewSimulator(g, rain)` / `Step()` / `Run(n)`：推进仿真并记录历史快照；
- `RegionsAt(t)`：时刻 t 的淹没连通区域（BFS 划分）及边界多边形
  （边界边定向链接成环，外边界逆时针、孔洞顺时针）；
- `BreakpointsAt(t, net)`：沿道路折线采样，输出被水体阻断的
  进入/离开断点列表；
- `DepthAt(t)` / `TotalWater(t)` / `SnapshotAt(t)`：历史状态查询。

## 运行

```sh
go test -v ./...   # 单元测试：守恒性、连通域、边界环、孔洞、断点
go run ./cmd/flood # 样例：V 形谷地 + 暴雨时序的逐 tick 演化
```
