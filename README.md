# configlease — 带版本约束的配置信息租约绑定器

集群动态配置分发与生效机制，仅使用 Go 标准库。

## 机制

- **租用**：工作节点通过 `Center.Issue` / `Node.Start` 向配置中心租用配置版本，
  获得绑定该版本号、带 TTL 的租约凭证（`Lease`）。
- **更新**：`Center.Update` 修改配置（如数据库密码），版本号 +1，
  并**撤销此前签发的全部租约**；`Center.Publish` 向各在线节点下发新配置与新租约凭证。
- **接客约束**：`Node.Serve` 仅在持有有效租约（未过期、版本与所持配置一致）时处理请求，
  否则返回 `ErrNoValidLease`。
- **续期**：`Node.Renew` 在到期前向配置中心换发新租约；旧租约已被撤销/过期时续期失败，
  节点立即停止服务。
- **脱网兜底**：脱网节点收不到撤销与推送，但旧租约会自然过期，
  节点凭本地过期判定主动停止接收流量，避免使用过期配置操作脏数据。

## 运行测试

```sh
go test -race -v ./...
```

## 运行样例

```sh
go run ./cmd/demo
```

演示完整验收流程：修改数据库密码 → 发布新配置并收回旧租约 →
脱网慢节点旧租约自然失效后拒绝服务 → 恢复联网后重新租用新配置。

## 文件

- `lease.go` — 配置中心（`Center`）、工作节点（`Node`）、`Config`/`Lease` 类型
- `lease_test.go` — 验收测试（假时钟，确定性）
- `cmd/demo/main.go` — 端到端运行样例
