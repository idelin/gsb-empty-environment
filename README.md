# metric-ledger

本地指标账本：季度考核权重可追溯修订，同一页面可同时回答
“当时看到多少分”（`asOfSeq` 历史时点）和“按现在规则重算是多少”（缺省查询）。
所有分数与权重均为约分后的整数分数（bigint 分子/分母），不依赖浮点误差容忍。

## 运行

```sh
npm test          # 等价于 node --test 'test/*.test.ts'（Node >= 22.18，原生类型擦除）
```

## 模型

- 事件共享全局唯一录入序号 `seq`：修订 `revision`、撤销 `revocation`、指标得分 `score`。
- 修订含业务有效半开区间 `[validFrom, validTo)`、规则 ID、整套指标权重（非负且和恰为 1）。
- 某日适用规则 = 覆盖该日、`seq <= asOfSeq`、未被可见撤销命中的修订中 `seq` 最大者。
- 撤销只在撤销序号之后生效，之后回退到仍有效的前一版。
- 缺分日期在结果 `missing` 中返回缺失指标，不当 0；季度总分为完整得分日的加权分算术平均。
- 结果含 `segments`：采用的规则版本及其日期段。

## 查询

```ts
ledger.queryQuarter('2025-01-01', '2025-04-01');        // 按现在规则（增量 + 日级缓存）
ledger.queryQuarter('2025-01-01', '2025-04-01', 1500);  // 当时看到的结果
ledger.queryQuarterScan('2025-01-01', '2025-04-01');    // 独立逐日扫描，用于对照
ledger.ingestBatch([...]);                              // 批量补录/修订/撤销
```

缓存按 `日期#时点` 粒度维护，事件只失效其受影响日期区间内的条目。
