# SlidingWindowHistogram — 滑动窗口直方图与高百分位数估算器

TypeScript 实现，零依赖，使用 Node.js 内置测试运行器（`node:test`）验证。

## 设计

**混合分桶**（固定桶宽 + 对数桶）：

| 区间 | 桶型 | 默认参数 | 误差界限 |
| --- | --- | --- | --- |
| `[0, 1000ms)` | 固定桶宽线性桶 | 桶宽 `0.1ms`，共 10000 桶 | 绝对误差 ≤ `0.05ms` |
| `[1000ms, 1h]` | 对数桶 | 相邻桶比值 `1.005`，共 1643 桶 | 相对误差 ≤ `(logBase-1)/2 = 0.25%` |

**滑动窗口与反向补偿**：

- 容量 `capacity`（默认 1000）的环形缓冲区，每个槽位仅保存样本的**桶索引**（`Uint32`），
  不常驻保存全部明细样本；总内存 `O(桶数 + 容量)`，约 50KB。
- `record()` 为 O(1)：窗口满时，最老样本的桶计数减一（反向补偿）后槽位被复用，
  实现窗口滑动过期。
- `quantile(q)` 在桶计数上按 nearest-rank 累计扫描，返回所在桶代表值
  （线性桶取算术中点，对数桶取几何中点），复杂度 O(桶数)。

**误差理论界限**：估计值与窗口内精确 nearest-rank 值落在同一桶内，故

```
|est - exact| ≤ max( fixedBucketWidth/2 ,  exact · (logBase-1)/2 )
```

默认参数下，对 `≥ 20ms` 的百分位值，相对误差 ≤ 0.25%，满足 ≤ 0.5% 的验收要求。

## 运行

要求 Node ≥ 22.18（原生 TypeScript 类型擦除，无需编译/依赖）。

```bash
nvm use          # 或任意 >= 22.18 的 Node
npm test         # node --test
npm run demo     # 运行样例
```

## 运行样例输出（`node src/demo.ts`）

```
窗口容量=1000 桶总数=11643 理论相对误差界限=0.25%

基线 1000 样本（窗口已满）   P90 est=112.25ms err=0.021% | P99 est=  213.75ms err=0.016%
压入 40 个 30s 极端毛刺      P90 est=132.35ms err=0.015% | P99 est=29934.44ms err=0.219%
毛刺滑出中（再压入 200 个）  P90 est=130.35ms err=0.009% | P99 est=29934.44ms err=0.219%
毛刺滑出中（再压入 500 个）  P90 est=120.95ms err=0.020% | P99 est=29934.44ms err=0.219%
毛刺全部滑出（再压入 1000 个）P90 est=102.55ms err=0.036% | P99 est=  167.85ms err=0.012%
```

极端毛刺（30s）进入窗口后 P99 立即抬升至 ≈30s；毛刺随窗口滑动被全部挤出后，
P99 灵敏回落至基线水平（≈168ms），全程与完全保留样本的精确值误差 ≤ 0.22%。
