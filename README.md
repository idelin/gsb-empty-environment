主库故障后，副本持有不同的、由同一批事务产生的已持久状态。恢复协调器不能选一个最像的副本猜测重放。请给协调器一个可导入的 Go 包。候选副本列出其已提交事务位图、精确键值和可查询的小组摘要（每项只返回指定事务组已提交数的奇偶）；哪一个是真实现场未知。一次恢复命令可提交一组事务的有序前缀，逐笔原子执行；已提交的事务按 ID 去重，既不重跑其读谓词也不再写。未提交的事务须满足完整半开区间读结果及前驱已提交，方可写入并设置提交位，否则命令在该笔前停止并返回拒绝编号。另有全程至多一次断连，环境可在命令任意两笔之间或首尾断开；只返回断连，不告知执行长度。探测摘要与提交命令各收费，探测可靠，提交命令不因拒绝或断连退款。固定可用命令库、目标键值及完整目标提交位图，输入均有限；失败或断连之前提交的事务绝不能回滚。一旦协调器宣布完成，所有相容现场必须都等于目标。合成最小最坏总费用的策略；无解返回可检查的不可能证书：对每个可发命令给出一个可发生的回执，使剩余不确定状态集仍处在证书覆盖的失败区域。费用为正，不能靠不断拒绝或探测相同摘要实现成功。交付按公开回执驱动的协调器及单副本执行器，策略不能查看真实位图。至多十个事务、六个键、十二个起始现场，允许按不同可达状态集增长。独立小实例核对最优费用、逐个断点验重复投递；特别测不同副本产生相同摘要、丢失末笔回执后重放、提交集相同但最终写者不同、以及仅凭可行短前缀就误报批次完成。
