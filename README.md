传统 Reed-Solomon `(k, m)` 纠删码在单盘故障时必须跨网络读取全部 `k` 个存活块才能修复，带来极高集群修复带宽放大；云存储系统广泛采用 **局部修复纠删码（Local Reconstruction Codes, LRC `(k, l, r)`，Azure/HDFS 风格）**，将 `k` 个数据块划分为 `l` 个局部组、每组配 1 个局部校验块，并附加 `r` 个全局校验块，四处代数与工程边界极易写错：1）**`GF(2^8)` 有限域算术与 LRC 生成矩阵构造**：基于不可约多项式（如 `x^8 + x^4 + x^3 + x^2 + 1`，`0x11d`）实现零查表越界的 `GF(2^8)` 加减乘除与求逆；构造 `(k + l + r) × k` 系统生成矩阵：前 `k` 行为单位矩阵，接下来 `l` 行为各局部组异或/加权局部校验行，最后 `r` 行为保证信息理论可解码性的柯西/范德蒙全局校验行（特别注意：全局校验系数必须保证任意 `r` 个故障加上每组 1 个局部故障的合法组合对应的子矩阵在 `GF(2^8)` 上**满秩可逆**！）；2）**单块故障零全局读取局部修复**：当仅某局部组内丢失 1 个数据块（或该组局部校验块）时，修复路径必须**严格只读取同组其余存活块（读取量仅 `k/l` 而非 `k`！）**即可位精确还原，并在指标中断言读取块集合不含其他局部组与全局校验块；3）**多块故障联合全局高斯消元重构与不可解判定**：当同时丢失 `2 .. (r + l)` 块时（例如某局部组丢 2 块 + 另一局部组丢 1 块，共 3 块 > `r=2` 但仍可借另一组局部校验协同解出！），自动从存活块中筛选满秩 `k × k` 子矩阵执行 `GF(2^8)` 高斯-约当消元完成位精确恢复；而当丢失模式落在信息论不可恢复集合（如同一局部组丢失 `r + 2` 块，即便总存活块 `>= k` 但子矩阵秩 `< k`！）时，必须返回明确不可恢复错误绝不可产出垃圾数据；4）**静默损坏（Silent Corruption）定位**：在全部块可读但某个块发生单字节静默翻转时，利用局部与全局伴随式（Syndrome）交叉定位被篡改的精确块号并自动纠错还原。为对象存储数据面交付可导入的 Go `GF(2^8)` LRC 编解码、低带宽局部修复与多故障全局重构包。验收覆盖任意 `k/l/r` 参数编解码位精确往返、单块故障仅读同组 `k/l` 块断言、跨组 `(r+1)` 块多故障联合满秩恢复、同组超限奇异子矩阵精确拒绝以及静默单块位翻转自动定位纠错。
