# 构造函数异常边上的未初始化引用

沙箱不能让构造失败的对象沿异常边变成可调用引用。请交付供Go字节码加载宿主调用的类型验证包，本题使用已解码指令数组，不解析完整class文件：指令为new(类)、dup、astore/aload(槽)、init(类)、use(类)、无条件或非确定双分支、return与throw。类继承是宿主给的以Object为根的有限树；new产生带该指令ID的未初始化引用，init从栈顶取接收者，只接受同类未初始化接收者；dup复制栈顶，astore弹栈写槽，aload从槽压栈，正常边把帧中该ID所有别名改为已初始化，异常边则把局部槽中的这些别名置不可用并清空操作数栈，再放入已初始化Throwable。new的异常边不产生对象，throw必须接收已初始化Throwable。异常表给可能到达的处理器集合，所有边都要验证。use要求已初始化且类型为所需类或其子类；局部槽合流不相容置不可用，栈合流类型不相容直接拒绝，已初始化类取最近公共祖先；回边携带未初始化引用一律拒绝。初始栈空、局部槽均不可用，return要求栈空。实现工作表不动点及首个拒绝路径，覆盖两个new同类却不同身份、构造失败处理器继续use、正常别名初始化和安全共享异常处理器。
