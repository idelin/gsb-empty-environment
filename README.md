# moc — 单文件多对象容器

纯 Go 标准库实现。文件布局:

```
[记录 0][记录 1]...[记录 N][索引块]
记录:  magic(8) | idLen(4) | id | version(8) | payloadLen(8) | sha256(32) | payload
索引:  magic(8) | indexLen(8) | 索引负载 | indexLen(8) | magic(8)   <- 位于文件尾部
```

索引负载记录每个对象每个版本的偏移、长度与 SHA-256 摘要。

## 语义

- **按 ID 读取**:`Get(id)` 返回最新版本,`GetVersion(id, v)` 读历史版本;读取前做越界检查,返回前校验摘要。
- **重名 ID 按版本处理**:同一 ID 重复 `Append` 版本号递增,全部版本保留在索引中。
- **追加发布原子**:先截断旧索引 → 写记录 → fsync → 写新索引块 → fsync。索引块是唯一发布点,崩溃只留无效尾部。
- **索引损坏可扫描重建**:`Open` 优先读尾部索引;缺失/损坏/越界时从头扫描数据区重建,`Source()` 标明来源(`tail-index` / `scan-rebuilt`)。
- **未完成尾部不发布**:扫描遇到不完整或损坏的记录即停止,其后内容不进入索引。
- **索引越界拒绝**:加载索引时逐项验证版本递增、偏移+长度落在已发布数据区内、摘要 32 字节,任一失败即拒绝整个索引。

## 序列化范围(封闭集合)

`nil`、`bool`、`int64`(含各宽度有符号整型)、`float64/float32`、`string`、`[]byte`、`[]interface{}`、`map[string]interface{}`。

解码仅按 1 字节类型标签构造上述值:不解析类型名、不反射构造、不执行宿主代码。所有变长字段为 uint32 长度前缀,**先验证长度不超过剩余输入再分配**;嵌套深度限制 64。
