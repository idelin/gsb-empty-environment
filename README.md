# maskedPaths目标无跟随遮蔽

容器运行时要用 /dev/null 或只读 tmpfs 遮蔽 /proc 下的敏感路径，攻击者提前在容器根文件系统里把遮蔽目标换成符号链接，让遮蔽落到别处。为Go运行时实现供容器初始化阶段调用的遮蔽准备包：maskedPaths 目标逐级以不跟随链接的方式解析，任一级是符号链接即拒绝；文件目标须绑定 /dev/null 字符设备（主设备号 1、次设备号 3），目录目标挂只读空 tmpfs；目标不存在时跳过，但其父级是符号链接时仍拒绝；readonlyPaths 逐项重挂只读，路径存在却不能重挂视为启动失败。用链接换位、不存在目标、设备号不符和正常路径验证。
