# 敏感控件触摸遮挡门禁

支付与授权界面上的确认按钮可能被另一个应用的半透明窗口盖住，攻击者让用户以为在点别的控件，实际点中的是确认键，遮挡窗口还会在抬手前一刻撤走。为TypeScript跨端框架写可嵌入控件事件通道的触摸门禁包，输入触摸事件序列（action 为 down、move、up、cancel，指针 ID，坐标，毫秒时间戳，flags 位：0x1 表示窗口被完全遮挡，0x2 表示部分被遮挡）与敏感控件的边界：任一 down 或 move 带遮挡位，整个手势作废，之后的事件一律不派发；手势要派发点击，须 down 与 up 都落在控件边界内、全程无遮挡位，并且 up 距最近一次出现遮挡位的事件至少 500 毫秒；cancel 事件清除手势状态，但不清除遮挡冷却的计时；多指事件按指针 ID 分别判定，任一指针被遮挡则整个手势作废。用全程遮挡、抬手前撤走遮挡、冷却内点击、cancel 后立刻点击和双指同时触摸验证。
