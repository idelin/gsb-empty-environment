集群地址控制器允许租户把若干批准前缀下的地址宣告给外部路由器。给 Go 控制面写可导入的地址授权包。输入为运营根签发的前缀能力、租户签发的可收窄委托、保留网段和一批待发布的服务地址集合。能力绑定地址族、前缀、主体、用途、有效期和最大可再委托前缀长度；IPv4 映射 IPv6 必须先还原。委托不得扩大祖先前缀、时间或用途，两条不同链的条件不能拼接。地址集合以允许前缀减去任意多个排除前缀描述，规模可达完整 IPv6 空间。给每项服务生成路由宣告，须精确覆盖所需地址、不含保留或跨租户地址，且每一条宣告都由一条完整能力链支持。先使前缀条数最少，再使证书中不同委托条数最少，并列按规范地址与委托 ID 决胜；最多16条候选委托。不允许把多个相邻租户的权限聚合成一个无主体归属的大前缀。提供独立证书校验函数；用小地址空间穷举对照排除洞、可合并的相邻前缀、共享委托降低全局成本及能力在同一发布时间失效的情况。
