# 计算图误差分析器 (errgraph)

基于**仿射算术 (affine arithmetic)** 的误差传播分析器, 全部使用 `math/big.Rat`
有理数精确计算, 无浮点误差。

## 核心思想

每个量表示为仿射形式: `center + Σ coeffᵢ·eᵢ`, 其中 `eᵢ ∈ [-1,1]` 是噪声符号。
**同一个符号 id 代表同一个误差源**, 因此共享节点的相关性被完整保留:

- `x - x = 0` 精确抵消 (符号相同, 系数相消)
- `x - y` (独立输入) 宽度为两者之和, 不会被错误抵消也不会重复放大

## 运算规则

- 加/减: 线性, 精确。
- 乘: 线性部分精确; 二次项 `(Σ|aᵢ|)(Σ|bᵢ|)` 归入一个新噪声符号 (保守)。
- 除: `a/b = a · (1/b)`。先检查 `b` 的保守区间, **跨 0 直接拒绝** (返回错误);
  否则对 `1/t` 取弦斜率仿射逼近, 余项用导数界 `δ = L·(hi-lo)/2` 严格包住,
  全为有理数运算。

## 输出

- `Node.Bound()`: 输出的保守误差区间。
- `Engine.TopSources(n)`: 误差来源按贡献 `|系数|` 降序排名, 识别最影响误差的输入。

## 验证

`VerifyContainment(root, grid)` 在有限小域上精确枚举: 每个输入符号在
`{-1, -1/2, 0, 1/2, 1}` 上取值, 用精确有理数对 DAG 求真实值域
(共享节点处处同值), 检查其被保守界包含。
