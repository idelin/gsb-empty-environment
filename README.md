基于模型的拥塞控制引擎（BBRv2 风格）通过联合估计瓶颈带宽 `BtlBw`、最小传播时延 `minRTT` 与安全在途上限 `inflight_hi` 来兼顾高吞吐与低排队延迟，其四态机（`STARTUP`/`DRAIN`/`PROBE_BW`/`PROBE_RTT`）隐藏着四类极易写错的耦合不变式：1）发送端交付率采样在遇到应用受限（`app_limited`）期间产生的低带宽样本**绝不可**压低带宽估计或触发 `STARTUP` 满管道退出，但若某个 `app_limited` 样本反而**高于**当前最大带宽滤波值，则必须采纳更新！2）`STARTUP` 仅在连续 3 个完整往返轮次（Round-Trip）的最高交付率增幅均不足 `25%`（且当轮非 `app_limited`）或遭遇显著丢包/ECN 标记率超过阈值时才退出进入 `DRAIN`（排空高增益造成的队列，直至 `inflight <= BDP` 才切入 `PROBE_BW`！）；3）`PROBE_RTT` 在 `minRTT` 超过 10 秒未被更低样本刷新时触发，必须把目标 `cwnd` 压至 `min(cwnd, max(4*MSS, 0.5*BDP))`，且仅当真实在途字节降到该目标以下后才开始计时持续至少 `max(200ms, 1 RTT)`；4）进入 `PROBE_BW` 后在 `DOWN`/`CRUISE`/`REFILL`/`UP` 四个子态循环，一旦发生丢包率超阈或 ECN 比例超阈，立刻将 `inflight_hi` 收缩至当前在途与交付安全下界并设定 `0.85 * inflight_hi` 的巡航裕度（`headroom`），而在未受限探测上升阶段按每轮指数试探突破旧上限！为传输拥塞控制层交付可导入的 Go 类 BBRv2 状态机与速率/窗口控制器包。规则完整实现 Kathleen Nichols 风格 3-点极值滑窗极大值滤波器（Windowed Max Filter）、`RoundTrip` 边界推进、`app_limited` 标记与解除、四态及 `PROBE_BW` 四子态转换、丢包/ECN 触发 `inflight_hi` 收缩与安全裕度巡航，以及平滑 pacing rate 与 cwnd 输出。验收覆盖 `app_limited` 期间低采样不误退 `STARTUP` 与高采样仍更新、连续 3 轮 `<25%` 满管道退出经 `DRAIN` 入 `PROBE_BW`、10s 触发 `PROBE_RTT` 达标后计时、以及 ECN/丢包收敛 `inflight_hi` 与 `0.85` 巡航裕度验证。
