档案服务既允许按路径委托，也允许按对象标签委托。给Go验权宿主写可导入的委托收窄证明库。每份签名声明的动作、有效时段和租户固定，资源条件是若干条有序的允许或拒绝规则，最后匹配生效。路径由标签构成，支持单段通配和任意深度匹配；对象标签是有限枚举且受宿主给定的互斥、必选与蕴含条件约束。子委托可用另一种等价规则表达，但实际授权资源必须被父授权覆盖，且子委托的显式拒绝不得在多父合并后被另一条路径的末尾允许意外重新放行；同一层要求两名批准人时按各自授权的交集限权，不能把两份各缺一半的许可合并为放行。交付包含关系判定和独立核验器，放宽时给段数最短、同长按输入字母表顺序最小的对象，成立时给可逐步检查的状态覆盖证书。路径可任意长，不能把固定展开深度当成证明。用有穷字母表的小策略对照单对象解释器，检验尾部例外、空后缀、不可实现标签和两父交集。
