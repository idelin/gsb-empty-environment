# CTAP2令牌权限范围

网页或应用从平台拿到 pinUvAuthToken 后，恶意页面想用它在别的 RP 上签发断言或改动凭据管理。为Go软件认证器写供 CTAP2 请求分发调用的令牌权限组件：令牌绑定权限位（mc、ga、cm、be、lbw、acfg）与可选 rpId，mc 和 ga 必须带 rpId，cm 不得带 rpId，权限位组合非法即拒；mc 权限在一次成功 makeCredential 后收回，ga 与 cm 按各自规则，超过无操作期限或认证器重新上电即失效，失效后任何请求拒绝；校验时 rpId 与请求不符、权限位缺失、令牌未被本认证器签发均拒绝；同一令牌不得跨 RP 复用。用跨 RP 断言、cm 令牌用于 mc、过期边界、重启与令牌重放验证。
