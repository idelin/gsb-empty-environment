# batchack

批量确认编解码库：用**连续区间（ranges）+ 有限位图（bitmap）**表示离散序号集合
（uint32，支持序号回绕），编码器产出给定格式下字节数最小的编码，解码器拒绝
重叠区间与一切非规范形式。

## 线格式

```
byte 0      control: RRRRR B MM
              RRRRR: 区间块数 (0..31)
              B:     位图存在标志
              MM:    位图长度码 (0..3 => 1..4 字节)；B=0 时必须为 0
byte 1..4   anchor: uint32 大端锚点。每个被确认序号 n 表示为
            n == anchor + off (mod 2^32)，0 <= off <= 2^31-1
RRRRR 个区间块，每个 8 字节: startOff uint32 BE, endOff uint32 BE（均含端点）。
            区间按 startOff 升序、不重叠、不相邻（相邻区间必须合并）
位图（若 B=1）: MM+1 字节。第 k 位（字节 k/8 的 bit k%8）覆盖偏移 k
```

- 位图覆盖偏移窗口 `[0, 8*len)`；区间只覆盖窗口之外的偏移。
- 编码器枚举全部位图长度（0..4 字节），取总字节数最小的组合；由于区间代价
  为 8 的倍数而位图长度 ≤ 4，最小值唯一，无需额外平局规则。
- 空集编码为 5 个零字节。

## 序号回绕的分段规则

序号按模 2^32 循环排序。锚点取**最大循环间隙之后的第一个元素**，因此偏移永不
回绕：跨越 `2^32-1 -> 0` 的连续段仍然是**一个**区间（不会被拆成两段）。
集合可编码当且仅当它落在 2^31 个序号的窗口内（最大循环间隙 ≥ 2^31+1），
否则返回 `ErrSpanTooLarge`。

## API

- `Encode([]uint32) ([]byte, error)`：输入可无序、可含重复；返回规范最小编码。
- `Parse([]byte) (*Message, error)`：解析为紧凑形式（锚点 + 区间 + 位图），
  不展开区间，对不可信输入安全。
- `Decode([]byte) ([]uint32, error)`：展开为有序序号列表；注意短编码可表示
  多达 2^31 个序号，处理不可信输入请用 `Parse` + `Message.Count` 先行判断。
- `Message.Contains / ForEach / Count / Members`：成员判定与遍历。

## 解码器拒绝的非规范形式

- 区间重叠或乱序（`ErrOverlap`）、区间起点大于终点（`ErrInvalidRange`）、
  偏移超过 2^31-1（`ErrOffsetTooLarge`）
- 相邻区间未合并、区间落入位图窗口、位图末尾零字节、保留位置位、
  锚点本身不是集合成员（锚点必须是最大循环间隙后的第一个元素）
- 非字节最小的位图/区间划分：在紧凑形式上重算全部位图长度的代价，
  编码所用划分不是唯一最小值即 `ErrNonCanonical`（区间代价为 8 的倍数、
  位图长度差 ≤ 4，最小值必唯一，无平局）
- 截断（`ErrTruncated`）与尾部多余字节（`ErrTrailingData`）

## 测试

```
go test ./...                # 单元 + 穷举 + 随机对照
go test -fuzz=FuzzDecodeCanonical -fuzztime=30s .
```

穷举对照覆盖三个 12 元素宇宙（共 3×2¹² 个子集）：`{0..11}`、跨越回绕点的
`{MaxUint32-5 .. MaxUint32, 0..6}`、以及稀疏混合宇宙；每个子集都验证
编解码往返一致、编码字节数等于独立暴力计算的最小值、且编码为不动点。
