剖析器与零开销异常展开器依赖 `.eh_frame`/`.debug_frame` 中的 DWARF CFI 字节码在任意指令地址 `PC` 处重建规范帧地址（CFA）及各被调用者保存寄存器的恢复规则；如果 SLEB128 负数符号扩展出错、未将 `DW_CFA_restore` 还原回 CIE 初始指令执行后的状态（而非当前压栈状态！），或忘了乘以带符号的 `data_alignment_factor`，在嵌套序言/尾声的压栈状态机里就会算错返回地址导致崩溃。为运行时系统交付可嵌入的 C++20 头文件与静态库组件，供剖析器直接调用实现 DWARF v5 CFI 字节码解码与帧表求值引擎。支持 ULEB128 与 SLEB128 解码（检测超 64 位移位溢出与截断输入，正确处理负 SLEB128 符号扩展）；解析 CIE（含 `code_alignment_factor`、有符号 `data_alignment_factor`、`return_address_register` 与 `initial_instructions`）及 FDE（含 `initial_location`、`address_range` 与 `instructions`）。完整执行 CFI 字节码状态机：`DW_CFA_nop`、`DW_CFA_set_loc`、`DW_CFA_advance_loc`/`1`/`2`/`4`（乘以 `code_alignment_factor`）、`DW_CFA_offset`/`extended`/`sf`（乘以 `data_alignment_factor`）、`DW_CFA_restore`/`extended`（严格回退到 CIE 初始行对应寄存器规则！）、`DW_CFA_undefined`、`DW_CFA_same_value`、`DW_CFA_register`、`DW_CFA_remember_state`、`DW_CFA_restore_state`（深拷贝状态栈，空栈弹出报错！）、`DW_CFA_def_cfa`/`sf`/`register`/`offset`/`offset_sf`、`DW_CFA_val_offset`/`sf`。给定查询 `PC`，校验 `PC` 落在 `[initial_location, initial_location + address_range)` 并按规范在首个推进后位置大于 `PC` 前停止执行，返回精确的 CFA 规则与各寄存器恢复规则表。验收覆盖函数序言多步压栈、分支内嵌尾声用 `remember_state`/`restore_state` 恢复中间状态、`DW_CFA_restore` 回退 CIE 初值、负 `data_alignment_factor` 有符号偏移以及空栈弹出与非法 LEB128 拒绝。
