桌面发起登录后，用户可能在手机打开同一封邮件，也可能是安全扫描器预取链接。给 TypeScript 认证宿主实现可导入的跨设备确认协议，只处理抽象事件，不发送邮件。邮件令牌绑定账户、发起浏览器、公钥挑战、用途和截止时间；打开与预取均不得消耗授权。用户在持有登记设备签名的确认页选择具体发起浏览器后，只有那个浏览器证明持有对应私钥才能领取。支持同时存在多封邮件、换设备、撤销发起浏览器和替换登记设备。确认消息可乱序，状态必须区分指向已过期挑战、仍在等待浏览器证明、已发证和结果未知；不能仅用账户与最近邮件匹配。底层签发服务可能成功后丢回执，再次领取只查询同事务，绝不另签。提供投递前后的不可变回执和离线验收，逐个持久化动作中断后仍可分辨哪些主体拥有有效授权。用设备凭据替身核对两窗口同码、跨账户同邮件地址、扫描器访问后真用户确认、撤销和签发确认交错以及浏览器密钥换代。
