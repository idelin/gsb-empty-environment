# 跨集群租约联邦与全局互斥控制器

主备跨数据中心（跨机房）全局活跃租约控制器：通过轻量级第三方**法官（Witness）**
维持跨机房全局单点写入租约；主机房整体失联时，法官向备用机房颁发接管租约，
从机制上彻底杜绝双机房双写（split-brain）。

## 架构

```
        ┌──────────┐   租约 RPC(acquire/takeover/validate)   ┌──────────┐
        │  dc1 主  │ ◄────────────────────────────────────► │ Witness  │
        │ controller│                                       │  法官    │
        └────┬─────┘ ◄────────────────────────────────────► └────▲─────┘
             │            peer 健康探测                        │ 独立探测
             ▼                                                  │
        ┌──────────┐                                            │
        │  dc2 备  │ ◄─────────────────────────────────────────┘
        │ controller│
        └──────────┘
```

- `src/witness.ts` — 第三方法官：全局租约唯一仲裁者，颁发/续租/接管/fencing 校验。
- `src/controller.ts` — 机房级租约控制器：`primary / standby / fenced` 状态机 + 写入门禁。
- `src/network.ts` — 可故障注入的传输层：`partition()` 模拟光纤挖断（生产对应跨机房 HTTPS RPC）。
- `src/types.ts` — 租约与角色类型定义。

## 安全不变式

1. **唯一租约**：法官任意时刻最多颁发一份未过期租约。
2. **fencing token 单调递增**：每次颁发 `term` 严格 +1；每次写入必须经法官
   `/lease/validate` 确认 term 有效，旧持有者的写凭证必然失效。
3. **接管双确认**：法官颁发接管租约前，必须
   (a) 亲自探测确认现持有者真正失联（而非仅凭申请者一面之词），且
   (b) 等待旧租约自然过期后才发证 —— 新旧租约有效期绝不重叠。
4. **fail-closed 写入**：控制器写入需同时满足 本机为 primary、本地租约未过期、
   法官确认 term 有效；任一不满足即只读。
5. **自动隔离**：旧主机恢复后续租被法官拒绝（凭证已失效），自动切换为
   `fenced` 只读态，需人工 `resetToStandby()` 才能重新参与竞选。

## 运行

要求 Node.js ≥ 23.6（原生 TypeScript 类型擦除，无需编译步骤）。

```bash
npm test          # node --test，运行全部内置测试
npm run demo      # 运行光纤挖断故障演练样例
npm run typecheck # 若本地装有 typescript，可 tsc --noEmit 类型检查
```

## 验收场景（tests/federation.test.ts 全覆盖）

| 步骤 | 事件 | 预期行为 |
|---|---|---|
| 1 | 正常态 | dc1 为主可写，dc2 备机写被拒绝 |
| 2 | 光纤挖断，两机房失联 | dc1 无法通过法官 fencing 校验，写失败（fail-closed） |
| 3 | 法官确认 dc1 真正失联 | 独立探测失败 + 等待旧租约过期后，向 dc2 颁发 term+1 晋升租约 |
| 4 | dc2 晋升 | dc2 可写；dc1 旧 term 被法官拒绝 |
| 5 | dc1 恢复 | 续租被拒，自动切换为 fenced 只读备机 |
| 6 | 终态 | dc2 唯一主；全程任意时刻至多一个可写者 |

另含负向用例：持有者存活时接管被拒（`holder-alive`）、观测 term 不符时接管被拒
（`stale-observed-term`）、主续租失败且本地租约到期后自动降级停写。
