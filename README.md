# The Graph查询证明与分配绑定

索引者对查询响应出具带签名的证明，网关据此追责，攻击者可拿别的查询的证明、已关闭分配的签名或错误子图的证明来冒充，也可在响应里谎称未来区块。给TypeScript网关写供响应验收调用的证明校验包，EIP-712 签名恢复与链上分配表由调用方注入：证明里的请求哈希与响应哈希须分别等于对实际请求体与响应体计算的 keccak256；恢复出的签名者必须是该索引者针对该子图部署的当前活跃分配的标识；证明里的部署标识须与查询的部署一致；响应的 _meta 区块号须不低于查询的 number_gte 且不高于调用方给出的链头；含 errors 的响应不验收。用换响应体、已关闭分配、他部署证明、未来区块号和含 errors 响应验证。
