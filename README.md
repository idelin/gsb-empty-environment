# MACsec包号回绕复用了旧SA

交换机实现MACsec XPN时若SA更新与64位packet number持久化不同步，崩溃后可能重复nonce或接受旧帧。请实现供C++20数据面调用的可导入Secure Association生命周期组件，身份绑定SCI、AN、密钥代次、SSCI、salt和持久化高位PN；发送PN在加密前从不可回退分配器批量预留，崩溃丢失的号不得重用，耗尽前阻断并要求rekey。接收端按XPN规则组合低位与高位，只有ICV通过后原子滑动至少128位窗口；同AN新SA发布前冻结旧SA新帧，迟到认证只结算旧代。持久化失败、回滚快照、AN轮转、乱序与并发rekey保持nonce唯一。用克隆磁盘、回绕边界、伪帧诱导滑窗、旧SA迟到、预留空洞和合法乱序验证发送不重nonce、接收不重放。
