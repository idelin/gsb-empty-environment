# 入侵规则时间否定

检测规则“失败登录后十秒没有成功且随后出现管理操作”不能在迟到日志到达前就定案。写供Go事件引擎调用的匹配包，规则由事件序列、键相等约束、时间窗与否定段组成；输入水位线单调，时间窗左闭右开，水位线达到段末才确认否定，超过水位线的迟到事件拒绝并说明。用乱序事件与批处理参考比对告警、证据ID和撤销前的暂定状态。

## matcher 包

`matcher` 是供 Go 事件引擎调用的事件时间序列匹配包，入口类型与语义：

- `Rule`：由有序 `Step`（正段/否定段 `Negate`）、`Window`（左闭右开
  `[Low, High)`，可锚定零号段或任意前序正段）与 `KeyEquality` 键相等约束组成，
  `NewEngine` 构造时会做完整校验。
- `Engine.ProcessEvent`：按事件时间接收事件；事件时间不晚于当前水位线的事件
  视为迟到，原封不动通过 `RejectedEvent` 返回并附中文原因（含事件时间与水位线），
  引擎状态不变。
- `Engine.AdvanceWatermark`：水位线只允许单调递增，回退/持平/零值均报错；
  否定段在水位线达到窗口右端（段末）前保持暂定，达到段末且窗口内无匹配事件
  才确认否定并定案告警。
- 状态机：`TENTATIVE`（暂定，可对外可见但不能定案）→ `ALERTED`（告警）；
  暂定期间否定窗口内到达匹配事件则 `REVOKED`（撤销，记录 `RevokedBy`）；
  正段窗口在水位线处关闭仍无候选则 `EXPIRED`（过期）。
- `MatchID` 由规则 ID 与正段证据事件 ID 确定性派生，暂定、告警、撤销、过期
  各阶段可追溯同一实例；`Evidence` 按段顺序保存证据 ID。
- `RunBatch` / `RunStream`：批处理参考运行器与逐条流式运行器，相同到达序列
  产生逐字节一致的输出日志、拒绝记录与最终匹配快照。

### 测试

`go test ./...` 覆盖：顺序/乱序事件、左闭右开边界（段末时刻事件）、水位线
确认否定、乱序撤销及撤销前暂定状态、迟到拒绝原因、过期、键相等隔离、
水位线单调校验，以及批处理与流式结果的深度等价比对。
