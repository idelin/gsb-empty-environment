# SKR令牌声明策略求值

机密容器向密钥代理申请密钥时只带一份认证令牌，攻击者可重放别的虚拟机的令牌、用调试虚拟机或旧 TCB 的令牌，或让主机换掉令牌里声明的运行时公钥。为TypeScript密钥代理写供密钥释放接口调用的策略求值组件：令牌验签由调用方注入，令牌须带一次性 nonce 且未过期，重放或跨虚拟机复用拒绝；策略为 allOf/anyOf 嵌套的声明条件，声明缺失或类型不符（字符串 "false" 不等于布尔 false）一律不满足，TCB 版本不得低于下限；REPORT_DATA 须由当前运行时公钥签出的报告产生并绑定密钥，调试模式或旧 TCB 即使声明齐全也拒绝；释放时密钥只能用令牌 runtime-data 里的公钥包裹，包裹失败不得输出明文。用重放、过期、缺失声明、类型混淆、调试模式、换公钥与嵌套短路验证。
