# riskengine

流式风控决策组件（Go 标准库实现）：

- **复杂规则条件**：单笔交易特征（金额阈值）+ 滑动窗口历史频次（如“10 分钟内转账超 3 次且金额超 1 万”）。
- **规则版本热切换**：`UpdateRules` 原子替换规则集；`BeginSession` 开启的长事务钉住开始时的版本，平稳过渡；新请求/新会话立即使用新版本。
- **审计日志**：每笔决策记录规则版本号，新旧版本在日志中共存可溯。

## 运行测试

```sh
go test ./...
```

## 运行样例

```sh
go run ./cmd/demo
```

复现验收边界：t=100 规则库更新为更严格阈值；t=90 开始的长事务按旧规则 v1 放行，t=101 发起的新请求按新规则 v2 拦截，审计日志分别标记 v1 / v2。
