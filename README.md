# memberstate

供 Go 数据面调用的组播组成员状态包，解决多监听者源过滤合并时排除集合被错误处理、
向隔离端口泄漏流量的问题。

## 设计要点

- 成员身份：`MemberKey{Tenant, Port}`，绑定可信租户与具体端口实例；同端口号跨租户
  复用视为不同成员，离开互不影响。
- 前缀代数：源集合只用 IPv4/IPv6 前缀表示，内部为二进制前缀 trie（`prefixset.go`），
  并集走 trie 插入并自动把兄弟前缀合并为最小覆盖；排除集合通过 trie 补集实现，
  全程只有 32/128 层前缀运算，不展开任何单地址。
- 过滤语义：每个成员独立给 Include/Exclude；Include 许可即所列前缀，Exclude 许可
  为整个地址族减去所列前缀；组内最终允许源是各成员许可集合的并集。
- 查询：`Allowed()` 返回精确、最小、互不相交的前缀覆盖（v4 后 v6）；
  `AllowedWithin(scope)` 把覆盖投影到小源地址全集；`EvidenceFor(src)` 返回每个放行源
  的授权成员与命中的具体规则（排除成员给出补集片段）。
- 原子发布：写操作由互斥锁串行化，读操作经原子指针拿不可变快照，模式切换不会让
  数据面看到半更新状态。
- 版本栅栏：`Version` 单调递增，迟到/重排的旧版本更新被 `ErrStaleVersion` 拒绝；
  `Leave` 保留墓碑版本，旧版本无法复活已离开的成员。
- 租约：`Renew` 仅在成员存活且版本匹配时生效；`Expire` 只撤销到期成员的贡献，
  到期后的迟到续期同样被栅栏拒绝，只有更高版本的重新加入才能恢复。

## 目录

- `memberstate/`：包实现与测试。
- `cmd/memberstate-demo/`：小源地址全集中混合包含/排除的证据输出示例。

## 运行

```sh
go test ./... -race
go run ./cmd/memberstate-demo
```
