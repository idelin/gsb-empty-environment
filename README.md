# CAA iodef上报目标限定

CA 在因 CAA 拒绝签发时可按 iodef 记录向域名所有人发报告，攻击者可在自己的域名下把 iodef 指向内网地址、带附加头的 mailto，或指向大量收件人制造骚扰。给Go签发服务写供拒签流程调用的上报包：iodef 值只接受 mailto 与 https 两种 scheme；mailto 不得含 ? 及其后的头字段，只含一个地址，地址本地部分不含控制字符；https 目标须为 443 端口、无 userinfo，解析出的地址全为全局单播，连接用已校验地址，不跟随重定向；单个域名每天最多发送一次，每次最多取前两条 iodef；报告正文只含该域名的被拒标识符与时间，不含订单中其他标识符。用 mailto 头注入、内网 https、重定向、多条记录和同日重复验证。
