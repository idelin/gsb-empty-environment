# SKR令牌声明策略求值

机密容器向密钥代理申请密钥时只带一份认证令牌，攻击者可重放别的虚拟机令牌、用调试虚拟机或旧 TCB，或让主机换掉令牌里声明的运行时公钥。为 TypeScript 密钥代理写供释放接口调用的策略求值组件：令牌验签由调用方注入且每次释放只许验一次；策略为 allOf/anyOf 嵌套的声明条件，声明缺失或类型不符（字符串 "false" 不等于布尔 false）一律不满足，数值声明按整数比较，TCB 版本不得低于下限；释放的密钥只能用令牌 runtime-data 里的公钥包裹，该数据哈希须等于报告 REPORT_DATA；包裹失败不得留下可用句柄。求值无副作用，同一令牌在策略不变时结论一致但句柄不复用。用缺失声明、类型混淆、旧 TCB、换公钥、包裹失败与重复请求对照。
