# minijit

动态语言运行时原型：可导入的 Go 字节码解释器、投机内联去优化（Deopt）帧重建与
两阶段虚拟对象（Virtual Object）物化。

详细架构、不变量与验收映射见 [DESIGN.md](DESIGN.md)。

- 解释器：独立物理帧，每帧私有字节码 pc、局部变量数组、操作数栈，异常按 pc 区间逐层展开
- 优化器：多层调用内联进单物理帧，未逃逸对象标量替换（堆上零分配）
- 去优化：由外向内重建多层解释器帧；两阶段物化支持共享/循环引用且保持 `===` 同一性
- 校验：终态值与可达堆图同构对比纯解释器基线

运行测试：`go test ./... -v`
