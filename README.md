# Binder事务缓冲配额与偏移校验

Android 每个进程的 Binder 映射缓冲约 1MB，单向事务只能用其中一半；攻击应用向系统服务连发大型单向事务占满缓冲，或在偏移数组里放重叠、越界的对象让服务端解析错位。为 Go 服务框架写供事务入口调用的检查包：配置缓冲总量 B，所有单向事务共用不超过 B/2，同一调用方待处理占用不超过 B/4，超限只让该调用方失败而不挤占他人；事务占用为数据长度加偏移数组长度（每项 8 字节），再向上取整到 8 字节；偏移须 4 字节对齐且严格递增，各对象（flat_binder_object 固定 24 字节）不得越界或重叠；事务完成事件释放占用。用单调用方占满配额、偏移重叠、越界一字节、他人仍可发送和完成后释放验证。
