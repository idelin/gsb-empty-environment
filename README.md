分布式租约锁在节点时钟存在有界漂移时，若协调器仅按本地时钟判断旧租约过期就发新锁，旧持有者可能因本地时钟走慢而仍自认为持锁，向存储层发起陈旧写。为锁协调器与存储屏障层交付可导入的 Go 安全状态机包。输入最大相对时钟漂移率 ρ（以整数百万分率 ppm 给出，如 500ppm 表示节点时钟速率落在 [1-ρ, 1+ρ]）、默认租约时长 L（微秒）以及按真实全局单调时间到达的客户端申请、续约、主动释放和存储写校验事件（事件可携带客户端声称的本地剩余时间与 Fencing Token）。规则：协调器仅按保守最坏漂移界计算旧租约在客户端本地必然过期的最早真实时刻 `t_safe = t_grant + ceil(L * (1+ρ)/(1-ρ))`（或收到旧持有者显式释放确认后立即可移交）；在 `t < t_safe` 前拒绝向其他客户端发新锁并返回需等待的最短安全微秒数；每次签发新主租约严格递增 64 位 Fencing Token（同一持有者合法续约保持原 Token 并推进 `t_safe`）；存储屏障端维护已见最高 Token，任何携带严格小于最高 Token 的写入必须拒绝（等于允许），即使旧租约在网络延迟后才到达。验收用最坏时钟漂移对抗场景对照线性化安全不变量（绝不同时存在两个自认持锁的活跃客户端，且任何被存储接受的写序列 Token 单调不降），覆盖续约延迟刚好跨过 `t_safe` 被拒、漂移上界精确整除与向上取整临界、主动释放提前解除等待，以及旧 Token 迟到写被存储端拦截。
