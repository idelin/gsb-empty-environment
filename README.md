# 常量折叠优化器（TypeScript）

对一个小型表达式语言做常量折叠，并用穷举差分测试证明优化前后行为一致。

## 语言

常量（数字/布尔）、变量、四则运算（`+ - * /`）、短路逻辑（`&& ||`）、条件表达式（`?:`）。
每个 AST 节点在创建时分配**稳定 id**，优化前后不变。

## 可观察行为

求值是严格从左到右的。可观察行为只有两类：

- **变量读取**：每次读取记录一条 `read(name#id)` 事件；
- **首个错误**：零除 / 类型错误 / 未绑定变量，错误携带出错操作的稳定 id。

纯常量计算不可观察，因此可以安全折叠。

## 折叠规则的安全性（src/fold.ts）

- 只折叠纯常量计算；所有可能的运行时错误（零除、类型错误）在折叠期算好，
  变成 `error` 常量节点——**只有被执行到时才抛出**，且携带原操作 id；
- 短路规则只在被跳过分支**永远不会执行**时触发（`false && _`、`true || _`、已知条件的 `?:`），
  未执行分支的读取与错误不会被提前；
- `true && r` / `false || r` 仅当 `r` 行为完全确定（常量或错误）时才消去逻辑节点，
  因为 `&&`/`||` 还会对右操作数做布尔类型检查（`true && 0` 是 TypeError）；
- 不做任何代数恒等变换（如 `x+0 → x`），变量读取与求值顺序完全保留。

## 来源对应

优化树 `OptExpr` 中：保留的节点沿用原稳定 id；折叠产生的新叶子通过
`src: number[]` 记录它由哪些来源节点折叠而来。`npm run demo` 可查看对应关系。

## 穷举差分测试（src/exhaustive.ts）

表达式集合 × 全部小环境（`x,y ∈ {0,1,2,true,false}` 及未绑定情形），
对比优化前后的 **值 / 首个错误(含 id) / 变量读取序列**：

- 全部深度 ≤1 的表达式（穷举）；
- 针对性用例：零除（`1/0`、`1/(2-2)`、`1/(x-x)`）、重复子表达式
  （`(0/0)+(0/0)` 验证首个错误来自左侧子树的 id）、条件已知但分支含错误、
  短路未执行分支含错误、类型错误与求值顺序；
- 固定种子的 5000 个随机深层表达式。

共 153,198 项检查全部通过。

## 运行

