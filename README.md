# keyinit

按键（per-key）懒初始化库：对象首次使用时执行初始化，同轮并发调用共享同一次结果。

## 语义

- **同轮共享**：同一 key 的并发 `Do` 加入同一轮，初始化函数只执行一次，所有调用者拿到相同结果。
- **成功缓存**：成功的结果一直缓存，直到 `Invalidate`；后续调用不再执行初始化函数。
- **失败广播与重试**：失败会广播给本轮所有等待者，不写入缓存；下一次 `Do` 开启新一轮重试。
- **迟到不污染**：轮次在进行中被 `Invalidate` 后，其迟到完成的结果只发给自己的等待者，绝不写回缓存覆盖新轮。
- **取消**：等待者自己的 `ctx` 取消只让自己退出（不影响轮次）；发起者的 `ctx` 取消会传给初始化函数，其返回的失败照常广播。
- **跨键初始化**：初始化函数可用传入的 `ctx` 调用其他 key 的 `Do`。
- **递归检测**：同一调用链中对已初始化中的 key（含 A→B→A 环）再次 `Do`，返回 `ErrRecursiveInit` 而非死锁。
- **panic 安全**：初始化函数 panic 会使本轮失败（释放所有等待者）并重新 panic，key 仍可重试。

## 用法

```go
m := keyinit.NewManager()

v, err := m.Do(ctx, "user:42", func(ctx context.Context) (interface{}, error) {
    // 可以在这里继续 m.Do(ctx, "other-key", ...) 初始化依赖
    return loadUser(ctx, 42)
})

m.Invalidate("user:42") // 使缓存失效；进行中的旧轮迟到完成也不会污染新轮
```

注意：key 必须可比较（能作为 Go map 键）；嵌套 `Do` 必须传初始化函数收到的 `ctx`，否则递归无法被检测。
