# SSB blob大小声明与流式哈希校验

SSB 的 blob 以 &Base64 哈希.sha256 标识，对端先报大小再传内容，攻击者可报小传大、报错标识，或同一标识由多个对端并发推送来污染存储。给Go blob 存储写供复制调用的接收包：标识须为 & 加 44 个标准 Base64 字符加 .sha256，且 Base64 解出恰好 32 字节；大小上限由调用方给定，对端宣告大小超过上限拒绝；接收时边写临时文件边增量计算 SHA-256，字节数超过宣告值立即中止并删除临时文件，不足宣告值同样失败；仅当字节数与哈希都吻合才原子移动到正式位置；同一标识并发接收时第一个成功者生效，其余中止，且任何失败都不得留下可被读取的内容。用报小传大、哈希不符、并发同标识、标识格式错和截断验证。
