# Exact Continuous-Time Poisson Process Simulation

Python 3.11, standard library only. Event times are **exact** under the
continuous-time model — no per-tick Bernoulli approximation anywhere.

## Model

- **Homogeneous**: constant rate; events spaced by exact `Exp(rate)`
  inter-arrival times (inversion of a linear cumulative hazard).
- **Piecewise constant**: optional per-interval rates; zero-rate
  intervals are skipped exactly and never produce events.
- **Piecewise linear (NHPP)**: intensity interpolated linearly between
  breakpoints. The cumulative hazard `Lambda(t)` is integrated
  analytically per segment (`v0*x + slope/2*x^2`) and inverted with the
  numerically stable form `x = 2h / (v0 + sqrt(v0^2 + 2*slope*h))`,
  which avoids catastrophic cancellation for small `|slope|` and works
  for both signs of the slope.

## Guarantees

- Events are generated by mapping a unit-exponential stream through the
  inverse cumulative hazard, so **chunked generation is bit-identical
  to whole-horizon generation** under the same exponential sequence.
- An event landing exactly on a segment boundary is emitted **once**
  (it belongs to the segment starting there).
- **Negative intensity is rejected** (`ValueError`).
- The random source is **injected by the caller** (`ExpStream` wraps any
  object with `expovariate`, e.g. `random.Random`); the seed and the
  number of draws are recorded, so any run is replayable with the same
  seed.
- `Simulator.checkpoint()` / `Simulator.restore(...)` resume a run
  exactly (rng state included).
- `Simulator.switch_intensity(...)` switches the intensity version at
  the current time point; already emitted events are kept (never
  resampled) and the pending exponential remainder carries over.
- `SegmentedIntensity.expected_count(t)` is the **analytic** intensity
  integral, used as the EXACT reference for empirical count estimates.

## Files

- `poisson_process.py` — library (`ExpStream`, `SegmentedIntensity`,
  `Simulator`, constructors `homogeneous` / `piecewise_constant` /
  `piecewise_linear`).
- `test_poisson_process.py` — `unittest` suite; EXACT vs EMPIRICAL
  assertions are labelled in each test.
- `demo.py` — runnable sample (`python3.11 demo.py`).

## Usage

```python
from poisson_process import ExpStream, Simulator, piecewise_linear

intensity = piecewise_linear([0.0, 1.0, 3.0, 4.0], [0.5, 2.0, 0.0, 1.0])
stream = ExpStream.from_seed(2026)          # caller-injected randomness
sim = Simulator(intensity, stream)
events = sim.generate_until(4.0)            # exact event times
print(intensity.expected_count())           # EXACT analytic E[N]
print(stream.seed, stream.draws)            # recorded seed and samples
```
