给Go密钥服务写一个在发布前调用的派生配方审查包。每个配方有独立用途、版本和有限字段模式，编码表达式由定长原样字段、长度前缀、转义、常量及按字段是否为空的分支拼接组成；字段是调用方给定字节字母表上的有界串，可同一字段引用多次。新旧版本可同时生成密钥的条件由一张版本兼容表给出。同一根密钥和盐下，必须证明不同用途不会把不同参数编码成同一info，且同一用途同版本必须可唯一解码；标成只读的旧配方还须避免被新用途认作有效编码。交付符号检查、独立编码器和见证核验器。出现冲突时返回总参数长度最短的一对输入，同长按配方编号和原始字节序决胜；状态预算耗尽只给未知。用小模式全枚举交叉核验重复字段、零长分支、二进制转义跨边界和只读版本重叠。
