裸设备块存储引擎（Ceph BlueStore Hybrid Bitmap Allocator 风格）必须直接管理 TB 级裸盘的空闲块分配、对齐拆分与崩溃前延迟释放保护：1）**多层级联汇总位图树（L0/L1/L2）**：底层 L0 按 `min_alloc_size` 粒度用 64 位字精确追踪每块空闲/已占状态，上层 L1/L2 对每个子区间实时维护“总空闲块数”与“最大连续空闲段长度”（支持 `O(log N)` 快速跳过已满或碎片化过小的整棵子树！）；每次分配或释放后必须自底向上精确同步全部高层汇总（绝不允许高层最大值与 L0 真实最大连续段漂移！）；2）**对齐约束与非连续碎片原子拆分**：请求分配 `(wantBytes, allocUnit, maxAllocSize, hintOffset)` 时，优先在 `hintOffset` 附近寻找单段满足对齐与长度的连续空闲区；若全局最大连续空闲段小于 `wantBytes`（但总空闲量足够！），按确定性最佳匹配/贪心最大连续块策略将请求拆分为多段对齐子区段（每段长度须为 `allocUnit` 整数倍且 `<= maxAllocSize`，各段总和严格等于 `wantBytes`！）；若总空闲不足（或扣掉对齐碎片后凑不够），必须原子返回 `ENOSPC` 且零部分修改任何位图！3）**双重释放/越界拦截与左右相邻合并**：释放任意区段 `[off, len)` 前必须严格校验对齐、边界与区间内全部块当前均处于已占态（若包含任意未分配块立刻报 `DOUBLE_FREE` 且零修改回滚！）；4）**事务延迟释放队列（Deferred Free / Uncommitted Hold）**：在 CoW/WAL 存储引擎中，某事务 `txID` 释放的旧物理块在检查点 `checkpointTxID < txID` 尚未落盘前**绝不可立刻重分配给新写入**（否则崩溃回退到旧检查点后旧数据已被新写覆盖损坏！）——支持 `ReleaseDeferred(txID, extents)` 把区间挂入延迟队列并维持不可分配态，仅当 `AdvanceCheckpoint(txID)` 推进后才将其原子归还给 L0/L1/L2 自由位图！为底层块存储引擎交付可导入的 Go 多级汇总位图分配与延迟释放保护包。验收覆盖 L0/L1/L2 汇总不变量随机压测、对齐与碎片多段原子拆分、`ENOSPC` 零副作用、`DOUBLE_FREE` 精确拦截以及延迟释放未过检查点绝不重分配、推进检查点后立即立即可用且总块数守恒。
