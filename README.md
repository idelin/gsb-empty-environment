# 闭包把栈上秘密借用逃逸给插件

脚本编译器把捕获栈变量的闭包交给异步插件后，原帧退出会留下悬垂引用，复用栈槽时还能读到别的租户秘密。给Go编译验证宿主实现可导入的闭包逃逸分析包：程序是有限SSA图，值类型为标量、FrameRef(frameID,slot,mutable)、HeapCell或Closure；操作含FrameAlloc、CaptureByRef、CaptureByValue、MakeClosure、StoreGlobal、PassAsync、CallNow、Return和HeapPromote。CaptureByValue复制标量，CaptureByRef保留FrameRef；HeapPromote为一个FrameRef分配唯一HeapCell并把该引用及所有已知别名改写到同一堆单元；提升发生后新CaptureByRef也必须引用该堆单元。闭包流入StoreGlobal、PassAsync、作为Return值或写入HeapCell即逃逸；逃逸闭包的每个by-ref捕获必须在逃逸前完成支配所有路径的HeapPromote，且捕获不可指向已经Return的帧。CallNow仅同步执行不算逃逸。合流保留来源集合，递归调用按调用点和frameID区分，预算不足返回未知。输出从FrameAlloc到逃逸点的最短证据及缺失提升路径；配套小程序解释器退出帧后用另一租户字节填充槽，验证被报告路径确能读取错租户值。覆盖分支只一侧提升、闭包嵌套捕获、by-value安全及提升后多个闭包共享同一HeapCell。
