ARM64 TrustZone 安全固件在配置 TZASC-400（TrustZone 地址空间控制器）内存访问区域与 GICv3 中断控制器安全组（Group 0 / Secure Group 1 / Non-secure Group 1）时，若 TZASC Region 0 默认允许非安全世界读写、高优先级重叠区域未覆盖完整 OP-TEE 安全内存（含 8 个 Sub-Region Disable 位 `SRD` 误设），或 GICv3 将安全外设中断错误路由到 Non-secure Group 1 且 `SCR_EL3.FIQ`/`IRQ` 捕获位配置疏漏，非安全态 REE 内核可直接读写安全世界物理内存或劫持安全外设中断。为 C++17 固件安全审计宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 TZASC-400 与 GICv3 安全隔离符号验证库（严禁逐页枚举）。输入为 TZASC 区域描述符数组（基址、2^N 大小、8 位 `SRD` 掩码、NSAID 读写许可与安全读写位）、GICv3 中断配置表（INTID、Group、Priority、路由亲和）以及安全世界受保护物理区间与安全外设 INTID 集合。验证库精确执行：（1）按 TZASC-400 规范解析全部启用区域与 1/8 子区禁用位 `SRD`，按高编号区域优先合并覆盖语义，检出任意非安全读/写（含任意非授权 NSAID）可访问安全受保护物理区间的最小违例物理地址；（2）校验 GICv3 全部安全外设 INTID 必须归属 Group 0 或 Secure Group 1、优先级严格高于非安全优先级掩码边界，且禁止非安全态修改安全中断路由或触发安全 SGI，输出全部违规配置项与见证。附含重叠子区 `SRD` 漏洞、默认 Region 0 泄漏与 GICv3 安全中断误路由的测试集。
