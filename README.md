# 填充反馈差异的可重放验证

密码服务准备把所有解密失败合成一种反馈，需要验证旧实现是否真的构成填充预言。用Go交付供本地安全回归宿主调用的实验包，目标只是一份由测试创建的AES-128-CBC解密回调，不连接外部服务。密文由16字节IV和至少一块正文组成；填充为末字节k且末k字节均为k，1≤k≤16。回调仅返回填充有效、填充无效或基础设施错误，不返回明文；攻击者可修改IV与密文，包须在调用方查询预算内逐字节恢复最后一块的中间值，再还原该块明文。每个猜测需消除原有多字节合法填充造成的假阳性，不能遇到第一个有效就固定；基础设施错误不当成无效填充，不无限重试，返回可恢复的查询日志及未知字节掩码。提供把认证放在解密前的修复回调，对未经认证的改动只返回统一拒绝，实验应明确报无法建立预言而非恢复错误明文。用随机密钥、原末尾为01和0202、完整填充块及预算恰好耗尽验证查询可重放且没有偷读目标密钥。
