给片上网络建模器交付可导入的 Go 包。输入是至多八个路由器的有向网、每条物理链路共享的两个虚通道、有限 credit 延迟、虫孔包的头身尾三类 flit 和每个输出端轮转指针。包头需下游 VC 可用才申请，直到包尾离开才释放；同拍释放的 credit 下一拍才可用，仲裁推进只发生在真实传输。给定合法注入的有限状态发生器以及各注入端弱公平约束（持续使能者最终被选择），判定指定包能否永远不出网。反例应是可回放的前缀与公平循环，并分别标注结构死锁或可活动饥饿；全都能退出时返回有限状态排名证明，明确公平而非全交错下的终止。检查器不调用求解器，并能否定漏计飞行中 credit 或不公平空转循环。小网络以独立逐拍仿真核对；无外部模型检查器。
