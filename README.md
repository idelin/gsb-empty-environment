# store

带版本比较的 Go 键值存储，支持单键 CAS 与多条件批量事务。

## 语义

- 每个键持有从 0 开始、每次变更（创建/更新/删除）严格 +1 的版本号。
- 不存在的键也有独立的缺失版本：从未写入为 0，删除后保留删除时的版本；
  各键缺失版本互不影响。
- `Condition{Key, Version}` 当且仅当键当前版本相等时成立，可同时表达
  “存在且版本为 v” 与 “缺失且缺失版本为 v”。
- `Txn(conds, writes)` 在同一快照上检查全部条件，全部通过才按序应用全部
  写入，否则什么都不写（全或无）。
- 删除同样推进版本且保留墓碑，因此删除后重建必然得到更高版本，
  旧条件永远不会再次成立（无 ABA）。代价是墓碑记录永久保留。

## 验证

`store/store_test.go` 包含定向场景（ABA、空批、同键冲突条件、缺失版本
独立性、批量原子性）以及 `TestExhaustive`：在 2 键 × 2 值的小状态空间上
用 100 个操作做有界深度穷举（181 个状态、9700 次迁移），逐迁移断言
全或无、版本单调、缺失版本独立、空批无副作用。
