容器镜像与虚拟机磁盘准入服务在挂载不可信 ext4 镜像前，若未做原始字节级只读结构审计，攻击者可在镜像中构造损坏的 Superblock/Block Group Descriptor、存在环路或越界物理块的 Extent 树（`ext4_extent_header`/`ext4_extent_idx`/`ext4_extent`）、多个不同文件交叉引用同一数据块（Cross-Linked Blocks）导致跨文件篡改，或在普通非特权镜像中偷藏 `SUID`/`SGID` 可执行文件或主设备号指向宿主机磁盘的字符/块设备节点（`S_IFBLK`/`S_IFCHR`）。为 C++17 系统安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的离线 ext4 镜像原始字节级安全审计库。库从偏移 1024 字节的 `ext4_super_block` 起严格解析：（1）校验魔数 `0xEF53`、块大小（1K/2K/4K）、总块数与总 Inode 数与镜像实际字节长度一致（无溢出越界），解析块组描述符表（支持 32/64 位）定位 Inode 表；（2）逐个遍历有效已分配 Inode 与目录项（线性目录项边界与长度防死循环/越界）：对使用 `EXT4_EXTENTS_FL` 的 Inode 递归校验 Extent 树（魔数 `0xF30A`、深度严格单调递减、逻辑块单调递增无重叠、已访问块集防环路、全部物理块落入合法数据块区间）；（3）维护全局物理数据块归属表，精确检出任意两个不同 Inode 共享同一物理数据块的交叉链接异常，并检出全部非白名单 `SUID`/`SGID` 位及任意 `S_IFBLK`/`S_IFCHR` 危险设备节点，输出违例 Inode 号、路径与块见证。附手工构造的合法微型 ext4 镜像与 Extent 环路、交叉链接块、隐藏块设备节点与越界目录项测试。
