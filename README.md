密码算法库在落地常量时间（Constant-Time）防计时与缓存侧信道攻击规范时，若手写或编译器优化后的底层 IR 中意外引入依赖秘密密钥的条件分支、以秘密值为下标的查表内存访问（如 S-box `table[secret]`）或非恒定延迟整数除法指令（`DIV`/`MOD`），攻击者可通过微架构缓存/分支计时轻松恢复完整私钥。为 C++17 密码安全审查宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的底层 SSA/三地址码 IR 秘密污点信息流与隐式流常量时间验证库。输入为控制流图（CFG）基本块与指令列表（含算术/位运算、常量时间条件选择 `CMOV`/`SELECT`、可变延迟 `DIV`/`REM`、内存 `LOAD`/`STORE`、条件跳转 `BR` 与 `DECLASSIFY` 显式脱敏边界），以及标注 `SECRET`/`PUBLIC` 的函数入参。验证器在格 `{PUBLIC < SECRET}` 上执行不动点数据流分析并完整追踪**显式流与隐式控制流（PC Taint）**：（1）在到达后支配汇合点（Post-Dominator）前，任何受污点条件分支控制的赋值语句都会将其目标污染为 `SECRET`；（2）检出全部违反常量时间策略的敏感 Sink——`BR` 条件为 `SECRET`、`LOAD`/`STORE` 地址为 `SECRET`、`DIV`/`REM` 任一操作数为 `SECRET`（而 `CMOV` 允许条件为 `SECRET` 且结果标为 `SECRET`）；（3）输出每处侧信道泄漏的精确指令 ID、污点传播路径见证及涉及的源秘密参数，并校验 `DECLASSIFY` 不得提前暴露未掩蔽密钥。附标准常量时间掩码比较/条件交换（必须零误报）与 S-box 查表、隐式控制流泄漏、秘密除法反例测试。
