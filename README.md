RISC-V 安全固件在配置物理内存保护（PMP）及 Smepmp 扩展（`mseccfg.MML`/`MMWP`/`RLB`）时，若校验器对 56 位物理地址空间的 TOR/NA4/NAPOT 区域采用采样检查或忽略优先级遮蔽与锁定位（`L`）在 `MML=1` 下的反转语义，低特权态或恶意 M 态代码可借未对齐边界或共享只读区逃逸隔离。为 C++17 固件安全验证宿主实现零外部依赖、严格 `-Wall -Wextra -Wconversion -Werror` 通过的精确符号区间 PMP/Smepmp 策略分析库。输入包含最多 64 条有序 `pmpcfg`/`pmpaddr` 表项（支持 `OFF`/`TOR`/`NA4`/`NAPOT` 解码，按规范处理 `pmpaddr` 最低位 0 掩码与 `TOR` 逆序空区间 `prev >= cur`）及 `mseccfg` 三标志位；库禁止按地址逐字节循环，须将所有有效表项分解为覆盖 `[0, 2^56)` 的最小不相交原子区间，并按表项下标最小优先的硬件仲裁规则为每个原子区间精确推导 M 态与 S/U 态各自的 `(R, W, X)` 有效权限（完整实现 Smepmp `MML=1` 时的 16 种 `L/R/W/X` 编码真值表，含共享只读/共享可执行、禁止 M 态执行 U 态代码及 `MMWP=1` 时默认拒绝）。对外提供：（1）跨状态迁移检查：验证锁定项在 `RLB=0` 时不可修改，且 `MML`/`MMWP` 置 1 后不可清除；（2）最小越权反例求解：对照调用方声明的隔离规格（M 态私有区、S/U 态隔离区与禁止 W^X 区域），若存在任何违例字节，输出最低物理地址及命中表项索引。附 12 位小地址空间全地址穷举参考实现，差分验证 NAPOT 边界、重叠遮蔽、`MML` 真值表与 W^X 冲突检测零误差。
