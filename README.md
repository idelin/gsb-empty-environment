有状态工作负载迁移时，控制器已确认旧节点被隔离，却不能把一组各自最新的卷快照直接交给新节点。每个物理卷的检查点是一棵有根树，边表示不可分割的日志片段；克隆、替换产生分支。每段含有全局事务号的若干参与标记（含逻辑卷号），同一事务在每个参与逻辑卷应恰好出现一次。恢复候选给出每个逻辑卷可挂的物理卷和树节点，沿根路径累积标记。请交付宿主可调用的 Go 恢复规划包。每逻辑卷选一个候选，同物理卷不能被选两次；每个事务在各卷上要么不存在，要么参与表中的每个标记恰好出现一次，来自错误卷、多标记或缺一方都不算已提交。必须包含调用方指定的事务，另有先决依赖。合法组合中最大化提交事务的带符号收益，平局最小化切换所需下载量：多个候选都引用的内容块只下载一次，费用由块 ID 给出。返回最优组合数和按给定名次选出的挂载证书（按逻辑卷、候选输入顺序），成本和计数用精确整数。宿主拿到证书后必须重新读取实际物理卷、世代及快照摘要；任一不符则整个挂载请求失败，不得发布半组。输入另给沿逻辑卷顺序的消元边界：处理前后两侧都可能引用的事务变量、依赖两端、共享物理卷和块的相关状态同时至多十项；请说明你实际保留的边界状态，允许拒绝超出支持宽度的输入，但不能以完整组合数为限。支持六十个逻辑卷、每卷最多四个候选。小树全组合对照证书、最优值、计数及名次；另测相同内容块在分支间共享、事务在一方重复另一方缺失、负收益的前驱被迫纳入、以及提交核验前仅一个设备换代。

## 实现

Go 包名 `recovery`，入口为 `Plan`（也可用 `PlanBest`、`PlanRank`）。

```go
res, err := recovery.Plan(in, rank) // rank 从 1 开始；nil 表示第 1 名
if err != nil { /* 非法输入、超宽、名次越界等 */ }
if !res.Feasible { /* 无合法组合；res.Count == 0 */ }

// res.Benefit、res.DownloadCost、res.Count 均为 *big.Int 精确值。
// res.Certificate.Choices 按逻辑卷、候选输入顺序给出。

obs := map[recovery.PhysicalVolumeID]recovery.Observation{ /* 宿主重新读取 */ }
choices, err := res.Certificate.Confirm(obs)
if err != nil { /* 任一项不符：choices == nil，整个请求失败 */ }
// 只有 Confirm 成功后才发布 choices。
```

### 提交判定

某事务 `t` 在逻辑卷 `v` 上累计到的标记中，记 `own` 为 `(t, v)` 的数量，
`wrong` 为 `(t, w)` 且 `w != v` 的数量。若 `v` 在 `t` 的参与表中，则必须
`own == 1 && wrong == 0`；若不在，则必须 `own == 0 && wrong == 0`。
所有逻辑卷都通过才算提交。错误卷标记、重复标记、缺少任一参与方都不会提交。

合法组合还要求调用方指定的 `Required` 事务全部提交，并且在先决依赖下闭合：
若 `t` 提交，则 `t` 的所有先决事务也必须提交。目标按字典序：
先最大化已提交事务的带符号收益总和，再最小化所选候选内容块并集的下载费用。

### 实际保留的边界状态

按逻辑卷输入顺序消元。事务在“最早可能检查到它的位置”之前不进入状态；若它是
某个已提交事务的先决依赖，则保留到其直接依赖方关闭之后。每个活跃事务只保留
2 bit：

- `viable`：尚未出现错误卷/多标记/缺标记；
- `mustCommit`：被调用方要求，或已被某个提交的依赖方强制要求。

依赖边本身不跨边界保留，只折叠成 `mustCommit` 位；先决事务不会早于其依赖方关闭。
另外，状态只保留**同时被切面两侧引用**的物理卷占用位和内容块已下载位；不会再被
引用的对象立即丢弃。

默认每层总保留项（活跃事务 + 共享物理卷 + 共享块）上限为
`DefaultMaxBoundaryItems = 10`，可用 `Input.MaxBoundaryItems` 调高；超过即返回
`ErrBoundaryWidth`。DP 只按边界状态数增长，不按完整组合数增长，因此可处理
60 个逻辑卷、每卷 4 个候选（最多 `4^60` 个组合）。

### 限制与错误

- `MaxLogicalVolumes = 60`，`MaxCandidatesPerVolume = 4`；超出返回 `ErrUnsupportedSize`。
- 结构错误（未知卷/节点、重复 ID、环、错误参与表等）返回 `ErrInvalidInput`。
- 名次必须满足 `1 <= rank <= Count`，否则返回 `ErrRankOutOfRange`。
- 证书核验失败返回 `ErrVerificationFailed`（`*VerificationError` 列出全部不符项）；
  `Confirm` 在失败时不返回任何挂载项，避免发布半组。

测试覆盖小树全组合穷举对照、共享内容块跨分支、单侧重复且另一侧缺失、负收益
先决事务被迫纳入、仅一个设备世代变化的核验失败，以及 60 逻辑卷/4 候选和超大
精确名次。
