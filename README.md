多个租户合并或拆分时，已导出的标记要能按授权映射回原值，又不能让新租户通过旧标记发现其他人的记录。写给Go令牌化宿主使用的迁移库。输入是有限域集合、带有效期的域变更、分片中的双向映射及签名绑定的发放记录。令牌只在发行域和代次内唯一，原值用不可逆承诺代表；同一原值的两个承诺只在有双方签名的等值证明时可合一。合并可能出现同令牌异承诺，拆分只准迁移明确授权的子集，空作用域不得沿用父域。选择最少需要重发的旧标记并建立兼容读取表，要求每个获准的旧读取都唯一还原、各域外读取不可见，未获准租户不能靠“存在但无权限”和“不存在”的差异枚举令牌。给出可行迁移证书及重发数下界；同价按发行记录ID序列择取。用小映射穷举对照重叠域、传递等值、重发后旧别名和迁移失败回滚。
