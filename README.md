针对带假命中填充且跨多轮动态更新的加密文档索引泄漏评估，给 Go 隐私测试宿主实现可导入的多纪元泄漏分析包。输入包含至多 18 个关键词与 `E <= 5` 个连续纪元（每纪元给出明文文档集合新增或变更，以及匿名令牌各自观察到的命中文档 ID 集合），其中服务器在每纪元对每个令牌允许掺入至多 `B` 个真实不存在的伪造假命中文档 ID（`0 <= pad <= B`），单文档同词去重而重复文档分别计数。许多单个纪元内的词频与二阶共现矩阵各自存在完全对称的词对，但跨纪元增量演变与有界假命中预算共同约束了合法双射。组件仅依据各纪元单点频次与二阶共现矩阵（严禁暗中使用三阶及以上高阶文档交集），结合可选已知对应，搜索所有满足每纪元二阶统计差异均落在 `[0, B]` 合法填充区间内的关键词—令牌双射，输出在所有可行 `(双射, 填充)` 方案中必然固定的对应、可能匹配集合与字典序前 20 个见证（预算耗尽明确返回未完成且不误报必然确定）。以小语料全排列穷举核对单轮对称而跨纪元破缺、假命中掩盖真实共现与严格二阶限制。
