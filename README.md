# depresolve

一个有限清单上的 Go 包依赖解析库（package `resolver`）。

## 模型

- **有限版本清单** `Manifest`：每包一组已知版本；解析只在此闭集内进行。
- **依赖** `Dependency`：某包版本要求另一包落在闭版本区间 `[Lo, Hi]` 内。
- **冲突** `Conflicts`：不能共存的 `(包, 版本)` 对。
- 每包至多选择一个版本。

## 求解目标（字典序）

1. 请求包的版本向量按请求顺序字典序最大化（先保证第一个请求包最高，再第二个……）。
2. 在此前提下最小化安装（传递）包总数。

## 输出

- 成功：`*Lock`（每包恰好一个版本的依赖锁定）。
- 失败：`*UnsatError`，含删除极小的不可满足核心 `Core` 与具体原因 `Detail`
  （清单无此版本 / 依赖区间无候选 / 版本对冲突 / 请求区间不相交等）。

## 验证

`resolver/solve_test.go` 中的 `TestAgainstBruteForce` 对 500 个随机小清单
（3–5 包、每包 1–3 版本、随机依赖与冲突）把求解器结果与全枚举暴力解逐一核对：
可满足性一致、锁定合法、目标值（请求版本向量 + 包数）等于暴力最优。

```sh
go test ./...
```
