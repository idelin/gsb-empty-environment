# cfg_analyzer — 上下文无关文法诊断工具

Python 3.11，仅标准库。字母表（终结符）与转移结构（产生式）显式输入，
不使用任何现成正则 / 自动机库。

## 能力

- **可生成性最小不动点证书**：逐轮记录新加入符号及其见证产生式，
  附带独立校验器（逐轮可重放 + 完备性检查 ⇒ 确为最小不动点）。
- **不可达符号**：BFS 与集合格不动点两种独立实现交叉核验。
- **ε-环（可空环）与无限歧义**：检测 A ⇒+ αAβ 且 αβ ⇒* ε 的环并给出
  环见证（具体推导序列）。**与语言无限性分别诊断**：
  同一终结串有无限多推导（无限歧义）≠ 语言无限（需增长环）。
- **最短问题链**：每个不可生成符号给出通往根因（无产生式 / 无终结出口的
  循环 SCC）的最短解释链，每步由真实产生式佐证。
- **无用规则清理映射 + 等价简化**：逐条规则给出保留/删除及理由，
  输出语言等价的简化文法；可选的单位环消除进一步去歧（语言仍等价，
  可空环的终结出口绝不误删）。
- **规则撤回后的增量修复**：可生成性集合按"删除-重导出"（DRed 风格）
  增量维护，返回差异（新不可生成 / 新不可达 / 新无用规则 / 语言是否变空），
  并与全量重算交叉验证。
- **有界推导树枚举交叉核验**：证书见证串必须能在足够深度内被枚举发现；
  **"枚举没找到"绝不作为不可生成的证明**——不可生成性仅由不动点证书证明。
- **可独立执行的反例**：导出的见证脚本仅依赖标准库，可脱离本包单独运行，
  独立复核证书、最短串见证与无限歧义反例。

## 运行

```bash
python3.11 -m cfg_analyzer                      # 全部内置样例
python3.11 -m cfg_analyzer --sample nullable_cycle_with_exit
python3.11 -m cfg_analyzer --json examples/nullable_cycle.json
python3.11 -m cfg_analyzer --save-witnesses /tmp/witnesses   # 导出可独立执行见证
python3.11 -m unittest discover -s tests -v     # 测试
```

JSON 输入格式（字母表与产生式显式给出，空右部为 ε）：

```json
{"terminals": ["a"], "nonterminals": ["S", "A", "B"], "start": "S",
 "productions": [["S", "A"], ["A", "B"], ["B", "A"], ["B", ""], ["A", "a"]]}
```

## 运行样例

### 样例 1：仅 A→B、B→A（不可生成 ⇒ 空语言）

```
[可生成性 · 最小不动点证书]
  第 0 轮即为空：没有任何符号可生成终结串
  可生成符号: ∅
  不可生成符号: {A, B}
  证书独立校验: 通过

[最短问题链 · 不可生成符号]
  符号 'A':
  根因: 循环依赖且无终结出口（环: A ⇒ B ⇒ A）

[无用规则清理映射]
  #0: A → B   删除: 左部 'A' 不可生成（根因: 环 A ⇒ B 无终结出口）; ...
  #1: B → A   删除: ...
  简化后文法（语言等价，0 条产生式）

[语言为空判定]
  L(G) = ∅。开始符 'A' 不可生成任何终结串（根因：环 A ⇒ B 无终结出口），故 L(G) = ∅。
```

### 样例 2：可空环另有终结出口（不能全删；无限歧义 ≠ 语言无限）

文法：S→A, A→B, B→A, B→ε, A→a

```
[无用规则清理映射]
  （所有规则均有用，无删除）          ← 可空环的终结出口 A→a 必须保留
[可选 · 单位环消除（语言等价的去歧简化）]
  消除单位环并再清理后（2 条产生式）:  S → a ; S → ε     ← 语言 {ε, a} 不变

[ε-环 / 可空环 与 无限歧义]（与语言无限性分别诊断）
  环见证: A ⇒ B ⇒ A
  诊断: 存在无限歧义 —— 某终结串具有无限多棵推导树
[语言无限性]
  诊断: 语言有限（不存在带增长上下文的有用环）
```

### 样例 3：深见证链（枚举没找到 ≠ 不可生成）

文法：A0→A1→…→A9→x（链深 10）

```
深度 ≤ 3 的枚举: yields = {}            ← 枚举什么都找不到
但不动点证书第 9 轮加入 A0 ⇒ A0 可生成，最短见证串 'x'
深度 ≤ 10 的枚举: 'x' 的推导数 = 1       ← 足够深度交叉核验通过
```

### 可独立执行的反例

```
$ python3.11 -m cfg_analyzer --sample epsilon_context_cycle --save-witnesses /tmp/w
$ python3.11 /tmp/w/epsilon_context_cycle__counterexample_infinite_ambiguity.py
OK: 终结串 'a' 至少有 5 棵不同推导树（绕环 0..4 圈）
绕环次数可任意增大 ⇒ 该串有无限多推导树（无限歧义）；语言未必无限
```

## 增量修复示例

```python
from cfg_analyzer import IncrementalAnalyzer
from cfg_analyzer.samples import SAMPLES

inc = IncrementalAnalyzer(SAMPLES["nullable_cycle_with_exit"][1])
inc.retract(4)   # 撤回 A→a：B→ε 仍支撑，A/S 级联删除后被替代证明恢复
inc.retract(3)   # 撤回 B→ε：失去最后终结出口 ⇒ A,B,S 不可生成，语言变空
```

## 测试结果

```
$ python3.11 -m unittest discover -s tests
Ran 37 tests in ~30s
OK
```

覆盖：三个特殊情形（仅 A→B/B→A 不可生成；可空环另有终结出口不能全删；
开始符无用返回空语言说明）、证书有效性与篡改拒绝、最短问题链、清理映射、
单位环消除语言保持、无限歧义 vs 语言无限、枚举非证明性、全部样例的单规则与
顺序撤回增量一致性（与全量重算比对）、全部见证脚本的子进程独立执行。

## 结构

```
cfg_analyzer/
  grammar.py      显式字母表 + 产生式，输入校验，JSON 加载
  core.py         最小不动点证书（可生成/可空）、证书校验、最短终结串、推导回放
  reach.py        可达性双独立实现、有用符号、可达见证
  cycles.py       Tarjan SCC、ε-环与增长环、环见证
  chains.py       最短问题链
  cleanup.py      无用规则清理映射、等价简化、单位环消除
  enumerate.py    有界最左推导枚举（交叉核验用，不作否定证明）
  incremental.py  规则撤回后的增量修复（DRed 风格）
  witness.py      可独立执行的见证/反例脚本生成
  report.py       诊断编排 + 中文报告
  samples.py      内置样例（覆盖全部特殊情形）
tests/            unittest 套件
examples/         JSON 输入样例
```
