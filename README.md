给 Go 备份宿主实现可嵌入的加密索引恢复协议。宿主能看到每次读写的槽号、长度、阶段和重试次数，但看不到内容；故障可发生在任何已确认写入之后。两个只在其他租户的块和租约上不同的初始索引，即使经历相同公开故障序列，恢复回调的完整可见轨迹也须一致。已确认的本租户快照必须精确恢复一次，尚未确认的批次只能整体回滚或由同一签名事务取回结果。旧代次页面、部分写入的日志和缓存别名不能替代认证后的提交证据。设计有界恢复计划并给出独立校验函数，验证每个允许的崩溃前缀都不造成可观察分叉及跨租户读取；稳定存储只有两个固定容量的加密日志区，不能为每个可能故障保存整份索引。用成对的内存存储枚举连续两次断电、旧日志重放、删除后新租约和容量不足失败的全部读写序列。
