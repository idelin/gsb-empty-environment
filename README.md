# 组合拍卖求解器

接收物品组合报价，求收入最大的无重叠中标集合，并为每个中标者计算移除其报价后的最优收入（用于 VCG 结算）。

## 规则

- 每个报价包含：投标编号 `id`（整数，唯一）、投标方 `bidder`、物品组合 `items`、报价金额 `price`（非负有限数）。
- 同一投标方可提交多个报价，这些报价彼此**互斥**（至多一个中标）。
- 任意两个中标报价不得共享物品。
- 主目标：中标报价金额之和最大。
- 次目标：收入相同时，按中标投标编号升序序列的**字典序**取最小者（均为前缀时短者胜出）。
- 报价数量上限为 25。

## 结算

对每个中标者，移除该投标方的**全部**报价后重新求解最优收入：

```
vcgPayment = revenueWithoutBidder - (revenue - 该中标报价金额)
```

## 输入校验

以下情况抛出 `AuctionInputError`：

- 报价数量超过 25
- 投标编号非整数或重复
- 投标方为空白
- 物品组合为空，或同一报价内物品重复
- 报价金额为负数或非有限数

## 使用

```ts
import { solveAuction } from "./src/combinatorial-auction.ts";

const result = solveAuction([
  { id: 1, bidder: "甲", items: ["a", "b"], price: 10 },
  { id: 2, bidder: "乙", items: ["a"], price: 6 },
  { id: 3, bidder: "丙", items: ["b"], price: 6 },
]);
// result.revenue === 12，中标为 [2, 3]，每个中标者 vcgPayment === 4
```

## 运行测试

需要 Node.js >= 22.6（原生 TypeScript 类型擦除）：

```sh
node --test
```

## 实现说明

胜者判定是 NP 难的加权独立集问题。实现采用分支定界：按报价金额降序排列，用剩余报价金额之和作为上界剪枝；冲突（共享物品或同一投标方）用位掩码表示，25 个报价可在毫秒级求解。VCG 部分对每个中标者各重解一次，规模同样受 25 上限约束。
