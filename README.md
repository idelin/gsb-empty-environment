当噪声分析程序同时存在公私混合秘密、多串通组披露代价与仿射常数偏移时，须防止组合消去随机项的同时也把目标秘密抵消殆尽，给 Go 安全测试宿主写可导入的随机依赖与可辨识性分析包。程序为有限仿射线性表达式，输入区分受保护的目标秘密集合、公开或非目标辅助秘密、各自带独立身份的随机变量以及所属串通组标签，每个可观测输出（至多 20 个）附带读取代价；同时支持在有理数域 `Q` 与素域 `GF(p)` 两种算术模式下分析。组件求解在给定总代价预算内能消去全部随机变量及非目标秘密项、且真正保留目标秘密非零投影的最小代价输出线性组合，并进一步判定该消噪组合是否足以精确隔离调用方指定的目标线性泛函 `L(target_secrets)`（或仅泄露出目标秘密空间中的某个非平凡函数）。返回基于 `big.Rat` 或 `big.Int mod p` 的精确消元证书，预算耗尽时返回已证上界与未证最优标记。用小规模全赋值与双域对比检验伪造常数项、目标被同步消零及代价受限可辨识性。
