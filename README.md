# 恶意归档的解压预算

Go附件预览服务要接入可导入的流式展开预算包，输入为调用方提供的嵌套容器树，每节点是字节流或子容器，解码回调可被攻击者构造为产生大量输出。预算同时限制实际解码字节总量、每条根到叶路径深度、叶数量和存活缓冲区；回调每次只能通过受控Writer输出，超限时在写入前拒绝且取消全部后代。共享节点每次引用都计解码量，循环引用立即拒绝；不能相信声明大小。仅全树成功后发布结果，否则回收所有暂存。提供可注入短写、取消、并发子流和谎报长度的测试，证明任何失败均无部分发布且实测峰值缓冲不超限。

## 实现

- `budget`：可导入的流式展开引擎（无第三方依赖，仅标准库）。
  - `Limits` 同时约束实际解码总字节、根到叶深度、叶引用数、并发存活缓冲；零/负值直接拒绝，避免“缺省即不限”。
  - `Node` 表示字节流（带 `Decode` 回调）或容器（`Children`）；`DeclaredSize` 仅作元数据，永不参与判定，只统计真实写入字节。
  - 回调只拿到受控 `io.Writer`：每次 `Write` 先在记账器锁内预留并校验，越界则在写入前返回 `ErrTotalBytesExceeded`，并取消上下文以终止全部后代/兄弟流。
  - 单线程 DFS 做结构校验（深度、环、叶数），祖先集合即时识别循环引用；共享节点按引用逐次访问与计费，DAG 不会被误判为环。
  - 固定大小 worker 池本身就是存活缓冲上限；`Result` 回传实测 `PeakLiveBuffers` 与 `PeakBufferedBytes`。
  - 短写按真实接受量退款并补足重试，零进度写入归为 `ErrShortWrite`。
  - 仅全树成功才进入唯一发布点；任何失败回收全部暂存缓冲，返回 `nil` 结果且不发布。
- `preview`：附件预览服务接入层，把 `budget.Unfold` 包成 `Service.Preview`，成功才调用 `Store.Render` 一次。

## 测试

故障注入覆盖：可恢复/永久短写、sink 硬错误、外部取消、并发子流峰值缓冲、谎报长度、环、共享引用计费、晚到失败无部分发布、预算越界联动取消兄弟流。
