数据库压缩线程想替换同一层的几页，但相邻层仍保留较老的值，误删一个区间墓碑就会让键复活。写一个可导入的 Go 包供压缩线程生成并安装替换页。每条旧记录是点值、点删除或字节串半开区间删除，带唯一序号；按快照读某键时只看不晚于快照且覆盖该键的记录，最大序号决定结果，空值与缺失不同。输入分为不能改的其余层、要替换的页、一份允许生成的候选页目录。候选页只能原样复制要替换的点记录或截短其中的范围墓碑，不能创造新键值或新序号；同序号碎片可重叠，语义等同原记录。候选页给出独立编码字节和共享字典段，使用同一字典段只计费一次。给定须保留的快照序号闭区间之并（含最新快照），挑选总物理字节最少的候选页，使任意合法快照的完整范围扫描与替换前逐项一致；并列取页数最少再取页编号向量最小。不能只证明每个键至少有一个正确版本：漏掉的中间删除可能被更旧的外层值穿透，多选一页也可能使本已正确的键读错。至多二十二个候选页，不按序号跨度或字节串键空间枚举。无解给出一个包含关系极小的观测集（键、快照、正确结果），删去任一观测后给出能满足其余观测的合法页集。安装器应当用自己的读游标验证输入清单，并报告首个反例，排序按键字节再按快照序号。小数据库枚举页子集对照，须覆盖非 UTF-8 键、同序号相交碎片、多个共享字典、恰在下界生效的墓碑和内部空洞。
