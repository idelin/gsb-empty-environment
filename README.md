两级光交换机共用一拍边界，级间没有无限缓冲。给设备控制器提供可导入的 Go 日历编译包：两个交换级各自有有限个允许配置，每条有向连接每拍最多传一格且仅运送其输入、输出所标的那个流。相邻拍切换配置需为该级插入相应整数个无传输拍，两级可独立重配；闲置也是动作。输入给出周期 P≤10 的逐流到达序列，要求源队列与独立中间 FIFO 容量均不超给定上限。每拍先到达，再执行两级：二级可取拍初的队首，若启用直通且该 FIFO 拍初为空，也可同拍取一级刚输入的格；若旧队列非空则不得越过旧格。出队与入队同时结算，容量按结算后检查。每个格携带流号与源到达拍，须在 D≤P 拍内交付（含到达拍，要求交付拍减到达拍不大于 D）。编译一条每 P 拍完全重复的调度日历：输出每级每拍的配置、重配开始及逐连接的启用位；按无限周期稳态核证 FIFO 顺序、溢出和逐格时延，不能把周期首队列强制清空或忽略跨边界的重配。输入至多三个流、两个 FIFO，每拍到达总量不超二；给定的设备配置和流固定路径无歧义。允许挑选一个真实可重放的边界状态（格年龄为非负且不超过 D），一整周期后队列和格年龄、重配倒计时及配置必须精确回到同态。先最小化周期内两级重配总次数，再最小化峰值中间队列总占用。交付按日历驱动入队和设备发送回调的执行器；用小设备独立穷举状态环核对最优值，覆盖只能跨边界排队、零缓存必须直通、两级同时重配、空转补足周期以及吞吐量够但期限无解。
