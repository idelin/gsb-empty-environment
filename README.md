# 回滚位置迁移规划组件

为 Go 启动宿主提供可导入的安全芯片回滚位置迁移规划器，求解**最坏烧录次数最少**
的部分可观测策略，并产出可由独立核验器离线复核的证书。

## 问题语义

- **计数位置**：每个位置有稳定所有者（owner）与固定签名范围（scope）集合；
  旧位置承载当前防回滚代次，影子位置用于暂存新计数。
- **共享位置分裂**：一个旧位置可覆盖多个签名范围，迁移目标可拆成多个影子
  兄弟位置，每个影子只承载其中一部分范围，两侧范围并集必须一致。
- **两类持久动作**：烧录计数（单调升高、消耗会话预算）与切换指针是不同的
  持久动作；切换分 `request_switch`（进入 pending）与 `confirm_switch`
  （进入 committed）两步，两步之间允许掉电。
- **掉电窗口**：pending 阶段旧路径与影子路径都可能被固件选中。
- **安全不变量**（每个可达具体状态都必须满足）：
  - 逐签名范围独立保证：每个可选位置在其持有范围上的当前代次都高于原已
    撤销映像在该范围的版本，从而任何固件可选中的路径都拒绝撤销映像；
  - 至少一个指定恢复组合仍可完整启动（烧录上限由恢复映像版本封顶，
    防止把恢复映像“烧穿”）。
- **部分可观测**：公开读回只包含 `public=true` 位置的代次，指针阶段与
  非公开位置从不出位。策略只能按观测分支，禁止依据不可见内部状态选择
  不同动作。
- **会话预算**：单次升级会话最多烧录 `MaxBurns` 次；掉电重启后预算重置，
  非烧录动作（request/confirm/yield）零代价。已生效动作的重放是幂等的，
  重复烧录相同代次作为“空烧录”被拒绝，不重复计费。

## 包结构

- `spec/`：纯数据类型、确定性 JSON 指纹（`Canonical`/`Fingerprint`）
  与证书格式。不含任何迁移语义。
- `migration/`：芯片语义、安全谓词、动作合法性与转移、信念空间 BFS 枚举、
  Bellman–Ford 式最小最坏烧录求解，以及宿主会话 API 与证书生成。
- `verifier/`：**独立**核验器。只依赖 `spec` 的数据类型，自行重写全部
  语义、枚举与求解，绝不 import `migration`，因此核验结论不被规划器背书。
- `migrationtest/`：小芯片完整枚举测试，覆盖题目点名的四类场景，并验证
  规划器与独立核验器结论一致、证书可 JSON 往返后仍通过核验。

## 求解方法

1. 在具体状态空间枚举所有合法动作与 `ack`/`boot` 两类环境结果；
2. 按观测把后继状态分组为信念（相容具体状态集合），相同信念强制同一动作；
3. 在（信念，剩余预算）格点上做 Bellman–Ford 松弛：环境取最差分支
   （最大烧录），宿主取最优动作（最小最坏烧录）；
4. 等代价动作按“到终止信念的最短边距”打破平局，避免选择零代价自环
   （如 pending 下重放 request）导致策略空转。

## 核验证书

`migration.Planner.BuildCertificate()` 产出的 `spec.Certificate` 自包含：
芯片规格与指纹、全部枚举具体状态、信念及其相容状态集合、信念级转移
（动作 → 观测 → 后继信念）、每个（信念，预算）格点的策略动作与最坏烧录值。

`verifier.Verify(cert)` 独立重建语义并重新求解，核验：

- 规格指纹一致、初始（含备选初始）状态全部安全；
- 枚举到的每个具体状态都满足安全不变量；
- 证书与独立枚举的状态集合、信念集合、成员关系、转移完全一致；
- 策略动作在信念的每个相容状态上都合法（观测一致性）；
- 独立求解的最小最坏烧录次数与证书声明相同；
- 所有 boot 读回只含公开位置信息。

## 宿主导入用法

```go
planner, _ := migration.Solve(chip)
cert, _ := planner.BuildCertificate()

if report := verifier.Verify(cert); !report.OK() {
    panic(report.Errors)
}

session := planner.NewSession()
for !session.Done() {
    action := session.NextAction()
    // 执行 action，把芯片确认（ack）或掉电读回（boot）喂回会话
    _ = session.Observe(action, observation)
}
```

完整可运行示例见 `migration/example_test.go`。
