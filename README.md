# fsdiff

基于稳定 inode ID 的目录树比较库。

## 语义

- **移动识别**：身份由 inode 决定。原地重命名（inode 不变）输出 `move`；
  内容相同但 inode 不同（删除后重建）输出 `remove` + `add`，绝不误判为移动。
- **硬链接**：一个 inode 对应多个路径时按路径集合输出差异 —
  集合中消失的路径为 `link-remove`，新增的路径为 `link-add`，不产生 `move`。
- **目录移动**：目录移动只输出目录自身的 `move`，被前缀推导覆盖的子孙
  `move` 会被抑制；但子孙的内容修改仍输出 `modify`，目录移动不会隐藏内部修改。
- **修改**：同一 inode 内容哈希变化输出 `modify`（可与 `move` 同时出现）。

## 应用与验证

`VTree` 是虚拟 inode 树：`NewVTree(src)` 播种后 `Apply(ops)` 按序应用差异，
`Snapshot()` 还原出的快照必须与目标完全一致。移动按 inode 解析，
交叉移动（a↔b 互换）中目标路径仍被占用时，占用者先进入临时槽位，
由后续操作归位；目录移动会级联重写子树路径。
