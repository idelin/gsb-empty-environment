执行引擎按键和事件时间把两个有序分片流做全外区间连接。为算子库实现 Go 包：同键左行与时间落入其闭区间 [t-a,t+b] 的每个右行各输出一次，不匹配的行最终只输出一条空扩展。输入行有不可复用的分片内递增序号，输入日志提供不可变的按分片号和序号随机读取接口，恢复时可向它核对重放行的原文，日志不计入算子快照；重放完全相同的前缀是合法输入。每个分片会单调推进整数水位 W，保证以后新行时间不小于 W，恰好 W 的行仍可出现；分片结束才相当于正无穷。调用方还会在输出序列的任意位置要求检查点，包括某行已经产生四万对但下游只确认前三对的时刻。交付拉取式游标、检查点编码及恢复接口；以到达批次为序，每批中新匹配对按左右分片号与序号排序，随后输出本批可判定的空扩展并按侧、分片号、序号排序。返回值的确认与游标推进分离，崩溃恢复后精确重发未确认后缀，既不能重发已确认对也不能漏掉部分乘积。不能持久化完整结果或笛卡尔积，快照大小随仍可能参与匹配的行、当前批行数和分片数线性增长；不得为与当前键无关的行扫描全部库存。给出小流全量对照测试，在每个确认边界序列化后从新对象恢复，覆盖多分片最慢水位、闭区间压线、重复时间但不同序号、重放已越过水位的旧行以及同序号不同内容的明确拒绝。时间端点用饱和的有符号 64 位运算。
