# curve-intersect

在有限区间 `[lo, hi]` 上求两条**分段有理多项式曲线**的全部相等点（交点）与完全重合区间，并输出可核对的证据。

## 构建与运行

```sh
go build -o curve-intersect .
./curve-intersect examples/coincident.json
cat examples/mixed.json | ./curve-intersect
```

## 输入格式（JSON）

```json
{
  "lo": "0", "hi": "4", "eps": "1/1000000",
  "f": { "pieces": [ { "start": "0", "end": "4", "num": ["1","1"], "den": ["1"] } ] },
  "g": { "pieces": [ ... ] }
}
```

- 数字一律用字符串，支持 `"3/2"`、`"1.5"`、`"-2"` 等有理数写法；内部全部使用精确有理数运算，无浮点误差。
- 多项式系数按**升幂**给出（常数项在前）；`den` 缺省为 `1`。
- 每段生效区间为 `[start, end)`；`end` 缺省为下一段的 `start`，最后一段缺省为 `+inf`。

## 语义约定

- **右连续**：断点处的取值属于从该点开始的分段。
- **末端单独包含**：查询区间右端点 `hi`（以及定义域末端）单独包含，归于最后一段。
- **重根接触算相等**：偶数重根（切触）同样报告，`contact` 标记为 `tangency`，奇数重根为 `crossing`。
- **极点**：分母为零的点函数无定义，列为 `pole_points`；叉乘引入的“差为零且分母为零”的伪根被剔除并列入 `excluded_points`。

## 算法

1. 合并两曲线断点，把 `[lo, hi]` 切成原子区间，每段上两曲线各有唯一有理表达式。
2. 每段构造叉乘差多项式 `D = n1·d2 − n2·d1`：
   - **`D ≡ 0`（恒零）**：两有理函数在该段完全重合，直接记录重合区间——绝不进入根隔离流程，恒零差多项式不会导致无限循环。
   - 否则用 `gcd(D, d1·d2)` 除去与分母共享的因子（剔除伪根），再对约化后的 `D` 做 **Sturm 序列精确根隔离**（不计重数、对切触根同样有效），隔离到宽度 `≤ eps`；遇到有理根时因式降阶给出精确值。
3. 根的重数由 `gcd(D, D^(k))` 链判定，用于区分穿越/切触。
4. 相邻重合段在共享断点处函数有定义且相等时合并为极大重合区间；极点处不合并。

## 证据与核对

- **根隔离证据**：每个根给出精确值或隔离区间、重数、穿越/切触类别；核对阶段对精确根回代验证 `f(r)=g(r)`，对区间根验证隔离宽度与浮点残差。
- **公共因子构造**：重合区间的每段给出约化型 `reduced_f/reduced_g`（分母首一化后逐系数一致）与公共叉乘 `n1·d2 = n2·d1`，并声明叉乘差恒为零。
- **错位断点核对**：用两组彼此错开的偏移族 `(2j+1)/10`、`(2j+1)/14` 在重合区间内部采样（自动避开所有断点与极点），精确回代验证 `f(t)=g(t)`；合并跨越的内部断点另做右连续取值核对。
- 全部核对结论汇总在 `verification` 字段。
