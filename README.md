硬件推理运行时将算子接成有向同步数据流图，一次 firing 在每条输入消耗定量 token，结束才在各输出产生指定数量；反馈边预装延迟 token。给执行后端写可导入的 Go 包。共享算力单元同时只能跑一个 firing，DMA 可并发但共用有限描述符，边缓冲容量必须在启动时为输出预留。周期输入用长游程描述，问能否在有限缓冲内无限运行且满足每 N 个输入至少提交 M 个输出的窗口约束；找最小总边容量，平局按边号，输出可回放的周期调度与不可再降的证书。禁止靠模拟固定轮数断言稳定。小图最多六算子、每边最多四槽、流水在途有限；代价和周期空闲长度可到 2^45，不逐空闲拍迭代。验证反馈初始 token 不足、输出空间已被另一个在途 firing 预订及平均速率够但滑窗不够。

## 实现

可导入包位于 `sdf/`，入口为 `sdf.Solve(*Problem) (*Result, error)`。

- 速率一致性：按连通分量传播有理比例，求最小正整数重复向量，逐边整数校验。
- 结构下界：孤立边在有限 `(backlog, reservation)` 状态空间精确搜索，零延迟边复现经典 `p+c-gcd(p,c)`。
- 无时间活性：在有限 token 积压状态空间做穷举可达，死态即真死锁；全可达且无死态则由有限性保证存在可达环，不靠固定轮数。
- 有时间周期：确定性自定时事件驱动，仅在静止的输入周期边界取归一化快照；快照复现即构造性证明最终周期。长游程与空闲按算术跳转，支持到 2^45。
- 滑窗约束：用闭合的周期输出计数，每个输入相位采样一次并外推全部后续周期，能区分「平均速率够但突发窗口不够」。
- 容量最小化：按总容量递增、边号字典序枚举，首个可行向量即唯一最优；`Certificate` 含可独立重算的下界与逐边降一不可行见证。
- 回放：`Schedule.Verify` 用独立资源模型重放前缀与任意个周期，校验算力单元、DMA 描述符、token 与输出预留。

状态分类：`StatusFeasible`、`StatusInconsistent`、`StatusDeadlock`、`StatusOverrun`、`StatusWindow`、`StatusInconclusive`（搜索触达安全包络而非伪称稳定）。

## 验证

`go test ./...` 覆盖：不一致速率、反馈初始 token 不足死锁、在途 firing 预留导致溢出、平均够但滑窗不够、描述符限制在途、六算子反馈图、多输入 LCM 对齐、长游程 2^40/2^45 不逐拍、字典序平局、固定容量与证书独立复核。
