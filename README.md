# 两服务器PIR响应被单边篡改

客户端用两台不串通服务器做XOR私有检索，一台恶意服务器可篡改响应让客户端得到攻击者选择的数据。给Go隐私宿主实现本题PIR与完整性包：数据库有N个等长32字节记录，1≤N≤4096；可信发布方对每条记录计算tag_i=HMAC-SHA256(key,大端索引||记录)并把record||tag作为64字节行，两服务器持同一快照ID和Merkle根（根只用于绑定数据库快照，PIR响应完整性由行tag验证）。客户端查询索引j时从宿主随机源取N位向量q0，q1=q0 XOR e_j；每台服务器返回所有置位行的逐字节XOR、快照ID，并给出对“查询向量摘要、响应、快照ID”的Ed25519签名。客户端验证两签名、服务器身份不同、快照和登记根一致，再XOR响应得到目标行并验tag_j；任何失败只返回统一错误。查询向量长度固定ceil(N/8)，尾部多余位必须为0，服务端执行时间不作为本题承诺。实现恶意服务端夹具，可改单比特、换快照、重放另一查询响应或让两端相同身份；用真实签名/HMAC验证所有篡改拒绝、合法查询返回正确行。另记录发送给每台服务器的向量分布，在N≤8时枚举全部q0，证明任一单服务器看到的每个向量概率相同且与j无关；不得声称防两服务器串通。
