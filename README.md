# J1939传输协议与地址声明

J1939 的传输协议用 BAM 广播或连接模式传多包数据，攻击者伪造 TP.CM 控制帧、重复声明地址或制造超时，让接收端占满缓冲或收下拼错的数据。为C++ ECU 写可导入的 TP 重组包，供 CAN 接收回调调用：TP.CM_BAM 控制字节 32，含总字节数（2 字节）、总包数（1 字节）与 PGN；总字节数须在 9 到 1785 之间，且总包数等于总字节数除以 7 向上取整，不符拒绝；TP.DT 序号从 1 递增，乱序或重复则中止该会话；同一源地址同时只允许 1 个 BAM 会话，新 BAM 到来即放弃旧会话；包间隔超过 750 ms（调用方时钟）中止；地址声明（PGN 60928）里 NAME 较小者保留地址，较大者必须放弃该地址，其已有重组会话随之清除；源地址为 254 或 255 的 TP 帧忽略。用总包数不符、乱序、两个 BAM、超时和地址声明冲突验证。
