网关下发的不是一组可任意重排的数据包，而是一条循环执行的发送微程序。给发送端和两个收端提供可导入的 Go 编解码包：每个节拍先产生一个独立源字节，再按本节拍的掩码广播当前与至多三个过去源字节的异或（负下标为已知零）。掩码表周期最多 6，每个相位从给定候选表选一个，长期重复、不接收反馈。两个收端分别有给定的有限状态丢包信道；有初态、每条转移标明本拍收到或丢失，允许无限游走且任一状态有后继。每个收端必须在源字节生成后的 D 拍内交付该字节（含生成拍，最迟拍号为生成拍号加 D，0≤D≤5），交付顺序不可错，不得假定能预知下一转移。为两个信道都求满足无限时域保证的最低成本周期掩码表；成本为每相位掩码给定非负 uint64 费用之和，同价按相位顺序取掩码数值字典序最小。不可只测一个周期或固定深度；对一张给定不安全表须返回实际信道的一条最短状态转移路径和两组字节流，在截止拍之前所有收到字节一致而待交付字节不同。安全表要能驱动逐字节的在线接收器，不保留整段历史。小信道逐路径与整段方程消元核对收到的数据、最早错失和最优表；另造首次违约晚于两个周期、未知旧字节可相消而单行不能直接解码、左右接收端分别排除不同候选表的实例。
