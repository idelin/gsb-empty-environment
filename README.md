# leaserouter

细粒度分区范围租约路由网关（Go 标准库实现）。

## 设计

- `KeyRange`：半开字典序区间 `[Start, End)`。键空间上界用哨兵 `"["`
  （ASCII 中 `'Z'` 的下一个字符），因此 `[A, "[")` 覆盖所有 A–Z 开头的键，
  打印时显示为 `[A-Z)`。
- `Lease`：把一段键区间的独占服务权授予某个节点，带 epoch 与 TTL。
- `Gateway`：持有租约表（按区间起点排序、互不重叠），负责授予租约、
  分裂区间与路由查询。网关锁只在查表时持有，节点处理期间不持锁，
  因此不同节点上的查询互不阻塞。
- 分裂（Split）：找到覆盖分裂点的有效租约，在同一临界区内原子地
  撤销父租约并授予两个子区间租约，路由不会观察到空洞或重叠。
- 租约继承：子租约继承父租约的 `epoch+1` 与 TTL。

## 运行

```sh
go run .        # 演示：[A-Z) 在 'M' 处分裂，Apple/Zoo 并发路由到两个节点
go test -v ./...  # 运行测试
```

## 验收场景

1. 初始 `[A-Z)` 租约授予 Node-1，数据过大后在 `'M'` 处分裂；
2. 网关分别向 Node-1、Node-2 授予 `[A-M)`、`[M-Z)` 两个独立子租约；
3. 查询 `Apple` 路由到 Node-1、`Zoo` 路由到 Node-2，二者并发处理、
   互不阻塞（测试中用阻塞钩子验证：Node-1 被卡住时 Node-2 照常完成）。
