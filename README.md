芯片微码在表与表之间可以替换目的地址上的一段位，不再是全程拿原地址查表。实现控制平面可导入的 Go 软件参考管线，接受两份配置和入口，按最初目的地址比较其行为。宽度可选 1..128；最长前缀表命中后可输出端口、丢弃，或以指定常量覆盖任意连续位段再跳表；无匹配为独立的未命中。配置另有 TTL（0..63）：每条跳表扣一，余额不足时报跳数耗尽，终结动作不扣。即使重访同一张表也不能直接判环；相同端口的两个成功输出还需比较最终改写地址是否相同。交付驱动使用的选择器：返回差异原地址的精确个数，按无符号地址升序反选第 k 个，并给选中地址的两条可重放逐跳轨迹。不得逐地址枚举、物化差异地址集合或预建全部 CIDR 输出。允许结构化符号表示，内存可按实际出现的不同符号子问题增长；需处理高位前缀到低位段的映射引起的非连续地址集合。小位宽用与编译器不共用匹配逻辑的双执行器逐地址校验计数、名次和轨迹；大位宽覆盖默认路由反复回表后命中更具体前缀、最终端口相同但地址只有一个低位不同、两侧经过不同的中间地址后又恢复到相同结果，以及全部 2^128 个地址均发生分歧。
