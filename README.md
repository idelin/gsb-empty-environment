一棵只读索引在多个事务快照中共享页面内容。归档器可以整页写入，或将页写成相对另一页的补丁；一个热门基页被用于过多次反而会挤满读缓存。为数据库页读取器实现可导入的 Go 归档包。输入为所有页的等长真实字节、各快照的有序页访问串、以及有向候选补丁边。整页成本由原始页长度给定；补丁使用规范编码：从左到右找出所有最大连续差异段，依次以无符号 LEB128 编码该段相对上一段末尾的间隔、段长及目标字节，空补丁为零字节，元数据固定开销另给。每页全局只选一种表示，解码引用不能成环，最大依赖深度 H≤4。读请求递归装入：命中移到最近端；未命中先递归取得基页，再读本页字节、还原并插入最近端，满时淘汰最久未用页。每个快照从独立空缓存开始。预算为所有持久字节数硬上限，先最小化所有快照中最大的单快照实际读字节数，再最小化总持久字节；要交付布局和能按页随机读取的解码器。缓存至多三页、页数至多 16，每页至多三个候选基页，不能把每个请求当冷读或把快照入口当共享缓存。小图枚举不同布局独立计算真实读数，另测跨页共享引起的非局部淘汰、最短补丁边环、零差异页、LEB128 两侧长度和预算恰好少一字节而无解。
