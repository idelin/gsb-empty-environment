集群滚动升级时，旧控制器不会回传它不认识的自定义资源字段。交付宿主可导入的 Go 迁移规划包和一个按计划驱动的 API server 模拟器。每种对象的逻辑状态、各版本可存的线格式都是给定的小型有限集合，字段缺失与空值由输入区分。每类控制器给出线格式到可见元组的读表、每个外部编辑的元组更新表，以及将整个更新元组覆盖写回线格式的表；每次编辑的预期逻辑转换另给，允许无变化。服务按客户版本转换、自带一个有界旁存标签保存不可见信息。候选迁移动作由输入给出：整批转码（旧线格式和标签到新格式和标签的确定表）、切换某控制器的读写表、永久退役一类写入。初始对象可是任意合法逻辑态，对象之间互不影响；每个迁移动作前后用户都可能任意多次按任一仍活跃的控制器编辑。维护 API 规定的每个可观察读、成功或拒绝及写后读，须与理想逻辑对象在相同编辑序列下完全相符；拒绝不得改变对象。计划不观察对象内容，不可依靠选一组好数据。各候选动作至多执行一次且带前置及非负代价，最终须处于指定读写方案并清空所有可达旁存标签；最多十五动作、三类写入、六十四种逻辑态。找总代价最小的安全迁移序列，同价取动作编号向量词典序最小。另提供对任意提议序列的独立检查：返回最早不安全的动作边界及达到该边界违规的最短编辑轨迹，记录每次编辑在哪个边界执行，可逐步回放。测试成对转换都能往返但连续旧写丢字段、必须先开旁存再切换、任意多次编辑中至少三次才暴露丢失、两个同价可执行顺序仅一条全程无损。
