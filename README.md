# 一次性登录链接的预取抵抗与浏览器绑定

邮件里的一次性登录链接会被邮件安全扫描器预取，攻击者也可以把自己生成的链接发给受害者，让受害者的浏览器完成登录，随后进入攻击者的会话。给TypeScript认证服务实现可导入的登录链接兑换包：发起登录的浏览器拿到一个设备绑定值（随机 128 位，写入仅限 HTTP 的 Cookie，服务端只存其哈希），链接令牌随机 256 位，服务端只存哈希；GET 请求只返回确认页，不消耗令牌，不改变任何状态；POST 兑换时必须同时带令牌与设备绑定值，二者哈希都对得上同一条记录才登录，令牌一次性且 15 分钟内有效；设备绑定值缺失或不符时不消耗令牌，只提示改用邮件里的验证码；同一邮箱 10 分钟内最多签发 5 个令牌，签发新令牌使旧令牌失效；兑换成功后轮换会话标识。用扫描器 GET 预取、攻击者链接放进受害者浏览器、缺设备绑定值、令牌重放和第六个令牌验证。
