RPC 服务用 Hessian2 接收对象，攻击者在类定义里引用白名单外类名、用分块长字段伪造声明长度，或用引用编号把深层对象图拼成环。为Go网关实现供RPC入口调用的 Hessian2 流预检包：识别类定义 C、对象 O 与紧凑对象字节 0x60 至 0x6f，类名须在调用方白名单内；引用 0x51 与类型引用须指向已出现且不构成间接循环的合法对象，拒绝重复Map键与非标量键。严格校验跨分块字符串与二进制实际字节同声明长度一致，嵌套深度、对象总数与声明长度超预算即拒；流提前截断须返回可区分的截断错误，遇到不认识的类型字节立即停止并拒绝。用白名单外类名、间接环引用、分块长度伪造、截断流及合法嵌套对象在仓库级测试中验证。
