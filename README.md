Hypervisor 在支持 x86-64 嵌套虚拟化（L0->L1->L2）并合成影子扩展页表（Shadow EPT：`EPT02 = compose(EPT01, EPT12)`）时，若权限合并逻辑遗漏基于模式的执行控制（MBEC：区分 `X_supervisor` 与 `X_user`）、忽略 2MB/1GB 大页拆分后的权限收紧，或允许未对齐/保留位非零的 EPT 表项生效，恶意 L1 或 L2 客户机可利用权限放大漏洞在 L2 执行 L0 禁止的只读页或读写 L0 宿主物理页。为 C++17 虚拟化安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 4 级嵌套 EPT 精确合成与安全隔离符号验证库。库完整建模 48 位物理地址空间上的两张 4 级 EPT 页表（`EPT01` 与 `EPT12`，支持 4KB/2MB/1GB 页、`R`/`W`/`X_sup`/`X_usr` 权限位、保留位与 EPT Misconfiguration 判定）：（1）精确大页拆分与权限交集合成：对任意 `EPT12` 映射 `(L2_GPA -> L1_GPA)`，将其覆盖的完整区间在 `EPT01` 上精确查表（必要时自动拆分为更小粒度区间），最终 `EPT02` 权限必须满足逐位精确交集（`R = R01 & R12`、`W = W01 & W12`、`Xs = Xs01 & Xs12`、`Xu = Xu01 & Xu12`，且禁止出现 EPT 规范禁止的 `W=1, R=0` 非法组合）；（2）跨整个 48 位地址空间的符号差集验证（严禁逐页循环）：核验任意待审 `EPT02` 合成实现不存在任何 `L2_GPA` 能访问到 `EPT01` 未授权的 `HPA`、不存在任何高于 `EPT01 ∩ EPT12` 的权限放大，且所有保留位违例均触发 EPT Misconfiguration 而非静默映射，若有违例则输出最低违例 `L2_GPA` 及完整各级页表项见证。附 16 位缩微物理空间全页穷举交叉验证零误差。
