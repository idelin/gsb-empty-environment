# 时空聚合热力图与密度网格累加器

流式人流/车流时空密度分析器（Go，仅标准库）。将地理空间按瓦片网格离散化、
时间按小时分桶，构成时空数据立方体（Data Cube），支持百万级轨迹点流式落桶
累加，并对任意时空窗口回答 Top-K 拥堵热点查询。

## 结构

- `density/grid.go` — 瓦片网格：经纬度 ↔ 瓦片坐标（等距圆柱近似，可配置瓦片边长）
- `density/cube.go` — 时空立方体：`map[uint64]float64` 扁平哈希表，键为
  `(小时桶, 瓦片X, 瓦片Y)` 打包的 uint64；`Add` 为 O(1)；`Prune` 按保留窗口裁剪旧数据
- `density/topk.go` — Top-K 查询：窗口内按瓦片聚合 + 大小为 K 的最小堆，
  查询内存与数据总量无关
- `cmd/demo/main.go` — 运行样例：流式导入 100 万出租车载客点，查询
  “上周五晚高峰全市人流密度最高的前 10 个网格中心经纬度”

## 内存模型

内存只与**活跃时空单元数**（不同 小时×瓦片 组合数）成正比，与导入点数无关。
每个单元约 50 字节；配合 `Prune` 限定保留窗口即可严格封顶。

## 运行

```sh
go test ./density/ -v   # 单元测试 + 百万点流式压测
go run cmd/demo/main.go # 运行样例
```
