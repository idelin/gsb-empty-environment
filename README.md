# qexpand：显式同义组查询扩展 + 带权词图 + 位置倒排 TopK

纯 Python 3.11 标准库实现（`re` / `heapq` / `collections` / `dataclasses`），
文档为本地合成 UTF-8 文本，不使用任何搜索服务或全文检索库。

## 文件

- `qexpand.py` — 全部实现（分词、同义组、词图、路径枚举、位置倒排、TopK）
- `test_qexpand.py` — 25 个 unittest 用例
- `demo.py` — 可运行样例（中英文合成文档）

## 分词规则（`tokenize`）

1. 全文 `casefold`（Unicode 大小写归一）；
2. ASCII 字母 / 数字 / 下划线的最长连续串为一个词元（`foo_bar`、`v2`）；
3. 其余任何 Unicode 单词字符（中日韩汉字、带重音字母）**逐字**成词元
   （标准库没有分词器，CJK 按字切分，如 `机器学习` → `机 器 学 习`）；
4. 空白与标点只作分隔，不产生词元。

对应正则：`[a-z0-9_]+|[^\W\s]`（`re.UNICODE`）。

## 设计要点

- **单词同义与短语同义分开**：`add_word_group` 只收单词元成员，
  `add_phrase_group` 至少含一个多词成员；两类组分开存储、分开生效。
- **一跳扩展，循环只展开一次**：只对查询原词扩展，扩展词不再被扩展。
  `a↔b` 对称组查询 `a` 只得 `{a, b}`；即使另有 `b↔c` 组也不会传递出 `c`，
  从机制上避免循环扩展与指数组合。
- **带权词图**：原词位置为节点（0..n），原词边权重 1.0，扩展边权重 0.8；
  多词同义加成边链（中间为内部节点），路径保留长度与原词位置区间
  `original_span`。短语成员必须在原词流中**连续**出现才触发，不可拆散。
- **预算截断**：`enumerate_paths(graph, max_paths)` 超出预算即停，
  返回 `truncated=True`，`SearchResult.complete` 明确标记结果不完整。
- **联合 TopK**：对全部（未截断的）路径逐一在位置倒排上做连续短语匹配，
  汇总后用堆取 TopK。
- **计分有界、不重复**：
  - 同一文档同一匹配区间只取最高权重 → 共享扩展（同一扩展词来自多个
    同义组 / 多条路径）不重复计分；
  - 同一文档不同区间命中以概率和 `1 - Π(1 - w)` 合并，总分恒 ≤ 1 →
    原词与扩展词同时命中不会无界叠分；
  - 原词权重 1.0 > 扩展 0.8，原词命中恒排在仅扩展命中之前。
- **证据可区分来源**：每条 `Match` 带 `is_original` 与 `group_keys`
  （`("w", 组号)` / `("p", 组号)`），demo 中以 `[原词]` / `[扩展[...]]` 展示。

## 运行

```sh
python3.11 demo.py              # 运行样例

```

## 运行样例（节选）

```text
样例 1：短语同义 new york <-> ny（多词不可拆散，d8/d9 不应命中）
  查询词元: ['new', 'york']  路径数: 2（上限 64，枚举完整）
    路径0: 'new york'   权重=1.00 长度=2 原词区间=(0, 2) [原词]
    路径1: 'ny'         权重=0.80 长度=1 原词区间=(0, 2) [扩展[('p', 0)]]
  #1 d1  score=1.000   [原词] 词=('new', 'york') 位置=[0,2) / [10,12)
  #2 d2  score=0.960   [扩展[('p', 0)]] 词=('ny',) 位置=[0,1) / [6,7)

样例 2：单词同义 car <-> automobile
  #1 d3  score=1.000   [原词] ('car',)
  #2 d4  score=0.800   [扩展[('w', 0)]] ('automobile',)

样例 4：路径预算截断（(1+4)^2=25 条路径，预算 4）
  路径数: 4（上限 4，枚举不完整（路径预算截断））
  ⚠ 结果不完整：路径预算已耗尽，未枚举的扩展未参与计分
```

完整输出见 `python3.11 demo.py`。
