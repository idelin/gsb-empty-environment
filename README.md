嵌入式 TLS 客户端与代码签名校验器在离线验证 X.509 v3 证书链时，若使用宽松 BER 解析器放行非最短长度编码或冗余前导零整数，或在路径验证中遗漏中间 CA 的 `BasicConstraints.pathLenConstraint` 递减计数、`NameConstraints`（`permittedSubtrees` 与 `excludedSubtrees`）对 DNS/IP/Email SAN 及无 SAN 时回退 CN 的强制约束，攻击者可利用受限子 CA 签发越出允许域名的伪造证书或通过畸形 DER 编码触发解析多义性绕过吊销检查。为 C++17 密码安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的严格 ASN.1 DER 解码器与 RFC 5280 X.509 路径约束验证库（签名校验通过抽象验签回调完成）。库分两层严格实现：（1）零宽松 DER 解码器：硬拒绝不定长编码（`0x80`）、非最短长度字节、超过 4 字节长度或越界截断、非规范 BOOLEAN（仅 `0x00`/`0xFF`）、INTEGER 冗余前导 `0x00`/`0xFF`、BIT STRING 未使用位非零或超界、非法 OID 首字节/超长子标识符以及未消费尾随字节；（2）RFC 5280 路径约束验证引擎：逐级校验有效期、`BasicConstraints`（非叶子必须 `CA=true`、`pathLenConstraint` 精确统计非自签中间 CA 数量）、`KeyUsage`（中间 CA 必含 `keyCertSign`）、`ExtendedKeyUsage` 传播交集，以及 `NameConstraints` 完整语义——递归合并链上全部 `permitted`/`excluded` 子树，校验叶子全部 DNS/IP（CIDR 掩码精确匹配）/RFC822 SAN（若无 SAN 则回退检查 Subject CN），任一命中 `excluded` 或不满足任一非空 `permitted` 立即拒签，同时拦截未知 `critical=true` 扩展。附非最短 DER 编码、越界 `pathLenConstraint`、`NameConstraints` 绕过与未知关键扩展测试。
