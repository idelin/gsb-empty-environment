# causalrouter

离散消息因果一致性路由与交付器（Go 标准库实现）。

- `VectorClock`：版本向量，支持比较（before/after/equal/concurrent）、合并、自增。
- `Client`：发送时自增自身分量并附上向量时钟；交付时合并消息时钟。
- `Router`：维护每个客户端的连续交付前沿。
  - 前置依赖未满足的消息入队暂存，依赖到达后按因果顺序自动交付；
  - 重复消息幂等丢弃；
  - 在暂存队列上检测循环因果（互相等待的依赖环），生成不可达证据并隔离，
    依赖被隔离消息的暂存消息会被传染式隔离。

## 运行

```sh
go test ./...     # 测试（含验收边界场景）
go run ./cmd/demo # 运行样例
```

## 验收边界

X 发送 `(A:1)`，Y 收到后发送 `(A:1, B:1)`。若接收端先收到 Y 的消息，
路由器将其暂存，直到收到 X 的 `(A:1)` 后按因果顺序交付 `A:1 -> B:1`。
对应测试：`TestAcceptanceCausalOrder`。
