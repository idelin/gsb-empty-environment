# 四维时空反向索引与历史相交证明器

追溯引擎:证明"实体 A 与实体 B 是否在历史某个时空相遇过"。
基于时间切片倒排网格表组织轨迹,快速检索两实体在任意时刻
空间距离小于给定阈值的相遇接触记录,并输出全部相交时段与
不可抵赖的地点证书。仅使用 Go 标准库。

## 架构

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 轨迹模型 | `types.go` | 时空采样点、线性插值还原连续运动、轨迹数据 SHA-256 摘要 |
| 反向索引 | `index.go` | 时间切片 × 空间网格 -> 实体集合的倒排表,候选时间窗裁剪 |
| 精确求交 | `intersect.go` | 分段匀速运动下距离平方为二次函数,解析求根得精确相交时段 |
| 证书 | `certificate.go` | 哈希链 + HMAC-SHA256 签名的地点证书,可核验、不可抵赖 |
| 引擎 | `engine.go` | 登记轨迹、求交追溯、解析最近兴趣点、签发链式证书 |

## 工作流程

1. **索引裁剪**:轨迹按采样段写入"时间切片 -> 网格单元 -> 实体"
   倒排表;查询时只保留两实体网格邻域相交的时间切片,合并为
   候选时间窗(网格边长 ≥ 阈值时保证零漏报)。
2. **解析求交**:在候选窗内取两轨迹采样时刻并集作为分段点,
   每段内距离平方是关于时间的二次函数,求根得到精确的进入 /
   离开时刻,不依赖采样密度,无遗漏、无近似误差。
3. **签发证书**:每段相交输出相遇中心坐标、最近兴趣点(柜台),
   证书绑定双方轨迹摘要,沿哈希链链接并由证明机构 HMAC 签名。

## 不可抵赖性

- 轨迹数据摘要在签发前固化进证书,事后替换数据即摘要失配;
- 任意字段被篡改则证书哈希校验失败,链条顺序被破坏则链校验失败;
- 没有证明机构私钥无法伪造合法签名。

## 运行

```sh
go run ./cmd/demo   # 疾控流调演示:两名确诊者在商场 3 段 <10 米相遇
go test ./...       # 单元测试 + 场景验收 + 索引零漏报性质测试
```
