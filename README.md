组织更换 OpenPGP 介绍人后，要判断哪些用户标识仍有足够彼此独立的信任。给 TypeScript 密钥环宿主写可导入的验收包。每张信任签名绑定发送与接收密钥的材料指纹、有效时段、可再委托层数、信任权重和允许邮箱域的正规语言。沿链权限语言取交、截止时间取最早；两个背书不能共享中间管理域，同一实际密钥的多个用户 ID 也不能重复计票。对给定的一批邮箱与时刻，算能同时选用的最大独立背书总权重，一条链上的权重取最弱边；不能先各自找最强路径再删掉重复域。另给符号查询：返回某后缀内哪些邮箱子语言达标，并附验收器可核对的路径与独立域证书；含环的授权不得通过重复遍历增加权重。离线快照缺一张必需签名时报告未知。用小图枚举全部简单路径与相容背书集合，核对撤销一条共享边、两把别名密钥、正则域范围交叠、精确过期时刻和阈值边界。
