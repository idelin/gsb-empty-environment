# StandardMessageCodec声明长度

插件与 isolate 之间用 StandardMessageCodec 二进制消息，攻击者在长度字段里声称比实际更多的元素，或嵌套出很深的列表。为Go宿主实现可导入的消息解码包：类型字节 0 空、1 真、2 假、3 int32、4 int64、5 float64（先按 8 字节对齐补零）、7 字符串、8 uint8 列表、12 列表、13 映射，大小前缀 <254 为 1 字节，254 后跟 2 字节，255 后跟 4 字节（小端）；声明长度超过剩余字节、深度超过 16、元素总数超过 10 万、映射重复键、对齐填充非零或尾部多余字节都拒绝，且不得按声明长度预先分配。用谎报长度、深层嵌套、对齐填充与重复键验证。
