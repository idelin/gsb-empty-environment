# 多版本医疗处方配伍禁忌检查器

基于**双时态（bitemporal）模型**的处方配伍禁忌判定器：

- **业务时间（valid time）**：规则在临床上生效的时间（指南生效日期）。
- **知悉时间（transaction time）**：规则被录入知识库、系统开始知悉该规则的时间。

由此支持两类判定：

1. **开立时合规性判定** `checkCompliance`：以处方开立时刻同时作为业务时间与
   知悉时间截点，回答"这张处方在开立时，按当时的指南认知是否合规"。
   事后更新的指南不影响历史处方的合规结论。
2. **追溯风险审计** `auditRetrospectiveRisk`：以审计时刻生效且已知悉的
   最新规则，回看历史处方的药品组合，回答"按当前最新医学规则，
   这张历史处方是否存在开立后才被指南揭示的配伍风险"。

## 验收场景

| 时间 | 事件 |
| ---- | ---- |
| t=10 | 处方 P 开立，含甲药 + 乙药；知识库此时无甲乙禁忌 |
| t=20 | 指南 v2 更新，甲乙列为"慎用"，录入知识库 |
| t=25 | 查询：开方合规性 = **合格**；风险审计报告 = **标记追溯风险** |

## 运行

要求 Node.js ≥ 23.6（内置 TypeScript 类型擦除，无需编译、无第三方依赖）。

```bash
npm test     # Node.js 内置测试运行器
npm run demo # 运行验收场景样例
```

## 结构

- `src/types.ts` — 双时态类型定义（规则、处方、合规/审计报告）
- `src/ruleStore.ts` — 双时态规则库：录入即生成版本链，支持 `(validTime, knownAt)` 双坐标查询
- `src/checker.ts` — 合规判定与追溯风险审计
- `test/checker.test.ts` — 验收场景 + 规则更正、业务生效性、无序药品对等测试
- `examples/demo.ts` — 验收场景可运行样例
