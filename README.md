代码与固件签名校验器在解析简化 DER 编码的 PKCS#7 `SignedData` 时，若忽略 `SignerInfo` 中的 `authenticatedAttributes` 必须包含 `contentType` 与 `messageDigest`、未校验 `signingTime` 落在证书有效期内，或允许攻击者替换 `unauthenticatedAttributes` 或混入未授权第二签名者，恶意固件即可绕过准入。为 C++17 安全启动宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的原始字节级 DER PKCS#7 `SignedData` 校验库（RSA/ECDSA 验签与 SHA-256 由抽象接口注入）。库严格按 DER 规范解码 `ContentInfo` -> `SignedData` -> `SignerInfos`（拒绝非最短长度与尾部冗余字节），核验每个 `SignerInfo` 的 `SID`（IssuerAndSerialNumber 或 SubjectKeyIdentifier）唯一匹配合法证书，强制 `signedAttrs` 存在且按 SET OF DER 规范排序后重新编码为 `0x31` 标签参与验签，核对 `messageDigest` 等于原文 SHA-256 且 `signingTime` 处于证书 `[NotBefore, NotAfter]` 内，并拒绝存在任意未通过策略信任链的额外 `SignerInfo`。附合法样本与属性篡改、过期回溯及多签名者混淆攻击测试。
