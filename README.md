灾备库的一条恢复记录不是一个时刻，而是每个分片回放到哪个 LSN。为恢复协调器写可导入的 Go 包。每个分片列出允许停止的整数 LSN 闭区间（可重叠，相同位置只算一次）；事务给出各参与分片的提交 LSN，选中的切点须使它在所有参与分片上全见或全不见。另有日志依赖：分片 A 回放到 x 或更高时，分片 B 必须至少到 y；允许环。仓库要求包含或排除一组事务，还要在可行切点中最大化已包含事务的带符号总价值，再最小化需读取的归档块费用。每个归档块列出一个或多个（分片、LSN 阈值），达到任一个就下载一次，无论多少分片共用。返回最优切点向量的精确个数，并为请求的 1 基名次恢复向量及归档块清单；按固定分片顺序、LSN 递增排序。宿主还会在已有分片前缀上查可用的最优后缀数；指全局最优，不是固定前缀重新优化。单个 LSN 可达 2^62，支持八十个分片，不得枚举 LSN 或实际组合。沿输入分片序，跨已选和未选两侧的事务、单条依赖、共享归档块合计至多八项，纯本地项不限；可按题设宽度拒绝越界，不得按一层本地事件数判超宽。独立小日志穷举核对总数、各前缀和首尾名次；必须覆盖阈值两边夹着很长空档、后置分片负价值因原子提交被迫包含、同一共享块被多个边同时触及以及跨分片依赖环。
