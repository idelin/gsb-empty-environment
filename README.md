# grayalloc — 策略灰度分配器

升级灰度时，把若干**不可分割的用户组**整体分配到目标版本，使目标版本上的
总用户数落入指定的精确人数区间，并**最小化迁移用户数**。组数上限 20。

## 问题形式化

- 输入：`n ≤ 20` 个组，每组有人数 `u_i` 与当前版本；目标版本 `T`；
  精确人数区间 `[LO, HI]`（由比例 `r±tol` 或直接指定）。
- 约束：每组要么整体在 `T` 上、要么整体不在（**禁止拆组**）。
  设 `x_i ∈ {0,1}` 表示组 `i` 是否分到 `T`，要求 `LO ≤ Σ x_i·u_i ≤ HI`。
- 目标：最小化迁移用户数 `Σ [x_i ≠ cur_i]·u_i`（版本发生变化的组内全部用户）。
- 不可达时：输出**可机器校验的不可达证明**。

## 算法

`n ≤ 20` ⇒ 全部 `2^n ≤ 1,048,576` 种按组分配可以完备枚举（实测 ~0.1s）：

1. 子集和 DP 预处理 `weightSum[mask]`；
2. 枚举所有掩码，迁移代价为 `weightSum[mask XOR curMask]`；
3. 取区间内代价最小者（平局取最接近区间中心者）——枚举完备，故**全局最优**；
4. 无可行解时，可达人数集合 = 全部子集和，构造不可达证明。

## 不可达证明

证书（JSON）包含两级判据：

- **算术判据**（`arith_proof`）：若所有组人数的 `gcd = g > 1`，则任何可达
  人数都是 `g` 的倍数；区间内无 `g` 的倍数即一行证毕。
- **完备枚举判据**：证书携带完整的有序可达人数集合、其 SHA-256 摘要、
  以及区间的前驱/后继。`-verify` 由输入**独立重算**可达集合并逐项比对，
  同时检查集合与区间不相交——篡改任何一项都会校验失败。

## 用法

```sh
go build -o grayalloc .

# 按目标比例 ± 容差求解
./grayalloc -input examples/feasible.json -target canary -ratio 0.30 -tol 0.005

# 直接指定精确人数区间
./grayalloc -input examples/infeasible.json -target v2 -min 301 -max 399 -cert proof.json

# 独立校验不可达证明
./grayalloc -input examples/infeasible.json -verify proof.json
```

退出码：`0` 找到最优解；`2` 不可达（已输出证明）；`1` 参数/校验错误。

输入格式：

```json
{"groups": [{"name": "region-cn-1", "users": 5200, "version": "stable"}, ...]}
```
