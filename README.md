挂载宿主从备份恢复视图时，路径和显示名可以一样，内容对象和授权代次却可能已变。给 Go 恢复服务写可嵌入的挂载隔离校验包，仅处理内存清单。每份经宿主验签的清单给出不可变对象身份、可授权的子区间、读写执行保护位、可传播的域和父清单摘要。恢复日志含相对路径移动、子区间重映射和共享域的继承，可能缺失若干连续段；每个缺段由签名检查点界定可发生的操作集合。只对所有相容历史都能证明同一对象、同一逻辑区间和保护位的句柄恢复访问，证据不足要返回未知。不同路径的共同底层对象不得借宽松别名放宽授权。产出逐区间的恢复凭据，凭据必须能在策略收紧后按受影响范围失效；不能因一个不相关分支缺段而冻结全部挂载。用短日志全枚举比对缺段前后重命名、同址换对象、子区间重叠、先撤销再重新授权和有充分证据的旁支。
