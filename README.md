# meshsimp

模型处理管线要把高面数网格简化到目标面数。给Go模型处理管线实现网格简化包：按二次误差度量做边折叠，最小堆里过期的条目要能识别；拒绝会翻转法线、产生非流形边或改变开放边界的折叠，顶点属性按位置插值；达不到目标面数时说明原因。用球面和带孔平面测试面数、误差上限和拓扑保持。

## 实现

包 `meshsimp`（入口 `Simplify(mesh, Options)`）实现 Garland–Heckbert
二次误差度量（QEM）边折叠：

- **最小堆与过期条目**：每条候选边按 QEM 成本放入 `container/heap` 最小堆，
  堆条目携带边的 `version`；折叠使邻域边重新评估并自增版本号，弹出时版本号
  不匹配或顶点已失效的条目即判定为过期并丢弃（计入 `Result.Rejects.StaleEntries`）。
  弹出当前版本条目后还会做一次实时合法性复核，避免邻域变化未触达该边。
- **三类折叠拒绝**：
  - 触碰开放边界顶点的折叠（`RejectBoundary`），边界顶点与边界边保持不动；
  - 违反链接条件、会产生非流形边的折叠（`RejectNonManifold`）；
  - 会翻转或退化相邻面法线的折叠（`RejectNormalFlip`）。
- **顶点属性插值**：法线、UV、颜色按目标点在折叠边上的位置做凸权重插值，
  可选对法线/颜色重新归一化；输入网格被深拷贝，不会被修改。
- **达不到目标**：当没有合法折叠或触发 `MaxError` 时停止，`Result.ReachedTarget`
  为 `false` 且 `StopReason` 给出具体原因和当前面数。
- **误差度量**：`DistanceToMesh` / `SymmetricHausdorff` 基于表面采样与
  点到三角形最近距离，给出 RMS、最大距离与 Hausdorff 上界。

## 测试

`go test ./...` 使用 UV 球面和带孔平面网格覆盖：

- 精确达到目标面数、闭合曲面保持流形且无新增边界；
- 简化后表面误差上限（RMS、最大距离、顶点半径偏差）；
- 带孔平面两条边界环的边/顶点数量与坐标完全保持、法线方向不变；
- 不可达目标时返回明确原因、属性插值、过期堆条目统计与输入不可变等。
