# Exact-Clearance Grid Path Planner

在障碍多边形之间为带半径机器人规划网格可行路径。所有坐标为整数或有理数，
全部拓扑判断（相交、包含、净空）用 `fractions.Fraction` 精确完成，
**不依赖任何 epsilon 修补**。仅使用 Python 3.11 标准库。

## 运行

```bash
python3.11 demo.py                          # 运行样例（5 个场景）
python3.11 -m unittest discover -s tests -v # 运行测试（19 个用例）
```

## 模型与约定

- 机器人是半径 `radius`（有理数）的闭圆盘，路径指其圆心轨迹。
- **净空规则**：位形自由 ⟺ 对每个障碍 `dist(点, 障碍) ≥ radius`。
  恰好相切（距离 == radius）视为可行。零半径机器人（`radius == 0`）收紧为
  `dist > 0`，即点机器人不能占据障碍本身。该规则在代码中唯一实现于
  `GridPlanner._is_clear`，网格阻塞、线段校验、简化复核共用。
- **障碍形状**（退化情形定义）：
  - 1 个顶点 → 点障碍（膨胀后为圆盘）；
  - 2 个顶点 → 线段障碍（膨胀后为胶囊）；
  - ≥3 个顶点 → 实心多边形，边界属于障碍；自交多边形按 even-odd 规则填充。
- **网格离散**：单元格为闭正方形；若其与障碍的距离 `< radius`（即与开
  膨胀体相交）则阻塞。因此自由单元格内的圆心路径天然满足净空。
- **8 连通 + 禁角切**：对角移动要求两个正交相邻格均自由，带半径机器人
  无法从两个对角障碍的夹缝中挤过（夹缝 < 2r 时膨胀体重叠封死）。
- **路径简化**：贪心直线shortcut，每个候选shortcut先做精确净空校验；
  最终路径的每一段再统一复核（`validate_path`），全部通过才输出。

## 无解判定（均精确）

- 起点或终点被膨胀障碍覆盖（`dist < r`，含位于多边形内部）；
- 起点/终点在 `bounds` 之外（若指定了场地边界）；
- 当前网格分辨率下不存在通路；
- 任一路径段最终校验失败。

## 已知局限

- 网格法是分辨率不完备的：宽度仅略大于 `2r` 的通道可能因栅格对齐问题
  找不到路径，可减小 `cell_size`（支持有理数）细化。
- 距离以精确平方值（Fraction）比较，避免开方；展示用的距离近似值仅为
  显示用途，不参与任何判定。

## 文件

- `geometry.py` — 精确几何谓词与距离（orient、线段相交、点在多边形、
  点/线段/单元格到形状的距离）。
- `planner.py` — `GridPlanner`：网格构建、Dijkstra 搜索、禁角切规则、
  简化与逐段校验。
- `demo.py` — 5 个场景的运行样例。
- `tests/test_planner.py` — unittest 测试（几何精确性、净空约定、
  对角夹缝、起点覆盖、退化障碍、禁角切、简化复核等）。
