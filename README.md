# dyngraph — 动态图连通性查询工具（离线批次算法）

无向图上持续加边 / 删边，对每个查询：

- **连通**：给出一条具体路径（BFS 最短路）；
- **不连通**：给出分割证据 —— `u` 所在连通块的顶点集合 `S`。
  该集合没有任何活跃边连向外部，且 `v ∉ S`，即为一个真实的割。

## 语义

- 输入是操作日志，**时间由文件行序决定**（从上到下依次生效）；
  `tick` 只是回显在输出里的标签。同一 tick 可有多条操作，靠上的先生效。
- 每个查询都按**它自己所处位置**的图状态作答，绝不使用最终图。
- 重复边按**引用计数**处理：`add` 两次需 `del` 两次才真正消失。
- `del` 一条当前不存在的边 → 报错退出（含行号）。
- 边无向：`add 1 2` 与 `add 2 1` 是同一条边。

## 输入格式

每行一条操作（空行与 `#` 开头的行被忽略）：

```
<tick> <add|del|query> <u> <v>
```

`add`/`del`/`query` 也可写作 `+`/`-`/`?`。顶点为整数。

## 用法

```sh
go run . [-verify] [输入文件]     # 无文件参数时读 stdin
go test ./...                     # 运行测试（含随机化核对）
```

`-verify` 开启逐时重建核对：对每个查询，从头重放操作日志到该查询位置、
重建当时的图，独立验证连通性结论、路径上每条边当时确实活跃、
割集与重建出的连通块完全一致。

## 输出示例

```
tick=2 query 1 4 -> CONNECTED path=1-2-3-4
tick=3 query 1 4 -> DISCONNECTED cut={1} (component of 1; no active edge crosses this cut, 4 lies outside)
```

## 算法（离线批次）

1. **区间化**：扫描操作日志，配合引用计数把每条边的存活期拆成若干
   时间区间 `[add位置+1, del位置-1]`（对查询位置而言）。同一条边多次
   开启/关闭会产生多个不相交区间。
2. **时间线段树**：把每个区间插入线段树的 O(log n) 个规范节点。
3. **DFS 扫描**：沿线段树深度优先，进入节点时挂上该节点的边、离开时
   摘下；到达叶子（某个操作位置）时，根到叶路径上的边恰好是当时的
   活跃边集。若叶子是查询，则在该边集上跑一次 BFS 给出路径或割集。

复杂度：设操作数 `n`、边区间总数 `I`，建树开销 `O(I log n)`，
每个查询叶子额外付出当时活跃边数级别的 BFS 开销。

## 文件

- `main.go` — CLI、输入解析
- `solver.go` — 区间计算、时间线段树、BFS（路径 / 割集）
- `verify.go` — 逐时重建核对器
- `solver_test.go` — 单元测试 + 随机化对拍（同 tick 爆发、重复开关、引用计数）
- `example.txt` — 示例输入
