# maxcsp — 带权最大约束满足（Weighted Max-CSP）分支定界求解器

纯 Go 标准库实现。当约束无法同时全部满足时，为每个软约束赋予破坏惩罚
权重，用分支定界（Branch and Bound）在保证硬约束绝对成立的前提下，
找到加权违反代价最小的全局最优赋值。

## 模型

- `Variable`：有限整数域变量（名称 + 值域）。
- `Constraint`：硬约束（必须满足）或软约束（带惩罚权重 `Weight`）。
  `Violated(assign)` 在部分赋值下求值：约束涉及的所有变量都已赋值时
  才返回 `decided=true`，未决定的约束不计入代价。
- `Solve(p)`：深度优先分支定界。下界为已决定且被违反的软约束权重之和
  （每个约束在其最后一个变量被赋值时恰好计费一次）；下界不小于当前
  最优解即剪枝，因此返回结果保证全局最优。
- `BruteForce(p)`：全量枚举，用于测试中与分支定界结果交叉验证。

## 验收场景：任务排期

5 个任务 T1..T5 分配到时段 {1..5}，3 个硬约束 + 5 个软约束：

| 约束 | 类型 | 权重 | 含义 |
|------|------|------|------|
| H1 | 硬 | — | 任意两个任务不共用时段 |
| H2 | 硬 | — | `slot(T1) < slot(T3)` |
| H3 | 硬 | — | `slot(T5) <= 2`（截止时间） |
| S1 | 软 | 10 | `slot(T2) == 1` |
| S2 | 软 | 8  | `slot(T4) == slot(T1)+1` |
| S3 | 软 | 4  | `slot(T3)` 为偶数 |
| S4 | 软 | 3  | `slot(T4) <= 3` |
| S5 | 软 | 2  | `slot(T2) < slot(T4)` |

该实例不存在满足全部软约束的排期。全局最优解恰好违反 2 个次要软约束
S3、S4，总惩罚 7：

```
slot1: T2 | slot2: T5 | slot3: T1 | slot4: T4 | slot5: T3
```

## 运行

```sh
go run ./cmd/schedule   # 打印最优排期表与搜索统计
go test ./...           # 运行全部测试（含与暴力枚举的一致性校验）
```
