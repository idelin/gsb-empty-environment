# A/B固件更新绕过防回滚索引

设备有A/B两个启动槽，攻击者能回滚普通存储或切换槽位，不能让旧漏洞固件重新启动。给Go固件宿主实现可导入的更新状态机：可信熔丝只保存不可降低的32位rollbackIndex，普通持久状态含每槽镜像摘要、签名清单、版本索引、成功标记、尝试次数及active槽，可在任一写后崩溃并被攻击者回滚到旧快照。镜像清单由宿主验签回调确认绑定设备型号、槽位无关的镜像摘要、rollbackIndex和最低引导版本；安装只能写inactive槽，完整写入并重读摘要后原子标候选。首次启动候选前必须把可信熔丝提升到其索引，提升失败不启动；成功启动由运行镜像回报绑定启动随机数的确认后才原子标成功并切active；确认随机数仅该次启动有效，尝试耗尽可回退另一槽，但另一槽索引不得低于熔丝。相同索引不同摘要是否允许由策略固定，默认拒绝。恢复算法读取熔丝和普通状态，删除低索引候选并选择已成功且符合索引的最高版本，找不到则进入恢复模式而非降低熔丝。逐故障点测试安装、熔丝提升、active切换和确认写入，枚举普通状态回滚，核对任何实际启动镜像索引都不低于可信熔丝。
