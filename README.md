调试终端可经多级代理把控制权借给另一工作站，归还后迟到的旧控制消息不能打断当前作业。给Go会话宿主写可导入的接管协议包。一次控制权由进程启动ID、会话根、允许信号集、被委托的终端维度和一次性序号范围表示，父端允许将不相交的维度并行借出。子端可再借，但归还必须包含所有未完成后代的签名回执或逐一封存其未消费序号；只收到直接子端回执不够。乱序事件和网络分区可留下多个相容状态，返回已证实可控范围、确定失效范围和仍待证明范围，三者要形成不重叠分割。接收者的效果回执可查询，发出信号后本机中断时须能恢复并避免复发。以逐序号小模型核对跨层部分归还、相邻区间、两个窗口共享显示ID及进程号重用；大序号范围不可展开。
