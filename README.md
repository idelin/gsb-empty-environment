同一对象的分片可由多个受权发送方分段转送，字节相同仍可能属于不同授权。给 C++20 网关写可导入的重组组件，输入为不可变分片记录：对象版本、发送方、半开区间、字节摘要和该发送方获准写的区间，签名检查由宿主注入。清单将对象划为有序叶片，每片要求指定门槛的不同签名主体，公钥材料相同的别名只算一票，授权可覆盖叶片的部分区间。只有每一字节都有足够多主体对同一内容版本背书，且跨叶拼接能复算受信根时可交付；不一致的签名分片保留冲突证据，不能靠先到先赢。针对一次查询，返回足够核验的最小证书，先最少记录数，再最少引用总字节，最后按记录 ID 破同分；最多 22 条候选记录，坐标为 64 位稀疏区间，不许按最大地址分配。撤销某个主体后再查询必须自当前信任快照重新判定，已借出的证书仍可在其原快照查验。用小输入的事件端点切分和所有记录子集作对照，验证跨叶部分授权、相同字节不同版本、别名重复票、嵌套区间及旧租约回读。
