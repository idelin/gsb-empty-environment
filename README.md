# fragment-permission-text

文本拼接库：追踪各来源片段的读者集合，支持复制、移动和合并片段；
维护每个输出字符的来源权限交集，格式化操作不丢失限制；
查询某读者可见文本时返回遮挡区间与原因来源。

## 权限模型

- 每个**来源片段**（source）在 `SourceRegistry` 中注册一个读者集合。
- 每个输出字符携带一个**来源集合**（可能为空，空集合 = 不受限，所有人可见）。
- 字符对读者 `r` 可见 ⟺ `r` 属于其来源集合中**所有**来源的读者集合（权限交集）。
- 查询 `queryReader(r)` 返回可见文本（不可见字符替换为 `█`）与合并后的
  遮挡区间 `[start, end)`，每个区间附带**原因来源**：来源集合中排除了 `r` 的那些片段。

## 操作语义

| 操作 | 来源集合语义 |
| --- | --- |
| `append` / `insert` | 新字符来源 = 指定片段 |
| `copyRange` | 复制字符及其来源集合（产生重复引用，互不影响） |
| `moveRange` | 删除后插入（dest 基于删除后坐标系），来源随字符移动 |
| `deleteRange` | 移除字符，其余字符来源不变 |
| `replaceRange` | 新字符来源 = 被替换字符来源的**并集**，故可见读者为被替换范围的权限交集；空范围替换 = 继承相邻来源 |
| `mergeRange` | 注册新来源（读者 = 范围内全部来源读者的交集），范围内字符来源追加新来源 id，保留溯源 |
| `insertFormatting` | 格式化字符来源 = 左右相邻字符来源的并集，不丢失限制 |
| `mapRange` | 逐字符映射（大小写、展开、删除），输出字符继承原字符来源 |

## 参考验证

- `ReferenceDocument`：逐字符来源集合的朴素参考实现。
- `FragmentDocument`：按相同来源集合分区间（run-length）存储的高效实现，语义完全一致。
- `verifyAgainstReference(doc, ref, readers)`：逐字符比较文本与来源集合，
  并逐读者比较查询结果（遮挡区间与原因来源）。
- `test/differential.test.ts`：多个随机种子下对两种实现施加相同的随机操作序列
  （含重复引用、删除、跨权限边界替换、合并、格式化），每步后全量比对。

## 运行测试

需要 Node >= 22.18（原生 TypeScript 类型剥离），在 v24.19.0 上验证通过：

```sh
node --test 'test/*.test.ts'
```

## 目录结构

- `src/model.ts` — 来源注册表、来源集合规范化、权限交集计算
- `src/query.ts` — 读者查询：遮挡文本、遮挡区间与原因来源
- `src/document.ts` — 高效实现（区间存储）
- `src/reference.ts` — 逐字符参考实现
- `src/verify.ts` — 展开视图 / 查询结果比对与参考验证
- `test/scenarios.test.ts` — 重复引用、删除、跨权限边界替换、合并、格式化等场景
- `test/differential.test.ts` — 随机操作序列差分验证
