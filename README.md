通讯录在连续多个纪元间反复迁出、修改并迁回稀疏二叉树子树时，须杜绝利用跨代节点拼接复活已撤销公钥，给 Go 客户端写可导入的多纪元迁移验收包。树标签为至多 256 位的定长位串，根哈希绑定树节点类型（空树、叶、内节点）、高度、位前缀以及当前纪元号。输入为连续 `m` 个纪元（`E0 -> E1 -> ... -> Em`，`1 <= m <= 6`）的签名根链、各步不相交前缀迁移清单及撤销计数器序列，以及客户端收到的多标签共享边界证明。一颗子树在早期纪元迁出并撤销密钥后，即便在后续纪元携相同原始字节迁回同一前缀，也必须携带完整的新增授权回执且严禁复用旧纪元子树哈希；未展开子树仅当在对应整个连续纪元跨度内均证明无授权迁移与无撤销事件时方可折叠。除校验全部迁移内外存在性、键值与单调撤销计数器外，还须严格判定所提交证明节点的极小性与规范唯一性（删去任一边界节点即无法重构全部 `m+1` 个根）。用 6 位完整目录做独立参考真值，检验跨代往返迁回复活、不同纪元折叠深度混用与非极小冗余节点拒收。
