# gofer逐段遍历与符号链接边界

用户态内核把文件访问委托给 gofer，攻击者在容器文件系统里放置含 .. 的名称、指向根外的符号链接或链接环，企图让宿主文件被打开。为Go沙箱文件系统实现供内核处理 walk 与 open 请求时调用的路径解析包：walk 的每个名称必须是单个路径分量，空串、.、.. 与含 / 或 NUL 的名称拒绝；符号链接由内核侧自行解析而非交给宿主，绝对目标从挂载根重新开始，.. 不得越过挂载根，最多跟随 40 次，超出返回环错误；open 须以不跟随末级链接的方式进行，请求 O_NOFOLLOW 时遇到链接返回错误。用 .. 分量、越根相对链接、40 次与 41 次链接链、绝对目标和合法深层路径验证。
