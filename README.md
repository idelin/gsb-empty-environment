# 有理矩阵高斯消元（精确有理运算）

在**有理数域 Q** 上做高斯消元：求矩阵的秩、线性方程组 `Ax = b` 的解空间，
并对不相容系统给出显式证据。全程使用标准库 `fractions.Fraction` 精确运算，
**绝不转浮点**，不依赖任何符号代数库（仅标准库）。Python >= 3.11。

## 特性

- **精确有理数**：输入接受 `int` / `Fraction` / 精确字符串（如 `"3/2"`），
  显式拒绝 `float`，杜绝浮点污染。
- **操作轨迹**：每一步初等变换都记录可读描述与**适用域**说明：
  - 行交换 —— 任意环（置换不改变行生成的子模）
  - 行缩放（除以非零元）—— 任意域（非零元为单位，可逆）
  - 行倍加 —— 任意交换环（只需加法与乘法）
  - 列交换 —— 任意环，但等价于**变量重命名**，须记录置换
- **欠定系统**：给出特解 + 零空间基，通解 `x = x_p + Σ t_k·v_k`。
- **不相容系统**：给出 `0 = c (c ≠ 0)` 矛盾行与秩判据 `rank(A) < rank([A|b])`。
- **列交换还原**：列交换记录置换 `新列 -> 原列`，解向量最终还原为原始变量顺序。

## 用法示例

```python
from rational_gauss import solve, rank

rank([[1, 2, 3], [4, 5, 6], [7, 8, 9]])        # -> 2

sol = solve([[1, 1, 1], [1, -1, 1]], [6, 2])   # 欠定系统
sol.particular        # [Fraction(4), Fraction(2), Fraction(0)] 特解
sol.nullspace_basis   # [[Fraction(-1), Fraction(0), Fraction(1)]] 零空间基

bad = solve([[1, 1], [1, 1]], [1, 2])          # 不相容
bad.consistent                # False
bad.inconsistency_evidence    # ['RREF 第 2 行: 0 = 1（矛盾，0 != 1）', ...]
```

## 运行样例（节选）

样例 2（欠定系统，`x1+x2+x3=6, x1-x2+x3=2`）的实际输出：

```
rank(A) = 2, rank([A|b]) = 2, 变量数 n = 3
结论: 方程组相容，无穷多解（自由变量 1 个）
  主元变量: ['x1', 'x2']
  自由变量: ['x3']
  特解 x_p = (4, 2, 0)
  零空间基 v1 = (-1, 0, 1)
  通解: x = x_p + t1*v1（t_k 为任意有理数）
  验证: A*x_p = b 且 A*v_k = 0（精确成立）
```

样例 3（不相容系统）的实际输出：

```
rank(A) = 2, rank([A|b]) = 3, 变量数 n = 2
结论: 方程组不相容（无解）。不相容证据:
  * RREF 第 3 行: 0 = 1（矛盾，0 != 1）
  * 秩判据: rank(A) = 2 < rank([A|b]) = 3，方程组不相容
```

样例 4（列交换后还原变量顺序）：`[[0,0,2],[0,3,1]] x = (4,5)`，
消元中执行 `C1<->C2`、`C2<->C3` 并记录置换，最终特解按**原变量顺序**给出
`x_p = (0, 1, 2)`（x1 自由取 0，x2=1，x3=2），验证 `A*x_p = b` 精确成立。
