# ranktrack — 二维匀速点集的前 K 排名变化（仅 Go 标准库）

给定静止查询点与若干匀速运动点（坐标、速度、T 均为有理数），求 [0,T] 内
按距离平方（并列时按对象 ID）排名的完整变化时间线。

## 原理

- 每对对象的距离平方之差是次数 ≤ 2 的有理系数多项式 `Quad`；排名只可能在
  其根处改变。枚举所有对象对（O(n^2)），求出 [0,T] 内全部实根。
- 事件时刻 `Root` 精确表示：有理数直接存 `big.Rat`；无理根以
  `u + v*sqrt(m)`（m 无平方因子）闭式 + 多项式 + 有理隔离区间表示。
  比较时先符号判等（同 m、u、v 则相等），否则二分收缩隔离区间直至分离——
  因此多个事件同刻发生能被精确合并，切触（判别式为 0 的重根）也作为事件
  保留但不交换次序。
- 相邻事件时刻之间的开段取有理采样点（两端隔离区间有理端点的中点）计算
  固定排名；事件时刻的排名用"该时刻差多项式是否为 0"判并列、ID 破并列，
  其余对的符号由相邻段采样或有理点精确求值确定。
- 完全相同距离函数的对象对永不产生事件，处处按 ID 破并列。

## 证书（Verify）

1. 事件严格递增且端点为 0、T；
2. 独立重算每对多项式的所有根，断言没有任何根落在某个输出开段内部
   （不存在未处理交点）；
3. 每个开段用 3 个不同的有理采样点复算排名并与输出比对；
4. 每个事件：声明并列的对确实在该时刻有根；未并列的对在事件排名中的
   次序与左右相邻段一致。

## 使用

```sh
go test ./...        # 运行测试（K=0、K>n、负速度、相同距离函数、切触、边界根等）
go run . example.json   # 或 cat example.json | go run .
```

输入为 JSON：有理数写作字符串（"3/2"、"-1.5"、"4"）或数字；
`query`、`T`、`K`、`objects[{id,x,y,vx,vy}]`。
