# 任意写原语下的返回地址可达性

固件测试平台需要区分普通栈越界和能覆盖返回地址的写入。实现供平台调用的Go有界利用可达性包，不操作真实进程：栈为64字节，调用方给输入槽区间、保存返回地址的4字节位置、完整初始栈及初始返回地址和最多8条写操作；每条写操作的目标偏移及长度都是一个输入字节的仿射式，结果用数学整数计算，复制源为该输入串起点的指定长度前缀，源不足立即陷阱，越出栈立即陷阱。攻击者可控制最多3个输入字节，每个字节允许值集合显式给出；返回地址按小端解释，允许目标是调用方给的地址集合。若启用4字节canary，返回前须与初值完全相同，否则不发生控制流转移；canary可被覆盖后恢复。输出能使最终返回地址属于允许目标且不同于初值的输入、逐次写区间和最终栈，按输入字典序选最小；返回槽与canary必须是不重叠的合法栈内区间；若只能破坏canary则单独报告，不能称利用成功。给出朴素重放器与预算未知状态，覆盖重叠复制按临时副本语义、跨canary修复写、部分返回地址覆盖和陷阱先于返回。
