# 基数约束的 CNF 编码与验证（纯标准库，Python 3.11）

把 **至多 k（at-most）/ 至少 k（at-least）/ 恰好 k（exactly）** 编码为 CNF，
并对小规模输入穷举验证投影等价性：

> 任一原赋值满足基数条件 ⟺ 存在辅助赋值使 CNF 成立。

不调用任何 SAT/SMT 库：求解器为自实现的朴素 DPLL + 单元传播，
满足性结论均由独立检查器（直接计数 / 逐子句检查）验证。

## 文件结构

- `cnf.py` —— 变量管理（`VarManager`，编号单调、命名不冲突）、子句规范化、
  单元传播、朴素 DPLL、辅助赋值穷举、独立子句检查器。
- `encoders.py` —— 两种编码器与边界化简：
  - `seq`：Sinz 顺序计数器，寄存器 `s[i][j]` = “前 i 个输入至少 j 个为真”；
  - `net`：基于 Batcher 奇偶归并的基数网络，只生成前 k+1 个一元输出
    （简化归并），比较器按全功能（iff）编码，每个 OR/AND 门 3 条子句。
- `verify.py` —— 直接计数检查、原赋值→辅助赋值的构造性扩展、
  投影等价验证、传播能力度量、求解+独立验证。
- `demo.py` —— 全部运行样例（`python3.11 demo.py`）。
- `test_cardenc.py` —— unittest 测试套件（`python3.11 -m unittest test_cardenc -v`）。

## 语义与边界化简

| 情形 | at-most | at-least | exactly |
|---|---|---|---|
| k < 0 | 恒假（空子句） | 恒真（空 CNF） | 恒假 |
| k > n | 恒真 | 恒假 | 恒假 |
| k = 0 | n 个负单位子句 | 恒真 | = at-most 0 |
| k = n | 恒真 | n 个正单位子句 | 全取真单位子句 |
| n = 0, k = 0 | 恒真 | 恒真 | **可满足**（空赋值） |

at-least-k 归约为对取反文字的 at-most-(n-k)；exactly = at-most ∧ at-least。
输入允许负文字。变量域有限（布尔），一切结论可穷举判定。

## 增量收紧与撤回

- **激活文字 + 假设机制**（两种编码通用）：编码时传入 `activation=a`，
  所有子句附加 `-a`。假设 `a` 为真即启用约束；假设 `a` 为假即撤回。
  收紧 = 用新激活变量编码更紧的界并切换假设，旧界可随时恢复（见示例 4b）。
- **网络编码原生收紧**（`tighten_network`）：一元输出 `outputs[j]` 为真
  ⟺ 至少 j+1 个输入为真，收紧到 k' 只需加一条单位子句 `-outputs[k']`
  （单调、不可单独撤回；见示例 4a）。顺序计数器无一元输出，不支持此方式。

## 验证方法

1. **投影等价**：对全部 2^n 个原赋值，
   - 构造性方向：`extend_assignment` 按编码定义（寄存器计数 / 门电路求值）
     确定性地算出辅助赋值，再由独立检查器逐子句验证；
   - 存在性方向：辅助变量数 ≤ 10 时**穷举全部辅助赋值**，否则用自实现 DPLL；
     两者在小规模上交叉验证一致（`test_brute_force_agrees_with_dpll`）。
2. **传播能力**：在全部 3^n 个部分赋值上统计 UP 冲突检出率与强制值检出率。
3. **声称有解时**：DPLL 解投影回原变量，用直接计数独立验证原约束。

## 子句数与传播能力差异（结论）

- **传播能力**：两种编码在 at-most / at-least / exactly 上均达到完全传播
  （GAC：不可扩展的部分赋值 100% 被 UP 检出冲突，被强制的原变量 100% 被 UP 推出），
  由 `TestPropagation` 在 3^n 个部分赋值上穷举验证。
- **规模**：顺序计数器更紧凑（子句 2k(n-2)+n+k-1，寄存器 (n-1)k）；
  网络编码因全比较器（每门 3 子句，换双向 GAC）子句更多、UP 工作量更大。
- **增量能力**：网络编码的一元输出支持 O(1) 原生收紧；顺序计数器需经
  假设机制重编码（可撤回）。

## 测试结果

`python3.11 -m unittest test_cardenc -v`：**21 个测试全部通过**（约 2 分钟），覆盖：

- 边界语义：k<0 / k>n / k=0 / k=n / n=0（含 n=0 恰好 0 可满足）；
- 投影等价网格：n∈[0,6]、k∈[-2,n+2]、三种约束 × 两种编码，全部 2^n 原赋值
  与直接计数一致；
- 原赋值→辅助赋值扩展通过独立检查器；穷举辅助赋值与 DPLL 互验；
- 增量收紧（网络原生 + 假设机制）与撤回恢复；
- 辅助变量编号/命名不冲突；已知子句数公式回归；UP 传播完备性。
