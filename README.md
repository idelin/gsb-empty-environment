# 决策表分析器 (decision-table-analyzer)

为含**范围、枚举、否定**条件的优先级决策表寻找**命中见证**:对每条规则,
找出能让它真正胜出的最小输入模式;若规则永远无法胜出,则给出它被哪些
规则覆盖的符号化解释;同优先级规则冲突时,给出同时命中的见证输入。

字段域有限但组合巨大(例如 `121 × 4 × 4 × 10001 ≈ 1.9 亿`),分析全程
采用符号化的"盒子"(各字段允许值集合的笛卡尔积)求交/求差,不做穷举。

## 运行

需要 Node.js ≥ 22.6(直接运行 TypeScript,无需编译;推荐 23+):

```sh
node src/cli.ts examples/discounts.json          # 人类可读报告
node src/cli.ts examples/discounts.json --json   # 机器可读 JSON
node --test test/*.test.ts                       # 运行测试
```

`--json` 输出中,枚举字段的取值集合为普通数组,int 字段压缩为
`{ "runs": [[lo, hi], ...] }` 区间形式,未约束字段为 `"any"`。

## 决策表格式

```jsonc
{
  "name": "discounts",
  "fields": [
    { "name": "age",   "kind": "int",  "min": 0, "max": 120 },
    { "name": "tier",  "kind": "enum", "values": ["standard", "gold"] }
  ],
  "rules": [
    {
      "id": "R1",
      "priority": 100,              // 数值大者胜出; 缺省为 0
      "action": "discount-20",      // 可选, 仅用于展示
      "conditions": {               // 可选; 缺省 = 匹配一切 (兜底规则)
        "age":  { "op": "range", "min": 18, "max": 65 },
        "tier": { "op": "not", "cond": { "op": "eq", "value": "standard" } }
      }
    }
  ]
}
```

条件算子(同一字段的多个条件可经 `and`/`or` 组合,字段之间隐式合取):

| 算子    | 含义                                   |
| ------- | -------------------------------------- |
| `any`   | 不约束                                 |
| `eq`    | 等于某个值                             |
| `in`    | 属于值集合                             |
| `range` | 整数区间 `[min, max]`(仅 int 字段)   |
| `not`   | 否定(相对字段域取补)                 |
| `and`   | 全部子条件成立                         |
| `or`    | 任一子条件成立                         |

## 语义

- **胜出**:输入命中规则 R,且没有任何优先级 `>=` R 的其他规则命中。
  同优先级同时命中视为**冲突**,不算真正胜出。
- **最小见证**:一个部分赋值模式(尽量多的字段为"任意"),其所有补全
  都保证 R 胜出;报告同时给出约束字段数、保证胜出的输入总数和一个
  具体示例输入。
- **覆盖**:若 R 的命中区域被优先级 `>=` 它的规则完全覆盖,则用贪心
  集合覆盖 + 冗余消除给出一组(近似最小的)覆盖来源,并标注每条来源
  覆盖的区域及关系(`higher-priority` / `equal-priority`)。
- **冲突**:同优先级规则命中区域相交即报告;若交集中存在不被更高
  优先级规则截获的输入,则为"有效冲突",否则标注"被更高优先级遮蔽"。
- **不可满足**:条件本身矛盾(如 `and(eq gold, not(in gold))`)的规则
  单独标记。

## 输出示例

```
规则 R5-youth-dup  (priority=70  action=discount-5)
  状态: 被覆盖 —— 任何命中本规则的输入都会被其他规则截获
    - R4-youth (更高优先级) 覆盖区域: age ∈ 20..25, tier ∈ {standard}

冲突: 1 组同优先级规则可同时命中
  R2-promo × R3-apac (priority=90, 有效冲突)
    同时命中见证: { age: 0, tier: "standard", region: "APAC", spend: 500 }
```

## 实现要点

- `src/model.ts` — 类型定义与 JSON 校验(域大小上限 100 万)。
- `src/boxes.ts` — 条件编译为值集合;盒子的交、差(按字段分裂)、体积。
- `src/analyze.ts` — 胜出区域 = 规则盒子减去所有优先级 ≥ 它的盒子;
  见证松弛、覆盖解释、冲突检测。
- `src/report.ts` / `src/cli.ts` — 文本报告与命令行入口。
- `test/` — 单元测试 + 300 个随机小表对暴力枚举的交叉验证
  (状态、见证、模式补全、冲突对完全一致)。
