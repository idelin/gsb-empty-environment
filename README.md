# 撤销集合的非成员证明混入旧根

凭据服务使用RSA累加器压缩撤销集合，需要同时验证成员和非成员证明，不能把旧根的证明搬到新一代。为Go服务实现可导入的证明包，本题算法固定：宿主提供可信奇数N、单位群元素g和互异32位素数集合，P为集合元素乘积，A=g^P mod N；成员x的证明W=g^(P/x)，验证W^x=A。非成员用整数a、b满足a*x+b*P=1，给D=g^a及0≤b<x，验证D^x*A^b=g；负指数通过模逆处理，非单位元素拒绝。实现生成、验证及增删集合后的新根计算；每个证明的调用身份必须绑定宿主指定的集合ID、代次与根摘要，不能凭证明自报根。x非素数、重复集合元素、非规范整数及不匹配代次直接拒绝，集合至多128项；空集合P=1。用小RSA参数全集合参考核对合法证明方程和在集合内禁止生成非成员证明，测试不将小参数视为抗分解配置，加入删除后的旧证明、D不在单位群、b为负或等于x及同根不同集合ID。验证仅声称本题代数与身份条件，不把可复用的旧验证结果当当前撤销结论。
