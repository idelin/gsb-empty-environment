卫星下行一轮发完后，上行只能回一段很短的 SACK 比特流，且多轮报告之间没有长度字段。为可靠传输栈交付可导入的 Go 码本编译包与增量解码器。每个发送端上下文给绝对首包号、按序的发送槽（槽为发包或空洞）、已确认的绝对包号集合。接收端报告仅含低 w 位基号、从该基号起的固定长接收位图；不能读发送端上下文。同一报告在所有上下文必须用同一码字。输入还枚举允许的（上下文、绝对基号、接收位图、发生次数）事件，保证基号低位相符，不能假设窗口内没有回绕。事件的正确重传清单是上下文中本轮实际发送、既未预确认也没有被该绝对位图覆盖为已收的包，按原发送槽序返回。若相同可见报告在同一上下文给出不同清单，返回两条冲突事件。其余情形给每个报告分配 1 到 L 位码字：在同一上下文可见的不同码字必须前缀无关，同一码字可复用但必须返回同一清单；不同上下文之间允许严格前缀重合。最小化所有事件的码长乘发生次数之和（精确整数），再最小化最大码长，余下任选。无解与输入冲突区分。解码器按调用方给的当前上下文吃任意分块位流，首个完整码字结束时即吐出该轮的绝对重传清单，未消费的比特留给下一上下文。禁止靠整段结束符推断边界。最多十八种报告、L≤8、二十四种上下文，不能枚举所有裸码字赋值；小规模用独立全分配验证最优费用，并核对存在码字在一个上下文立刻可解在另一上下文仍须继续、同报文窗口回绕别名、只因最后一个空槽而可合码，以及分块正好截在两个码字中间。
