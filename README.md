# uniparse

面向文本标注器的合一文法解析库（Go）。非终结符可携带**有限特征映射**，
特征值为常量或规则局部变量；解析器对短词序列返回**所有可合一分析的共享森林**。

## 文法格式

```
# 注释
start S
S[num=N]  -> NP[num=N] VP[num=N]
NP[num=N] -> Det N[num=N]
Det       -> "the"
N[num=sg] -> "dog"
N[num=pl] -> "dogs"
VP[num=N] -> V[num=N]
V[num=sg] -> "barks"
V[num=pl] -> "bark"
```

- 特征值首字母大写为**变量**（规则局部），其余为常量；引号串恒为终结符/常量。
- 右部裸词若不作为任何规则的左部出现，则视为终结符。
- 限制：规则数 ≤ 20、无空产生式、输入词数 ≤ 20（允许递归文法）。

## 核心保证

- **每次展开重新命名**：规则实例化与节点复用时变量一律换新名。
- **重复键冲突失败**：两特征映射共有的键，值不可合一则整体失败；单侧键不受约束。
- **不跨分支污染**：代换不可变，扩展前克隆，兄弟分支互不影响。
- **规范去重**：特征结构按首现顺序重命名为 `v1, v2, ...`，
  α-等价的代换折叠为同一森林节点；相同（规则, 子节点）的推导折叠为同一 packing。
- **共享森林**：节点 =（类别, 规范化特征, 跨度），`Packings` 记录全部推导方式。

## 验证

`Forest.Verify(maxTrees)` 把每个根节点**独立展开**为具体树（迭代加深，
循环森林也能终止），逐棵重新检查：

- 词序：终结符从左到右的 yield 与输入完全一致；
- 特征一致：每个内部节点用全新变量重新合一其规则与全部子节点。

`VerifyTree` 可单独校验一棵树（对篡改过的树会报错）。

## API 速览

```go
f, err := uniparse.ParseText(src, words)   // 文本格式 → 共享森林
g, err := uniparse.ParseGrammar(src)       // 仅解析文法
f, err := uniparse.Parse(g, words)         // 程序化构造的文法 → 森林
trees := f.Trees(10)                       // 展开最多 10 棵树
n, err := f.Verify(10)                     // 独立展开并逐棵验证
```

程序化构造：`NT("NP", Feats{"num": Var("N")})`、`T("dog")`、`Rule{...}`。
