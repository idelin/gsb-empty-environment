# 两种长度声明让代理夹带了第二个请求

反向代理同时接受`Transfer-Encoding: chunked`与`Content-Length`，后端取其中一个，攻击者可夹带第二个请求读走他人响应。请实现嵌入TypeScript代理的可导入消息边界判定中间件。对每个请求确定唯一framing：同时出现两种长度、重复TE、末编码非chunked、chunk扩展含歧义即拒绝；HTTP/1.1升级和h2c降级按显式策略处理，规范化后的头集合与消息边界交给后端，不接受二次解析。连接复用前清空残留缓冲区，超时和半关闭不产生新的隐式请求。用CL.TE、TE.CL、双TE、chunk终止符变体、h2降级和合法分块请求验证代理与后端的边界一致。
