# 分层租约与多级代理授权协调器

大规模微服务集群的分级授权模型：根协调器只与少量区域网关维系长周期粗粒度租约，
区域网关向本区工作节点颁发短周期细粒度子租约，将中央协调压力分流到边缘。

## 架构

```
RootCoordinator (1)          根租约 TTL = 60s，粗粒度配额池
   └─ RegionGateway (5)      子租约 TTL = 5s，细粒度配额，本地超时回收
         └─ WorkerNode (1000) 仅与本区网关通信，过半续租
```

- `src/root-coordinator.ts` — 根协调器：颁发/续租/回收 60s 根租约，只认识区域网关
- `src/region-gateway.ts` — 区域网关：持有根租约，细分颁发 5s 子租约，掉线节点子租约在本地超时释放
- `src/worker-node.ts` — 边缘工作节点：申请/续租子租约，`drop()` 模拟掉线
- `src/clock.ts` — 时钟抽象（`ManualClock` 保证测试确定性）
- `examples/sample.ts` — 1000 节点 / 5 网关 / 70s 仿真样例

## 运行

要求 Node.js >= 22.6（原生 TypeScript type-stripping，零依赖，无需编译）：

```bash
npm test          # Node 内置测试运行器（node:test）
npm run sample    # 运行仿真样例
```

## 验收边界（由测试与样例共同验证）

1. **1000 个边缘节点获得配额** — 全部持有有效子租约；
2. **根协调器仅与 5 个区域网关通信** — `root.getPeers()` 只含网关 ID，根租约表恒为 5 条，
   根中心消息复杂度 O(网关数)，与边缘规模解耦；
3. **边缘掉线根负载零波动** — 200 节点掉线后，其子租约在网关侧 5s 超时释放，
   根中心消息数/操作数零增长（见测试「边缘节点掉线仅本地子租约超时释放」与样例的
   每 10s 操作数时间线 `[5, 0, 0, 5, 0, 0, 5]`，掉线时刻无尖峰）。
