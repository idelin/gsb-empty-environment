给 Go 软件认证器写可导入的凭据事务授权包。宿主在用户解锁后建立一个会话，可签出绑定设备启动代次、RP、操作集合、过期时刻及事务号的授权票。每个请求带票、序号、前一成功响应的摘要和本次命令摘要，使用会话密钥对长度前缀编码的全部字段做 HMAC-SHA256。一次事务可先枚举指定 RP 的凭据，再从已枚举集合选择一个执行断言；新加入的凭据不可被选中，已撤销的在最终签名时拒绝。断言只能成功一次。相同序号、完全相同命令的重传应返回同一已提交响应，不得让宿主签名两次；相同序号换命令、跨 RP、错链或设备重启前的票据均拒绝。宿主提供 SignOnce(事务号，命令摘要，凭据ID) 与 Lookup(事务号)；前者在同一步消费凭据授权并保存断言字节，后者能取回该事务已签的命令摘要及原始断言。超时后通过 Lookup 核实，只有明确查无此事务才可按同一事务号重试，返回的断言字节必须与首次签发完全相同。用固定密钥和可控的提交回调，覆盖提交后丢回包、两份并发重传、枚举后撤销、权限收窄及两次启动重用序号，核对宿主实际签名次数。
