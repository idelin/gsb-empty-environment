# 容器生命周期钩子在宿主命名空间执行不可信路径

运行时执行prestart或poststop钩子时若信任容器根里的路径和环境，攻击者可让宿主权限执行替换后的程序。给Go运行时宿主实现钩子冻结与执行包：钩子配置含阶段、宿主绝对可执行路径、参数、环境键值、超时和允许命名空间集合；只有宿主受信目录下的普通文件可执行，逐段目录句柄解析不跟随symlink，记录设备/inode/内容摘要/模式/属主及打开的只读且不可经该句柄写入的可执行句柄。参数和环境按字节预算验证，环境键唯一，清除LD_PRELOAD、动态库路径和题面保留键，PATH由宿主固定。冻结所有钩子后才启动容器；执行通过已冻结句柄，不按路径重开，文件身份或摘要变化则拒绝。阶段策略规定CreateRuntime、Poststop在宿主Mount/UserNS但无容器网络，CreateContainer、StartContainer在容器Mount/PID/Net且使用降权凭据；钩子不得请求额外namespace或能力。每个钩子状态Pending/Running/Succeeded/Failed持久化，启动前阶段失败阻止容器，poststop失败记录但不复活容器；响应丢失按hookID幂等。用可注入文件系统在冻结与执行间替换路径、symlink父级、环境注入、namespace错配和超时终止钩子及其全部后代进程测试，宿主执行回调只接冻结句柄。
