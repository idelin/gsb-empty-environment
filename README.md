# minisql：分区裁剪与跳过证明

纯 Python 3.11+ 标准库实现（不调用任何 SQL 引擎）的教学级关系表 + 分区裁剪分析器。

## 特性

- **整数范围分区**：任意开闭边界归一化为整数闭区间（开界 `lo -> lo+1`、`hi -> hi-1`），
  构造时校验所有分区无缝覆盖整条整数线（前区 `hi + 1 ==` 后区 `lo`），
  从机制上保证边界行不漏不重。
- **有限枚举分区**：值到分区的映射 + 可选 catch-all（约束建模为「已枚举值的补集」，可精确裁剪）。
- **NULL 独立分区**：键为 NULL 的行单独存放；基于三值逻辑（`NULL` 比较得 `UNKNOWN`，
  `WHERE` 只保留 `TRUE`）可证明 NULL 分区对普通比较谓词安全跳过。
- **跳过证明**：每个分区的保留/跳过决定都附带自然语言证明
  （区间不相交、枚举无命中、UNKNOWN 过滤、参数未绑定保守保留等）。
- **未绑定参数**：分析阶段参数 `$1` 未绑定时保守保留全部范围分区
  （NULL 分区仍可证明跳过）；绑定后同一计划可精确裁剪。
- **多重集合语义**：行以 list 存储，重复行独立计数；OR 跨分区结果为各分区命中行的并集（不去重）。
- **正确性验证**：`select_full_scan` 提供无裁剪对照；随机化测试（300 行 × 200 随机谓词）
  验证裁剪扫描与全表扫描逐行一致。

## 结构

| 文件 | 职责 |
| --- | --- |
| `minisql/logic.py` | 三值逻辑 TRUE/FALSE/UNKNOWN |
| `minisql/predicate.py` | 谓词 AST、NOT 下推（德摩根 + 算子取反） |
| `minisql/partition.py` | 区间归一化、覆盖性校验、范围/枚举/NULL 分区、表 |
| `minisql/analyzer.py` | 分区裁剪判定与跳过证明生成 |
| `minisql/engine.py` | 本地执行器（只扫描保留分区）+ 全表扫描对照 |
| `demo.py` | 运行样例（范围分区 7 查询 + 枚举分区 2 查询） |
| `tests/` | 50 个 unittest 用例 |

## 运行

```bash
python3 demo.py                          # 运行样例
python3 -m unittest discover -s tests    # 运行测试（50 用例）
```

```
=== Q3 OR 跨分区并集 ===
谓词: (amount < 0 OR amount >= 100)
  [扫描] p_low    OR 存在可能为真的支路：键域 [-inf, -1] 与谓词域 [-inf, -1] 存在交集，可能命中
  [跳过] p_mid    OR 各支路均不可能为真 ⇒ 可跳过。[amount < 0]: ∀行: 键 ∈ [0, 99]，而谓词要求
                  键 ∈ [-inf, -1]，两区间不相交 ⇒ 谓词对该分区每行均为 FALSE；...
  [扫描] p_high   OR 存在可能为真的支路：键域 [100, +inf] 与谓词域 [100, +inf] 存在交集，可能命中
  [跳过] p_null   OR 各支路均不可能为真 ⇒ 可跳过。...NULL 比较结果为 UNKNOWN，WHERE 不保留 ...
  结果 4 行: [(1, -50), (4, 100), (5, 100), (6, 800)]  ✓ 与全表扫描一致

=== Q6 参数未绑定（分析阶段保守保留） ===
谓词: amount = $1    参数: {'1': 100}
  [扫描] p_low    参数 $1 未绑定，无法排除任何区间 ⇒ 保守保留
  [扫描] p_mid    参数 $1 未绑定，无法排除任何区间 ⇒ 保守保留
  [扫描] p_high   参数 $1 未绑定，无法排除任何区间 ⇒ 保守保留
  [跳过] p_null   键恒为 NULL，NULL 与任何值比较结果均为 UNKNOWN ⇒ 该分区每行都被过滤
  结果 2 行: [(4, 100), (5, 100)]  ✓ 与全表扫描一致
```
