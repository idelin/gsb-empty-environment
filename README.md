# hier-graph-store

将多表记录与增量变更组装为带稳定实体 ID 的层级图。纯 TypeScript，零依赖，
利用 Node.js ≥ 23.6 内置的类型擦除直接运行，测试使用 Node.js 内置测试框架
（`node:test`）。

## 运行

```sh
npm test        # node --test test/*.test.ts
npm run sample  # 可重放样例：node src/sample.ts
```

## 模型

- **实体与来源**：实体以稳定 ID 标识，存在性由各来源的 presence 贡献共同决定；
  某来源删除仅移除该来源的贡献，其余来源仍在则实体保留并回退字段值。
- **字段级解析**（`src/fields.ts`）：每个字段保留每个来源一份贡献
  `{source, version, value, path}`。有效值取最高优先级层；同层不同值 →
  **未决（pending）**，绝不任选；同层同值按版本、来源名确定性坍缩。
  父关系即特殊字段 `_parent`，继承同一套优先级/版本/未决语义；
  父字段未决时保持现状（hold），不任意选边。
- **JSON 语义**：对象键无序（`{a,b}` 与 `{b,a}` 相等，不产生假冲突），
  数组有序（`[1,2]` 与 `[2,1]` 冲突）。批次内事件按数组顺序应用。
- **孤儿队列**：子先于父到达时进入有序孤儿队列，父到达后自动接续；
  删除父时按显式策略 `preserve-children-as-orphans` 保留待接续子，
  不静默级联丢数据。
- **子树移动与成环**：父关系更正整体移动子树；把 A 移入其后代 B（或自身）
  时原子拒绝——先校验后提交，统计与结构零变化，错误带 JSON 路径。
- **聚合统计**：`subtreeSize` / `subtreeConflicts` 沿祖先链增量维护，
  `lastTouched` 精确记录每个事件触及的节点，可验证只更新受影响祖先链。
- **幂等与版本**：`eventId` 跨批次去重不双计；字段贡献按版本单调，
  过期事件与过期删除（tombstone）被忽略。
- **快照与重建**：每批次结束生成快照，`restore(batchId)` 可还原旧来源视图；
  `rebuild()` 从事件日志全量重建，`canonical()` 投影用于与增量状态对照。

## 错误定位

所有错误（`CYCLE`、`INVALID_PARENT` 等）与字段级血缘均携带输入文档中的
具体 JSON 路径，如 `$.batches[2].events[0].parent`。

## 测试结果

```
ℹ tests 19
ℹ pass 19
ℹ fail 0
```

覆盖：字段优先级/未决/版本、JSON 键序与数组序、孤儿队列与自动接续、
子树移动与受影响祖先链、成环原子拒绝且统计不变、删父保留子与身份恢复、
跨批次去重、快照还原旧来源、tombstone 防过期复活、增量 == 全量重建、
聚合统计与独立重算一致。

样例 `npm run sample` 输出各阶段状态并以 `REPLAY OK` 结束（内置断言，
失败即非零退出）。
