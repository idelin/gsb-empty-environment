# rectcover — 矩形覆盖求解器

在有限整数格点中，用轴对齐格点矩形覆盖全部目标点且不包含任何禁点。
目标函数为字典序：**先最少总面积，再最少矩形数**。矩形允许重叠，
重叠面积重复计费（总面积 = 各矩形面积之和）。

## 构建与测试

```sh
go build -o rectcover .
go test ./...
```

## 使用

输入为 JSON（stdin 或 `-input` 文件），点可写作 `[x, y]` 或 `{"x":x,"y":y}`：

```sh
echo '{"targets":[[0,0],[1,0],[3,0],[4,0],[1,2]],"forbidden":[[1,1]]}' | ./rectcover -verify
```

输出包含：最优矩形列表（含每个矩形覆盖的目标下标）、总面积、矩形数、
**逐点覆盖证据**（每个目标被哪些矩形覆盖）、求解方法、候选数、节点数等。

参数：

- `-dp-budget N`：目标数 ≤ N 时用子集 DP 精确求解（默认 22），否则用分支限界。
- `-max-nodes N`：分支限界节点预算（0 = 不限）。预算耗尽时中断搜索，
  返回当前最优可行解并置 `interrupted: true`。
- `-verify`：小网格上用**全体候选子集**的独立子集 DP 交叉核对结果。

## 方法

1. **候选枚举**：最优矩形的四条边总可收缩到目标点坐标上（收缩不会引入禁点），
   故只需枚举边经过目标坐标的矩形，要求至少覆盖一个目标且不含禁点。
2. **约简**：相同覆盖集合只保留最小面积矩形；小规模时再做法支配剪枝
   （覆盖为超集且面积不更大的候选淘汰被支配者）。
3. **精确搜索**：目标数少时用目标子集 DP；否则用分支限界，下界为
   “剩余面积 ≥ 未覆盖目标数”（每个矩形面积不小于其覆盖目标数）与
   “任一未覆盖目标的最便宜矩形”的较大者，并以全单点矩形作为初始 incumbent。
4. **缺口/孤点**：与禁点重合的目标、或没有任何候选能覆盖的目标，
   会在 `uncoverable` 中报告，`feasible` 置为 false。

注：由于每个矩形面积 ≥ 其覆盖的不同目标数，且单点矩形总可行，
最优总面积恒等于可覆盖目标数；第二目标（最少矩形数）相当于求
“实心矩形”（内部全为目标点）的最少划分。
