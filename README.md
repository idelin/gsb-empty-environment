实时音视频网关在执行 WebRTC ICE（RFC 8445）连通性检查与 DTLS-SRTP（RFC 5764）密钥导出时，若未校验 SDP `a=fingerprint` 与实际 DTLS 对端证书哈希一致、忽略 STUN `MESSAGE-INTEGRITY` HMAC 校验，或允许通过 `host`/`srflx` 候选地址探测内网保留 IP，攻击者可发动媒体流中间人劫持或利用 WebRTC 探测用户真实内网拓扑。为 TypeScript 媒体安全宿主实现可导入的零外部依赖（仅用 `node:crypto`）ICE/STUN 认证与 DTLS-SRTP 绑定核验引擎，严禁联网。组件解析 STUN 绑定请求/响应（校验魔术 Cookie `0x2112A442`、`FINGERPRINT` CRC32 与 `MESSAGE-INTEGRITY` HMAC-SHA1），严格拦截未通过认证的伪造 `USE-CANDIDATE` 提名；对 ICE 候选地址实施与浏览器一致的 mDNS `.local` 脱敏与私网/环回/链路本地 IP 过滤策略；在 DTLS-SRTP 阶段强制核对对端证书 SHA-256 指纹与信令 SDP 声明完全一致后，按 RFC 5764 使用 `EXTRACTOR-dtls_srtp` 导出客户端/服务端主密钥与主盐并严格隔离发送/接收方向密钥。附真实密钥构造的指纹篡改、STUN 伪造提名与内网候选地址泄漏拦截测试。
