大规模 Transformer 流水线并行训练中，经典 1F1B 调度把反向传播当作整体，导致稳态前后留有可观的流水线气泡；Zero-Bubble 流水线（ZB-H1/H2 风格）把每个微批 `m` 在阶段 `s` 的反向计算拆分为两个独立任务：**激活梯度 `B(m, s)`**（依赖 `F(m, s)` 与后一阶段的 `B(m, s+1)`，完成后立即把梯度发送给前一阶段 `s-1` 解除上游等待！）和**权重梯度 `W(m, s)`**（仅依赖本阶段自身的 `F(m, s)` 与 `B(m, s)`，不阻塞任何其他阶段，可被灵活延迟调度去填满后续气泡空洞！），但显存生命周期与跨阶段通信死锁约束极其严格：1）**显存两阶段释放硬上限**：在阶段 `s` 启动 `F(m, s)` 立即占用激活显存 `memF`；执行完 `B(m, s)` 释放部分无需用于权重梯度的中间激活（剩余 `memW` 驻留）；直到 `W(m, s)` 执行完毕才彻底归零释放！任意时刻每个阶段 `s` 的驻留显存总量必须严格 `<= memLimit[s]`（因此绝不能为了填气泡把过多 `W` 无限拖延导致显存爆掉！）；2）**数据依赖与同步 P2P 通信无死锁验证**：支持非均匀耗时 `(tF, tB, tW)` 与通信延迟 `tComm`，完整建模跨阶段 `Send`/`Recv` 依赖（含双向同步发送时的奇偶配对或调度序校验，证明最终排期图严格无环、零通信死锁！）；3）**最小气泡排期器与 1F1B 基准对比**：给定阶段数 `P`、微批数 `M`、各块耗时 `(tF, tB, tW)`、单微批显存 `(memF, memW)` 与显存上限 `memLimit`，先构造标准 1F1B 基准排期作为对照，再求解合法的 Zero-Bubble `F/B/W` 排期（优先把关键路径上的 `B` 尽早推进以解锁上游，把非关键 `W` 精准填入空闲气泡并在显存逼近上限时强制提前排空最老 `W`！），输出每阶段精确起止时间甘特表、全过程峰值显存与气泡率。为分布式训练框架交付可导入的 Go Zero-Bubble 流水线调度与显存/死锁验证包。验收覆盖 `F -> B -> W` 全部跨阶段与阶段内依赖校验、严格显存峰值 `<= memLimit`（含紧显存强制提前插入 `W`！）、通信无死锁检测、以及气泡率严格优于同配置标准 1F1B 的实测断言。
