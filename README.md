# 云存储匿名入口收敛

对象库的匿名可见性由桶策略、对象标签和访问点共同决定。写供Go策略宿主调用的可达性包，输入有限对象类别与三层布尔条件，匿名访问必须存在同一条完整入口路径，不能组合不同访问点的许可。求全部公开对象类别及最短路径证明，用入口关闭和标签变更的全量重算验证增量结果。

## 用法

实现在 `reachability/` 包中：

- `NewModel(entries, statements, tagRules)` 构建模型：访问点（入口层）、桶策略语句（策略层，绑定唯一访问点）、对象标签规则（标签层，绑定唯一语句与类别）。
- `FullRecompute(m)` 从零求全部公开对象类别及每类的最短路径证明（`Proof`，3 跳直达或 4 跳经标签规则）。
- `NewEngine(m)` + `Apply(events...)` 增量维护：入口开关、语句允许/拒绝、标签匹配变更只重算受影响的语句；`Verify()` 用全量重算对拍增量结果。
- `CheckEvents(m, events...)` 便捷校验器：克隆模型后增量应用事件并与全量重算比对。

```sh
go test ./reachability/
```
