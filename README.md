# 格式串计数写入的最小载荷

日志兼容层仍支持计数写入转换，需要验证攻击者控制格式文本能否修改受保护字节。用Go做供安全测试宿主调用的载荷规划与回放包，仅执行本题格式子集，不调用真实格式函数：普通ASCII可打印字符（32至126，百分号只能写作%%）使计数加1，%%加1，%Nc使计数加N，%K$hhn把当前计数模256写到第K个参数指定的字节地址，N与K为不带前导零的正十进制数。宿主给最多8个参数地址、16字节初始内存和目标字节约束，攻击者只能使用这些参数，每个参数至多写一次，总计数不得超过4096。求达到全部目标且不改变非目标字节的格式，优先最小最终计数，再最少写入次数，再格式字节字典序；允许零输出的相邻hhn，但不允许N=0。输出写序列、实际计数和最终内存，无法达成须说明。回放器严格拒绝未知转换、越界参数及溢出计数，错误前不提交任何内存写。用同址参数、目标值回绕、写入初值不变及4096边界核验，不能把普通格式解析错误当成漏洞。
