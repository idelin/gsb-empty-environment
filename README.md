# int-ir-optimizer

带分支的整数中间码（IR）优化库（TypeScript）。核心约束：**溢出与除零是可见错误**，优化不得改变程序的可观察行为——包括错误类别、出错位置与执行轨迹。

## 中间码

32 位有符号整数（`src/ir.ts`），指令带稳定 `id`：

- `const r, v` / `input r`（外部输入，编译期未知）
- `add / sub / mul / div / mod r, a, b`：溢出（含 `INT_MIN / -1`）与除零抛出 `EvalError`
- `br cond, L1, L2` / `jmp L` / `ret r`

## 解释器（`src/interp.ts`）

`run(program, inputs)` 返回：

- `trace`：按执行顺序记录的指令 `id` 序列（错误轨迹）
- `outcome`：`ok:value` 或 `err:{kind, instrId}`

## 优化器（`src/optimize.ts`）

前向数据流常量传播（worklist，格：`const | unknown | bot`）：

- **常量折叠**只在求值确定不触发错误时进行；确定出错的指令（如 `1/0`）原样保留，错误仍在同一 `id` 抛出
- **不做代数恒等式化简**（如 `x*0 → 0`）：`x` 的求值可能出错，化简会消除该异常
- **只删确定不可达的指令**（入口状态为 `bot`）：常量条件分支折叠为 `jmp` 后，死分支及确定出错指令之后的代码才可删除
- 所有保留/重写的指令保持原 `id`，错误位置与执行轨迹可逐条比较

## 差分测试

- `src/gen.ts`：种子可复现的随机程序生成器（结构化前向分支、边界值常量池、input 指令），自带定义-使用校验
- `src/difftest.ts`：对同一随机程序与同一输入，比较原解释器与优化后解释器的**结果及完整错误轨迹**
- `src/tests.ts`：定向用例（`x*0` 不消错、溢出折叠保留、死分支删除、`INT_MIN/-1` 等）

```sh
npm test                 # 定向测试 + 2000 个随机程序差分
node dist/difftest.js 50000 1   # 指定程序数量与起始种子
```

当前验证：50000 个随机程序（约 26% 以溢出/除零结束）结果与错误轨迹完全一致，0 不一致。
