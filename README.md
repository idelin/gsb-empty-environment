备份索引要放进能观察读写槽号的外部存储；即使所有租户 API 返回相同的阶段通知，按摘要查不同桶仍会暴露某块早就存在。给 Go 备份宿主写可嵌入的批次索引，存储回调只接收槽号和等长密文。公开参数为索引容量 M、固定批量 Q 和当前代次。批内可以建立租户引用、撤销或续读租约，操作及是否命中均为私密；不足 Q 的位置填充。相同公开参数及相同公开故障时点下，读写槽号、操作方向、次数、密文长度和提交回调顺序须完全一致，包括容量不足而拒绝的批次。输入块拥有权由宿主验证的租户上传收据授予，知道全局摘要仍不能直接建立引用。去重物理记录与租户引用分别有固定槽预算，删除最后一项引用还需等有效租约结束。每次重写槽使用独立认证加密，身份、槽号和代次作为关联数据，重放旧页须拒绝。索引不能对每个请求重扫 M 个槽；单批访问上限 O((M+Q)log²(M+Q))，明文工作空间 O(log(M+Q)) 个记录，宿主能检查每次外存访问。请用独立的小型明文向量模型核对快照与租约，再用成对执行逐项比较公开轨迹，覆盖同批共享摘要、上批已存在、全是填充、表满和中断后重试。
