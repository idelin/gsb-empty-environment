# versionedkv

带版本比较条件的内存 KV 存储。

## 语义

- **版本比较更新**：`CompareAndSwap(IfVersion(v), Put(...))` 仅当键仍处于版本 `v` 时写入。
- **批量比较**：`Batch(conds, writes)` 要求全部条件同时成立才原子写入；任一条件失败则整体拒绝，不产生任何副作用。
- **独立缺失版本**：读取不存在的键返回该键专属的缺失版本（`Exists=false`，锚定在墓碑修订号上），可用于 "仅当仍不存在时创建" 条件。
- **无 ABA**：全局单调递增修订号，版本绝不复用。删除并重建后，旧条件（包括旧缺失版本条件）永远不会再次成立。

## 测试

- `store_test.go`：针对版本更新、批量全通过才写、缺失版本独立性、删除重建 ABA、空批、同键多条件冲突的单元测试。
- `exhaustive_test.go`：小状态穷举（2 个键 × 19 种动作 × 深度 4，约 13.7 万条序列），每步校验 ABA 不变量、批量原子性与模型一致性。
