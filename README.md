网关从旧证书链迁到新证书链时，同一账户可能同时持有硬件钥、服务证书和短期访问令牌。给Go资源宿主写可导入的持有证明验收库。输入已核验签名的事件，描述密钥生成、交叉认证、令牌续发、撤销、时钟偏移声明及一次资源请求。每条授权列出允许的操作集、有效闭区间与委托深度上限，撤销可按主证书指纹或事务批次生效且立即阻断基于被撤销凭证的所有后续续发与派生。校验请求时刻下是否存在一条未过期的有效授权链与当前持有证明同时成立，防止利用旧链续发的短期令牌在新链撤销后继续复用或越权延长有效期；当事件存在偏序不确定或缺少关键撤销水位时返回未知而非放行。另给独立复核函数，验证返回的有效链与拒绝理由中引用的每条事件均存在于输入且满足时间与委托深度单调递减。用小事件集穷举核对交叉认证回滚、撤销竞态、令牌续发超期及水位缺失情形。
