# 城市传感器采集得到的计量值会补发校准参数，历史值需要重算而不丢原读数

城市传感器采集得到的计量值会补发校准参数，历史值需要重算而不丢原读数。为Go时序接入宿主实现校准映射包，原始样本按设备实例与序号固定，校准为生效半开时间区间内的有理仿射变换；参数迟到时仅重算相交样本，重叠校准按明确版本优先，版本相同异参数拒绝。输出修订事件与原始证据，不能覆写原读数。用全量重算核对时钟回拨标记、边界相等与撤回校准。

## 实现

包 `taskpkg`（`calibration.go`）以 `Engine` 为入口，全部读数使用
`math/big.Rat` 做精确有理运算，避免浮点误差。

- 原始样本 `Sample` 以 `(Device, Sequence)` 固定身份，存入后不可变；同身份
  异读数返回 `ErrSampleConflict`，完全相同的重复写入为幂等空操作。
- 校准 `Calibration` 在半开区间 `[EffectiveFrom, EffectiveUntil)` 内生效，
  `EffectiveUntil` 为零值表示开放到无穷远；变换为 `value*Scale + Offset`。
- 迟到校准只重算样本时间与区间相交的历史样本；无变化不产生新事件。
- 重叠校准取最大 `Version`；同版本异参数（或复用已撤回版本）返回
  `ErrVersionConflict`，同版本同参数重复提交为幂等空操作。
- 每次重算只追加不可变 `Revision`，携带 `Evidence`（原读数快照 + 生效校准
  快照），原读数永不被覆写。
- 时钟回拨按序号顺序重算：样本时间严格早于前一样本即标记 `RolledBack`。
- `WithdrawCalibration` 撤回校准后，相关样本回退到下一优先校准或恒等映射。

## 核对

`Recompute` 仅依据原始样本与当前有效校准独立重建全量物化视图；`Verify`
在此基础上逐条比对物化值、回拨标记、修订序号连续性，以及每条修订是否可由
其自身证据快照复现，覆盖时钟回拨、半开边界相等与撤回校准三类场景。
