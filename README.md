# robustline — 鲁棒直线拟合器

给定平面上至多 20 个整数坐标点，剔除至多 `k` 个离群点，拟合一条直线
（一般式 `ax+by+c=0`），使保留点到直线的**最大垂直距离**最小。
统一使用一般式表示，竖直线自然支持；全部比较为精确整数运算。

## 构建与运行

```sh
go build -o robustline main.go
./robustline            # 从 stdin 读
./robustline input.txt  # 或从文件读
go test .               # 3000 组随机数据与暴力枚举对拍
```

## 输入格式

```
n k          # 点数 1<=n<=20，剔除上限 0<=k<n
x1 y1
...
xn yn        # 整数坐标（|坐标| <= 10^6）
```

## 输出

- 最优直线的一般式（系数已约分）；
- 被剔除的离群点编号与坐标；
- 最大垂直残差：精确值 `sqrt(p/q)`（残差² 的约分分数）+ 十进制近似；
- 最优性证据：压在下/上边界上的点，以及枚举的候选法向数量。

## 算法

1. 对固定点集，"最小化最大垂直残差"的最优直线 = 点集**最窄包含条带的中线**，
   最优误差 = 条带宽度 / 2。
2. 条带宽度关于法向是分段正弦函数，段内唯一驻点为极大值，故最小值必在
   某两点连线方向的法向（事件方向）处取得 —— 只需枚举 O(n²) 个点对法向，
   无需斜率表示，竖直线（水平法向）自动覆盖。
3. 每个法向下，把点投影到法向（整数），排序后取覆盖至少 `n-k` 个点的
   最窄窗口；窗口严格之外的点即离群点（至多 k 个）。
4. 跨方向比较误差² = `extent² / (4·|n|²)`，用整数交叉相乘（math/big），
   完全精确，无浮点误差。

复杂度：O(n³ log n)，n=20 时约 0.04s。
