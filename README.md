Git 对象库推送与拉取采用 Packfile v2 二进制流，其中 `OFS_DELTA` 使用特殊的负偏移变长编码（每多一个续字节都要对高位加一，极易与普通 LEB128 混淆），而增量指令流中的 `copy` 指令在长度字段为 0 时按协议代表复制 65536 字节而非 0 字节；解析或编码时任何一位出错都会导致校验和失效或大块数据截断。为代码托管存储后端交付可导入的 Go Packfile v2 编解码与增量重建包。编码器支持写入完整对象（commit/tree/blob/tag）以及 `OFS_DELTA`/`REF_DELTA` 增量对象，计算 zlib 压缩流与包尾 SHA-1 校验和，并支持为两个任意字节序列生成合规的 delta 指令流（含源长/目标长变长头、insert 指令和 copy 指令，正确编码 65536 字节块及大偏移）。解码与重建器按流解析包头（魔数 `PACK`、版本 2、对象总数）及各条目头（3 位类型 + 4 位首段长度 + 后续 7 位小端续字节），解析 `OFS_DELTA` 特殊变长负偏移定位包内基对象，`REF_DELTA` 按 20 字节对象 ID 查找包内或外部薄包（thin-pack）基对象，支持多层增量链还原并校验最终字节长度与源/目标头匹配；遇到越界偏移、增量环路、深度超限、指令越界、尾部多余字节、SHA-1 不匹配或非法 `0x00` 保留指令字节时必须返回明确分类错误。验收覆盖含 65536B copy 指令、多字节 `OFS_DELTA` 负偏移边界（127/128/16511/16512）、5 层混合 `OFS_DELTA`+`REF_DELTA` 链重建、薄包外部基对象解析以及单字节篡改与环路拒绝。
