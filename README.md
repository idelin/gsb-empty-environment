运行时把多个来源的调用过滤表优化为一份跳转程序。给 Go 沙箱宿主写可导入的策略校验组件：参考语义是有序过滤器，动作优先级为终止、拒绝、通知、允许，等优先使用最近安装者的数据。规则谓词含系统调用号、架构和六个 64 位参数的掩码匹配、无符号区间，规则可接收调用方定义的命名谓词。优化结果为只能向前跳的判定 DAG，叶子带动作、数据和审计义务集合。验证对所有输入，优化结果既不放宽权限也不丢失参考策略要求的通知与审计；对调用方指定的透明优化区还须完整等价。每条错误要能定位成输入空间的一个不相交符号区域及双方决定；安全结论附覆盖完整输入域的证书。不可逐个枚举 64 位值，不把未知调用号或未用参数假作零。证明绑定源规则、命名谓词版本及区域约束；改动一个命名谓词只重查有依赖的部分，复用其余证据须可验。给独立的小位宽解释器，完整枚举核对区间跨最高位、符号区域空、等优先不同数据、谓词同名异版本及重叠审计标签。
