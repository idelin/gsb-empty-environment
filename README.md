# merklemulti — 多叶子批量默克尔证明(Multi-Proof)压缩器

将针对多个不同叶子的独立默克尔证明合并去重:共享的祖先节点哈希只保留
一份,可由验证端自行重算的中间节点全部省略,最终生成单个 DAG 结构的批量
证明;验证端通过一次自底向上的遍历完成全体验证。

## 原理

- 独立证明:每片叶子携带从叶到根路径上的全部兄弟哈希,多条路径的公共
  祖先被重复传输。
- 批量压缩:按层维护"验证端已知哈希"集合。某节点的兄弟若也在已知集合
  中(可由下层重算),则不传输;否则将其哈希按 (层, 索引) 升序只附加一次。
- 验证:从叶子层出发,按相同顺序消费证明哈希,逐层重算父节点,最终与
  期望根一次性比对。

## 运行

```sh
go test -v ./...   # 测试(含验收用例:叶子 3/4/7/8, 压缩率 > 50%)
go run ./cmd/demo  # 运行样例
```

128 叶子树上对叶子 3、4、7、8 的实测:4 条独立证明共 32 个哈希,压缩后
的 DAG 证明仅 14 个哈希,体积缩减 56.2%。
