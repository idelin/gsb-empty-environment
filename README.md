组播网关把两端的反馈合并成一对从小到大排列的秩；发送端永远拿不到带端名的收包日志。为网关做可导入的 Go 修复控制器。每代至多四个等长源符号，两端各自初始掌握的 GF(2) 掩码和各自要恢复的源符号均已知。一个时隙可从给定非零掩码表广播一个实际异或载荷；要么全收，要么仅一端失收，全程单端失收至多两次，不能假定独立概率。数据时隙结束只报告两端当前的匿名秩对。另一种动作是花一个时隙轮询指定一端，可靠获得该端当前子空间的唯一行最简基（按源符号编号从小到大选主元，按主元列排序）；这一时隙不传符号，不消耗丢失预算。两种动作都有给定正整数线路费用。限七个时隙内，找出能保证两端分别恢复其目标的策略，使最坏总费用最小；同费用再最小化所有路径中用掉的最大时隙数，这两项最大值允许出自不同分支。只根据已发动作及实际反馈选下一步或停发，停止须对所有相容历史成立；无保证方案要明确报告。提供逐时隙可调用的策略和收端用实际字节消元取回目标的实现。用独立小规模策略树枚举核对两个最优值，回放允许的全部失收位置并和原始字节对照；覆盖秩相等但能解出的目标不同、端名互换给出同一观测，以及立即停止和耗尽时隙仍无法保证恢复的情形。
