# examsched — 考试安排工具

为考试分配时段与考场，避免学生考试冲突，并对连续考试施加分级惩罚。
优化目标为**字典序**：先最小化**最大个人惩罚**，再最小化**总惩罚**——
不会为了降低总和而让少数学生承担全部连续考试。最多支持 12 门考试。

## 构建与运行

```sh
go build -o examsched .
./examsched -input examples/sample.json
```

选项：

| 选项 | 说明 |
| --- | --- |
| `-input` | 问题定义 JSON（必填） |
| `-slots N` | 覆盖输入中的时段数（0 = 使用输入配置） |
| `-maxnodes N` | 搜索节点上限（0 = 不限；超限后结果不再保证最优，输出会标注） |
| `-top N` | 报告中展示个人惩罚最高的前 N 名学生 |
| `-json` | 以 JSON 输出完整解 |

运行测试：`go test ./...`

## 输入格式

```json
{
  "slots": 0,
  "slotsPerDay": 3,
  "rooms": [{"name": "A101", "capacity": 30}],
  "exams": [{"id": "MATH101", "students": ["S01", "S03"]}],
  "runPenalty": [0, 0, 1, 3, 6]
}
```

- `slots`：时段数。`0` 表示自动——求解器从冲突下界开始逐增时段数，
  保留目标最优的解（目标随时段数单调不增，达到 (0,0) 即停止）。
- `slotsPerDay`：每天时段数。大于 0 时，跨天的相邻时段**不算**连续考试。
- `runPenalty[l]`：连续 l 场考试的惩罚（可选）。缺省为三角数分级：
  连考 2 场 = 1，3 场 = 3，4 场 = 6，……，即 l(l-1)/2，
  连续场次越长惩罚增长越快。

## 约束与目标

硬约束（违反即不可行）：

- 同一学生在同一时段只能有一场考试；
- 同一时段同一考场只能安排一门考试；
- 考场容量不得小于考试人数。

软目标（字典序优化）：

1. 最小化最大个人惩罚 `max_s penalty(s)`；
2. 在前者最优的解中，最小化总惩罚 `sum_s penalty(s)`。

学生惩罚：将其考试时段排序后，每段长度为 l 的极大连续时段序列
产生 `runPenalty[l]` 的惩罚，求和。

## 算法

考试数 ≤ 12，采用回溯搜索 + 分支限界：

- 按冲突度降序安排考试，冲突用位掩码判断；
- 下界：已形成的相邻考试对在学生最终惩罚中至少各贡献 1，
  据此对 (最大惩罚, 总惩罚) 做字典序剪枝；
- 贪心解作为初始 incumbent 加速剪枝；
- 考场分配按时段独立做二分匹配（回溯），搜索中即时检查可行性。

搜索是完备的：未设节点上限时，输出解为可证明最优。

## 输出核验

报告包含独立核验（`verify.go` 从零重算，不复用求解器状态）：

- 每门考试恰好安排一次，时段/考场合法；
- 无学生同时段冲突、无考场重复占用、容量满足；
- 个人惩罚、最大惩罚、总惩罚重算与求解器声明一致；
- 个人惩罚分布与惩罚最高的学生名单，便于检查公平性。
