# facetlib：多值属性分面统计（纯标准库 Python 3.11）

在本地合成 UTF-8 文本文档上，对主查询结果做多值属性分面计数。
不依赖任何搜索服务或全文检索库，仅使用 Python 3.11 标准库；测试用 unittest。

## 运行

```bash
python3.11 main.py                          # 演示：合成文档 -> 索引 -> 分面计数 -> 快照/增量 -> 全组合核对
python3.11 -m unittest discover -s tests -v # 单元测试（含 4 分面全组合穷举核对）
```

## 文档格式（本地 UTF-8 纯文本）

```
id: doc-0001
@颜色: 红, 蓝, 红
@作者: alice
@年份:

正文自由文本……
```

- 没有 `@<分面>` 行 -> 该分面**缺失**；`@<分面>:` 后为空 -> **存在但空集合**。两者严格分开。
- 同一值重复出现（如 `红, 红`）-> 索引按文档身份去重，**同文档同值只计一次**。

## 分词规则（facetlib/tokenizer.py）

1. NFKC 规范化 + casefold；
2. ASCII 字母/数字/下划线的最长连续段 -> 一个词元；
3. 每个 CJK 表意字符 -> 独立的单字词元；
4. 其余字符一律为分隔符。

## 查询与计数语义（facetlib/query.py）

- 主查询：全部词项 AND；计数绝不包含不匹配主查询的文档。
- 同一分面内选中值之间 **OR**；不同分面之间 **AND**。
- 空选择（空集合）= 不约束；哨兵 `MISSING` = 选“缺失”。两者不同。
- **自排除模式**：分面 F 的计数基线 = 主查询 AND 除 F 外所有分面过滤。
  同时选中 A、B 两个分面时，A 的计数含 B 的过滤、B 的计数含 A 的过滤，各自只排除自己。
- 每个分面输出：各值计数 + **缺失单列** + 基线文档数。

## 位图与共享中间结果（facetlib/index.py）

- Python `int` 作为不可变位图，bit i = 槽位 i 的文档；计数 = `(基线 & 值位图).bit_count()`。
- 主查询位图只建一次，被所有分面计数复用；每个过滤分面的位图只建一次。
- k 个受约束分面用**前缀积 + 后缀积**求各自基线：合取 2k 次，而非朴素的 k(k-1)。
- 引擎全程只做位图运算，**不为任何分面重扫文档**（`EvalStats.docs_scanned` 恒为 0）；
  逐文档布尔求值仅存在于独立参考实现 `facetlib/verify.py`，用于核对。

## 增量更新与历史快照

- `add_or_update(doc)` / `remove(doc_id)`：按文档身份（doc_id）增量维护全部位图。
- `snapshot()`：浅拷贝字典即可隔离（int 位图不可变），快照上的查询返回历史结果，
  不受后续增删改影响。

## 正确性核对

`verify_all_combinations` 穷举每个分面 `(值域 ∪ {MISSING})` 的全部子集选择，
对每组主查询，把引擎的每个分面计数与逐文档布尔参考逐项比对：

- `main.py`：3 分面 × 2 组主查询 × 120 文档，8192 组合 / 24576 项计数；
- `tests/test_facets.py`：4 分面 × 2 组主查询，16384 组合 / 65536 项计数。
