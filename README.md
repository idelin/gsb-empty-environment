# multiproof

多叶子批量默克尔证明（Multi-Proof）压缩器，纯 Go 标准库实现。

## 原理

针对多个叶子的独立证明路径在树上共享大量公共祖先节点。压缩器将
这些路径合并为单个 DAG 证明：自底向上逐层追踪验证端已可计算的节点
集合，只把缺失的兄弟哈希发出一次，公共祖先由验证端自行重算，无需
传输。证明按「逐层、层内从左到右」排序，验证端一次顺序遍历即可完成
全体验证。

## 使用

```go
tree := multiproof.NewTree(leaves)              // 构建默克尔树
mp, _ := tree.GenerateMultiProof([]int{2, 3, 6, 7}) // 压缩证明（叶子 #3,#4,#7,#8）
ok := multiproof.VerifyMultiProof(tree.Root(), mp)  // 单次遍历验证
```

## 运行

```sh
export GO111MODULE=on
go test ./... -v   # 测试
go run ./cmd/demo  # 样例：8 叶子树，证明 #3,#4,#7,#8
```

## 效果

验收用例（8 叶子树，叶子 #3,#4,#7,#8）：4 条独立证明共 12 个哈希，
压缩后仅需 2 个，体积缩减 83.3%。树越大缩减越显著（256 叶子、证明
其中 128 个时缩减 87.5%）。
