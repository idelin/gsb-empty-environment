# 多架构镜像拉到了未验证的子清单

集群拉取多架构镜像时只校验清单列表摘要，节点按平台选择子清单却没核对子清单自身的摘要链，攻击者可在同一列表下推送未签名的旧镜像。请实现供Go容器运行时调用的可导入镜像解析与平台选择组件。验证从清单列表、平台子清单、配置到每个层blob的逐级摘要，平台匹配按os、architecture、variant和OS版本；签名或证明只在其覆盖的摘要上生效，annotations不能替代摘要。缓存按摘要寻址，标签移动不改变已解析结果；缺层、摘要算法不一致和重复平台按失败处理。用标签重推、子清单摘要不符、变体混淆、层篡改、合法多架构和缓存命中验证选择结果只来自已验证的摘要链。
