# 多点多项式证明的重复求值点

数据可用性接入层批量验证同一多项式的多个求值时，重复横坐标可能被插值实现静默覆盖。请交付供Go接入宿主调用的多点承诺验证包：可信宿主提供素数域q、G1/G2群运算、配对、规范编码及同一秘密tau的幂SRS，包不接收请求方自带SRS。请求含承诺C、1至32对(z,y)及证明pi；相同z与相同y合并，相同z不同y拒绝，再按z排序构造唯一插值多项式I与Z(X)=∏(X-z)。验证e(C-CommitG1(I),G2)=e(pi,CommitG2(Z))，SRS次数不足必须拒绝；若CommitG2(Z)为单位元返回参数退化，其他规范单位元承诺或证明允许，所有标量须在0至q-1，非法点先拒绝再配对。返回规范化求值集合与所用SRS身份，空请求不能当作成功。另用已知tau的小域配对代数替身生成正确和错误证明，对低次多项式全枚举验证插值、重复点、零多项式及证明替换；明确这些测试验证的是代数与编码边界，真实配对实现由宿主负责。
