# 关系分解检查器

对关系模式的分解做两项**相互独立**的判定：

1. **无损连接**：有限表格追逐（tableau chase）。输出逐步合并证据。
2. **依赖保持**：令 G = ∪ π_Ri(F)，用投影闭包算法判断 G ⊨ F，
   不物化 G。对不保持的依赖给出闭包缺口 `(X)+_F \ (X)+_G`。

两项结论分别报告，互不蕴含（见测试中的四种组合）。

## 运行

Node >= 23.6（原生类型擦除，无需构建）：

```sh
node src/cli.ts --attrs ABCDE --fds "A->BC;CD->E;B->D;E->A" --decomp "ABC CDE"
node src/cli.ts --file spec.json     # {"attributes":"ABCDE","fds":"...","decomposition":"ABC CDE"}
node src/cli.ts ... --json           # 机器可读输出，便于重放校验
node tests/run.ts                    # 测试
```

退出码：`0` 无损且保持；`1` 有损或不保持；`2` 输入错误。

## 确定性与可重放约定

- 属性、FD、分解分量均按输入顺序处理；集合一律排序去重。
- 符号规范命名：第 k 列杰出变量 `a<k>`，第 i 行第 k 列非杰出变量 `b<i>_<k>`。
- 合并裁决：杰出变量优先；两个非杰出变量保留名称字典序较小者（合流）。
- chase 每轮按 (FD 序号, 行对字典序, 右部属性序) 找到第一个可执行合并，
  全局替换后重新扫描。符号总数严格下降，chase 有限终止。
- 同一输入产生逐字节一致的证据序列（测试 6 验证）。

## 限制

- 最多 10 个属性，超出拒绝。
- 属性名：字母开头的标识符；无分隔符的纯字母串按单字符拆分（`ABC` = A,B,C）。
