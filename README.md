嵌入式网关从不可信TCP分片流解析嵌套TLV协议时，非最短定长编码、构造标志位欺骗、重复标签覆盖或累计字节计数回绕均可绕过安全策略，给C++17网关实现可嵌入的增量事务型TLV解析头文件库（零动态异常，支持 `-Wall -Wextra -Wconversion -Wsign-conversion -Werror` 编译）。每条TLV记录含2字节大端Tag（明确编码class、constructed构造位与13位tagNum）、可变长度编码头与载荷：规则规定必须严格区分基础型与构造型，构造型记录载荷须由零个或多个完整合法子记录精确拼满且最大嵌套深度为8；所有长度字段拒绝负数、`INT32_MIN`与一切非最小规范多字节长度前缀（含前导零长），同一构造作用域内禁止同一tagNum重复出现（防覆盖参数污染）。外部注入的流总配额可高达 `SIZE_MAX`，累计消耗须同步计入每级头部字节、载荷字节与子记录开销并在加法前做严格防溢出截断。核心事务保证：`feed(chunk)` 无论在任何单字节或随机分片边界切割输入，仅当一棵完整顶层子树通过全部语法、防重复、深度与配额检查后，才按先序发出回调并推进 `committed()`；任意子层越界、缺字节、构造位不符或重名即刻触发整棵顶层记录零回调回滚，`committed()` 停在顶层起点，解析器永久进入锁定终止态拒收后续输入。附基于逐字节切分与随机重分片的差分测试矩阵，覆盖`INT32_MIN`、非规范长度前缀、同级重复标签回滚、深度8/9阈值及 `SIZE_MAX` 边界配额不回绕。
