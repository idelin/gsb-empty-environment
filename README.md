旁路缓存在高并发读未命中与并发写删交错时，慢读回填旧值会长期污染缓存，单靠版本号无法阻止缓存击穿下的惊群。为缓存服务核心交付可导入的 Go 租约状态机包（参照 Memcache Lease 机制并明确全部规则）。支持按毫秒时间戳处理的 Get、Set(key,val,leaseToken)、Delete(key) 事件与全局租约有效期 L、失效静默抑制窗 H。规则：键缺失且不在抑制窗内时，Get 返回未命中并签发全局单调 64 位新租约令牌，且在租约有效且未发生 Delete 前，后续 Get 不再签发新租约而返回热键等待指示（附建议等待剩余时长）；Delete 立即清除缓存值、作废该键所有已签发租约，并将该键置入持续 H 毫秒的抑制窗（期间 Get 返回未命中但不签发有效租约，防止读到写前旧库值回填）；Set 仅在携带该键当前唯一有效且未过期的租约令牌时才写入并结束租约，否则静默拒绝并报告具体拒绝原因（过期、被删除作废、令牌不匹配）。验收用并发交错序列对照不变量（任何早于最近一次 Delete 的租约绝不可写入），覆盖读未命中后发生 Delete 再 Set 必拒、抑制窗内热键读不发令牌、租约过期后重新发牌且旧牌失效、以及多键互不干扰。
