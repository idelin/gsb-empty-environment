# 折叠内积证明的转录替换

证明接入服务需要验证对数长度的内积证明，不能把另一承诺的折叠路径搬过来。给Go宿主实现以下自定义素数阶群协议的证明生成与核验包，群阶q、群运算和规范点编码由可信适配器提供，n为不超过1024的二次幂。承诺P=Σa_iG_i+Σb_iH_i+<a,b>U；每轮把向量均分，L=<aL,GR>+<bR,HL>+<aL,bR>U，R=<aR,GL>+<bL,HR>+<aR,bL>U。挑战x由SHA256对域标签、宿主上下文、n、全部生成元、P及截至本轮有序L/R编码的长度前缀转录取模q产生，零值加计数器重哈希。折叠a=x*aL+x^-1*aR，b=x^-1*bL+x*bR，G=x^-1*GL+x*GR，H=x*HL+x^-1*HR，P更新为P+x²L+x^-2R，末轮核对单元素承诺。生成元由宿主固定且非单位元；规范编码的单位元P、L、R允许，零向量仍是合法见证。拒绝轮数错误、非规范标量或点及转录上下文不符，不能只检查最终等式而跳过挑战重建。提供P-256测试适配与小阶代数参考，验证交换L/R、改n、换上下文和截断证明均被识别，不声称测试适配替代生产群参数审查。
