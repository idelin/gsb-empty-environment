# 动态容量感知一致性哈希

结合实时 CPU/内存负载的一致性哈希分发器：节点在哈希环上的虚拟节点数量随实时健康度动态伸缩，高负载节点虚拟节点收缩，流量自动向周围节点分流泻洪，避免雪崩。

## 环境要求

- Node.js ≥ 22.18（或 ≥ 23.6）：直接以类型擦除方式运行 TypeScript，无需编译、零依赖。

## 快速开始

```bash
npm test    # 运行 Node.js 内置测试（node:test）
npm run demo # 运行验收场景演示
```

## 架构

| 模块 | 职责 |
| --- | --- |
| `src/hash.ts` | MD5 哈希，将键映射到 32 位环空间 |
| `src/ring.ts` | 一致性哈希环：权重 = 虚拟节点数，二分查找顺时针路由 |
| `src/controller.ts` | 容量感知器：按周期把实时负载换算为环上权重 |
| `src/distributor.ts` | 分发器门面：路由 + 负载上报 + 周期调控 |

### 健康度模型

压力取 `max(cpu, memory)`，健康度因子：

- 负载 ≤ 软阈值（0.5）：因子 = 1，保持满权重；
- 超过软阈值：因子 = `(1 - load) / (1 - softThreshold)`，线性衰减；
- 钳制下限 `minFactor = 0.2`，节点不会被完全摘除，防止流量整体迁移引发二次雪崩。

权重 = `round(baseWeight × factor)`。因此 CPU 30% → 权重 100；CPU 90% → 因子 0.2 → 权重 20（验收边界）。

### 泻洪机制

权重收缩即虚拟节点从环上移除，原本落在这些虚拟节点弧段上的键顺时针漂移到相邻节点（B/C），实现自动分流。一致性哈希保证：**只有高负载节点上的键发生迁移，健康节点上的键 100% 不动**，无全局重哈希。

## 使用示例

```ts
import { LoadAwareDistributor } from "./src/distributor.ts";

const d = new LoadAwareDistributor();
d.addNode("A", { cpu: 0.3, memory: 0.3 });
d.addNode("B", { cpu: 0.3, memory: 0.3 });
d.addNode("C", { cpu: 0.3, memory: 0.3 });

d.route("user-42"); // → "B"

// 监控探针上报：A 的 CPU 骤升至 90%，下一个调控周期生效
d.updateLoad("A", { cpu: 0.9, memory: 0.3 });
d.cycle(); // A 的虚拟节点权重 100 → 20，流量自动泻向 B/C
```
