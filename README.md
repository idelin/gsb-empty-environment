# symexec-int8

八位有符号整数小语言的符号执行器(TypeScript 实现,Node ≥ 22.6 直接运行,零依赖)。

## 运行

```sh
node src/main.ts        # 或 npm start
```

对 `src/examples.ts` 中的每个程序:符号执行求出触发指定断言失败的最小输入,
再与全输入穷举(每个输入 256 种取值的具体执行)逐一对照,全部一致时退出码为 0。

## 语言

- 语句:赋值 `assign`、条件 `if/else`、有界循环 `while`(带 unroll 上界 `bound`)、断言 `assert`。
- 表达式:int8 字面量、输入 `in{i}`、变量、一元 `-`/`!`、算术 `+ - *`、比较 `< <= == != >= >`、逻辑 `&& ||`。
- 语义:算术按 int8 回绕(-128..127)并检测溢出;条件非零为真;逻辑运算不短路;
  变量未赋值默认为 0;循环迭代超过 `bound` 的路径被截断并记录。

## 设计

- **符号执行**(`src/executor.ts`):状态为 `{ pc, store, ovf }`。在每个语句之后、
  循环头每次迭代处,符号存储完全相同的状态被合并为一个——路径条件取各状态的**析取**
  (各自路径条件被保留),溢出条件取 `∨(pc_i ∧ ovf_i)`;存储不同的状态并存于同一位置。
- **溢出检查**:每次算术运算产生符号溢出条件(`ovf` 节点),沿路径累积;
  终止点(程序结束 / 断言失败 / 循环超界)记录 `pc ∧ ovf`,析取后即为“发生溢出”的输入条件。
- **不可达分支**:每条分支边(`if#n:then`、`while#n:enter`、`assert#n:fail` 等)记录到达条件,
  可满足性检查判定可达性。
- **求解器**(`src/symbolic.ts`):输入域有限,按字典序枚举给出最小模型,
  即“触发断言失败的最小输入”;带结果缓存。
- **穷举对照**(`src/exhaustive.ts`、`src/crosscheck.ts`):对每个输入向量具体执行,
  逐输入比对断言失败集合、最小失败输入、溢出集合、循环截断集合与分支可达性。

## 示例结果

| 程序 | 目标断言 | 最小失败输入 | 说明 |
|---|---|---|---|
| overflow-add | assert#0 | `[1, 127]` | 1+127=128 回绕为 -128,溢出路径 |
| bounded-loop | assert#1 | `[1, 50]` | 有界循环;`if#1:then` 不可达;in0>8 被截断 |
| merge-demo | assert#0 | `[-128, 0]` | if#0 两分支汇合后状态合并,pc 保留析取 |
| unreachable | assert#0 | 无 | `if#1:then` 等分支不可达,断言不可触发 |
| neg-overflow | assert#0 | `[-128]` | -(-128) 回绕溢出 |
| mul-overflow | assert#0 | `[2, -128]` | (-128)²=16384 回绕为 0 |
