# ambcheck — CFG 歧义检查器

给定一个**不含空产生式**的上下文无关文法和最大串长 N，找出具有两棵不同解析树的**最短串**；同长度时按文法中终结符的出现顺序选择。找到后输出两棵不同的解析树，供独立验证。

## 用法

```sh
go run ./cmd/ambcheck -g examples/expr.cfg -n 8            # 默认不限预算
go run ./cmd/ambcheck -g examples/expr.cfg -n 8 -budget 100000
cat examples/expr.cfg | go run ./cmd/ambcheck -n 6         # 标准输入
go test ./...                                              # 运行测试
```

文法格式：每行一条规则 `LHS -> alt1 | alt2`，记号以空白分隔，`#` 为注释；
同一 LHS 可写多行；第一条规则的左部为开始符号。出现在某条规则左部的符号
是非终结符，其余为终结符。空产生式与单位产生式环（如 `A -> B`、`B -> A`）
会被拒绝。

## 输出

- 找到时：最短歧义串、两棵不同的解析树（括号记法），并对两棵树做独立校验
  （每个内部节点必须对应一条产生式、叶子的顺序连接必须等于该串、两棵树必须不同）。
- 未找到：`length <= N` 内无歧义串。
- 预算耗尽：退出码 2，结果不可定论。

## 设计要点

- **共享解析森林（SPPF）去重**：对每个候选串做 CYK 式识别，节点为
  `(符号, i, j)`，节点下挂"压缩节点"=（产生式， 切分点， 子节点）。同一棵子树
  的不同构造路径（不同推导顺序、重复规则）映射到同一个压缩节点，因此
  **不会把同一棵树的两条构造路径误计为歧义**。不同树的数量 =
  压缩节点求和、子节点求积（封顶为 2）。
- **重复规则**：解析时按内容去重；即使绕过解析器，压缩节点键也按产生式
  内容（而非规则编号）生成，双重保险。
- **预算**：以"已展开状态数"（产生式 × 切分 的尝试次数）计量，跨候选串累计，
  耗尽即返回不可定论。
- **见证树**：从森林中物化两棵不同的树返回，`ValidateTree` 不依赖森林状态
  独立校验。
- **测试**：`ambiguity_test.go` 内含一个完全独立的暴力参考实现——按句型
  广度优先展开所有推导、物化每棵部分树并序列化去重——对一组小文法
  （含左递归、重复规则、单位产生式链、三元规则、同长平局）与森林实现
  逐一交叉核对。
