主机分多次获取设备度量，更新固件或重置设备后，不能把两个轮次中各自通过验签的片段拼成一次可信启动。给 C++17 准入服务写可嵌入的证明汇集器。每份已验签分片携带设备、启动代次、挑战随机数、度量算法、闭开索引区间、整批承诺根和有效期；验证回调须覆盖这些字段及分片内容。主机策略列出必需部件以及互斥的固件组合，部件别名可指向同一度量槽，别名不能重复贡献支持数。允许请求乱序到达和幂等重传；相交分片的度量必须逐项一致，同一设备代次出现两个经验证但不同的根则整轮失效，不能因后来补齐而恢复。只有同一挑战下的完整覆盖、策略组合及最终设备代次都通过才能发放一次准入句柄，过期或重置后的晚到回调不得发放。对每个放行结果返回从必需部件到具体签名分片的最小见证集，并列取字典序最小的分片编号序列。用独立穷举检查小分片集，覆盖重叠区间、别名、只靠跨轮拼接才齐全、较大分片贪心失败及重置与补齐同时到达。
