# 压缩长度反馈恢复隐藏前缀

服务把秘密标识与攻击者文本一起压缩，想验证只暴露压缩长度是否足以识别标识。为Go安全实验宿主实现候选消除包，压缩格式由本题完全定义：从左到右，在此前最多32字节中找最长非重叠匹配，长度3至15，等长取最近距离，匹配记为2字节，否则字面量记1字节。待压缩内容为秘密候选、分隔字节255和攻击者查询；秘密候选最多256个，每个1至16字节且不含255，查询仅从宿主给定的最多128条字节串中选。回调只返回压缩后的长度，包按上述算法预测每个候选的反馈，选择使最大剩余候选数最小的查询，并列按查询字节序；不能减少集合时停止并报告不可区分组，不宣称恢复。回调反馈不匹配任何候选则报模型不一致。输出逐次候选排除依据，允许预算中断与恢复；用独立逐位置参考压缩器核对重叠禁止、距离并列、短于3的重复以及两个始终同长度的秘密。
