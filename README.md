检索服务把查询与候选各自分成两路整数特征，部署时第二路的平方增益 t 可取给定正有理闭区间中的任何实数。为服务提供可导入的 Go 排名索引。查询和每个候选总范数非零；加权内积 D(t)=D₀+tD₁，平方范数同样按两路加权，分数为带符号的真实余弦，而不是其平方。输入至多十二个候选、两路各至多十六维、坐标为有符号 32 位整数。按真实分数降序，同分按候选编号升序。一次建索引要给出整个 t 区间的前 k 个有序编号：输出榜单恒定的极大连通段，端点是否包含须明确，单点榜单不能漏。非有理端点用本原平方自由整数多项式及只含该实根的有理隔离区间表示；允许不同多项式表示同一个数，但相邻段的共有边界必须能精确判等。宿主会用有理数以及先前返回的代数端点回查榜单，不能用浮点或固定精度网格裁决次序。交付向量检索调用样例和可重放测试：覆盖负分导致平方比较反向、两候选在整段恒等、一重合点上三者按编号排出与左右均不同的次序，以及两个分数仅相切不换序。小实例用独立逐对的符号比较核对每段内部和边界的榜单，并说明为何没有遗漏中间的换序点。
