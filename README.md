递归解析器收到不存在的域名回答时，要靠权威端的散列否定记录确认这个名字确实没有。给验证路径交付可导入的 Go 证明组件。输入是待证名称、一组否定记录（散列算法、迭代次数、盐、下一散列、位图）和通配符记录。组件按 RFC 5155 计算名称的散列，先找最近的存在父节点，再证明该节点到目标之间没有通配符匹配，同时逐个确认目标自身的散列落在记录覆盖的区间之外；散列比较按规范的左旋转位序。区间回绕、盐为空、迭代次数为零、位图里不含对应类型，都要给出明确判定。验收用一组手工构造的区对照判定，覆盖名称恰好等于某条记录的散列、区间首尾相接、通配符存在但类型不符、祖先中有不安全委派导致应直接判不存在的情形。
