# cyclecut — 循环依赖拆解工具

给定一张构建依赖图，其中部分边被**授权**可用指定引导产物（bootstrap
artifact）切断，每条可切边有各自成本。`cyclecut` 求出**总成本最低**的
引导产物集合，使剩余依赖图无环，并输出拓扑构建计划。

约束：可切边数量不超过 **25** 条。未授权的边一律不可切断——不允许用
已有产物替代未授权的边。

## 构建与运行

```sh
go build -o cyclecut .
./cyclecut example.json          # 从文件读取
cat example.json | ./cyclecut    # 从标准输入读取
./cyclecut -json example.json    # 机器可读的 JSON 输出
```

## 输入格式

```json
{
  "nodes": ["a", "b"],                      // 可选，未列出的节点会从边中推断
  "edges": [
    {"from": "a", "to": "b"},                                              // 不可切边
    {"from": "b", "to": "a", "cuttable": true, "artifact": "stub-a", "cost": 4}
  ]
}
```

- `cuttable: true` 的边必须给出 `artifact`（该边授权的引导产物）与非负 `cost`。
- 缺省 `cuttable` 的边为不可切边，任何方案都不得切断。

## 输出

- 总成本与切边清单：每条切边注明所用引导产物与成本。
- 拓扑构建计划：按阶段分层，同一阶段内可并行构建，阶段间按序进行。
- 若不可切边自身成环，则报告无解并指出该循环。

## 算法

最小成本反馈边集（限定只能删可切边）。以「尚存可切边集合」的位掩码为
状态做记忆化搜索：每次在当前图中找一条环，对环上每条可切边分支
（切断并支付成本），取最小值。状态数上界 2^25，配合环检测剪枝，实际
远小于该上界。不可切边预先做无环校验，成环即无解。
