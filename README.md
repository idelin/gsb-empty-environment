镜像网关允许客户端从源仓库复用已有层，避免重新上传，但有些租户只有目标仓库的写权。给 Go 网关写可导入的跨仓库挂载授权包。请求指明源仓库、源清单摘要、层摘要、目标仓库及待更新标签。每份授权由宿主验签后给出主体、租户、仓库分量前缀、动作和有效期。读源和写目标须由同一会话主体同时取得，委托链每层只能缩窄权限，两条不同身份链的授权不能合拼。即使内容库已有同摘要层，也只有源清单引用它且请求人能读该清单时才准复用；无权看到源的请求，对层存在或不存在须返回相同的结果。授权通过后返回一次性提交票，绑定源清单代次、目标标签原始值、双方策略代次和请求摘要。宿主提供比较并替换接口，提交遇到标签变化、源层被移除或任一边撤权须统一撤销票据，不能留下可见的目标引用。用内存清单和真实签名的委托凭据测试跨身份拼权、同摘要不同仓库、授权后撤权、目标标签竞争和成功时重传；比较返回内容及最终引用。
