归档网关只需要条带中指定范围，不一定能解出整份原文。给它交付可导入的 Go 包和可注入的分片读接口。一个条带有至多八个等长源分片；每个候选读动作从一台库取一行非系统码，返回这些源分片按给定系数逐字节线性组合的结果（GF(2^8)，模多项式 0x11d），或报告该库本次离线。动作仅可各试一次，成功和失败都付全价。离线单位是库，第一次读的成败约束该库其余动作；整个恢复中至多两库离线，事先不知是哪几库。目标是一批源分片的半开范围，只需实际请求的源坐标可由成功行线性表示；重叠、空范围和乱序均合法，输出须按请求顺序。每动作可以只覆盖某个已知的条带列区间，其系数在区间内恒定；不得把不相交列的成功行合并求秩。求对所有合法离线集合都保证恢复的策略，最小化最坏累计费用；在此上限内，再最小化所有合法离线集合等权的费用和。控制器只能观察可用性，不能把载荷当成探测故障的旁路。若无解，给出一个允许的离线集合和一列上的两个不同源向量，使所有可取得的编码行一致但某个请求字节不同；成功时给分段解码系数证书并让网关用实际返回的载荷解码。最多十六个动作、七个库，大条带不能逐偏移构造矩阵，允许输出随请求字节数增长。独立小条带遍历策略对照双目标，实测非二元系数、局部可解但全条带欠秩、失败回执信息有价和同库两个动作成败相关。
