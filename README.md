# Batch Inventory (FEFO, event-sourced)

批次库存库：按到期日出库（FEFO），支持可取消的预留、历史时点库存查询、迟到入库安全与退货回原批次。

## 运行

需要 Node.js >= 23.6（内置 TypeScript 类型擦除，无需编译）：

```sh
npm test
```

## 设计

`src/inventory.ts` 中的 `InventoryLedger` 是一个只追加的事件日志。每个事件携带两个时间：

- `recordSeq`：事件被记录的顺序（单调递增，决定分配竞争的先后）；
- `eventTime`：业务时间，可以早于记录时间（迟到入库）。

### 核心规则

- **按到期日出库**：`ship` / `reserve` 按 `(expiry, inboundSeq)` 排序贪心分配——先到期先出，同到期日按入库序号决胜。
- **迟到入库不改写历史**：出库分配在记录时刻基于"当时已知"的批次计算，并固化在出库事件上；之后补录的更早批次不会改变已完成出库的批次归属，但会正常出现在历史时点库存中。
- **历史时点库存**：`stockAsOf(t)` 只重放 `eventTime <= t` 的事件；`snapshot()` 给出当前分配。
- **预留可取消**：`reserve` 冻结库存，`cancelReservation` 释放；同一时刻的预留竞争按记录顺序结算，先到先得，绝不超分（守恒：`reserved + available == onHand`）。
- **过期隔离**：`expiry < 业务日期` 的批次被隔离——仍在账面（`expired` 标记）但永不参与分配。
- **退货回原批次**：`returnGoods` 把数量加回指定原批次，且累计退货不得超过该批次已出库数量。

## 测试

`test/inventory.test.ts` 覆盖：

- FEFO 顺序与入库序号决胜；
- 迟到入库后历史出库归属不变、新出库按新状态 FEFO；
- 退货回到原批次、超量退货与未知批次拒绝；
- 过期批次隔离（账在、不分）；
- 同刻预留竞争守恒、取消释放、历史时点仍可见预留。
