# expsim — 顺序停止实验模拟器

接收显式整数观测与预先给定的上下边界，逐步累计统计量（累计和），首次触边即停止。

## 语义

- **处理顺序**：观测按 `(Time, Seq)` 排序处理；同一时间多个观测按序号先后生效。
- **首次触边即停**：累计和 `>= Upper` 或 `<= Lower` 时停止，结论（边界、累计和、步数、触边证据）立即冻结，后续数据不改变结论。
- **重复事件幂等**：同一 `(Time, Seq)` 的重复观测被忽略，重放安全。
- **迟到修订**：修订为事实追加新版本（不覆盖旧版本），随后从最新事实版本重算首次停止点（可前移、后移、翻转或消失）。
- **不可撤动作**：停止时执行的动作写入只追加账本，永不篡改；重算结论与已执行动作分歧时，只追加补偿建议条目。
- **三类持久状态**：事实版本（`FactStore`）、重算结论历史（`Simulator.Conclusions`）、动作版本（`Ledger`）。

## 核对机制

- `VerifyPrefixExhaustive`：对每个前缀，增量引擎与从头重算一致；边界恰好触发一次；重复摄入不改变状态。
- `VerifyCheckpointRecovery`：在任意前缀保存检查点（含停止证据）并恢复，继续运行与不间断运行结果一致。
- `Replay`：事件重放完整复现事实版本、结论历史与账本，用于核对停止点前移/后移及恢复。

## 运行

```sh
GO111MODULE=on go test ./sim/ -v
GO111MODULE=on go run ./cmd/expsim
```
