企业出站代理与沙箱出口网关在提供 SOCKS5（RFC 1928）与 HTTP `CONNECT` 隧道服务时，若在策略校验时做一次 DNS 解析而真正建连时再解析一次（DNS Rebinding TOCTOU）、仅过滤 IPv4 私有段而漏拦 IPv4-mapped IPv6（`::ffff:127.0.0.1` / `::ffff:169.254.169.254`）与 6to4/Teredo/NAT64 封装地址，或允许 SOCKS5 协商静默降级至 `NO AUTHENTICATION REQUIRED`（`0x00`），沙箱内恶意代码可直接探测内网服务与云元数据接口。为 Go 网络安全宿主实现可导入的 SOCKS5 与 HTTP `CONNECT` 原始协议解析、认证协商及防 DNS Rebinding 出口准入控制包，严禁真实联网（DNS 解析与目标建连通过注入的模拟接口完成）。组件严格实现：（1）SOCKS5 协议原始字节状态机：校验版本 `0x05`、方法列表严格交集（策略要求认证时硬拒绝降级至 `0x00` 并返回 `0xFF`）、校验用户名/密码子协商（RFC 1929）及 `CMD=CONNECT`（硬拒绝非授权 `BIND`/`UDP ASSOCIATE`），解析 `ATYP=IPv4`/`DOMAINNAME`/`IPv6` 并拦截截断与越界长度；（2）HTTP `CONNECT` 严格解析：仅允许 `host:port` 权威形式，硬拒绝含路径/userinfo/CRLF 注入/多重 `Host` 头与非白名单端口的隧道请求；（3）统一防 SSRF 与防 Rebinding 出口锁：对域名仅执行**单次**解析并直接将已校验通过的字面量 IP 传入建连回调（杜绝二次解析 Rebinding）；阻断全部回环、私网（RFC 1918/4193）、链路本地（`169.254.0.0/16`、`fe80::/10`）、CGNAT（`100.64.0.0/10`）、多播/未指定地址，以及上述所有地址的 IPv4-mapped/IPv4-compatible/6to4/NAT64（`64:ff9b::/96`）IPv6 变体。附认证降级拦截、DNS Rebinding 二次变 IP 阻断、IPv4-mapped/NAT64 云元数据拦截与 CRLF 走私测试。
