# budget-solver

预算项目组合求解器：在预算约束下选择项目子集，使**总收益最大**。
支持前置依赖、互斥关系与**成对协同收益**（可为负）。协同收益始终作为
成对项参与建模与求解，**不会**被提前摊入项目的固定价值。

## 问题模型

- 每个项目有 `cost` 与独立收益 `value`（可为负）。
- `requires`：选了 A 就必须选 B（传递闭包，循环依赖视为非法输入）。
- `excludes`：A 与 B 不能同时选（对称）。
- `synergies`：仅当 A、B 同时被选中时，额外产生 `value` 的收益（可为负，
  即负协同/冲突成本）。
- 目标：最大化 `Σ value(i) + Σ 协同(i,j)`，约束 `Σ cost(i) ≤ budget`。
- 项目数 ≤ 26。

## 用法

```sh
go run . -input example.json          # 文本报告
go run . -input example.json -json    # 机器可读 JSON
cat instance.json | go run .          # 从标准输入读取
go test ./...                         # 含与暴力枚举对拍的随机测试
```

输入格式见 `example.json`。

## 输出

- 选中项目及其成本、独立收益；
- 成本/收益分解：总成本（含预算余量）、独立收益合计、逐条生效的
  协同项（含负值）、协同合计、总收益；
- 上界证据（最优性证书）：根节点松弛上界、搜索节点数与剪枝数，
  以及“所有被剪子树的松弛上界均不超过最优值、其余节点全部枚举”
  的最优性论证；
- 独立重算校验：按选中集合重新逐项计算总收益并与报告值比对。

## 算法

分支定界（branch & bound）：

1. 决策顺序取前置依赖的拓扑序，同层按“价值+正协同”/成本的启发式
   优先级排序；包含分支优先。
2. 上界：对未决策项目计算逐项上界边际
   `ub(i) = value(i) + 与已选项的正协同 + 与未决策项的正协同`，
   再对 `(cost(i), ub(i))` 做**分数背包松弛**。任意完成的真实增量
   不超过对应 `ub(i)` 之和（负协同被丢弃、内部正协同被双端重复计入），
   而整数背包不超过其分数松弛，故该上界有效。全部运算为精确整数
   （128 位中间结果），小数部分向下取整（真实总收益为整数，取整后
   上界仍有效）。
3. 上界 ≤ 当前最优即剪枝；每个部分解本身可行，随时更新最优解。

由于协同收益以成对形式保留在目标与上界中，负协同只会降低包含
对应项目对的分支的界，而不会被错误地摊薄到单个项目上。
