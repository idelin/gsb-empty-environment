# algebraic — 代数数精确比较与符号判定（Go，仅标准库）

对形如「有理数 + 根号嵌套」的代数数做**严格**的大小比较与符号判定，
全程使用精确有理数运算（`math/big`），不借由任何浮点近似得出结论。

## 表示与算法

一个实代数数 `Num` 表示为：

- **零化多项式**：Q 上的无平方多项式（`MinimalPoly()` 可进一步给出不可约极小多项式）；
- **隔离区间**：有理数端点区间，含且仅含该多项式的这一个根。

核心组件：

| 文件 | 内容 |
|---|---|
| `poly.go` | Q[x] 多项式运算、Sylvester 结式、Lagrange 插值 |
| `factor.go` | 无平方因子分解；Kronecker 算法做 Q 上不可约分解 |
| `modp.go` | 模素数 Rabin 不可约性测试（快速证明不可约，失败回退 Kronecker） |
| `isolate.go` | Sturm 序列实根计数与隔离、区间二分细化 |
| `num.go` | 代数数加减乘、开方、符号判定 `Sign`、比较 `Compare` |

- **和/差**：`h(x) = res_y(f(y), g(±(x−y)))`，其根为两根之和/差；
- **积**：`h(x) = res_y(f(y), y^m g(x/y))`；
- **开方**：`h(x) = f(x²)`；
- 结式通过对 `deg+1` 个整数点求值再插值得到，全部精确；
- 用操作数的隔离区间推出结果的包含区间，在各无平方因子的隔离根中
  选出唯一候选（必要时对区间做二分细化直至分离）；
- **符号判定**：若零化多项式以 0 为根且隔离区间含 0，则该数**恒等于 0**
  （精确判等）；否则细化区间直到不含 0，按区间定号；
- **比较**：`Compare(a, b) = Sign(a − b)`。

## 运行样例

```sh
go run ./cmd/demo
```

输出：

```
a = sqrt(2) + sqrt(3)
  minimal polynomial : x^4 - 10*x^2 + 1
  isolating interval : [3.146264369942, 3.146264369942]  (width < 2^-50)
  decimal (display)  : ~3.146264369942
b = sqrt(10)
  minimal polynomial : x^2 - 10
  isolating interval : [3.162277660168, 3.162277660168]  (width < 2^-50)
  decimal (display)  : ~3.162277660168
c = sqrt(5 + 2*sqrt(6))
  minimal polynomial : x^4 - 10*x^2 + 1
  isolating interval : [3.146264369942, 3.146264369942]  (width < 2^-50)
  decimal (display)  : ~3.146264369942

compare(a, b) = -1  =>  a < b
compare(a, c) =  0  =>  a == c (proved exactly)
```

`sqrt(2)+sqrt(3)` 与 `sqrt(5+2*sqrt(6))` 被构造出同一个极小多项式
`x^4 − 10x² + 1` 与同一隔离区间；差值的零化多项式以 0 为根且隔离区间
含 0，故判定**严格相等**，而非浮点意义下的“近似相等”。
（十进制输出仅供展示，不参与任何判定。）

## 备注

- 比较差值的零化多项式（如 `sqrt(2)+sqrt(3) − sqrt(10)` 的 8 次多项式）
  分裂域为 Q(√2,√3,√5)，Galois 群为 (Z/2)³，因此它**模任何素数都可约**，
  无法靠模 p 测试证明不可约；故运算路径只要求无平方因子 + 隔离区间
  （对比较与符号判定已充分），不可约极小多项式按需经 Kronecker 算法求得。
- 仅依赖 Go 标准库（`math/big`）。
