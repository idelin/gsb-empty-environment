# Zcash Orchard动作规范编码与花费证据

Orchard 动作里的废止符、注记承诺与锚点都是域元素编码，攻击者可提交非规范编码、重复废止符或旧锚点绕过双花检查。给Go节点写供区块验证调用的 Orchard 束准入包，证明与签名验证由调用方注入：flags 字节只有最低两位有定义，其余位非零拒绝；每个动作的废止符与 cmx 是 32 字节小端域元素，值须小于 Pallas 基域模数 0x40000000000000000000000000000000224698fc094cf91b992d30ed00000001，否则拒绝；束内废止符不得重复，且不得出现在链上已花费集合中；锚点必须属于调用方提供的已知树根集合；区块内多个束的废止符同样不得重复。用等于模数的编码、重复废止符、未知锚点和保留位验证。
