查询执行器把几行标量程序融合成一个向量批，某个 lane 提早报溢出不能吞掉它前面几行已交付的结果。给 JIT 后端实现可导入的 Go 降低包。输入给参考标量块和一张机器指令候选表，标量按行、行内按指令顺序跑；按位异或、带有符号溢出陷阱的八位加法、谓词选择、按索引查常量短表（越界陷阱）和向结果流追加字节。所有寄存器初值为输入列或常量，追加立即可见；第一次标量异常停止全批，报告行、指令和此前的完整输出字节序列。机器指令按给定 lane 掩码并行算一条标量操作，可重排覆盖物理寄存器；每条先统一取数再统一写回。机器算术与查表不直接抛出，出错 lane 写零并把对应标量异常位置记入该 lane 的粘滞位集合。另有候选指令可将给定 lane 的值按列明顺序逐项追加，或以给定优先表取已置异常位中第一项并停止整批。客户还可在每条机器指令后要求退回标量：输入列出每个边界可选的若干恢复描述，逐项指定标量续跑位置、寄存器从哪些机器槽或常量恢复，只能选一项，已经交付的字节不能撤回。为至多四行、每行六条操作、十条各限用一次的候选找最低费用机器程序和逐步恢复描述，使任意输入下不停机执行和任意边界退回的完整结果均与参考相同；费用正，同费优先指令少。一个边界的描述对所有输入相同；已经因陷阱结束的路径不再退回。交付独立执行和验证接口，坏计划要给可重放的输入字节、最早出错边界或自然结束以及两边输出或异常的位置。至多 16 个独立输入字节，不能靠列举 256 的幂或随机数据证明等价。极小域逐值核对，包含异常来源属于较晚行但机器先算出、已正确提交一行后退回导致重发、以及值一致而陷阱位置互换的情形。
