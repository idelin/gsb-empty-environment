# 内存查询引擎与谓词下推等价性穷举检查

## 结构

- `src/engine.ts` — 内存查询引擎
  - 三值逻辑（Kleene）：真 `T` / 假 `F` / 未知 `U`，`AND/OR/NOT` 按三值真值表求值
  - 空值比较：`NULL` 与任何值（含 `NULL` 自身）比较都得 `UNKNOWN`，`IS NULL` 例外
  - 算子：`filter`（只保留谓词为真的行）、`project`、`join`（inner/left/right/full）
  - 外连接未匹配侧用 `NULL` 补齐，补出的 `NULL` 与真实 `NULL` 走同一求值路径
- `src/pushdown.ts` — 在值域 `{0, 1, NULL}`、每表 ≤2 行的小表空间内穷举，
  按包语义比较“下推后计划”与“原计划”的输出
- `src/main.ts` — 三值逻辑演示、补空值一致性演示、规则检查入口

## 运行

```sh
tsc -p tsconfig.json && node dist/main.js
```

## 检查结论

| 规则 | 结论 |
| --- | --- |
| R1–R3 `σp(A ⋈ B)` 下推到内连接任一侧 | 成立（1690 用例无反例） |
| R4 `σp(A ⟕ B) → σp(A) ⟕ B`（p 只引用保留侧） | 成立 |
| R5 `σp(A ⟕ B) → A ⟕ σp(B)`（p 只引用补空侧） | **不成立**，如 `p: b=0, A={a:0}, B=∅`：原计划为 ∅，下推后多出补空行 `{a:0, b=NULL}` |
| R6 `σp(A ⟗ B) → σp(A) ⟗ B`（全外连接任一侧） | **不成立**，如 `p: a=0, A=∅, B={b:0}`：原计划为 ∅，下推后多出 `{a=NULL, b=0}` |
| R7 `σp(A ⟕ B) ≡ A ⋈ σp(B)`（p 拒空，即 `p(NULL)` 不为真） | 成立：拒空谓词使外连接退化为内连接 |
| R8 `π(σp A) ≡ σp(π A)`（p 引用的列均被投影保留） | 成立 |

R5 不成立的根源：先筛选会改变“哪些左行未匹配”，使本应被 `UNKNOWN` 丢弃的补空行出现在结果中；
同时 `b IS NULL` 这类谓词在补空行上为真，两侧语义更不可能一致。
