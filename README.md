多租户密钥目录合并后在分布式控制面发生网络分区与脑裂期间继续对外分发 JWK 缓存与验证收据，若验签客户端把来自两个冲突分区恢复决策的密钥证明拼成同一次发布，或未能拦下已触发紧急根撤销的重放密钥及 `alg` 混淆降级，已淘汰密钥即可借同名 `kid` 越权签发受众令牌。为TypeScript验签宿主实现可导入的分区防脑裂策略迁移与最大可信缓存提取包（严禁联网）：输入包括旧新两代已签名根锚定的租户密钥目录、永久租户 UUID、绑定密钥指纹/用途/`alg`/受众列表与有效期窗的迁移动作、带时间戳的紧急根撤销清单、以及可能处于分叉态的多分区共识恢复视图（每个分区视图声明自身覆核的前沿纪元与决议摘要）。严格规则如下：绝对禁止仅依据 `kid`、发布者名称或仓库显示名自动合并两租户密钥；禁止跨安全算法族降级重绑（如 `RS256` 密钥不可通过模糊条目改充 `HS256` 验证）；必须校验每张收据在单一同源完整目录纪元下满足 `(issuer, tenantUUID, pubkey, alg, aud, validAt)` 联合授权并经受最新紧急撤销前沿重放过滤；发现两份证明源自彼此互斥的分区决策前沿时立即整组拦截。输出按时间片与受众严格切分的最大确定安全可复用缓存子集与自包含只读证书，其余标为 `Reverify`/`Unknown`，附全量重建基准核对。
