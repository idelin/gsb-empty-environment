# 间接目标预测器的跨域投毒

隔离运行时担心低信任域训练间接分支预测器，让高信任域在推测窗口执行攻击目标。为Go安全实验宿主实现本题预测器模型：分支站点用16位PC和8位domainID标识，表有64项，索引为(PC右移2)模64，tag为PC高10位；每项保存tag、目标和2位置信度，训练命中同tag时更新目标并加置信度，tag不同时只有置信度为0才替换，否则减1；预测要求tag匹配且置信度至少2。模型A不含domainID，模型B索引再异或domainID且tag包含domainID。攻击者可在域1执行至多8条(trainPC,target)训练，受害者域2随后在固定PC执行一次间接分支，架构真实目标来自宿主白名单；若预测目标不同且属于宿主危险目标集合，则记录最多6条推测操作，barrier停止窗口，所有寄存器写回滚但probe(address)观察保留。搜索使架构目标安全而probe轨迹出现的最短训练序列；每条训练事件的tag、索引和置信度变化都进入见证，等长按PC、target字典序；训练PC与目标均取调用方有限集合。分别报告A/B结果，B无见证只限给定集合和长度。用完整状态BFS参考核对同索引异tag、置信度衰减、域隔离及barrier，不把架构真实调用危险目标算预测器漏洞。

## 实现说明

- `predictor.go`: 预测器模型。索引 `(PC>>2) mod 64`，tag 为 PC 高 10 位；模型 B 索引再异或 domainID、tag 拼接 domainID。训练同 tag 更新目标并饱和加置信度(上限 3)，异 tag 仅在置信度为 0 时替换(新项置信度 1)否则减 1；预测要求 tag 匹配且置信度 ≥ 2。
- `spec.go`: 推测窗口。误预测到危险目标时顺序记录至多 6 条操作，barrier 停止窗口，寄存器写回滚、probe 观察保留。
- `search.go`: `FindWitness` 按 (长度, (PC,target) 字典序) BFS 并对完整表状态去重，返回最短见证；`CompareModels` 分别报告 A/B，B 的"无见证"只对给定集合与长度上限成立。架构真实目标危险或不在白名单时不算预测器漏洞。
- `reference.go`: 完整状态 BFS 参考(`ReachableStates`/`PredictInState`)与不去重的枚举参考(`BruteForceWitness`)，交叉核对同索引异 tag、置信度衰减、域隔离与 barrier 语义。

运行 `go test ./...` 执行全部单元测试、参考核对与端到端示例。
