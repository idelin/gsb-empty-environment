# errmerge

并行/回溯解析器的诊断归并库（Go）。

## 归并规则（`Merge`）

1. 取消费位置最远（`Pos` 最大）的诊断，近端直接丢弃；
2. 位置相同时，合并（求并集）该处的期待 token 集合；
3. 来源链按调用上下文（最内层规则名）分组，每个上下文只保留最短的一条链。

## 回溯语义

诊断沿失败路径事务性传播：`Alt` 的某个分支一旦成功，已放弃分支的
失败诊断连同其成功消费一起被丢弃；只有所有分支都失败时才归并各分支
诊断。因此"最远位置"永远只来自存活路径上的失败点，不会被回溯掉的
消费污染。`Seq`/`Alt` 失败时都会把 `Pos` 恢复到入口位置。

## 组合子

- `Tok(lit)` / `EOF()`：终结符；
- `Seq(...)` / `Alt(...)`：序列与有序选择；
- `Named(name, r)`：命名规则，记录来源链并强制执行 `MaxDepth`
  递归深度限制（0 表示不限），超限时产生 `depth-limit:<name>` 诊断。

测试见 `parser_test.go`，用带歧义前缀（公共前缀 `"abc"`）的小文法
核对回溯丢弃、同位归并、EOF 定位与递归深度限制。
