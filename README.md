主机网卡按 RFC 4862 执行 IPv6 无状态地址自动配置（SLAAC）时，既要走完重复地址检测（DAD）才能启用新地址，又要遵循 RFC 4862 第 5.5.3(e) 节复杂的两小时防 DoS 生存期降级规则，避免伪造路由器通告（RA）把合法地址瞬间清零断网。为协议栈交付可导入的 Go 接口地址状态机包。输入接口 64 位接口标识符、DAD 重传次数与间隔及按秒递增的事件：收到带多个前缀信息选项（PIO：前缀长度、L/A 标志、ValidLifetime、PreferredLifetime）的 RA、收到冲突 NS/NA、时钟推进。严格实现 RFC 4862：(1) 忽略 A=0、前缀非 /64、链路本地前缀 `fe80::/10` 或 `PreferredLifetime > ValidLifetime` 的非法 PIO；(2) 新有效前缀生成地址进入 `Tentative` 态并启动 DAD 定时发射 NS，期间收到同地址冲突 NS/NA 则立即标为 `Duplicate` 永久禁用，未冲突走完重传转入 `Preferred`（若 PreferredLifetime=0 直接转 `Deprecated`）；(3) 对已存在地址更新生存期时，按第 5.5.3(e) 节：若新 `ValidLifetime > 7200s` 或大于当前剩余有效生存期则直接采用新值；否则若当前剩余有效生存期 `> 7200s` 则将其降为 `7200s`；若当前剩余本就 `≤ 7200s` 且非经认证 RA 则保持原剩余有效生存期不变（但 `PreferredLifetime` 始终按新值更新且不超过最终 `ValidLifetime`！）；(4) 到期分别触发 Preferred->Deprecated 与 Deprecated->Removed 迁移。验收对照 RFC 4862 节条款逐秒核对状态与精确剩余生存期，覆盖残余 5000s 收到 Valid=100s 的 RA 拒绝降级但 Preferred 仍更新、残余 10000s 收到 Valid=100s 精准压到 7200s、Tentative 期撞 DAD 禁用，以及 `Preferred > Valid` 整项忽略。
