# 探针规则短路证据真实性

安全网关需要向审计方说明一次允许决定实际执行了哪些规则，不能事后按最终值伪造执行路径。写供Go规则宿主调用的短路执行包，表达式含AND、OR、NOT与可取消检查，每个检查返回判定和证据摘要；执行轨迹绑定节点、次序、返回值与规则版本，验证器独立重放并拒绝缺步或添加未执行分支。用异常、取消和共享节点测试证据不能证明未做过的检查。

## 实现：`shortcircuit` 包

位于 `shortcircuit/`，供 Go 规则宿主直接调用。

- 表达式树：`CheckNode`（叶子检查）、`AndNode`、`OrNode`、`NotNode`，AND/OR 左到右短路，NOT 取反。
- 可取消检查：`CheckFunc` 接收 `context.Context`，返回 `(判定, Evidence 证据摘要, error)`；引擎在每个节点入口检查 `ctx.Err()`，检查自身报错或 panic 也会中止本次决定，绝不产出“允许”。
- 执行轨迹 `Trace`：每次访问生成一条 `Entry`，后序记录，绑定节点 ID、共享节点的访问序号 `Occurrence`、次序 `Seq`、返回值、规则版本 `RuleVersion`、证据摘要与中止原因。
- 防篡改：条目之间用覆盖全部审计字段的 SHA-256 哈希链串联；配置 Ed25519 私钥后对轨迹摘要封印，审计方仅持公钥即可验证，事后重链的伪造也会被封印拒绝。
- 独立重放验证器 `Validator`：**不调用任何检查函数**，叶子取值只来自轨迹条目，按与引擎相同的短路遍历重放。缺步、添加未执行分支、次序交换、返回值/规则版本不符、多余条目、中止标记不一致一律拒绝（`ErrTraceRejected` / `ErrBadSeal`）。

## 关键测试（`*_test.go`）

- 短路：AND/OR 跳过后续检查，`recordingCheck` 调用计数证明未执行的节点确实没跑。
- 异常：检查返回错误或 panic 时记录 `error` 中止条目，后续节点不执行，决定不允许。
- 取消：入口预取消与执行中途取消都记录 `cancel` 条目并通过重放；取消点之后的检查零调用。
- 共享节点：同一节点被多次访问时按 `Occurrence=1,2,...` 分别绑定；伪造的第三次访问被拒绝。
- 防伪造：篡改证据、增删分支、翻转取值、交换次序、规则版本漂移均被拒绝；带封印时重链伪造触发 `ErrBadSeal`，无封印时结构重放仍能拒绝。
- 重放独立性：把所有检查函数替换成会 panic 的毒丸，验证仍通过，证明验证器不执行检查。

运行：`go test ./... -race`
