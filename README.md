# Capsicum权利单调收窄

被攻陷的沙箱进程想放宽描述符权利，或用 openat 的 .. 与绝对路径逃出目录描述符。为C++17沙箱库写可嵌入的权利模型：cap_rights_limit 只能收窄，收窄失败须保持原状；openat 须基准描述符含 CAP_LOOKUP，路径不得是绝对路径，含符号链接、空段或 .. 时须在基准内解析后再判定，新描述符权利不超过基准；fcntl、ioctl 需对应子权利，ioctl 命令须在允许表内，未登记命令拒绝；并发对同一描述符收窄与使用时，不得出现已收窄后仍按旧权利放行。以内存描述符表模型测试放宽、部分收窄、符号链接越界、权利继承、未登记 ioctl 与并发收窄。
