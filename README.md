# SPDM测量响应签名绑定

SPDM 的设备测量证明靠 nonce 与消息记录哈希防重放，攻击者作为中间人转发旧的 MEASUREMENTS 响应，或让设备出示别的会话的签名。为C++主机固件写可导入的响应校验包，供 GET_MEASUREMENTS 响应处理调用，按本题约定：请求里的 32 字节 nonce 由调用方随机源生成，响应须带自己的 32 字节 nonce，并与请求 nonce 不同；签名覆盖的是此前全部消息的摘要（SHA-384 作用于 VCA、证书链记录、请求与响应中除签名外的字节），摘要不符拒绝；证书链根的 SHA-384 须在调用方受信集合内；测量块索引须唯一且升序，重复索引拒绝；请求了签名而响应无签名，或签名长度与算法不符，拒绝；测量值与期望值逐块比对，缺块或多块按失败。用重放旧响应、改 nonce、记录摘要变化、重复索引和缺签名验证。
