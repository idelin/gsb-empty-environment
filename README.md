# geomesh — 带共享顶点网格的事务化编辑（精确算术）

纯 Python 3.11 标准库实现（`fractions.Fraction` + `unittest`），对带共享顶点的
平面网格执行 **移动顶点 / 拆边 / 合边** 三类事务操作，保证引用完整性与面的方向，
失败整体回滚，并生成可逆的结构化补丁（JSON 可序列化）。

## 设计要点

- **精确坐标**：坐标只接受 `int` / `Fraction`（补丁 JSON 中分数编码为 `"p/q"`）。
  浮点数一律拒绝，杜绝引入误差。
- **无 epsilon 的拓扑判断**：共线、在线段上、线段相交、多边形简单性全部由
  精确叉积符号判定（`geomesh/exact.py`）。退化情形有明确定义：
  - 共线 = 叉积精确为 0；端点接触计入相交；
  - 拆分点必须严格位于边的内部（端点被拒绝）；
  - 相邻边仅允许共享端点，共线重叠（尖刺）视为非简单；
  - 重复顶点、零面积、边坍缩为点均为非法。
- **引用完整性**：面通过顶点 ID 引用共享顶点，移动公共顶点自动同步所有引用面；
  拆边会在所有以该边为边界的面中插入新顶点；合边会从所有引用面中移除公共顶点。
- **方向保持**：每个受影响面的有向面积符号在操作前后必须一致，且不为零。
- **合边自交拒绝**：合边产生的新弦若使任何面自交（精确相交判定），
  操作被拒绝并回滚。
- **事务与回滚**：`Transaction` 把每个原语变更记录为 （正向， 逆向） 日志条目；
  任一步失败即整体回滚到事务前的精确状态。
- **可逆补丁**：`commit()` 返回 `Patch`（`forward` / `inverse` 结构化条目），
  `revert()` 精确恢复所有 ID 与坐标，`apply()` 重放；`to_json()` / `from_json()`
  支持持久化与传输。

## 运行

```bash
python3.11 main.py                          # 演示：移动/拆边/合边/回滚/自交拒绝
python3.11 -m unittest discover -v          # 运行全部测试
```

## 代码结构

- `geomesh/exact.py` — 精确几何谓词（orient / on_segment / 相交 / 简单性）
- `geomesh/model.py` — Mesh / Vertex / Edge / Face 与校验
- `geomesh/ops.py`   — Transaction、Patch、三类操作与日志
- `main.py`          — 端到端演示
- `tests/`           — unittest 测试套件
