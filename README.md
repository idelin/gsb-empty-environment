# extcheck —— 重复表达式抽取的重构检查工具

把程序中重复出现两次的表达式 `e` 抽取为 `let tmp = e`（绑定插入在首个
出现所在的顶层语句之前，两处出现替换为 `tmp`）之前，检查绑定与求值行为
是否保持。语言含可变变量、函数调用与异常；每个函数的读集合、写集合及
是否抛错由输入（`FuncTable`）给定。

## 判定条件（逐路径检查，全部满足才允许抽取）

1. **求值次数**：每条执行路径上 `e` 的求值次数不变。抽取后次数恒为
   "是否到达绑定点"，因此要求原程序在到达绑定点的路径上 `e` 恰好求值
   一次（短路/分支跳过两次出现、或两次出现同路径都被求值，均拒绝）。
2. **首错**：首个异常及其与副作用的相对位置不变。`e` 求值抛错时，抽取
   会把异常提前到绑定点，要求绑定点到原求值点之间没有写操作。
3. **读取版本**：每个读取都看到相同的变量版本（版本 = 被写次数）。
   绑定点到求值点之间：不得写入 `e` 读取的变量；也不得读/写 `e` 写入
   的变量（反依赖）。

拒绝时输出**依赖路径**，例如
`let@S0 -> write(x)@S0.else[0] -> e@S0.else[1]`。

## 实现要点

- `lang.go`：表达式/语句 AST、函数规约、结构相等、出现计数与替换。
- `check.go`：抽象解释器沿所有路径执行（`And`/`Or`/`If` 处分叉；版本号
  与值无关，故路径有限）；同一条件表达式在相同版本下复用分支结果
  （路径敏感的分支关联，可识别 `x && e` 与 `x || e` 的互补短路）。
- `interp.go`：具体解释器，用于对照；`equivalent` 枚举初始环境比较
  终态环境、首错与 `e` 求值次数。
- `check_test.go`：定向用例（短路分支、两次出现之间变量被写、异常提前、
  反依赖等）+ 约 1.7 万个枚举小程序的交叉验证：检查器放行的程序必须
  经解释器确认行为一致（可靠性不变式）。

## 运行

```sh
go run .    # 演示 8 个场景，打印判定、依赖路径与解释器对照
go test ./  # 定向测试 + 枚举对照
```
