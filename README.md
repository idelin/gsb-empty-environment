# 法线贴图在镜像UV接缝处翻转

## `tangent` 包

`tangent` 子包为 Go 资产生成切线基，核心入口是 `tangent.Generate`。

- 角点按位置、法线平滑组（`Corner.Group`，0 表示硬边）和 UV 方向拆分；
  镜像 UV（负 UV 行列式）的角点与正向 UV 永不合并，接缝两侧各自累积。
- 每个三角形用 Lengyel 公式求原始切线/副切线，按三角形面积加权累加到拆分
  顶点，再对平滑后的法线做 Gram-Schmidt 正交化。
- 手性符号保存在 `Vertex.Handedness`（+1/-1），不打包进切线；运行期用
  `tangent.Bitangent` 重建副切线，`tangent.PerturbedNormal` 采样法线贴图。
- 退化 UV（零行列式）的角点改用确定性的法线正交轴（取法线最小分量轴叉乘），
  结果在重复运行间稳定。
- 负尺度实例通过 `Options.Transform` 传入：位置走完整 4x4，法线走上 3x3 的
  逆转置，手性在变换后的坐标系中判定。
- 输出 `Result.Indices`（拆分后三角形索引，长度与输入角点一致）和
  `Vertex.Source`（该顶点对应的原始角点下标）。

校验：`go test ./tangent/...`，覆盖已知平面、圆柱接缝、镜像接缝不平均、
负尺度实例与退化 UV 场景。

法线贴图在镜像UV接缝处翻转。写供Go资产管线调用的切线基生成包，按位置、法线平滑组和UV方向拆分角点，累积三角形面积加权的切线与副切线，再对法线做正交化；手性符号单独保存，退化UV使用确定的法线正交轴。输出拆分后的索引及原角点映射，不能跨镜像接缝平均。用已知平面、圆柱接缝和负尺度实例核对重建副切线与扰动法线方向。
