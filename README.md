# 被污染的秘密分片恢复

密钥恢复服务收到参与方提交的错误分片，不能选前k份插值后把错误秘密交给下游。给Go恢复宿主实现可导入的纠错包：分片为互异非零横坐标x及y，均在调用方给定素数p的有限域内，p≤65521；真实分片来自次数小于k的多项式，1≤k≤16，k≤n≤40。调用方声明最多t份错误且n≥k+2t，采用代数纠错恢复多项式和f(0)，随后逐份重算并返回不一致分片ID；找不到与至少n-t份相符的次数受限多项式时拒绝，不能挑一组恰好能插值的分片凑成功。未知错误少于t时也必须成功，处理线性系统多解和误差定位多项式含多余因子的情形；拒绝重复x、非素数域与不满足距离约束的请求。用独立全子集参考在小域核对唯一性，注入0至t个恶意分片，另造超限但仍碰巧落在另一合法码字附近的输入，报告只能说明与收到分片的一致性，不能声称识别了真实攻击者。
