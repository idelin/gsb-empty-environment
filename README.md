# sudoers通配命令放行了额外参数

运维主机允许值班员执行`/usr/bin/systemctl restart app`，sudoers用通配匹配整条命令，攻击者追加`--exec-start=/bin/sh`即可执行任意程序。请实现供C++20提权代理调用的可导入策略匹配组件。策略条目建模为程序路径、固定参数序列、通配位置和禁止参数；匹配按参数边界而不是整串前缀，通配不得覆盖可加载代码、输出文件或解释器选项。环境变量、工作目录、用户与组、超时和审计按条目绑定，`sudo -e`类编辑路径单独授权。用追加危险参数、参数重排、符号链接替换程序、环境注入、合法重启命令和显式编辑场景验证只有声明参数组合可通过。
