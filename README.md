# macroexp — 文本宏展开器

支持参数、嵌套调用与局部变量卫生改名的文本宏展开器。每个输出 token
携带定义位置、调用位置与完整展开链；实参只展开一次；遇到递归环或
预算耗尽时保留最短调用证据。

## 语法

```
#define name(p1, p2) locals(l1, l2) 函数体... #end   // 函数式宏
#define NAME 替换文本... #end                        // 对象式宏
```

- `= ` 可写在头部与宏体之间作为分隔（可选）。
- `locals(...)` 声明宏的局部变量；每次展开时它们被改名为
  `名字__N`（N 为全局唯一的展开序号），不会捕获实参中的同名自由变量。
- 调用：`NAME`（对象式）或 `name(arg1, arg2)`（函数式）。
  实参可为空：`f(, x)`、`f()` 均合法；`f()` 对零参宏视为零个实参。
- 函数式宏后面没有 `(` 时按普通标识符处理。

## 语义

- **实参只展开一次**：每个实参在调用处上下文中完全展开一次并封存，
  形参的每次引用共享同一份展开结果（`Result.Counts` 可观察展开次数）。
- **嵌套调用**：宏体替换后递归展开；实参中的嵌套调用（如 `d(d(1))`）
  不是递归，正常展开。
- **递归环**：展开栈上出现同名宏即停止，保留该调用不展开，并报告
  诊断；诊断的 `Chain` 是首次重入时的展开链——即最短调用证据。
- **预算**：`Expand` 的 `maxSteps` 限制总展开次数；首次耗尽时报告一次
  诊断（链最短），其余宏调用原样保留。
- **实参内部错误**：实参展开期间的诊断（如参数个数不匹配）定位到
  实参文本在调用处的位置，链上带有 `InArg` 帧指向外层调用。

## Token 溯源

```go
type Token struct {
    Pos     Pos     // 该次出现的物理位置
    DefPos  Pos     // token 文本的定义位置（宏体或源文件）
    CallPos Pos     // 把它带入输出的宏调用位置（源 token 为零值）
    Chain   []Frame // 完整展开链，最外层在前；源 token 为 nil
}
type Frame struct {
    Macro   string
    DefPos  Pos  // 宏定义位置
    CallPos Pos  // 宏调用位置
    InArg   bool // 该层展开发生在某调用的实参中
}
```
