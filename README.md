双控制器共享的卷要在见证节点日志不完整时接管。请交付可导入的 Go 包，让设备驱动提交一批日志和本地读数，只在所有与日志相容的时钟下旧主都已失去写权时解锁。每台设备在整段记录里使用同一个仿射钟 C(t)=a*t+b，正斜率和偏移各在给定有理闭区间内；同一条探测消息在两端均有本地戳，其真实单向时延在给定闭区间。旧主获得的每张见证票有本地生效、到期戳，左闭右开；任一指定仲裁组内同时有效的不同见证达阈值即可写，同一见证多票不重复计数。输入指定新主设备和整数读数窗 [L,U]，找窗内最小整数 n，使新主读数从 n 到 U（含其间所有实数）都不可能出现旧写权，不是仅在 n 取样。若连 U 都不安全，返回一套相容时钟及实际有效的仲裁成员；若 n>L，再给出 [n−1,U] 内反驳更早接管的具体有理读数和时钟。区分日志本身矛盾、合法但无解与成功，返回的反例由独立验票路径重算而不是相信规划器布尔值。最多六台钟、十四张票、五组；可以随票数指数增长，但不能逐刻度扫描或用浮点容差代替端点。请配一个驱动拒绝不合格接管的调用例，并测试只在两个整数间短暂达到多数、到期点正好另一票生效、逐对可行但不存在一组共同斜率、巨大整数窗和不同票落在同一见证的情形。
