# clockcal — 多通道时钟校准器

处理带**整数偏移**和**有理漂移率**的多通道时钟校准：校准点以误差区间给出，
求解每个通道可行的校准参数范围；不可行时输出极小不相容校准点集合；
事件对齐后先后顺序仍不确定的，保留偏序，绝不按估计中点强行排序。

## 模型

通道时钟读数 `r` 与参考时间 `t` 的关系：

```
r = ρ·t + β      ρ ∈ ℚ（漂移率），β ∈ ℤ（偏移）
```

校准点 `i`：在参考时刻 `T_i`，读数落在误差区间 `[lo_i, hi_i]`，即约束
`lo_i ≤ ρ·T_i + β ≤ hi_i`。

## 可行性（精确条件）

存在 `ρ` 当且仅当 `max_i (lo_i−β)/T_i ≤ min_j (hi_j−β)/T_j`，等价于所有
点对约束。对 `0 < T_i < T_j`：

```
β ≥ (T_j·lo_i − T_i·hi_j) / (T_j − T_i)
β ≤ (T_j·hi_i − T_i·lo_j) / (T_j − T_i)
```

- `T_i = 0` 的点直接约束 `β ∈ [lo_i, hi_i]`；
- 相同 `T` 的点要求区间相交；
- `β` 取整数：有理下界取 `ceil`、上界取 `floor`，区间为空则不可行。

可行时漂移率范围为 `[L(β_max), U(β_min)]`（`L`、`U` 关于 `β` 单调不增）。
所有运算用 `math/big.Rat` 精确进行，无浮点误差。

## 不相容集合

不可行时用删除法提取**极小不相容子集**（IIS）：反复移除"去掉后仍不可行"
的点，剩下的集合任意去掉一个点都可行，输出其 ID 列表。

## 事件对齐与偏序

事件读数 `r` 映射到参考时间 `t = (r − β)/ρ`。在参数可行域的包围盒四角
求值得到时间窗 `[t_min, t_max]`（保守：只会放宽窗口、丢失序关系，绝不
捏造序关系）。两事件的先后关系：

- **同通道**：映射关于读数严格单调（正漂移），按读数排序；读数相等则不可比；
- **跨通道**：`e ≺ f` 当且仅当 `t_max(e) < t_min(f)`（窗口严格分离）；
- 其余一律保留为**不可比对**，输出在 `incomparable` 中，不按中点排序。

## 输入格式（JSON，数字用字符串以保持精确，支持 `"p/q"`）

```json
{
  "channels": [
    {"name": "A", "points": [{"id": "a0", "ref": "0", "lo": "3", "hi": "7"}]}
  ],
  "events": [{"id": "e1", "channel": "A", "reading": "30"}]
}
```

## 使用

```sh
go run ./cmd/clockcal examples/sample.json   # 或 cat input.json | go run ./cmd/clockcal
go test ./calib/
```

输出报告包含：每通道 `offset_min/max`（整数）、`drift_min/max`（有理数）
或 `incompatible_points`；每事件的对齐时间窗；`precedence`（确定先后）
与 `incomparable`（保留的偏序不确定对）。

## 限制

- 参考时刻须非负；
- 漂移范围非严格正（可能非单调）或参数无界时，事件标记为不可对齐，
  其序关系全部保留为不可比。
