# 协议时序变异约束

安全测试需要扰动消息时间而保持握手前置条件。给Go测试宿主写时间变异包，输入事件偏序与整数时间上下界，选择新的合法时间赋值并返回可复现实验种子；必须能产生同时发生、截止前一刻和截止时刻的边界样本。约束矛盾给出负环证据，用小时间域枚举核对覆盖与合法性，不实际发送网络流量。

## 实现

包 `netsec` 是纯离线的时间变异器，只处理整数时间戳，不导入任何 `net`
包、不发送流量。

- `NewProblem` 输入事件名、整数上下界（闭区间）与偏序（`WeakOrder` 表示
  `<=`，`StrictOrder` 表示整数域上的 `<`）。
- 所有约束统一降为差分约束 `t[v]-t[u] <= w`。`Solve` 用 Bellman-Ford
  判可行；矛盾时返回 `*CycleError`，`Explain` 给出可读的负环证据（环上
  权重和严格为负）。
- 可行实例通过全源最短路得到每个事件的紧致整数窗口，以及最早/最晚合法
  赋值。
- `Random(seed)` 用 `math/rand/v2` 的 PCG 生成器，先在紧致窗口内拒绝采样，
  高耦合时回退到拓扑构造，保证每次结果合法且同种子可复现。`Generate`
  批量产出去重赋值。
- `BoundarySamples` 确定性地给出三类边界：`Simultaneous`（至少两事件同
  时刻）、`BeforeDeadline`（某事件取 `Deadline-1`）、`AtDeadline`
  （某事件取 `Deadline`）。结构上不可能的边界对应字段为 `nil`。
- `Enumerate` 在小时间域上回溯枚举全部合法赋值；`CheckCoverage` 用枚举
  结果核对采样的合法性与覆盖率。

## 验证

`go test ./...` 覆盖求解、负环证据、种子可复现、三类边界、枚举全覆盖与
无网络导入的静态检查。
