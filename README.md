同一可执行文件有两个硬链接，路径策略不同，签名验证期间文件还可能被改写。给 Go 加载器写一个可导入的完整性准入包。调用方提供对象 ID、不可回绕的内容代次、字节读取器和原子 Pin(id, generation) 回调。加载只消费 Pin 返回的不可变句柄。签名消息按顺序拼接 ASCII IMA1、16 字节对象 ID、8 字节大端代次和文件内容的 SHA-256，以策略信任的 Ed25519 公钥验证。路径按分量最长前缀匹配，规则为拒绝、要求签名或只核验登记摘要，无匹配即拒绝。策略整批替换并递增代次，可吊销密钥。并发读取可共享同一对象代次的内容哈希，但不得共享不同路径或策略代次的放行决定。返回前须在同一策略代次内完成最终准入，文件改写、密钥撤销或 Pin 失败均不得发出句柄。用可控屏障和真实签名验证弱策略路径先命中缓存、哈希后改写、验签后撤销及并发等待读取者单独取消；校验最终返回的句柄内容和读取次数。
