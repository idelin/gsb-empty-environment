Go 名称解析宿主会缓存“名称不存在”的答复。写一个可导入的验证包，输入从根到子区的授权链、每个区的签名版本和查询标签。名称按原始小写 ASCII 标签分量比较，不能按字符串后缀授予区控制权。一个区快照分别承诺精确名称和子区委派两个有序集合；缺名必须同时提供由区签名绑定的相邻边界，证明没有精确名称，且从候选最长祖先逐级核对没有更具体委派，不能用父区负答覆盖已授权子区。密钥轮换由旧新阈值各自签名，签署者按公钥去重；从两个版本各取部分签名不得拼出一次轮换。负缓存键绑定实际经过的区版本向量及查询名；只要路径上的委派或区签名版本改变就失效，旁支轮换不应清空无关缓存。以真实 Ed25519 签名、三个嵌套区和前后相邻名称验证错误区签名、漏验更具体委派、轮换前凭据重放与旁支变化，要求检测函数能说明首次失效的区和证明项。
