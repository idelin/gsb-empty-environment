交换机配置控制器要为一条不可排队的数据流选发送相位。第一帧在非负整数时刻 x 发出，之后每隔 P 个时钟节拍发一帧；在第 i 跳占用链路的半开区间为 [x+kP+d_i, x+kP+d_i+t_i)，每一帧 k≥0 都必须完全落在周期门控表的开放部分。各跳的偏移 d_i 已知，开放段可跨零点、相接或重叠，按并集解释。请交付控制器可导入的 Go 包。门周期都是 2 的幂且可达 2^63，P 和占用时长均为正 uint64，不能枚举联合周期或发送相位。给定任意 [L,R]（uint64 闭区间），返回可用整数相位数并支持按递增次序取第 n 个，相位数可能等于 2^64。还要能为被拒绝的相位返回一跳和一个非负帧号，使控制器可直接重放该帧碰到的关闭节拍。门表输入用周期内起点和长度表示，长度允许为零或整个周期。交付逐节拍的小周期独立对照，覆盖超长占用但门永久开放、多个周期后首次碰到闭门、跨零点可通行，以及相位区间位于 uint64 末端。
