# 四维时空反向索引与历史相交证明器

回答“实体 A 与实体 B 是否在历史某个时空相遇过”的追溯引擎。
基于**时间切片倒排网格表**快速检索两实体在任意时刻空间距离小于给定阈值的
相遇接触记录,输出全部相交时段与**不可抵赖的地点证书**。

## 架构

```
spacetime/
  types.go      4D 采样点 (x,y,z,t)、轨迹线性插值、轨迹 SHA-256 内容寻址
  index.go      时间切片倒排网格索引:(时间切片, 网格单元) -> [线段...]
  intersect.go  精确求交:相对运动 |d(u)|² 为二次函数,解析求根得精确时段
  place.go      柜台级三维地理围栏,坐标 -> 语义地点
  cert.go       地点证书链:轨迹哈希绑定 + PrevHash 哈希链 + Ed25519 签名
cmd/epidemo/    疾控流调演示(两名确诊者商场轨迹)
```

- **索引**:每条轨迹线段按时间跨度落入的每个时间切片、空间包围盒覆盖的
  每个网格单元登记进倒排表。查询时仅将 A 的线段包围盒外扩阈值 r 收集 B 的
  候选线段对,避免 O(N·M) 全量比较。
- **精确求交**:两实体在相邻采样点间匀速运动,相对距离平方是关于归一化
  时间 u 的二次函数,解析求根得到进入/离开阈值的精确时刻(非步进采样)。
- **不可抵赖**:每份证书绑定双方轨迹的 SHA-256;证书经 PrevHash 串联成
  哈希链;证明方以 Ed25519 私钥签名,任何人可用公钥离线验证。
