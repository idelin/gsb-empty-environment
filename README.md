固态盘页级闪存转换层（FTL）把逻辑页号（LBA）动态映射到物理擦除块内的顺序可写页（PPA），在引入 `TRIM/Deallocate`、后台垃圾回收（GC）与异常掉电恢复后存在三类极易出错的不变式：1）物理页只能从块内页 0 到页 `P-1` 严格顺序编程，覆写必须异地追加并把旧 PPA 标为无效，擦除只能以整块为单位且递增该块擦除计数（Erase Count）；2）`TRIM(lbaStart, count)` 必须立刻解除映射使旧物理页失效且后续读取返回确定性全零，同时必须在掉电日志中持久化 `TRIM` 记录——否则掉电后从物理页 OOB（Out-of-Band）反向元数据扫描恢复时，旧物理页里残留的旧 LBA 会被误当有效数据“僵尸复活”！3）GC 在空闲块触及预留水位（Over-Provisioning）时触发，必须兼顾写放大与磨损均衡（热块与冷块擦除次数差超出阈值时主动搬迁静态冷块！），且如果在 GC 搬迁中途发生掉电，同一 LBA 可能同时在源块和目标块各存在一个带不同写入序列号 `seq` 的完整物理页，恢复必须严格按单调 `seq` 保留最新版本且绝不丢失正在搬迁的数据！为存储仿真与块设备固件层交付可导入的 Go 页级 FTL 与掉电恢复包。规则：1）强制闪存硬件约束（禁止非顺序页写、禁止未擦除覆写、支持注入页编程撕裂坏校验页）；2）完整实现 `Read`/`Write`/`Trim`/`Checkpoint` 与受磨损差阈值约束的贪心+冷数据迁移 GC（保留预留块确保 GC 永不死锁！）；3）掉电重启仅读取最后完整检查点映射表，并按 `seq` 升序扫描全部物理块 OOB 元数据与持久化 `TRIM` 日志记录（丢弃校验损坏的半写页！），精确重建与掉电前最后一次已确认操作完全一致的 L2P 映射表、每块有效页位图与空闲写指针。验收覆盖 `TRIM` 后掉电防僵尸复活、GC 搬迁中途掉电不丢页不回退、热冷负载磨损差均衡收敛、撕裂半写页精确丢弃及物理页状态守恒校验。
