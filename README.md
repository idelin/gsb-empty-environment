# expsched：带冷却与互斥约束的实验选择求解器

## 模型假设

- 每个候选实验占据一个整数时隙 `[Slot, Slot+1)`，收益可以为负。
- 同一设备上两次实验之间至少冷却 `Cooldown` 个完整时隙：
  时隙 `t` 的实验之后，同设备下一次实验时隙须满足 `t' >= t + 1 + Cooldown`。
- `Group != 0` 的实验属于互斥组，同组至多选一个；`Group == 0` 无互斥约束。

## 第一部分：单阶段子集选择（`solver.go`）

`Solve` 在至多 20 个候选中（`2^20` 子集穷举）选收益最大的合法子集；
并列时先选实验数更少者，再按排序后 id 列表的字典序更小者。
合法性用**时间回放**（`replay.go`，沿时间轴维护冷却计数）核对，
与逐对间隔检查（`experiment.go`）在随机实例上交叉验证一致。

## 第二部分：两阶段带观测策略树（`policy.go` / `verify.go`）

- 阶段一在观测前选择一批实验执行；执行后观测到它们在当前情景下的
  实际收益，据此把情景划分为可区分的**观测组**。
- 阶段二只能依据观测组（而非具体情景）选择剩余实验——不能预知未来。
- 冷却与互斥约束跨阶段延续，同一实验不能执行两次。
- 目标：最大化最坏情景总收益（至多 6 情景、10 候选）。
  并列时先选总实验数更少者，再按全部选中实验 id 列表字典序。

`SolveTwoStage` 枚举阶段一子集，按观测键划分情景，对每个观测组独立
枚举最优阶段二子集。`VerifyPolicy` 对每条情景路径逐路径回放：
检查分支存在（不依赖未观测信息）、跨阶段约束合法、观测相同的情景
决策一致，并核对回放最坏收益与声明值一致。

## 测试

```sh
GO111MODULE=on go test ./...
```

包含：手工用例（负收益、冷却、互斥、两级并列打破）、
单阶段求解器 vs 递归预言机的随机交叉核对、两种合法性检查的随机一致性、
两阶段适应性优于静态的示例、作弊策略（缺分支 / 跨阶段违例 / 虚报值）
的拒绝，以及两阶段求解器 vs 决策表预言机（显式过滤预知未来的表）
在随机小规模实例上的最坏收益一致性。
