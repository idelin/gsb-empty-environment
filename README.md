# readproof

`readproof` 是可导入的 Go 读取证明验证包（仅依赖标准库），位于
`readproof/`，模块路径 `formal.local/w28-9bb8fbbfd0/readproof/readproof`。

## 提交结构

- 块大小固定为 `BlockSize = 4096`，最后一块可以更短。
- 叶子哈希 `LeafHash(index, data)` 绑定域标记、块索引、有效长度和块字节。
- 内部哈希绑定域标记、半开区间 `[start,end)` 以及左右子哈希。
- 非二次幂区域在 `splitPoint`（严格小于区域长度的最大二次幂）处切分，
  左子树恒为完全二叉树。
- 空文件使用独立承诺 `EmptyRoot`，不进入常规树结构。
- 所有哈希为 SHA-256，变长字段带长度前缀，杜绝编码歧义。

## 签名清单

`Manifest` 绑定文件身份 `FileID`、字节长度 `Length`、单调 `Version`、
`PreviousRoot` 与当前 `Root`，并通过 `Signer`/`Verifier`（内置 Ed25519
适配器）对规范化编码签名。

## 合并读取证明

`Proof` 一次覆盖多个可能非连续的 `Range`：

- `Leaves`：请求块各一次，携带字节与重新计算并校验的叶子哈希；
- `Nodes`：认证所需的兄弟子树承诺，每个恰好一次。

`Verify` 严格拒绝额外区间、重复叶子/兄弟、错误有效长度、错误区间、
签名失败以及任何不等于清单根的重算根。因此旧根下正确的兄弟无法用于
新句柄。

## 归档、句柄与缓存

- `Archive` 同时保留每个已发布版本，旧 `Handle` 在新版本发布后仍读旧内容。
- `MemoryNodeCache` 以根为键、带版本标记，并发安全；不同代的兄弟互不
  可见，错代缓存条目在查找时即被拒绝。
- `MergeRanges`/`Handle.Read` 会把相交或相邻区间合并去重为单个证明。

## 增量更新

`UpdateProof(previous, next, verifier, oldProof, changed, ranges)` 输入旧
证明、变化叶子和新签名清单：

- 先验证旧证明并校验清单链（身份、版本号、前版根）；
- 仅当子树区间在两代结构中一致、不含变化叶子、且不含任一尾块时才直接
  复用旧承诺，保证索引、区间和有效长度均可证明未变；
- 其余子树用显式变化叶子与已认证旧叶子重建；
- 被截短删除的块在重新扩展时必须作为变化叶子重新提供，旧尾块无法复活；
- 组装后对新清单自检，失败即返回错误。

## 独立参考与测试

`BuildTree` 是独立的全量建树参考实现。测试用同一文件身份的四个连续版本
（建版 → 同长度改叶 → 截短 → 重新扩展）覆盖：

- 旧句柄持续读出旧内容；
- 错代缓存拒绝与跨代兄弟嫁接失败；
- 末块有效长度变化；
- 相交读取请求的证明去重；
- 增量证明与全量参考逐节点一致；
- 截短尾块不能复活、空文件生命周期与坏链拒绝。
