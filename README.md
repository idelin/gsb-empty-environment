# 组播源过滤越权防护

虚拟交换机合并多个监听者的组播源过滤时，错误处理排除集合可能向隔离端口泄漏流量。写供Go数据面调用的成员状态包，成员绑定可信租户与端口实例；源集合用IPv4或IPv6前缀表示，禁止展开为单地址；同组每个成员分别给包含或排除源集合，最终允许源为各成员许可集合的并集，查询返回精确且不相交的前缀覆盖，成员模式切换原子发布，离开只撤销本成员贡献，租约到期同理。用小源地址全集对照混合包含排除、端口复用与迟到续期，输出每个放行源的授权成员证据。

## memberstate 包

实现位于 `memberstate/`，仅依赖标准库（`net/netip`、`sync/atomic`）。

### 安全语义
- 成员身份绑定 `TenantID`（可信租户）+ `PortID`（端口实例）+ `GroupKey`（VLAN + 组播组）。
- 每个成员独立声明 `Include`/`Exclude` 源前缀集合；组放行集合严格等于各成员许可集合的并集：
  - `Include`：许可集合即包含前缀；
  - `Exclude`：许可集合为全集对排除前缀的补集；排除集合不会跨成员合并，杜绝向隔离端口泄漏。
- 成员未声明某地址族时在该族没有任何许可，避免把单族成员误当另一族的通配授权。
- 源集合全程以 CIDR 前缀表达：内部是二进制基数 trie 的集合代数（并/交/差/补），不展开单地址；
  查询输出经 `compact` 折叠为最小、精确、互不相交的前缀覆盖。

### 并发与生命周期
- 写时复制快照 + `atomic.Pointer` 发布：`Join` 的模式切换对读侧原子可见，读路径无锁。
- `LeaseToken` 带代次（generation）：离开、到期、端口复用后重新加入都会作废旧令牌，
  迟到续期/迟到离开返回 `ErrUnknownLease`，不会重新授权已撤销端口。
- 租约到期在写路径与读路径都会惰性清理；`Sweep` 供控制面主动维护。
- 离开与到期只移除该成员自身的贡献，不影响同组其他成员。

### 查询证据
`AllowedSources(group, family)` 返回 `[]AllowedPrefix`，每块放行前缀附带 `Authorizers`：
- INCLUDE 成员给出相交的 `IncludePrefixes`；
- EXCLUDE 成员给出其 `ExcludePrefixes`（与放行块不相交，可复核“源不在排除集合内”）。

### 测试
- 小全集（IPv4 /28、IPv6 /124）逐地址参考模型对照混合 INCLUDE/EXCLUDE 的并集与授权证据；
- 覆盖端口复用、迟到续期、离开只撤销自身贡献、原子模式切换、非法输入与 `-race` 并发读写。
- 逐地址枚举只存在于测试参考模型中，生产代码不做地址展开。
