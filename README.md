# 规则覆盖分析器（rule-coverage-analyzer）

按顺序匹配的有序规则集覆盖分析：规则条件由**有限整数区间**（端点可开可闭）与**枚举集合**合取而成，首个命中的规则决定动作。分析完全基于盒（box）代数的**精确符号运算**，不做任何抽样推断。

## 能力

- **完全不可达规则**：区域被更靠前的规则全覆盖，给出被抢走的最小见证点。
- **部分遮蔽范围**：给出遮蔽来源规则、被遮蔽侧与存活侧各自的最小见证点。
- **未覆盖输入**：给出精确区域、精确个数与最小反例。
- **空规则**：空区间（如 `[5,5)`、`[7,3]`）或空枚举集合直接标为 `empty`。
- **最小反例**：按属性声明顺序字典序最小（整数取下界、枚举取声明序首个值）。
- **增量更新**：`addRule` / `removeRule` 后仅重算受影响后缀（缓存每条规则之前的已覆盖区域），追加为 O(1) 扩展；全程符号运算，结果与批量重算逐项一致（测试保证）。

## 运行

需要 Node ≥ 22.6（内置 TypeScript 类型擦除；≥23.6 免标志）：

```sh
node tests/run.ts   # 测试：小域穷举对拍
node src/demo.ts    # 演示报告
```

## 结构

- `src/model.ts` — 域 / 条件 / 规则类型；整数域边界显式有限（`min`/`max` 闭区间）。
- `src/region.ts` — 盒代数：交、差（逐维分裂）、测度、包含判定、最小见证点。
- `src/analyzer.ts` — `Analyzer`：顺序首匹配语义、增量后缀重算、报告生成。
- `src/exhaustive.ts` — 小域穷举：枚举全部输入暴力首匹配，与符号分析逐项对拍。
- `tests/run.ts` — 互斥条件、空区间、相邻半开端点（无缝拼接 / 缝隙反例 / 端点重叠）、完全与部分遮蔽、增删增量一致性、300 组随机小域对拍。

## 方法说明

每条规则的区域表示为各属性维度约束的笛卡尔积（盒）。按顺序维护“已覆盖”盒并集：
规则 `i` 的存活区域 = 规则盒 − 已覆盖；已覆盖区域按构造互不相交。
遮蔽区域 = 规则盒 ∩ 各更早规则的首次命中区域。未覆盖 = 全域 − 已覆盖。
所有计数均为盒测度精确求和，穷举对拍仅用于验证，不参与推断。
