# 字典序约束传播器（lexprop）

纯 Python 3.11 标准库实现的字典序约束传播器：对两个变量向量施加严格
（`<lex`）或非严格（`<=lex`）字典序，做真正的域过滤（GAC），不调用任何
SAT/SMT 库。

## 语义规则（长度规则对所有情形一致）

比较前 `min(n, m)` 个位置：

- 若某位置首先不同，则该位大小决定结果（前位已小，后位不再受任何约束）；
- 若重合部分全部相等，则短者为小：
  - 非严格：左向量是右向量的前缀即可（`n <= m`）；
  - 严格：左向量必须是右向量的**真**前缀（`n < m`）。

推论：

- 相同向量只满足非严格（`X <lex X` 恒矛盾）；
- 空向量：`[] <=lex Y` 恒成立；`[] <lex Y` 当且仅当 `Y` 非空；`[] <lex []` 矛盾；
- 共享变量（同一变量出现在两侧或同侧多处）被联合处理：前缀等式把变量并入
  等价类，类内域取交集，首差位置两侧若同类则该情形不可行。

## 传播器（lexprop.py）

- **过滤而非界限比较**：对每个 `(变量, 值)` 做支持检查——固定该值后，
  用"首差位置 / 全等前缀"情形分析在多项式时间内判定原约束可行性，
  不可行则删值，迭代至固定点，达到 GAC。
- **删除证明**：每个被删值附带 `Explanation`，逐情形说明原约束为何不可满足
  （前缀等价类交集为空 / 首差位无法严格小于 / 长度规则不成立）。
- **前缀支持缓存**：前缀等式诱导的变量等价类按前缀长度缓存；
  `push()`/`pop()` 保存并恢复域、缓存与删除日志。
- **预算**：`propagate(budget=k)` 限制支持检查次数；预算耗尽时返回
  `fixpoint=False` 并明确说明"尚未达到传播固定点"。
- **矛盾**：约束不可满足时抛出 `Contradiction`，携带逐情形的失败证明。

## 独立检验器（checker.py）

不复用传播器任何逻辑，全赋值枚举：

- `evaluate`：按语义规则直接判定完整赋值；
- `find_witness`：传播器声称有解时，独立找出并验证一个满足原约束的赋值；
- `verify_pruned_domains`：验证保留域**恰好**包含所有支持值。

## 运行

```sh
python3.11 -m unittest -v   # 测试
python3.11 demo.py          # 样例
```

## 文件

- `lexprop.py` — 变量、约束、传播器（证明、缓存、push/pop、预算）
- `checker.py` — 独立全赋值枚举检验器
- `test_lexprop.py` — unittest 测试套件
- `demo.py` — 运行样例
