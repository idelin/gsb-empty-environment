# FlexRay静态时隙所有权

FlexRay 静态段按时隙分配发送权，被攻陷的节点可在别人的时隙发帧，或在同步帧上作假。为C++网关写可导入的时隙所有权包，供总线监视回调调用：调用方给出静态时隙表（时隙号对应所属节点、cycle repetition 与 base cycle），并为每帧附上其判定的发送端口；帧头含帧 ID（11 位）、payload length、cycle count（6 位）与同步指示位；仅当当前周期 c 满足 c mod repetition = base、帧 ID 等于时隙号、发送者是该时隙所有者时才放行；同一周期同一时隙收到两帧视为冲突，两帧都丢弃并计入该时隙对应节点；非所有者发送的帧计一次违规，同一节点累计 3 次违规后隔离其后续全部帧；带同步指示位的帧只能出自登记的同步节点，且 cycle count 必须等于全局周期计数。用借用他人时隙、repetition 错相位、同时隙双帧、非同步节点置同步位和隔离阈值验证。
