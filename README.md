# ssp — 负权图多源最短路工具

对有向加权图（允许**负边权、平行边、自环、负环**）从**多个源点**计算最短路。
对每个 (源点, 目标) 对报告三种结果之一：

- **finite**：有限最短距离，并输出一条最短路径；
- **unreachable**：源点不可达目标；
- **negative-infinity**：目标受负环影响（距离无下界），并输出**证据**。

## 负环语义（不污染）

目标 `t` 被判为 `-inf` 当且仅当存在一个负环 **同时**满足：

1. 从源点 `s` 可达该环；
2. 该环能到达 `t`。

全图其它位置的负环（不可达、或到不了 `t`）**不会**污染结果。
证据包含三部分：一个**简单负环**（顶点不重复、总权 < 0）、
源点到环的连接路径、环到目标的连接路径。

## 算法

- **有限步动态规划（Bellman-Ford）**：`n` 轮松弛。`n-1` 轮后未受负环
  影响的顶点距离已收敛；第 `n` 轮仍可松弛的顶点位于可达负环上或其下游，
  沿正向边 BFS 标记所有 `-inf` 顶点。
- **环提取**：从第 `n` 轮被松弛且能到达 `t` 的顶点出发，沿前驱指针走 `n`
  步必进入负环，再继续走到顶点重复即得简单环；用松弛时记录的边索引
  （`PredEdge`）精确还原平行边情形下的环边。
- **交叉核对**（`verify.go`，测试与 `-verify` 标志使用）：
  - 枚举全部**简单环**（DFS，指数级，仅用于小图核对），独立推导每个
    目标的应有状态——零环（总权 = 0）严格不算负环；
  - 独立的 k 步 DP（`dp[v]` = 至多 k 条边的最小权）复核有限距离。

## 使用

```sh
go build ./cmd/ssp
./ssp -graph examples/graph1.json            # 文本输出
./ssp -graph examples/graph1.json -format json
./ssp -sources s,x -targets t,y < graph.json # 标志覆盖 JSON 中的源/目标
./ssp -graph g.json -verify                  # 同时跑暴力枚举核对，不一致则退出码 1
```

输入 JSON：

```json
{
  "edges":   [{"from": "a", "to": "b", "weight": 2.5}],
  "sources": ["s"],
  "targets": ["t"]          // 可选，缺省为全部顶点
}
```
