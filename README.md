多子图 GraphQL 联邦网关在受理客户端复杂查询时，若仅按语法树深度限流而忽略别名（Alias）指数放大、嵌套片段（Fragment）展开或跨子图 `@requires`/`@key` 实体解析中的权限丢失，攻击者既可用几十字节查询打满后端计算资源，也能借联邦实体回查绕过源子图的字段级访问控制。为 TypeScript API 网关实现可导入、零第三方 GraphQL 依赖的查询解析、静态最坏代价计算与联邦字段授权隔离组件。组件从零解析 GraphQL 查询文档（支持操作选择、变量绑定、内联片段与具名片段、别名、指令 `@skip`/`@include`），严格检测并拒绝片段环引用、未定义片段及未知类型条件；在将片段展开为规范执行计划时，精确计算组合最坏复杂度与估计返回节点总数——按 Schema 声明的列表分页参数上限（含变量注入与默认值）、字段基础权重、跨 Union/Interface 多态分支取最大值以及同层别名累加进行指数防溢出结算，超过深度、别名总数或总代价预算即在执行前静态拦截。在授权隔离层，针对每个子图字段、接口实现与联邦实体回查键（`@key`/`@requires`）强制核对调用主体声明集：当子图 B 依赖子图 A 的受限字段作为 `@requires` 输入时，禁止将未对调用者开放的敏感依赖字段通过错误消息、部分响应或别名重命名回泄，且在接口/联合类型展开时对未授权具体类型分支实施零存在性泄漏裁剪。附对比基准测试验证别名炸弹、循环片段、多态分支代价低估与跨子图 `@requires` 越权泄漏全拦截。
