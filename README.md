# XPC对端审计令牌绑定

iOS 守护进程用 XPC 接收应用请求，若按对端 pid 校验代码签名，攻击者可在检查后 exec 另一个二进制，或在 pid 被复用后借用已通过的检查调用特权方法。为 Go 编写的权限代理写供连接建立和每条消息处理调用的对端校验包：输入连接的审计令牌（pid、pidversion、euid）、代码要求判定结果（团队 ID、签名标识、是否平台二进制）、exec 与退出事件、方法调用所需的授权键；放行结果绑定整个审计令牌而不是 pid，exec 或退出后旧令牌立即作废，pidversion 变化须重新判定；令牌缺字段按拒绝；授权键在每条消息按当前令牌查询，不用连接建立时缓存；团队 ID、签名标识与平台二进制标志须同时匹配登记项；同一 pid 的新连接不得继承旧判定。用检查后 exec、pid 复用、仅同团队不同标识、令牌作废与合法调用验证。
