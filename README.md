# anchored-virtual-list

可变行高列表的锚定滚动核心。纯 TypeScript、零依赖，核心计算（前缀高度索引、锚点换算、
行高测量）均为纯算术，不借浏览器布局引擎；节点树与字形度量由夹具给出（见 `examples/fixtures.ts`）。

要求 Node.js ≥ 22.6（原生类型擦除，直接运行 `.ts`，无需编译）。

## 能力

- 可变行高：估计行高 + 异步实测修正，实测到达时同步调整布局与滚动位置
- 锚定滚动：锚点以「稳定条目 ID + 条目内部偏移」表示；上方插入/删除/测量修正时保持锚点视觉位置
- 反向滚动与跳转：`onScroll` 支持正反向，`jumpTo(id)` / `jumpToOffset(y)` 跳转
- 版本化前缀高度索引：Fenwick 树增量维护（`src/height-index.ts`），每次修改 `version` 递增
- 折叠分组：组内条目有效高度变为 0（零高行），展开后恢复
- 独立全量布局对照：`NaiveIndex` 每次查询从头累加，随机操作测试逐步比对滚动位置与可见集

## 公开后备规则

1. **上方变化同步滚动**：锚点之前的高度增减多少，`scrollTop` 同步增减多少
   （锚前新增 100px → `scrollTop += 100`）。
2. **锚点被删**：锚点落到原位置的**后继**条目（offset 归零）；无后继 → 前驱；列表为空 → 锚点清空。
3. **迟到旧测量**：测量令牌携带条目测量纪元；条目已删除或令牌签发后条目被重排 →
   `applyMeasure` 忽略并返回 `false`。折叠期间到达的有效测量记录高度，展开后生效。
4. **零高行**：按偏移查找（Fenwick 下降）天然跳过零高行，查找与可见集遍历必然终止，不会死循环。
5. **未滚动前**：锚点为 `null`，列表保持顶部对齐。

## 结构

- `src/height-index.ts` — `PrefixIndex` 接口；`FenwickIndex`（增量）与 `NaiveIndex`（全量对照）
- `src/list-model.ts` — 条目/分组/测量令牌模型（`ListModel`）
- `src/scroller.ts` — 锚定滚动控制器（`VirtualList`）
- `test/` — Node 内置测试器：索引等价性、锚点规则、随机操作对照
- `examples/` — 可运行样例与节点树/字形度量夹具

## 运行

```sh
npm test     # node --test "test/*.test.ts"
npm run demo # node examples/demo.ts
```
