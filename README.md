# rollback-sam

可回滚的字节串后缀索引（后缀自动机 SAM），Go 实现。

## 功能

- `Append` / `AppendString`：末尾追加字节。
- `Version` / `Rollback(v)` / `Pop`：撤销到任意历史版本或逐字节撤销。
- `Occurrences(pat)` / `Count(pat)` / `Contains(pat)`：查询模式的全部出现位置。
- `DistinctSubstrings()`：不同非空子串总数。

## 空模式约定

- 空模式视为在位置 `0..n` 均出现（共 `n+1` 次），`Occurrences("")` 返回 `[0 1 ... n]`。
- `DistinctSubstrings` 永远不计入空串。

## 回滚正确性

每次 `Append` 前压入快照（状态数、`last`、不同子串计数、文本长度、日志长度），
扩展过程中对**已有状态**的每次修改都记录 undo 日志：

- 新增转移 → 回滚时 `delete`；
- 覆盖转移（克隆重定向）→ 回滚时恢复旧目标；
- 修改后缀链接 → 回滚时恢复旧链接。

回滚时逆序撤销日志并截断状态数组，因此不会残留指向已删除状态的转移，
不同子串计数也精确恢复（克隆操作对总计数的净贡献为 0，只有 `cur` 状态改变计数）。

## 持久内存占用

- 状态数 ≤ `2n-1`，转移数 ≤ `3n-4`（n 为文本长度），即 `O(n)`。
- undo 日志只记录真实发生的修改，均摊 `O(1)` 条/次追加，总量 `O(n)`。
- 快照每条 `O(1)`，每个存活字节一条，共 `O(n)`。
- 回滚后逻辑空间被截断，但 Go 切片容量保留以便复用；被截断状态的
  转移 map 成为不可达对象由 GC 回收。因此常驻内存上界为历史最大文本
  长度对应的 `O(n_max)`，而非当前长度。

## 测试

```
GOCACHE=/private/tmp/gocache go test ./...
```

测试以暴力枚举全部子串为参考：覆盖重复字符（`aaaaaa`）、交替串
（`abababab`）、周期串、克隆密集串（`mississippi`、`abacabadabacaba`）、
长度 ≤ 8 的全部二进制串，以及"撤销后换另一后缀"的回滚场景。
