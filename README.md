移动应用的一批原生桥调用可以把前一项返回的句柄作为后一项参数，回调还会异步返回。为 TypeScript 宿主写可导入的批处理调度包。调用、回调、资源句柄和撤销各用独立的命名空间与代次；资源只可按注册表规定借用、移交或共享只读。先对整批 DAG 做能力检查，禁止一条分支移交后另一条分支继续借用，互斥条件下的两个移交则可以合法。条件由入参中有限个已验证标志决定，禁止逐项检查时各自假设有利取值。回调持有的借用直到结案才释放，异步失败和取消都只释放一次；若原生副作用已执行但响应丢失，只有收到签名的幂等回执才可确认结果，不盲目重调。输出拒绝原因及冲突的最小调用集合；通过后，执行器只消费与批次哈希及能力代次匹配的计划。用模拟原生服务枚举小批的合法顺序，测试重入回调、句柄编号复用、两互斥分支、撤销与迟到响应和分支条件改变后旧计划被拒。
