# 多轨混音使用不同长度的房间脉冲响应，直接卷积延迟过大

多轨混音使用不同长度的房间脉冲响应，直接卷积延迟过大。给Go实时音频宿主实现分区卷积包，统一分块FFT与overlap-add，脉冲响应可在块边界更新，更新期间两套滤波结果按指定样本数交叉淡化；旧尾响保留到明确结束，不得突然清空。多声道矩阵卷积允许输入输出通道数不同。用小信号直接时域卷积核对每一输出样本、尾部长度及更新中连续性，未满块输入不得提前丢弃。

## 设计

- **统一分区卷积**：IR 按固定块长 `blockSize` 切分，所有分区共用单一 FFT 尺寸
  `nextPow2(2*blockSize)`，频域延迟线（FDL）+ overlap-add 重建，延迟仅为一个块。
- **流式接口**：`Process` 接受任意长度输入（不足一块会缓冲，绝不丢弃），输出按块粒度
  与输入样本对齐；`Flush` 在流结束时补齐未满块并输出完整尾响，总输出长度恰为
  `len(input) + len(IR) - 1`。
- **IR 热更新**：`SetIR(ir, fadeSamples)` 在下一个块边界生效。新旧两套滤波器共享输入
  历史（FDL），新层的 overlap-add 尾缓冲通过重放最近帧精确重建，因此切换后与直接卷积
  逐样本一致。淡化期间输出为 `(1-g)·旧 + g·新`，g 在 `fadeSamples` 个样本内从 0 线性
  升到 1；旧尾响一直保留到淡化明确结束，只有显式调用 `Reset` 才会清空状态。
- **矩阵卷积**：`Matrix` 为 `numOut × numIn` 的卷积器网格，输入输出声道数可不同，
  每对 (out, in) 有独立 IR，可独立更新；所有对共享块长、块边界对齐。

## 用法

```go
c := taskpkg.NewConvolver(512, ir)      // 单声道
out := c.Process(in)                    // 任意长度输入
c.SetIR(newIR, 4800)                    // 下一块边界切换，100ms@48k 交叉淡化
tail := c.Flush()                       // 流结束：输出完整尾响

m := taskpkg.NewMatrix(2, 4, 512)     // 2 进 4 出矩阵
m.SetIR(0, 1, ir, 4800)                 // 设置 (输出0, 输入1) 对的 IR
outs := m.Process([][]float32{in0, in1})
```

## 测试

`go test ./...` 以小信号直接时域卷积为参考，逐样本核对：完整输出与尾部长度、
未满块输入不丢弃、更新期间两套滤波的精确混合比例与连续性、硬切换边界、
矩阵各输出声道及其尾长。
