统计平台正把一组有状态查询机制开放给外部分析者。分析者能看见每次公开回答再选择下一条查询，某些机制还会沿用上一步的内部随机状态；把各轮上限独立相加无法判断这份配置是否满足承诺。请扩展现有 TypeScript 模块，给发布宿主提供可导入的隐私准入组件，沿用 src/weight.ts 的有理概率字节格式。输入仅为两组相邻数据集上的合成有限状态概率表，没有真实个人记录。每种公开查询把当前隐藏状态按精确概率变成一对公开回答和后继隐藏状态。给定最多8轮、每轮允许的查询、公开历史决定的提前结束规则以及正有理数倍率 L≥1，要计算所有可按公开历史行动的分析者中最坏的双向偏差：对终止转录的两种概率分布 P、Q，偏差为各转录 max(P−LQ,0) 之和，两方向取大。相同观察历史下不能在两份数据上各选不同查询，隐藏状态也不能当作可见信息。返回精确分数和独立可复核的上界证书，不输出针对个人的识别方法。要正确处理某个历史在一侧概率为零、几个隐藏分支发出相同回答、停止本身可见和共用随机状态；不能枚举完整自适应策略树。用小表暴力核对，另给大量重复后验状态的8轮实例检验共享计算。

## 隐私准入组件

`src/admission.ts` 通过子路径 `privacy-admission/admission` 导入，全部计算使用
BigInt 精确有理分数，不做浮点近似。

- `admissionWorstCase(spec)`：在归一化的后验信念状态上做记忆化 Bellman
  动态规划，求所有仅依据公开历史行动的分析者中最坏的双向曲棍球偏差，
  返回精确分数 `direction01`、`direction10`、取大后的 `worstDivergence`
  以及可独立复核的 `certificate`。同一公开历史在两份数据上强制选择同一查询，
  隐藏状态只以条件后验的形式参与，从不可见。
- `verifyCertificate(spec, certificate)`：不依赖求解器内部状态，重新解析
  规格、重建停止自动机、逐条边重算后验概率与 Bellman 不等式，并校验根值、
  可达性和证书无冗余节点；任一不一致即返回 `valid:false` 及原因列表。
- `assessAdmission(spec)`：求解后先独立验证证书，再与可选预算 `delta`
  比较给出准入结论。

### 输入要点

- `rounds` 为 1..8；`tables` 依次是两份相邻数据集的
  `查询 -> 隐藏状态 -> (回答, 后继状态, 概率)` 列表，每个隐藏状态的概率和为
  `1/1`，概率沿用 `src/weight.ts` 的 canonical 字节格式。
- 发出相同回答的多个隐藏后继分支会被精确合并；某回答在一侧概率为零时
  条件后验退化为零分布并按零质量边处理。
- `stopHistories` 是触发提前结束的公开历史（`[查询, 回答]` 序列）列表，
  内部编译成确定的停止自动机；停止本身是可见转录事件，空序列表示立即停止。
- `multiplier` 为 L≥1 的 canonical 分数；所有结果值（允许超过 1）使用
  `n/d` 形式的非负约分有理字节串。

### 方法与证书

求解器不枚举自适应策略树：子问题以 `(轮次, 停止自动机节点, 两侧后验信念)`
为键记忆化，绝对质量只在父节点的线性边组合中出现，因此不同转录到达的
相同后验共享同一节点。证书逐节点给出每个允许查询在合并后的回答边上的
两侧概率、后继键、以及取得最大值的查询；校验器重算全部数值并验证每个
Bellman 等号成立，从而独立确认上界既正确又可达。证书只含聚合概率量，
不含任何针对个人的识别信息。

### 测试

`test/admission.test.mjs` 用独立的暴力策略枚举器对小表逐策略核对，覆盖
单侧零概率、回答分支合并、可见停止与 L>1；另含两个 8 轮实例：单状态重复
后验（仅 8 个记忆节点）与双状态共享随机状态（后验汇合），并用代数独立的
历史递推复核结果。
