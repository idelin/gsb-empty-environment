现代 LSM 引擎允许每一层独立选择分级（Tiered，层内保留多路有序段、写放大低但读放大高）或分层（Leveled，层内合并为单路、读放大低但写放大高），人工拍脑袋调参常顾此失彼。为存储调优引擎交付可导入的 Go 规划包。输入层数 L（1≤L≤8）、各层候选容量扇出比集合 T_i（整数 ≥2）、最大允许点查读放大上界 R_max、最大允许空间放大上界 S_max 及基础单层落盘写放大参数。每层选模式 m_i∈{Tiered, Leveled} 与扇出比 t_i∈T_i：第 i 层若为 Leveled，贡献写放大 t_i、点查读放大 1、空间贡献系数 1/∏_{j>i}t_j；若为 Tiered，贡献写放大 1、点查读放大 t_i、空间贡献系数 t_i/∏_{j>i}t_j（最底层固定计入 1 倍基准空间，且层间模式切换时从 Tiered 进入 Leveled 的合并额外计入一次读出合并代价因子）。在不超过 R_max 和 S_max 约束下，求总写放大最小的精确每层（模式，扇出比）向量，全精度有理数比较，并列按空间放大最小，再按配置向量字典序最小。验收用小规模全枚举对照最优解与三级决胜，覆盖全 Tiered 超读预算迫使底层转 Leveled、空间预算收紧改变扇出比、层间切换额外代价翻转最优策略，以及无可行配置返回明确错误。
