自动化金丝雀发布平台（Kayenta/Flagger 模式）在对比基线（Baseline）与金丝雀（Canary）指标分布时，若直接比均值会被长尾毛刺误导，而直接套用朴素无结（No-Tie）Mann-Whitney U 检验又会在离散错误率或大量重复延迟读数下算错方差 `sigma_U` 导致 p 值严重失真；此外当样本量极大时，哪怕金丝雀延迟仅比基线慢 `0.2%` 也会统计显著，若未叠加效应量门限（Effect Size / 相对退化比例门限）与关键指标一票否决（Critical Veto）及缺数策略，就会频繁误回滚或放行严重错误率回归。为发布控制面交付可导入的 TypeScript 金丝雀统计裁判与多阶段流量推进状态机。组件实现：1）精确双样本 **Mann-Whitney U 检验**：合并基线与金丝雀样本按升序分配平均秩（Mid-Rank），计算 `U_canary`、`U_baseline` 及含结校正项的精确标准差 `sigma_U = sqrt(n1*n2/12 * ((N+1) - sum(t_k^3 - t_k)/(N*(N-1))))`（当所有值完全相同时 `sigma_U == 0` 须按零差异直接判通过，绝不产生 `0/0 = NaN`！），计算双侧与单侧（仅关心变差方向：`failOnHigh` 或 `failOnLow`）z 值与精确正态尾部 p 值，并叠加相对中位数/分位数效应量比率门限（须同时统计显著且退化幅度超过 `minEffectRatio` 才判该指标失败！）；2）处理缺失数据策略（区分 `NODATA_FAIL`、`NODATA_PASS` 与低于 `minSampleSize` 返回 `INCONCLUSIVE` 触发重试而不立即回滚）；3）多指标分组加权聚合（组内等权/加权，组间权重归一，忽略标注为 `NODATA_PASS` 的指标并重新归一化剩余有效权重，但任一 `critical: true` 指标失败或因 `NODATA_FAIL` 失败时无视总分直接一票否决回滚！）；4）驱动多阶段流量递增状态机（如 `5% -> 25% -> 50% -> 100%`，要求每阶段连续 `K` 次通过才晋级，单次明确失败或连续不确定超上限即刻回滚至 `0%`）。验收覆盖含大量相同读数结校正 `sigma_U` 对照精确手算、全相等样本零 NaN、大样本微小 0.2% 差异被效应量门限豁免、`critical` 指标一票否决总分过线、缺数重归一化权重及多阶段连续通过晋级与即刻回滚。
