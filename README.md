固件的非易失存储放不下完整吊销表。为 Go 引导策略宿主写可导入的策略压缩包，必须证明压缩之后不会放回被吊销的启动链。策略条目按签署者永久 ID、组件名的标签前缀、世代号区间和启动位置匹配，可禁止整个范围，或由受信根签出只对一个精确镜像摘要有效的恢复豁免。豁免不能传给依赖它的其他镜像。一次引导输入包含至多8个带签名的组件及其父子加载边，某些条目只在指定父组件范围内生效；不同父链不能凭组件名相同共用豁免。给定已有策略与一组由宿主提供的压缩候选条目，选择编码字节最少的子集，使其对全部可能输入的准入结论与原策略完全一致，并禁止压缩产生新的恢复豁免。至多18个候选，世代号为完整32位，组件标签长度无固定上限，不得按采样世代或限制标签深度验证等价。为选出的子集给出按前缀和区间端点划分的等价类证书，交由另外的验证函数枚举有限类检查；用小配置全枚举覆盖重叠范围、相同组件的两个父加载者、恢复镜像过期和拒绝范围边界。

## 实现（package bootpolicy）

- types.go / evaluate.go：策略条目与引导输入模型，按签署者 ID、标签前缀、完整 32 位世代闭区间、启动位置和精确父作用域匹配；KindDeny 禁止整段范围，KindExempt 仅对受信根签出的精确镜像摘要生效并校验 NotAfter。每个加载事件独立判定，豁免不会传递给依赖镜像；父作用域精确匹配，同名组件的不同父链不共享豁免。
- partition.go / partition_build.go / partition_enum.go：把全部可能加载事件划分为有限等价类。标签轴以前缀 trie 的节点子树与出边残余区域划分；世代轴在所有 GenLo 与 GenHi+1 处切分并始终覆盖 [0, 2^32-1]；时间轴在 NotAfter+1 切分；位置、根、摘要为精确取值类；父轴枚举根加载、各命名作用域与通配父。类内任何条目的匹配结论恒定，逐类枚举是完整证明，不依赖采样世代或标签深度上限；超过单元上限时返回 ErrPartitionTooLarge 而非降级采样。
- compress.go：先拒绝任何不属于原策略的豁免候选（ErrNewExemption），再对至多 18 个候选做带界剪枝的穷举子集搜索，按线编码字节数选出最小等价子集，平局结果确定。
- wire.go / wire_cert.go：大端、长度前缀的确定性二进制包，尾部 SHA-256 校验，内含选中策略与等价类证书。
- verify.go：独立验证函数 VerifyCertificate。验证方不信任证书内的判定掩码，自行用原策略与待装策略重建分区、枚举每个有限类并用真实准入器复算结论，同时检查不存在原策略之外的恢复豁免。
- 测试：小配置全枚举（重叠范围、同一组件两个父加载者、恢复镜像过期、拒绝边界）、8 候选 2^8 暴力最优性对照、18 候选规模压测、随机等价性、证书篡改检测与包往返。
