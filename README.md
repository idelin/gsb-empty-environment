# sqlifinger

WAF按关键词拦截SQL注入，注释、嵌套括号和大小写拼接都能绕过。给Go WAF实现SQL词法指纹组件：按MySQL方言切词，识别各类注释、带转义的字符串、反引号标识符和十六进制字面量，把参数值折叠成词类序列，再与可配置的危险指纹匹配；分别按不在引号内、处在单引号内、处在双引号内三种起始上下文切词。用绕过样本和正常业务参数集测试检出率与误报。

## 用法

```go
d := sqlifinger.DefaultDetector()
if det, ok := d.Detect(paramValue); ok {
    // det.Context 命中上下文，det.Pattern 命中指纹，det.Fingerprint 完整词类序列
    block(paramValue)
}
```

## 原理

1. **切词**（`lexer.go`）：按 MySQL 方言把参数值切成 token。识别 `--`、`#`、`/* */` 注释；
   `/*! ... */` 版本注释的内容会被 MySQL 执行，故递归切词；字符串支持 `\'`、`''` 转义；
   另有反引号标识符、`0x`/`x''`/`b''` 字面量、`@` 变量。
2. **折叠**（`fold.go`）：token 折叠为单字符词类——`1` 数字、`s` 字符串、`v` 标识符、
   `n` 反引号标识符、`k` 关键字、`U` UNION、`&` 逻辑连接（AND/OR/XOR/&&/||）、
   `f` 函数调用、`o` 运算符、`( ) , ;` 标点。大小写拼接、换值、注释填充等绕过手段
   折叠后得到相同序列。
3. **匹配**（`detect.go`）：词类序列与危险指纹做子串匹配，如 `&1o1`（AND/OR 1=1）、
   `&sos`（AND/OR 'a'='a'）、`Uk`（UNION SELECT）、`&f(`（AND SLEEP(）、`;k`（堆叠查询）。
   指纹集可通过 `NewDetector` 整体替换或 `Add` 追加。

检测时对每个参数值分别按不在引号内、单引号内、双引号内三种起始上下文切词，
任一上下文命中即判定为注入。

## 测试

```sh
go test -v ./...
```

测试语料含 33 条绕过样本（注释替换空白、版本注释、嵌套括号、大小写拼接、
十六进制字面量、反引号、`||` 拼接、双引号上下文、堆叠查询等）与 37 条正常业务参数
（姓名、邮箱、日期、URL、JSON、自然语言等），当前检出率 100%、误报率 0%。
