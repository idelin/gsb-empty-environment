# DAG 可达性位图索引器

有向无环图（DAG）全节点可达性查询索引：基于压缩位图维护传递闭包，
任意两点可达性查询为 O(1) 单次位测试，边插入后通过字级位运算并行增量更新下游可达集。

## 设计

- **压缩位图**（`src/compressed-bitmap.ts`）：按 256 bit（8 个 uint32 字）分块，
  只为含 1 的块分配内存。内存占用严格正比于非零块数量，而非节点总数，
  稀疏可达集下远低于 n²/8 的稠密位矩阵。
- **索引**（`src/reachability-index.ts`）：每个节点 u 维护位图 `reach[u]`（含自身）。
  - 查询 `reachable(u, v)`：一次位测试，O(1)。
  - 插入边 `(u, v)`：先做成环检测（`v` 可达 `u` 则拒绝），随后沿父链收集 `u`
    的全部祖先 `a`，执行 `reach[a] |= reach[v]`。合并以 256 bit 块为单位做
    8 路字级并行 OR，仅遍历源位图的非零块。
  - 拓扑层级按最长路径分层，随边插入增量提升并向下游传播。

## 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 查询 `(u, v)` 可达 | O(1) |
| 插入边 `(u, v)` | O(祖先数 × 非零块数)，字级并行 |
| 内存 | O(非零 256 bit 块数)，受压缩算法严格约束 |

## 运行

需要 Node.js >= 22.6（原生 TypeScript 类型擦除 + 内置 `node:test`），无第三方依赖。

```bash
npm test        # node --test
npm run example # node examples/demo.ts
```

## 测试覆盖（test/reachability.test.ts）

- 层级 DAG 构建与最长路径分层校验
- 跨层边插入后全部祖先下游可达集的增量更新
- 成环边 / 自环拒绝、重复边幂等
- 压缩位图非零块内存上界校验
- 稀疏 DAG 上压缩内存 ≤ 稠密矩阵一半
- 120 节点随机 DAG（含 40 条随机跨层边）与 BFS 基线逐对（14400 对）一致性
- 2000 节点链上 20 万次查询的 O(1) 性能验证
