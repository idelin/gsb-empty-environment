插件宿主要在两个隔离域间传递只读对象快照，重复穿过边界的引用还得保持对象身份。给 TypeScript 提供可导入的视图库。输入是不可变描述图，不执行输入携带的任何函数；本地属性、原生属性、原型链继承边和访问器各有独立来源。策略沿属性路径限定可见边，不同路径到同一节点时应保留各自剩余权限，同一视图可递归引用。身份相等只在底层对象、当前域和剩余策略的语义完全相同时成立，且禁止利用原型链回溯或弱引用缓存键碰撞绕过受限域边界。宿主能撤销某一级授权，撤销必须传到旧视图和之前缓存的函数结果，但不能误伤经独立授权得到的同一对象视图。请给视图缓存实现语义等价判定，允许用循环策略图，不准把地址排序或路径字符串相同当成证明。提供观察历史的重放验收，涵盖持续持有旧引用、域重建后复用对象编号、同一节点两种受限视图、撤销与异步结果同时到达以及属性读取始终不调用内容访问器。用小图的有限状态关系检查对照，不为验收反射执行页面脚本。
