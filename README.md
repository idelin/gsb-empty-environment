零信任微服务采用离线可衰减能力令牌（Biscuit 风格：权威块 + 若干离线追加的衰减检查块 + 可选第三方认证块）进行无状态授权时，若校验器未按链式 Ed25519 密钥对验证每个追加块的密封签名，或允许持有者在追加块中直接声明新的权威事实（如 `right("admin")`）绕过区块命名空间隔离，低权限客户端即可离线自我提权。为 TypeScript 零信任宿主实现可导入、零外部加密/Datalog 库依赖（仅用 `node:crypto`）的离线衰减能力令牌签发、衰减、第三方块验签与 Datalog 策略求值引擎。令牌结构由权威块（根公钥签名）和链式追加块序列组成，每追加一个衰减块时由当前块内嵌的新临时 Ed25519 私钥签名并将下代公钥写入块内（保证已签块不可删改，只能单调追加新限制）；支持由独立外部公钥签名的第三方块（Third-Party Block）。Datalog 求值器严格实施区块事实隔离：（1）权威事实仅能来源于块 0（权威块）与验证方上下文，追加的衰减块只能添加 `check` 约束或限于本块作用域的局部规则，绝不能伪造权威事实或覆盖上游检查；（2）第三方块签发的事实须携带其签发方公钥标记，权威策略显式声明 `trusting <pubKey>` 才采信；（3）验证通过当且仅当全部链式签名有效、无任何块 ID 命中撤销表、权威 `allow` 策略成立且**所有**块（含全部衰减块）的 `check` 断言全部满足。附离线衰减生效、删块/篡改拦截、追加块伪造权威事实拦截与第三方块公钥隔离测试。
