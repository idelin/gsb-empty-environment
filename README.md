# strdict — 版本化共享字符串字典与流式编解码

对象批次共享字符串字典：编码引用与内联可混合，字典按版本冻结，流式解码超预算拒绝扩张。

## 设计

- **字典分代发布**：`Registry.Publish` 冻结 `Builder` 为不可变 `Dictionary`，版本号单调递增。
- **读租约与回收**：`Acquire` 返回 `Lease`；`Reclaim` 在存在活跃租约时拒绝；`Cancel`/`CancelAll` 支持单个与批量取消，取消后新租约失败、存量租约失效。
- **哈希碰撞**：查找按 (hash, 全串比较) 解析，`NewBuilderWithHash` 可注入退化哈希强制碰撞。
- **线格式**（自定义序列化范围，仅扁平字符串序列，解码不执行宿主代码）：
  - `0x00` INLINE：uvarint 长度 + 原始字节
  - `0x01` REF：uvarint 索引（相对当前版本）
  - `0x02` SWITCH：uvarint 版本号，显式切换点，仅影响其后的引用
  - `0x03` END：流结束
- **解码会话**：启动时固定版本；切换点之前的引用按旧版本解释，绝不复用旧引用套新词义。
- **字节预算**：`MaxBytes` 涵盖字典字节 + 暂存缓冲 + 已解码输出；先验证长度再分配，超预算即粘性失败，拒绝继续扩张。
- **边界**：空串可入池；未知索引报错而非当空串。
