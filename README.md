移动系统服务会把一份已经检查过的 Bundle 转发给另一版本的读取器，其中部分字段允许保留未知扩展。为 C++17 消息宿主交付可导入的双版本验收组件。输入是两份有限 schema 描述，字段有稳定编号、长度头宽度、对齐、重复策略和作用域；外层声明长度限定内部读取范围，扩展可以保留为原始字节但不能参与授权或覆盖已知字段偏移。需验证一次读取、按源版本重新编码、目标版本读取后，所有标为授权相关的字段、缺省值、重复策略折叠结果与来源位置是否保持一致，不能只比最终字节数。相同编号在嵌套对象内有不同身份，字段名别名及跨版本默认枚举映射均不得产生新授权。损坏数据须报告首个能确定拒绝的原始偏移，增量流式切块不得使拒绝偏移或边界不同；目标 schema 缺少足够证据解释未知字段或发生默认字段静默升级时返回未判，不猜成已知类型。提供来源映射与只读验收接口，使用小消息全枚举比较两种独立解析路径，覆盖流式切块、长度恰及边界、尾随填充、重复键版本差异和字节相同但授权意义不同的情况。
