金融与账务 SQL 查询使用 `DECIMAL(p, s)`（最高 38 位有效十进制数字）做加减乘除与取模；当两个不同精度的十进制数相乘或相除时，中间结果极易超出 128 位有符号整数上限，或因尺度对齐、负数取模符号和半值舍入模式（四舍五入远离零 vs 银行家偶舍入）不一致导致分厘误差。为向量化计算引擎交付可导入的 Go `Decimal128` 定点内核（禁止借用标准库 `math/big` 绕过核心定长运算，仅允许在测试中把 `math/big` 作为参考对照！）。内部用自定义 128 位补码整数（高 64 位有符号 + 低 64 位无符号）和 `(precision, scale)` 元数据表示，范围 `[-10^38+1, 10^38-1]`。实现 SQL 标准结果类型推导（加减对齐最大 scale、乘法 `s1+s2`、除法及超 38 位精度时的规范尺度缩减规则）、无损对齐、乘法（需内部 256 位宽积再按舍入模式缩减并检测 38 位溢出）、长除法（支持 HalfAwayFromZero 与 HalfToEven 两种舍入且精确余数判定奇偶半点）、取模（结果符号与被除数一致，除零返回明确错误）及字符串双向解析格式化（支持科学计数法、前导零、负零归一化与尾部零按 scale 补齐）。验收以 `math/big.Rat` 精确有理数作对照，覆盖 38 位极大正负数乘除不溢出、跨 64 位借位/进位、负数取模与向零截断一致性、两种半值舍入在正负数上的精确差异以及超 `10^38-1` 溢出捕获。
