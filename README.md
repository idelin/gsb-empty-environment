# 密文长度可识别集合

隐私评估需要判断加密消息长度是否足以识别用户动作。写供Go评估宿主调用的推断包，输入各动作的有理先验、每状态的有理长度发射分布和有理转移矩阵；每个时刻是否丢失由显式掩码给出且与秘密独立，丢失位置对全部发射长度边缘化；计算每个观察序列的兼容动作与最大后验，返回达到阈值的最短序列。限制观察深度八，用全序列枚举验证填充和消息丢失的明确语义。

## 模型与约定

- 离散 HMM：隐状态即用户动作；先验是首时刻动作 `X_1` 的分布。
- 首时刻只在初始状态上发射长度；之后每个时刻在当前状态上发射，再按转移矩阵扩散。
- 发射分布按 `BlockSize` 做填充块聚合：长度 `l` 归入块首 `(l/BlockSize)*BlockSize`，同块概率精确相加，表达“填充后同块长度不可区分”。
- 丢失掩码 `Observation.Lost` 与秘密独立：丢失时刻对全部发射长度边缘化，发射因子恒为 1（只推进转移）。
- 全部概率与中间量使用 `math/big.Rat`，阈值判定为精确比较；观察深度硬限制为 `MaxDepth = 8`。

## 公开 API

- `NewModel(*Model) (*Compiled, error)`：校验先验/转移/发射均为和为 1 的非负有理分布，并完成填充聚合。
- `Filter(*Compiled, []Observation) (*Result, error)`：精确前向滤波，返回后验、兼容动作（后验严格为正）、MAP（并列取最小下标）与全联合似然。
- `Walk` / `Enumerate(*Compiled, maxDepth)`：在 `丢失符号 ∪ 长度字母表` 上做全序列枚举，按深度与字典序确定排列。
- `Shortest(*Compiled, threshold) (*Sequence, error)`：BFS 返回 MAP 后验 `>= threshold` 的最短序列；深度内不存在返回 `ErrNoSequence`。

## 验证

`netsec_test.go` 用独立的全隐状态路径枚举作为参照实现，交叉校验：

- 滤波后验、兼容集合、MAP 与联合似然（含空序列与不可能序列）；
- 填充块内任意原始长度给出完全相同的后验，且聚合概率等于手工求和；
- 丢失时刻发射因子为 1、连续丢失被完全边缘化（似然保持 1）；
- 枚举数量与字典序、`Shortest` 命中序列与 `Enumerate` 首个命中一致；
- 深度上限与输入分布归一化的错误路径。

运行：`go test ./...`（另有 `example_test.go` 演示宿主调用）。
