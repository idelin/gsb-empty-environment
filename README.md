# 规则模块系统

TypeScript 实现，零依赖，直接利用 Node.js（>= 22.6，建议 23.6+）原生类型擦除运行，
以 Node.js 内置测试运行器（`node:test`）验证。

## 设计要点

- **显式导入导出**：模块通过 `imports`/`exports` 按显式名称交换绑定，命名空间彼此隔离；
  本地导出遮蔽同名导入，别名（`as`）可同时引入同名绑定。
- **版本必须匹配**：导入声明精确版本，与批次内实际版本不一致即报 `VERSION_MISMATCH`。
- **环依赖分级**：声明图与求值图分别建图（`buildDepGraphs`）。`decl` 类导出无求值副作用，
  允许成环；`value` 类导出成环即报 `EVAL_CYCLE`，并输出最短错误来源链（BFS 最短环）。
- **原子批量链接**：先完成全部导入/导出签名检查（错误一次性聚合），再整批构建；
  任一环节失败抛 `LinkFailure`，注册表不发生任何部分换版。
- **热替换与存活决策快照**：`ModuleRegistry.hotReplace` 整批链接成功后原子换版；
  `snapshot()` 取得不可变快照，进行中的决策（含旧异步属性读取）继续返回旧版本的值。
- **缓存隔离**：`ModuleCache` 以模块的完整依赖版本向量（自身 + 全部传递依赖版本）为键，
  同名同版本模块在依赖版本不同时缓存互不混用。
- **策略引擎**：只读显式属性（未声明属性读取/写入均抛错），条件仅限有限集合 `in`、
  整数比较 `eq/ne/lt/le/gt/ge` 与布尔运算 `and/or/not`，纯同步求值，不接外部身份服务。
- **同名规则隔离**：规则以 `模块名:规则名` 全限定登记，两个模块的同名规则互不覆盖。
- **错误定位**：缺失导出等错误携带导入语句位置（`loc`）。

## 目录结构

- `src/types.ts` — 模块源、导入导出声明类型
- `src/errors.ts` — `LinkError` / `LinkFailure`（含最短来源链与语句位置）
- `src/graph.ts` — 图构建、最短环、拓扑排序
- `src/linker.ts` — 签名检查 + 双图环检测 + 整批链接
- `src/registry.ts` — 注册表、热替换、存活决策快照
- `src/cache.ts` — 按完整依赖版本向量隔离的模块缓存
- `src/policy.ts` — 策略条件校验与求值
- `src/rules.ts` — 命名空间隔离的规则簿
- `tests/` — `node:test` 测试
- `examples/demo.ts` — 运行样例

## 运行

```bash
npm test     # node --test "tests/**/*.test.ts"
npm run demo # node examples/demo.ts
```
