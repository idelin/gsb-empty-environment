Zstandard（RFC 8878）数据块的序列段采用有限状态熵编码（FSE）与三槽位重复偏移历史（Repeat Offset `[1, 4, 8]`），其规范中有三处极易踩坑的细节：归一化概率为 `-1` 的极低频符号必须倒序填在解码表最末尾而非参与步长散布；FSE 比特流是按字节从后往前读取并以最高有效 `1` 位作为哨兵对齐；以及当序列字面量长度为 `0` 且编码偏移值落在 `1..3` 时，重复偏移槽位索引必须整体后移一位（`1->rep2, 2->rep3, 3->rep1-1`，且结果 `<= 0` 属于非法损坏流！）。为压缩存储引擎交付可导入的 Go RFC 8878 FSE 与序列执行内核。组件实现：1）FSE 归一化分布表头解码（按准确度对数 `accuracyLog` 变长位读取各符号频率，校验和等于 `1 << accuracyLog`，支持概率为 `-1`、连零跳过及默认预定义 LL/ML/OF 分布表）；2）标准步长 `(tableSize >> 1) + (tableSize >> 3) + 3` 的 FSE 解码表构建；3）逆向比特流（Backward Bitstream）读取器与三状态交错（LL、OF、ML）FSE 序列解码（支持 Predefined、RLE、FSE_Compressed 与 Repeat 四种压缩模式）；4）完整序列执行器（结合字面量段、重复偏移历史 `[1, 4, 8]` 更新规则、重叠 RLE 拷贝 `offset < matchLength` 及窗口大小上限检查）。验收覆盖 `-1` 极低频符号 FSE 表构建、`LL == 0` 与 `LL > 0` 重复偏移边界、重叠短偏移拷贝、跨块 Repeat 模式复用前块 FSE 表，以及非法哨兵零字节、越界偏移与 `rep1 - 1 == 0` 损坏流拒绝。
