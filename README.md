# 攻击者先窃取令牌再横向访问服务，检测器不能把不同主体的正常事件拼成攻击链

攻击者先窃取令牌再横向访问服务，检测器不能把不同主体的正常事件拼成攻击链。写供Go事件宿主调用的检测包，事件为令牌读取、以令牌认证、受保护操作，令牌身份包含签发者、摘要与代次，主体和设备均带可信实例号；只有同一令牌沿读取者派生关系流到认证主体，且操作发生在撤销后，才输出三段证据。输入时间为偏序，至多20事件，分别判必然、可能或不成立；用全部合法拓扑序核对，缺少因果边不得报确定攻击。

## 检测包说明

包 `taskpkg` 实现“令牌读取 → 以令牌认证 → 撤销后受保护操作”三段攻击链
检测，供 Go 事件宿主通过 `Analyze(Input) (Report, error)` 调用。

- 令牌身份为 `(Issuer, Digest, Generation)` 三元组，代次不同即不同令牌。
- 主体与设备均为带可信实例号的 `Instance`；只有认证主体/设备分别沿受信任
  派生图自读取主体/设备可达时，才承认令牌流动，防止跨主体拼接正常事件。
- 受保护操作必须与认证同主体、同设备、同会话（`Session`）绑定。
- 输入时间是偏序（`Event.After` / `Revocation.After`），普通事件至多 20 个。
- 结论三值：`VerdictCertain`（证据所需因果边全部被偏序蕴含）、
  `VerdictPossible`（补边无环但有缺失边）、`VerdictNotEstablished`
  （所有候选与偏序矛盾或不满足同一令牌/派生/绑定条件）。
- `LinearExtensions` 枚举全部合法拓扑序；测试用独立穷举预言机与 `Analyze`
  做随机等价性对照，保证缺少因果边时不会报确定攻击。
