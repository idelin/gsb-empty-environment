数据库要把行策略下推到外连接子树，错误的改写会让隐藏行改变公开行数或用户函数的调用。给TypeScript规划宿主写可导入的改写验收包。旧、新计划均由最多三张二列表的扫描、策略过滤、投影、左右外连接和UNION ALL组成，值域由输入给出且含SQL NULL，重复行按多重集处理。比较、AND、OR用三值逻辑，连接成功只认TRUE，未匹配的一侧要补NULL；策略谓词先于其保护的扫描结果对外可见。用户函数是声明好的有限表，调用产生可见的参数多重集并返回表值或错误。对每张表至多两行的有限数据库，证明两计划在授权行袋、调用参数和报错类别上等价，或返回总行数最小的差异数据库及两份逐节点演算。同一层运算按输入定义的稳定序，报错后停止。实现可剪枝的符号比较并给独立的直接解释器，在小域穷举核对；特别验证两个相同隐藏行、外连接补空、拒绝行上用户函数抛错和空表。
