域名查询服务把外连交给共享连接池。给 TypeScript 连接池写可导入的目的地授权组件。租户策略写成 IPv4/IPv6 前缀的允许或拒绝规则，最长匹配，长度相同拒绝优先，缺省拒绝；IPv4 映射 IPv6 统一按 IPv4 判定。解析器返回有序的 CNAME 链、最终地址与分别的 TTL。每跳域名都须满足租户的标签后缀白名单，循环拒绝；凭据的有效期取整链最早到期值与策略截止时间的较早者。凭据绑定租户、规范化域名、地址、端口及策略代次。复用已建连接时，须核对实际对端及同租户凭据，不能因两个域名解析到同一地址而替用。双栈候选可并行握手，只有仍获授权的候选能胜出；胜出后关闭其余连接，策略更新和超时都要清退不合格候选。用注入的解析器和假连接按可控顺序完成握手，核对 CNAME 中间跳到期、共享地址跨租户、IPv4 映射地址、撤权与第二个候选同时成功时的连接去向。
