统计服务只向租户发布聚合量，但多个合法结果一起使用时可能唯一确定某个人的数值。给 Go 查询网关写可导入的发布准入组件。每个数据代次包含至多128个未知量，取值在素域 F_65537；已公开的校验关系、已发布查询和候选查询均为带常数项的仿射方程。保密策略列出不可被唯一确定的线性量，以及几个受保护子空间：发布后对每个子空间最多新增学习到指定数量的独立方向。必须相对公开先验计算新增知识，不能把先验已确定的方向再扣一次预算。多租户可声明串通组，检查每个组成员可见方程的并集；同一发布同步影响多个组，整批要么全部写入历史要么全部拒绝。跨快照只通过宿主签名的变量映射和守恒关系传播，不可按姓名或列序自动对齐。返回每项保密约束发布前后的维数以及独立可复核的秩证明，拒绝时不得输出个体取值。以小域全枚举对照单人、串通组、先验重叠和变量换序场景，并验证不同消元顺序不会改变准入结果。
