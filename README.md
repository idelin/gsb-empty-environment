# objectindex

内存对象索引库，模拟对象列表服务，不依赖任何外部服务（仅标准库）。

## 语义

- **新增/覆盖**：`Put(key, value)` 返回全局唯一、永不复用的对象 ID。
- **墓碑删除**：`Delete(key)` 写入墓碑；删除后重建同键会得到全新 ID，
  不会与旧对象混为同一对象。
- **前缀分页**：`List(prefix, cursor, limit)` 按字典序分页。
  - 游标绑定**快照版本**与**最后考察键**，列表期间并发更新不可见。
  - **限额按返回项计**；扫描预算（`limit * ScanFactor`）约束单次调用
    考察的候选键数。前缀过滤导致空页时游标仍推进，调用方应翻页至
    `Cursor.Done`。
  - 快照超出保留窗口（`Retention` 个版本）后返回 `ErrSnapshotExpired`。

## 测试

`go test ./...` 覆盖：并发更新下与冻结排序映射参考核对、空前缀、
最大键（`\xff` 边界）、快照过期、删除重建身份、空页游标推进，
以及随机操作对参考模型的交叉验证。
