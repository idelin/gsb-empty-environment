设备虚拟化宿主要把一段物理内存从租户 A 交给 B，可是旧设备的 IOTLB、分离的读写队列和已提交的散布聚集请求可能仍持有映射。给 Go 宿主写可嵌入的内存交接判定包，用抽象事件描述映射授予、提交请求、部分完成、撤销、失效通知和设备确认，不操作真实硬件。确认绑定设备实例代次、被撤销的地址域和序号前缀；读队列确认不能代替写队列，同一编号设备重新注册后的确认不能覆盖旧实例。一次传输的每个物理区间须持续归属同一租户，只有全部相关旧访问都已完成或者被宿主确认取消，并且所有对应缓存失效都已确认，才准交接。输入给每队列内部次序和显式跨队列先后边；最多16个尚未确定顺序的事件。计算哪些物理子区间在所有合法交错下都已安全，按端点分段，不枚举字节。对可交接区间给出由最少确认和完成事件组成的证书，独立检查函数只用证书与原事件约束核对是否足够。验证部分完成切开同一页、队列序号相同但来源不同、设备重用编号、重复确认及两个物理别名的失效确认无法互相替代。
