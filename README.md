# reachidx — 动态可达性索引

维护有向多重图上的**正长度路径**可达性，支持随机增删与重复边，
每轮用全图 BFS 核对索引正确性。

## 语义

- **多重边**：`Add(u,v)` 计数加一；`Remove(u,v)` 只减一次计数，计数归零才删除边。
  重复增删不改变图结构时，可达性不变（无变化点对输出）。
- **正长度路径**：`reach(u)` 是长度 ≥ 1 路径可达的节点集。
  节点到自身可达当且仅当存在自环或经过它的环。
- **变化输出**：每次操作返回新增/消失的可达点对 `(from, to)`。

## 索引维护

- **加边 (u,v)**：新路径必经过该边，增量传播
  `({u} ∪ pred(u)) × ({v} ∪ reach(v))` 中尚未可达的点对。
- **删边 (u,v)**（计数归零时）：可能失效的点对，其源点必能到达 u（或等于 u）。
  对 `{u} ∪ pred(u)` 中每个源点用 BFS 重算可达集并取差集——
  桥边删除后，环上源点逐一重算，由环自我支撑的伪可达性随之清除。

## 运行

```sh
go test ./...                                  # 随机核对 + 重复边/自环/桥边单测
go run . -seed 7 -nodes 12 -rounds 300         # 随机演练，打印每轮变化点对
go run . -v=false                              # 只输出最终核对结果
```
