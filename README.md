数据库把权限过滤下推到外连接时，可能把“连接成功但另一租户无权访问”和“没有匹配行”混淆。给 TypeScript 查询宿主实现可导入的计划准入组件。输入为参考计划、候选计划与租户读取策略，计划语法仅含两表内连接或左连接、过滤、投影、UNION ALL；表达式支持 SQL 的三值等号、IS NULL、AND、OR、NOT，输出保留重复行。每表至多两行，列可为有限枚举值、NULL 或相等性标识；相等性标识的实际取值域无限，但只能作相等比较，题面常量各有固定身份。策略先按主体和行租户确定能否参与运算，隐藏行的存在和内容均不得改变读者可见的结果多重集。只有候选计划与带策略的参考计划在此完整边界内等价，才为计划摘要和策略版本发出执行凭据。构造有限代表数据库时须覆盖标识相等关系、同名常量、重复行、全 NULL 扩展行和空表，不得靠随机采样；为等价结论提供完备划分证书，由独立函数检查代表类覆盖。测试包括行数相同但重复次数不同、谓词在 ON 与 WHERE 间移动、隐藏右行改变左行补空结果及无实际权限差别的重写。
