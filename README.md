# sedt — 有限二维整数网格的精确平方欧氏距离变换

为图像编辑器提供二值掩码的距离场：每个像素返回到最近**异值**像素的平方
欧氏距离及该像素坐标；距离相同按**行再列**决胜；整图同值时返回无目标标记
（`dist2: null`）。支持矩形区域翻转后的增量更新、变化像素集合输出与旧快照
查询。

## 构建与测试

```sh
go test ./...        # 单元测试 + 小网格枚举 + 随机翻转对拍
go build ./cmd/sedt  # JSON 命令行
```

## JSON 命令行

标准输入每行一条 JSON 命令，标准输出每行一条响应：

```json
{"op":"new","width":5,"height":1,"rows":["10001"]}        -> {"ok":true,"snapshot":0}
{"op":"query","snapshot":0,"row":0,"col":2}               -> {"ok":true,"cell":{"dist2":4,"src":[0,0]}}
{"op":"flip","snapshot":0,"x":0,"y":0,"w":1,"h":1}        -> {"ok":true,"snapshot":1,"examined":5,"changedCount":3,"changed":[...]}
{"op":"field","snapshot":0}                               -> 整个距离场
```

`cell` 为 `{"dist2":D,"src":[row,col]}`，无目标时为 `{"dist2":null,"src":null}`。
旧快照 id 永久有效，查询结果不受后续翻转影响。

## 算法与复杂度

设 N = W×H。

- **距离变换**：Felzenszwalb–Huttenlocher 可分离下包络算法，先逐列后逐行
  做两次 1D 变换，每个 1D 变换 O(长度)，整体 **O(N) 时间、O(N) 空间**。
  对"到 1 像素"与"到 0 像素"各算一遍，每个像素取异值集合的结果。
  全程整数运算，无浮点误差。
- **决胜规则**：1D 变换携带源像素坐标，抛物线交点取整时按
  (距离, 行, 列) 全序决胜（`split` 返回首个胜出整数位置）。两次传递的
  决胜组合后等价于全局 (距离, 行, 列) 最小，由 `ReferenceField` 全配对
  参考实现交叉验证。
- **翻转更新**：翻转矩形 O(面积) 修改掩码，随后**全量重算** O(N) 并与上一
  版本逐像素 diff O(N)，得到精确变化集合。受检像素数 `Examined = N` 如实
  记录。不把变化范围限定在编辑框附近：删除唯一最近点可能改变全图（测试
  `TestDeleteUniqueOppositePixel`、`TestChangeSetExtendsBeyondEditBox`
  覆盖）。局部化增量修复（如从编辑框边界做波前传播）是未来优化方向，
  当前版本优先保证正确性。
- **快照**：每个版本持有独立的掩码与距离场，O(N) 内存/版本；旧快照不可变，
  查询 O(1)/像素。
- **参考实现**：`ReferenceField` 为 O(N²) 全配对暴力，仅供测试，不依赖
  任何增量索引。

## 测试覆盖

- 单像素（唯一异值点，邻域决胜）
- 棋盘格（全部距离为 1）
- 两个等距种子（行再列决胜）
- 删除唯一异值像素（全图变为无目标 + 旧快照仍返回旧距离）
- 变化集合超出编辑框
- 小网格全掩码枚举（1×1 到 4×4 等，与参考实现逐一比对）
- 随机尺寸、随机掩码、随机矩形翻转序列对拍（场、变化集合、受检数、
  旧快照不变性）

## 明确不包含

- 三维或等值面提取
- 实时耗时保证（全量回退意味着单次更新 O(N)）
