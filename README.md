审计客户端只应收到被授权字段的值，同时能核对导出内容确实属于已签名的归档。给 Go 归档服务写可导入的选择性披露包。归档是有序键值树，叶子承诺为 SHA-256(0x00、四字节大端键长、键、四字节大端值长、值、固定32字节盐)，内部承诺为 SHA-256(0x01、左右承诺)；叶子按键的原始字节排序，不补复制节点，非二次幂区间按小于区间长度的最大二次幂切开。根签名绑定租户、版本、叶子数和根摘要。请求包含多个半开键区间，可要求区间完整披露或仅证明区间为空。验证者必须从同一份证明同时确认所有披露值、边界和空区间，拒绝遗漏夹在区间内的叶子、跨快照拼证以及额外暴露的字段值。为证明有序边界，允许披露相邻叶子的键但不能泄露其值或盐：设计并说明一个补充的按索引签名绑定的键承诺结构，将它与值树一起绑定到同一根签名。输出证明须合并重复的边界与兄弟节点，严格检查重复索引、冗余节点和不足节点。用小树穷举每种区间组合，对照完整树扫描，并核对 proof 中没有越权值或盐。
