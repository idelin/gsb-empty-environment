# 选课规划器 (course-planner)

给定课程目录（先修、同修、开课季节、学分）与毕业要求，求：

1. **最早毕业** 的排课方案（最少学期数）；
2. 在最早毕业前提下 **额外学分最少**（总学分 - 毕业要求学分）；
3. 全程课程总数不超过 **22 门**（可配置）；
4. 输出每学期安排、被满足的 **课程组替代路径**；
5. 识别 **无法通过同修解决的先修环**（严格先修构成的环；纯同修环可同学期修读，可解）。

## 运行

需要 Node.js ≥ 22.6（原生 TypeScript 类型擦除），无需安装依赖、无需编译：

```sh
node src/main.ts          # 运行示例
node --test tests/*.test.ts
```

## 模型

- `Course.prereqs`: `PrereqRequirement[]`，每条要求必须满足；一条要求内
  `alternatives: string[][]` 为“或”关系，每个替代是一组需全部完成的课程（课程组替代）。
- `Course.coreqs`: 同修课程，同学期或更早修读即可。
- `Course.offered`: 开课季节（`fall`/`spring`/`summer`/`winter`），按学年循环。
- `TermSpec`: 每学期的学分上限与门数上限（学分负载）。

## 算法

- **先修环检测**（`src/cycles.ts`）：不动点迭代求最大“被困集合”——
  若某门课无论选择哪条替代路径，先修都落回集合内部，则被困；
  在集合内构图取强连通分量作为环的见证。同修边不参与（可同学期解开）。
- **排课搜索**（`src/planner.ts`）：按学期做状态 DP，状态为已完成课程集合；
  每学期枚举满足先修/同修/学分/门数/总门数约束的课程子集，
  逐学期推进，首次覆盖全部毕业要求的学期即最早毕业；
  同层状态按总学分最小择优，并做支配剪枝。

## 文件

- `src/types.ts` — 领域模型与结果类型
- `src/cycles.ts` — 先修环检测
- `src/planner.ts` — 排课优化器
- `src/catalog.ts` — 示例课程目录与学期生成
- `src/main.ts` — CLI 演示
- `tests/planner.test.ts` — 单元测试
