# 安全检查插桩控制流保持

安全编译器在内存访问前插入检测，不能破坏原程序的异常边与SSA合流。写供Go编译宿主调用的插桩包，输入带源节点ID的有限SSA图，内存读写前插入纯检测回调，拒绝必须在访问前跳转到带原源位置的陷阱；拆分临界边时同步修正phi前驱，循环回边不得产生重复插桩。配套独立解释器比较合法访问的返回与异常顺序，并核对被拒写入没有副作用。

## 包结构（module `example.org/netsec/q0491`，package `netsec`）

- `ir.go` / `ids.go`：有限 SSA IR（块/指令/寄存器、源节点 ID、源位置、Phi 与终结符）。
- `instrument.go`：插桩入口 `Instrument`，纯检测回调 `OpCheck`、拒绝策略、
  陷阱跳转安全校验、临界边拆分 `SplitCriticalEdge` 与 phi 前驱修正。
- `clone.go`：深拷贝，保留原图用于对照。
- `interp.go` / `memory.go`：与插桩解耦的独立解释器、字节内存与越界判定。
- `compare.go`：返回值/异常顺序对照与“被拒写入无副作用”核对。

## 关键不变量

- 每条 `load/store` 前恰好一个 `OpCheck`，携带原源节点 ID 与 `Position`。
- 默认 `ModeCallback` 不新增块、不改终结符与 phi，异常边与 SSA 合流原样保留。
- `ModeTrap` 仅在目标为无 phi、无前驱的叶子陷阱块时接受访问前跳转；
  需要拆边或改动合流时返回 `*RejectError`，不留半成品。
- 拆临界边时把后继 phi 中指向旧前驱的标签改写为新合成块。
- 插桩幂等：`OpCheck` 已守护的内存指令跳过，循环回边不重复检测。
- 解释器在访问前调用检测；拒绝即终止，写事件不发生，内存快照与拒绝前一致。

## 验证

`go test ./...`（含 `-race`）覆盖：插桩位置与源位置、幂等与回边去重、
合法访问等价、被拒写入无副作用、trap 安全/拒绝、phi 前驱修正与合流求值。
