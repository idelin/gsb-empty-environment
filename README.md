# merklediff — 可验证日志快照与差异回溯比对器

基于默克尔树（Merkle Tree）高效识别两个日志快照版本之间的差异记录，仅使用 Go 标准库。

## 原理

- 每个版本的记录列表构建为一棵 **16 叉默克尔树**：叶子为 `SHA-256(0x00‖record)`，
  内部节点为 `SHA-256(0x01‖children…)`（域分离同 RFC 6962）。
- **全等判定**：两个版本的根哈希相同 → 直接判定全等，一次比较，零展开。
- **差异下钻**：根不同则自顶向下逐层比较子节点哈希，只展开哈希不一致的分支，
  哈希一致的子树整体剪枝——无需下载、无需扫描其下任何叶子。
- **可验证快照**：支持为任意记录生成包含证明（inclusion proof），
  第三方可凭根哈希独立验证某条记录确实属于该快照。

## 验收边界

两棵各含 **1,000,000** 条记录的树，仅 **3** 条记录被修改：

- 16 叉树高仅 5 层，下钻最多沿 3 条路径展开 `1 + 3×4 = 13` 个内部节点（要求 < 50）；
- 仅下载约 200 个节点哈希，即精准输出 3 条变动明细，免去 100 万条全量扫描。

## 运行

```sh
go test ./...        # 运行全部测试（含 100 万条记录的验收用例）
go test -v ./merkle  # 查看展开节点数等统计
go run ./cmd/merklediff   # 运行演示样例
```

## API 一览

- `merkle.Build(records [][]byte) *Tree` — 构建快照树
- `(*Tree).Root() Hash` / `Count()` / `Height()` — 快照元信息
- `merkle.Diff(old, new *Tree) *Result` — 差异比对，返回变动叶子列表与工作量统计
- `(*Tree).Prove(index)` + `merkle.Verify(root, record, proof)` — 包含证明的生成与校验
