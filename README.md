两台认证设备允许同一 RP 离线提交不同凭据请求，合并时可能有重复回执和不完整的消费日志。给 Go 认证宿主实现可导入的合并准入组件，收据签名绑定设备启动代次、凭据永久 ID、已授权用途、事务摘要与消费前缀。旧日志只保留批摘要和候选凭据集合。必须存在同一份全局分配使所有已确认事务均有唯一合法消费，且为新的签名许可选出的凭据在每份相容历史中都未消费。另一个 RP 的同名凭据、同一事务在两台设备的重传和撤权前仅预约的凭据要分别处理。产出可验的恢复结论与固定凭据证明；不能用分别有解的局部分配代替全批一致。用小规模完整枚举对照局部都有余量但全局无法分配、共同候选在全部合法解中均被占用、事务绑定不同摘要及恢复后重复调用不再产生签名。
