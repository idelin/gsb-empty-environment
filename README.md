# perish — 易腐品批量生产库存优化（Go）

两部分共用一个按批次年龄记账的模拟内核：

1. **确定性**（`det.go`）：10 天需求已知，保质期 `Shelf=d` 天，每日产能
   `Cap`、启动固定费 `Setup`、单位生产费 `ProdCost`、单位日持有费
   `HoldCost`。最早到期先消耗（FEFO），禁止缺货，数量整数，总需求 ≤ 30。
   以 (天, 库存年龄向量) 为状态做 DP，输出最优生产计划与批次年龄账。

2. **随机**（`stoch.go`）：每天开始揭晓当日需求，至多 6 条需求情景，各有
   理概率（`Num/Den`，精确用 `big.Rat` 运算）。情景按需求前缀合并成树，
   决策挂在树节点上——历史相同必为同一节点，天然满足非预知性。最小化
   期望总成本，每条路径不得缺货，过期库存按年龄向量随节点共享。

## 模型约定

- 日 p 生产的产品可在日 p … p+d-1 使用，日 p+d-1 结束时过期报废。
- 每日顺序：揭晓需求 → 决定生产（≤ Cap，>0 付启动费）→ FEFO 满足需求
  → 计期末库存持有费 → 库存年龄 +1，到期者报废。
- 上界剪枝：产量不超过剩余路径需求，不影响最优性（成本非负）。

## 验证（`verify_test.go`）

- `TestDetMatchesBruteForce`：小实例穷举全部生产序列与 DP 对比（含不可行情形）。
- `TestExpiryBoundary`：直接核对 `stepDay` 的过期边界，并用 d=2 vs d=3
  改变最优解的实例钉死边界语义；浪费性计划的过期账条目。
- `TestLedgerConservation`：生产 = 消耗 + 过期 + 期末库存。
- `TestStochMatchesBruteForce`：枚举所有非预知策略（每节点一个整数产量），
  精确有理数期望成本与树 DP 对比；DP 策略逐路径模拟复核期望成本与批次账。
- `TestNonAnticipativity`：共享前缀的情景必须得到相同决策、映射到同一节点。

## 运行

```sh
go run .        # 两个演示实例：确定性 10 天 + 6 情景随机树
go test ./...   # 穷举核对
```
