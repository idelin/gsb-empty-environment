通知模板允许普通文本进入元素正文和带引号的属性，但同一字段可能在两个上下文中重复使用。给 TypeScript 模板引擎写可导入的安全渲染组件。模板以已经分词的 AST 给出，只有元素、静态属性、文本占位、属性占位和条件分支；标签名及属性名仅可来自宿主白名单，动态值始终是 Unicode 文本。渲染器可把一份结果拆成任意多个 UTF-8 输出块，允许字符、转义引用或多字节字符跨内部输入块。对每个合法模板和输入，最终按本题给定的引号属性、命名实体、数字引用及文本规则重新解析后，须与直接按 AST 构造树在标签、属性集合和每个字段的 Unicode 标量序列上完全相同。拒绝无效 UTF-8、孤立代理和重复属性。另写独立校验器核对输出与来源映射：每个动态文本标量都可追溯到具体字段的标量区间，不能跨分支或借字符引用吞入后续静态文本。失败时不能发出可被下游接受的半个模板，支持限额内的暂存与原子提交。用小字母表枚举所有短输入及其全部切分位置，和独立树构造器比较；验证同值用于两种上下文、相邻字段边界与失败后接续下一模板。题内实体仅支持 amp、lt、gt、quot、apos 及带分号的十进制和十六进制 Unicode 标量引用，输入值里的实体拼写始终是字面文本。
