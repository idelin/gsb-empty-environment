# ratpiece：分段区间上的有理表达式求和、乘法与连续性检查

纯 Python 3.11 标准库实现（仅用 `fractions.Fraction` 与 `math.gcd` 做精确有理数
计算，不调用任何符号代数库）。所有判定都附带精确代数证据；无法在预算内判定的
边界明确保留为“未决”，绝不猜测。

## 功能总览

- **精确有理函数**：约化存储（分子分母互素、分母首一），保留原始分母以追踪
  定义域空洞；区分可去奇点（约去因子的零点）与极点，并给出端点单侧极限。
- **自动细分**：把每个片段的区间端点与表达式的一切有理排除点（极点、可去
  空洞）并入共同边界集，任意交叠区间自动细分为一致的单元划分。
- **求和 / 乘法**：在并集划分上逐单元组合；任一侧无定义的单元保持未定义
  （空洞保留未定义）；相同表达式在排除点两侧**不**跨点合并。
- **连续性检查**：跳变（左右极限不同即报告跃度）、无穷间断（奇偶阶数定号）、
  可去间断、单侧定义（只一侧有定义时不冒称连续）、连续，全部附代数证据。
- **根隔离与符号测试**：有理根由有理根定理精确求出（含重数）；无理根用
  Sturm 定理隔离到有理端点开区间；极点单侧符号由区间端点的精确符号测试
  决定。二分预算耗尽时报告 `undecided`。
- **增量维护**：`set_piece / replace_piece / remove_piece` 只分裂、合并、重标
  受影响的单元，单元 id 稳定，来源映射（单元 → 来源片段）随编辑即时更新。
- **开闭保持**：区间端点开闭在交、并、组合与合并中精确保留。

## 目录结构

```
ratpiece/
  poly.py        精确有理系数多项式：四则、gcd、Sturm 链、无平方部分
  roots.py       实根分类：有理根（重数）+ Sturm 隔离 + 预算内未决簇
  rational.py    有理函数：定义域空洞、可去奇点、单侧极限、变换日志
  interval.py    有理端点区间，开闭标记在运算中保持
  piecewise.py   分段模型：共同细分、来源映射、增量编辑、组合与合并
  continuity.py  连续性判定：跳变/无穷/可去/单侧/未决，附证据
demo.py          运行样例（五个场景）
tests/           unittest 测试套件
```

## 快速开始

```python
from ratpiece import Interval, PiecewiseModel, Poly, RationalFunc, check_continuity

f = PiecewiseModel("f")
f.set_piece(Interval.open(None, 1), RationalFunc.identity(), "f1: x")
f.set_piece(Interval.closed(1, 3), RationalFunc.constant(2), "f2: 2")

g = PiecewiseModel("g")
g.set_piece(Interval.open(0, 5),
            RationalFunc(Poly((-1, 0, 1)), Poly((-1, 1))),   # (x^2-1)/(x-1)
            "g1")

h = PiecewiseModel.combine(f, g, "add", "h")   # 自动细分交叠区间
print(h.evaluate(2))                            # 5
print(h.evaluate(1))                            # None：g 的空洞保留未定义
print(check_continuity(h).summary())
```

## 方法说明（每步变换的适用域）

- **约分**：`num/den` 约去 `gcd` 后在除去其零点的定义域上与原式恒等；这些
  零点被记录为可去奇点（定义域空洞），不会从定义域中丢失。
- **通分求和 / 相乘**：`a/b + c/d = (ad+bc)/(bd)`、`(a/b)(c/d) = (ac)/(bd)`，
  在两个函数定义域的**交集**上成立；结果的未约化分母取两边原始分母之积，
  因此空洞在组合后全部保留。
- **有理点极限**：定义域内直接代入；可去奇点对约化后的分式代入；极点用
  `(x-b)` 在分子分母中的重数奇偶性确定单侧符号（纯代数，无数值近似）。
- **无理极点**：Sturm 定理给出含唯一根的有理端点开区间；精修到与分子零点
  分离后，在区间端点做精确符号测试得到两侧极限方向。预算耗尽时输出
  `undecided` 并说明原因。
- **合并规则**：仅当相邻片段表达式相等、来源相同且共享端点本身有定义时才
  合并；相同表达式跨排除点（空洞）绝不合并。
