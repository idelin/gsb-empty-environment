# Chandy-Lamport 一致性快照记录器

分布式全局一致性快照截取算法的 TypeScript 实现：进程发起 Marker 标记，
各进程在收到 Marker 后记录本地状态，并在所有入信道收到 Marker 后记录信道
在途消息状态——全程无需暂停业务即可捕获一致割（consistent cut）。

## 环境要求

- Node.js >= 23（推荐）：原生支持运行 TypeScript（type stripping）与内置 `node:test`。
- Node 22.6+：需加 `--experimental-strip-types` 运行。
- 无任何第三方依赖。

## 结构

- `src/messages.ts` — 转账消息与 Marker 消息类型
- `src/network.ts` — 异步消息网络：每条有向信道严格 FIFO、随机投递延迟（模拟在途消息）
- `src/process.ts` — 进程：本地状态记录、Marker 收发、入信道在途消息记录（算法核心）
- `src/cluster.ts` — 全连接集群编排：并发转账流量、快照发起与结果汇总
- `src/demo.ts` — 运行样例：3 节点（A/B/C）持续转账，A 发起快照并校验守恒
- `test/snapshot.test.ts` — Node.js 内置测试（`node:test`）

## 算法要点

1. **发起**：发起进程记录本地余额（割点），随即向所有出信道发送 Marker，
   并开始记录所有入信道上的后续转账消息。
2. **首次收到 Marker**：进程同样记录本地状态并向所有出信道转发 Marker；
   由于信道 FIFO，Marker 之前到达的消息已计入本地状态。
3. **再次收到 Marker**：关闭对应入信道的记录，已记录的消息即为该信道的在途状态。
4. **一致割性质**：信道状态恰好包含"割前发送、割后接收"的消息，因此
   `Σ 本地状态 + Σ 信道在途金额 = 总资产`，严格守恒。

## 运行

```bash
npm run demo    # 运行样例（3 节点并发转账 + 快照 + 守恒校验）
npm test        # node --test 内置测试
```
