# MPTCP数据序号映射重叠注入

多路径连接的不同子流可把各自TCP序号映射到同一数据序号，恶意子流若提交冲突字节会改写已认证应用流。给Go传输宿主实现可导入的DSS映射账本：连接级64位DSN不回绕，子流ID唯一，每项含32位子流序号起点、64位DSN起点、16位长度、FIN标记、payload及认证代次；payload长度须等于长度，地址加法溢出拒绝。每个子流上的映射按其32位序号相对已认证检查点还原，跨度不得越过2^31；连接级DSN区间可被多个子流重传，但每个重叠字节必须相同，来源集合合并，任何冲突使整项零生效并冻结该子流。长度为0的映射只允许携FIN且不含payload；FIN只绑定数据流末端DSN，多个FIN必须相同，末端之后映射拒绝。认证回调成功后才加入账本，失败不能占用DSN或推进子流检查点。交付器只按DSN从0起输出连续且字节一致的前缀，每字节最多交付一次，后到重传只补来源。用两个子流交错、一个子流序号回绕、映射包含与部分重叠、认证失败后合法重传及冲突FIN测试，逐DSN参考模型核对交付字节与冻结位置。
