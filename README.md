模板注册宿主允许旧渲染实例在升级后继续输出。给 TypeScript 宿主实现可嵌入的迁移验证包，输入为冻结的旧新模板、编码器状态表、调用栈摘要和已发布前缀的认证收据。迁移只能在对齐的输出边界发生，随后所有动态字段都必须继续满足来源标签、转义语境和词法上下文授权，禁止利用迁移前后编码器状态重命名绕过原始上下文转义。旧实例尚未输出的尾部可能位于递归调用中，不能只比较两个入口的返回状态或丢弃深层返回义务。设计可独立验证的栈摘要迁移证书，证明所有与收据相容的旧栈在新版接续后都保持已发布字节的来源和安全上下文，缺少信息时隔离该实例。用两版共享调用片段、返回点合并、尾部跨编码边界、只在深层调用的错误迁移和原版仍可安全完成的样例对照真实宿主输出。
