# 追踪数据脱敏与关联保留

安全事件跨服务关联需要稳定标识，但不能把不同租户的同一邮箱关联起来。写供Go追踪宿主调用的伪名组件，域分隔编码绑定租户、字段类型和密钥代次，使用HMAC-SHA256；批次换代必须同时重写事件键与引用，整批验证后原子发布映射，无法解析的引用保留为显式缺失。用跨租户同值、循环引用和中途存储失败验证可关联性与隔离，不保存原始秘密到映射表。

## 组件结构

- `token.go`：`pn1.` 前缀令牌编码（版本 | 密钥代次 | HMAC-SHA256 摘要），租户/字段/秘密按 uint32 长度前缀做无歧义域分隔，恒定时间比较。
- `keyring.go`：多代次密钥环，代次密钥由 `HMAC(根密钥, 域标签 || 代次)` 派生；根密钥不参与事件 HMAC、不落映射表。
- `pseudonym.go`：`Pseudonymizer` 派生与校验伪名；`WithTenant`/`PseudonymizeFromContext` 在追踪上下文里透传租户域。
- `rotation.go`：`RotateBatch` 两遍换代——先校验旧键并派生新键，再解析引用（循环/前向引用可解析，无法解析者以 `Missing=true` 原样保留），整批验证后单次原子提交。
- `store.go`：`MappingStore` 接口；`MemoryStore`（写时复制）、`FileStore`（临时文件 + rename 原子发布）、`FaultInjector`（提交故障注入）。

## 验证

```sh
go test -race -count=1 ./...
```

关键用例：跨租户同值隔离、同租户稳定可关联、循环引用重写、显式缺失保留与已发布映射回退解析、中途存储失败零部分发布且可重试、映射表只含令牌不含原始秘密。
