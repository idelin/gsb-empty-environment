# pageindex

不可变页索引库（Go）：写时复制 B 树 + 显式页编号 + 快照隔离 + 纪元门控页回收。

## 设计

- **不可变页**：每个页有显式编号（`PageNo`，从 1 开始）。页一旦发布绝不原地修改；
  写者克隆被修改的路径到新页，原子地发布新根（`DB.Put` / `DB.Delete`）。
- **快照**：`DB.Snapshot()` 固定当前根页与提交纪元；`Snapshot.Close` 幂等且并发安全
  （`sync.Once`），可重复调用。分析型读者可长时间持有旧版本，写者继续提交互不影响。
- **回收**：提交时被替换的旧页以「退休纪元」登记。某页在纪元 e 退休，当且仅当所有
  活跃快照的纪元都 ≥ e（或没有活跃快照）时才进入空闲链表等待再分配——即只有任何
  活跃快照都不可达的页才可回收，再分配不会污染旧读者。
- **引用图检查器**：`Reachable` 从任意根集合遍历页引用图；`DB.CheckInvariants`
  校验：空闲页不可达、退休页对当前根不可达、已分配页不泄漏、B 树结构合法
  （键序、子节点数、占用界、叶深度一致）。

## 测试

`pageindex_test.go` 覆盖：分叉快照各自看到一致的版本、删除不触碰已固定的快照、
显式页编号回收（关闭最后一个快照后旧根页被回收并复用）、固定页内容指针级防污染、
并发关闭与并发提交（`-race`）、随机操作下的检查器不变式。

```sh
go test ./... -race -count=3
```
