# 特性成对覆盖测试配置生成器

输入布尔特性及互斥 / 蕴含约束，生成**数量最小**的合法配置集合，覆盖全部
**可达**的两两取值组合（pairwise / 2-wise 覆盖），并对最小性给出可验证的证明。
不可达组合单独列出并逐条解释，非法配置从不计入覆盖率。

## 运行环境

- Node.js ≥ 23.6（直接以类型擦除方式运行 TypeScript，无需编译）
- 无第三方依赖

```bash
node src/cli.ts examples/shop-app.json   # 运行示例
npm test                                 # 运行测试（node --test）
```

## 输入格式（JSON）

```json
{
  "features": ["A", "B", "C", "D"],
  "mutex": [["A", "B"]],
  "atMostOne": [["B", "C", "D"]],
  "implies": [["C", "A"]]
}
```

- `features`：2–12 个特性名（去重）；
- `mutex`：两特性不能同时为 1；
- `atMostOne`：一组特性中至多一个为 1（展开为两两互斥）；
- `implies`：`["X", "Y"]` 表示 X=1 ⇒ Y=1。

所有约束统一编译为二元子句（2-CNF）。

## 方法

1. **合法配置枚举**：n ≤ 12，枚举全部 2^n 个赋值并过滤出合法配置。
2. **可达组合**：某特性对的某个取值组合可达 ⟺ 存在合法配置包含它。
   只有可达组合计入覆盖率分母。
3. **精确最小集合覆盖**：全集 = 可达组合，候选集 = 合法配置。
   - 上界：贪心 + 随机重启；完全无约束时改用 Kleitman–Spencer 构造。
   - 下界：
     - 装箱下界——找一组两两不能被同一合法配置同时覆盖的组合，
       其大小即配置数下界（输出中列出见证组合）；
     - 组合下界——若某子集 F 的特性不出现在任何约束中，则覆盖 F 的
       两两组合至少需要 CAN(2,|F|,2) 个配置；该值通过在"N 行上两两定性
       独立的 0/1 列族"相容图上做精确最大团搜索（Tomita 算法）获得，
       搜索本身即下界证明。
   - 若下界 < 上界，执行**分支限界确定性穷举**（按候选最少的组合分支，
     装箱下界与最大新增覆盖下界剪枝，失败记忆表），证明少一个配置不可行；
     报告搜索节点数作为穷举证明的规模。
4. **不可达组合解释**：在蕴含图上从假设取值做单元传播；2-SAT 完备性保证
   不可达 ⟺ 某特性的 0、1 同时被推出。输出两条完整推导链及矛盾点。
5. **自检**：输出前断言每个配置合法、全部可达组合被覆盖，否则抛错。

## 结果中的证明如何阅读

- `下界 = 上界`：直接得证（装箱见证或组合下界 + 构造）。
- 否则：分支限界穷举证明 `k-1` 个配置不可行，节点数给出证明规模；
  剪枝只使用两条恒成立的规则（装箱下界、最大新增覆盖下界），
  因此穷举是完备的。

## 局限

- 特性数上限 12（合法配置枚举为 O(2^n)）。
- 约束极少而特性很多的病态实例中，分支限界穷举可能较慢
  （完全无约束的情形已由组合构造+下界直接解决）；超过节点上限会显式报错，
  不会输出未证明的结果。
