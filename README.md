# firehose游标解析与回放放大限制

AT 协议的事件流订阅接受 cursor 参数从历史序号回放，攻击者可用畸形、过大或过旧的游标让服务器重复回放大量积压，或在回放与实时交接处造成丢包与重复。给Go中继写供订阅握手调用的游标包：cursor 只接受十进制无符号整数，无符号号、加号、前导零和十六进制写法都拒绝；大于当前最新序号回 FutureCursor 错误帧并关闭；小于保留窗口最早序号先发 OutdatedCursor 信息帧再从最早序号开始；回放到追上实时的交接点必须序号连续不重不漏；每个来源地址同时进行的回放不超过 2 个，回放速率不超过调用方给定上限。用畸形游标、未来游标、过旧游标、交接时并发写入和第三个并发回放验证。
