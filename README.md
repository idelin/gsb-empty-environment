# 附加段把别的域记录塞进了递归缓存

递归解析器处理授权服务器响应时，若不检查附加段名称是否属于当前查询的授权范围，攻击者可让权威服务器顺带返回受害域的A记录并长期缓存。请实现供Go递归解析器调用的可导入缓存准入组件。对每个响应按查询名、qtype、权威区和通配符展开确定bailiwick，附加段与权威段中越出该范围的记录只作为一次性提示而不入缓存；CNAME和DNAME链的每一跳各自计算范围，委托变更使旧范围失效。DNSSEC验证只覆盖签名区，未签名越界记录不得借已验证的父区进入缓存；大小写、压缩指针和重复记录按同一规范化处理。用附加段投毒、CNAME跨区、通配展开、越界NS、重复记录和合法同区附加验证缓存只接受自己权限内的数据。
