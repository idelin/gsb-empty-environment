# clusterdigest — 去中心化集群拓扑视图分歧检测与快速比对

多节点成员状态一致性审计器（Go，仅标准库）。

## 设计

- **增量哈希环 Digest**：成员 ID 经 CRC32 映射到 32 位哈希环，环切分为 16 个区间；
  每个区间维护一个 XOR 折叠的 4 字节摘要，成员增删改只需 O(1) 增量更新（`digest.go`、`node.go`）。
- **周期探活**：相邻节点每轮双向交换 4 字节 CRC 摘要，相等即通过，零额外负载（`sim.go`）。
- **区间状态对账**：摘要失配时交换 16 个区间摘要定位差异区间，仅对失配区间
  双向拉取成员记录，按 version 做 last-writer-wins 合并。

## 运行

```sh
go run .        # 分区愈合演示
go test ./...   # 测试（含“5 轮内全量双向对齐”验收）
```

## 验收场景

`TestPartitionHealConvergesWithin5Rounds`：6 节点分区为 {A,B,C}|{D,E,F}，
两侧独立演化（左侧判 D 死并加入 G，右侧判 A 死并加入 H）；愈合瞬间第一轮
探活即通过摘要失配察觉不一致，触发区间对账，1 轮内完成全量双向对齐（上限 5 轮）。
