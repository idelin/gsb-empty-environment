# router

在带转向限制的路网上求总时间最短路径的 Go 库。

## 模型

- 每条有向边有行驶时间 `Time`（非负）。
- 部分连续边对 `(prev, next)` 禁止通行（`ForbidTurn`）。
- 连续边对可设转向等待时间（`SetTurnWait`），在两条边之间计费；路径首条边之前不计等待。
- 路径总代价 = 各边行驶时间之和 + 相邻边对转向等待之和。

## 算法

- **状态 = 到达边**，而不是顶点。到达同一顶点的不同边是不同状态，因为
  后续可行转向与转向等待取决于"从哪条边到达"。只按顶点记录最短距离会在
  转向限制下丢失次优到达方式，得到错误答案（见
  `TestArrivalEdgeState`）。
- 在边状态图上跑 Dijkstra，优先队列按 `(总代价, 边 id 序列字典序)` 排序；
  同代价下字典序更小的序列会更新标签并重新展开，保证同代价路径中取边 id
  序列字典序最小者。
- **零代价环禁止重复状态**：扩展时跳过已在当前路径上的边。重复到达边即
  成环——零代价环被规则禁止，正代价环只会增大总代价，因此最优路径必然
  状态简单，该限制不改变答案且保证算法终止。
- 到达目的点即记录候选、不再扩展：继续走下去只会增加非负代价并使 id
  序列字典序更大，所以路径在首次到达目的点时结束。

## 正确性核对

`BruteForce`（`bruteforce.go`）是指数级参考实现：对边状态做深度优先展开，
枚举所有状态简单路径，按同一序（总代价，边 id 序列字典序）取最优。
`router_test.go` 中的随机测试在数千张小图（含零代价边、零等待、禁转、
平行边、自环）上逐图比对 `ShortestPath` 与 `BruteForce`，并校验返回路径的
连通性、禁转合规、状态不重复与代价重算一致。开发时另用 20 万随机图与
6 万张零代价稠密图做过压力核对，二者完全一致。

## 用法

```go
g, err := router.New([]router.Edge{
    {ID: 1, From: 0, To: 1, Time: 3},
    {ID: 2, From: 1, To: 2, Time: 4},
})
if err != nil { /* ... */ }
_ = g.SetTurnWait(1, 2, 5) // 边 1 -> 边 2 等待 5
path, cost, ok := g.ShortestPath(0, 2) // path=[1 2], cost=12
```

```sh
go test ./...

```
