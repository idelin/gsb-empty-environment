# 最小面积定向包围矩形（精确算术）

Python 3.11，仅标准库。对二维整数 / 有理数点集求最小面积定向包围矩形，
全程使用 `fractions.Fraction` 精确运算：**没有任何浮点 epsilon**，
所有拓扑判断（凸包转向、卡壳推进、面积比较）都是精确有理数比较。

## 文件

- `minrect.py` — 凸包、旋转卡壳、证书、核验器、动态点集
- `test_minrect.py` — unittest 测试套件（25 个用例）
- `demo.py` — 运行样例

## 算法

1. **凸包**：Andrew 单调链，精确叉积；共线中间点剔除，全共线退化为两端点。
2. **旋转卡壳**：对 CCW 凸包每条边维护三个单调推进的支撑索引
   （最大叉积、最大/最小点积），首条边全量扫描初始化，之后每条边
   O(1) 摊还推进，总计 O(n)。每条边产出一个候选矩形
   （最优矩形必有一条边与凸包边共线，故枚举凸包边即完备）。
3. **精确面积**：候选面积 = `(umax-umin)*(vmax-vmin)/|e|^2`，
   以 `Fraction` 精确比较，不存在 epsilon 决定最优的问题。

## 等面积决胜规则（规范选择）

多个候选面积相等时，按 **规范四角元组的字典序** 取最小者：

- 四角按 CCW 排列，并旋转到字典序最小的角起始（规范形）；
- 依次比较 `(area, corners)` 元组，面积精确相等时比角点序列。

该规则与输入点的顺序、重复次数无关（凸包由排序去重后的点集确定），
因此结果是规范、可复现的。测试用例：三角形 `(0,0),(4,0),(1,2)`
的三条边各给出一个面积均为 8 的最优矩形，规范选择为四角
`((-3/13, 2/13), (36/13, -24/13), (4, 0), (1, 2))`。

## 退化情形定义

- **空点集**：`min_area_rectangle` 抛出 `ValueError`。
- **单点**：面积 0，四角均为该点，`support_edge=None`，方向取 `(1,0)`。
- **两点 / 全共线**：面积恰为 0（精确零，非 epsilon 意义），
  退化矩形的四角为两端点各重复两次。
- **近共线大坐标**：精确叉积不会把近共线误判为共线，也不会产生负面积；
  有专门测试（`10^9` 量级坐标，面积精确等于 `2*10^9`）。

## 证书（RectangleCertificate）

- `area`：精确面积（`Fraction`，恒 >= 0）
- `support_edge`：贴合的凸包边
- `direction`：支撑边方向向量 `e`（未归一化，保持有理）
- `corners`：规范 CCW 四角；角点 = `alpha*e + beta*n`，
  `alpha=dot(e,p)/|e|^2`、`beta=cross(e,p)/|e|^2`，故恒为有理数，
  旋转矩形的四角可精确恢复原等面积框（鞋带公式核验）
- `proj_along` / `proj_across`：所有点向 `e` 与法向 `n=(-ey,ex)`
  的投影范围（未归一化，精确可验证）
- `extremes`：四个极值点 `(min_along, max_along, min_across, max_across)`
- `extreme_handles`：由 `PointCloud` 回填的输入句柄组

## 核验器

`verify_certificate(points, cert)` 以**逐凸包边枚举**为独立参考，
检查：面积最优性、投影范围/四角/鞋带面积自洽、极值点真实且达到
投影范围、支撑边确为凸包边、所有点投影落在证书范围内。

## 动态点集（PointCloud）

- `add` / `add_batch`：每个点获得唯一句柄（身份）；
  **坐标重复的点拥有各自独立句柄**，几何计算自动去重。
- `remove` / `remove_batch`：按句柄批量撤回；无效或重复撤回抛 `KeyError`。
- `min_area_rectangle()`：对当前活跃点重算，并在证书中回填
  每个极值点对应的全部同坐标句柄。
