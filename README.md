# scheduler — 二分图边调度器

把二分多重图的边划分到若干轮（合法边染色），同一端点的边不同轮，
轮数恒等于最大度 Δ（Kőnig 定理保证最优），并输出每轮的匹配。

## 用法

```go
s := scheduler.New()
a := s.AddEdge(0, 0) // 左顶点 0 — 右顶点 0，返回边 ID
b := s.AddEdge(0, 1)
c := s.AddEdge(1, 0)
rounds := s.Schedule() // [][]int：每轮的边 ID 列表，len(rounds) == s.MaxDegree()
if err := s.Verify(rounds); err != nil { ... } // 独立校验
s.DeleteEdge(a)        // 删除后重新 Schedule，不会遗留旧颜色索引
```

- 允许平行边（同一对端点的多条边获得不同 ID，必被分到不同轮）。
- 左右顶点编号空间相互独立。
- 边 ID 单调递增、永不复用，删了再加不会与旧边混淆。

## 算法

增广换色（augmenting recoloring）：按边 ID 顺序逐边上色，取左端点最小
空闲色 `cu` 与右端点最小空闲色 `cv`；若不同，从 u 出发沿 `cv/cu` 交错
路径翻转两色（二分性保证路径不会经过 v），释放 `cv` 后染新边。
每边一次路径翻转，O(E·V) 总量级。`Schedule` 每次从零重算，不缓存任何
颜色状态，因此删除/补边不可能遗留旧颜色索引。

## 输出规范化

轮次编号按首现边 ID 规范化：按边 ID 升序扫描，第一个出现的颜色为第 0
轮，下一个新颜色为第 1 轮，依此类推，输出确定且与内部颜色编号无关。

## 测试

- `Verify`：独立检查每边恰好出现一次、每轮无冲突、轮数等于最大度。
- 穷举 2x2/2x3/3x3 简单图与 2x2/2x3 多重图（重数 ≤2），与暴力回溯
  交叉核对最优性（Δ 可行、Δ-1 不可行）。
- 随机增删模糊测试 + 压力测试（`-short` 可跳过压力测试）。
