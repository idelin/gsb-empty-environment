# 变长块样本-时间映射

纯标准库（Python 3.11）实现：变长块的样本↔时间映射，处理采样率切换、
缺口与重叠，支持双向索引、版本裁决、校准原子更新与稳定游标。
样本数组与采样率全部由本地夹具（`fixtures.py`）提供，**不接触音频设备**。

## 文件

- `timeline.py` — 核心库：`Block` / `Timeline` / `Cursor` / `_Generation`
- `fixtures.py` — 本地样本夹具（斜坡/正弦），声明延迟与数值容差
- `test_timeline.py` — unittest 套件（含独立逐样本参照对照）
- `demo.py` — 运行样例

## 模型与规则

- 有效起点 `effective_start = nominal_start + calibration_offset`；
  样本 `i` 覆盖半开区间 `[start + i/rate, start + (i+1)/rate)`。
- 采样率切换后按各块自身 `sample_rate` 换算，不沿用旧率。
- 重叠裁决：版本高者优先，同版本按 `block_id` 字典序（确定性）；
  样本按**中点归属**唯一认领，切片按时间不相交，边界查询不重复样本。
- 校准/增删块触发新 `_Generation` 完整构建后一次性换入（原子更新）；
  旧 `Cursor` 持有旧代快照，读取稳定。撤回块后被遮蔽样本自动恢复。
- 多级索引：一级为显式按时间排序的切片数组 + 二分（不假设插入/
  校准顺序时间单调），二级为切片内样本级换算；样本可越出拥有区间
  半个采样周期，二分留有安全余量。
- 声明：延迟 `DECLARED_LATENCY_S = 0.002s`（仅元数据，可经校准折入）；
  数值容差 `TIME_TOLERANCE = 1e-9s`（样本域按采样率缩放）。

## 运行

```sh
python3.11 demo.py                 # 运行样例
python3.11 -m unittest test_timeline -v   # 测试
```
