审计客户端只同步获准键区间，归档期间区间外的键和值都不能作为边界证据透露给它。为 Go 同步服务实现可导入的差分披露组件。键为48位无符号数，按高位到低位建固定高度的稀疏二叉树。空子树摘要按高度预定义，非空叶绑定键、长度、值和32字节盐，内部摘要绑定高度、前缀、左右摘要。签名清单把租户、版本、父清单和根绑定。请求持有旧清单和一个未经信任的局部节点缓存，要证明新清单中全部授权区间内哪些值新增、删除或改变；未变化的内容不能重复披露。租户可另给已撤回的子区间，回复连这些区间先前的键是否仍存在都不能透露，只许使用整子树摘要。证明在旧新两树间可共用相等且地址相同的子树，缓存节点也要经所引用清单和前缀认证后才可省略。验证者必须拒绝少报删除、在空树高度间挪用摘要和外部缓存冒充已认证节点，对区间外只返回不可解释的摘要。实现规范证明编码，同一对根、授权集合和已认证缓存只有一种最简节点序列；给出检查器验证必要性。用6位键的小树穷举差分、撤权和缓存子集，并在48位稀疏空间验证不展开所有键。
