# 剪辑软件需要让字幕跟随非匀速视频，而不是只给时间戳乘常数

剪辑软件需要让字幕跟随非匀速视频，而不是只给时间戳乘常数。写供Go字幕管线调用的重定时包，时间映射为按源时间排序的连续分段有理线性函数，可含静止段与反向段；每条字幕在目标时间轴返回所有可见半开区间，并保持原字幕ID和文本。重叠区间按目标起点再按源ID排序，零时长不显示。用有理端点的全区间参考验证倒放、停帧与同一字幕多次出现，所有计算禁止浮点累计漂移。

## API

`taskpkg` 提供目标时间到源时间的连续分段有理线性映射：

- `NewTimeMap([]Segment)` 校验时间轴连续、源时间连续且每段目标时长大于零。
- `Segment.SourceStart == Segment.SourceEnd` 表示停帧；`SourceEnd < SourceStart` 表示倒放。
- `TimeMap.VisibleIntervals(Subtitle)` 返回该字幕在目标轴上的最大半开可见区间。
- `TimeMap.RetimeAll([]Subtitle)` 返回按目标起点、再按源 ID（字符串字典序）排序的扁平字幕区间。
- `TimeMap.RetimeSubtitles([]Subtitle)` 按原字幕分组返回多个可见区间。

所有端点均使用 `*big.Rat`。`NewRat(n, d)` 可直接构造精确分数；内部投影使用端点间的精确有理运算，不经过浮点转换，也不做浮点累计。

倒放段的源区间映射到目标轴时端点包含方向相反，库按目标轴统一归一化为半开区间 `[start, end)`，并保留精确有理边界。相接或重叠的同一字幕区段会合并；不同字幕的重叠区段不会合并，最终按目标起点和源 ID 稳定排序。零时长字幕不产生结果。
