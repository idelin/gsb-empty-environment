# wireint — 有符号/无符号/任意精度整数线格式 + 流式 JSON 桥

纯 Go 标准库实现，无任何第三方依赖。

## 线格式（自描述、每值唯一规范编码）

| 编码 | 含义 |
|---|---|
| `0x00..0x7F` | 内联无符号值 0..127（单字节） |
| `1 VVV KKKK` + 负载 | 标签字段：VVV=协议版本(1/2)，KKKK=种类 |

种类：`0..3` = u8/u16/u32/u64（大端幅值），`4..7` = i8/i16/i32/i64（大端补码），
`8` = bigint（仅 V2）：uvarint 长度 + 符号字节(0x00/0x01) + 大端幅值（无前导零）。

**规范规则（解码强制）**：0..127 必须内联；其余值必须用能容纳它的最小种类
（更宽的有符号种类携带负数 = 非规范符号扩展，拒绝）；非负值用无符号种类；
bigint 仅用于超出 64 位的值，幅值不得有前导零，负零不存在。
字段自描述定界，拒绝非规范字段时不消费下一字段的字节。

## 多版本协议

- V1：仅定宽种类；V2：增加任意精度 bigint。
- 解码器用 `maxVersion` 钉死可接受的最高版本；V1 解码器拒绝 V2 标签。

## 支持的序列化范围（自定义）

- 定宽：u8/u16/u32/u64、i8/i16/i32/i64 全范围（最大 64 位无符号精确往返）。
- 任意精度：`|v| < 2^MaxBits`，`0 < MaxBits <= 32768`（幅值上限 4096 字节，
  长度前缀**先验证后分配**）。
- 负数永远不能进入无符号字段（`Field.Contains` 强制）。

## JSON 桥

- 整数以字符串标签 `"iw:<kind>:<decimal>"` 过 JSON，绝不经过 53 位浮点。
- 输入也接受原始 JSON 数字词法（`json.Number`，`UseNumber`）：先判断是否为整数
  （指数 vs 小数），再按字段位宽额度判断，**绝不先转宿主浮点**；
  `1e999999999` 之类按额度拒绝，不会物化天文数字。
- `Value` 三分离保存：`Raw`（原始词法）、`Int`（精确值）、`Field`（位宽约束）。
- 流式：`EncodeJSONStream` 逐元素写数组；`DecodeJSONStream` 基于 token 流式读。
- 解码只把字节解释为数字，不执行任何宿主代码。

## 运行

```sh
go test ./...    # 全部测试（穷举/极值/随机对照/非规范拒绝）
go run ./cmd/demo
```
