消息代理的紧凑日志按键保留最新值。给压实器交付可导入的 Go 包，输入是若干非活动段及其记录批，每批带事务标记：普通批、已提交事务批、已中止事务批和控制批，记录带偏移、键和可空的值。输出保留记录的原偏移序列和每段回收字节数。可清理范围止于最后稳定偏移，遇到未结束事务的批时把范围截到该批首偏移之前。范围内每个键只留最大偏移的一条；值为空的墓碑若偏移不小于删除保留水位则保留，否则一并丢弃；已中止事务的记录和控制批全部丢弃。段内记录字节数按各批头部声明的大小计。验收用朴素模型逐键对照保留集合，覆盖墓碑早于水位、墓碑之后又有新值、中止事务跨段、未结束事务截断和只含控制批的段；记录数可到十万，不得对每个键单独扫描整段。
