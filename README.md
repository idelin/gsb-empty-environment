# rms — 动态窗口均方根库

精确有理数算术（`math/big`）实现的滑动窗口 RMS 统计库。

## 特性

- **精确分数**：`MeanSquare()` 返回 `*big.Rat`，即平方和的精确分数 `sum(x^2)/n`，
  其中 `n` 为窗口内实际样本数（样本不足窗口长度时按实际数量归一化）。
- **平方根区间**：`SqrtInterval(prec)` 用定向舍入返回严格区间
  `lo <= sqrt(MeanSquare) <= hi`，`prec` 为尾数位数。
- **运行中改窗**：`SetWindow(n)` 在 `[1, MaxWindow()]` 内随时调整；
  缩窗后再扩窗会复用保留的历史。
- **有界历史**：历史最多保留 `MaxWindow()` 个样本，更老的样本被永久丢弃。
- **无溢出**：`float64` 样本先转成精确有理数再平方，
  `math.MaxFloat64`、最小非规格化数等极值都不会溢出或下溢。

## 用法

```go
w := rms.New(1024)        // 历史上限 1024 个样本
w.Add(1e308)              // 或 w.AddAll(xs...) / w.AddRat(r)
w.SetWindow(256)          // 运行中改变窗口长度
ms := w.MeanSquare()      // 精确分数 *big.Rat（空窗口返回 nil）
lo, hi, ok := w.SqrtInterval(128) // sqrt(ms) 的严格上下界
```

## 验证

`go test ./...` 覆盖：

- 极值平方溢出/下溢（`MaxFloat64`、`5e-324` 等与朴素 `float64` 对比）；
- 缩窗、扩窗及扩窗后历史复用、淘汰样本不复活；
- 分块边界：同一序列按 1/3/7/16/17/... 不同块长喂入结果完全一致；
- 环形缓冲回绕 + 随机改窗的 3000 步对照测试（与朴素参考实现逐步比对）；
- 平方根区间严格包含真值（`lo^2 <= ms <= hi^2` 精确校验），精度越高区间越窄。
