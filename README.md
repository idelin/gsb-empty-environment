设备网关要在轮换会话密钥时把已验证的数据流迁给新接收器。给Go协议宿主写可导入的重放窗口交接库。线上的序号只有低b位，b取4至32；完整序号来自设备签过名的检查点和有限乱序界，窗口按密钥代与设备持久身份划分。多个节点在失联期间可各自收到不同的认证回执，迁移材料只有低位序列、每节点的先后约束及少量带完整序号的锚点。对待接收帧，只有在全部相容的完整序号分配下都在窗口内且从未获准时才可接收；全部为旧帧则拒绝，其余返回需补哪个锚点。不能任取最接近的高位。给出两种相反结论的完整赋值以证明歧义；状态冲突单列。接收和登记须原子化，无效认证不产生状态。用小位宽全赋值解释器验证两次回绕、半窗口边界、节点观察顺序互不相同、密钥并行交接及同帧并发到达。
