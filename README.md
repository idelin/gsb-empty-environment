Wasm/沙箱运行时在回收线性内存碎片时，部分对象正被异步宿主 I/O 引用而被钉住（pinned），不可移动；其余存活对象需向低地址滑动压缩以收缩尾部页数，且必须满足各自对齐要求（8/16/64 字节）并精确重定位全部内部指针。为运行时内存管理器交付可嵌入的 C++20 压缩组件。输入线性内存总字节数（页大小 64KB 的整数倍）、全部对象描述符（对象 ID、当前偏移、长度、对齐要求、是否存活、是否 pinned，以及对象内部偏移处指向其他对象基址+字段偏移的指针表）和外部根指针列表。规则：所有 pinned 存活对象原地不动，死亡对象空间全部回收；其余存活对象按原地址升序依次迁往不高于原地址的最低对齐空闲位置（允许跨过 pinned 块填入其前后的空闲缝隙，且不得与任何 pinned 块或已安置对象重叠）；迁完后更新全部外部根与对象内部指针（保持原字段内偏移不变），并计算新堆顶向上取整到 64KB 页边界后可归还操作系统的尾部空闲页数；同时输出安全原地字节搬移序列（因只向低地址滑动须确保读源前不被覆盖，若存在跨 pinned 间隙重排导致依赖则给出无覆盖拷贝顺序）。验收用真实字节缓冲写入标记模式执行完整压缩与指针解引用核对，覆盖大对齐对象跳过小缝隙、小对象回填 pinned 块前空洞、对象内部含自指针与交叉指针重定位，以及尾部 pinned 块阻止页收缩。
