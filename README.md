# flowshop

两机阻塞流水车间（blocking flow shop）精确求解库：

- 每件工件先过机器一、再过机器二，两机采用相同顺序（置换调度）。
- 中间缓冲容量为零：工件在机器一上加工完毕后若机器二仍忙，则占住机器一（阻塞）。
- 支持已知、有限的机器停机表；正在加工的工件可暂停但占住机器，恢复后继续。
- 最多 10 件工件，全排列枚举保证最优；最优解并列时按工件 id 字典序取最小序列。
- 输出完整的阻塞时段与停机证据，并提供独立的离散事件模拟交叉核对。

## 接口

- `Solve(jobs, down1, down2)`：全排列求最短完工序列，返回 `Result{Sequence, Schedule}`。
- `Replan(prefix, remaining, down1, down2)`：已开工前缀保持原顺序原时刻，仅对剩余工件重新优化；返回覆盖全程的阻塞与停机证据。
- `Verify(seq, down1, down2)`：用离散事件模拟核对递推模型（完工时间、时间线、阻塞、停机证据逐项一致）。

`Schedule` 内含 `Timeline`（每件工件进出两台机器的时刻）、`Blocking`（阻塞时段）、
`Downtime`（停机导致的暂停证据）与 `Makespan`。

## 测试

```sh
go test ./...        # 含 10 工件全排列（3,628,800 种）精确求解
go test -short ./... # 跳过 10 工件测试
```

测试用手工算例核对阻塞/停机语义，并在随机算例的全部排列上断言递推模型与
事件模拟完全一致，同时用事件模拟暴力枚举独立验证 `Solve`/`Replan` 的最优值
与并列取舍规则。
