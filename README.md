# 默克尔锚定器（带时间戳与防重放签名）

外部存证锚定组件。定时将本地系统的默克尔根哈希与当前时间戳打包签名；
支持出示带时间戳证明的存证证书，证明特定数据在特定历史时间点之前已经确定存在。

## 结构

- `merkle.go` — 默克尔树构建、包含证明生成与验证（SHA-256，叶/节点域分离）
- `anchor.go` — 锚定器与验证方：ECDSA P-256 签名，载荷为
  `domain || seq || timestamp || prevAnchorHash || merkleRoot`，序号 + 哈希链防重放
- `certificate.go` — 存证证书（审计凭据）的签发与验证
- `anchor_test.go` — 全部测试（`go test`）
- `cmd/demo/main.go` — 端到端运行样例

## 运行

```sh
go test -v .        # 测试
go run ./cmd/demo   # 演示
```

## 安全性质

- **存在性证明**：证书中的默克尔路径重算出的根必须等于被锚定的根，
  且锚定时间戳 ≤ 声明时刻，即数据在该时刻前已入库固定。
- **不可篡改**：锚定记录带 ECDSA 签名，事后修改数据、根或时间戳都会使验证失败。
- **防重放**：锚定序号严格递增 + 前向哈希链，验证方拒绝重复、乱序、断链的锚定。
