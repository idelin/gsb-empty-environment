站点采用每响应独立的 CSP 授权，拼装时既有服务端片段也有缓存片段。给 TypeScript 渲染宿主实现可导入的片段合成器：授权由宿主生成，绑定响应 ID、片段树位置、脚本内容承诺、可继承的子脚本来源与可信脚本根，不能把旧响应的 nonce 直接带入新页。片段树允许跨页重用同一节点，脚本加载规则形成有环的有向图，strict-dynamic 下只有受信根实际发起的加载链可放行，单靠主机名命中不足。合成多个独立策略时按各自完整判定求交，不能先分别把来源集合求并。对给定目标脚本输出精确允许条件和最短授权链；发布一份共享片段缓存时，另给所有可接受渲染配置的证书，表明任何内容承诺变化都将令相应授权失效。配置开关由固定序 BDD 输入，按符号条件计算可达性，不能枚举开关取值。以小配置逐页构造和图遍历作参考，核对两个策略各自存在链却没有共同执行配置、共享片段两处不同继承、撤销可信根后孤立的环、同主机不同脚本字节和 nonce 未发布时取消。
