# trainsim — 列车轨段占用仿真库

Go 仿真库：列车沿给定路径申请轨段的半开占用区间，支持扰动后的重规划与独立核对。

## 占用模型

- 占用为半开区间 `[start, end)`：同刻释放后进入不冲突；任何重叠（含同向）都禁止。
- 相邻轨段占用首尾相接；等待只允许发生在车站轨段（表现为延长该段占用）。
- 路径申请原子确认：全量预约成功才写入，失败不留部分预约（`Table.Reserve`）。
- `Scheduler.PlanPath` 为单车计算最早可行方案（带备忘录的递归搜索，有限时间域）。

## 重规划

- 方案被切成已承诺前缀（已进入轨段，绝不移动）与可调整后缀；
  正停在车站的列车可延长停站，延误列车可延长当前轨段占用至 `ReadyAt`。
- `Replan` 枚举"包含延误车的子集 × 放置次序"，目标字典序：
  先最少受改列车数，再最小总延误；最多 4 车、有限时间域。

## 核对

- `Table.Verify` / `Replay`：逐轨段区间扫描，回放占用核对交会、取消、
  同刻释放后进入与连锁冲突。
- `BruteForceReplan`：独立枚举每车全部合法后缀方案与所有子集组合，
  交叉核对 `Replan` 的目标值（测试中使用）。
