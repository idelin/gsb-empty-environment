# 多设备列表分叉隐藏恶意设备

消息服务可向同一账号的不同联系人返回不同设备列表，把攻击者设备只展示给部分会话。给Go客户端实现可导入的设备列表一致性包：账号状态含accountID、单调listVersion、按deviceID排序的设备项(deviceID、身份公钥、添加版本、可选移除版本)和前一列表摘要；账户主密钥Ed25519签名覆盖完整规范列表、版本和前摘要。服务同时提供透明日志检查点与该列表叶的存在证明，证明回调由宿主注入；客户端保存最高版本/摘要和最近检查点，新版本必须恰为旧版本加一，前摘要必须等于已保存值，设备项不能在未移除时换公钥或复用deviceID。联系人之间可交换带签名的观察回执(accountID,version,listDigest,checkpointDigest)；同版本异摘要或同一旧检查点下互斥证明形成可导出的分叉证据并冻结新会话，较旧观察只记陈旧。新增设备在完成主密钥签名列表和日志证明前不能接收消息，移除后相应会话立即停止新发送。实现恶意目录给两个客户端分叉列表、延迟日志证明和回滚检查点，测试设备隐藏、remove后重加同ID、版本跳跃、联系人回执乱序及合法轮换。
