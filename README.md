复制数据库合并一个并行执行的小批次时，每个事务只带读集结果和拟写入的键，不能靠没有写写冲突就放行。实现事务协调器可导入的 Go 串行提交包。输入有限初始键值映射、最多 18 个事务及必须先提交的 DAG。事务先观察当时数据库：点读区分缺失与空值，区间读给出完整按字节序排列的键值列表，空列表也约束幻读；随后按输入顺序原子应用本事务的一串 put/delete。键和值为任意字节串，区间半开、可无界。另有可选的事务对邻接费：若 u 后面紧邻 v 则收该有向费用。找出能解释全部观察的最低总费用串行提交顺序；还须返回全部同价最优顺序的精确数量，支持按事务编号字典序对最优顺序反选并通过宿主提交回调实际执行。无解与排名越界分开。不能仅凭已提交事务集合合并状态：同一集合可能留下不同最后写入者，也可能得到完全相同内容却有不同末事务和费用。不得枚举所有排列；可按经核证相等的数据库内容、提交集合和必要上下文合并，不允许只用有碰撞风险的哈希判断相等。互不影响的 18 笔空写事务、费为零时应能反选最后一个排名。小规模用不复用产品读集判定逻辑的全排列参照核对计数及最优顺序；覆盖空值与删除、区间边界上的插入、暂时出现又消失的幻读、同一写集不同写者和总代价超 uint64。
