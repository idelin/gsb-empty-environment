逻辑复制接收端按表分流，多个表可独立推进；同一读事务在开启时固定一份整库发布视图。接收端需要可导入的 Go 切换计划包和真实调用它的发布器适配层。每张表给出初版及一至四个按序替换的不可变版本，版本列出完整主键行和外键值，单表版本内主键唯一；全初版与全末版均保证满足外键。一次屏障为每个表选择不早于当前的目标版本；至少一张表前进。两屏障间，任一表可独立从当前版逐版推进到目标版，任何时刻都可能开启读事务，因此两端之间每一种版本组合都必须满足跨表外键（含自引用、复合键，任一外键分量为空即免检）。到达目标后发布器等全表确认才能开启下段，不允许拿同一读事务混用不同时刻的表指针。求从全初版到全末版的最少屏障次数；同次数时使沿计划的峰值驻留字节最小：每段须同时保留各表从起点到终点含两端的所有版本，输入给的是不可变页标识及页字节数，同一段跨表或跨版本引用同页只计一次，相邻段不叠算。无解要能指出一个无法越过的前沿：可安全到达的极大版本向量（按逐分量偏序），并给出其每个单表下一版的具体外键反例。最多八张表、全部版本向量总数不超六千。提供发布器用的屏障序列和独立回放：小例逐组合验每个屏障、穷举比较两级最优值，展示端点都合法却有中间混版孤儿、两个独立表同时换到新键并不能骗过旧读者，以及两个最短计划因共享页而有不同峰值。
