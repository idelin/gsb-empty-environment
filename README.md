# 租约控制器(Lease Controller)

支持**动态续期**与**平滑优雅移交(Handover)**的租约控制器,纯 Go 标准库实现。

## 设计

- `lease.Coordinator` 协调中心:租约授予、动态续期、写入 fencing 校验、主动移交仲裁。
- `lease.Node` 集群节点:持有租约后以 `剩余TTL/3` 的动态间隔续期;收到停机指令时
  冻结本地写入,通过协调中心把租约凭证(剩余 TTL + 业务上下文 + 递增 fencing token)
  打包交给候选节点。
- 移交在协调中心内原子提交,旧持有者的续期与写入立即被 fencing token 拒绝;
  候选人收到交接包后立即接管主角色并继续动态续期,无需等待自然超时。

## 运行样例

```sh
go run ./cmd/demo
```

输出(切换耗时为微秒级,远低于毫秒上限,全过程零写入错误):

```
[启动] A 获取租约 order-service, 成为主节点
[运行] A 动态续期保活中, 已处理写入 407109 次
[重启] A 收到滚动重启指令, 冻结写入并请求向 B 移交
[移交] B 收到交接包并无缝接管主角色, 切换耗时 17.583µs (墙钟 17.834µs)
[完成] 当前主节点: B, fencing token: 2,  继承上下文: map[offset:1024 shard:7]
[统计] 总写入 746448 次, 错误 0 次 (零错误中断)
```

## 测试

```sh
go test ./lease/ -v
```

覆盖:动态续期保活、优雅移交(上下文/剩余 TTL 继承、毫秒级切换)、
移交全程零写入错误、旧持有者 fencing 拒绝、候选人不存在时解冻回退、自然过期重获取。
