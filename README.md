# 时间命名空间偏移写入校验

时间命名空间让容器看到偏移后的 CLOCK_MONOTONIC 与 CLOCK_BOOTTIME，偏移只能在命名空间里第一个进程创建前通过 /proc/PID/timens_offsets 写入。攻击者想事后改偏移、写出负的单调时间或溢出值，把依赖这些时钟的租约、令牌过期判断推到异常状态。为 Go 容器运行时写供写入 timens_offsets 前调用的偏移校验包：每行为时钟名、秒、纳秒，只允许 monotonic 与 boottime；命名空间内已有进程后拒绝写入；纳秒须在 0 到 999999999；偏移后容器内的 monotonic 不能为负，加上宿主读数溢出 int64 拒绝；调用者须有 CAP_SYS_TIME；同一时钟重复出现按最后一行为准并提示。再提供宿主读数到容器读数的换算函数，溢出时返回错误。用已有进程后写入、纳秒越界、负单调值、溢出和 realtime 行验证。
