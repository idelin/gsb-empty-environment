给流处理运行时交付可导入的 Go 包，离线验证分布式检查点是否对应某个一致切面。每个算子有有序的输入消费、状态更新、输出和 barrier 事件，多输入有独立通道序号；反馈边不要求无环，其未消费消息必须进入通道快照。部分算子的可选切点只给区间；逐通道给 FIFO 投递记录，快照可用若干连续序号段表示。求总未消费字节数最小的可行切面，平局按算子 ID 的切点向量；不可行时返回由事件先后和消息依赖构成的可回放冲突链。不能把所有切点做笛卡尔积，事件可达十万。要能核验输出切面并恢复每条通道上的确切未消费序列。小图穷举核对，包含自反馈、一发多路不同消费进度、零字节 barrier、只看各通道局部均合法但无法拼成公共切面的情况。
