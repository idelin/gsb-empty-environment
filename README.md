机密计算宿主机在审计 Intel TDX（Trust Domain Extensions）的物理地址元数据表（PAMT：`PT_NDA`/`PT_REG`/`PT_TDR`/`PT_TDCS`/`PT_EPT`）、安全扩展页表（Secure EPT，含 `SEPT_PENDING`/`SEPT_MAPPED`/`SEPT_BLOCKED` 状态）以及 `TDVMCALL` 共享内存边界时，若宿主机 VMM 在 `TDH.MEM.PAGE.REMOVE` 后未通过 `TDH.MEM.TRACK` 完成全核 TLB 刷新就重分配该物理页、允许将同一 HPA 同时映射至两个不同 TD 的 Secure EPT，或 TD 客体在 `TDVMCALL` 中将私有 GPA（Shared Bit=0）直接暴露给非可信 VMM，恶意宿主机可发动跨 TD 内存别名窃听或 TLB 残留重放。为 C++17 机密计算审计宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 Intel TDX PAMT / SEPT / TDVMCALL 状态机符号验证库。库建模多 TD 隔离域、物理页 PAMT 元数据（类型、归属 `owner_tdr`、页粒度 4KB/2MB）、各 TD 的 Secure EPT 与 Shared EPT、全局 Epoch/TLB 追踪状态以及 `PAGE.ADD`/`PAGE.AUG`/`PAGE.ACCEPT`/`SEPT.BLOCK`/`MEM.TRACK`/`PAGE.REMOVE`/`TDVMCALL` 操作流：（1）维护 PAMT 唯一归属不变式，硬拒绝任意 HPA 双重归属不同 TD、跨 TD 别名映射或未清零（`scrubbed=false`）的页被重用；（2）严格校验 `SEPT_BLOCKED -> TDH.MEM.TRACK -> PAGE.REMOVE` 顺序与全 vCPU 退出跟踪屏障，拦截未完成 TLB 追踪即移除/回收页的竞态漏洞，以及对 `SEPT_PENDING` 未经客体 `TDG.MEM.PAGE.ACCEPT` 即允许读写的违例；（3）审计 `TDVMCALL` 缓冲参数，硬拒绝任何 Shared Bit=0 私有 GPA 或跨私有/共享边界的缓冲区间交给 VMM。附未 `MEM.TRACK` 回收竞态、跨 TD 别名映射、未 `ACCEPT` 访问与 `TDVMCALL` 私有页泄漏测试。
