向量执行器的 selection vector 经多次过滤、字典展开、稳定分组和局部 top-k 后，诊断器要从结果位置反推源批、原行号和每次重排的秩。请为诊断器交付可导入的 Go 包。输入用排序游程表示，各操作带显式空值排序规则；分组是按首次出现次序而非键序，同键排序保持输入先后。请求还可反向指定源行区间，枚举最终输出中所有重复出现的位置，以可跳跃序列表示。要求提供可检查的可逆映射摘要，删除某个阶段的摘要后如仍能无歧义恢复就不保留它；在给定候选集内先最少保留字节再最少查询访页次数。逻辑展开可达 2^52，最多十二个摘要，不能物化全部位置。小输入用附带真实来源标签的逐行解释器核对，测同一源行在字典多次出现、NULL 参与第一次分组与截断 ties 的组合。
