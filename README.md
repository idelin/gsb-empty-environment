租户迁移广播树时会留下两代设备密钥和有限的桥接能力。给 TypeScript 广播宿主写可导入的头部验收包。每个封装组绑定永久租户、内容代次和符号化的设备区间，设备可以同时保留若干旧能力。桥接声明经签名后只允许指定区间、用途及代次的旧能力参与本轮，不能用名称或单一成员关系替代。消息可能要求同时持有两份不同来源的部分封装才能打开；同一物理设备的两个别名不能算作两个独立来源。判断每一类合法设备是否都能读取、任一容许串通的被撤销设备组是否会新增读取权，仅返回授权类和风险判定，不输出秘密或恢复操作。48位编号区间中有稀疏例外，不能枚举所有设备。输出分区与证书供独立验收函数重算，用小设备域穷举正常读取范围及撤销方联合能力，覆盖同样区间不同密钥代次、局部迁移、未获签的桥接和边界刚好被撤销的一台设备。
