# Gemini请求读取与走私防护

Gemini 请求是一行以 CRLF 结尾的绝对 URL，攻击者可在同一 TLS 连接里追加第二个请求，用裸换行、超长行或 userinfo 绕过前置代理的过滤。给Go Gemini 服务写供连接处理循环调用的请求读取包：最多读取 1026 字节，URL 不超过 1024 字节，必须以 CRLF 结尾，裸 LF 或缺 CR 回 59；scheme 非 gemini、含 userinfo 或含 fragment 回 59；主机与端口（默认 1965）不等于本服务配置回 53；路径规范化点段，对 %2e、%2f 解码后的穿越按路径穿越拒绝；每个连接只处理第一个请求，CRLF 之后读到的任何字节都丢弃，不当作下一个请求。用任意切分的分片读取、CRLF 后追加请求、%2e%2e 与超长行验证。
