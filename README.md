# ISO-TP连续帧重组防护

CAN 网关用 ISO-TP 重组多帧消息，攻击者发来声称极长的首帧、重复或乱序的连续帧，耗尽缓冲或拼出伪造载荷。为C++网关写可导入的 ISO 15765-2 重组包（11 位标识、普通寻址），供 CAN 接收回调调用：首帧高半字节为 1，12 位长度；长度为 0 时随后 4 字节为 32 位长度，且该值必须大于 4095，否则拒绝；长度超过调用方给的缓冲上限则拒绝并回送溢出流控；连续帧序号 SN 从 1 起，到 15 后回到 0；序号不等于期望值则丢弃整个重组；未收到首帧的连续帧忽略；重组进行中又收到首帧则放弃旧重组，从新首帧开始；单帧长度字段须在 1 到 7 之间；超过 N_Cr 超时（调用方时钟）丢弃。用 32 位长度逃逸取小值、SN 回绕、乱序、孤立连续帧和超时验证。
