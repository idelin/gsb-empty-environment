共享索引给编辑端返回前缀建议。用户只有权读部分文档，即使结果列表没包含私有词，排名、并列顺序与分页令牌也可能泄露隐藏文档的存在。给 TypeScript 搜索宿主写可导入的建议准入和排名组件。每篇文档有稳定对象身份、所有者签出的访问标签、版本化分词表和段落来源。一个用户的词频、文档频率、邻接词和首次出现次序必须从同一授权快照中的可见段落产生，复制同一来源段落不能重复贡献独立文档数。词典支持合并旧词与拆成多个新词，映射精确到原位置，不能仅按当前拼写合并不同权限来源；旧分页续页只许重用经证明可见贡献未变的排名。更新允许批量撤权、换词典与移动段落，延迟的索引回执不得恢复旧可见性。输出 top-k、仅含可见来源的说明和绑定授权的续页凭据；同一用户在两份只改变隐藏文档的索引中应得到相同的可见结果、排序、说明和续页类别。用独立的逐段重建器核对持续更新后的结果，覆盖旧词映射重叠、文档别名、部分撤权、并列时序和一个批次先公开后又撤回。
