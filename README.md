# 对称稀疏正定矩阵：确定性最小度排序 + 可增量更新的符号 Cholesky 分析器

纯 Python 3.11 标准库实现，不调用任何现成稀疏分解/排序库。输入为全部对角位置
（隐含，`n` 个顶点）加无向结构边；重复边自动合并；不涉及数值主元交换。

## 模块

- `symchol/mindeg.py` — 第一阶段：隐式商图上的确定性精确最小度排序。
- `symchol/incremental.py` — 第二阶段：固定置换下可增量更新的符号 Cholesky
  分析器（L 模式 + 消元树 + 来源追溯 + 原子事务 + 可重放日志）。
- `symchol/oracle.py` — 独立小图 oracle：显式消元图、每次完整重算，
  不复用商图/依赖缓存/来源代码，仅供对拍。
- `tests/test_symchol.py` — unittest 套件（15 个用例）。

## 第一阶段：最小度排序（商图）

### 表示

- 变量 `v`：`adj_var[v]`（直连活变量）与 `adj_el[v]`（相邻元素）；
- 元素 `e`（已消元顶点）：`el_adj[e]`（覆盖的活变量），表示一个未展开的团。
- 精确度数：`deg(v) = | adj_var[v] ∪ (⋃_{e∈adj_el[v]} el_adj[e]) \ {v} |`，
  多个元素覆盖同一邻居时由集合并自然去重，**绝不用元素大小求和**。
- 吸收：新元素产生后，任何满足 `el_adj[e] ⊆ el_adj[new]` 的冗余元素被删除。
- 惰性堆：键 `(degree, id)` 保证并列取最小原始 ID；每次出堆都重算精确度数，
  过期键修正重推或丢弃，因此选择与显式图参考算法逐步一致。

### 正确性不变量

1. 商图与显式消元图表示同一邻接关系：`u,w` 相邻 ⟺ 直连或共享元素。
2. 每步选出的 `(degree, id)` 是全体活顶点中的字典序最小者（出堆验证保证）。
3. 填充边 = 当前步活跃邻居中尚不相邻的对；只统计原始结构不存在的非对角边，
   每对只计一次（`fill_edges` 集合判重）。
4. 第 `k` 步活跃邻居集合 = L 第 `k` 列对角线下非零行（置换后位次）。

### 复杂度

- 每步精确度数计算为 `O(|adj_var[v]| + Σ|el_adj[e]|)`；全部消元总时间
  `O(Σ_v τ_v)`，其中 `τ_v` 为 v 被访问时的邻接规模，上界 `O(n · α)`，
  `α` 为最大元素规模；堆操作 `O((n + 失效键数) log n)`。
- 内部商图内存 `O(Σ|el_adj[e]| + Σ|adj_var[v]|)`（峰值由
  `memory_report()["internal_quotient_peak"]` 报告）；最终产物内存
  `O(nnz(L))`，与内部结构分离报告（`output_l_nonzeros` 等）。

## 第二阶段：增量符号分析（固定置换）

### 数学模型与来源追溯

L 的非对角位置是如下闭包的最小闭集（位次行列，行 > 列）：

- (E) 原始边 `{u,v}` ⇒ 位置 `(max(pos), min(pos))`；
- (F) `(r1,c),(r2,c) ∈ L` ⇒ `(max, min) ∈ L`（第 c 列后邻居补团）。

每个位置维护 `support` 集合：`("e",u,v)`（原始边直接支撑）与
`("f",k)`（第 k 列填充支撑，有效 ⟺ `(r,k)`、`(c,k)` 当前都在 L 中）。
位置存在 ⟺ support 非空。删除一条原始边只移除其来源；只要仍有其它路径
（别的边或某列填充）支撑，位置保留。

### 不变量

1. `support[(r,c)]` 非空 ⟺ `r ∈ rows[c]`（位置存在）。
2. `("f",k) ∈ support[(r,c)]` ⟺ `r ∈ rows[k]` 且 `c ∈ rows[k]`。
3. `("e",u,v) ∈ support[(r,c)]` ⟺ 边 `{u,v}` 当前存在且映射到 `(r,c)`。
4. 由于填充来源的列下标严格减小，支撑关系无环，删除级联收敛到
   “剩余边的最小闭集”，与完整重算一致（对拍验证）。
5. 消元树 `parent[c] = min rows[c]`，仅依赖本列，故只需重算被访问列。

### 工作队列传播

- 新增位置 `(a,b)`：与列 `b` 当前所有行配对，产生/补充 `("f",b)` 来源并入队。
- 删除位置 `(a,b)`：与列 `b` 的 *当前行 ∪ 本次级联已删行* 配对，移除
  `("f",b)` 来源；来源清空的位置级联删除。（同列多位置同一级联相继删除时，
  只看当前行会漏清已删行之间的配对来源，必须并上已删集合。）
- 只访问受影响列；每次 `update` 返回 `visited_columns`、
  `added_positions`、`removed_positions`、`etree_updates`。
- 最坏情况（如路径图加首尾边）影响沿消元树链传到根，退化为 Θ(n) 列，
统计如实报告；局部修改（另一连通块）访问计数严格局部。

### 事务与快照

- `update(add, delete)` 先整批校验（自环、增删冲突、删除不存在的边），
  再应用；任何异常完整回滚，已提交的日志与状态不变。
- `snapshot()` 返回深拷贝只读快照，后续修改不影响旧快照的模式与消元树。
- `reorder()` 是独立显式操作：重跑最小度并整体重建；固定置换的增量更新
  绝不改变顺序。

### 复杂度

- 设某次更新实际访问列集合为 `V`，这些列的行总数为 `R`。增删传播时间为
  `O(Σ_{c∈V} |rows[c]|)` 级别（每对来源操作 O(1) 均摊），即与受影响区域
  成正比，而非每次整图符号分解；消元树只重算 `|V|` 列。
- 空间：`O(nnz(L) + 来源数)`；来源数 ≤ 原始边数 + Σ_c C(|rows[c]|, 2) 中
  实际产生的不同 `(位置, 列)` 对数。

### 可重放更新日志

`ana.log` 是 JSON 可序列化记录序列：`init`/`reorder`（全量边与置换）与
`update`（增删边 + 实际访问列 + 重算条目 + 消元树更新）。
`IncrementalSymbolicCholesky.replay(n, log)` 从零确定性重建相同状态。

示例（路径图加边再删边后重排序）：

```json
[{"seq": 0, "type": "init", "edges": [[0,1],[1,2],[2,3],[3,4]], "perm": [0,1,2,3,4]},
 {"seq": 1, "type": "update", "add": [[0,4]], "delete": [],
  "visited_columns": [0,1,2], "added_positions": [[4,0],[4,1],[4,2]],
  "removed_positions": [], "etree_updates": []},
 {"seq": 2, "type": "update", "add": [], "delete": [[1,2]],
  "visited_columns": [1,2], "added_positions": [],
  "removed_positions": [[2,1],[4,2]], "etree_updates": [[1,4]]},
 {"seq": 3, "type": "reorder", "edges": [[0,1],[0,4],[2,3],[3,4]], "perm": [1,0,2,3,4]}]
```
