# negsp — 负边权多源最短路工具

读取有向带权图（允许负边、平行边、自环），对每个源点报告每个目标的三种状态：

- `dist=D path=...`：有限最短路及路径
- `unreachable`：源点不可达
- `-inf`：受负环影响（距离无下界），并输出证据：简单负环 + 源点到环的路径 + 环到目标的路径

负环判定是逐 (源, 目标) 精确的：只有**从该源可达、且能到达该目标**的负环才会报告
`-inf`；图中其他位置的负环（断开分量、或到不了目标的环）不会污染结果。

## 输入格式

每行一条边：`u v w`（w 为整数），`#` 开头为注释。节点名为任意字符串。

## 用法

```sh
go build -o negsp .
./negsp -f graph.txt -s A,B     # 指定源点
./negsp -f graph.txt -all       # 所有节点作为源点
./negsp -f graph.txt -all -verify   # 附带暴力枚举交叉核对（小图）
cat graph.txt | ./negsp -s A
```

## 算法

- 每源点 Bellman-Ford：n-1 轮松弛得最短路；第 n 轮仍被松弛的节点标记为
  dirty，从 dirty 沿图 BFS 得到的集合恰好是"距离为 -inf"的节点集。
- 证据提取：从某个能到达目标的 dirty 节点沿前驱指针走 n 步必入环，回溯得到
  简单负环；环必可从源到达（前驱链性质）且能到达目标。连接路径用 BFS 给出。
- 若前驱提取失败（防御性），回退到简单环枚举找证据。

## 核对（测试与 -verify）

`brute.go` 提供两个独立实现用于对拍：

- 枚举所有简单环（按边区分平行边）+ 枚举所有简单路径，直接按定义判定三种状态；
- 有限步 DP：`dp[k][v]` = 至多 k 条边的最短游走。判据：存在 u 使
  `dp[2n][u] < dp[n][u]` 且 u 可达目标 ⟺ 目标受负环影响；否则 `dp[n-1][t]`
  即为有限距离。

`sp_test.go` 覆盖零环、平行边（含平行边构成的负环）、断开负环、自环、
源=目标，以及 400 组随机图的三方式对拍（Bellman-Ford vs 枚举 vs DP），
并校验证据结构（环简单且权为负、连接路径端点与边存在）。
