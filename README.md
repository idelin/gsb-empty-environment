# seqrank：序贯秩和检验的精确随机化推断

按给定时间顺序观测两组实验（总样本量 ≤ 24），随机分组保持最终组大小
`N1`/`N2`，且所有前缀共享同一份最终分配。本库对每个指定查看时刻
（前缀长度）用**该前缀内**的合并平均秩计算秩和统计量，并在所有
`C(N1+N2, N1)` 种最终分配上精确枚举，给出首次越界时间的精确分布。

## 模型约定

- **统计量**：前缀 `p` 内组 1 秩和 `R`，期望 `E = m1·(p+1)/2`
  （`m1` 为前缀内组 1 样本数），取 `|R − E| / Scale`，其中 `Scale`
  为输入的有理标准化因子（每个查看时刻可不同）。
- **越界判定**：双侧，`|R − E| / Scale ≥ Threshold` 即越界，
  **相等计越界**。
- **停止规则**：任一指定查看时刻达到门限即停止，首次越界时刻即
  停止时刻。
- **空组不查看**：某前缀内任一组样本数为 0 时，该时刻不查看。
- **重复值**：等值样本共享平均秩，但按样本身份仍是不同个体，
  枚举时各占一种分配（不因等值合并）。
- **精确概率**：曾越界概率来自共享同一最终分配的联合枚举，
  **不**把各次查看的 p 值当作独立相乘。
- **状态预算**：`Budget` 限制枚举的分配数；超预算时保留已枚举的
  部分计数并标记 `Complete=false`，此时概率接口返回 `nil`，
  部分枚举不得当作精确概率。

## 用法

```go
spec := seqrank.Spec{
    Values: []float64{1.2, 0.7, 3.1, 2.2, 0.4, 1.9}, // 观测时间顺序
    N1:     3, N2: 3,                                 // 最终组大小
    Looks: []seqrank.Look{
        {Prefix: 4, Scale: seqrank.Rat(2, 1), Threshold: seqrank.Rat(3, 2)},
        {Prefix: 6, Scale: seqrank.Rat(3, 1), Threshold: seqrank.Rat(3, 2)},
    },
}
res, _ := seqrank.Enumerate(spec)
// res.FirstCross[i]：首次越界发生在第 i 个查看时刻的分配数
// res.Never：从未越界的分配数；res.CrossProbability()：精确曾越界概率
// res.FirstCrossingDistribution()：首次越界时间分布 + 末位未越界质量

// 观测到的实际分配的停止时刻：
lookIdx, crossed, _ := seqrank.StoppingTime(values, group1Labels, looks)
```

## 精确性说明

- 平均秩的二倍恒为整数（并列块平均秩 `(i+j+2)/2`），因此秩和与
  期望都以整数二倍值累计，与有理数 `2·Scale·Threshold` 一次性
  比较，全程 `math/big` 精确有理运算，无浮点误差。
- 枚举用 Gosper's hack 遍历全部 `C(N1+N2, N1)` 个分配掩码，
  每个分配独立地逐前缀重算统计量。
- 最坏情形 `C(24,12) ≈ 2.7×10^6`，单次数秒级（Apple M1 Pro 上
  3 个查看时刻约 1 秒）。
