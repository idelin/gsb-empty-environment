浏览器收到预检通过后可能跨网络接口迁移，授权时观察到的网络区域不一定还是实际发送时的区域。为Go网络宿主写可导入的预检证明缓存。有效决定须同时绑定请求主体、目标资源身份、动作和头集合、凭据模式，以及解析、代理、传输三个阶段的地址空间证明，各证明由不同权威签发并有独立失效事件。路由配置以分流和有条件代理图表达；某个目的名可走多条路径，可复用缓存当且仅当新请求所有可行路径都受原预检明确覆盖。条件之间有宿主给出的互斥约束，不得把互斥的两段拼成一条路径，也不能因首选路径仍公开就忽略可用私网路径。返回可复查的覆盖证书，失效时给最少须重新取得的证明种类及一条未覆盖条件。用小配置全枚举验证代理重选、缓存按较窄头集合复用、域名不变而连接代次变更和网卡切换时并发命中。
