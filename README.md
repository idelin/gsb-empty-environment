# 统一列级 k-匿名泛化工具

在有限层级属性上搜索**统一列级**泛化方案：每列选定一个层级后作用于所有行
（不逐行变化），使每个最终等价组合至少包含 `k` 条记录（默认 `k=3`），
并保证**总泛化损失最小**。

## 运行

环境自带 Node.js（>= 22.6，原生支持 TypeScript 类型擦除）即可，无需安装依赖：

```bash
node src/cli.ts examples/sample.json          # 使用文件中的 k（默认 3）
node src/cli.ts examples/sample.json --k 4    # 命令行覆盖 k
node --test 'test/*.test.ts'                  # 运行测试
```

## 输入格式（JSON）

```json
{
  "k": 3,
  "columns": ["age", "zip"],
  "hierarchies": {
    "age": { "levels": [ {"21": "20-29", ...}, {"20-29": "青年", ...} ] },
    "zip": { "levels": [ {"10001": "1000*", ...} ] }
  },
  "rows": [ {"age": 21, "zip": "10001"}, ... ]
}
```

- `levels[i]` 把第 `i` 层的取值映射为第 `i+1` 层的取值；`levels[0]` 作用于原始值。
- `levels` 为空数组表示该列不允许泛化。

## 语义约定

- **统一列级**：每列一个层级，所有行一致；枚举全部层级组合，返回损失最小者。
- **损失**：单行损失 = Σ列 `level_c / maxLevel_c`；总损失 = 行数 × 单行损失，
  另输出归一化平均损失（∈ [0,1]）。
- **空值独立处理**：`null` 不随层级提升，只与其他 `null` 同组，永不与非空值合并。
- **明确无解**：
  - 总人数 `< k` → `INSUFFICIENT_RECORDS`；
  - 全部列提到最高层级仍有小组 `< k` → `NO_FEASIBLE_SCHEME`，并列出违规分组。

## 输出

可行时打印每列层级、每个等价组合的取值与人数、总损失与平均损失；
无解时打印原因与（如有）最高层级下仍违规的分组，退出码为 1。

## 文件

- `src/types.ts` — 数据集、层级、结果类型定义
- `src/anonymize.ts` — 校验、分组、按损失升序枚举层级组合并返回首个可行解
- `src/cli.ts` — 命令行入口
- `test/` — 单元测试与示例端到端测试
- `examples/sample.json` — 示例数据
