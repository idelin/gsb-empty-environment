# 增量 AC-3（Python 3.11，仅标准库）

二元约束、有限域的增量 AC-3 实现，支持约束动态增删、值恢复、
带回溯的 push/pop，以及每个删值的可审计理由。

## 文件

- `ac3.py` — `CSP` 实现（AC-3 传播、理由、trail、恢复不动点）+ 演示 `main`
- `reference.py` — 独立参考实现（全量重算 AC、完整解枚举、赋值检查器）
- `test_ac3.py` — unittest 测试（确定性样例 + 随机会话对照）

## 设计要点

- **传播队列**：`(变量, 约束)` 弧配 `in_queue` 集合去重；弧出队即移出集合，
  之后仍可重新入队，去重不丢必需的重检。
- **删值理由**：每个被删值记录 `Reason(constraint_id, neighbor,
  neighbor_domain)`，证据来自原约束（邻居变量当时的活域快照）。
- **push/pop**：trail 记录删除、恢复、理由改写、约束增删、支持缓存写入；
  检查点同时快照传播队列与 `in_queue`，pop 完整恢复。
- **撤回约束**：不是继续删域，而是计算最大不动点——所有弧删值作为候选，
  候选间可互为支撑，逐轮剪枝后幸存者恢复（互支持环也能一起恢复）；
  仍被删但理由指向已撤约束的值，用现存约束重写理由。
- **决策删值**（`delete_value`/`assign`）标记为 decision，约束撤回不恢复，
  只有 pop 撤销。
- **冲突**：任何变量域变空立即抛 `Conflict`。
- **求解器**：`solve_one`/`solve_all` 基于 push/pop + 传播回溯；
  声称有解时用 `reference.check_assignment` 对原约束独立验证。

## 运行

```bash
python3.11 ac3.py          # 演示样例
python3.11 -m unittest test_ac3 -v
```

```

  删除 x=2: no support in y (domain [1, 2]) for constraint c_xy
  删除 y=1: no support in x (domain [1]) for constraint c_xy

=== 样例 2: 空域立即冲突 (x<y, x∈{1,2}, y∈{1}) ===

传播后: {'x': [1, 2], 'y': [2, 3]}

pop 恢复后: {'x': [1, 2], 'y': [2, 3]}

=== 样例 4: 撤回约束后重新判断值可恢复 ===
两条约束传播后: {'x': [1], 'y': [2], 'z': [2]}

全部解个数: CSP=2, 枚举=2
```

## 测试结果（`python3.11 -m unittest test_ac3`）

15 个测试全部通过（约 0.7s）：

- 必需样例：`x<y` 收缩为 `x={1}, y={2}`、空域立即冲突、push/pop 恢复、
  撤回约束后值恢复、部分恢复 + 理由重写、决策不被约束撤回恢复、
  队列去重不丢重检、pop 恢复队列/缓存/理由、互支持值一起恢复。
- 求解器：4 皇后解经独立检查器验证；全部解与完整枚举一致（2 个）；
  3 皇后不可满足（AC 即判空），枚举确认为 0 解。
- 随机会话：6 个随机种子 × 250 步混合操作（加/删约束、决策删值、
  赋值、push/pop），每步与独立参考实现（全量重算 AC）比对域、
  校验每条删值理由、并用完整枚举确认传播从未删除合法解。
