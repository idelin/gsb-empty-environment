跳板机与开发容器在转发 SSH Agent（`SSH_AUTH_SOCK`）签名请求时，若未绑定会话生命周期、目的主机公钥约束（`session-bind@openssh.com`）或允许已降级子进程继续调用高权限私钥签名，被攻陷的远端主机可静默盗用本地密钥登录其他生产服务器。为 Go SSH 安全代理宿主构建可导入的 SSH Agent 协议解析与多跳签名约束核验包，严禁联网。组件从原始二进制包解码 `SSH_AGENTC_REQUEST_IDENTITIES`/`SIGN_REQUEST`/`EXTENSION`（含 `session-bind@openssh.com` 扩展绑定记录），维护真实 Ed25519 密钥环与每把密钥的约束策略（允许目的主机公钥集合、最大跳数、确认回调与有效期）：（1）对所有无 `session-bind` 链或跳数超过上限的转发签名请求一律拒签；（2）当远端主机尝试用非授权目的主机指纹或重放旧会话绑定签名挑战时立即阻断并吊销该转发会话句柄；（3）严格校验 `SSH2_AGENT_SIGN_REQUEST` 载荷中的会话 ID 与绑定扩展一致，防止跨会话签名混淆。附真实 Ed25519 密钥构造的多跳合法转发与跨主机盗用、重放绑定、越界跳数攻击测试集。
