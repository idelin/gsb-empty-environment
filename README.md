虚拟磁盘压缩器要向底层卷发出一批对齐的 discard；不是每个逻辑零都可打孔。写可导入的 Go 包，读取快照树上按半开逻辑区间覆盖的零、显式数据及父卷回退映射。打孔的语义是移除本层覆盖并显露父层，不等于写零。每层允许的命令是给定幂二大小的对齐区间，每命令固定费；某些物理 extent 多处共享，只有全部活引用解除才获得释放收益。要保持指定可挂载快照的逐字节可见来源一致，零来源之间允许互换但数据来源 ID 不得变。给定预算，先最大化实际释放物理字节，再最小化命令费与命令序列。区间端点到 2^55，每个共享分量最多十八个候选命令，不能展开卷。附独立的小卷解释器和反例，显示仅按零范围或单一子卷做打孔会暴露非零父数据。
