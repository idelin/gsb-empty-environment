# config-lease-binder

带版本约束的配置信息租约绑定器：集群动态配置分发与生效机制。

## 机制

- **配置中心（ConfigCenter）**：持有带版本号的集群配置；向节点签发与配置版本绑定的租约（含 TTL）。
- **工作节点（WorkerNode）**：向配置中心租用配置，仅在持有**未过期租约**时对外接客；租约有效性由节点本地时钟判定，无需联系配置中心。
- **配置更新**：配置中心递增版本号、**撤销全部旧租约**，并向在线节点推送新配置与新租约凭证。
- **版本约束**：节点拒绝不高于本地版本的配置重放；配置中心拒绝为旧版本租约续期，强制重新绑定。
- **脱网熔断**：脱网节点收不到推送，其旧租约到期后**自然失效**，节点主动停止接收流量，防止使用过期配置操作脏数据；恢复联网后重新租用新配置方可恢复服务。

## 目录结构

- `src/clock.ts` — 可注入时钟（`SystemClock` / `ManualClock`），保证测试确定性
- `src/lease.ts` — 租约模型：绑定配置版本 + TTL
- `src/config-center.ts` — 配置中心：签发/续期/撤销租约，发布新配置
- `src/worker-node.ts` — 工作节点：租约门槛、版本约束、脱网熔断
- `test/config-lease.test.ts` — Node.js 内置测试（`node:test`）
- `examples/demo.ts` — 端到端运行样例

## 运行

要求 Node.js >= 23.6（原生 TypeScript 类型擦除，零依赖）。

```bash
npm test      # 运行测试
npm run demo  # 运行样例
```

## 验收边界覆盖

| 验收边界 | 测试 |
| --- | --- |
| 配置中心修改数据库密码 | `更新配置后版本递增，旧租约全部撤销，在线节点收到新配置与新租约` |
| 发布新配置并收回旧租约 | `旧租约在配置中心侧失效：续租被拒绝，凭证校验不通过` |
| 脱网慢节点旧租约自然失效主动停止接收流量 | `脱网节点收不到新配置，旧租约到期后拒绝流量，防止脏数据` |
