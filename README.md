# fxconv — 可审计汇率走势时态折算器

双时态（bitemporal）汇率折算，仅用 Go 标准库。

## 时态模型

每条汇率版本携带两个时间维度：

- `ValidFrom`：牌价**生效时间**（业务时间）
- `KnownAt`：发布中心**知悉时间**（系统时间，支持延迟发布与紧急更正）

折算规则（`Store.Convert`）：对发生于 `txnTime` 的交易，按知悉时刻 `asOf` 查询，
在 `KnownAt <= asOf` 且 `ValidFrom <= txnTime` 的版本中取 `ValidFrom` 最新者；
并列时取 `KnownAt` 最新者（更正覆盖原牌价）。版本库只追加、永不删除，
折算结果 `Conversion` 附带采用版本与被覆盖版本，构成完整审计依据。

## 验收场景

交易 10:00 发生；10:05 收到 10:00 生效的汇率 A(7.10)；10:10 收到更正 B(7.12)：

- 知悉时刻 10:06 查询 → 采用 A，1000 USD = 7100 本币
- 知悉时刻 10:11 查询 → 跃迁到 B，1000 USD = 7120 本币，A 列入被覆盖清单

## 运行

```sh
go test ./... -v   # 测试（含验收场景、延迟发布、多次更正等）
go run ./cmd/demo  # 运行样例，打印版本跃迁与审计历史
```
