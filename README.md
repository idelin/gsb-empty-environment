# Windows作业对象脱离与嵌套限制

Windows 作业对象用来限制沙箱进程数、内存与退出清理，攻击者在作业允许脱离时用 CREATE_BREAKAWAY_FROM_JOB 创建子进程，或借嵌套作业放松限制。为 Go 沙箱宿主写供创建进程与配置作业调用的限制组合包：作业限制含活动进程数上限、作业内存上限、KILL_ON_JOB_CLOSE、BREAKAWAY_OK、SILENT_BREAKAWAY_OK 与 UI 限制位；创建进程带脱离标志时仅当作业允许才放行，沙箱策略要求两种脱离均关闭；嵌套作业的有效限制取父子中更严格者（上限取小，必须位取并），子作业不能关闭父作业已开的 KILL_ON_JOB_CLOSE；创建数超过上限时拒绝创建，而不是杀掉已有进程。用脱离标志、嵌套放宽、超限创建和合法嵌套验证。
