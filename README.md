# 签名份额在两个区块高度上双签

门限签名节点必须证明自己没有在同一高度为冲突区块贡献份额。请给Go共识宿主实现可导入的签名份额防双签账本：成员清单固定，每个成员有Ed25519公钥和唯一ID；份额消息签名覆盖链ID、高度、轮次、阶段{prepare,commit}、区块摘要及父摘要。对同一成员，安全规则为同高度同阶段只能支持一个区块；同高度不同阶段不互相构成双签；commit必须已有该成员同高度同区块且轮次不高于commit的prepare，轮次不得倒退；高度h的任何prepare，其父摘要必须等于该成员最近一次已commit高度中最大的区块摘要，允许中间高度缺席。事件可乱序到达，缺前置时暂存；补齐后按规则发布，若两份有效签名构成冲突，输出可独立验证的最小双签证据并冻结该成员，不能用后到覆盖。持久化按成员维护已签索引、暂存和冻结证据，重启、重复消息与批次中途崩溃不得漏报。用真实签名模拟乱序prepare/commit、同高度不同轮、跨高度错误父项和两份冲突份额，核对无私钥者不能伪造证据，普通分叉只在成员实际双签时定罪。
