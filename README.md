# Fulcio证书扩展与工作流身份绑定

Fulcio 签发的证书用私有扩展 OID 1.3.6.1.4.1.57264.1.x 记录 OIDC 颁发者、构建签名者、源仓库、提交摘要、引用与触发事件，验证者只看 SAN 就会被另一个仓库里同名的工作流冒充。为 Go 验证服务写供签名验证流程调用的证书身份绑定包：从扩展取 .1.8 颁发者（DER UTF8String）、.1.9 构建签名者 URI、.1.12 源仓库 URI、.1.13 源仓库摘要、.1.14 源仓库引用、.1.20 构建触发事件，按调用方策略要求全部匹配；旧的 .1.1 颁发者（原始字节，无 DER 包装）与 .1.8 同时出现且不一致时拒绝；同一 OID 重复、必需项缺失、SAN 与 .1.9 不一致、引用为分支而策略要求标签均拒绝。用同名工作流异仓库、.1.1 与 .1.8 冲突、重复扩展和合规证书验证。
