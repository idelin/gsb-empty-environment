# llk — LL(k) 文法前瞻预测分析器

基于固定 K 步前瞻的递归下降分析器（Go 标准库，零依赖）。

## 原理

1. 对每个候选式计算 FIRST_k 集合（不动点迭代 + k 连接运算）；
2. 同一规则的两个候选式 FIRST_k 相交（存在长度 ≤ K 的公共前缀）时，
   构建阶段显式抛出 `GrammarOutOfBoundsError`（文法超界异常）；
3. 否则构建“前瞻串 → 候选式”分支预测表；
4. 解析时每次仅前瞻 K 个 Token 查表决定分支，输入指针单调前进，
   无回溯，线性时间。

## 验收样例

文法 `A -> 'a' 'b' 'c' | 'a' 'b' 'd'`：

- K=2：公共前缀 `a b` 无法区分分支，构建时抛出文法超界异常；
- K=3：成功构建预测表 `{"a b c"→#0, "a b d"→#1}`，线性解析输入。
