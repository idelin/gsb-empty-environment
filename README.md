物联网消息代理在落地 MQTT 5.0 增强认证（`AUTH` 报文多轮挑战）与主题级 ACL 时，若状态机允许客户端在增强认证完成前发送 `PUBLISH`/`SUBSCRIBE`，或主题匹配器未按规范区分 `+` 单层通配、`#` 多层通配与 `$SYS/` 系统保留前缀，受限设备可跳过认证或订阅全量系统控制主题。为 Go 物联网安全代理宿主构建可导入的 MQTT 5.0 二进制报文解码、SCRAM-SHA-256 增强认证状态机与主题 ACL 隔离验证包，严禁联网。组件从原始字节解码可变长度整数（拒绝超 4 字节与非规范编码）、`CONNECT`/`AUTH`/`PUBLISH`/`SUBSCRIBE` 报文及属性区；在认证阶段强制执行 `CONNECT(AuthenticationMethod)` -> `AUTH(Continue)` -> `AUTH(Success)` 严格状态转移（核对客户端随机数、服务端签名与盐值），未达 `Authenticated` 状态前收到任何业务报文立即断开；在主题授权层严格校验共享订阅 `$share/{ShareName}/{filter}` 与系统主题 `$SYS/` 隔离（`#` 与 `+` 绝不能匹配以 `$` 开头的系统主题），并精确判定订阅过滤器是否被调用者权限集完全覆盖。附畸形变长整数、认证状态机跳过与 `$SYS` 通配符越权测试。
