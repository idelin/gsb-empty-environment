块缓存在顺序扫描和反复点查之间切换时，固定按最近使用淘汰会来回抖动。给缓存交付可导入的 Go 替换组件，采用自适应替换：四个目录分别是只见过一次的近期、只见过一次的幽灵、见过多次的近期、见过多次的幽灵，另有目标值控制两个近期目录的大小划分。新块取自幽灵目录或两个近期目录总长达到上限时调整目标值，随后淘汰一个近期目录中最近最少使用的块；见过多次的块进入前若对应近期目录已满而另一目录有空位，要先从另一目录淘汰。组件只做准入和淘汰决策，数据由调用方存放。验收用事件重放对照朴素模型逐次核对淘汰对象，覆盖目标值在上限与零之间来回、连续扫描后转入点查、两个目录长度不等时上限触发；目录总长可到百万，单次访问不得线性扫描。
