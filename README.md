# WebGPU异步映射回调写入复用缓冲

浏览器GPU进程允许脚本异步map缓冲区，若destroy后槽位被复用而旧回调仍返回，攻击者可能读写另一页面的新缓冲。请实现供WebGPU宿主调用的TypeScript缓冲映射生命周期组件。资源身份绑定device、origin隔离分区、buffer槽位与generation、allocation ID和device timeline；mapAsync请求保存模式、范围、promise代次和提交时的device-lost epoch，检查对齐、usage及区间无溢出后进入Pending。GPU回调只在资源仍为同一generation且状态Pending时发布映射；destroy、unmap、device loss、导航或策略撤销会原子取消并使所有ArrayBuffer视图detached，迟到成功只释放旧allocation。MappedAtCreation、只读/只写模式和重叠映射按状态机处理，跨origin设备池不能共享generation空间。用可暂停GPU回调交错destroy后重建、device loss后恢复、导航、重复unmap、范围边界和合法映射，证明旧promise或视图不能访问复用资源。
