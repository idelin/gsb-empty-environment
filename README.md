# spatial-focus-nav

嵌套滚动与模态区域的方向键焦点导航。纯 TypeScript 实现，节点树与字形度量由夹具给出，
核心计算（几何、遮挡、候选评分、滚动偏移、文本测量）不借浏览器布局引擎。

## 运行

需要 Node.js ≥ 22.6（使用 `--experimental-strip-types` 直接运行 TypeScript）。

```sh
npm test      # Node.js 内置测试（node:test），24 个用例
npm run sample # 可重放样例：打印回放日志 / 决策轨迹 / 读屏公告
```

## 结构

- `src/geometry.ts` — 矩形、方向、主轴/副轴位移等基础运算
- `src/metrics.ts` — 夹具字形度量 → 文本宽度
- `src/scheduler.ts` — 确定性手动调度器（任务数上限，循环等待可检测）
- `src/tree.ts` — 节点树：矩形、可见遮挡、逻辑次序、异步挂载状态、布局版本
- `src/candidates.ts` — 候选收集与方向选取（公开主轴优先规则、回环、方向布局）
- `src/navigator.ts` — 导航状态机：先定候选 → 请求滚动/挂载 → 完成时校验 → 提交/重规划
- `src/fixtures.ts` — 夹具：嵌套滚动侧栏/芯片条、可折叠区、模态对话框
- `src/replay.ts` — 键盘事件回放引擎（逐步校验不变量）
- `samples/scenario.ts` + `samples/replay-sample.ts` — 可重放样例
- `test/` — `node:test` 测试

## 公开规则

### 主轴优先（含斜向候选）

1. 候选中心在主轴上的位移必须严格为正（沿按键方向）；
2. 先按主轴位移升序，再按副轴偏移升序，最后按逻辑次序（文档序）升序；
3. 斜向候选不另设规则，同样按上述次序参与竞争；
4. 焦点已在某祖先内部时，该祖先不再是空间候选。

### 回环

主轴正方向无候选时，取主轴反向位移最大（反方向极值）的候选，
平局按副轴偏移、逻辑次序裁决。

### 方向布局

容器声明 `orientation` 且按键沿其主轴时，按逻辑次序在兄弟间移动（含回环），
优先于几何选取（工具栏 / 列表语义）。

### 异步与一致性

- 每次按键使导航令牌递增：先前慢挂载/滚动的完成回调因令牌不符被丢弃
  （连续两次按键使首次慢挂载结果过期）；
- 异步完成时校验布局版本：版本不符说明几何/结构已变，丢弃结果并重规划；
- 候选在等待期间被删除或变为不可见：重规划，绝不把焦点交给不可见旧节点；
- 重规划深度有上限，超限落到合法后备，调度器任务数有上限 —— 无循环等待。

### 合法后备

结构变更（删除、折叠、隐藏）使焦点失效时：取作用域（模态优先）内逻辑次序
在锚点之后的最近可聚焦节点；无则取之前最近者；再无则取作用域内第一个。

### 模态

模态可见期间，背景节点被遮罩（更高 z 的不透明层）遮挡而不可聚焦；
候选收集限制在模态子树内，回环也不越界；焦点在模态外时打开模态会自动
救援进入模态，关闭模态后后备到逻辑次序上的相邻节点。

### 读屏同步

每次焦点提交同步追加一条公告（`节点ID:标签`），`checkInvariants()`
校验公告流尾部与当前焦点一致；回放引擎在每个步骤后自动校验。
