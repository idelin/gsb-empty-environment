磁盘阵列掉了一台机架，幸存机架内部可以任意异或本地块，但跨机架只能把系数向量和等长字节块一起发送到恢复端。给存储引擎做可导入的 Go 修复计划包。条带的每个逻辑分片是 GF(2) 上 n≤12 个独立源字节串的线性组合。输入给出各幸存机架实际持有的系数行、每架可跨网发送的最大块数和每发送一块的正整数费用；待恢复的是给定的多行系数，不一定独立。每架发出的行必须属于自己的行空间，恢复端只可异或已收到的块；不能让机架先互换数据。求最少总费用，同费再最少块数，返回每条消息在原本地分片上的系数和每个目标在消息上的解码系数，无解须明确拒绝。允许各架联合发送单独看与目标子空间交集为零的行；不能只从题目列明的原始行里挑。必须支持各架任取子空间，不能展开所有输入机架决策的笛卡尔积；同一架重复或零行不扩大可用维数。交付实际流式编码和解码，块可分片读取，最后一段不足缓冲区；允许读取本地分片多次但不能整条带缓存。用 n≤4 的独立行空间穷举对照两级最优并逐字节验证，另给至少一例最便宜修复依赖本地预组合且所有单架均无法独立恢复目标。
