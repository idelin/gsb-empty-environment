ARMv8.5-A 系统运行时在启用内存标签扩展（MTE，16 字节颗粒度 + 4 位逻辑/分配标签 `0x0`–`0xF`）防御堆越界与释放后重用（UAF）时，若释放对象时 `IRG`/`ADDG` 未排除旧标签导致重分配撞上同一标签、忽略内核全匹配标签 `0xF`（Match-All Tag）被非特权指针篡改注入、或在异步检查模式（`TCF=2`）下延后报告 `TFSR_EL1` 导致越权写先于异常落盘，攻击者可绕过 MTE 实施确定性堆利用。为 C++17 内存安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 ARM64 MTE 颗粒标签状态机与内存访问验证库。库建模 16 字节对齐的堆颗粒标签表（Allocation Tag）、64 位带顶字节标签指针（TBI 位 `[59:56]`）、同步/异步/非对称检查模式（`TCF=1/2/3`）以及 `ALLOC`/`FREE`/`RETAG`/`LOAD`/`STORE`/`MEMCPY` 操作流：（1）严格校验所有 `LOAD`/`STORE`/`MEMCPY` 覆盖的每一个 16 字节颗粒（含跨颗粒非对齐访问）的指针标签与内存分配标签匹配；硬拦截将内核特权 Match-All 标签 `0xF` 下发给用户态对象或未隔离保留标签；（2）审计分配器重标策略：检出释放后未立即更新颗粒标签（保留旧标签造成静默 UAF）、相邻块未强制异标签（导致线性溢出无感越界）以及 4 位标签回绕未跳过前代活跃悬垂指针标签的缺陷；（3）针对异步模式检出在 `STORE` 触发标签错配后、异常同步屏障前存在外部可见副作用（如 I/O 或指针发布）的窗口，输出精确违例步号、地址与标签见证。附跨颗粒非对齐越界、UAF 旧标签残留、Match-All `0xF` 滥用与异步窗口泄漏测试。
