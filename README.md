# 盲签名额度在重试中被额外兑现

匿名凭据签发器允许每张授权票据兑换一次RSA盲签名，网络重试不能额外获得签名。给Go签发宿主实现可导入的兑换事务包：宿主固定RSA公钥(N,e)和私钥操作回调，客户端提交唯一128位ticketID、授权声明摘要、盲值b及请求ID；要求1<b<N且gcd(b,N)=1，签名回调只计算b^d mod N。票据由注入验签器确认绑定ticketID、声明摘要、截止时间和最多兑换数m，m为1至16；同一ticketID维护已承诺请求ID到盲值摘要、序号和盲签名结果的映射。首次请求先原子占用一个序号并持久化盲值摘要，再调用签名器，签名结果在占用之后的第二次原子提交保存，不能与此前占用假设为同一事务；崩溃在占用后可用同请求ID和同盲值恢复计算，换盲值拒绝，额度不归还。不同请求ID超过m拒绝；重复同请求返回相同结果。私钥回调失败不泄露部分结果且仍保留占用。提供客户端测试用随机可逆因子r构造b=m*r^e mod N并解盲，核对签名；逐持久化点故障、并发重试、ticket复制及同requestID换b时，成功解盲的不同消息数不得超过m。
