# 刷新令牌家族重用判定

移动端刷新请求断线重试时不应被误判为盗用，但已轮换令牌也不能无限复活。写供Go认证服务调用的刷新事务组件，旧令牌与幂等键绑定一次轮换；相同键返回同一已提交结果，不同键重用旧令牌撤销整个家族。结果先持久化再返回，撤销与刷新有单一先后顺序。用崩溃存储和并发屏障测试响应丢失、孙代令牌已签发与家族撤销。

实现位于 `refresh/` 子包：

- `refresh/service.go`：刷新事务服务 `Service`，按家族加锁串行化，强制幂等绑定、重用检测与先持久化后返回。
- `refresh/store.go`：崩溃可恢复的写时复制存储 `CrashableStore`、原子 `Apply` 事务与追加式家族事件日志。
- `refresh/refresh_test.go`：覆盖响应丢失重试、孙代令牌签发后家族撤销、提交前/提交后崩溃重开、同键/异键并发屏障与刷新-撤销全序。

运行：`go test ./... -race`。
