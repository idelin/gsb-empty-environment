# mvcc — 多版本快照键值存储（仅标准库）

## 能力

- **多键同版本读取**：`Snapshot.Get(keys...)` 在快照固定的版本上解析所有键，
  单次读取永远是一个一致视图，不会出现 A 旧 B 新的混合结果。
- **快照期间旧版本保留**：每个键保留完整版本链，快照钉住其开启时的版本。
- **写入批次原子发布**：`Commit(ops...)` 把整批写操作发布为同一个新版本，
  要么全部可见，要么（注入失败时）全部不生效、版本号不变。
- **GC 以活跃快照最小版本为界**：回收界线是所有活跃快照的最小版本
  （无活跃快照时为最新版本）；界线处最新版本保留，更旧的版本回收。
- **删除可见性**：删除写入墓碑版本，旧快照仍可见该键，新快照与最新读不可见。

## 可注入点（`Options`）

- `Now Clock`：时钟，测试可用手动时钟推进时间。
- `Load Loader`：底层数据源，内存中无版本的键回源读取；不依赖任何远程缓存。
- `Fail FailHook`：失败注入钩子，在 `begin`/`commit`/`get` 前触发，
  返回错误即在状态变更前中止操作。
- `SnapshotTTL`：快照生存期，0 表示永不过期。

## 超期快照策略

快照超过 `SnapshotTTL` 后：读取返回 `ErrSnapshotExpired`，快照被自动释放
（从注册表移除），不再阻碍 GC；之后再 `Close` 是安全无操作。过期是终态，
不可续期。`Close` 幂等；关闭后的读取返回 `ErrSnapshotClosed`。

## 资源释放验证

`Store.ActiveSnapshots()` 报告持有资源的快照数（调用时先惰性释放过期快照）。
测试验证：N 次 `Begin` 后计数为 N，全部 `Close` 后归零，重复 `Close` 不破坏注册表。
