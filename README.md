# 双向流量控制信标 + 滑动窗口协调器

自实现的轻量级滑动窗口流控协议（TypeScript，零依赖，仅 Node.js 内置模块）。

## 协议设计

### 帧格式（15 字节定长头 + 载荷）

```
0        1        5        9        13       15
+--------+--------+--------+--------+--------+-----------------
| flags  |  seq   |  ack   | window | paylen | payload ...
+--------+--------+--------+--------+--------+-----------------
```

- `flags` (u8)：`ACK=0x01`、`FIN=0x02`、`PROBE=0x04`
- `seq` (u32BE)：本帧载荷首字节的流序号
- `ack` (u32BE)：累积确认号 = 接收端下一期望字节（流量控制信标）
- `window` (u32BE)：接收端当前接收窗口（字节），**每个 ACK 帧都携带**
- `paylen` (u16BE)：载荷长度

### 双向信标机制

每个 `FlowEndpoint` 同时持有发送协调器与接收协调器；**所有出站帧**
（数据帧、纯 ACK 帧）的帧头都捎带本端最新信标 `(ack, window)`，
对端发送器以此作为唯一发送授权。

### 发送端协调器（`SlidingWindowSender`）

- 不变式：`bytesInFlight <= peerWindow`（任何时刻在途字节数不超过最新通告窗口）
- 在途数据填满窗口 → 立即挂起（`suspend` 事件）
- 窗口归零 → 进入探测模式：每 `probeIntervalMs` 发送 1 字节 `PROBE` 帧
  （不计入在途、不消耗序号，仅用于引出对端信标）
- 收到窗口扩大 ACK → 恢复发送（`resume` 事件）

### 接收端协调器（`WindowedReceiver`）

- 接收窗口 `window = capacity - buffered`，窗口变化即发出信标通告
- 应用 `consume(n)` 消费 → 窗口扩大 → 触发窗口扩大 ACK
- `resize(cap)` 调整容量 → 下发窗口缩小/扩大通知
- 乱序、重复、超窗的段一律丢弃并回告当前信标

## 目录结构

```
src/frame.ts      帧编解码（15 字节头）
src/sender.ts     滑动窗口发送协调器（挂起/恢复/零窗口探测）
src/receiver.ts   窗口化接收协调器（信标生成）
src/endpoint.ts   双向端点（信标捎带、收发协调）
src/transport.ts  传输抽象 + 内存双工链路（可注入时延）
examples/demo.ts  运行样例：1MB 大文件 + 慢消费 + 窗口缩小通知
tests/            Node.js 内置测试（node:test）
```

## 运行

要求 Node.js >= 22.6（利用原生 TypeScript 类型擦除，无需编译；仓库内含 `.nvmrc`）。

```bash
nvm use          # 或任何 >= 22.6 的 Node
npm test         # node --test
npm run demo     # node examples/demo.ts
```

## 运行样例输出（`npm run demo`）

场景：A 快速注入 1MB 文件；B 每 25ms 仅消费 4KB；1s 时 B 下发窗口缩小
通知（64KB → 16KB），4s 时恢复。

```
[    1ms] A 注入 1024KB 文件，sha256=3cea9f73605422a7...
[    1ms] A 挂起 #1：在途 0B / 对端窗口 0B，暂停发送
[    4ms] A 恢复 #1：收到窗口扩大 ACK（窗口=65536B），继续发送
[    5ms] A 挂起 #2：在途 65536B / 对端窗口 65536B，暂停发送
[ 1003ms] B 下发窗口缩小通知：接收容量 64KB -> 16KB
[ 1046ms] A 零窗口探测 #1（1 字节 PROBE 帧）
[ 1097ms] A 零窗口探测 #2（1 字节 PROBE 帧）
...
[ 4002ms] B 恢复接收容量：16KB -> 64KB
...
[ 6834ms] 传输完成：1024KB，完整性校验 通过 ✓

===== 统计 =====

峰值在途字节    : 65536B（不超过通告窗口）
```
