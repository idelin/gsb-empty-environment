# 代理凭据被原样转发给了源站

请求经过认证代理后，`Proxy-Authorization`没有在转发前删除，源站收到代理口令并写入访问日志，攻击者读取日志即可复用代理。请实现供Go反向代理调用的可导入转发头裁剪组件。按跳数与逐跳头规则移除Proxy-Authorization、Proxy-Authenticate、Connection及其列出的头，转发时重建头集合而不是增量修改；代理自身凭据只存在于到下一跳的连接，不进入请求。X-Forwarded链按受信代理追加，客户端提供的同名头先剥离。用代理口令泄露、Connection列头、嵌套代理、伪造转发链和合法代理验证源站收不到代理凭据。
