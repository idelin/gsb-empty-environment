虚拟化宿主机在配置 RISC-V IOMMU（v1.0）设备目录表（DDT）、两阶段地址翻译（First-Stage / Second-Stage Sv39x4/Sv48x4）与 MSI 页表（IMSIC 中断重映射）时，若设备上下文（DC）未校验 `device_id` 稀疏目录边界、二阶段大页映射部分覆盖宿主机内核物理区，或 MSI 地址掩码 `msi_addr_mask`/`msi_addr_pattern` 配置错误放行了越界写入，恶意 PCIe 设备可通过伪造 DMA 请求或伪造 MSI 写事务直接篡改宿主机内存或注入跨虚拟机中断。为 C++17 虚拟化安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 RISC-V IOMMU 隔离策略符号验证库。输入为 DDT 树、设备上下文集合、两级稀疏页表（严禁逐页枚举）、MSI 页表（Flat/MRIF 模式）、各虚拟机合法物理内存区间及宿主机受保护区集合。验证器精确判定：（1）沿 DDT 1/2/3 级目录解析每个有效设备上下文，核对保留位、PASID 边界与 `iohgatp`/`iosatp` 模式合法性；（2）联合分析一阶段与二阶段页表及大页区间，检出任意可写/可读 DMA 路径落入宿主机敏感物理区或跨虚拟机物理内存的隔离违例；（3）解析 MSI 地址模式匹配与 MSI PTE（区分 Basic Translate 与 MRIF），拦截指向非所属虚拟机 IMSIC 中断文件物理页的伪造 MSI 写路径，并输出最小违例 `(device_id, iova)` 及完整逐级表项见证。附缩微地址空间全枚举交叉核对与跨机 MSI 伪造对抗测试。
