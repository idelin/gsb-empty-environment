# dedup

按事件 ID 去重的 Go 库,带水位回收与显式来源进度判定。

## 语义

- **首次有效载荷**:同一 ID 只保留首次载荷;重复事件返回 `Duplicate` 与首次载荷,载荷不一致时标记 `Conflict`。
- **水位回收**:每个来源通过 `ReportProgress` 上报显式进度(单调);全局水位为各来源进度最小值的单调推进。仅当 `水位 > 事件时间 + 保留期` 时条目才被回收。
- **过旧判定**:ID 已被回收后再次重放,库中无记录,此时依据该事件来源的显式进度判定 `Stale`,绝不当作新事件;来源未上报过进度的事件按新事件接受。

## 核对

`model_test.go` 用全历史参考模型(永不回收)对随机操作序列(多来源、进度推进、重放、同 ID 冲突)逐步核对实现的判定、载荷、水位与回收不变式。

```sh
go test ./...
```
