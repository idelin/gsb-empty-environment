支持 Intel CET（Control-flow Enforcement Technology）影子栈（Shadow Stack）与间接分支追踪（IBT）的安全运行时在处理 `setjmp`/`longjmp`、协程切换（`RSTORSSP`/`SAVEPREVSSP`）与信号返回时，若影子栈切换令牌（Restore Token）未校验 64 位模式位与 `busy` 标志互斥、允许普通内存写指令触碰影子栈页，或间接跳转落点缺少 `ENDBR64` 指令，攻击者可伪造影子栈令牌劫持 `SSP` 或发动 JOP 攻击。为 C++17 运行时安全分析宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 Intel CET 影子栈与 IBT 指令流符号验证库。库建模常规栈、只读受保护影子栈页（仅允许 `CALL`/`RET`/`WRSS`/`INCSSP`/`SAVEPREVSSP`/`RSTORSSP` 访问）、影子栈指针 `SSP`、恢复令牌表与 IBT 等待状态机（`IDLE` vs `WAIT_FOR_ENDBRANCH`）：（1）任何 `CALL` 同步压入常规栈与影子栈，`RET` 严格比对两栈返回地址，不相等立即触发 `#CP` 控制保护异常；（2）完整实现 `RSTORSSP` 与 `SAVEPREVSSP` 令牌原子切换协议——验证目标令牌地址 8 字节对齐、位 0（`busy`）为 0 且位 1（64 位模式）为 1，校验成功后原子置 `busy=1` 并切换 `SSP`（拦截双协程共用同一活跃影子栈的令牌重放与伪造令牌）；（3）对所有间接 `JMP`/`CALL` 进入 `WAIT_FOR_ENDBRANCH` 状态，若下条执行指令非 `ENDBR64` 立即报错，并支持检出 `INCSSP` 跳过受保护返回帧的栈展开越权。附 ROP 篡改、双活令牌重放、非法普通写影子栈与缺失 `ENDBR64` 测试。
