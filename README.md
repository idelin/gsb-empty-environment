# 三频带 FIR 分频 + 分带包络压缩 + 前瞻限幅

Python 3.11,仅标准库。样本数组与采样率由本地夹具(`fixtures.py`)提供,
不接音频设备。所有滤波系数显式构造并作为普通列表传入处理器。

## 架构

```
fixtures → Block(音频 + 每样本有效标记)
        → Crossover   3 带 FIR(显式系数) → 分带联动压缩 → 群延迟补偿 → 求和
        → LookaheadLimiter  前瞻窗 + 共享增益 + 固定延迟线
        → 输出 Block + 遥测(逐阶段延迟 / 增益轨迹 / 超限证据)
```

- `dsp/block.py` 音频块与有效标记;NaN 自动判无效并清零
- `dsp/fir.py` 流式 FIR(奇数长对称系数,群延迟 (N-1)/2)与整数延迟线
- `dsp/compressor.py` 软膝静态曲线、包络跟随、阈值热更新斜率平滑、增益速率限制
- `dsp/crossover.py` 三带分频;各带按 (最大群延迟 − 本带群延迟) 补偿后求和
- `dsp/limiter.py` 前瞻限幅:窗内峰值 → 需求增益 → 瞬时攻击/声明速率释放
- `dsp/pipeline.py` 级联与遥测聚合

## 声明的延迟(@48 kHz)

| 阶段 | 延迟(样本) | 说明 |
|---|---|---|
| 分频 | 90 | 各带群延迟 (60, 90, 90),重组对齐到最大 |
| 压缩 | 0 | 侧链包络,不延迟音频 |
| 限幅 | 64 | 前瞻窗 = 音频延迟线 |
| 总计 | 154 | ≈ 3.208 ms |

## 声明的数值容差

- 旁路重组误差 ≤ 1e-6(实测 ~4e-16,系数互补至机器精度)
- 限幅输出相对当前平滑阈值的残余超限 ≤ 1e-6(线性幅度)
- 相位核验 ≤ 1e-4 rad;增益速率核验 ≤ 1e-9 dB/样本

## 关键行为

- **多通道联动**:压缩与限幅的控制增益取各通道最小值(共享),
  音频通路各自独立;仅右声道尖峰也会联动衰减左声道。
- **阈值热更新**:目标阈值按声明斜率(dB/s)逐样本平滑;需求增益对
  前瞻窗内所有样本按当前阈值重算,窗内中途收紧不漏限幅。
- **取消/恢复**:旁路仅把施加增益置 0 dB,延迟线与内部增益跟踪不变,
  无双延迟;恢复即按当前跟踪增益生效,不漏限幅。
- **缺测传播**:无效样本按 0 参与运算;FIR 按抽头跨度、延迟线按位移、
  限幅按音频路径 ∪ 检测窗传播无效标记;包络在无效期间保持。
- **不裁平**:限幅完全通过平滑增益实现,遥测记录每次压限的
  输入峰值/阈值/施加增益/输出峰值作为超限证据。
