# 二值 RGBA 图像轮廓游走

从内存中的 RGBA8 小图提取前景像素的外轮廓和洞。实现不使用 Canvas、滤镜或现成图像处理库；只依赖 Node.js 内置模块和内置测试运行器。

## 环境

- Node.js `>= 22.6`（使用内置 `node:test` 与原生 TypeScript 类型擦除）
- 无第三方 npm 依赖

当前 shell 若是较旧的 Node，`scripts/run-node.sh` 会优先查找 `~/.nvm/versions/node/v22.*`，也可以显式指定：

```sh
NODE_BIN=/path/to/node npm test
```

## 命令

```sh
npm test
npm run sample
npm run check
```

- `npm test`：运行 Node.js 内置测试。
- `npm run sample`：生成自建 12×9 RGBA8 样例、轮廓 JSON 和填回 RGBA。
- `npm run check`：对 TypeScript 文件做 Node 原生语法检查。

## 坐标和输出

像素 `(x, y)` 是左上角为原点的单位方格，覆盖网格点 `(x,y)`、`(x+1,y)`、`(x+1,y+1)`、`(x,y+1)`。图像外部按背景处理，因此贴边对象仍会输出完整四边。

`Contour` 包含：

- `vertices`：闭合游走中不重复的网格点；最后一个点隐式连回第一个点。
- `edges`：每个相邻点对以及最后一个点回到起点的单位边。
- `signedArea`：y 向下坐标中的有向面积。
- `kind`：正数为 `outer`，负数为 `hole`。

外轮廓沿顺时针游走，洞沿逆时针游走。单像素得到 4 个点和 4 条单位边。

## 算法

1. 按 alpha 阈值（默认 `>= 128`）或自定义 RGBA 谓词生成二值 mask。
2. 为每个前景像素枚举与背景或图像外部相邻的边，并构造“前景在右侧”的有向边。
3. 到达网格点时按“右转优先，其次直行，最后左转”选择下一条边。
4. 每条有向边只访问一次；空图没有边，因此没有环。
5. 用有向面积区分外轮廓与洞。
6. 填回时在每个像素中心计算非零环绕数；洞和嵌套轮廓都会还原为原 mask。

对角接触只共享一个网格点。右转优先规则会在该点让两个对象的边界各自闭合，不会把对角接触错误连成桥，也不会制造假洞。

## 样例

`scripts/sample.ts` 自建以下 12×9 RGBA8 图像：

```text
#...........
............
......#####.
......#...#.
......#.#.#.
......#...#.
......#####.
.#..........
..#.........
```

它包含贴边单像素、带洞矩形、洞内单像素和一对对角接触像素，共生成 6 个闭合游走。

输出文件：

- `samples/sample-12x9.rgba`：原始 raw RGBA8，按行存储，每像素 4 字节。
- `samples/contours.json`：所有轮廓点和边。
- `samples/sample-roundtrip-12x9.rgba`：由轮廓填回得到的 RGBA8。

样例校验两个 RGBA 文件字节一致。最近一次运行的 SHA-256 均为：

```text
f7ade8381a23214528c831c94f4091c966802246fb0b38b50d974a85434e702f
```

## 测试覆盖

- 空图无轮廓，空轮廓填成全背景。
- 单像素输出四条边。
- 对象贴住图像边缘时仍沿图像边界闭合。
- 整幅图均为前景时，图像四边仍形成完整外轮廓。
- 3×3 环同时输出外轮廓和洞，方向相反。
- 对角接触像素生成两个独立外轮廓，不产生假洞。
- 外环、洞、洞内对象的嵌套结构填回后一致。
- alpha 阈值和自定义 RGBA 前景谓词生效。
- 所有环闭合、顶点不重复、每条边都是单位长度。

## 代码入口

- `src/image.ts`：RGBA8 构造、小图栅格化、mask 转换。
- `src/contours.ts`：边界枚举、闭环游走、方向判定和非零环绕填回。
- `test/contours.test.ts`：Node.js 内置测试。
- `scripts/sample.ts`：可运行样例。
