# incremental-label-map

二值图的 4/8 连通分量标注，支持**局部像素修改后的增量更新**（分量合并 / 拆分）与**稳定代表 ID**。
纯 TypeScript 实现，零依赖：不调用 Canvas 滤镜，不使用任何图像处理库；验证用图为代码内自建的 RGBA 小图。

## 环境

- Node.js >= 23.6（直接以类型擦除方式运行 `.ts`，无需编译、无需安装依赖）

## 运行

```bash
npm test     # 等价于 node --test，运行 Node.js 内置测试
npm run demo # 等价于 node examples/demo.ts，运行演示样例
```

## 设计

- `LabelMap`（`src/label-map.ts`）持有 0/1 掩码、逐像素标签数组和分量尺寸表。
- **初始标注**：`LabelMap.fromMask` / `labelMapFromRGBA` 做一次全量洪泛。
- **增量更新**：`setPixel(x, y, value)` 只触及受影响的分量——
  - 打开像素：收集相邻分量，无邻居则新建分量；有邻居则并入，多个邻居时**合并**，保留最小 ID 作为代表，其余分量经局部洪泛改标。
  - 关闭像素：从被删像素的邻居出发局部洪泛，统计碎片；仍连通则只更新尺寸，否则**拆分**——最大的一块保留原 ID（并列取最小像素索引所在块），其余块分配新 ID。
- **稳定性**：未被波及的分量，其 ID 与逐像素标签完全不变。
- RGBA 工具（`src/rgba.ts`）：`maskFromRGBA` 默认把“不透明且偏暗（Rec.601 亮度 < 128）”的像素视为前景，可传入自定义谓词；`makeRGBA` 用于在测试/演示中手工构造小图。

## 测试结果（`npm test`）

```
✔ 对角像素：4 连通分开，8 连通相连（自建 RGBA 图）
✔ 删除桥像素使分量分裂
✔ 拆分时最大块保留原 ID
✔ 添加桥像素使两个分量合并，保留最小 ID
✔ 无关分量的标签在局部修改后保持稳定
✔ 8 连通下跨对角合并与拆分
✔ 增量更新与全量重标注结果一致（随机操作）
✔ maskFromRGBA：默认谓词与自定义谓词
✔ 重复设置相同值是安全的空操作
ℹ tests 9
ℹ pass 9
ℹ fail 0
```

其中“增量更新与全量重标注结果一致”用固定种子的伪随机序列在 12x8 图上各执行 300 次随机修改（4 连通与 8 连通各一遍），每一步都与全量重标注的分量结构对照。
