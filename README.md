编辑器把净化后的富文本片段缓存成共享子树，后来又把同一子树嵌入邮件、预览页和离线导出。给 TypeScript 文档宿主写可导入的片段准入组件，输入是已经分词的节点 DAG，以及各消费位置的命名空间、允许元素与属性、允许的 URL 来源和文本处理上下文。每处引用都必须满足从根到该处整条路径的策略交集，不能因为某个节点已经在宽松父节点下通过就跳过另一父节点的校验。策略版本更新可只撤回一个属性或来源，旧缓存不能给新发布的片段授权。输出仍允许共享子树，但须按可见结构与实际权限将上下文等价的引用合并，权限不同的引用不得复用同一发布句柄；上下文只允许有限枚举，层数可达40，全展开路径数可呈指数增长。发布前由独立函数按原始节点、有效策略与投影摘要验证等价类划分，确认任何消费者均看不到其不允许的节点、属性或目的来源。用小 DAG 显式展开逐处比对，验证共享子树的两条祖先链、嵌套命名空间、策略撤销、仅文本变化与同结构不同权限的句柄隔离。
