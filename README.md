# dvsim

距离向量路由模拟器：split horizon + poison reverse，纯标准库，离散事件模型。

## 模型

- 时间为整数 tick，所有包、队列、链路都是模拟器内的事件，不发真实网络流量。
- 每条消息的投递时延为 `[1, MaxLatency]` tick 的随机值，因此同一发送者的消息可能乱序到达。
- 度量上限 `Infinity = 16` 代表不可达，为 count-to-infinity 提供上界。
- 更新为触发式（路由变化或链路状态变化时发送），事件队列清空即收敛。

## 协议规则

- **Poison reverse**：向邻居通告时，把下一跳是该邻居的路由度量改为 `Infinity`。
- **版本规则**：每个目的地的版本号由目的地在自身链路变化时递增。
  更新的版本总是获胜；同版本时接受来自当前下一跳的通告（好消息或坏消息）
  或更优度量；更旧的版本视为过期消息丢弃。
- **乱序防护**：每个发送者的消息带单调递增序号，接收方丢弃序号不更大的消息。
- **链路断开**：经该链路学到的路由立即置为 `Infinity` 并触发更新；
  链路上的在途消息按丢失处理。count-to-infinity 有界（上限 16）且必然终止。

## 运行

```sh
go run ./cmd/dvsim   # 样例：收敛 -> 链路断开重路由 -> 节点隔离 -> 恢复
go test ./...        # 测试
```
