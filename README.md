向量检索引擎不再展开产品量化码本。索引是一个分层有向无环图：每条边携带该层的残差子向量和全局唯一边号，从入口走到终点所得子向量依次拼接成一个候选向量，候选 ID 是完整边号序列；不同路径即使产生相同向量也不可合并计数。向查询内核交付可导入的 Go 包，处理连续查询 q(t)=a+t·b，t 属于给定有理闭区间。对每种候选用真实平方欧氏距离比较。索引要返回使最优候选 ID 集合恒定的极大连通区间，省略候选集合的展开，用可查询的共享表示代替；单点上并列的路径可能远多于左右开区间。对任意有理 t 和零起始大整数 k，能报最近候选的精确个数、反选字典序第 k 个 ID 并解码其字节量化码，不准把取一条最短路当作去重。所有比较、交点、计数精确；层数可达 64，允许同层多个节点共享后续子图；不能逐路径生成距离直线或按候选数分配内存。时间空间可依赖图大小、各节点实际最优边集合的分段数及其交点，不可依赖路径总数。交付检索游标和小图独立解码穷举，对边界上只在一点并列而从未独占最优的路径，以及具有 2^60 条等距离路径、但全区间内只有一种最优集合的索引，核对首末名次、计数和越界拒绝。
