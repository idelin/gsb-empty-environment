# B+ 树范围扫描迭代器（Go）

仅用标准库实现的 B+ 树有序范围查询：根据起始 Key 定位叶子节点与槽位，
沿叶子链表向前迭代，跨越物理页边界时自动 Pin 新页、Unpin 旧页。

## 结构

- `bufferpool.go` — 固定容量缓冲池，LRU 置换；只淘汰 pin=0 的页，
  全部页被 Pin 时返回错误（页面泄漏会立刻暴露）。
- `btree.go` — B+ 树（页 = 节点，叶容量 32），插入分裂、叶子链表
  `next` 指针；`findLeaf` 逐层下溯，父页在子页 Pin 后立即 Unpin。
- `iterator.go` — `Scan(start, end)` 返回半开区间 `[start, end)` 的
  迭代器；任意时刻只持有 1 个叶子页的 Pin，跨页时先 Pin 后 Unpin；
  `Close` 幂等，提前关闭同样释放页。

## 运行

```sh
go test ./... -v   # 验收测试
go run ./cmd/demo  # 运行样例
```

## 验收

树中 10000 条连续记录，`Scan(2500, 7500)` 顺序输出 5000 条不重复记录
（键 2500..7499），跨越 600+ 个叶子页；缓冲池仅 16 帧，扫描结束后
`PinnedCount() == 0`，无页面泄漏、无内存溢出。
