LSM 压实器需要可导入的 Go 包，为多个只读快照重写一个选定键区间。记录含点写、点删和半开范围删除，按序列号及同批操作序定新旧；相邻的外层文件只公开可能含旧点的稀疏键区间，不许打开。输出压实片段，须对所有符合摘要的下层内容、每个保留快照以及最新视图等价。允许复用源点版本，或把源墓碑裁短、在同一版本合并；只能以已有端点与点键的后继为分界。先最少输出记录，再最少墓碑总覆盖长度，再取规范序列最小者。切片边界外必须原样不动。键为 uint64，最大键后继用独立正无穷端点，快照最多八个、重叠墓碑最多十个。给独立的小键域全量对照和回放，含同批先删后写、跨输出边缘的删除、以及某快照需要墓碑但最新视图不需要的反例。
