# resman — 多类整数资源管理器

`resman` 提供一个固定维度的整数资源向量池，语义如下：

- **全有或全无**：一次 `Acquire` 请求一个资源向量，只有每个分量都足够时才授予；
  等待期间不扣减任何令牌，绝不部分授予。
- **FIFO 队首阻塞**：请求严格按入队顺序处理；队首请求不满足时，其后所有请求
  一律阻塞，即使后面的请求本身可以满足。
- **显式归还**：已授予的令牌归调用方所有，只能通过 `Grant.Release` 显式归还
  （幂等）。context 取消只会把*等待中*的请求移出队列，绝不会自动释放
  *已授予/使用中*的资源；若取消与授予同时发生，授予优先，调用方仍须 `Release`。
- **守恒不变量**：任意时刻 `available[i] + granted[i] == capacity[i]`，
  可用 `Manager.CheckConservation()` 在线校验。

## 运行测试

```sh
GO111MODULE=on go test -race -count=1 ./...
```

测试覆盖：全有或全无与队首阻塞顺序、等待取消/授予后取消的语义、非法向量
拒绝、超时不得扣减令牌，以及 32 goroutine 随机向量压力下（`-race`）持续
校验守恒不变量。
