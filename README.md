控制器只保留了各交换机本地有序的转发表变更，没有全局切换时刻。给控制器的变更复盘服务提供可导入的 Go 网络诊断包：输入每次变更允许的整数时刻闭区间、跨设备安装依赖（至少相隔给定非负拍数）、新旧 IPv4 前缀规则的插入/替换/删除，以及若干带源设备、目的地址、注入时间窗、TTL 的探针。所有探针共用同一份安装时刻，同设备指令可同拍但按原序生效，每拍全部更新完成才转发；最长前缀可交付、丢弃或转到另一设备，链路延迟由该探针在给定整数区间内逐跳选取。未匹配即丢，设备查表时 TTL 为零即过期，否则转发才减一。采样器只给部分有序的（设备、时间窗）记录，这些必须是该探针实际查表事件的子序列，同一记录不能重复使用同一跳，最后的实际结果还须符合观测。请判定观测是否整体可满足；能满足时输出按变更编号字典序最早的安装时刻向量及每个探针完整路径、时刻和结局。如果某条指定探针在满足全部记录下还能从另一出端口离开指定设备的首次访问，给两套可独立重放的解释，否则明确不存在；未访问不算出端口。不能把设备上的局部可行时间窗分别拼成一条伪路径。时钟到 2^48，最多八台交换机、十六次变更、六条探针，每条最多十二次转发；禁止按时间跨度逐拍或枚举所有整数时刻。请随库交付不依赖求解逻辑的逐跳回放器，以短时钟穷举作参照，覆盖安装同拍、回环后二次采样、两探针单看均成立但共享安装时刻冲突和区间内部才有解。
