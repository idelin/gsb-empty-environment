隐私验证节点在处理多方批量提交的对数内积证明（IPA）时，若缺少零知识致盲因子、跳过标量非零性验证或在多证明批量聚合中允许跨证明复用共享随机数，攻击者可直接求解私密向量或用恶意证明相互抵消。给Go密码协议宿主实现带致盲零知识扩展与安全批验证的可导入IPA协议包，群运算与唯一规范编码由可信 `Group` 接口注入，支持各自长度 `n_k <= 1024`（2的幂）的同构及异构向量证明。承诺扩展为 `P = <a, G> + <b, H> + <a, b>U + tau * B`（引入独立盲化生成元 `B` 与每轮 `L_j, R_j` 的随机数盲化项），末轮引入盲化常数 `r_a, r_b, tau_final` 执行紧凑零知识揭示以防从末轮标量反推原始见证；Fiat-Shamir 转录哈希须带域分离标签、宿主上下文、全部生成元摘要、当前 `(n, P)` 及所有历史轮 `(L, R)` 的规范长度前缀编码，`SHA-256` 转 `mod q` 得0时按计数器重算。批验证器允许一次接收多份不同向量长度的证明：先按长度补齐折叠树或独立维护轮次，每份证明的批聚合系数必须严格绑定全部证明摘要与上下文后逐份独立生成（禁止批内共享挑战或抵消无效轮次）。附P-256测试适配与小素数阶代数参考测试，实证盲化揭示可过验、批验证无法相互抵消坏L/R、不同长度批量对齐以及0标量/非规范点/转录篡改全拒收（同时明确测试适配不替代生产安全参数审查）。
