# taxiheat — 时空聚合热力图与密度网格累加器

流式人流/车流时空密度分析器（Go，仅标准库）。将地理空间按瓦片网格离散化，
按小时维护时空立方体（Data Cube），支持流式轨迹点快速落桶累加，
并可在任意时空窗口内秒级查询 Top-K 拥堵热点区域。

## 设计

- **Grid**：等经纬度瓦片网格（`MinLat/MinLng/CellDeg/NX/NY`），`Cell()` 完成经纬度→桶索引映射，越界点丢弃计数。
- **Cube**：`map[Unix小时][]float32`，每个小时一层稠密权重网格。
  - 内存 = 小时层数 × NX × NY × 4 字节，**与导入点数无关，严格有界**
    （示例：100×60 网格 × 168 小时 ≈ 4 MB）。
- **Add**：O(1) 落桶累加，单点约 0.9µs（老旧测试机）。
- **TopK**：窗口内小时层累加 + 容量为 k 的小顶堆，单次查询亚毫秒。

## 运行样例

```sh
go run ./cmd/taxiheat -n 1000000 -k 10
```

流式生成 100 万条模拟出租车载客点（含 5 个热点区域），导入一整周，
然后回答"上周五晚高峰 17:00–20:00 全市密度最高的前 10 个网格中心经纬度"。

## 测试

```sh
go test ./... -v          # 单元测试 + 百万点内存有界验收测试
go test -bench=. .        # BenchmarkAdd / BenchmarkTopK
```

基准（同机）：`BenchmarkAdd` 873 ns/op；`BenchmarkTopK` 0.85 ms/op（百万点、168 层之上）。

## API 摘要

```go
grid, _ := taxiheat.NewGrid(39.8, 116.2, 0.005, 100, 60)
cube := taxiheat.NewCube(grid)
cube.Add(lat, lng, timestamp, weight)          // 流式落桶
hs := cube.TopK(start, end, 10)                // 窗口 Top-K 热点（含中心经纬度）
added, dropped, hours, memBytes := cube.Stats() // 统计与内存估算
```
