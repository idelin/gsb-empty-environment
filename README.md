# tbsim — 离散事件令牌桶整形/监管模型

纯 Go 标准库实现。所有包、队列与链路运行在整数 tick 的离散事件模型中，
不发真实网络流量。令牌速率为精确有理数（`math/big.Rat`）。

## 语义

- **监管（Policer）**：到达即裁决，永不延迟；路径上所有祖先桶都有足够令牌才放行，
  否则丢弃且不扣任何桶（原子检查，不漏检）。
- **整形（Shaper）**：可延迟，但队列字节数永不超过缓存上限（`BufCap`），超出即丢；
  每包等待 = 全部祖先桶等待的**最大值**（不是某个桶的局部等待），
  到点后重新逐桶检查再消费。
- **突发边界**：等于桶容量；空闲后令牌封顶，永不超限。
- **事件跳跃**：用有理数精确计算下一可放行 tick（`ceil(need/rate)`），直接跳事件，
  不逐 tick 空转；`TestEventHopMatchesPerTickReference` 与逐 tick 小参考逐包比对通过序列。
- **热换/取消/时钟恢复**：`SetRate` 先结算再换率；权重热换只影响调度；取消只动队列；
  桶时钟单调（回拨被忽略），任何情况下令牌不重复补充。
- **证据**：每包输出逐桶等待分解（`EmitRecord.Waits`）；每桶守恒审计
  `consumed + remaining + overflow == cap + generated`（`Bucket.Audit`）。

## 运行

```sh
go test ./...    # 全部测试（含事件跳跃 vs 逐tick 参考对照）
go run ./cmd/demo
```

## 结构

- `bucket.go` — 精确有理令牌桶：懒补充、单调时钟、等待计算、守恒审计
- `model.go` — 树形节点、流（优先级/权重/缓存）、记录类型
- `sched.go` — 严格优先级 + 平滑加权轮询（两种实现共用，保证状态一致）
- `shaper.go` — 事件跳跃整形器（控制/到达/检查三类事件）
- `policer.go` — 丢弃式监管器（事件式 + 逐tick参考）
- `reference.go` — 逐 tick 参考整形器
- `cmd/demo` — 同流量整形 vs 监管对照样例
