当查询同时包含内连接、左外连接、半连接与反半连接时，优化器不能像纯内连接那样任意重排连接树（如把外连接盲目推到内连接下面会凭空造出本不该存在的补空行），但完全放弃重排又会错过最优 Bushy 树。为查询优化器交付可导入的 Go 冲突感知连接枚举包（按 Moerkotte & Neumann 的冲突规则 CD-C + DPhyp/连通子集 DP 精确建模）。输入原始语法连接树（≤8 张基表，内部节点为 InnerJoin、LeftOuterJoin、SemiJoin、AntiJoin，附带各节点引用的基表集合与谓词选择率）及基表基数与精确整型连接代价模型。组件先从语法树为每个连接算子计算精确的最小需求基表集（TES）与冲突规则集（Conflict Rules：当算子 b 依赖子树中的算子 a 且不满足交换律或 L-ASSCOM/R-ASSCOM 结合律时生成对应冲突规则 `T1 -> T2`）；随后在连通子集动态规划枚举所有合法 Bushy 拆分 `(S1, S2)` 时，校验适用算子满足其 TES 与全部冲突规则，求出所有语义等价 Bushy 连接树中总代价最小者（并列按前序编码字典序最小）。验收在小表真实数据上对枚举出的最优树与原语法树做全量结果等价核对，并与全连接树枚举比对最小代价，覆盖内连接与左外连接可合法左结合（L-ASSCOM）重排、反半连接不可越过左外连接空值侧、两个左外连接在满足空值拒绝谓词时的合法结合，以及含不可交换链时精确禁止非法树。
