# allocator

加权分片分配器：精确整数配额 + 最小搬迁重分配，一切并列按节点编号决胜。

## 用法

```go
nodes := []allocator.Node{{ID: 1, Weight: 5}, {ID: 2, Weight: 3}, {ID: 3, Weight: 2}}
old := []int{1, 1, 1, 2, 2, 3} // 每个分片当前所属节点，allocator.Unassigned 表示未分配
plan := allocator.Reassign(len(old), nodes, old)
// plan.Assignment  新归属（满足精确配额）
// plan.Migrations  实际搬迁数，恒等于 plan.LowerBound
// plan.Proof       下界证据（逐节点缺口 + 求和论证）
```

## 算法

1. **配额（最大余数法）**：理想份额 `shards*weight/totalWeight` 向下取整，
   剩余分片按小数余量从大到小补给节点；余量相同则节点编号小者优先。
   配额之和恒等于分片总数，且每节点配额与理想份额之差小于 1（非近似均衡，
   是带整数约束的精确解）。权重为 0 的节点配额为 0；全部权重为 0 时退化为
   按节点编号均分。
2. **放置（最小搬迁）**：每节点尽量保留现有分片（保留编号最小者），
   盈余分片释放后，按分片编号顺序依次补给出缺口的节点（节点编号升序）。

## 搬迁下界证明

节点 i 最终须持有 `quota[i]` 个分片，其中至多 `oldCount[i]` 个可以是它原本
持有的，因此至少 `max(0, quota[i]-oldCount[i])` 个分片必须易主到达 i；
每个到达的分片都是一次搬迁。对所有节点求和即得下界
`Σ max(0, quota[i]-oldCount[i])`。上述放置策略恰好只移动这么多分片
（每节点保留 `min(oldCount[i], quota[i])` 个），故搬迁数达到下界，即为最优。
`TestBruteForceOptimal` 对小规模随机用例穷举全部满足配额的归属方案，
验证本实现搬迁数等于穷举最优值。

## 覆盖场景

- 新增节点：配额从 0 涨起，只从盈余节点迁入缺口数目的分片。
- 节点下线：其分片全部释放，按编号顺序补给出缺口的存活节点。
- 权重归零：等价于逻辑下线，配额为 0，分片全部迁出。
- 未分配分片（`Unassigned`）：计入缺口一并填充。
