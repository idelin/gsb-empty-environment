档案验证方只许接触获准记录，但数千条记录会共享早年的时间戳与算法迁移凭据。给 Go 档案宿主实现可导入的验证组件。每个签名时间戳可承诺多个证据节点，续证必须绑定它实际覆盖的旧节点及内容摘要；同一服务永久身份换钥仍是同一时钟来源。时钟偏移由有签名的差值上下界给出，所有引用同一来源的节点必须共享一个偏移。对获准档案返回一份固定证书，使每种相容校时情况下都能证明从原始签署到当前验收的可信连续性；可以随实际校时选择证书内的链，但不能临时再披露未获准的节点。按包含的不同证据节点数最少选择证书，隐藏档案的内容及身份不得出现在证书中，仅许可的共享承诺可用。用小图全枚举比较时间相接、共享前驱、服务换钥和不同校时分别有安全链但其并集含不可披露节点的案例。
