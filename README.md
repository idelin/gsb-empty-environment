# streamsum

流式浮点求和库（Go）：返回补偿求和结果及该算法**明确的误差界**，支持分块合并与撤回最近一块。

## 算法与误差界

- 每个分块用 Neumaier 改进 Kahan 补偿求和。块内 `n` 个有限值、
  `S = Σ|xᵢ|` 时，误差界为 `(2u + n·u²)·S`，其中 `u = 2⁻⁵³` 是
  float64 的单位舍入。
- `Merge()` 合并栈顶两块、`Total()` 折叠所有块时，每次合并额外计入
  `u·(|s₁+s₂| + |c|)` 的舍入；最终结果 `sum+comp` 再加 `u·|result|`。
- 所有界用 float64 保守累积。

## 公开的非有限值规则

- 输入含 NaN → `Total` 返回 `(NaN, +Inf)`。
- 输入含 ±Inf 或有限中间值溢出 → 结果按 IEEE 754（±Inf，或异号无穷
  相遇得 NaN），误差界为 `+Inf`。
- **结果非有限时误差界绝不有限**——不给无穷运算伪有限误差界。
- 非有限状态按块记录：`Retract()` 撤回引入非有限值的块后，结果与
  误差界恢复有限。

## API

```go
a := streamsum.NewAccumulator()
a.AddChunk(xs)          // 流入一块
a.Merge()               // 合并最近两块（之后只能一起撤回）
info, ok := a.Retract() // 撤回最近一块，精确移除其贡献
sum, errBound := a.Total()
```

## 测试

`go test ./...` 用 `math/big.Rat`（二进制浮点值的精确有理表示）复算
小例，并覆盖：大数抵消（`1e16 + 1 - 1e16`）、小增量丢失（1000 个
`1e-17` 加到 `1`）、不同块大小对误差界的影响、合并后撤回、以及
NaN/±Inf/溢出规则。
