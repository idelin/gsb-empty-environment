分析库同时存了若干预计算左外连接物化视图，优化器要在集合语义下判断给定查询能否由单张视图经筛选和去重投影无损重写。为优化器交付可导入的 Go 判定包。查询和每张视图均表示为无环连接树：叶节点是基表，内部节点是内连接或左外连接，附带基表等值连接条件、常量范围谓词、空值拒绝谓词和输出列集合；某些基表列声明非空或主键。视图若在某子树产生补空行，只有当查询同样保留该补空行或能通过查询自带的空值拒绝谓词将其精确滤除，且不因视图多做的内连接或更强谓词提前丢行时才可重写。组件返回所有可无损重写原查询的视图编号及对应补偿筛选条件，不可重写时给出区分查询与视图的最小反例表实例（每表至多两行）。验收在有限域上生成全部小表实例对照集合语义输出，覆盖左外连接被上层空值拒绝谓词退化为内连接、视图输出列缺少判空所需非空键列导致无法区分真值空与补空行、以及多层嵌套左外连接补偿失败构造反例。
