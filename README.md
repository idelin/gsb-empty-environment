# 密码重置事务没有撤销已发行会话

账户密码重置成功后，旧刷新令牌和并行登录事务若仍有效，攻击者可立即夺回账户。给Go认证宿主实现可导入的重置提交包：账户记录含credentialEpoch、64位sessionEpoch、密码哈希、恢复策略摘要和状态；重置事务绑定accountID、随机resetID、开始时两个epoch、恢复证明摘要、目标密码参数和截止时刻。恢复证明由调用方验证回调返回已满足的方法集合，必须满足当前策略而非开始时旧策略；新密码哈希在隔离区完成并通过参数下限。提交在单一事务中比较账户仍为开始epoch、写新密码、credentialEpoch和64位sessionEpoch各加1、消费resetID、撤销全部刷新令牌族并取消其他登录/重置事务；任一失败零生效。访问令牌验证每次比较64位sessionEpoch，刷新令牌还绑定令牌族代次并单次轮换，旧epoch即使签名有效也拒绝。响应丢失后同resetID返回原提交回执，换目标密码拒绝；崩溃恢复不能重复加epoch。用确定并发模型交错重置、刷新、登录完成和另一次重置，搜索待审实现中旧证明或旧令牌在重置线性化点之后签发新会话的最短轨迹。覆盖策略收紧、密码哈希失败、sessionEpoch达到最大值时拒绝重置并报警，不能回绕；覆盖epoch上限、回执丢失及刷新轮换竞争。
