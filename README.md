# OpenPGP信任签名深度与域范围

OpenPGP 的信任签名可把验证权委托给介绍人，并用正则限制可认证的邮箱域，攻击者作为介绍人可越出域范围认证，或重复签名凑够信任量。给TypeScript密钥环库写供用户标识有效性计算调用的信任包，密码学验签由调用方注入：信任签名携带级别与数量（数量 120 为完全信任，60 为边缘），在此基础上，本题规定：用户标识有效当且仅当存在从自有根密钥出发、每段级别递减的路径，且累计数量不低于 120；信任签名的正则只允许 <[^>]+[@.]域名>$ 形式，其他形式整条无效，用户标识的邮箱须匹配；同一签发者对同一用户标识只计最新一份，已撤销或过期的不计；深度超过根给定上限的不计。用越域认证、重复签名、撤销与深度验证。
