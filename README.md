# 物流中转规划器

给定有限班次表与最多 10 批货物，求全部货物送达的**最小总费用**方案，并输出每次装卸与中转衔接。

## 模型与规则

- **绝对分钟计时**：所有时刻为从第 1 天 00:00 起算的绝对分钟，跨午夜自然大于 1440（如次日 01:00 = 1500），输出格式为 `D2 01:00`。
- **固定装卸时间**：货物在 `班次发车时刻 - loadTime` 之前必须到达装车站点；到站后在 `到达时刻 + unloadTime` 才可提取。因此转运必须满足
  `上一班 arrive + unloadTime + loadTime <= 下一班 depart`，**到站时刻不等于可转运时刻**。
- **合车不超载**：同一班次可合装多批，但总 size 不得超过班次容量；批次不可拆分。
- **班次为单次事件**：每个班次在整个方案中至多使用一次。
- **费用**：`班次固定费（载货即收一次）+ perUnitCost × 合装总 size`，目标为总费用最小。

## 求解方法

对状态 `(每批的位置与可提时刻, 已用班次集合)` 做 Dijkstra 搜索：每个状态对每个未用班次枚举可装批次的所有非空子集（满足装货时限与容量），松弛费用边。状态空间有限（可提时刻均取自班次到达时刻），最多 10 批时规模可控。不可行时会区分"单批即不可达"与"合车载重限制"并报告问题批次。

## 运行

```bash
npm install        # 安装 typescript（无网络时可用 Cursor 内置编译器，见 tools/compile.js）
npm test           # 编译并运行测试
npm run demo       # 运行内置示例
node dist/src/demo.js examples/sample.json   # 求解自定义 JSON
```

输入 JSON 格式见 `examples/sample.json`（`handling` / `batches` / `trips` 三段）。

## 文件结构

- `src/types.ts` — 问题与方案的类型定义
- `src/planner.ts` — Dijkstra 求解器与输入校验
- `src/format.ts` — 绝对分钟格式化与方案文本输出（装卸、衔接、各批行程）
- `src/demo.ts` — 内置示例 + JSON 文件入口
- `test/planner.test.ts` — 30 个断言：合车、超载拆分、班次不可复用、转运缓冲、跨午夜格式化等
