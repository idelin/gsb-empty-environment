# trace-veil

可追溯轨迹时态加密索引与假名化审计器（隐私保护的时空数据检索组件）。

- 实体真实 ID 经**带密钥的时变伪随机函数**（HMAC-SHA256，按时间桶轮换）假名化；
- 空间坐标经**加盐网格哈希**（HMAC-SHA256）索引，明文轨迹以 AES-256-GCM 密封存储；
- 日常只读查询仅输出 **k-匿名脱敏聚合热力分布**；
- 出示**司法审计授权凭证**（HMAC 签名、绑定案件号 / 目标 / 时间窗 / 有效期）后，
  系统对目标用户在指定时间段内的轨迹做**定向解密还原**，并写入**哈希链审计日志**。

零第三方依赖，TypeScript 源码由 Node.js（>= 23.6）原生类型擦除直接运行，
测试使用 Node 内置测试运行器（`node:test`）。

## 架构

```
                 ┌──────────────────────── 主密钥（HSM 保管）────────────────────────┐
                 │ HKDF 派生： pseudonymKey │ gridSalt │ recordKey                   │
                 ▼                                                                     │
  ingest ──► 假名 = HMAC(pseudonymKey, entityId|bucket)        时变、跨桶不可链接        │
             格键 = HMAC(gridSalt, 细网格|bucket)              加盐、抗字典攻击          │
             密文 = AES-256-GCM(recordKey, 明文轨迹, AAD=桶|假名|格键)                   │
                 ▼                                                                     │
        TrajectoryIndex（src/store.ts）                                                │
          ├─ heatmap(from,to)  → 粗网格计数，k-匿名阈值抑制（唯一只读出口）              │
          └─ reveal(entityId,from,to) ← 仅由 Auditor 在凭证验证通过后调用 ◄─────────────┘

  AuditAuthority（src/audit.ts）  独立机构密钥，签发/验证授权凭证（签名绑定全部范围参数）
  Auditor        （src/audit.ts）  验证凭证 → 定向还原 → 追加审计日志（拒绝同样留痕）
  AuditLog       （src/audit.ts）  追加式哈希链，verify() 可检测任何篡改
```

| 文件 | 职责 |
| --- | --- |
| `src/crypto.ts` | 密钥派生（HKDF）、时变假名 PRF、加盐网格哈希、AES-256-GCM 密封 |
| `src/grid.ts` | 经纬度 → 网格单元（细 / 粗两级精度） |
| `src/store.ts` | `TrajectoryIndex`：加密写入、聚合热力查询、定向还原 |
| `src/audit.ts` | `AuditAuthority` / `Auditor` / `AuditLog`：凭证、还原编排、哈希链审计 |
| `src/demo.ts` | 端到端运行样例 |

## 安全设计要点

- **时变假名**：假名按时间桶轮换，跨桶不可链接，长期行为画像无法基于假名拼接。
- **加盐网格索引**：索引键为 `HMAC(gridSalt, 细网格|时间桶)`，网格空间有限，
  加盐抵御对网格坐标的字典穷举；盐由主密钥 HKDF 派生，不出系统边界。
- **最小暴露面**：日常查询唯一出口是 `heatmap()`，仅返回过 k-匿名阈值的粗网格计数；
  精确坐标与真实 ID 只存在于 GCM 密文中，AAD 绑定（桶|假名|格键）防止密文迁移重放。
- **定向还原而非万能钥匙**：凭证由独立审计机构密钥签名，绑定案件号、目标实体、
  时间窗与有效期，篡改任一字段即验签失败；还原按桶重算目标假名、精确匹配，
  不触及其他实体；过期、伪造、越权签发均被拒绝并留痕。
- **完整审计链**：每次还原（含被拒绝的尝试）追加一条哈希链日志，
  `AuditLog.verify()` 可检测任何事后篡改。

## 边界说明

本实现为可运行的核心组件参考：存储为内存结构（生产可替换为按 `桶|格键` 分区的
持久化 KV/列存，接口不变）；主密钥与审计机构密钥在真实部署中应由 KMS/HSM 托管，
并通过门限分片或多方共管进一步约束单点解密能力。
