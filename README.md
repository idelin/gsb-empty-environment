高性能存储引擎（如 LeanStore/WiredTiger）在 B+Tree 叶子页中为每页维护闭开范围围栏键 `[low_fence, high_fence)`（最左页 `low_fence` 为负无穷空串、最右页 `high_fence` 为正无穷无界），提取两围栏键的最长公共前缀 `prefix = lcp(low_fence, high_fence)` 并从页内全部键中剥离该前缀，再按每 `R` 条记录设重启点做块内增量前缀压缩；一旦页分裂时没有先把旧页剥离的 `prefix` 还原再针对左右新围栏 `[low_fence, sep)` 与 `[sep, high_fence)` 重新计算各自更长的公共前缀，或把无穷围栏当普通空串计算 LCP，就会引发键损坏、二分查找错位或反向扫描跳过首键。为存储引擎缓冲层交付可嵌入的 C++20 头文件与静态库组件，供索引访问层直接调用实现围栏键前缀压缩 B+Tree 叶/内页管理与双向扫描核。规则：1）每页显式记录 `has_low_fence`、`has_high_fence`、`low_fence`、`high_fence` 与 `page_prefix`（仅当两端围栏均存在时 `page_prefix = lcp(low_fence, high_fence)`，否则为空！）；2）页内条目仅存去掉 `page_prefix` 后的后缀并辅以每 `R`（如 4 或 16）条设一个完整重启点，相邻非重启条目再做局部前缀共享；3）插入触发叶页字节超限时，计算最短合法分隔键 `sep`（满足 `left_max < sep <= right_min` 且尽可能短以最大化子页前缀压缩收益！），重建左右两页各自的围栏键、重算两页新的 `page_prefix` 与重启点并同步提升 `sep` 到父内节点（支持多级级联分裂直至根节点分裂增高）；4）支持 `Get`、`Put`、`Delete` 与跨多页双向有序迭代器（`SeekGE`、`SeekLT`、`Next`、`Prev`，正确处理边界空页、键恰好等于 `sep` 围栏以及首尾页无穷界）。验收用长共同前缀随机与对抗键序列（含空键、含 `0x00` 二进制字节键、极长共享前缀与正反交替扫描）对照 `std::map<std::string, std::string>` 逐操作检验点查、分裂前后围栏不变式、前缀压缩率与全量正反扫描逐键一致。
