# ratpoly — 有理多项式扩展 GCD

单变量有理系数多项式的 GCD / 扩展 GCD 库。采用**子结式 PRS**（fraction-free）
算法抑制系数膨胀，返回**首一**最大公因子与贝祖系数，并用**独立的朴素乘加**
路径验证证书，全程统计系数位长。

## 表示约定

- `Poly` 为稠密系数切片，`c[i]` 是 `x^i` 的系数；规范化后无尾零。
- **零多项式**：空切片，`Degree() == -1`。
- 系数恒为**约分有理数**（`math/big.Rat` 自动保持最简）。

## GCD 约定

- `gcd(0, 0) = 0`，贝祖系数 `u = v = 0`。
- `gcd(0, f) = gcd(f, 0) = Monic(f)`。
- 两个非零**常数**的 gcd 为 `1`（首一常数）。
- **重根**按普通因子处理：gcd 保留每个公共不可约因子的最小重数，
  例如 `gcd((x-1)^3(x+2)^2, (x-1)^2(x-3)^4) = (x-1)^2`。
- 结果一律首一化；贝祖系数满足 `u*a + v*b = g`（有理系数）。

## 算法

1. 一次性通分，把输入提升为整系数多项式。
2. 在 **Z** 上跑**子结式多项式余式序列**（伪除法 + 精确的 β 因子约简，
   Geddes–Czapor–Labahn 形式），中间系数被控制在子结式界附近，
   避免朴素欧几里得在 Q 上的指数级膨胀。
3. 贝祖余因子随同一伪除法步骤同步更新（扩展子结式格式），
   最后按首一化比例换算回 Q。
4. `Stats` 记录迭代步数、每步余式最大位长、余因子最大位长，
   以及验证阶段的乘/加运算计数。

## 证书验证

`VerifyCertificate(a, b, g, u, v)` 使用**独立实现**的朴素乘加与长除法
（不复用库内算术）做符号化精确检查：

1. 零情形符合上述约定；
2. `g` 首一（或为零）；
3. `g | a` 且 `g | b`（长除法余式为零）；
4. `u*a + v*b == g`。

3+4 蕴含“最大”性：任意公因子都整除 `u*a + v*b = g`。
全部检查为精确有理运算，**不做随机点代入**。

## 测试

测试通过**构造已知因子**验证：取 `A = G·P`、`B = G·Q` 且先证 `gcd(P,Q)=1`，
再断言 `gcd(A,B) == Monic(G)`、贝祖恒等式符号成立、商恰好还原互素部分；
另有零/常数约定、重根、系数膨胀对比（子结式 vs 朴素欧几里得位长）、
篡改证书的拒绝等用例。
