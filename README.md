# Solana v0消息地址表加载账户解析

Solana 的 v0 交易用地址查找表加载账户，攻击者可把关键账户放进查找表，使只看静态账户的钱包预览漏掉它们，或让同一账户既在静态又在加载列表里。给Go钱包写供签名前检查调用的 v0 消息策略包，查找表内容由调用方注入，账户顺序与可写判定按 Solana 约定：静态账户在前，随后是各表加载的可写账户，再是只读账户；设头部三个计数为 n签名、n只读签名、n只读非签名，静态账户中前 n签名−n只读签名 个为可写签名者，接着 n只读签名 个为只读签名者，末尾 n只读非签名 个为只读非签名者，其余为可写非签名者。消息首字节须为 0x80（v0），0x81 及以上与小于 0x80 的旧式消息一律拒绝；同一地址出现两次拒绝；账户总数超过 256 拒绝；指令的程序账户索引必须落在静态账户内；拒绝名单检查与可写判定都在完整账户列表上进行。用把拒绝名单账户藏进查找表、程序索引指向加载账户、重复地址和首字节 0x81 验证。
