# cutstock

一维切割库存（cutting stock）精确求解库（Go）。

## 模型

- 母材有多种整数长度，各有采购价格 `Stock{Length, Price}`。
- 零件订单最多 12 个 `Order{Length, Qty}`；同长度不同订单的零件保持区分，
  布局中按订单号标注。
- 每刀损耗锯缝 `k`；每根母材上最后一件不另收尾刀，即一根放 n 件的母材
  刀数为 n-1，锯缝损耗 (n-1)*k，余料 = 母材长 - 零件长和 - (n-1)*k。
- 目标：先最低总采购成本，再最少总余料（字典序）。

## 用法

```go
sol, err := cutstock.Solve(stocks, orders, kerf) // 精确最优
err = cutstock.Verify(stocks, orders, kerf, sol) // 子集分组枚举核对
fmt.Print(sol.Layout())                          // 逐根布局
```

## 方法

- 枚举所有能放进某根母材的非空零件组合（下料模式），每个模式绑定
  （价格最低、再长度最短）的母材。
- 在剩余需求向量上做带记忆化的精确 DP，按 (成本, 余料) 字典序取优。
- `Verify` 独立地把零件按母材分组、按订单分组重新枚举核对：每件归属、
  每根刀数 = 件数-1、余料、需求覆盖与各项总计。
