推理运行时把一组张量切片拼回同一个分配区，语义上每个切片都应读到本次搬运前的内容，而设备只会行 DMA。请交付可导入的 Go 调度包。输入至多十四条逻辑行搬运，源、目的由同一元素宽度和长度的带符号步长视图给出（基址按字节，允许非对齐、重复源和负步长）；单行目的元素不重叠，各行目的字节集合须两两不交，越界或写冲突要返回具体逻辑索引。每条行命令在一个时刻先同时读取该行所有源字节，再写全部目的；行间不原子。可提前把某行原始数据打包到连续暂存区，执行该行时从该区读且执行后释放。物理字节地址序列逐项相同的源行可共享一个已经保存的副本，只有最后一个使用者执行后才能释放；也可选择不使用现有副本直接读。无需保存会读错的行之外的内容。暂存成本按同时存在的打包数据字节总数计算，不计内部碎片。输出最小峰值以及能达到它的保存、搬运和释放流；另写一个检查任意给定流的接口，错误返回第一个读到非原始来源的行、元素序号和字节偏移（按该顺序取最小）。内容相同的数不等于同一来源，按原始分配区的物理字节编号定义语义。长行有 2^40 个元素，元素宽度 1 至 16，禁止展开地址或按分配区大小分配内存。用明确的初始字节标签在短行上独立模拟并与全指令搜索比峰值，覆盖部分字节交叠、指向自身的原样写、反向地址集相同却不能共享暂存以及共享副本跨几个无关搬运存活。
