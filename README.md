# 考试安排工具（examsched）

为考试分配时段与考场，避免学生考试冲突，并对同一学生的连续考试施加分级惩罚。

## 目标

字典序优化两级目标：

1. **最小化最大个人惩罚**（首要）——保证公平，不会为了压低总惩罚而让少数学生承担全部连续考试；
2. **最小化总惩罚**（次要）——在最大个人惩罚不变的前提下整体最优。

求解器用分支限界穷举全部时段分配（考试数 ≤ 12），因此输出是**可证明的最优解**。

## 模型

- 同一学生选修的两场考试不能排在同一时段（硬约束，冲突核验）。
- 同一学生两场考试间隔 `gap` 个时段产生 `gap_penalties[gap-1]` 的分级惩罚，
  例如 `[10, 4, 1]`：相邻时段罚 10，隔一个时段罚 4，隔两个罚 1，更远不罚。
- 每个时段内，考试一一装入考场，考场容量不得小于选课人数（硬约束，考场核验）。

## 使用

```sh
go run .                     # 内置示例
go run . -input example.json # 从 JSON 读取
go run . -v                  # 打印每个学生的惩罚明细
go run . -json               # 输出完整 JSON 报告
go test ./...                # 运行测试（含暴力枚举对照）
```

## 输入格式

见 `example.json`：`num_slots`（时段数）、`gap_penalties`（分级惩罚表）、
`exams`（≤ 12 场）、`rooms`（容量）、`enrollments`（学生 → 考试 ID 列表）。

## 输出

- 每个时段的考试与考场安排；
- **冲突核验**：学生冲突与考场违规（应为零）；
- **惩罚核验**：逐学生重算的分级惩罚、最大个人惩罚与总惩罚；
- 搜索节点数（穷举规模，佐证最优性）。

## 实现要点

- `solver.go`：分支限界。冲突图用位掩码；按度降序排考试；增量维护每个学生的
  惩罚并按下界剪枝；考场可行性用排序形式的匹配条件逐时段检查。
- 对称性破缺只使用**平移**（要求最小时段为 0），因为任意重排时段编号会改变
  间隔从而改变惩罚，不能安全剪枝。
- `verify.go`：独立于求解器重算冲突、考场与全部惩罚，供人工与测试核验。
- `solver_test.go`：用独立暴力枚举对照求解器结果，并测试公平性目标、
  冲突检测、12 场上限与不可行场景。
