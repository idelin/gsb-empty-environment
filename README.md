# domain — 精确定义域分析器

对单变量实表达式做**精确**定义域分析：有理常量、四则运算、`p/q` 次幂，
变量 `x` 取值于给定的有理区间。全部计算基于 `math/big.Rat`，
绝不使用浮点 / NaN 猜测边界。

## 用法

```sh
go run ./cmd/domain 'x^(1/2) + 1/(x-1)' -2 9/2
# domain: [0, 1) ∪ (1, 9/2]
```

或作为库：

```go
e, _ := domain.Parse("x^(2/4)")
d := domain.DomainOf(e, domain.Interval{Lo: lo, Hi: hi}) // 闭区间端点为 *big.Rat
```

## 判定规则（只处理可精确判定的实数分支）

- 指数先约分到最简（`2/4` 与 `1/2` 等价），再按分母奇偶分类。
- 分母为偶：要求底数 `>= 0`（指数为负时 `> 0`），负底数拒绝。
- 分母为奇：负底数取实奇次根，允许。
- 指数为负：底数不得为 0（零的负次幂无定义）。
- 指数为 0：恒为 1（约定 `0^0 = 1`）。
- 嵌套幂按结构逐层分析，**不合并**指数：`(x^(1/2))^2` 的定义域是
  `x >= 0`，而不是 `x^1` 的全体实数。

## 精确性手段

- 零点集：仅对可精确求解的形式求零点（仿射式 `a*x+b`、乘积的零点并、
  商的分子零点、正次幂的底数零点）。
- 符号判定：底数在其定义域区间上连续，相邻零点之间符号恒定，
  取有理样本点（中点）用精确符号规则判定；和式仅在各项符号可合并时
  判定，否则报告无法支持。
- 无法精确判定的部分（如 `x^(1/2)-1` 的零点）记入
  `Domain.Unsupported`，绝不猜测。

## 语法

`+ - * /`、`^` 或 `**`（右结合）、括号、一元 `+/-`（比 `^` 结合更紧）、
整数/小数常量（精确转为有理数）、变量 `x`。指数必须是有理常量，
否则解析期报 unsupported。
