# Wasm GC递归组等价导致私有类型暴露

宿主向不可信 Wasm GC 模块暴露一个带私有字段的结构体引用，模块自己声明了结构完全相同的递归组，再用 ref.cast 转型就读到了私有字段，因为规范化后等价的类型在运行时是同一类型。为 Go 嵌入层写供模块实例化前调用的类型暴露检查包：输入宿主暴露类型的递归组定义和模块各递归组定义（成员为 struct，字段类型为 i32、i64、f64、对本组成员的引用或对更早类型的引用，可带 final 标志与上级类型），按等价规范化比较组内结构而不是比较名字；模块里存在与宿主私有类型规范化后相同的组即拒绝实例化并指出组序号；仅字段顺序、可变性、final 标志、上级类型或引用目标不同时视为不等价。用同构换名、字段可变性不同、引用环、带上级类型和无关模块验证。

## 用法

```go
err := netsec.CheckModule(hostGroup, moduleGroups)
var exp *netsec.ExposureError
if errors.As(err, &exp) {
    // 拒绝实例化：exp.GroupIndex 为违规递归组序号
}
```

- `RecGroup` 用绝对类型索引描述：`Base` 是组内首个成员在类型空间中的索引，引用目标落在 `[Base, Base+len(Members))` 内即组内引用，小于 `Base` 即对更早类型（含上级类型）的引用。
- 等价判定对整组做结构规范化：成员一一对应，final 标志、上级类型、字段序列（种类、顺序、可变性）逐项一致，组内引用经对应关系映射，组外引用须指向同一绝对类型索引。
- 运行 `go test ./...` 可复现同构换名、可变性差异、引用环、上级类型与无关模块等场景的验证。
