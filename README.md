生产级 JIT 与编译器后端的线性扫描寄存器分配器（Wimmer / Poletto-Sarkar 扩展）远非单区间贪心着色：当虚拟寄存器的活跃区间被分支或循环切出多个不连续活跃洞（Lifetime Holes）时，两个外包络重叠但活跃子段互不相交的区间必须能复用同一物理寄存器；遇到函数调用（Clobber 全部调用者保存寄存器）或指令强制固定寄存器（如 `x86` 除法输入输出固定 `R0`/`R1`）时，分配器必须在固定区间之前精确分裂（Split）冲突虚拟区间，将高循环深度的热区间优先留在物理寄存器而将外层冷片段溢出到栈槽；并在控制流边上执行并行移动消解（Edge Resolution），当同一条边上出现 `R1 -> R2, R2 -> R1` 寄存器环交换时必须借用临时槽/交换序列避免覆盖！为编译器后端交付可导入的 Go 线性扫描寄存器分配与执行验证包。输入为带循环嵌套深度的线性化多基本块 IR（含普通虚拟操作数、带固定物理寄存器约束的指令、带 Clobber 集合的 `call` 指令及条件/无条件跳转）与可用物理寄存器数 `K`。规则：1）先执行精确活跃性分析并按线性指令编号构造每个虚拟寄存器的有序不相交子段活跃区间（含活跃洞）与使用位置列表（区分必须寄存器 vs 允许栈槽）；2）把所有固定物理寄存器占用建模为不可驱逐的固定区间（Fixed Intervals），主分配循环按起始位置推进 `active`/`inactive`/`handled` 集合，精准检测当前区间仅与 `inactive` 活跃洞外重合时的冲突、并按“最远下次使用位置 + 循环深度权重”决定分裂点（优先在活跃洞内或循环外边界分裂！）；3）对所有被分裂或跨基本块位置发生改变的虚拟寄存器，在控制流边（必要时分裂关键边）生成完整并行赋值消解序列（含环交换破环！）；4）内置 IR 虚拟执行器与物理寄存器/栈槽目标机执行器，逐路径对比分配前后所有输出与函数调用实参完全一致，且验证每条指令时刻绝无两个同时活跃的虚拟寄存器占用同一物理寄存器或破坏 Clobber 约束。验收覆盖活跃洞共享物理寄存器、固定寄存器指令与 `call` Clobber 前后分裂、循环内保热溢出冷、控制流边寄存器环交换破环及双执行器语义等价验证。
