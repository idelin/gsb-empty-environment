# 带撤销的最小解释集（minwitness）

布尔结果由 AND/OR 无环电路计算，叶子是可撤销事实。对每个当前为真的根，
输出其**最小事实见证集**：一个当前为真的叶子子集，使得“仅这些叶子为真”时根仍为真。

- 重复叶子只计一次（见证集是集合，天然去重）；
- 比较规则：先按集合大小，再按 ID 排序后的字典序，取最小者；
- 撤销/恢复叶子后，值与见证**增量更新**（值沿父链传播，祖先根的见证缓存失效并惰性重算）；
- 最小见证是**全局最优**，不是逐子树局部最优的拼接。

仅使用 Python 标准库，兼容 Python 3.11+。

## 验收边界

`root = (a OR b) AND (b OR c)`：全局最小见证是 `{b}`（1 个事实）。
逐子树贪心会分别选 `{a}` 和 `{b}`，拼出非最优的 `{a, b}`（2 个事实）。
`test_minwitness.py` 中的 `TestAcceptanceBoundary` 覆盖该边界。

## 运行

```sh
python3 minwitness.py [输入文件]   # 缺省读标准输入
python3 -m unittest -v             # 运行测试
```

## 输入格式

每行一条命令；`#` 开头为注释，空行忽略。子节点必须先于父节点定义（由此保证无环）。

| 命令 | 含义 |
| --- | --- |
| `leaf <id>` | 新建叶子事实，初始为真 |
| `and <id> <child>...` | 新建 AND 节点 |
| `or <id> <child>...` | 新建 OR 节点 |
| `root <id>` | 将节点标记为根 |
| `revoke <id>` | 撤销叶子事实（置假，增量更新） |
| `assert <id>` | 恢复叶子事实（置真，增量更新） |
| `value <id>` | 输出 `<id> = true\|false` |
| `witness <id>` | 输出 `<id> = {b}` 或 `<id> = none` |

## 输出格式

- `value`：`<id> = true` 或 `<id> = false`
- `witness`：`<id> = {a, c}`（ID 升序、逗号分隔）；根为假时输出 `<id> = none`；空见证输出 `{}`

## 示例

```sh
$ python3 minwitness.py examples/acceptance.txt
r = {b}
r = {a, c}
r = true
r = {b}
```

## 算法与复杂度

对根锥体内当前为真的叶子，按 (数量, 字典序) 顺序枚举子集，第一个使根为真的
子集即全局最小见证——枚举顺序保证结果**可证最优**。该问题是单调电路的
min-ones（一般情形 NP-hard），因此最坏情况为指数级；适合中小规模电路。
所有示例与测试数据均为合成数据。
