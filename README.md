# llex — 带最优性证据的码长受限编码器

纯 Go 标准库实现，不依赖任何现成压缩库。

## 功能

- **码长受限最优前缀码**（`SolveLengths`，`lengths.go`）：package-merge 算法
  （Larmore–Hirschberg），直接求解长度受限问题，**不是**“普通 Huffman 再截短”。
  - 目标：最小化加权码长 `Σ f_i · l_i`，约束 `1 ≤ l_i ≤ L` 且满足 Kraft 不等式。
  - 决胜规则：同成本时取**按符号 ID 排序后字典序最小**的码长向量。
  - 频数与代价全程使用 `math/big` 精确整数，支持任意大的频数。
  - 空字母表 → 空码表；单符号 → 码长固定为 1；零频符号照常获得合法码字。
  - `n > 2^L` 时返回 `InfeasibleError`，附 Kraft 证据
    （`n · 2^-L > 1`，最多 `2^L` 个码字）。
  - 大 `L` 不会枚举 `2^L` 个叶子：最优完全码深度不超过 `n−1`，算法把有效
    `L` 钳制到 `min(L, n−1)`，复杂度与 `2^L` 无关。
- **规范码与线格式**（`code.go`、`format.go`）：由码长表导出规范码
  （按 `(码长, ID)` 顺序连续赋值），格式显式包含符号顺序、码长、原始符号数、
  有效位数与 CRC32 校验。解码拒绝：非规范（非零）填充位、过订阅码表
  （Kraft > 1）、非法码字（不完整码表的空洞**不会**被补成任意符号）、
  输出额度超限、截断码字、越界计数。
- **分块文件编码器**（`chunk.go`）：在任意候选边界切块，每块独立求解满足
  `L` 上限的码表；用精确动态规划按“索引项＋码表头部＋数据位＋对齐填充”的
  真实总字节数选择**全局最优**分块，绝不把局部最优块拼起来冒充全局最优。
  - 边界数量（`MaxBlocks`）与块内符号上限（`MaxBlockTokens`）显式配置。
  - `EvalBudget` 限制精确块评估次数；预算不足时结果保留可行方案与可靠下界
    （逐块熵下界，`Optimal=false`），可行解路径的评估不占用预算。
  - 块索引支持随机解码（`DecodeFileBlock`）。
  - 流式解码器（`stream.go`）：任意字节分片输入、背压暂停（`emit` 返回
    `false`）都不改变解码结果；篡改的索引/长度只会报错，不会越界分配。

## 复杂度

设 `n` 为符号数，`L` 为最大码长，`L' = min(L, n−1)`：

- 码长求解：`O(n log n + n·L')` 次大整数运算（L 层，每层归并两个有序表），
  操作数宽度 `O(n·log L + log f_max)` 位；空间 `O(n·L')`。与 `2^L` 无关。
- 规范码构建/校验：`O(n log n)`。
- 分块 DP：`O(K·N·M)` 条转移（`N` 个 token、`K` 块上限、`M` 块内符号上限），
  每个候选块一次 `O(a·L')` 的 package-merge（`a` 为块内不同符号数），结果缓存。

## 最优性论证要点

- package-merge 精确求解“硬币收集者”形式的长度受限问题，得到 Kraft 和 ≤ 1
  下的最小加权码长；最优解必然饱和 Kraft（否则可缩短某码长，与字典序最小
  矛盾），故是合法完全前缀码。
- 决胜通过精确符号扰动实现：取 `B = L+1`、`C = B^n`，符号 `i`（按 ID 序）
  以权重 `w_i = f_i·C + B^(n−1−i)` 求解。组合目标
  `Σ l_i·w_i = C·(Σ l_i f_i) + Σ l_i B^(n−1−i)` 的高部唯一确定加权成本、
  低部（一个 B 进制数）唯一确定码长向量本身，因此组合目标的唯一最小解
  正是字典序最小的最优向量。
- 分块 DP 枚举所有合法划分（边界 × 块数），代价为真实文件字节数，故在候选
  边界集合上是全局最优；预算耗尽时，未评估的块用熵下界替代参与下界 DP，
  保证 `LowerBound ≤ 真实最优 ≤ Feasible`。

## 验证（两层）

1. **码长层**（`lengths_test.go`）：对小字母表独立枚举全部合法码长向量
   （`1 ≤ l_i ≤ L`、Kraft ≤ 1），逐位比较成本与决胜结果（500 组随机用例，
   含等频、零频、巨频 `≥2^60`、偏斜分布）。另有具体案例：等频、零频符号、
   `2^L` 边界（`n=2^L` 可行 / `n=2^L+1` 不可行并给出证据）、`L=10^9` 不枚举
   叶子、字典序决胜（`[1,2,3,3]` 胜 `[1,3,3,2]`）。
2. **分块层**（`chunk_test.go`）：对短符号序列枚举全部候选分块，验证含索引、
   头部与对齐的全文件最优性（150 组随机用例）；构造贪心分块必然失败的具体
   案例（7×A+1×B：贪心 8 块 vs 最优 1 块）；预算不足时验证
   `LowerBound ≤ 最优 ≤ Feasible` 且文件仍可完整解码；随机解块与整文件解码
   一致；篡改索引/长度（含修复校验和的结构性篡改）全部报错；流式解码在随机
   分片与随机背压下结果不变。
