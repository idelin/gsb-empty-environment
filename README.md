# SAML引用解析选中了攻击者断言

服务提供方接收带多个签名对象的SAML Response，攻击者可复制ID或利用包装元素让XML库验签一个节点而业务代码读取另一个Assertion。请实现嵌入登录服务的TypeScript SAML验证组件，输入保留节点身份的已解析XML树和原始字节定位，不允许验证后再次按XPath搜索。只接受明确命名空间下的Response、Assertion、Signature、Reference与ID属性；全树ID必须唯一，禁止DTD、实体、XSLT、未知签名变换和包围签名歧义。每个Reference URI只能是同文档单一ID，摘要和SignedInfo规范化按配置的安全算法执行，签名证书绑定租户IdP元数据代次。策略指定必须签Response、Assertion或两者，验证成功后返回被签节点的不可变句柄；issuer、destination、audience、InResponseTo、时间和SubjectConfirmation全部从该句柄读取。用重复ID、Assertion移位、命名空间重绑定、未签Response内的已签旧Assertion、多Reference混淆及合法双签响应验证业务对象与验签对象恒等。
