# voxelsurf

体素集合表面积库（Go）。输入为整数坐标的体素集合（重复坐标只计一次），输出：

- **全部暴露面面积** `TotalSurface`：所有与空气接触的 unit 面；
- **外表面积** `OuterSurface`：只计接触外界空气的面，封闭空腔的内壁不算；
- **空腔证据**：每个封闭空腔的体积 `Cavity.Volume` 及其围面编号 `Cavity.Faces`；
- **面编号证据** `Faces`：每个暴露面的编号、所属体素、法向、分类（`outer` / `cavity #k`）。

约束：体素数 ≤ 10000，坐标跨度任意大（`int64`），**不分配包围盒**（连压缩后的也不分配）。

## 算法（坐标压缩洪泛）

1. **坐标压缩**：每个轴压缩为"平面"——每个出现过的体素坐标一个平面、相邻坐标间距 ≥ 2 处插入一个间隙平面、两端各一个边界平面。压缩模型中空气的面邻接关系与真实模型等价。
2. **关键观察**：间隙平面与边界平面是延伸到无穷远的平板，必然属于外界空气，因此空腔细胞只会落在三个轴都是体素坐标的格点上，且每个恰好代表一个单位立方体——空腔体积就是细胞计数。
3. **射线封锁**：封闭空腔中的细胞，其 6 个轴向射线必然都被实心体素挡住（否则该射线就是通向无穷远的空 corridor）。于是洪泛只需从实心体素的 ≤ 6n 个空邻居出发、只经过射线封锁的细胞：洪泛遇到非封锁细胞 ⇒ 整个连通分量是外界空气；洪泛耗尽 ⇒ 找到一个封闭空腔。
4. **复杂度**：由 Loomis–Whitney 不等式，射线封锁的空细胞数 ≤ n^(3/2)（它们的三个正交投影都被实心集合的投影覆盖），n = 10000 时约 1e6，与坐标跨度无关。总复杂度 O(n log n + n^(3/2) log n)，内存 O(n + n^(3/2))。

朴素做法（压缩网格上整体洪泛）在坐标稀疏时仍有 O(Ny·Nz) 个压缩行要扫（n=10000 时可达 4e8），本实现用射线封锁约束规避了这一点。

## 对照验证

`AnalyzeBrute` 是独立的**小包围盒逐格模型**：直接分配整个（加边的）包围盒、逐格外界洪泛、逐面分类。`voxelsurf_test.go` 中的 `TestDifferentialRandom` 用 300 组随机数据（稠密团块、带间隙平面、随机游走、随机破洞壳层、遥远坐标、重复坐标）逐面对照两个实现：总面积、外表面积、空腔体积多重集、每个面的分类及其空腔体积必须完全一致。

## 用法

```go
res := voxelsurf.Analyze([]voxelsurf.Vec3{{X: 0, Y: 0, Z: 0}, ...})
fmt.Print(res.Summary())   // 面积与空腔汇总
fmt.Print(res.Evidence())  // 逐面编号证据
```

命令行演示（标准输入读 "x y z" 行）：

```sh
go run ./cmd/voxdemo [-faces] < voxels.txt
```
