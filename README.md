# 包源映射与保留前缀的整次还原准入

企业内部包只应来自私有源，攻击者会在公共源抢发同名高版本包，或抢先登记保留前缀后发布仿冒包。为Go包还原服务写可导入的源决策与发布准入包：源映射模式为字面ID或以*结尾的前缀，ID比较不分大小写，每个包ID只取最长匹配模式对应的源集合，并在该集合内选满足约束的最高版本，无匹配模式则不从任何源还原，也不回退到其他源；版本约束与大小比较由调用方注入。一次还原递归处理整张依赖图，任一包无可用源或所在源缺少满足约束的版本，整次还原失败，还原缓存不得写入任何条目。映射表可被管理员原子替换，一次还原从开始到结束只用开始时的那一版，并发替换不得让同一次还原混用新旧模式。保留前缀以点结尾，先登记者为所有者，同一前缀并发登记只有一个成功；非所有者发布落入保留前缀的ID被拒，被拒发布不得出现在任何源的索引里。用公共源同名高版本、最长前缀、大小写、依赖图深处无映射、还原途中换表和并发登记验证。
