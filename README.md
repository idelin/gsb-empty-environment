# 前缀有效性预言的多区间收缩

密码实验服务只返回RSA解密值是否落入固定前缀区间，仍可能泄漏整段明文。请给Go回归宿主实现可导入的自适应恢复包：本地合法RSA公钥(N,e)，k为N的字节长度且k≥3，B=2^(8*(k-2))，目标密文c对应未知m并已知2B≤m<3B；预言对x只回答2B≤Dec(x)<3B、否或暂时不可用，这不是完整填充格式校验。允许查询c*s^e mod N，须通过有效乘数s和整数商范围不断收缩候选整数区间并合并相邻区间，不能逐个枚举m；端点全部用精确大整数。暂时不可用消耗查询预算但不改变候选集，预算耗尽返回完整区间及下一搜索位置；恢复检查点必须绑定公钥、目标密文和已记录查询。只有剩一个整数且重加密匹配c时才成功，伪造或矛盾的回调结果报不一致。用小RSA模数逐明文枚举验证区间更新，覆盖一次反馈产生多个区间、边界2B与3B-1、空交集和从中断处恢复；只连接本地夹具，不输出未验证的明文猜测。
