混合语言安全运行时在 C++ 与外部 FFI 插件之间传递借用切片、回调函数与不透明句柄时，若静态/动态审计器未追踪跨边界的生命周期所有权转移（`Owned` vs `Borrowed`）与可变别名互斥（Aliasing XOR Mutability），插件可能在宿主释放缓冲后继续解引用或制造数据竞争。为 C++17 运行时安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 FFI 跨边界生命周期与别名安全验证库。库建模宿主分配区、借用句柄表、代次（Generation）计数器与 FFI 调用事件流（`AcquireOwned`/`BorrowShared`/`BorrowMut`/`Release`/`InvokeCallback`）：（1）强制所有活跃借用必须在宿主释放目标对象前全部归还，任何在活跃 `BorrowMut` 期间发起的并发 `BorrowShared`/`BorrowMut` 或释放后访问立即判为 UB 阻断；（2）支持跨多跳回调重入检测，防止外部回调重入宿主修改正在迭代的容器；（3）提供有界 6 步对抗序列搜索器，自动找出能触发跨 FFI 悬垂引用或双可变借用的最小调用序列。附确定性边界与重入对抗测试。
