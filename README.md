# KV前缀缓存跨租户命中

推理服务共享前缀KV缓存，若键只含token序列，租户A可能命中租户B带私有系统提示的状态。给Go推理宿主实现可导入的前缀缓存包：缓存身份绑定tenantID、模型权重摘要、适配器摘要、tokenizer摘要、解码位置、规范token前缀摘要、安全策略代次和KV布局版本；条目含每层K/V块句柄、有效token范围、创建代次、引用租约和由宿主密钥计算并绑定完整身份及块摘要的内容MAC。只有身份全部相同且MAC通过才命中；调用方可配置明确publicScope，使指定公开前缀跨租户共享，但其token原文摘要、模型/适配器/tokenizer/策略仍全绑定，私有后缀从新块开始。取消或请求失败只减租约，最后租约归还后秘密块清零再入池；池槽复用带代次，迟到填充不能覆盖新条目。前缀扩展采用写时复制，旧条目不可原地附加私有token。实现待审cacheKey回调的有限差分搜索，找弱键相同但规范身份不同且标记KV解码出另一租户秘密token的最短例。覆盖同token不同系统提示摘要、模型量化摘要变化、适配器切换、publicScope边界、取消/填充竞争和槽位复用。
