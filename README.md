多租户代理把内部的签名与重试事件隐藏起来，外部租户只能观察响应类别、长度桶及先后，不能据此区分两个秘密初态。为 Go 代理写可导入的协议准入包，用宿主给出的有限状态机描述公开输入、内部不可见步和外部可见事件。同一状态对公开输入可有多个后继；秘密初态分成两组。要求对每个相同的公开输入序列，两组所有可能的有限可见事件序列相同，不能用逐状态一一配对代替语言等价。结束和显式超时是不同的可见符号，纯内部环本身不算一次结束。只有通过校验才能向代理注册协议版本，注册句柄绑定冻结表摘要及观察者的投影规则，投影规则变化后旧凭据失效。返回由成对状态子集组成的证明，独立验收函数只读原表逐步核对初始闭包、每个公开输入和可见符号的后继闭包及接受条件。每台机器至多12个状态；用小表枚举核实证明，覆盖隐藏环、多分支合流、仅结束可见性不同和一侧的两条分支合起来才与另一侧相等。
