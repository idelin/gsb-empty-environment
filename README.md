# streamdec — 增量事件式对象流解码器

纯 Go 标准库实现。解码器可在**任意字节**暂停与恢复，以事件形式输出
字段开始/结束与值，**单个对象完整后才发布**其全部事件，错误携带**绝对
字节偏移**。解码过程不执行任何宿主代码：输入字节只驱动状态机、填充
缓冲区。

## 线上格式（自行定义的序列化范围）

每条消息 = **4 字节大端 uint32 长度头** + **JSON 子集对象负载**。

```
+--------+--------+--------+--------+-------------------+
|              length (BE)          |   object payload  |
+--------+--------+--------+--------+-------------------+
```

负载支持的序列化子集：

- 顶层必须是**对象**（object），对象可嵌套，最大深度 128；
- 键：字符串，支持全部 JSON 转义（含 `\uXXXX` 与代理对）；
- 值：字符串（UTF-8 校验）、数字（严格 JSON 数字文法，解析为
  `float64`）、`true` / `false` / `null`、嵌套对象；
- 不支持：数组、顶层标量、单引号、尾逗号、注释、`NaN`/`Infinity`；
- 允许 JSON 标准空白（空格、`\t`、`\n`、`\r`）。

## 安全性质

- **先验证长度再分配**：长度头超上限（`NewDecoder(maxObjectSize)`）或
  为零时直接报错，不会按头部声明分配内存；
- **长度头可拆多块**：头部自身按字节累积，跨块拆分不影响正确性；
- **深度上限**：嵌套超过 128 层报错，防止栈耗尽；
- **不执行宿主代码**：无 `eval`、无反射、无 `interface{}` 断言以外的
  任何动态行为；
- **finish 校验**：`Finish()` 遇未闭合对象或截断的长度头报错；
- **取消释放缓存**：`Cancel()` 丢弃当前对象的负载缓存与已缓冲事件，
  解码器可复用于新流。

## API

```go
d := streamdec.NewDecoder(1 << 20) // 最大对象 1 MiB
events, err := d.Feed(chunk)       // 任意大小的块；返回本块内完成对象的事件
if err != nil { /* err.(*streamdec.Error).Offset 为绝对偏移 */ }
err = d.Finish()                   // 流结束时校验边界
d.Cancel()                         // 消费者取消：释放当前对象缓存并重置
```

事件类型：`EventObjectStart` / `EventObjectEnd` / `EventFieldStart` /
`EventFieldEnd` / `EventValue`（值为 `string`、`float64`、`bool` 或
`nil`）。`Event.Offset` 为对应 token 在流中的绝对偏移。
