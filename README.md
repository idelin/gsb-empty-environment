浏览器承诺，同一组可串通站点在一次会话里得到的全部公开结果，不能把任何用户属性值的后验概率提高到先验的三倍以上。请给TypeScript隐私宿主写可导入的放行器。输入是有限的秘密取值和正有理先验、每个已签工作模块在各秘密下产生可见候选编号的概率表，以及公开的站点合并与重放事件。模块可按已见结果自适应选择，两个编号若解析到同一公开资源，观察者只见合并后的值。合并两个观察者时按共同事件ID去重并按原始顺序计算联合似然；同一次抽样被两方各见不同投影时须取联合原像，不能把它算成两次独立抽样，且允许条件退避分支引入空观测。不同抽样给定秘密后独立。准入前对本次每个可能结果核算，任一超额就对所有秘密走同一固定拒绝结果，不留下可见的部分扣费或差异化错误码。用精确分数返回最坏后验、达到它的秘密和观察证据，用小事件树穷举验证边际均合规而合并后越界、零概率分支、条件空观测、重放与分母恰好相等。

## 模块

- `src/fraction.ts`：`Fraction`，基于 bigint 的精确有理数，全程不经过浮点。
- `src/privacy-gate.ts`：`PrivacyGate` 放行器与全部输入/输出类型。
- `src/event-tree.ts`：`enumerateTree` 小事件树穷举器，支持自适应模块策略。
- `src/index.ts`：统一导出入口。

## 语义

- 准入门槛：对任一秘密 `s`，要求 `posterior(s) <= bound * prior(s)`，默认 `bound=3`；
  比值等于 `bound` 合规，严格大于才越界。
- 新事件 `propose` 会先枚举该模块每个可区分公开结果的后验；任一结果在任一秘密下超额，
  整个事件返回对所有秘密完全一致的固定拒绝资源，不写入任何约束或日志。
- `resolution` 中解析到同一资源的候选编号对观察者不可区分；`null` 表示条件退避空观测，
  其似然是该空桶内所有候选概率之和。
- 相同 `eventId` 视为同一次抽样的重放：按 `observedResourceId` 取第二投影的原像，
  与已有原像做交集，联合似然只计一次，不会按两次独立抽样连乘。
- `merge` 合并观察者时按共同事件 ID 去重（走重放交集），其余事件按对方原始顺序追加；
  任一步骤越界则整体回滚，宿主状态不变。
- 不同抽样在给定秘密下条件独立，联合似然为各抽样因子的精确乘积。
