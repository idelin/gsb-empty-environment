# antientropy

反熵同步工具：两端各为键值集合构造**固定范围摘要树**，递归交换摘要定位差异并收敛。

## 设计

- **固定键空间**：键经 FNV-1a 映射到 `[0, 2^64)`，树覆盖整个固定范围。
- **分裂规则**（`Config`）：桶内记录数超过 `MaxLeafItems` 且深度未达 `MaxDepth`
  时，按区间中点二分。树形只取决于键集合与分裂规则，与插入顺序无关。
- **摘要**：叶节点对记录摘要（含版本与墓碑标志）做 XOR 聚合；内部节点确定性
  合并左右子摘要。相同内容、任意构建顺序产生相同树形与摘要。
- **递归同步**（`Sync`）：摘要相同则跳过整棵子树；叶摘要冲突时交换该范围内
  的**真实记录**（含删除墓碑），按 last-writer-wins（版本高者优先，同版本
  墓碑优先）合并进两端存储。
- **通信计数**（`Stats`）：递归轮次、摘要消息数、记录消息数、传输记录数、
  被剪枝子树数。

## 使用

```go
st := antientropy.Sync(storeA, storeB, antientropy.DefaultConfig)
```

## 测试

```sh
go test ./...
```

覆盖：空范围、倾斜键（深层非平衡分裂）、不同构建顺序产生相同树形、
墓碑参与摘要并传播、通信计数与剪枝有效性。
