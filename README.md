# batcher

Go 客户端分批请求引擎：响应按请求 ID 对齐，容忍乱序、缺失与重复，
由服务端单调提交版本裁决终态。

## 语义

- **分批发送**：`New(transport, batchSize, maxAttempts, reqs)` 将请求切批后顺序派发。
- **ID 对齐**：响应可乱序、部分缺失或重复，逐项按 `Response.ID` 归位；未知 ID 忽略。
- **失败不覆盖**：批级失败（`Send` 返回 error）与单项失败（`Response.Err`）都不会
  覆盖已确认项；缺失项进入下一轮重试，且保持原始请求 ID。
- **版本裁决**：同一项可跨多个尝试在途；更高的提交版本获胜，旧版本（含旧失败）被丢弃；
  同版本异值判定为冲突，该项被隔离、不再重试，经 `Conflicts()` 上报。
- **取消**：`ctx` 取消仅停止未派发的项，已在途的批次正常完成。
- **检查点**：`Save`/`Restore` 保留请求身份、确认版本与缺失集；恢复后仅重发缺失项，
  故障重放（旧版本或同版本同值）不会回滚已确认状态。

## 测试

```sh
go test ./...
```

`scriptTransport` 按脚本编排每批的响应/故障，覆盖空批、乱序缺失、重复冲突、
批级失败、跨尝试在途、取消、检查点恢复与故障重放等场景。
