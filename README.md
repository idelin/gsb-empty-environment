边缘路由器把流量交给两个顺序串联的双桶着色级。为驱动的配置检查器写可导入的 Go 包：每桶容量、初始令牌和按周期补给序列全为整数，满桶丢弃溢出，给定明确的先补再发顺序。每级按输入颜色上限依次尝试绿桶再黄桶，够包长则只扣命中桶，否则输出红；第二级接受第一级颜色。对给定循环报文日历和两套不同配置，求第一个最终颜色不同的报文并输出两边逐级扣款见证，若永远相同则出具可核验的周期等价证明。桶容量及重复空闲时隙可到 2^50，禁止逐空闲时隙推进；对于持续满载、单一包长且连续同一扣款模式的 2^45 个报文也不得逐个执行。交付独立逐包小规模参考测试，覆盖阶段内颜色不同而最终一样、溢出后重新收敛及恰好够一包的边界。
