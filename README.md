多租户 JWT 网关同步三地密钥目录，轮换期间三个副本可能依次看到不同版本。给 TypeScript 网关写可导入的签名验证组件。宿主固定每个租户的目录根公钥、颁发者及受众；每个目录增量签名绑定租户、前版摘要、版本、密钥用途、算法、激活和撤销时刻。kid 可在不同代复用；一个令牌只能用同一份已认证快照里的密钥、算法和有效期验证，不能拼接多个快照，也不能仅按 kid 缓存验签。网关可在缺前驱时暂存增量；只有两个不同副本对同一版本摘要给出带签名确认才可发布。若发现同一根下同版本的有效增量分叉，冻结该租户的放行，直到受信根明确引用两支头部签出处置结果。接收令牌时须检查签名、issuer、audience 与租户策略；若验证过程中发生撤销，最终发出授权前须再次检查使用的密钥代次。用本地生成的 Ed25519 密钥以及虚拟时钟，覆盖同 kid 换钥、跨租户共享公钥、迟到前驱、一个副本重复确认、分叉恢复和验签后撤销，验证其他租户在冻结期间仍可正常工作。
