# 签名nonce仿射关联的私钥暴露

签名服务迁移随机源后，怀疑两次签名使用了满足k2=a*k1+b mod n的nonce。给Go密码审计宿主交付可导入的验证包，输入P-256公钥、两份消息摘要、两份ECDSA签名及a、b，n取曲线阶；r、s必须在1至n-1，a、b必须在0至n-1，公钥必须是曲线上非无穷远点，所有标量先验证范围，摘要按ECDSA左侧截断到n的位数解释，先验签再分析。服务可能把s换成n-s，所以必须检查每份签名的两个符号选择；按s*k=z+r*d的模n方程恢复候选私钥d与nonce，并用基点乘法同时验证公钥、两个r及仿射关系。线性方程退化时返回信息不足，不枚举私钥空间，不将无候选误称安全；多个有效候选需全部返回并注明歧义。输出推导中用到的符号选择和方程，可由独立回调重验。测试密钥与nonce均由本地夹具创建，覆盖相同nonce、非零偏移、仅一份签名low-s化、无关系但均验签成功及退化方程；不连接真实签名服务，不以r相同作为唯一检测条件。
