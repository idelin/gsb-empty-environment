# 分组限流模拟器

按轮分配的分组限流模拟器（Go 实现）：每组保留最低额度（保底），空闲份额可暂借
给其他组；组恢复活跃后下一轮收回借额，已发出的许可不撤回。

## 语义

- **保底**：每组有保留额度 `reserve`，且 `Σreserve ≤ total`。每轮分配时，有等待
  请求的组先用自己的保留份额满足请求。
- **借出**：保底分配后剩余的空闲容量（空闲组的保留份额 + 未保留余量）按轮转
  （round-robin）方式借给仍有等待请求的组。
- **收回**：借出只影响当轮；拥有份额的组恢复活跃后，下一轮其保留份额优先用于
  自己（取消事件释放的容量先补保底），但已借出并已发放的许可不撤回。
- **组内 FCFS**：每组的请求进入 FIFO 队列，许可严格按到达顺序发放。
- **取消事件**：释放该组最早持有的许可；若该组无持有许可，则丢弃其队首的待处理
  请求。

## 输入格式

从标准输入读取脚本，每行一条命令，`#` 开头为注释：

```
total 5            # 总许可容量（须为第一条命令）
group a 2          # 声明组 a，保底 2
req a              # 组 a 提交一个请求（当前轮）
cancel a           # 取消：释放组 a 最早持有的许可
alloc              # 执行一轮分配，输出本轮发放的许可
status             # 向 stderr 打印各组 active/pending 状态
```

脚本末尾如有未 `alloc` 的事件，会自动补一轮分配。

## 输出

每个许可一行，按发放顺序输出到 stdout：

```
round=1 group=b req=1
```

`req` 为组内请求序号（从 1 开始），可用于核对组内先来先服务。

## 运行

```sh
go test ./...          # 运行不变量测试（保底 / 总量 / 组内 FCFS）
go build -o grouplimiter . && ./grouplimiter < script.txt
```
