# temporalfx — 可审计汇率走势时态折算器

跨国交易多时区汇率双时态折算器，Go 标准库实现，无第三方依赖。

## 模型

每条汇率发布是不可变版本，携带两个时间维度（内部统一归一为 UTC）：

- **Effective（牌价生效时间）**：汇率在业务上开始有效的时刻；
- **Known（知悉时间）**：发布中心实际收到该牌价的时刻。

折算语义：对交易时刻 `txnTime`、知悉视角 `asOf`，在
`Effective <= txnTime 且 Known <= asOf` 的版本中，按
**生效时间 → 知悉时间 → 发布序号** 取最新者。由此天然支持：

- **延迟发布**：牌价生效早于知悉，交易可回溯命中；
- **紧急更正**：同一生效时刻的新版本在更正知悉后取代旧版本，
  但更正前的知悉视角查询仍返回旧版本（历史不可篡改）；
- **多时区**：录入时携带各自时区，统一按 UTC 时刻比较。

每笔折算返回 `Conversion` 审计记录（命中版本、折算依据、金额），
并追加进 `Store.AuditLog()`；金额用 `math/big.Rat` 精确计算。

## 验收场景

交易业务 10:00 发生；10:05 收到 10:00 生效的汇率 A(7.20)；
10:10 收到对 10:00 牌价的紧急更正 B(7.25)：

| 知悉时间查询 | 命中版本 | 牌价 | 1000 USD 折算 |
|---|---|---|---|
| 10:06 | `USD/CNY#1` (A) | 7.20 | 7200 CNY |
| 10:11 | `USD/CNY#2` (B, 更正) | 7.25 | 7250 CNY |
