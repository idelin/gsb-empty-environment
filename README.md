归档修复服务能读取某对象若干历史代的稀疏碎片与分段 XOR 校验；不同代之间只有明确声明未改动的逻辑区间才共享符号。请写可导入的 Go 包，对多次修复请求找最小读取费用的自适应计划：一次读取返回一个给定的二进制线性投影，最多一台故障设备会对其所有返回施加同一个未知固定异或向量。控制器可依据先前的返回选下一读，目标是确定所需区间的原始位值而非定位故障设备。若不能确定，返回两套与全部观察相容而目标不同的原始值、故障设备与掩码。干净设备读取结果也可能与某个故障解释重合。交付符号化策略 DAG、查询接口和不调用规划器的校验器；先最小最坏费用再最少最坏读次，同价按动作号。小实例以全部真实世界与策略树穷举；大实例有 120 个源位但候选读取至多十次、每次一至三位，不能列举原始对象。
