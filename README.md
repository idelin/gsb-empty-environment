一个有状态 Pod 的数据卷和日志卷由不同后端提供。迁移节点时，挂载插件只接受覆盖整个卷组的一张许可证。为控制器实现可导入的 Go 调和包，输出可原子持久化的状态和可重复投递的设备命令。每个卷各自持久化单调世代以及获准节点，设备命令只能做精确比较并交换，回执携带请求号、设备身份及实际世代。设备可以独自重启但保留栅栏。许可证要列出每卷身份和世代，节点仅在所有卷仍认可该节点及对应世代时有整组写权。迁移期间允许更换目标、取消迁移返回旧节点，以及把组中某卷替换为已确认兼容的新设备；替换设备前必须收到旧设备停止接受旧组写入的回执，即使旧设备暂时失联。旧节点和新节点都可能缓存任意历史许可证。持久状态须在任意一条消息投递后可恢复，迟到的成功回执不能复活已撤销的组配置。给出真正调用调和包的持久化宿主和独立设备模拟器，穷举两卷三节点的小规模事件交错，包含部分卷已切走后取消、同一逻辑卷名换物理身份后收到旧确认、崩溃后重复投递。逐步检查任意两张已签发的许可证不能同时让不同节点拥有整组写权，也不能向目标提前发证；在配置稳定且消息最终送达时演示最后的目标获得写权。
