加密卷升级会同时留下两套元数据，校验和正确也可能引用正在重写的密钥槽。写一个可导入的 Go 恢复包给卷宿主调用。输入是只读块镜像及选定的当前信任根；两个头各自包含代次、父头摘要、槽区间、加密段区间和已签名的槽到段授权。每个槽由多个独立写入单元组成，单元带版本和内容承诺；范围可以相交但不可将同一物理单元的新内容解释成旧槽。只有全部引用经核对且没有混合代次的头可用于解锁，冲突的同代有效头报分叉。另给目标头、可用备用单元、有限写入及冲刷动作，单次冲刷之前的写在崩溃时可持久化任意子集，跨冲刷有序；至多 16 个动作。规划最少冲刷次数，使每个崩溃镜像都至少有一套完整受信授权，可使用旧头或新头，但任何已不可撤回的撤销都不能被旧头恢复。将撤销承诺作为单独可靠单调寄存器，写该寄存器也算动作。无安全计划须给可核验原因，状态预算不足须返回未知。用内存块设备穷举小例的持久化子集，对照重叠槽、同代分叉、两次写同单元和撤销提交早于备用头的情况，不依赖真实设备。
