# BFCache恢复了注销前的敏感页面

用户注销后按后退键恢复BFCache页面，旧DOM、内存令牌或可提交表单可能继续访问敏感数据。给TypeScript浏览器宿主实现可导入的页面冻结与恢复状态机：文档身份绑定topLevelSite、origin、browserSessionID、documentGeneration、authSessionID及策略代次；进入BFCache前触发pagehide并冻结定时器、网络能力、表单提交能力和MessagePort，保存的DOM快照只能在内存中。认证服务向宿主发送由账户认证服务Ed25519签名的AuthEpoch事件(accountID,authSessionID,epoch,state Active/Revoked)，注销、密码重置或风险升级递增epoch并Revoked。pageshow恢复前重新读取当前AuthEpoch和策略：只有原authSession仍Active、epoch/策略/分区全匹配才解冻；否则把旧文档标Discarded，清理敏感状态并执行全新导航，旧脚本不得先运行任何任务。冻结期间到达的网络响应、消息和Promise回调绑定旧文档代次，恢复成功后也按原顺序投递，失败恢复全部丢弃。实现确定事件循环，交错pagehide、注销事件、pageshow和迟到响应，搜索待审实现在Revoked后产生敏感DOM读取或网络提交的最短轨迹。覆盖多个历史项、同会话策略收紧、跨站后退和响应先于注销但投递晚于注销。
