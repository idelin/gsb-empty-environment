对象库对外只返回某租户能看见的目录名，隐藏对象不能通过分组计数、页游标或空页暴露出来。给Go读取宿主写可导入的目录投影器。底层有多层不可变有序段，键为任意字节串，版本按单调代次取最新，同代次删除标记优先；策略由前缀许可与拒绝构成，最长匹配生效，同长拒绝优先。调用方可选多字节分隔符和起始前缀，分组只由至少一个可见对象产生。每页返回按原始字节序的对象或公共前缀，游标须绑定快照、策略摘要和请求，不能包含隐藏原键；分页串接必须与一次全量投影逐字节一致。底层提供前缀范围的计数与跳过接口，只含拒绝对象且无更深许可的区间不能逐键读。输出能复验的跳过理由。用小键空间参考模型检验全为FF的上界、删除遮挡旧版、分隔符重叠、允许子前缀嵌在拒绝前缀内，以及增删隐藏对象时公开答复与游标均不变。
