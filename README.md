# tagcache

条目-多标签缓存（纯标准库，无远程缓存依赖）。

- 条目可关联多个标签；标签版本（代际）变化使相关条目失效
- 删除条目时清理 tag→条目 反向索引
- 加载期间标签变化通过代际校验丢弃（`ErrStaleGeneration`）
- 数据源、时钟、失败点均为可注入函数；加载资源（`Release`）在成功/失败/过期三种路径都保证释放
- 计费按去重后的条目计，同条目两个标签不重复计费
- 删除标签只移除该标签的关系，不影响条目的其他标签
- 失效与写入竞态在同一把锁下做代际比对，不留下旧代际的有效条目

## 运行

```sh
go test -race -v ./...   # 测试
go run ./cmd/demo        # 演示
```
