监控服务先收到部分证据，随后可能收到经认证的更正：某个进程实例绑定错了命名空间，或一段流的覆盖水位被撤回。请给 TypeScript 告警宿主实现可导入的增量判定组件。每项观察带来源、签名代次、序号区间和稳定事件身份；更正必须精确引用被替代证据，同一序号两份不同合法内容视为分叉。规则可合取多个来源的事实，也可要求某时段没有授权事件；否定条件只有在整个区间有同一有效分支上的覆盖证书时成立。一个确定告警可能有多组独立支持，撤销其中一组不能立即撤回告警，也不能从互不相容的两支各拿一半继续保留。返回告警、确定无告警或待证，并给出变化时需要撤回的最小通知差异。用独立的全量重算器对照乱序更正、覆盖变短、分叉后根签名选支、共享支持被撤销与两个签名来源刚好各缺一个事实。
