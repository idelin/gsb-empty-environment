# ils — 整数线性方程求解器 (Integer Linear System Solver)

求解整数线性方程组 **A x = b**（x ∈ Zⁿ），使用 `math/big` 大整数运算，
消元过程不会溢出。支持任意形状的矩阵：矩形、秩亏、零行、零列。

## 功能

`Solve(A, b)` 返回两种结果之一：

- **解 `Solution`**：一个特解 `X0`（整数向量，非有理解）加上齐次解格
  `{x ∈ Zⁿ : Ax = 0}` 的一组 **Z-基** `Kernel`。全部解恰为
  `X0 + Σᵢ cᵢ·Kᵢ`（cᵢ ∈ Z）。
- **不可解证据 `Certificate`**：有理行向量 `y = Num/Den`，满足
  `y·A ∈ Zⁿ` 但 `y·b ∉ Z`。若存在整数解 `x`，则
  `y·b = y·A·x ∈ Z`，矛盾——故方程组无整数解。

## 算法

对 `Aᵀ` 做单模（unimodular）行变换的整数阶梯形分解 `R = V·Aᵀ`
（gcd 风格的欧几里得消元，全程整数，无分数）：

- `A·Vᵀ = [H 0]`，其中 `H` 列满秩 `r = rank(A)`；
- 核格基 = `V` 的后 `n−r` 行；
- 特解通过对 `H z = b` 沿主元行回代得到，要求每步整除；
- 整除失败或相容性失败时，从阶梯形数据显式构造不可解证书 `y`
  （三角回代求出 `y·H` 为单位向量/零向量，而 `y·b ∉ Z`）。

## 验证器

- `VerifySolution(A, b, sol)` 独立检查：
  1. `A·X0 = b` 精确成立（大整数）；
  2. 每个基向量 `k` 满足 `A·k = 0`；
  3. **格的完备性**：基向量个数 = `n − rank(A)`，线性无关，且生成格是
     **饱和格**——基矩阵所有极大子式的 gcd 为 1（等价于 Smith 不变因子
     全为 1），因此基张成整个核格而非真子格。
- `VerifyUnsat(A, b, cert)` 检查：`Num·A` 的每个分量被 `Den` 整除，
  而 `Num·b` 不被 `Den` 整除。

只有整数数据才能通过验证——仅有理解无法通过。

## 测试

```sh
go test ./ils/
```

测试包括：基本可解/不可解用例、零行零列边界、验证器拒绝错误证书
（错误特解、非核向量、**不完备子格**、伪不可解证书）、60-bit 大系数
随机矩阵（int64 会溢出的规模）、以及小系数矩阵的**有界枚举对照**
（枚举 `[-3,3]ⁿ` 内全部整数解，核对 UNSAT 结论与解格成员关系，
并用极大子式 gcd 独立复核格的饱和性）。
