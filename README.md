光传送网要把七条业务从旧频段搬到指定频段。只验新旧两张占用图会漏掉开备用光时已在传输的邻道失锁。为网管控制器交付可导入的 Go 包：每业务给若干已选好路由的候选光路；每条光路逐段给有向光纤、整数频槽半开区间、左右保护带及接收端串扰预算，相邻段频槽须一致，只有列明的波长转换器可改变中心且转换宽度不变。转换器按正在发光的路径逐次占端口。每纤上载荷连同保护带不许重叠，贴边合法；另有一张非对称干扰表，按纤上两条路径的边缘间距所在整数区间给受扰路径增加非负损耗，沿这条路径全部光纤、全部其他正在发光的路径精确累加后不得超预算。业务有一条正在承载流量的主光路，可以先点亮一条备用，等待输入给定的连续稳定时间后切主，再熄掉旧光；切主本身不熄光。允许拆除未切主的备用，允许借用中间频段，各时刻每业务最多两条发光且至少一条承载。操作在整数拍开始执行；每拍可同时发给不同设备若干次点亮、切主、熄光，各命令绑定输入指定的控制设备，同设备每拍只能一条。设备回执先后不可控，这一拍中每一种执行排列的每一步都须符合上述约束，整批收齐才进入下一拍。求到达仅目标主光路发光的最少拍数，同拍数最少点亮次数；无解与非法初态分别返回。输出可按乱序回执驱动的命令批次，并提供对任意计划的验证，失败须指出最早不安全的拍及能复现的批内顺序和受扰业务或资源。至多每业务四条候选，稳定时长可至 2^40 拍；允许输出压缩空等，不能逐拍遍历长等待或枚举所有执行历史。独立小拓扑逐拍对照两个目标；测试保护带不交但总串扰越限、同拍切主加熄旧只有一种回执顺序安全、以及先把无关业务搬去中间波段才能打破环形占用。
