# dagexec

DAG 任务执行模型，支持三种启动（汇合）条件，并对每个启动/跳过决定记录原因链。

## 启动条件

| 条件 | 启动时机 | 何时立即跳过 |
|---|---|---|
| `AllSuccess` 全成功 | 所有父任务成功 | 任一父任务失败/取消/被跳过（条件已不可能满足） |
| `AnySuccess` 任一成功 | 任一父任务成功 | 所有父任务终态且无一成功 |
| `AllTerminal` 全终态 | 所有父任务进入终态（不论成败） | 永不跳过（条件不可能失效） |

## 语义要点

- **唯一启动**：每个任务的决定（启动或跳过）只做出一次，`Starts()` 恒为 0 或 1。
- **立即跳过**："可满足"与"不可能"均单调，事件一到即判定，条件不可能满足的子任务在
  使条件失效的那个父任务终态事件上同步跳过，并级联传播，不会永久等待。
- **失败与取消分别记录**：`Cause.Outcome` 区分 `Failed` 与 `Cancelled`，不合并。
- **原因链**：跳过沿 DAG 级联，`RootCauses(name)` 追溯到真正运行过且失败/取消的根因任务，
  `Explain(name)` 打印缩进的原因链树。

## 验证

`executor_test.go` 在小 DAG（A、B 为根；C=all-success(A,B)；D=any-success(A,B)；
E=all-terminal(C,D)；F=all-success(D)）上枚举全部终态组合与完成顺序
（根 3×3 终态 × 2 种顺序 × 非根 3⁴ 终态，共 1458 个场景），逐一核对：

- 无永久等待：所有事件处理后无任务停留在非终态；
- 唯一启动：启动的任务恰好启动一次；
- 决定正确：决定类型等于对最终父终态应用纯语义函数 `decide` 的结果；
- 即时性：把触发父任务及更晚终态的父任务还原为 Pending 后，决定不可导出
  （既不提前也不滞后）；
- 原因链：跳过任务的根因只含 `Failed`/`Cancelled`，且与实际父终态逐一相符；
- `AllTerminal` 任务在全部 1458 个场景中始终启动，从不跳过。
