一批离线终端长期固定服务端公钥。管理员要迁到新的信任根，不能只看当前连接是否成功。给Go更新宿主写可导入的固定策略发布验收器。每份签名策略按单调序号生效，含生效窗、主用与备用公钥、角色门槛和上一策略摘要；旧根与新根的过渡授权必须覆盖同一主机、同一份新策略和全部交接角色，且不允许用备用公钥回滚到已废止序号的策略。输入有限证书与策略发布时间表、设备可能的初始检查点、离线时长上限和本地时钟误差区间。终端上线时只能取当时已发布且仍有效的内容。验收须同时证明所有允许的离线与时钟选择下都无法接受被撤销或回滚的钥，并且每个合法上线窗口里至少存在一条可验证的迁移链。按事件端点划分时间但要区分相等点与开区间，返回可逐项核验的结论；失败给最早的时间区间、检查点和缺少的授权。用小整数时间穷举对照跨窗续签、备用键回滚、两份各得半数角色的策略和撤钥恰在上线边界。
