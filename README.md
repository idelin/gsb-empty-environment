# SecOC新鲜度值低位重建

AUTOSAR SecOC 在报文里只带新鲜度值的低位，接收方要自己补全高位；攻击者利用回绕与不同步让旧报文被接受，或把接收方计数器推到未来而拒绝合法报文。为C++ ECU 写可导入的新鲜度重建包，供 PDU 接收路径调用：本地 64 位计数器为 L，报文携带低 8 位（本题规定）；候选完整值取大于 L 且低 8 位等于报文值的最小整数 V；V 与 L 之差超过调用方给的前向窗口（如 128）拒绝；MAC 验证通过后才把 L 更新为 V，验证失败不更新；低位回绕到 0 时的高位进位只在 MAC 通过后生效；连续 3 次验证失败后进入重同步状态，只接受来自受信同步消息的计数器，普通报文一律拒绝。用回绕边界、窗口外跳变、MAC 失败不推进、重放旧值和重同步期间的普通报文验证。
