# anchored-virtual-list

可变行高虚拟列表核心（TypeScript，无浏览器依赖）：版本化前缀高度索引、
稳定条目 ID 锚点、异步实测、折叠分组。所有高度计算由夹具（glyph 度量表 +
内容节点树）纯算完成，不借助浏览器布局引擎。

## 运行

需要 Node.js >= 23.6（原生 TypeScript 类型擦除）。

```sh
npm test    # node --test（内置测试运行器）
npm run demo
```

## 结构

- `src/heightIndex.ts` — 版本化前缀高度索引：增量编辑 O(1)，查询时惰性延展
  前缀和；`indexAtOffset` 为定次二分查找，零高行不会导致死循环（并列偏移取
  最下面一行）。每次变更 `version` 自增。
- `src/virtualList.ts` — 列表模型：插入/删除/重排、折叠分组、估计行高 +
  实测覆盖、测量纪元（epoch）、滚动与跳转、锚点捕获/恢复。
- `src/metrics.ts` — 由夹具字形表做贪心换行与节点树测高（text/image/
  spacer/stack）。
- `test/reference.ts` — 独立全量布局对照实现（纯线性扫描），供差分测试。
- `test/differential.test.ts` — 随机操作流（插入/删除/重排/折叠/测量/迟到
  测量/正反向滚动/跳转/改宽度），每步对照全量布局，检验 **滚动位置与可见
  集**，而非只检验最终总高度。

## 锚点

锚点 = `{ id, offset }`：稳定条目 ID + 视口顶边相对该行顶部的像素偏移。
每次变更前捕获、变更后恢复。

## 公开后备规则（按优先级）

1. 锚点行仍可见：保持视觉位置，`scrollTop = offsetOf(id) + offset`。
   锚前插入 100px → scrollTop 同步 +100；上方实测修正同样按差值平移。
2. 锚点行被删除或所在组被折叠：锚点移到其后继（下一个幸存可见行）；
   无后继则取前驱。
3. 前两条都失败：使用滑入锚点原槽位的行；空列表则 scrollTop = 0。
4. 迟到旧测量：测量携带行级 epoch 令牌，仅在令牌与当前纪元一致且行仍
   存在时应用，否则丢弃（重排不使测量失效，改宽度/重新测量会使其失效）。

恢复结果始终钳制到 `[0, totalHeight - viewport]`。

## 零高行

`indexAtOffset` 是固定迭代次数的二分查找，零高行连排不会死循环；
偏移恰好落在零高行堆上时解析到该偏移处最下面的一行。
