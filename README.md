# staged-source-mapping

源码经两轮转换的段式来源映射库（TypeScript，零依赖）。

## 段模型

每轮转换产生一个 `SourceMapping`：输出文本的半开区间 `[outStart, outEnd)`
映射到输入文本的半开区间 `[inStart, inEnd)`。段分三种（`src/mapping.ts`）：

- `copy`：等长复制/移动，逐字符线性对应，可任意细分；
- `block`：替换块，输出整体原子对应输入整体（长度可不等），部分命中按整个来源区间计；
- `insert`：纯插入，输入侧退化为零宽锚点 `[a, a)`。

## 组合

`composeMappings(inner, outer)` 把第一轮（中间文本 → 原始输入）与第二轮
（最终输出 → 中间文本）组合为最终输出 → 原始输入的映射：

- 外层 `insert` 的锚点经 `translatePoint` 平移，仍为零宽锚点；
- 外层 `copy` 按内层段边界细分，仅两侧严格相接的 copy 片段合并（保持线性对应）；
- 外层 `block` 原子处理：其输入范围覆盖的每个来源连续段各产生一个同输出
  范围的段（多值），来源空隙不被合并。

## 查询

- `querySource(m, q0, q1)`：输出范围的来源片段。结果规范化为按来源位置有序、
  不相交的区间集（重叠/相接合并），**绝不跨删除空隙合并**；零宽锚点永不并入
  区间，仅相同锚点去重。
- `queryOutput(m, s0, s1)`：反向查询，同一来源被复制多份时返回多个不相交
  输出范围（多值）；插入锚点按半开规则 `s0 <= a < s1` 命中。

## 测试

`test/tagged-model.ts` 是独立的逐字符来源标签模型：每个字符携带其来源片段
标签，与库的组合结果交叉核对。`test/mapping.test.ts` 包含替换、复制（多值
反向）、纯插入（零宽锚点）、删除空隙等定向用例，以及 3 个种子 × 500 轮的
随机模糊测试（每轮核对全部字符的正向查询、随机区间正向查询、逐字符与随机
区间的反向查询）。

运行测试需要 Node.js ≥ 22.6（利用原生类型擦除直接运行 `.ts`）：

```sh
npm test
```
