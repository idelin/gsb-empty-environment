# 云安全例外到期联动

临时安全例外到期后，依赖它建立的资源不能继续新增敏感操作。为Go控制宿主实现例外依赖索引，资源记录所依赖例外的版本集合，撤销或到期使整条依赖链进入受限状态；保留已开始操作的明确终止策略，不能仅移除根记录。用虚拟时钟与菱形依赖测试重复失效和重建新代例外。

## 模型

- `ExceptionVersion{ID, Generation}`：例外按业务 ID 版本化，重建同 ID
  例外会产生新世代，旧世代作为墓碑保留，旧依赖不会自动迁移。
- `Resource`：记录直接依赖的例外版本集合与上游资源；失效沿
  资源依赖图反向 BFS 传播，整条下游链进入受限状态并记录全部原因。
- 失效方式：`Revoke` 显式撤销，`SweepExpired` 依据 `Clock` 扫描到期；
  两者均幂等，重复触发不产生新墓碑、不重复中止操作。
- 终止策略（挂在例外上，随失效传播，只能升级）：
  - `TerminateAbort`：立即把在途敏感操作置为 `aborted` 并记录审计说明；
  - `TerminateDrain`：禁止新增操作，在途操作保持 `running`，只能经
    `CompleteOperation`/`FailOperation` 显式终止。
- 受限资源拒绝 `BeginSensitiveOperation`；操作终态
  `completed/failed/aborted` 均保留时间戳，根例外记录与失效事件
  （`Events`）不会被删除。

## 世代重建

新世代例外注册后，仍钉在旧世代的资源保持受限；需要调用
`RebaseResource` 显式切换依赖集合，索引随即全量重算。禁止在已失效
世代或受限上游上建立新依赖，依赖图不允许成环。

## 测试

`go test ./... -race` 覆盖：虚拟时钟到期边界与链路传播、菱形依赖
原因去重、abort/drain 策略升级、重复失效幂等、新世代重建与再次
失效、注册期校验（重复 ID、缺失/受限上游、环）。
