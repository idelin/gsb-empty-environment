链路聚合芯片把多个输入通道的固定宽度字条带化，接收端靠带周期序号的对齐标记复原；标记也占一个 FIFO 位置。给链路配置器写可导入的 Go 包：通道各有独立有理数节拍、初相区间、周期性合法空闲插入表。所有通道共用同一未知振荡偏差（从给定有限集合选一次保持），不是每次读独立选分支。接收器只能同时取各通道相同帧号的字，标记用于校正模 M 帧号，偏斜可超过一次绕回；若观测前缀对应多种绝对对齐不得任意挑一个。求在给定观察窗口内能保证不丢数据且唯一重建的各路最小统一深度，或给出两组相同观测却不同去条带结果的初相、偏差与时刻。输入节拍与窗口为整数分数，时间到 2^48，同一周期重复到 2^40，不能逐 tick 或逐重复帧模拟；输出可跳段的相位证书并支持检查。小参数全相位逐拍枚举核对，包含标记恰好压线、两个模绕回、以及把通道偏差独立化才会出现的假溢出。
