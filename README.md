写时复制存储池把多个快照的逻辑文件映射到物理段内的任意半开字节子区段，删除部分快照并整段回收一个物理段时，只应搬迁仍被存活快照实际引用的字节，且不得把同一物理字节重复搬运两遍。给段回收器交付可导入的 Go 规划包。输入快照树（每个快照可继承父快照并覆盖若干逻辑半开区间，指向物理段偏移或显式空洞）、待删快照集合及目标回收物理段。组件先沿快照继承链展开每个存活快照的精确物理子区段映射，对落入目标段的物理区间做合并去重得到最小搬迁字节集（按物理偏移升序且相邻不重叠合并），为每个合并块分配新物理段中的连续目标偏移，并输出每个存活快照更新后的逻辑到物理区间表（保持逻辑相邻同物理连续的区间合并）。验收用按字节展开的朴素存储模型逐字节核对存活快照读写不变与搬迁总字节最小，覆盖子快照局部覆写切碎父区段、空洞遮蔽物理引用、多个存活快照部分重叠引用同一物理区间，以及删除中间父快照后子快照仍保留原引用的情形。
