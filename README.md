列式执行器把一个分区交给下游时只有游程：每段是一个可空的 int64 值和连续行数，段可跨页，空页合法。下游既要点查连续分位数，也会对一段输出再做 SUM。请交付可导入的 Go 窗口内核及直接调用它的分页执行器适配层。窗口是当前行和前 W−1 行，分区开头按实际存在的行截断；忽略 NULL，但它仍占窗口位置。固定参数 0≤p≤q、q>0。窗口内非空值排序为 x[0..n−1]，h=(n−1)p，k=h div q，r=h mod q；输出 ((q−r)x[k]+r*x[min(k+1,n−1)])/q，n=0 才输出 NULL。建索引后，对任意零基闭行区间及给定有理闭值域，返回其内分位数落入值域的非空行数、这些分位数的精确有理总和，并支持取按行号排序的第 j 个命中行；无命中时计数和总和为零，越位要报告。分区行数和 W 均可达 2^63−1，p、q 为 uint64，值域端点用有符号任意精度分子及正分母。查询与建索引可以随输入段数和整数位长增长，不得逐逻辑行或逐分母余数枚举，也不能输出按行展开的中间列。请用独立的逐行排序算法核对小表的三种查询结果，任意切页后结果不变；另展示 NULL 长段逐步滑出、相邻秩值不同且插值呈锯齿、精确比较恰在值域端点、sum 的分子超过 128 位。给一个含万亿逻辑行和大分母的实跑用例，用可核对的解析结果验证不是只测运行时间。
