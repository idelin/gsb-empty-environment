消费组在线重分片时，事务投递器要把每个旧分区的处理日志截取一个前缀，交给新分区恢复。每条记录属于一个事务，带有唯一消息号、旧分区内递增但不连续的偏移及目的新分区；一笔事务可能在多个旧分区出现，所有记录要么都保留要么都重放。旧分区给出可截断的最小与最大前缀长度。业务依赖 u→v 表示保留事务 u 必须保留 v，同环事务允许一起保留。每笔事务保留可节省带符号的重放代价；两个事务之间还可能有一条有向搬运费，前者保留而后者重放时扣该非负费用。给代理实现 Go 检查点交接包，找净节省最大的合法切面；需返回每个旧分区在所有最优解中的最短及最长前缀，并答复任意两个事务是否在所有最优解中同进同退。不能把各自可取的区间误当作能自由组合。调用方还能对少量事务钉住保留或重放，须在原最优解集合中给出最小包含的满足解，若不存在须拒绝，不能改拿次优。用切面驱动新分区实际恢复：对给定消息号查询是否应该投递，不得用该新分区最大已见偏移简单过滤。最多八万条记录、三十万依赖或费用边，预处理不枚举前缀向量；回答同进同退与钉住查询不得重解原优化问题。总费用可能超过 int64。测试用小日志枚举所有最优解核对极值、联动和钉住结果，覆盖前缀间隙、交叉事务构成环、同价却不可任意拼接的截点及净节省全负仍有强制保留。
