对象存储采用局部可修复码（LRC）降低单块损坏的跨机架流量：一个条带含 k 个数据块，分为 g 个局部组（每组配 1 个组内异或局部校验块），另配 p 个全局校验块（在 GF(256) 给定生成矩阵上计算），每个块存放于指定机架。多块同时损坏时，某些失效可局部修复、某些须拉取跨机架全局校验并可能级联解锁其他局部组。为修复规划器交付可导入的 Go 求解包。输入生成矩阵（含全部数据、局部校验、全局校验行，位于 GF(256) 本原多项式 0x11d 上）、每块所在机架、目标修复落盘机架及当前损坏块集合。组件须首先通过高斯消元判定损坏集合在当前存活块下是否信息论可恢复（即剩余行与待解列构成可解线性系统），不可恢复则返回不可修复；可恢复时在节点总数不超过十六下，求能完整还原所有损坏块且跨机架传输块总数（即所选存活读取块中不在目标机架上的块数）最少的精确读取块子集（并列按总读取块数最小，再按块编号向量字典序最小），并实际执行 GF(256) 解码验证还原后的字节与原块完全一致。验收用全子集搜索与真实随机字节条带解码核对，覆盖纯局部单块修复、局部+全局联合解出两块后解锁第二局部组、表面损坏数不超 p+g 但全落同一局部组导致秩亏不可恢复，以及机架局部性使选全局校验反而比跨机架局部读更省流量。
