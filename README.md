# kanonymity：合成数据 k-匿名试算工具

Python 3.11+，仅标准库，测试用 `unittest`。**仅处理合成数据。**

## 范围与免责声明

- 本工具只评价**声明的指标**：NCP 泛化损失 + 抑制惩罚。
- 输出**不构成**绝对匿名声明，也**不等同**完整隐私保障（未覆盖
  背景知识攻击、l-多样性、差分隐私等）。
- 精确枚举核验只适用于小域；统计实验不作为形式隐私证明。

## 定义

- **准标识符（QI）**：参与分组的属性，各配一棵泛化层级树（叶子=原始值，
  根=`*`）。
- **等价类**：给定泛化层向量下，泛化后 QI 元组完全相同的记录集合。
- **k-匿名**：每个未抑制等价类的计数 ≥ k。计数方式 `count_mode`：
  - `record`：按记录数；
  - `subject`：按不同主体数（同一主体多条记录只计 1，按题面主体计数）。
- **不足 k 记录**：所属等价类计数 < k 的记录。
- **空值**：`None`/空白串映射为独立的 `<NULL>` 类别，直接挂在根下，
  不与非空值合并（除非泛化到根层 `*`）。
- **抑制**：移除记录，每条计入 `suppression_penalty` 的损失；
  总抑制数不得超过 `budget`。
- **信息损失**：单记录 = 各 QI 的 NCP 均值，
  NCP = `(|leaves(node)| - 1) / (|leaves(root)| - 1)`；
  方案总损失 = 未抑制记录泛化损失之和 + 抑制惩罚 × 抑制数。
- **重新分组**：泛化层变化后，等价类与计数一律从原始记录重算，
  不沿用旧计数。

## 参数

| 参数 | 含义 | 默认 |
|---|---|---|
| `k` | 等价类最小计数 | 必填 |
| `budget` | 抑制预算（最多移除记录数） | 必填 |
| `count_mode` | `record` / `subject` | `record` |
| `suppression_penalty` | 每条抑制记录的损失 | `1.0` |
| `max_evals` | 层向量评估预算，耗尽即中断并给上下界 | 无限制 |

## 功能

- `compute_classes` / `evaluate`：等价类、不足 k 记录与损失试算。
- `optimize`：联合各 QI 泛化层级与抑制预算，求满足 k 的最低损失方案，
  返回每记录归属证据（`Evidence`：kept/suppressed、类键、类计数、是否达 k）。
  中断时返回 `lower_bound` / `upper_bound`。
- `brute_force_best_loss` / `check_optimal`：小域精确枚举核验最优性。
- `IncrementalAnonymizer`：新增/撤回记录后**全局**增量修复——
  对所有等价类重新分组、重新计数、重新优化，
  不因局部组达 k 而忽略其他组。

```bash
python3 run_sample.py            # 运行样例（合成数据）
python3 -m unittest discover -s tests -v   # 测试
```
