# 追溯性信用额度占用流水账

支持历史冲正与重叠期冻结的信用额度管理器（TypeScript，零依赖）。

## 特性

- **只追加账本**：消费、额度调整、冻结、违约警报均为不可变记录，绝不物理删除。
- **历史冲正**：`adjustLimit(from, to, limit, recordedAt)` 可在任意历史区间追溯插入临时额度或调低额度。
- **违约识别**：每次变更后重放全部消费流水，若某时刻累计占用超过当时有效额度，输出违约警报（时间点 + 超额差量）并写入审计日志。
- **重叠期冻结**：`freeze(from, to)` 冻结区间后，与之重叠的额度调整被拒绝，拒绝行为同样记入审计日志。

## 环境要求

Node.js >= 23.6（原生 TypeScript 类型擦除 + 内置 `node:test`，无需编译与第三方依赖）。

## 运行

```bash
node --test      # 运行内置测试
node src/demo.ts # 运行验收样例
```

## 验收场景

初始额度 1000；时间 10 消费 800；时间 20 消费 150；时间 30 追溯将区间 [5, 15] 额度调整为 700。
系统自动识别时间 10 发生 100 的超额并记录审计日志：

```
[违约警报] 时间 10 占用 800 超过额度 700，超额 100
#5 [VIOLATION_ALERT] 违约警报：时间 10 占用 800 超过额度 700，超额 100
```

## API 概览

| 方法 | 说明 |
| --- | --- |
| `new CreditLedger(baseLimit)` | 以初始额度创建账本 |
| `consume(time, amount)` | 在指定时间点登记消费 |
| `adjustLimit(from, to, limit, recordedAt)` | 追溯调整区间额度，返回新发现的违约 |
| `freeze(from, to, reason)` | 冻结区间，拒绝重叠调整 |
| `getLimitAt(time)` / `getUsageAt(time)` | 查询某时刻有效额度 / 累计占用 |
| `getViolations()` / `getAuditLog()` | 查询违约警报 / 完整审计日志 |
