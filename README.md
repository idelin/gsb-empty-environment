# docexec — 文档示例执行器

按依赖顺序执行 Markdown 文档中的示例代码块，支持共享命名空间，并把每块输出定位回原文位置。解释器为纯本地实现，不调用任何真实外部命令。

## 文档格式

围栏代码块的信息串以 `run` 开头，后接 `key=value` 选项：

    ```run name=setup needs=base,other
    set greeting hello
    ```

- `name`：块名，需唯一；重复定义会产生校验错误。
- `needs`：逗号分隔的依赖块名，全部成功后本块才运行。

## 迷你指令集

| 指令 | 语义 |
| --- | --- |
| `set NAME VALUE...` | 定义变量；重名定义报错 |
| `print TEXT...` | 展开 `$name` / `${name}` 后输出；未定义变量报错 |
| `fail MSG...` | 让当前块失败（用于演示/测试失败路径） |
| `# ...` | 注释；空行忽略 |

## 执行语义

- 按依赖拓扑序执行，同层块按文档出现顺序。
- 所有块共享一个命名空间；每块在事务中执行，失败时其写入全部回滚，不会部分泄漏。
- 某块失败/被跳过，仅其（传递）依赖者被跳过，无关块照常运行。
- 校验：依赖循环、重名块名、未知依赖均报告为校验错误，涉及块被跳过。

## 使用

```sh
go test ./...
go run ./cmd/docexec example.md            # 文本报告（含原文行号）
go run ./cmd/docexec -annotate example.md  # 输出插回原文的标注文档
```
