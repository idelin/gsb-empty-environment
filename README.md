向量化引擎将两个字典编码列按 run-end 编码传进连接算子。实现可导入的 Go 包，计算两表按等值键连接后的逻辑行选择视图，不物化行对。列有多级本地字典且允许别名；区分普通等值和 NULL-safe 等值。各边另给不相交的有效行掩码区间；输出按左原行、右原行排序，支持 full outer，未匹配右行统一排在尾部。提供双向 rank/select：由序号查行对，或从合法行对反求序号，空侧用专门标记；支持按半开序号区间惰性批读。单个 run 长度可到 2^60，结果比 uint64 更大，不能按原行数分配索引。用独立的小表展开验证排序、掩码切碎长 run、两层字典映到同值和空侧秩；循环字典及越界必须明确报错。
