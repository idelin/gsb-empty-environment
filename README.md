安全监控服务从内核审计和容器运行时分别接收事件。两个来源只能各自保证顺序，时钟偏移由宿主给出区间。给 TypeScript 规则宿主写可导入的关联判定包：规则可以声明同一进程实例在窗口内依次出现 A、B，并要求两者之间未出现授权事件 C。进程身份绑定启动代次和命名空间，PID 相同不能合并；每个来源流带签名序号段与覆盖水位，丢失区间不能作为 C 不存在的证据。批输入至多18个事件，另含跨源因果边、各事件的最早最晚时刻和两个来源的时钟偏移范围，同一来源的所有事件共享一个偏移变量。分别判定所有符合这些约束的时间赋值与交错都支持告警、都不支持或证据不足；不能把每个事件的偏移各自独立选择。对确定告警给出 A、B、签名序号覆盖与证明窗口约束的证书，供独立验收函数核对；输入约束自相矛盾要单列。用小整数时间域全枚举对照共享偏移、边界相等、C 所在流缺段、进程代次复用和后补覆盖使未知变为确定的情况。
