数据库执行器需支持取消后恢复带 WITH TIES 的多路归并 LIMIT。提供可导入的 Go 包：每个有序 run 使用自己的混合升降序、NULL 排序元数据，须先核对等价排序描述，排序值相等时用稳定行号确定回放顺序，但 ties 不包含行号。外部 run 只给按键下界索引和压缩页，页可部分返回，页头最小键是保守下界不是实值。实现拉取与确认分离的游标，对尚未读取的页只有证明不可能贡献当前输出时才可跳过；把确认位置序列化后从只读 run 恢复，不能序列化所有重复键行。输出每次跳页或终止的下界证书，验证器不得展开已证明无关的页。小规模以全量稳定排序核对每个确认边界的恢复，含跨所有 run 的长 ties、页中空过滤结果及下界相等却仍不能结束。
