虚拟化平台移动一段客户内存后，设备可能仍持有早先获准的子页翻译。写供 C++20 虚拟化宿主调用的映射验收组件，输入包括设备所属域、PASID 租约代次、支持的页大小、权限位及缓存翻译范围。一次更新可拆分大页、合并小页或把局部范围交还另一租户；旧翻译的失效回执以设备本地序号和区间返回，可分片、重复和乱序。重用物理页前须证明所有可能仍具旧读写能力的设备都已确认，不能用大页条目消失推断此前取得的小页已失效。计算能安全重用的最大地址区间集合，并为剩余区间规划最低代价的失效请求，候选失效可按设备、租约或范围覆盖，代价和可使用次数由宿主给定。提供独立检查器核对覆盖、权限收窄与原租户数据擦除屏障，验不全返回等待。使用稀疏 64 位坐标和精确整数，不展开页地址；用小域逐页对照，测大页拆分、物理别名、多队列共享 PASID、序号复用与只有部分设备确认。
