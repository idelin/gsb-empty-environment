# 闪电借入投票权通过治理快照

治理模块若在投票时读取当前余额，攻击者可在同一交易借入代币、投票后归还，瞬间取得多数。给TypeScript治理宿主实现可导入的检查点与提案状态包：每账户余额变化写(blockNumber,txIndex,balance)检查点，同一位置覆盖，查询严格取目标位置之前最后值；总供应量同样检查点。提案创建于位置P=(blockNumber,txIndex)，投票快照固定为P之前，投票延迟、开始、结束、排队和执行时刻用块号半开区间定义。投票权取快照余额，委托关系也在P前固定且形成有向森林，环拒绝；同一底层余额沿委托链只计一次。每账户每提案只能投一次，投票交易内后续余额变化不影响。法定票数按快照总供应量的有理比例按分子加分母减一后整除向上取整，成功还需赞成大于反对；执行绑定提案动作摘要和治理配置代次。实现一个当前余额待审回调，在至多4账户、2笔同块交易的小模型中搜索借入、投票、归还后攻击者净余额恢复却改变结果的最短见证；正确快照模型应无此见证。覆盖同块txIndex顺序、委托变更、供应铸造/销毁和重复投票。
