# 回调地址按前缀匹配放行了攻击者域名

OAuth客户端注册回调时平台用字符串前缀比对，`https://app.example.com.attacker.io`也能通过，授权码被送到攻击者站点。请实现供TypeScript授权服务器调用的可导入回调校验组件。注册与使用时都按完整URI解析，scheme、主机、端口和路径逐段精确比较，不允许用户信息、片段或未声明端口，路径匹配只允许注册时显式声明的通配段且不得跨目录。主机按IDNA规范化后比较，环回地址与自定义scheme单独授权。授权码绑定client、redirect_uri、PKCE挑战与nonce，兑换时重比一次。用后缀域名、子域、路径穿越、默认端口、IDN混淆和合法精确回调验证码只发往注册地址。
