# 单条指令跳过后的认证旁路

设备启动代码担心电压故障跳过一条比较。请给Go安全回归宿主写有界故障分析包：自定义程序至多32条指令、4个布尔寄存器，寄存器初始全假，控制流越出末条视为halt，非法寄存器或跳转目标输入拒绝；指令为读公开输入位、读验签结果位、and、not、条件跳转、unlock、halt；最多8个公开输入位，验签结果由宿主给定，攻击者不能改它，只能在一次执行中跳过一条非halt指令，跳过的跳转也直接走下一条。搜索验签结果为假却执行unlock的最短轨迹，无故障同输入也解锁的情形标为原有漏洞，不能归因于故障。再从宿主给定的至多8个位置选最少插入点，插入“验签结果为假则halt”的原子保护指令；保护本身同样可能是唯一被跳过的指令。补丁须保证所有正常有效验签输入的unlock次数和原程序一致，并堵住所有界内故障；循环最多64步，超限不能报安全。用独立穷举执行核对补丁、未修复见证及无解，等大小补丁按位置序列排序。
