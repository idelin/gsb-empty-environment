# 事件闭区间上的必然偏序推导

事件的发生时间是**闭整数区间**（不确定集），不是点，也不允许用区间中点
伪造全序。系统从两类原始约束出发：

- 可更正时间区间：`event ∈ [low, high]`（闭区间，整数 tick）
- 显式因果边：`earlier ≺ later`，即 `t_later - t_earlier ≥ min_gap`（≥1）

输出：确定顺序层、必然先后的紧凑表示（传递归约）与全闭包、成对列出的
不可比较组、可行时间见证，以及矛盾环的原始约束证据。

## 语义

- **必然先后**：在*所有*可行整数赋时中 `t_u < t_v`。
- **不可比较**：存在 `t_u ≤ t_v` 的见证，也存在 `t_v ≤ t_u` 的见证
  （允许同时刻）。不可比较**不具有传递性**，因此不是等价类，只成对列出。
- 闭区间相接（如 `[0,2]` 与 `[2,3]`）只能推出 `≤`（可同时取 2），
  **不**构成先后；`[0,2]` 与 `[3,4]` 保证间隔 ≥ 1，是必然先后。
- 输入顺序不影响结果：内部一律按事件/约束名排序处理。
- 推导与判定相互独立：
  - max-plus（差分约束）Floyd–Warshall 计算必然关系与正权矛盾环；
  - 小整数域**完全枚举**所有可行赋时作为核验神谕，与闭包逐一比对。
- 撤回任意约束后整体重算：失去全部支持路径的先后关系随之删除；
  更正区间等价于替换该条原始证据。
- 时间表示区分三类对象：`WallClock`（墙钟日历时间）、`TimePoint`
  （整数时间点）、`Duration`（持续时长）。点−点=时长，点+时长=点，
  点+点在类型层面被禁止。
- 合成偏移转换表：`ticks = value × ticks_per_unit + offset_ticks`，
  全部为整数；带偏移的单位只用于点坐标，时长仅用零偏移单位换算。

## 运行

```bash
python3.11 demo.py                 # 运行样例（输出见 sample_run.txt）
python3.11 -m unittest discover -s tests -v
```

仅使用 Python 3.11 标准库。

## 代码结构

- `temporal_po/time_model.py`：单位转换表、时长/时间点/墙钟
- `temporal_po/constraints.py`：区间约束与因果边（含证据文本）
- `temporal_po/solver.py`：max-plus 闭包、矛盾环、传递归约、分层、枚举核验
- `temporal_po/format.py`：紧凑文本输出
- `demo.py`：6 个运行样例
- `tests/test_temporal_order.py`：20 个 unittest 用例
