# inventorysim

多副本库存模拟器：副本可离线扣减，副本间通过可转让的扣减额度（quota）消息协作，总额度守恒。

## 设计

- **额度守恒**：`总量 = Σ(各副本可用量) + Σ(已扣减) + Σ(在途消息额度)`，任意时刻不变。
- **不为负**：副本只能扣减本地持有的额度（`Replica.Deduct`），离线也不会让总量变负。
- **可转让额度**：`Network.Transfer(from, to, amount)` 立即从发送方托管额度并生成带唯一 ID 的转让消息。
- **不得预支**：在途（in-flight）额度不计入接收方可用量，消息送达前接收方无法使用。
- **幂等送达**：接收方按消息 ID 去重（`Replica.Receive`），重复投递/重复 gossip 不会重复授予。
- **合并规则**：`Network.Heal(a, b)` 重连时投递排队消息，并双向 gossip 已知转让集合（按 ID 求并集）；
  已被目的副本入账的排队消息副本会被清除，避免虚增在途额度。

## 运行

```sh
GO111MODULE=on go test ./...   # 分区/重连守恒、幂等、禁止预支等测试
GO111MODULE=on go run .        # 演示：分区 → 离线扣减/转让 → 重连合并，输出各副本可用量与转让流水
```
