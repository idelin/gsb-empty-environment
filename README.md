为 IP 地址签发证书的 CA 要把验证工作交给不同机房，但同一网络运营方有多个探针身份。写供 Go 签发宿主调用的证据汇聚包。订单绑定经规范化的公网 IP、端口、挑战类型、账户、nonce 和公钥摘要；每份签名见证还带探针所属管理域、路由起源、观察时间区间、请求实际连接地址与返回的证明摘要。订单要求至少 k 个互异管理域，且同一路由起源最多贡献一票。见证可有多个合法身份归属，身份清单本身带版本；每份回执只能选择一个经认证的归属，所有选择须同时成立。只有选中的见证存在公共的观察瞬间，且该瞬间在授权窗口内，才能签发。按见证数量、总代价、最后按编号字典序选择有效证据；另给验收函数，不相信汇聚器自报的域数和时间交集。撤销探针或路由证明时按签发时点重验，签发以后才发生的撤销不能追溯污染历史。支持重复回执去重、等编号异摘要的分叉隔离和缺失身份补证。用小集合穷举核对贪心选域导致路由冲突、时间窗口只两两相交却全体无共同点的多段时间输入、同一 IPv6 地址的不同文本以及 IPv4 映射地址。每份见证的时间可为有限闭区间并集。
