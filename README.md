# 目录服务的引用把凭据带给了第三方主机

企业目录网关做用户搜索时跟随服务端返回的referral，并把绑定口令原样发到引用主机，攻击者控制的目录服务器可借此收取凭据。请实现供Go目录网关调用的可导入引用跟随组件。解析每个引用URL的主机、端口、协议与DN，只有引用主机在当前信任域且配置允许转发凭据时才重新绑定，否则以匿名简单绑定继续或返回不可跟随；LDAPS与StartTLS按证书与主机身份校验，降级到明文即拒绝。引用链深度、循环和跨森林边界受显式限制，绑定的用户身份、认证机制与原始请求来源记入审计。用跨域引用、主机别名、端口替换、循环引用、明文降级、合法同域引用和匿名可跟随场景验证口令只发往信任主机。
