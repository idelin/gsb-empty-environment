旧控制器失去租约不等于旧写已经落完：共享盘仍可能把先入队的片段写到新映射。为卷管理器交付可导入的 Go 接管分析包。输入一批必发生的入队、片段落盘和持久栅栏事件，标有本机时钟读数。每台设备有至多两次有序开机世代，每代时钟独立为 a·t+b，正斜率与偏移给有理闭界；切换的真实时刻另给闭界，前代只在切换前有效、后代从切换当刻生效。日志缺代号，可给一个事件多个候选代，必须在整份历史中只认定一种。成对消息给真实时延上下界，设备日志给先后偏序，同拍有序事件按可行线性扩展执行。每个旧请求声明卷中半开块区间、编号模数下的标签、真实入队后最大驻留时长，并将其区间恰分成若干片段；每条落盘回执只载标签和片段范围，须一对一匹配一个已入队且未超时的片段，所有片段都已列出。栅栏覆盖输入指定的队列：栅栏生效前入队的被覆盖请求，其全部片段必须在栅栏生效前已落盘；不排序其他队列，同拍先后计入。新控制器在固定不重启的本地钟上，自整数 n 起逐段改变块映射，各区间在 n 加给定非负有理偏移时生效且不再回退。若相交旧片段在该区间切换时刻或之后才落盘即不安全，同一物理时刻按旧写可能在切换后保守处理。求窗口 [L,U] 内对所有相容历史均安全的最小 n；日志矛盾、窗口无解、成功分开。非最左解要给 n−1 的完整失败见证，无解给 U 的见证，含每代钟、切点、回执对应、同拍次序及相交块；实现独立回放验证，一份历史必须同时满足全部盘与消息，不能逐项取最迟值拼接。八笔旧请求、十二片段、四设备，允许随离散匹配数增长；精确处理有理开闭界，不逐块、不逐刻扫描。小例用固定钟及有限候选匹配穷举核对；覆盖同标签回绕、某片段单看能落得更晚但抢了另一回执的唯一匹配、切点可无限逼近却不能取到，以及已确认整队排空仍有另一队写同一块。
