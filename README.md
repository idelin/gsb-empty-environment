# 授权响应iss参数混淆防护

客户端对接多个授权服务器时，攻击者让用户在恶意服务器上发起授权，再把得到的授权码交给诚实服务器的令牌端点（混淆攻击）。为TypeScript客户端写供回调路由调用的 RFC 9207 iss 校验包：每次授权请求在会话里记下所用授权服务器的 issuer；回调的 iss 缺失而该服务器元数据声明 authorization_response_iss_parameter_supported 为 true 时拒绝；iss 存在时须与会话记录逐字节相等（不做 URL 规范化）；iss 在查询里出现多次拒绝；校验在使用 code 之前完成，失败时不得向任何令牌端点发请求；错误响应里的 iss 同样校验。用 iss 缺失但已声明支持、iss 不同、尾部斜杠差异、重复 iss 和错误响应验证。
