# NFS文件句柄跨导出代次指向新对象

对象网关把NFSv4文件句柄映射到后端对象，若删除导出后复用相同fsid和inode，客户端持有的旧句柄可能访问另一租户新对象。请实现供Go NFS服务调用的可导入句柄编解码与生命周期包。句柄AEAD封装export UUID、export generation、后端稳定对象ID、对象generation、类型和策略摘要，AAD绑定服务器实例与格式版本；解析只返回opaque能力，所有LOOKUP/OPEN/READ/WRITE前核对导出仍活跃、对象代次和租户策略。导出替换、快照回滚、对象删除重建和密钥轮换分别有明确STALe/拒绝结果，旧密钥只在宽限期验证旧代且绝不授权新对象。并发删除与OPEN采用代次快照，迟到存储回调不能更新复用对象。用相同fsid/inode重建、跨租户搬运、密文篡改、回滚、密钥轮换和合法硬链接验证旧句柄稳定失败而非换绑。
