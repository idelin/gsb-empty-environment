# morpho-incremental

TypeScript（Node ≥ 23.6 内置 type-stripping，无第三方依赖）实现的形态学流水线：

- 自定义结构元素（显式原点、非对称方向正确）的膨胀 / 腐蚀 / 开 / 闭
- 受 mask 约束的测地重建（形态学重建），带不动点预算
- 多阶段操作图编译 + 局部输入修改后的增量维护
- 每阶段独立的边界模式（`zero` / `one` / `clamp` / `ignore`）、SE 原点与标签掩码
- 全流水线共享的瓦片缓存上限（LRU + RLE 冷存储），内存占用受控
- 自建 RGBA 小图验证，不调用 Canvas 滤镜或现成图像处理库

## 运行

```sh
npm test    # node --test（内置测试运行器）
npm run demo
```

## 结构

- `src/se.ts` — 结构元素：偏移集合 + 原点；`reflected()` 用于腐蚀/膨胀对偶
- `src/ops.ts` — 膨胀/腐蚀/开/闭的点查询与全图参考实现（同一套逻辑，引擎复用）
- `src/reconstruct.ts` — 迭代测地重建参考实现（报告不动点收敛或预算耗尽）
- `src/tiles.ts` — `TileStore`（RLE 冷瓦片）+ 全局 `TileCache`（容量上限的 LRU 热缓存）
- `src/graph.ts` — 图规格与编译（拓扑校验、影响半径预计算）
- `src/engine.ts` — 增量引擎：脏区域传播、受影响区域重算、事务式发布
- `src/rgba.ts` — 自建 RGBA 小图工具（ASCII 调色板、通道/亮度阈值、叠加渲染）

## 语义要点

- **膨胀方向**：SE 以原点为锚“盖印”到每个前景像素；偏移 `(0,0),(1,0),(2,0)`、原点 `(0,0)` 时向 +x 生长。腐蚀使用未反射的 SE；对偶关系经 `reflected()` 成立。
- **开/闭的单调性**：开不增前景在 `zero`/`ignore` 边界下严格成立；闭不减前景在 `one`/`ignore` 下严格成立。`one`（`zero`）边界会让开（闭）在图像边缘产生合理的边界效应。
- **重建不超 mask**：结果按构造 ⊆ mask，且 ⊇ marker ∩ mask。
- **增量重建不截断**：输入变化集合 C 的受影响区域 A = (oldMask ∪ newMask) 中触及 C 的（对称化 SE）连通分量；A 内从当前 marker 重新做测地膨胀波前传播。A 不受核半径限制，因此单像素打通长通道会传播到远端；断开时旧传播支持被精确撤销（A 内重算，失去支持的像素归零）。
- **事务式发布**：重建阶段设有迭代预算；预算耗尽时报告 `budget-exhausted` 并保留原发布输出（不写入部分结果）。
- **标签掩码**：每阶段可指定标签集合；不匹配的像素直接透传输入，不参与该阶段写入。
- **瓦片缓存**：所有平面存于 `TileStore`；解码后的热瓦片全局限额（LRU 驱逐时重新 RLE 编码），正确性不依赖缓存大小。

## 验证

`test/` 下用 node:test 以小图逐次迭代参考实现交叉核验：

- `ops.test.ts` — 非对称 SE 方向、对偶性、开/闭单调性、边界模式、标签掩码
- `reconstruct.test.ts` — 结果 ⊆ mask、与连通分量刻画的等价性、长走廊不被核半径截断、预算耗尽报告、RGBA 工作流
- `incremental.test.ts` — 单像素打通/断开 60px 通道的传播与撤销、预算耗尽保留原发布版、随机编辑下三阶段图与朴素全量重算逐像素一致（瓦片缓存限额 8）
- `tiles.test.ts` — RLE 往返、缓存容量约束、驱逐后数据正确
