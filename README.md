# TOML表劫持

应用把用户上传的 TOML 片段合并进主配置，攻击者在片段里用点号键、带引号的键与重复表头去改写 [security] 表。为Go的配置服务写可导入的 TOML 片段准入包（TOML 1.0.0）：先剥离 UTF-8 BOM 并把 CRLF 归一，非法 UTF-8 拒绝；片段内每个键的完整路径按 TOML 键语法解析（裸键、带引号键、点号键，允许空白），引号段的 \u 转义按规则还原后再逐段比较且区分大小写，例如 `user.a = 1` 通过，`"\u0073ecurity".x = 1` 拒绝；第一段必须是 user；跨片段合并时同一路径重复定义、表头与点号键对同一张表重复定义、内联表后续追加、`[a]` 与 `[[a]]` 混用均拒绝；片段超过 64 KiB 拒绝。测 BOM/CRLF、引号与转义变体、跨片段重复、内联表追加、数组表混用与超限。
