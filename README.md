现代文件系统用 `fallocate` 预分配物理块时将其标记为未初始化（unwritten），读该区段须返回全零而不暴露旧盘数据；随后对其中间一段执行真实写入时，必须把该未初始化区段精确一分为三，把中间段转为已初始化，并自动尝试与左右物理连续且同标志的区段合并。为文件系统块映射层交付可导入的 Go Extent 树包。每个叶节点最多存 M 条有序非重叠区段（逻辑起始块、长度、物理起始块、unwritten 布尔标志），支持操作：`Preallocate(lba,len,pba)`、`WriteInit(lba,len)`（将已分配未初始化子区段转为已初始化，若遇未分配空洞按调用方给定分配器分配物理块）、`PunchHole(lba,len)`（切分并释放被覆盖的物理区间，返回精确释放的物理半开区间列表）、`ZeroRange(lba,len)`（将覆盖区间转为 unwritten 保留原物理块）与 `Query(lba,len)`。要求始终维持树高度平衡、叶条目数在 `[ceil(M/2), M]`（根除外）、相邻且物理连续同标志区段立即合并，异标志或物理不连续绝不合并。验收用按逻辑块逐块展开的朴素数组模型对照每次操作后的逐块物理地址与初始化状态完全一致，覆盖中间子区间写入一分为三、连续两次互补写回触发三段合并为一段、PunchHole 跨三个区段释放精确物理块列表，以及连续删除引发树叶合并与降高。
