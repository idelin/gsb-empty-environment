# SWIM 故障检测 MTTD / 误报率度量分析仪 (TypeScript)

量化 SWIM 风格故障检测协议的运行指标：针对每次故障注入事件，记录
**发生时刻、首次怀疑时刻、最终标记时刻**，计算 **MTTD（平均检测时间）** 与
**误报率**，并输出详尽诊断报告。

纯 TypeScript 实现，零第三方依赖；Node.js ≥ 23.6 直接以类型擦除方式运行，
测试基于 Node.js 内置测试运行器 (`node:test`)。

## 架构

| 文件 | 职责 |
| --- | --- |
| `src/rng.ts` | 可复现的种子化随机数生成器 (mulberry32) |
| `src/swim.ts` | 离散协议周期驱动的 SWIM 仿真：直接 ping、间接 ping-req、怀疑-反驳-确认 |
| `src/metrics.ts` | 度量分析仪：事件时序记录、TP/TN/FP/FN 判定、MTTD / 误报率聚合 |
| `src/report.ts` | 详尽诊断报告渲染 |
| `src/scenario.ts` | 验收场景编排：故障注入调度 + 仿真驱动 + 指标采集 |
| `src/run-sample.ts` | 运行样例入口 |
| `test/analyzer.test.ts` | Node.js 内置测试（7 个用例） |

## 运行

```bash
npm run sample        # 运行验收场景并打印诊断报告
npm run sample 42     # 指定自定义随机种子
npm test              # node --test（内置测试运行器）
```

## 验收场景

- 12 节点集群，怀疑超时 2 周期，间接探测 k=3；
- 注入 **10 次真实节点宕机**（node-1..node-10，每 4 周期一次）；
- 注入 **5 次短暂网络丢包扰动**（node-11/node-12，各持续 1 周期）；
- 确定性种子（默认 6）保证结果可复现。

## 验收结果

- **MTTD 平均 = 2.40 周期**（最小 2 / 最大 3）；
- **误报率 = 0.0%**（5 次扰动全部正确放行，怀疑-反驳机制抑制误判）；
- **检出率 = 100%**（10 次宕机全部检出，TP=10 TN=5 FP=0 FN=0）。
