# contribution-bounds（合成数据专用）

按主体（`subject_id`）做贡献界定的最小实现：全局记录数上限、分组数上限、
数值上下界裁剪、跨分片确定性合并、撤回/更正回填、逐条裁剪证据、
裁剪前后贡献审计，以及小域枚举的实际 L1 贡献检查。

仅使用 Python 3.11 标准库；测试基于 `unittest`。**只处理合成数据。**

## 参数定义（`BoundConfig`）

| 参数 | 含义 | 默认 |
|---|---|---|
| `max_records_per_subject` | 每主体全局保留记录数上限 k | 4 |
| `max_groups_per_subject` | 每主体全局保留分组数上限 g | 2 |
| `value_lower` / `value_upper` | 数值裁剪下/上界（负值同样按下界裁剪） | -5.0 / 5.0 |

派生量（统计量 = 保留记录裁剪值之和）：

- `max_abs_value = max(|lower|, |upper|)`
- 增删单主体 L1 界：`k * max_abs_value`
- 替换单主体 L1 界：`k * (upper - lower)`

## 关键定义

- **稳定保留策略**：每主体内部按 `record_id` 字典序贪心保留，先满足分组上限
  再受记录数上限约束；所有排序键只依赖记录内容，与输入顺序、分片划分、
  分片合并顺序无关（选择是候选记录集合的纯函数）。
- **全局去重**：按 `record_id` 全局去重，同 ID 多副本按确定性键取唯一胜者，
  落选副本出具 `duplicate_id` 证据；把同一 ID 挪到别的分片不会多算。
- **分片合并**：`ShardState` 携带分片内规范化候选记录与每主体计数；
  合并先取并集再施加全局上限，因此同主体分散在两片仍只保留总上限 k。
- **撤回 / 更正**：候选池完整保留被丢弃记录；撤回主体或更正记录后重新选择，
  空出的名额由候选池按同一稳定策略确定性回填。
- **审计**：每主体输出候选数、保留数、保留分组数、裁剪前总和、裁剪后总和、
  实际 L1 贡献及其是否不超过增删界；每条记录输出保留/丢弃决定、原因、
  原始值、裁剪值与是否被裁剪。合并报告附各分片状态大小与合并状态大小（字节）。
- **小域枚举**：`enumerate_subject_l1` 在有限小域上穷举单主体全部可能数据集
  （含跨两个分片的情形），统计实际最大 |sum|（增删视角）与最大差值（替换视角），
  与理论界对照。

## 运行

```bash
python3.11 run_sample.py                  # 合成数据端到端样例
python3.11 -m unittest test_contribution_bounds -v
```
