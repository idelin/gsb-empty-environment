# 承诺与可见性逐步收窄

被攻陷的进程想在 pledge/unveil 之后放宽权限，或借符号链接与 .. 读到未暴露路径。为Go沙箱库写可导入的承诺与可见性模型：Pledge 只能收窄 promises 集合，锁定后再调用失败且原集合不变；Unveil 在锁定前登记（路径，r/w/x/c），锁定后任何调用失败，同一路径重复登记只保留权限交集且不得扩大，登记后该路径权限为已有登记与本次的交集；访问判定先经调用方注入的文件系统解析符号链接与 ..，逐段进行，符号链接可指向已登记路径但不得越出，最终路径须落在登记项下并具备所需权限；未暴露路径返回 ENOENT 而非 EACCES，权限不足才返回 EACCES；路径大小写与尾斜杠按平台规则归一。用提权重调、权限扩大、跨登记符号链接、锁定后收窄、ENOENT 与 EACCES 区分验证。
