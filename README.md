进程内沙箱运行时利用 Intel MPK/PKU（Memory Protection Keys for Userspace，16 个 4 位保护键 `PKEY 0–15` 与 32 位 `PKRU` 寄存器）将不可信插件与宿主敏感内存隔离时，若仅扫描对齐指令流而忽略 x86-64 变长指令中间字节隐藏的 `0F 01 EF`（`WRPKRU`）或 `0F AE /5`（`XRSTOR` / `XRSTORS` 间接覆写 `PKRU`）、未确保不可信代码只能落入 `PKEY != 0` 且在切换边界用受信任跳板校验 `PKRU` 掩码，或允许不可信代码通过 `mprotect_pkey`/`sigreturn` 篡改页表保护键，沙箱内插件可直接修改 `PKRU` 读写宿主全部机密内存。为 C++17 系统安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 Intel MPK/PKU 字节码扫描与沙箱隔离状态机验证库。输入为不可信代码段原始机器码字节序列（含导出入口表与控制流跳转目标）、虚拟内存页表 `PKEY` 分配表、宿主受保护 `PKEY` 集合以及安全跳板（Trampoline）白名单区间。验证库精确执行：（1）对不可信代码段执行全字节偏移滑动扫描与解码（不仅限于指令首地址，防止非对齐跳转命中隐藏操作码），硬检出全部 `WRPKRU`（`0F 01 EF`）、`XRSTOR`/`XRSTORS`（`0F AE /5`、`0F C7 /3`）及 `SYSCALL`/`INT 0x80`（可能调用 `pkey_mprotect` 或 `rt_sigreturn` 绕过 `PKRU`）的非法出现，排除显式白名单跳板区；（2）校验全部页表映射：不可信插件可读/可写页不得使用宿主受保护 `PKEY` 或默认 `PKEY 0`，且不可信代码页必须严格只读可执行（`W=0 & X=1`，防运行时自修改注入 `WRPKRU`）；（3）验证每个沙箱调用入口/出口的 `PKRU` 掩码转换（每位 `AD`/`WD` 禁止读写宿主键），输出精确违例偏移与字节见证。附指令内部隐藏 `0F 01 EF`、`XRSTOR` 绕过、可写代码页注入与宿主 `PKEY 0` 泄漏测试。
