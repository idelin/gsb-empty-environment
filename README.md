# swrcache

Go 的 stale-while-revalidate 缓存库：过期后短暂返回旧值，同时保证同一 key 只有一个刷新者。

## 语义

`Get(ctx, key, maxStale)` 按调用者给定的可接受旧值窗口工作：

- **新鲜**（年龄 < `TTL`）：直接返回。
- **过期但在 `maxStale` 窗口内**：立即返回旧值，并在后台触发刷新
  （single-flight：已在刷新或处于失败退避期则不重复触发）。
- **过期超出窗口（或未命中）**：调用者等待刷新完成；若已有刷新在
  进行则加入等待（`done` channel），否则自己成为刷新者同步加载。

`maxStale` 是每次调用的参数，因此不同调用者可以有不同的旧值容忍度。

## 主动失效与版本检查

`Invalidate(key)` 递增 key 的代际（generation）并删除条目。进行中的
旧刷新在完成时做代际比对，发现代际已变则丢弃结果，绝不会把旧值重新
装入。失效会唤醒正在等待旧刷新的调用者，让它们转入新一代的加载。

## 失败退避

刷新失败时按指数退避（`InitialBackoff` 起，翻倍至 `MaxBackoff`）记录
`nextRetryAt`：退避期内不再发起刷新；窗口内的调用者继续收到旧值，
窗口外的调用者收到 `(旧值, ErrRefreshBackoff)` 作为尽力而为的结果。

## 时钟

`Clock` 接口抽象时间，测试用 `FakeClock` 手动推进，确定性核验过期、
删除、刷新成功相邻到达与退避窗口。传 `nil` 使用真实时钟。

## 测试

```sh
GO111MODULE=on go test -race ./...
```

覆盖：过期与旧值服务、失效丢弃在途刷新、并发到达 single-flight、
失败退避（含翻倍）、按调用者的旧值窗口。
