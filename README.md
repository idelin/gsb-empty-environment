# 局部变换流水线 + 差分解释器（纯标准库，Python 3.11）

自行实现一个小型 IR 的语法解析与解释执行（不使用 eval 或现成编译器），
串联多个局部变换，每步生成前后 IR 与结构验证结果，验证失败即回滚该步；
最后用差分解释器在有限测试域上比对原始程序与变换后程序的可观察行为。

## 模块

- `ir.py` — 指令定义、行式语法解析器（每条指令携带 UTF-8 字节区间 `Span`）、
  结构验证器（标签唯一性、分支目标存在性、操作数个数与种类）。
- `interp.py` — 解释执行器，带步数上限防死循环。
- `transforms.py` — 局部变换：常量折叠、删除空指令、死写消除、不可达代码删除，
  以及故意有缺陷的 `buggy_label_cleanup`（只查 `jmp` 引用就删标签，
  会破坏 `brz/brnz` 分支目标，用于演示拦截）。
- `pipeline.py` — 流水线：逐步执行变换并记录 `StepReport`
  （前后 IR、候选 IR、验证错误、是否应用）；结构验证失败回滚该步，
  后续安全步骤继续运行。
- `diffcheck.py` — 差分解释器：在有限测试域（默认每个输入变量取 [-2, 2]）
  上枚举全部输入组合，比对两边输出/异常行为。报告明确声明
  “并非全域等价证明”。

## 运行

```sh
python3.11 main.py            # 演示样例
python3.11 -m unittest test_all -v   # 测试
```
