支持嵌套保存点（Savepoint）与部分回滚的事务在提交后，其单条键的版本链上可能混杂已回滚子事务留下的废弃版本、同一事务覆盖的中间版本以及被多个活跃快照或逻辑复制槽钉住的历史版本；错误回收某中间版本会截断旧快照的可见路径或破坏版本链连续性。为存储引擎垃圾回收器交付可导入的 Go 版本链裁剪包。输入单键有序版本链（每版本含版本 ID、创建事务及所属子事务栈、是否已中止/被保存点回滚、逻辑提交序号与删除标记）、当前活跃快照列表（各带快照可见边界与所属事务，含同一事务内处于某保存点处的读视图）及逻辑复制槽保留下界。规则：已中止或被已回滚保存点创建的版本对所有非其自身未回滚子分支一律不可见，可直接摘除；对已提交版本，须保留每个活跃快照各自可见的精确最新版本、逻辑复制槽下界及之后的所有已提交版本、以及全链最新已提交版本（即使为删除墓碑，若仍有更老快照依赖其上界也须保留直至无老快照早于它）；其余彻底不可见的历史覆盖版本标记回收，并返回摘除回收版本后每个保留版本的新前驱指针。验收对照全快照逐版本可见性朴素模拟，覆盖三层嵌套保存点仅回滚中层、同事务先删后插留墓碑、复制槽钉住比所有活跃事务更老的版本，以及仅留删除墓碑且无老快照时整链清空。

## 交付包：versionchain

`versionchain` 是可导入的单键版本链垃圾回收裁剪包，面向支持嵌套保存点与
部分回滚的事务引擎。

- 入口：`versionchain.Prune(chain Chain) Reclaim`
- 输入：新到旧有序的单键版本链（版本 ID、创建事务、子事务/保存点栈、中止
  或保存点回滚标记、逻辑提交序号、删除墓碑标记）、活跃快照列表（可见上界、
  所属事务与保存点处读视图）、逻辑复制槽保留下界。
- 输出：保留版本链、可回收版本 ID 列表、摘除回收版本后每个保留版本的新前驱
  指针（链尾无前驱条目）。

保留规则：

1. 已中止或被已回滚保存点创建的版本对所有普通读视图不可见，可直接摘除；
   仅当仍有读视图严格位于该回滚子分支内部时才暂时保留。
2. 每个活跃快照只钉住其可见的精确最新版本（新到旧遍历到的第一个可见版本）。
3. 复制槽保留下界及之后的所有已提交版本一律保留；未提交且未中止的版本因
   结局未知而保留。
4. 最新已提交版本（含删除墓碑）在仍有快照可见或被复制槽覆盖时保留；当无更
   老快照依赖其上界且无槽覆盖时，墓碑也可回收，整链清空。

同事务保存点读视图语义：非回滚版本在读视图创建序号不晚于快照时跨同级保存点
可见；回滚版本仅对严格嵌套在该回滚分支内的读视图可见。

运行验收：

```sh
go test ./...
go test -race ./...
```

测试包含四个规定场景（三层嵌套保存点仅回滚中层、同事务先删后插留墓碑、
复制槽钉住比所有活跃事务更老的版本、仅留墓碑且无老快照时整链清空），并通过
`TestPruneAgainstNaiveSimulation` 对照独立编写的全快照逐版本可见性朴素模拟做
500 组随机链交叉验证。
