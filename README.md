# 义务合并引擎（obligation-merge-engine）

允许判定伴随限额、遮蔽字段、审计标签等义务；合并采用各义务专用代数；
不兼容义务导致明确失败，绝不静默择一或静默丢弃。

## 运行

要求 Node.js >= 23.6（原生 TypeScript 类型剥离 + 内置测试运行器，零依赖）。

```sh
npm test       # Node.js 内置测试运行器
npm run demo   # 运行样例
```

## 设计

- `src/attributes.ts` — 只读显式属性存储：整数、布尔、有限字符串集合；
  构造时快照冻结，求值期间不可变；不接外部身份服务，未定义属性读取即明确失败。
- `src/conditions.ts` — 条件语言：整数比较、有限集合成员判断、布尔与/或/非，纯函数求值。
- `src/obligations.ts` — 义务类型：限额、遮蔽字段、审计标签、输出格式、
  依赖限额（`value(key) >= value(relativeTo) + minGap`）、顺序敏感步骤。
- `src/solver.ts` — 合并求解器，每种义务使用专用代数：
  - 限额：取更严格值（上限取 min，下限取 max）；
  - 遮蔽字段 / 审计标签：并集（顺序无关，满足交换律）；
  - 输出格式：互斥选择，两个不同格式 => 明确冲突失败，双方义务全部保留；
  - 依赖限额：与普通限额构成约束满足问题，在有限候选域上求解，
    产出满足全部义务的方案及来源证据（贡献者 / 决定者 / 依赖关系）；
  - 顺序敏感步骤：按规则顺序显式保序拼接（不满足交换律），位置与来源显式记录；
  - 不可满足 => 返回子集最小不可满足核。
- `src/unsat.ts` — 基于删除的最小化：核不可满足，且任意真子集可满足。
- `src/reference.ts` — 有限枚举参考检查器：独立穷举有限候选域，
  交叉验证求解器的可满足判定与所给解。
- `src/engine.ts` — 策略求值：deny 优先且不执行允许义务；
  被抑制的允许义务显式记录来源与抑制者（不静默丢弃）；
  撤回规则（不可变操作）后重新求值，先前被压制的义务随之恢复。
