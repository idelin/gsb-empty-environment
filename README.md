# TopK 建议：压缩前缀树 + 版本化 TopK 上界

纯 Python 3.11 标准库实现（不使用任何搜索服务或全文检索库），在压缩前缀树
（radix tree）上维护**带版本的 TopK 上界缓存**，支持词频更新、删除、大小写
规范化、显示别名聚合、稳定决胜、排名游标分页，以及内存压缩重定位下的游标
语义。

## 文件

- `topk/tokenizer.py` — 确定性 UTF-8 分词器
- `topk/index.py` — `TopKIndex`（压缩前缀树 + TopK 缓存 + 游标 + 压实）
- `demo.py` — 运行样例（本地合成 UTF-8 文档）
- `test_topk.py` — `unittest` 测试（含随机增删对照全排序）

## 分词规则（tokenizer）

1. **词元**是"词字符"的极大连续段：Unicode 类别以 `L`（字母）、`M`（附加
   符号，组合重音不丢）、`N`（数字）开头的码点，以及下划线 `_`。其余码点
   （空白、标点、emoji 等）均为分隔符。
2. **词身份**为 `str.casefold()` 结果：`Apple`/`APPLE`/`apple` 是同一个词；
   `Straße` 折叠为 `strasse`。
3. **显示形式**保留原文片段。同一规范词的多个显示别名按词身份聚合，展示
   时取别名计数最高者，平手按 `(casefold, 原始串)` 字典序最小者——完全
   确定、稳定。

## 排名与稳定决胜

排名键为 `(-freq, normalized_word)`：词频降序，规范词字典序升序决胜。这是
全序，因此分页游标、缓存合并、参考实现全排序三者结果必然一致。

## 版本化 TopK 上界缓存

- 每个基数树节点缓存其子树的 top-`topk_capacity` 候选（按排名键有序），并
  携带版本号与 dirty 标记。
- 每次增/删/改词频只把到根的路径标脏（O(词长)），缓存**惰性**重建：合并
  各子节点已排序的缓存（`heapq.merge` + 截断），不扫描整棵子树。
- 词频下降或删除时，合并自然从子节点**补回**下一候选（backfill），无需
  特殊路径。
- 一个词是另一个词的前缀时（如 `app` 与 `apple`），中间节点同样持有词条，
  两者都可返回；空前缀即查询根节点，结果数受 `limit` 上限约束。

## 查询与分页（不扫描全部前缀子树）

`suggest(prefix, limit, after=None)`：

1. 沿压缩边定位前缀节点（前缀可落在边的中间，此时整棵子树匹配）。
2. **快路径**：若节点缓存未装满（即子树全量在缓存中）或请求页完全落在
   缓存范围内，直接切片返回，O(K)。
3. **深分页**：否则做 best-first 下降——堆中节点的优先级即其缓存上界
   （子树最优候选），弹出节点才展开其子节点；上界不优于游标 `after` 的
   子树被整体剪枝。每发出一个结果只需 O(出度) 的堆操作，绝不扫描全部
   前缀子树。

分页游标 `after` 是上一页最后一条的 `(freq, word)` 二元组（排名键），把
字典序与排名组合成全序游标，页与页之间无缝衔接。

## 内存压缩与游标语义

- 节点存放在 arena（槽位数组）中；删除/边压缩产生的废弃槽位计入
  `garbage_slots`，`stats()` 可观测。
- `compact()` 先沿脏路径刷新缓存，再把活树复制进新 arena（重定位），
  `generation` 递增，旧槽位标记 `retired` 但**冻结保留**。
- `open_cursor(prefix, strict=False)` 钉住某前缀节点的版本：
  - 压实后，非严格游标继续**读原版本**（冻结的旧槽位缓存，词频为旧值；
    显示别名属展示层，按当前别名解析）；
  - 严格游标在压实或任何版本变化后**明确失效**，抛 `StaleCursorError`。
  - 未压实的普通词频更新：非严格游标透明读到新版本。

## 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 增/删/改词频 | O(词长 + 路径标脏) |
| 缓存重建（单次、懒） | O(脏路径 × 出度 × K log 出度) |
| `suggest` 快路径 | O(K) |
| `suggest` 深分页 | O((limit + 展开节点数) · log 堆) |
| `compact` | O(活节点数) |

## 运行

```bash
python3.11 demo.py            # 运行样例
python3.11 -m unittest -v     # 测试（25 个用例）
```

测试要点：`RandomizedReferenceTest` 以固定种子做 4000 步随机增/删/改/查，
每步查询（含随机前缀、随机 limit、随机排名游标、全前缀分页扫描）都与
"全排序参考实现"逐条对照；另覆盖别名聚合、前缀即词、删除/降频补回、空
前缀上限、压实前后游标语义、缓存不扫描子树等。
