实时风控引擎把三条乱序变更流（A、B、C）按相同键做三路区间内连接：要求 t_B 落在 [t_A-d1, t_A+d2] 且 t_C 落在 [t_B-d3, t_B+d4]，同时允许上游发送撤回记录并推进全局水位。为流算子库交付可导入的 Go 增量维护包。每条输入带流标识、键、事件时间、行号、负载及正负重数（+1 插入，-1 撤回），另有全局水位推进事件。水位 W 到达后，所有已无可能再与未来事件匹配的状态行按各流安全下界清理；若随后仍收到早于已清理边界的迟到事件，须计入迟到丢弃计数而不破坏现有状态；同一批次内对同一输出三元组产生的正负增量须按键和行号抵消压缩后再发射，零净变化不得输出。验收用全历史批处理重算每次事件后的理论三路连接快照做差分对照，覆盖先收到撤回后收到插入的乱序抵消、三流安全清理水位因链式时间窗偏移不对称、迟到记录边界判定，以及单条 B 撤回同时撤销多条 A×C 组合并被同批新插部分抵消。
