# 块编码选择器（多选背包精确求解）

从每个图块的候选编码方案中各选一个，使总字节数不超过预算、整图总平方误差最小，
且每个所选方案的最大误差不超过该块限制。输出精确最优解与预算余量。

## 构建与运行

```sh
g++ -std=c++17 -O2 -Wall -Wextra -o selector main.cpp
./selector < input.txt
```

## 输入格式

```
N B                  # 图块数 N，字节预算 B
# 以下重复 N 次（每块一段）：
k L                  # 候选方案数 k，该块最大误差限制 L
bytes max_err sse    # 共 k 行：字节数、最大误差、总平方误差
```

## 输出格式

- `OPTIMAL`：随后给出 `total_sse`、`total_bytes`、`slack`（预算余量）及每块所选
  方案的原始序号与参数。
- `INFEASIBLE`：某块没有任何满足最大误差限制的候选（附原因行）。

## 算法

1. **可行性过滤**：剔除 `max_err > L` 的候选；某块为空则整体不可行。
2. **支配裁剪**：块内按 `(字节升, 误差升, 原始序号升)` 排序，仅保留平方误差严格
   更小的方案——被支配者（字节更多且误差不更小）不可能出现在最优解中。
   完全并列 `(bytes, sse)` 的重复方案保留原始序号最小者，决胜规则不被裁剪破坏。
3. **精确 DP**：`dp[b]` = 已处理块恰好共用 `b` 字节时的最小总平方误差，逐块转移，
   记录每格所选方案用于回溯。复杂度 `O(N · B · K)`，空间 `O(N · B)`（回溯表）。

## 决胜规则（确定性）

1. 总平方误差最小（主目标）；
2. 误差并列时总字节最少（预算余量最大）——对 `dp[b]`（b ≤ B）按升序取首个最小值；
3. 仍并列时按输入顺序先见者优先（块、方案均按输入序号扫描，仅在严格更优时替换）。
