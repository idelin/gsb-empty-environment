# swapplanner — 换电路径规划器

在带整数耗电的图上规划从起点到终点的行程：部分节点是换电站，可付费
换满电池，但受每日营业时间限制；允许等待。优化目标为字典序：

1. **最早到达**终点；
2. 到达时间相同时**总换电费用最低**。

## 运行

```sh
go run . examples/sample.json   # 或: cat input.json | go run .
go test ./...
```

## 输入模型（JSON）

- `capacity`：电池容量（整数电量单位）；`initial_battery` 缺省为满电。
- `edges`：`{from, to, energy, time}`，有向边，耗电与耗时均为非负整数（分钟）。
- `stations`：`{node, fee, swap_time, open, close}`，`open/close` 为每日
  分钟数（0–1440），`close <= open` 表示隔夜窗口（如 20:00–08:00）。
  换电可在窗口内任意时刻开始；到达时未营业则等待至开门。

假设：营业时间每日重复；只在换电站等待才有意义（边耗时与费用不随时间
变化），因此等待动作只作为换电的一部分生成。

## 算法

多准则标签设置法（label-setting，类似多目标 Dijkstra）：

- **标签**：`(node, battery, time, cost)`，优先队列按 `(time, cost)`
  字典序弹出；边耗时与费用均非负，因此第一个弹出的终点标签即最优解。
- **状态支配**：同节点的标签 A 支配 B 当且仅当
  `A.time <= B.time && A.cost <= B.cost && A.battery >= B.battery`。
  支配同时考虑时间与费用：更慢但更便宜、或更贵但电量更多的标签都不会
  被误删，每个节点保留一组 Pareto 最优标签。
- **零耗电环终止性**：电量是 `[0, capacity]` 内的整数，每节点至多
  `capacity+1` 个电量层级；同一电量层级下互不支配的 `(time, cost)`
  构成时间的严格下降链（时间相同则费用低者支配），而时间是有下界的
  非负整数，链必有限。零耗电零耗时环只会复制出相同或更差的标签，
  被支配检查直接剪枝，不会无限搜索。

## 输出

到达时刻、总费用，以及逐段行程：每段骑行后的剩余电量、每个停站动作
（等待开门时长、换电费用与耗时、换电后电量）。
