消息代理在同一请求内可把若干消费者临时拼成 fan-in：上游先预留字节信用，解码出整帧后才知道该把哪些信用返给哪些下游。给代理宿主交付可导入的 Go 包，输入每层有限状态的帧解码器、连接上的 FIFO 片段、共享内存页数，以及粘包时一页被多帧引用直至最后一帧确认的规则。求最少共享页数，使任何合法分包和确认顺序都不会到达全局停顿；没有可行容量时给一条不依赖容量的等待环。确认可乱序但只释放该帧持有的引用，源都到 EOF 后不能把未完整帧当作成功消费。输出一个可回放反例及安全容量的状态不变量证书，检查器不得调用容量搜索。每分量最多五连接、八帧，帧体可用重复段达 2^35 字节，不按字节展开。小实例系统枚举所有分包对照，重点验证单连接均无停顿却共享页互相锁死。
