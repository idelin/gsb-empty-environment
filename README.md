审计日志换了签署委员会，旧、新两边各自达到本轮阈值，仍可能给同一日志位置签出互斥结论。给 C++17 日志宿主写可嵌入的重配置准入组件。配置由带权签署者组和必须同时满足的分组阈值组成，同一永久身份换钥不增加投票权。同一机房或托管域可包含多个身份，失效策略声明允许哪些域一起失效。切换证书列出实际签过的锁定收据，绑定旧配置根、新配置根、日志位置与前缀摘要。新配置准入的条件是任一合法旧确认集合、任一合法新确认集合及任一容许失效集合组合下，仍有一个两边都认可且持有一致锁定收据的未失效身份。拒绝时只返回未获证明的配置条件，不生成攻击或发包步骤。实现有限证书，让独立函数能从签名配置和收据验证全集覆盖；提供者可给分块及公共边界，校验器需检查成员身份、域与阈值没有被错误拆开。小委员会用全枚举对照，多组共享一名签署者、域间相关故障、同钥不同身份与先签旧摘要后迁移均有明确验收结果。
