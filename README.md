# xportsim — 传输协议模拟器

按包序号维护发送 / ACK / 重传 / 超时状态的 Go 传输模拟器。
输入显式事件日志与给定的窗口增减规则，输出逐步状态轨迹，
并用守恒式与丢包重放做核对。

## 语义

- **在途守恒**：逻辑在途数 = 已发送且未 ACK 的不同序号个数。
  重传复用原序号，不增加逻辑在途包数。
- **重复 ACK**：不重复释放在途额度、不重复增大窗口，只计数。
- **Karn 规则**：重传包的 ACK 不用于 RTT 采样；超时后 RTO 指数退避。
- **窗口规则**（给定）：新 ACK → `cwnd += 1`（加性增）；
  超时 → `cwnd = max(1, cwnd/2)`（乘性减）。
- **丢包**：`drop` 是网络事件，发送方状态不变，只能靠超时发觉。

## 事件日志格式

每行一个事件，`#` 之后为注释：

```
tick <ms>     推进时钟；到期的重传定时器自动触发
send <n>      应用层交付 n 个包（受 cwnd 限制，可能阻塞）
ack <seq>     收到 seq 的 ACK（重复 ACK 不释放额度）
drop <seq>    网络丢弃 seq 当前在链路上的副本
timeout       强制对最老未确认包超时重传
```

## 运行

```
go run . -f events.txt                 # 或 cat events.txt | go run .
go test ./...
```

参数：`-cwnd` 初始窗口（默认 4）、`-minrto`（200ms）、
`-rto` 首个 RTT 采样前的默认 RTO（1000ms）、`-maxrto` 退避上限（60000ms）。

## 核对

1. **守恒式**：每个事件后断言 `acked + inflight == sent`、`cwnd >= 1`、
   `dropped <= transmissions`、被 ACK 的包必有副本存活到达。
2. **丢包重放**：结束后审计每个被丢包——必须经重传恢复或仍在途，
   绝不可能由被丢的副本换来 ACK。
3. **确定性重放**：同一日志再跑一遍，轨迹必须逐行一致。

任一不变量被破坏时进程以非零码退出。
