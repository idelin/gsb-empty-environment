# pathcheck

路径模式检查器：给定允许模式集合与拒绝模式集合，判断是否存在"被允许且未被拒绝"的路径，
并返回段数最少的见证路径。

## 模式语言

每个模式是 `/` 分隔的段序列，段只有三种：

| 段 | 含义 |
| --- | --- |
| `a` | 字面量，恰好匹配同名段（含 `*` 但不等于 `*`/`**` 的段，如 `a*`，也是字面量） |
| `*` | 单段通配，恰好匹配任意一个段，**不能跨越分隔符** |
| `**` | 多段通配，匹配零个或多个连续段 |

空路径 `""` 与根路径 `"/"` 是明确区分的两个路径：模式 `""` 只匹配空路径，
模式 `"/"` 只匹配根路径（`Rooted` 标志必须一致）。空段非法（`a//b`、`a/` 报错）。

## 判定算法（`Check`）

1. **有限字母表**：取所有模式中出现过的字面量，外加一个"新鲜"符号代表任意未提及的
   字面量。匹配只针对提及的字面量做相等判断，因此在该有限字母表上存在见证，当且仅当
   在任意字面量上存在见证，且最少段数相同。
2. **按段数穷举**：以段数递增（同段数按字典序、非根优先）枚举候选路径，第一个
   "匹配某个允许模式且不匹配任何拒绝模式"的路径即最少段见证。
3. **完备深度界**：允许（拒绝）模式并集可确定化为至多 `2^a`（`2^d`）个状态的自动机
   （`a`/`d` 为各模式段数+1 之和），乘积自动机最短接受字不超过 `2^(a+d)` 段
   （实现中饱和到 `2^30`）。枚举到该深度仍未命中即可判定 `None`（包含关系成立）。
4. **预算**：`budget` 为可检查的候选路径数上限；预算在达到完备深度前耗尽时返回
   `Unknown`，绝不给出不确定结论。

## 用法

```sh
go run ./cmd/pathcheck -allow 'a/*,b' -deny 'a/c' -budget 1000000
```

退出码：0 = 找到见证，1 = 无见证，2 = 未知（预算不足），3 = 用法错误。

## 测试

```sh
go test ./...
```

测试包含：解析与匹配单元测试（含 `*` 不跨分隔符、空/根路径区分）、判定表驱动测试、
预算不足返回 `Unknown` 的测试，以及用独立穷举对判定结果做交叉验证的测试
（见证合法性与最少段性、`None` 在完备深度内成立）和随机化差分测试。
