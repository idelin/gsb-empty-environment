终端准入网关在审计 Windows PE32+ 可执行文件与 DLL 的内存加固状态时，若仅检查常规导入表（IAT）而忽略延迟加载导入表（`IMAGE_DIRECTORY_ENTRY_DELAY_IMPORT`）和基址重定位表（`.reloc` / `IMAGE_DIRECTORY_ENTRY_BASERELOC`），攻击者可利用位于可写节的未受保护 Delay-Load IAT 劫持延迟解析函数指针，或在 `.reloc` 块中构造指向只读代码段/头部的畸形重定位项（如 `IMAGE_REL_BASED_DIR64` 越界写或负长度块死循环）破坏运行时完整性。为 C++17 二进制安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的原始字节级 PE32+ Delay-Load IAT 与 `.reloc` 安全审计库。库严格解析 PE32+ 头、节表及两大数据目录：（1）解析 `.reloc` 全部 `IMAGE_BASE_RELOCATION` 块：硬拒绝 `SizeOfBlock < 8`、非 4 字节对齐、越出目录边界或整数回绕；校验每条重定位项（高 4 位类型、低 12 位页内偏移）的目标 RVA + 写入宽度严格落入合法已映射节内且不得覆盖 PE 头、导入目录或重叠相邻重定位写区间，并拦截高危异常类型；（2）解析 `ImgDelayDescr` 延迟导入描述符数组（区分 `grAttrs & 1` RVA 模式与旧式 VA 模式）：校验 `szName`/`pIAT`/`pINT`/`pBoundIAT` RVA 全部合法且无越界字符串；硬检出缺失 `GUARD_CF` 或 `IMAGE_GUARD_PROTECT_DELAYLOAD_IAT`（Load Config `GuardFlags`）且 Delay-Load IAT 位于可写节未受保护的劫持风险，以及延迟导入表引用非白名单/相对路径 DLL 名称。附手工构造的合法 PE32+ 样本与 `.reloc` 越界/重叠篡改、零尺寸块死循环、未保护可写 Delay-Load IAT 测试。
