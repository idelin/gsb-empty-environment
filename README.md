关系库在同事务里删除一批主键时，多条外键同时带 CASCADE、SET NULL、RESTRICT 和延迟 NO ACTION，不同触发顺序可能让 RESTRICT 提前拦截或留下不同空值。为事务执行器交付可导入的 Go 级联求值包。输入表结构、外键动作与是否可延迟、当前各表行集（支持复合键、多列部分为空按 MATCH SIMPLE 忽略引用、以及自引用和表间环）及待删主键集合和提交前补插行。立即 RESTRICT 在任一可达触发顺序中只要指向它的子行尚未被删或置空就触发拒绝；延迟 NO ACTION 仅在事务提交且全部补插完成后检查。组件返回唯一收敛的最终行集，或明确报告立即违约、延迟违约，或因触发顺序不同产生至少两种不同终态（并给出两条产生差异的触发序列）。验收在总行数不超过十二的小实例上用全触发序搜索对照所有可达终态，覆盖自引用环 CASCADE、菱形路径同时出现 SET NULL 与 CASCADE 导致歧义、MATCH SIMPLE 部分空外键、以及删后提交前补插消除延迟 NO ACTION 违约。
