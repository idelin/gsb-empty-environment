针对多时间窗叠加、跨子网横向扫描与内存驱逐导致误判的网络探针场景，给 Go 检测宿主写可导入的流式扫描识别组件。连接事件带探针启动代、连接实例号、单调起始时间 `s` 及源/目 IP 端口，同一实例冲突元数据直接拒绝；连接生命周期严格遵循 `Start -> {Fail | Success | ResetAfterSuccess}`：成功覆盖同实例先前的失败记录，而成功之后的重置不得再退回失败。宿主可同时注册多个交错时刻 `t_i` 与宽度 `W_i` 的查询窗口，按规范化地址（先解映射 IPv4 映射 IPv6）分别统计 `[t_i - W_i, t_i)` 内的同源对单主机不同失败端口数、同源对同端口不同失败主机数，以及同源跨越的不同 `/24`（IPv4）与 `/64`（IPv6）目的子网数，任一达阈值即告警。水位线 `w` 推进前允许成功覆盖撤回未冻结查询的告警；当容量超限触发按源公平驱逐时，须精确维护每个窗口的计数上下界，从而严格区分 `ConfirmedAlert`、`ConfirmedClean` 与 `UncertainDueToEviction`。用全量重算核对多窗撤回、子网去重、状态机单向覆盖及驱逐不确定性边界。
