# 员工绩效考评时态指标账本

跨考评周期的 KPI 目标/权重时态管理组件（Go，仅标准库）。

## 设计

- **追加式版本账本**：每次战略调整通过 `AddVersion` 追加不可变版本，
  记录责任人、原因、登记日，并对内容计算 SHA-256 版本签名。
- **时态权重**：每条 `Entry` 在考核周期内的天区间 `[StartDay, EndDay)` 生效，
  支持追溯调整（新区间可覆盖全季度）。
- **季度末加权得分**：有效权重 = Σ(权重 × 生效天数) / 周期天数，
  得分 = Σ(有效权重 × 实际得分)。
- **历史快照推演**：`Score(versionID, actuals)` 可在任意历史版本下重算得分；
  `Impact(from, to, actuals)` 输出版本间的权重变化与得分差。

## 运行

```sh
go test ./... -v   # 测试（含验收边界场景）
go run ./cmd/demo  # 运行样例
```

## 验收边界

Q1（90 天）：v1 目标 A 权重 0.6 在 `[1,60)` 有效；第 45 天追溯调整为
全季度 A=0.4、B=0.6（v2，责任人签名保留）。实际得分 A=80、B=90 时：

- 调整前（v1 快照）：55.0667
- 调整后（v2 快照）：86.0000
- 实际得分差：+30.9333
