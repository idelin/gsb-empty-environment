训练运行时希望预检分块 reduce-scatter 调度是否会因接收缓冲耗尽而停住。交付可导入的 Go 包：每 rank 给一段有分支的指令 DAG，发送必须匹配另一端相同标签与分块的接收；小包可先占用有限 eager 槽，大包必须会合，同一发送通道不可越序。归约输入携带贡献 rank 的不交集合，重复贡献必须拒绝，终点各分块应恰有全员贡献。对至多六 rank、每个八条操作的小组，从所有合法异步交错中找最短反例（死锁、重复贡献或错误最终分片），同长按全局操作编号排序；若不存在则给可重放的可达状态闭包，不枚举重复的执行历史。证书检查器不能调用搜索器。用同步与 eager 混合、跨分块别名和只有特定交错才会耗尽槽的例子验证。
