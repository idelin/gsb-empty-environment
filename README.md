网关从旧证书链迁到新证书链时，同一账户可能同时持有硬件钥、服务证书和短期访问令牌。给Go资源宿主写可导入的持有证明验收库。输入已核验签名的事件，描述密钥生成、交叉认证、令牌续发、撤销及一次资源请求。每条授权列出用途、持有者不可变ID、所需证明角色和有效区间；同一物理钥的别名不能满足两个独立角色。轮换允许跨几条中继证明，但须一路约束同一持有者、资源和用途，且所有证明签发时各自的前置授权都有效。事件只给局部先后与时间区间，撤销可能与续发同刻；同刻按显式因果，不能自行补顺序。只有所有相容执行中请求都能满足互异材料的角色匹配才放行；一部分能则返回不确定与相反见证，无相容执行单列。用六事件全排列基准检验先续发后撤销、两角色共用一钥、交叉认证成环和资源范围缩窄。
