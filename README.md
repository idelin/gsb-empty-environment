数据库索引执行器希望在提交表尚未补齐时仍能跳过堆页。交付可导入的 Go 包，按快照返回一个索引页在所有合法事务补全下可见版本数的精确最小值和最大值，以及各自的补全见证。快照上界之后或快照中活跃的事务视作尚未生效；其他事务可已知提交、已知中止或未知。版本当且仅当创建事务生效且删除事务未生效时可见，无删除者视作未删除。依赖 u→v 表示 u 提交必有 v 提交，这约束最终判定，不能把快照中的暂未生效等同于最终中止。允许依赖环，已知状态矛盾须报告。未知结果在整页及多页合并时共享；逐行分别取界再求和会错。页摘要可分裂合并，相同事务对只保留重数。最多 4096 个事务，给出一棵合法树分解，每袋至多 11 个事务，所有依赖边及创建删除对都由某袋覆盖；不得枚举全局补全。支持在固定分解上反复补齐最终提交状态及修改局部版本重数，提供计数证明只更新受影响袋到根的路径。测试重放每个见证核对行数，在随机小例穷举合法补全，并覆盖依赖环横跨多个袋、同一事务在两个子树抵消、空页、快照跨越依赖两端和矛盾补全后撤销的情况。
