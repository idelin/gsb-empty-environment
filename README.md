配置宿主只允许加载登记过的类型。新版协议允许同一个节点以不同角色被两处引用，例如一个地址能作公开说明，却不能作凭据来源。为Go加载器写可导入的检查包，输入有限的有向对象图与受签名的递归类型声明；边可为具名字段、列表位置或共享引用，类型有记录、可选字段、带判别值的联合及命名递归。权限按字段路径上的角色收窄，引用沿该次访问的角色生效，不能把此前在公开位置的成功检查复用到敏感位置。普通值边必须展开，只有声明标成惰性且角色不扩大的引用边允许闭环。结果应给出覆盖每个可达节点、类型和角色组合的有限验收证书，失败时给最短不合规访问路径；相同长度按字段字节序取首。限制十万条边，不能复制展开共享图。用独立小图解释器验证仅部分联合分支允许环、同节点多角色访问、标识重名和惰性标记移到错误层级。
