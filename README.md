# bplustree

Go 实现的 B+ 树（仅标准库），重点是**删除操作中的叶子节点兄弟借调（Borrowing）**。

## 删除重平衡规则

- 节点最多容纳 `order` 个键，非根节点键数低于 `order/2`（最小装填因子）即下溢。
- 叶子下溢时优先**从左兄弟**借调其最大一条记录，左兄弟无富余再向**右兄弟**借调其最小一条记录；每次借调后精确修正父节点中的路由分界键。
- 两个兄弟都无富余时才合并，合并可能向上传播并使树高减一。
- 借调不改变树高；被借调叶子的新最小键若记录在祖先分界键中，会沿父链向上修正。

## 运行

```sh
go test -v ./...   # 测试
go run ./cmd/demo  # 演示：删除 5 触发从左兄弟借调 4，父分界键 5 -> 4，树高不变
```

## 文件

- `bplustree.go` — B+ 树实现（插入/删除/查找/借调/合并）
- `bplustree_test.go` — 单元测试与随机化不变量测试
- `cmd/demo/main.go` — 运行样例
