# monotone-rational-cubic

保单调的有理分段三次 Hermite 插值库（TypeScript，零依赖）。
给定节点与函数值，构造 C¹ 连续的分段有理插值；**当输入数据单调时，每一段都严格保持单调**，
并且对每一段输出**解析的（非采样的）导数非负证据**。

## 特性

- 有理分段三次插值（Delbourgo–Gregory 族），C¹ 连续；
- 数据单调 ⇒ 每一段单调（有完整数学证明与可机检证书）；
- 端点导数规则**固定**（Fritsch–Carlson 单侧三点公式加单调性钳制），无调参；
- 重复横坐标：同值去重，**异值拒绝**（抛 `DuplicateAbscissaError`）；
- 每段输出系数与导数非负证据 —— 证据来自**精确二次导数根分析**，不是采样检查；
- 平台（水平段）、陡变、非均匀间距均有精确处理与测试；
- 非单调输入：自动按局部趋势分段保形（不产生过冲），可选 `requireMonotone` 直接拒绝。

## 数学原理

### 段上有理形式

第 i 段 `[x_i, x_{i+1}]` 上，记 `h = x_{i+1} - x_i`，`s = y_{i+1} - y_i`，局部坐标
`θ = (x - x_i)/h ∈ [0,1]`，端点导数为 `d0, d1`。取 Delbourgo–Gregory 有理三次族

```
P(θ) = N(θ) / D(θ),
D(θ) = (1-θ)² + r θ(1-θ) + θ²,
N(θ) = y0(1-θ)³ + ((r+1)y0 + h d0) θ(1-θ)² + ((r+1)y1 - h d1) θ²(1-θ) + y1 θ³.
```

**关键选择**：形状参数取 `r = α + β`，其中 `α = h d0 / s`，`β = h d1 / s`。此时

1. `N` 的三次项系数恰好为 0，分子退化为二次：
   `N(θ) = y0(1-θ)² + m θ(1-θ) + y1 θ²`，`m = r y0 + h d0 = r y1 - h d1`；
2. 导数分子**精确为二次多项式**：
   `dP/dx = W(θ) / (h D(θ)²)`，
   `W(θ) = h d0 + 2(s - h d0) θ + (h(d0+d1) - 2s) θ²`。

（可以验证：对一般 `r`，`W` 是四次多项式——其四次项系数为 `(α+β-r)(2-r)`。
事实上，任何真正的"三次分子/二次分母"有理 Hermite 插值的导数分子都是四次的；
要求导数分子精确为二次，唯一确定 `r = α+β`。这正是本库能做**精确二次根分析**的原因。）

### 单调性定理

若 `s > 0` 且 `d0, d1 ≥ 0`（固定的 PCHIP 导数规则保证这一点），则 `W(θ) ≥ 0` 在 `[0,1]` 上恒成立。

证明要点：`W(0) = h d0 ≥ 0`，`W(1) = h d1 ≥ 0`。

- `w2 ≤ 0`（凹或线性）：最小值在端点取得，故 `W ≥ 0`；
- `w2 > 0`（凸）：顶点 `θ* = (h d0 - s)/w2`。
  - `θ* ∉ (0,1)`：`W` 在 `[0,1]` 上单调，最小值在端点；
  - `θ* ∈ (0,1)`：等价于 `α > 1` 且 `β > 1`，于是
    `W(θ*) = (4 w0 w2 - w1²)/(4 w2) ≥ 0 ⟺ αβ ≥ 1`，显然成立。∎

`s < 0` 的情形对称（证 `W ≤ 0`）。`s = 0`（平台）时规则导数必为 `d0 = d1 = 0`，
此时 `P(θ) ≡ y0` 严格为常数，`W ≡ 0`。

### 证书（导数非负证据，非采样）

每段的证书完全由二次式 `W` 的**闭式分析**给出：

- 分类：`identically-zero` / `linear` / `concave-endpoint-min` /
  `convex-vertex-outside` / `convex-vertex-inside`；
- `certifiedMin`：`σ·W` 在 `[0,1]` 上的闭式下界（端点最小值或顶点值
  `(4w0w2 − w1²)/(4w2)`），`≥ 0` 即证毕；
- `rootsInUnitInterval`：用求根公式算出的 `W` 在 `[0,1]` 内的精确实根；
- `denominatorMin`：分母下界 `min(1, (2+r)/4) > 0`（保证无极点）。

整个过程没有任何采样点检查；测试中的稠密采样仅作为对解析证书的交叉验证。

## 节点导数规则（固定）

- 内部节点：相邻割线斜率 `Δ_{i-1}, Δ_i` 异号或含零 ⇒ `d_i = 0`；否则加权调和平均
  `d_i = (w1+w2) / (w1/Δ_{i-1} + w2/Δ_i)`，`w1 = 2h_i + h_{i-1}`，`w2 = h_i + 2h_{i-1}`；
- 端点（固定规则，不再可调）：单侧三点公式
  `d_0 = ((2h_0 + h_1)Δ_0 − h_0Δ_1)/(h_0 + h_1)`，随后钳制：
  与 `Δ_0` 异号 ⇒ 0；若 `Δ_0, Δ_1` 异号且 `|d_0| > 3|Δ_0|` ⇒ `3Δ_0`。右端对称。
- 两个节点时 `d0 = d1 = Δ0`（直线）。

## 重复横坐标

- 相邻完全相同的点（同 `x` 同 `y`）：自动去重；
- 同 `x` 异 `y`：抛出 `DuplicateAbscissaError`（携带 `x`、`firstValue`、`conflictingValue`）；
- 节点必须非递减排列，否则抛 `InvalidInputError`。

## 非单调输入的处理

默认模式下非单调数据**不被拒绝**：固定的导数规则在局部极值点处自动令 `d_i = 0`，
于是每一段的导数符号与该段割线符号一致——样条在每一段上保持数据的局部单调趋势，
**不会引入数据中没有的极值（无过冲）**，整体仍是 C¹。每段证书照常输出，
`verify()` 对每段验证"段内趋势保持"。

若业务上要求输入必须单调，传 `requireMonotone: true`，非单调输入将抛出
`NotMonotoneError`。

另外可传 `derivatives` 自定义节点导数：此时证书仍然**如实检验**，
`verify()` 会报告哪些段破坏了单调性（证书不是橡皮图章）。

## 使用

```ts
import { createSpline } from 'monotone-rational-cubic';

const spline = createSpline([0, 0.5, 1, 2, 2.5, 6], [0, 0, 0.5, 3.5, 3.5, 4]);

spline.evaluate(1.5);    // 插值
spline.derivative(1.5);  // 精确导数 W(θ)/(h D(θ)²)

spline.getCoefficients();        // 每段 N / D / W 系数（θ 的升幂系数）
spline.getMonotonicityEvidence(); // 每段导数非负证据（含精确根与顶点分析）
spline.verify();                 // 整体验证报告 { holds, certifiedMinMargin, failures }
```

区间外求值用端点段外推（证书只覆盖节点范围内）。
