# 分片交接模拟器

模拟分片数据从甲（源）迁往乙（目标）的完整交接过程，TypeScript 实现，无任何外部依赖。

## 设计

- **甲 `SourceNode`**（src/source.ts）：接受写并分配全局递增 `seq`，应用本地并追加 oplog。
  落下切换栅栏后拒绝新写（返回 `fenced`），但栅栏前已接受的在途请求继续完成并正常返回结果。
- **乙 `TargetNode`**（src/target.ts）：仅当条目 `seq` 更新时才覆盖，因此乱序/重复的增量幂等；
  删除以墓碑（`value = null`）保留版本，旧版本的 put 乱序到达或重发都不会让记录复活。
- **增量通道 `UnreliableChannel`**（src/channel.ts）：随机乱序投递，按概率产生重发副本。
- **复制流程**（src/simulator.ts）：
  1. 基础数据复制：逐条时点读取（复制期间甲仍在写入，允许不一致）；
  2. 增量复制：从 oplog 游标持续发送变更，经乱序重发通道投递；
  3. 栅栏切换：甲拒绝新写，等待在途请求完成；
  4. 追平游标并排空通道，完成切换。
- **检查器 `Checker`**（src/checker.ts）：
  - 逐步检查：每轮复制后，乙的每个条目必须与甲 oplog 中同 `seq` 的写一致，墓碑不可见；
  - 最终检查：每个已确认写的最终效果在乙可见（乙每 key 的 `seq` 等于最后已确认写），
    且乙不多出任何未确认的 key（栅栏后被拒的写不会泄漏到乙）。

## 运行

```sh
tsc -p tsconfig.json   # 编译到 dist/
node dist/simulator.js # 确定性场景 + 5 个种子的随机模拟
```

`src/scenarios.ts` 包含确定性场景：乱序删除不复活、重发幂等、栅栏语义、旧快照被增量覆盖。
