# BuildKit源策略准入

BuildKit 的构建图里 source 操作可以是镜像、git、http 或本地上下文，源策略规则对它们做允许、拒绝、转换（如把标签固定为摘要），攻击者提交的构建定义可用带 @ 的伪造标识、可变的 git 引用或重定向的 http 地址绕过。为 Go 构建服务写供 solve 请求准入调用的源策略包：输入构建定义（顶点、source 标识串、属性、依赖边）和有序规则（匹配类型 EXACT、WILDCARD、REGEX，动作 ALLOW、DENY、CONVERT）；镜像引用须规范化（补默认注册中心域名与 library 前缀，标签与摘要并存时以摘要为准），git 引用要求固定到提交且 URL 不含用户信息，http 源须带校验和；规则自上而下首个命中为准，CONVERT 的结果须再通过其后规则中的 DENY；多个顶点复用的子图只判定一次。用 @ 伪造、分支引用、无校验和 http、转换后命中拒绝规则验证。
