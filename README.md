# 同一密钥流下多条秘密的联合泄漏

加密日志误把多条消息放在同一异或密钥流上，单独看每条候选都合法，合起来却可能暴露秘密。用Go写供密码回归服务调用的恢复包：输入至多12条密文字节串、各自使用密钥流的非负起始偏移，以及每条最多64个合法明文候选，候选长度须等于对应密文；密文等于明文与共享密钥流逐字节异或。求全部可满足的候选组合，不能仅逐对检查；输出每条记录可取候选集合、每个密钥流位置被所有解一致确定的字节，以及至多20个按候选索引字典序排列的完整见证，解过多明确截断。没有完整解则找按记录数最少、记录ID字典序决胜的冲突子集，提供删除任一记录后的解；搜索预算不足返回未知并保留已证约束，不把当前候选交集当成唯一解。支持非重叠片段、空消息、重复候选及三方两两兼容但整体冲突；用小候选集全组合枚举验证恢复范围，不能把统计偏好伪装成确定明文。
