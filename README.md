# pausecoord

暂停协调库：让工作者在安全点停下，全部确认后才允许读取一致快照。

## 协议

- 每次 `Pause` 开启一个新一轮次，轮号（epoch）单调递增。
- 工作者在 `Checkpoint` 确认当前轮号并驻停，直到 `Resume`；确认按轮号
  标记，过期轮次的确认永远不会被计入当前轮次。
- 暂停期间退出的工作者（`Close`）直接从待确认集合中移除。
- 暂停期间新工作者 `Register` 会阻塞，直到恢复。
- `Pause` 超时则放弃本轮：释放所有驻停工作者，后续 `Pause` 使用新轮号。
- 仍驻停在检查点的工作者跨轮次时会在等待循环内确认新轮号——它始终
  处于安全点，因此快照仍然一致。

## 用法

```go
c := pausecoord.New()

// 工作者 goroutine
w := c.Register()          // 暂停期间会阻塞到恢复
defer w.Close()
for {
    w.Checkpoint()         // 安全点
    // ... 工作 ...
}

// 快照方
if err := c.Pause(5 * time.Second); err != nil {
    // 超时，本轮已放弃
}
// 所有工作者已确认并驻停，可读取一致快照
c.Resume()

// 或使用便捷封装
c.WithSnapshot(5*time.Second, func() { /* 读快照 */ })
```

## 测试

```sh
go test -race ./...
```

过期确认不计入、暂停期间工作者退出、新工作者等待恢复。
