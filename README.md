一台边界时钟在双向对时报文之间可能切换频率。采集端只留下各网卡的低位硬件时间戳与包的收发配对，网络栈不能用猜的单向时延改写包序。实现可导入的 Go 时间重建包：每个端口的捕获事件已按本地顺序排列，原始计数宽度 w=3..48，输入为每两个相邻事件提供实际递增 tick 数的闭区间上界与下界，可能跨多圈；相邻 tick 差须与低位差同余。每个相邻间隔注明所用的纪元；同一端口同一纪元使用同一未知的换算率，由固件给出的最多三个正有理候选值选择，时间在切换点连续。每个报文的真实收发差落在自己的有理延迟闭区间，少数事件有绝对时间锚区间，并为所有事件给一个有限全局时间窗。端口至多四个、每端口最多十二个事件，每个相邻 tick 差区间最多含四个同余候选。调用方按捕获 ID 查询任意两事件的真实时间差：返回所有可行重建对应的精确可达集合，规范化为递增、不相交闭区间，接触则合并；不能只回最小最大或对离散纪元还原做凸包。每个区间的两个端点各附可回放的完整时钟和回绕选择；若输入无解，返回不一致而不是空精度区间。输出可随实际可达区间数增长，不允许逐 tick 枚举时间窗；从网卡回放接口用一个可行证书还原到达时刻。用短捕获的独立枚举和有理约束闭包比对，覆盖中间出现真空洞、非对称报文延迟、负时间差、跨多个低位计数圈、以及各段独立可行但同纪元共享倍率后不相容。
