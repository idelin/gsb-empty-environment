编译器把 SSA 形式退化为普通三地址码时，基本块入口的多个 Phi 节点等价于在每条前驱边上同时执行的并行复制，存在读写环和公共源变量，若前驱有多个后继还涉及关键边冲突。为代码生成后端交付可导入的 Go 退化调度包。输入控制流图边集合、各块 Phi 定义列表（目标变量及各前驱边上的源变量或常量）以及允许使用的专用临时寄存器名。规则：先识别所有从多后继块连向含 Phi 的多前驱块的关键边，插入最小集合的分裂中继块使并行复制落位无干扰；再对每条边上的并行复制组做精确序列化，要求无环依赖按先读后写拓扑序直接生成移动指令，每个纯粹变量置换环须借助单个临时寄存器打破（若允许硬件 swap 模式则用最少 swap 替代），且同一源变量扇出给多个目标时不得因覆盖提前破坏未读取目标，最终等价语义须与并行赋值完全一致。验收用符号执行对照每条边上原并行赋值语义，覆盖三元置换环、带扇出尾巴的 ρ 型依赖图、自赋值消除、常量与变量混合复制，以及关键边分裂前后所有路径值不变。
