# rational_pieces — 分段有理表达式的精确代数工具

纯 Python 3.11+ 标准库实现（`fractions.Fraction` 精确有理数），**不调用任何符号代数库**。
支持分段区间上有理表达式的求和、乘法与连续性检查。

## 功能特性

- **精确有理计算**：多项式加/减/乘/带余除/首一 gcd/求值全部基于 `Fraction`，无浮点误差。
- **共同细分**：两个分段函数相加/相乘时自动对交叠区间做共同细分；空洞（无定义区域）保持无定义；区间开闭在组合后精确保持。
- **来源映射**：每个细分段记录 `sources`（如 `('L:f1', 'R:g1')`）。
- **增量维护**：`CombinedPiecewise.edit()` 编辑片段后仅重算相关细分段，未受影响段按对象同一性原样复用。
- **不跨排除点合并**：相邻同表达式段仅在接点被覆盖且表达式在该点有定义时才合并。
- **定义域空洞 / 可去奇点 / 极点**：书写分母决定定义域（空洞不回收）；约去 gcd 仅用于极限；可去奇点给出连续延拓值。
- **单侧极限**：极点处按分母零点重数与符号精确判定 ±∞。
- **连续性判定（精确代数证据）**：左右极限与函数值精确比较；左右值不同报告跳变（含跳跃度）；只一侧定义不冒称连续（结论为 `continuous_on_domain` 而非 `continuous`）。
- **独立根隔离与符号测试**：Sturm 序列计数 + 二分隔离，每个隔离区间核验“恰含一个根”；无理根以隔离区间表示，有理根由有理根定理精确命名。
- **预算语义**：根隔离预算耗尽时，未分离区间明确保留为 `undecided`，总体结论为 `undecided`，绝不猜测。
- **变换记录**：每步变换在 `trace` 中注明适用域（如“约去公因子 (x-1)：等式仅在 (x-1)≠0 处成立”）。

## 目录结构

```

  poly.py       # 有理系数多项式：精确算术、gcd、deflate
  roots.py      # Sturm 根隔离（带预算）、有理根定理、区间符号测试
  ratfunc.py    # 有理式：空洞/可去奇点/极点、单侧极限、变换记录

tests/          # unittest 测试（42 例）
examples/demo.py
```

## 快速开始

```python
from rational_pieces import Piecewise, Piece, Interval, Poly, RationalFunction

x = Poly.x()
f = Piecewise([
    Piece('a', Interval(0, 1, True, True),  RationalFunction.of(Poly([1]), label='1')),
    Piece('b', Interval(1, 2, False, True), RationalFunction.of(x, label='x')),
])
print(f.analyze())
```

## 设计约定

- 有理式的**书写分母**决定定义域：`1/x + (-1/x) = 0/x^2` 在 `x=0` 仍无定义（可去奇点），
  约简只用于极限计算，不回收空洞。
- 根计数区间为 `(lo, hi]` 约定；片段内部奇异点与边界端点分别判定，互不重复。
- 结论分四档：`continuous` / `continuous_on_domain` / `discontinuous` / `undecided`。
