发布服务从多个审批域接收对同一制品摘要的签名。给 Go 发布门禁写可导入的授权证书校验包。域策略是一棵阈值树，内部节点要求至少 k 个不同子节点成立，叶子要求指定角色的一名签署者；同一签署者即使持有不同角色或轮换过密钥，整份证书也只能用一次。角色委托是带有效期和发布范围的有向图，路径上每段都必须允许本次摘要所属的仓库，环不能产生额外权限。选择的所有签名和委托必须存在同一有效时刻，区间左闭右开；核验回调须验证绑定仓库、摘要和策略版本的真实 Ed25519 签名。最多 20 名签署者、64 个叶子、128 个时间端点。返回使用签署者最少的见证，并列取排序后签署者 ID 序列最小者，再取最早有效时刻。提供独立见证检查函数和小规模穷举对照，覆盖各分支单独可满足但整体抢占同一人、两条委托时间仅端点相接、换钥重复签名及贪心先选者阻断后续授权。
