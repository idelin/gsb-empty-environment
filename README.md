# 联邦图查询网关绕过与子图实体解析授权

图查询联邦里，子图通常直接暴露在内网，攻击者绕过网关向子图发 _entities 查询，传入任意类型与键，就能读到网关本来会拦截的字段。为TypeScript子图服务写可导入的请求准入中间件：只接受带网关签名头的请求（HMAC-SHA256，输入为请求体字节与毫秒时间戳，时间戳偏差不超过 30 秒，常量时间比较），缺失或不符时对 _entities 与 _service 查询一律拒绝；_entities 的 representations 最多 100 个，每个必须含 __typename，且在调用方给的本子图实体白名单内；每个 representation 的键字段须与该类型声明的键一致，不得含声明之外的字段；解析出实体后，按类型与字段重新执行授权回调，逐字段拒绝而不是整体放行；生产环境下自省查询拒绝；查询深度超过 12 拒绝；批量请求（数组形式）整体拒绝。用无签名头直接查 _entities、未登记的 __typename、多余键字段、过期时间戳和合法网关请求验证。
