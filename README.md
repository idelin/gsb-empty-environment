# 套接字凭据降权窗口

进程降权后，既有本地连接可能继续携带旧身份操作。给Go消息宿主实现凭据代次组件，每次请求按接收时的可信凭据快照授权，连接身份只用于审计不能替代逐消息身份；同一消息的句柄与正文必须同代。用降权与接收交错、缺失凭据和批量消息测试旧权限不能因连接复用而延长。

## 组件设计

- `CredentialEpoch`（`epoch.go`）：凭据代次组件。`Downgrade` 单调降权（只允许删除身份与能力）并开启新代次，`Lookup` 始终按调用时刻的代次返回不可变快照，历史代次通过 `AtEpoch`/`History` 保留供审计。
- `Host`（`host.go`）：消息宿主。每帧在 `HandleFrame` 内用“逐消息”对端身份（如 AF_UNIX 的 `SO_PEERCRED` 重新读取结果）查询当前代次快照后授权；`RegisterConnection` 记录的连接身份仅写入审计，不参与授权。
- 同代不变量：句柄帧按接收代次挂起，正文帧的代次必须与句柄一致，跨降权到达的正文返回 `ErrGenerationMismatch` 并作废句柄，旧权限无法借长连接延续。
- 缺失凭据：当前代次查无身份的帧返回 `ErrMissingCredential`，句柄不会挂起；正文缺凭据同时清理已挂起的同名句柄。
- 批量与泵循环：`HandleBatch`/`Pump` 中每帧独立按各自接收时刻的快照授权，单帧拒绝不影响其余帧，全部判定进入 `Audit()` 审计链。
