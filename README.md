更换接收节点时，旧 OSCORE 端点的窗口、高可用副本的日志和新端点收到的包可能互相错开。给 Go 服务端写可导入的重放状态交接包，输入为题内有限协议，不调用网络。序号为 40 位，按安全上下文和发送者分区；一个原始请求可被路由到任一节点，每次向业务成功交付都算一次。各节点以写时复制区间集合记录已承诺交付序号，节点日志由连续有序的签名批次构成，批次头绑定前根和代次。迁移只取得多个带认证根的范围证明，证明只能说明某一节点在某一屏障前的已见集合；未覆盖区间须按未知处理，不得视为空。旧端点租约全部结束后，只有当每个可能服务该发送者的节点均能证明某号未交付，新节点才能接受；任一已见则拒绝，其余返回等待并指出最少还要索取哪些证明页。候选页可覆盖多节点多区间，最多 20 页，每页有成本。对一批任意半开查询段，给出逐区间决策和使全部尚有可能通过的序号确定的最小成本补页集合，不能枚举序号。边界查询含 2^40，证明页重复、乱序、相同屏障不同根一律按规定分别去重或隔离。给可单独验收的覆盖证书，用小域全枚举与所有页子集核对，验证旧租约未结束、范围缺一端及同一请求跨节点竞态。
