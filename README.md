审计服务用多方承诺与随后公布的值分配独立复核者。参与方可能在看见公开前缀后选择公布或弃权，不能把最终成功发布过的轮次当成没有选择性缺失的随机样本。给 Go 分配宿主实现可导入的轮次准入包。输入只含签名承诺身份、公开消息类型、有理数概率表、每个参与方能看到的公开分区和规则允许的弃权位置；不接收真实私钥。相同可见历史下的同一主体必须采用相同选择，不能根据隐藏分支分别决定；多方若属同一失效域，选择条件由宿主明确给出。计算每个审计类别相对理想分配的最坏偏差以及无法完成轮次的概率界，已弃权轮次是否重试由公开规则决定，最多两次重试且共享已发布的承诺。输出精确有理数界和独立核验证书，不输出操纵步骤。轮次树可共享相同后续状态，状态数数千而公开决策点至多14。用小树完全枚举验证有条件弃权、未成功轮次的归一化、同一公开观察对应多个秘密状态和重试时不能重新抽取已固定随机量。
