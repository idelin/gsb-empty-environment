# CBJ CSP Solver — 带非时序回溯（Backjumping）的 CSP 求解器

TypeScript 实现的冲突导向回跳（Conflict-directed Backjumping, Prosser 1993）
约束求解引擎。搜索遇到死胡同时，不按传统时序方式仅回退到上一变量，而是
根据冲突分析定位导致矛盾的最深根源变量（冲突集 / Conflict Set），直接
跳跃回溯，剪除与矛盾无关的整棵子树。

零依赖：使用 Node.js (>= 23.6) 原生 TypeScript 类型擦除与内置测试运行器。

## 运行

```bash
node --test        # 运行内置测试（node:test）
node src/demo.ts   # 运行 10 变量基准样例（CBJ vs 时序回溯对照）
```

## 验收场景

基准问题（`src/problem.ts`）：10 个变量 X1..X10，其中 X8 与 X2 之间存在
硬约束 `X8 <= X2 + 1` 且 X8 值域为 {3, 4}。X2 首选 1 时，第 8 步必然
死胡同，且冲突只由第 2 步的取值引起：

- 第 8 步 X8 值域耗尽，冲突集 = {第2步 X2}；
- 求解器直接跳过第 3..7 步回跳到第 2 步，修改 X2 = 2；
- 随后一路赋值到底，找到解 `[1, 2, 1, 2, 1, 2, 1, 3, 1, 2]`。

样例实测（`node src/demo.ts`）：

| 算法 | 搜索节点 | 约束检查 | 死胡同 |
| --- | --- | --- | --- |
| CBJ（本求解器） | 23 | 18 | 1 |
| 时序回溯（对照） | 248 | 241 | 94 |

节点数减少 90.7%，约束检查减少 92.5%。

## 代码结构

- `src/csp.ts` — CSP 问题模型（变量、值域、二元约束）与解校验
- `src/solver.ts` — CBJ 求解器：冲突集维护、最深根源变量回跳、冲突集回传；
  `mode: "chronological"` 退化为时序回溯用于对照
- `src/problem.ts` — 10 变量验收基准问题及不可满足变体
- `src/demo.ts` — 运行样例：完整搜索轨迹 + 两种算法统计对比
- `test/solver.test.ts` — Node.js 内置测试（`node:test` + `node:assert`）

## 算法要点

1. 为当前变量试值时，与所有已赋值变量做一致性检查；每次冲突把肇事的
   过去变量记入当前变量的冲突集 `conf[i]`。
2. 值域耗尽（死胡同）时，跳到 `conf[i]` 中下标最大（最深）的变量 `h`，
   而非上一变量 `i-1`。
3. 回跳时把 `conf[i] \ {h}` 合并进 `conf[h]`，保证跨层冲突原因不丢失，
   算法保持完备性。
4. 冲突集为空说明矛盾与任何赋值无关，判定问题不可满足。
