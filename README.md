多租户口令服务的 KDF 批处理要从一次内存预留改成跨节点接力。给 Go 服务写可导入的容量凭证组件；只调度宿主注入的哈希回调与验签回调，缺少或为 nil 的必要回调必须在构造与接收入口立即拒绝而不得降级跳过。每份凭证有唯一身份、租户、总字节额度和与输入绑定的参数承诺，可拆成不相交的编号区间转交另一节点，不能复制额度。拆分与移交由带签名的因果事件提交，各节点可先见子凭证后见父凭证；同一父区间的两份冲突移交即使签名都对，也不得在两处同时做可分配余额。隔离冲突子树但允许不相交兄弟继续。运行前必须既有完整额度链又有调用方的最终性回执，回执绑定根与事件前缀；未经最终确认的撤销只能阻止新预留，不能让已交付缓冲区被再次分配。内存按 s_cost×32 精确计量，64 位数须防回绕；同一任务崩溃后重入不得另占一份，回调结束、异常或取消只归还一次且先完成擦除。提供在线乱序增量合并及从不可变事件全集重算两个入口，结果须一致。用短交错全排列和计数分配器测试缺失回调拒绝、跨租户偷用、父区间一半冲突、重复完成和参数替换。
