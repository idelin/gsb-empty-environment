# 显式同义组查询扩展 + 位置倒排联合 TopK（本地原型）

纯 Python 3.11 标准库实现（`dataclasses/heapq/collections/math/unittest/re`），
**不使用任何搜索服务，也不使用 Lucene/Whoosh/Elasticsearch 等全文检索库**。
文档为本地合成的 UTF-8 文本，全部规则确定、可单测复现。

## 目录结构

- `syno/tokenizer.py` — UTF-8 规则分词器
- `syno/synonyms.py` — 显式同义知识库（单词同义 / 短语同义分离）
- `syno/query_graph.py` — 带权词图、两阶段扩展、预算截断、小图路径枚举
- `syno/index.py` — 文档与位置倒排索引（含短语连续位置核验）
- `syno/search.py` — 查询图 × 位置倒排联合 TopK、全局位置归属、证据输出
- `data/corpus.txt`、`data/synonyms.txt` — 合成语料与同义说明
- `demo.py` — 端到端运行样例（输出存于 `demo_output.txt`）
- `tests/` — unittest 测试（41 个）

## 分词规则（明确写清）

1. 输入按 UTF-8 解码，先 `str.casefold()` 统一小写。
2. token 两类，按出现顺序切分：
   - `word`：连续 ASCII 字母/数字 `[A-Za-z0-9]+`（如 `NYC123` 为一个 token）；
   - `cjk`：单个 CJK 统一表意文字/假名（中文按**单字**切分，
     `机器学习 -> 机|器|学|习`）。
3. 空白、标点（含中文标点）只作分隔并被丢弃。
4. 不做停用词过滤、不做词干化；每个 token 保留序号与字符起止偏移，
   供证据回显定位原文。

## 同义表示

- **单词同义**：显式同义组在组内连无向完全团（clique）。
  `add_word_group(["car","automobile","vehicle"])` 同时给出所有双向边；
  `add_word_pair(a,b)` 等价于二元素。重复声明同一对只保留**最大权重单边**，
  因此 `a↔b` 不会因重复声明而扩展两次。
- **多词同义**：短语作为不可拆散的整条替换单元单独存放
  （允许 `kicked the bucket ↔ died` 这种长短语到单词的替换，
  但 `died` 不会进入任何单词层边）。
- 边权 `0 < w <= 1`，默认 0.7；沿路径传播时权重**相乘**，
  原词固定权重 1.0（最高），跳数越多权重越低。

## 扩展算法（如何避免循环与指数组合）

阶段 A，全局闭包（多源按层 BFS）：

- 每个 surface 节点只**创建一次、扩展一次**；
- `max_word_hops` 限定层数，分支遇到已在路径上的节点即剪枝；
- `a↔b`：`a->b` 是发现树边，`b` 回看 `a` 的父边被剪枝并计入
  `back_edges`（演示中恰为 1），不存在 `a->b->a->b...`；
- 多个查询根共享的扩展节点只创建一次，标记 `shared`，不重复扩展；
- `node_budget` / `edge_budget` 耗尽立即停止，结果显式带
  `truncated=True` 与 `truncation`（`node_budget`/`edge_budget`），
  TopK 输出头部打印 `[未完成]`。

多源 BFS 首次发现节点的层数等于“距任意查询根的最小跳数”，
因此一次遍历即可得到所有根在跳数限制内的可达并集。

阶段 B，按根归因：在阶段 A 裁剪出的**有界无向闭包子图**上，
为每个查询根跑最大权 Dijkstra（目标是边权乘积最大），得到
“该 surface 可由哪些查询位置命中、各自权重与证据链”。子图规模受预算上界约束，
分支带 path-guard，有环也必然终止。

短语层独立枚举（左端点最长优先、覆盖区间不重叠），**绝不拆成单词边、
绝不与单词扩展做笛卡尔积**，因此没有指数组合。

`syno/query_graph.py` 另提供 `enumerate_simple_paths`：仅允许在
`<= 64` 节点的小词图上枚举无重复节点的简单路径用于人工核验，
超限直接拒绝。

## 联合 TopK 与不重复计分

- 单词候选取概念（查询位置）下所有 surface 的倒排位置；
  短语候选通过位置倒排做连续位置核验（以最稀疏词为锚点）。
- **全局位置归属**：候选证据按
  `原词/原短语 → 短语 → 权重高 → 路径短 → 概念 → 位置`
  排序后贪心占用文档 token 位置；每个位置只归属一个概念的一个 surface。
  因此同一位置原词与扩展词同时命中只计一次，多根共享扩展也不重复计分。
- **有界打分**（不无界叠分）：

      idf = ln(1 + (N+1)/(df+1))
      tf_merged = n_orig + best_w * n_exp          # 原词/扩展合并进同一 tf
      score_concept = idf * tf_merged/(k1+tf_merged) + (有原词 ? 0.5*best_w : 0)

  饱和项使多次命中边际递减（8 次命中的得分远不到 1 次的 8 倍），
  原词 bonus 固定不随命中数增长；文档分为各概念分之和。

## 证据展示

每条证据给出：来源标记（`原词/扩展词/原短语/扩展短语`）、概念、
文档中实际命中的 surface、传播权重、token 位置、跨度
（短语保留其路径长度）、以及 `原词 -> ... -> surface` 证据链。

## 运行

```bash
python3.11 demo.py
python3.11 -m unittest discover -s tests -v
```

## 已验证的关键性质

- `a↔b` 循环只展开一次（节点集仅 `{a,b}`，回边计数 1）；
- 短语不能拆散匹配（`the bucket was kicked` 不命中 `kicked the bucket`）；
- 原词与扩展词同概念多次命中得分饱和、有上界；
- 共享扩展在同一文档位置只产生一条证据；
- 预算截断明确标记未完成；
- CJK 单字切分与 CJK 短语同义（`机器学习 ↔ 人工智能`）。
