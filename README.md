内核态沙箱运行 eBPF 字节码时，若验证器在 64 位/32 位寄存器算术（`ALU64`/`ALU32`）之间不同步更新三态位掩码（`tnum`：`value`/`mask`）与有符号/无符号区间边界（`smin`/`smax`/`umin`/`umax`/`s32`/`u32`），攻击者可利用 32 位截断、有符号溢出或条件分支求精失配制造“验证期边界为 0、运行期偏移越界”的内核读写漏洞。为 Go 沙箱安全宿主机实现可导入的 eBPF 字节码抽象解释与内存越界核验包。输入为受限 eBPF 指令序列（含 `MOV`/`ADD`/`SUB`/`AND`/`OR`/`XOR`/`LSH`/`RSH`/`ARSH` 的 64/32 位指令、条件跳转 `JEQ`/`JNE`/`JGT`/`JGE`/`JLT`/`JLE`/`JSGT`/`JSGE`/`JSLT`/`JSLE` 含 32 位变体、`LDX`/`STX` 内存读写与 `EXIT`，仅支持前向 DAG 控制流与受限有界回边）。验证器为每个寄存器精确维护标量域 `(tnum, u64[umin,umax], s64[smin,smax], u32[u32min,u32max], s32[s32min,s32max])` 及指针域（`PTR_TO_CTX`/`PTR_TO_MAP_VALUE`/`PTR_TO_STACK` 含基址范围与偏移标量）：每条算术与位运算后必须执行完备的双向跨域归约（`tnum` 与四个区间互相收紧并处理 32 位写零扩展），条件跳转须按真/假分支分别精确求精寄存器边界并支持无符号/有符号等价推导，汇合点执行声音（sound）上界并操作；所有内存访问须证明最坏偏移完全落在合法对象界内（且拒绝在指针与未知标量相加后缺少 Spectre-v1 掩码截断的推测越界路径）。附 8 位缩微指令集全状态枚举声音性测试，证明抽象域永不低估真实运行时可达集合，并实测拦截经典 32/64 位边界失步与符号溢出 CVE 模式。
