# pathfill

图表渲染服务需要高质量的抗锯齿矢量填充。给Go渲染服务实现供图表绘制调用的路径光栅化包：把二次和三次贝塞尔曲线按误差容限展平，按有符号面积累积计算每个像素的覆盖率，支持非零和奇偶环绕规则，自交与重叠子路径正确，坐标可以超出画布；结果是8位alpha遮罩。与高倍超采样的参考结果比较误差，并测试共边路径不出现缝。

## 用法

```go
r := pathfill.NewRasterizer(width, height) // 画布像素尺寸
r.Flatness = 0.25                          // 贝塞尔展平容差（像素，可选）

p := &pathfill.Path{}
p.MoveTo(pathfill.Point{X: 10, Y: 10})
p.LineTo(pathfill.Point{X: 100, Y: 10})
p.QuadTo(control, end)                    // 二次贝塞尔
p.CubicTo(c1, c2, end)                    // 三次贝塞尔
p.Close()

r.AddPath(p)                              // 可累加多个路径/子路径
mask := r.Alpha(pathfill.FillNonZero)     // 或 pathfill.FillEvenOdd
// mask 长度为 width*height，行主序，每像素一个 8 位 alpha（0-255）
```

## 实现要点

- **贝塞尔展平**：`QuadTo`/`CubicTo` 用中点递归细分，以控制点到弦的垂直距离
  作为平直度估计，小于 `Flatness` 时停止，并以最大深度（18 层）兜底，避免
  退化曲线造成无限递归。
- **有符号面积累积**：每条边按它跨越的像素行切成梯形带。在一行内，边对绕数
  的贡献是一个阶跃（垂直边）或线性斜坡（斜边），在边左侧为 0、右侧为带符号
  带高。斜坡拐点编码为事件并排序，扫描时对线性函数逐像素解析积分，得到该像素
  的有符号覆盖率（绕数按面积加权）。
- **环绕规则**：非零规则取有符号覆盖率的绝对值；奇偶规则把绕数折进交替的
  0/1 带。自交路径和重叠子路径通过绕数自然叠加，反向子路径可挖空。
- **画布裁剪**：所有坐标允许超出画布，事件在 x=0 处折叠初始状态，y 方向按
  画布上下界裁剪；NaN/Inf 坐标被安全忽略。
- **输出**：覆盖率四舍五入为 8 位 alpha，全遮罩像素为 255。

## 测试

- `referenceMask` 是独立的 16x16（部分用例 12x12）规则网格超采样参考实现，
  逐采样点计算整数绕数，与分析式结果比较 MAE / 最大误差。
- 覆盖场景：整数与分数矩形、三次贝塞尔圆（含面积校验）、二次贝塞尔图形、
  五角星自交路径、重叠圆/方形、反向绕数挖空、越界坐标、展平容差收敛、
  退化路径、零尺寸画布、复用与 Reset。
- `TestSharedEdgeNoSeam` 验证共享斜边/垂直边的两个邻接形状，其覆盖率之和
  与合并光栅化结果一致，共边上没有缝隙。
