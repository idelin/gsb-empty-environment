# Latch Crabbing / Coupling（螃蟹脚并发加锁协议）— Go 实现

在 B+ 树上实现多线程遍历并发控制，仅使用 Go 标准库。

## 协议要点

- **读遍历（Get / Range）**：自上而下逐层 `RLock` 子节点后立即 `RUnlock` 父节点
  （耦合前进），任意时刻最多持有相邻两层的读锁，高层节点上读与读互不阻塞。
- **写遍历（Insert）**：下行途中若发现孩子已满，先在父锁保护下将其分裂
  （top-down 预分裂），使子节点变为“安全”（不会分裂），随后立即释放父节点锁。
  任意时刻最多持有相邻两层的写锁，写临界区最小。
- **无死锁**：所有锁严格按 `rootMu -> 根 -> 叶` 的固定全局顺序获取；
  根分裂时先释放节点锁、再按 `rootMu -> 节点锁` 顺序重新获取，避免 ABBA 死锁。

## 文件

- `btree.go` — B+ 树与螃蟹脚协议实现
- `btree_test.go` — 正确性、不变量、并发无死锁、读者不被写者阻塞等测试
- `cmd/demo/main.go` — 10 读线程 + 5 写线程的运行样例

## 运行

```sh
go test -race -v ./...
go run ./cmd/demo
```
