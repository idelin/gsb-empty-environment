# 诊断数据最小披露

安全接口错误需要解释失败字段，但不能顺带返回附近的秘密字节。写供Go解析宿主调用的诊断构造包，错误携带原始区间和敏感标签，展示上下文必须裁剪到授权区间，跨UTF-8码点不切半，隐藏部分用长度不可区分的固定标记。用重叠秘密区间、非法编码和多个错误合并验证不会经长度或上下文泄漏。

## `diag` 包

解析宿主在发现错误时用字节区间（而非字节切片）构造诊断，渲染时再传入原始输入：

```go
e := diag.NewError("token", "credential rejected",
    diag.Interval{Start: 15, End: 16},                 // 失败区间
    []diag.Secret{{Interval: diag.Interval{15, 22}, Label: "bearer"}}, // 敏感区间+标签
    []diag.Interval{{0, len(input)}})                 // 授权可见区间
fmt.Println(e.Render(input))
```

多错误合并使用 `diag.RenderAll(input, errs)`：任一错误声明的敏感区间会取并集，
在所有错误的上下文中一致裁剪；`diag.MultiError` 实现 `error` 且不含任何源文本。

### 最小披露保证

- **固定标记**：所有隐藏片段统一替换为常量 `diag.Marker`（`[REDACTED]`，10 字节），
  相邻秘密合并为单个标记，输出不反映秘密的数量或长度。
- **按可见原子计窗口**：上下文边距按“可见码点/字节”计数，被隐藏内容不消耗可见
  预算，因此隐藏长度无法借由周围上下文的多寡侧漏。
- **码点不切半**：窗口与授权边界以 `utf8.DecodeRune` 得到的原子单位判定，任何
  跨边界的完整码点整体保留或整体省略；非法/截断编码按单个原子字节处理，既不
  切成半字节也不被改写成 `U+FFFD`。
- **授权裁剪**：授权区间之外的字节静默省略且不产生标记，避免以标记形状暴露
  未授权区域的规模；码点只有整体落在授权区间内才会输出。
- **标签不外泄**：敏感标签只保留在结构化 API（`Error.Secrets`）上，从不进入
  渲染文本；`NewError` 会复制并规范化区间，调用方后续修改切片不影响诊断。
- **无效区间容错**：反向、负数或越界区间在构造时丢弃/在渲染时钳制，空输入不 panic。

### 验证

`go test ./... -race` 覆盖重叠/相邻秘密、非法 UTF-8、授权间隙跨码点、窗口边界
切码点、多错误秘密并集、长度不可区分对比，以及遍历全部失败位置与秘密区间的
属性化扫描（渲染结果只能包含非秘密字节且始终是合法 UTF-8）。
