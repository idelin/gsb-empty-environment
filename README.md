# linesim — 阻塞式产线仿真器

Go 实现的离散时间产线仿真：容量有限的站点 + 确定性加工时间，零中间缓冲。
下游满时，上游完工件占住本机（blocking-after-service）。

## 模型

- **站点**：`capacity` 台机器，加工时间 `procTime`（≥1 tick），无站内缓冲。
- **工件**：沿固定路由（站点下标序列）流动，可为环路。
- **机器状态**：`.` 空闲 / `J1:2` 加工中（剩 2 tick）/ `J1!` 阻塞（完工但下游满）/ `J1>` 已装载待开工。
- **死锁判定**：系统中仍有工件但已无任何机器在加工 —— 状态将永不改变。

## 每 tick 固定公开顺序

1. **离站**：按**下游→上游**逆序扫描站点；完工/阻塞的机器尝试把工件推向下游
   空闲机（末站则离系统）。逆序使同一 tick 内空位沿链回传，形成连锁解堵。
2. **入站**：外部到达工件按 FIFO 进入首站空闲机，进不去的排队等待。
3. **开工**：已装载的机器开始加工，占用 `procTime` 个 tick。

## 运行

```sh
go run .      # 打印两个场景的逐时占用时间线
go test ./... # 核对连锁解堵、死锁、离站先于入站
```

- 场景 1（直线 S1→S2→S3，S2 为瓶颈）：t=02 起 J2 堵在 S1；t=05 S2 完工，
  同一 tick 内 J1→S3、J2→S2、J3→S1 连锁解堵。
- 场景 2（环路 S1⇄S2，各持一件互等）：t=01 双方同时完工、互占下游，
  判定 DEADLOCK。
