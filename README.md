# gateway-ratelimit

网关模拟用的精确令牌桶限流库（Go）。

## 语义

- **整数纳秒时间**：所有事件携带 `int64` 纳秒时间戳。
- **有理令牌速率**：速率为 `Num/Den` 令牌/纳秒，桶内余额用 `math/big.Rat`
  精确表示，全程无浮点误差。
- **惰性补充**：仅在事件到达时按经过的纳秒数精确结算补充量。
- **容量截断**：补充后超出容量的部分直接丢弃，被截掉的余量不会保留，
  后续事件不会"找回"这些令牌。
- **配置切换**：`SetConfig` 先按旧配置结算到切换时刻，再从该时刻起
  应用新速率与容量；余额超出新容量时同样截断。
- **时间倒退**：`Allow` / `SetConfig` 收到早于已结算时刻的时间戳时返回
  `ErrTimeBackward`，状态与配置均不变。

## 测试

`limiter/limiter_test.go` 内含一个独立的逐事件有理参考模型（用
`big.Int` 分子/分母自行结算，与被测实现走不同的算术路径），覆盖：

- 长空闲后余额恰好等于容量、截断余量不回流；
- 边界消耗（余额恰好等于消耗量时放行，分数余额不放行）；
- 速率/容量切换的结算时刻与截断行为；
- 时间倒退拒绝且状态不变；
- 2000 个伪随机事件（长跳、边界消耗、配置切换）与参考模型逐事件对拍。

运行：

```sh
go test ./limiter/ -v
```
