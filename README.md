# Dotted Version Vectors (DVV) 精确因果跟踪器

面向无主复制（Leaderless）场景的去重优化因果跟踪。每次写入表示为一个
**点状事件** `(NodeID, Counter)` 加上一份**前置因果上下文**（版本向量），
从而：

- **精准区分**相同值的重复写入（幂等吸收，单分支）与不同值的并发覆盖
  （保留真实兄弟分支）；
- **消除幽灵分支**：被覆盖的旧值随点状标识被精确淘汰，不像传统版本向量
  那样残留无法互相判定的陈旧分支；
- **乱序/重复广播收敛**：`Join` 满足交换律、结合律、幂等律，副本以任意
  顺序接收事件都收敛到同一极小集合。

## 核心 API（`dvv.go`，仅标准库）

| API | 说明 |
| --- | --- |
| `New()` | 空 DVVSet |
| `s.Update(node, value)` | 协调写：观察全集后写，结果恒为单分支 |
| `s.Event(ctx, node, value)` | Leaderless 写：基于客户端上下文发放下一个点 |
| `s.Sync(o)` / `Join(sets...)` | 合并副本，丢弃被支配分支，吸收重复事件 |
| `s.Values()` / `s.Context()` | 当前可见值（>1 即真实冲突）/ 汇合因果上下文 |
| `s.GraphSize()` | 版本图体积：活分支数 + 上下文 (node,counter) 对数 |

`Event` 契约：调用方（写节点）须在 `ctx` 中携带自己的最新计数器，
保证点状标识全局唯一。

## 运行

```sh
go test ./... -v   # 测试
go run ./cmd/example   # 样例：高频写 + 乱序广播收敛演示
```
