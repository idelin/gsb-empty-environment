# crdt-tree-move

树形层次文件系统的**无环 CRDT 重命名与移动协调器**（TypeScript，零依赖）。

多节点分布式虚拟目录树中，并发的移动操作可能产生孤立环路
（如节点 1 把 `/dirA` 移入 `/dirB`，节点 2 同时把 `/dirB` 移入 `/dirA`）。
本实现通过**日志时间戳（Lamport clock）+ 父节点因果追溯 + 确定性全序仲裁**
自动检测并断环，保证所有副本收敛到同一棵无环树，且不丢失任何目录。

## 算法

1. 每个副本维护完整的移动操作日志，操作携带 `(Lamport 时间戳, 副本 id)`。
2. 物化树状态时，按**确定性全序**（时间戳升序，副本 id 打破平局）重放日志。
3. 应用每条操作前，沿目标父节点链做**因果祖先追溯**：若被移动节点是目标
   目录的祖先，应用该操作将闭合拓扑依赖环，该操作被**撤销（跳过）**。
   由于全序中较早的操作已就位，被撤销的恒为冲突对中**后发生**的操作。
4. 同名兄弟节点冲突按确定性规则加 `#<nodeId>` 后缀，不覆盖、不丢数据。

## 运行

需要 Node.js ≥ 22.6（利用原生 TypeScript 类型剥离，无需编译/依赖）。

```bash
npm test     # node --test（Node.js 内置测试运行器）
npm run demo # 验收场景演示
```

## 验收场景

节点 1 移动 `/dirA` 到 `/dirB` 下，节点 2 并发移动 `/dirB` 到 `/dirA` 下
（两者 Lamport 时间戳均为 1）。合并后：

- 全序 `(t=1, node1) < (t=1, node2)`，node2 的操作被判定为后发生；
- 因果追溯发现 `dirB` 是 `dirA` 的祖先，node2 的操作会闭环 → 撤销；
- 两个副本收敛为 `/dirB/dirA`，`dirA`、`dirB` 及全部文件均可从根到达。

## 结构

- `src/types.ts` — 操作/节点类型与确定性全序比较器
- `src/crdt-tree.ts` — 核心：日志重放、因果追溯断环、冲突消解
- `src/replica.ts` — 分布式副本：Lamport 时钟、本地操作、反熵同步
- `test/crdt-tree.test.ts` — node:test 测试
- `demo/sample.ts` — 验收场景运行样例
