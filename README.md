# gsq — 灰度量化求解器

将灰度直方图压缩为 K 个整数代表值（调色板），目标为字典序最优：

1. **先最小化最大绝对误差** E（对所有像素）；
2. **再在该约束下最小化加权平方误差**（按像素数加权）。

空灰度级（计数为 0）不参与分组，也无需被任何组覆盖。

## 算法（精确，非启发式）

- **阶段一**：对 E 二分。判定可行性时，用直径 ≤ 2E 的区间贪心覆盖所有非空灰度级
  （直线上定点覆盖的贪心最优），所需组数 ≤ K 即可行。
- **阶段二**：精确动态规划。`dp[j][g]` 为前 j 个非空灰度级分成 g 组的最小加权 SSE，
  仅允许直径 ≤ 2E 的组。每组代表值取加权均值四舍五入后夹取到 `[hi-E, lo+E]`，
  保证整数代表值且满足最大误差约束。
- 复杂度 O(256²·K)，256 级灰度下瞬时完成。
- `solver_test.go` 用穷举所有分组的暴力法在小规模随机直方图上逐案核验 DP 结果。

## 用法

```sh
go build -o gsq .
./gsq -k 4 < histogram.txt
```

输入：每行 `灰度值 像素数`（`#` 开头为注释）。输出：最小化的最大误差、
该约束下的最小加权 SSE、各组灰度边界与调色板代表值。
