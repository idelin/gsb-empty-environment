# sudoers通配符与参数约束

sudoers 规则允许用户以 root 运行带通配符的程序，* 可以匹配斜杠和空格，攻击者借此塞入额外路径或选项。为Go提权网关写可导入的规则匹配包，供授权决策调用：规则形如 用户 主机=(目标用户) 程序 参数模式；程序须为绝对路径并逐字相等，不做符号链接解析；参数模式为空表示允许任意参数，写成 "" 表示不允许任何参数；参数列表用单个空格连成一个字符串后做 fnmatch 匹配，本题规定 * 可匹配任意字符含 / 与空格；在此之上，参数含 .. 路径段而模式含 * 时拒绝，参数中任一项以 - 开头而模式没有逐字出现该选项时拒绝；规则带 !（否定）时与同一程序的其他规则取最后一条匹配者；Cmnd_Alias 展开后重复的程序各自保留参数模式。用 .. 穿越、塞入额外选项、空串与引号、否定规则和最后匹配生效验证。
