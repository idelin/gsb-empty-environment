数据库回放器在排查一次提交异常：它拿到事务的读写程序、桶状偏序和某个客户端实际见过的返回值，但不想永久保留所有读观测。写一个宿主可导入的 Go 针对性追踪编译器。每事务按程序顺序执行 begin、点读、put/delete、commit；begin 获取当时已提交快照，read 优先读本事务覆盖，commit 使用 first-committer-wins，无论是否同值写，快照后有其他成功事务碰过写集即失败。不同桶严格排序，同桶保持给定偏序。每条可选读观测给出记录值（缺失是单独值）和保留费用，commit 的成败并非预先固定。输入另给有序目标事务清单及其报告的成功位串。先验证所有读观测共同成立时至少有一条能得到报告位串的真实历史。随后选总费用最小的读观测子集，使所有满足这部分读值的历史都得到该位串；同价先取记录条数最少再取输入下标序列最小者。若保留全部还不能确定，返回两条都满足全部读值而目标不同的完整历史。成功时为每条选中观测返回删去该条后仍满足其余观测但目标不同的一条反例；费用为正。交付独立内核回放这些历史及宿主按所选编号过滤观测的代码。最多十二个候选读、十个事务、六十个事件，每桶至多十二事件；允许探索不同的数据库可达状态，禁止逐条枚举所有桶的全排列。小例穷举并对照所有观测子集，覆盖两个并列最廉跟踪方案、读值相同但来自不同写者、有成功历史却无法唯一诊断、一条无关只读事务造成阶乘种历史而不改变答案。
