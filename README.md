# rectunion

计算闭轴对齐整数矩形并集的**面积**与**周长**的 Go 库。

- 输入为闭矩形 `[X1,X2] x [Y1,Y2]`，角点顺序任意（内部归一化）。
- 零面积矩形（退化的线段、点）不贡献并集。
- 重叠边只计外露部分；相接矩形的内部公共边不计入周长。
- 角点接触不产生共享边，两个矩形的周长各自完整计入。
- 算法为扫描线（非栅格化）：沿 x 扫描，事件处用 y 覆盖的对称差
  累计竖直边，每个 slab 内按 y 连通分量数累计水平边。
- 结果返回 `*big.Int`，坐标范围不受 64 位乘积溢出限制。

## 用法

```go
import "rectunion"

area, perimeter := rectunion.Union([]rectunion.Rect{
    {X1: 0, Y1: 0, X2: 2, Y2: 2},
    {X1: 1, Y1: 0, X2: 3, Y2: 1},
})
// area = 5, perimeter = 10
```
