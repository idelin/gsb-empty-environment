# matsim — 物料溯源模拟器

Go 实现的物料实体模拟器：每个物料批次（lot）携带**来源份额向量**，
全程使用 `math/big.Rat` 精确有理数运算，无浮点误差。

## 模型

- **Lot**：`{ID, Qty int64, Vec}`。`Vec` 为 `source -> 份额` 的有理数映射，
  不变式：份额之和恒等于 1（每个事件后均校验）。
- **事件**（均带唯一 ID）：
  - `receive`：从纯来源引入整数数量，向量 = 单位向量。
  - `split`：按**整数数量**拆分，子批次继承父向量；拆分余量作为**显式损耗**记入回执。
  - `merge`：多批次合并，向量按数量加权平均（精确有理数），严格守恒（损耗恒为 0）。
  - `loss`：显式损耗，按向量**比例有理扣减**（各来源份额同比扣减，份额不变、总量减少）。

## 守恒律

每个事件满足 `Σ输入 = Σ输出 + 损耗`。拆分超出数量、损耗超出数量、
合并不平衡都会被拒绝且不改变状态。所有损耗在 `Receipt` 中显式记录
（数量 + 损耗的来源构成向量），支持来源级守恒审计：
`Σ(在库批次 数量×向量) + Σ(损耗 数量×向量) = Σ接收来源量`。

## 追溯

`Trace(lotID)` 输出任意终品的来源线性组合，例如：

```
lot product-1 (qty 60) = 2/5·mine-A + 3/5·mine-B   [amounts: mine-A=24, mine-B=36]
```

同时给出归一化份额与绝对量（份额×数量），二者均精确求和校验。

## 重放与幂等

- **幂等**：事件 ID 已应用过时，`Apply` 直接返回原回执，状态不变。
- **重放**：`Replay()` 从事件日志重建全新模拟器并逐批次比对
  （数量 + 有理数向量），证明日志完全决定状态。

## 运行

```sh
go test ./material/   # 单元测试：守恒/追溯/重放/幂等/向量不变式
go run ./cmd/simdemo  # 端到端演示
```

## 结构

- `material/vector.go` — 来源向量（有理数运算、加权合并）
- `material/lot.go` — 物料批次
- `material/event.go` — 事件与审计回执
- `material/sim.go` — 模拟器（应用、守恒校验、重放）
- `material/trace.go` — 终品来源线性组合追溯
- `cmd/simdemo/main.go` — 演示程序
