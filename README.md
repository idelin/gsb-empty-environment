# 指令地址污损跟踪

## shadow 包

`shadow/` 提供可嵌入 Go 仿真宿主的逐位影子执行能力：

- 支持 8/16/32 位寄存器值、间接跳转目标和内部 1 位进位/借位。
- 每个结果位保存 `SourceSet`，来源粒度为输入字节号和字节内位号。
- 支持 AND、OR、XOR、NOT、ADD、ADC、SUB、SBB、CMP、逻辑/算术移位。
- 8/16 位寄存器写入只覆盖低 8/16 位，保留 32 位寄存器的高位标签。
- 内存按字节存储；动态读写地址的来源会并入被访问数据。
- 加法使用逐位进位链，ADC/SBB 传播内部进位/借位。
- `Xor(x, x)` 通过血缘识别生成无来源零值，模拟清零异或。
- `IndirectJump` 返回目标地址和逐位来源；包内只执行机器无关 IR，不执行真实机器码。

宿主负责解码目标指令，并将其转换为 `shadow.Instruction`，或直接调用 `Machine` 的值操作。

## 验证

测试对 8 位输入的 256 个取值逐位翻转，并对 16 位进位、移位计数、动态内存地址和间接跳转做小域穷举。任何翻转后实际变化的结果位，都必须能在影子来源集合中找到对应输入位。

```sh
go test ./...
go vet ./...
go test -race ./...
```
