RISC-V 多域安全 SoC 在部署 WorldGuard（多世界域 `WID` 标记 + 总线 Checker `wgChecker` 物理区间策略）与 Supervisor 级物理内存保护（sPMP）时，若总线主设备（DMA/CPU Core）的 `WID` 映射未锁定、高优先级 `wgChecker` 槽位（采用与 PMP 类似的优先命中或槽位覆盖规则）遗漏某个安全世界域的物理地址间隙导致非可信世界 `WID` 可读写可信世界 `WID` 的机密内存，或 sPMP 在开启共享区/只读区时允许 S 态对共享用户态代码页同时具备写执行权限，低权限域可直接越界破坏可信世界或内核代码。为 C++17 固件安全审计宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 RISC-V WorldGuard 与 sPMP 多域隔离符号验证库（严禁逐页枚举）。输入为 `wgMarker` 主设备 WID 绑定表（含锁定状态）、各 `wgChecker` 槽位配置（TOR/NA4/NAPOT 地址模式、每个 `WID` 的 R/W 权限位图与锁定标志）、sPMP 表项集合、各安全世界合法物理区间以及机密隔离矩阵（允许/禁止跨 WID 访问关系）。验证库精确执行：（1）解码全部 TOR/NA4/NAPOT 区间并按 `wgChecker` 优先级合并，跨全部物理地址空间精确检出任意非授权 `WID` 具备读/写权限访问其他世界机密物理区的最小违例 `(WID, phys_addr)` 与命中槽位见证；（2）检出未锁定（`lock=0`）的可被低权限修改的 `wgMarker`/`wgChecker` 关键槽位；（3）联合校验 sPMP 表项，硬拦截 S 态对非可信 U 态可写页具备执行权限（防 SMEP 绕过）或 S 态自身同时可写可执行映射。附 16 位缩微地址空间全枚举交叉验证、NAPOT 边界间隙逃逸、未锁定 WID 槽位与 sPMP 写执行冲突测试。
