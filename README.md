存储客户端用两条网络连接并行访问同一个加密共享。给 Go 会话层写可导入的多通道准入包。每条连接有独立的协商消息记录，主通道经宿主验签后确立共享会话；新通道只有在自己的记录摘要、双方随机数、服务器身份、共享标识和会话密钥代次一起通过绑定签名时才可接入。请求使用每通道独立递增的序号，可乱序到达；窗口内只接受一次，只有认证通过才移动窗口。更换会话密钥时，新旧代次允许在宿主指定的交叠期并存，但不能把新通道序号拿到旧代次重用；收到已认证的退休边界后，超过该通道末序号的旧代请求永久拒绝。两个通道各有不同的退休边界，不能按全局最大号裁决。连接关闭再重建不得继承旧的窗口或绑定签名。宿主提供原子授权回调，认证过程中若通道或密钥被撤销，数据不能交给共享。用真实 HMAC 和可控时序验证签名跨通道搬移、同号不同代、乱序退休、窗口边界及两个协程同时完成同一报文认证，核对实际交付序列。
