备份目录从多个副本收到了分片检查点，只公开其中部分检查点的落盘位。恢复控制台要按编号翻阅所有不同的可见镜像，而不是把不同的后台切点当作不同镜像。提供可导入的 Go 目录索引及恢复控制台适配器。输入按备份目录给定的顺序列出至多 400 个检查点，每个是一位，1 表示纳入恢复切点。每条复制依赖 u→v 表示选 v 必须选 u，依赖无环但目录次序不一定拓扑有序。另有条带持久化回执：列出至多四个位和允许的局部位图集合，表示该条带实际允许哪些同时落盘；所有回执必须同时满足。部分位标记公开，其余只用于校验。按目录顺序取公开位形成等长串，只要存在私有位补全就计一次。对任意字典序闭区间返回不同可见镜像的精确数量，并支持取区间内从零开始第 k 个及其完整可重放切点；同一镜像选择按完整目录位串字典序最小的补全。给定次序的每条分界线上，左侧仍参与跨界依赖或跨界回执的不同位总数至多五个。不得按 2 的总位数次方枚举全切点或先列出可见镜像；数值不得饱和。用独立穷举核对小目录的计数、顺序和补全，覆盖空公开集有多个私有解与完全无解的区别、两个前缀拥有重叠但不同的可延伸私有状态，以及超过 2^128 个镜像仍能定位末项的回放。
