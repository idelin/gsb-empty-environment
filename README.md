远程证明验证服务校验终端上报的 TPM 2.0 PCR Quote（`TPMS_ATTEST`）与 Linux IMA（Integrity Measurement Architecture）二进制度量日志时，若验证器忽略 `ima-ng`/`ima-sig` 模板摘要重算、未拦截日志中的 `ToMToU`（Time-of-Measurement Time-of-Use）全零违例扩展，或未绑定证明请求方随机 `qualifyingData`（nonce）与可信 AK（Attestation Key）证书链，被攻陷节点可重放历史合法 Quote 或篡改事件日志隐藏恶意二进制执行。为 Go 远程证明宿主实现可导入的原始字节级 TPM 2.0 `TPMS_ATTEST` 解码与 IMA 日志重放安全验证包，严禁依赖外部 TPM SDK（仅用 Go 标准库密码原语）。组件从大端原始二进制完整解码 `TPMS_ATTEST`（校验魔数 `0xFF544347`、`TPM_ST_ATTEST_QUOTE` 类型、绑定 `extraData == expectedNonce`、`TPMS_QUOTE_INFO` 的 `pcrSelect` 位图与 `pcrDigest`）及真实 ECDSA-P256 AK 签名；完整解析 IMA 二进制事件流（每条含 4 字节小端 PCR 索引、20 字节 SHA-1 模板哈希、模板名与变长模板数据，支持 `ima-ng` 与 `ima-sig`），按真实模板字段重新计算模板摘要并拒绝日志中声称哈希与重算值不符的伪造记录，严格检测并标记全零哈希（ToMToU/open-writers 违例，按规则用 `0xFF..FF` 参与 PCR 扩展而策略上直接判定平台不安全）。将全量日志按 `PCR_new = SHA256(PCR_old || entryDigest)` 从全零初值重放至最终各 PCR 寄存器，再拼接所选 PCR 组计算摘要并与已验签 Quote 中的 `pcrDigest` 精确比对，同时逐条对照白名单基线与 `ima-sig` 文件签名校验执行载荷合法性。附真实密钥构造的合法证明与篡改单条日志、重放旧 nonce、伪造 ToMToU 掩盖与 PCR 位图错位攻击测试集。
