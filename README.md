无锁索引把退休节点交给回收器时，某个读者可能已看见旧指针，却尚未发布保护。给 C++17 索引宿主实现可导入的回收许可组件，输入为合成的线程事件，不接触实际地址。对象标识由地址和不可回绕代次组成。读者先读取根标识，发布到自己的保护槽，再重读同一根；两次根标识相同且发布后槽未被覆盖，才允许解引用。退休批次携带从根移除对象的发布序号；扫描可分片，但只有每个存活线程的槽都在移除后被观察过、期间注册过的新线程也被覆盖、且无人保护该代对象，才可发出一次性回收许可。领取许可前必须原子核对线程注册及保护槽的版本；若扫描与核对间有变化，只使受影响片段失效。线程退出须先清空自己的槽，新线程复用编号不继承旧扫描证据。用按全部槽重新扫描的参考实现检查小规模交错，比较每次准许或延迟回收的对象集合，覆盖根的同址换代、扫描间重新注册和两名回收者竞争同一许可。
