# Bazel远程缓存写入准入

团队的构建缓存同时服务 CI 与外部贡献者的 PR 构建，攻击者在 PR 构建里写入被投毒的 ActionResult，让主干构建命中并产出带后门的二进制。为Go缓存服务实现可嵌入 gRPC 前置的写入准入包：只有标记为可信的写入者能更新动作缓存，PR 来源只读；CAS 上传的 blob 必须与资源名里的 sha256 和大小一致，校验失败不得留下半成品；ActionResult 引用的每个输出摘要都要已在 CAS 中且大小相符，命中前须再次核对引用仍存在；同一动作摘要被不同输出覆盖时拒绝并记录，写入按动作摘要串行化，并发只允许一个成功；ByteStream 资源名里的 hash 必须为 64 位小写十六进制。用伪造摘要、缺失 blob、半成品上传、命中时 blob 被删、并发同摘要写和 PR 写入验证。
