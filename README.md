发布网关有几千份签名构建声明，不能再枚举声明子集来证明缓存制品有独立可信来源。给 Go 网关写可导入的证书生成与核验包。宿主给出两个必须分别容忍的信任域失效情形，声明在每种情形下可用或不可用；每份声明绑定动作、输入输出摘要及严格递增的构建层级。用布尔变量表示某声明是否出现在某一情形的证明中；每种情形都必须为根制品选到受信生成者，选择声明意味着每个非受信输入都由某条更低层声明支持。两种情形共同使用同一声明只支付一次披露成本。约束格式为一个触发变量及一组可替代的支持变量，支持同一制品不得误用不同环境或动作摘要。输入还给出约束原始图的树分解，袋中放声明 ID，每条支持约束的全部声明应被某个袋覆盖，每个声明出现的袋须连通，宽度不超过4；不可信的分解要先核验。最多3000份声明，不能枚举全局子集。返回最小总披露成本及具体两套来源证明，等价最优解按排序后的声明编号序列决胜。独立校验函数从签名根、约束、分解和逐袋的最优值证明核对全局最优性，不能只确认给的解可行。用小图穷举对照，在大图验证多袋共享声明只计一次、两个兄弟子树各自便宜却全局更贵、伪造分解遗漏依赖，以及信任域重叠时两份证明不能互相借用签名。
