# cachemodel

缓存页按字节区间标脏的 Go 实现，以及用于核对它的逐字节版本参考模型。

## 设计

- `Page` 的脏集合是**带版本的区间列表**：每次 `Write` 递增页版本号，并把
  写入区间以新版本插入脏集合（覆盖旧区间、同版本相邻合并）。
- `BeginWriteback` 捕获当前**页版本号 + 脏集合快照 + 页数据快照**，同一时刻
  只允许一个写回在飞。
- `CompleteWriteback(wb, written)` 只清除 `written`（实际落盘的区间，短写时
  是捕获脏集合的子集）中**版本 ≤ 捕获版本**的字节；写回期间被重新写脏的
  字节版本更高，不会被旧写回的完成清除。
- `Evict` 阻塞等待脏集合为空且无写回在飞后才返回页内容。

## 核对方法

`Model` 是逐字节版本参考模型（每字节一个脏版本号）。随机并发测试把缓存
的每个线性化事件（写 / 写回开始 / 短写落盘 / 写回完成 / 淘汰）记录成日志，
再按序重放到 `Model` 上，最终比对：

- 页数据与逐字节脏状态（区间实现 vs 逐字节模型）；
- 磁盘镜像；
- 淘汰返回点模型必须全干净（否则 panic）。

覆盖场景：并发写、短写（部分写成功）、写回期间重脏、页淘汰等待。

## 运行

```sh
go test -race -count=1 ./...
```
