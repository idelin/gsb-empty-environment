# JWS头jku与x5u密钥来源登记

JWS 头里的 jwk、jku 与 x5u 允许令牌自带验证密钥或指向密钥位置，攻击者借此让服务用自己的密钥验证伪造令牌。为TypeScript JWT 网关写可导入的密钥来源判定包，供验签前调用：头里的 jwk 与 x5c 不得作为验证密钥，若 jwk 的公钥与登记表里同 kid 的公钥不同则按伪造令牌拒绝，相同则仍只用登记表里的密钥；jku 与 x5u 仅当 URL 为 https、主机与路径前缀精确等于该 kid 在调用方登记表里的来源（主机不分大小写，路径逐字比较，不得含 userinfo、查询串、片段或 .. 段）时才可抓取；抓取不得跟随重定向，响应超过 64 KiB 拒绝；kid 不在登记表内时不触发任何抓取；alg 必须在该来源登记的算法集合内。用自带 jwk、jwk 与登记密钥不同、jku 指向别的路径、userinfo 绕过和重定向验证。
