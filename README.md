安全运行时给指针附认证标签，认证上下文复用可能让数据指针被当函数指针，或经跨线程别名逃逸验证门禁。写供Go运行时调用的指针封装包：标签由注入HMAC接口覆盖指针地址、对象代次、只读/可写/可执行种类和调用上下文，派生子切片或偏移指针必须重新计算认证且仅允许保留或收窄种类；对象释放与地址重用立即废弃旧代次。并发访问时在解引用前原子核验对象代次与标签匹配，禁止对已退役代次或未认证的跨上下文借用指针降级放行。用真实HMAC测试跨对象伪造、跨上下文交换、并发释放竞态及对象退役后的使用门禁。

## `ptrauth` 包

`ptrauth` 是供 Go 运行时调用的指针认证封装，HMAC 由 `Authenticator`
接口注入（生产/测试均使用真实 HMAC-SHA256）。每个 `TaggedPtr` 的标签绑定
地址、对象代次、访问种类（只读/可写/可执行，W^X 互斥）、调用上下文和授权跨度。

- `Registry.Tag` 铸造首代标签；`Derive`/`Subslice` 重新计算 HMAC，且只允许
  种类保留或收窄，数据指针无法被重标为函数指针。
- `Recontext` 是唯一的跨上下文借用通道：先验源上下文，再铸造绑定新上下文的
  新标签；手改上下文字段只会得到 `ErrTagForged`/`ErrContextMismatch`。
- `Free` 原子退役代次并保留墓碑；同地址重新注册后旧标签判定为
  `ErrGenerationStale`，释放后使用判定为 `ErrGenerationRetired`。
- `Read`/`Write`/`Call` 在解引用前完成 HMAC、上下文、种类、代次四道门，
  对象锁保证解引用与释放不会撕裂；`Call` 要求 `KindExecute`，数据指针不可调用。

### 运行测试

```sh
go test -race -count=1 ./...
```

测试使用真实 HMAC 覆盖：跨对象伪造（移植 MAC、改地址/种类/跨度、异密钥、
字节篡改）、跨上下文交换与受控重认证、并发释放/重用竞态（race 检测器）、
退役代次门禁、W^X 与种类收窄、可执行对象调用门禁。
