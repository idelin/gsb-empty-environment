# Sub-cluster Gossip — 海量规模动态分片广播降噪器 (TypeScript)

将扁平全网划分为虚拟局部集群（Cluster Cell），Cell 内高频感知、跨 Cell 低频汇聚，
在万级节点规模下把 Gossip 网络噪音降低 95% 以上，同时保持 Cell 内崩溃的亚 300ms 感知。

零依赖：Node.js >= 22.6（原生 TypeScript 类型擦除）即可直接运行，测试使用 Node 内置 `node:test`。

## 分层拓扑设计

```
┌─ Cell 0 (25 nodes) ─┐   ┌─ Cell 1 ─┐        ┌─ Cell 39 ─┐
│  ring heartbeat 2s  │   │          │        │           │
│  度2环形心跳(稳态)   │   │          │        │           │
│  崩溃事件即时推送    │   │          │        │           │
└────────┬────────────┘   └────┬─────┘        └─────┬─────┘
         │ Leader (最小存活id)  │                    │
         └────── 每2s 向3个对等Cell Leader 汇聚广播 ──┘
```

- **Cell 内（高频感知、低频稳态）**：每个节点向环内 2 个后继每 2s 发一次心跳（稳态仅 ~2 包/s）。
  检测延迟与心跳间隔**解耦**：节点崩溃时传输层链路复位（TCP RST 语义）即时通知环邻居，
  首个发现者确认 DEAD 后**事件驱动**地向全 Cell 推送，局部感知延迟 ≈ 两跳网络延迟（<10ms）。
  另有 6s 心跳超时作为网络分区场景的兜底检测器。
- **跨 Cell（低频汇聚广播）**：Cell Leader（视图内最小存活 id，崩溃后自动重选）每 2s 与
  3 个随机对等 Cell 的 Leader 交换**整 Cell 聚合摘要**——1 个包承载 25 个节点的状态；
  全局视图经普通心跳在 Cell 内免费扩散，普通节点零跨 Cell 流量。
- **扁平基线**：经典全网 Gossip（fanout 3、周期 100ms，逼近亚秒级全局检测所需强度），
  单节点 60 包/s，正是本组件要消除的噪音。

## 运行

```bash
npm run sample   # 运行 1000 节点仿真样例
npm test         # node:test 验收测试
```

## 代码结构

- `src/simulator.ts` — 虚拟时钟离散事件模拟器（二叉堆）
- `src/network.ts` — 模拟网络：逐节点出入包计数 + 随机投递延迟
- `src/subClusterNode.ts` — 分片协议：环形心跳、事件推送、Leader 汇聚广播
- `src/flatGossipNode.ts` — 扁平全网 Gossip 基线
- `src/experiment.ts` — 1000 节点对照实验与指标采集
- `test/subcluster.test.ts` — 验收边界测试（95% 降噪 / 300ms 局部感知）
- `examples/run-simulation.ts` — 运行样例
