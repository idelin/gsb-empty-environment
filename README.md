只读对象服务允许用户索取压缩归档的少量切片。给 Go 读取端实现可导入的验收包：清单由原始块、可重复引用的字典片、反向切片和按次数重复的子树组成，清单签名绑定总长度、根、压缩策略摘要和版本。每个租户的读取许可只覆盖若干根坐标区间，物理字典块相同不能共享授权，且禁止经由反向切片或重复子树边界把未授权邻接字节拖入同一解码缓存页后越界读取。解码工作量按实际解码过的物理块计，返回数据量按根坐标去重计，两类额度分开；缓存命中可省解码工作量，不增加可读区间。对一批相交读取，在有限容量缓存和给定可选检查点下求最低解码成本的执行计划，允许重排物理读取但输出按请求次序。若请求越权须在任何解码回调前整批拒绝；若无满足成本上限的计划，须与证据不足分开。支持总展开长度 2^48，不逐字节展开重复子图，给紧凑计划检查器，重验每段来源、授权、缓存驱逐和两套资源账。用小图全搜索对照共享块在不同根位置、跨反向切片、只覆盖一半的许可、旧版缓存和回调取消后重试。
