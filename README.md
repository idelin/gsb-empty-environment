同一依赖包的补丁只改了某个对象文件，发布服务要决定哪些签名产物必须撤销。给 Go 构建宿主写可导入的影响分析包，输入是两版带签名来源身份的调用摘要，以及至多 20 个关联的构建选项。摘要含普通调用、返回、可选符号和受条件控制的回调注册/注销，注册句柄与对象来源绑定；回调执行只能返回对应调用点。对每个入口求出存在可行调用并会触及已撤销对象的配置集合，以及证据缺失导致无法判定的集合。失签或缺摘要沿实际可达路径传播未知，不能把同名安全对象的摘要借来，也不能因不可达缺证污染所有入口。输入的合法配置约束用固定序的 BDD 表示，结果仍用相同变量序的规范 BDD。支持替换一条摘要、撤销对象或改变同名符号绑定后增量更新，包括递归环内最后一条支撑路径消失；原签名证书在原快照仍能核验。独立验收器核对结果 BDD、来源身份和调用返回配对。用短调用深度的小程序与全配置枚举核对，另测深度不限的互递归、重复注册的不同句柄、两个不可同时成立的边、根摘要缺失和仅弱符号绑定改变。
