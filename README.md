分布式追踪网关在边缘解析 W3C `traceparent`/`tracestate` 并在后端执行尾部采样（Tail Sampling）时，容易在两处出线上事故：一是未按 W3C Level 1 规范拒绝全零 `trace-id`/`parent-id`、大写十六进制或版本 `ff`，或者错误拒绝了携带尾部扩展字段的未来版本号（`version > 00` 按规范必须前向兼容解析前四段！）；二是尾部采样器在微服务的子跨度（Span）乱序到达、根跨度晚到或节点时钟轻度漂移时，提前按不完整跨度树做出了错误丢弃决策。为可观测采集网关交付可导入的 TypeScript W3C TraceContext 与流式尾部采样引擎。组件实现：1）严格 W3C `traceparent` 编解码（拒绝版本 `ff`、全零 ID、非小写十六进制与长度错；版本 `00` 严格禁止尾部多余字符，版本 `01..fe` 按规范允许并忽略 `-` 后的未知扩展段）；2）严格 `tracestate` 解析与更新（合法单租户 `key` 与多租户 `tenant@vendor` 语法校验、值字符集与尾空格限制、上限 32 条目、更新已有 key 时移至头部、超限按规范优先截断超 128 字节条目或从最右侧截断）；3）流式尾部采样器：按 `traceId` 汇聚乱序到达的 Span，支持等待窗口 `decisionWaitMs` 过期或缓存达上限提前淘汰时做出最终采样判决，支持基于单策略（延迟阈值、Error 状态、属性正则匹配、基于 `traceId` 确定性 FNV/Murmur 哈希的比例采样、滑动窗口每秒限流）以及 `AND` 复合与 `Invert` 取反组合策略的精确优先级仲裁（`InvertNotSampled` 优先否决 -> 任一 `Sampled` 命中 -> 否则 `NotSampled`！），并实现跨度树父子拼接、孤儿跨度挂接与子早于父的时钟偏移校正统计。验收覆盖 W3C 官方全部正反例（含 `version=01` 扩展段、`ff` 拒收、多租户 `tracestate` 32 条截断）、乱序晚到根跨度等待窗口判定、`Invert` 否决压过普通命中以及时钟偏移子早于父的完整树拼装。
