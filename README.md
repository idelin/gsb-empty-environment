数据中心 VXLAN/EVPN 控制面（RFC 7432）在虚拟机跨叶交换机热迁移与双活多归属（All-Active Multihoming）并存时，MAC 路由学习极易触发二层环路或震荡黑洞：当某 MAC 先后在两台 VTEP 上被学习时，RFC 7432 用 MAC Mobility 扩展团体属性中的 `Sequence Number` 仲裁胜者（更高序列号胜出，序列号相同时按更低发送方 IP/RD 决胜！），但一旦某本地或远端通告带有 `Sticky` 标志（静态锚定 MAC），无论对端序列号多高都必须拒绝迁移并锁死在 `Sticky` 位置（双端同为 `Sticky` 则上报配置冲突！）；更微妙的是，如果某宿主经 LAG 双活接入共享同一非零 `ESI` 的两台 VTEP，这两台 VTEP 间互相收到的同 `ESI` Type-2 通告**属于正常多归属负载分担，绝不可触发序列号递增或误判为 MAC 迁移！**而一旦在时间窗口 `M` 内发生超过 `N` 次真正跨 ESI 迁移，控制面必须触发 Duplicate MAC 检测冻结该 MAC 停止继续通告。为数据中心路由控制面交付可导入的 Go RFC 7432 EVPN MAC/IP Type-2 与多归属 ESI 状态机包。规则：1）维护每个 EVI（广播域）的本地与远端 MAC-VRF 表，处理本地学习、本地老化、远端 BGP EVPN Type-2 增删通告；2）严格实现 RFC 7432 序列号递增（本地覆盖远端非同 ESI 路由时自动设为 `remote_seq + 1`）、`Sticky` 免疫迁移、同非零 `ESI` 形成 All-Active ECMP 下一跳集（不递增序列号！）以及 `M` 窗口 `N` 次跨 ESI 迁移触发 Duplicate MAC 冻结与自动恢复计时器；3）实现 RFC 7432 §8.3 水平分割（Split Horizon）与指定转发器（DF Election，按 HRW 最高随机权重对每个 VLAN 选出唯一 DF）转发决策器：面向某多归属 ESI 发出 BUM 流量时必须同时检查入向 ESI 标签屏蔽回环以及仅由该 VLAN 的 DF 向下行转发。验收覆盖跨 VTEP 热迁移序列号递增、Sticky MAC 拦截高序列号迁移、All-Active 同 ESI 形成 ECMP 且不误触发 Duplicate MAC、真实震荡触发冻结以及 HRW DF 选举与 ESI 水平分割防环。
