# segsweep

线段相交工具：给定一组整数坐标线段，返回**全部交点**与**共线重叠段**，
坐标一律为规范有理数（`math/big.Rat`，自动约分）。

## 语义约定

- 端点接触算相交。
- 多条线段交于同一点时，该点只列出一次，并保留全部参与线段 ID 集合（升序）。
- 共线且共享正长度部分 → 输出 `Overlap`（按参与者集合恒定切分的极大区间，
  支持多重共线覆盖）；共线但仅在单点相触 → 输出交点。
- 零长度线段按点处理；竖线、水平线、重复线段均被支持。
- 交点坐标为精确有理数（如 `(2/3,2/3)`）。

## 用法

```go
res := segsweep.Sweep([]segsweep.IntSegment{
    {ID: 1, X1: 0, Y1: 0, X2: 10, Y2: 10},
    {ID: 2, X1: 0, Y1: 10, X2: 10, Y2: 0},
})
// res.Points   []IntersectionPoint{P Point, IDs []int}
// res.Overlaps []Overlap{A, B Point, IDs []int}
```

命令行（每行一条线段 `id x1 y1 x2 y2`）：

```sh
printf '1 0 0 10 10\n2 0 10 10 0\n' | go run ./cmd/segx
```

## 实现

- `Sweep`：精确有理数扫描线（Bentley–Ottmann 风格）。事件为点，按
  (x, y) 字典序入堆；同一坐标的所有事件按 y 次序成组处理，组内一次性
  收集经过/起止于该点的线段并记录参与者集合，再把状态重排为"刚过该点"
  的次序（y 相同按斜率、再按 ID）。竖线在其 x 坐标处与活动线段逐一求交；
  零长度线段作为事件点参与；共线情形交给按支撑线分组的 1D 覆盖扫描。
- `BruteForce`：O(n²) 全配对参考实现，用于交叉核对（竖线、零长度段、
  多重共线覆盖等退化情形）。
- 测试包含手工退化用例与数千组随机用例的 Sweep/BruteForce 一致性校验。
