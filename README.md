# Nostr事件规范序列化与可替换事件决胜

Nostr 的事件 id 是对固定数组序列化后的哈希，攻击者可用别的转义写法生成同内容不同 id 的事件，或重放旧的可替换事件覆盖新状态。给TypeScript中继写供事件入库调用的 NIP-01 校验包，Schnorr 验签由调用方注入：id 须等于 sha256([0,pubkey,created_at,kind,tags,content] 的无空白 JSON 序列化) 的小写十六进制，其中 content 只转义 \n、\"、\\、\r、\t、\b、\f，其余字符原样；pubkey 为 64 位小写十六进制，sig 为 128 位；created_at 比当前晚超过调用方给定秒数拒绝；种类 0、3、10000 至 19999 为可替换，30000 至 39999 以 d 标签为键可寻址，替换时较新 created_at 胜，相同则 id 字典序较小者胜。用别的转义写法、旧事件重放、同时间戳决胜和未来时间验证。
