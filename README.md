# 最小必要括号表达式库

在抽象**语法树结构**（而不是数值等价）意义下，把表达式打印成括号
**最少**、且能解析回同一棵树的字符串。解析器与打印器相互独立
（打印器不调用解析器，解析器不调用打印器），仅共享一份可配置的
优先级/结合性表。只使用 Python 3.11 标准库（`dataclasses`、
`fractions`、`unittest`），不调用任何符号代数库。

## 目录结构

```
exprlib/
  ast.py        语法树节点（不可变 dataclass）
  grammar.py    可配置优先级/结合性表，歧义表构造时拒绝
  lexer.py      词法分析
  parser.py     递归下降解析器（优先级 climbing）
  printer.py    最小必要括号打印器
  evaluator.py  fractions.Fraction 精确求值，含各运算适用域
  errors.py     异常类型
tests/          unittest 测试，含两个穷举小树集合
demo.py         运行样例
test_results.txt 最近一次完整测试输出
```

## 运行

```bash
python3.11 demo.py
python3.11 -m unittest discover -s tests -v
```

## 语法与默认优先级

数字越大越紧密；`L` 左结合、`R` 右结合。

| 结构 | 符号 | 层级 |
|---|---|---|
| 条件 | `c ? a : b` | 最低，右结合 |
| 加减 | `+ -` | 1，L |
| 乘除 | `* /` | 2，L |
| 一元负号 | `-`（前缀） | 3，介于乘除与幂之间 |
| 幂 | `^` | 4，R |
| 调用 | `f(...)` | 后缀，最紧密 |
| 原子 | 整数、有理字面量、变量、`( ... )` | — |

- **幂右结合**：`2^3^2 == 2^(3^2)`。
- **一元负号与幂分开**：`-x^2 == -(x^2)`；要表示 `(-x)` 的平方必须写
  `(-x)^2`，打印器也一定保留这对括号。
- **有理常数字面量**：`p⁄q` 中的 `⁄` 是 Unicode 分数斜线
  U+2044，与二元除法 `/` 是两个字符，因此 `1⁄2` 是一个原子常数，
  `1 / 2` 是除法表达式，词法层不存在歧义。分母必须是整数字面量且
  非零；不支持浮点（`1.5` 直接词法报错），从源头杜绝浮点损失。
- **函数调用**：`name(arg, ...)`，允许零实参，实参位置可以放完整
  条件表达式而无需括号：`f(a?b:c)`。
- **条件表达式**：条件位是完整表达式，分支右结合：
  `a?b:c?d:e == a?b:(c?d:e)`；条件位自身为条件式时需要括号：
  `(a?b:c)?d:e`。

## “最小括号”如何以树结构定义

打印器只依据父节点上下文、子节点类型与语法表中的优先级/结合性判定，
不做任何数值化简。因此：

- `a-(b-c)` 与 `a-b-c` 是两棵不同的树，前者**必须**打印成
  `a - (b - c)`，永远不会被“分配律化简”成后者。
- 同级算符的经典规则：左结合只在**右**子树加括号
  （`a - (b - c)`），右结合只在**左**子树加括号
  （`(a ^ b) ^ c`）；`a - b - c`、`a ^ b ^ c` 不加括号。
- 一元 `Neg` 作为幂（及任何 `优先级 >= 一元层` 的算符）的**左**
  操作数时必须加括号：`(-x) ^ 2`；作为右操作数永不加：`x ^ -2`、
  `a * -b`。
- 一元负号包住更松的二元层时加括号：`-(a*b)`、`-(a+b)`；
  包住更紧的幂不加：`-x ^ 2`；负负得正只是显示为 `--x`，
  节点仍是两层 `Neg`（结构不被消除）。
- 条件式出现在算符之下恒加括号：`(a?b:c)+1`；调用实参与条件分支
  位置不加：`f(a?b:c)`、`a?b?c:d:e`。

### 括号必要性的判定口径（可证伪）

对任意一棵小树，测试枚举打印结果中的**每一对匹配括号**并同时删除，
然后重新解析。最小性要求：删除后要么词法/语法失败，要么解析得到一棵
**不同**的树。这比“删除单个括号字符”更强地检验了“分组括号成对”的
必要性（调用括号 `f(x)` 删除后会变成别的 token 结构而失败）。

## 穷举验证

`tests/test_exhaustive.py` 按精确节点预算枚举全部同构树（去重）：

1. 算术集合（节点预算 6，`+ - * / ^` 与一元负号、有理字面量）：
   **9018** 棵树，检查 **29375** 对括号；
2. 条件/调用集合（预算 5，含 `Cond`、一元 `Call`）：**3830** 棵树。

每棵树都验证：`parse(print(t)) == t`；每对输出括号删除后必失败或变树。

## 歧义运算表必须拒绝

`Grammar.build([(符号, 优先级, 'L'|'R'), ...], unary_symbol='-',
unary_prec=3)` 在构造时抛出 `GrammarError`：

- 符号重复或占用保留符号 `? : ( ) ,`；
- 优先级非正整数、结合性非法；
- **同一优先级混排左结合与右结合**：`a OP b OP c` 分组不唯一；
- **比一元负号更紧的二元层声明为左结合**：前缀位置 `-a~b` 的归约
  次序不唯一（比一元更紧的层只允许右结合，对应幂的标准约定）。

## 求值：精确有理与每步变换的适用域

求值返回 `fractions.Fraction`，逐节点映射，不做符号化简：

- `+ - *`：任意有理数；
- `/`：除数非零，否则 `DomainError`；
- `^`：指数必须是整数（分母为 1）；负指数要求底数非零；
  非整数次幂不属于有理域，`DomainError`；
- 一元负号：任意有理数；
- `c ? a : b`：`c != 0` 为真，且只对选中分支求值
  （`x ? 1/x : 42` 在 `x=0` 时安全得到 `42`）；
- 变量必须出现在环境中，函数必须显式提供，否则 `EvalError`。

## 运行样例（摘录）

```
a-(b-c)                  => a - (b - c)
a-b-c                    => a - b - c
(-x)^2                   => (-x) ^ 2
-x^2                     => -x ^ 2
2^3^2                    => 2 ^ 3 ^ 2
(2^3)^2                  => (2 ^ 3) ^ 2
a?b:c?d:e                => a ? b : c ? d : e
(a?b:c)?d:e              => (a ? b : c) ? d : e
f(g(a+b), c?d:e)         => f(g(a + b), c ? d : e)

1⁄3 + 1⁄3 + 1⁄3 = Fraction(1, 1)（恰好等于 1）
2^64 = 18446744073709551616
```
