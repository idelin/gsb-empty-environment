# Device Mapper表加载校验

存储组件经 DM_TABLE_LOAD 向内核加载设备映射表，攻击者可构造 linear 目标把受保护块设备的一段映射成可写设备，或用 crypt 的空加密算法让数据明文落盘。为 Go 存储管理服务写供表加载前调用的校验包：解析表行（起始扇区、长度、目标类型、参数），表须自 0 扇区起首尾相接，无空洞无重叠；目标类型只允许 linear、crypt、verity、thin、thin-pool；linear 与 verity 引用的底层设备须在调用方登记的设备集合内，不得是同表里其他映射设备以致成环，起点加长度不得超过底层设备大小；crypt 不允许 cipher_null，密钥长度须与算法吻合；总扇区数溢出 u64 拒绝；已标记只读的底层设备不得经 linear 暴露为可写映射。用空洞、环、越界、cipher_null 和只读设备验证。
