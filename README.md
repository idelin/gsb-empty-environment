云原生 eBPF 服务数据面（Cilium 风格）把 Maglev 一致性哈希后端选择、NodePort `DSR`（Direct Server Return）与 `SNAT` 分流以及基于最长前缀匹配（LPM）的 CIDR 安全身份策略融合在同一报文管线中，四处细节一旦失真就会造成连接抖动或策略旁路：1）**Maglev 素数表构建**：表长 `M` 必须为素数，对每个按规范排序的活跃后端计算主哈希 `offset = h1 % M` 与步长 `skip = (h2 % (M - 1)) + 1` 生成长度 `M` 的完整置换序列，轮询各后端依次填充首个空槽直至全部 `M` 槽填满（支持后端加权重复槽位！），单后端上下线时除极小比例重映射外其余键保持稳定；2）**NodePort `DSR` vs `SNAT` 与 `externalTrafficPolicy: Local` 分流**：当服务设为 `Local` 且入站节点本机存在就绪后端时直接本地转发（绝不经跨节点 Maglev！）；设为 `Cluster` 且选中远端节点后端时，在 `DSR` 模式下必须保留原始客户端源 IP 并在转发封装头写入服务 VIP/端口元数据供目标节点直回客户端（若报文为分片非首片或超出 DSR 封装 MTU 则须按策略降级或触发 PTB！），在 `SNAT` 模式下则分配节点唯一 NAT 端口并建立双向反向还原表项；3）**LPM CIDR 身份与 Deny 优先策略**：入站源 IP 在多个重叠 CIDR（含 `except` 排除子网！）中必须先按最长前缀掩码（`prefixLen` 最大）确定唯一来源安全身份（排除子网对应更长前缀回落到外层或 `world` 身份！），再执行 `Deny > Allow > DefaultDeny` 端口+协议裁决；4）后端缩容进入 `Terminating` 时须从 Maglev 新连接查找表摘除，但已存在的五元组连接跟踪（CT）表项仍继续放行至连接关闭。为容器网络数据面交付可导入的 Go Maglev、DSR/SNAT 转发与 LPM CIDR 策略引擎。验收覆盖 Maglev 素数表确定性与单节点变动低扰动率断言、`Local` 优先与 `DSR` 保源 IP vs `SNAT` 双向还原、重叠 CIDR 含 `except` 最长前缀身份推导、`Deny` 压倒 `Allow` 以及 `Terminating` 后端存量 CT 保活与新流隔离。
