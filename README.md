两个 SecretStore 交接同一租户的前缀时，有些键还由旧控制器写，另一些已由新控制器接管。为 TypeScript 调谐宿主写可导入的事务规划器。每个声明带命名空间、不可变主体 ID、源前缀选择器、目标名、creationPolicy 和逐键来源版本；存储清单用确定性有限自动机定义允许键语言，声明选择器也是 DFA，必须对整个语言做包含检查，不能只验当前列出的键。目标按键记录属主、保护位、最后一次已提交来源和代次。None 永不写入，即便同名目标属于别人；Owner 需整对象拥有权，Merge 只可改动自己拥有或明确交接且未保护的键，Orphan 不接管删除权。一次调谐同时处理主存储与镜像存储的签名快照，两个快照时间不要求相同；只有双方共同确认的交接代次才可改变拥有者，未观测到某键不是删除证明。对任意合法顺序抵达的增量页、撤销及旧页重放，规划出的写集合不能依赖翻页顺序。调用方按比较并交换提交多个目标，每个键的身份、来源代次、值摘要都进入比较条件；遇到对象局部更新时可重算未冲突键，但不得越权完成一半交接。给离线验收函数，以两份完整快照重算已发布计划允许的每次写。使用 UTF-8 字节字母表，覆盖选区当前无键却语言越界、None 无操作、合并时外部抢占一个键、陈旧镜像页和撤销到达最后。
