# sparsepoly：稀疏多变量多项式（精确有理数 + 预算化求值 + 外存归并）

纯 Python 3.11 标准库实现，不调用符号代数库。多项式以
`{指数向量元组: Fraction}` 稀疏存储，零系数项一律回收（规范形式）。

## 功能

- **核心运算**：加、减、乘（教科书式，交叉项按指数和精确合并）、偏导；
  输出按分级字典序规范化排序。
- **精确有理数**：系数为 `fractions.Fraction`，全程无浮点误差。
- **内存额度**：`Budget(max_live_terms=...)` 限制乘积累加器的项数膨胀；
  超额时把有序运行段溢写临时文件，最后做外存 k 路归并
  （重复单项式精确合并、零项回收、临时文件自动清理）。
- **惰性展开节点**：`Add / Mul / Deriv / Leaf` 构成表达式树，
  `evaluate(budget)` 在预算（内存额度或步数额度）不足时返回
  **可继续计算的表达式**（`_MulCont` 续算节点），而非截断的多项式；
  用更大预算再次求值即可恢复，断点位置不影响最终规范输出。
- **峰值项数记录**：`budget.peak_live_terms` 跟踪整个计算过程的
  峰值在内存项数。
- **边界语义**：`x - x` 得零多项式；负指数构造即拒绝（`ValueError`）；
  零变量常数（`nvars=0`）有定义，退化为常数环 Q。

## 适用域说明（每步变换）

| 变换 | 适用域 |
| --- | --- |
| 加/减 | 任意交换环（此处 Q），同指数项精确合并、零项回收 |
| 乘 | 交换环（此处 Q），交叉项按指数和合并 |
| 偏导 | 特征 0 的环：`d(c*x^e)/dx_i = c*e_i*x^(e_i-1)`；特征 p 下 `x^p` 导数为 0，本库不在有限特征下工作 |
| 外存归并 | 单项式分级字典序全序；系数 Q 上精确相加 |
| 惰性求值 | 同核心层；断点续算不改变规范输出 |

## 运行样例输出（节选）

```
=== 基本运算与规范输出 ===
    (x+y)^2        = x^2 + 2*x*y + y^2   # 交叉项合并为 2xy
    x - x          = 0（零多项式，零项已回收）

=== 惰性求值：步数预算暂停/恢复 ===
    第 1 次求值后暂停（步数额度 5 耗尽）-> Add(left=_MulCont(row=1/4, ...), ...)
    恢复完成，共 3 次求值: x^3*y + 2*x^2*y^2 + ... - 3/2

=== 内存额度 + 外存归并 ===
    内存额度 4 项 -> 溢写运行段 10 个，峰值项数 34
    归并结果 34 项，与直接乘法一致: True

=== 预算不足返回可继续表达式 ===
    内存额度 2 且禁止外存 -> 返回 _MulCont(...)（可继续，非截断）
    加大预算恢复后与直接乘法一致: True
```

## 测试

- `tests/test_core.py`：合并同类项、规范排序、加乘、偏导、`x-x=0`、
  负指数拒绝、零变量常数、精确分数运算。
- `tests/test_lazy.py`：惰性求值与即时求值等价；外存归并与直接乘法一致
  （含跨运行段零抵消）；预算不足返回续算表达式且可恢复。
- `tests/test_reference.py`：**独立**稠密小域参考实现 `DensePoly`
  （GF(101) 上平坦数组，不共享 sparsepoly 代码），对照加/乘/偏导的
  mod p 投影；在 Q 上与 GF(p) 上分别验证偏导交换关系
  `d/dxi d/dxj = d/dxj d/dxi` 与 Leibniz 法则。
- `tests/test_pause_resume.py`：随机表达式树 + 随机小步数预算的
  暂停/恢复，规范输出与一次性求值完全相同；溢写与暂停交织时结果
  仍一致；峰值项数被记录且覆盖最终项数。

测试结果：`Ran 26 tests ... OK`（Python 3.11）。

## 结构

```
sparsepoly/
  core.py      # Polynomial：稀疏存储、加乘、偏导、规范输出
  budget.py    # Budget：内存额度 + 步数额度 + 峰值项数
  lazy.py      # Add/Mul/Deriv/Leaf 惰性节点与 _MulCont 续算节点
  extmerge.py  # 运行段溢写 + k 路外存归并
tests/         # unittest 测试（含独立稠密小域参考）
demo.py        # 运行样例
```
