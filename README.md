# SSH用户CA强制命令的按主体合并

SSH 用户 CA 签发的证书可含多个主体，服务端的主体文件又给每个主体配选项，攻击者可靠证书里的另一个主体挑中无限制的那一行，或让证书与主体行各给一个不同的强制命令。给Go会话网关写供认证后选项合并调用的包，以下按本题规定：证书 principals 里每个出现在主体文件中的名字都命中对应行，不是第一行；命中行里只要有 command，则最终必须执行该 command；命中行之间 command 不同、或与证书 force-command 不同则拒绝登录；source-address 取证书与全部命中行的交集，任何一方不匹配即拒绝；主体行只能收紧：证书没有 permit-pty 时主体行不能授予；未知选项拒绝。用主体顺序调换、两个命令冲突、网段交集为空、主体行试图授予 pty 验证。
