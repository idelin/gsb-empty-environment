# 表达式引擎：解释器 + 安全 CSE 优化器

一个支持**纯函数**与**带计数副作用函数**的表达式语言，包含解释器、
公共子表达式消除（CSE）优化器，以及基于随机 AST 的差分测试。

## 语言

| 构造 | 语义 |
| --- | --- |
| `lit` | 数值字面量 |
| `pure` (`add/sub/mul/div/mod/neg/abs/min/max`) | 纯函数；`div/mod` 除零抛错（可能报错的纯函数） |
| `eff` (`tick`) | 带计数副作用：计数器 +1、追加调用轨迹、返回参数值 |
| `if` / `and` / `or` | 惰性分支 / 短路求值（0 为假） |
| `let` / `var` | 仅由优化器引入，承载共享子树 |

## 优化器安全不变式（`src/opt.ts`）

- **仅复用纯子树**：含 `tick` 的子树不参与 CSE，副作用调用既不合并也不移动，
  调用轨迹（顺序与计数）逐条保持一致。
- **可报错纯函数不跨惰性边界提前执行**：含 `div/mod` 的纯子树只在
  「绑定点到首次出现之间全为严格边、且左侧兄弟均为纯且全函数」的位置
  建立 `let` 绑定，因此不会跨 `if/and/or` 分支、副作用或其它可能报错的
  求值点提前执行。
- **纯且全函数的子树**（无 `div/mod`）无任何可观察行为，可提升到根节点全局共享。

共享以 `let __cseN = <子树> in ...` 形式落地，解释器按严格顺序求值 `let`。

## 差分测试（`src/fuzz.ts`）

对每个程序分别解释执行原始 AST 与优化后 AST，比较三者：

1. 结果值（`Object.is` 精确比较）
2. 错误（错误消息由运行时参数值构造，同一失败调用在优化前后消息一致）
3. 副作用调用轨迹（`tick#计数(参数)` 序列）

包含 10 个针对各不变式的固定边界用例，以及种子确定的随机程序
（生成器维护共享子树池，制造大量重复子表达式）。

## 运行

```sh
bun run src/fuzz.ts [迭代次数]   # 默认 5000
```

当前验证：10 个固定用例 + 20000 个随机程序，0 失败。
