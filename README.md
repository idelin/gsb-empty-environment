# 差分故障暴露末轮密钥列

硬件密码回归台要从故障前后输出判断末轮密钥是否暴露，请给Go宿主做可导入的候选恢复包，只处理本题四字节模型。GF(256)采用多项式0x11b；S盒先取乘法逆元（0映射0），再计算y XOR rotl8(y,1) XOR rotl8(y,2) XOR rotl8(y,3) XOR rotl8(y,4) XOR 0x63。正常输出C_i=S(v_i) XOR K_i；故障输出F_i=S(v_i XOR M[i,j]*d) XOR K_i，其中未知j在0至3，非零d在1至255，每组v、j、d可不同，K固定。M四行依次为[2,3,1,1]、[1,2,3,1]、[1,1,2,3]、[3,1,1,2]。输入最多8组(C,F)，求满足每组存在某j,d的全部四字节K，按字节序输出，不能枚举2^32个密钥；利用逆S盒差分表生成并交叉筛选候选。给每个保留候选附各组j,d见证；无候选为模型不一致，多候选明确未唯一，不声称恢复完整密码主密钥。用已知本地K合成多组、单字节无效故障、重复观测及零故障输入测试候选集，接口允许宿主限定每字节密钥候选集合，默认全字节域；以每字节仅4个允许值的小域全组合枚举交叉验证候选生成。
