制品验签服务要判断一次可复用工作流调用是否被根仓库授权。给 Go 服务写可导入的构建身份验证包。输入是宿主验过签的证书声明、调用收据和不可变提交索引，每个收据签名绑定调用方和被调用方的仓库永久 ID、工作流路径、准确提交、构建事件 ID、产物摘要与下一跳随机数。名字可能在转让后重用，分支名只用于展示；同名或同提交不得替代永久 ID。一条授权只许某个根仓库的指定事件，经允许的工作流路径及提交约束，到达唯一的产物签署者。并行任务可共享中间调用，但不能把两次构建中分别有效的收据拼接，或把某次允许的测试事件改作发布事件。报告每条被采信收据的父调用及所绑定的实际产物，拒绝不可达收据夹带授权、未闭合调用、同一随机数指向两份后继和接收范围仅前缀相似。授权随时间更新，要求以签署发生时已生效的历史策略核对整个调用链，同时执行当前对仓库身份的紧急吊销。用多租户、转让前后同名仓库和共享子调用的合成图，拿独立的逐链明确授权表对照批量结果。
