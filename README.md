页式数据库的增量备份包含全页镜像与双页交换日志。为恢复器写可导入的 Go 包：增量记录列出输入页的版本指纹及所产生的新页版本，只有全部前置版本同时可用才能原子重放，日志位置并不保证跨分支全序。备份目录的同名页可来自不同时间线，不能仅按最大 LSN 选取。每次取镜像有传输费用、每次重放有 CPU 费用，用户只要求一组指定目标版本；允许临时保留页的多个不可变版本。求总费用最小的合法恢复 DAG，共享前置只收费一次，平局按镜像 ID 和日志编号规范排序。环状依赖无初始镜像不能自证可用。每个相连分量最多二十四个可用操作，输出可独立检查的逐步来源证书；小图全子集对照，要测两个目标共享一张昂贵底页以及一条交换日志同时产出两个目标。
