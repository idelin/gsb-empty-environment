# 委托收窄证明库

本模块为 Go 验权宿主提供可导入的多级委托关系判定、状态机证书和独立核验组件。

## 语义

- 每份 `Delegation` 用 Ed25519 签名，并绑定租户、动作、有序规则、父委托与 `k-of-n` 门限。
- 路径模式支持字面段、单段通配 `*` 与任意深度通配 `**`；规则同时要求路径、标签谓词和半开时间窗 `[Start,End)` 均匹配。
- 同一委托的多条规则按规则列表顺序检查，最后一条匹配规则生效；没有匹配规则时按拒绝处理。
- 标签集合必须满足互斥、必选和蕴含约束；谓词由必含标签和禁含标签的合取构成。
- 子委托的显式拒绝始终优先，不能被任何父路径末尾允许绕过。
- 非根委托只有在本地允许且至少 `QuorumK` 个父委托允许时才允许；不同父组合的允许集合按法定人数取交并。

## 入口

根包路径为模块本身：

```go
import (
    delegation "formal.local/h26-32a6cdd198"
    "formal.local/h26-32a6cdd198/verifier"
)
```

- `delegation.NewProver(universe)`：编译委托图、标签集合、路径 DFA 和时间分段。
- `prover.Prove()`：成功返回 `CertificateBundle`，失败返回最小 `Counterexample`。
- `prover.Explain(tuple)` 与 `prover.ExplainDelegation(id, tuple)`：生成单对象解释，包含逐层规则匹配、父投票和门限。
- `verifier.VerifyBundle(universe, bundle)`：不调用证明器，独立重算签名、路径匹配、标签约束、时间窗、父投票和门限。

## 状态机证书

`CertificateBundle` 为每个根可达委托保存一个 `DelegationCertificate`：

- `PathStates` 是路径乘积 DFA，迁移为路径小字母表上的全函数，因此可覆盖任意长路径。
- `TimeSegments` 由全部可达规则端点划分，段内所有规则的时间有效性保持不变。
- `Outputs` 覆盖路径状态、合法标签集合和时间分段的完整笛卡尔积。
- 每个输出记录本地效果、最后匹配规则、父允许列表、实际法定人数和最终决策。
- bundle 与每张证书均使用 SHA-256 哈希绑定；独立核验会重新计算哈希并拒绝篡改。

## 最小反例

反例按 `(path, tags, timestamp)` 排序：

1. 路径段数最少；
2. 段数相同时按路径字典序；
3. 路径相同时按标签序列字典序；
4. 再按时间戳升序。

门限未闭合时填充 `FailedQuorum`；父委托自身无证明时，子层报告 `FailedParent`。归因中的委托、门限需求、达成数和允许父列表均针对该最小反例重算。

## 验证

```sh
go test ./...
```

测试使用小路径字母表 `{a,b,c}` 与小标签字母表，覆盖三层委托链、多时段窗口、任意深度路径、`2-of-3` 门限交并、显式拒绝优先、标签约束、最小反例归因、独立核验和证书篡改检测。
