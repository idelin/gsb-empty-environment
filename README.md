# lexprop：有限域字典序约束的支持过滤传播器

Python 3.11，仅标准库，不调用 SAT/SMT 求解器。对两个变量向量施加严格
（`lex_less`）或非严格（`lex_leq`）字典序，实现基于**支持**的过滤
（GAC），而非只比较当前上下界。

## 语义（长度规则明确，与 Python 列表比较一致）

- `lex_leq(x, y)` ⟺ 元组 `x <= y`；`lex_less(x, y)` ⟺ 元组 `x < y`。
- 公共前缀全等时按长度判定：短的是真前缀则更小；等长则相等。
- 相同向量只满足非严格；`[] <= []` 成立，`[] < []` 不成立；
  `[] < [..]` 成立（空向量是任何向量的真前缀）。
- 前位已小（首差已确定）时，后位不受任何额外约束。

## 传播算法

对首差位置 `k ∈ 0..min(n,m)` 做情形分析，用**并查集**把前缀等式
`x_j == y_j (j < k)` 与共享变量统一成等式分量，因此不同长度、共享
变量、严格比较被同一框架联合处理：

- `k < min(n,m)` 可行 ⟺ 前缀等式一致（分量域交非空）且位置 `k` 两端
  不在同一分量并满足 `min(Dx_k) < max(Dy_k)`；
- `k == min(n,m)` 可行 ⟺ 长度规则成立（`n < m`，或 `n == m` 且非严格）。

值 `v` 有支持 ⟺ 固定该变量为 `{v}` 后约束仍可行。每个保留值都有真实
支持，每个被删值都输出一条引用原约束的**删值证明**（`Proof`），列出
每个首差位置不可行的原因，并可用 `Proof.verify()` 独立复核。

`prefix_info` 是前缀支持缓存（按域签名记忆前缀相等可行性与各位置等式
分量域）；`Solver.push()/pop()` 在回溯时同时恢复变量域与该缓存。
`prefix_stats` 报告已强制相等的前缀长度 α 与首个可能首差位置 β。

## 预算与固定点

每次支持检查消耗 1 步预算。预算耗尽时返回 `UNKNOWN`，
`fixpoint_reached=False`，消息为“预算不足，尚未达到传播固定点”。

## 独立检验

- `checker.check_assignment`：按原始语义独立判定完整赋值；求解器声称
  SAT 前强制用它验证候选解。
- `checker.enumerate_supported_values`：全赋值枚举所有解，检验传播后
  的保留域**恰好**等于所有支持值（测试中以 300 个随机实例 + 手工实例
  逐一比对，含共享变量、不同长度、严格/非严格）。

## 运行样例（节选）

```
样例 1: lex_less([x0,x1], [y0]) —— 不同长度 + 严格
  前缀相等长度 alpha=0, 首个可能首差位置 beta=0
  保留域: {'x0': [1], 'x1': [0, 1, 2], 'y0': [2]}
  删值证明：约束 lex_less([x0,x1], [y0]) 中，变量 x0 取值 2 无支持……
    首差位置 k=0: 无法形成 x_k < y_k（本侧最小 2 >= 对侧最大 2）
    首差位置 k=1: 公共前缀全等后按长度规则不满足（n=2, m=1, strict=True）
    => 独立复核: 通过

样例 2: lex_less([a,b], [b,a]) —— 共享变量
  保留域: {'a': [0, 1], 'b': [1, 2]}
  独立枚举: 3 个解, 支持值 a=[0, 1], b=[1, 2]
  保留域恰好等于支持值: True

样例 3: push/pop —— 恢复域与前缀支持缓存
  push 时缓存条目数: 5
  深入后:  {'x': [2], 'y': [2]} 缓存条目数: 7
  pop 后:  {'x': [0, 1, 2], 'y': [1, 2]} 缓存条目数: 5

样例 5: 预算不足
  状态: UNKNOWN, fixpoint_reached=False
  消息: 预算不足，尚未达到传播固定点

样例 6: 空向量 / 相同向量
  lex_leq([], [])      : SAT
  lex_less([], [])     : UNSAT
  lex_less([], [w])    : SAT
  lex_less([w], [])    : UNSAT
  lex_less([w], [w])   : UNSAT
  lex_leq([w], [w])    : SAT
```

## 测试结果

```
Ran 16 tests in 0.016s
OK
```

覆盖：基本传播（前缀相等/首差/前位已小则后位自由）、长度规则（空向量、
不同长度、相同向量仅非严格）、共享变量、push/pop 恢复域与前缀支持缓存、
预算不足报告未达固定点、SAT 解的独立验证、以及保留域与全赋值枚举支持
值精确一致（手工 + 300 随机实例，含每条删值证明的独立复核）。

## 文件结构

- `lexprop/core.py` — 变量、预算、`LexConstraint`（前缀缓存、情形分析、支持过滤、删值证明）
- `lexprop/solver.py` — 固定点传播、push/pop 轨迹、回溯搜索
- `lexprop/checker.py` — 独立语义判定与全赋值枚举
- `tests/test_lexprop.py` — unittest 测试套件
- `examples/demo.py` — 运行样例
