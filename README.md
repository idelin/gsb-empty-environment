存储控制器要在机架维护期间迁移纠删码卷。给调度插件交付可导入的 Go 包，节点有磁盘槽、区域和机架；每卷分片带向量系数，故障后能否解码按 GF(2) 秩而不是剩余片数判断。一次复制占两端带宽和目的槽，复制完成前不提供可读片；随后可删除源片，删除不占带宽。每轮允许并发的复制受链路割容量、端口与空槽限制。给定维护轮次和隔离的故障域集合，要求每轮开始、复制中和删除后，任意一个指定故障场景下各卷都能解码。找最少轮次的布局并在同轮次下最少复制字节，输出逐轮秩见证和可单独运行的包内校验器。小集群至多八节点三卷、每卷四种片、八轮；用全状态搜索对照，特别测试复制未完成时误把目的片计入以及独立机架却系数线性相关。
