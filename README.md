权威 DNS 解析里，空非终节点（Empty Non-Terminal）、子域委派切点、DNAME 重写合成和通配符匹配叠加时，极易错把 NODATA 回成 NXDOMAIN 或被通配符越权劫持子域。为权威服务器交付可导入的 Go 查询应答包，严格遵循 RFC 1034、4592 与 6672。输入单个权威区的完整记录集（SOA、NS、A/AAAA、TXT、CNAME、DNAME、通配符 `*.` 与子域委派 NS 及胶水 A/AAAA）和查询（qname, qtype，大小写无关但响应保留原大小写）。规则：先定位最长匹配祖先，若落入子域委派切点（且非查询切点处 DS 记录）则立即返回转介应答（含 NS 与区内胶水，绝不触发父区通配符）；若命中的节点或其祖先带 DNAME，须合成对应 CNAME（目标超过 255 字节线格式返回 YXDOMAIN）并继续在区内追踪目标；若存在更深层后代使 qname 成为空非终节点，则必须返回 NOERROR/NODATA 并带 SOA，不得回 NXDOMAIN 也不得落回通配符；仅当最近存在祖先无对应子分支时才匹配其直接通配符并按 qname 合成属主名；CNAME 链遇环或超最大跳数返回 SERVFAIL。验收用手工构造的复杂区逐项核对 RCODE、AA 位及 Answer/Authority/Additional 区段，覆盖 ENT 返回 NODATA、DNAME 合成超长 YXDOMAIN、子域委派遮蔽通配符、CNAME 指向通配符，以及双 CNAME 环检测。
