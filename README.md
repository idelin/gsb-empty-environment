# 线段集合平面分割（精确有理数）

输入一组线段，输出全部交点与共线重叠段切分出的平面图：顶点、子边及每条子边的来源线段。

## 运行

```sh
python3 main.py            # 运行样例
python3 -m unittest -v     # 运行测试（10 个用例）
```

## 精确性保证

- 坐标接受 `int` / `Fraction` / 可分数字符串（如 `"1/2"`），统一转为
  `fractions.Fraction`，全程精确运算。
- 拓扑判断只用叉积的精确符号（`== 0` / `< 0` / `> 0`），**不使用任何 epsilon**。
- 顶点以精确坐标元组为键去重：共享端点、十字交点、T 型节点只建一个点。
- 子边以无序顶点对为键去重，来源集合合并：完全重合的两段产生一条子边、双来源。

## 退化情形定义

- **零长度线段**：不进入求交的分式计算（无除零分支），单独输出为
  `isolated_points`，并精确标注它落在哪些非退化线段上。
- **共线重叠**：重叠为区间时，重叠段成为一条（或多条）双来源子边；
  重叠退化为单点（端点相触）时只产生共享顶点，不产生零长度边。
- **端点接触 / T 型接触**：被触线段在该点被切开，触点只建一次。
- **平行不相交**：互不影响，各自成为独立子边。

## 结构

- `planar_graph.py` — 核心：`Segment.of(...)` 构造，`build_planar_graph(...)`
  返回 `PlanarGraph(vertices, edges, isolated_points)`；`Edge.sources` 为来源标签元组。
- `main.py` — 演示：十字交叉、部分重叠、完全重合、有理数坐标、T 型、零长度。
- `test_planar_graph.py` — 10 个 unittest 用例覆盖上述全部情形。
