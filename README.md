# 离散六边形分层空间索引 + 自适应动态阈值控制（Go）

基于二十面体展开的离散六边形地理网格系统（aperture-7，类 H3），
以及根据外部压力与环境指标自调节内部参数的自适应阈值控制器。
仅使用 Go 标准库。

## 设计要点

**空间索引（`grid` 包）**

- 二十面体 20 个三角面作为基础单元，球心投影（gnomonic）展开到切平面。
- 六边形格点用 Eisenstein 整数表示（轴向坐标 `(q,r)`），层级缩放基
  `A = 2+ω`（范数 7）：每个父单元恰分为 7 个子单元，每级旋转
  `arg(2+ω) ≈ 19.1°`（编码/解码按分辨率补偿旋转，父子地理嵌套）。
- 数字集 `{0, e1..e6}` 构成模 A 完全剩余系 ⇒ 任意格点有唯一 A 进制
  展开，即分层编码的拓扑骨架；父单元 = digit 前缀截断，子单元 = 追加 digit。
- 64 位索引（H3 风格位布局）：`[mode:4][res:4][baseCell:7][15×digit:3]`，
  编码为十六进制字符串。
- **K-Ring 遍历纯整数**：邻居偏移为常量整数向量，环距离为立方坐标
  切比雪夫距离，digit 展开/折叠为整数矩阵运算，全程无浮点三角计算。
- 覆盖校验 `VerifyContiguousClosed`：共享边抵消后，边界边在顶点图上
  度为 2 且连通 ⇒ 单一闭合环 ⇒ 连续、无洞、无重叠（纯整数证明）。

**自适应控制（`adaptive` 包）**

- 压力 = `max(CPU/目标CPU, P99/延迟目标)` 的 EMA；迟滞带 `[0.8, 1.0]` 防抖。
- 压力越线或错误率 > 2%：**乘性快速回退**（×0.5）+ 冷却期，规避雪崩。
- 健康且在途需求饱和（≥90% 阈值）：按余量比例**加性爬坡**，最大化资源
  利用；无需求时不上调（负载感知）。
- 阈值始终钳制 `[Min, Max]`；NaN/负值脏指标直接丢弃。
- `Limiter` 动态阈值准入（许可释放幂等）；`Tuner` 后台周期调谐，
  `Stop` 幂等且等待 goroutine 退出，严格无泄漏。

**已知简化**：20 基单元（未细分 122 个）；跨面边界不做折叠（面边缘单元
重编码可能落入邻面，索引仍合法）；五边形基单元按六边形拓扑处理。

## 测试结果

`go test ./... -race -count=1` 全部通过（29 个测试）：

```
ok  hexgrid/adaptive  4.570s   (15 个测试)
ok  hexgrid/grid      15.198s  (14 个测试)
```

- **验收**：`TestAcceptanceGPSKRingCoverage` — GPS→res8 十六进制编码，
  半径 3 环 37 单元，边界边 42 条单一闭合环，无重复、无孤立、无空洞。
- **拓扑**：Eisenstein 展开/折叠互逆（4 万随机点）、K-Ring 尺寸
  1/7/19/37/61/91、邻居对称性、环距离、空洞/重复检测。
- **层级**：父子 digit 前缀一致、7 子单元互异、子父地理嵌套、
  全球 1° 扫描 digit 展开永不超位（无截断）。
- **自适应边界**：Min/Max 钳制、无需求不上调、错误率即时回退、
  冷却期禁升、迟滞带稳定、脏指标丢弃、配置校验。
- **并发与泄漏**：32 写 + 4 读 goroutine 下阈值恒在界内（`-race`）；
  许可释放幂等、并发后 `InFlight==0`；Tuner 反复 Start/Stop 后
  goroutine 数回到基线（严格无泄漏）。
