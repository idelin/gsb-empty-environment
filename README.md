# 时域抗锯齿在移动物体交叉遮挡时把后层历史混进前层

时域抗锯齿在移动物体交叉遮挡时把后层历史混进前层。为Go渲染管线实现带几何证据的重投影包，输入当前帧与前帧的像素深度、线性预乘颜色、对象代次、法线，以及每对象从前帧到当前帧的可逆仿射矩阵和两帧相机矩阵；按像素中心反投影前帧点再正向投到当前帧，以双线性足迹分发历史，碰撞按当前相机深度再按对象ID排序。只有与当前对象代次相同、深度误差和法线夹角在输入阈值内的贡献可用，剩余颜色按权重归一后裁剪到当前同对象3×3邻域范围；缺历史精确用当前值。相机近平面穿越、负尺度对象和alpha为零各有明确拒绝或零值处理，所有历史在新帧完成前不可覆写。用合成双层遮挡、相机抖动及逐点几何参考核对遮挡顺序、空洞和图块并行等价。
