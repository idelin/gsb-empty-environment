# snapscan：固定数据快照 + 动态权限的分页扫描模型

## 核心语义

- **数据快照固定**：首次 `NextPage(nil, ...)` 时 `Pin()` 一个快照（全局序列号），
  整个分页过程只读该快照；之后的写、删、新增均不影响扫描结果。
- **权限按交付时最新版本校验**：权限不参与快照，每条记录在交付瞬间查询
  `PermStore.Allow(key)`。撤权立即生效。
- **撤权后未交付项不得泄漏**：被扫描但当时无权限的键被跳过，记入审计日志
  `Skipped()`，不进入交付页。
- **已交付项不撤回**：交付日志 `Delivered()` 只追加；交付后再撤权不影响已交付记录。
- **游标 = 数据快照 + 最后扫描键**（而非最后交付键）：被拒绝的键同样推进游标，
  不会被重复扫描；跳过之后再重新授权也不会补发——一次扫描中每个键只判定一次。

## 工作有界

`Scanner.MaxScanPerPage` 限制单次 `NextPage` 扫描的键数（含被拒绝的）。
预算被无权限键耗尽时返回空页 + 非 nil 游标，调用方携带游标继续即可。

## 文件

- `store.go`：带版本的键值存储与快照扫描（`Store` / `Snapshot` / `ScanAfter`）。
- `perm.go`：动态权限模型（`PermStore`：Grant / Revoke / Allow）。
- `scanner.go`：游标分页扫描器（`Cursor` / `Scanner.NextPage`）。
- `scanner_test.go`：快照隔离、撤权跳过、游标语义、空页续扫，
  以及用动态权限模型逐键核对跳过项与分页完整性的模型测试。
