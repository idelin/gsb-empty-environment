# unify — 类型合一求解器

支持函数类型、元组类型、柔性类型变量与显式刚性变量的合一（unification），
产出最一般替换（MGU），并在失败时给出最短冲突方程链。

## 类型

```go
V("a")          // 柔性变量：可绑定到任意类型
R("r")          // 刚性变量：只能与同名刚性变量合一，不能绑定到任意类型
Fn(a, b)        // 函数类型 a -> b
Tup(a, b, ...)  // 元组类型 (a, b, ...)
```

同名变量节点（即使指针不同）被视为同一变量。

## 用法

```go
s := unify.NewSolver()
if c := s.Unify(Fn(V("a"), V("b")), Fn(V("b"), V("a")), "eq1"); c != nil {
    fmt.Println(c) // 失败：原因 + 最短冲突方程链
}
sub := s.Substitution() // 成功：最一般替换（幂等）
```

## 设计要点

- **并查集 + 证明森林分离**：等价类用带路径压缩的并查集维护（`find` 会压缩
  `parent` 指针），但解释来源记录在独立的证明森林中——每次合并两个等价类时
  记录产生该合并的方程作为森林边。路径压缩绝不触碰证明森林，因此冲突链的
  解释来源不会被毁掉。每个等价类在证明森林中是一棵树，任意两点间路径唯一，
  即最短冲突方程链（实现上仍用 BFS 保证最短性）。
- **occurs 检查**：柔性变量 `v` 绑定到类型 `t` 前检查 `v` 的等价类是否出现在
  `t` 中；若出现则拒绝构造递归类型，并输出冲突链（含 `v` 在 `t` 中的出现位置，
  如 `arg0.arg1`）。
- **刚性变量**：同名刚性变量规范化为同一节点因而直接合一；刚性变量与任何
  其他类型（柔性变量、不同名刚性变量、函数、元组）合一均失败，因为合并
  等价类会把刚性变量绑定到任意类型。
- **最一般替换**：`Substitution()` 按等价类提取替换，未绑定的变量类映射到
  类内字典序最小的规范名，因此结果是 MGU 且**幂等**（像中不含定义域变量，
  `σ∘σ = σ`）。`Compose(g, f)` 组合两个替换时完全应用像并丢弃恒等绑定，
  保持幂等性。

## 测试

```
go test ./...
```

- `unify_test.go`：函数/元组合一、MGU、occurs 直接/链式失败、路径压缩后
  冲突链仍完整（10 个链式方程压缩后仍输出 11 步链）、刚性变量、构造子
  不匹配、跨别名冲突链、重命名结果。
- `enum_test.go`：小类型树枚举验证（变量 `{a,b}` + 刚性 `{r}`，深度 ≤2 共
  903 个类型）：
  - 所有 `v = t`（`v ∈ t`）均被 occurs 检查拒绝（1364 条递归方程）；
  - 任意类型与其等价变量重命名副本合一成功，结果为纯、单射、幂等的重命名；
  - 逐对枚举验证：成功则替换幂等、使两侧相等、自组合幂等；失败则冲突链非空；
  - 自合一产生恒等替换；刚性变量枚举上永不绑定。
