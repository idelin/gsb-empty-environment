# 乱序收敛列表模型（CRDT）

TypeScript 实现的列表模型，支持操作乱序、重复到达时收敛到一致顺序。

## 语义

- **insert**：携带全局唯一 `id` 与前驱 `pred`（`null` 表示列表头部）。
- **排序**：同一前驱下的兄弟按 `id` 字典序；列表顺序为根节点深度优先遍历。
- **delete 可先于 insert 到达**：先建占位墓碑，insert 到达后补全内容但保持删除态；墓碑永久保留，作为后继节点的锚点。
- **幂等**：重复 insert / delete 安全忽略。
- **未知前驱暂存**：前驱完全未知（无 insert 也无墓碑）的 insert 进入暂存区，前驱出现后自动级联挂载，绝不丢弃。
- **诊断**：`diagnostics()` 返回暂存的 insert（`pendingInserts`）与被引用但从未到达的 id（`missingDependencies`）。

## 运行测试

```sh
bun test
```

测试对封闭操作集枚举**全部排列**（如 6 条消息的 720 种顺序，含混入重复操作的变体），断言最终顺序一致且诊断清空；另覆盖缺依赖暂存、级联唤醒、占位墓碑锚定等场景。
