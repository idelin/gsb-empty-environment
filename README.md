# 可变长度CBC-MAC的拼接伪造

设备协议把不同长度的块串直接做CBC-MAC，攻击者从两条合法消息可拼出第三条有效消息。给Go密码测试宿主实现本题AES-CBC-MAC包：密钥由宿主回调持有，分组16字节，消息必须非空且整块；初始链值全零，每块计算AES_K(block XOR state)，最终state为tag。攻击输入两条已获标签的消息M和N，构造F=M||(N_first XOR tagM)||N_rest，证明MAC(F)=tagN；包通过只会调用Tag(message)的本地oracle确认，不能读取密钥。支持M、N各1至8块，输出逐块链值仅由测试oracle的可观察调试模式提供，生产接口不暴露。随后实现加固格式：MAC输入为固定域标签、消息块数的大端64位块和消息，域标签为固定15字节ASCII后接一个零字节，恰为一块，所有调用方都用该格式；旧tag不得在新格式中接受。用标准库AES随机密钥验证拼接公式、改任一字节失败、长度块不同、空消息拒绝及旧新域隔离；不要把CBC-MAC用于加密，也不要把固定长度下的安全性说成任意长度。
