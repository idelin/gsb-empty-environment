# 攻防轮次极小极大

隔离演练平台需要比较防护动作对攻击链的实际影响。写供Go演练宿主调用的有限回合博弈包，状态为至多16个事实，攻方与守方轮流选满足前置条件的增删动作，守方有整数预算；目标是守方在给定回合内保证目标不被攻方获得。求完整策略树或攻方反策略，不能用单条最低成本路径代替。用极小模型穷举验证动作失效、无合法动作和预算耗尽。

## 实现

子包 `adgame` 提供供 Go 演练宿主调用的完整实现：

- `model.go`：16 事实位图状态（`State`/`Fact`）、带前置条件与增删集合的
  `Action`、整数预算的 `Game` 与静态校验。
- `solver.go`：对 `(状态, 半步, 规范化预算, 行棋方)` 记忆化的极小极大求解，
  输出完整策略 DAG（`Solve`/`Solution`/`Node`/`Edge`）。攻方节点枚举全部
  合法动作，守方节点标注全部制胜防护动作；守方无法保证安全时同一结构给出
  攻方反策略。`NextMove` 供宿主逐步查询，`Stats` 汇总展开规模。
- `minmodel.go`：可达论域上的包含极小模型穷举
  （`EnumerateInclusionMinimal`）与单调 Horn 最小闭包（`LeastFactClosure`）。
- `verify.go`：`Verify` 用极小模型穷举给出动作失效（前置不满足 / 生效无
  变化 / 预算阻断）、无合法动作、预算耗尽的极小事实集见证，外加闭包证书。
- `replay.go`：`ValidateStrategy` 用独立的纯语义极小极大参考实现回放整棵
  策略 DAG，交叉验证边合法性、后继状态与每个节点的胜负。

## 验证

```sh
go test -race ./...
```

测试覆盖守方必胜完整树、预算翻转胜负、回合耗尽、初始即达目标、无合法
动作停着、三类动作失效、预算耗尽最小追加预算、闭包不可达证书、确定性
查询，以及 200 个随机博弈上求解器与独立参考实现的差分一致性。
