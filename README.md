归档读取端同时保留旧文件句柄和增量更新后的新快照。给 Go 块服务写可导入的读取证明验证包。文件按 4096 字节分块，叶子哈希绑定域标记、块索引、实际有效长度和字节；内部哈希绑定域标记、区间起止及两个子哈希。非二次幂区域从小于区域长度的最大二次幂处切分，空文件单独承诺。签名清单绑定文件身份、长度、版本号、前版根和本版根。一次读取可跨多个非连续区间，接收端要验证一个合并证明：每个必要兄弟节点恰好一次，不接受额外区间、重复叶子或将旧根下的正确兄弟用于新句柄。增量更新输入为旧证明、变化叶子和新签名清单；只允许复用能证明索引、区间和有效长度都未变的子树，截短后再扩展不能复活旧尾块。提供独立的全量建树参考，用同身份四个连续版本对照旧句柄依然读旧内容、错代缓存拒绝、末块长度变化和相交读取请求的证明去重。
