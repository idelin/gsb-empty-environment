集团将部分邮件用途委托多个发送商，一个收件人可能对同一地址保有不同来源的有效同意。给 TypeScript 投递宿主写可导入的授权解释组件。签名授权声明绑定永久主体、用途树节点、发送商集合、地域范围和半开有效期；撤回可切走其中一个子用途、地域或发送商，不等于撤掉整份授权。迁移一组列表时，只能从同一链继承用途、主体和地域，不能从不同同意记录拼出一次发送权。对给定发布批次，产出可核验的最大可投递子集合及其签名依据，任何接收者或授权边界不明确的项须待判。输出回执只允许向发送商披露它负责的结果，其他发送商是否已有同意不能影响可见响应。输入可能按不同顺序送达，含显式更正、同签发者分叉、时间不重叠的恢复声明和多个别名映到同一收件主体；缓存要正确反映选择性撤回。用逐时刻全量授权参考对照增量版本，验证只撤一条重叠授权时另一份仍合法，以及看似覆盖同一地址但用途和地域不在同一份授权中的情况。
