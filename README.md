# ratid：有理多项式表达式恒等判断

在**空仓库**中用 **Python 3.11 + 标准库（`fractions`、`dataclasses`、`enum`、`unittest`）**实现，
不调用任何符号代数库。对两个一元有理多项式表达式做精确的展开、规范化与恒等判断：

- `equivalent`：恒等（值恒等 **且** 在有理数上的定义域相同）；
- `not_equivalent`：非等价，给出**有理数反例并实际代入两个原始表达式复核**；
- `unknown`：超出支持域，或项数预算超限——此时**明确标记未知，绝不猜测**。

## 快速运行

```bash
python3.11 -m ratid.demo                     # 10 个覆盖各类情形的演示案例（完整输出见 sample_run.txt）
python3.11 -m unittest discover -s tests -v  # 43 个单元测试（输出见 test_run.txt）
```

编程接口：

```python
from ratid import judge

r = judge("(x^2 - 1)/(x - 1)", "x + 1", budget=256)
print(r.verdict)        # Verdict.NOT_EQUIVALENT
print(r.counterexample.describe())
# 定义域不同：x = 1 处仅右侧有定义（左有定义=False，右有定义=True）
```

## 方法（每一步都是确定性代数操作，适用域随步标注）

每个子表达式维护三元组 `(P, Q, D)`：

- `P/Q`：作为有理函数的值，`P、Q` 为整系数多项式（乘除全部**展开**，再用自实现的
  多项式 GCD 约去分子分母公因式，仅用于控制规模与规范形）；
- `D`：**语法中实际出现过的分母（原始除式）之积，完全不预约分、不取消**。
  表达式在有理数上的适用域为 `{x ∈ Q : D(x) ≠ 0}`。

判定两个表达式 `P1/Q1` 与 `P2/Q2`：

1. **值判据（充要条件）**：交叉相乘，检查 `Δ = P1·Q2 − P2·Q1` 是否为零多项式。
   `Δ ≡ 0` 当且仅当两式在公共定义域上值恒等。这是精确的代数判据。
   > 随机/定点代入相等**不能**证明恒等；本工具不把采样当作证明，只把代入用于复核反例。
2. **定义域判据**：用**有理根定理**枚举 `D` 的全部有理根（含重数，综合除法精确剥离），
   比较两侧根集合（比较时忽略重数）。
   > 约分结果相同不代表恒等：`(x²−1)/(x−1)` 与 `x+1` 的约分形一致，但前者在 `x=1` 无定义。
   > 定义域必须从**原始分母**提取，不能只看约分结果。
3. `Δ ≡ 0` 且根集合相同 ⇒ `equivalent`；否则 `not_equivalent`，并构造有理数反例：
   - `Δ ≢ 0`：在“小分母有理数点”中搜索使两式都有定义而值不同的点；
   - 根集合不同：取对称差中的一个点（可以是分数，如 `1/2`）；
   - 反例一律通过对两个**原始表达式**独立精确求值来复核（测试中另有直接按 AST 递归
     求值的独立复核，不经过判定器自身的规范化结果）。
4. 非有理根（如 `x²−2` 的 `±√2`）不影响有理数上的判断：两侧在 `Q` 上的定义域只按
   有理根集合比较。

每一步变换（常量/变量、加减乘除、整数幂）都会记录“做了什么”与“适用域”，
可在 `JudgeResult.steps` 中查看，演示程序会逐条打印。

## 项数预算

- `budget`（默认 256）限制**单次乘法/幂展开后的非零项数**；有理根候选枚举、除根商式
  同样受控。一旦超限，立即抛出 `BudgetExceeded` 并返回 `unknown`。
- 真恒等的表达式若展开规模超过预算，也同样返回 `unknown`（宁可不判，不可错判）。

## 支持域（超出即 `unknown` 并说明原因）

- 仅单变量 `x`；整数与小数（有理数）常数；`+ - * /`，幂 `^`/`**`（右结合）；
- 幂指数必须是整数字面量（可带负号，如 `x^-2`）；支持括号；必须显式写乘法（禁 `2x`）；
- 除以零多项式、`0^0` 等无定义构造；无函数符号、无多变量、无字符串/方程。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `ratid/parser.py` | 手写词法 + 递归下降语法分析，生成 AST；支持域外直接报错 |

| `tests/` | 43 个 `unittest` 用例 |
