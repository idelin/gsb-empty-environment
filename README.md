# 多副本库存模拟器

基于托管额度（escrow / bounded-counter）模型的多副本库存模拟：
副本离线扣减时总库存也不会变负。

## 模型

- 总库存 `total` 初始化时拆分为各副本持有的扣减额度 `rights`。
- 副本扣减只消耗自己的额度（`Deduct`），离线可用，额度不足即失败，
  因此任意时刻 `sum(spent) <= total`，总库存永不为负。
- 额度不足的副本可向他人转让（`Grant`）：转出方立即扣减自己的额度，
  生成带唯一 ID 的转让消息；接收方收到消息（`Receive`）后才获得额度，
  在途额度不得预支。
- 转让消息按 ID 去重，重复投递/重复合并不重复授予。
- 合并规则（`MergeFrom`）：交换转让流水并集，对未应用且收款方为
  自己的消息补记额度；满足交换/结合/幂等律（join-semilattice）。

守恒不变量：`sum(rights) + sum(在途未应用转让) == total`。

## 运行

```sh
go test ./... -v   # 含分区重连守恒测试与随机压力测试
go run ./cmd/demo  # 演示：分区 -> 离线扣减/转让 -> 重连合并
```

## 文件

- `inventory.go` — 副本、扣减、转让、合并
- `network.go` — 网络分区/重连模拟与守恒统计
- `inventory_test.go` — 幂等、不可预支、分区重连守恒、随机压力测试
- `cmd/demo/main.go` — 演示程序，输出各副本可用量与转让流水
