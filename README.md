富文本与协作文档服务在服务端清洗不可信 HTML/SVG 片段时，若仅用正则过滤 `<script>`/`on*` 属性或在解析后直接序列化回字符串而不校验浏览器二次解析的命名空间切换规则，攻击者可利用 `<math><mtext><table><mglyph><style><!--</style><img src=x onerror=alert(1)>`、`<svg><desc>` 或 `<noscript>` 触发 HTML/SVG/MathML 外来内容（Foreign Content）模式跳变，造成经典变异跨站脚本（mXSS）。为 TypeScript 服务端宿主实现可导入的零外部依赖安全 HTML/SVG/MathML 解析器、白名单净化器与二次解析幂等验证组件。组件严格实现 HTML5 树构建命名空间状态机（HTML / SVG / MathML 三态及 `mtext`/`mi`/`mo`/`mn`/`ms`/`annotation-xml`/`foreignObject`/`desc`/`title` 集成点规则）与规范序列化器：（1）只允许白名单标签与属性，硬剥离所有事件处理器属性（`on*`）、`<script>`/`<style>`/`<iframe>`/`<object>`/`<embed>`/`<base>`/`<meta>`/`<noscript>` 以及非白名单协议（`javascript:`/`vbscript:`/`data:`，含空白符、控制字符与实体编码混淆）；（2）硬拦截一切可能导致二次解析树结构变化的危险嵌套（如外来内容中嵌套 `<table>`/`<form>`/`<style>` 或注释内含闭合标签伪装）；（3）强制执行“净化 → 序列化 → 再次解析”幂等闭环校验，若二次解析树与净化后 AST 出现任意标签、命名空间或属性漂移则直接拒收并报告 mXSS 载荷位置。附覆盖 `<math><mtext>`、`<svg><style>`、实体编码 `javascript:` 与幂等校验的对抗测试集。
