# vsets — 版本集合与多包传递依赖求解（Python 3.11，纯标准库）

不联网；包与构建输入均来自本地 JSON。版本为 `major.minor.patch`，可选预发布
后缀 `-channel.seq`（如 `2.0.0-alpha.1`，省略 seq 时为 1）。

## 设计要点

- `vsets/intervals.py`：在任意离散全序域上的**有限半开区间并** `[lo,hi)`，
  支持无界端（`*`）。规范形式 = 互不相交、排序、相接即合并的区间元组。
  布尔运算（并/交/差）只操作区间端点，**不枚举无限版本域**。
  另提供 `min_absent`（集合中最小缺席点）与 `min_included`（差集中最小元素）。
- `vsets/versionset.py`：发布轨一条区间集合，每个**显式允许的预发布通道**
  一条独立区间集合。预发布只有在其通道出现且落在该通道区间内时才被包含；
  数值位相同不会让预发布混进发布集合，反之亦然。
  规范序列化 `rel=...;pre:alpha=...`，`digest()` 为序列化的 SHA-256。
- `vsets/spec.py`：规格串解析：区间 `[1.0.0,3.0.0)`、比较器
  `>= > <= < == !=`、差 `-`、交 `&`、并 `|`、排除点 `!=2.0.0`、
  通道投影 `[2.0.0,3.0.0)@alpha` / `2.0.0-alpha.1` / `@alpha`。
  解析器也接受规范序列化文本，可往返。
- `vsets/target.py`：目标（构建）条件 `key=value` 合取门控版本集合；
  条件集合用输入中**有限的原子**构造真值表并做吸收/Quine 共识化简，
  规范化与版本域大小无关。
- `vsets/index.py`：从本地 JSON 读取包版本、依赖（可按 `when` 门控），
  以及根约束、构建上下文、锁版本。
- `vsets/solver.py`：按包求约束交集 + 回溯选版本；已选包遇到循环边时直接
  复验约束，因此**跨包循环天然既可兼容也可冲突**。剪枝点记录最小不可满足核
  （逐个剔除仍能排除全部已知候选的需求），`Unsatisfiable` 携带该核。
- `vsets/explain.py`：把不可满足核渲染为约束集合、来源路径、已知版本和提示
  （如“命中的是预发布但没有任何约束允许该通道”）。
- `vsets/lockdiff.py`：锁版本变更前后分别求解，输出每个选择发生变化的包、
  旧/新版本与原因（新锁定钉死、被相邻重锁牵连、属于最小不可满足核）。
- `vsets/brute.py`：对有限夹具做全组合穷举，仅供交叉验证。

## 运行

```bash
python3.11 -m unittest discover -s tests -v
python3.11 demo.py
```

## 夹具

`tests/fixtures/packages.json` 含兼容循环（a<->b，含 alpha 预发布轨）、
冲突循环（c<->d 互相要求对方落在不同区间）、目标门控（img->codec 仅
`format=av1`）、无界/相接开边界链（web->http->sock）。
`tests/fixtures/build_*.json` 为构建输入。

## 测试覆盖（对应任务的三项必测情形）

- `[1.0.0,3.0.0) - [2.0.0,4.0.0) = [1.0.0,2.0.0)`（前半段），含成员抽查与最小反例。
- 预发布通道隔离：数值位相同不混入；显式通道才允许；布尔运算不同书写次序
  规范化后等价（`tests/test_version_set.py`、`tests/test_spec_fuzz.py`）。
- 跨包循环兼容/冲突，6x6 需求矩阵 × 多个根区间逐格用穷举交叉验证；
  另测无界端与相接开边界（`tests/test_solver.py`）。
