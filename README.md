# 鲁棒仓位分配求解器

不超过 10 件物品分到 3 个仓位（A/B/C）。每个场景给出各物品体积；仓位容量可全局给定（`capacity`），也可被单场景 `caps` 覆盖。物品 `i` 在仓位 `b` 的搬运费为 `handle[i][b] × 体积`。

## 第一部分：固定分配（`runStatic`）

- 分配在场景揭晓前固定，所有场景共用同一分配（**禁止按场景分别分配**）。
- 约束：每个场景、每个仓位的负载都不超过容量。
- 目标：最小化最坏场景搬运费；并列时最小化场景等权平均搬运费；再并列按分配向量字典序取规范解。
- 求解：三进制计数枚举全部 `3^N` 种分配；另用独立的递归枚举核对最优值与最优解一致。
- 输出：最优分配、最坏/平均费用、逐场景容量证据（各仓位 负载/容量）。

## 第二部分：观测后一次搬仓（`runRecourse`）

- 揭晓前可观测 `observe` 中物品的体积。观测值完全相同的场景构成**观测组**；组内场景不可区分，**不能选择不同动作**（非预期性约束）。
- 每个观测组可在第一阶段分配 `a0` 基础上搬仓一次：搬动物品数 ≤ `moveLimit` 且搬仓总费 ≤ `moveCostLimit`（共享上限）。
- 成本模型：按**最终仓位**计搬运费，再加搬仓费；`a0` 须在**所有**场景满足容量（揭晓前放置），搬仓后分配须在**组内所有**场景满足容量。
- 目标：最小化最坏场景总成本（并列取平均最小）的两阶段策略。
- 求解：枚举 `a0`；给定 `a0` 时各观测组相互独立，逐组枚举可行搬仓方案取最优，合并即全局最优策略。
- 输出：观测分组、`a0`、各分支搬仓方案与搬仓后分配、逐场景容量轨迹（阶段1 → 阶段2）、最坏/平均成本及相对静态的改善。
- 核对：在策略空间足够小的实例上枚举**全部两阶段策略**（`a0` × 各组搬仓方案的笛卡尔积，成本与容量从头计算），验证与分解求解的最优值一致。主实例策略空间过大时自动跳过并提示。

## 运行

```sh
go run . -i instance.json   # 主实例：10 物品 / 4 场景 / 观测物品 0,5
go run . -i small.json      # 小实例：4 物品 / 3 场景，自动执行全策略枚举核对
```

也可 `go build -o solver .` 后运行 `./solver -i <实例.json>`。

## 内置实例结果

- **主实例**（10 物品，容量 40×3，观测物品 0/5，搬动 ≤3 件且搬仓费 ≤12）：
  静态最优最坏搬运费 293.80；两阶段策略最坏成本 281.00（**改善 4.4%**）。
  观测分组：{基准}、{旺季}、{促销A,促销B}（促销组内不可区分，共用同一搬仓动作）。
- **小实例**（4 物品，容量 16×3，观测物品 0，搬动 ≤3 件且搬仓费 ≤6）：
  静态最坏 60.00；两阶段最坏 50.00（**改善 16.7%**）；
  全策略枚举 13704 个策略，与分解求解结果一致 ✓。
