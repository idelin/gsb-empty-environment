# eventlimiter — 事件驱动精确速率限制桶

Go 标准库实现的滑动时间窗口精确令牌桶/漏桶限流器。

## 设计

- **精确滑动窗口**：事件按发生时间排序保留；事件 `t` 合法当且仅当窗口
  `(t-Window, t]` 内已放行事件数 `< Limit`（漏桶语义：被拒绝的事件不占配额）。
- **事件时间判定**：限流依据事件发生时间而非物理到达时间，支持乱序/迟到提交。
- **迟到重评估**：`Submit` 插入迟到事件后，按事件时间重放全部历史并重新计算
  合法性，与之前状态对比，输出纠正决策：
  - `ACCEPTED` / `REJECTED`：本次提交事件的判定；
  - `REVOKED`：原已通过、重评估后超额的事件（撤销通知）；
  - `REINSTATED`：原被拒绝、重评估后恢复合法的事件。

## 文件

- `limiter.go` — 限流器实现（`Limiter.Submit` 返回决策列表）
- `limiter_test.go` — `go test` 测试，含验收边界用例
- `cmd/demo/main.go` — 验收场景运行样例

## 运行

```sh
go test ./... -v   # 运行测试
go run ./cmd/demo  # 运行验收场景演示
```

## 验收场景

规则：每 10 秒最多 3 次请求。

1. `t=1, 2, 8` 依次到达，全部 `ACCEPTED`；
2. 迟到事件 `t=0` 到达，`ACCEPTED`，同时重评估：`t=0,1,2` 占满 3 个配额，
   原已通过的 `t=8` 超额，发出 `REVOKED` 纠正通知。
