为阻断多设备推送认证中的误点劫持、降级攻击与跨会话移植，给 Go 认证宿主实现可导入的多设备推送状态机与对抗搜索包。每账户可登记最多 3 台设备并区分 `primary` 与 `backup` 信任等级及各自撤销代次，高风险请求仅允许 `primary` 设备批准。挑战绑定 `accountID`、`browserSessionID`、`deviceID`、`challengeID`、请求摘要、风险等级、有效窗口与三位显示码；显示码必须由服务端用 `HMAC-SHA256(key, challengeID||requestDigest||browserSessionID||riskLevel) mod 1000` 计算。同一账户至多一个 Pending 挑战，风险升级或设备撤销立即作废旧 Pending 挑战；用已过期或风险已升级的旧挑战提交批准不但失败还须累加连续拒绝锁计数。设备响应须带对应设备的 Ed25519 签名覆盖全部挑战字段与决定，且消费 Approved 签发会话时绑定同一 `browserSessionID` 并单次消耗。实现确定性并发调度搜索器（深度至多 8），完整探索伪造/过期签名、错码、跨会话移植、双设备竞争、临近截止边界与撤销并发下的攻击最短轨迹。
