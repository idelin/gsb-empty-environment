针对带附加认证数据（AAD）的重复 nonce 多项式认证泄漏场景，给 Go 安全实验宿主实现可导入的密钥恢复与伪造组件，严格采用题内算法而不冒充真实协议。域元素为 128 位无符号数（最低位为 `x^0`），在 `GF(2)` 上按 `x^128 + x^7 + x^2 + x + 1` 约简；每条消息含 0 至 7 个 AAD 块 `A_1..A_a` 与 1 至 8 个密文块 `M_1..M_l` 及长度块 `L = (a<<64)|l`，完整标签为 `S XOR sum(block_i * H^(n+1-i)) XOR L*H` 并可截断至 `t` 位（`64 <= t <= 128`，高 `t` 位有效）。攻击者可输入 2 条或更多同 nonce 观测以消去 `S`，对应特征 2 域上最高 16 次多项式：须完整实现无平方因子分解（含 `p` 次根提取）、不同次分解与确定性等次分解以求取全部不同根 `H`（禁止枚举 2^128）；多组观测发生冲突时须定位到具体冲突观测对下标。给定新消息与目标截断位数时，仅当全部 `(H, S)` 候选生成相同 `t` 位标签才判定确定伪造；以 8 位域 `x^8+x^4+x^3+x+1` 全穷举对照高次重根、截断碰撞与矛盾定位。
