给 Go 事件订阅服务写可导入的续传授权组件。每条事件有流标识、单调序号、所属租户与对象类别；每个发布段由受信发布者签出首尾序号、段内逐事件摘要树根及前段摘要。读者只许订阅获准类别，能看到被授权事件，但不能从续传响应推知其他类别的条数。续传凭据以带随机数的认证加密绑定读者、租户、过滤表达式、授权代次、段头和已确认游标；固定长度密文不得暴露内部物理序号。确认只对实际已发送的一段有序可见事件生效，重复确认幂等，跨读者或跨过滤器确认拒绝。过滤改变或撤权后不能用旧凭据继续取数据。读者断线时服务可能已发送但未收到确认，重连允许重发未确认部分，不能跳过任何仍可见事件。段压缩由宿主提交旧新段之间的签名映射，只有连续性与事件摘要均吻合时才能换游标。用两个仅在不可见事件数量上不同的流对照返回形状，另测乱序确认、段重写、断线重传、撤权和并发确认后不漏发。
