# affarith

保留变量依赖的区间计算库（仿射算术，affine arithmetic）。

每个量表示为仿射形式 `x = c0 + Σ ci·ei`，其中 `ei ∈ [-1,1]` 是带身份的
噪声符号。同一变量出现两次时共享符号而非当作独立输入，因此 `x - x` 精确为 0。

## 特性

- **加减**：逐符号合并系数，依赖精确保留、精确相消。
- **乘法**：线性部分精确；二次偏差 `(Σ|ai|)(Σ|bi|)` 作为新噪声符号保守包围。
- **除法**：除子区间跨零时 `Div` 返回 `*ZeroCrossingError` 明确拒绝；
  `DivPieces` 返回分段定义域（除子负/正两段，值域可无界）。不跨零时用
  Chebyshev 线性化倒数（余项为新符号）再相乘。
- **余项数量超限**：`NewEngine(maxNoise)` 限制每个仿射形式的符号数，超限时
  反复把最小的两个系数保守合并为一个新符号（幅值相加）。
- **可检查证书**：`Certify` 输出 `Certificate{Domain, Lower, Upper, GridSize}`；
  `Verify` 把定义域划分为小有理网格盒，在每个盒上用**独立区间规则**做精确
  有理数（`big.Rat`）求值，所有盒包围必须落在证书界内。验证的是可靠性，
  不是紧致性：更宽的可靠界通过，被收窄的不可靠界被拒绝。

## 示例

```go
e := affarith.NewEngine(0)      // 0 = 不限制噪声符号数
x := e.Var(0, 1)
f := x.Mul(e.Const(1).Sub(x))   // x*(1-x)，负相关被保留
iv := f.Interval()              // ≈ [0, 0.5]，朴素区间为 [0, 1]

cert := e.Certify(f, 8)
err := affarith.Verify(cert, f.Node()) // 独立复核
```
