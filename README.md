# 安全计费重入回调

网关在调用不可信检测插件时会临时扣减资源预算，插件回调宿主可能再次进入同一请求并绕过限额。写供Go宿主调用的执行上下文包，嵌套调用共享预算和截止时间，任何重入都先扣费，取消不可被子调用清除；异步派生需显式移交租约，父完成后未被授权的回调拒绝。用恶意测试插件构造递归重入、双重完成和失败返还，核对总预算与唯一结束事件。

## 包结构

- `execctx`：请求级执行上下文。`Controller` 持有共享预算、截止时间与取消信号；`Frame` 是一次先扣费的插件调用（实现 `context.Context`，无取消入口）；`Lease` 是异步回调的显式授权。
- `execctx/execctx_test.go`、`execctx/lease_test.go`：宿主网关与恶意插件测试，覆盖递归重入、预算/深度拦截、双重完成、超额返还、租约授权与撤销、取消不可清除、共享截止时间、panic 收容、并发预算与唯一结束事件。

## 不变量

- 任何准入路径（`Controller.Enter`、`Lease.Enter`）都在运行插件代码前扣费，重入共享同一预算。
- `Charged - Refunded = Consumed`，且 `Consumed <= Budget`。
- 帧只能结算一次，重复结算返回 `ErrSettled`，退款不重复入账。
- 取消只由宿主 `Controller.Cancel` 触发，幂等且不可撤销；子调用只能观察。
- 异步工作必须 `Frame.Detach` 取得 `Lease`；`Finish` 后未持有有效租约的回调一律拒绝，结束事件只发布一次。

## 运行

```sh
go test -race -count=1 ./...
```
