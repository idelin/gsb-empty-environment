一套集群策略会由入口、转发、出口三个控制面分批下发，标签可能同时变。给 Go 网络控制器写可导入的变更验收包，模型只描述受管租户之间的授权。每条连接携带不可变租户 ID、发起时标签和各跳当前标签；策略是有序的标签谓词与动作，每次转发须过该跳出口与下一跳入口，两者缺省拒绝。连接跟踪只可缓存已经核对的具体跳，缓存绑定策略代与源、目的租户；有向拓扑可循环。输入给每个端点的允许标签变化图、每跳的新旧规则及最多 16 个原子切换组。对候选切换顺序的每个前缀，验证是否所有可达连接都处在该租户对的端到端允许关系内，并且指定探活对始终有可行路径。已有连接可跨切换继续，但不能把旧连接的已验跳应用到另一标签历史。若给出的顺序不满足要求，允许重排互无依赖的组，求最少交换相邻组得到的合规顺序，按原编号破同分。提供可单独检查的授权覆盖证书；预算用尽明确返回未定。通过小图对每个完整事件交错和拓扑中的循环核对误放、误拒以及同一中间节点因来源租户不同而必须分开的状态。
