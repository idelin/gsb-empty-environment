# FastCGI脚本路径拆分与上传目录门禁

PHP 站点常把上传的图片放在可访问目录里，攻击者上传内含脚本的 avatar.jpg，再请求 /uploads/avatar.jpg/x.php，网关按路径拆分脚本文件与附加路径信息时会把图片当脚本执行。为Go FastCGI 网关写可导入的路径拆分包，输入 URL 路径、站点根目录的虚拟文件清单（含符号链接目标）、脚本目录白名单和上传目录列表：只有路径中以 .php 结尾的某一段所对应的文件真实存在、位于脚本目录白名单内，且解析符号链接后仍在站点根内时，才以它为 SCRIPT_FILENAME，其后的部分作 PATH_INFO；上传目录下的任何路径一律不得拆分执行，即使文件名以 .php 结尾；有多个候选时取最靠前的一段；.php 后缀不分大小写，后缀后紧跟的点与空格先去除再判定；PATH_INFO 含 %00 或 .. 段时拒绝。用 avatar.jpg/x.php、上传目录里的 shell.php、符号链接指向上传目录、.PHP 大写和 %00 验证。
