金融与高安全应用在核验 WebAuthn Level 3 / Passkey 登录断言（`webauthn.get`）时，若仅验证签名有效而忽略 `signCount` 异常回退或停滞（硬件安全密钥被物理克隆）、未校验 `BE`（Backup Eligibility）与 `BS`（Backup State）标志位的非法组合及跨次登录的非法状态跃迁（例如不可备份的硬件绑定密钥 `BE=0` 突然变为 `BE=1` 或 `BS=1`），或允许同一一次性 `challenge` 在并发请求中被重复消费，攻击者可利用克隆密钥或重放断言静默接管账号。为 TypeScript 认证宿主实现可导入的零外部依赖 WebAuthn Assertion 完整状态校验与克隆检测组件（签名验真支持注入验签器或 Node `crypto`）。组件严格实现：（1）解析原始 `authenticatorData`（≥37 字节）与 `clientDataJSON`：校验 `rpIdHash == SHA256(rpId)`、`type == "webauthn.get"`、精确匹配预期 `origin`（且按策略拒绝 `crossOrigin === true`）、一次性 `challenge` 原子消费防并发重放，以及强制 `UP=1` 与按策略要求 `UV=1`；（2）校验 ECDSA P-256 / Ed25519 / RS256 签名覆盖 `authData || SHA256(clientDataJSON)`（对 ECDSA 严格校验低 S 规范或完整 DER 格式拒绝尾随字节）；（3）实现凭证状态机与克隆检测：按 WebAuthn Level 3 规范，当存储计数器或本次 `signCount` 任一非零且 `newSignCount <= storedSignCount` 时立即判定为疑似克隆并锁定该凭据拒绝登录；严格拦截 `BE=0 && BS=1` 非法组合，且当已注册凭据初始标记为不可备份（`storedBE=false`）时硬拒绝后续断言中 `BE` 跃迁为 `true`（以及当租户策略强制设备绑定密钥时拒绝 `BE=1` 的云同步通行密钥）。附克隆计数器停滞/回退锁定、非法 `BE/BS` 跃迁、`challenge` 并发重放与跨源拦截测试。
