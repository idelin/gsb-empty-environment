# 路径硬链接隔离核验

隔离区文件通过硬链接可能与宿主共享对象，路径位于根内并不足够安全。实现供Go隔离宿主调用的对象闭包核验包，输入目录树、文件对象引用与允许共享对象集合；报告未经允许的跨域共享及最短两侧路径，断开一条链接只更新受影响对象。用多名字同对象、目录环及对象号代次复用测试结果。

## 包说明（`package netsec`）

- `ObjectID{Number, Generation}`：以对象号加代次标识文件对象，同号不同代视为不同对象。
- `Tree`：由 `Node`（目录/文件，目录项 `Entry` 可形成环）与宿主侧锚点 `OutsideRefs` 构成的输入图；多个节点可引用同一对象以建模硬链接。
- `NewChecker(tree, allowed)`：校验输入并完成初始闭包核验；`allowed` 中的对象允许跨域共享。
- `Reports()`：返回未经允许的跨域共享对象，含两侧最短路径（`InsidePath` 相对隔离区根，`OutsidePath` 首段为宿主锚点名），按对象号、代次排序。
- `Unlink(parentID, name)`：断开一条文件硬链接，仅重算该链接所引用对象的状态；断开目录项返回 `ErrNotDirectory`。

两侧分别从隔离区根和宿主锚点做 BFS：节点首次访问路径为其规范最短路径（环由 visited 截断），再按对象在所有同名节点中取最短、等长取字典序最小。

## 测试

`go test ./...` 覆盖：多名字同对象与增量 Unlink、允许集合过滤、目录环、对象号代次复用、最短路径字典序裁决、输入校验。
