# PLC操作链分叉与恢复窗口

did:plc 的操作链由旋转密钥签名，旋转密钥按优先级排列，攻击者拿到低优先级密钥后可发出竞争操作，或在窗口外改写历史。给Go目录服务写供操作提交调用的链校验包，签名验证与 DAG-CBOR 哈希由调用方注入：每个操作须以 prev 指向现有操作的 CID，创世操作 prev 为空；签名必须来自 prev 操作所列的旋转密钥之一；rotationKeys 数量 1 至 5；同一 prev 上出现竞争操作时，仅当新操作的签名密钥在 rotationKeys 里的位置严格更靠前，且被取代操作距今不超过 72 小时才接受，被取代的操作及其后代标记为无效但保留在审计记录中；其余情况拒绝。用低优先级密钥分叉、恰好 72 小时边界、同优先级竞争和孤立 prev 验证。
