网络接收宿主用多段 mbuf 同时将不同视图交给校验器和解码器，前一阶段核对的长度不保证后一个阶段仍在看同一块内存。给 C++20 接收宿主写可导入的链式缓冲视图库。段含分配身份及代次、真实容量、有效窗口、只读密封标记和下一段索引；允许多个包共享尾部和同一分配上的不相交窗口。借用需记录范围和含义，修改前只复制与不可变借用实际相交的字节，不得清空或覆写仍被其他包或未释放借用引用的尾部。释放与重分配可能复用地址和段编号；读取凭证必须绑定逻辑包代、段位置校验和底层分配代。对一次 pullup、拆包、拼包或部分消费，返回事务性变更计划和可核验的读写集，规划失败零副作用。数据总长和跨段偏移均按精确无符号运算，禁止为了校验稀疏逻辑长度而申请同样大的缓冲。用会在每次分配和引用计数更新处失败的注入宿主验证，和逐字节的不可变参考对象对照：共享尾部分离、零长段、重叠窗口、取消后旧视图访问以及地址复用时的迟到释放。
