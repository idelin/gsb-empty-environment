# TLS导出器跨虚拟主机复用

同一边缘连接可承载多个虚拟主机，应用若只按TLS会话缓存exporter，会把一个主机的通道绑定密钥交给另一主机。请实现供反向代理调用的可导入Go TLS导出器门面，输入不可变握手摘要、连接代次、ECH内外名称、最终认证证书身份、ALPN、恢复PSK身份和应用给出的label/context。只有握手完成且证书、SNI路由与ALPN决定冻结后才能导出；缓存键覆盖最终虚拟主机、握手摘要、label原始字节、context有无及长度，区分nil与空值。0-RTT、HelloRetryRequest、ECH拒绝、会话恢复和证书热更新分别产生新代次，旧异步请求不得填充新缓存。禁止保留`EXPORTER-`前缀冲突标签并限制输出长度。用两个主机共享socket、相同PSK跨证书、空context、HRR前后请求、ECH外名诱导及合法恢复验证任何导出值只属于冻结身份。
