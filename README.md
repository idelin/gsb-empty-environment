冷备回迁的瓶颈是两台顺序磁带机和三个缓存槽。恢复服务要依次向只写输出流交付一串指定块；同块在多盘磁带上可能有副本，也可由同长的两个块逐字节异或重建，给出的重建依赖无环。实现可导入的 Go 恢复调度包。每台机独占一卷，载入从零位置开始，卸卷及载入各用给定拍数；一卷同一时刻只可在一台机上。磁带用有序（偏移、块号）及长度描述；从当前头位读取选中出现位置的开销为跨过空隙的拍数加一拍，结束时头位在该位置之后一格，不允许倒带，重新装卷可回零。启动读取须预占一个空缓存槽；异或任务占一个计算单元，启动时预占输出槽且固定两输入至结束，输出提交按给定清单顺序耗一拍并占独立输出单元。同拍先统一结束，再释放不用的块，再启动；不可拆分非抢占操作，任选多个不冲突操作同时启动，允许故意等候。每个槽可存一个完整块，无论大小相同；所有动作整数时刻，允许槽中同块存在多个副本。找最早输出结束时刻，平局取装卷总次数最少；输出含各设备、槽、起止时刻和读位置的可执行计划。给服务提供事件式执行器，从实际带面读字节、做异或、顺序输出；另能拒绝不可能重放的计划。最多四卷、每卷六个有意义的位置、目标长度至多八块，偏移到 2^45，禁止逐拍展开空带。用小带面的逐拍独立穷举对最优耗时和装卷数；特测读头平行移动时共享槽争用、两任务同拍结束后才允许复用、重装反而比取远端副本快、必须丢弃并稍后重读同块的案例。异或耗时由重建规则给出且为正；源数据一致性由调用方保证。
