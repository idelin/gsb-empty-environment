B-link 索引在并发分裂与页回收期间不持跨页锁，靠叶页高键和右兄弟链定位后继，异常实现常在分裂窗口里漏键或重复读。给索引诊断层交付可导入的 Go 核验包。输入若干叶页在整数逻辑时刻上的版本历史（每帧含页号、键集合、可选高键、右兄弟页号及已回收标记）和一次按升序区间 [L,R] 执行的扫描观察到的键序列。合法的 B-link 扫描每次仅能读取不早于上一次读页时刻的某叶页版本，进入页后收集落在区间内且大于上次已发射键的键，若高键小于 R 则沿该帧右兄弟继续，不得读取已回收帧或倒退逻辑时刻。组件判定是否存在至少一条合法读取路径能精确复现观察序列，存在时输出字典序最小的（页号，版本时刻）轨迹，否则指出首个无法续接的观察键下标。验收用小历史穷举全部单调读轨迹对照判定，覆盖连续两次分裂跳过中间兄弟、高键等于 R 终止、扫描起点落入刚分裂左页后向右追赶，以及因并发删插造成不可线性化的漏键反例。
