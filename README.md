# ACME IP标识符规范化与验证目标

ACME 允许为 IP 地址签证书，攻击者可用前导零、IPv4 映射或私网地址的写法申请不属于他的地址，或指望用 DNS 记录通过验证。给Go签发服务写供订单创建与验证调用的 IP 标识符包，按 RFC 8738：type 为 ip 的标识符值必须是规范文本，IPv4 无前导零（010.0.0.1 拒绝），IPv6 为 RFC 5952 压缩形式；回环、私网、链路本地、唯一本地、多播、IPv4 映射及保留地址拒绝；通配不适用；只接受 http-01 与 tls-alpn-01，dns-01 拒绝；http-01 直接连标识符给出的地址，Host 头为该地址，重定向只能留在同一地址；tls-alpn-01 的 SNI 取反向解析名。用非规范写法、私网地址、dns-01 和跨地址重定向验证。
