# 安全栈分类漏掉间接取址变量

编译器把局部变量分到安全栈与不安全栈，若别名分析漏掉间接取址，缓冲区溢出会覆盖返回元数据。给Go编译验证宿主实现可导入的栈分类包：输入有限SSA图，局部对象有大小、对齐和用途，指针操作含AddrOf、GEP常量/有界变量、Phi、Select、StorePtr、LoadPtr、PassCall、PtrToInt、IntToPtr和ReturnPtr；调用摘要逐参数声明NoCapture、ReadOnly及可访问最大偏移，未知调用摘要按可捕获且任意访问。对象只有在所有派生指针都不逃逸、所有访问范围可证明在对象内、没有PtrToInt/IntToPtr来源、且不与变长对象共享布局时才可放安全栈；否则进不安全栈。返回地址、影子栈指针等控制元数据不由本包布局。分析别名按对象与常量字段路径区分，未知索引合并为整对象；分析字段敏感，递归调用摘要求不动点，预算耗尽保守判不安全。另接受待审分类回调，搜索被其标安全但参考模型不安全的最短来源路径，并用布局模拟器把越界写扩展到相邻槽，只有能触及控制元数据或另一个安全对象才报告安全影响。覆盖Phi一支逃逸、NoCapture但越界摘要、指针存入局部再取出、整数往返及安全只读切片。
