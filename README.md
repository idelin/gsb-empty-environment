# IPMI RMCP+套件准入与用户枚举

IPMI 2.0 的 RMCP+ 会话在套件选 0 时不需要认证，攻击者借此免口令登录 BMC，RAKP 阶段还会把可离线破解的哈希交给任何人。为Go BMC 模拟固件写可导入的会话套件准入包，供 RMCP+ 会话建立调用：RAKP 的认证、完整性与机密性算法三元组中，认证算法为 0（none）或机密性算法为 0 的套件一律拒绝；只放行调用方登记的套件编号（如 3 与 17）；用户名未知时 RAKP2 的响应必须与口令错误时同形（同长度，响应时间落在同一档，由调用方时钟模拟），不得提前返回错误码泄露用户是否存在；匿名登录（空用户名加空口令）拒绝；同一源地址在 60 秒内 RAKP 失败超过 10 次后，丢弃其后续会话请求。用 cipher 0、未登记套件、用户枚举、匿名和失败节流验证。
