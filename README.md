# 带权重投票的协同决策无冲突选择器（TypeScript）

多方分布式加权表决状态合并器（CRDT）。各节点基于持股权重提交 **赞成 / 反对 / 弃权**，
投票权重随时间**因果动态调整**；网络分区愈合后，状态合并自动汇总出**确定性**的全网决策。

## 设计

- **选票（LWW 寄存器）**：每个节点对同一提案至多一条生效选票；并发改票按
  Lamport 时钟 + 序号 + 固定选项次序做确定性裁决。
- **权重（Grow-only 事件集）**：每次权重变更是一条带因果时间戳的事件；
  每张选票按其**投票时刻因果可见的最新权重**计权（投票前的调权生效，投票后的不追溯）。
- **合并**：取事件并集 + 选票 LWW，满足交换律、结合律、幂等律 ——
  任意合并顺序、重复合并都收敛到同一状态。
- **决策规则**（确定性）：
  - `approved`：赞成权重 > 全网有效总权重的一半
  - `rejected`：反对权重 ≥ 全网有效总权重的一半（平局判负）
  - `pending`：其余情况；弃权计入已投票权重与法定人数（quorum），不计入赞成/反对

## 环境要求

Node.js ≥ 22.6（利用原生 TypeScript 类型擦除运行，无需编译步骤；仓库含 `.nvmrc`）。

## 运行

```bash
nvm use          # 或任意 >= 22.6 的 Node
npm test         # Node.js 内置测试运行器（node:test）
npm run demo     # 四节点网络分区演示
```

## 运行样例输出（`npm run demo`）

场景：A=40, B=30, C=20, D=10 创世权重；分区 {A,B} | {C,D}；
P1 先把 B 调权为 50 再投赞成，P2 中 D 先投弃权、之后 D 才被调权为 25。

```
=== 愈合后全网共识 ===

[合并后全网视角]
  赞成权重   yesWeight     = 90     (A:40 + B:50，B 调权后投的票)
  反对权重   noWeight      = 20     (C:20)
  弃权权重   abstainWeight = 10     (D 的弃权早于调权，仍按 10 计)
  已投票权重 votedWeight   = 120
  全网总权重 totalWeight   = 135    (40 + 50 + 20 + 25)
  法定人数   quorum        = true
  最终决策   decision      = approved

合并顺序 A→B→C→D / D→C→B→A / B→D→A→C
结果一致（确定性收敛）: true
```
