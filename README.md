列式文件格式 Parquet 依赖 Dremel 的定义级别（Definition Level）与重复级别（Repetition Level）把任意深度的嵌套结构拍平为叶列，并用 RLE/Bit-Packing 混合编码压缩级别流；如果未能精确区分空列表 `[]`、仅含空元素的列表 `[null]` 以及外层可选结构体为空这三种状态，重组后的嵌套记录就会丢元素或把空列表错误变成 `null`。为列存读写库交付 C++20 头文件与静态库组件。模式树支持任意深度的 `REQUIRED`、`OPTIONAL`、`REPEATED` 结构体与列表嵌套；切分器将嵌套记录数组编码为各叶列的 `(values, rep_levels, def_levels)`，重组器从叶列流无损还原出等价的嵌套记录树。同时实现 Parquet 规范的 RLE/Bit-Packing Hybrid 编解码器处理 `rep_levels`/`def_levels` 与字典索引流：支持位宽 `0..32`（位宽 0 时无载荷字节！），正确编码和解码低位为 `0` 的 RLE 游程头（`count << 1` 加最小字节序值）与低位为 `1` 的位打包头（`num_groups << 1 | 1`，每组固定 8 个值、小端跨字节紧致拼接、尾部不足 8 个补零并按期望总数截断）。验收使用含三层嵌套可选列表与结构体的对抗用例（混合 `null`、`[]`、`[null]`、`[[], [null, 1], null]`、`{opt_struct: null}`、`{opt_struct: {list: []}}`）验证切分->RLE混合编码->解码->重组全链路往返无损，并覆盖位宽 0、1、3、7、13、17 的非对齐位打包边界与截断非法流报错。
