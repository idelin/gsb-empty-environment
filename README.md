存储节点要把已有条带原地换成另一套纠删码布局，不能假设断电后还知道迁移进度。给块层交付可导入的 Go 编译包。每盘一个原子槽，内容是一个带持久标签的编码字节；输入以 GF(256) 系数行描述新旧两套布局，共用至多六个独立源字节，模多项式 0x11d。另给最多十八个可选写动作，各有唯一编号、代价、读取槽和系数、目标槽、新标签，各动作正常迁移最多使用一次；先读全体再覆盖目标，允许原地读改写。要编成一条顺序表，保持每个已写前缀（含两端）删去任意至多 f 块盘后仍可读出全部源字节，并最终精确达到新布局和标签。断电加丢盘后，恢复器只拿得到幸存槽的标签和实际字节、丢盘编号、该顺序表；不知道执行到第几步，不得从标签推断题面未声明的序号。恢复须对每个可达前缀及任意源向量都能无歧义还原原始源字节；不要求区分前缀本身。在此条件下求最小总代价，再取编号序列字典序最小；不可行要与输入格式错误区分。交付实际按步计算写入的执行器及按观测解码或报告不一致的恢复器，不为每个源字节赋样例值就宣布可恢复。最多十个槽、f≤2；不能穷举源字节或只对每个前缀独立查秩。用缩小到二元域的完整小例核对最优写序与解码，包含所有前缀分别满秩但同观测对应不同源、相同标签却因编码子空间可分仍可解，以及只在某块标签盘丢失时出现歧义。
