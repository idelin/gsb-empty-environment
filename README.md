# tri-replica-merge

三副本版本归并库：同一键可离线修改，所有事件用向量时钟标记，支持支配判断、
并发版本保留与显式解决。零依赖，TypeScript 实现，Node ≥ 23.6 直接运行。

## 核心概念

- **向量时钟**（`src/vector-clock.ts`）：`compare` 给出 `equal / before / after /
  concurrent` 四种因果序；`dominates(a, b)` 即 `a` 严格覆盖 `b`。
- **副本**（`src/replica.ts`）：每个副本维护事件时钟与「键 → 版本集合」。
  - `put(key, value)`：本地写，时钟自增，自动剪枝被支配的旧版本。
  - `resolve(key, value, seen?)`：显式解决。新版本时钟 = 调用者见过的全部
    版本时钟的 merge 再自增，因此**恰好支配所有已见版本**；未见的并发版本
    与之并发，同步后仍然保留，不会被误删。
  - `emit() / receive(msg)`：消息级反熵。`receive` 幂等且与顺序无关——
    重复投递按时钟去重，被支配的迟到消息直接丢弃。
- **同步**（`src/sync.ts`）：`gossip`（单向）、`sync`（双向）、`syncAll`（全互联）。

## 运行测试

```sh
npm test   # 等价于 node --test
```

对照测试（`test/merge.test.ts`）覆盖：

- 支配判断：时钟排序与顺序写剪枝；
- 并发保留：三副本离线写同键，同步后保留全部兄弟版本且集合一致；
- 显式解决：解决事件支配全部已见版本；未见版本不被误删；
- 交换：不同成对同步顺序收敛到同一最终集合；
- 重复：消息投递 1/2/3 次结果相同；
- 乱序：25 种随机排列及「乱序 + 重复」组合下最终集合一致。
