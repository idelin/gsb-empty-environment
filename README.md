查询优化器想把多张重叠物化视图拼成一条 GROUP BY 的替代路径。为优化器交付可导入的 Go 包，输入每视图的分组键投影、整数线性过滤区间与保留的 SUM、COUNT、非空 COUNT；NULL 组独立，缺组和计数为零不可混同。替代计划可以用给定的小整数系数相加视图行，再投影合并。要对任意底层多重集保证 HAVING 和结果行语义都等价，并选读取费用最小的计划。不能把 AVG 当线性量直接相加，SQL 空 SUM 也不能默认作零。若不等价，给行数最少、平局按元组序最小的反例底表；限制底表每种元组重数不超过题给上界，编码范围可达 2^40，条件只在稀疏端点变化。候选视图最多十个，分组维度三，提供独立查询解释器和小域全表穷举，包括存在相同聚合数值但一个计划多出空组的情形。
