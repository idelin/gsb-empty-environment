# 短轮分组置换的差分弱点

密码评估服务需要给自定义16位SPN找高概率差分轨迹。请交付供Go评估宿主调用的分析包：每轮先对4个半字节分别用同一16元素双射S盒，再按调用方给的16位置换重排比特，轮数1至4，最低位编号0，输入S盒或比特映射不是双射即拒绝，差分与轮密钥均须在0至65535；轮密钥在轮首异或，差分轨迹计算与其值无关。输入非零起始差分集合和目标差分集合，计算S盒差分分布表，每条具体轨迹的分数为各活跃S盒转移计数除16后的精确有理数乘积，求最大分数，等分按各轮差分整数序列排序。可用分支定界，预算耗尽必须同时返回最佳已知轨迹及尚未排除的概率上界；两者未闭合不能称最优。另写逐明文枚举的真实差分概率复核器，对调用方指定密钥和输入输出差分计数。报告明确区分单条轨迹概率与多条轨迹合并的真实概率，不能把前者当后者。用恒等S盒、非线性双射、不可达目标及小轮数枚举验证边界。

## 交付说明

包 `netsec`（模块 `example.org/netsec/q0021`）提供：

- `NewCipher(sbox, perm []uint8, rounds int)`：构造 1–4 轮 16 位 SPN。S 盒或 16 位置换不是双射即报错；`perm[i]` 表示输入比特 i 移到输出位置 i 的目标位（最低位编号 0）。差分与轮密钥均为 `uint16`，天然落在 0–65535。
- `(*Cipher).DDT()`：S 盒差分分布表。
- `(*Cipher).SearchTrails(SearchRequest)`：最优轨迹优先分支定界。`Starts` 为非空非零起始差分集合，`Targets` 为目标差分集合，`Budget` 为节点展开预算（0 表示不限）。轨迹分数是各活跃 S 盒转移计数除 16 的精确有理数乘积（`math/big.Rat`）；等分时按各轮差分整数序列升序取最小者，`Ties` 记录等分轨迹数。预算耗尽时 `Optimal=false`，同时返回最佳已知轨迹 `Best` 与尚未排除的概率上界 `UpperBound`，两者未闭合不得称最优。
- `(*Cipher).CountDifferential(roundKeys, inDiff, outDiff)`：逐明文枚举 65536 个明文，对调用方指定轮密钥（每轮一个，轮首异或）统计真实差分计数与概率。
- `Analyze(c, req, roundKeys)`：搜索 + 复核一步完成，返回 `Report`；`Report.String()` 明确区分单条轨迹概率与多轨迹合并的真实概率。

```go
c, _ := netsec.NewCipher(sbox, perm, 4)
rep, _ := netsec.Analyze(c, netsec.SearchRequest{
    Starts:  []uint16{0x0001},
    Targets: []uint16{0x0001, 0x0100},
    Budget:  200000,
}, []uint16{0x1234, 0x5678, 0x9ABC, 0xDEF0})
fmt.Println(rep)
```

注意：单条轨迹概率只是多条轨迹合并后真实差分概率的一个组成部分（密钥平均意义下真实概率等于所有轨迹概率之和），不能把单轨迹分数当作真实概率；真实概率以逐明文枚举为准。

验证：`go test ./...` 覆盖恒等 S 盒、非线性双射（PRESENT S 盒）、不可达目标、小轮数暴力枚举对拍、预算耗尽上界有效性及 1 轮情形轨迹概率与真实概率精确相等。
