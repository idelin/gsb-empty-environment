# ambcheck — CFG 语法歧义检查器

给定**不含空产生式**的上下文无关文法和最大串长 N，寻找拥有两棵不同解析树的**最短串**；
同长度时按文法中终结符的声明顺序取字典序最小者。返回两棵解析树供独立验证。

## 用法

```sh
go run ./cmd/ambcheck grammar.json   # 或从 stdin 读取
```

```json
{
  "terminals": ["a", "+"],
  "nonterminals": ["E"],
  "start": "E",
  "rules": [{"lhs": "E", "rhs": ["E", "+", "E"]}, {"lhs": "E", "rhs": ["a"]}],
  "maxLength": 8,
  "budget": 1000000
}
```

库接口：`ambcheck.Check(g *Grammar, opts Options) (*Result, error)`，
正结果可用 `Result.Verify(g)` 独立复核（两棵树都合法、都派生出该串、且结构不同）。

## 算法

- 按串长 1..N 递增构造**共享解析森林**：`derived[A][L]` 记录非终结符 A 派生出的
  每个长度为 L 的串及其至多两棵结构不同的解析树（子树指针共享）。
- 非单元产生式按长度卷积展开（无空产生式 ⇒ 右部每个非终结符严格更短，子结果已就绪）；
  单元产生式（A -> B）在同一长度内做不动点传播，因此 `A -> A` 这类单位循环
  （同一串有无穷多棵树）也能正确处理。
- **去重按树的结构 canonical 形式**，而非构造路径：重复规则、不同切分点等产生的
  同一棵树只算一棵，不会误报歧义；重复规则本身也不构成歧义。
- 每个 `(非终结符, 串)` 只保留两棵不同的树即足以检测并重构歧义，保证森林有界。
- **预算**按已展开状态数（候选 `(非终结符, 串, 树)` 插入次数）控制；耗尽时返回
  `BudgetExceeded`，结论为"未知"而非"无歧义"。

## 测试

- 已知文法用例：表达式歧义、左/右递归、重复规则、单位循环、终结符次序平局等。
- 独立验证器：对返回的两棵树重新核对（合法派生、产出该串、结构互异），并测试篡改拒绝。
- 交叉核对：与刻意朴素的自顶向下穷举参考实现（无共享森林、无去重）在 14 个精选文法
  及 400 个随机小文法（注入左递归与重复规则）上逐一比对最短歧义串。
