支持乱序写入的时序库会把迟到样本落盘成时间区间与正常块重叠的乱序块（OOO Block），后台压缩必须同时合并重叠块、应用删除墓碑并把结果重新切齐到固定时间边界，才能保证后续块级剪枝正确。为时序存储压缩器交付可导入的 Go 合并包。输入一组持久化块（每块带单调递增块代号、时间半开区间 [minT,maxT) 和按序列标识分组的有序采样点 (t,v)）、一组针对指定序列的闭区间删除墓碑 [delMin,delMax]（各墓碑带生效块代号上界：仅删除代号不大于该上界的块中样本！）以及目标块对齐步长 B（目标块边界为 [k*B, (k+1)*B)）。规则：先按墓碑代号作用域精确过滤历史样本（新于墓碑代号的晚到重补样本必须保留！），再将所有存活样本按序列归并，同一序列同一时间戳出现多次时以块代号最大者胜出（同块内以最后出现者胜出），最后按对齐窗口 [k*B,(k+1)*B) 切分生成互不重叠的输出块（空窗口不生成块），并严格保持块内序列有序与样本时间戳严格递增。验收用全量样本时间点查询朴素参考模型对比压缩前后任意时间范围查询结果逐点一致，覆盖乱序块跨多个对齐窗口、墓碑只删旧块不删晚到新块、同时间戳新旧块覆写决胜，以及删除清空整个对齐窗口后不产出空块。
