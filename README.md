# gencache — 代际控制的并发缓存（纯标准库）

## 语义

- **代际控制写入**：每次加载启动时记录 `(keyGen, globalGen)` 快照；完成时仅当两代际均未变化才写入缓存。`Invalidate(key)` 推进键代际，`Clear()` 推进全局代际，因此失效后完成的旧加载**不会复活旧值**。
- **独立键不互相阻塞**：加载按键隔离，慢键不影响其他键；同键并发 `Get` 共享一次加载。
- **新加载无需等待**：`Invalidate`/`Clear` 使在途加载脱钩，新 `Get` 立即启动新加载，旧加载继续运行至结束但结果被丢弃。
- **等待者语义**：`Get` 调用者总是收到**它所加入的那一次加载**的结果（值与错误），无论该结果最终是否被缓存。
- **可注入**：数据源 `Loader`、时钟 `Clock`（TTL 判定）、失败处理 `OnError` 均为函数注入，不依赖远程缓存。
- **资源释放**：`Close()` 拒绝新请求并等待全部在途加载结束。

## 运行

```sh
go run ./cmd/demo        # 运行样例
go test -race -v ./...   # 运行测试
```
