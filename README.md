# blkdict — 分块前缀压缩的有序字符串词典

纯 Go 标准库实现。有序字符串按块做前缀压缩存储，支持随机取词（第 k 词）、
字节前缀区间查询、不可变段合并的批量更新与旧快照，块损坏一律报错而非静默错解。

## 编码布局（真实字节布局）

```
Segment := Block{1..N}                       // 块顺序拼接
Block   := magic        4B   0x424C4B31 ("BLK1")
           entryCount   2B   1..BlockSize(16)
           firstKeyLen  4B
           firstKey     ...  重启键，完整存储
           entry{2..n}  ...  与前一词的公共前缀压缩
           crc32        4B   IEEE，覆盖本块此前全部字节
entry   := prefixLen(uvarint) suffixLen(uvarint) suffix[suffixLen]
```

段内另有一张内存块偏移表（64 位下 8 B/块）。每块首词完整存储（重启点），
因此**任意块可独立定位与解码**，前缀重建绝不引用前一块的内容。

实测占用（`go run ./cmd/demo`）：20 个短词 138 B（含每块 14 B 头+CRC 开销）；
1 万条 `user:NNNNNN:profile` 由 190000 B 压到 124705 B（65.6%）。

## 关键设计

- **随机取词**：`Get(k)` 按 `k/16` 算术定位块，块内顺序解码 `k%16+1` 条；
  单次随机读取最多解码 `BlockSize` 条，由 `Stats.MaxDecodedPerRead` 统计。
- **前缀区间查询**：`PrefixRange(p)` 用重启键二分定位起始块，扫描
  `[p, successor(p))` 区间。前缀按**字节**匹配，允许切断 UTF-8 序列，
  但输出的永远是完整的已存字符串（合法 UTF-8 字符串的字节公共前缀
  必然落在字符边界上）。
- **损坏检测**：解码先校验 CRC-32；`prefixLen > 前词长度` 与越界的
  `suffixLen` 在**任何分配之前**拒绝（`CorruptError`），不会向后静默错解，
  也不会因前块损坏而连锁失败。
- **批量更新**：`ApplyBatch` 将排序后的批次与当前段归并（`mergeKeys`）
  为**新的不可变段**并原子切换视图；旧段被快照钉住期间继续可读。
- **快照与回收**：`Snapshot` 固定当前段；段的回收条件为
  「不在当前视图 **且** 无任何打开的快照引用」（引用计数归零），
  回收次数计入 `Stats.SegmentsReclaimed`。
- **重复词策略**：构建与单批内重复 → 报错拒绝；批次与既有词典重复 →
  幂等跳过（集合语义）。
- **空字符串**：允许，且可为首项（空串按字节序自然排最前）。

## 运行

```sh
go test ./...     # 全部测试（含独立字符串数组对照、损坏注入、快照/回收）

```
