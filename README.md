列存与检索索引使用 Roaring Bitmap 压缩 32 位无符号整数集合，每个 16 位高前缀桶在有序数组（Array，基数 ≤4096）、固定 65536 位图（Bitmap）和游程区间（Run，存 `(start, len-1)` 对）三种容器间动态切换；实现 `AND`、`OR`、`XOR`、`ANDNOT` 与 `RunOptimize` 时，9 种容器组合转换与空容器剔除的边界极易出错。为索引引擎交付可嵌入的 C++20 Roaring Bitmap 组件。完整支持三种内部容器的插入、范围批量写入 `[lo,hi]`（含 32 位全值域与 `UINT32_MAX` 防溢出）、删除、`RunOptimize`（严格按序列化字节比较：Run 占 `2 + 4*nRuns`，Array 占 `2*card`，Bitmap 占 `8192`，仅当 Run 严格更省时转 Run，否则按基数 ≤4096 选 Array、>4096 选 Bitmap）、全 9 种容器对的 `AND`/`OR`/`XOR`/`ANDNOT`、范围取反 `Flip(lo,hi)` 及精确 `Rank(x)`/`Select(k)` 查询。要求每次运算后严禁残留空容器、Run 容器内区间严格不相邻不重叠、Array 严格升序且 `card <= 4096`、Bitmap 严格 `card > 4096`。验收对照 `std::set<uint32_t>` 朴素参考实现执行全 9 种容器组合交叉运算与结构不变量校验，覆盖 Run+Run 跨满 65536 边界合并、Array 达 4096->4097 自动升格 Bitmap、`ANDNOT` 使 Bitmap 降格 Array 或清空移除桶、以及 `UINT32_MAX` 闭区间不溢出。
