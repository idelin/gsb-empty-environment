# rootiso — 整系数多项式在有理开区间上的精确实根隔离

精确计数**不同**实根并逐个隔离。全程使用 `math/big` 精确有理数运算；
固定精度（浮点）近似只作信息展示，**从不作为最终裁决**。

## 方法

1. **重根去重**：先算平方自由部分 `q = p / gcd(p, p')`（Q[x] 上的欧几里得
   算法），q 与 p 有完全相同的不同实根，且都是单根。
2. **精确计数**：对 q 构造 Sturm 序列。按"跳过零"的符号变号约定，
   `V(a) - V(b)` 精确等于 `(a, b]` 内不同实根个数（端点可以是根）。
   开区间计数 = `V(a) - V(b) - [q(b)==0]`。
3. **逐个隔离**：二分中点（始终是有理数），用 Sturm 计数决定根落在哪半，
   直到每个区间恰含一个根。若中点恰为根（有理根），作为**精确点根**单独
   报告，两侧继续隔离。
4. **端点是根**：查询区间端点 `lo`/`hi` 若是根，单独报告为精确点，不计入
   开区间。
5. **零多项式**：直接拒绝（每个实数都是根，无法计数）。

## 输出

- 每个隔离区间附带**符号变化证据**：平方自由部分在两端点的精确符号
  （必为一正一负，单根必穿越）。偶数重根在原多项式上没有符号变化，
  因此证据取自平方自由部分。
- 所有开区间两两不交；点根不落在任何隔离区间内。

## 用法

```sh
go run ./cmd/rootiso -c "-2,0,1" -i "0,2"      # x^2-2 在 (0,2)：隔离 √2
go run ./cmd/rootiso -c "-6,11,-6,1" -i "0,3"  # 端点 3 是根 → 单独报告
go run ./cmd/rootiso -c "-8,20,-10,-13,17,-7,1" -i "-3,3"  # (x-1)^2(x-2)^3(x+1) → 3 个不同根
go run ./cmd/rootiso -c "-1,0,1" -all          # Cauchy 界内全部实根
```

`-c` 为升幂整系数，`-i` 为有理端点 `lo,hi`（支持 `a/b` 形式）。

## 验证（go test ./...）

- 已知有理根乘积：`(x+2)(2x-1)(4x-3)(x-5)` 等，逐根验证被区间包含；
- 端点根单独报告（含两端都是根的 `x^2-1`）；
- 重根去重：`(x-1)^2(x-2)^3(x+1)` → 恰好 3 个不同根；
- 含无理根的低次例：`x^2-2`、`x^3-2`、`x^2-x-1`，用精确有理数比较
  （如 `lo^2 < 2 < hi^2`）验证区间确实夹住 √2、∛2、黄金比；
- 零多项式拒绝；`x^2+1` 无实根；
- **固定精度不能裁决**：根 `1/3` 与 `1/3 + 1e-25` 在 float64 下完全相等，
  精确算法仍分出两个不交区间。
