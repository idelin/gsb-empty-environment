# 可更正的重采样器

把不规则采样转换到固定时间网格，缺测段不会被一条直线掩盖：
显式断点与超过上限的缺测间隔都禁止跨越插值，迟到样本与撤回会产生修订。

## 语义规则

- **网格**：`origin + i * step`，内部用 `Fraction` 精确表示，输出时间永远是精确网格位置（支持负时间、非整数步长）。
- **step 模式**：右连续阶梯，取最近一个 `t <= 网格点` 的有效样本；样本值至多向后保持 `max_gap`，超出为未知（`gap`）。
- **linear 模式**：在左右相邻有效样本间线性插值；任一侧缺失为未知（`no_data`）；两侧间隔超过 `max_gap` 为未知（`gap`）。
- **显式断点**：断点把 timeline 切成 `[b_i, b_{i+1})` 段，左右样本不得跨段组合；被阻断的输出为未知（`breakpoint`）。样本精确命中网格点时不受断点/缺测限制。
- **同时间多样本**：按 `(version, id)` 裁决，大者生效；`version` 缺省按摄入顺序自增。被遮蔽的样本保留，撤回生效者后旧样本自动顶上（可更正）。
- **精度与舍入**：插值用有理数精确计算，输出固定 `ROUND_HALF_UP`（中点远离零）保留 6 位小数。

## 接口

```python
rs = Resampler(origin=0, step=1, count=7, mode="linear", max_gap=6, breakpoints=[...])
rev = rs.ingest([("a", 0, 0), ("b", 4, 8)])   # 摄入（可迟到、可同 id 更新）-> Revision
rev = rs.retract(["b"])                        # 撤回（未知 id 为 no-op）-> Revision
rs.query(start, end)                           # 查询 [start, end) 网格点
rs.grid()                                      # 完整网格
rs.seal(watermark)                             # 封闭水位线，返回被释放的样本 id
```

每个 `GridPoint` 携带：`t`（精确时间）、`value`、`valid`、`mode`、`source_ids`（所用原始采样 ID）、`reason`。
`Revision.changed` 是本次变化网格点的新状态；一个时间点的变更只影响其左右相邻有效样本之间的网格点，修订按此最小区间产出。

## 消费修订恢复完整网格

见 `consumer_example.py`：消费者用 `grid()` 引导一次快照，之后逐条应用 `Revision` 即可恢复完整网格（示例中校验了与重采样器逐点一致）。

## 历史样本保留与释放规则

- **保留**：所有样本（含被同时间新版本遮蔽者）在它们可能影响未封闭网格点期间都必须保留——撤回与迟到样本随时可能改写这些点。
- **封闭**：`seal(w)` 声明水位线后，`t < w` 的摄入/撤回被拒绝，对应网格点冻结、不再出现在修订中。
- **释放**：有效样本 `s` 的影响区间是 `(prev(s), next(s))`；当 `next(s) <= w` 时该区间整体封闭，`s` 及同时间被遮蔽的样本即可释放（`seal` 返回被释放 id）。`next(s) > w` 的样本必须保留——它仍是水位线之上网格点的左端点。
- 消费者侧对称地可以丢弃 `t < w` 的网格状态。
