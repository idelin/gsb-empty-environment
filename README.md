# mask_bool — 掩码布尔差运算与最优矩形分解

对整数网格（最大 12×12）上的 **保留矩形集 − 排除矩形集** 求差，
把结果掩码分解为 **不重叠矩形**，目标依次为：

1. **矩形数最少**（由穷举搜索证明，非启发式声称）；
2. 矩形数相同时取 **字典序最小**：矩形记为 `(t l b r)`（0 起始、闭区间），
   解按矩形排序后逐元素比较。

## 构建与使用

```sh
c++ -std=c++17 -O2 -o mask_bool mask_bool.cpp
./mask_bool [输入文件] [--max-nodes N]     # 无参数时读标准输入
```

输入格式（`#` 为注释）：

```
H W          # 行数 列数，均 ∈ [1,12]
K            # 保留矩形数
t l b r      # K 行，0 起始闭区间
E            # 排除矩形数
t l b r      # E 行
```

## 输出内容

- `MAP` / `LAYOUT`：目标掩码与分解方案图示；
- `SCANLINE`：行扫描线分解的矩形数，仅作上界参考，**明确标注不声称最优**；
- `LOWER_BOUND`：根节点下界（角格数、两两不兼容格集、面积商三者取大）；
- `SEARCH`：每个预算 K 的搜索记录（节点数、可行/已穷尽）——K 从根下界
  逐步递增，首个可行预算即最优，此前所有更小预算均被穷举证否，
  这就是最优性的搜索记录凭证；
- `OPTIMAL K`：经证明的最少矩形数；
- `VERIFY`：重建校验——输出矩形两两不相交、均在目标内、并集精确等于
  目标掩码；
- `LEX_PASS` / `LEX minimal`：在最少矩形数约束下按字典序分支，
  首个完整解即字典序最小；
- `SEARCH_STATS`：总节点数、置换表命中等统计。

## 方法要点

- **完备分支**：剩余掩码中按行主序最靠前的空格，必为覆盖它的矩形的
  左上角，故只需枚举以该格为左上角且完全落入剩余掩码的矩形。
- **下界**：①角格（上、左均无同伴的格）各自需要独立矩形；②两两
  "不兼容"（外接框不全在目标内）的格集——相对完整目标预计算兼容表，
  对任意剩余子掩码依然有效，贪心取集；③ceil(格数/可放入最大矩形面积)。
- **置换表**：记录每个掩码已被证否的最大预算，跨迭代加深与各阶段复用。
- **两阶段**：阶段一按面积降序分支求最少矩形数 K；阶段二在预算 K 下
  按 `(b,r)` 升序分支，首次得到的解即字典序最小。
