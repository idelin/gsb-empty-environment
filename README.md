软件制品安全准入网关离线验证 Sigstore Bundle（无密钥短周期 Fulcio 证书 + Rekor 透明日志证明）时，若仅校验制品签名而不核对 Merkle 树包含证明（Inclusion Proof）、检查点签名（Signed Checkpoint）以及 `integratedTime` 是否严格落在短周期证书 `[NotBefore, NotAfter]` 窗口内，攻击者可伪造历史时间戳或用已过期泄漏的短期证书签发恶意镜像。为 Go 供应链安全宿主实现可导入的 Sigstore 离线验签与透明日志包含证明核验包，严禁联网与严禁调用外部 Sigstore SDK（仅用 Go 标准库密码原语）。组件解析离线 Bundle（含制品 SHA-256 摘要、制品 ECDSA 签名、叶证书与中间证书链、Rekor 日志条目原文、`integratedTime`、RFC 6962 Merkle Inclusion Proof 哈希路径、Signed Checkpoint 与可选 SET），执行全链路离线验证：（1）核验叶证书链接至可信 Fulcio 根 CA，提取 OIDC 签发者（OID `1.3.6.1.4.1.57264.1.1`/`1.8`）与主体 SAN（Email/URI），精确匹配调用方策略白名单且拒绝缺少 `CodeSigning` EKU 的证书；（2）按 RFC 6962 规范计算叶哈希 `SHA-256(0x00 || canonicalEntryBytes)` 与内部节点哈希 `SHA-256(0x01 || left || right)`，沿 `logIndex`/`treeSize` 逐层重建 Merkle 根并核对与已验签 Checkpoint 根哈希完全一致（拒绝非法 `logIndex >= treeSize`、路径长度不符或多余节点）；（3）从日志条目中核对绑定的制品摘要与签名与当前待验制品完全一致，并以可信日志时间 `integratedTime`（而非本机当前时间或不可信声明时间）严格校验 `cert.NotBefore <= integratedTime <= cert.NotAfter`。附真实 ECDSA 构造的合法离线 Bundle 与伪造 Merkle 路径、超窗时间戳、OIDC 发行者不匹配与日志制品摘要调包攻击样本实测全拒收。
