# 临时凭据缓存跨租户复用

凭据代理缓存外部STS结果时只按role名命中，两个租户可能拿到同一临时凭据。给Go代理宿主实现可导入的凭据缓存包：缓存身份由租户ID、精确角色ID、权限策略摘要、会话标签规范摘要、外部身份ID、受众和凭据提供者配置代次组成，全部用固定标签及大端长度编码后SHA256；过期时刻不晚于STS返回时间，缓存仅使用到过期前的宿主安全余量。并发同身份请求合并为一个刷新，但每个等待者独立取消；取消最后等待者可取消回调，迟到结果仍须重新核对身份。STS结果含accessKeyID、secret句柄、sessionToken、roleID、tenantID、audience、标签摘要、签发与过期时间，且签发不晚于当前时钟加偏差、过期晚于签发，任何字段不符销毁secret句柄且不缓存。配置换代、撤销role或策略收紧立即使旧项不可新借出；已借出句柄有租约，归还后清零，不能在租约中途换绑身份。实现一个待审cacheKey回调的差分碰撞搜索，从每字段两候选中找弱键相同而规范身份不同且跨租户或权限摘要不同的最短例。用可观察STS和secret句柄测试同role异租户、标签顺序、策略变更、并发取消、失败刷新及accessKeyID相同但secret不同。
