# 共享清理子程序里的伪造返回令牌

旧字节码的共享清理子程序用局部槽保存返回位置，恶意代码可能把别处的返回位置搬来劫持控制流。给Go加载宿主实现上下文敏感验证包，指令数组支持jsr(目标)、ret(槽)、store/loadReturn(槽)、pushInt、store/loadInt(槽)、pop、goto、非确定分支和return，槽数及栈深均不超过32。jsr把仅属于本次调用、值为下一指令位置的返回令牌压栈并进入子程序，ret读取的令牌必须属于当前最内层调用，返回后其所有别名失效；整数与返回令牌不可转换，加载失效令牌拒绝。子程序可共享且可嵌套至4层，活动调用中再次进入同一子程序视为递归并拒绝；方法return时活动调用栈和操作数栈必须为空。按调用点栈区分分析上下文，不能把两个调用方的返回位置并成任意可跳目标；合流时局部槽不相容变不可用，栈不相容拒绝。允许普通控制流环，预算耗尽给未知而非可加载结论。用同一清理段的两个合法调用方、外层令牌被内层ret使用、ret后旧别名及循环再次调用验证，输出拒绝前的调用点链。
