# .NET类型名绑定递归判定

遗留 .NET 序列化入口用 SerializationBinder 把程序集限定类型名映射成类型，攻击者借泛型实参、数组后缀和嵌套类型把受限类型夹带进允许的泛型容器。为TypeScript网关实现供反序列化前调用的类型名绑定判定包：解析形如 Ns.List`1[[Ns.A, Asm, Version=1.0.0.0, PublicKeyToken=abc]] 的名称、数组后缀 [] 与 [,]、嵌套类型的 + 以及程序集名，递归检查每个泛型实参与元素类型；仅当完整类型、程序集名、版本和公钥标记都在调用方白名单内才放行，括号未闭合或嵌套超深拒绝。用夹带受限实参、数组元素类型、版本不符和合法嵌套泛型验证。
