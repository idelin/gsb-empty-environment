# unarc — 自定义安全归档解包工具

## 用法

```sh
unarc pack <dir> <archive>     # 把目录打成归档（目录/文件/符号链接）
unarc unpack <archive> <root>  # 解包到 root（root 必须不存在）
```

## 归档格式（小端）

```
8 字节魔数 "UNARC001"
随后是条目流直到 EOF：
  u8  类型：'D' 目录 / 'F' 文件 / 'S' 符号链接 / 'H' 硬链接
  u16 路径长度 + 路径字节（斜杠分隔、相对路径）
  'F'     : u32 权限 + u64 大小 + 数据
  'S'/'H' : u16 目标长度 + 目标字节
```

## 安全模型

解包分两阶段：先在内存中的虚拟文件系统上按序验证全部条目（不触盘），
再落地到与目标根同前缀的临时目录（`.<name>.tmp-*`，同父目录保证
`rename` 原子性），成功后原子就位；任何失败清理本次临时项。

验证规则：

- 只接受相对路径：拒绝绝对路径、`..` 越界、空路径与 NUL。
- 同一解析路径的类型冲突（如先目录后文件）拒绝；同类型重复允许（覆盖/合并）。
- 符号链接目标不得为绝对路径、不得文本越界；后续条目穿越符号链接时
  在根内解析，越界即拒绝，链接环（a↔b、自环）由展开上限检测。
- 硬链接目标必须解析到**此前已验证**的归档内部普通文件；
  引用不存在的、尚未声明的、目录或越界目标一律拒绝。
