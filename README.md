# 会话句柄跨登录状态可用

硬件安全模块的会话在用户登出后仍可用，攻击者复用句柄调用私钥操作。请实现供C++20密钥设备中间件调用的可导入会话生命周期组件。会话绑定应用、用户、登录状态与代次，登出、超时与设备重置使句柄失效；对象句柄按会话隔离，跨会话使用拒绝。并发与权限逐调用校验。用登出后复用、跨应用句柄、超时、合法调用和重置验证句柄不越会话。

## 组件说明

`netsec::SessionManager`（`netsec.hpp`）为可导入的会话生命周期组件：

- 会话句柄绑定应用、用户、登录状态与设备代次；登出、空闲超时、`reset()` 设备重置均使句柄失效。
- 对象（密钥）句柄按会话隔离，跨会话、跨应用使用返回 `cross_session_object` / `cross_application`。
- 私钥操作（sign/decrypt/derive）逐调用校验登录态；所有校验在互斥锁内完成，支持并发调用。
- 超时判定基于可注入时钟（构造函数 `NowFn`），便于确定性测试。

## 构建与测试

```sh
cmake -S . -B build -DCMAKE_CXX_STANDARD=20
cmake --build build
ctest --test-dir build --output-on-failure
```

测试覆盖：登出后复用、跨应用句柄、跨会话对象、超时、未登录权限、合法调用、设备重置与多线程并发。
