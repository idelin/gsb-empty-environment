# BLS聚合公钥注册与持有证明

委员会用 BLS 聚合签名证明多数同意，攻击者注册一个由他人公钥推导出来的恶意公钥，就能单独伪造出看似所有人都签过的聚合签名。给Go共识节点实现可导入的验证者注册与聚合验证包，配对运算与哈希到曲线由调用方注入：注册公钥必须附带持有证明，即对自己的公钥字节签名，使用与普通签名不同的域分隔标签（持有证明标签与签名标签不得相同）；未通过持有证明的公钥不得进入验证者集合，同一公钥重复注册忽略；同一消息的聚合签名验证中，聚合公钥只由集合内且位图选中的公钥相加得到，位图长度须等于集合大小，选中数低于阈值拒绝；对不同消息的聚合，消息两两不同才接受，有重复消息时拒绝；公钥为无穷远点时拒绝。用无持有证明的恶意公钥、两种标签相同、位图长度不符、重复消息和阈值不足验证。
