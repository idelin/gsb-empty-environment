支持数组与 JSONB 检索的通用倒排索引（GIN）为避免每次单行写入触发多键随机 I/O，先把新写入的 `(key, tid)` 批量追加到快速更新待插列表（Fast-Update Pending List），再由后台合并到主索引的 Entry Tree 与 Posting List/Tree；查询执行器在合并待插表和主索引时，若遇到有损页级位图（Lossy Page Bitmap）或 `NOT`/空匹配键，必须按三态逻辑（`TRUE`/`FALSE`/`MAYBE`）精确判定是否可以跳过回表核验。为数据库索引层交付可导入的 Go GIN 索引与三态查询引擎。写入路径支持快速插入待插表、逻辑删除标记（防止旧 TID 复活）以及超过容量阈值时将待插表原子排空合并入主索引（当单键 Posting List 超阈值自动升级为有序 Posting Tree，去重并清除已删 TID）。查询路径支持由谓词键集合与自定义三态一致性函数（`AND`、`OR`、子集包含、带否定的复合表达式）驱动的扫描，同时融合主索引与尚未排空的待插表，并支持配置页级位图内存上限：当单次扫描缓存的精确 TID 数超限时自动将最密集堆页降级为有损页（仅保留页号），对该页返回 `recheck = true` 且在三态求值中将有损输入作为 `MAYBE` 传播（例如 `FALSE AND MAYBE => FALSE` 可直接剪枝，而 `TRUE AND MAYBE => MAYBE` 须标回表！）。验收覆盖待插表未排空与排空后任意时刻查询结果逐 TID 一致、同 TID 反复插删再插、Posting List 升级为 Posting Tree、有损降级下三态剪枝与精确回表标记校验。
