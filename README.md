# 聚合接口信任了客户端自带的前置身份头

Kubernetes聚合API服务器把`X-Remote-User`当已认证身份，而前置代理并未剥离客户端同名头，攻击者直接访问后端即可冒充任意用户。请实现供Go聚合API服务器调用的可导入请求身份组件。只有当请求来自配置的前置代理地址、携带mTLS客户端证书且证书SAN在前置代理信任列表时才接受身份头；头名、大小写、重复与值格式按单一规则解析，客户端请求中的同名头在进入后端前必须删除。身份绑定集群、代理实例、证书代次和请求审计ID，代理重连或证书轮换后旧连接失效。用直连后端伪造头、重复头、大小写变体、非信任代理证书、合法前置代理和证书轮换验证身份只能来自已验证代理。
