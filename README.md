# flowlb — 稳定流 ID 的加权等价路径分配 + 离散事件仿真

纯 Go 标准库实现，无任何第三方依赖，不发真实网络流量。

## 设计

- **分配算法**：加权 rendezvous hashing (HRW)。对每条流 `f` 与路径 `p` 计算
  `u = hash(f, p) ∈ (0,1)`，得分 `E = -ln(u) / weight`（指数竞赛），取最小者。
  数学性质保证 `P(f → p) = weight_p / Σweight`，容量权重显式生效。
- **稳定同路径**：分配是 `(flowID, 路径集合)` 的纯函数，同一条流的包永远走同一路径。
- **最小迁移**：
  - 删除路径：只有原本落在该路径上的流迁移，其余路径零迁移；
  - 新增路径：只从旧路径按比例"吸走"流，旧路径之间互不迁移；
  - 权重 0：不参与分配，不接新流。
- **哈希**：FNV-1a + murmur3 fmix64 终混（FNV 对短输入雪崩不足，需终混保证均匀）。
- **仿真**：整数 tick 离散事件模型。每 tick 两阶段：
  1. 各流按确定性速率产生包，经 Assigner 入对应路径的 FIFO 队列；
  2. 各链路按容量（权重导出，包/tick）出队发送。
  全程内存事件模型，无真实网络流量。

## 文件

- `assign.go` — 加权 HRW 分配、迁移统计、负载统计
- `sim.go` — 离散事件仿真器（包/队列/链路，整数 tick）
- `main.go` — 演示：初始分配、删路径、加路径、权重0、仿真负载
- `assign_test.go` / `sim_test.go` — `go test` 测试

## 运行

```sh
go run .     # 演示
go test ./... -v
```

## 运行样例（go run .）

```
== 初始分配 (权重 1:2:3:4) ==
  路径 p1   权重  1.0  流数  1055  占比  10.55% (期望  10.00%)
  路径 p2   权重  2.0  流数  1983  占比  19.83% (期望  20.00%)
  路径 p3   权重  3.0  流数  3051  占比  30.51% (期望  30.00%)
  路径 p4   权重  4.0  流数  3911  占比  39.11% (期望  40.00%)

== 删除路径 p2 ==
迁移流数 1983 / 10000，迁移比例 19.83% (p2 原占比 19.83%，其余路径 0 迁移)

== 新增路径 p5(权重2) ==
迁移流数 1951 / 10000，迁移比例 19.51% (p5 新占比 19.51%)
新增后分配:
  路径 p1   权重  1.0  流数  1046  占比  10.46% (期望  10.00%)
  路径 p3   权重  3.0  流数  3055  占比  30.55% (期望  30.00%)
  路径 p4   权重  4.0  流数  3948  占比  39.48% (期望  40.00%)
  路径 p5   权重  2.0  流数  1951  占比  19.51% (期望  20.00%)

== 加入权重0路径 p6 ==
p6 分到流数: 0（权重0不接新流）

== 离散事件仿真 (200 tick, 每流 1 包/tick) ==
  路径 p1   容量 1100 包/tick  发送 209200 包  负载占比  10.46%  峰值积压     0 包
  路径 p3   容量 3300 包/tick  发送 611000 包  负载占比  30.55%  峰值积压     0 包
  路径 p4   容量 4400 包/tick  发送 789600 包  负载占比  39.48%  峰值积压     0 包
  路径 p5   容量 2200 包/tick  发送 390200 包  负载占比  19.51%  峰值积压     0 包
  合计发送 2000000 包（无真实网络流量，纯内存事件模型）
```
