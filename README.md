# Topics观察者过滤与纪元隔离

Topics API 向调用方返回用户的兴趣话题，追踪方想借新嵌入的第三方脚本读到它从未观察过的话题，或靠反复调用剥离随机噪声。为TypeScript浏览器宿主写供 document.browsingTopics() 调用的话题返回包：每周纪元保存（话题, 观察过该话题的调用方集合）；调用方只能得到它在该纪元里对该话题观察过的结果；最近 3 个纪元各取一个话题，最多返回 3 个；每个（顶层站点, 调用方, 纪元）的随机话题与取舍由宿主种子确定，同一组合重复调用结果相同；纪元之间使用独立种子，同一调用方不得借此把不同纪元的随机结果关联起来；调用来自跨源 iframe 且无 browsing-topics 权限策略时返回空数组。用从未观察、重复调用、跨纪元、无权限 iframe 验证。
