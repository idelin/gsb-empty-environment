HTTP/2 连接的发送次序由流依赖树决定。给连接组件交付可嵌入的 TypeScript 调度组件。所有流初始依赖空闲根，权重 256；PRIORITY 帧可以改父节点、设权重并声明排他依赖，排他时原来挂在目标父节点下的流改挂到本流之下；流结束后其子节点上提到它的父节点，它的权重按子节点原权重比例分给这些子节点，取整多出的单位给编号小的子节点。调度器每次被调用返回下一个可发送的流：只有有数据且流窗口、连接窗口都允许的流参与，分配比例沿树自上而下按子节点权重占比传递。验收先核对树结构：给定帧序列后各流的父节点、权重与排他改挂结果逐项对照手算；再构造总计两百个块以上的待发数据，对照各流实际发送占比与朴素递归模型，误差不超过两个百分点；流窗口耗尽、收到窗口更新、流被重置都要在后续调度中生效。
