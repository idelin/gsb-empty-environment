系统安全运行时在允许加载带 C++ 异常处理的不可信 ELF 插件前，若未审计其 `.eh_frame` 中的 CIE/FDE 与 DWARF CFA（Canonical Frame Address）栈展开字节码（`DW_CFA_*` / `DW_OP_*`），攻击者可构造恶意 FDE 或 `DW_CFA_expression`/`DW_CFA_def_cfa_expression` 表达式，在抛出异常触发栈展开（Unwind）时劫持返回地址寄存器（RIP）或任意读写栈外内存实现 Weird Machine 控制流劫持（CFOP）。为 C++17 二进制安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 `.eh_frame` CIE/FDE 与 CFA 字节码安全验证库。库从原始字节流解析 CIE、FDE 与 ULEB128/SLEB128 编码的 `DW_CFA_*` 指令序列：（1）硬拒绝越界记录长度、CIE 指针循环或指向非 CIE、FDE 地址范围 `[pc_begin, pc_end)` 重叠或回绕、以及非法寄存器号；（2）完整模拟 CFA 状态机（覆盖 `DW_CFA_def_cfa`/`def_cfa_offset`/`def_cfa_register`/`offset`/`restore`/`remember_state`/`restore_state`/`advance_loc*`），硬拦截 `remember_state` 栈溢出或空栈 `restore_state`，并拒绝将返回地址寄存器（RA）规则设为非法任意表达式、常量或指向当前帧合法栈界之外的负/越界偏移；（3）对内嵌 DWARF 栈表达式（`DW_CFA_def_cfa_expression`/`DW_CFA_val_expression`）实施严格指令白名单与栈深度/步数上限验证：硬禁止 `DW_OP_deref*` 任意地址解引用与写操作，确保所有 CFA 计算均严格受限于当前帧栈区间。附正常 FDE 状态机样本与 `DW_OP_deref` 劫持 RA、重叠 FDE、空栈 `restore_state` 及畸形 LEB128 测试。
