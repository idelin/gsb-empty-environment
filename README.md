# 广告排期工具

离散时段广告排期求解器 (TypeScript): 在滚动频控与相邻品牌互斥约束下求收益最大的投放计划。

## 模型

- 最多 20 个离散时段, 每时段最多 5 个候选广告 (也可空放), 超限输入直接抛错。
- **滚动频控**: 每个用户组在任意连续 `windowSlots` 个时段内曝光不超过 `max` 次。
  窗口按时段序号滑动, 与日历日无关 —— 跨午夜窗口不清零。
- **相邻品牌互斥**: 相邻时段不得投同品牌, 也不得投配置为互斥的品牌对。
- 目标: 总收益最大。

## 算法

按时段递推的记忆化搜索 (DP)。状态 = `(当前时段, 最近 maxWindow-1 个时段的选择)`;
更早的历史不影响后续决策, 因此可安全记忆化。正确性由随机小规模用例与暴力枚举对照保证。

## 运行

```bash
node src/demo.ts          # 演示: 输出最优计划、各窗口计数、跨日窗口验证
node --test src/**/*.test.ts  # 测试 (需 Node >= 22.6 的类型擦除, 或先用 tsc 编译)
```

无依赖; 本仓库用 Node 23 直接运行 TypeScript。若装有 TypeScript, 也可 `tsc` 编译后运行。

## 文件

- `src/scheduler.ts` — 求解器 (`solve`)、窗口计数 (`countWindows`)、计划校验 (`verifyPlan`)
- `src/demo.ts` — 两天 12 时段演示, 打印各滚动窗口计数并验证跨日不清零
- `src/scheduler.test.ts` — DP 对暴力枚举、跨日窗口、品牌互斥、输入上限测试
