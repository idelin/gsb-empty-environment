# 统一列级泛化 k-匿名分组工具

给定带有限泛化层级的准标识符列，求**统一列级**泛化方案（每列一个层级，对全部行一致生效，
不允许逐行不同层级），使每个最终组合至少出现 `k` 次（默认 3），且**总泛化损失最小**。

## 规则

- 每列层级用「值 -> 父值」映射表示，不在键中的值视为根；第 0 级为原始值。
- 空值（`null`）独立处理：不随层级泛化，只与其他空值归为一组。
- 总泛化损失 = 各列 `(层级 / 列最大层级) × 该列非空单元数` 之和（同时报告原始层级总和）。
- 利用单调性判定无解：若所有列都泛化到最高层级仍有不足 `k` 人的分组（或总人数 < k），
  则明确报告无解及原因。
- 在可行方案中穷举所有层级组合，取总损失最小者（平局取原始层级总和更小者）。

## 输入格式（JSON）

```json
{
  "k": 3,
  "columns": [
    { "name": "age", "hierarchy": { "23": "20-24", "20-24": "20-29", "20-29": "*" } }
  ],
  "rows": [["23"], ["24"], [null]]
}
```

## 运行

```sh
# 本环境无 tsc，可直接运行手工转译的 JS 副本（与 anonymize.ts 逻辑一致）
node anonymize.js examples/sample.json
cat examples/sample.json | node anonymize.js

# 有 TypeScript 编译器时
tsc && node dist/anonymize.js examples/sample.json

# 测试
node tests.js
```

输出：每列选定的层级、各分组的泛化元组与人数（含行号）、总泛化损失；
无解时退出码为 1 并说明原因（人数不足 / 空值孤立分组等）。
