# dirstats

目录容量统计库：为目录树同时维护**逻辑字节**与**物理唯一块字节**两套统计，
正确处理硬链接与跨目录共享块，所有更新沿受影响的祖先链增量传播。

## 概念

- **逻辑字节**：子树内每个目录项的文件大小之和（硬链接按项重复计数）。
- **物理唯一块字节**：子树内可达的不同块（`BlockID`）大小之和，共享块只计一次。
- 每个目录维护 `refs map[BlockID]int64`（子树内引用计数），计数从 0 变正时
  累加物理字节，归零时释放。

## 操作

| 操作 | 说明 |
| --- | --- |
| `Dir.Mkdir` | 新建子目录 |
| `Dir.AddFile` | 新建文件（注册块，尺寸冲突原子失败） |
| `Dir.Link` | 为已有文件创建硬链接项 |
| `Dir.Move` | 移动/改名子树或文件；拒绝环状引用 |
| `Dir.Remove` | 删除项（目录则整棵子树） |
| `File.SetBlocks` | 更换文件块引用，沿全部硬链接项的祖先传播差量 |
| `Dir.Stats` | 读取增量维护的统计 |
| `Dir.Recompute` | 全树逐项重算（参考实现） |
| `Dir.Verify` | 逐目录比对增量统计与重算结果 |

## 不变式

- **原子性**：所有变更操作先完整校验（名称、冲突、环、块尺寸），校验失败
  不产生任何部分加减。
- **环拒绝**：将目录移入自身或其后代返回 `ErrCycle`，树保持不变。
- **空间释放**：块在子树内最后一个引用被移出或删除时，该子树的物理字节
  立即释放；仍被共享时不受影响。

## 测试

```sh
go test ./...
```

覆盖跨目录共享、同父改名、最后引用移出释放、环拒绝原子性、失败操作原子性，
并以确定性随机操作序列对每步结果做全树重算核对（`TestRandomizedAgainstRecompute`）。
