# stgrid — 时空网格哈希碰撞预警引擎

大规模动态实体近邻接触侦测引擎（Go，仅标准库）。空间划分为三维哈希网格，
时间以时隙（Time Slot）分片；根据每个实体的当前坐标与速度向量推演下一时隙的
外包胶囊体（Capsule），以摊还常数时间发现潜在碰撞航线，并在最小安全距离被
突破前精准输出预警信标（Beacon）与两机当前拓扑距离。

## 结构

- `vec3.go` — 三维向量运算
- `capsule.go` — 胶囊体扫掠体积、线段间距离、突破时间解析解（二次方程）
- `grid.go` — 时空哈希网格：(cellX, cellY, cellZ, slot) 键，胶囊 AABB 插入 ≤ 8 格
- `engine.go` — 预测引擎：宽相（网格候选对）+ 窄相（相对运动精确突破时间）
- `cmd/demo/main.go` — 500 单元运行样例
- `engine_test.go` — 单元测试与 500 单元验收测试

## 原理

1. 每个时隙内，实体从 p(t0) 匀速运动到 p(t1)，扫掠出半径为 MinSep/2 的胶囊体。
2. 胶囊的半径扩展 AABB 插入时空哈希网格；两胶囊相交必共享至少一格，故宽相不漏检。
3. 候选对用相对运动解析求解 |r + v·t|² = sep²，得到时隙内最早突破时刻。
4. 跨时隙取每对实体最早突破时刻；突破时间落入预警提前量（WarnLead）时输出信标。

## 运行

    go test ./... -v   # 测试（含 500 单元验收）
    go run ./cmd/demo  # 运行样例

## 验收场景

500 个空中交通单元：A 从原点以 50 m/s 飞行，B 从 1050 m 外以 50 m/s 对向飞行，
二者将在 t=10 s 时突破 50 m 最小安全距离；其余 498 个单元分布于疏朗点阵。
引擎在 t=0 即预测到 10 s 内的突破，并在碰撞前恰好 5 s（t=5 s）输出首个预警信标，
报告两机当前距离 550 m。

## 样例输出

    [BEACON t= 5.0s] A <-> B | current distance   550.0 m | breach of 50 m min-sep in  5.0 s | predicted closest approach   0.0 m

宽相效率：3 个候选对 vs 1,247,500 个暴力对（约 41 万倍缩减）。
