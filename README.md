# 曲线描边在尖角和短线段处出现突刺

曲线描边在尖角和短线段处出现突刺。给Go矢量渲染宿主编写描边轮廓包，输入分段三次贝塞尔、宽度、连接样式及端帽；按曲率与弦误差自适应划分，构造左右偏移轮廓，miter超过给定倍率切换bevel，圆接头按最大弦误差离散。零长段与反向折返有明确圆端处理，输出带方向的闭合轮廓。用直线、圆弧近似和尖角参考检查宽度误差与接头，不以增加固定采样数替代误差控制。

## 实现

包 `taskpkg`（见 `stroke.go`）暴露：

- `Point`、`Cubic`、`Path`：分段三次贝塞尔中心线，`Path.Closed` 控制闭合。
- `Options`：`Width`、`Join`（`JoinMiter`/`JoinBevel`/`JoinRound`）、`Cap`
  （`CapButt`/`CapRound`/`CapSquare`）、`MiterLimit`（SVG 斜接长度/描边宽度
  倍率，超限降级为 bevel）、`Tolerance`（最大弦误差）。
- `Stroke(Path, Options) ([]Contour, error)`：返回带方向的闭合轮廓，外轮廓
  顺时针、内轮廓逆时针（屏幕坐标，y 向下）。

### 误差控制（无固定采样数）

- `flatEnough` 同时检查控制点到弦的垂直距离（弦误差）、切线转角（曲率守卫，
  按容差对应弦所张角度限制）以及零导数尖点，递归 de Casteljau 二分直到满足。
- 圆接头与圆端帽由弧矢高公式 `r*(1-cos(a/2)) <= Tolerance` 反解每段最大圆心
  角，段数完全由容差推出；容差越紧顶点越多。

### 接头与退化处理

- 拐角顶点同时保留入边/出边切线；转角内侧恒为 bevel，外侧按 `Join` 处理，
  miter 全长超过 `MiterLimit*Width` 时切换 bevel。
- 反向折返（相邻切线夹角 ≥150°，含精确 180°）把折点复制为相邻两点，中心线
  切成两段并各自以圆端帽封口；递归上限处的精确尖点同样以反向切线对输出。
- 零长段不打断子路径链接；全零长路径退化为按容差离散的圆点，零宽返回空。

### 验证

`stroke_test.go` 用直线（精确半宽、butt/square 端帽）、四次贝塞尔圆弧近似
（径向带宽误差）、90°/30° 尖角（miter 几何、倍率边界、bevel、圆接头弧点）、
精确折返与尖点三次曲线（圆端、无突刺）、零长段及非法参数做参考检查，并断言
收紧容差会增加顶点、放宽则减少，而非依赖固定采样数。
