# Tor onion服务客户端授权描述符

v3 onion 服务可只允许持有授权密钥的客户端解开描述符，撤销客户端后新描述符不应再被其解密，攻击者借撤销前的密钥或小阶公钥可保持访问或探测授权人数。给Go onion 服务写供描述符生成调用的授权客户端包，X25519 与对称加密由调用方注入：授权文件格式为 descriptor:x25519:加五十二字符大写 Base32 公钥，格式错、重复、公钥使共享密钥全零的都跳过；每次生成描述符使用新的临时密钥与新的描述符 cookie，不得跨修订复用；授权项条数补足到 16 的整数倍，补的条目随机填充，且补足后总条数不暴露真实人数；撤销的客户端在下一份描述符里必须不在其中。用格式错、重复、小阶公钥、撤销后重新生成、补足边界验证。
