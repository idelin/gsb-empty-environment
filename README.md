# tempsched — 时区与日历排程的时间区间代数约束求解器

基于 **Allen 区间代数**（Allen's Interval Algebra）的时间关系约束网络求解器，
仅使用 Go 标准库。

## 功能

- **13 种 Allen 原子时态关系**：`Before`、`Meets`、`Overlaps`、`Starts`、
  `During`、`Finishes`、`Equal` 及其逆关系（`After`、`MetBy`、`OverlappedBy`、
  `StartedBy`、`Contains`、`FinishedBy`）。
- **组合表自动推导**：13×13 组合表不是硬编码的，而是由端点点代数
  （`<` / `=` / `>`）在初始化时推导生成，正确性可由测试验证。
- **传递闭包 / 路径一致性**（PC-2）：对约束网络反复执行
  `C[i][j] &= C[i][k] ∘ C[k][j]` 直至不动点，检测不相容性并推断出
  任意两个任务之间被收紧的时态关系。
- **数值时间窗**：将（传播后为原子关系的）时态约束转换为简单时态网络
  （STN），用 Floyd-Warshall 全源最短路计算每个任务的最早/最晚开始与
  结束时间，以及项目全局关键路径窗口。负环即不相容。
- **工期与截止日期**：任务工期区间 `[min, max]`、开始/结束不早于/不晚于
  某一天等绝对约束。

> 数值层按调度惯例将关系解释为非严格（`≤`）。

## 运行样例

```sh
go run ./cmd/example
```

输出：

```
=== 时态约束求解（Allen 区间代数 + STN）===
约束: A Before B;  B Overlaps C;  C 开始 ≤ 第 5 天
工期: A=2 天, B=4 天, C=3 天

传递闭包推断:
  A 与 C 的时态关系: Before

各任务可行时间窗 (单位: 天):
  任务 A: 开始 [0, 2]  结束 [2, 4]
  任务 B: 开始 [2, 4]  结束 [6, 8]
  任务 C: 开始 [3, 5]  结束 [6, 8]

任务 A 最迟结束时间: 第 4 天
项目全局关键路径窗口: [第 6 天, 第 8 天]
```

### 结果解读（验收场景）

约束：A 必须在 B 之前结束（`Before`），B 与 C 部分重叠（`Overlaps`），
C 必须在第 5 天前开始。

- 传递闭包推断出 **A Before C**（`Before ∘ Overlaps = Before`）。
- `Overlaps(B,C)` 蕴含 `eB ≤ eC`；由 `sC ≤ 5` 且 C 工期 3 天得 `eC ≤ 8`，
  故 `eB ≤ 8`，B 工期 4 天 ⇒ `sB ≤ 4`，于是 **A 的最迟结束时间为第 4 天**。
- 同理 `eC ≥ eB ≥ 6` 且 `eC = sC + 3` ⇒ C 最早第 3 天开始。
- 项目关键路径窗口为 **[第 6 天, 第 8 天]**（关键链 A → B → C）。

## 测试

```sh
go test ./...
```

测试覆盖：

- 组合表正确性（与已发表的 Allen 组合表抽查比对）；
- 路径一致性的传递闭包推断与环不相容检测；
- 验收场景端到端求解（A 最迟结束时间、各任务时间窗、项目关键路径窗口）；
- 截止日期导致的不相容检测、`Meets`/`Equal` 与工期区间。

## 代码结构

- `allen.go` — Allen 关系定义、组合表推导、约束网络与路径一致性。
- `stn.go` — 简单时态网络（Floyd-Warshall 全源最短路、负环检测）。
- `solver.go` — 高层 API：任务、工期、截止日期、关系约束 → 时间窗。
- `cmd/example/main.go` — 验收场景运行样例。
