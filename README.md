# offlinecli — 依赖混淆替代安装分析器

离线读取两个包源（`public` / `private`）的包版本与传递依赖区间，结合私有包名单，
按以下规则做确定性依赖解析，并找出**第一次能被依赖混淆替代的安装**：

- 每包全局单版本（整个依赖图中同一包只装一个版本）；
- 每个包优先选择能完成整图的最高版本，同版本优先私源；
- 包之间按包名字节序依次决策，失败时回溯并记录冲突链。

## 用法

```sh
go run . -input scenario.json          # 输出完整决策、混淆事件、高候选回退冲突链
go run . -input scenario.json -verify  # 附加小图穷举核验
go test ./...                          # 固定场景断言 + 300 组随机小图穷举对拍
```

## 输入格式（JSON）

```json
{
  "roots": { "pkg": ">=1.0.0" },
  "private_packages": ["internal-lib"],
  "sources": {
    "private": { "packages": { "pkg": { "1.0.0": { "deps": { "dep": ">=1.0.0 <2.0.0" } } } } },
    "public":  { "packages": { "pkg": { "9.9.9": { "deps": {} } } } }
  }
}
```

- `roots`：顶层安装需求，值为版本区间；
- 区间支持 `*` 与逗号/空格分隔的比较器（`=` `!=` `>` `>=` `<` `<=`），如 `">=1.0.0 <2.0.0"`；
- 版本号为点分数字（如 `1.2.0`），按数值序比较；
- `private_packages`：私有包名单，命中名单却从 `public` 解析出的包即判定为依赖混淆。

## 输出

1. **解析决策**：按包名字节序列出每个包的最终版本与来源，标记落入公源的私包；
2. **依赖混淆事件**：按决策序列出全部私包落入公源事件，首个即"第一次能被依赖混淆替代的安装"；
3. **高候选回退冲突链**：每个被否决的更高候选及其冲突链（约束来源、已定型版本、不可达依赖）。

## 核验

`-verify` 与测试中的穷举核验会枚举小包全集的所有装配（含"不安装"），
校验解析结果等于字典序最优有效装配，并逐条验证每个被回退的高候选
在既定前缀下确实不存在任何有效装配。
