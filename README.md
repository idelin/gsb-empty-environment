机密计算（SGX/SEV-SNP）Enclave 在处理不可信宿主机通过共享内存（OCALL/ECALL 缓冲区）传入的指针与嵌套结构体时，若边界检查未验证指针区间完全位于不可信外部地址空间（防止宿主传入指向 Enclave 内部私有内存的指针诱导越权读写），或在校验长度后未先深拷贝到 Enclave 私有内存就直接二次解引用，恶意宿主机可通过并发覆写发动双重读取（Double-Fetch TOCTOU）击穿内存安全。为 C++17 机密计算运行时宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 Enclave 边界校验、安全深拷贝与双重读取对抗验证库。库建模 Enclave 私有虚拟地址区间 `[encBase, encEnd)`、外部共享内存池及带类型/长度/嵌套指针描述的 ABI 结构，提供：（1）严格指针区间审计器：所有入参指针与嵌套指针及其字节跨度必须经防整数溢出加法检查后完全落于合法外部共享区且与 `[encBase, encEnd)` 零交集，输出缓冲区同样严禁覆盖 Enclave 私有区，同时校验变长结构体内部偏移不越界且无环引用；（2）单次快照安全封送（Marshal）引擎：对嵌套输入在边界处执行一次性原子字节拷贝至 Enclave 私有缓冲后再执行语义校验与业务处理，确保外部共享页的每个字节至多读取一次；（3）有界对抗模拟器：模拟恶意宿主线程在任意读取间隙篡改共享页字节，对比“未深拷贝直接校验使用”的易受攻击实现（必须稳定检出并复现越界/篡改违例）与本库安全封送实现（证明在任意并发篡改交错下始终满足 Enclave 私有内存零越权与逻辑一致性）。
