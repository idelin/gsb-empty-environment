# truncation-engine

按给定字形簇度量实现的多行文本截断引擎。节点树与字形度量全部由夹具注入,
核心计算不借浏览器布局引擎。TypeScript 源码由 Node.js(>=22.6)直接运行,
测试使用 Node 内置测试运行器。

## 能力

- **多行截断**:贪心折行,支持 `start` / `middle` / `end` 三种省略位置。
- **关键片段保留**:中间省略模式下关键片段强制保留;互相超容量时输出
  明确的 `key-fragment-over-capacity` 冲突(含各片段所需宽度与可用宽度)。
- **混合方向**:RTL run 视觉反转;RTL 原子左边缘命中逻辑 `end`;
  反向选择(`anchor > focus`)方向保留,复制始终得到逻辑序原文。
- **链接区间**:跨省略区的链接被分成多个可见片段,均指向同一原范围。
- **不可拆实体**:实体是单个原子,永不折半、永不从中间截断;
  emoji 组合簇(ZWJ 序列、国旗、肤色、组合记号)同样不可切开。
- **退化**:省略号本身超宽时输出 `ellipsis-too-wide` 退化并继续布局。
- **映射**:视觉坐标 -> 原文偏移(命中测试)、选区 -> 各行视觉矩形、
  复制选区、截断后仍返回完整可访问名称。
- **度量晚到**:版本化度量库只接受更新版本;晚到的旧测量(含异步竞态)
  一律拒绝,不覆盖新布局;接受后增量重排(宽度缓存按版本复用)。
- **最优性对照**:末行保留集在小规模(<=20 原子)时穷举 2^n 求最优
  (主目标:关键原子保留数;次目标:总保留数),大规模用贪心 + 交换改进,
  测试用穷举结果对照贪心与引擎输出。

## 结构

- `src/grapheme.ts` 字形簇切分(`Intl.Segmenter`,含内置回退规则)
- `src/flatten.ts` 节点树 -> 逻辑序原子 + 可访问名称
- `src/metrics.ts` 版本化字形度量库
- `src/layout.ts` 折行、省略、双向重排
- `src/optimal.ts` 保留集穷举 / 贪心求解
- `src/mapping.ts` 命中测试、选区、复制、链接片段
- `src/engine.ts` 引擎:增量重排与版本守卫
- `fixtures/` 节点树与多版本度量夹具
- `test/` Node 内置测试
- `samples/demo.ts` 运行样例

## 运行

```sh
npm test          # node --test 'test/*.test.ts'
npm run sample    # node samples/demo.ts
```
