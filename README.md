# idxkey — 全序索引键与保序编码

支持 `Null / Int(int64) / Double / String` 四类键的全序比较与 memcomparable 编码。

## 公开固定的类型顺序

```
Null (tag 0) < Int (tag 1) < Double (tag 2) < String (tag 3)
```

比较器与编码共同遵守该顺序,属于对外契约,不得更改。

## 语义约定

- 整数与浮点**不跨类型等价**:`Int(1) != Double(1.0)`,先按类型标签排序。
- 浮点 **NaN 全等**:任意 NaN 位模式(含负 NaN、任意 payload)互相等价,
  且排在 `+inf` 之后(编码为规范位 `0x7FF0000000000001`)。
- `+0.0` 与 `-0.0` 等价,编码相同。
- 编码保序:`memcmp(encode(a), encode(b))` 的符号与 `compare(a, b)` 一致。

## 编码格式

| 类型   | 格式                                                        |
|--------|-------------------------------------------------------------|
| 公共   | 1 字节类型标签(值即类型序)                                 |
| Int    | 符号位翻转后的 8 字节大端序                                  |
| Double | 规范化(NaN→规范 NaN,`-0`→`+0`)后做保序位变换,8 字节大端序 |
| String | `0x00`→`{0x00,0x01}` 转义,`{0x00,0x00}` 结尾,支持内嵌 NUL |

## 构建与验证

```sh
cmake -S . -B build && cmake --build build
./build/key_test   # 或 ctest --test-dir build
```

测试以 20 万个随机键三元组验证:比较器自反/反对称/传递性、
编码与比较器序一致、等价键(NaN 各形态、±0)编码相同。
