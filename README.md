# zerosum — 精确零和矩阵博弈求解器

用 Go 实现的二人零和矩阵博弈求解器。所有计算均基于 `math/big.Rat`
精确有理数运算：**不**使用任何浮点迭代或近似算法，返回的价值与混合
策略都是精确有理数，并附带任何第三方都可独立复核的最优性证书。

## 数学保证

对收益矩阵 `A`（行玩家收益），求解器输出 `(x, y, v)` 及证书：

- `x`、`y` 为合法混合策略：每个分量 `>= 0`，且分量之和**精确**等于 1；
- 行玩家保证下界 `Lower = min_j (xᵀA)_j >= v`——无论列玩家如何出牌
  （纯或混合），行玩家的期望收益至少为 `Lower`；
- 列玩家封顶上界 `Upper = max_i (Ay)_i <= v`——无论行玩家如何出牌，
  期望收益至多为 `Upper`。

由于恒有 `Lower <= Upper`，两界夹住 `v` 即迫使 `Lower = Upper = v`，
由极小极大定理即证得双方策略均为精确最优、`v` 为博弈值。任何人只需
`(A, x, y)` 即可重新计算这两个界，无需信任求解器本身。

## 实现

- `Game.Solve`：主求解器。先把矩阵平移为严格正（只平移博弈值，不改
  最优策略，因此全负收益矩阵同样适用），再用 **Bland 规则的精确有理
  单纯形法** 求解列玩家 LP；Bland 规则保证有限步终止，行玩家策略从
  最终单纯形表的对偶变量（松弛列的检验数）读出。返回值前会先用
  `Verify` 自检。
- `Game.EnumerateOptima`：小矩阵的独立复算器。依据 Shapley–Snow
  定理，任何矩阵博弈都存在支撑集构成方阵（kernel）的最优策略。枚举
  所有 `k×k` 子矩阵，精确求解对应的线性方程组，再对**整个**矩阵重新
  核验最优性条件。重复行/列、退化支撑、多重最优均被妥善处理；找到的
  所有不同最优策略都会去重后返回。复杂度随支撑规模组合增长，限
  `k <= 8`，适合小矩阵交叉验证。
- `Game.Verify`：独立核验器。检查分布合法性（非负、和精确为 1）并重
  算上下界，拒绝任何不夹着 `v` 的声明——包括被篡改的价值、非分布向
  量和次优策略。
- `Game.SaddlePoint` / `Game.ValueBounds`：纯策略鞍点检测与纯策略安
  全界。鞍点博弈自然对应 `1×1` 支撑，两个求解器都会返回纯策略解。

## 使用

```go
g, _ := zerosum.NewGameFromInts([][]int64{{-5, -2}, {-3, -4}})
sol := g.Solve()                 // 精确单纯形解
fmt.Println(sol.Value)           // -7/2
fmt.Println(sol.Cert)            // value=-7/2  row guarantees >= -7/2  column allows <= -7/2
all := g.EnumerateOptima()       // 小矩阵支持集枚举复算
cert, ok := g.Verify(sol.Row, sol.Col, sol.Value) // 独立核验
```

命令行：

```console
$ go run ./cmd/zgsolve -- '-5 -2; -3 -4'
exact value v = -7/2
row strategy x     = [ 1/4  3/4 ]
column strategy y  = [ 1/2  1/2 ]
certificate: value=-7/2  row guarantees >= -7/2  column allows <= -7/2
```

矩阵按行输入，行之间用 `;` 分隔，元素可为整数或分数（如 `3/4`）。
`-enumerate` 额外列出支持集枚举找到的全部不同最优解。

## 测试

```console
$ go test ./...
```

测试覆盖：纯策略鞍点、猜硬币/石头剪刀布（完全混合）、全负收益
（含负值鞍点与负的分数博弈值）、重复行列、多重最优策略、非方阵、
被支配列、伪造证书拒绝、以及 60 组随机小矩阵上两种求解器结果逐位
一致且均可核验。
