# JNI临界区指针使用检测

JNI 的 GetPrimitiveArrayCritical 在虚拟机里给原生代码直接指针，临界区内不得调用其他 JNI 函数或阻塞，释放后指针不能再用；攻击者借超长输入让原生库越界写，或在临界区内阻塞垃圾回收。为 Go 宿主写供 JNI 调用跟踪订阅的临界区检测包：事件含线程、Get 与 Release 的数组标识和长度、其他 JNI 调用、阻塞调用，以及指针读写（地址与长度）；报告临界区内调用除 Release 与嵌套 Get...Critical 之外的 JNI 函数、阻塞调用、写入超出数组长度、释放后读写、同一数组重复释放、线程结束时未释放；Release 模式为 JNI_ABORT 时拷贝上的写入视为丢弃并提示。用临界区内 NewStringUTF、越界一字节、释放后使用、重复释放和合规写入验证。
