块设备模拟器在两次暂停时读到了部分扇区；单独看两份读数都合理，却可能找不到一条实际落盘次序能同时解释它们。请给模拟器提供可导入的 Go 判定包。输入初始扇区值和控制器在两次读数前已发出的整批写请求；每个请求由一个或多个明确列出的原子片段组成，片段一次把一组扇区同时改成指定值，同一请求内各片段可独立落盘。输入另给片段之间的先后边（包括由刷盘屏障产生的边），整体无环；除此之外没有隐含顺序，包括写同一扇区时。每个片段恰好落盘一次，两次暂停是同一全序上的两个前缀，允许相等。两份读数分别含扇区值和若干请求的持久化确认位，位为真当且仅当该请求的所有片段均已落盘；未观测的项不限。对另一个指定请求，返回它在两次暂停时已落盘片段数的全部可行数对，每个数对给出一条完整次序及两个切点；若没有可行解，从给定观测项中找出基数最少的矛盾子集，同基数任取，保留初态和顺序边不变。可枚举至多十八个片段的子集，不得枚举全部落盘排列；扇区最多八个，观测项总数最多十二个。交付接入模拟器的回放测试：对小例用独立的全排列算法核对集合与最小矛盾基数，并覆盖同值复写掩盖了不同末写者、原子片段跨扇区、两次各自可解但不共享次序，以及只有把三项观测合在一起才冲突的输入。
