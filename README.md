隔离端点时，同一文件映射可能同时由多个进程、后台请求及已发送但尚未领取的消息句柄持有。用Go写供端点防护宿主调用的撤回协调库。输入是抽象内核提供的带代次对象事件和各通道单调水位，水位之前的事件已完整。复制、转发与派生都产生新的有来源的持有权，关闭源句柄不撤回已发送的接收权。请求隔离某进程最初持有的指定映射范围，并保留同对象上无关授权。对水位不齐的快照只能将有证据的片段判为已撤回，必须给出未知范围和缺少哪个通道的进展；允许晚到但不跨水位的事件，重复与不同代次重用按身份判别。协调器支持中断恢复，同一外部撤回请求带幂等ID，成功回执绑定实际范围。用小型完整事件图解释器核验跨进程转交、待接收消息、仅部分字节有独立授权和水位错开时看似为空的扫描。
