推理引擎准备在同一分配区上并行执行一个读算子和一个写算子，只有两个视图实际覆盖的字节不相交才能放行。请提供执行器可导入的 Go 包。每个视图由起点、元素字节宽度和至多两个维度的长度及有符号字节步长描述，步长可负也可为零；零维表示标量，有长度零的维度表示空视图。先求每个非空视图是否完整落在分配区 [0,N) 内，然后精确判定两者相交性；相交时返回最低共享字节，以及两侧各自覆盖它的字典序最小下标。起点、步长为 int64，N 和各维长度为 uint64，元素宽度为 1 至 64。每个视图至多一个维度的长度大于 16，其余短维可展开；计算不得枚举长维或按 N 分配空间。用小视图逐字节穷举作独立测试，覆盖包围区间相交但字节集合不相交、元素头不相交但尾部别名、负步长反转最小下标、广播导致同一字节有许多见证，以及乘法中间值越过 int64 的无效视图。交付调度器的放行与拒绝调用示例。
