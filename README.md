# SMB3加密协商降级拒绝

要求加密的共享里，攻击者在协商阶段篡改方言列表或加密算法列表，把会话压到不加密的 SMB 2.1 或不含加密的配置。为Go的 SMB 服务端写可导入的协商判定包：SMB 3.1.1 下服务端通过协商上下文挑选加密算法，客户端所报算法与服务端偏好无交集则拒绝；共享或服务器要求加密时，方言低于 3.0、没有可用算法、TREE_CONNECT 之后出现未加密请求一律拒绝并断开；服务端自行累计预认证完整性哈希（初始 64 个零字节，H = SHA-512(H ‖ 报文字节)，覆盖协商请求与响应），会话建立消息的签名由调用方注入的函数用该哈希验证，失败即断开；协商完成后再收到 NEGOTIATE 立即断开。测降级方言、算法列表篡改、哈希不符、未加密请求。
