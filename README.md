# EtherCAT邮箱帧长度与文件名

EtherCAT 主站收到从站邮箱数据时，攻击者控制的从站可在 FoE 文件名、CoE 段传输或长度字段上做手脚。为C++主站写可导入的邮箱帧校验包，供邮箱读取回调调用：邮箱头 6 字节（长度 2、地址 2、通道与优先级 1、类型 4 位加计数器 3 位加保留 1 位）；头里的长度不得大于调用方给的邮箱同步管理器大小减 6，也不得大于实际收到字节数减 6；计数器取 1 到 7 循环，0 保留，与上一帧计数器相同视为重传丢弃，跳号只记录不拒绝；类型 3 为 CoE，4 为 FoE，只放行调用方登记的类型；FoE 写请求的文件名不得含 /、\、.. 段或字节 0；CoE 段传输的后续段 toggle 位必须交替。用长度字段过大、计数器 0、重传、FoE 路径穿越和 toggle 错误验证。
