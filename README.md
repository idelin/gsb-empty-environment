数据库驱动执行准备好的批导入时，服务端只能索取客户端已签授权中声明的数据片段。给Go导入宿主写可嵌入的许可编译库，所有输入均是内存中的计划、字节区间和回调。导入计划可嵌套并行、顺序、条件回退与二选一，叶子是带不可变对象身份、代次、有限范围和最大读取次数的一次性许可；每个选择必须由绑定本会话与计划摘要的已认证事件决定。客户端只见部分先后约束，服务端发来的请求有时与多个候选叶匹配或跨多个相邻区间拼接。只有在保留全部可能解释后，每一种合法执行都授权了本次同对象范围读取，才可向数据回调转发；提交后还须保留所有尚可成立的消费方式，并精确扣减所有相容分支的剩余配额，不能任取一个叶造成下次误拒或配额超发。返回允许、拒绝或等待哪个选择事件，取消的分支、过期会话与已耗尽配额分支永远不能再开读。用小计划全轨迹解释器核对两个相同许可的晚消歧、跨叶拼接读取、部分读取、跨会话重放和同时取消，配额用64位区间表示。
