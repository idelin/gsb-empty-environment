# reducer

约束感知的 delta 缩减器（ddmin），用于缩减整数操作序列。

## 操作编码

- `op > 0`：创建 id `op`
- `op < 0`：引用 id `-op`
- `op == 0`：中性操作

合法序列：任何引用之前必须存在同 id 的创建（创建先于引用）。
缩减器不会评估、更不会接受非法候选。

## 判定约定

`Predicate func(seq []int) Verdict` 返回三种判定：

- `Fail`：仍复现失败 —— 只有这种候选会被接受
- `Pass`：不再失败
- `Unknown`：不确定 —— 计入 `Stats` 并快照到 `UnknownSeqs`，绝不当作失败接受

## 终止保证

`Reduce` 先按 ddmin 分块删除（非法候选跳过不评估），再做单项删除
不动点扫描。最终结果满足 1-最小性：删除任一保持合法性的单项后，
判定都不再返回 `Fail`。输入本身不失败时原样返回。

## 测试

```sh
GO111MODULE=on go test ./...
```

测试通过植入故障验证：组合故障的最小性、创建先于引用约束的维持、
不确定判定的记录与拒收、以及非失败输入的透传。
