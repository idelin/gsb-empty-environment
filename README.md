# ilse — 整数线性方程求解器 (Go)

求解整数线性方程组 **A x = b**（x ∈ Zⁿ），支持矩形、秩亏、零行/零列矩阵，
全部运算使用 `math/big` 任意精度整数，消元不会溢出。

## 功能

- `Solve(A, b)` 返回两种结果之一：
  - `*Solution`：特解 `X0` 与齐次解格基 `B`（列向量），通解为 `x = X0 + B·z, z ∈ Z^(n-r)`；
    同时携带完整性证书：单模矩阵 `U`（det = ±1）满足 `A·U = [H | 0]`，
    `H` 列满秩，`X0 = U·[Y;0]`，`B = U[:, r:]`。
  - `*Infeasible`：不可解证据——有理行向量 `c`，使得 `c·A` 的整数张成
    为 `g·Z`（`g` 为 `c·A` 各分量的有理 gcd），而 `c·b ∉ g·Z`。
- `VerifySolution` / `VerifyInfeasible`：独立验证器。
  - 检查原方程 `A·X0 = b`、基向量齐次性 `A·B = 0`；
  - 通过证书核对生成格的**完整性**：`det U = ±1`、`A·U = [H|0]`、
    `rank(H) = r`，从而任何整数解 `x` 满足 `U⁻¹x ∈ Zⁿ` 且前 `r` 个分量
    被 `H·Y = b` 唯一确定，故 `x ∈ X0 + B·Z^(n-r)`，绝无遗漏；
  - 额外独立交叉核对：`B` 的所有最大阶子式的 gcd = 1（饱和纯子格，
    子式数有界时启用）。
- `Enumerate(A, b, bound, max)`：小系数矩阵的有界枚举，用于对照实验。
- `Solution.InLattice(x)`：格成员判定（利用 `U` 证书）。

## 算法

对 `A` 做列向 Hermite 约化：用扩展 gcd 的幺模列变换把 `A` 化为
`A·U = [H | 0]`（`U` 为累计的列变换矩阵，自动单模）。在 `H` 的主元行
构成的下三角块上回代求解 `H·Y = b`；任一处整除失败或剩余行不一致时，
从三角块的逆中直接读出不可解证书 `c`。

## 使用

```sh
go test ./...        # 随机测试：与有界枚举双向对照、大整数、边界情形
printf '2 3\n2 1 -1\n1 3 2\n8 -1\n' | go run ./cmd/ilse
```

输入格式：第一行 `m n`，随后 `m` 行矩阵，最后一行 `m` 个 `b` 分量。
