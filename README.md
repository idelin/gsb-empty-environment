# sched

单机精确排程库（Go）。一台设备处理至多 12 个订单，每个订单有类型、
加工时长和截止时间；相邻两个订单类型不同时按矩阵支付换型代价
（矩阵可不对称），设备初始类型给定。

## 模型

- 换型是**纯代价**，不占用设备时间；完工时间只由加工时长累加得到。
- 同型相邻（或首单与初始类型相同）不收费，矩阵对角线不参与计算。
- 目标按字典序：
  1. 最小化最大迟交量 `max(C_j - d_j)`（可以为负，表示全部提前）；
  2. 在此前提下最小化总换型代价；
  3. 仍有并列时取输入下标字典序最小的排程，结果确定。

## 用法

```go
orders := []sched.Order{
    {ID: "A", Type: 0, Duration: 3, Deadline: 5},
    {ID: "B", Type: 1, Duration: 2, Deadline: 4},
}
setup := [][]int{{0, 2}, {3, 0}} // setup[前型][后型]，可不对称
s := sched.Solve(orders, setup, 0 /* 初始类型 */)
fmt.Print(s) // 打印时间表
```

- `Solve` 返回最优 `Schedule`（含每单的开始/结束/迟交/换型）。
- `Evaluate` 可对任意给定排列按同一模型评估，便于核对。
- 复杂度 `O(2^n · n^2)`，精确求解，适合 `n ≤ 12`。

## 正确性核对

`solver_test.go` 用全排列暴力枚举作为独立参照，在大量小规模随机
算例（不对称换型矩阵、窄取值范围以制造并列）上逐一比对最优代价
与并列时的选序；另含针对不对称性、字典序并列、目标优先级、初始
类型计费和 12 单规模的专项测试。
