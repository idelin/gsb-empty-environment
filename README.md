ARM64 安全运行时启用指针认证（PAC）与分支目标识别（BTI）防御 ROP/JOP 攻击时，若二进制中存在同一上下文盐值（modifier）跨函数指针类型复用、裸 `PACIA`/`AUTIA` 签名预言机或缺少 `BTI c/j` 着陆垫的间接跳转目标，攻击者可借助签名预言机伪造任意函数指针并劫持控制流。为 C++17 二进制安全分析宿主实现可嵌入、零外部依赖、严格 `-Wall -Wextra -Wconversion -Werror` 通过的 ARM64 PAC/BTI 语义流与签名预言机验证库。输入为受限 ARM64 指令控制流图模型（含 `PACIA`/`PACIB`/`PACDA`/`PACDB`/`AUTIA`/`AUTIB`/`XPACI`/`BLRAA`/`BRAA`/`RETAA`/`BTI c`/`BTI j`/`BTI jc`、栈帧读写与条件分支，以及函数指针类型表与虚拟页 `GP` BTI 保护位）。分析器构建跨基本块符号抽象状态，精确追踪每个通用寄存器与栈槽携带的指针标签（未签名原始值、已签名指针及其密钥域 `IA/IB/DA/DB`、绑定 `modifier` 来源及指针类型、或认证失败后高位被置为非法错误码的“毒化指针”）：（1）检出任何认证失败后未触发故障却经 `XPACI` 剥离高位再次间接跳转的认证绕过路径；（2）检出攻击者可控输入进入 `PAC*` 且结果流向外部可观测槽位的签名预言机；（3）检出不同签名类型（如虚表回调与普通返回地址）共用相同 `(key, modifier)` 的跨类型替换冲突；（4）校验每条 `BR`/`BLR`/`BRAA`/`BLRAA` 间接跳转在 `GP=1` 页面上的全部可达目标均具有匹配类型的 `BTI` 着陆指令。附小控制流图穷举验证与签名预言机、`XPACI` 绕过、BTI 缺失反例测试。
