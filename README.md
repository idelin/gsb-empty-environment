浏览器离线合并企业预置规则、用户分区缓存和后来收到的 HTTPS 更新时，删除一条子域规则不能同时删除同名父规则的继承效果。给 TypeScript 网络栈提供可导入的 HSTS 策略库。记录绑定 DNS 标签序列、签发主体、网络分区、是否覆盖子域、单调事件 ID 和绝对到期时间；同一规则的删除只撤销它明确观察到的版本。可信网络时间可能是闭区间并集，对一个请求须区分在所有可能时间都要升级、都不用升级、以及证据不足。跨层来源优先级由宿主明确指定，企业禁止豁免的规则不得被用户例外减弱。离线设备用签名的范围摘要同步，摘要说明一个域子树在某前缀处已完整，不包括其他分区；旧设备晚到的 add 不能复活已确认删除版本。支持导出受影响的最小域子树集合与决定依据，能对未枚举长子域查询；恢复检查点必须绑定后缀规则和分区代次。用小域名树与全事件回放对照删除同名条目、父策略到期先后、设备重装导致同名分区重用和观察时间横跨到期。
