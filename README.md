# peritext — 富文本格式标注区间 CRDT（Go 实现）

Peritext/Fugue 风格的富文本重叠格式标注（粗体、斜体、下划线、超链接等）合并器，
仅使用 Go 标准库。

## 设计要点

- **字符序列（Fugue 风格）**：每个字符有全局唯一 ID `(Actor, Seq)`；插入操作
  携带左右邻居（left/right origin），同一位置的并发插入按
  `(rightOrigin, ID)` 全序确定性归并，所有副本收敛到同一文本。
- **格式标注（Mark）**：`{key, value, start, end}`，区间边界**锚定到字符 ID**
  而非下标，并发插入不会使标注错位或断裂。取消格式即写入 `value="false"`
  的标注，与“设置”标注共同参与冲突判定。
- **边界展开（Peritext 默认规则）**：
  - 起点锚定到首字符左边界：在区间起点处插入的文本**不**进入区间；
  - 终点锚定到末字符右边界：只有在因果上**晚于该标注**、且在终点边界处
    追加的文本才进入区间（通过字符的 Lamport 时间与标注时间比较判定），
    标注创建前已存在的右侧文本不会被误吞。
- **冲突判定**：同一 key 的多条标注逐字符按 `(Lamport, Actor)` 取最大者
  生效（LWW）：
  - 因果在后的操作必然胜出（B 看到 A 的加粗后再取消 ⇒ 取消生效）；
  - 并发冲突（A 加粗、B 同时取消）按确定性规则裁决，所有副本结果一致。

## 运行

```sh
go test ./...     # 运行测试
go run ./cmd/demo # 运行演示
```

## 验收边界

文字 `ABC`：用户1 给 `AB` 加粗，用户2 并发给 `BC` 加下划线。
合并后：`A` 加粗、`B` 加粗+下划线、`C` 仅下划线，无格式断裂。
见 `TestOverlappingBoldUnderline`。

## 文件

- `doc.go` — 字符序列 CRDT（Fugue 风格插入、归并、副本合并）
- `mark.go` — 格式标注（锚点、边界展开、LWW 冲突判定）
- `doc_test.go` — 测试（验收边界、因果/并发冲突、边界展开、合并性质）
- `cmd/demo/main.go` — 可运行演示
