DDS 桥接器把域 A 的主题转到域 B，并可按固定前缀改写主题名。参与者在各域各有签名许可证，逐跳检查都通过时，最终订阅者仍未必有权接收原始数据。给 Go 路由宿主写可导入的跨域授权组件。数据标签包含原始域、原始主题和所属分区，经过桥接不可丢失；每一跳必须同时满足发送者在本域的发布规则、接收者在目标域的订阅规则和原始数据许可中的转发限制。规则按声明顺序首个匹配决定，主题和分区的模式分别支持字面段、单段通配和任意多段通配。前缀改写只可替换首段，桥接图可以有环。不能仅在实际出现过的主题上试跑：路由配置注册前要按完整主题语言证明，所有可终止的转发路径都不会把原始数据交给未授权订阅者；不可达路径不应导致误拒。输出按规则编号与域归类的覆盖证书，独立函数验证每条转移的标签和模式边界；不输出可用于发送流量的指令。以两三个域的小字母表穷举校验重命名后匹配另一个许可证、环、优先 deny、空分区与多段通配。
