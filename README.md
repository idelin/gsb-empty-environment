# tagcache

纯标准库实现的内存标签版本化缓存（无远程缓存依赖）。

- 条目可关联多个标签，同一标签去重，同条目多标签只计费一次
- `InvalidateTag` 提升标签代际并驱逐相关条目（连带清理其他标签下的反向关系）
- `DeleteTag` 只摘除该标签关系，不误删条目的其他标签关系
- `Delete` 删除条目并清理反向索引，空索引集合即时释放（`Stats` 可验证）
- 加载前后做代际快照校验：加载中标签变化则丢弃重试，超限经注入的
  `FailureHandler` 上报，绝不留下旧有效条目
- 数据源 `Source`、时钟 `Clock`、失败处理 `OnFailure` 全部可注入

## 运行

```sh
go test -race ./...
go run ./cmd/demo
```
