# 三节点投票选主协议 · 有界状态枚举模型检查器

用 TypeScript 实现的显式状态模型检查器，验证类 Raft 投票子协议的核心安全性质：

> **同一任期不可能出现两个获得多数派的领导者。**

## 协议模型

- 3 个节点，多数派 = 2。每张选票/每条消息都携带任期。
- 每节点每任期最多投一票（`votedTerm` 记录；`--buggy` 模式故意放开此约束以演示反例）。
- 节点超时时任期 +1、转为候选人、自投一票并向其余节点拉票；候选人收齐多数派选票即当选。
- 收到更高任期的消息时让位为 follower 并清空投票记录。

## 网络语义

- 在途消息是无序多重集合：天然覆盖**延迟**与**重排**；每条消息可随时被**丢弃**。
- 容量上限 `--net-cap N`（默认 3）约束在途消息数；网络满时新消息直接丢失。
- 惰性消息（投递必为空操作：过期任期，或回执送达非候选人）视为被网络立即回收，
  容量按仍在途的有效消息计。该归一只会让网络对手更强，证明结论对原始语义依然成立。

## 三种互斥结论

| 结论 | 含义 |
| --- | --- |
| `COUNTEREXAMPLE` | 发现违反性质的状态；BFS 保证输出**最短**反例轨迹，逐步打印动作与状态 |
| `PROOF` | 商状态空间已穷尽且未触及任何截断界 ⇒ 对**任意步数、任意任期**的执行均成立（见下） |
| `BOUNDED` | 因 `--max-steps` / `--max-states` 截断而停止，仅说明界内未发现反例，**不构成证明** |

## 为什么状态穷尽 = 无限执行证明

任期是无界整数，但协议中任期只参与三种操作：**比较（< / =）、复制、+1**。
`src/canon.ts` 把具体任期替换为**截断间距编码**（排序后相邻值的间距截断为 2，
即只区分“相邻”与“有间隔”），可以证明该编码与转移关系可交换（精确互模拟）：

- 编码保序 ⇒ 所有比较守卫结果不变；
- 对 `t+1`：无论下一个不同值与 t 相邻还是有间隔，重编码后结果唯一确定；
- 复制显然可交换。

商状态空间有限（不同任期值的数量受节点数与在途消息数约束），BFS 穷尽即饱和；
商图中无反例 ⇔ 任意具体执行（任意任期取值、任意长度）中都无反例。

## 用法

需要 Node ≥ 23.6（或 ≥ 22.6 加 `--experimental-strip-types`），直接运行 TypeScript，无需构建。

```bash
node src/main.ts                  # 验证正确协议 → PROOF
node src/main.ts --buggy          # 注入“同任期可重复投票”故障 → 最短反例
node src/main.ts --max-steps 4    # 截断探索 → BOUNDED（非证明）
node src/main.ts --net-cap 4      # 加大网络容量（状态空间增长很快）
npm test                          # 运行测试
```

参考规模（正确协议）：net-cap 2 ≈ 2.6 万状态 / 1s；net-cap 3 ≈ 19.8 万状态 / 8s；
net-cap 4 ≈ 125 万状态 / 2min。

## 文件结构

- `src/model.ts` — 协议状态与转移规则（超时 / 投递 / 丢弃）、安全性质判定
- `src/canon.ts` — 状态规范化：截断间距编码、字段归一、惰性消息回收、紧凑序列化
- `src/checker.ts` — BFS 有界枚举器：最短反例轨迹重建、三种结论
- `src/main.ts` — CLI 入口与输出格式化
- `test/checker.test.ts` — 覆盖三种结论路径与反例轨迹的逐步合法性
