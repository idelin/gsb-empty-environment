进程内的即时编译器允许先写代码再执行，但多个逻辑映射可能指向同一物理页。用Go给内存宿主写可导入的权限验收器。映射按对象代次和半开偏移区间描述，支持共享、写时复制、分段重映射与别名。CPU可短暂保留旧的执行或写入权限，撤销确认按CPU和映射代次到达。安全条件为同一物理字节不能同时被任何有效视图写入和执行；即使每个单独视图都满足W或X也须检查别名。调用方提交无全局顺序的批次和依赖边，验收器在所有允许的交错中证明阶段提交安全，或给出最短失败前缀及首个物理冲突区间。写时复制只分离真正写入的页，回执丢失不能释放旧权限。支持64位范围，预算不足返回未知。用小页表的逐字节枚举核对同一时刻的延迟确认、局部分离、别名撤销后重建和物理地址复用。
