边缘网关将 HTTP/2 流量降级转发至 HTTP/1.1 后端时，若 HPACK 解码器未严格校验伪头顺序与动态表大小更新时机，或降级器把含 `\r\n`、NUL、非法 `Transfer-Encoding` 或矛盾 `Content-Length` 的头域直接拼接进后端报文，攻击者可在单条流中走私隐藏请求污染其他用户响应。为 Go 反向代理宿主构建可导入的原始字节级 HTTP/2 帧解析与 H2->H1 降级走私防御包，严禁依赖标准库 `http2` 解析帧与 HPACK。组件从原始二进制帧流完整解码帧头、流状态机（含 `HEADERS`/`CONTINUATION` 连续性强制约束，禁止中间插入其他流帧）、RFC 7541 HPACK 静态/动态表与规范 Huffman 解码（严格拒绝非 EOS 填充、超过 7 位填充、动态表大小更新出现在首个索引/字面头之后或超过 `SETTINGS_HEADER_TABLE_SIZE`）。安全语义校验覆盖：拒绝大写头名、伪头出现在普通头之后、重复或缺失 `:method`/`:scheme`/`:path`、含连接级头（`Connection`/`Keep-Alive`/`Proxy-Connection`/`Upgrade`）或非 `trailers` 的 `TE`、头名或值含 CR/LF/NUL、多值不等的 `Content-Length` 以及实际 `DATA` 帧总字节数与 `Content-Length` 不符（含 `END_STREAM` 提前截断或尾部超发）。另提供面向待审弱降级器的对抗用例生成器：在合法 H2 帧语法约束内构造 H2.CL、H2.TE、CRLF 头注入与 `CONTINUATION` 拆分走私载荷，并用后端 H1 严格解析器验证防御包对全部走私变种零放行且正常多路复用请求全部通过。
