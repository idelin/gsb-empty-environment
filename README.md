# contour

Go 轮廓库：从二值图提取四邻接边界，输出可回放的单位边环，并对每个
连通区域给出面积、孔洞数与网格周长。

## 模型约定

- **前景 4-连通**：仅在角上接触（对角相邻）的区域被分开，各自成环，
  两个环共享同一个格点顶点。
- **背景 8-连通**（Jordan 对偶）：对角狭缝仍与外部连通，不算孔洞；
  被完全围住的单个背景像素是孔洞；对角相连的背景对是一个孔洞，
  其边环在夹点处自接触（`Loop.SelfTouches`）。
- 像素 `(x, y)` 覆盖单位方块 `[x,x+1]×[y,y+1]`，y 向下。边界是整数
  网格上的有向单位边，前景始终在行进方向左侧：外环为顺时针（图像
  坐标系），孔环为逆时针。狭缝处边环会两次经过同一顶点（自接触角）。

## API

- `Extract(im) *Result`：区域标记 + 边环追踪，给出
  `Region{Area, Perimeter, Holes, Loops}` 与 `Loop{Region, Hole, Points}`。
- `Replay(res) *Image`：把边环重新栅格化，`Replay(Extract(im)) == im`。
- `Validate(im, res) error`：交叉验证——
  1. 单位边计数：周长 `= 4·面积 − 2·共享边数`，面积 `= 边环有向面积`；
  2. 洪泛背景模型：从边界 8-连通洪泛，被围背景分量与孔环一一对应；
  3. 回放一致性：边环栅格化后与原图逐像素相同；
  4. 几何合法性：闭环、单位边、左前景右背景、边不重复。
