跨域消息宿主升级许可证时不能暂停所有桥接器。请给 Go 宿主写可导入的路由许可组件，输入是签名的旧新策略、各桥接器已确认的版本前沿，以及消息携带的原始域和主题标签。策略作用域由主题标签前缀、分区集合、发布者与订阅者身份组成。每条边可重命名主题，但不得改变原始标签。策略更新可能同时撤销旧订阅并授予新订阅，任何一条实际投递必须能归属到同一个受信策略版本，不能把两版中各自允许的一段路由拼接放行。判断当前哪些确认前沿可以继续投递，哪些必须等待；已撤销者的晚到消息不能因循环路由回到有效队列。生成供独立使用端核验的证书，包含支撑此次授权的版本、原始标签和必要确认。在有共享桥接器的图上按所有合法升级顺序核对结果，另测改名后前缀相撞、未更新的旁支无需阻塞及同一消息绕环后撤销已生效。
