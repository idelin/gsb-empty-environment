引导ROM信任一个根密钥签发的固件密钥清单，攻击者可能重放旧清单恢复已撤销密钥，或重复同一签名者凑阈值。给Go引导准入宿主实现可导入的清单验证包：根信任集合由宿主固定，每根有Ed25519公钥和唯一ID；清单规范编码包含设备型号、单调代次、有效时间窗（左闭右开）、固件签名阈值t、固件密钥条目(keyID、公钥、用途、启止代次)及撤销keyID集合。根签名覆盖完整规范编码，按根ID去重，至少达到宿主当前根阈值；未知根不计票，重复根不同签名为冲突。可信存储保存已接受最高代次和清单摘要，较低代次拒绝，同代次仅允许完全相同摘要。固件清单签名覆盖型号、镜像摘要、固件版本和清单代次；计票只使用当前清单内未撤销、用途含firmware且代次在条目窗口内的不同keyID，公钥材料相同的别名只计一次，达到t才启动。新清单的撤销集合必须包含旧清单全部撤销项，且旧清单中仍有效的keyID不能在新清单中换公钥材料；阈值不得低于宿主最低值；提交最高代次与清单须原子，崩溃恢复不能出现新代次配旧内容。用真实签名测试旧清单重放、别名密钥、撤销回退、阈值降低、同代分叉和最后一笔持久化失败。

## 实现

可导入包位于 `manifest/`，模块路径 `prescreen.local/ps-d4797ec147/manifest`。

- `manifest/canonical.go`：长度前缀 + 大端整数的确定性规范编码（集合按字典序），根签名只覆盖该编码；`FirmwareSigningBytes` 用独立域标签覆盖型号、镜像摘要、版本和代次。
- `manifest/sign.go`：根签名按根 ID 去重计票，未知根不计票，同根不同签名报 `ErrRootConflict`；固件计票只认未撤销、用途含 `firmware`、代次落在 `[GenStart, GenStop)` 的条目，按公钥材料去重（别名只计一票）。
- `manifest/host.go`：`Host.Accept` 做结构/时间窗/阈值/根法定人数校验，并对已接受状态执行代次单调、同代摘要一致、撤销集合只增、存量 keyID 公钥材料不变、阈值不低于宿主最小值等过渡检查；`Host.BootCheck` 做固件准入。
- `manifest/store.go`：`Store` 接口与 `FileStore`，gob 序列化后写同目录临时文件、fsync、原子 rename 再 fsync 目录；提交失败或崩溃后只会观察到上一份完整状态，不会出现新代次配旧内容。
- 错误均为可 `errors.Is` 匹配的哨兵错误（`ErrReplayedManifest`、`ErrForkedManifest`、`ErrRevocationRollback`、`ErrRootConflict` 等）。
