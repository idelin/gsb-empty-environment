# exact-rasterizer

将**可能自交的闭合折线**光栅化为像素掩码的 TypeScript 库。同时按
**奇偶规则（even-odd）** 和 **非零绕数规则（non-zero）** 生成掩码，
并输出两种规则结果不同的区域。所有交点计算使用**精确有理数**
（BigInt 分数），水平边与顶点的处理不含任何浮点误差或 epsilon 容差。

## 规则定义（显式规定）

1. **采样点**：像素 `(i, j)` 的采样点固定为像素中心
   `(originX + i + 0.5, originY + j + 0.5)`。y 轴向下（图像坐标系），
   仅影响绕数全局符号，不影响两种规则的判定结果。
2. **边界点规则**：采样点恰好落在多边形边界上（任一条边上，包括
   水平边，或恰好落在顶点上）时，在两种规则下都判定为**内部**
   （boundary-inclusive）。是否"恰好"由精确有理数运算判定。
3. **射线与半开区间**：否则从采样点向 +x 方向投射射线。非水平边
   `(a, b)` 与扫描线 `y = y0` 相交当且仅当
   `min(a.y, b.y) <= y0 < max(a.y, b.y)`（下端点含、上端点不含），
   因此每个顶点恰好被计算一次；**水平边永不计为交点**。
4. **判定**：
   - 奇偶规则：采样点右侧交点数为奇数 ⇒ 内部；
   - 非零规则：右侧交点的绕数和（上行边 +1、下行边 −1）非零 ⇒ 内部。

输入坐标按 IEEE-754 双精度的**精确值**转换为有理数（每个双精度数都是
二进有理数，转换无损），此后全部运算精确进行。

## 安装与构建

```sh
npm install   # 需要 typescript（devDependency）
npm run build # 编译到 dist/
npm test      # 构建并运行 test/run-tests.js
```

## API

```ts
import { rasterize } from 'exact-rasterizer';

const result = rasterize(
  [ [1, 1], [6, 1], [1, 6], [1, 1], [6, 1], [1, 6] ], // 同一三角形绕两圈
  { width: 8, height: 8 },                            // 可选 originX / originY
);

result.evenOdd.at(1, 1);  // 0：绕两圈 => 交点数 2（偶）=> 外部
result.nonZero.at(1, 1);  // 1：绕数 ±2 ≠ 0 => 内部
result.diff.at(1, 1);     // 1：两种规则在此像素结果不同
result.diffPixels();      // 所有规则不同像素的 [x, y] 列表
```

- 顶点可给 `{ x, y }` 对象或 `[x, y]` 数组；折线自动闭合，首尾顶点
  重复也允许；零长度边被忽略。
- 返回的 `evenOdd` / `nonZero` / `diff` 均为 `Mask`（行主序
  `Uint8Array`，1 = 内部），支持 `at(x, y)` 与文本化 `toString()`。
- `diff` = `evenOdd XOR nonZero`，即"两种规则不同的区域"。

## 实现要点

- `src/rational.ts`：BigInt 分数，永远约分；`fromNumber` 无损转换
  双精度数；交点横坐标 `x = x1 + (y0 - y1)·(x2 - x1)/(y2 - y1)` 全部
  精确计算。
- `src/rasterize.ts`：逐扫描线收集交点并按精确值排序后扫描整行；
  交点横坐标与像素中心**精确相等**时按边界规则处理；水平边单独做
  区间覆盖检测；局部极值顶点（半开区间两端都不含时）由边界检测捕获。

## 测试

`test/run-tests.js` 包含：有理数运算、整数/半整数顶点正方形、水平边
穿过像素中心、顶点恰在像素中心（局部极值）、自交领结形、五角星
（中心区域两规则不同）、双重环绕三角形（整个内部两规则不同）、
非零原点，以及 300 个随机多边形与朴素浮点参考实现的逐像素交叉验证
（4 万余个非边界像素完全一致）。
