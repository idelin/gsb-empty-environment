联邦查询网关把已授权字段拆给几个子图，结果再按别名合并。给TypeScript子图宿主写可导入的授权投影库。输入已解析的查询树和经过签名的字段许可，只处理记录、列表、别名、有限类型片段、条件布尔变量、联合类型回退以及实体引用；许可绑定稳定实体键、实际类型、字段原名、父路径、子图来源与变量取值，显示别名与客户端指令不参与授权。多个分片可在同一响应路径贡献不同的字段，必须证明对每个合法类型与变量赋值，相同别名不会合并两种含义，也不会从另一个父实体或兄弟子图借到许可。空列表、缺实体和被拒字段分别有独立表示，禁止借由空列表长度或错误路径差异泄露被拒字段的存在性。构建可重复使用的分片放行计划，为每个允许叶附上许可出处，无法证明的分支封闭。用独立的小树解释器穷举类型与条件，验证嵌套列表实体键相同但父不同、互斥片段重用别名、两层片段同名冲突和许可在分片之间被撤销。
