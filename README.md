# Maglev 一致性哈希查找表（Go 实现）

Google Maglev 无锁一致性哈希查找表算法的纯标准库 Go 实现。

## 算法要点

- 查找表固定为素数大小（默认 `65537`），每个槽位存储一个后端节点索引。
- 每个节点用两个独立哈希（MD5 / SHA-1）生成全局排列偏好序列：
  `perm[j] = (offset + j*skip) % size`，其中 `offset = h1(name) % size`，
  `skip = h2(name) % (size-1) + 1`。因 `size` 为素数，该序列遍历全部槽位恰好一次。
- 各节点按轮转（round-robin）顺序依次认领自己排列中第一个空槽，直到填满。
- 查找为一次取模加一次数组索引，O(1) 常数时间，表构建后只读、无锁。

## 文件

- `maglev/maglev.go` — 核心算法（排列生成、填表、O(1) 查找）
- `maglev/maglev_test.go` — 验收测试与基准
- `main.go` — 运行样例

## 运行

```sh
go run .                # 运行样例
go test ./maglev/ -v    # 验收测试
go test ./maglev/ -bench=. -run=XXX   # 基准
```

## 验收结果（5 节点，表大小 65537）

- **均匀性**：每节点 13107~13108 槽（20.0000% ± 0.001%），极差 ≤ 1，近乎完美等分。
- **最小扰动**：杀死第 2 个节点重建后，无漂移槽位 52350/65537 = **79.88%**，
  与理论值 (n-1)/n = 80% 完全契合；幸存者槽位级联漂移仅 0.12%。
- **查表速度**：平均约 220ns/次，常数级 O(1)（BenchmarkLookup: 217 ns/op）。
