# 重复nonce后的多项式认证伪造

教学加密服务把同一nonce用于两条消息，导致多项式认证中的掩码S重复。请给Go安全实验宿主实现可导入的密钥候选与伪造包，严格使用本题算法，不冒充真实协议：域元素是128位无符号数，最低位为x的0次项，在GF(2)上按x^128+x^7+x^2+x+1约简；消息为1至3个域元素M1…Ml，标签T=S XOR M1*H^(l+1) XOR … XOR Ml*H^2 XOR l*H，l按无符号整数嵌入域。攻击者持同nonce下两条消息及其标签，允许重复观测以检验信息是否足够，消去S后得到最高四次多项式，求该域中的全部不同根H，并为每根恢复S；零多项式返回信息不足，常数非零多项式返回观测不一致，不能枚举2^128个元素。给定新消息时输出各候选产生的标签，只有所有候选标签一致才标确定伪造，否则标需更多观测；支持追加同nonce观测过滤根。实现域运算与低次多项式求根，覆盖重复根和H=0；再以8位域x^8+x^4+x^3+x+1复用同一路径，穷举所有根核对算法，128位测试使用本地已知H、S合成但求根器不得读取它们。

## 实现说明（仅教学用途，不对应任何真实协议）

- `field.go`：GF(2^n) 域运算，`Field128()` 为本题 128 位域，`Field8()` 为 8 位教学域。
- `poly.go`：域上多项式运算（加减乘除、gcd、求值、特征 2 平方）。
- `roots.go`：`Roots` 求全部不同根——先与 X^(2^n)-X 取 gcd 做互异根分离，再用迹映射等次数拆分，不做全域枚举；重复根只报一次，H=0 正常命中。
- `forger.go`：`Forger` 维护同 nonce 观测；`AddObservation` 消去 S 后用 gcd 过滤候选根，零多项式报“信息不足”，常数非零报“观测不一致”；`Forge` 输出各候选标签，全部一致才判“确定伪造”。
- `cmd/gsbhost`：演示宿主，本地合成观测并走完整恢复-伪造流程。

运行：`go test ./...`；演示：`go run ./cmd/gsbhost`。
