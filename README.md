# DMARC子域策略sp回退

攻击者用组织域下没有 DMARC 记录的子域伪造发信，想借组织域 p=none 与 sp 的差异绕过拒收。为Go收件组件写可导入的 DMARC 策略查找包：先查 _dmarc.<发件域>，无记录且发件域不是组织域时再查 _dmarc.<组织域>，组织域由调用方传入的公共后缀判定函数给出；回退到组织域记录且发件域是其子域时应用 sp，sp 缺省取 p；记录须以 v=DMARC1 开头，多条有效记录视为没有记录，标签重复或 pct 不是 0 到 100 的整数则该记录无效；调用方为每封邮件提供 0 到 99 的随机数 r，r 小于 pct 才执行策略，未选中时降一级（reject 降为 quarantine，quarantine 降为 none）。用子域继承 sp=reject、发件域自带记录覆盖、多条记录、pct=0 与 pct=100 边界验证。
