# rulecache — 带缓存失效传播的规则结果计算器

高频查询规则结果缓存与失效控制器，仅使用 Go 标准库。

## 设计

- `DimensionStore`：模拟外部维度表，维度更新时发布事件。
- `Engine`：规则结果计算器。规则通过 `EvalContext.Get` 读取维度，
  每次读取被记录为依赖；结果连同依赖集合写入 `Cache`。
- `Cache`：结果缓存 + **维度键 → 缓存键** 的精确反向索引。
  维度更新时沿索引精准剔除受影响缓存项，其余缓存零失效。

## 运行

```sh
go test ./... -v   # 测试
go run ./cmd/demo  # 样例：10000 用户中仅 U42 等级变更，仅 1 条缓存失效
```
