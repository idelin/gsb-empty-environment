快照文件系统合并延迟引用时，旧版本把共享树块的子引用按根数扣减，导致仍被快照使用的数据区间被提前释放。给事务提交器写一个可导入的 Go 包，输入是若干只读根、带唯一地址的不可变树块，以及一个原子根替换批次。内部块可被多个根或同一父的多个槽指向；叶块按槽引用半开物理数据范围，不同槽允许部分重叠。树块的入引用数按存活父槽及根句柄计，不按可达路径数计：一个父块无论有几个入引用，其出槽只生效一次。要求在不破坏仍存活块的前提下生成批次前后精确的元数据引用差、按区间分割的数据计数差和最终可释放区间，附一份可以逐步回放的释放顺序。一个批次内所有新根引用必须先建立再撤旧根，回放的任何前缀都不能释放新根将依赖的数据。独立校验器应能拒绝少算重复槽、早释放或把未分配空洞列入回收的错误证书。反复提交同一批次 ID 与相同内容应返回原证书，内容不同应报错；任一步失败均保持批前状态。给定根可达的块结构及精确初始引用索引，新增根可引用先前没有活引用的预分配块；该批触及的子图中有环、悬挂引用或端点溢出须拒绝。未触及树可由一个读取计数的只读接口提供，局部替换不得遍历全盘或逐字节展开。用独立的小图全量重建逐批对照，特别检验一个叶块同批先失去最后旧父又获得新父、重复槽和部分数据覆盖在同一点分裂的组合。
