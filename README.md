时间敏感网络控制器现有每端口各一张周期门表，设备升级后几个端口只能共用一张有长度限制的物理指令表；每端口仅能选择入口索引与一个整数相移。为控制器交付可导入的 Go 包，将多张期望表压成一张循环微程序。指令可设置门位、翻转给定掩码、维持若干拍，然后顺序到下一条；入口前寄存器不是零，必须在周期边界自洽。每流的开放与禁止时间窗各有整数相位误差，同步源相同者共享一个误差，跨端口需覆盖给定的端到端串行发送窗口。先最少指令数，再最小所有允许误差下最坏发送完成延迟，最后取规范循环旋转最小编码。验证器可独立回放，错误表须给具体误差、报文及首次违约拍。周期与连续运行长度可达 2^42，不逐拍遍历；小周期枚举全部微程序验证。
