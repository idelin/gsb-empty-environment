算子融合后，张量只剩若干活跃轴段，通用的整块换布局会踩掉相邻算子的字。给执行引擎写可导入的 Go DMA 降低包。地址空间是长度 N≤2^48 的字数组，输入至多 32 个三元组（源起点、目标起点、长度），表示把该段入口时的字一一平移到目标。各源段互不相交，各目标段也互不相交，两组之间可任意重叠。目标以外的字必须保持入口值。设备没有整段搬移指令，只能逐字 copy 或用唯一暂存器 save、restore，各算一拍；每个字视作不同的不透明标记，不能凭值重建。相邻边界在输入中全部给出但反复平移可能产生很长的轨道。提供流水线用于报价的接口：不枚举 N 个字或逐步走长轨道，精确返回最少拍数，并区分固定字、开放链上的移动字、非平凡环的个数；给出算法依据。编译器可以输出含整数循环的搬移程序，由运行时按需吐出单步设备动作；执行输出允许与实际移动字数成正比，但规划与首个动作前的空间不得与 N 成正比。报价允许随段数及端点位数增长，不接受在单次两段互换组成的大旋转上按周期长度迭代。另交小域解释器，逐拍回放检查未覆盖字和唯一暂存器，对七字以内以实际设备状态搜索核对最少拍数。覆盖旋转被删去一个源字后整环断为链、多段边界相接却属于不同轨道，以及长度近 2^48 的互素旋转。
