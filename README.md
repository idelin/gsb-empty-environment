# SWIM 故障检测度量分析仪 (Go)

量化 SWIM 故障检测协议的运行指标：对每次故障注入事件统计发生时刻、
首次怀疑时刻、最终标记时刻，计算平均检测时间（MTTD）与误报率，输出详尽诊断报告。
仅使用 Go 标准库。

## 组件

- `swim.go` — 简化 SWIM 集群模拟器：环形探测拓扑，每周期 1 次直接 ping +
  间接 ping，怀疑超时（默认 2 周期）未澄清则最终标记故障。
- `metrics.go` — 度量分析仪：将观测流与注入计划匹配，生成逐事件档案并聚合
  MTTD、首次怀疑时延、确认时延、误报率、漏检数、瞬时怀疑数。
- `scenario.go` — 验收场景：16 节点，10 次真实宕机 + 5 次短暂丢包扰动。
- `main.go` — 运行样例，打印诊断报告。

## 运行

```sh
go run .        # 运行模拟并输出诊断报告
go test ./...   # 运行全部测试
```

## 验收结果

- 10 次宕机全部检出（6 次 2 周期、4 次 3 周期），MTTD = 2.40 周期；
- 5 次丢包扰动：3 次被间接 ping 吸收、2 次触发瞬时怀疑但在超时前澄清，
  误报率 0.00%。
