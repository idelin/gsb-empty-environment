列存扫描器读取字典编码行块时，码字按任意位宽 b（1≤b≤20）紧密打包在 uint64 数组中并允许跨 64 位字边界，空值位图采用小端位序（1 表示有效，0 表示空值）。为向量化算子交付可嵌入的 C++20 过滤组件。输入字典字符串数组、位打包码字缓冲、位宽 b、行数 N、可选空值位图、上游升序选择行号向量（为空表示全行扫描），以及支持 AND、OR、NOT、BETWEEN、IN、IS NULL、IS NOT NULL 的三值布尔表达式树（SQL 三值逻辑：未知在顶层滤除，但在 NOT 和 OR 中按三值传播）。组件须先在字典域求各原子谓词的匹配码字位集，合并为有效行三值真值表，再仅对上游选择行号做跨字位解包计算并输出升序匹配行号，非法码字越界须显式报错而非静默截断。验收对照逐行解码求值的朴素 SQL 三值解释器，覆盖位宽 b=1/7/13/20 跨 64 位边界解包、NOT(x IN (...)) 与 OR(x BETWEEN ..., IS NULL) 的空值传播、空字典含全空值列、上游选择向量为空或稀疏，以及越界码字报错。
