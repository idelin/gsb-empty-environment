# 有界恶意电路的差分故障

Go硬件仿真宿主需要可导入的故障检测包，电路是至多128节点的布尔DAG，节点含输入、AND、XOR、NOT和输出，输入至多12位。攻击者可选择一个内部节点永久卡0或卡1；给定公开测试向量集合，找出所有测试均未发现但存在输入使安全输出位由拒绝0变为放行1的故障。用位并行仿真或符号法搜索并返回节点、故障值、逃逸输入及正常/故障逐节点状态，必须独立回放；无遗漏枚举全部故障才能报告不存在，预算耗尽为未知。另给最小新增测试向量集合覆盖所有可检测危险故障，输入空间限定4096且危险故障最多20，精确求最少数量并按向量字典序决胜。

## 用法

```go
c := &netsec.Circuit{
    NumInputs: 2,
    Secure:    4, // 安全输出位（0=拒绝，1=放行）
    Nodes: []netsec.Node{
        {Op: netsec.GateInput, A: -1, B: -1, Pin: 0}, // 0: a
        {Op: netsec.GateInput, A: -1, B: -1, Pin: 1}, // 1: b
        {Op: netsec.GateNot, A: 1, B: -1},            // 2: ~b
        {Op: netsec.GateAnd, A: 0, B: 2},             // 3: a & ~b
        {Op: netsec.GateOutput, A: 3, B: -1},         // 4: 安全输出
    },
}

// 逃逸分析：枚举全部内部节点固定0/1故障。
rep := netsec.Analyze(c, []uint32{0, 1}, -1) // 公开测试 {00,01}，预算不限
// rep.Status == netsec.StatusFound
// rep.Escapes[0]: Fault{Node:2, Stuck:1}, Input:3，
//                 NormalState/FaultyState 为独立标量回放的逐节点状态。

// 最小新增测试向量：精确最小规模，按向量字典序决胜。
cov := netsec.MinimalAdditionalTests(c, []uint32{0, 1}, -1)
// cov.Vectors == []uint32{3}
```

## 设计要点

- **位并行仿真**：每个节点全部 `2^NumInputs` 个取值压缩进机器字（≤12 输入即 64 个 uint64），一次按位运算完成 4096 个输入的并行求值，因此默认即穷尽整个输入空间。
- **故障模型**：攻击者可选任一内部节点（AND/XOR/NOT 门）永久卡 0 或卡 1；主输入与主输出不可注入。
- **检测判据**：某测试向量下任一主输出取值与正常电路不同，即该故障被观测；危险故障指存在输入使安全输出位由 0 变为 1。
- **独立回放**：每个逃逸故障的逃逸输入与正常/故障逐节点状态由独立的标量求值器 `evalScalar` 重新回放产生，并与位并行结果交叉校验。
- **结论状态**：`StatusNone`（穷尽枚举后无逃逸）、`StatusFound`、`StatusUnknown`（预算耗尽，附部分结果）、`StatusError`。
- **最小测试集**：精确最小集合覆盖（分支限界 + 容量/死路剪枝），候选向量限定 `[0, min(2^NumInputs, 4096))` 且不与公开测试重复；已被公开测试覆盖的危险故障不计入待覆盖集合，传空公开集即得独立全覆盖。规模并列时取向量序列字典序最小者。
