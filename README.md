# 多目标崩溃归类

相同异常名称可能来自不同缺陷，安全测试服务需要稳定归类。写供Go测试宿主调用的崩溃指纹包，栈帧包含模块摘要、相对地址与内联链，按输入映射消除地址随机化，截断栈只允许与共同已知后缀兼容而不强行合并。归类必须满足等价关系；对不确定匹配保留候选关联，用排列插入测试结果不依赖到达顺序。

## crashfp 包

`crashfp` 为 Go 测试宿主提供崩溃指纹与稳定归类。

- 归一化：`Normalize(frames, modules)` 用调用方提供的模块加载映射，把绝对地址换算为 `模块摘要 + 模块内偏移`，并保留物理帧符号信息与内联链；输入切片会被深拷贝。
- 指纹：`Stack.Fingerprint()` 对长度前缀的规范化字节流取 SHA-256。异常名与 `Truncated` 不参与指纹——异常名仅作展示，截断只表示采集质量。
- 等价归类：`Classifier.Add` 仅在规范化栈完全相同时合并，并查集保证自反、对称、传递；类 ID 取类内字典序最小的报告 ID，与到达顺序无关。
- 不确定关联：截断栈只有在其已知帧是对方严格后缀时记录 `truncated_suffix`；其他共享已知后缀但更早分叉的情况记录 `common_suffix`。候选关联只存不合并，按稳定指纹对去重并在输出时映射为类 ID。
- 验证：`go test ./...` 对 7 个报告的全部 7! 种插入排列断言相同的类划分、候选集合与等价关系三性质。

帧顺序约定为“最外层调用在前、故障叶帧在后”；Go 运行时按叶帧优先打印的栈需由调用方先反转。
