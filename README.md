# 资源受限规划器 (resource-constrained-planner)

在有限状态空间内求**预算内收益最高**的动作计划；收益相同时取**动作成本最低**者。
动作只消耗不可再生资源，目标项可任选若干达成。绝不按目标距离贪心。

## 模型

- **资源** `ResourceSpec`：不可再生，取值域 `[0, capacity]` 整数，`capacity` 即初始预算。
- **动作** `ActionSpec`：`cost`（次目标）、`consumes`（各资源消耗）、`achieves`（达成的目标集合）。
- **目标** `GoalSpec`：每项带固定收益 `profit`，可任选子集达成。
- **状态** = 资源向量 × 目标位掩码，天然有限，作为输入约束。

## 算法

- `Planner.plan()`：在状态空间上做记忆化 DP（等价于有限 DAG 上的最优后缀搜索），
  字典序优化 `(收益↓, 成本↓, 动作数↓)`，返回每步资源余额。
- `Planner.analyzeDeadEnds()`：BFS 枚举可达状态，识别**死端**——
  未达成目标尚存但最优后缀收益为 0 的状态；对每个被卡目标给出
  缺口最小的动作、关键资源缺口（need vs have）、以及路径上消耗关键资源的动作。
- `greedyPlan()`：按目标距离贪心的基线，仅用于对比演示。

## 运行

```bash
npm test    # 编译 + 运行 9 项断言测试
npm run demo # 演示：最优 26 vs 贪心 16，并打印死端报告
```

## 演示场景

`fuel` 是全局关键资源。`quick-patch`（成本 1，耗 fuel 3）看似便宜又离目标近，
贪心选它后 `deploy-beta` 因燃料不足被卡死（收益 16）；
最优计划改用 `careful-patch`（走 parts 通道），三目标全达成（收益 26）。
