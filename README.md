# 多方统计服务在设备掉线后恢复掩码，不能把仍参与聚合的设备个人值一并解开

多方统计服务在设备掉线后恢复掩码，不能把仍参与聚合的设备个人值一并解开。写供Go聚合宿主调用的阶段验证包，每设备提交带签名的参与集合摘要、被掩码整数及种子份额类型；种子分为个人掩码与两两掩码，完成集合必须由至少t个不同受信设备对同一摘要签名确认。只有完成设备的个人种子、未完成设备与完成设备之间的配对种子可交给恢复回调，禁止同时恢复一个设备的两类种子。回调返回恢复种子的标量掩码；配对掩码在较小设备ID端为加、较大端为减，聚合模给定素数时去除完成者个人掩码与跨集合配对掩码，用标准库签名和可观察恢复器测试分裂视图、重复身份、迟到提交及合法掉线，验证输出对应同一完成集合且无个人双重解掩。
