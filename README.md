# 滑动窗口峰值重叠区间检测器

设备占用区间峰值并发统计器。输入为带时间区间的设备占用事件（半开区间
`[start, end)`），允许乱序到达、迟到补录与撤回；每次变更后动态输出
并发峰值数值及对应的全部连续时间段。

## 语义约定

- 区间为左闭右开：`[0, 5)` 与 `[5, 9)` 在端点 5 处不重叠，并发为 1。
- 每条区间以唯一 `id` 登记；同 `id` 重复登记视为覆盖修正，`remove(id)` 撤回。
- 快照包含：
  - `peak`：当前并发峰值；
  - `segments`：达到峰值的极大连续时间段（相邻同峰值段已合并）；
  - `atomicSegments`：以所有端点为切分点的原子峰值段。

## 实现

`src/peakOverlapDetector.ts`：扫描线法。取全部区间端点排序，相邻端点
构成原子段 `[a, b)`；区间 `[s, e)` 覆盖原子段当且仅当 `s <= a && b <= e`，
端点恰好相接不会多计。单次快照复杂度 `O(n²)`（n 为在册区间数），
对设备占用事件规模足够且保证补录/撤回后的强一致性。

## 运行

需要 Node.js ≥ 23.6（原生 TypeScript 类型擦除 + 内置 `node:test`），
无需安装任何依赖。

```sh
npm test        # 运行内置测试（node --test）
npm run demo    # 运行验收场景样例
```

## 运行样例输出

```
1) 登记设备占用 [0, 5) 与 [5, 9)：
   峰值并发 = 1，峰值原子区间 = [0, 5), [5, 9)
2) 补录迟到区间 [4, 6)：
   峰值并发 = 2，峰值原子区间 = [4, 5), [5, 6)
3) 撤回补录区间 [4, 6)：
   峰值并发 = 1，峰值原子区间 = [0, 5), [5, 9)
```
