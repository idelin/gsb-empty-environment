# budgetsem

下载器按任务字节预算申请容量的 Go 信号量。

## 语义

- **严格 FIFO**：队首的超大申请阻塞整个队列，后来的小申请即使放得下
  也不得越过（`advanceLocked` 只从队首授予）。
- **取消即推进**：队首被取消后立刻从队列移除并尝试授予后继者。
- **授予/取消唯一结果**：授予决定与取消都在同一把锁内判定；若授予
  已先生效，迟到的取消不撤回，`Acquire` 返回 `nil`，调用方持有额度
  并负责 `Release`。
- **动态缩容不撤回**：`SetCapacity` 调小后已授额度继续有效；存量可
  变为负数（赤字），后续归还先抵偿赤字，超额存量不会重新变成可授
  额度。

## 用法

```go
sem := budgetsem.NewSemaphore(64 << 20) // 全局下载字节预算

if err := sem.Acquire(ctx, task.Bytes); err != nil {
    return err // 任务取消或超时
}
defer sem.Release(task.Bytes)
// ... 下载 ...
```

## 测试

```
go test -race ./...
```

测试用可控屏障（`gate` + 入队计数等待）确定性地编排并发交错，覆盖：
预算守恒、FIFO 反饥饿（小申请不得越过队首）、取消队首立即推进、
授予与取消竞争的唯一结果、缩容不撤回与超额存量归还（赤字吸收）。
