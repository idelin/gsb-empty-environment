机密计算宿主机与安全固件在验证 AMD SEV-SNP 机密虚拟机内存隔离时，若反向映射表（RMP）中同一宿主机物理页（SPA）被同时映射给两个不同 ASID、宿主机将同一 GPA 重映射到不同 SPA 却未在客体侧通过 `PVALIDATE` 检测 Validated 位变化，或客体在 GHCB（Guest-Hypervisor Communication Block）共享页交换 I/O 数据时未校验私有/共享 C-bit 边界而把机密私有页暴露给宿主机，恶意 Hypervisor 可发动页重映射重放（Memory Aliasing / Replay）或静默篡改机密客体代码。为 C++17 机密计算审计宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 SEV-SNP RMP 与嵌套页表及 GHCB 隔离状态机验证库。库建模宿主机物理页表（RMP 表项：`Assigned`、`ASID`、`Immutable`、`PageSize`、`GPA`、`Validated`）、虚拟机 NPT 映射（含 C-bit 私有/共享标记）与 `RMPUPDATE`/`PSMASH`/`PVALIDATE`/`GHCB` 操作流：（1）维护 RMP 全局不变式——同一 SPA 至多归属一个 `ASID`；任一 `Assigned=1` 私有页仅允许映射至 RMP 记录的唯一 `(ASID, GPA)`，硬拦截任意双 GPA 别名映射（Aliasing）或跨 ASID 共享私有页；（2）精确模拟 2MB 大页 `PSMASH` 拆分为 512 个 4KB 页时的 `Validated` 继承语义，以及宿主机改写 RMP 后 `Validated` 清零并触发客体 `#VC` / `PVALIDATE` 失败检出重映射重放；（3）审计 GHCB 通信页与 MMIO 请求，硬拒绝将 `C-bit=1` 私有页或未撤销验证的机密内存区作为共享 GHCB 缓冲交给宿主机。附双 GPA 别名拦截、RMP 重映射重放检出、`PSMASH` 拆分验证与 GHCB 私有页泄漏阻断测试。
