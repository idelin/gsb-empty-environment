# 行级安全谓词排序

数据库行级安全策略在查询计划下推谓词时，用户自定义函数若先于策略谓词执行，就能经错误消息或副作用泄漏被隐藏的行。为TypeScript查询规划组件实现供 SQL 引擎优化阶段调用的谓词排序包：谓词分为策略谓词与用户谓词，安全屏障内用户谓词只有函数被标为 leakproof 才可排在策略谓词之前；PERMISSIVE 策略以 OR 合并、RESTRICTIVE 策略以 AND 与其合并，没有任何 PERMISSIVE 时默认拒绝；返回执行顺序，并拒绝会让非 leakproof 函数看到未过滤行的计划。用泄漏函数下推、内置 leakproof 比较、混合策略和无策略默认拒绝验证。
