# prefrank — 带权成对偏好排序器

接收带置信权重的成对偏好，在允许冲突与缺失的情况下，给出违约总权重最小的对象排名。

- 对象数 `0 <= n <= 18`，编号 `1..n`
- 偏好可冲突（同时存在 `a>b` 与 `b>a`）、可缺失（缺失不代表任何方向）
- 有环不等于无法排序：程序总是输出一个最优排名，环通过违约最便宜的边来打破
- 并列最优时，输出按编号字典序最小的排名

## 输入（stdin）

```
n m
a1 b1 w1
...
am bm wm
```

`a b w` 表示"偏好 a 排在 b 前"，置信权重为 `w`（整数，可重复，重复时权重累加）。

## 输出（stdout）

```
<最小违约总权重>
<最优排名：n 个编号，空格分隔，最优者在前>
<被违反的边数 k>
a b w   （共 k 行，按 (a, b) 字典序）
```

## 示例

输入：

```
4 5
1 2 6
2 3 5
3 1 4
3 4 2
4 2 1
```

输出：

```
5
1 2 3 4
2
3 1 4
4 2 1
```

## 算法

最小权重反馈弧集（minimum weighted feedback arc set），子集 DP：

- `back[v][S]`：v 指向集合 S 的边权和（子集递推预计算）
- `dp[S]`：集合 S 内部的最小违约权重，`dp[S] = min_{v in S} dp[S\{v}] + back[v][S\{v}]`
- `tail[S]`：把补集排在 S 之后的最小额外违约权重
- 重建：从小到大尝试每个编号，选取仍能达到全局最优 `dp[S]+tail[S] == opt` 的最小者，
  得到字典序最小的最优排名

复杂度 `O(2^n * n)` 时间、`O(2^n * n)` 空间；`n = 18` 时约 0.1 秒。
