数据库升级要把多个分区的局部字典改编成一个全局字典，旧编码仍被快照上的范围索引引用。交付优化器可导入的 Go 包。输入分区字典、别名、不同排序版本各自的全预序及仍存活的索引切点；每个旧切点声明 LT 或 LE，等价键不一定同码。全局码空间有若干保留洞且已有外键码不能移动，允许为特定分区挂有限张例外翻译页。要求所有列出的旧查找和范围扫描仍返回同一行集，先最少例外页，再最少实际使用的物理码数，最后取最小确定性映射。例外页是一段源码区间及仿射增量，不能为每个查询保存结果。最多十二个冲突等价类，稀疏码空间到 2^50；返回可独立复查的映射，不能兼容时给两项具体范围观察或固定码约束的冲突证书。用小码表枚举验证两个排序版本对同键组拆分、NULL 与空字符串及洞边界。
