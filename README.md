编辑器现在允许读者在净化后的富文本上修改自己有权编辑的段落。服务端保存的是含私有注释、隐藏节点和共享片段的原文，不能直接把界面偏移当成原文偏移。给 TypeScript 文档宿主写可导入的编辑准入组件。公开位置由可见节点的稳定身份、UTF-16 偏移及左右偏好组成；原文以 UTF-8 字节保存，引用同一片段的不同出现位置各有授权，改动一个出现位置必须按需复制，不能连带更改另一租户的片段。宿主给出从用户看到的版本到当前版本的编辑日志，可能只有隐藏区变化，也可能包含公开拆段、合段、删除或撤权。对插入、删除、替换以及跨段选区要么生成一份可原子应用的最小原文补丁，要么说明公开可见的冲突类别。不能发出隐藏文本、长度或隐藏节点数量；只发生隐藏区变化的两份文档，用户收到的结果、冲突类型和新游标必须相同。被撤权的可见锚点不得因为邻居同名而重新获得写权。应保留隐藏字节及未编辑引用的身份，半个代理对不能作为编辑边界。用成对文档重放公开编辑，检验投影后的新结果等于直接编辑可见树，尤其是多个隐藏区折叠到同一界面位置、跨段撤权、共享片段和非 BMP 字符。
