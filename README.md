日志聚合器要合并两个厂商留下的转义格式。为 TypeScript 写可导入的编解码组件，输入是两份有限状态字节转写表，每步读一个字节，可输出零至两个字节，终态另有尾输出；编码前的记录语法用 DFA 表示，字段边界是独立标记，不属于字段值。要求判断所有合法记录的输出是否都能唯一恢复字段边界和原始字节；聚合流只给编码结果，没有格式前缀，任一厂商格式都可能出现。最大记录 128 字节，不能逐记录枚举。调用方另给最大未匹配输出延迟，先验证其在所有仍有共同输出前缀的两条路径上确实成立；不成立返回“界不成立”，不能当作格式安全。可唯一解码时生成无回退的增量解码表，输入任意切块，只有对所有可完成路径都相同的记录前缀才可释放，遇到非法尾部不得交付未确认字段。表和证明绑定两份格式与记录 DFA 的摘要。用小字母表短记录全枚举核对，引入空输出、不同步字段边界、双字节展开和只有终止符能区分的两条路径，验证计入预算后的未定与真正不唯一分开。
