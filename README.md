# plsolver

精确求解一维分段线性优化问题（Go 实现，全程 `math/big.Rat` 有理数精确运算）：

```
min  f(x) = Σ w_i·|x − a_i|  +  Σ c_j·x + d_j,     x ∈ [Lo, Hi]
```

权重 `w_i` 允许为负，目标一般非凸，因此**不使用**仅适用于凸情形的加权中位数结论。

## 方法

1. 收集域端点与所有内部断点 `a_i`，排序并合并重复断点（断点在域外的绝对值项在域上本来就是线性的，只贡献斜率）。
2. f 在每个相邻断点间的开区间上是线性的：用区间中点精确计算斜率 `Σ ±w_i + Σ c_j`。
3. 线性函数在闭段上的最小值必在端点取得，因此全局最小值 = 所有断点处函数值的最小值。
4. 最优集：函数值等于最小值的断点，加上斜率为 0 且端点值达到最小值的整段；相邻最优原子合并为极大闭区间（孤立最优点输出为单点区间）。

`Result.Evidence()` 输出逐段斜率证据：每个断点的精确函数值、每个基本段的斜率及增/减/平坦判定。

## 用法

```go
s := plsolver.NewSolver(rat(-3, 1), rat(3, 1))
s.AddAbs(rat(-2, 1), rat(0, 1))      // -2|x|
id := s.AddLinear(rat(1, 2), rat(-1, 1)) // x/2 - 1
res := s.Solve()
fmt.Print(res.Evidence())
s.Remove(id)                          // 支持增删项后重新 Solve
```

运行示例：`go run ./cmd/pldemo`

## 测试

`go test ./...` 用独立的暴力枚举参考实现交叉核对：枚举全部断点（含重复断点合并），在断点与段中点处精确求值，用中点值（而非斜率）判定平坦段，覆盖平坦段、端点最优、负权重、重复断点、空目标、退化域及 1000 组随机用例；并校验斜率证据恒等式 `f(hi) − f(lo) = slope·(hi − lo)`。
