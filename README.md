数据中心高速二层交换机在实现 IEEE 802.1AE MACsec（含 64 位扩展包号 `GCM-AES-XPN-256`）链路加密时，若未校验 `SecTAG`（EtherType `0x88E5`）TCI/AN 标志位与 `Short Length` 合法性、在 32 位低包号回绕时错误重构 64 位 `PN` 与 96 位 GCM IV（`SSCI || (PN XOR Salt)`），或在接收侧未拒绝明文帧降级（`validateFrames=strict`）与未认证前就更新防重放窗口，二层攻击者可剥离 `SecTAG` 注入明文控制帧、触发 IV 复用破坏 GCM 机密性或利用伪造高 `PN` 推飞接收窗口造成链路阻断。为 C++17 网络安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 IEEE 802.1AE MACsec `GCM-AES-XPN-256` 帧封装/解封与安全策略验证库（内置 AES-256-GCM）。库严格实现：（1）原始以太网帧与 `SecTAG` 解析/构造：校验 `DstMAC`/`SrcMAC`、EtherType `0x88E5`、TCI 位（`V=0`、强制 `E=1 & C=1` 加密完整性模式时拒绝仅完整性或未加密降级、`SC` 位决定是否携带 8 字节 `SCI`）、`AN`（0–3 关联号）与 `SL`（`1..47` 时精确校验加密载荷长度，拦截畸形短长填充）；（2）精确按 IEEE 802.1AEbw 构造 96 位 XPN IV（`32-bit SSCI || 64-bit PN` 与 96 位 `Salt` 逐位异或）与 AAD（`DstMAC || SrcMAC || SecTAG`），在 32 位包号跨回绕边界时正确恢复 64 位候选 `PN` 并在 `AES-256-GCM` 认证通过**后**才推进防重放滑动窗口与最高 `PN`；（3）硬拒绝 `PN == 0`、`PN == 2^64-1` 耗尽、严格模式下无 `SecTAG` 明文帧注入、未知 `SCI`/`AN` 以及重放包。附内置 AES-256-GCM 向量、跨 2^32 回绕测试、明文剥离拒收、未认证高 PN 推飞阻断与重放测试。
