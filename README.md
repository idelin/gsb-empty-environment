# 隐蔽通道的输出整形

Go隔离执行宿主需要可导入的输出整形包，保护秘密任务的完成时刻。宿主按公开计划给出固定N个时隙，每槽固定L字节；任务只能提交至多(N-1)*L字节秘密结果，输出端在每槽都发送L字节经认证加密的数据，未有结果也发送填充，最后一槽携带加密的真实长度与成功/失败状态。使用AES-GCM且每槽独立nonce由轮次uint32和槽序号uint64拼成，AAD绑定公开计划与轮次；同密钥轮次不能复用，最后槽不足以编码元数据时拒绝计划。无论任务早完、晚完或报错，外部帧数量大小和发送槽号相同，超截止未完成以失败结束。用可控时钟测试轨迹不可区分与解密正确性，不宣称隐藏加密内容以外的进程侧信道。
