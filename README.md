# derived-cache

按依赖版本与访问权重管理的派生值缓存。零依赖 TypeScript，不借助任何响应式框架，
用 Node.js 内置测试运行器（`node:test`）验证。要求 Node.js ≥ 22.6（23.6+ 原生运行 `.ts`，更早版本经 `--experimental-strip-types`）。

## 运行

```bash
npm test    # node --experimental-strip-types --test test/*.test.ts
npm run demo  # node --experimental-strip-types examples/demo.ts
```

## 架构

| 模块 | 职责 |
| --- | --- |
| `src/ledger.ts` | 内存账本：物理块字节 + 临时重算预留共用同一预算，超支抛出 `BudgetExceededError`（明确拒绝） |
| `src/blocks.ts` | 物理块存储：值经 hash-consing 物化为不可变块 DAG，相同子结构物理共享、引用计数，账本按物理块计费 |
| `src/state.ts` | 源状态：事务缓冲写入、同步原子提交、失败整体回滚；操作日志可序列化，`Store.replay` 完整重建 |
| `src/eviction.ts` | 固定驱逐策略（见下），纯函数、可测试 |
| `src/scheduler.ts` | 异步重算调度：并发去重、依赖块借用、临时预留、过期结果丢弃、`drain`/`checkQuiescent` 资源检查 |
| `src/reactive.ts` | 门面：派生图、版本化缓存、订阅保留准入、级联失效 |
| `src/verify.ts` | 独立引用遍历核验账本（不信任内部计数，从引用根重数） |

## 关键语义

- **依赖版本**：每个源单元/派生节点有单调版本号。源提交后沿依赖图级联递增所有传递依赖者版本；
  缓存项仅在全部依赖版本匹配时有效 —— 依赖变更后绝不命中旧缓存。
- **驱逐策略（固定）**：候选 = 未订阅的派生缓存项（源状态与订阅保留值永不驱逐）；
  权重 = 命中次数，低者先走；并列按最久未使用、再按 id 字典序。驱逐只释放可重算值。
- **订阅保留**：存活订阅的值按策略保留；订阅时做准入控制 —— 保留后 `pinnedBytes` 必不超缓存预算，
  否则抛出 `SubscriptionRejectedError`（可证明不超预算或明确拒绝）。
- **异步交错**：重算对依赖块持借用（引用计数），驱逐无法释放被借用的物理块；
  计算完成后校验依赖版本，过期结果丢弃重算 —— 频繁变化的依赖不会把旧结果重新发布。
- **临时重算占额度**：每次重算先向账本申请预留，结束释放；预算不足时读取显式失败。
- **0 容量缓存**：`cacheBudget = 0` 时不存缓存项，每次读都重算，功能仍正确。
- **读者隔离**：事务写入先缓冲，提交是单一同步换入；快照为物化深拷贝，读者看不到事务中间态。

## 核验

`verifyLedger` 从引用根（源单元、缓存项、在途借用）独立遍历块 DAG，重数每个物理块的
引用与字节，并独立重算缓存足迹与订阅保留集，逐项与账本对账；调度器 `checkQuiescent`
确认驱逐后的安全重算与资源释放（无在途任务、无未释放借用与预留）。
