# 网格被平面剖切后需要生成可渲染的封口，而不能只删掉背面三角形

网格被平面剖切后需要生成可渲染的封口，而不能只删掉背面三角形。实现供Go建模宿主调用的剖切包，输入有向闭合三角网格和有理平面，保留非负半空间；跨边交点按原边ID共享，交线组装成有向环，含孔封口按平面坐标三角剖分。共面面按法向确定保留且不重复生成，非流形输入拒绝。用立方体、多孔棱柱及顶点恰在平面的案例验证封口朝向、边配对与体积守恒。

## 使用

```go
res, err := taskpkg.Cut(mesh, plane) // 保留 A*x+B*y+C*z+D >= 0
if err != nil { /* 非流形、退化平面等 */ }

renderable := res.Mesh       // 原表面裁剪结果 + 封口三角形
caps := res.CapTriangles     // 封口三角形
loops := res.Loops           // 有向封口环（外环为正面积，孔为负面积）
```

`Mesh.Triangles` 以逆时针为外法向。`Cut` 先验证输入为有限的、有向一致的闭合三角
2-流形；每条无向边必须恰好出现两次且方向相反，每个顶点的 link 必须是单环。不是
闭合流形时返回包裹 `ErrNonManifold` 的错误。

精确有理平面可用 `CutExact`：

```go
p, _ := taskpkg.NewExactPlane(big.NewRat(1, 1), big.NewRat(0, 1),
	big.NewRat(0, 1), big.NewRat(-1, 3))
res, err := taskpkg.CutExact(mesh, p)
```

实现约定：

- 顶点相对于平面的符号用 `big.Rat` 精确判定；交点参数与交点坐标也先精确计算，再输出为 `float64`。
- 每个原始边有稳定 `EdgeID`；同一条边上的交点只生成一个输出顶点，结果在 `Result.Intersections` 中给出 `EdgeID`、边、顶点编号和参数 `T`。
- 裁剪后保留表面的平面边按方向配对，未配对边反向组装成封口环；环在平面坐标中按嵌套深度确定为外环/孔，并以耳切法三角剖分。
- 与平面共面的三角形按其外法向是否指向保留侧决定保留或丢弃；保留的共面面就是封口，不会再生成重复封口。
- 封口三角形法向与平面法向相反，即指向被移除的半空间。

测试覆盖立方体半切、斜切、负向法向、平面恰过顶点/四顶点、共面面保留与丢弃、双孔
棱柱、有理 1/3 平面以及开放/顶点非流形拒绝；并对随机平面检查结果流形性、封口朝向
和体积范围。
