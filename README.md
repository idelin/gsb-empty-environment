# desim — 离散事件仿真库

事件键为 **(时间, 阶段, 插入序号)** 的全序三元组，调度队列是有序列表。

## 调度规则

- 键序：先时间、再阶段、最后插入序号（`Key.Less`）。
- 同刻新事件不得插入到已经执行完的更早阶段：若引擎当前位置为
  `(now, phase)`，则插入 `(now, phase')` 且 `phase' < phase` 会被显式拒绝
  （返回 `*PhaseError`）；插入过去时间同样被拒绝。
- 事件可取消（`Cancel`）；取消已执行事件失败。
- 事件在处理器内通过 `ctx.Schedule` 生成因果后继（记录 `Cause` 链）。
- `Run` 在队列空时结束（空队列终止）。

## 撤销与检查点回滚

- `Checkpoint()` 在事件边界记录用户状态快照（`State` 接口：
  `Snapshot`/`Restore`，均需深拷贝）。
- `Undo(id)` 撤销已执行事件：
  1. 计算因果链（目标事件 + 全部传递后继）；
  2. 未执行的后继直接从队列取消；
  3. 已执行的非外部后继进入撤销集；
  4. **外部已确认效果不可撤销**（`External()` 选项），只产生补偿要求
     （`Compensation`，效果保留）；
  5. 从最近的历史长度 ≤ 最早被撤销事件的检查点恢复状态，重放其后的
     历史（跳过被撤销事件，重放期间调度被抑制），生成重放日志。
- `CausalChain` / `FormatCausalChain` 输出因果链；
  `UndoReport` 含因果链、撤销集、补偿要求与重放日志。
- `Resimulate()` 从创世检查点全量从头模拟，返回状态快照，用于与
  当前状态核对（测试中以 `reflect.DeepEqual` 验证）。
