# 连接迁移模拟器

模拟连接迁移期间新旧链路短暂并存的可靠传输：逻辑消息使用连续序号，
发送方在迁移点切换活动链路，两条链路的累积确认按规则合并。

## 运行

```sh
node migration-sim.ts        # Node.js >= 23（原生类型擦除）
node --experimental-strip-types migration-sim.ts   # Node.js 22.6+
```

## 模型

- `Sender`：滑动窗口限流；每条链路独立记录 `sentMax`（已发最大序号）与
  `linkAck`（该链路确认的前缀）。RTO 超时后在当前活动链路上重传全部未确认包。
- 确认合并：链路 L 到达的累积确认 `cum` 先钳制到 `sentMax[L] + 1`
  （旧链路的迟到确认可以推进已发送前缀，但不能确认只在新链路上发过的数据），
  合并前缀 `acked = max(linkAck.old, linkAck.new)`。
- `Receiver`：接收窗口 `rwnd` 内的乱序包进入重排缓冲，按序交付业务层
  （恰好一次）；收到数据或周期性定时器触发时，在所有开放链路上重发累积 ACK。
- `Link`：随机丢包 + 随机时延（产生乱序）；迁移点打开新链路，
  重叠期结束后关闭旧链路。

## 验证

- 单元测试 `testAckMergeClamp`：确定性验证钳制与合并规则。
- 场景验证（5 个普通种子 + 3 个高丢包压力种子）：
  业务交付严格为 `0..N-1` 恰好一次；发送方未确认缓冲 <= 窗口、
  接收方重排缓冲 <= rwnd（内存有界）；双端重传与钳制路径均被实际触发。
