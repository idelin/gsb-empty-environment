# polygon_clip — 凸裁剪窗裁剪简单多边形

Python 3.11，仅使用标准库（`fractions.Fraction` 精确有理数运算），
拓扑判断**不使用任何 epsilon**。测试基于 `unittest`。

## 文件

- `polygon_clip.py` — 核心库（校验、裁剪、区域拆分、规范化输出）
- `test_polygon_clip.py` — 31 个 unittest 用例（含 300 组随机模糊测试）
- `demo.py` — 8 个运行样例

## 规则定义

**坐标**：只接受 `int` / `Fraction` / 可被 `Fraction` 解析的 `str`（如 `"2/3"`），
拒绝 `float`（避免二进制浮点歧义）。所有交点、面积均为精确有理数。

**闭集语义（边界包含规则统一）**：被裁多边形与裁剪窗都视为**闭集**，
裁剪结果也是闭集。内外判定统一为 `cross >= 0`（在裁剪边左闭半平面即算内部）。
因此恰好贴在裁剪边界上的边、线、点一律保留，不会丢失。

**输入校验（非法输入抛出 `ValueError`）**：
- 被裁多边形必须是简单多边形：非相邻边不得有任何交点（含触碰）、
  相邻边不得重叠或折返（尖刺）、顶点不得重复、面积不得为零；
- 裁剪窗必须是面积非零的凸多边形（允许相邻边共线的弱凸），
  自交窗口（如五角星）同样被拒绝；
- 顺/逆时针均可，内部统一规范为逆时针。

**输出**：`ClipResult.regions` 为若干 `Region`（可能多个连通区域）：
- 非退化区域：逆时针、起点为最小顶点的规范形，`area` 为精确面积；
- 退化区域：裁剪结果仅为线段或点时 `degenerate=True`、`area == 0`，
  顶点为规范化的点集（1 个顶点 = 点，2 个及以上共线顶点 = 线段）；
- `Region.edge_sources[i]` 给出边 `vertices[i] -> vertices[(i+1)%n]` 的来源：
  `("subject", i)` 来自被裁多边形第 i 条边，`("clip", j)` 来自裁剪窗第 j 条边
  （编号均按各自输入时的顶点顺序）。

**不变量**（均有测试保障）：
- 输出总面积 ≤ 原多边形面积；窗口包含原图时两者相等；
- 幂等：把输出的非退化区域用同一窗口再裁一次，几何（顶点规范形）不变
  （来源信息按新输入重新标记）；
- 窗口顶点旋转/反向输入，输出几何不变。

## 算法

1. 校验输入（O(n²) 精确相交检测）；
2. Sutherland–Hodgman 逐裁剪边裁剪（闭半平面），每条输出边携带来源标记；
3. 得到的弱简单闭走廓先做“顶点落在边上”的剖分，再在重复顶点处拆成
   若干简单环 —— 多个连通区域由此产生；
4. 纯裁剪边界上往返的零面积“桥”不是真实几何，丢弃；
   含原图边来源的退化环（贴边线段、触点）保留并标记 `degenerate`；
5. 每个环规范化为逆时针、最小顶点起点的规范形后输出。

## 运行

```bash
python3.11 demo.py                    # 运行样例
python3.11 -m unittest test_polygon_clip -v   # 运行测试
```
