# WPS PIN分半验证的位置泄漏与失败锁定

无线路由器的 WPS 外部注册协议用 8 位 PIN，最后一位是校验位，协议把 PIN 拆成前 4 位与后 3 位分别验证，接入点若在第一半错误时就返回失败，攻击者就能分别猜两半，把 10 的 7 次方次尝试降到约一万一千次。为C++17路由器固件写供 WPS 状态机调用的 PIN 验证与锁定库，输入 PIN 的 8 个数字、注册方提交的两半承诺材料和锁定策略：校验位按“前 7 位中第 1、3、5、7 位之和乘 3，加上第 2、4、6 位之和，模 10 后取补”计算，校验位错误的 PIN 在进入协议前拒绝；两半的验证结果在整个交换结束前不得有任何可区分的响应，第一半错误时仍须完成第二半的运算，最终只返回统一的失败码，响应时间差不得依赖哪一半出错；失败累计 3 次后锁定，锁定时长从 60 秒起每次翻倍，上限 24 小时，锁定期间对任何 PIN 的请求直接拒绝且不做计算；锁定状态必须持久化，重启不清零，更换注册方 MAC 也不重置；成功一次清零失败计数。用第一半错误与第二半错误的响应一致、校验位错误、重启后仍锁定、更换 MAC 和锁定时长翻倍验证，并枚举全部一万个前半值核对计时一致。
