# bezierextrema — 一维有理 Bézier 曲线在 [0,1] 上的认证极值

只用 Go 标准库(`math/big` 精确有理数运算),对次数 1–5、控制值与正权重
均为有理数的曲线 B(t) = N(t)/D(t),求导数分子 P = N'D − ND' 在 (0,1) 的
全部实根,并给出可独立验证的证书。**全程无浮点运算。**

## 方法

- **实根隔离**:对 P 的无平方部分 Q 构造 Sturm 序列,在 (0,1) 上二分
  隔离全部实根;每个根表示为「整系数多项式 Q + 有理隔离区间 [l,r]」,
  区间宽度 ≤ ε。有理根精确命中([l,r] 退化)。
- **重数**:root 重数 = 使 gcd(Q, P^(k)) 在该区间内有根的最大连续 k,
  精确判定;偶重数为驻留拐点(不改变单调性),奇重数为局部极值。
- **单调性**:相邻隔离区间之间取有理采样点,精确求 P 的符号
  (sign B′ = sign P,因为 B′ = P/D² 且 D > 0)。
- **并列极值(精确,不靠浮点)**:构造结式 R(y) = Res_t(Q, N − yD)
  (Sylvester 行列式,用 Bareiss 无分数算法 + 插值)。候选点的值 B(α)
  必为 R 的根;两个候选值相等 ⟺ 其值包围盒与 R 的同一个根隔离区间
  相交。端点的有理值 v 与驻点值相等 ⟺ R(v) = 0 且落在同一区间。
  因此并列极值的所有参数都被保留,恒定曲线返回整段 [0,1]。
- **值包围**:对含根参数区间做精确区间算术(Horner),细化到宽度 ≤ ε。
- **分母正性**:权重全正 ⟹ D 是正数的凸组合;另用 Sturm 计数独立
  验证 D 在 (0,1] 无根且 D(0) > 0。

## 证书检查器

`verify` 子命令独立重算并检查:导数分子与证书一致、根数 = Sturm 计数、
每个隔离区间变号差恰为 1、区间互不相交且有序、宽度 ≤ ε、重数(gcd 法)、
单调性标签(独立采样)、分母正性、值包围可靠(包含重算包围盒且 ≤ ε)、
并列分组(结式法)以及全局最大/最小的参数集合完全一致(不缺不多)。

## 用法

```sh
go run . solve  -values "0,1,0" -weights "1,2,1" -eps "1/1000" -out cert.json
go run . verify -cert cert.json
```

有理数写作 `p/q` 或整数;`-out -` 把证书 JSON 打到标准输出。

## 测试

```sh
go test ./...
```

覆盖:线性、对称二次(端点并列最小)、带权二次(非多项式)、常值、
重驻点 ((t−1/2)³,二重根)、极近驻点(相距 10⁻⁶,认证分离)、
W 形四次(两个并列最小值 + 端点并列最大值)、端点驻点 (t³)、
五次带权曲线,以及篡改证书(重数/并列/值区间/单调性/根数)必须被拒。
高精度采样(4000 点精确求值)仅作辅助佐证,不作为完整性证明。
