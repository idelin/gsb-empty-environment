# 只泄露解密奇偶性的密钥服务

密钥服务统一了错误文本，却仍有回调泄露解密整数的最低位。请做供Go密码回归宿主调用的攻击验证包，只面对本地测试回调：由本地合法RSA密钥导出的公开奇数模数N和指数e，目标密文c=m^e mod N且0≤m<N；回调接收0≤x<N并仅返回x解密后的奇偶性或暂时不可用，测试密钥由宿主生成，包不能读取私钥。通过乘以2的e次方迭代构造查询，用精确有理区间收缩恢复m，禁止浮点近似；当只剩一个整数候选时必须再验m^e mod N=c，才标成功。暂时不可用时保留当前查询，不推进区间；达到调用方总查询预算返回可序列化检查点，恢复需绑定N、e、c与完整查询历史摘要。支持密文0、m接近N、输入非法和连续暂时不可用。提供一个在认证前不解密的修复回调，其统一拒绝不能被当成偶数；恢复实验应报告无可用预言。用小模数穷举所有明文核对区间端点，再以宿主生成的较大密钥做随机验证，日志只包含可观察查询与推导，不能记录回调内部明文。
