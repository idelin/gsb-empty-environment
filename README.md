采用页级公共前缀截断的 B+ 树在变长键插入溢出时，不同分裂位置会让左右两页产生截然不同的页内公共前缀长度与父级分隔键长度，随便对半分常导致单页仍超字节上限或父节点过早连锁分裂。为页存储管理器交付可导入的 Go 节点重平衡包。输入页总字节上限 P、页头固定开销 H、每条记录的槽目录开销 S、键前缀共享编码规则（页内所有键存一个共享前缀及各自后缀字节，叶页每条记录另带定长值指针，内页另带子节点指针）、最小填充字节阈值 M，以及待插入新键后的有序条目列表和左右兄弟页当前内容。规则：先检查能否通过向单个相邻兄弟重分布借移若干边界键避免分裂（两页均须 ≤P 且重分布后新父分隔键为满足区分左右键的最短前缀后缀截断键）；不能重分布时选择合法分裂点（左右页编码总字节均 ≤P 且 ≥M），在所有合法分裂点中使推广到父节点的最小区分分隔键字节数最短，并列使左右两页编码字节差绝对值最小，再按左页键数最小决胜。组件返回动作（重分布或分裂）、新左右页精确前缀与编码字节数，以及最短合法父分隔键。验收用全部切分点穷举与字节编码还原核对所有键无损、父分隔键严格满足 `max(Left) < sep <= min(Right)` 且最短，覆盖公共前缀因分裂剧增而让原本放不下的切分变合法、重分布优于分裂、最短分隔键截断后仍区分，以及无合法分裂点时报告单键超页上限。
