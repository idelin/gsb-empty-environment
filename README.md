RPC 网关把来自多个服务的错误原因图投影给客户端，根错误公开并不意味着所有嵌套原因都可公开。实现可导入的 TypeScript 错误出口包。节点带服务身份、租户、类型 URL、原始字节与逐字段披露声明，原因和补充详情是有序边，可共享节点或成环。对外消息由给定 schema 解码，未知类型必须隔离；同类型在不同注册表版本可以有不同字段含义。投影不能泄漏隐藏节点的存在：返回的序号、原因数量、去重结果、截断位置及序列化字节数都只由调用者可见的子图决定。全局字节与节点预算按投影后的规范序列化计量；截断只能在字段边界，给出可核验的继续游标，游标不能跨租户、注册表或权限代次复用。后台可保存完整诊断但公开证书仅含获准字节。用独立小图投影解释器和成对历史对照，共享节点经两种权限路径、隐藏分支先于公开分支、递归详情、注册表热更新及恰好只能放下空字符串的预算都应得到确定输出。
