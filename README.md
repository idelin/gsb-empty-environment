# 布尔特性两两覆盖测试生成器

接收布尔特性及互斥（mutex）、蕴含（implies）约束，生成**数量最小**的合法配置集，
覆盖全部**可达**两两取值组合，并对配置数的最小性给出可检验的证明。

## 运行

需要 Node.js ≥ 23.6（原生 TypeScript 类型擦除，无需编译、无第三方依赖）。

```bash
node src/cli.ts <input.json>          # 人类可读报告
node src/cli.ts <input.json> --json   # 机器可读输出
npm test                              # 运行测试（含独立暴力验证）
```

## 输入格式

```json
{
  "features": ["A", "B", "C", "D"],
  "constraints": [
    { "type": "mutex", "a": "C", "b": "D" },
    { "type": "implies", "from": "A", "to": "C" }
  ]
}
```

- 特性数 1–12，名称唯一。
- `mutex(a, b)`：两者不能同时取 1；`implies(a, b)`：a=1 时 b 必须为 1。
- 示例见 `examples/`（`basic.json`、`chain.json`、`constrained12.json`、`unconstrained12.json`）。

## 方法

1. **枚举合法配置**：n ≤ 12 ⇒ 全空间 ≤ 4096，逐条用约束过滤（全零配置恒合法，故解必然存在）。
2. **可达组合**：对每个合法配置计算其覆盖的两两组合位掩码（BigInt），取并集得到可达集；
   不可达组合**不计入**覆盖率，单独列出并附解释。
3. **最小覆盖 = 精确集合覆盖**：
   - 构造阶段：贪心 + 去冗余 + min-conflicts 局部搜索，得到上界见证；
   - 下界（证明核心，取四者最大）：
     - **特性对界限**：任一特性对的可达组合数（每个配置至多贡献 1 个）；
     - **总量界限**：⌈可达组合数 / 单配置覆盖数⌉；
     - **结构界限**（Kleitman–Spencer 型）：若某特性子集内部组合全部可达，k 个配置在其上
       构成二元 2-覆盖族，大小不超过 maxk(k)；maxk(N) 由精确最大团算出
       （maxk(6)=10、maxk(7)=15，故 12 个无约束特性需要 7 个配置）；
     - **LP 界限**：集合覆盖 LP 松弛的对偶打包值，由乘性权重法求得，负载为精确整数，
       对偶可行性可精确验证；
   - 若见证等于下界，直接得证；否则对介于其间的每个 k 运行**穷尽分支限界**
     （MRV 分支、逐节点界限剪枝、翻转/置换对称性破缺、失败状态记忆化），
     全部失败即排除更小覆盖。
4. **自校验**：输出的每个配置逐一验证合法、并集验证覆盖全部可达组合（非法配置使用数恒为 0）。

## 不可达组合的解释

- **直接违反**：组合本身违反某条约束（如 mutex 双方同取 1）。
- **传播矛盾**：固定组合取值后做单元传播，推出某特性同时被要求取 0 和 1，
  输出完整推导链。mutex/implies 均为 Horn 子句，Horn 公式上单元传播是完备的，
  故不可达组合必有此类证明；万一传播未推出矛盾，则回退为在最小约束子集上
  穷举全部 2^n 赋值作为证明。

## 输出内容

- 合法配置数、可达/不可达组合数；
- 最小配置集（每个配置的全部特性取值）；
- 最小性证明：各项下界的具体数值与理由，以及（如有）每个被排除目标 k 的搜索统计；
- 覆盖校验结果（可达组合 100%，非法配置 0）；
- 不可达组合逐条解释。

## 文件结构

- `src/types.ts` — 约束类型与格式化
- `src/solver.ts` — 枚举、可达集、精确最小覆盖（构造 + 分支限界）
- `src/bounds.ts` — 结构界限（maxk 精确最大团）与 LP 对偶界限
- `src/explain.ts` — 不可达组合的解释生成
- `src/cli.ts` — 命令行入口与报告
- `test/solver.test.ts` — 测试（含对全部小实例的独立暴力最小性验证）
