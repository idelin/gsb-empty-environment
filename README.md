# dagindex — DAG 可达性位图索引器

Go 标准库实现的有向无环图全节点可达性查询索引。

## 设计

- **拓扑层级**：每个节点维护 `level`（最长路径深度），边插入时若违反层级约束则沿下游提升层级，保证所有边从低层指向高层。
- **压缩位图**：每个节点 `u` 保存其传递闭包下游集合 `down[u]`（含自身）。位图按 64 位字切分，仅存储非零字（稀疏字压缩），内存与可达点对数成正比，严格小于稠密 N×N 位矩阵。
- **增量更新**：插入边 `u->v` 时，将常量集合 `down[v]` 沿 `u` 的前驱链做字级并行 OR（每步合并 64 个可达事实），集合不再变化的祖先立即剪枝。
- **O(1) 查询**：`Reachable(u, v)` 即一次位测试。
- **环检测**：若 `v` 已可达 `u`，拒绝插入并保持索引不变。

## 运行

```sh
go test ./... -v   # 测试（含分层 DAG、跨层边更新、环拒绝、压缩上界、随机 DAG 对照 BFS）
go run ./cmd/demo  # 运行样例
```
