# CABAC 内核（上下文自适应二进制算术编码）

仿视频编码标准（H.264/AVC 的 M-coder）的上下文自适应熵编码内核，TypeScript 实现，
零依赖，使用 Node.js 内置测试运行器验证。

## 特性

- **64 状态概率模型**：每个语法元素的每个 bin 绑定独立上下文（状态编号 + MPS 方向），
  通过查表（`rangeTabLPS`）完成无乘法的区间更新，与硬件友好实现一致；
- **状态随命中迁移**：每编码一个 bin，按命中情况沿 `TRANS_IDX_MPS` / `TRANS_IDX_LPS`
  迁移概率状态编号，在线跟踪局部统计特性，榨干连续符号的统计相关冗余；
- **多上下文建模**：repeat 标志、操作码截断一元码（按前一指令操作码条件化的一阶上下文）、
  寄存器字段前缀树上下文，不同语法元素维护独立的状态转移概率模型；
- **可切换静态基线**：`adaptive=false` 时状态冻结，退化为无上下文静态算术编码，用于对照。

## 目录结构

```
src/
  tables.ts        概率状态表（rangeTabLPS / 状态转移表 / 概率-状态反查）
  bitstream.ts     MSB-first 比特流读写器
  cabac.ts         CABAC 内核：ContextModel / CabacEncoder / CabacDecoder
  isa.ts           指令语法层：二值化方案、上下文布局、结构化指令流生成器
  static_model.ts  对照基线：无上下文静态模型（全局直方图训练后冻结）
  demo.ts          运行样例
test/
  cabac.test.ts    引擎测试（往返 / 状态迁移 / MPS 翻转 / 穷举往返）
  isa.test.ts      指令层与验收测试
```

## 环境要求

Node.js >= 22.6（利用原生 TypeScript 类型擦除直接运行 `.ts`，无需编译与任何依赖）。

## 运行

```bash
node src/demo.ts     # 运行样例（压缩率对比 + 收敛曲线）
node --test          # 运行全部测试
```

### 整体压缩率对比（10 万条指令）

高频指令流（延时循环形态）：

| 模型 | 比特/指令 | 相对 CABAC |
|---|---|---|
| 原始定长 | 11.00 | 57.0x |
| 静态均匀（p=0.5，无上下文） | 1.13 | 5.9x |
| 静态训练（全局直方图，无上下文） | 0.21 | 1.08x |
| **CABAC（上下文自适应）** | **0.193** | 1.0x |

多相位结构化程序（非平稳信源：紧循环 + 顺序块，统计特性随相位迁移）：

| 模型 | 比特/指令 | 相对 CABAC |
|---|---|---|
| 原始定长 | 11.00 | 4.0x |
| 静态均匀（p=0.5，无上下文） | 4.73 | 1.7x |
| 静态训练（全局直方图，无上下文） | 4.12 | 1.48x |
| **CABAC（上下文自适应）** | **2.78** | 1.0x |

注：平稳信源下训练后的静态模型接近熵率（信息论极限），CABAC 的核心优势在于
**在线自适应**（单遍、无需预训练/传输模型）与**非平稳信源跟踪**（多相位流上
领先训练后冻结的静态模型 1.48 倍）。

## 与 H.264 规范的两处有意偏差

1. `TRANS_IDX_LPS[63]` 取 62（规范为 63 吸收态）：本内核面向长流、无切片级上下文
   重置的场景，保证状态机始终可逆迁移、MPS 可翻转；
2. `rangeTabLPS[63]` 取 `{5,6,8,9}`（规范为 `{2,2,2,2}`，原是配合吸收态的极端钳位）：
   按几何级数 `pLPS = 0.5 * 0.95^63` 取值，使长流稳态码率贴近熵率。
