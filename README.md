# Slotted-Page：紧凑可变长字节槽位页管理器

固定 4KB 页的内存紧凑存储，TypeScript 实现，零依赖，Node.js 内置测试。

## 页布局

```
0                8                freeStart        freeEnd            4096
┌────────────┬───────────────────┬────────────────┬──────────────────┐
│ 页头(8B)   │ 槽位数组(向前增长) │  连续空闲空间   │ 记录数据(向后增长) │
└────────────┴───────────────────┴────────────────┴──────────────────┘
```

- **页头（8B）**：`slotCount` / `freeStart` / `freeEnd` / `fragmentedBytes`（uint16 LE）
- **槽位（每条 4B）**：`offset` + `length`，从页前向后增长；删除置墓碑 `offset=0xFFFF`，槽位 id 稳定且可复用
- **记录数据**：可变长字节，从页尾向页前紧密填充

## API

| 方法 | 说明 |
| --- | --- |
| `insert(data)` | 写入可变长记录，返回槽位 id；空间不足抛 `PageFullError` |
| `get(slotId)` | 读取记录，已删除/越界返回 `null` |
| `delete(slotId)` | 墓碑删除，记录字节计入碎片 |
| `compact()` | 碎片整理：存活记录向页尾对齐压实，重写槽位偏移，空闲空间合并为一段 |
| `freeSpace()` / `fragmentedSpace()` / `stats()` | 空间统计 |

## 运行

```bash
npm test    # node --test（Node ≥ 23，原生运行 TypeScript）
npm run demo
```

## 验收路径（demo 输出）

1. 写入 7 条长短不一记录 → 连续空闲 1515B，利用率 62.1%
2. 删除中间 3 条 → 产生 1928B 碎片，连续空闲不变
3. `compact()` → 存活数据向页尾对齐、槽位偏移重写，碎片归零，连续空闲合并为 3443B
4. 存活记录逐字节校验一致；后续写入复用墓碑槽位
