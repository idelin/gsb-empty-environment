# eventstabilizer

弱有序事件流的拓扑重排稳定化窗口（Go，仅标准库）。

## 概述

面向乱序监控事件的稳定性延迟窗口算子。设定最大逻辑时间乱序窗口 `K`，
算子收集乱序事件流，在逻辑时钟推进越过安全线（水位线 `maxSeq - K`）后，
才输出严格按因果全序排列的标准化事件序列。

## 设计

- `Event`：携带逻辑时钟 `Seq`、传感器标识 `Source`、测量值 `Value`。
- `Stabilizer`：内部维护基于 `container/heap` 的最小优先级队列，
  键为 `(Seq, arrival)`——相同逻辑时钟的事件按到达次序决胜，
  保证全局严格全序。
- `Push(e) []Event`：摄入一个事件，返回本次越过水位线而稳定化的事件
  （可能为空）。水位线未越过的事件一律缓存在堆中。
- `Flush() []Event`：输入流结束时排空残余事件。
- 迟到事件（`Seq <= lastEmitted`，即乱序度超出窗口 `K`）被丢弃并计入
  `Dropped()`，输出流因此严格具备全局时态单调性。

## 运行

```sh
go test ./... -v   # 测试
go run ./cmd/demo  # 样例：含微小时间回退的传感器事件流
```
