列存或流式算子在严格内存预算下归并几十个溢出到盘的有序段时，既要处理 `NULLS FIRST/LAST` 和多键升降序稳定比较，又要在输入段数超过可用内存帧数时规划出总磁盘 I/O 字节最少的多趟归并树。为执行内核交付可嵌入的 C++20 外部归并组件。输入 N 个初始有序段（各段含字节大小及若干带复合键、空值标志和变长字节负载的记录）、可用总缓冲帧数 B（B≥3，每趟归并需占 1 帧输出缓冲和最多 B-1 帧输入缓冲）及排序规格（多列各自升/降序与 `NULLS FIRST/LAST`）。组件分两部分：第一部分规划最优 k 路多趟归并树（哈夫曼 k-叉最优归并树，按需要补齐虚段使每次满扇入合并，最小化除原始输入与最终输出外的全部中间落盘读写总字节数，并列按合并趟数最少）；第二部分使用败者树（Loser Tree）在内存严格受限于每路单帧下实际执行各趟归并，严格保证等键记录按原始段号及段内顺序稳定输出。验收对照全量内存稳定排序结果逐条完全一致，并用小规模全合并树搜索核对中间磁盘 I/O 总字节精确最优，覆盖 N 不满足 (N-1) mod (k-1) == 0 时首趟虚段补齐降低总 I/O、复合键含 `NULLS FIRST` 与 `DESC` 组合、空段跳过，以及等键跨多段稳定保序。
