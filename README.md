给 TypeScript 邮件投递服务写可导入的路由授权组件。域名所有者通过宿主提供的验签回调签发路由声明，每份含序号、前版摘要、有序 MX 规则、起止时间和是否撤销。序号从 0 开始；相同序号不同摘要构成分叉，该域的投递凭据立即停用，直到受信根签出同时引用两条分支头的恢复声明。旧分支之后补到的声明不能撤回恢复结果。MX 规则按标签比较，允许精确主机或仅覆盖一个子标签的通配，每条可绑定多个证书公钥摘要。投递时必须同时选中一条满足主机和公钥的规则，不许各取一条拼接。缓存中为进行中握手保存域、声明摘要、MX 和实际公钥；最终发信前由宿主原子核对这四项仍获授权。两个不同域的序列相互独立。提供可控时钟与乱序事件测试，验证过期、先到后继、重放旧分支、跨规则拼接和握手途中撤销。
