# LSM钩子inode决策与审计

eBPF LSM 钩子拒绝打开受保护文件，攻击者借硬链接、重命名、绑定挂载或并发切换挂载命名空间换路径，审计与决定不一致会掩盖拒绝。为 C++17 守护组件实现供模拟内核钩子调用的决策与审计包：策略按（设备号，inode）保护文件，路径只进日志；程序按挂载顺序执行，首个拒绝即终态且不再执行后续；每调用恰一条审计，含最终决定、首个拒绝程序与 inode；环形缓冲写满仍按策略拒绝并累加丢失计数，下一条成功记录携带此前累计丢失数，并发下计数与记录不得错配；策略代次切换时在途调用按旧代次完成并标代次，新调用立即用新代次；给出的审计须能按序重放出与决策一致的丢失计数序列。用别名、并发命名空间切换、多程序顺序、缓冲写满与代次切换对照。
