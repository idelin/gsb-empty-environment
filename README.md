# 异步任务继承了过期的模拟令牌

服务线程为一个请求临时模拟低权限客户端，异步回调若捕获线程令牌并在请求结束后继续使用，可能跨请求混淆身份。给Go服务宿主实现可导入的模拟作用域组件：进程有固定主令牌，线程可持模拟栈，每个令牌绑定认证连接ID、请求ID、代次、级别{Identification,Impersonation,Delegation}和不可延长以宿主单调时钟表示的截止时刻。Enter只能压入当前请求由认证层签发的令牌；Identification只能读取身份不能访问资源，Impersonation仅限本机资源，Delegation才可调用远端。SpawnAsync必须显式选择NoIdentity或Capture：Capture生成只读身份快照但默认降为Identification；若要保留更高级别，调用方须持宿主授权且任务截止不晚于请求，任务句柄绑定请求代次。Exit按栈顶令牌精确弹出，连接重用或请求结束撤销该代全部任务身份；回调开始与每次资源调用都重验句柄。panic或取消必须恢复原栈，不能RevertToSelf后丢失外层模拟。用确定调度器交错两个请求，搜索待审实现中回调以另一请求或已结束请求身份成功访问的最短轨迹，覆盖嵌套模拟、线程池复用、外层恢复及远端Delegation。
