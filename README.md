统计平台正把一组有状态查询机制开放给外部分析者。分析者能看见每次公开回答再选择下一条查询，某些机制还会沿用上一步的内部随机状态；把各轮上限独立相加无法判断这份配置是否满足承诺。请扩展现有 TypeScript 模块，给发布宿主提供可导入的隐私准入组件，沿用 src/weight.ts 的有理概率字节格式。输入仅为两组相邻数据集上的合成有限状态概率表，没有真实个人记录。每种公开查询把当前隐藏状态按精确概率变成一对公开回答和后继隐藏状态。给定最多8轮、每轮允许的查询、公开历史决定的提前结束规则以及正有理数倍率 L≥1，要计算所有可按公开历史行动的分析者中最坏的双向偏差：对终止转录的两种概率分布 P、Q，偏差为各转录 max(P−LQ,0) 之和，两方向取大。相同观察历史下不能在两份数据上各选不同查询，隐藏状态也不能当作可见信息。返回精确分数和独立可复核的上界证书，不输出针对个人的识别方法。要正确处理某个历史在一侧概率为零、几个隐藏分支发出相同回答、停止本身可见和共用随机状态；不能枚举完整自适应策略树。用小表暴力核对，另给大量重复后验状态的8轮实例检验共享计算。
