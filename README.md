块设备聚合器需要可导入的 Go 包，把多路径 SCSI 风格的残余长度报告还原为可确认的写入区域。每次命令沿 scatter/gather 段序列连续传输，残余在给定闭区间；多个重试可更换路径及分段，覆盖以物理完成次序为准。控制器只记录每路径 FIFO 和部分跨路径完成边，带 flush 的提交仅在其依赖的写实际落入稳定层后才可见。定义一次掉电切点为偏序的任一向下闭合集合，已知观察到的 flush 必须在内，其他写可在内或不在。按最终可读来源把目标 LBA 范围分成确定、或有歧义的最大区间，歧义返回两个合法执行；没有满足观察的执行应单独报错。每冲突分量最多十二命令，地址空间为 64 位，不逐块枚举。测试用小盘穷举传输前缀、完成序及切点，覆盖单命令的散列表回写同一 LBA、重复重试及 flush 后的竞争写。
