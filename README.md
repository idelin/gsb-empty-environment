支持单条确认的消息消费者在部分消息失败转入多级延迟重投时，既要向前推进连续提交位点，又要靠最大未确认跨度防止个别慢消息无限拉长恢复窗口。给消息代理分区协调器交付可导入的 Go 位点状态机包。输入分区起始偏移、最大在途跨度 W、每级延迟表与最大重试次数，以及按毫秒递增的拉取发射、确认 ACK、否定重投 NACK、延迟到期、分区切主重连和超时事件。规则为：仅当消息最终 ACK 或达到最大重试转入死信，才视为终态；NACK 且未达上限时，若已转入独立延迟主题并取得延迟投递凭证，原分区偏移立即视为终态可推进主位点，否则原地占坑直至下次重试终态；任意时刻新发射偏移与最小未终态偏移之差不得超过 W，阻塞时须报告精确阻塞偏移与未终态集合；切主重连后未终态原分区偏移须重置为待重发而不得丢失已确认空洞。验收用事件流对照朴素全状态表，覆盖跨度刚好达 W 被最老偏移卡住、带凭证转延迟队列立即释放主位点空洞、达到上限进死信解锁窗口、以及切主后保留高偏移已确认记录并重发低偏移空洞。
