# 跨源置信证据决策引擎

一个用 Python 3.11 标准库实现的**可追溯规则推理引擎**。规则为确定子句（有限事实
集合推出单个事实），**不支持否定**；事实可由多个互相独立的来源提供。引擎输出派生
事实的**最小来源集合**，并在撤销来源时只删除失去全部支持的派生事实。所有示例数据
均为合成数据。

## 运行方式

```bash
# 方式一：可执行包装脚本
./run_engine examples/acceptance.json

# 方式二：模块方式（文件参数；- 表示标准输入）
python3.11 -m evidence_engine examples/acceptance.json
echo '{...}' | python3.11 -m evidence_engine -
```

运行测试：

```bash
python3.11 -m unittest discover -s tests -v
```

## 语义定义

- **事实**：非空字符串（基原子），例如 `"A"`。
- **来源**：非空字符串，例如 `"s"`。来源之间相互独立；一个事实可被多个来源断言。
- **规则**：`{"premises": [事实...], "conclusion": 事实}`。前提按集合处理（去重），
  结论唯一。前提列表允许为空，表示**公理规则**：结论由空来源集 `[]` 支持，不依赖
  任何外部来源，也不会被撤销来源删除。没有否定、没有失败即否定。
- **推理**：对每条规则，从每个前提各选一个来源集合，取并集作为结论的来源集合。
- **最小性**：每个事实只保留按集合包含关系极小的来源集合（反链）。若 `S ⊊ T`，
  则丢弃 `T`。输出顺序先按来源数量升序，数量相同再按来源 id 排序元组的字典序。
- **最小不动点（防循环自举）**：推理从基事实出发做半朴素前向链接，取最小不动点。
  因此循环规则**不能凭空自我支持**：环上若没有任何外部/公理支撑，环中所有事实都
  不成立；一旦环上某事实获得独立来源，整个可达环按该来源成立。
- **撤销**：撤销某来源后，从剩余基事实重新计算最小不动点。只有失去全部来源支持的
  派生事实才会消失；仍有独立来源支持的事实（及其可派生的事实）保留。
- **可追溯性**：内部记录每个来源集合的配方（基断言或规则 + 各前提所选集合），
  `Engine.trace(fact)` 返回最小来源集合对应的完整证明树。
- **预算与中断**：最小来源集合的数量可能指数增长。`budget` 统计已处理的基断言、
  公理触发和规则组合总数；超过预算时停止计算并将 `interrupted` 置为 `true`。
  此时返回的状态是**可靠但可能不完整的前缀**（报告出的每个支持都真实存在，但可能
  尚未枚举全部最小支持），调用方必须检查该标记。

### 为什么保留整条包含反链而不只是单个最小集合

只保留每个前提“数量最少/字典序最小”的单个集合，可能丢失全局最优：某前提上数量相同
但字典序更大的集合，可能与其他前提的来源重叠更好，并集反而更小。因此引擎保留所有
互相不包含的极小集合，再统一按（数量、字典序）排序。

## 输入格式

单个 JSON 文档（文件路径或标准输入）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `budget` | 整数，可选 | 推导预算，默认 `1000000`，必须非负 |
| `rules` | 数组 | 规则列表，`premises` 为字符串数组，`conclusion` 为字符串 |
| `base` | 数组，可选 | 初始基断言，元素为 `{"source": ..., "fact": ...}`，按序施加 |
| `commands` | 数组，可选 | 依次执行的命令，见下 |

命令：

- `{"op": "add", "source": s, "fact": F}`：由来源 s 断言事实 F 后重新求不动点。
- `{"op": "revoke", "source": s}`：撤销来源 s 的全部基断言后重新求不动点。
- `{"op": "supports", "fact": F}`：查询 F 的全部最小来源集合及 `supported`。
- `{"op": "state"}`：输出当前成立的全部事实及其最小来源集合。

其他未知字段会被忽略。输入非法（字段类型错误、空字符串、未知操作码）时进程以
退出码 2 报错并向 stderr 输出原因。

## 输出格式

标准输出为 `{"results": [ ... ]}`，每个命令对应一个结果对象。

`add` / `revoke` 结果：

```json
{"op": "revoke", "source": "s", "interrupted": false, "derivations": 0}
```

`supports` 结果（集合以排序后的数组表示；不支持的事实返回空列表）：

```json
{"fact": "A", "supported": true, "supports": [["t"]],
 "interrupted": false, "derivations": 3}
```

`state` 结果：`facts` 为排序事实名数组，`state` 将每个事实映射到其最小来源集合
列表（同样按数量、字典序排序）。所有结果都带 `interrupted` 与 `derivations`。

## 验收边界（合成数据）

规则 `A -> B`、`B -> A`，来源 `s` 断言 `A`：

1. `A`、`B` 均由 `{s}` 支持（B 经 A 推出，A 也可经 B 循环推出，但根基仍是 s）。
2. 撤销 `s` 后重新求值：循环没有任何外部支撑，`A` 与 `B` **同时消失**。
3. 再增加独立来源 `t` 断言 `B`：`B` 由 `{t}` 直接支持，`A` 经 `B -> A` 由 `{t}`
   支持，**二者保留**。

运行：

```bash
./run_engine examples/acceptance.json
```

## 库 API 摘要

```python
from evidence_engine import Engine, Rule

engine = Engine([Rule(["A"], "B"), Rule(["B"], "A")], budget=1_000_000)
engine.add_source("s", "A")
engine.supports("B")          # [frozenset({"s"})]，按(数量,字典序)排序
engine.trace("B")             # 最小支持的证明树
engine.revoke_source("s")
engine.all_facts()            # []
engine.interrupted            # 是否触发预算中断
engine.derivations            # 已处理推导数
```

## 已验证范围与未声称事项

- 已用 21 个 `unittest` 用例验证：验收边界、多独立来源、并集/支配消除、
  数量+字典序排序、跨切面来源备选、撤销级联、空前提公理、证明树、预算中断与
  中断前缀可靠性、输入校验，以及 CLI 层行为。全部通过（Python 3.11.15）。
- 预算中断时仅保证结果**可靠**，**不保证**已枚举全部最小来源集合；该场景下
  “最小/最优”输出可能不完整，已由 `interrupted=true` 显式标记。
- 引擎未做增量维护，每次增删来源都整体重算最小不动点；这是有意选择，优先保证
  撤销语义简单正确，未对大规模输入做性能最优保证。
