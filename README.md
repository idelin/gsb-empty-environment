# 视频编辑器要把两路不同曝光画面拼成平滑接缝

视频编辑器要把两路不同曝光画面拼成平滑接缝。实现供Go图像管线调用的最小代价缝合包，输入已配准线性RGB帧及重叠掩码，缝必须每行一个有效像素且相邻行横移不超过一；代价为颜色差加梯度差，视频相邻帧再加与前缝距离惩罚。掩码不连通返回无法拼接，不能跨无效像素。用小图全路径枚举核对最优缝及字典序平局，并输出固定宽度的线性光羽化结果。

## 包 `taskpkg`

- `Frame`：行优先存储的线性光 RGB 帧（每像素 3 个 `float64`）。
- `Mask`：重叠区有效性掩码，缝合线只能经过 `true` 像素。
- `Find(a, b, overlap, prevSeam, opts)`：逐行动态规划求最小代价缝。
  - 单像素代价 = 两帧颜色欧氏距离平方 + 水平/垂直中心差分梯度差平方和；
    提供 `prevSeam` 时再加 `TemporalWeight * |x - 前缝列坐标|`。
  - 约束：每行一个有效像素，相邻行列坐标差绝对值不超过 1。
  - 不存在贯穿所有行的 8 连通有效组件时返回 `ErrDisconnected`。
  - 代价并列时返回字典序最小的缝（自上而下比较列坐标）。
- `Feather(a, b, overlap, seam, halfWidth)`：在线性光空间按固定宽度
  `2*halfWidth` 做 alpha 线性过渡；`halfWidth=0` 为缝处硬切。

## 验证

`go test ./...` 在随机小图上深度优先枚举全部合法缝，逐一对账动态规划
输出的最优代价与字典序平局，并覆盖时间域惩罚、不连通报错和羽化结果。
