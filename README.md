# delegation

多租户服务允许后台作业携带一次性授权继续执行。为Go作业执行器实现可委派的票据校验包，每次转授只能收窄对象集合、动作及期限，撤销祖先后全部后代失效。用同一票据并发启动两个作业只允许一个取得执行权；验证撤销与领取交错时有一致的先后顺序，失败验证不会消耗票据。

## 模型

票据（`Ticket`）是一张带签名的能力凭证，包含租户、对象集合、动作集合和绝对截止时间。
根票据由 `Service.Issue` 签发，`Service.Delegate` 在其基础上派生子票据，形成一棵委派树。
令牌格式为 `v1.<base64 载荷>.<base64 HMAC-SHA256 签名>`，载荷可被作业方读取但无法篡改：
任何字段改动都会使签名校验失败（`ErrInvalidToken`）。

## API

| 方法 | 语义 |
| --- | --- |
| `NewService(key, opts...)` | 创建票据权威；HMAC 密钥至少 32 字节，可用 `WithClock` 注入时钟 |
| `Issue(scope)` | 签发根票据，返回签名令牌；集合会被去重、排序 |
| `Delegate(token, scope)` | 收窄转授：同租户、期限不延长、对象/动作必须是父票据的非空子集 |
| `Revoke(token)` | 撤销该票据及其整棵子树；操作幂等 |
| `Validate(token)` | 只读校验（签名、期限、撤销、是否已领取），不消耗票据 |
| `Claim(token, tenant, object, action, jobID)` | 原子校验并领取一次性执行权，成功后票据标记为已消耗 |

## 保证的不变量

- **只能收窄**：`Delegate` 对租户、对象集合、动作集合、期限分别做子集/不延长校验，
  任何扩大尝试返回 `ErrScopeWidened`，空集合或空白条目返回 `ErrMalformedScope`。
- **撤销向下传播**：撤销祖先后，子树全部失效（`ErrTicketRevoked`）；
  撤销时递归标记子树，校验时同时沿父链向上检查，兄弟分支不受影响。
- **一次性领取**：`Claim` 在同一把互斥锁内完成全部检查并写入 `consumed` 标记，
  并发领取只有一个成功，其余得到 `ErrTicketConsumed`。
- **线性化顺序**：撤销与领取的所有状态读写都由 `Service` 的单把 `sync.Mutex` 串行化，
  二者并发时必然有明确的先后顺序，且后续调用观察到的状态与该顺序一致。
- **失败不消耗**：签名错误、过期、已撤销、超出授权范围等失败分支都在写入
  `consumed` 之前返回，同一令牌修正请求后可重试；`Validate` 本身不改变任何状态。

## 测试

```sh
go test -race -count=1 ./...
```

测试覆盖收窄规则（含跨租户、延长期限、集合扩大）、撤销子树传播、64 路并发领取
（25 轮，每轮恰有一个胜出）、200 组撤销/领取交错的一致性，以及失败验证后票据仍可领取。
