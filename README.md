# fwaudit — 防火墙固件字节码越界读取审计器

对无环指令图做符号执行，找出所有**可达的越界数组读取**，并为每一处给出
**能重放的最小字典序输入**。同一输入字节被重复读取时取值一致（输入是按位置
索引的字节数组，而非流）。

## 指令集

寄存器为 8 位（每程序 1–16 个），后继为 `-1` 表示停机。

| 指令    | 语义                                            |
| ------- | ----------------------------------------------- |
| `input` | `Reg[dst] = Input[pos]`（按位置读输入字节）     |
| `and`   | `Reg[dst] &= imm`                               |
| `add`   | `Reg[dst] += imm`（mod 256）                    |
| `jnz`   | `Reg[src] != 0` 走 `next[1]`，否则走 `next[0]`  |
| `load`  | `Reg[dst] = Arrays[array][Reg[src]]`            |

`load` 索引越界即固件故障；其后的路径只有在该索引界内才可达。

## 用法

```sh
go run ./cmd/fwaudit examples/oob.json
```

输出每处漏洞的指令位置、越界索引值和最小字典序重放输入（十进制与十六进制）。

## 方法

- 枚举 DAG 上的执行路径，寄存器携带符号表达式（输入字节经 and/add/load 组合）。
- 分支与界内约束累积为路径条件；对每个 `load` 求解 `index >= len(array)`。
- 求解器按输入位置升序、字节值升序回溯，用 256 位值集做可靠剪枝，叶节点精确
  求值——第一个解即字典序最小；未受约束的字节取 0。
- 正确性由 `TestExhaustiveRandom` 保证：1000 个随机短程序上，与 256^n 全输入
  穷举模拟逐点对照（漏洞位置与最小输入完全一致）。
