# 有限域加法分享多方求和 —— 协议流程模拟器

> **免责声明**：本项目是**协议流程模拟器**，仅用于教学与状态机验证，**只处理合成数据**。
> 它**不构成任何密码学安全背书**，**不声称实现了任何生产级密码协议**。
> **串谋（collusion）与认证（authentication）明确不在本模拟的保证范围内**；
> 基于本模拟器的任何统计实验**不作为形式化隐私证明**。
> 请勿用于真实敏感数据或生产环境。

## 参数与定义

| 符号 | 含义 |
| --- | --- |
| `p` | 有限域 F_p 的素数模数（默认 `2^61 - 1`，构造时校验素性） |
| `n` | 已承诺参与方数量 |
| `t` | 阈值：幸存参与方数量下限，`1 ≤ t ≤ n` |
| `round_id` | 轮次标识，用于轮次隔离 |
| `x_i` | 参与方 `i` 的输入，`x_i ∈ [0, p)` |
| `s_{i→j}` | `i` 分发给 `j` 的加法份额，满足 `Σ_j s_{i→j} ≡ x_i (mod p)` |

- **加法分享 / 还原**：`share_secret` 生成 n-of-n 份额（n−1 个随机值 + 1 个配平值），
  `reconstruct` 计算 `Σ share mod p`，二者在 mod p 下一致。
- **轮次输出定义**：幸存参与方（committed − dropped）输入之和 mod `p`。
  结果对象明确列出 `effective_parties` 与 `dropped`，**绝不以部分和冒充总和**。
- **轮次隔离**：份额携带 `round_id`；旧轮分享、跨轮混用、重复重传一律拒绝。
- **阈值规则**：幸存方数量 `< t` 时轮次 `ABORTED`，不输出任何数值。
- **恢复规则**：幸存方 `i` 针对**已声明掉线**的 `j` 重传其原始份额 `s_{i→j}`；
  恢复材料仅可用于已声明掉线方，且必须与原始分享一致；
  缺少必要恢复份额时返回 `INCOMPLETE`（无输出）。

## 轮次阶段（状态机）

```
COMMIT → SHARE → CONFIRM_DROPOUT → RECOVER → CLOSED
                                      │
                                      └─ 幸存方 < t → ABORTED（无输出）
```

1. **COMMIT**：一次性承诺参与集合，之后不可变更。
2. **SHARE**：每个参与方把输入拆成加法份额并分发给全部已承诺参与方。
3. **CONFIRM_DROPOUT**：声明掉线方集合；幸存方低于阈值则中止。
4. **RECOVER**：幸存方为已声明掉线方提交恢复材料。
5. **输出**：`COMPLETE`（含总和与有效参与集合）/ `INCOMPLETE` / `ABORTED`。

## 明确不在保证范围内

- **串谋**：不模拟、不抵御参与方之间或参与方与聚合者之间的串谋。
- **认证 / 完整性**：份额来源认证、传输安全、恶意聚合者均不在模拟范围内。
- **隐私**：统计实验（如份额分布观察）不构成形式化隐私证明。
- **生产用途**：本代码不是生产密码协议的实现。

## 测试结果（`python3.11 -m unittest`）

29 个测试全部通过，覆盖：

- **有限域一致性**：分享/还原 mod p 一致；非素数模数拒绝；越界秘密值拒绝。
- **守恒性状态探索**：小素数域 `p=7`、3 参与方、阈值 2 下，穷举全部
  `7^3 = 343` 种输入组合 × 8 种掉线模式（共 2744 个状态），
  核验每轮 `COMPLETE` 输出 ≡ 幸存方输入之和 (mod p)，
  阈值不足时一律 `ABORTED` 且无输出。
- **轮次隔离与重放**：旧轮分享、跨轮混用还原、重复份额、重复恢复材料均拒绝。
- **恢复授权**：仅已声明掉线方可作为恢复对象；掉线方不能提交恢复材料；
  篡改的恢复份额拒绝。
- **阈值与未完成**：阈值不足中止且无输出；缺少必要恢复份额返回 `INCOMPLETE`；
  分享不完整不能进入下一阶段。
- **阶段与成员**：越阶段操作、未承诺参与方、重复承诺均拒绝。
