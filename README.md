# hpastar

面向游戏服务器的分层寻路（HPA\*）组件。地图被划分成固定大小的方形簇，
在簇边界建立入口节点并预计算簇内精确路径代价；查询时把起点/终点临时插入
抽象图，在抽象图上做 A\* 搜索，再用预存的 Dijkstra 父树把入口序列细化成
逐格路径。障碍变化时只重建受影响的簇及其相邻簇。

## 文件结构

- `grid.go`：网格、8 向移动（禁止穿墙角）、八段距离启发函数。
- `heap.go`：泛型二叉最小堆，供 Dijkstra / A\* 复用。
- `fullastar.go`：全图 A\* 参照实现，作为正确性对照的“真值”。
- `hpastar.go`：分层结构、簇预计算、动态更新、查询与路径细化。
- `*_test.go`：随机地图对比、动态障碍、簇角斜穿、工作负载与基准测试。

## 抽象图的构造

1. 网格按 `clusterSize x clusterSize` 划分为簇（边缘簇可不满）。
2. 一个可通行格只要存在任意跨簇的合法步（正交步，或不穿墙角的对角步），
   就是该簇的一个入口。入口按单格保留，不合并宽度，避免近似误差。
3. 对每个入口在簇内跑一次受限 Dijkstra，得到：
   - 到簇内其他入口的精确最短代价（抽象图的簇内边）；
   - 覆盖簇内所有可达格的父指针树，用于查询后的路径细化。
4. 入口的每个跨簇合法邻格生成一条抽象跨簇边，权重就是单步代价
   （正交 1，对角 `sqrt(2)`）。

## 查询流程

1. 在起点所在簇、终点所在簇各跑一次局部 Dijkstra，得到到本簇入口的精确
   代价与父树，作为临时节点插入抽象图。
2. 在抽象图上用 A\*（八段距离启发）搜索入口序列。
3. 用簇内父树把每段入口序列还原成逐格路径，跨簇边直接追加单步，并对
   边界上可能重复的格去重。

## 正确性与路径长度

- 可达性一致：簇内 Dijkstra 精确刻画簇内连通性；跨簇边由网格上真实存在
  的合法步生成，抽象图既不增加也不丢失任何合法移动，因此抽象图中的可达
  关系与原网格完全相同。测试对每张随机地图的每对查询断言
  `HPA 可达性 == 全图 A* 可达性`。
- 代价精确：所有抽象边的权重都等于其对应网格路径的真实代价，抽象路径的
  权重和等于一条真实网格路径的代价；抽象图又包含全部合法移动，故抽象
  A\* 找到的最短代价等于全图最优代价（误差仅浮点 `1e-9` 量级），
  比值恒为 1.0，天然满足不超过 1.1 倍最优解的要求。
- 细化合法性：测试逐段校验每一步都是合法的 8 向移动、不进入障碍格、
  对角步不穿墙角，且累加代价与报告代价一致。

## 动态障碍

`UpdateObstacles(map[Cell]bool)` 批量写入障碍变化后，只重建发生变化的簇
及其 3x3 相邻簇（相邻簇的边界入口集合也可能受影响），其余簇的预计算
结果保持不变。测试通过 `RebuildCount()` 断言重建范围有上界，并把在线
更新后的层级结构与全新构建的层级结构、全图 A\* 逐一比对。

## 用法

```go
g := hpastar.NewGrid(64, 64)
g.SetBlocked(10, 10, true)
h := hpastar.NewHierarchy(g, 8)

path, cost, stats, ok := h.FindPath(hpastar.Cell{X: 0, Y: 0}, hpastar.Cell{X: 63, Y: 63})

// 动态障碍：true 表示阻挡，false 表示放行
_ = h.UpdateObstacles(map[hpastar.Cell]bool{
    {X: 10, Y: 10}: false,
    {X: 11, Y: 10}: true,
})

// 参照真值
fullPath, fullCost, fullOK := hpastar.FullAStar(g, start, goal)
```

## 验证

- `go test ./...`：24 张随机地图 x 24 对查询的精确性/可达性对比；
  24 轮随机障碍翻转的增量更新一致性；簇角对角斜穿专项；连通性开关测试。
  语句覆盖率 96%+，并通过 `-race`。
- `go test -bench .`：层级构建、单次 HPA 查询、全图 A\* 查询、增量更新
  的基准。复杂长距离场景下抽象搜索展开的节点数显著少于全图 A\*
  （128x128、25% 障碍实测约为全图的 45%，见 `TestSearchWorkComparison`）。
