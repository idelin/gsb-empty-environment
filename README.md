SOCKS5代理的UDP ASSOCIATE会开放中继端口，攻击者在互联网上直接向该端口发包或借IPv4映射地址与端口漂移反射流量。给Go代理写供UDP中继循环调用的关联准入包：关联存活时间与TCP控制连接及半关闭状态联动即时回收；对客户端声明地址及目标地址执行IPv4映射IPv6规范化比对（声明0.0.0.0或::时取TCP来源地址），并锁定首个客户端来源端口后禁止漂移，多客户端复用同一端口时按四元组严格隔离。FRAG非零、保留字段非零、域名长度越界或伪造域名回包直接丢弃；回程数据只送回已锁定客户端，目标地址受调用方禁止网段限制。用外部伪造来源、IPv4映射地址绕过、端口漂移、TCP半关闭及禁止网段发包验证。
