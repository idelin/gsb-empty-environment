# trend_df — 时间桶文档频率趋势引擎

纯 Python 3.11 标准库实现，无搜索服务、无全文检索库。

## 分词规则
1. 文本先做 Unicode 小写化（`str.lower()`）。
2. 连续 `[0-9a-z]` 构成一个词元。
3. 每个 CJK 统一表意文字（U+4E00–U+9FFF）单独成词。
4. 其余字符均为分隔符。
5. 文档频率按文档内去重：同一词在同一文档只计一次。

## 核心语义
- 时间被切分为定长桶；窗口 = 最近 `window_buckets` 个桶。
- 分母 N = 窗口内可见文档身份的去重数；迟到文档修订其时间戳所属桶，
  撤回文档立即从计数与分母移除，重复提交幂等忽略。
- 平滑比率：`ratio(t) = ((df_cur+α)/(N_cur+α)) / ((df_prev+α)/(N_prev+α))`，
  0→1 为有限值 `(1+α)/α`，不会无穷。
- 任一窗口 N=0 时结果退化，不报告增长。
- `df_cur < min_support` 的词不进入排名。
- TopK 剪枝上界 `UB(t) = ((df_cur+α)/(N_cur+α)) / (α/(N_prev+α))`：
  平滑常数进入上界，最低支持数在界计算前过滤候选。
- 增量路径只触及单个桶，绝不每次扫描全部历史文档；
  `verify()` 从事件日志独立全量重算，检查分母变化、零窗、重复事件，
  并对每处排名更正输出贡献证据（相关文档身份）。

## 运行
```
python3.11 trend_df.py        # 运行样例
python3.11 -m unittest -v     # 测试
```
