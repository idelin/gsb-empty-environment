分区追加盘的写指针只能证明物理槽位已消耗，不能证明其中的条带属于最新一代。给恢复挂载器写一个可导入的 Go 包，从离线设备报告重建逻辑读视图。每个 zone 有容量、代号、写指针与按物理槽号排序的稀疏页头；指针之前没页头的槽是撕裂页，不是空闲空间。页头列出本区代号、条带序号、片号、长度和内容摘要。提交目录是一张带父指针的有根树，每个节点只增量覆盖若干逻辑区间：覆盖描述给定条带号和任取 k 个不同片号即可恢复的编码宽度，并为每片指定代号、长度和摘要。给出多个候选根到叶挂载点，分别返回该分支能完整读取的最深祖先。只检查祖先当时仍可见的逻辑区间；祖先因缺片不可读，不代表覆盖缺口后的子节点不可读。不得拼用兄弟分支的覆盖描述、指针之外的页或旧代页；同一片的多个物理副本只算一次。还要支持按所选祖先查询逻辑偏移，列出恢复所用的 k 个片号及其物理位置，按片号、区号、槽号取字典序最小见证；找不到可挂载祖先时返回每个候选点最小的不可读逻辑偏移，根也可带初始覆盖。未映射区间按零读取。区间一律半开，偏移和长度均为 uint64，端点溢出、重叠的同节点覆盖、非法父环必须返回输入错误。设备报告最多二十万页、目录十万节点、十万次局部覆盖，逻辑地址空间极稀疏；不允许逐字节展开或为每个分支复制整张映射。用小设备的逐分支全量重建作对照，覆盖兄弟分支对同一偏移互相矛盾、两片同号伪满宽、覆盖一个坏条带的中段后两端仍不可读，以及长链中不可挂载与可挂载交替的情况。
