# 精确有理数线性方程消元器

Python 3.11 标准库实现，不调用符号代数库。程序把线性等式转成增广矩阵，用精确的 `fractions.Fraction` 执行 RREF（简化行阶梯形）消元，并记录每一步的代入条件、适用域、零主元/无法消去情形和条件除法分支。

## 文件

- `rational_elimination.py`：解析器、线性多项式、RREF 消元器、CLI。
- `test_rational_elimination.py`：`unittest` 测试。
- `sample_output.txt`：内置四个运行样例的完整输出。
- `test_results.txt`：当前测试结果记录。

## 运行

```bash
python3.11 rational_elimination.py --demo
python3.11 rational_elimination.py '2x + 4y = 1/2' 'x - y = 1/3'
python3.11 -m unittest -v
```

无参数运行等价于 `--demo`。

## 支持的表达式

- 有理数常数：`1/2`、`-3/4`、`0.25`（内部仍转成精确分数）。
- 线性运算：`+`、`-`、`*`、`/`、括号；支持 `2x` 这类省略乘号。
- 变量名：字母或下划线开头，后接字母、数字、下划线。
- 等式顶层符号除法：如 `x/(a-1)=2`；仅在非零分支乘回后仍为线性方程时自动展开。
- 显式非线性项会拒绝，例如 `x*y=1`，或乘回变量分母产生变量相乘。

## 消元规则

1. 先把等式移项为线性多项式 `= 0`，变量顺序按变量在原始等式中首次出现的顺序记录。
2. 构造增广矩阵，系数和常数都使用 `Fraction`，不产生浮点误差。
3. 每列寻找非零主元：
   - 非零有理数主元可安全归一化；
   - 若候选系数为 0，不除以 0，记录“零系数分支”并继续下一列；
   - 用整行线性组合消去该列其他系数。
4. 循环等式不做无限替换。例如 `x=y+1`、`y=x-1` 会消成 `0=0`，表示同一条自由族，而不是矛盾。
5. `0=非零常数` 才是矛盾。例如 `x=y+1`、`y=x` 消成 `0=1`，结论无解。
6. 独立方程不足时，无法取得主元的变量保留为自由变量并记录“无法消去分支”。

## 条件除法与适用域

- 静态非零常数分母可直接乘倒数，例如 `x/2`。
- 静态 0 分母立即报 `ZeroDivisorError`。
- 含变量的顶层除数必须分支。以 `x/(a-1)=2` 为例：
  - `a-1 ≠ 0`：原除法有定义；两侧乘回分母得到 `x - 2a + 2 = 0`，后续所有 RREF 步骤只在该域有效。
  - `a-1 = 0`：原除法未定义，不属于原等式适用域。

## 内置样例

- `x=y+1`、`y=x-1`：自由族 `x = y + 1`，`y` 自由。
- `x=y+1`、`y=x`：消成 `0=1`，矛盾无解。
- `2x + 4y = 1/2`、`x - y = 1/3`：唯一解 `x=11/36, y=-1/36`。
- `x/(a-1)=2`：在 `a≠1` 下为 `x=2a-2, a 自由`；同时记录零除数分支。
