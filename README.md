# 对象污点与原型写入

我们的Go服务接收一个受限脚本AST，需要在执行前检测原型污染。交付嵌入服务的分析包：AST支持对象分配、变量别名、字符串常量或外部字符串、字段读取写入、顺序、条件分支及最多16次循环。对象最多32个，字符串常量只含a、b、__proto__、constructor、prototype，外部字符串可为其中任何值。对象默认有共享原型，constructor读到固定构造对象，其prototype指回共享原型；写__proto__改变接收对象的原型，写共享原型任何字段均危险。实现上下文中的别名与字符串集合传播，报告可达危险写的节点及数据流证据，正常独立对象字段写不得误报；通过小程序具体执行穷举验证无漏报，分支合并可保守误报但须标明可能性。
