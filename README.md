# 恶意字典的哈希碰撞

Go服务接收攻击者可控键，需供请求解码器调用的哈希表包，防止构造碰撞拖垮同进程其他租户。键是至多256字节原始字节串，支持插入查询删除，每表使用独立随机秘密；实现带密钥哈希并在单桶超过8项时切换平衡树，树按原始键字节排序，不能仅按哈希排序。随机源由调用方注入且失败必须拒绝建表；测试接口可注入恒定哈希来验证最坏碰撞下操作比较次数为对数级，正常接口不可选择哈希函数。并发扩容、删除与查询保持线性化，输出不泄漏密钥。测试全碰撞、长公共前缀、随机源失败和扩容竞争，提供操作计数证据。

## 用法

```go
tbl, err := netsec.New(crypto_rand.Reader) // 随机源由调用方注入；失败拒绝建表
if err != nil { /* 不降级到弱熵源 */ }
err = tbl.Insert(key, value) // key ≤ 256 字节，超长返回 ErrKeyTooLong
v, ok := tbl.Get(key)
deleted := tbl.Delete(key)
```

## 设计

- 哈希固定为带每表随机秘密的 SipHash-2-4，正常接口（`New`）不可选择哈希函数；秘密只被哈希闭包捕获，`String`/`GoString`/错误输出均不含秘密。
- 桶内 ≤8 项用切片，超过即切换为按原始键字节排序的 AVL 树，全碰撞最坏情况每次操作 O(log n) 次键比较。
- 所有操作经单把 `sync.RWMutex` 序列化，扩容、删除、查询并发时保持线性化。
- 仅测试二进制可见的钩子（`export_test.go`）允许注入恒定哈希并读取比较计数器，用于最坏情况证据。

## 测试

`go test -race ./...` 覆盖：全碰撞对数级比较计数、长公共前缀、随机源失败/短读、扩容竞争、同键并发线性化、秘密不泄漏、SipHash 参考向量。
