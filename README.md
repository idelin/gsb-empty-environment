时序库把一个指标的采样点顺序压进块里。给写入路径交付可导入的 Go 压缩包，采用 Gorilla 的方案：块内首个时间戳写绝对值，之后写相邻时间戳增量之差，差值为零占一位 0，否则依次用前缀 10 加七位、110 加十位、1110 加十四位、1111 加三十二位的有符号补码；浮点值与前值按位异或，异或为零占一位 0，否则按前导零是否不变选择两位控制码，再写前导零数、有效位长和有效位，位长字段为零表示六十四位。位按字节高位先行打包。时间戳差值放不进十四位、或点数达到块上限时结束当前块，下一块重新写头。验收对照手算的十六进制样例，十万点往返逐位相等，按时间区间读取的解码结果与原采样点完全一致，并覆盖值从零变非零、前导零恰好为六十四位、差值在负数边界和块恰好满额的情况。
