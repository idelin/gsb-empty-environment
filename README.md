# canonkey

可空多字段规范键 + 去重存储 + 检查点持久化的 Go 库。

## 规范键编码

键由若干**可空、带类型**的字段组成，编码格式：

```
K1#<字段数>#<字段>...
字段 = <类型标签><负载长度>:<负载字节>
```

类型标签：`N`=null，`S`=string，`I`=int64，`F`=float64，`B`=bool，`X`=bytes。

无歧义保证：

- **长度前缀**而非分隔符切分：负载可包含 `#`、`:`、数字、NUL 字节乃至
  另一段合法编码文本，都不会与框架字符混淆。
- **类型标签参与编码**：`"1"`、`1`、`1.0`、`true`、`"true"` 互不同键。
- **空值 ≠ 空串**：`Null()` 编码为 `N0:`，`String("")` 为 `S0:`，
  `Bytes(nil)` 为 `X0:`，三者互不相同（nil 与空 byte 切片视为同值）。
- 编码是单射：字段列表相等 ⟺ 键相等；`Key.Fields()` 可无损解码并拒绝
  畸形键。

## 去重与冲突策略

`Store.Add(key, content)` 的三种结果：

- `Inserted`：新键，写入。
- `Duplicate`：同键同内容（SHA-256 判定），去重命中，无操作。
- 同键异内容：按构造时指定的显式策略处理，**绝不悄悄覆盖**：
  - `ConflictReject`：返回 `ErrConflict`，原内容保持不动；
  - `ConflictIsolate`：原内容保持不动，冲突内容进入该键的隔离桶，
    可按到达顺序通过 `Store.Isolated(key)` 取回审计。

## 检查点

`Store.SaveCheckpoint(path)` 将去重集合（含隔离桶与冲突策略）原子写入
（临时文件 + rename，崩溃不留半截文件），文件带 SHA-256 校验和。
`LoadCheckpoint(path)` 恢复时逐项验证：校验和、格式版本、键编码合法性、
键唯一性、每条内容哈希，任何篡改都会以 `ErrCheckpointCorrupt` 拒绝。
