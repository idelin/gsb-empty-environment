内核数据包过滤器在加载前必须静态证明所有包内存读写都落在 [pkt_data, pkt_end) 范围内，仅靠单一无符号区间无法处理按位掩码和有符号比较组合。为程序加载器交付可导入的 Go 静态验证包。输入有向无环控制流图（基本块含 64 位寄存器算术指令 ADD/SUB、位指令 AND/OR/LSH/RSH、条件跳转 JEQ/JLT/JSLT/JGE/JSGE、包指针偏移叠加以及带访问宽度 w 的包内存读指令）。验证器须为每个标量寄存器联合维护无符号区间 [umin,umax]、有符号区间 [smin,smax] 与三态位掩码 tnum(value,mask)，并在每步指令与条件分支真假两路执行区间与 tnum 双向交叉收紧（如按位与后收紧 umax、分支窄化后同步更新有符号/无符号界与确定位）；对包指针加已验证偏移并经 `ptr + k <= pkt_end` 比较后，为同源包指针记录安全可读上界；合并多前驱路径时取保守并集。组件判定整段程序是否所有包访问均必然安全，安全时返回各出口抽象状态，否则指出首个可能越界的指令编号与反例路径。验收用小字宽具体输入穷举与手工边界用例对照，覆盖按位与 `x & 0xff` 后做偏移、有符号比较未排除负数导致无符号溢出越界被拦截、分支后两路合并丢失部分上界，以及多步加偏移后验证边界恰好等于 `ptr+w<=pkt_end`。
