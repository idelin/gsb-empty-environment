内网客户端收到多个分发点的完整和增量吊销列表，同一序列号在两个签发者下可能代表不同证书。给 Go 证书路径宿主实现可导入的状态判定包。输入为经过宿主验签的 CRL 元数据和条目：每份声明签发者、分发点、原因位集合、本版号、可选基础版号、thisUpdate/nextUpdate；间接列表的条目可以切换实际证书签发者，后续条目直到下一次切换前沿用该身份。查询按证书签发者、序列号及需覆盖原因位判定。每个增量只能与同作用域且恰好对应的完整基础版本合并，removeFromCRL 只能撤销同身份此前被置为 certificateHold 的条目，不能清除其他原因；过期或未来列表不给出覆盖。独立作用域都有效时，只要一份有效吊销证据成立就拒绝；只有全部要求原因位均有有效未吊销覆盖时才返回有效，其余返回未知。返回一组数量最少的已签列表作为判定证书（增量及其基础均计入，基础可共享），并列取编号序列最小者。写独立检查函数和至多12份列表的子集穷举参考，覆盖间接签发者切换、同序列号、hold 恢复、缺原因位以及共享基础改变最优选择。
