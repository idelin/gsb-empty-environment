# OPC UA PubSub安全头与nonce

OPC UA PubSub 的安全头里令牌 ID 与消息 nonce 若不被核对，攻击者可重放旧的 NetworkMessage，或在密钥轮换后继续使用过期令牌。为Go订阅端写可导入的安全头准入包，供 UADP 消息接收路径调用：SecurityHeader 含 SecurityTokenId（4 字节）与 MessageNonce（本题规定 8 字节：4 字节随机前缀加 4 字节大端计数器）；只接受当前令牌与上一令牌（由调用方给出，轮换后保留 1 代）；同一令牌下同一发布者的 nonce 计数器须严格大于已见最大值，签名与解密成功后才更新；随机前缀在一个令牌生命周期内变化视为伪造；签名校验失败的消息不得推进任何状态；令牌 ID 小于上一令牌且不等于当前令牌拒绝。用重放、跨令牌 nonce 回退、前缀变化、上上代令牌和校验失败不推进状态验证。
