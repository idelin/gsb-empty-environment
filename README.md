主机恢复旧镜像时只掌握片段化的签名更新收据，不能确定两个并行增量谁先持久化。给 Go 加载宿主实现可导入的恢复准入包。一个更新可修改内容或仅收紧执行权限，两者均绑定发布者、旧根、新根和作用页区间；别名页可共享内容，但权限属于映像位置。判定请求区间中的每一页是否在所有与检查点相容的历史里都由同一可信内容及足够权限支持，分别返回确定可执行、确定禁止与未知的精确子区间。不能把不同历史中的内容和签名范围拼接成一个确定结果。更新 DAG 允许共享分支，宿主提供可核验的分片边界，页号48位，不得展开所有页。小地址域全历史对照丢失提交确认、别名内容一致权限不同和只撤销半区间，再核验已安全确定的旁支不被无关缺口冻结。
