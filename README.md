Kubernetes CRD 引入验证规则与棘轮机制（Validation Ratcheting）后，集群升级收紧校验规则时允许既有不合规对象在未被触碰的字段上继续完成无关更新，但只要某字段在本次更新中发生实质变更或规则本身属于引用 `oldSelf` 的转换规则（Transition Rule），就必须严格拦截；而在 `x-kubernetes-list-type: map` 列表上，按元素顺序下标做新旧比对会把重排或插入误判为整表改动，必须按 `x-kubernetes-list-map-keys` 联合键精确配对新旧元素！为声明式 API 控制面交付可导入的 TypeScript CRD 结构化裁剪、默认值物化与棘轮校验库。输入为 OpenAPI v3 Structural Schema（含 `default`、`x-kubernetes-preserve-unknown-fields`、`x-kubernetes-list-type` 为 `atomic`/`set`/`map` 及 `x-kubernetes-list-map-keys`、各节点上的校验规则集合——支持属性访问、算术/比较/布尔/正则/集合量词 `all`/`exists`/`exists_one`、可选 `oldSelf` 引用及自定义规则路径）与创建或更新请求的 `(oldObj, newObj)`。规则：1）创建与更新前先按 Schema 执行未声明字段裁剪（默认 `preserveUnknownFields=false` 裁剪未知键，显式 `true` 保留）与缺失默认值递归物化（含数组元素内部默认字段，但不覆盖显式 `null` 除非声明 `nullable` 规则）；2）更新操作时自顶向下递归建立新旧值对应关系——对象按字段名对齐，`list-type: map` 按全部 `listMapKeys` 组合键对齐（缺键或重复键直接报结构错误！），`list-type: set` 按深相等元素集合比对，`atomic` 按整体比对；3）对每条规则判定求值策略：创建时自动跳过引用 `oldSelf` 的转换规则；更新时若规则引用 `oldSelf` 且旧对象对应节点不存在则跳过，存在则必须求值且禁止棘轮豁免；若规则不引用 `oldSelf` 且新值校验失败，仅当新旧对应子树在规范语义下深相等（映射列表按 key 无序比对、集合忽略元素顺序）且旧值在该规则下同样失败时，才触发棘轮放行并记录豁免审计明细！4）任何规则执行遇到类型错或除零等运行时错误，在更新时不可被棘轮静默吞掉。验收覆盖未知字段裁剪与默认值物化先后顺序、map 列表乱序重排触发棘轮放行、修改单个 map 项精准拦截、创建跳过 `oldSelf` 转换规则与非棘轮运行时错误报错。
