# fparse — 有限特征合一解析库

面向文本标注器的 Go 解析库：非终结符携带有限特征映射，特征值为常量或规则局部变量。
输入至多 20 条无空产生式的文法与至多 20 词的词序列，返回所有可合一分析的共享森林。

## 文法格式

每行一条产生式，`#` 为注释：

```
S[mode=M] -> NP[case=nom num=N] VP[num=N mode=M]
NP -> Det N
N[num=sg] -> "dog"
```

- 方括号内为特征对，空格或逗号分隔；
- 大写开头的值为**规则局部变量**，其余为常量；
- 引号字符串为终结词；空产生式（epsilon）被拒绝。

## 使用

```go
g, _ := fparse.ParseGrammar(src)
forest, _ := g.ParseForest([]string{"they", "run"}, "S")
n := forest.NumAnalyses(1000)   // 打包森林中的分析数
trees := forest.Trees(0)        // 独立展开为各棵树（默认上限 4096）
err := forest.Verify(0)         // 独立验证每棵树的词序与特征一致性
```

## 设计要点

- **变量重命名**：每次规则实例化、每次读取已存节点时，变量都经 `freshener`
  重新命名（`feature.go`），规则局部变量在同一次展开内保持同一新身份。
- **分支隔离**：代换 `Subst` 写时复制，合一失败或兄弟分支绝不污染当前分支。
- **重复键冲突**：合一特征映射时，共有键的值不可合一则整个分析失败。
- **递归文法**：自底向上图表解析，按跨度递增 + 单元产生式不动点，左右递归均可。
- **规范去重**：节点按（类别, 规范化特征, 跨度）去重；`canonical` 把自由变量
  按序重命名，等价（α-等价）特征代换共享同一打包节点。
- **独立验证**：`Verify` 重新展开森林，对每棵树自叶向上重放合一，校验词序
  等于输入、各节点特征可由规则与子女特征重新推出。
