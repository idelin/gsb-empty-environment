# 有理数超平面分离定理核验器

多维空间（R^d）中两组有限点集的**严格线性可分性**精确验证器。全部计算基于
BigInt 分数的精确有理数运算，无任何浮点误差。

## 功能

给定两组点集 `P`、`Q`（任意维度 d ≥ 1，坐标可为整数/小数/分数）：

- **可分离**：通过精确单纯形法求解可行性 LP，输出分离超平面的**精确有理数法向量**
  `a` 与偏移 `b`，满足 `a·p < b`（所有 p ∈ P）、`a·q > b`（所有 q ∈ Q），
  并给出形如 `2x - 3y + 5 = 0` 的整数化方程。
- **不可分离**：由 Farkas 引理，两凸包必相交。求解交集 LP，输出两凸包的
  **公共有理点** `x*`，并附带它在两组点上的**重心坐标**（凸组合系数），
  作为不可分的构造性证明。

## 原理

1. **分离 LP**：严格分离 ⟺ 存在 `a, t` 使 `a·p - t ≤ -1`（p ∈ P）、
   `a·q - t ≥ 1`（q ∈ Q）（任意严格分离超平面可缩放至单位间隔）。
   自由变量拆分为非负差后，用两阶段单纯形法（Bland 规则，保证终止）精确求解。
   偏移取 `b = (max_P a·p + min_Q a·q) / 2`，使两组点等距落在两侧。
2. **交集 LP**（分离 LP 不可行时）：求 `λ, μ ≥ 0`，`Σλ = Σμ = 1`，
   `Σ λᵢpᵢ = Σ μⱼqⱼ`。解出的 `x* = Σ λᵢpᵢ = Σ μⱼqⱼ` 即 `conv(P) ∩ conv(Q)`
   中的公共点，`λ`、`μ` 为其重心坐标证明。

## 运行

要求 Node.js ≥ 23.6（原生 TypeScript 类型擦除，无需编译）。

```bash
npm test    # node --test，运行全部测试
npm run demo  # 运行验收样例
```

## API

```ts
import { separate, verifySeparation, verifyCommonPoint } from './src/index.ts';

const res = separate(
  [[0, 0], [1, 0], [0, 1]],          // P
  [[3, 3], [4, 2], [2, 4]],          // Q（坐标支持 number / string / bigint / Fraction）
);
// 可分:  { separable: true,  normal, offset, hyperplane: '2x + 2y - 7 = 0' }
// 不可分: { separable: false, point, coeffsP, coeffsQ }
```

## 测试结果（`npm test`，Node 内置 test runner）

```
ℹ tests 22
ℹ pass 22
ℹ fail 0
```

覆盖：

- `test/fraction.test.ts`：分数构造/解析/四则运算/比较的精确性；
- `test/lp.test.ts`：单纯形法有界最优、极小化、等式约束、不可行、无界、
  负右端项与冗余等式；
- `test/separator.test.ts`：验收边界（二维可分 → 严格超平面；二维相交 →
  公共重心点）、边界相触不严格可分、单点重合、有理数坐标、三维可分/相交、
  超平面格式化（`2x - 3y + 5 = 0` 样式）、维度异常；
- `test/randomized.test.ts`：300 例随机点集，与独立几何 oracle
  （精确转向判定 + Carathéodory 枚举）交叉验证判定结果与证书。
