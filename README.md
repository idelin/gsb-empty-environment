# singleflight demo

同键并发调用共享一次计算，等待者可独立取消；所有等待者都取消时取消任务函数的
`context.Context` 从而终止计算；完成（成功/失败/panic）后不缓存状态，新的调用会
重新执行。仅使用 Go 标准库（`sync.Mutex`、`context`、channel 等）。

## 语义

- `Group.Do(ctx, key, fn)`：同 key 且仍在执行时，后续调用作为等待者加入，共享
  `fn` 的返回值与错误。
- 每个等待者用自己的 `ctx` 独立取消；单个等待者取消不影响其他等待者。
- 最后一个等待者取消时，传给 `fn` 的 context 被取消，map 条目删除；之后的新调用
  启动一次全新计算。
- `fn` panic 会被 recover 并转换为 `*singleflight.PanicError`（含 recover 值与堆栈），
  投递给所有等待者并释放该 key。
- 结果绝不记忆化：完成与新调用之间通过「持锁标记 closed + 删除条目，随后再投递结果」
  保证新调用不会复用已完成/失败/关闭的旧调用。

## 运行

```sh
go test -race -v ./...
```

## 测试覆盖

- 十路同键并发只执行一次，且都拿到同一结果。
- 取消九个等待者，剩余一个仍能拿到结果，计算不中断。
- 全部等待者取消后任务 context 被取消；随后的新调用重新执行。
- 失败不缓存：下一次调用重新执行并可以成功。
- panic 转成明确错误释放所有等待者，之后的新调用可正常执行。
- 完成与新调用竞态：结果投递窗口期内的新调用启动新计算，而非复用已关闭调用。
