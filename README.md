# interval_arith — 精确有理数区间 / 仿射算术（Python 3.11，仅标准库）

## 设计要点

- **精确有理数**：所有端点为 `fractions.Fraction`，四则运算、平方、幂、单调函数像均无舍入误差；不调用任何符号代数库。
- **保守端点舍入**：`Interval.from_float` 对 float 做精确转换（不隐藏误差）；`round_outward(step)` 把端点向外舍入到有理网格（下端向下、上端向上），保证包含原区间。
- **除零不隐藏**：除数区间闭包含 0 时 `__truediv__`/`reciprocal` 抛出 `DivisionByZeroInterval`；`reciprocal_split()`/`div_split()` 在奇点 0 处把定义域分裂为开端点子区间，像为无界区间（如 `(-∞,-1]`、`[1/2,+∞)`），即不连续域的诚实表示。0 作为**开**端点时允许取倒数（像无界）。
- **仿射相关表示**（`affine.py`）：`x = c0 + Σ ci·εi`，`εi∈[-1,1]` 共享噪声符号保持同一变量重复引用的相关性。线性运算精确；非线性余项用可验证保守界：`|A·B| ≤ (Σ|ai|)(Σ|bi|)`、`E∈[-r,r] ⇒ E²∈[0,r²]`，全部可用纯有理数算术复核。
- **奇点分裂 + 预算**（`domain.py`）：`split_at` 在奇点处分裂定义域（奇点端点开）；`analyze` 逐段分析，`Budget` 耗尽时剩余区间保留在 `AnalysisResult.unanalyzed`，绝不静默丢弃。
- **采样仅用于反例**（`sampling.py`）：有理网格采样只能证伪（找到界外点），不能证明包含性。
- **证书验证**（`certificate.py`）：每步变换记录规则与适用域；`verify` 用精确区间算术重新求值并检查子集关系——区间求值是可靠的，故验证通过即为包含性证明，而非采样假象。
- **相关性说明**：`x*x` 直接相乘按独立处理、结果保守（`[-1,1]*[-1,1]=[-1,1]`），`dependency_note` 给出说明；`square()`/仿射 `square` 利用相关性得紧界 `[0,1]`。

## 运行

```bash
python3.11 -m unittest discover -s tests -v   # 35 个测试
python3.11 examples/demo.py                    # 运行样例
```

## 样例输出（节选）

```
[-1,1].square()      = [0, 1]
[-1,1] * [-1,1]      = [-1, 1]            # 保守，dependency_note 说明相关性
affine x.square()    = [0, 1]             # 仿射形式利用相关性，精确
除数 [-1,2] 跨 0     -> 抛 DivisionByZeroInterval
div_split: [-1,0) -> [-inf,-1] ; (0,2] -> [1/2,+inf]
x^3 on [-2,3]        = [-8, 27]
预算 1 分析 1/[-2,3]  -> analyzed [-2,0)->[-inf,-1/2]；UNANALYZED (0,3] 保留
采样: 界 [0,1/2] 被反例 x=-1 证伪；界 [0,1] 无反例（非证明）
证书: verify = True（精确区间求值 [0,1] ⊆ [0,1]）
[1/3,2/3] 向外舍入到 1/10 网格 = [3/10, 7/10]
```
