沙箱里的多个服务会复制、分割和转交描述符，管理端要在不关闭共享文件的情况下撤销一个租户的写能力。给C++17宿主写可嵌入的权利证明库。能力绑定对象代次、半开字节范围、读写位和来源证明。分割只缩小范围，合并可按操作取多个来源区间的并集；同一字节有两条合法来源时，撤掉一条仍可访问。转交时允许快照授权和随上游撤销的委托两种模式，快照仍受对象代次和显式本地撤销约束。输入一份有限无环的传递记录、待禁与必须保留的操作区间，以及至多18个带代价的可撤销授权，求能满足两类要求的最低代价撤销方案，平价按有序授权ID列表决胜。区间端点64位，拒绝溢出或缺失来源，先验算再一次发布；返回按真实区间分段的存活或阻断理由。用逐字节小模型交叉核对相邻但权限不同、异源重叠、快照与委托相交和描述符编号重用。
