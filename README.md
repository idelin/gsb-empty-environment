# prefixdict

多来源加权词典的 Go 库，支持前缀 top-k 查询。

## 语义

- 每个词从多个命名来源累积整数权重；同一来源对同一词的重复更新是替换而非累加。
- `TopK(prefix, k)` 返回总权重最高的至多 k 个词，并列按 UTF-8 字节序。
- `RemoveSource` 只撤销该来源的贡献；零权重词仍然存在，直到最后一个来源被删除。
- `ReplaceSource` 原子地批量替换一个来源的全部贡献。
- `Snapshot` 是不可变视图：持旧快照的查询仍见旧权重。
- 索引在后台重建（`StartRebuild`/`Finish` 或 `RebuildAsync`），重建期间的新写入
  在切换时按差量补齐；索引中的旧分数在查询时对照权威数据失效重算。

## 测试

`go test ./...` 用全表聚合 + 排序的朴素模型做性质核对，覆盖重复来源更新、
Unicode 前缀、快照隔离、重建与写入交错、赢家权重下降后次优晋升等场景。
