IPv6 报文里逐跳选项头的每个选项都可能让报文被跳过、丢弃或触发差错回报。给协议栈交付可导入的 Go 解析组件。选项头以八位组类型、长度和值排列，长度以八个八位组为单位；特殊的填充选项只占一个八位组或只带一个字节的填充长度。类型最高两位决定遇到不认识的选项时的动作：跳过、静默丢弃、丢弃并回报参数差错、除非目的地址是组播否则丢弃并回报。路由器告警选项要求值从两字节边界起，长度恰为二且取值受限。报文带分片头时不得再带逐跳选项头，选项总长超出报文实际长度、未知选项的长度字段不可信，都要按规范处理。组件返回首个须回报的位置或 nil，并给出各选项的偏移。验收按 RFC 8200 第 4.2 节构造样例逐字节对照，覆盖仅一个字节的填充、对齐不足、长度为零的可变选项、截断的选项头和动作位四种取值。
