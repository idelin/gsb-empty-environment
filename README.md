# 动态批处理把一租户输出交给另一租户

推理调度器把不同租户请求拼成批次，取消、排序或可变长度填充处理错误会把输出切片交给别的请求。给Go推理宿主实现可导入的批次账本：请求含tenantID、requestID、模型代次、输入token数组（每项为非负32位整数）、最大输出长度、截止时间和取消代次；requestID仅在tenant内唯一。组批只允许同模型代次与相同解码策略，先按到达序再requestID排序，生成随机batchID和每请求不可变rowIndex、输入长度、输出上限及身份摘要。张量回调接收规范批次并返回batchID、模型代次、每行token数组和行级完成状态；返回行数必须相同，每行长度不超上限，按rowIndex和身份摘要交付，不能按完成顺序或当前队列位置。取消只撤销该行交付资格，不压缩其余索引；超时后迟到结果丢弃，模型换代使整批失效。流式多步解码每步保持rowIndex，已完成行用mask冻结，回调若改其token拒绝整步。实现待审映射回调的确定调度搜索，交错取消、完成和模型换代，找tenant A收到由B输入决定token的最短轨迹；用标记模型让输出编码输入身份，覆盖同requestID跨租户、空输入、部分完成和回调重复结果。
