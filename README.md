# policy-decision-cache

带精确失效语义的策略判定缓存（零依赖 TypeScript，Node.js 内置测试运行器验证）。

## 语义保证

- **缓存条目自描述**：每条记录保存判定结果、实际读取的属性快照、规则版本号、时间失效点。
- **精确失效**：属性更正/删除只失效实际读取过该属性的条目；未读取的属性变化不失效任何条目；已读取属性被删除必须失效。
- **隔离性**：缓存键为 `(策略, 主体, 上下文)`，跨主体、跨上下文绝不串用。
- **规则版本**：规则变更必须递增版本号（否则 `updatePolicy` 抛错）；版本变化后旧允许结果一律不得沿用。
- **时间失效点**：条目带 TTL，过期即视为未命中并清除。
- **策略能力受限**：条件只允许有限集合成员判定（`in`）、整数比较（`eq/ne/lt/le/gt/ge`）与布尔运算（`and/or/not`），加载时校验；属性值只允许字符串、布尔、整数。
- **只读显式属性**：属性仅来自内置 `AttributeStore`（`subject.<name>` / `context.<name>`），不接任何外部身份服务。

## 结构

- `src/conditions.ts` — 条件模型、校验与短路求值
- `src/attributes.ts` — 显式属性仓库（唯一属性来源）
- `src/engine.ts` — 策略求值（拒绝优先、默认拒绝），记录实际读取属性
- `src/cache.ts` — 判定缓存：版本/时间校验 + 属性反向索引精确失效
- `src/service.ts` — 授权服务：组合仓库、引擎、缓存与失效入口
- `demo/run-sample.ts` — 运行样例
- `test/` — Node 内置 `node:test` 测试（21 个用例）

## 运行

需要 Node.js >= 22.6（使用 `--experimental-strip-types` 直接运行 TypeScript，无需编译与第三方依赖）。

```sh
npm test    # 运行全部测试
npm run demo  # 运行场景样例
```

## 测试结果

```
# tests 21
# pass 21
# fail 0
```

覆盖：有限集合/整数/布尔运算及短路读取、条件校验拒绝非法能力、缓存命中与时间失效点、
版本不一致不命中、跨主体/上下文隔离、属性级精确失效、已读属性删除强制失效、
规则版本变化作废旧允许结果、同版本换规则被拒绝、拒绝优先与默认拒绝。
