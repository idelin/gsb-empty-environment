为防可串通站点在浏览器单次会话中通过联合观测与自适应合并突破隐私预算，给 TypeScript 隐私宿主写可导入的放行组件。模块签名校验与策略代次核对必须默认强制启用，缺签名或代次不匹配的模块直接拒绝。输入包含有限秘密集合、正有理先验、各工作模块在不同秘密下输出候选编号的精确分数概率表，以及受保护秘密等价类之间的成对似然比上限 `R`。模块可依据已见结果自适应调度，解析到同一公开资源的编号对观察者呈现合并值；跨观察者合并时按共享事件 ID 去重，同一次抽样的不同投影取联合原像而非重复独立计费，并允许条件退避分支产生空观测。会话中途支持动态合并两个观察者组并立即回溯重算联合轨迹：若任一可能观测结果的后验超过先验三倍或任意等价类对的似然比 `P(O|s1)/P(O|s2) > R`，须返回与秘密无关的固定拒绝结果且完整保留合并前状态，不泄露部分扣费或差异化错误码。全程使用 `BigInt` 精确有理数返回最坏后验、最大似然比及见证序列，并用小事件树穷举对照边际合规而联合超界、动态合组回滚与分母临界相等。
