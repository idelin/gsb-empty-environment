# treepath — 树上路径不同颜色数查询（支持单点改色）

对一棵树维护节点颜色，支持两类操作，且**颜色可在线新增**（改色可以使用从未出现过的颜色值）：

- `Query(u, v)`：询问 u 到 v 路径上不同颜色的数量；
- `Recolor(v, c)`：把节点 v 的颜色改为 c。

每个查询严格对应它在操作流中的**修改时刻**——只看该时刻之前已生效的改色，绝不使用最终颜色。

## 算法：带修改莫队（离线，欧拉序 + LCA + 时间维）

1. 任取一根做 DFS，得到长度 `2N` 的欧拉序（每个节点出现两次）与倍增 LCA 表。
2. 查询 `(u, v)`（设 `tin[u] ≤ tin[v]`）：
   - 若 `lca(u,v) = u`：区间为 `[tin[u], tin[v]]`；
   - 否则：区间为 `[tout[u], tin[v]]`，另补计 LCA 节点。
   区间内出现奇数次的节点恰好在路径上（toggle 维护）。
3. 改色操作作为时间维：莫队指针在时间轴上前移/回退时，应用/撤销对应改色；
   若被改节点当前在路径集合内，同步更新颜色计数。
4. 排序键为 `(L块, R块, 时间)`，按块奇偶交错方向，最后以查询下标作决胜键，
   因此**结果完全确定**，与 map 迭代顺序等无关。
5. 颜色用惰性离散化（`map[color]id`），新颜色随时出现随时分配 id。

## 实际复杂度

设 N 为节点数，Q 为查询数，U 为改色数，C 为不同颜色总数：

| 阶段 | 时间 | 空间 |
|---|---|---|
| 预处理（欧拉序 + 倍增 LCA） | `O(N log N)` | `O(N log N)` |
| 莫队扫描（块长 `(2N)^(2/3)`） | `O((N + Q) · N^(2/3))` 次 toggle，均摊 `O(1)` | `O(N + C)` |
| 每次查询的 LCA | `O(log N)`（预处理阶段一次性算好） | — |
| 合计 | `O((N + Q) · N^(2/3) + N log N)` | `O(N log N + Q + C)` |

对照实现 `NaiveDistinctColorsOnPaths`：每次查询 BFS 枚举路径，`O(Q·N + U)`，
与根选取无关，用于对拍验证。

## 正确性验证（`go test ./...`）

- **根变化无关性**：同一组数据分别以 `0`、`n/2`、`n-1` 为根运行，结果一致且等于无根朴素枚举；
- **同点路径**：`Query(u, u)` 恒为 1，包括对同节点反复改色（含改成同色）；
- **颜色反复改回**：改色→查询→改回→查询，结果精确复原；查询只看自己时刻的颜色；
- **时刻语义**：更新前的查询不受后续改色影响，更新后的查询不看初始颜色；
- **随机对拍**：多组种子、含在线新颜色/改回/同点查询，与朴素枚举逐一比对；
- **确定性**：相同输入重复运行结果完全一致。

## 使用示例

```go
edges := []treepath.Edge{{0, 1}, {1, 2}, {2, 3}}
colors := []int{1, 1, 2, 3}
ops := []treepath.Op{
    treepath.Query(0, 3),   // 3
    treepath.Recolor(2, 4), // 在线新增颜色 4
    treepath.Query(0, 3),   // 3
    treepath.Recolor(3, 1),
    treepath.Query(0, 3),   // 2
}
ans := treepath.DistinctColorsOnPaths(4, edges, colors, ops, 0)
```
