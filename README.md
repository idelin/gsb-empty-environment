# 指令选择器：最小成本覆盖（C++17）

对表达式 DAG 做 BURG 风格的动态规划指令选择。目标指令模式是可跨多节点的
树模式，叶子为带寄存器类别约束的通配符；共享子表达式（fanout ≠ 1）只计算
一次，额外引用按显式复制成本计费。

## 构建与运行

```sh
g++ -std=c++17 -O2 -Wall -o isel instruction_selection.cpp
./isel < tests/t1_tree.in
```

## 模型

- DAG 节点按拓扑序给出（孩子下标小于自身）。
- 模式 = 树：`OP name arity` 内部节点（可嵌套，即可跨节点），`WILD c` 为
  通配叶子，要求该位置的值在寄存器类别 `c` 中可用。
- 模式的内部节点只能匹配 fanout == 1 的 DAG 节点；fanout ≠ 1 的节点
  （共享子表达式、被多处引用的输出）必须物化为模式根。
- 共享节点只产生一次（取成本最小的类别 `rep`），其覆盖成本全局计一次；
  每次引用若所需类别不同，付 `copyClos[rep][c]` 的显式复制成本
  （复制成本矩阵的 min-plus 闭包，支持多跳复制，-1 表示不可直接复制）。
- 同一节点处允许不同类别间的转换同样按复制闭包计费。
- 方案定义：每个模式根的（模式, 结果类别）分配。`WAYS` 为达到最小总成本
  的方案数（各类别/模式选择按 DP 累乘累加；共享节点的覆盖方案全局只乘
  一次，且只计入复制成本与所选代表类别一致的并列类别）。

总成本 = Σ 非共享输出根 cost[n][c] + Σ 被使用的共享节点 cost[v][rep[v]]
\+ Σ 共享输出根的复制成本。

## 输入格式（stdin，空白分隔）

```
N C
<N 行: op arity c0 ... c{arity-1}>   # DAG 节点，拓扑序
<C 行，每行 C 个整数>                # 复制成本矩阵，-1 = 不可复制
K
<K 个模式: cost resultClass 后跟先序模式树>
    模式树节点: "OP name arity" + arity 个子树 | "WILD class"
R
<R 行: node class>                   # 输出根及其要求的寄存器类别
```

## 输出格式（stdout）

```
COST <最小总成本>        # 或 INFEASIBLE
WAYS <并列最优方案数>
<i> ROOT pattern=<pid> class=<c> [shared]   # i 是模式根
<i> COVERED owner=<root>                    # i 被 root 的模式覆盖
<i> DEAD                                    # i 不可达
```

## 测试

`tests/` 下：t1 基本树覆盖；t2 共享子表达式只算一次 + 复制；t3 跨节点融合
模式与并列最优（WAYS 2）；t4 强制跨类别复制；t5 不可行；t6 共享节点并列
覆盖计数；t7 共享节点同时是输出根。
