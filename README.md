# 带时效性的空间点集凸包演化器

每个坐标点携带**进入时间**与 **TTL 失效时间**；随逻辑时间推进，新点加入、老点自然过期淡出，演化器**增量维护**当前存活点集的二维凸包多边形顶点序列（逆时针），全程**从不全量重跑 Graham 扫描**。

典型场景：无人机编队飞行散点 → 动态活动空域安全边界。老探测点随 TTL 失效淡出，边界随之收缩（见下方运行样例中 t=12 编队返航后面积从 1534 收缩到 534 的过程）。

## 运行环境

- Node.js ≥ 22.6（利用 `--experimental-strip-types` 原生运行 TypeScript，零依赖、零构建）

## 快速开始

```bash
npm test     # Node.js 内置测试运行器（node:test）
npm run demo # 无人机编队动态空域边界演化样例
```

## API

```ts
import { DynamicConvexHull } from "./src/index.ts";

const evolver = new DynamicConvexHull();

evolver.add(x, y, ttl);              // 当前时刻进入，ttl 后过期
evolver.schedule(x, y, ttl, tEnter); // 预约未来时刻进入
const hull = evolver.advanceTo(t);   // 推进逻辑时间：先过期淡出、后新点进入
                                     // 返回 t 时刻凸包顶点序列（逆时针）
evolver.getHull();                   // 当前凸包顶点（不含共线冗余点）
evolver.getAlivePoints();            // 当前存活点
evolver.getStats();                  // 增量维护统计（fullRescans 恒为 0）
```

## 算法：上/下双链增量维护

凸包拆为两条 x 单调链（上链 ∩、下链 ∪），存活点集同时保存在按 `(x, y)` 有序的顺序表中，过期事件由最小堆驱动：

- **插入** `O(log n + k)`：新点若落在当前包络内侧（对所在 x 处链边做叉积判断），直接忽略；否则将其并入对应链并做一遍局部单调性扫描——新凸包顶点集必为 *旧链顶点 ∪ {新点}* 的子集，无需触碰其余存活点。`k` 为被挤下链的顶点数，均摊 O(1)。
- **过期** `O(log n)` 或局部修复：过期点不是链顶点则零几何代价；是链顶点时，由支撑线论证其左右链邻居必然仍是凸包顶点，新暴露顶点只可能出现在邻居夹出的 x 开区间内——仅从有序表取该区间切片做局部链重建，**绝不全量重扫**。
- **生命周期**：进入/过期各由最小堆调度，`advanceTo(t)` 按时间顺序消费事件（同一时刻先过期后进入）。

`getStats()` 可验证增量性质：`insertSweeps`（插入触发链扫描次数）与 `localRepairs`（过期触发局部修复次数）均显著小于事件总数，`fullRescans` 恒为 0。
