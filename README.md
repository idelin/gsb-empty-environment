插件宿主在三个及以上隔离域间往返传递只读代理对象时，若策略图折叠或包装层叠加破坏了语义等价判定，将触发身份分裂或权限放大，给 TypeScript 宿主实现可导入的多域双向互模拟视图组件。输入为不可变描述图（严禁执行携带函数），支持 `read`/`write`/`invoke`/`construct`/`enumerate` 衰减能力、原型链继承边与多域往返传递（如 `A -> B -> C -> A`）；同一对象沿同一或等价策略路径再次穿回原域时，须恢复一致的身份映射且绝不因拆封或重包装而放宽任何能力。组件采用循环策略图上的严格互模拟（bisimulation）语义判定两个代理视图是否共享缓存身份，禁止依赖对象地址排序或路径字符串字面相等。支持针对多分支菱形授权的细粒度撤销：撤销其中一条授权边时，仅立即降级或失效依赖该边的缓存视图与异步回调结果，经独立授权分支获得的同一底层对象视图不受误伤，且不得通过 `enumerate` 键顺序泄露已撤销属性。用有限状态图关系模型对照三域往返、菱形部分撤权与非反射不执行约束。
