# symex8 — 8 位整数小语言的符号执行器

TypeScript 实现，支持赋值、条件、有界循环；相同程序位置的状态会被合并，
但各条路径的路径条件以 `ite(路径条件, 值A, 值B)` 守卫的形式完整保留在
符号值中。对指定断言输出触发其失败的**最小输入**，并用**全输入穷举**
（256^n 个输入逐一具体执行）对照验证，同时检查**算术溢出**与**不可达分支**。

## 运行

需要 Node ≥ 22.18 或 ≥ 23.6（原生 TypeScript 类型擦除），或有 `tsc` 时自行编译。

```sh
node src/main.ts        # 演示：符号执行 + 穷举对照报告
node test/run-tests.ts  # 测试：单元测试 + 已知答案程序 + 随机程序模糊对照
```

## 语言语义

- 所有值为 8 位有符号整数（-128..127），`+ - *` 溢出按二进制补码回绕；
- 条件以非零为真；比较与逻辑运算（`&& || !`）产生 0/1，均不短路；
- 读取未赋值的变量得到 0；
- `while` 是有界循环：循环体最多执行 `loopBound` 次；第 `loopBound+1` 次
  条件求值仍为真的路径记为“越界”并丢弃（不参与后续断言判定），
  越界输入集合会单独报告并与穷举对照。

## 最小输入定义

按输入声明顺序、以无符号字节（0x00..0xFF）字典序最小的输入元组。

## 工作原理

- `src/sym.ts`：符号值 DAG（常量 / 输入 / 算术 / 比较 / `ite` / 溢出谓词），
  构造时做常量折叠与布尔化简；
- `src/executor.ts`：符号执行。`if` 分叉为两个状态、汇合处合并；
  `while` 在循环头每轮合并。合并规则：变量取 `ite(守卫, v1, v2)`，
  路径条件取析取。执行中记录每个断言的失败条件（`pc ∧ ¬cond`）、
  每个分支臂的可满足性公式、每个算术点的溢出公式（`pc ∧ ovf`）；
- `src/solve.ts`：求解器。8 位输入空间很小，按字典序枚举即可，
  首个满足失败条件的输入即最小输入；
- `src/interp.ts`：同语义的具体解释器；
- `src/check.ts`：对全部输入逐项比对 —— 失败输入集合、最小输入、
  逐断言失败集合、分支可达性（查不可达分支）、溢出点、循环越界集合。

## 示例输出（demo 程序）

```
a = x + 60
if (a > 10) b = a * 2 else b = a - 100
b = b + y
while (i < 3) { b = b + x; i = i + 1 }
assert(b != 0)
```

失败条件（合并后单个符号状态上求得）：

```
(((x+60)>10) | !((x+60)>10)) & !((ite ((x+60)>10) ? (x+60)*2 : (x+60)-100) + y + x + x + x) != 0)
```

最小触发输入：`x=0x00 (0), y=0x88 (-120)`，与 65536 个输入的穷举结果一致。
