日志宿主在一条长记录处理中可能收到受签的脱敏词典切换通知，必须明确哪些仍未发布的原始字节适用哪一代策略。给 TypeScript 宿主写可导入的流式发布组件，接受有界歧义的归一化规则、字节片、签名版本切点和回退收据。一个秘密串可跨块与切点，按宿主登记规则由它涉及的两代策略共同裁决；不能把原始字节拆成两个各自安全的前缀提前发布，且禁止在多字节 UTF-8 或归一化折叠边界产生半字符泄漏。已认证公开前缀不能在重试中重复释放，未知确认只能取回同一份暂存结果。为每段可发布前缀给出含原始位置和所用规则代次的可核验凭据，不泄露被屏蔽内容或不同合法分词的数量。用短串全部切分和两代词典全分词参考对照并列命中、切点落在多字节字符内、撤销与最后一片同时到达及异常后恢复。
