# dom — 动态图支配树维护与反例生成器

Go 标准库实现的控制流图支配关系计算器：

- 从入口节点计算所有节点的直接支配者（idom），基于迭代数据流方程
  `dom(n) = {n} ∪ (∩ dom(p))`。
- `Tree.AddEdge` / `Tree.RemoveEdge` 在增删单条边后做增量局部更新：
  仅在受影响区域（变更边目标可达的节点集）上重跑数据流；插边时以当前解
  热启动（支配集只缩），删边时将受影响区域重置为格顶元再收敛（支配集只涨）。
- `Tree.Counterexample(x, y)` 对不成立的支配断言 "x 支配 y" 输出一条
  从入口到 y 且不经 x 的反例路径（BFS 避点）。

## 运行

```sh
go test -v ./...   # 验收测试
go run ./cmd/demo  # 菱形结构演示
```
