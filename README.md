RPC 框架要不经代码生成直接读写协议缓冲区的线上格式。给编解码层交付可导入的 Go 包。线格式按字段号、线型和载荷：变长整数、六十四位、长度前缀、三十二位，以及成对的分组起止标记。读取时按调用方给出的模式还原消息，模式含字段号、线型、是否可重复、是否打包、映射和单选组；未在模式中的字段按原字节原次序保留，写出时原样接回。映射项按两个子字段的消息读，缺省用零值；单选组后出现的字段生效。以下情况报错：变长整数超过十个字节、长度前缀超出数据、分组起止不配对、字段号为零。验收用十六进制样例逐字节对照，随机消息往返不变，覆盖负数枚举、打包与非打包两种写法读出相同结果、嵌套分组中的未知字段和截断输入。
