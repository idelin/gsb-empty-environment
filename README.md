# orgtree — 可追溯员工组织架构时态树

纯 Go 标准库实现的双时态（bitemporal）组织架构汇报线组件。

## 模型

每条汇报关系记录带有两个时间维度（均为左闭右开区间）：

- **业务时间 `[ValidFrom, ValidTo)`**：汇报关系在现实中生效的区间；
- **系统时间 `[SysFrom, SysTo)`**：该事实被系统知悉（录入）的区间。

所有历史版本以追加方式保留，修订只关闭旧记录（`SysTo` 置为录入时刻），
从不改写或删除，因此任意 `(业务时刻, 知悉时刻)` 组合都可精确回溯。

## API

- `Assign(employee, manager, validFrom, validTo, sysTime)`：在知悉时刻
  `sysTime` 录入汇报关系；与现存记录业务区间重叠时自动分裂——旧记录关闭，
  不重叠的头尾部分以 `sysTime` 重新录入，重叠部分由新记录覆盖。
- `ManagerAt(employee, validTime, sysTime)`：查询某知悉时刻看来、某业务
  时刻的直接汇报对象。
- `ChainAt(employee, validTime, sysTime)`：查询完整汇报链（含环检测）。
- `Records()`：返回全部记录版本（含已关闭历史），用于审计。

## 验收边界

员工 E 在业务 `[1,10)` 汇报给 M1（知悉 1 录入）；知悉 5 补录业务 `[3,7)`
汇报给 M2。则：

| 查询                | 结果 |
|---------------------|------|
| 知悉 6 / 业务 4     | M2   |
| 知悉 6 / 业务 8     | M1   |
| 知悉 4 / 业务 4     | M1   |

补录后记录自动分裂为：`[1,3)->M1`、`[3,7)->M2`、`[7,10)->M1`
（知悉 `[5,∞)`），原始 `[1,10)->M1` 保留为知悉 `[1,5)` 的历史版本。
