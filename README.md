高性能网络防火墙在 XDP 层直接解析原始以太网帧并执行包过滤时，若解析器假定固定 14 字节以太网头而未按规范推进多层 802.1Q/802.1ad VLAN 标签、MPLS 标签栈或 IPv6 扩展头链，攻击者可通过堆叠标签或分片扩展头绕过 L3/L4 策略检查并触发 `data_end` 越界读取。为 C++17 网络安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的原始字节级多层封装数据包安全解析与策略验证库。组件从 `[data, data_end)` 原始指针区间严格执行前置边界检查后逐层解码：Ethernet -> 最多 4 层 VLAN（`0x8100`/`0x88A8`）-> 最多 8 层 MPLS（校验栈底位 `S=1`）-> IPv4（校验 `IHL >= 5`、`TotalLength` 与分片偏移）或 IPv6（遍历 Hop-by-Hop/Routing/Fragment/Destination Options 扩展头链并设最大跳数防死循环）-> TCP/UDP/ICMPv6；任何一层剩余字节不足、扩展头循环或异常截断立即返回安全丢弃。策略引擎对解出的最内层五元组与分片标志执行严格过滤，拒绝利用 `IPv6 Fragment` 首片不含 L4 端口或重叠分片绕过防火墙的畸形报文。附手工构造的多层 VLAN+MPLS 封装、IPv6 扩展头环路、`IHL<5` 截断与分片绕过样本实测全拦截。
