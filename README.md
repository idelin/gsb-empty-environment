# 安装生命周期脚本越过声明能力

包安装器允许依赖运行构建脚本，恶意包可能读取宿主凭据或写出安装根。给Go安装宿主实现可导入的脚本能力计划包，不执行真实进程：包图节点含内容摘要、依赖边及脚本声明，声明的动作仅为Read(path)、Write(path)、Exec(toolID)、Connect(endpointID)和Env(name)。宿主策略按包摘要授予各动作集合，路径从该包不可变源码根或专属输出根的目录句柄解析，禁止绝对路径、点段、symlink父项和跨包输出；工具与端点只认宿主登记ID，环境变量按名称逐项授权且值只在执行时注入。计划器输出每包能力清单；脚本事件轨迹由测试回调产生，每个实际动作必须被声明且被策略授权，派生子进程继承两者交集，不得自行扩权；并行脚本的输出根隔离，发布阶段才按固定依赖顺序合并，冲突路径拒绝。任一越权或回调失败使整包输出不可见并撤销其后继，已完成的无关包保留不可变缓存。用恶意轨迹测试读取凭据、工具别名、symlink换父目录、子进程加网络和两个包写同一路径，输出从包到违规动作的依赖证据。
