# pkgincr — 增量打包工具

按有序路径规则把目录树打包成 tar，支持子树剪枝遍历、决胜规则输出、
符号链接只存链接本身，以及基于清单（manifest）的增量打包。

## 构建与测试

```sh
go build ./cmd/pkgincr
go test ./...
```

## 用法

```sh
pkgincr -root DIR -rules rules.txt -out out.tar [-manifest m.json] [-v]
```

- `-rules`：规则文件，缺省时包含全部文件。
- `-manifest`：上一轮产出的清单；提供后只把新增/变化的文件写入本次
  tar（目录条目无数据、总是写入；被删除的路径从清单中移除）。
- `-v`：额外打印被排除与被剪枝的路径。

正常输出会为每个文件打印决胜规则，例如：

```
include  build/keep.txt   rule #4: + /build/keep.txt
exclude  build/junk.txt   rule #3: - /build/ via ancestor
pruned   build/sub        (subtree skipped: no later rule can match inside)
```

## 规则语义

- 每行一条规则：`+ 模式` 包含，`- 模式` 排除；`#` 为注释。
- **后规则覆盖前规则**：对每个路径，最后一条命中的规则生效。
- 规则命中某个目录时对其整个子树生效；但**排除目录后，更靠后的
  子规则仍可重新包含**其中的路径（`- /build/` 之后
  `+ /build/keep.txt` 会找回该文件）。
- 没有任何规则命中的路径默认包含。

## 模式语法（类 gitignore）

- 不含 `/`（尾斜杠除外）的模式匹配任意深度的**基名**：`*.o`。
- 含 `/` 的模式**锚定**到根：`/a/b`、`a/b/c`。
- 尾斜杠表示仅匹配目录：`build/`。
- 段内支持 `*`、`?`、`[...]`；整段的 `**` 匹配**零或多级**路径：
  `a/**/b` 命中 `a/b` 与 `a/x/y/b`。
- 同名路径的不同写法会归一化：`./a/b`、`a//b`、`a/./b`、`/a/b`
  行为完全一致；不允许 `..`。

## 遍历剪枝

目录被排除时，若其决胜规则之后没有任何规则可能匹配到它的子孙
（用 glob 前缀可匹配性保守判定），整棵子树直接跳过，不再 stat
任何子节点；否则继续下潜以寻找被重新包含的路径。

## 符号链接

符号链接只保存链接本身（tar 中的 `TypeSymlink` + 链接目标），
从不跟随；指向目录的符号链接不会被当作目录下潜，目录限定模式
也不会命中它。

## 测试

- `rules_test.go`：模式匹配、`**`、归一化、子树可匹配性判定。
- `walk_test.go`：重新包含、剪枝、空目录、符号链接；并用**有限
  文件树全遍历参考实现**（不剪枝、按“命中自身或祖先的最后一条
  规则”直接定义）对随机树 × 随机规则集做 400 轮差分核对，覆盖
  双通配、空目录与同名路径归一化。
- `pack_test.go`：tar 中符号链接形态、空目录保留、增量清单行为。
