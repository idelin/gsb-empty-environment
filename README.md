条带巡检器碰到了静默损坏：同一盘返回的若干分片可能一起不可信，但盘没有报告是哪一块坏了。给对象存储提供可导入的 Go 读修复包。每个分片记录物理盘、条带、原始片号、GF(256) 系数行，以及分片中实际读出的若干字节位置和值；同一逻辑分片后续可补齐先前读不到的位置。给定最多 f 个坏盘的预算，删去它们的所有观测后剩余方程必须在每个字节位置自洽；同一个坏盘集合适用于整组条带的所有位置。域模多项式为 0x11d，各条带的源数据相互独立。每次收到观测后，返回在所有合法坏盘集合、所有一致源数据中值相同的源字节；对一个未决定的查询，返回两套能独立核验且给出不同字节的完整解释。若不存在任何解释，隔离这批输入并返回覆盖所有大小≤f删盘集合的反证：每个叶子用原片号、位置与线性组合系数证实零行非零常数；允许共享冲突分支，不能只说秩不对。某个位置看似能单独纠错，并不保证所有位置能同时由同一组坏盘解释。交付只对已经无歧义的字节写回的存储适配器；失败批次不得改写已发布数据或污染下一批状态。最多 40 块盘、f≤3、每条带最多 12 个源块，不得枚举源字节取值的笛卡尔积。用缩成二元系数且源块数很少的子实例独立穷举做一致性对照，另测两个位置分别要求丢弃不同盘、两种故障归因却导出相同请求值、重复输入不重复写回、满秩单一解释不能代表全局确定。
