# motion

运动相交计算库：给定两条分段匀速轨迹，返回距离平方不超过指定阈值的**全部**时间区间。

## 模型

- 轨迹由若干 `Segment` 组成，每段在半开区间 `[Start, End)` 上有效，
  位置为 `Pos + Vel*(t-Start)`。段间允许跳跃（断点处位置由**后一段**决定），
  也允许覆盖空隙（空隙上轨迹未定义，不产生任何区间）。
- `Intersect(a, b, maxDistSq)` 返回排序、合并后的 `[]Interval`，
  满足 `|a(t)-b(t)|² <= maxDistSq`。

## 精确性

- 对每对重叠时间段，相对距离平方是局部时间 `s` 的二次函数
  `f(s) = a·s² + b·s + c`，直接求解精确二次不等式 `f(s) <= 0`，
  **不是**只检查每段起终点（段中下凹低于阈值也能检出）。
- 区间端点由二次方程根隔离给出（稳定求根公式）。
- 擦边（相切）接触报告为点区间：`Start == End` 且 `EndClosed == true`。
- 输出区间起点总是闭的；`EndClosed` 表示终点是否包含。
  解延伸到段边界时终点为开——该瞬间的距离由后一段（可能已跳跃）决定。

## 测试

- `motion_test.go`：手工构造的精确用例（擦边、静止、断点跳跃开闭性、
  根恰落在断点、零阈值会合、覆盖空隙、3D 等）。
- `reference_test.go`：独立的逐对全枚举 + 符号采样参考实现，
  与主扫描线实现做 5000 组随机交叉核对；并对每个结果做语义验证
  （在临界点与中点处直接采样轨迹位置，核对区间成员关系与端点开闭性）。
