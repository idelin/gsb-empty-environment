嵌入式事务引擎把不同连接的 WAL、可见性位图和检查点页交给三个写回队列；一个刷新操作只保证其覆盖范围内已排队的较早记录稳定，并非整个设备屏障。给事务层做可导入的 Go 包：输入依赖有向图、各动作在三个队列的归属、提交返回及候选刷新位置和覆盖集合，每个动作附实际编码字节。求费用最小的刷新集，使任何合法交错和单次掉电后的磁盘可见前缀经真实恢复解释器解码后，不丢失已确认事务，也不泄漏已回滚的写。部分长 WAL 记录跨页，在校验和完整之前不能视为可重放。提供可重放反例（具体交错、落盘前缀和解码后表），并为最优结果给下界证明，不能把所有先后边当必须刷新。每个分量至多十二事务与十六候选位点；小图逐事件对照，覆盖一条范围刷同时满足多提交和撤销日志被截半。
