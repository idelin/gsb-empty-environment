镜像网关允许将多架构索引中有权读取的平台复制到另一个仓库。过滤掉平台描述符后索引字节和摘要会变化，原索引的签名不能继续冒充新索引的签名。给 Go 网关做可导入的授权投影包。清单、嵌套索引、层和附加证明组成有向图，可以共享节点；每条描述符边绑定源仓库身份、允许的主体、平台谓词与精确子摘要。只能沿同一授权路径读取节点，物理内容库里已经有相同摘要也不构成读取许可。输出只保留目标主体可见的描述符，并从叶向根重算规范字节与摘要。附加证明若绑定的主体字节未改变，可按签名策略保留；主体变了必须剥离旧证明，同时生成由宿主另行签名的投影来源收据，不能从另一仓库同摘要证明拼接。每个公开条目都要有独立可验的源路径与目标写授权，返回信息不得揭示隐藏平台数量。相同节点在不同路径授权不同时应产生不同投影，完全等价时应共享；只能按可达节点与有效授权上下文处理，不能展开指数多条路径。用具有共享子索引的合成仓库对照全展开小图，验证删一个描述符使祖先签名失效、相同层在另一仓库无权读、未变子图的签名保留和并发标签换代时整次复制不发布。
