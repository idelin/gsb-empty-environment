# 9P附着点与walk越界

9P2000.L 服务把某个目录作为附着点导出，攻击者在 Tattach 的 aname 里写路径，或用 Twalk 连续 `..` 与符号链接离开导出根。为Go的 9P 服务写可导入的 fid 授权包：aname 只能是调用方登记的导出名，找不到即返回 Rlerror；每个 fid 绑定其附着根，Twalk 逐元素处理，元素含 `/` 或 NUL 拒绝，`..` 在根处停在根自身；单次 Twalk 元素数超过 16 拒绝；符号链接按调用方注入的文件系统解析后的真实路径须仍在根内；newfid 已被占用且不等于 fid 时拒绝；Tclunk 之后 fid 立即失效，复用须重新 walk。测 `..` 越根、符号链接、重复 newfid、clunk 后使用。
