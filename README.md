Linux 特权二进制与插件加载器在上线前做安全准入审计时，若仅凭字符串检索判断加固标志而未从原始 ELF64 程序头、`.dynamic` 段与重定位表精确核算内存映射边界，攻击者可利用未覆盖完整 `.got`/`.got.plt` 的伪 Full RELRO、可写可执行的 `PT_GNU_STACK`、含相对路径或空项的 `DT_RPATH`/`DT_RUNPATH` 搜索劫持，以及指向可写段的 `STT_GNU_IFUNC`/`R_X86_64_IRELATIVE` 解析器实现特权提升。为 C++17 二进制安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的原始字节级 ELF64 动态安全加固审计库。库严格解析 ELF64 头、程序头（`PT_LOAD`/`PT_DYNAMIC`/`PT_GNU_RELRO`/`PT_GNU_STACK`）、节头及全部 `DT_*` 动态项与 `Elf64_Rela` 重定位表：硬拒绝越界偏移、整数加法回绕与重叠不可兼容的 `PT_LOAD` 权限段；精确按页对齐核算 `PT_GNU_RELRO` 区间是否完整覆盖 `.dynamic`、`.got`、`.got.plt` 及 `.init_array`/`.fini_array`，并结合 `DT_BIND_NOW`/`DF_BIND_NOW`/`DF_1_NOW` 判定真实 Full RELRO 与 Partial RELRO；扫描 `DT_RPATH`/`DT_RUNPATH` 检出空路径段（等价当前目录 `.`）、非绝对路径、未受限 `$ORIGIN` 穿越与 `PT_GNU_STACK` 可执行标志；同时检查全部 `R_X86_64_IRELATIVE` 与 `STT_GNU_IFUNC` 解析器地址必须落入只读可执行段且不指向可写区。附手工构造的合法 Full RELRO 样本与伪 RELRO、空项 RPATH 劫持、可写 IFUNC 样本测试。
