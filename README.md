反向代理与 API 网关在解析客户端原始 HTTP/2（RFC 9113）二进制帧流时，若未强制限制连续 `CONTINUATION` 帧数量与头块总字节、允许在头块未 `END_HEADERS` 前交错其他流帧、未校验伪头字段（`:method`/`:scheme`/`:authority`/`:path`）顺序与唯一性，或未拦截单位时间内海量新建流随即发送 `RST_STREAM` 的 Rapid Reset（CVE-2023-44487）攻击，攻击者可瞬间打满 CPU/内存或实施请求走私。为 Go 网关安全宿主实现可导入的 HTTP/2 帧流安全解析与 DoS/走私防御状态机包，严禁联网与严禁调用外部 HTTP/2 库。组件直接处理原始二进制帧（9 字节帧头 + 载荷）与简化 HPACK 头表：（1）严格执行帧序与头块状态机：收到未置 `END_HEADERS` 的 `HEADERS`/`PUSH_PROMISE` 后，下一帧必须为同一流 ID 的 `CONTINUATION`（任何跨流交错或非 `CONTINUATION` 立即返回 `PROTOCOL_ERROR`），并对单头块最大 `CONTINUATION` 帧数与累计字节数设硬上限（拦截 CONTINUATION Flood）；（2）严格校验伪头规范：硬拒绝重复伪头、普通头之后再出现伪头、大写头名、头名/头值含 `CR`/`LF`/`NUL` 或非法 `Connection`/`Transfer-Encoding` 逐跳头，以及 `Content-Length` 与实际 `DATA` 帧总字节不符的走私报文；（3）实现滑动窗口 Rapid Reset 检测器：追踪客户端在窗口内发送 `HEADERS` 后于响应完成前主动 `RST_STREAM` 的次数与占比，超阈值立即返回 `ENHANCE_YOUR_CALM`（`0xb`）并触发 `GOAWAY` 断连。附 CONTINUATION 洪泛、跨流交错、伪头走私与 Rapid Reset 触发 `GOAWAY` 对抗测试。
