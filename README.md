# 外呼服务通过域名检查后并行拨号，攻击者在重试时改变DNS答案以进入内部管理网

外呼服务通过域名检查后并行拨号，攻击者在重试时改变DNS答案以进入内部管理网。实现供Go拨号宿主调用的目标绑定包，许可固定规范域名、端口、已验证IP集合和策略代次；连接回调返回实际对端，必须属于该集合且仍满足当前禁止CIDR，禁止按域名让底层再次解析。配置撤销与交付有单一顺序，迟到连接关闭。用本地替身解析器和拨号器构造答案变换、IPv4映射地址与双成功竞争，核对内部对端从未交付。

## 包结构（package taskpkg）

- `Policy` / `NewPolicy`：固定规范域名、端口、已验证 IP 集合、禁止 CIDR 与策略代次；IPv4 映射地址（`::ffff:a.b.c.d`）在校验前去封装并去重。
- `Binder.Dial`：通过注入的 `Resolver` 只解析一次域名，仅保留命中已验证集合的答案，再以 `ip:port` 字面量并行拨号；底层 `Dialer` 永远收不到域名，因此不会发生第二次 DNS 解析。
- 单一交付门：实际对端必须属于已验证集合、端口匹配、代次仍为当前代次、且不命中当前禁止 CIDR。`Update`、`Revoke` 与交付共用同一把互斥锁，撤销/换代后到达的连接以及并行竞争中的败者都会被关闭，绝不回调。
- `OnConnect` 回调返回连接与实际对端 `net.Addr`。

## 验证

```sh
go vet ./...
go test -race -count=1 ./...
```

测试使用替身解析器与拨号器覆盖：重试时 DNS 答案切换到内网（rebinding）、伪造内网对端、IPv4 映射地址的拒绝/接受/禁止 CIDR、双成功竞争只交付一条、撤销前后与在途迟到连接、代次换代与主机端口绑定。
