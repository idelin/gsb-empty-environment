# 聚合器检查点与幂等发布演练

演示聚合器在崩溃恢复下的精确一次（effectively-once）语义：

- **检查点**（`checkpoint.go`）持久化累计值（Offset/Sum/Count）、待发结果
  （Pending）和结果 ID 序号（NextResultSeq），临时文件 + 原子 rename 落盘。
- **发布与确认分离**（`aggregator.go`）：先生成结果并随检查点落盘，再发布，
  接收方确认后才从待发中移除。结果 ID 来自持久化序号，恢复重发同一 ID，
  绝不生成替代 ID。
- **幂等接收模型**（`receiver.go`）：按结果 ID 去重，重复投递只确认不计数，
  并校验结果区间连续性（空洞/重叠计入 GapErrors）。
- **故障演练**（`scenario.go`）：在 6 个故障点逐一注入崩溃（模拟进程重启，
  仅从检查点恢复），验证两项进度：
  1. **计算状态恢复**：位移重放后 offset/sum 与输入完全一致；
  2. **效果确认**：待发清空、接收方合计精确、无重复计数、无区间空洞。

## 运行

```sh
go run .        # 打印各故障点的两项进度表
go test ./...   # 逐项断言幂等与恢复不变量
```
