# 设备授权码暴力猜测限流

设备授权流程里，攻击者批量猜测 user_code，把自己的设备绑到受害者的授权上，或高频轮询拖垮后端。为Go授权服务器写供设备授权端点调用的 user_code 与轮询管控包（RFC 8628）：user_code 为 8 个字符，取自 BCDFGHJKLMNPQRSTVWXZ，展示时 4-4 用连字符分隔，输入时忽略连字符与大小写；同一来源 IP 在 5 分钟内最多 5 次错误，超过后该来源锁定 15 分钟，对所有 user_code 一视同仁；单个 user_code 累计 5 次错误尝试即作废；设备轮询间隔默认 5 秒，早于间隔再次请求返回 slow_down 并把间隔加 5 秒；device_code 换出令牌后立即失效；用户拒绝授权后轮询返回 access_denied。用连字符与大小写、错误次数、间隔违规、成功后重放和锁定边界验证。
