密钥从虚拟地址擦掉后，写时复制快照仍可能持有原页。给 C++20 加密宿主实现可导入的秘密页生命周期库，以注入的页分配器和可暂停擦除器承载真实缓冲区。逻辑区间可跨页；克隆继承区间，首次写才复制受影响页；调用方可借只读视图持有固定版本。部分轮换只替换指定区间的密钥代次，单个物理页因此可能含多个代次的密钥，且必须阻止通过页内邻接未擦除间隙或部分失败的暂存复制缓冲区发生跨代次读取。删除一个代次后立即阻止新借用，已获准的借用须在约定释放点前保持字节稳定；最后一个合法可见者退出后，擦掉所有曾接收该代次的物理字节和分配器内的暂存副本，才可发出销毁证明。不得清零同页仍活跃的其他代次。地址可重用，擦除完成回调可乱序、重复或迟到。证明绑定分配代次、字节区间、借用屏障和擦除回执，另给宿主一个只读事件验收函数，漏掉任一区间或把旧回执算给新页都须拒绝。分配或复制中途失败必须仍能释放已写入的秘密。用追踪分配器逐字节核对跨页分裂与再合并，枚举借用退出、迟到确认、同址重分配的短交错，在每次暂存复制后注入异常。
