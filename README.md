# pixel-delta-history

局部像素编辑的差量历史引擎：自建 RGBA 小图，不依赖 Canvas 滤镜或任何图像处理库。
纯 TypeScript，零依赖，使用 Node.js（>= 23.6，原生类型擦除）内置测试运行器验证。

## 特性

- **差量历史**：局部编辑只存储变化像素的 span（偏移+长度）及前态/后态，不存整图。
- **分支撤销**：历史组织为树；undo 后新编辑产生分支，`redo(transactionId)` 可显式选择分支，默认走最新分支。
- **内存压缩**：所有差量负载经像素单元（4 字节）PackBits 风格 RLE 压缩；纯色区域压缩率 >100x。
- **重叠编辑逆序恢复**：每个事务只记录自身前态，撤销重叠笔触之一时仅写回其前态，另一笔触不受影响。
- **元数据尺寸变化纳入事务**：裁剪等结构变化作为结构事务（整图前后态快照）进入同一棵历史树，撤销裁剪可完整恢复被裁像素。
- **历史淘汰不损坏当前图**：超过 `maxTransactions` 时先剪除不在当前路径上的死分支，再把最老事务前滚合并进基线快照；淘汰只动历史末端，`verifyAgainstReplay()` 可随时校验当前图与基线重放一致。

## 结构

- `src/image.ts` — RGBAImage：自建 RGBA 像素容器（getPixel/setPixel/crop/clone/equals）
- `src/rle.ts` — 支持多字节单元的 RLE 压缩/解压
- `src/history.ts` — Transaction（span 差量 / 结构快照）、分支历史树、淘汰与前滚合并
- `src/editor.ts` — PixelEditor 门面：stroke / fillRect / crop / undo / redo / branches / stats
- `test/` — node:test 测试
- `examples/demo.ts` — 运行样例（ASCII 渲染画布）

## 运行

```bash
npm test    # node --test test/*.test.ts
npm run demo
```

## 运行样例（节选）

```
== 两个重叠笔触 A(红横) + B(蓝竖) (12x12) ==
......B.....
..RRRRBRRRR.   <- 交点被 B 覆盖
......B.....

== 撤销 B：交点恢复为 B 之前的红色，A 完好 ==
..RRRRRRRRR.

== 裁剪后（尺寸变化已纳入事务） (6x6) ==  ->  == 撤销裁剪：被裁像素全部恢复 (12x12) ==

== 分支：e1 之后有两个可重做分支 ==
#2 e2 | #3 e3

== 100 次编辑，历史上限 10 ==
活事务: 10  前滚合并: 90  可撤销深度: 10
差量负载: 291B  基线快照: 1863B（原始整图 4096B）
淘汰后当前图与基线重放一致: true
```

## 测试结果

```
✔ 重叠笔触：撤销一个只恢复其前态，另一笔触不受影响
✔ 裁剪再撤销：恢复被裁像素与原始尺寸
✔ 元数据尺寸变化与像素编辑在同一事务链中交错撤销
✔ 分支撤销：undo 后新编辑产生分支，可选择分支重做
✔ 历史淘汰：超限后当前图与无历史参考完全一致，且逐步撤销始终自洽
✔ 内存压缩：纯色大矩形的差量负载远小于原始像素
✔ RLE 往返：随机数据 / 纯色数据 / 混合游程 / 长度校验 / 像素单元模式
ℹ tests 11  pass 11  fail 0
```
