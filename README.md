通知服务允许租户上传已经编译的模板片段，片段声明“可在属性中使用”，但这项声明不能由上传者自证。给 TypeScript 模板注册宿主写可导入的字节码准入组件。宿主给出有限的词法状态转移表与编码器摘要，每种动态值有自己的允许上下文、来源标签及输出类别；类别可以跨块改变解析状态。字节码含静态块、动态字段、条件跳转、片段调用和返回，调用图可递归。注册时须证明任一可结束路径上的每个动态字段都在受允许的上下文使用，片段返回时实际状态满足调用点约定；不可用固定调用深度展开，分支到达同一行时也不能把不同调用者的返回位置混用。无条件死循环不能算成功返回，能进入死循环前的字段输出仍须验权。为每个入口生成可核验的摘要关系，独立检查函数验证静态转移、动态授权、调用返回匹配、可达前缀安全与正常结束条件。注册凭据同时绑定代码、被调片段版本及编码器表；替换同名片段后旧凭据不能加载新实现。用显式小步解释器验证非递归小程序，另含互递归、同一片段从两种上下文调用、只在尚未返回的深层出现动态字段及无返回路径等用例。
