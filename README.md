# Lightning粉尘HTLC敞口与费率更新

Lightning 通道里低于粉尘阈值的 HTLC 不会出现在承诺交易输出里，强制关闭时金额直接成为手续费，攻击者可用大量粉尘 HTLC 和抬高费率让对方承担损失。给Go通道状态机写供 add_htlc 与 update_fee 处理调用的粉尘敞口包，按 BOLT 3 非锚点通道：htlc-timeout 权重 663，htlc-success 权重 703，费用等于 feerate_per_kw 乘权重除以 1000 向下取整；我方发出的 HTLC 金额小于粉尘限额加 timeout 费用即为粉尘，对方发来的小于粉尘限额加 success 费用为粉尘；本方与对方两份承诺交易分别按各自视角判定（同一 HTLC 在对方视角方向相反，并使用对方的粉尘限额），每份交易上待决粉尘 HTLC 的金额总和都不得超过调用方给定的最大粉尘敞口，超出则拒绝 HTLC；update_fee 用新费率重算两份敞口，超限同样拒绝。用恰好等于阈值、费率上调使旧 HTLC 变粉尘、两份承诺交易视角不一致验证。
