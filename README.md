权限与血缘分析引擎用带否定的递归 Datalog 规则维护物化视图，但基表删除一条事实后，不能盲目删掉依赖它的推导元组（可能存在另一条独立推导路径），也不能允许负环破坏语义。为查询内核交付可导入的 Go 规则求值与增量维护包。输入基表事实（EDB）、规则集（头部谓词及若干正/负体部原子，支持常量与等值变量连接）及后续一批基表增删变更。引擎先构建谓词依赖图，检测跨负边的强连通环（存在负环返回错误并指出环路谓词）；无负环时按层号拓扑分层，初始用半朴素迭代求得每层最小不动点；收到基表增删后，采用删除-重推导（DRed）策略：先自顶向下收集可能失效的过度删除集，再从同层未删事实重推导仍可由其他路径支撑的元组，最后向上层传播净增量（包含负体部因下游删除而反触发新增推导的情形！）。验收对照每批变更后全量重新求值的理论不动点逐元组核对完全一致，覆盖双路径推导删除其一元组仍保留、删除触发否定子句成真导致上层新增推导、递归环中删边断开自支撑环（计数法会出错而 DRed 正确清除），以及负环规则被拒绝。
