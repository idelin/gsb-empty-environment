# 动态排班技能资质时态匹配器

轮班调度与岗位资质的**双时态**（bitemporal）匹配器，TypeScript 实现，零依赖，
使用 Node.js 内置测试运行器（`node:test`）验证。

## 时态模型

- **Valid time（生效时间）**：证书在现实世界中生效、复审延期、被吊销的时间。
- **Knowledge time（知悉/事务时间）**：调度系统获悉某一事实的时间。

所有判定都可在任意知悉时间点上重放，因此支持**追溯性吊销**的影响分析：
系统在 `knownAt=200` 才获悉"证书在 `60` 被吊销"时，能自动找出已排班次中
落在失效区间的违规班次。

## 核心语义

- 证书生效期为半开区间 `[validFrom, validTo)`；复审事件延长 `validTo`（取最大），
  吊销事件截断 `validTo`（取最小），二者与登记顺序无关。
- 排班校验：班次 `[start, end)` 必须被员工对应技能的所有证书有效区间**持续覆盖**，
  否则拒绝排班并输出缺资质的缺口区间。
- 吊销通知：登记吊销事件后自动重校验该员工该技能的已排班次，输出违规预警列表。

## 文件结构

- `src/intervals.ts` — 半开区间运算（覆盖、合并、减集求缺口）
- `src/matcher.ts` — `QualificationMatcher` 双时态匹配器
- `tests/matcher.test.ts` — 13 个测试（含全部验收边界）
- `examples/demo.ts` — 验收场景运行样例

## 运行

需要 Node.js ≥ 22.6（利用内置 TypeScript 类型擦除，无需编译）：

```bash
npm test      # 运行测试
npm run demo  # 运行验收场景样例
```

## 验收边界覆盖

| 场景 | 结果 |
| --- | --- |
| 持证 `[10,100)`，排班 `[80,120)` | 拒绝，缺口 `[100,120)` |
| 排班 `[80,100)` 恰好落在有效期内 | 通过 |
| 知悉时间收到"证书在 60 吊销" | 自动预警已排班次（如 `[80,95)`）违规 |
| 复审延期至 150，但证书已在 60 吊销 | 仍拒绝，吊销截断优先 |
