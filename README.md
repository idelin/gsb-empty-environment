# keymap-dispatcher

多键序列快捷键分发器（TypeScript），完全由**显式逻辑时钟**驱动，内部不使用任何真实定时器，便于确定性测试与事件重放。

## 核心语义

- **多键序列与前缀等待**：短序列是长序列前缀时进入等待期，期限为 `timeoutMs`（逻辑时间）。期限到达（含恰好等于 `deadline`）执行短命令；等待期内按齐长序列则立即执行长命令。
- **显式时钟**：`handleKey(key, at)` 与 `tick(at)` 是唯一的时间来源，`at` 必须单调不减。按键到达时刻若已越过期限，先按超时结算再处理该键。
- **失配处理**：已输入键 + 当前键无任何候选时，先执行待定短命令，再把当前键从空缓冲重新匹配（仅重试一次）。
- **焦点变更**：`focusChanged()` 取消待定序列，不执行任何命令。
- **上下文栈**：`pushContext` / `popContext` / `setContextStack` 管理上下文栈；候选按栈层优先级裁决，高层（如弹层）候选遮蔽全局候选。等待期间上下文变化会**重新裁决已输入键**，但重新裁决本身绝不触发命令，期限保持原值。
- **配置原子热更新**：`setConfig` 先校验后整体替换；非法配置抛错并保留旧配置。替换后同样重新裁决待定序列。
- **暂停/恢复**：`pause()` 忽略按键与时钟事件；`resume()` 后序列状态、期限与代际（`generation`）保持不变。
- **代际（generation）**：每条新序列（首个有效按键）递增一次，执行/取消事件均携带，便于断言暂停恢复与同刻重放行为。

## 运行测试

需要 Node ≥ 22.6（利用原生 type stripping 直接运行 `.ts`，无需编译；推荐 v23.9.0，见 `.nvmrc`）：

```sh
npm test
```

测试全部通过显式时钟构造事件序列，覆盖：前缀嵌套与恰好到期、同刻按键、失配重匹配、焦点取消、弹层遮蔽、等待期上下文/配置切换的重新裁决、原子热更新失败保留旧配置、暂停恢复保存代际、同刻混合事件重放、时钟单调性。
