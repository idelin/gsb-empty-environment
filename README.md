# sccdemo — 增量强连通分量维护器

动态有向图的 SCC 维护组件，纯 Go 标准库实现。

## 能力

- 顶点动态增删：`AddVertex` / `RemoveVertex`
- 有向边插入/删除：`AddEdge` / `RemoveEdge`（幂等，端点自动补建）
- 每次变更返回 `Delta`，描述分量的合并（`Merges`）与分裂（`Splits`）差量
- 分量标识稳定：取成员中的最小节点 ID

## 实现要点

- **边插入**：若两端点已同分量则无变化；否则从 `to` 做局部前向遍历、
  从 `from` 做局部反向遍历，两者交集即新环上的节点，将涉及的所有旧分量
  增量缩点合并为一个新分量。
- **边删除**：仅当被删边位于某分量内部时，对该分量诱导的子图做局部
  Tarjan 重算；若不再强连通则输出分裂差量。
- 跨分量边的增删不触发任何重算，直接返回空差量。

## 运行

```sh
go test ./...    # 运行测试（含验收场景）
go run ./cmd/demo  # 运行样例
```

## 样例输出

```
== 1. 构建三角形环 A->B->C->A ==
  差量: 合并 [A B C] -> {A,B,C}(id=A)
== 2. 加入独立节点 D 及边 C->D ==
  差量: 无变化
== 3. 删除边 B->C ==
  差量: 分量 A 分裂 -> {A}(id=A)  {B}(id=B)  {C}(id=C)
  当前分量: {A}(id=A)  {B}(id=B)  {C}(id=C)  {D}(id=D)
```
