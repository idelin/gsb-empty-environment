多阶段沙箱宿主使用 Linux Landlock LSM（ABI v1–v4）逐层收窄子进程的文件系统与 TCP 端口权限时，若开发者误认为子层新规则集可以“覆盖放宽”父层限制、漏声明 `handled_access_fs` 导致未列权限默认放行，或忽略 `LANDLOCK_ACCESS_FS_REFER` 跨目录硬链接/重命名时的双端权限与父子集约束，攻击者可将高权限目录中的敏感文件移入可写沙箱目录实现权限提升。为 C++17 沙箱安全宿主实现可嵌入、零外部依赖、`-Wall -Wextra -Wconversion -Werror` 编译通过的 Landlock 嵌套规则域策略求值与逃逸验证库。库建模目录树、文件/目录类型、TCP 绑定/连接端口以及进程继承的多层 Landlock 规则栈（每层含 `handled_access_fs`、`handled_access_net` 与路径/端口规则列表）：（1）严格按内核语义计算任意路径访问的最终裁决——某项权限仅当在所有声明了该 `handled_access_*` 位的祖先规则层中均存在匹配祖先路径/端口的允许规则时才放行，保证任意子层只能单调收窄权限；（2）完整实现 `LANDLOCK_ACCESS_FS_REFER` 跨目录重命名与硬链接校验：要求源目录与目标目录均具备 `REFER` 权限、操作者同时拥有移除源与创建目标所需权限，且移动后目标位置对被移动目录树授予的权限集合必须是源位置权限集合的子集（防止通过 `rename` 提权）；（3）提供策略审计入口，自动检出漏配 `handled_access` 导致未受控高危权限、以及存在可经由跨目录 `rename` 绕过只读约束的文件逃逸路径并给出见证。附多层域交集、跨目录 `REFER` 提权拦截与 TCP 端口收窄测试。
