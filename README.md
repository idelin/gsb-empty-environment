# range-rule-normalizer

范围规则规范化工具：把一组映射到标签的整数多维盒（规则）规范化为互不重叠的
规范分区，重叠时按优先级决胜，并合并相邻同标签区域。输出与输入规则顺序无关。

## 语义

- 盒为半开区间 `[lo, hi)`，坐标必须为整数，维度 1–3（`MAX_DIMS`）。
- 重叠区域由 `priority` 最大的规则决胜。
- 同一位置若有两条同优先级、不同标签的规则同时覆盖，属于未定义行为，
  `normalize` 会抛出冲突错误（同标签同优先级则正常合并）。

## 算法

1. **网格分解**：按所有规则边界在每一维上切分，得到基本单元格。单元格内
   不会被任何规则边界穿过，因此每个单元格的标签是唯一的。
2. **优先级决胜**：对每个单元格取覆盖它的最高优先级规则的标签。
3. **不动点合并**：沿维度 0..d-1 反复合并“同标签、其余维度范围相同、在该
   维度上首尾相接”的区域，直到整轮没有任何合并为止。只合并一遍可能在
   高维留下仍可合并的区域，因此必须迭代到不动点。
4. **规范排序**：输出按坐标字典序排序。由于带标签的单元格集合本身与输入
   顺序无关，且合并过程是该集合的确定性映射，最终输出与输入规则顺序无关
   （测试对 6 条规则的 720 种排列逐一验证）。

## API

- `normalize(rules): Region[]` — 生成规范分区。
- `queryPoint(regions, point): Label | undefined` — 在规范分区上做点查询。
- `queryRules(rules, point): Label | undefined` — 直接在原始规则上按优先级
  决胜（用作参照实现）。
- `partitionVolume(regions)` / `unionVolume(rules)` — 分区体积 / 规则并集体积
  （后者沿独立路径经网格重算）。
- `verifyPartition(rules, regions): VerifyReport` — 体积核验：检查分区两两
  不相交、总体积等于规则并集体积、且每个基本单元格上的标签与规则决胜一致。

## 复杂度

设第 d 维有 n_d 条不同边界，则单元格数 ≤ ∏(n_d − 1) ≤ (2n)^dims，
规范化与核验均为 O(单元格数 × 规则数)。

测试覆盖：优先级切割、相邻合并、L 形不动点合并、720 种排列的顺序无关性、

分区核验、完全合并不变式、顺序无关性和点查询一致性（共 6208 项断言）。
