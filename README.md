# DMA完成环代次归属

设备完成环复用槽位时，旧完成项可能释放新租户正在使用的缓冲。写供Go驱动宿主调用的环管理包，队列槽位绑定提交代次、缓冲租约与租户，硬件只回传截短代次；按最多半圈在途范围恢复完整代次，歧义必须隔离队列，不能猜最近请求。提交序号耗尽时先排空再换纪元。用小位宽环穷举乱序完成、重复项、设备复位和迟到完成，验证只释放对应租约一次。

## genring

实现位于 `genring/`，供 Go 驱动宿主调用：

- `Submit` 把提交代次（纪元 + 纪元内序号）、缓冲租约、租户绑定到槽位，硬件描述符只写槽位号与 `Ring.Tag` 截短代次。
- `Complete` 在“最多半圈在途”窗口内扫描恢复完整代次；截短标签命中多个在途代次或槽位号与属主不符时隔离队列，绝不猜测最近请求。
- 重复完成返回 `ErrDuplicateCompletion`、迟到完成返回 `ErrStaleCompletion`，两者都不释放租约；每个租约经 `OnRelease` 恰好释放一次。
- 序号耗尽进入排空态（`ErrDraining` / `ErrSequenceExhausted`），排空后 `Rollover` 先排空再换纪元；`Reset` 处理设备复位并推进纪元。
- `genring/exhaustive_test.go` 在小位宽环上 DFS 穷举提交、乱序完成、重复、迟到、复位的所有交错，校验只释放对应租约一次。

```sh
go test ./...
go test -race ./genring/
```
