# stats — 加权分位数与多分区一致切面

Go 统计库：输入整数值与非负整数权重，支持在线增减样本，并从多个可断连
分区的带序号差量中构建可查询的一致屏障切面。

## 分位数语义

- `Quantile(q)` 返回累计权重首次大于等于 `q*总权重` 的最小值。
- `q <= 0` 取带正权重的最小值；`q > 1` 按 1 处理。
- 零权重样本不贡献累计权重，永远不会被返回。
- 空集合（总权重为零）单独返回 `ok=false` / `ErrEmpty`，不与正常值混淆。
- `Add`/`Remove` 支持在线增减指定样本；超量移除返回 `UnderflowError`
  且集合保持不变。

## 多分区协调器

- 每个分区发布带序号（`Seq`）的增减差量（`Delta`），差量可携带屏障号
  （`Barrier`），屏障号须随序号递增。
- 差量允许乱序、重复到达：序号用于去重与重排，缺口前的差量先缓冲。
- 只有完整屏障切面可查询：任一被跟踪分区未到达所查屏障时，
  `Query` 返回 `ErrIncomplete`，绝不用新旧混杂的状态作答。分区断连
  即停止发布，查询自然阻塞；`Untrack` 可将其移除。
- 查询通过撤销日志（undo log）把各分区状态回滚到屏障切面后合并，
  因此历史屏障在分区继续推进后仍可查询。
- `Snapshot`/`Restore` 以 JSON 保存并恢复全部状态：去重水位
  （`nextSeq`）、撤销日志与乱序缓冲区，恢复后可安全续传流式差量。

- `coordinator_test.go`：以“汇总原始样本”模型核对多分区屏障切面，
