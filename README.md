快照清单由一串压缩块组成，每块有前代号、字典号、差分基块和恢复所需的两个独立输入范围。给备份检索器写可导入的 Go 包，决定在不可修改的清单旁额外存哪些跳转页；跳转页也是容错单位。读取请求指定一批逻辑块，设备只能向前扫描，允许有限次回卷和两块解码缓存；请求共享解码时必须保留依赖块直至用完。要求任意一张额外跳转页丢失时，所有给定请求仍可在各自读字节预算内完成。先最少额外页数，后最小所有故障与请求中的最坏回卷次数，再取编号向量最小。返回布局、每故障每请求的实际读序和缓存轨迹，核对器按字节跨度计费，不能以最短依赖路径代替。候选跳转页最多十二、每个请求最多十个依赖块，可枚举故障，不得枚举长度达 2^46 的填充字节。小盘穷举参考和去掉一张跳转页后需完全改变解码次序的反例。
