# 跨域服务票据里的PAC没有验签

企业域信任另一森林的KDC，攻击者用可写服务账号构造带管理员组PAC的票据，目标服务只解KDC签名而没核对PAC签名，从而获得域管权限。请实现供C++20 Kerberos服务端调用的可导入PAC校验组件。检查票据的加密类型、KDC签名与PAC内的服务签名、PAC_INFO_BUFFER类型和长度，跨域票据必须由目标域可信KDC签发且PAC签名密钥来自本域krbtgt；只接受声明算法，忽略未知缓冲但记录。委派信息、组SID与用户SID按域边界核对，票据时间与撤销状态一并评估。用跨森林伪造组、缺PAC签名、算法降级、未知缓冲、合法跨域票据和无PAC票据验证只采用本域可信的授权数据。
