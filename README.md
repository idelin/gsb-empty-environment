# 固定点三角形光栅器（TypeScript / Node.js 内置测试）

不依赖 Canvas、滤镜或任何图像处理库；RGBA 图为自建 `Uint8ClampedArray`。
需要 Node.js ≥ 23.6（内置 type stripping，可直接运行 `.ts`）。

```sh
npm test        # = node --test test/*.test.ts
```

## 架构

- `src/fixed.ts` — 16.16 定点转换，**溢出饱和**（不回绕），NaN 向上传播以丢弃非法图元。
- `src/clip.ts` — 裁剪空间 Sutherland–Hodgman：近平面 `z >= -w`、远平面 `z <= w`
  （两者合并同时排除 `w <= 0` 的相机背后反射点）。所有属性在裁剪空间线性插值，
  与透视正确插值严格一致。
- `src/project.ts` — 视口变换到 16.16 定点屏幕坐标，深度量化为 24 位整数，
  每顶点预存 `1/w` 与 `a/w`。
- `src/raster.ts` — 核心光栅化：
  - 边函数用 **BigInt** 精确求值（无舍入、无溢出），采样点为像素中心；
  - **顶左规则**（y 向下、内部为正的绕序）：左边（dy<0）与顶边（水平且 dx>0）拥有边上像素，
    共享边恰好归属一个三角形；
  - 绕序归一化（面积为负交换顶点，零面积丢弃）→ 顶点次序不影响覆盖；
  - 深度为屏幕线性 24 位整数，分子分母全整数运算，跨 tile 完全一致；
  - 属性透视正确插值：`Σλᵢ(aᵢ/wᵢ) / Σλᵢ(1/wᵢ)`。
- `src/renderer.ts` — 分块渲染器。每个 tile 独立地从场景完整重光栅化
  （先不透明 pass，再按 face id 升序的透明 pass），因此**结果与 tile 执行顺序无关**，
  可任意并行。网格编辑（`setFace`/`removeFace`）只重绘该面旧/新屏幕包围盒覆盖的 tile；
  由于 tile 是从场景重算而非图层合成，**删除前景三角形自然恢复被遮挡内容**。
- `src/reference.ts` — 单线程逐像素参考实现（结构上独立于分块渲染器），作为对照真值。

## 显式决胜规则

| 情况 | 规则 |
|---|---|
| 共享边 | 顶左规则：边上像素归"顶边或左边"所在的三角形，恰好覆盖一次 |
| 深度相同（不透明） | 更小的 face id 获胜（稳定、与插入/执行顺序无关） |
| 透明层 | 在不透明 pass 之后按 face id 升序依次 `over` 混合；对不透明深度做 `<=` 测试，不写深度，透明层之间不做深度比较 |
| 退化三角形 | 零面积直接丢弃，不产生任何片元 |
| 定点溢出 | 坐标饱和到 16.16 可表示范围；NaN 图元丢弃；均不抛异常 |

## 测试（test/，node:test + node:assert）

- `coverage.test.ts` — 矩形两三角形恰好覆盖一次（逐像素计数）；逆顶点次序覆盖一致；退化三角形无输出。
- `clipping.test.ts` — 越过近平面（w<0）的三角形：手算透视正确期望值 R≈179/162 逐像素验证，
  并证明"直接套未裁剪坐标"会把该像素丢到三角形外；视口矩形裁剪。
- `depth.test.ts` — 同深度按稳定 face id（两种插入顺序结果一致）；透明层精确混合值
  （单层 `(255,127,127,191)`、双层 `(127,63,191,159)`）；透明片元被不透明遮挡。
- `tiles.test.ts` — 删除前景三角形仅重绘 12 个相关 tile 且恢复背景；移动图元旧新位置都正确；
  5 个随机种子的 tile 乱序执行与逐像素参考逐字节一致；定点溢出/Infinity/NaN 饱和且不崩溃。
