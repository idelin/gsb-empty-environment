# simhashidx

Go 采集管线使用的 SimHash 近重（near-duplicate）索引：对网页分词后的加权特征计算 64 位
SimHash 指纹，并用分段置换表支持汉明距离 ≤ 3 的插入、删除与近重查询。

## 设计

- `SimHash(features)`：每个特征按 FNV-1a 哈希到 64 位，按权重在对应位累加（置位加、
  未置位减），累加结果取符号位得到 64 位指纹；`WeightedTokens` 以词频作为权重。
- 4 张分段置换表：64 位指纹切成 4 个 16 位段，每张表以一个段为桶键，桶内保存该段相同的
  指纹多重集合（支持重复插入）。汉明距离 ≤ 3 的指纹最多翻转 3 个段，必然与查询在至少一个
  16 位段上完全相同，因此查询只需探测 4 个候选桶即可保证召回。
- `Insert` / `Delete` 同步维护 4 张表；删除会清理空桶，被删除的指纹不会再被查询返回。
- `Query` 只扫描候选桶并用精确汉明距离过滤；`QueryCandidates` 额外返回检查的候选数，
  `Stats` 返回表数量、非空桶数量与条目数量。
- `BruteForce` 是暴力扫描参考实现，测试用随机指纹对两种实现做差分对比。

## 验证

```sh
go test -race -count=1 ./...
go run ./cmd/simhash-demo
```

测试在 5000 个随机指纹上执行 4000 次查询（含删除前后），与暴力扫描逐条对比结果；演示程序
在 10000 个随机指纹、1000 次查询的基准上统计表数量与候选数量（平均每次查询仅检查约 2 个
候选，而暴力扫描需要检查全部 10000 个指纹），并展示网页语料的近重命中与删除效果。
