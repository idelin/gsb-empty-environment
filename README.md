# packer — 增量打包工具

按有序规则遍历目录树并输出打包清单，每条目附带其决胜规则；支持增量
（manifest）模式与 tar 输出。

## 规则语义

规则文件每行一条：`+ 模式`（包含）或 `- 模式`（排除），`#` 为注释。

- **有序覆盖**：后面的规则覆盖前面的规则。路径的决胜规则是匹配该路径
  或其任一祖先目录的最后一条规则；无匹配时按默认值（默认包含，
  `-default-exclude` 反转为默认排除）。
- **排除后可重新包含**：排除一个目录会传播到其子树，但之后的规则仍可
  重新包含其中的路径，例如：
  ```
  - /node_modules
  - *.log
  + /a/b/c.txt
  ```
- **模式语法**：`*`、`?`、`[...]`（支持 `!`/`^` 取反与 `a-z` 区间）在
  单个路径段内匹配；整段 `**` 匹配零个或多个完整路径段；含 `/` 的模式
  锚定到根，单段模式匹配任意深度的同名基名；结尾 `/` 仅匹配目录；
  `\` 转义。
- **规范化**：`./a//b`、`a/./b`、`a/b` 规范化后等价（词法清理空段、
  `.` 与可解析的 `..`）。

## 遍历与剪枝

遍历时若某目录被排除，且不存在任何更靠后的包含规则可能匹配其子树
（对锚定模式做前缀可行性判定，基名模式保守视为可行），则整棵子树被
跳过。`ReferenceCollect` 提供不剪枝的全遍历参考实现，
`TestDifferentialRandom` 在随机有限文件树与随机规则集上核对两者结果
完全一致（覆盖 `**`、空目录、符号链接与重新包含场景）。

符号链接只保存链接本身（目标路径），绝不跟随、不下钻。

## 用法

```
packer -root DIR -rules FILE [-manifest FILE] [-default-exclude] [-tar OUT] [-v]
```

- 无 `-manifest`：全量打包，输出 `INC 类型 路径 决胜规则`。
- 有 `-manifest`：增量打包，输出 `ADD`/`CHG`/`DEL`，并更新清单
  （文件按 size+mtime 判变更，符号链接按目标判变更）。
- `-tar OUT`：把本次选中的条目写入 tar（符号链接存为链接头）。
- `-v`：向 stderr 打印遍历统计（visited/pruned/packaged/deleted）。
