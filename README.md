# 相邻行双面翻转的放置证明

内存分配器要避免把敏感页放在攻击者可反复访问的两条相邻DRAM行之间。给Go宿主实现本题物理布局审查与重排包：物理页号0至4095，经调用方提供的纯函数映射到(channel,bank,row)，函数输出须在给定有限范围内；每页有租户、角色{attacker,sensitive,ordinary}和是否可迁移。攻击模型要求同channel与bank、两条不同attacker页分别位于敏感页row-1和row+1，且三页均映射成功；attacker角色页可来自任意低信任租户；同一攻击者页不能同时充两侧。先返回所有最小三页见证。修复允许把可迁移页一一重映射到宿主提供的空闲物理页，页内容身份不变；求迁移页数最少的安全方案，等数按被迁移页ID及目标物理页序列排序，最多20个可迁移页和20个空闲页，预算耗尽返回最佳已知及未闭合下界。初始布局允许存在待修复见证；每个中间迁移步骤不得增加见证集合，最后必须为空，若最终方案存在但无安全顺序则报不可在线迁移。用完整三元组枚举参考核对银行交错、边界row、同侧多页、不可迁移敏感页及必须先搬攻击页的情况；结论只覆盖本题邻接模型，不声称模拟真实DRAM扰动率。
