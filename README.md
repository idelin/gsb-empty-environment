# 跨租户内存去重形成写时延探针

宿主把不同虚拟机相同页面合并为一份只读页，攻击者可通过写时复制延迟判断受害者是否持有某段秘密。为Go隔离测试宿主实现内存去重策略与泄漏实验包：页面含domainID、内容摘要、敏感标签集合、可共享标志和物理页ID；只有同domain且无敏感标签、双方显式可共享的页可合并，跨domain默认禁止。待审策略回调决定合并，内存模型在合并页首次Write时产生COW事件成本10，私有页Write成本1，其他访问成本固定；攻击者能创建候选内容页并观察离散成本，不读取受害页。包枚举有限候选秘密集合，对每个秘密建立受害页，再运行攻击者Prime/Write序列，按观察轨迹分组并输出能区分两个秘密的最短序列。加固策略下跨domain轨迹须独立于受害秘密；同domain去重仍可发生，但若页面标签敏感也禁止。更新页面内容或标签先解除合并再写，物理页引用计数归零才回收，地址复用带代次。用故意全局去重策略复现探针，覆盖摘要碰撞替身、标签后加、COW失败、引用计数和调用方给每种事件的成本闭区间；成本噪声区间；若噪声区间重叠则只能报告可能泄漏。
