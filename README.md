# 销毁规划库（destplan）

供卷宿主调用的 Go 库：在密钥包裹有向图上规划“停用哪些包裹边”，使某租户在指定逻辑区间上彻底丧失解密能力，同时保证依法保留的区间仍然可读。

## 模型

- **映射树**：不可变快照根，节点类型为分支 `NodeBranch`、叶子 `NodeLeaf`、稀疏洞 `NodeHole`、平移复用 `NodeShift`。同一子树可被多个快照/节点共享；快照自带整体平移。
- **块标识 vs 坐标**：叶子给出稳定的密文块标识区间 `[BlockBase, +Span)` 和存储坐标区间（`CoordBase`，缺省等于 `BlockBase`）。同一密文块在不同快照中可以有不同坐标，冲突判定使用块标识而非坐标。
- **包裹图**：根密钥 `KeyRoot` 沿存活边可到达数据密钥 `KeyData`（以及内部包裹密钥 `KeyIntermediate`）。边可带别名，停用一条边会原子地停用其全部别名。
- **请求**：`Destroy` / `Retain` 都是半开 64 位逻辑区间，按快照给出。稀疏洞上的请求没有解密义务，解析结果以 `Gap` 显式返回。

## 64 位地址与符号运算

完整地址空间的半开上界是 `2^64`，无法放进 `uint64`。所有端点用 128 位 `Addr` 表示（`Addr64`、`AddrEnd`、`SpanFull`、`FullSpace`），区间裁剪、平移、块区间运算全程是符号区间，**不按扇区展开**。一个覆盖百万扇区的叶子在解析结果里仍是一条 `Piece`。

## 求解

候选边按别名归组后至多 20 个决策变量。求解器枚举全部 `2^M` 个停用子集，对每个子集用根出发的 BFS 重新计算可达性：

- 销毁区解析出的每个数据密钥都必须不可达——即每条根到密钥的路径都被切断，而非只检查某条见证路径；
- 保留区解析出的每个数据密钥都必须至少有一条存活路径；
- 同一块标识或同一数据密钥同时被销毁与保留时，直接判定不可行。

可行集合排序：总代价升序 → 停用边数升序 → 排序后的规范边 ID 序列字典序。零代价边同样参与该排序。

## 返回结果

- 可行：`Result.Plan` 给出停用组（`DisabledGroups`）、需实际停用的全部别名（`DisabledAliases`）、代价，以及 `OptimalityCertificate`（变量顺序、枚举子集数 `2^M`、下界、可行子集数）。
- 不可行：`Result.Infeasible` 给出四类证明之一：
  - `key-conflict`：销毁与保留共用同一数据密钥；
  - `block-conflict`：销毁与保留共用同一密文块标识；
  - `retain-unreachable`：保留密钥在不停用任何边时就无路径；
  - `cut-coupling`：枚举全部包含意义最小的销毁割，证明每个割都必然切断某个保留密钥。

## 独立验收器

`verifier` 子包不依赖求解器的枚举结论，而是自行重建别名组、重新解析区间、自行枚举全部子集，独立复核：可行性、最优代价与下界、决胜序列、别名原子性，以及各类不可行证明（含耦合证明中每个最小割的有效性和完备性）。篡改代价、边集合、下界或证明都会被拒绝。

## 测试

- `TestDifferentialAgainstSectorOracle`：250 个随机小卷，用完全独立的“逐扇区物化 + 独立子集枚举”预言机与符号求解器差分，并同时过验收器；
- 覆盖共享密钥、切片/别名原子性、零代价边与决胜、删除中途撤销（块/键冲突）、稀疏洞与平移、全 `2^64` 空间边界、高基址叶子、diamond 耦合不可行、20 条边的 `2^20` 枚举性能；
- `verifier_tamper_test.go` 验证验收器拒绝伪造方案与伪造证明。
