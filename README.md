# Perl污点模式启动强制检查

服务端用 Perl 脚本处理上传文件名，污点模式只有解释器启动时带 -T 才生效；首行写了 -T 但实际启动缺它，perl 会报错，攻击者还能借 PERL5OPT、PERL5LIB 注入。为 Go 任务启动器写供脚本执行前调用的启动检查包：输入脚本首行、实际启动参数列表、环境变量与是否 setuid，要求污点模式生效且两处一致，即首行带 -T 时启动参数也须有 -T，只有 -t 不算；污点模式下 perl 忽略 PERL5OPT 与 PERL5LIB，启动器按调用方策略拒绝或清除二者；PATH 含当前目录或可写目录、IFS 非空、环境含 ENV 或 BASH_ENV 时拒绝；-I 指向相对路径拒绝。用首行与启动参数不一致、仅 -t、PERL5OPT 注入、PATH 含 . 和合规启动验证。
