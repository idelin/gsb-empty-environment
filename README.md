# 内核地址输出擦除

沙箱内程序可读取诊断输出，攻击者借其中泄漏的内核地址推断 KASLR。写供 Go 诊断日志服务调用的流式擦除包，识别 0xffff 开头的十六进制内核指针、无前缀 16 位十六进制、%pK 输出及小端字节转储，替换为固定长度占位；同一地址被缓冲块边界拆开时也要识别，普通哈希和用户空间地址保持。用逐字节分块、跨行地址和混合文本验证，输出与不分块结果一致。

## 用法

批量处理：

```go
clean := netsec.Redact("kptr=0xffff888012345678")
// clean == "kptr=[REDACTED]"
```

流式写入（适合诊断日志的 `io.Writer` 管线）：

```go
var sink bytes.Buffer
r := netsec.NewRedactor(&sink)
_, _ = r.Write([]byte("kptr=0xffff8880"))
_, _ = r.Write([]byte("12345678\n"))
_ = r.Close()
// sink.String() == "kptr=[REDACTED]\n"
```

`Write` 会立即输出完整行，并保留末尾未完成的一行；`Flush` 或 `Close` 会处理最后的缓冲内容，因此不要求输入以换行结尾。输出与直接调用 `Redact` 一致，不受 `Write` 分块大小影响。

## 识别范围

- `0xffff...` / `0XFFFF...` 形式的 64 位内核指针。
- 无 `0x` 前缀的 16 位十六进制内核指针（高 16 位为 `ffff`）。
- `%pK` / `%px` 输出的同类原始指针文本。
- 小端字节转储，如 `78 56 34 12 80 88 ff ff`、逗号/冒号/`0x`/`\x` 分隔形式，以及连续形式 `785634128088ffff`。
- 缓冲区边界处的地址会被拼接识别；匹配不跨换行。

普通哈希（16 位以外的十六进制串、常见 32/40/64 字符摘要）和用户空间地址（如 `0x00007ffff7a0d000`、`00007ffff7a0d000`）保持不变。
