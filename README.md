# 选课规划器（Course Planner）

TypeScript 实现的毕业选课规划器：处理**先修**、**同修**、**开课学期**、**学分负载**，
部分先修支持**课程组替代**（组内任选其一）。求解目标：

1. **最早毕业**（学期数最少）；
2. 其次**额外学分最少**（总修读学分 − 毕业要求学分，最小化）；
3. 总课程门数不超过 **22 门**（可配置）。

输出每学期课程安排、所满足的课程组替代路径，并识别**无法通过同修解决的先修环**。

## 运行

需要 Node.js ≥ 23.6（原生运行 TypeScript，无需编译）：

```bash
node src/index.ts        # 运行示例
node --test "test/*.test.ts"   # 运行测试
```

或使用 npm scripts：`npm start` / `npm test`。

## 数据模型（`src/types.ts`）

- `Course.offered`：开课学期（`fall` / `spring`）。
- `Course.prereqs`：先修，必须**严格更早**学期完成；`{ anyOf: [...] }` 表示课程组替代。
- `Course.coreqs`：同修，**同学期或更早**修读即可。
- `PlannerInput`：必修课、毕业学分要求、每学期学分上限、门数上限（默认 22）、
  入学学期、最大学期数、选修池。

## 算法（`src/planner.ts`）

1. **需求展开**：必修课 + 单课先修 + 同修递归闭包；课程组先修对每个选项分支，
   得到若干候选课程集合（每个集合附带替代路径记录），超过门数上限即剪枝。
2. **学期分配**：对学期数 T 从 1 递增做回溯搜索——按先修链深度排序分配课程，
   校验开课学期、严格先修（更早学期）、同修（同学期或更早）、每学期学分上限。
   第一个可行的 T 即最早毕业时间。
3. **选修凑学分**：必修学分不足毕业要求时，按（总学分, 门数）升序枚举选修子集，
   装入剩余学期容量，最小化额外学分。
4. 在同一 T 下比较所有候选展开，取总学分最少者。

## 先修环检测（`src/cycles.ts`）

同修边允许同学期修读（非严格），先修边要求严格更早学期。依赖环中只要含有
至少一条先修边，沿环即推出 `sem(c) < sem(c)` 的矛盾——用 Tarjan SCC 找出
含严格边的强连通分量即为**无法通过同修解决的先修环**。报告会标注环是否涉及
课程组替代边（`involvesSubstitution`）：若是，更换替代选项可能消除该环，
规划器会自动尝试其他选项（见测试「课程组替代：换选项避开先修环」）。

## 示例输出

```
最早毕业：8 个学期
总学分 56（毕业要求 56，额外学分 0），共 16 门课
第 1 学期（秋）— 11 学分 ...
满足的课程组替代路径：
  CS320 的先修 [CS301 / CS302] → 选择 CS301（数据库系统）
```
