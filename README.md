# tri-policy

缺失属性为 `unknown` 的三值（Kleene）策略语言，TypeScript 实现，零依赖，
Node.js 内置测试运行器验证（Node 23 直接擦除类型运行 `.ts`）。

## 能力

- **三值逻辑**：`true / false / unknown`，缺失属性一律 `unknown`，绝不按 `false` 化简
  （编译器刻意不做补律/排中律折叠，`x OR NOT x` 在 x 缺失时保持 `unknown`）。
- **受限策略语法**（`src/expr.ts`）：布尔字面量、有限整数集合 `inSet`、整数区间
  `inRange`、`and/or/not`。只读策略中显式声明的属性，不接外部身份服务。
- **共享决策 DAG**（`src/dag.ts`）：哈希cons（hash-consing）结构共享，只做 Kleene
  安全的常量折叠；and/or 子节点保持书写顺序，保留短路语义与读取依赖。
- **异步属性获取与版本一致性**（`src/store.ts` / `src/engine.ts`）：每个
  (subject, attr) 独立版本号；求值记录读取依赖，结束时校验版本，请求中途
  属性变化则重试（有界），持续冲突返回 `conflict`，绝不混版本放行。
- **精确缓存失效**：缓存按主体隔离，条目记录所读属性版本与规则版本；
  属性热更新只失效读过它的条目，规则热更新（`setPolicy`）失效全部。
  取消与取值失败不写入缓存。
- **部分求值**（`engine.partial`）：已知属性折叠为常量（缺失 => `unknown` 常量），
  生成针对剩余未知属性的残差条件 DAG。
- **最小解释切片**：从实际读取的属性中逐个试删（置 `unknown`），结论不变则移除，
  返回支撑结论的最小属性集合。
