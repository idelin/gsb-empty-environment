特权服务采用声明式环境文件时，某个值即使字符都来自可信常量，是否出现该值也可能取决于未受信租户。实现供 Go 启动宿主调用的环境构造和发布检查包。表达式含字面串、变量引用、有界循环、条件分支和子串；值以共享拼接图保存，最终长度可达 2^44。每个输入带身份、信任域和由有限自动机约束的允许字符语言，条件只能比较输入是否属于给定正则语言。敏感导出必须同时满足内容来源可信、控制来源可信，且输出按 POSIX 路径段解释时落在批准前缀下。允许宿主声明受信净化函数的准确输入输出关系；仅删除危险字符不能自动洗掉控制依赖。实现按偏移查询字符与来源，以及不展开整串的批准前缀证明；无法通过检查时给最早未获准的输出区间并区分内容、控制与路径约束。用短输入逐字符解释作对照，覆盖两条分支输出相同而可消去控制依赖、分支只改变输出长度、切片跨共享节点、同名变量跨租户及字符串边界组成新的路径段。
