# 溢出检查谓词保持（netsec）

加固编译器把有符号整数运算改成更宽运算后，原有的溢出检查可能不再等价。
本包对“旧版 SSA 图”和“加固后新版 SSA 图”做可导入的重写核验。

## 核验目标

两版图最多读取 12 个输入字节，支持 8/16/32 位有符号加、减、乘，截断、
符号/零扩展以及条件分支。对任意相同输入必须满足：

- 旧版显式溢出并在源节点 `N` 报错时，新版必须在同一源节点 `N` 报错；
- 旧版正常返回时，新版必须返回相等的整数（宽度与值都相等）。

## 组成

- `ir.go`：SSA IR（`Graph`/`Block`/`Value`）与结构、支配关系、类型校验。
- `builder.go`：顺序 ID 的图构建器，便于宿主下沉 IR 与测试造图。
- `interpreter.go`：独立具体解释器，直接做定宽字运算并单独推导有符号
  溢出标志，作为可信基准，不与符号引擎共享实现。
- `boolexpr.go`：哈希等价（hash-cons）的布尔表达式 DAG 工厂。
- `symbol.go`：位级爆破，含行波进位加减、无符号乘积加符号修正的有符号
  乘法，以及加/减/乘溢出谓词。
- `paths.go`：带路径条件的符号执行，枚举无环 CFG 的受卫终止结果，路径
  数超上限即截断。
- `sat.go`：Tseitin CNF + 监视文字 DPLL；小输入域走完全枚举回退，预算
  跨所有查询共享，耗尽返回未知。
- `verify.go`：核验主入口 `Verify`，输出等价/不一致/未知及可复现见证。
- `exhaustive.go`：8 位小图全枚举，用解释器交叉核验符号搜索结论。

## 预算与未知

`Config.Budget` 同时约束 CNF 发射、传播与决策工作量。任何阶段耗尽预算或
路径枚举被截断，`Verify` 都返回 `StatusUnknown`，绝不在未完成证明时给出
确定性结论。`Budget` 为 0 时使用 `DefaultBudget`。

## 8 位全枚举校验

测试对 8 位加/减/乘在全部 65536 组双字节输入上，逐组比较符号引擎的溢出
判定与独立解释器结果，并对等价重写、错误节点漂移、丢弃检查、截断扩展、
比较分支及随机小图做 `EnumerateAll` 与 `Verify` 的双向交叉核验。
