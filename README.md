# proofpack

从指定结论（根目标）反向裁剪完整依赖子图，导出可独立离线重放的证明包。
纯 Python 3.11 标准库实现，测试基于 `unittest`，样例数据全部为合成数据。

## 运行

```bash
python3.11 -m proofpack.sample          # 端到端样例（合成贷款审批场景）
python3.11 -m unittest discover -v      # 18 个单元测试
```

## 设计

- `proofpack/model.py` — `Fact` / `Rule` / `KnowledgeBase`。事实、规则均带稳定
  字符串 ID 与整数版本；事实标记 `public`（公开事实，泄露代价）与
  `evidence`（可否作为叶子证据）。
- `proofpack/search.py` — 有限 AND-OR 图上的精确搜索。目标按字典序：
  **先最少泄露公开事实，再最小包大小**（包大小 = 事实节点 + 规则 + 步骤数）。
  搜索在「待证目标集合」上做带记忆化的 DFS，共享子证明按集合并只计一次；
  每步扩展至少增加一项，因此最优解的探索路径不会重复状态，环剪枝是精确的。
  超出扩展预算时返回未决界限：可采纳下界 + 贪心有效上界。
- `proofpack/export.py` — 导出包：事实（区分 base/derived 角色）、规则、按拓扑
  序生成的证明步骤（`S001…`，含规则版本），以及校验摘要（各项计数 + 对规范化
  字节的 SHA-256）。序列化为规范 JSON（键排序、紧凑分隔符、UTF-8），相同输入
  必得相同字节。
- `proofpack/verify.py` — 独立离线验证器：仅从包内 base 事实与规则前向重推，
  要求声明的步骤与重推结果完全一致（不信任任何“已证明”标记）；检查内容哈希、
  计数、无悬空引用、所有根目标可推导、无无关证据。
  `minimality_failures` 逐项删除并重签后复验，任一必需项被删都必须失败。

## 性质（均有测试覆盖）

- 多替代证明下按 （泄露公开事实数， 包大小） 字典序取最优；
- 共享事实只推导、只计数一次；
- 预算耗尽返回 `BUDGET_EXCEEDED` 及上下界；
- 导出包满足所有根目标且无悬空引用；
- 删除任一事实/规则/步骤，验证失败；
- 篡改载荷或规则版本被哈希/重推检测；
- 相同输入导出稳定字节（与知识库构造顺序无关）。
