计量系统对同一组计数发布不同精度的模聚合值。例如在模 8 下公布 2x 的结果，未必能唯一确定 x，却会把它的可能值从8个缩到2个。对于两个相关秘密，还要区分各自的可能值数与联合取值数。给 Go 查询网关写可导入的发布准入包。每个未知量属于 Z/(2^k)，k 在 1 到 48 之间；每行聚合有自己的模数和有符号整数系数。跨代次映射也是带常数项的同余约束。每个串通组的策略指定一组受保护线性量及其各自模数，限制的是这些量联合可能取值数相对先验最多缩小多少倍，不能把单个量的缩小倍数相乘。候选发布可能是一批相关行，输入不一致与一致但泄漏过多要分别处理。返回无需枚举秘密值即可核对的精确基数证明，证明同时覆盖仿射可解性、混合模数下解核的大小以及受保护量联合投影像的大小；验证器须拒绝仅交换消元步骤就改变结果的证书。至多64个变量、128条约束，所有倍数使用任意精度整数。小模数用全赋值枚举检查，另测非单位系数、只暴露低位、两个量单独仍均匀但联合关系已确定、跨代映射不可逆和整批拒绝后历史应保持一致。不得输出个体取值。
