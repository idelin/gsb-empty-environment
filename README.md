多租户网关同时接收 JSON 文本和二进制定长整数字段，两个入口必须为同一授权对象生成相同的签名键。交付网关可导入的 TypeScript 增量解码包。宿主提供可含递归对象、数组、字段别名与版本转换的类型图；字段身份按声明编号，不能只按属性字符串。JSON 数字必须保存词法表示直到与字段类型比对，id64 可接受规范十进制字符串和精确安全整数，批量映射可把旧字段迁进新嵌套位置；二进制以网络序编码类型编号、字段编号、长度和值，未知非关键字段可跳过但其字节不进入授权身份。两个别名映射到同一字段，不论值是否相同都拒绝。签名键绑定租户、类型版本和按编号排序的最小编码，不允许在校验全部输入前产生授权回调。实现不物化整棵对象树的流式校验，能跨任意字节切块和中途恢复；检查点绑定 schema 摘要、解析深度与所有未闭合对象的已见字段集合。独立的小对象参考比较两入口和所有切点；测试 UTF-8 代理对边界、不同深度同编号、超出安全整数的相等误判、多段别名冲突、未知字段吞掉相邻值及恢复时类型图换版。
