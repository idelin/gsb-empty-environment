# updater

一个 Go 依赖更新器：给定旧锁文件、有限的候选版本和依赖约束，选出最优的版本组合。

## 目标（按字典序，优先级从高到低）

1. **安全禁用列表**：任何被选中的版本都不得在 `banned` 中，且所有依赖约束必须满足（可行性，硬约束）。
2. **最少改变已锁包数**：与锁文件版本不同的已锁包数量最少。新增依赖不计入改变数。
3. **最大化版本向量**：已锁包按包名排序组成的版本向量，字典序越大越好。
4. **总包数（次级目标）**：活动依赖闭包中的包总数（含新增依赖）越少越好，作为最终平局裁决。

## 求解与验证

- `Solve`（solve.go）：回溯搜索。只给从锁文件根**可达**的包分配版本（闭包外的包不施加任何约束），
  并按主目标剪枝（已改变数超过当前最优即停止）。
- `BruteForce`（bruteforce.go）：对全宇宙包做候选版本的笛卡尔积全枚举，逐一检查可行性并保留最优。
  作为参考验证器，保证求解器**不会为了保留旧版本而违反新依赖的约束**，也不会漏掉更优解。
- `TestRandomizedAgainstBruteForce`（solve_test.go）：随机生成数百个问题实例（随机禁用列表、
  随机依赖边、锁定版本可能不在候选中），逐一对拍两个求解器的目标值。

## 使用

```sh
go test ./...                          # 运行全部测试（含随机对拍）
go run ./cmd/updater -verify examples/problem.json
```

输入 JSON 模式见 `cmd/updater/main.go` 的文档注释或 `examples/problem.json`。
