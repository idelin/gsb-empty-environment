执行器要从按变量序排列的多列 trie 索引求多关系自然连接，各关系只涵盖变量子集，重复元组有 uint64 重数。给算子库实现可导入的 Go 包，返回按全局变量序的加权结果游标，支持 seek 到任意前缀、跳过精确的 N 个连接输出（重复按重数相乘）、以及从断点恢复。索引边可能是连续整数区间，整个区间共享同一子树；不能按区间长度展开，不可把全部连接结果先计入内存。跳过一段要给出可复核的区间交集及乘积计数，任意精度，不得把单一输入索引的子树基数当成连接结果基数。索引共享子图无环、最多六变量，给全局变量顺序不一致、溢出端点或负重数要拒绝。用小表全物化作独立对照，验证环形三表连接、同一变量出现在不同列序、空前缀与大于 2^64 的单条结果重数。
