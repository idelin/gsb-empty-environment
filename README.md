批处理引擎要在包含分支与汇合的查询版本图上复用中间结果，某个物化分片失效时仍要在预算内重算。给调度器写可导入的 Go 包，节点是 bag 关系的单键投影、选择、等值连接或 union all；输入给按键游程的基数摘要，允许键间关联由共享的有限场景参数决定。边传输成本按实际匹配基数计，同一物化只在相同投影与输入版本下可复用；仅相同基数不足以当作相同结果。选择总持久空间最小的分片物化点，使每个允许的底表场景、每个指定请求集和一次任意分片丢失后都可按时完成，重算时内存槽有限。给按场景与故障分支的计划、逐步峰值空间及核对器，输出必须避免展开 2^50 重复行。小图用实际多重集求值对照成本与结果，再穷举候选物化集验证最小性。
