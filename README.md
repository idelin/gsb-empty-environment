# rxcheck — 多版本医疗处方配伍禁忌检查器

基于**双时态**模型的处方配伍禁忌判定器，仅使用 Go 标准库。

## 双时态模型

- **业务时间**（valid time）：处方实际开立的时间（`Prescription.BusinessTime`）。
- **知悉时间**（transaction time）：配伍禁忌规则随临床指南版本更新、被规则库收录知悉的时间（`Rule.KnownFrom`）。规则库只追加、不修改，天然支持多版本。

## 两类判定

- `CheckCompliance` — **开方合规性判定**：以处方开立时刻规则库"当时知悉"的规则版本评估，判定历史处方在开立时是否合规。
- `AuditRisk` — **追溯风险审计**：以查询时刻"当前最新"的规则版本重新评估历史处方；若某药品组合的禁忌级别较开立时上升（如 无禁忌 → 慎用），则标记**追溯风险**。

## 验收边界

处方 P 在业务时间 10 开立（含甲药、乙药）；知悉 10 时规则库对甲乙无禁忌；知悉 20 时指南 v2 将甲乙列为慎用；知悉 25 查询：

- 开方合规性 = **合格**（按开立时的规则版本）；
- 风险审计 = **标记追溯风险**（按最新规则版本）。

对应测试：`TestAcceptance_*`（checker_test.go）。

## 运行

```sh
go test ./... -v   # 运行测试
go run ./cmd/demo  # 运行样例
```

样例输出：

```
处方 P 开方合规性判定（按知悉时间 10 的规则版本）：合格
处方 P 追溯风险审计（按知悉时间 25 的最新规则版本）：
  追溯风险提示：乙药 + 甲药：慎用（依据指南 指南v2）
```
