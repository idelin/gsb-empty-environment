# 重定向地址拼接让响应头被拆开

登录跳转把用户提供的`next`直接拼进Location，攻击者注入CRLF即可在响应里插入额外头甚至第二段响应，污染共享代理缓存。请实现嵌入TypeScript登录服务的可导入重定向构造组件。目标必须是本站相对路径或白名单绝对地址，解析后按RFC 3986规范化并拒绝控制字符、裸百分号编码、反斜杠和多重编码；构造时只使用单一权威API生成Location，其余头在发送前按名称与值语法校验。同一请求不得出现重复Location，响应体与状态码一致。用`%0d%0a`注入、双编码、Unicode换行、协议相对地址、白名单外主机和合法站内跳转验证响应结构不被改写。
