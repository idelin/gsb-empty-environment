为 IP 地址签发证书的 CA 要把验证工作交给不同机房，但同一网络运营方有多个探针身份。写供 Go 签发宿主调用的证据汇聚包。订单绑定经严格规范化的公网 IP（拒绝全部 IPv4 与 IPv6 保留、文档、基准测试、链路本地、多播及环回网段）、端口、挑战类型、账户、nonce 和公钥摘要；每份签名见证还带探针所属管理域、路由起源、观察时间区间、请求实际连接地址与返回的证明摘要。订单要求至少 k 个互异管理域，且同一路由起源最多贡献一票。见证可有多个合法身份归属，身份清单本身带版本；每份回执只能选择一个经认证的归属，所有选择须同时成立。只有选中的见证存在公共的观察瞬间，且该瞬间在授权窗口内，才能签发。按见证数量、总代价、最后按编号字典序选择有效证据；另给独立验收函数，不相信汇聚器自报的域数、保留地址检查和时间交集。撤销探针或路由证明时按签发时点重验，签发以后才发生的撤销不能追溯污染历史。支持重复回执去重、等编号异摘要的分叉隔离和缺失身份补证。用小集合穷举核对贪心选域导致路由冲突、IPv4文档段拒绝、时间窗口两两相交却无公共点以及多段时间并集。

## 实现概览

包名为 `evidence`，主要入口：

- `Aggregate(Request)`：校验订单与回执，解析版本化身份清单，选择证据并返回 `Bundle`。
- `Accept(Request, Bundle)` / `Audit(Request, Bundle)`：独立验收。重新计算公网地址策略、管理域数量、路由起源去重和全局观察时间交集，不读取汇聚器自报的 `Claimed*` 字段。
- `ParsePublicIP`、`NormalizePublicAddr`：严格的公网单播地址校验。
- `TimeSpan`、`Interval`、`IntersectAll`：半开区间 `[start, end)` 的并集与全局交集。
- `IdentitySupplement`：为缺失或不完整的身份清单补充归属；`SelectAttributionID` 可固定一份回执在多个合法归属中的选择。

选择目标默认是 `SelectFewest`：先最少见证数，再最低总代价，最后按回执编号字典序。需要更强证据时可在 `Request.Selection` 中设为 `SelectMost`。两种模式都要求同一路由起源最多选择一条回执，并要求所有选中回执（含所选归属的有效期）存在公共观察瞬间。

`Bundle.IssuedAt` 是签发时点。`Accept` 以该时点重验撤销记录：`RevokedAt` 晚于签发时点的撤销会被忽略，因此不会追溯污染历史。
