# 代理状态属性被剥离后策略被伪造

漫游RADIUS代理转发请求时丢弃`Proxy-State`，归属服务器把客户端自带的运营商属性当可信来源，攻击者可伪造漫游身份或计费组。请实现供C++20 RADIUS代理调用的可导入属性转发组件。每次转发追加不可预测的Proxy-State并保留原始次序，响应必须带回完全相同的链才被接受；用户可写属性与代理生成属性分区，类属性按类型长度严格解析，重复单值属性拒绝。来源按NAS-Identifier、共享密钥代次和漫游对端身份核对，计费与授权使用同一归属判定。用剥离Proxy-State、追加伪造运营商属性、重复属性、链不匹配、共享密钥轮换和合法两跳漫游验证策略只取自可信链。
