# sourcemap

源码映射组合库：接收编译链中的多层区间映射，支持复合与查询。

## 模型

- 每层 `Layer` 是一组有序、不重叠的 `Segment`，把**半开**输出区间
  `[Start, End)` 映射到零个、一个或多个输入区间 `SourceRef`。
- `Copied` 段：与唯一来源区间等长的 1:1 复制，位置可精确换算。
- `Synthesized` 段：生成内容，可携带任意数量来源区间（0 = 完全无来源），
  无位置对应关系。
- 零宽段（`Start == End`）表示插入点；边界与插入点处的查询由
  `BiasLeft` / `BiasRight` 偏好参数裁决，`InsertionsAt` 可取插入点本身。

## 复合

`Compose(out, in)` 把 `out`（最终输出 → 中间表示）与 `in`（中间表示 →
其输入）复合；`ComposeChain` 折叠整条编译链。复制段会在下一层的每个段
边界处切分以保持精度：落在复制段上的碎片仍为 `Copied`，落在合成段或
空洞上的碎片降级为 `Synthesized`，源区间内部的插入点会在对应输出位置
重新生成零宽段。相邻复制碎片只有在来源**真正连续**时才合并——多来源
合成片段永远不会被伪造成连续的原区间。

## 查询

- `Lookup(p, bias)` / `MapPosition(p, bias)`：位置 → 段 / 来源位置。
- `CharSources(length)`：逐字符来源集合，用于核对复合结果
  （交错映射、空区间边界）。
