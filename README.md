# factor — 有理联合概率表的最细独立分解库

给定至多 6 个离散变量（每域 ≤ 4）的完整有理联合概率表，求变量的**最细互相独立分区**：
原表必须精确等于各块边际分布的乘积。全部计算使用 `math/big.Rat` 精确有理数，
只做加法与乘法，**从不做条件除法**，因此零概率格被当作普通等式 `0 = 边际乘积` 直接验证，
不会被跳过，也不会出现除零。

## 用法

```go
tb, _ := factor.NewTableFromStrings([]int{2, 2, 2},
    []string{"1/4", "1/4", "0", "0", "0", "0", "1/4", "1/4"})
p, cert, _ := factor.Decompose(tb)
// p = {0,1}|{2}，cert 为每次拆分的精确等式证书
fmt.Print(cert)                  // 打印全部等式
err := factor.VerifyCertificate(tb, cert) // 独立复核
```

## 设计要点

- **最细性**：联合分布的合法乘积分解在"交细化"（meet）下封闭——即使存在零概率格也成立
  （若 `P = f(x_A)g(x_B) = h(x_C)k(x_D)`，则 P 进一步按 `{A∩C, A∩D, B∩C, B∩D}` 分解，
  全零切片单独处理）。因此最细合法分区唯一，等于全部合法二分 `{S | V\S}` 的 meet，
  这就是 `FinestPartition` 的算法。
- **独立验证**：`VerifyFinest` 不复用上述论证，而是枚举**全部**集合划分
  （6 变量时 Bell(6) = 203 个），逐一做乘积检验，确认不存在更细的合法分区。
- **成对独立 ≠ 共同独立**：只对完整联合表做乘积检验。XOR 分布
  （X、Y 均匀比特，Z = X⊕Y）两两边际独立，但最细分区仍是单块 `{0,1,2}`，
  见 `TestPairwiseIndependentNotMutual`。
- **规范形**：分区按块编号序规范化——块内变量升序、块按最小变量升序，
  使结果可比较、输出唯一。
- **证书**：`Certificate` 含各块边际表、全表每格的精确等式
  `P(x) = P_{B1}(x_{B1})·…·P_{Bk}(x_{Bk})`，以及逐级拆分的等式
  `P(剩余_i) = P(块_i)·P(剩余_{i+1})`。`VerifyCertificate` 从原表重算一切并逐格复核，
  篡改任何一项都会被拒绝。

## 文件

- `table.go` — 精确有理联合表、边际化（纯加法）
- `partition.go` — 规范形集合划分、全划分枚举（限制增长串）、meet/细化
- `decompose.go` — 乘积形判定、最细分区、全枚举最细性验证
- `certificate.go` — 等式证书生成与独立校验
- `factor_test.go` — 零概率格、XOR 反例、六变量混合块、篡改检测等测试

运行测试：`go test ./...`
