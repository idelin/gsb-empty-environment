# bilinear2d — 纯标准库二维双线性采样与坐标变换

Python 3.11，仅标准库，不依赖自动微分或张量库。数据用嵌套 list
（`data[y][x]`）表示，坐标为归一化 `[-1, 1]` 的 `(u, v)`。

## 功能

- 双线性采样前向 + 手写反向（对数据、坐标、仿射参数求梯度）。
- 对齐约定：`align="corners"`（角点对齐，`p=(u+1)(N-1)/2`）与
  `align="centers"`（中心对齐，`p=((u+1)N-1)/2`）。
- 边界规则：`clamp` / `reflect`（镜像反射，周期 `2(N-1)`）/
  `zeros`（零填充 + 有效 mask，闭区间 `[0, N-1]` 内 mask=1）。
- 仿射变换 `affine_apply / affine_backward / affine_compose`，支持链式
  组合，奇异变换行为明确（前向仍定义，输入梯度塌缩到行空间，参数梯度
  正常累加）。
- 分块执行 `sample_grid_tiled`：tile 只是执行划分，所有边界判定使用
  整幅图像尺寸，各 tile 的 `grad_data` 累加进同一份梯度。
- `checkpoint=True`：前向只存输入，反向时重算中间量，结果与缓存模式
  逐位一致。
- 所有梯度贡献用 `+=` 累加：同一位置重复采样（视图共享）梯度相加。

## 显式次梯度策略（不可微点）

采样关于坐标分段双线性，折点位于整数像素节点与边界转折点：

- 整数节点 `q==k`（`0<=k<N-1`）：取右侧单元 `[k,k+1]` 的导数（右导数）。
- 末节点 `q==N-1`：取末单元 `[N-2,N-1]` 的导数（左导数）。
- clamp：`0<=p<=N-1`（含端点，内侧）导数为 1，严格外部为 0。
- reflect：`t = p mod 2(N-1)`，`t<=N-1` 时 `dq/dp=+1`，否则 `-1`；
  转折点取 `+1` 分支。
- zeros：mask 视为局部常数，`dmask/dp=0`（包括跳变点）。
- 零长轴 `N==1`：单 tap 权重 1，坐标导数为 0。

## 运行测试

```sh
python3.11 -m unittest discover -s tests -v
```

测试包含：同位置多次采样梯度累加、反射区方向梯度、夹紧区外梯度、
两段变换链式 vs 直接组合、零长轴/奇异变换/全 mask、避开不可微点的
中心有限差分独立验证、不可微点约定检查、分块与整体一致性、
checkpoint 重算一致性。最近一次实际运行结果见 `test_results.txt`。
