# AllDifferent — Régin 过滤算法（Go 标准库）

基于二分图最大匹配与强连通分量的全局互斥约束传播器。

## 算法流程

1. **建图**：变量在左、值在右，变量值域中的每个值对应一条边。
2. **最大匹配**：Hopcroft–Karp。若匹配大小 < 变量数（Hall 条件被破坏），
   在搜索开启前瞬时判定无解。
3. **残余图**：未匹配边定向为 变量→值，匹配边定向为 值→变量。
4. **过滤**：边 (x,v) 属于某个最大匹配，当且仅当
   - 它在当前匹配中，或
   - v 可从某个自由值节点沿交替路径到达，或
   - x 与 v 属于同一个强连通分量（Tarjan）。
   
   其余边全部从值域中剔除，达到广义弧一致（GAC）。

## 运行

```sh
go run .        # 运行样例（含验收边界：4 变量共享 {1,2,3} 瞬时判无解）
go test -v ./... # 运行测试
```

## 文件

- `alldiff.go` — 约束、Hopcroft–Karp 匹配、Tarjan SCC、Régin 过滤
- `main.go` — 运行样例
- `alldiff_test.go` — 测试（含暴力枚举对照校验）
