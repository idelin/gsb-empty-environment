# Whois转介跟随的主机与协议限定

Whois 客户端会跟随应答里的 ReferralServer 或 Whois Server 行去查注册商，攻击者控制的注册信息里可以写出这样的行，把查询发往内网端口，或让查询串里的换行变成别的协议命令。给TypeScript域名查询库写供查询流程调用的转介包：只在应答首部块（第一个空行之前）里识别转介行，正文里同名行忽略；转介目标必须是主机名，不含 IP 字面量、userinfo、路径，端口只能是 43；解析出的地址须全为全局单播，连接时使用已校验的地址；最多跟随三次且不得回到已访问主机；查询串不得含 CR、LF、NUL，不得以 - 开头，长度不超过 255 字节。用注册人备注里的伪造转介、127.0.0.1、端口 6379、查询串里的换行、环路验证。
