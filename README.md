# Luau共享标准库写隔离

Luau 宿主让多个不可信脚本线程共用同一套标准库，攻击者改写 string.format 之类的库函数、给共享字符串元表加字段，或借 getfenv 取回基础环境，就能影响其他脚本与宿主。为 Go 宿主写供沙箱构造步骤调用的写隔离模拟包：输入标准库表与共享元表的只读标记、各线程全局表对基础环境的代理关系，以及脚本操作序列（赋值、rawset、setmetatable、getfenv、setfenv、table.freeze）；经代理表的写入落在线程私有表，穿透写共享表时返回错误；只读表经 rawset 或 setmetatable 也不可改；getfenv 对内置函数不返回基础环境；最后输出哪些共享表被改动。用改写库函数、rawset 绕过、字符串元表追加、线程私有赋值和冻结后写入验证。
