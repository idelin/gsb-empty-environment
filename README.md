# NSEC合成否定答案越过租户视图

企业递归解析器为不同租户维护分裂视图，攻击者若能把一个视图里的DNSSEC否定证明用于另一个视图，就能隐藏仅在内网存在的名称。请为解析服务实现可导入的Go激进否定缓存包。缓存键必须绑定租户视图、验证过的zone apex、DNS class、NSEC或NSEC3参数集、验证密钥代次和原始查询名的规范DNS wire形式；只有完整通过签名链、有效期、opt-out语义与closest-encloser/wildcard证明的记录才能合成NXDOMAIN或NODATA。NSEC3按RFC 5155处理迭代次数、salt和base32hex，空非终端、通配符、委派点及opt-out覆盖必须分别判断；证明过期、密钥撤销、视图策略变化或时钟回拨会使相关条目失效。调用方提供可控时钟和每视图上游响应，返回合成结论及所用RRset见证。测试覆盖同名跨视图、NSEC3 opt-out下未签名委派、通配符存在、空非终端、密钥轮换和合法缓存命中，证明攻击者不能借另一视图的区间制造否定答案。
