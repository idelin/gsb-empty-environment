分布式密钥库在素数幂模环 `Z/(p^e Z)`（`e >= 1`）上修复缺失分片时，非单位倍数乘子可能只泄漏模 `p` 的局部剩余而逃过域秩检查。为 TypeScript 密钥库宿主实现可导入的模环修复准入组件：输入为有限素数幂环上的原分片生成矩阵、独立随机掩码及带签名的多轮自适应修复步骤。每条步骤绑定发送域、接收域、局部输入索引、线性组合系数及所属代次；系统需通过带签名线性承诺检测并拒绝作弊辅助节点在不同接收者间发送矛盾组合（模环模棱两可）。组件一方面证明目标域在最后一轮能唯一重构原缺失分片（处理不可逆零因子时须求模核与 Smith 标准型基数而非普通域秩），另一方面核对每个给定串通域集合所获全部修复消息与原有分片联合起来，对任一受保护线性量在 `Z/(p^e Z)` 下的条件分布基数均未相对修复前收缩，严禁跨代掩码重放或零和掩码对消。以小素数幂环（如 `Z/4Z`、`Z/9Z`、`Z/8Z`）全秘密与掩码赋值穷举核对部分模位泄漏与作弊辅助拦截。
