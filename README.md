# rlebits — 游程压缩的可变位序列

纯 Go 标准库实现。位序列以「段（run）」存储：一段是连续同值的 bit。
只保存首段值 + 各段长度，段值按奇偶交替推出，并维护长度前缀索引
支持 O(log r) 的 rank/select（r 为段数）。

## 编码布局

内存：

| 字段    | 类型       | 说明                                   |
|---------|-----------|----------------------------------------|
| `start` | `byte`    | 首段 bit 值（0/1）                      |
| `runs`  | `[]uint64`| 各段长度；相邻段必异值，无零长段         |
| `pos`   | `[]uint64`| 长度索引：位位置前缀和，`pos[i]=Σruns[:i]` |
| `ones`  | `[]uint64`| 长度索引：1 的个数前缀和（rank/select 用）|

磁盘（`Encode` 输出）：

| 偏移 | 字段      | 大小                |
|------|-----------|---------------------|
| 0    | magic     | 4B `"RLB1"`         |
| 4    | flags     | 1B，bit0 = 首段值    |
| 5    | numRuns   | uvarint             |
| …    | totalLen  | uvarint（校验用）     |
| …    | runs      | uvarint × numRuns   |

## 操作

- `Flip(l, r)`：区间翻转。在 l、r 处切分段后，区间内各段取反仍交替；
  天然边界处与外侧同值需合并，切分点处取反后自然错开不合并。翻转两次还原。
- `Insert(p, v, n)`：段边界处插入直接延长相邻同值段，不产生重复位置；
  段内插入异值时一分为三。
- `Delete(l, r)`：跨段删除后按「删除段数 + 两端是否切分」的奇偶性
  合并交界同值段，不留零长段；头部删除奇数段时翻转首段值。
- `Rank1/Rank0(p)`、`Select1/Select0(k)`：基于 pos/ones 前缀和二分。

每次修改后重建长度索引（O(r)），查询为二分（O(log r)）。
