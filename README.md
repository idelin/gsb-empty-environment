WebDAV网关处理COPY和MOVE时，攻击者请求Depth: infinity，把有读权限的目录连同其中无权读的子项复制到自己的集合，或利用符号链接与并发覆盖指向他人租户。给Go写供WebDAV处理器调用的授权与执行包：Destination必须是同主机同租户的规范路径且拒绝经由中间符号链接跳出租户根，对大小写及Unicode NFC/NFD等价路径保持权限判定一致；父目录或目标受Lock-Token保护及Overwrite: F的检查须与复制动作原子绑定以防TOCTOU。每个被复制成员单独检查读权限，目标集合检查写权限，MOVE额外检查源删除权限；无权成员在207里逐项返回403，部分失败按配置整体回滚到操作前快照或保留已复制项。用百分号编码点点路径、中间链接逃逸、锁竞争、Overwrite: F和无权子项验证。
