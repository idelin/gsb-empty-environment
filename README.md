归档系统要决定一个租户的历史密钥是否已经无法恢复。给 TypeScript 密钥管理宿主写可导入的销毁证书检查包。宿主给出不可变密钥谱系：原始密钥可有封装备份，只有同时持有备份和包装密钥才能解封；阈值分片须来自同一分片轮次且索引不同，同一存储对象的别名只计一次。快照里允许多层包装、共享子密钥和循环引用，无已知输入的循环不能自行恢复。撤销凭据只影响未来读取，已导出的副本仍可用。输入至多 16 个可销毁存储对象、64 个派生节点和若干必须继续可恢复的其他租户密钥；返回能使目标不可恢复且保全这些密钥的最小删除集合，并列按对象 ID 取字典序最小。另写独立证书校验函数：在删除后重算最小不动点，逐一还原被删对象并给出目标恢复见证；无解需指出保全约束或本已导出的副本，并区分目标本来就无法恢复。用小图穷举对照，覆盖跨轮分片误拼、别名重复、无根环和切断共享包装密钥时误伤另一租户。
