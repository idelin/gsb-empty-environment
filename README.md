分段路由（SR-MPLS）在链路或共享风险链路组（SRLG）发生故障时，通过 TI-LFA 在 50 毫秒内把流量切到事后最优路径而不产生瞬时微环，前提是准确算出保护点与目的地的扩展 P 空间和 Q 空间并合成最短标签栈。为路由控制面交付可导入的 Go TI-LFA 计算包。输入无向正权网络图（含节点 SID、每条有向链路邻接 SID 与 SRLG 集合）、待保护链路 (u,v)（或含同 SRLG 全部链路）及目的节点 d。规则：基于最短路不等式（严格考虑 ECMP 多等价路径：只有节点所有最短路径均不经过受保护故障集合才算在 u 的 P 空间内；扩展 P 空间允许 u 的直接健康邻居经非故障链路到达且不回流故障；Q 空间为任意到 d 的最短路均不经过故障集合的节点集合）。求将流量从 u 安全引导至 d 且沿着故障后拓扑最短路径（post-convergence path）不形成微环的最短显式 SID 标签栈：若扩展 P 空间与 Q 空间交集非空，选跳数最小（并列节点编号最小）的单 Node-SID；否则寻找从扩展 P 空间节点到 Q 空间节点的健康直连链路，构造 `[Node-SID(p), Adj-SID(p->q)]`；若仍需多跳修复，按最小标签栈深度迭代求解并输出无解原因（如故障导致图割断）。验收用故障前后全最短路仿真验证标签栈逐跳转发绝不触发环路、绝不经过任何受保护链路且标签栈深度最小，覆盖存在 ECMP 导致普通节点落出 P 空间、单 Node-SID 命中 P∩Q、须用 `Node+Adj` 双标签跨过 P/Q 间隙，以及 SRLG 同时失效两条链路改变修复路径。
