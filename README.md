CardDAV 客户端拿着旧同步令牌分页查询，服务器迁移联系人 ID 并更改了成员可见字段。给 TypeScript 地址簿宿主写可导入的同步投影包。每张卡是多值属性集合，值有参数、稳定实例 ID、权限来源与版本；一次编辑可删改部分属性，两个名称相同的属性不等于同一实例。查询表达式支持存在性、文本匹配、AND/OR、否定及按值参数筛选，只在获准可见的投影上求值。服务必须输出客户端两次授权快照之间真正可见的增删改，单纯的隐藏属性变动不可影响返回序列、分页边界、游标是否出现或可观察的计数。权限收回须表现为可见内容删除；另一授权来源仍允许时要保留，且不披露授权来源数。不可重新扫描全库：宿主给按属性与权限变化的倒排索引、稳定 ID 合并映射和前缀完整性证明，缺证返回待同步。提供可验的增量回执，与完整快照投影参考逐页比对，覆盖同名多值、两个旧 ID 合并、一条隐藏编辑夹在两页之间、撤权与续权交错和客户端重复确认。
