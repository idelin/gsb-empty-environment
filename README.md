# 测试模拟器外部副作用封锁

安全测试插件声称只操作模拟目标，但错误适配器可能访问真实网络。实现供Go测试宿主调用的能力路由包，插件只能持有宿主生成的模拟端点句柄，所有读写、计时与解析都路由到确定性模拟器；句柄不可从地址字符串重新构造，跨试验代次一律失效。用恶意插件尝试转交句柄、延迟回调和猜测ID验证没有真实拨号回调发生。

## capnet 能力路由包

`capnet/` 是宿主与不可信插件之间的唯一网络边界：

- 宿主通过 `Host.NewTrial` 开启试验代次，用 `Trial.Mint(地址, 脚本)` 铸造不透明 `Handle`；真实地址只保存在宿主侧。
- 插件只持有 `*Router`，所有 `Dial/Read/Write`、行与长度前缀帧解析、截止时间、`Now/Sleep/AfterFunc` 都经 `Handle` 校验后路由到内存中的确定性模拟器。
- `Handle` 无导出字段、无导出构造器，`String/GoString` 一律脱敏；地址字符串无法重建句柄，令牌为 128 位随机值并用恒定时间比较。
- 代次 `End` 后所有句柄返回 `ErrStaleHandle`，连接关闭、挂起定时器取消；`capnet_malicious_test.go` 以外部包视角验证转交、延迟回调、ID 猜测等攻击均不产生真实拨号。

验证：`go test -race -count=1 ./...`
