# snapshot — 跨分区一致读切面求解器

给定各分区的有序版本序列（每个版本属于一个事务，事务可跨分区写多个版本）
和每个分区的水位，求**不晚于水位的最大事务一致切面**：切面内任意事务要么
全部版本可见，要么全部不可见（绝不暴露半个事务）。同时记录每一次回退的原因，
支持对任意被回退版本重建完整的原因链。

## 模型

- 分区 `p` 的版本为前缀序列 `Partitions[p][0..]`，切面是每分区一个前缀，
  用 `Frontier[p]`（包含的版本数）表示。
- 事务关联由版本上的事务 ID 隐式给出：同一事务 ID 出现在多个分区即表示
  该事务跨这些分区写入。关联可以形成环（如 A 在 p0 上先于 B，B 在 p1 上先于 A）。
- 切面一致 ⟺ 不存在"分裂事务"：某事务部分版本在切面内、部分在切面外。

## 算法（反复回退到不动点）

1. 初始 `Frontier = Watermark`。
2. 对每个事务维护两个计数：`inc`（有版本被包含的分区数）与
   `exc`（有版本被排除的分区数）。事务分裂 ⟺ `inc > 0 && exc > 0`。
3. 工作队列循环：取出分裂事务 `t`，取 `t` 的一个被排除版本作为**见证**，
   把 `t` 仍有包含版本的每个分区 `p` 回退到 `first[t][p]`（即排除 `t` 在
   `p` 的全部版本），记录一条 `RollbackEvent`；被新排除的版本所属事务若
   因此分裂则入队。
4. 队列空时无分裂事务，当前 `Frontier` 即答案。

每个版本被排除时记录排除它的事件 ID（或水位），于是任意版本的原因链可沿
"事件 → 见证版本 → 排除见证的事件 → …" 回溯到水位。

## 终止性证明（允许关联成环）

定义度量 `M = Σ_p Frontier[p]`，为非负整数。

- 每次回退事件把某分区前沿从 `f` 降到 `first[t][p] < f`，`M` 至少严格减 1。
- `M ≥ 0` 有下界，故事件序列有限，循环必然终止；事件数 ≤ Σ 水位 ≤ 总版本数 V。

更强的界：`inc` 单调不增、`exc` 单调不减，事务一旦 `inc = 0` 就永远不再分裂，
因此**每个事务至多被完整回退一次**，事件总数 ≤ Σ_t deg(t) = E（事务-分区关联数）。

关联成环只影响"哪些回退被触发"，不影响度量的严格下降——环上不存在无限递降的
自然数序列，故反复回退必终止。同理，原因链中见证版本先于事件被排除，链上事件 ID
严格递减，链必有限且终结于水位，即使事务依赖图有环。

## 正确性（结果是"不晚于水位的最大一致切面"）

- **一致性**：循环不变式保证任何分裂事务都会入队；队列空时不存在分裂事务。
- **不晚于水位**：`Frontier` 从 `Watermark` 出发单调不增。
- **最大性**：对任意一致切面 `C ≤ Watermark`，归纳证明 `C ≤ Frontier` 全程成立。
  初始 `Frontier = Watermark` 显然。设某事件因事务 `t` 分裂（见证版本 `(q,j)`
  已被排除）把分区 `p` 回退到 `first[t][p]`。若 `C_p > first[t][p]`，则 `C`
  包含 `t` 在 `p` 的版本；而 `C_q ≤ Frontier_q ≤ j` 说明 `C` 排除了见证版本，
  即 `C` 只含半个 `t`，与 `C` 一致矛盾。故 `C_p ≤ first[t][p]`，不变式保持。
  终止时 `Frontier` 本身一致且不劣于任何合法切面，即唯一最大一致切面。
  这也说明结果与队列处理顺序无关（汇合性）。

## 复杂度

设 `V` = 版本总数，`E` = Σ_t（事务 t 涉及的分区数）≤ V。

- 每个版本至多被排除一次（排除时 O(1) 更新计数），每个事务至多回退一次
  （扫描其分区表 O(deg(t))）：总时间 **O(V + E) = O(V)**，对输入规模线性
  （使用哈希表为期望线性）。
- 空间 **O(V + E)**。
- 单次原因链查询 O(链长)，链长 ≤ 事件数 + 1 ≤ E + 1。

## 使用

```go
s, err := snapshot.Solve(snapshot.Problem{
    Partitions: [][]string{{"A", "B"}, {"B", "A"}}, // p0, p1 的提交序
    Watermark:  []int{2, 1},                          // 每分区允许的前缀长度
})
s.Frontier          // 最大一致切面，例如 [0 0]
s.Events            // 全部回退事件（含见证与成因）
s.IsConsistent()    // 一致性校验
chain, ok := s.ReasonChain(snapshot.VersionID{Partition: 1, Index: 0})
fmt.Println(s.Explain(snapshot.VersionID{Partition: 1, Index: 0}))
```
