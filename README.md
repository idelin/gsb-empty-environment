容器镜像安全扫描网关在逐层合并 OCI 镜像 tar 层（OverlayFS 语义）时，若仅独立扫描单层或忽略不透明目录白出（`.wh..wh..opq`）与单文件白出（`.wh.<name>`）的覆盖顺序、符号链接穿透层边界以及扩展属性 `security.capability`（VFS_CAP_REVISION_2/3）与 `SUID`/`SGID` 权限位，攻击者可在底层植入带 `CAP_SYS_ADMIN` 或 `SUID root` 的二进制、在上层用畸形白出或硬链接遮蔽扫描器却在运行时恢复执行。为 Go 制品安全宿主实现可导入的 OCI 多层文件系统精确合成与特权残留验证包，严禁联网。组件按从底到顶的层序模拟精确 OverlayFS 合并规则：处理 `.wh..wh..opq` 清空下层同目录全部子项（但不影响同层后续新增条目）、`.wh.<name>` 删除下层对应路径（拒绝非法的 `.wh..` 或跨目录白出名）、同层与跨层硬链接目标追踪以及目录替换为非目录的冲突语义；完整解码每条目的 POSIX 模式位与二进制 `security.capability` xattr 载荷（校验版本魔数、有效位 `VFS_CAP_FLAGS_EFFECTIVE`、Permitted/Inheritable 64 位掩码及 v3 `rootid`）。策略验证入口核对合并后的最终根文件系统及任意中间层快照，检出全部未在白名单中的 `SUID`/`SGID`、危险文件能力（`CAP_SYS_ADMIN`/`CAP_SETUID`/`CAP_DAC_OVERRIDE`/`CAP_NET_RAW`）、通过白出覆盖隐藏的敏感凭据残留以及跨层符号链接指向受限目录的逃逸路径。附多层白出覆盖顺序、硬链接逃逸与二进制 xattr 能力解码测试集。
