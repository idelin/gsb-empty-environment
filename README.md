# settle

Go 结算库：按事件时间把有理数用量分配到费率的半开区间 `[Start, End)`，
跨段线性用量按重叠时长占比分摊，全程 `math/big.Rat` 精确运算，
最后对总金额做半偶（银行家）舍入到分。

## 模型

- `Rate`：半开区间 `[Start, End)` 上的单位价格；恰好落在 `End` 的事件属于下一段。
- `Event`：某一时刻的瞬时用量，归入覆盖该时刻的费率区间。
- `Linear`：`[Start, End)` 上均匀分布的总量，跨段部分按 `重叠时长 / 总时长` 分摊；
  零时长用量为零、不参与覆盖校验。
- `Settle`：返回每段的 `Segment{Qty, Amount}` 与精确总额 `Total`；
  用量未被费率区间完全覆盖时报错。
- `Cents`：仅对总金额半偶舍入到分（分段不提前舍入，避免丢分）。
- `DeltaCents(prev, curr)`：追溯费率变更只输出差额（新舍入总额 − 旧舍入总额），
  不重记总额；差额在修订链上可望远镜求和：
  `Σ Delta(Sᵢ₋₁, Sᵢ) == Delta(S₀, Sₙ)`。

## 测试

```sh
go test ./...
```

覆盖：区间端点归属、零时长与负时长线性用量、不均匀分摊的有理精确性、
半偶舍入边界（±0.005/0.015/0.025/0.035）、单次追溯差额、反复修订的望远镜一致性。
