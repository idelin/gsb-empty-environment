匿名凭据持有人可以从两个发行方领取不同面额的授权票据，再向多个服务兑换。给Go核销宿主交付可导入的交易验收包。签名由宿主验证，票据只显露发行方、活动代次、公开承诺值、整数面额及一次性核销标识；匿名兑换证明将一组输入承诺绑定到本次交易、输出权益和找零承诺，证明核验也由宿主注入。参与方可离线产生若干相互依赖的交易，输出找零又被后续交易消费，同一核销标识可出现在竞争分支。给定最终确认的交易前缀与各发行方剩余限额，在不泄露持有人身份的前提下，求可一起接受的交易子集，最大化完成的服务权益总数，再按交易ID序列决胜。逐活动守恒，不跨发行方挪限额；选中交易须包含未确认前驱，找零只能花一次，环不能自筹资金。至多22笔候选，输出签名验证和核销证明以外的独立可核对最优性证书。用小集合全枚举验证找零共享、同标识异票面、确认前缀冲突以及含零成本环的依赖图。
