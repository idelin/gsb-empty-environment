# Falco规则条件字段与事件类型绑定

Falco 规则条件按事件类型过滤，字段只在特定事件下有值，攻击者对规则声明的事件类型之外的系统调用动手，或利用对 15 字节截断的进程名做不完整比较，就能躲开检测。为 TypeScript 规则管理服务写供规则加载前调用的字段绑定检查包：输入条件语法树（字段名、运算符、字面量、与或非）、字段到可用事件类型的映射、规则声明的 evt.type 集合；某字段在声明事件类型下恒为空（如 fd.name 对 execve）时报告该事件类型下规则永不匹配；not 与 or 组合使条件在某事件类型下恒真时同样报告；proc.name 与超过 15 字节的字面量做 = 比较时报告；宏展开出现循环引用拒绝，展开深度不超过 20。用 fd.name 配 execve、or 恒真、长进程名比较和宏环验证。
