向量执行后端的片上地址译码器比较器很少。给后端提供可导入的 Go 表项编译包：逻辑页号最多 48 位，输入是有序不交的半开区间，每段的行为是未映射，或命中某个存储体、权限位和固定的物理页号差值，未列出部分一律未映射。生成最少条目的有序表；条目匹配逻辑页的任意二进制前缀，首个命中的动作生效（默认未映射）。动作可选输入中的任一行为或显式未映射，允许先放更具体的异常条目再放覆盖空洞的默认大前缀。硬件规定同一深度与动作组合至多 K 条（K 作为输入，可为零），不能把每个子树分别最省的解简单拼起来。等长表归一化为更深前缀在前、同深按前缀值递增，比较这个顺序下的（深度、前缀值、动作输入编号）元组序列取字典序最小者。给出执行器用指令页实际校验译码并生成物理访问或缺页；输入若有任何已映射页加差值越出物理位宽则整份拒绝。最多 32 个输入区间，动作种类至多六个，硬件总表容量上限 14；超容量需准确报告无解，不接受贪心放弃。禁止展开页空间；独立把前缀和区间端点坐标压缩，核对所有地址的译码等价。小位宽枚举合法表比较规定的两级最优条件；另覆盖跨越半域的大空洞、必须用显式未映射项、局部最优冲破共享深度额度而另一同长方案可行、端点恰为 2^48。
