# 分块图像金字塔（image-pyramid）

TypeScript 实现的分块图像金字塔：父块由四个子块区域经可分离滤波核降采样生成，
局部编辑只重算精确受影响的块，支持可中断的增量更新，且过期结果绝不覆盖新版本父块。

## 运行

```bash
npm test        # node --test（Node >= 23，直接运行 TypeScript）
```

无第三方依赖。

## 核心设计

- **分层与分块**：第 0 层为原图，第 L+1 层尺寸为 `ceil(W/2) x ceil(H/2)`，直到 1x1。
  每层划分为 `blockSize x blockSize` 的块，块是失效与重算的最小单位。
- **降采样**：父像素 `px` 采样子层区间 `[2px - r, 2px + r + 1]`（`r` 为核半径），
  可分离核（默认二项式 `[1,3,3,1]/8`）。采样按像素坐标寻址，天然跨块读取。
- **镜像延拓**：边缘采样使用 reflect101 镜像（`-1 -> 1`，`n -> n-2`），见 `mirror()`。
- **精确失效**：编辑矩形逐级向上传播。子层脏区间 `[x0, x1]` 影响父层像素区间
  `[ceil((x0-r-1)/2), floor((x1+r)/2)]`，再映射到父层块区间；只有这些块入队。
- **版本化更新**：每个块有 `version`（脏版本）与 `cleanVersion`（数据版本）。
  任务携带调度时的版本号：
  - 执行时：`block.version !== task.version`（已过期）或已干净则跳过；
  - 提交前：再次校验版本，若计算期间发生新编辑则丢弃结果——旧结果不得覆盖新版本父块。
- **更新顺序**：队列按层级从低到高消费；父块任务执行前要求其采样足迹覆盖的
  子块全部干净，否则推迟到队尾。这保证跨块采样永远读取已更新的子块数据。
- **可中断**：`update(budget)` 每轮最多重算 `budget` 个块（过期/推迟不计入预算），
  可随时插入新编辑，最终 `update()` 收敛到与全量重算一致的结果。

## API

```ts
import { Pyramid } from "./src/pyramid.ts";

const p = new Pyramid({
  width: 512, height: 512,
  blockSize: 16,                 // 可选，默认 16
  kernel: [1, 3, 3, 1],          // 可选，单轴权重，自动归一化
  initial: (x, y) => 0,          // 可选，第 0 层初始像素
});

p.edit({ x, y, width, height }, 1.0);        // 局部编辑（或传 (x,y,cur)=>v）
p.update(8);                                  // 增量更新：本轮最多重算 8 块
p.update();                                   // 跑完全部待处理任务
p.isClean;                                    // 是否全部收敛
p.pendingTasks;                               // 待处理任务数
p.peekTasks();                                // 任务快照（调度器/测试用）
p.runTask(task);                              // 单任务执行（带版本与子块就绪校验）
p.readPixel(level, x, y);                     // 读某层像素
p.toArray(level);                             // 导出某层完整像素
```

## 测试覆盖（`test/pyramid.test.ts`）

- 初始构建与独立参考实现逐层逐像素一致（奇数尺寸、多层、镜像边缘）；
- 局部编辑的失效范围精确到块，且每块只重算一次；图外编辑为空操作；
- 跨块编辑与父块跨块采样；
- 角部镜像延拓的手工推导校验；
- 连续两轮未完成更新：过期任务被跳过，最终收敛；
- 过期任务直接执行不得提交；提交前发生新编辑时旧结果被丢弃；
- 随机压力：多种子 × 多块大小 × 两种核半径，30 轮随机编辑 + 随机预算的部分更新后收敛。
