# LoRa入网随机数回滚重放旧会话

终端掉电后若回滚DevNonce，攻击者可重放旧JoinAccept让设备复用会话密钥。给Go网络服务器与终端测试宿主实现本题入网状态包：设备注册表固定DevEUI、JoinEUI和根密钥句柄；JoinRequest含二者及16位DevNonce，MIC回调覆盖规范字节。服务器对每设备持久记录已见DevNonce集合、最大JoinNonce（24位耗尽后永久拒绝，不回绕）和会话代次；MIC通过后才原子占用从未见过的DevNonce并分配严格递增24位JoinNonce，耗尽拒绝。JoinAccept绑定JoinNonce、NetID、DevNonce、设备标识和随机sessionID，先加密再由回调认证；终端持可信单调joinEpoch和普通可回滚存储，接受前核对DevNonce等于当前未决请求、JoinNonce大于已接受值、sessionID未见且认证通过，再原子提交会话密钥句柄和joinEpoch。响应丢失时同一JoinRequest可返回原JoinAccept，换MIC或设备拒绝；旧JoinAccept不能覆盖新会话。实现可回滚终端存储和恶意网络回放夹具，在每个持久化点故障，验证DevNonce回滚、跨设备转发、JoinNonce回绕、重复请求及服务器重启时任何成功会话的派生输入均未重复。
