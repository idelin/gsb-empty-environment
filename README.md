安全容器与二进制准入网关在审核不受信任的 ELF64 共享库与可执行文件时，若仅凭节表名检查加固标志，攻击者可构造畸形程序头偏移、未页对齐的 `PT_GNU_RELRO`、残留可写 `.got`/`.init_array`、恶意 `DT_RPATH` 劫持或冲突版本化符号（`DT_VERSYM`/`DT_VERNEED`）在装载期篡改控制流。为 C++17 二进制安全审查宿主实现直接解析原始字节缓冲的 ELF64 动态装载安全验证库（零外部库依赖，`-Wall -Wextra -Wconversion -Werror` 编译通过）。验证器仅依据 ELF 头与程序头表（`PT_LOAD`/`PT_DYNAMIC`/`PT_GNU_RELRO`/`PT_GNU_STACK`/`PT_INTERP`）建立虚拟地址到文件偏移的精确映射（拒绝节头欺骗、拒绝 `PT_LOAD` 虚拟页重叠或 `p_filesz > p_memsz`、拒绝加法回绕与越界读）；完整解析 `PT_DYNAMIC` 条目（`DT_STRTAB`/`DT_SYMTAB`/`DT_RELA`/`DT_JMPREL`/`DT_BIND_NOW`/`DT_FLAGS`/`DT_FLAGS_1`/`DT_INIT_ARRAY`/`DT_FINI_ARRAY`/`DT_RPATH`/`DT_RUNPATH`/`DT_VERNEED`/`DT_VERSYM`）。强制安全判定包括：拒绝可执行栈或同时 `PF_W|PF_X` 的装载段；验证 Full RELRO 成立——必须启用立即绑定（`DT_BIND_NOW` 或 `DF_BIND_NOW`/`DF_1_NOW`），且按目标页大小向下/向上对齐后的只读覆盖区间须完整包裹 `.dynamic`、`.init_array`、`.fini_array` 及全部重定位写入目标（`R_X86_64_GLOB_DAT`/`JUMP_SLOT`/`RELATIVE`/`IRELATIVE`），同时检出未声明在白名单内的 `STT_GNU_IFUNC` 解析器、含相对路径或空项的 `DT_RPATH`/`DT_RUNPATH` 及未绑定版本定义的危险符号覆盖。用字节级构造的合法 Full-RELRO ELF 与 Partial-RELRO、页偏移错位、重叠 `PT_LOAD`、隐蔽 `IRELATIVE` 劫持样本实测全检出。
