# Tcl安全解释器访问路径令牌翻译

Tcl 安全解释器不让从属脚本看到真实路径，宿主用访问路径列表给它虚拟令牌路径（本题规定形如 $p(:N:)/子路径），再由主解释器代为 source 与 glob。攻击者在令牌后拼 ..、伪造令牌编号，或把目录换成符号链接。为 Go 宿主写供安全从属解释器的主侧别名调用的路径翻译包：输入访问路径列表与可访问子目录，令牌路径翻译成真实路径后规范化须仍在对应访问路径下；令牌编号越界、含 .. 逃出、符号链接指向外部均拒绝；翻译与最终打开之间不得因目录被替换而逃逸，打开时按已解析的句柄再校验；glob 结果反向翻译回令牌，任一结果含真实前缀即整批失败，错误信息在嵌套访问路径下也不得泄露真实前缀；source 只接受 .tcl 文件且须通过同一检查。用伪造编号、令牌拼 ..、符号链接替换、打开时目录替换、glob 混合结果和错误信息验证。
