反向代理允许服务端通过 103 预先提示资源，浏览器适配层会提前建立请求。我们遇到的故障是资源本身没被缓存，下一次顶层导航却继承了上一次用户的预加载授权。请在 Go 适配层实现可导入的预加载许可组件。每次导航都有不可重用的实例号、顶层站点、凭据模式和策略代次。多个 103 可声明同一资源的不同变体；只有请求目标、来源策略、凭据模式及表示选择字段全部相同的提示可共享下载，重定向后每一跳重新判定且不继承前一源的凭据。最终响应可收紧策略或要求重新验证，此前收到的字节只能暂存，必须在终态授权通过并绑定实际响应源和表示摘要后才能交给导航。取消、跨站导航和缓存重验证的晚到回调不得发布旧下载；失败的资源也不得通过跨用户命中时间暴露另一导航是否预取过。用能暂停在响应头、重定向与最后一个字节的假运输层，核对两次导航并发时发出的请求头、实际发布的字节和缓存项归属。
