# 矩阵时钟（Matrix Clock）与分布式垃圾回收

TypeScript 实现，零依赖，使用 Node.js 内置测试运行器（`node:test`）验证。

## 原理

每个节点维护一个 `N × N` 矩阵时钟 `M`：

- `M[i][j]` = 本节点所认知的「节点 i 所认知的节点 j 的逻辑时钟」；
- 第 `self` 行即本节点自己的向量时钟，随消息携带整个矩阵快照传播；
- 接收合并规则：自身行与发送方向量逐分量 `max`，其余各行同样逐分量 `max`（间接认知传播），随后自身分量 `+1`。

**GC 安全水位**：对矩阵逐列取最小值 `horizon[j] = min_i M[i][j]`，
其语义为「集群中**每一个节点**都已确认知悉节点 j 至少推进到 `horizon[j]`」。
凡向量时间戳被 `horizon` 逐分量支配（`<=`）的日志记录，对应事件均已被全网
完整接收并处理，其历史消息日志可安全物理截断。截断只作用于连续 LSN 前缀，
且 `truncateLog(upToLsn)` 的截断点永不越过安全水位。

## 目录结构

- `src/matrix-clock.ts` — 矩阵时钟：tick / receive 合并 / horizon 水位 / 支配判定
- `src/node.ts` — 节点：事件日志（LSN + 向量时间戳）、GC 水位计算、物理日志截断
- `src/cluster.ts` — 确定性同步集群模拟器（按通信轮次投递消息）
- `src/demo.ts` — 运行样例：3 节点通信数轮，A 截断 LSN ≤ 10 的历史日志
- `test/` — `node:test` 单元测试与端到端验收测试

## 运行

需要 Node.js ≥ 23.6（原生 TypeScript 支持；Node 22.6+ 可加 `--experimental-strip-types`）。

```bash
node src/demo.ts                 # 运行样例
node --test 'test/*.test.ts'     # 运行测试
# 或配置好 PATH 后: npm run demo / npm test
```
