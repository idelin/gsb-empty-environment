# 换电路径规划器

在带整数电耗的图上求 **最早到达**（其次 **最低费用**）的行驶/换电方案。
部分节点为换电站，可在营业窗口内付费换为满电电池，允许原地等待开门
（窗口按 24 小时循环，可等到次日）。

## 输入

JSON（文件路径作为参数，或从标准输入读取）：

```json
{
  "capacity": 10,          // 电池容量（整数电量上界）
  "start": "S", "goal": "G",
  "startTime": 6,
  "edges": [{"from": "S", "to": "A", "time": 4, "energy": 6}],
  "stations": {"A": {"fee": 5, "windows": [{"open": 8, "close": 20}]}}
}
```

## 运行

```sh
go run . example.json     # 或 go test ./...
```

## 算法

- 状态为 `(节点, 剩余电量)`；电量是 `[0, capacity]` 的整数，状态空间有限。
- 优先队列按 `(时间, 费用)` 字典序弹出（Dijkstra），首次弹出终点即最优。
- 每个状态维护 `(时间, 费用)` 的 Pareto 前沿：同节点若存在
  `电量 ≥ b 且 时间 ≤ t 且 费用 ≤ c` 的已结算标签，则新标签被支配剪枝
  （电量更高的标签的后继动作是低电量的超集，可跨电量等级支配）。
- 动作：沿边行驶（电量足够时）；在换电站等待至最近营业窗口并付费换满电。

## 终止性

- 前沿中时间递增则费用严格递减且费用有下界 0，故每个状态的前沿有限；
  被支配标签不再扩展，搜索必然终止。
- 零耗电（甚至零耗时）环上的重访标签，时间与费用均不优于已有标签，
  必被支配剪枝，不会无限搜索。
