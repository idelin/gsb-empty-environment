# snapshot-exporter

Go 导出器：从固定快照分页读取数据，落盘为页文件 + 清单，支持断点续导与完整性校验。

## 设计

- **固定快照读取**：`Source.Page(snapshotID, offset, limit)` 要求调用方钉住一个快照 id；源一旦更新，快照轮换，旧快照的读取直接失败（`MemSource` 演示该语义）。
- **清单（manifest.json）**：记录 `snapshot_id`、页大小、每页的范围（offset/limit/count）、文件名与 SHA-256 摘要，以及由所有页摘要折叠出的集合摘要 `set_sha256`。
- **断点续导**：仅在清单的快照 id 与页大小和当前一致时才考虑复用；且每页必须重新校验文件摘要、范围与条数，全部匹配才跳过重写——绝不直接信任偏移。
- **页文件损坏**：摘要校验失败的页按页重导，其余页原样保留。
- **写盘**：页文件与清单均先写临时文件再原子 rename；导出结束后清理上一轮的残留页文件。
- **核对**：`Verify(dir)` 逐页校验摘要与条数、重建完整集合并校验集合摘要。

## 测试

```
go test ./...
```

覆盖：源更新后快照失效必须全量重导、页文件损坏/丢失只重导该页、伪造清单不被信任、反复破坏-恢复后收敛到同一完整集合、源收缩后清理残留页。
