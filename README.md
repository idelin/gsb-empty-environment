多租户容器运行在多层 cgroup-v2 层次化设备策略下时，父级与子级允许/拒绝规则间的通配区间合并或 `mknod` 能力传递极易让隔离容器意外读写宿主块设备。给Go运行时写可导入的分层设备策略符号编译与审计验证包：规则区分设备类型（`c`/`b`/`a`）、闭区间 `[majorMin..majorMax]` 与 `[minorMin..minorMax]`（范围 `0..4095`，支持 `*` 全区）及 `r`/`w`/`m` 权限位；单层顺序按先后叠加与剥离权限，而多层cgroup嵌套必须保证子层永不能通过任意 `Allow` 规则重新恢复已被任一祖先显式 `Deny` 或未授予的 `(类型, 主次号, 权限)`，且单独的 `m`（`mknod`）授权绝不能隐含推导 `r`/`w`，跨挂载命名空间委托必须附带权限衰减掩码。由于主次设备号二维空间达 `2 * 4096 * 4096`，禁止逐点暴力枚举：编译器须构建精确的不相交二维区间符号决策图，并与目标规范策略（有限允许集合+强制拒绝集合）核对：若发生任何越权放行，输出按 `(类型 c<b, major, minor, 权限位)` 字典序最小的提权反例设备及涉事规则链见证；若收紧过度误杀合法设备，同样输出字典序最小的误拒设备。另提供待审优化器语义等价判定入口，按符号区间直交比对优化前后策略对任意设备的最终判决是否逐位一致，并用小域全枚举验证层级压制、`m`与`rw`隔离、跨区间拆分及优化器漏洞捕获。
