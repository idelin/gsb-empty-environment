# 双链摘除写原语的受控复现

自研分配器摘除空闲块时先执行next.prev=prev，再执行prev.next=next，恶意块头可能把这两次写变成任意写。为Go漏洞测试宿主编写内存模型包：内存是64个32位字，块头位于4字对齐地址，字段0为prev索引、字段1为next索引；攻击者只能改调用方指定块头的这两个字段，允许值集合显式给出。摘除版本A要求两次读写使用的全部字索引在0至63内，prev.next是内存[prev+1]，next.prev是内存[next]，版本B还核对next.prev与prev.next都指回当前块，版本C在B基础上要求两邻居都属于宿主登记的空闲块集合。按确切先后次序执行，两次写有别名时后写覆盖先写；预检须在任何写之前完成，拒绝保持内存不变。宿主给受保护字集合与期望攻击值，搜索最小字典序(prev,next)使摘除成功后任一受保护字被改为攻击值，输出每次读写地址和值；不能把普通链断裂算成功。独立回放比较三版本，覆盖两个写目标重叠、伪造回指满足B但不满足C、正常头尾哨兵和越界字段。
