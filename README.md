# 全景投影转换后，跨经度接缝的线条出现断裂

全景投影转换后，跨经度接缝的线条出现断裂。给Go图像渲染管线写等距柱状到立方体贴图的重采样包，每个输出像素通过明确的面坐标转成单位方向，柱状图横向周期、纵向极点夹取；过滤在方向空间自适应采样以覆盖像素立体角，权重按面积归一。面朝向与上下方向作为输入矩阵给定。用方向编码测试图、常量图及六面接缝采样核对旋转一致性与能量误差。

## eqcube 包

`eqcube` 实现等距柱状（equirectangular）全景图到立方体贴图六个面的重采样，
入口在 `eqcube/`：

- `eqcube/types.go` — `Vec3`、`Mat3`（列为 Right/Up/Front 的面朝向矩阵）、
  `Face` 与标准六面 `DefaultFaces`。面朝向和上下方向完全由输入矩阵给定。
- `eqcube/equirect.go` — 等距柱状采样器：经度方向按 `2*pi` 周期环绕（跨左右
  边界不断裂），纬度方向在两极夹取，双线性插值。
- `eqcube/resample.go` — `Convert` 主流程。每个输出像素由面坐标 `(u,v)` 经
  `Rotation.Apply` 显式转成单位方向；按像素四角在方向空间的经/纬度跨度相对源
  像素角间距自适应决定子采样网格（极点、接缝处自动加密），每个子样本权重为其
  子单元在单位球上的立体角，权重和即像素立体角，从而按面积归一。
  `PixelSolidAngle` 给出解析像素立体角，六面求和为 `4*pi`。

### 方向约定

世界坐标 X=东、Y=上、Z=前；经度 `phi=atan2(Z,X)`，纬度 `theta=asin(Y)`。
面矩阵三列依次为局部 `+u`（纹理右）、`+v`（纹理上）、面中心方向，局部方向
`(u,v,1)` 经矩阵映射后归一化为世界单位方向。

### 用法

```go
pano := eqcube.NewEquirect(srcImage)
faces := eqcube.DefaultFaces(256) // 每个面 256x256
for i := range faces {
    faces[i].Image = image.NewNRGBA(image.Rect(0, 0, 256, 256))
}
eqcube.Convert(pano, faces, &eqcube.Options{MaxSamples: 8})
```

### 测试

`eqcube/eqcube_test.go` 覆盖：

- 常量图：六面所有像素保持常量（面积归一不改变常量信号）。
- 方向编码测试图：像素颜色编码其单位方向，逐像素核对投影方向。
- 旋转一致性：对源图施加绕 Y 轴 90° 旋转后，输出方向同步旋转。
- 经度接缝：双线性采样在 `phi=±pi` 两侧周期连续；画在接缝经线上的条纹在
  共享该方向的相邻立方体面之间不断裂。
- 极点夹取：极点方向采样不越界。
- 立体角与能量误差：六面立体角和为 `4*pi`（误差 < 1e-10），平滑图能量误差
  < 2%，随机高频图上自适应采样能量误差优于单样本最近邻。
- 自适应密度：极点像素子采样网格密于面中心，且受 `MaxSamples` 上限约束。

运行：`go test ./...`（当前覆盖率约 97.7%）。
