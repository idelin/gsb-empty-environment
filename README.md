训练框架把模型切成若干段做流水线并行。给调度器交付可导入的 Go 排期组件。每段同一时刻只执行一个指令，前向第 i 个微批在第 s 段开始前要在第 s−1 段完成，反向同理依赖下一段；每段为前向完成但反向未开始的微批占一个激活名额，名额上限由输入给出。各段先执行若干个预热的前向，个数可在零到段数减段序号再减一之间自选，之后交替执行一个反向和一个前向，最后把剩余反向做完。组件按各指令给定的耗时输出最早开始时刻、每段峰值占用和总完成时间，并选总完成时间最小的预热个数。验收用小规模的离散事件模拟对照开始时刻；对不超过六段的实例穷举各段预热个数，组件的总完成时间不得比最优值差；覆盖首尾段预热为零、反向比前向慢和名额上限小于默认预热的情形。
