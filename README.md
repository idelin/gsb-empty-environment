离线设备只能间歇领取签过名的授权租约，控制台需要知道撤销后何时才能安全地把同一资源交给新租户。交付给 TypeScript 授权宿主的可导入判定包。设备可在父租约范围内签发子租约，绑定设备身份、资源集合、期限与父授权摘要；观察到的设备时间为偏移和漂移均受限的区间，所有时间用有理数。授权范围是资源前缀差集，不因后发子租约覆盖父前缀就可扩大。设备可提交签过名的提前归还与子树完整性证明；缺少完整性证明时不能把未见子租约当作不存在。求每个符号资源区间最早可安全重授的服务端时刻，区分已回收、尚有确定有效租约和只有可能有效的区间，且不得把多个设备不可能同时成立的时钟取值拼成真实见证。给出可回读的上下界证书与阻碍回收的授权链，离线设备永久失联时须依靠真实期限而非假定其已过期。小例用完整时钟约束求解对照开闭边界、父先归还子仍有效、重名设备、新代次与迟到归还。
