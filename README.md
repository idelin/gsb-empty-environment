# 组播门表编译器

模块可直接导入：

```go
import gt "prescreen.local/ps-282b6ff8a3"
```

`gt.Compile(problem)` 返回一个无限重复的超周期门表计划，包含：

- 每帧每出口的固定相对起发偏移、逐副本真实起发拍；
- 每帧最坏完成延迟、峰值共享槽数；
- 逐拍端口忙掩码，以及圆环压缩后的物理表项；
- `Result.Replay(cycles)` 逐拍设备回放：真实起发、槽释放、当前端口掩码、
  当前活动副本与活动槽数。

## 语义

`Problem.Period` 是超周期 `T`（1..96）。每帧在 `Release` 相位释放一次，
`Ports`/`Durations` 给出出口集合和各出口的非抢占发送时长，`Deadline` 是
相对释放的最坏完成期限（1..`2T`）。

帧 `f` 的出口 `p` 使用固定偏移 `o(f,p)`；第 `k` 代实例的真实起发为
`Release[f] + k*T + o(f,p)`。偏移按帧输入顺序、帧内 `Ports` 顺序构成
字典序平局标准。实现只枚举 `[0,T)` 内的偏移：更大的偏移与减去一个周期
的偏移有相同的端口相位，但延迟和槽占用都不会更小，因此不可能是最优解。

端口约束按圆环检查：同一端口上的所有副本（包括同类帧的相邻代）不得在
同一拍重叠，且不得占用 `Forbidden` 为 true 的拍。

每帧实例的共享槽区间是半开区间
`[Release+k*T, Release+k*T+max_p(o(f,p)+duration(f,p)))`。`SlotsUsed`
统计所有帧、所有代的最大并发槽数；同类帧的相邻代即使重叠也分别计数。

`Masks[t]` 是第 `t` 拍所有忙出口的位掩码（bit `p` 对应端口 `p`）。
`TableEntries` 是 `Masks` 在圆环上的最大恒定掩码区间数；全零或全一的
恒定掩码都只算一项。`Spans` 给出这些物理表项，跨越周期边界的同掩码区间
会合并为一项。`PortTableEntries` 仅作为每端口单比特位图的诊断信息，
不参与预算；`MaxTableEntries` 约束的是全芯片掩码表项。

## 优化目标

先最小化 `max_f frameLatency(f)`，其中
`frameLatency(f) = max_p(o(f,p)+duration(f,p))`；再在达到该最优延迟的
全部方案中取偏移字典序最小者。硬约束为 `MaxSlots` 和
`MaxTableEntries`；`gt.Unlimited` 可关闭任一预算。无可行解时返回
`err` 且 `errors.Is(err, gt.ErrUnschedulable)` 为 true。

## 验证

`gatetable_test.go` 包含独立的短周期暴力枚举器（逐一代数生成真实区间、
独立扫描槽峰值、独立压缩圆环掩码），对固定实例和随机实例核对延迟与
字典序偏移。另有针对以下场景的测试：

- 周期首尾同掩码必须合并；
- 延迟超过一周期时相邻两代槽并存；
- 两个端口各自局部可行、合并后超出共享槽预算；
- 所有拍均占线的恒定静态表只占一项；
- 禁发拍、期限、多口同帧同时发送、逐拍回放一致性。
