# 观察时刻推导结论差异分析（最小因果切片）

比较两个观察时刻（快照）的前向链推导结论，按 **新增事实 / 规则变更 / 证据失效**
三类原因输出**最小因果切片**。事实、规则、推导步骤均带稳定 ID 与版本；
每个切片都可重放验证；结果相同但支持来源改变的结论单列；无关输入不进入解释。

## 文件

- `engine.py` — 带溯源的前向链规则引擎（Fact/Rule/Step 均有版本化稳定 key）
- `causaldiff.py` — 快照差异分析：结论增删、支持来源变化、最小因果切片、重放验证
- `sample_data.py` — 合成样例（员工权限场景，t1 -> t2）
- `run_sample.py` — 运行样例并打印报告
- `test_causal_diff.py` — unittest 测试（13 例）

## 运行

```bash
python3 run_sample.py          # 打印差异报告（Python 3.11+，仅标准库）
python3 -m unittest test_causal_diff -v
```

## 关键设计

- **稳定 ID/版本**：`Fact.key=("fact",fid,ver)`，`Rule.key=("rule",rid,ver)`，
  `Step.sid` 为输入与结论的 sha1，跨进程稳定；同规则 ID 内容变更按版本识别。
- **最小因果切片**：先取结论支持集中与对端快照的增量元素，再贪心缩减至
  1-最小（去掉任一元素重放即不成立）。
- **可重放**：新增结论在旧快照上仅应用切片即可重推；消失结论在新快照上
  恢复切片即可重推；报告中附重放步骤 sid。
- **无关输入**：未出现在任何变化结论任一支持集中的增量输入，仅列入
  “未进入解释的无关输入”，不参与解释。
