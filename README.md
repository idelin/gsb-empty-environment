单点登录依赖方（RP）在接入 OpenID Connect Back-Channel Logout 1.0 实现跨应用强制登出时，若复用普通 ID Token 验签函数而未校验 `events` 声明与禁止 `nonce` 声明、忽略 `sid`/`sub` 组合语义或未记录已撤销会话时间水线，攻击者可将窃取的普通 ID Token 冒充 Logout Token 发动强制登出拒绝服务，或反之将 Logout Token 当作 ID Token 登录系统，甚至在登出后继续复活旧会话。为 TypeScript 认证宿主实现可导入的零外部依赖 OIDC Back-Channel Logout 令牌验证与会话撤销状态机组件（非对称签名通过注入验签器或 Node `crypto` 完成）。组件严格执行：（1）令牌类型双向隔离：Logout Token 必须包含 `events["http://schemas.openid.net/event/backchannel-logout"]` 为空对象 `{}`、严禁出现 `nonce` 声明、`sub` 与 `sid` 至少存在其一、校验 `iss`/`aud`（精确匹配 `client_id`）/`iat`/`exp` 窗口与 `jti` 防重放，且仅允许白名单非对称 `alg`（拒绝 `none`/对称混淆）；同时提供 ID Token 准入拦截器硬拒绝任何带 `backchannel-logout` 事件的令牌；（2）实现租户与主体级会话撤销账本：收到仅含 `sid` 的撤销精确吊销对应会话，收到仅含 `sub` 的撤销按主体撤销水线吊销该用户签发早于水线的全部现存及迟到旧会话，并防止并发刷新令牌复活已吊销 `sid`。附 ID Token 冒充 Logout Token、含 `nonce` 拒绝、主体级水线撤销与旧 `sid` 复活拦截测试。
