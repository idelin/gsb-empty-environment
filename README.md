# 签名保护页之外的可执行覆盖

固件加载器先验签区段再按重叠顺序装入内存，攻击者可能利用未签名区段覆盖已验签代码。交付供Go固件宿主调用的加载计划审查包：镜像由最多32个区段组成，给出唯一ID、目标地址、原始字节、执行标记和签名覆盖的原始字节区间；签名真伪由注入回调提供，只有回调成功且位置处在覆盖区间内才可信。加载按显式ID顺序，每区段可选择原样或RLE解码，RLE为(count,value)字节对，奇数字节数拒绝，零长段允许且不贡献执行范围，count为1至255；任一对未被签名覆盖，则它展开的所有字节不可信。最终每个执行标记区段覆盖地址都要求最终字节可信且来自调用方指定的目标镜像身份；每个区段携声明身份，验签回调返回其实际认证身份，执行范围为所有带执行标记区段的展开地址并集；后写覆盖先写；返回首个违规地址、最后写入来源及导致该地址进入执行范围的区段。地址为32位，展开总量最多1MiB，溢出和超限先拒绝再执行任何装载回调。测试签名原数据被未签名区段覆盖、RLE只签count、重叠同值但不可信及无重叠合法镜像；可信性不能用字节恰好相同替代。
