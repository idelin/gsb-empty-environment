# leasesim — 主备租约协商状态机（单机离散 tick 模拟）

仅用 Go 标准库实现。5 节点集群（多数派 = 3），全部事件记录在离散 tick 上。

## 设计

**时序模型**
- 单向网络延迟 2 tick；节点收到报文后 1 tick 才发出应答（租约请求往返 = 5 tick）。
- 每节点本地时钟 = 全局 tick + 偏移，偏移受界于 `DriftBound`（ε = 1 tick）。

**租约安全规则**（`LeaseDuration` L = 11 tick）
- 主节点：仅在本地时钟 `<= 最后多数派应答 + L - ε` 时服务并续租；超时**主动降级为候选者**（假设自己时钟偏快 ε）。
- 从节点：本地时钟 `< 最后心跳 + L + ε` 时拒绝为其他候选者投票（假设自己时钟偏慢 ε）。
- 主侧减 ε、从侧加 ε：只要真实漂移不超过 ε，新旧主租约窗口绝不重叠，**杜绝双主脑裂写入**。

**续租**：主节点每 2 tick 广播心跳，收到多数派心跳应答即续租。
**黑洞**：建模为延迟突增（窗口内送达的报文 +30 tick），延迟报文重新出现时因过期纪元被新主拒绝。

## 验收时序（TestLeaseNegotiationAcceptance）

| tick | 事件 |
|------|------|
| 100  | 节点 0 发起租约协商（epoch 1） |
| 105  | 多数派（3/5）确认，节点 0 成为主节点 |
| 106–138 | 心跳续租，最后一次多数派应答在 tick 139 |
| 140  | 注入网络黑洞：节点 0 与外界报文 +30 tick |
| 145  | 旧主租约仍有效，写入成功 |
| 150  | 旧主租约到期（139 + 11 - 1 = 149 后）自动降级为候选者 |
| 150  | 节点 1 选举超时（138 + 11 + 1），发起 epoch 2 选举 |
| 152  | 旧主已降级，写入被拒绝 |
| 155  | 节点 1 获多数派选票，成为新主 |
| 156  | 新主拒绝旧主迟到的请求（"already voted for node 1 in epoch 2"） |
| 170+ | 旧主被黑洞延迟的过期心跳浮出，被新主以 stale epoch 拒绝 |

不变式：任意 tick 至多一个 Primary（测试逐 tick 断言）。

## 运行

```sh
go test -v ./...      # 验收测试
go run ./cmd/leasesim # 事件日志样例
```

- `sim_test.go` — 验收测试 / 时钟漂移上界测试 / 无黑洞稳定续租测试
