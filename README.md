# causal：两时刻推导结论对比与最小因果切片

纯 Python 3.11 标准库实现（测试用 unittest）。对比两个观察时刻的推导结论，
把每条变化归因为 **新增事实 / 规则变更 / 证据失效**，并输出 **最小因果切片**；
结果相同但支持来源改变的结论单独列出；证据可重放。

## 运行

```sh
python3.11 run_sample.py     # 合成样例：报告 + 可重放证据 JSON
python3.11 -m unittest -v    # 14 个测试
```

## 设计

- `causal/model.py` — `Fact`/`Rule`/`Step` 均带稳定 ID 与版本；步骤 ID 是
  (规则ID, 规则版本, 输入事实引用, 输出) 的 SHA-256 内容哈希，跨运行稳定。
  规则 ID 相同但内容变更时以不同 `version` 识别。
- `causal/engine.py` — 单调前向链推导到不动点，为每条派生结论记录溯源步骤；
  `cone()` 沿步骤回溯到断言事实，得到溯源锥。
- `causal/diff.py` —
  - `root_diffs`：输入层差异（事实/规则的新增、撤回、版本更新）；
  - `compare`：对每条结论变化，取溯源锥内的根差异为候选，用贪心
    **1-最小化**（再移除任一元素性质即不成立）得到最小因果切片——
    溯源锥外与被重放证伪的输入（无关输入）不进入解释；
  - 每个切片在 `t1 + 切片` 上 **重放** 验证：新增结论可推导 / 失效结论
    不可推导 / 支持变更结论仍成立但步骤集合改变。
- `sample_data.py` — 合成样例（账户风控），覆盖全部变化类别及无关输入。

## 变化分类

| 类别 | 含义 |
| --- | --- |
| `added` | 新出现的结论（典型原因：新增事实） |
| `removed` | 失效的结论（典型原因：证据失效、规则变更） |
| `support_changed` | 结果相同但支持来源改变（单列） |

假设：规则集不冲突（同一结论 ID 不会被不同规则赋予不同载荷），推导单调。
