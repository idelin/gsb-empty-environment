# tree-table-nav

TypeScript 树表单元格导航库，基于**扁平可见网格模型**：树形数据被投影为
只含可见行/列的二维网格，所有导航与焦点调和都在该网格上进行。

## 模块

- `src/model.ts` — `TreeTableModel`：行森林 + 有序列；展开/折叠、异步展开
  （`expandAsync`，loader resolve 前可见网格不变）、行/列增删、单元格禁用；
  每次变更同步发出 change 事件。
- `src/grid.ts` — `buildVisibleGrid` / `gridToMatrix`：把模型投影成扁平
  可见网格（DFS 行序 + 深度 + 每格禁用标记），供渲染与测试核对。
- `src/navigator.ts` — `Navigator`：焦点移动与变更后的自动调和。

## 导航规则

- 上/下/左/右只在**可见且未禁用**的单元格间移动；禁用单元被跳过，
  隐藏行（祖先折叠）不可进入，`setFocus` 同样拒绝。
- 折叠使焦点所在子树隐藏（或焦点行被删除）时，焦点回到**最近可见祖先的
  同列**；该列不存在时取**最近左列**（左侧没有则取最近右列）；目标格被
  禁用则继续向左再向右找最近可用格。
- 删除焦点所在列时同样按“最近左列 → 最近右列”回退（借助变更前的列序
  快照定位缺口）。

## 运行测试

需要 Node ≥ 22.6（原生类型擦除，无需编译）：

```sh
node --test test/*.test.ts   # 或 npm test
```
