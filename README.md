VPN 隧道宿主在实现 WireGuard `Noise_IKpsk2` 握手与传输层数据平面时，若转录哈希链更新错序、TAI64N 时间戳未按静态公钥单调防重放，或抗 DoS Cookie（MAC1/MAC2）与 2048 位滑动窗口边界存在偏移差一，攻击者可重放旧握手包打断会话或绕过负载保护伪造传输帧。为 C++17 网络隧道宿主实现可嵌入的 `Noise_IKpsk2` 协议状态机与防重放验证库（严禁联网，`-Wall -Wextra -Wconversion -Werror` 编译通过；底层密码原语 X25519、ChaCha20-Poly1305、BLAKE2s 由标准抽象接口注入并附一套可运行参考实现用于测试）。状态机严格按 WireGuard 规范维护初始 `chaining_key` 与 `hash`、逐字段 `MixHash`/`MixKey`（覆盖发起包 `static`/`timestamp` 加密与响应包 `ephemeral`/`empty` 混合 `preshared_key`）、静态公钥级严格递增 12 字节 TAI64N 防重放表、以及无状态 MAC1/MAC2 校验（高负载开关开启时缺失有效 MAC2 必须返回加密 Cookie 回复而非执行 DH 运算，且 Cookie 每 120 秒轮换密钥并绑定源端点）。会话建立后，数据平面维护 64 位发送/接收计数器与严格 2048 位无符号滑动防重放窗口：精确处理乱序到达、重复序号拒收、大跨度跳跃时的位图清零边界，以及达到 `REJECT_AFTER_MESSAGES`（`2^64 - 2^13 - 1`）或 `REJECT_AFTER_TIME`（180s）时强制失效并显式清零会话密钥材料。附确定性对抗测试覆盖握手重放、错误 PSK、高负载无 MAC2 拦截、2048 窗口边界（`N`、`N-2047`、`N-2048`、大跳跃）及超时密钥清零。
