流式脱敏宿主在连续多代词典切换、回退以及跨块前后上下文敏感规则下发布前缀时，绝不能因分块切割而释放半个多字节字符或未定边界秘密，给 TypeScript 宿主写可导入的流式发布组件。输入为带签名策略代次的多代词典（支持 `gen 1 -> 2 -> 3` 连续切换与受签回退回执）、有限重叠的重写 DAG 归一化规则（每片段至多 4 种不同长度合法候选展开）、窗口大小为 `K` 的前后向上下文敏感脱敏条件，以及逐片到达的字节流。当一个敏感片段跨越大块与代次切点，或当前位置是否脱敏依赖后续至多 `K` 字节及未来策略版本时，组件须精确计算最小安全可发布前缀，将仍受多代交界或前瞻窗口影响的后缀保留在内部缓冲，绝不拆分成两个各自安全的片段提前输出，也禁止在多字节 UTF-8 或重写折叠边界泄露半字符。重传确认具备幂等性，每个已发布前缀附原始偏移与生效策略代次凭据且不暴露被遮蔽内容与候选分词数。用 1 字节极端切块与全切分参考对照回退竞态、前瞻跨越切点及多重写对齐。
