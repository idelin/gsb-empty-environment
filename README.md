训练卡在 reduce-scatter 中途复位了通信引擎，显存没丢。整层重算不一定可行：有的梯度已被原地归约覆盖。为训练运行时写可导入的 Go 恢复包。输入每个 rank 的物理槽及张量切片到槽的映射（可以别名），每个初始槽是零或某一逻辑分片的一个 rank 的原始梯度。用独立形式变量代表每份梯度，不读取浮点数猜内容。掉电前给一组至多八条在途单包 DMA：已知偏序，每条至多执行一次，可能执行了任一下闭子集的任一拓扑序；原子操作为复制或把源加到目的，读操作数后才写，别名也照此规则。哪些包执行及顺序都不可见，只知道若干包确定执行或确定未执行，以及各目的卡收到的包数模四。首先判定回执是否自洽。恢复器可从输入的有限清单选择逐步探问某张卡上某组原包的实际执行数（只返回奇偶），或者同步下发清单中的复制、相加、清零命令；恢复命令不再丢包，每条命令和每项探问在一条分支上至多用一次，费用均为正整数。选择只能依赖已经得到的回答，不能按真实掉电历史挑计划。成功时每个指定输出槽必须对其分片所有 rank 各含一次，对别的变量系数为零。求保证成功的策略树，先最小化最坏分支总费用，再最小化达到该费用条件下整棵树的动作节点数，同规模任取；只计可能回答，公共子树展开计数。另提供独立验证接口，能指出给定策略哪条回答路径、哪种合法掉电历史及哪个输出系数不对，策略越权或重复动作则指出位置；无策略和矛盾回执分别返回。至多四卡、十二槽、十二个可用动作；可按不同可达配置与信息集合搜索，不得枚举所有完整恢复策略再择优。以小例穷举作对照，测试两种历史显存相同但以后探问能区分、探问已知的包仍无法辨别复制与覆盖的先后、以及各个历史单看都能修但不存在共同策略的情形。
