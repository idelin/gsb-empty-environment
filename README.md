分析数据库的分区目录只有摘要，没有数据行，错误裁剪会直接漏数。给优化器做可导入的 Go 包，输入是三列可空整数字段、分区摘要和过滤表达式 DAG。每列摘要给本地字典版本、若干可能编码区间以及是否可能为 NULL；字典按分段仿射表映射到有符号逻辑值，段可反向且不同编码可映成同值。另有跨列约束：当两列非空时必须满足给定的差值闭区间，NULL 时该约束不生效。过滤支持列与常量或另一列比较、IS NULL、AND、OR、NOT，按 SQL 三值逻辑，只 TRUE 的行保留。要求判定满足摘要的行中是否至少有一行能通过，不是只对每个叶独立做区间近似。能通过时给出按 NULL 最小、随后逻辑值字典序最小的三列见证及对应最小编码；不能通过时返回一棵可由独立检查器重放的裁剪证明，检查器不调用裁剪器且不能依赖单个布尔结论。为使输入可精确处理，仿射斜率只取 ±1，每列最多八段，过滤最多十二个不同原子，可枚举段与原子分支但不得枚举 64 位编码区间内的值。输入越界、不完整映射、空分区与始终 UNKNOWN 的谓词要区分。在小字典穷举所有行对照，测试非单射映射、有符号极值比较、各叶单独可满足而组合矛盾、NOT UNKNOWN 仍不保留，以及相同逻辑见证有多个物理编码。
