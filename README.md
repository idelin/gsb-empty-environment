# ledger

Go 复式记账库：整数分金额、借贷平衡凭证、幂等批次、乱序冲销。

## 规则

- **整数分**：所有金额为 `int64` 分，无浮点误差；每条分录借/贷恰其一为正。
- **借贷平衡**：每张凭证借方合计必须等于贷方合计，否则整批拒绝（`ErrUnbalanced`）。
- **批次原子性**：`Submit(Batch)` 全成全败；任一张凭证非法则整批不落账。
- **幂等**：批次 id / 凭证 id 重复提交且内容一致 → 空操作；同 id 异内容 → `ErrConflict`。
- **冲销**：凭证设 `ReversalOf` 引用原凭证，分录必须逐行相反（同账户、借贷互换、金额相等），否则 `ErrReversalMismatch`。
- **乱序冲销**：冲销先于原凭证到达时挂起（pending），原凭证到账时结算；结算时校验失败则标记拒绝（`Rejected`），不影响原凭证落账。
- **二次冲销**：同一凭证只能被冲销一次（含已挂起的冲销），再次冲销 → `ErrAlreadyReversed`；冲销凭证不可再被冲销（`ErrReversalOfReversal`）。

## 验证

- `Conservation()`：余额守恒 —— 每张已落账凭证平衡且全部账户余额合计为 0。
- `VerifyReplay()`：从日志重放全部批次，校验重放状态与当前状态一致，证明跨批依赖（含挂起冲销）的结算是确定性的。
