# FUSE请求uid映射

FUSE 文件系统以 allow_other 方式挂载后，内核请求头里的 uid 与 gid 可以是任意本地用户，守护进程若直接用自己的身份访问后端存储，就把所有用户都提升成守护进程的权限。为Go的 FUSE 守护进程写可导入的调用者身份映射包：按调用方给的映射表把请求头 uid、gid 转成后端身份，表里没有的 uid 返回 EACCES，不得回退到守护进程身份；uid 0 只在表里显式映射时有效；新建文件的属主取映射后的调用者；forget、interrupt 等没有授权意义的请求不做映射；文件句柄绑定打开时的映射身份，换另一个映射身份使用同一句柄一律返回 EACCES。测未映射用户、root 回退、跨用户使用句柄、新建文件属主。
