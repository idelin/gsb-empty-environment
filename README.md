物化半连接维护器收到一批带正负重数的外表更新和内表去重计数变化。给它写可导入的 Go 包，支持 SQL 的 EXISTS、NOT EXISTS 与带 NULL 的 NOT IN 三种语义，外表行带分组与可空键。内表每个分片只公开某些键计数的范围、空值总数范围和相邻查询共享的线性约束。允许自适应读取候选汇总页，每页给一组准确计数。求在所有符合摘要的数据库上足以确定本批所有分组输出增量的最小最坏读取费用；若存在两个底库对所有可读页相同但输出不同，返回最小见证。初末计数均不得负，批内可相互抵消，不得只按是否有 NULL 给 NOT IN 打全局删除标记。每冲突分量最多十个不确定计数且每项 0..4，候选页最多十张；大量确定计数用区间表示。用独立逐行 SQL 三值解释器对小底库和读取树穷举核对。
