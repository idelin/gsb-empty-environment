LSM 存储要把很老的 range delete 下推给设备。设备只有固定数量的范围描述符，每条为（半开键区间、序列号），并可和已有点版本共同决定读结果。实现数据库读路径可导入的 Go 压缩包。有限键表给出所有实际存在过的点版本（含 put 的任意字节值、单键 delete），序列号全局唯一；范围墓碑另给，无穷端点不同于空字节串。读取一个快照时取不晚于其序号的最新点版本，若其为删除或有更新且不晚于快照的覆盖墓碑则缺失。不允许改变点版本；可重写墓碑，序号必须取自原墓碑，区间端点取所有原端点、已知键以及显式给出的切割点。目标只需保持给定的最多八个快照及当前快照对所有键的值（不在点表的键始终缺失），不要求重放墓碑本身。每个描述符有按端点编码长度和序列号决定的正整数设备费用；最多容纳 12 条，先最小费用再最少条数。不能将每个键的最新遮挡序号独立简化后直接拼区间：允许跨过一个在该快照没有可见点的键，历史快照可能不允许跨过。交付二进制比较器、编译器和用新表实际执行的快照点读/范围迭代；无解须区分于全空输出。至多 30 个不同切割点与 12 个旧墓碑，禁止遍历字节串键域；小输入用枚举描述符子集核对最优，逐快照实际遍历比对旧新结果，覆盖两个 put 值相同但序号不同、点删除后重新 put、跨空洞能省表项和只在中间历史快照可见的反例。
