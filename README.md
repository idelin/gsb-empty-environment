# merkle-anchor

外部存证锚定组件：定时将本地系统的默克尔根哈希与当前时间戳打包签名，并可出示
带时间戳证明的存证证书，证明特定数据在特定历史时间点之前已经确定存在。

## 组件

- `src/merkle.ts` — 默克尔树：SHA-256（叶 `0x00` / 节点 `0x01` 域分离），包含证明的生成与验证。
- `src/anchorer.ts` — 锚定器：Ed25519 签名 `{version, sequence, timestamp, merkleRoot, prevAnchorHash, nonce}`；
  防重放依赖单调递增序号、锚哈希链、时间戳严格递增与随机 nonce；`AnchorVerifier` 是有状态登记方，
  拒绝重放、乱序、链断裂与时间回拨。
- `src/certificate.ts` — 审计凭据：默克尔包含路径 + 签名锚定记录。验证通过即证明
  该数据在 `anchor.timestamp` 之前已入库固定。

## 运行

需要 Node.js >= 23.6（原生 TypeScript 类型擦除）。

```sh
npm test     # node:test 内置测试
npm run demo # 运行样例：t=1000 锚定 → t=2500 出证 → 重放/伪造/篡改攻击均被拒绝
```

## 验收场景

1. t=1000：定时任务将默克尔根与时间戳打包签名并锚定；
2. t=2500：针对某条业务记录生成审计凭据；
3. 验证凭据 ⇒ 证明该业务事实早在 t=1000 前已固定，事后无法伪造篡改
   （改数据 → 根不匹配；改时间戳 → 签名失效；重放旧锚 → 序号/链校验拒绝）。
