无密码认证宿主接入 WebAuthn Level 3 / Passkey 注册与登录时，若依赖宽松 JSON/CBOR 解析器忽略 `authenticatorData` 标志位一致性、放过跨源 `iframe` 伪造 `topOrigin`，或未对多设备备份标志（`BE`/`BS`）与 `signCount` 回退建立严格克隆风控，攻击者可利用伪造证明或克隆漫游密钥绕过强认证。为 TypeScript 身份服务宿主实现可导入、零外部 CBOR/COSE/WebAuthn 依赖（仅用 `node:crypto`）的原始二进制解码与策略核验引擎。组件从原始字节实现确定性 CBOR（RFC 8949 Core Deterministic Encoding，硬拒绝非最短整数、重复映射键、不定长容器与尾部多余字节）及 COSE_Key（ES256/EdDSA/RS256）解码；完整解析 `authenticatorData`（32 字节 `rpIdHash`、标志字节 `UP`/`UV`/`BE`/`BS`/`AT`/`ED`、大端 32 位 `signCount`、变长 `attestedCredentialData` 与 CBOR 扩展）及 `clientDataJSON`。注册核验覆盖 `packed` 与 `none` 证明格式、严格 `challenge` 单次消费与时效、`type` 精确匹配、`origin` 与跨域 `crossOrigin`/`topOrigin` 白名单绑定、`rpIdHash == SHA-256(rpId)`、要求 `BS=1` 必先满足 `BE=1`（拒绝非法标志组合）及算法白名单校验；登录核验除用冻结 COSE 公钥验证 `authenticatorData || SHA-256(clientDataJSON)` 签名外，严格执行 `UV` 策略与克隆异常检测——当凭证非多设备备份（`BE=0`）且先前或当前 `signCount > 0` 时，若 `newSignCount <= storedSignCount` 必须判定为疑似克隆立即阻断并冻结凭证，同时验证 `BE` 标志一经注册不可变。用真实密钥构造合法及非法 CBOR 畸形、跨源钓鱼、`BE/BS` 违例与 `signCount` 回退样本实测全通过。
