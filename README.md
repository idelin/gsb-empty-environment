# 四维时空反向索引与历史相交证明器

追溯引擎：证明“实体 A 与实体 B 是否在历史某个时空相遇过”。
基于**时间切片倒排网格表**建立四维（t, x, y, z）反向索引，快速检索两实体
在任意时刻空间距离小于给定阈值的相遇接触记录，输出全部相交时段与
**不可抵赖的地点证书**。

纯 TypeScript 实现，零第三方依赖（仅用 Node.js 内置 `crypto` / `test` 模块）。

## 运行环境

- Node.js **>= 22.6**（利用原生 TypeScript 类型擦除直接运行 `.ts`，无需编译）。
- 若系统默认 Node 版本过低，仓库自带的 `./run.sh` 会自动探测可用的
  Node >= 22.6（包括 Codex 运行时内置的 Node 24）。

## 快速开始

```sh
./run.sh demo     # 运行疾控流调演示（等价于 node src/demo.ts）
./run.sh test     # 运行全部内置测试（等价于 node --test test/）
```

环境 Node >= 22.6 时也可以直接 `npm run demo` / `npm test`。

## 架构

```
src/
  types.ts         轨迹点 / 相遇时段等基础类型
  grid_index.ts    四维时空反向索引：时间切片 × 空间网格倒排表
  intersection.ts  精确时空求交：分段线性轨迹 + 二次方程求根
  merkle.ts        Merkle 树（轨迹承诺与包含证明）
  certificate.ts   接触证书：承诺、见证点、链式哈希、独立校验
  prover.ts        相交证明器：预筛 -> 求交 -> 出证 -> 验证
  scenario.ts      疾控流调验收场景（商场两名确诊者轨迹）
  demo.ts          演示入口
test/              Node.js 内置测试（node:test）
```

### 1. 时间切片倒排网格索引（`SpacetimeGridIndex`）

- 时间轴切成等长切片（默认 5 分钟），每切片内维护倒排表
  `网格 cell -> 实体集合` 与正排表 `实体 -> 轨迹点集合`。
- 跨切片的轨迹段在切片边界处**线性插值出边界点**，保证每个切片自包含，
  求交无需跨切片回溯。
- 轨迹段扫过的全部网格经 **3D DDA**（Amanatides-Woo）遍历登记，
  快速移动的实体不会漏检（预筛无假阴性）。
- 查询预筛：先做每切片**包围盒 O(1) 粗筛**，再对存活切片做网格邻域
  （`ceil(阈值/格宽)` 圈邻格，数值化网格键整数加减）精确预筛，
  绝大多数时空被倒排索引直接剪枝。

### 2. 精确时空求交（`computeContactIntervals`）

- 两轨迹均为分段线性；在双方折点时刻切分出的“基本窗口”内，相对位置的
  平方距离是归一化时间 u∈[0,1] 的**二次函数**，与阈值球面的交点由求根
  公式精确给出 —— 不是采样近似，时段端点精确到浮点精度。
- 相邻窗口的接触子区间自动合并，输出完整相交时段、最近距离与时刻。

### 3. 不可抵赖证书（非否认证明）

- **轨迹承诺**：每个实体的整条轨迹点哈希构成 Merkle 树，根哈希先行公开
  即不可篡改。
- **见证点**：每张接触证书携带覆盖相遇时段的原始轨迹点及其 Merkle
  包含证明，任何第三方可独立验证这些点确属已承诺轨迹。
- **可重算性**：验证器从见证点重新执行时空求交，重算的相遇时段与最近
  距离必须与证书声明一致。
- **链式哈希**：证书按 `H(prevHash | bodyHash)` 链接成链，最终摘要
  `proofDigest` 可对外公开存证；增删、调序、篡改任一字段都会使验证失败。

## 验收场景（疾控流调）

输入两名确诊者（张某、李某）在星光购物中心的轨迹数据，阈值 10 米。
引擎在 **1 毫秒内**完成时空求交（实测约 0.4ms），精准输出 **3 段**相距小于 10 米的
相遇时段及具体柜台位置（化妆品专柜 / 奶茶柜台 / 生鲜柜台），并生成
不可抵赖证书。实测输出见 `src/demo.ts` 的运行结果：

- 相遇 #1：10:05:00.000 – 10:10:00.000，化妆品专柜，最近 0.000 米
- 相遇 #2：10:30:40.000 – 10:34:00.000，奶茶柜台，最近 3.254 米
- 相遇 #3：10:44:30.000 – 10:49:07.049，生鲜柜台，最近 0.000 米

## 测试

`test/` 下 5 个测试文件、25 个用例，全部通过：

- `intersection.test.ts`：求交数学正确性（解析解对照、合并、三维、边界）
- `grid_index.test.ts`：倒排索引预筛、跨切片插值、边界情形
- `certificate.test.ts`：Merkle 证明、证书链、6 类篡改检测
- `scenario.test.ts`：疾控流调验收（恰好 3 段相遇、时刻/地点精确）
- `performance.test.ts`：500 实体 × 1440 点（72 万轨迹点）规模下，
  实测平均单次求交（含出证）约 0.4ms

实测性能（Node v24，Apple Silicon）：

```
建索引 1078ms（720000 点）；预提交承诺 1872ms（一次性入库成本）；
200 次求交共 52ms，平均 0.258ms/次，共检出 86 段相遇
```
