# 协议密钥用途类型推导

教学协议把加密钥误用为认证钥，符号验证器不能把所有钥视为同类原子。写供Go验证宿主调用的类型推导包，消息构造区分加密、验签和派生，钥类型带所有者、用途与会话代；通过有限约束求解判断脚本是否可能发生用途混淆，返回最小冲突操作集。用多态辅助函数与递归角色模板测试。

## 设计

包路径 `example.org/netsec/q0481`（包名 `netsec`），宿主通过 `netsec.Solve(script, budget)` 调用。

- 钥类型 `KeyType` 含三个有限域维度：`Owner`、`Purpose`（`encrypt`/`verify`/`derive`）、`SessionID`（会话代/epoch）。
- 消息构造严格区分 `KindEncrypt`、`KindSign`、`KindDerive`，分别向钥项施加对应用途约束；`KindNewKey` 声明钥类型（模型事实，不参与最小冲突集）；`KindBindKey` 断言两个钥项为同一钥原子（别名）。
- 求解器为每个钥项的每个维度分配一个并查集变量，别名合并等价类并传播有限域；同一等价类被强制取不同值即产生 `Clash`。
- 最小冲突操作集 = 对所有冲突溯源集合的最小基数击中集，用带预算的分支定界搜索枚举全部等优解，预算耗尽时 `Stats.Exact=false` 并返回尽力而为结果。
- 多态辅助函数 `Func` 在每个调用点用全新类型变量实例化；递归角色模板 `Role` 按显式深度展开，每帧重绑 epoch，保证跨会话代的钥类型不被混同。

## 文件

- `types.go`：用途、构造子种类、钥类型、项与具体操作。
- `script.go`：脚本构建器、函数/角色模板声明与节点类型。
- `engine.go`：模板实例化（多态调用展开、有界角色递归）。
- `solver.go`：并查集 + 三维有限域约束传播与冲突报告。
- `mus.go`：最小击中集（最小冲突操作集）搜索。
- `netsec_test.go`、`example_test.go`：用途混淆、多态辅助函数、递归角色模板、所有者/会话代冲突、最小集性质与宿主示例。
