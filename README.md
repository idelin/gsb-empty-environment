数据库读取堆页时要知道每条元组对当前快照是否可见。给堆页读取路径交付可导入的 Go 可见性组件。元组带插入事务号与命令号、删除事务号与命令号；快照带最小活动事务号、已分配的上界和活动事务集合；事务状态由调用方注入，可返回进行中、已提交、已中止，并能取到提交号。规则是：插入者已提交且提交号小于快照起点、插入者不在活动集合、插入事务号不小于最小活动事务号，或者元组带冻结标记，才算插入可见；删除者为空、进行中、未提交或对快照不可见时元组有效，删除者的命令号不小于快照命令号时也有效。事务号差按三十二位回卷比较。验收用朴素真值表枚举插入者、删除者的状态与提交号先后，覆盖冻结元组、同一事务内先删后插、删除者提交晚于快照、事务号回卷后新旧颠倒，以及删除者就是快照自身事务的情形。
