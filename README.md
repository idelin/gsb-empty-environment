# 安全号码只覆盖账号却漏掉新增设备

用户线下比较的安全号码若只由账号主键生成，后来被服务端加入的恶意设备不会改变显示。给Go客户端实现可导入的多设备安全号码包：每个账号取经上题一致性校验通过的设备列表快照，按deviceID排序，每项编码deviceID、身份公钥和添加版本；账号身份摘要为SHA256固定域标签、accountID、列表版本、列表摘要及所有项。两方会话安全号码对两个账号摘要按字节序排序后SHA256，取校验值大端整数模10^60并左补零取校验值大端整数模10^60并左补零显示为60位十进制并分12组，同时生成含协议版本、双方accountID、列表版本/摘要和原始32字节校验值的二维码负载。验证二维码必须确认账号集合完全相同、每方当前列表版本和摘要与负载一致、校验值重算相同；较新列表使旧验证状态Stale，不能静默沿用。用户确认记录绑定双方列表摘要、确认方式和时刻；任何设备新增、移除或公钥变化撤销确认，普通设备在线状态变化不撤销。实现两个客户端各持可能不同快照的测试，服务端插入设备、隐藏设备、只换顺序、删除再加同ID及二维码方向交换，只有完整设备集合一致才显示Verified。
