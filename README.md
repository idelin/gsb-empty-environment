# maxflow — 增量最大流与最小割证书生成器

有向网络整数容量最大流的动态调整器（Go，仅标准库）。

## 功能

- `NewNetwork(n, s, t)` / `AddEdge(u, v, cap)`：构建有向容量网络。
- `MaxFlow()`：Dinic 算法求最大流（增量式，在现有流量基础上继续增广）。
- `Adjust([]Change)`：批量调整已有边容量（`Delta>0` 增，`Delta<0` 减）：
  1. 整批校验（边存在、容量不为负），失败不改动网络；
  2. 容量缩减导致流量超限时，沿残余网络反向增广轨撤回超限流量
     （`u~>s` 与 `t~>v` 两段反向推送 + 取消该边上的超出部分）；
  3. 重新增广寻找替代路径，恢复最大性；
  4. 返回最小割证书 `Certificate`：新最大流值、S/T 节点可达性划分、割边集合。
- `Cert()`：对当前流量单独生成最小割证书（残余图中从 s 可达集为 S 侧）。

## 运行

```sh
export GO111MODULE=on          # Go 1.11 需要
go test ./... -v               # 测试
go run ./cmd/demo              # 验收场景演示
```

## 验收场景（cmd/demo）

网络：`s->a 5, s->b 5, a->c 5(关键边), b->c 5, c->t 10, a->d 1, d->t 1`。

- 初始最大流 = 10；
- 关键边 `a->c` 容量 5 → 2：沿反向增广轨撤回 3 单位流量，
  替代路径 `s->a->d->t` 找回 1 单位，最终流量 = 8；
- 割证书：S 侧 `{s, a}`，T 侧 `{b, c, d, t}`，
  割边 `s->b(5), a->c(2), a->d(1)`，割容量 8 = 最大流。

`maxflow_test.go` 覆盖：初始最大流、容量缩减撤回与割证书内容、
