# 写时复制页秘密清零

快照沙箱释放共享秘密页时，清零操作不能破坏仍获授权的快照。给Go内存宿主写可导入的页所有权包，引用共享只读页，写入先复制；最后一个授权引用释放才清零并归还物理页，清零失败不得重新分配。用极小页池与可暂停清零器测试分叉、撤销及并发写，核对每页内容和引用账。

## 包结构（`netsec`）

- `Pool`：固定容量物理页池，页状态为 free/live/pending/zeroing/dead，
  后台回收协程只在清零成功后把页放回自由链表，失败页永久隔离（quarantine）。
- `PausableZeroer`：可暂停/恢复、可按页 ID 或次数注入失败的清零器，
  并记录清零调用与成功/失败页 ID，便于测试断言。
- `Host` / `Snapshot`：授权主体。`Host.Fork` 以引用计数共享只读页；
  `Snapshot.Write` 在共享时先复制（COW）再写入；`Snapshot.Revoke`/`Release`
  按引用释放，最后一个引用才入清零队列。

## 快速验证

```sh
go vet ./...
go test -race -count=10 ./...
```

测试覆盖：分叉共享与 COW 隔离、撤销后清零与页复用、清零失败隔离不重分配、
暂停清零器下的排队与耗尽、并发写与并发分叉/撤销、每页内容与引用账核对、
取消等待无 goroutine 泄漏，以及仅使用公开 API 的导入示例。
