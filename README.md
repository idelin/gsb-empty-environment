# 资源受限规划器

在不可再生资源预算内，从有限状态空间中选择动作序列：目标可任选若干项达成，
**主目标最大化总收益，次目标最小化总动作成本**，并在搜索过程中识别
“看似接近目标、实则关键资源已被耗尽”的死端。不做目标距离贪心。

## 问题模型

- **资源**：命名资源向量，只减不增（不可再生），初始量即预算。
- **有限状态空间**：动作声明 `from`（可触发的前置状态集）与 `to`（迁移目标状态），构成输入约束。
- **动作**：`cost`（动作成本，次目标）、`consumes`（资源消耗）、可选 `requiresGoals`（前置目标）、`achieves`（达成目标）。
- **目标**：每项带 `profit`，可达成任意子集；总收益为已达成目标收益之和。

## 算法（src/planner.ts）

搜索结点为标签 `(状态, 目标位掩码, 剩余资源, 收益, 成本, 深度)`：

1. **最佳优先扩展**：堆序为（收益降序, 成本升序, 深度升序），直接对应字典序目标。
2. **Pareto 支配剪枝**：同一状态下，若已有标签的目标集合为超集、资源逐项不少、
   成本与深度均不超过，则新标签被支配丢弃；新标签也会淘汰被它支配的旧标签。
3. **收益上界剪枝**：对每个未达成目标用 Dijkstra 求各资源的最小消耗下界
   （在 `(状态, 目标掩码)` 隐式图上、忽略其他资源，是合法下界）；
   单独可行的目标收益之和 + 当前收益构成上界，无法改进当前最优即剪枝。
4. **死端识别**：当上界等于当前收益（剩余资源内无法再达成任何目标），
   但仍有目标在图上可达时，即为资源耗尽的死端。报告每个被卡目标的
   图距离（忽略资源的动作数）与各资源缺口下界；距离 ≤ `nearDistance` 的标记为近距陷阱。
   自然终点（图上无可达目标）不误报。

`src/greedy.ts` 是反面对照：每步锁定图距离最近的未达成目标并选缩短距离最多的可行动作，
演示中它会被 G1 陷阱卡住（收益 10 vs 最优 55）。

## 运行

```bash
npm run demo        # 演示场景：最优计划 + 每步资源余额 + 死端报告 + 贪心对照
npm test            # 1000 个随机小实例与穷举搜索对拍，验证最优性
npm run typecheck   # 需要本机已安装 typescript（tsc --noEmit）
```

本仓库源码为标准 TypeScript（strict）。因当前环境无网络无法安装 tsc，
`tools/run.mjs` 提供了一个仅支持“可擦除语法子集”的极简类型擦除器用于本地运行；
安装 TypeScript 后可直接 `tsc --noEmit` 做完整类型检查。

## 输出

`PlanResult`（src/types.ts）：

- `steps[]`：每步动作、成本、消耗、**执行后资源余额**、新达成目标、所处状态；
- `profit` / `cost`：最优总收益与相应的最小动作成本；
- `deadEnds[]`：死端列表（动作前缀、剩余资源、被卡目标及其距离与资源缺口）；
- `explored`：扩展结点数（剪枝效果统计）。

## 限制

- 收益要求非负（支配与上界剪枝的前提）。
- 目标数量用 bigint 位掩码表示，规模不受 32 位限制，但隐式图随目标数指数增长，
  适合中小规模问题（演示与对拍规模：目标 ≤ 5、状态 ≤ 数十）。
- 资源缺口为逐资源独立下界：报告的缺口一定成立（sound），
  但联合不可行而逐资源可行的个别死端可能不报告（保守）。
