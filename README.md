# GraphQL别名合并让第二个字段跳过授权

GraphQL网关做字段级授权时只按第一个别名登记检查，执行器却按响应键合并两个别名，攻击者用同一字段的两个别名把受保护数据带出。请实现供Go GraphQL网关调用的可导入查询授权组件。遍历选择集时为每个别名、片段展开、内联片段和指令条件生成独立授权节点并绑定其响应路径；同一路径只有身份与授权结果都相同时才允许合并，`@skip`与`@include`在运行时求值后仍各自复审。变量、默认值和分页参数不得扩大字段范围，批处理与持久化查询共用同一计划摘要。用重复别名、原型污染式别名、片段复用、条件跳过、跨租户节点ID和合法多别名查询验证任一别名未授权即整条路径拒绝。
