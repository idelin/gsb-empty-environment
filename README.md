# 认证协议状态学习

测试团队希望根据模拟登录服务的行为发现未认证状态也能访问受保护操作。实现供Go测试框架调用的状态学习包，字母表由调用方给定，每条查询先重置服务，记录响应与授权位；通过区分后缀拆分观察上相同的状态，并将反例回灌到模型。只在指定最大深度内声称覆盖，超预算返回未完成。用隐藏状态的确定性服务验证短授权绕过路径和重置失败处理。

## 实现

`statelearning` 子包基于 L* 观察表主动学习确定性服务的 Mealy 机模型：

- `SUL` 接口由调用方实现，`Reset` 将服务恢复到固定初始状态，`Step` 应用一个
  字母符号并返回 `Output{Response, Authorized}`；字母表通过 `Config.Alphabet`
  由调用方给定。
- 每条成员查询先调用 `Reset`，再重放整条输入字，逐步记录响应与授权位；
  查询结果按输入字缓存，每个不同的字最多产生一次重置查询。
- 观察表用区分后缀（列）计算行签名，闭包/一致性检查把观察上相同的行拆分到
  不同状态；等价查询在 `Config.MaxDepth` 内穷举对比 SUL 与假设，反例的全部
  后缀回灌为新的区分列后重新收敛。
- 覆盖只在 `MaxDepth` 内声称：全部一致返回 `StatusComplete`；查询数达到
  `Config.MaxQueries` 时返回 `StatusIncomplete` 并包装 `ErrBudgetExhausted`，
  不会给出虚假的完整结论。SUL 的重置/步进失败通过 `Result.Err` 上报并中止学习。

入口：`statelearning.Learn(sul, cfg) Result`。

## 验证

`statelearning/mock_service_test.go` 用带隐藏状态（匿名、已认证、调试、锁定）
的确定性模拟登录服务验证：

- 学习结果与服务在最大深度内穷举一致，并发现两步短授权绕过路径
  `debug_enter -> access_protected`（未登录即获授权）；
- 重置失败与步进失败被包装为错误且状态为未完成，不会被当成观察；
- 查询预算耗尽返回未完成；深度边界与非法配置有对应校验；
- 反例回灌使浅深度假设被进一步拆分并收敛到正确的四状态模型。
