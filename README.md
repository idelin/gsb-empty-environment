单文件 B-Tree 存储引擎处理超出单页承载上限的大行载荷时，必须按固定数学阈值把记录拆分为“页内本地前缀 + 单向溢出页链（Overflow Chain）”，并在记录删除或重写时把释放的溢出页归入由树干页（Freelist Trunk）与叶页（Freelist Leaf）构成的空闲页链表；一旦本地前缀长度计算偏差 1 字节或空闲链表在树干页满/空边界处理不当，文件就会产生孤儿页泄露或读出截断载荷。为嵌入式存储后端交付可导入的 Go 页内载荷切分与空闲页管理器。页大小 `U` 可配置（512..65536 的 2 的幂），叶表记录本地最大阈值 `X = U - 35`、最小阈值 `M = ((U - 12) * 32 / 255) - 23`，当载荷长度 `P > X` 时按公式 `K = M + ((P - M) % (U - 4))` 取本地载荷字节数为 `K <= X ? K : M`，其余字节按每溢出页 4 字节下一页号头加 `U - 4` 字节载荷切链写入（尾页下一页号为 0）。空闲页链表按标准树干/叶结构组织：每个树干页首 4 字节指向下一树干页、次 4 字节存本树干挂载的叶页个数 `L`（上限 `(U - 8) / 4`），后续为 `L` 个 4 字节空闲叶页号；分配页时优先弹出当前首树干页的叶页，仅当 `L == 0` 时才把首树干页自身弹出并推进链表头；释放页时若当前首树干页已满，须将新释放页直接提升为新的首树干页。同时校验绝不分配/释放第 1 页元数据头及非法越界页号，并检测循环溢出链与重复释放同一页（Double-Free）。验收覆盖载荷在 `X-1`、`X`、`X+1`、`K == X` 与 `K == X+1` 精准拐点的切分重组、多页溢出链删除回收入空闲链表、树干页满溢升格与耗尽退格、以及全页守恒（已用页 + 树干页 + 叶页 == 总页数无泄露无重用）。
