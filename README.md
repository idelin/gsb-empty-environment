# 纪元回收漏掉休眠读取者

并发策略表用纪元回收旧规则，读取线程在休眠前未正确公布状态会在醒来后解引用已释放规则。给Go插桩宿主实现可导入的纪元回收事件模型与见证搜索包：全局纪元为0至3循环，至多3线程；线程事件为Enter、LoadRoot、Dereference、Exit、Quiescent，更新者事件为ReplaceRoot、Retire和TryAdvance。Enter记录当前全局纪元并置active，LoadRoot取得对象ID及对象代次；只有active时可Dereference。对象Retire记录当时纪元，TryAdvance仅在所有active线程的已公布纪元等于当前全局纪元时把纪元加1模4；对象其retire纪元之后至少发生两个成功推进且期间没有active线程仍持其ID和代次后才能回收。Quiescent仅对inactive线程有效，不能代替Exit；地址复用创建新代次。输入每线程至多8事件但交错未知，搜索合法交错中回收后解引用旧代次的最短见证，等长按线程号排序；另验证待审实现给出的推进/回收决定，指出首个不安全决定。用具体状态穷举对照正确模型，覆盖休眠active线程、连续推进、纪元回绕、地址复用和线程正常退出，不能只用当前数值纪元判断跨了两代。
