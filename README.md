# privacy-export — 声明式数据脱敏与合规导出器

仅使用 Go 标准库实现的数据安全导出转换内核：根据**访问者角色**与**合规级别**，
通过声明式策略（JSON）对敏感字段执行掩码、哈希假名化、差分加噪、区间化与遮蔽。

## 转换原语

| 规则 | 说明 |
|---|---|
| `mask` | 掩码，保留前 N 后 M 位（如手机号 `138****5678`） |
| `pseudonym` | HMAC-SHA256 假名化；单次导出内相同明文映射相同假名（关联一致性），跨导出不可关联 |
| `noise` | 拉普拉斯差分加噪，种子可注入以便复现 |
| `range` | 数值区间化（如薪资 `23500` → `20000-25000`） |
| `redact` | 固定值替换（完全遮蔽） |
| `keep` | 明文保留 |

未在策略中声明的字段**默认不导出**（默认拒绝）；未配置的 (角色, 级别) 组合拒绝导出。

## 内置策略（masking/policy.json）

- `hr_admin / internal`：完整名册，手机号/身份证掩码
- `finance / confidential`：薪资明细可见，手机号保留前3后4，身份证遮蔽
- `contractor / restricted`：姓名/工号假名化，薪资区间化，联系方式遮蔽
- `analyst / statistical`：工号假名化，薪资差分加噪

## 运行

```sh
go run ./cmd/demo   # 演示四种角色对同一员工名册的合规导出
go test ./... -v    # 运行验收测试
```
