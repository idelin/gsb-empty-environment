# gRPC二进制元数据重复项绕过鉴权

服务网格一层把gRPC metadata合并成逗号字符串，鉴权层却按多个值解释，攻击者可用重复`-bin`或伪首部让已签身份与业务看到不同字节。请实现嵌入Go网关的可导入元数据准入中间件，接收HTTP/2解码后的有序name/value字节对。名称必须小写ASCII且符合gRPC规则，`-bin`值逐项用严格无填充或规范填充base64解码，不能把逗号当二进制值分隔符；authorization、grpc-timeout、te及调用方单值安全头拒绝重复，普通多值头保留次序。签名输入按明确字段清单编码名称、值数量和每项长度，验证成功后返回不可变结构，下游只能使用它。禁止连接专用头、伪首部和超预算解码，错误统一。用重复authorization、两个`-bin`与合并值、非法padding、大小写名称、空值和合法多值trace头验证各层看到相同元数据。
