页表回收器准备把物理页交还分配器。清掉 TLB 并不一定有用：先前开始的页表遍历可能在清除之后才把旧映射装回来。写一个可由内存管理器导入的 Go 包，输入是有限个核的访存脚本和一条固定的页表更新及页回收脚本。每个核顺序执行操作，但 miss 可以先取页表项（含未映射结果），再在任意后续时刻完成并装入按 ASID、虚页索引的无容量限制 TLB；最多两笔未完，同核也能乱序完成。hit 直接返回；miss 完成时才返回。上下文切换只改当前 ASID，不清表，未完遍历保留发起时的键。控制核可以在给定脚本间隙插入带成本的组播（同一间隙按编号发出，收齐本条确认才发下一条），每个接收核可在任意两个原子动作间收件：普通收件清指定键并确认；排空式收件先阻止新访存，等匹配的旧遍历全完成再清并确认，不阻止其他核。控制核须收齐后才执行下一动作。脚本显式标注每次物理页重用的代，以及每个访存返回允许看到哪些代或未映射；同一物理页不同代不可混同。找对所有可结束交错均正确的最廉价插入集合（非负整数成本，同价取排序后的候选编号向量字典序最小）。另提供接受任意插入集合的检查器：错误时给出可逐动作重放的最短违规前缀，同长按输入给出的动作全序；不要只返回抽象状态。最多四核、每核十个动作、十八个候选；大例含大量互不相干的页，不能枚举调度历史或用随机压力测试代替证明。用小脚本全交错对拍，覆盖回收无当前缓存却有在途遍历、负缓存、ASID 再用和额外栅栏改变可达前缀。
