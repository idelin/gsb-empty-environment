# railsim

Go 仿真库：列车沿给定路径申请轨段的**半开占用区间**，并提供延误后的精确重规划。

## 模型

- 离散整数时刻，有限时间域（horizon）。
- 轨段占用为半开区间 `[Start, End)`：T 时刻释放的轨段，同刻即可进入。
- 每段轨段占用互斥：任意两车的区间不得重叠（同向也不行）。
- 轨段之间是站点，允许任意时长等待（相邻占用间可有空档）。

## API

- `Table.Reserve(train, segs, ivs)` — 原子全量预约：任一区间冲突则整体拒绝，不留部分预约。
- `Table.Cancel(train)` — 取消全部预约，释放的刻度（含释放同刻）立即可再约。
- `Table.SchedulePath(train, route, dur, ready, horizon)` — 计算最早可行占用（需要时在站点等待）并原子确认。
- `Table.Verify` / `Scan` — 区间扫描核对重叠。
- `Replay` — 逐段占用回放：按时刻模拟进入/退出事件，校验互斥占用与同刻释放后进入。
- `Replan(plans, horizon)` — 延误重规划。每车由 `TrainPlan` 描述：
  已承诺前缀 `Committed`（已进入轨段，不可移动）+ 可调整后缀 `Planned`，
  `ReadyAt` 抬高即表示延误。目标字典序：**最少受改列车数 → 最小总延误**。
  最多四车，精确搜索（枚举全部优先级序的串行调度生成，覆盖正则目标下的最优活跃调度）。
- `BruteForceReplan` — 独立对拍器：枚举可调整后缀的全部合法占用组合，用于核对 `Replan`。
- `EachStartCombo` — 枚举所有合法起点组合，驱动穷举核对。


覆盖：同刻释放后进入、重叠拒绝（含同向）、原子预约、取消、单线交会与站点等待、
已承诺前缀不可移动、连锁冲突（最小受改车数 > 1）、不可行情形，
