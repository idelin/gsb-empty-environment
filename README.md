托管 DNS 迁区时，同一递归解析器可能已经缓存旧转介、却没有缓存旧 glue。给变更控制器写可导入的 Go 时间窗分析包。输入固定的父区端点、至多六个递归查询键及每个权威端点在给定整数时刻原子切换的响应表。这里使用一个明定的解析模型：每个键从父端点开始，响应为终端值（含否定）或下一跳 NS 名；转介入按（当前端点，键）索引的缓存，另可附带按 NS 名索引的地址 glue，两项各有 TTL。命中转介只能复用 NS 名；无有效地址则向固定地址目录查询，目录随时刻给该名唯一端点和 TTL。每次实际取得的转介或目录地址即写相应缓存，glue 即使比现值更早过期也覆盖；终端值按原查询键缓存。解析在同一时刻原子做完，重复访问同端点返回环错，已做的缓存写入仍保留。TTL 半开，零 TTL 仅供本次刚收到的那一步使用。初始全空；每个整数拍最多解析一次，环境可空等或选任一键。指定探测键、禁止终端值及上界 H。求所有可能在 t 开始一次探测就答出该禁止值的 t（0≤t≤H），不是问一次固定访问日志；每个时刻可以有不同预热历史。返回互不相邻的闭整数区间，并能为区间中任给时刻恢复一条含预热查询和空等的可重放证据。H、切换时刻、TTL 都可到 2^45；实现不能按 H 分配或逐空拍扫描。输入另给整段期间含探测在内最多七次查询，允许按键序列、端点响应及有效期关系分支，不能把各条缓存独立取最坏值后组合。用短时窗枚举全部访问作对照；包含转介未过期但地址已漂移、环错留下缓存恰好改变下次答案、以及同一预热拍必须同时满足两个互斥过期条件故差异时窗实际为空。
