预写日志复用旧段文件或发生崩溃撕裂写（Torn Write）时，段尾部常残留上一周期的高 LSN 旧数据、跨页大记录的残缺尾片，或单页中后半段被部分落盘；恢复扫描器若错把旧周期页当合法续写，就会把已回收垃圾当成新事务重放。为 WAL 恢复层交付可导入的 Go 解析与截断包。日志按固定页大小 P（如 4096B）和每段 K 页组织：每页首部含魔数、页号、64 位纪元号 `epoch`（复用段文件时严格递增）与页头 CRC；记录分片含类型（FULL、FIRST、MIDDLE、LAST）、长度、全局递增记录序号与载荷 CRC32（大记录可跨页甚至跨段以 FIRST->MIDDLE*->LAST 拆片，页尾不足最小分片头时补零跳过）。规则：扫描器从起始段和预期纪元顺序读取，遇到以下任一情况必须立即停止并把合法恢复终点精准截断在上一条**完整**记录的结束字节偏移（而非半条 FIRST/MIDDLE 分片末尾！）：页头魔数/CRC 错、页纪元与当前段预期纪元不符（检测循环复用旧页！）、分片类型状态机非法（如未见 FIRST 却出现 MIDDLE/LAST，或 FIRST 后紧跟 FULL/FIRST）、载荷 CRC 错或跨段序号断层。组件返回全部完整无损记录列表、精确截断字节偏移与停止原因分类。验收用字节级故障注入（在每条记录与页边界任意截断/翻转单比特/拼接高序号旧纪元段）对照参考模型，覆盖跨段三片大记录在 LAST 片撕裂回退到 FIRST 之前截断、复用旧段含合法 CRC 但低纪元页被拦截、页尾零填充合法跳过，以及空段合法终止。
