混合专家（MoE）模型在结合 4D 并行与 Ring Attention 长上下文训练时，令牌路由与序列切分存在三类高频隐蔽缺陷：1）Top-K 门控在专家容量封顶（Capacity Factor）触发令牌丢弃（Token Dropping）时，未按规范对被留用令牌的路由权重重归一化，或错把辅助负载均衡损失 `L_aux = alpha * E * sum(f_i * P_i)` 里的 `P_i` 用成丢弃后概率（实际应为丢弃前全序列平均路由概率，而 `f_i` 为实际进入该专家的令牌占比！）；2）Ring Attention 若对因果掩码采用朴素连续切块，Rank 0 算力只有末 Rank 的 `1/(2N)` 导致严重木桶效应，必须采用首尾配对的 Zigzag 负载均衡切分；3）4D 并行 `(DP, PP, CP, TP)` 任意轴序的进程组映射稍有偏差就会把 All-to-All 令牌发错卡。为分布式训练框架交付可嵌入的 C++20 头文件与静态库组件，供训练调度层直接调用实现并行拓扑映射、MoE Top-K 分发/归位规划及 Zigzag Ring Attention 切分核。组件实现：1）可配置轴序的 4D 并行 rank <-> 坐标双向映射与同轴通信组生成；2）MoE Top-K（支持 `k=1,2,4`）确定性选优（同分按最小专家 ID 破平）、容量上限 `ceil(capacity_factor * T * k / E)` 截断（按令牌顺序优先录取并记录精确溢出丢弃位图）、可选保留权重重归一化、生成 All-to-All 发送计数/偏移及反向 Combine 还原张量（被全丢弃令牌输出全零）、精确计算 `L_aux`；3）Zigzag Ring Attention 切分器将 `S` 长度序列均分为 `2 * CP` 块，为第 `r` 号 CP 卡分配对称块对 `(r, 2*CP - 1 - r)`，计算每轮环传 `(step = 0..CP-1)` 中每卡需要计算的局部因果掩码块坐标及准确有效注意力单元数，验证各卡总计算量严格相等。验收覆盖容量溢出丢弃与重归一化、丢弃前后 `f_i`/`P_i` 计算区分、All-to-All 分发再 Combine 逐元素恢复、4D 多轴序双射校验以及 Zigzag 切分下全 CP 卡因果计算量严格均衡。
