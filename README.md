# isel — 基于树模式覆盖的指令选择器

对表达式 **DAG** 做最小成本覆盖（tiling）。模式是可跨多个节点的树，
叶占位符带寄存器类别约束；共享子表达式只计算一次，每次使用付显式复制成本。
输出每个节点的归属（被哪个 tile 覆盖）以及并列最优方案数。C++17。

## 构建与运行

```sh
make            # 构建 ./isel (CLI) 和 ./run_tests (单元测试)
make check      # 运行测试 + 示例
./isel < examples/fusion.txt
```

## 模型

- **DAG**：节点按拓扑序给出（操作数下标小于自身）。被引用多次（含作为输出）
  的节点是**共享节点**。
- **模式**：一棵小树。内部节点按 op 名和元数匹配；叶是占位符 `?c`，
  匹配任意子 DAG，要求其值以寄存器类别 `c` 交付。模式根声明结果类别。
- **复制成本**：`copyCost[from][to]` 表示把值从类别 `from` 移到类别 `to`
  的成本；对角线为 0，缺省为不可行。
- **覆盖成本** = 所有 tile 的模式成本之和
  + 每条占位符边的 `copyCost[生产者类别][占位符要求类别]`。

### 共享子表达式（不当普通树处理）

- 共享节点**只产生一次**，在其最便宜的产生类别 `s*` 中物化；
  **每次使用**付一次显式复制 `copyCost[s*][所需类别]`。
- 因此共享节点必须是 tile 根：匹配模式时，非根的内部节点若引用计数不为 1，
  匹配失败（不能被更大的模式吸收，否则其值会被重复计算或丢失）。
- 总成本 = 各输出的子树成本 + 每个可达共享节点的产生成本（仅一次）
  + 共享输出的交付复制。并列最优计数同样只把共享子树的内部方案数乘入一次。

`s*` 取"生产成本最低"的类别（平局取下标小者），这是一个确定性的显式规则；
复制成本随后按该类别逐边结算。

### DP

`dp[n][r]` = 以类别 `r` 交付节点 `n` 时，其下方区域的最小覆盖成本：

```
dp[n][r] = min over 匹配的模式 p (结果类别 = r):
    cost(p) + Σ 占位符(子节点 c, 要求类别 rc):
        c 为树边   : min_s (dp[c][s] + copyCost[s][rc])
        c 为共享边 : copyCost[s*[c]][rc]        (产生成本全局只计一次)
```

并列最优数 `cnt[n][r]` 与 `dp` 同步维护：取到最小值的模式方案数相加、
子边方案数相乘；共享节点的方案数在全局乘积中只出现一次。
计数在 `kCountCap`（4e18）处饱和。复杂度 `O(N·K·P·|match|)`。

## 输入格式（CLI）

```
classes K                  # 寄存器类别数, 类别编号 0..K-1
copy FROM TO COST          # 可重复; 缺省不可行, 对角线恒 0
node ID OP C1 C2 ...       # ID 从 0 递增; 操作数必须已定义
output NODE CLASS          # 输出及其要求的交付类别, 可多个
pattern ID COST RCLASS (op (op ?0 ?1) ?0)   # 模式树, ?k 为占位符
```

`#` 之后为注释；`nodes/outputs/patterns N` 这类计数行会被忽略。
一元/零元 op 可写 `(const)` 或裸符号 `const`。

输出：`cost`、`solutions`（并列最优数），以及每个节点的归属
（`root pattern=.. class=..` / `internal root=..` / `unused`）。

## 示例

- `examples/fusion.txt` — `add(mul(a,b),c)`：融合 madd 与拆分方案同价 → 2 个并列最优。
- `examples/shared.txt` — `x=a*b` 用两次：成本 8（树式重复计算则为 15）。
- `examples/regclass.txt` — 共享值跨类别：产生一次（类别0），两次使用各付 0→1 复制。

## 文件

- `include/isel/selector.h` — API（`Problem` / `Solution` / `select`）
- `src/selector.cpp` — DP、匹配、计数、归属回溯
- `src/main.cpp` — CLI 驱动
- `tests/tests.cpp` — 单元测试（融合平局、类别复制、共享、不可行等 9 例）

## 限制

- 共享节点的物化类别取生产成本最低者（确定性规则），不与使用点的复制成本
  联合优化；这是模型的一部分，按此规则成本与方案数都是精确的。
- 计数在 4e18 饱和（输出会标注 `saturated`）。
