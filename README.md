# FVS Solver — 带非负删除成本的有向图反馈顶点集精确求解器

## 目标函数（字典序优先级）

1. 最小化总删除成本
2. 平局时最小化删除顶点数
3. 再平局时取顶点 ID 序列（升序）字典序最小者

## 输入格式（stdin 或 `-i 文件`）

```
n m
c0 c1 ... c(n-1)     # 非负整数成本
u v                  # m 行有向边 u -> v，允许自环
```

## 用法

```
go run . -i graph.txt            # 精确求解
go run . -i graph.txt -budget N  # 节点扩展数预算，超限输出上下界
go run . -i graph.txt -time MS   # 时间预算（毫秒）
go run . -i graph.txt -brute     # 附加全子集枚举核对（n<=24）
go test ./...                    # 含随机图对拍测试
```

## 输出

- `status`: `optimal` 或 `budget_exceeded`
- `deleted` / `cost` / `count`: 最优（或当前最好）删除集
- `lower_bound` / `upper_bound`: 最优成本的界；精确完成时两者相等
- `topo_order`: 删除后剩余图的拓扑序，即可行性证书（可用 `VerifyTopoOrder` 校验）

## 算法

精确分支定界：

- 归约：迭代剥离入度/出度为 0 的点（不在任何环上，必不在最优解中）
- 分支：在剩余图中找一条有向环，对环上每个顶点各分一支（自环即单点环，
  强制删除）；按 SCC 整体处理而非假设"一个 SCC 删一点就够"
- 下界：剩余图中贪心打包顶点不相交的环，每环的最小点成本之和
  （环数同时给出删除数下界）
- 剪枝只在成本严格劣、或成本平局且删除数下界严格劣时触发；
  成本与计数均平局的分支继续搜索以保证 ID 字典序最优
- 预算中断：返回当前最优可行解（上界）与所有未探索子树下界的最小值（下界）

正确性由 `BruteForce`（全子集枚举）在随机图（含自环、零成本点、
多个相交环）上对拍验证。
