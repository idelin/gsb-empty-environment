# 权限规则排序器

规则按**首次匹配**生效，只允许**交换相邻规则**。给定 allow/deny 样例，
求满足全部样例的**最少相邻交换次数**，输出新顺序与每条样例的命中规则；
无解时给出**极小冲突样例子集**。规则数上限 15，绝不修改样例。

## 用法

```sh
npm test                              # 运行测试
npm run solve -- examples/solvable.json   # 求解（也可直接 node --experimental-strip-types src/cli.ts <file>）
```

输入 JSON：`{ "rules": [{id, action, pattern}], "samples": [{id, input, expect}] }`。
`pattern` 支持 `*`（任意序列）与 `?`（单字符）通配符。省略文件参数时从 stdin 读取。

## 算法

- 对每条样例，设匹配它的规则集为 M，其中动作符合期望的为 A、不符合为 B。
  首匹配约束 ⇔ **M 中排最前的规则属于 A**。
- 最少相邻交换次数 = 新顺序相对原顺序的**逆序对数**。
- N ≤ 15，用子集 DP（2^N 状态）：逐个放置规则，若规则 r 是某样例 M 中
  第一个被放置的且 r ∈ B，则禁止该转移；转移代价为未放置且原下标小于 r
  的规则数。DP 同时给出最小交换数与新顺序。
- 无解时用迭代删除法求极小冲突子集（MUS）：子集不可满足，但去掉其中
  任意一条即可满足，精确定位互相矛盾的样例。
- 某样例若无任何规则匹配、或所有匹配规则动作全错，则它自身即构成冲突，
  直接报告（调整顺序无法改变）。

## 文件

- `src/solver.ts` — 核心求解器（匹配、DP、冲突分析）
- `src/cli.ts` — 命令行入口
- `tests/solver.test.ts` — 测试（node:test）
- `examples/` — 可解与冲突两个示例
