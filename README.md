# segmented-policy-engine

把**整数时间区间规则**编译为**不重叠判定段**的策略引擎（TypeScript，零依赖，
Node.js ≥ 23.6 原生运行 `.ts`，内置 `node:test` 验证）。

## 能力对照

- **不重叠判定段**：所有规则端点构成切点，段 `[start, end)` 半开、互不重叠；
  `[0,5) allow` 与 `[5,10) deny` 在 `t=5` 命中 `deny`。
- **共享决策结构**：每段持有一条按 `(优先级降序, 版本降序, id 升序)` 排序的决策链，
  查询时沿链**惰性求值**，不做 时间 × 属性 的笛卡尔展开；
  条件节点与决策链均哈希共享（结构相同即同一对象），相邻同源段自动合并。
- **增量插删 + 批量原子**：`applyBatch` 先全量校验、在副本上应用、只重建受影响
  时间范围内的段，全部成功才一次性提交；任一 op 非法整体拒绝。
- **端点改变撤回旧证据**：同 `id` 重新插入视为新版本，旧区间计入脏范围重建，
  报告中列入 `retracted`。
- **来源溯源**：`query` 返回决定结果的来源规则 `source`、命中段、决策链 id
  及该段全部候选规则 `evidence`；相邻同结果但不同来源的段**不合并**，证据各自保留。
- **默认策略**：无任何规则条件命中时返回构造时指定的 `defaultEffect`，`source = null`；
  撤销全部规则后自动恢复默认。
- **受限策略语言**：仅有限整数集合成员（`in`）、整数比较（`cmp`/`between`）与
  布尔运算（`and`/`or`/`not`）；只读查询显式给出的属性，属性缺失视为不命中，
  不接任何外部身份服务。
- **触及记录**：每次批量更新返回 `touchedSegments` 与 `touchedDecisionNodes`，
  范围外的段与决策链对象原样保留（测试断言其 id 不变）。
- **全枚举对照**：`verifyAgainstEnumeration` 在有限时间格 × 有限属性域上逐点
  与朴素逐规则语义比对。

## 运行

```sh
node --version   # 需要 >= 23.6（原生类型擦除）
npm test         # node --test test/engine.test.ts
npm run demo     # node demo.ts
```

## 测试结果（`npm test`）

```
✔ 半开边界：[0,5) allow 与 [5,10) deny，t=5 命中 deny
✔ 撤销规则后恢复默认策略
✔ 相邻同结果不同来源：段不合并，证据各自保留
✔ 相邻同源同结构：段合并且共享同一决策链对象
✔ 批量原子性：任一 op 非法则整体拒绝，状态不变
✔ 端点改变：撤回旧证据，新区间生效，记录触及段与决策节点
✔ 增量更新只触及受影响范围，范围外段与决策节点保持原样
✔ 优先级与条件落穿：高优先级条件不满足时落到下一条，都不中走默认
✔ 条件只读显式属性：属性缺失 => 原子条件为 false，不外查
✔ 非法条件被拒绝：非整数、空集合、未排序集合
✔ 版本替换：同 id 新版本生效，旧版本证据撤回
✔ 同优先级版本高者优先
✔ 有限时间格 × 有限属性域全枚举对照（20×4×5 = 400 点，0 不一致）
ℹ pass 13 / fail 0
```

## 结构

- `src/conditions.ts` — 受限条件语言：校验、规范化序列化、哈希共享池、求值
- `src/engine.ts` — 段编译、决策链共享、增量批量原子更新、查询溯源
- `src/verify.ts` — 有限时间格 × 属性域全枚举对照器
- `test/engine.test.ts` — Node 内置测试（13 例）
- `demo.ts` — 运行样例
