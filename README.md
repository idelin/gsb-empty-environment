# affine

保留变量依赖的仿射算术（affine arithmetic）区间计算库。

每个量表示为 `c + Σ aᵢ·eᵢ`，其中 `eᵢ ∈ [-1,1]` 是噪声符号。
输入变量共享符号，因此同一变量出现两次不会被当作独立输入：
`x - x` 精确等于 0，共享子式 `s - s` 也精确抵消。

## 特性

- **加减乘**：线性运算精确合并同类符号；乘法的非线性余项
  `(Σ|aᵢ|)(Σ|bⱼ|)` 以保守的新余项符号包围。
- **余项预算**：`NewEnv(maxRemainder)` 限制每个形式携带的非线性
  余项符号数，超限后按 `|a|+|b|` 保守合并，保证结果仍然可靠。
- **除法**：除数区间跨零时返回 `ErrZeroDivisor` 明确拒绝；
  `SplitDomain` 可给出零点两侧的分段定义域。`Recip` 使用
  斜率 `-1/(lo·hi)` 的仿射逼近加保守余项。
- **可检查证书**：`Form.Certify()` 输出上下界证书；
  `Check` 用精确有理数（`big.Rat`）独立验证——先按独立区间
  规则重算半径，再在小有理网格 `{-1,-1/2,0,1/2,1}` 上逐点求值。
  `Range` 采用向外舍入，保证证书可被精确复算确认。

## 示例

```go
env := affine.NewEnv(4)   // 最多 4 个余项符号
x := env.Var()            // [-1, 1]
y := env.Var()

d := x.Sub(x)             // 精确 [0, 0]
_ = d

q, err := x.Div(y.Shift(2)) // y+2 ∈ [1,3]，可除
if err != nil { /* ErrZeroDivisor: 除数跨零 */ }

cert := q.Certify()
if err := affine.Check(cert); err != nil { /* 证书无效 */ }
lo, hi := q.Range()
```
