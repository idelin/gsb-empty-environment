# 重复JSON键让WAF和应用看到不同角色

API网关的WAF按首个`role`值放行，下游框架按最后一个值取到`admin`，攻击者用重复键绕过鉴权。请实现嵌入TypeScript网关的可导入请求规范化与准入组件。原始JSON只解析一次，产生带字节区间的规范结构与重复键清单；`role`、`tenantId`、`scope`等鉴权键出现重复即拒绝，其余重复键按声明策略折叠且折叠结果与签名摘要一致。规范化输出同时供WAF与路由使用，下游不得再解析原始体；数字精度、`\u`转义、代理对和嵌套深度按同一规则处理。用首尾不同值、嵌套重复、转义同名键、大小写键、超深嵌套和合法单值请求验证两层决策一致。
