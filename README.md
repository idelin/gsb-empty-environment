# 常量折叠优化器（保序、保错、可溯源）

TypeScript 实现的表达式常量折叠优化器。处理常量、变量、短路逻辑
（`&&` / `||` / `?:`）以及可能抛错的除法，并保证优化前后**可观察行为
完全一致**：相同的值、相同的首个错误（含出错节点 ID）、相同的变量访问序列。

## 语言语义

- 值：`number | boolean`；`false` 与 `0` 为假，其余为真。
- 算术 `+ - * /`：布尔强制转为 0/1；**除以零抛出 `DivByZero` 错误**，
  首个错误即终止求值。算术无短路：左右操作数总是从左到右求值。
- `&&` / `||`：JS 风格短路，返回操作数本身。
- `c ? a : b`：只求值被选中的分支。

## 可观察行为与稳定 ID

- 每个源 AST 节点在解析时分配**稳定 ID**（`#1, #2, ...`），优化前后不变。
- 可观察操作 = 变量读取（记录 ID、名称、值）与 `DivByZero` 错误（记录节点 ID）。
- 纯常量运算无可观察效果，因此可以在编译期折叠。

## 优化规则（`src/fold.ts`）

1. 常量子树折叠为常量；常量除零折叠为 `error` 节点——**留在原位置**，
   求值到它才抛错，ID 即原除法节点 ID，从而保留求值顺序与首个错误。
2. 短路折叠：`false && e → false`、`true && e → e`、`true || e → true`、
   `false || e → e`。被跳过的子树在原语义下也绝不会执行，删除安全。
3. 条件折叠：条件为常量时只保留会执行的分支；未执行分支（含其中错误）
   整体删除，不会提前报错。
4. 不做任何会删除变量读取或改变值类型的化简（`0 * x`、`x + 0` 等一律保留）。

每个优化后节点带 `src` 字段：来源对应（该节点由哪些源节点折叠而来），
`node src/main.ts` 会打印优化树及 `← src [...]` 标注。

## 验证（`src/verify.ts` + `src/fuzz.ts`）

- 对每变量取域 `{0, 1, 2, false, true}` 做**穷举小环境**（笛卡尔积），
  逐环境比较原表达式与优化后表达式的值、首个错误、变量访问序列。
- 34 个手工用例覆盖：零除（纯常量 / 变量前后 / 动态 / 首个错误选择）、
  重复子表达式（每次出现独立 ID 独立求值）、条件已知但分支含错误、
  算术无短路（`0 * (1/0)` 仍报错）、短路死分支不报错等。
- 另有 3000 个种子可复现的随机表达式做模糊验证。

## 运行

需要 Node ≥ 23.6（原生类型擦除；或 ≥ 22.6 加 `--experimental-strip-types`）：

```sh
node src/main.ts
```
