# bitemp — 双时态事实库

每条事实是两个维度上的一个矩形：

- **业务有效区间** `[From, To)`（半开区间）
- **入库序号** `Seq`（自 `Seq` 起生效，单调递增）

更正是与过去重叠、序号更高的新矩形；删除是带有效区间的墓碑矩形。
查询是二维点查询 `(t, asOf)`：在所有覆盖该点的矩形中取 `Seq` 最大者，
墓碑胜出即"无事实"。可见性被 `asOf` 截断，因此后来的更正永远不会
泄漏到旧的知晓快照。

## 实现

- `bitemp/store.go` — 区间切分实现：每个 key 的时间线被所有事实边界
  切成互不重叠的段，段上挂按 `Seq` 升序的版本链；查询 = 段二分 +
  版本链按 `asOf` 回溯二分。
- `bitemp/model.go` — 核对基准：保留全部矩形，暴力扫描回答点查询。
- `bitemp/store_test.go` — 更正/快照隔离、重叠取最大序号、删除区间、
  切分不变量等确定性用例。
- `bitemp/model_test.go` — 随机操作流下，对 (业务时间 × 已知序号)
  全网格逐点比对 Store 与 Model，含中途快照以验证回溯。
