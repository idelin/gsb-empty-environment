# Peritext/Fugue 风格富文本格式标注 CRDT（TypeScript）

富文本粗体、斜体、下划线、超链接等**可重叠格式标注**的 CRDT 合并器。
解决多人并发在同一字符区间添加/取消冲突样式时的合并与边界因果判定问题。

## 设计

**文本层 — RGA**：每个字符有全局唯一 ID 与 Lamport 时间戳，插入操作记录
前驱字符 ID；并发插入按 `(lamport, id)` 全序归并，所有副本收敛到同一字符顺序。

**格式层 — Peritext 风格锚定区间**：

- 格式标注表示为锚定区间 `Mark { type, start, end }`，边界锚定到**字符 ID**
  而非数组下标，并发插入不会移动语义边界。
- 边界是 RGA 树中的"虚拟节点"：锚定在某字符之后，并携带创建该标注操作的
  `(lamport, opId)` 作为排序键。标注创建**之后**插入到边界处的字符
  （lamport 更大）排在边界之前、落入区间内；创建时**已存在**的字符排在
  边界之后、落在区间外。由此得到 Peritext 边界语义：
  **区间末尾插入继承格式，区间开头插入不继承**。
- `removeMark(type, from, to)` = 删除所有与之重叠的标注 + 为范围外的左右
  剩余片段补发新标注（外侧边界复用原边界，保持原有扩张行为）。
- **边界因果判定**：删除操作按 `markId` 因果引用发起者已见过的标注，
  并发的 `addMark` 不受影响（add-wins）。例如初始 `ABC` 已加粗，
  用户1 取消 `AB` 加粗、用户2 并发给 `BC` 再加粗：合并后 `A` 无格式、
  `B`/`C` 保持加粗——用户1 的删除只作用于它因果上见过的旧标注。
- 所有操作可交换、幂等（tombstone 防止被删标注复活），副本间交换操作
  日志即可收敛，与合并顺序、重复次数无关。

## 目录结构

- `src/richtext.ts` — CRDT 核心实现（`RichTextDoc`）
- `src/index.ts` — 导出入口
- `test/richtext.test.ts` — Node.js 内置测试（`node:test`）
- `examples/demo.ts` — 运行样例

## 运行

需要 Node.js ≥ 22.6（利用原生 TypeScript 类型擦除直接运行 `.ts`，无需构建）。

```bash
npm test    # node --test "test/**/*.test.ts"
npm run demo
```

## 运行样例输出

```
场景 1：用户1 给 AB 加粗，用户2 并发给 BC 加下划线

== 合并结果 ==
  A  →  bold
  B  →  bold + underline
  C  →  underline
  标注区间: bold[0,2)  underline[1,3)
  两副本收敛一致: true

场景 2：初始 ABC 全部加粗；用户1 取消 AB 加粗，用户2 并发给 BC 再加粗

== 合并结果（因果判定：并发新增标注胜出，A 不再加粗，B/C 保持加粗） ==
  A  →  (无格式)
  B  →  bold
  C  →  bold
  标注区间: bold[1,3)  bold[2,3)
  两副本收敛一致: true
```
