# 二维排料求解器（C++17）

整数网格板材（含缺陷矩形）上放置可旋转的轴对齐多边形零件，保留固定刀缝，
求总价值最大的零件子集（≤ 12 件），并附带完整可行性验证器。

## 编译

```sh
g++ -std=c++17 -O2 -o nesting nesting.cpp
```

## 输入格式（input.txt）

```
W H kerf          # 板材宽、高、刀缝（整数）
D                 # 缺陷矩形数量
x1 y1 x2 y2       # 每行一个缺陷矩形
N                 # 零件数量（≤ 12）
id value nv       # 零件 id、价值、顶点数
x y               # nv 行顶点，边须轴对齐的简单多边形（可为凹形），顺序环绕
```

## 用法

```sh
./nesting solve sample.txt solution.txt   # 求解并输出解
./nesting verify sample.txt solution.txt  # 独立验证解的可行性
```

解文件格式：第一行 `总价值 件数`，随后每行 `id rot x y`
（rot 为 0..3 的旋转编号，对应输入多边形顺时针旋转 0/90/180/270 度）。

## 约束语义

- 零件完整位于板材内（板边缘不要求刀缝）。
- 任意两零件、零件与缺陷之间的距离 ≥ kerf（恰好等于 kerf 合法）。

## 精确碰撞检测（非包围盒）

- 每个零件多边形经扫描线**精确分解为不重叠矩形集合**（整数坐标，无近似）。
- 零件 vs 缺陷：缺陷矩形膨胀 kerf 后与零件的分解矩形做严格相交测试。
- 零件 vs 零件：一方分解矩形膨胀 kerf 后与另一方分解矩形做严格相交测试。
- 凹多边形凹口中的缺陷不会被误判（包围盒法会误判），真实碰撞也不会漏判。

## 求解算法

- 按价值降序的分支限界；上界 = 当前价值 + 剩余零件价值后缀和。
- 候选位置采用法线模式（normal patterns）：x/y 取自 {0} ∪
  {已放零件、缺陷的右/上边缘 + kerf}，对矩形零件该类位置中必含最优解。
- 旋转去重：对称零件的重复形态只搜索一次。

## 文件

- `nesting.cpp`：求解器 + 验证器（单文件）
- `sample.txt` / `solution.txt`：样例（8 件，含两个 L 形凹零件与两个缺陷）
- `notch.txt` / `notch_good.txt` / `notch_bad.txt`：凹口精确检测的演示用例
