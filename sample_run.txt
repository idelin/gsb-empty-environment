样例1：A=[0,2] 必然先于 B=[3,4]；A 与 C=[2,3] 在时刻2相接 → 不可比较
------------------------------------------------------------------------
事件：A, B, C
确定顺序层（层内互不可比较，层间为必然先后）：
  L0: {A, C}
  L1: {B}
必然先后（紧凑表示 = 传递归约）：
  A ≺ B  (保证间隔 ≥ 1)
      证据链: iA → iB
全部必然关系（传递闭包）：
  A ≺ B (≥1)
不可比较组（成对列出；不可比较不具传递性，非等价类）：
  A ∥ C
  B ∥ C
可行时间见证(tick): A=0, B=3, C=2
枚举核验: 可行赋时 12 个（已穷尽），与闭包判定一致 ✓

样例4：P∈[5,9]、Q∈[0,2] 却有因果边 P≺Q → 矛盾环
------------------------------------------------------------------------
事件：P, Q
结论：不可行（检测到矛盾环）
  矛盾环 含区间界 总间隔 4: P → Q → 0 ↺
      证据: [ePQ] 因果边 P ≺ Q（t_Q - t_P ≥ 1）
      证据: [iQ] 区间约束 Q ∈ [0, 2]（闭区间，整数 tick） （high界）
      证据: [iP] 区间约束 P ∈ [5, 9]（闭区间，整数 tick） （low界）

更正 iP 为 P∈[0,1] 后：
事件：P, Q
确定顺序层（层内互不可比较，层间为必然先后）：
  L0: {P}
  L1: {Q}
必然先后（紧凑表示 = 传递归约）：
  P ≺ Q  (保证间隔 ≥ 1)
      证据链: ePQ
全部必然关系（传递闭包）：
  P ≺ Q (≥1)
不可比较组（成对列出；不可比较不具传递性，非等价类）：
  （无）
可行时间见证(tick): P=0, Q=1
枚举核验: 可行赋时 3 个（已穷尽），与闭包判定一致 ✓

样例6：墙钟时间 / 时间点 / 持续时长 的精确区分
------------------------------------------------------------------------
第3拍 = 180 ticks = 墙钟 2026-09-26T00:03:00+00:00
第5拍 = 240 ticks = 墙钟 2026-09-26T00:04:00+00:00
持续时长 delta = 60 ticks = 1m
点坐标反算: p1=5 拍, p0=3 拍（偏移90s 是点坐标的基准）
时长只按零偏移单位换算: 60 ticks = 1m，不拿带偏移的“拍”度量时长
类型不可混: TimePoint+TimePoint 未定义；点-点=Duration，点+Duration=TimePoint
已验证: TimePoint + TimePoint 抛出 TypeError
