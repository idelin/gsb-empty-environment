# archiveaudit — 归档抽样审计工具

按块逻辑长度加权、无放回地从归档中抽样，验证抽中块的摘要。
归档为 JSON 格式，自带每个块的 SHA-256 摘要与逻辑长度。

## 用法

```sh
go build -o archiveaudit .

# 生成演示归档（自带块摘要）
./archiveaudit create -out demo.arc -blocks 10 -maxlen 3000

# 抽样审计：输出完整抽样过程与逐块验证结果
./archiveaudit audit -archive demo.arc -seed "auditor-2026-10-04" -n 3

# 小归档：枚举全部随机域，核对抽样概率与理论值一致
./archiveaudit enumcheck -archive small.arc
```

## 设计要点

- **加权无放回抽样**：每抽在剩余块总权重 W 上均匀取值 r，按累积权重区间定位
  命中块（概率严格正比于逻辑长度），命中后即从候选集移除。
- **可复现**：随机字节流由调用方种子经 SHA-256 计数器模式派生，不依赖
  标准库 PRNG，跨 Go 版本、跨平台结果一致。
- **恢复不改已选块**：k 次抽样是 k+m 次抽样的严格前缀，中断恢复或追加
  抽样时，已选中的块不会被改变。
- **大整数、无取模偏差**：总逻辑长度用 `math/big.Int` 计算（可远超 64 位），
  随机取值采用拒绝采样，候选值越界即丢弃重抽，分布严格均匀。
- **随机域枚举核对**：小归档（总权重不超过上限）枚举第一抽全部随机域
  [0, W)，验证每块命中次数恰等于其权重；更小时枚举两抽，验证有序对
  (i,j) 命中次数恰等于 w_i·w_j。枚举与真实抽样共用同一段定位逻辑。
- **结论措辞**：抽样通过仅说明被抽中的块摘要匹配，**不代表全文件完整**；
  仅当抽样数等于块总数（全覆盖）时才下各块完整的结论。
