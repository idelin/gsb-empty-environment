# 鲁棒仓位分配求解器

## 第一部分：揭晓前固定的鲁棒分配（`part1.go`）

10 件物品分入 3 个仓位，4 个等权场景各给出一套物品体积。分配在场景揭晓前
固定，必须在**每个**场景下满足仓位容量（不能按场景分别分配）。
费用 = 物品体积 × 仓位费率。目标按字典序：

1. 最小化最坏场景费用；
2. 最小化平均场景费用（等权，即费用和）。

求解器为分支定界（下界 = 已产生费用 + 剩余物品 × 最低费率）。
核对：三进制枚举全部 3^10 = 59049 个分配，比较最优值（最坏, 费用和）。
输出逐场景容量证据（各仓位负载 vs 容量），并给出"若违规按场景分别分配"
的单场景最优作为不可行下界参考。

## 第二部分：部分观测后一次搬仓的两阶段策略（`part2.go`）

6 件物品、3 个仓位、3 个等权场景。第一阶段分配在揭晓前固定；随后观测到
物品 1-3 的真实体积，**观测分组** = 已观测体积完全相同的场景归为一组
（T1/T2 同组，T3 独立成组）。每个分组允许一次搬仓：

- 共享上限：最多搬动 2 件、搬仓费用预算 7；
- 同一分组内的场景（未观测部分不同）必须采取**同一**搬仓动作；
- 容量约束在场景完全揭晓后对搬仓后的分配生效。

场景总成本 = 搬仓后仓位费率费用 + 搬仓费用。目标：最小化最坏场景总成本
（平局取费用和最小）。给定第一阶段分配后各分组独立优化，策略最坏值 =
各分组最坏值的最大。输出各分支分配与容量轨迹（阶段一负载 → 搬仓后负载）。
核对：小实例全策略枚举（第一阶段 × 各分组搬仓动作的笛卡尔积，共
181728 个策略），最优值一致。另输出"禁止搬仓"的固定鲁棒基准作对比
（本实例 85 → 75）。

## 运行

```sh
GO111MODULE=on go run .
```

`cmd/search` 为一次性辅助程序：随机搜索"两阶段严格优于固定分配且最优
策略使用搬仓"的场景矩阵，第二部分实例即由其筛出。
